# Beyond STEP

*Past STEP questions as a doorway to university mathematics* — a book in progress by Keith McNulty.

Each section takes one STEP question, works through it in guided stages, and then looks at the undergraduate mathematics behind it, with follow-up problems and reading suitable for a first-year student.

**Read it online:** https://beyondstep.keithmcnulty.org/

This repository is a public mirror of completed chapters. The website lives in [`docs/`](docs/) and is generated from the book's LaTeX source. Every section has a printable worksheet, and every chapter can be downloaded as a typeset PDF.
