Chapter 2 · Sequences, Series and Convergence

Answers to Try This Next

These are brief answers and hints, not full solutions: they give the result and the key step, so that you can check your own work. Try each exercise properly before looking.

2.1"Eventually" Means

  1. All terms of \((1 + x)^n = 1 + nx + \binom n2x^2 + \cdots\) are non-negative, so \((1 + x)^n \geq 1 + nx > nx\). With \(y = 1 + x\), \(y^n > n(y - 1) > K\) once \(n > K/(y - 1)\). Using the next term, \(y^n > \binom n2(y - 1)^2\), so \(y^n/n > \frac12(n - 1)(y - 1)^2 > K\) once \(n > 1 + 2K/(y - 1)^2\).

  2. If \(s_n \leq t_n\) for \(n \geq m_1\) and \(t_n \leq s_n\) for \(n \geq m_2\), then \(s_n = t_n\) for \(n \geq \max(m_1, m_2)\).

  3. For example \(s_n = n + 0.6\) for even \(n\) and \(s_n = n\) for odd \(n\), and \(t_n = n + 0.6\) for odd \(n\) and \(t_n = n\) for even \(n\). Both increase, and each exceeds the other infinitely often.

  4. \(2^n \leq n!\) for \(n \geq 4\) (induction: \(2^{n+1} = 2 \cdot 2^n \leq (n + 1)\,n!\)). For \(n^{10} \leq 2^n\), the inequality fails for every \(n\) from \(2\) to \(58\) and holds for all \(n \geq 59\), so the smallest \(m\) is \(59\).

2.2Golden Ratio as a Limit

  1. Induction: \(u_1 = 1 = F_2/F_1\), and if \(u_n = F_{n+1}/F_n\) then \(u_{n+1} = 1 + F_n/F_{n+1} = F_{n+2}/F_{n+1}\).

  2. Since \(\varphi - 1 = 1/\varphi\), \(u_{n+1} - \varphi = \frac{1}{u_n} - \frac1\varphi = -\frac{u_n - \varphi}{\varphi u_n}\). With \(u_n \geq 1\), \(|u_{n+1} - \varphi| \leq |u_n - \varphi|/\varphi\), and \(|u_1 - \varphi| < 1\), so \(|u_n - \varphi| \leq \varphi^{-(n-1)}\).

  3. \(\psi = \frac{1 - \sqrt5}{2}\) satisfies \(\psi^2 = \psi + 1\), so \(1 + 1/\psi = \psi\). Working backwards, \(u_{n-1} = \frac{1}{u_n - 1}\): from \(0\) we get \(-1, -\frac12, -\frac23, -\frac35, -\frac58, \ldots\), that is, \(u_1 = -F_{k-1}/F_k\) for some \(k \geq 1\). These values approach \(\psi\).

  4. The fixed point satisfies \(v = 1 + \frac{1}{1 + v}\), i.e. \(v^2 = 2\). The error is multiplied by \(-\frac{1}{(1 + v_n)(1 + \sqrt2)}\), of size at most \(\frac{1}{2(1 + \sqrt2)}\), so \(v_n \to \sqrt2\). And \(\sqrt2 = 1 + \cfrac{1}{2 + \cfrac{1}{2 + \cdots}}\).

2.3Divergent Series and Its Convergent Cousin

  1. \(\ln N + 0.5772 = 10\) gives \(N \approx 12\,400\); passing \(100\) needs about \(e^{99.4} \approx 1.5 \times 10^{43}\) terms.

  2. With \(k = 2\), block \(n\) is at most \(2^n \cdot 4^{-n} = 2^{-n}\), so the sum is at most \(\sum_{n \geq 0}2^{-n} = 2\). Adding \(1 + \frac14 + \frac19\) exactly and bounding the blocks from \(r = 4\) by \(\frac14 + \frac18 + \cdots = \frac12\) gives about \(1.86\). (The true value is \(\frac{\pi^2}{6} \approx 1.645\).)

  3. For \(1/(r\ln r)\) the block from \(2^n\) to \(2^{n+1} - 1\) is at least \(\frac{2^n}{2^{n+1}(n + 1)\ln 2} = \frac{1}{2(n + 1)\ln2}\), and these sum like the harmonic series: divergence. For \(1/(r(\ln r)^2)\) the block is at most \(\frac{1}{n^2(\ln2)^2}\), and \(\sum\frac{1}{n^2}\) converges.

  4. Allowed digits: \(7\) choices for the leading digit and \(8\) for each other digit, so there are at most \(7 \cdot 8^{d-1}\) allowed \(d\)-digit numbers, each at least \(10^{d-1}\). The sum is at most \(\sum_{d \geq 1}7(0.8)^{d-1} = \frac{7}{1 - 0.8} = 35\).

2.4 \(\pi^2/6\)

  1. The numbers \(\tan^2 = 1/\cot^2\) are the roots of the reversed polynomial \(\sum_j(-1)^j\binom{2n+1}{2j+1}y^j\), whose roots add to \(\binom{2n+1}{2n-1} = n(2n + 1)\). Then \(\mathrm{cosec}^2 = 1 + \cot^2\) gives \(n + \frac{n(2n - 1)}{3} = \frac{2n(n + 1)}{3}\).

  2. The even terms add to \(\frac14\sum\frac{1}{m^2} = \frac{\pi^2}{24}\), so the odd terms add to \(\frac{\pi^2}{6} - \frac{\pi^2}{24} = \frac{\pi^2}{8}\).

  3. The roots have \(e_1 = \frac{n(2n - 1)}{3}\) and \(e_2 = \binom{2n+1}{5}\big/\binom{2n+1}{1}\), giving \(\sum\cot^4 = e_1^2 - 2e_2 = \frac{n(2n - 1)(4n^2 + 10n - 9)}{45}\). Squeezing with \(\cot^4\theta < \theta^{-4} < (1 + \cot^2\theta)^2\) and letting \(n \to \infty\) gives \(\frac{\pi^4}{90}\).

  4. The lower bound gives \(\sum_{m \leq n}\frac{1}{m^2} > \frac{\pi^2n(2n - 1)}{3(2n + 1)^2}\), so the error is less than \(\frac{\pi^2(6n + 1)}{6(2n + 1)^2} < \frac{\pi^2}{4n}\). This guarantees accuracy \(0.001\) for \(n \geq 2468\); in fact \(n \approx 1000\) suffices.

2.5’s Product

  1. Repeatedly use \(\sin\theta = 2\sin\frac\theta2\cos\frac\theta2\): the product telescopes. Let \(n \to \infty\) (so \(2^n\sin(\alpha/2^n) \to \alpha\)) and take \(\alpha = \frac\pi2\), using \(\cos\frac\pi4 = \sqrt{\frac12}\) and \(\cos\frac\theta2 = \sqrt{\frac12 + \frac12\cos\theta}\).

  2. \(\frac{\sin(\pi/3)}{\pi/3} = \frac{3\sqrt3}{2\pi} = \cos\frac\pi6\cos\frac\pi{12}\cos\frac\pi{24}\cdots\), with \(\cos\frac\pi6 = \frac{\sqrt3}{2}\) and \(\cos\frac{\pi}{12} = \frac{\sqrt{2 + \sqrt3}}{2} = \frac{\sqrt6 + \sqrt2}{4}\).

  3. \(8\) factors give \(3.14157\), which rounds to \(3.1416\). After \(n\) factors the error is about \(\frac{\pi^3}{6 \cdot 4^{n+1}}\), because the omitted factors are \(\cos\frac{\pi}{2^{j+1}} \approx 1 - \frac{\pi^2}{2 \cdot 4^{j+1}}\): each factor divides the error by about \(4\), and \(\log_{10}4 \approx 0.6\).

  4. With \(x = \ln a\), the same argument gives\[\frac{a - 1}{\ln a} = \prod_{j \geq 1}\frac{1 + a^{1/2^j}}{2},\]so \(\frac{1}{\ln3} = \frac12\prod_{j \geq 1}\frac{1 + 3^{1/2^j}}{2}\). Seven factors give \(0.906\), which rounds to \(0.91\) (the true value is \(0.9102\)). Here the factors approach \(1\) like \(1 + \frac{\ln3}{2^{j+1}}\), so each new factor only halves the error (about \(0.3\) of a digit), whereas Viète’s factors approach \(1\) like \(1 - \frac{\pi^2}{2 \cdot 4^{j+1}}\) and quarter it.

2.6Arithmetic–Geometric Mean

  1. \(x_{n+1} - y_{n+1} = \frac12(\sqrt{x_n} - \sqrt{y_n})^2 = \frac{(x_n - y_n)^2}{2(\sqrt{x_n} + \sqrt{y_n})^2}\), and \((\sqrt{x_n} + \sqrt{y_n})^2 \geq 4y_n \geq 4y_0\).

  2. \(M(2, 1) = 1.456791\); after three steps \(x_3\) and \(y_3\) already agree to seven decimal places.

  3. Every step of the iteration scales by \(\lambda\), so \(M(\lambda x, \lambda y) = \lambda M(x, y)\). Substituting \(x = \lambda u\) in the integral gives \(\mathrm{I}(\lambda p, \lambda q) = \lambda^{-1}\mathrm{I}(p, q)\). Both sides of \(\mathrm{I} = \frac{\pi}{2M}\) scale by \(\lambda^{-1}\).

  4. \(M(1, \cos 30^\circ) \approx 0.9318\), so the period is longer by a factor \(1.073\): about \(7.32\%\).

2.7Digits or Six Hundred

  1. \((p^2 + 2q^2)^2 - 2(2pq)^2 = (p^2 - 2q^2)^2 = 1\); and \(577^2 - 2 \times 408^2 = 332\,929 - 332\,928 = 1\).

  2. \(y_{n+1} = \frac{2y_n^3 + 2}{3y_n^2}\), and \(y_{n+1} - \alpha = \frac{2y^3 - 3\alpha y^2 + \alpha^3}{3y^2} = \frac{(y - \alpha)^2(2y + \alpha)}{3y^2}\). If \(y > \alpha\), \(\frac{2y + \alpha}{3y^2} < \frac{3y}{3y^2} = \frac1y < \frac1\alpha\).

  3. \(y - \frac{1/y - a}{-1/y^2} = y + y - ay^2 = y(2 - ay)\), and \(1 - ay(2 - ay) = (1 - ay)^2\).

  4. \(y - \frac{y^{1/3}}{\frac13y^{-2/3}} = y - 3y = -2y\). The error formula needs \(\mathrm{f}'\) to be non-zero and \(\mathrm{f}''\) bounded near the root; here \(\mathrm{f}'\) is infinite at \(0\).

2.8and Subtracting Two

  1. \((2\cos u)^2 - 2 = 2\cos2u\), so induction gives \(x_n = 2\cos(2^{n-1}\theta)\). \(x_3 = a\) needs \(4\theta \equiv \pm\theta\): \(3\theta\) or \(5\theta \equiv 0 \pmod{2\pi}\). The cases with \(x_2 = a\) (fixed points \(a = 2\) and \(a = -1\)) are excluded, leaving \(\theta = \frac{2\pi}{5}, \frac{4\pi}{5}\): \(a = \frac{\sqrt5 - 1}{2}\) or \(a = -\frac{\sqrt5 + 1}{2}\), the two points of a \(2\)-cycle.

  2. For \(M_5\) the sequence is \(4\), \(14\), \(194 \equiv 8\), \(62 \equiv 0\): prime. For \(M_{11}\) it is \(4\), \(14\), \(194\), \(788\), \(701\), \(119\), \(1877\), \(240\), \(282\), \(1736 \neq 0\): composite, and indeed \(2047 = 23 \times 89\).

  3. \(A = t - \frac1t = \frac32\) gives \(t = 2\) and \(a = \frac52\). Then \(x_2 = \frac{17}{4}\), \(y_1 = \frac{Ax_1}{x_2} = \frac{15}{17}\), and \(\frac{\sqrt{x_2^2 - 4}}{x_2} = \frac{15/4}{17/4} = \frac{15}{17}\).

  4. \(x_k = t^{2^{k-1}} + t^{-2^{k-1}}\), and multiplying \(x_1\cdots x_n\) by \(t - t^{-1}\) telescopes to \(t^{2^n} - t^{-2^n}\). The sum becomes \((t - t^{-1})\sum_{n \geq 1}\bigl(\frac{1}{t^{2^n} - 1} - \frac{1}{t^{2^{n+1}} - 1}\bigr) = \frac{t - t^{-1}}{t^2 - 1} = \frac1t\). For \(a = 3\), \(t = \frac{3 + \sqrt5}{2}\) and \(\frac1t \approx 0.3820\); the series \(\frac13 + \frac1{21} + \frac{1}{987} + \cdots\) agrees.

2.9That Close In on e

  1. \(T_0 = e - 1\), \(T_1 = 3 - e\), \(T_2 = 7e - 19\), \(T_3 = 193 - 71e\), \(T_4 = 1001e - 2721\), giving \(\frac{19}{7}\), \(\frac{193}{71}\), \(\frac{2721}{1001}\). Since \(b_n = b_{n-2} - 2(2n - 1)b_{n-1}\) and (inductively) \(b_{n-1}\) has the opposite sign to \(b_{n-2}\), \(b_n\) has the sign of \(b_{n-2}\).

  2. \(t(1 - t) \leq \frac14\), so \(T_n < \frac{e}{4^nn!}\); the error in \(-a_n/b_n\) is \(T_n/|b_n|\), now improved by a factor \(4^n\).

  3. If \(e = \frac pq\), then \(qT_n = qa_n + pb_n\) is an integer. \(T_n > 0\) makes it a positive integer, so at least \(1\); but \(qT_n < \frac{qe}{n!} < 1\) for large \(n\).

  4. Integrating by parts twice (the boundary terms vanish), \(U_n = \frac14\bigl(U_{n-2} - 2(2n - 1)U_{n-1}\bigr)\), with \(U_0 = \frac{e^2 - 1}{2}\) and \(U_1 = \frac12\). So \(2^{2n+1}U_n = A_n + B_ne^2\) with integers \(A_n\), \(B_n\), while \(0 < U_n < \frac{e^2}{4^nn!}\). If \(e^2 = \frac pq\), then \(q2^{2n+1}U_n\) is a positive integer less than \(\frac{2qe^2}{n!}\), impossible for large \(n\). So the argument does prove that \(e^2\) is irrational.
