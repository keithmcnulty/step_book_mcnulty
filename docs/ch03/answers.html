Chapter 3 · Functions, Inequalities and Rigour

Answers to Try This Next

These are brief answers and hints, not full solutions: they give the result and the key step, so that you can check your own work. Try each exercise properly before looking.

3.1the Flaw

  1. As \(x\) runs from \(-1\) to \(1\) it passes through \(0\), where \(t = 1/x\) is undefined: the substitution is not continuous on the interval. Correctly, \(\int_{-1}^1\frac{\mathrm{d}x}{(1 + x^2)^2} = \frac12 + \frac\pi4\) (use \(x = \tan\theta\)), while \(\int_{-1}^1\frac{-t^2}{(1 + t^2)^2}\,\mathrm{d}t = \frac12 - \frac\pi4\).

  2. (a) True: both sides have logarithm \(\ln a\ln b\). (b) False: at \(\theta = 0\), \(\cos0 = 1 \neq \sin1\). (In fact they are never equal, since \(|\sin\theta \pm \cos\theta| \leq \sqrt2 < \frac\pi2\).) (c) False: a non-constant polynomial is unbounded, and a constant cannot be within \(10^{-6}\) of both \(1\) and \(-1\). (d) True: \(x^4 + x^{-4} \geq 2\) by AM–GM, with equality at \(x = 1\).

  3. The step from \(n = 1\) to \(n = 2\) fails: the “first \(1\)” and “last \(1\)” of two horses do not overlap.

  4. \(\int_\varepsilon^1x^{-1/2}\,\mathrm{d}x = 2 - 2\sqrt\varepsilon \to 2\), so by symmetry the integral exists (as a limit) and equals \(4\).

3.2–GM, Backwards

  1. If \(a_1, \ldots, a_{n-1}\) have mean \(A\) and geometric mean \(G\), add \(A\) as an \(n\)th number. The mean is still \(A\), so \((G^{n-1}A)^{1/n} \leq A\), which gives \(G \leq A\).

  2. The \(n + 1\) numbers have mean \(1 + \frac{1}{n+1}\) and geometric mean \((1 + \frac1n)^{n/(n+1)}\), and they are not all equal, so the inequality is strict; raise both sides to the power \(n + 1\).

  3. The faces have areas \(ab\), \(bc\), \(ca\), with \(S = 2(ab + bc + ca)\). AM–GM gives \(\frac S6 \geq (abc)^{2/3} = V^{2/3}\), with equality when \(ab = bc = ca\), a cube.

  4. AM–GM for \(1/a_i\): \(\frac1n\sum\frac1{a_i} \geq \frac1G\). Take reciprocals.

3.3Power of Convexity

  1. If \(\mathrm{f}'' < 0\) the gradient decreases, so the curve lies above each chord. With \(t = \frac13\): \(\mathrm{f}\bigl(\frac{u + v + w}{3}\bigr) \geq \frac13\mathrm{f}(u) + \frac23\mathrm{f}\bigl(\frac{v + w}{2}\bigr) \geq \frac13\bigl(\mathrm{f}(u) + \mathrm{f}(v) + \mathrm{f}(w)\bigr)\).

  2. \((\ln\sin x)'' = -\mathrm{cosec}^2x < 0\), so \(\ln\sin\) is concave on \((0, \pi)\). Jensen gives \(\frac13\ln(\sin A\sin B\sin C) \leq \ln\sin\frac\pi3\), so the product is at most \(\bigl(\frac{\sqrt3}{2}\bigr)^3\).

  3. \((\tan x)'' = 2\sec^2x\tan x > 0\) on \((0, \frac\pi2)\); Jensen gives \(\tan A + \tan B + \tan C \geq 3\tan\frac\pi3 = 3\sqrt3\).

  4. \((x^2)'' = 2 > 0\); Jensen gives the inequality, which says that \(\frac1n\sum a_i^2 - \bar a^2\), the variance, is non-negative.

3.4That Prove Inequalities

  1. With \(\mathrm{f} = \sin\) on \([0, \frac\pi2]\), equality holds when \(b = \mathrm{f}(a)\); take \(a = \arcsin t\), \(b = t\): \(t\arcsin t = (1 - \cos(\arcsin t)) + \int_0^t\arcsin y\,\mathrm{d}y\). Differentiating the right-hand side of the result gives \(\arcsin t + \frac{t}{\sqrt{1 - t^2}} - \frac{t}{\sqrt{1 - t^2}} = \arcsin t\).

  2. Young with \(p = q = 2\) gives \(ab \leq \frac12(a^2 + b^2)\). If \(\sum a_i^2 = \sum b_i^2 = 1\), adding gives \(\sum a_ib_i \leq 1\). In general, apply this to \(a_i/\sqrt{\sum a_j^2}\) and \(b_i/\sqrt{\sum b_j^2}\).

  3. \(\int_0^a(e^x - 1)\,\mathrm{d}x = e^a - 1 - a\) and \(\int_0^b\ln(1 + y)\,\mathrm{d}y = (1 + b)\ln(1 + b) - b\). Equality holds when \(b = e^a - 1\).

  4. \(t = 1\): \(1.571\) against \(1\); \(t = 2\): \(0.524\) against \(0.268\); \(t = 10\): \(0.1002\) against \(0.0501\). For large \(t\), \(t - \sqrt{t^2 - 1} = \frac{1}{t + \sqrt{t^2 - 1}} \approx \frac{1}{2t}\). The bound comes from \(a = 0\), where \((*)\) just says \(0 \leq \int_0^b\arcsin y\,\mathrm{d}y\); for small \(b\) this area is about \(\frac{b^2}{2}\), half of \(b\arcsin b \approx b^2\), and discarding it loses the factor \(2\).

3.5 \(\pi^e\) or \(e^\pi\)?

  1. \(n^m = m^n\) means \(h(n) = h(m)\). \(h\) increases on \((1, e)\) and decreases afterwards, so one of the two is less than \(e\): it must be \(2\) (as \(h(1) = 0\) is not taken again), and then the other is \(4\). The only pair is \(\{2, 4\}\).

  2. \(e < 3 < \pi\) and \(h\) decreases there, so \(h(3) > h(\pi)\), i.e. \(3^\pi > \pi^3\). Both \(\frac94\) and \(\sqrt5\) are less than \(e\), with \(\frac94 > \sqrt5\), so \(h(\frac94) > h(\sqrt5)\), giving the second. For \(1 < x < 2\): \(h(x) < h(2) = h(4) < h(x + 2)\) since \(3 < x + 2 < 4\), so \(x^{x+2} < (x + 2)^x\).

  3. \(9^{\sqrt2} = 3^{2\sqrt2}\) and \(\sqrt2^{\,9} = 16\sqrt2 = (2\sqrt2)^3\). Since \(e^2 < 8\), \(e < 2\sqrt2 < 3\), where \(h\) decreases, so \(h(2\sqrt2) > h(3)\), which gives \((2\sqrt2)^3 > 3^{2\sqrt2}\): \(\sqrt2^{\,9}\) is larger.

  4. \(e^{\pi/e - 1} > \frac\pi e\), so \(e^{\pi/e} > \pi\); raise to the power \(e\).

3.6Bound on Slopes

  1. Both sides are quadratics agreeing at \(x = -1, 0, 1\), so they are equal (Lagrange interpolation). Differentiating gives \(\mathrm{f}(-1)(x - \frac12) - 2\mathrm{f}(0)x + \mathrm{f}(1)(x + \frac12)\).

  2. \(|\mathrm{f}'(x)| \leq |x - \frac12| + 2|x| + |x + \frac12| \leq 4\) on \([-1, 1]\), with equality only at \(x = \pm1\), and only if \(\mathrm{f}(1)\), \(\mathrm{f}(-1)\), \(-\mathrm{f}(0)\) are all equal to \(1\) or all equal to \(-1\). A quadratic is determined by these three values, giving \(\pm(2x^2 - 1)\).

  3. \(T_3(\cos\theta) = \cos3\theta\) gives \(4x^3 - 3x\), and \(T_3'(1) = 12 - 3 = 9\). From \(\cos(n + 1)\theta + \cos(n - 1)\theta = 2\cos\theta\cos n\theta\), \(T_{n+1} = 2xT_n - T_{n-1}\), and \(T_4 = 8x^4 - 8x^2 + 1\).

  4. \(-\sin\theta\,T_n'(\cos\theta) = -n\sin n\theta\). As \(\theta \to 0\), \(\frac{n\sin n\theta}{\sin\theta} \to n^2\).

3.7 \(\pi^2 \leq 10\)

  1. \(\int_0^\pi\mathrm{f}^2 = \frac{\pi^9}{630}\) and \(\int_0^\pi(\mathrm{f}')^2 = \frac{2\pi^7}{105}\), so \((*)\) gives \(\pi^2 \leq 12\). The quartic is too flat near the ends and too peaked in the middle compared with \(\sin x\), so its ratio of slope to size is further from the optimum.

  2. \(\int_0^\pi(\sin x + \sin2x)^2 = \frac\pi2 + \frac\pi2 = \pi\) (the cross term integrates to \(0\)), and \(\int_0^\pi(\cos x + 2\cos2x)^2 = \frac\pi2 + 2\pi = \frac{5\pi}{2}\).

  3. Put \(\mathrm{g}(x) = \mathrm{f}(\pi x/L)\). The left side scales by \(\frac L\pi\) and \(\int(\mathrm{g}')^2\) by \(\frac{\pi}{L}\). For strings, the lowest frequency is proportional to \(\frac1L\): halving the length doubles the pitch.

  4. The bound \(\pi^2 \leq \int(\mathrm{f}')^2\big/\!\int\mathrm{f}^2\) (in suitable units) is minimised at \(\lambda \approx 1.133/\pi^2\), giving \(\pi^2 \leq 9.86975\), against the true value \(9.86960\).

3.8from Their Addition Laws

  1. Putting \(x = y = 0\) gives \(\mathrm{g}(0) = 0\). Differentiating with respect to \(y\) at \(y = 0\) gives \(\mathrm{g}'(x) = k(1 + \mathrm{g}(x)^2)\), so \(\frac{\mathrm{d}}{\mathrm{d}x}\arctan\mathrm{g}(x) = k\) and \(\mathrm{g}(x) = \tan kx\).

  2. Differentiating with respect to \(y\) gives \(\mathrm{f}'(x + y) = \mathrm{f}'(y)\), so \(\mathrm{f}'\) is a constant \(k\); and \(\mathrm{f}(0) = 0\) (put \(x = y = 0\)).

  3. \(\mathrm{f}(x) = \mathrm{f}(x/2)^2 \geq 0\), and \(\mathrm{f}\) is never \(0\) (or it would be \(0\) everywhere). Induction gives \(\mathrm{f}(n) = a^n\); \(\mathrm{f}(1/n)^n = \mathrm{f}(1) = a\) with \(\mathrm{f}(1/n) > 0\) gives \(a^{1/n}\); then \(\mathrm{f}(m/n) = \mathrm{f}(1/n)^m\). Without continuity the values at irrationals are unconstrained: there are strange solutions, built using a “Hamel basis”, that are not \(a^x\).

  4. Each firing adds rapidity \(\phi = \operatorname{artanh}\frac12\), so after \(k\) firings the speed is \(\tanh k\phi = \frac{3^k - 1}{3^k + 1}\): \(0.8c\), \(\frac{13}{14}c \approx 0.929c\) and \(\frac{40}{41}c \approx 0.976c\).

3.9a New Function

  1. At \(x = -1\), \(x^2 - 2^x = \frac12 > 0\); at \(x = 0\) it is \(-1\): so there is a negative root. Writing \(x = -2u/\ln2\) turns \(x^2 = 2^x\) (with \(x < 0\), taking \(x = -2^{x/2}\)) into \(ue^u = \frac{\ln2}{2}\), so \(u = \mathrm{g}\bigl(\frac{\ln2}{2}\bigr)\) and \(x \approx -0.7667\).

  2. \(\mathrm{g}'e^{\mathrm{g}}(1 + \mathrm{g}) = 1\) and \(e^{\mathrm{g}} = x/\mathrm{g}\). At \(x = -\frac1e\), \(\mathrm{g} = -1\) and the slope is infinite (the graph is vertical there).

  3. With \(x = we^w\), \(\mathrm{d}x = (1 + w)e^w\,\mathrm{d}w\) and \(w\) runs from \(0\) to \(1\): \(\int_0^1w(1 + w)e^w\,\mathrm{d}w = \bigl[(w^2 - w + 1)e^w\bigr]_0^1 = e - 1\).

  4. \(T = \sqrt2^{\,T}\) means \(\frac{\ln T}{T} = \frac{\ln2}{2}\), so \(T = 2\) or \(4\). The terms \(1.414, 1.633, 1.761, \ldots\) increase and stay below \(2\) (if \(t_n < 2\) then \(t_{n+1} < \sqrt2^{\,2} = 2\)), so \(T = 2\); the fixed point \(4\) is repelling.
