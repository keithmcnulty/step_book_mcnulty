4.1Is an Integral?

  1. The sum is the total area of \(n\) rectangles of width \(\frac1n\) under \(y = \mathrm{f}(x)\) on \([1, 2]\). With \(\mathrm{f}(x) = \frac1x\), \(\frac1n\sum\frac{1}{1 + m/n} = \sum\frac{1}{n + m} \to \ln2\). The second sum is \(\frac1n\sum\frac{1}{1 + (m/n)^2} \to \int_0^1\frac{\mathrm{d}x}{1 + x^2} = \frac\pi4\).

  2. The upper sum with \(n\) strips is \(\frac an\sum_{r=1}^{n}\bigl(\frac{ra}{n}\bigr)^2 = \frac{a^3(n + 1)(2n + 1)}{6n^2}\), and the lower sum is the same with \(n - 1\) in place of \(n + 1\) in the first factor; both tend to \(\frac{a^3}{3}\).

  3. The terms telescope: \(r(r + 1)\cdots(r + k) - (r - 1)r\cdots(r + k - 1) = (k + 1)\,r(r + 1)\cdots(r + k - 1)\).

  4. \(\sum_{r=1}^nr^5 = \frac{n^2(n + 1)^2(2n^2 + 2n - 1)}{12}\).

4.2Trigonometry from an Integral

  1. The derivative is \(-\mathrm{f}(a - x)\mathrm{f}(x) + \mathrm{f}(a - x)\mathrm{f}(x) = 0\), so \(\mathrm{f}(a - x)\mathrm{f}(x) = \mathrm{f}(a)\); put \(a = x + y\). For the cosine, with \(y\) fixed let \(p(x) = \mathrm{c}(x + y) - \mathrm{c}(x)\mathrm{c}(y) + \mathrm{s}(x)\mathrm{s}(y)\) and \(q(x) = \mathrm{s}(x + y) - \mathrm{s}(x)\mathrm{c}(y) - \mathrm{c}(x)\mathrm{s}(y)\). Then \(p' = -q\) and \(q' = p\), so \(p^2 + q^2\) is constant, and it is \(0\) at \(x = 0\).

  2. \(\frac{\mathrm{d}y}{\mathrm{d}u} = (1 + u^2)^{-3/2}\) and \(\sqrt{1 - y^2} = (1 + u^2)^{-1/2}\), so \(\frac{\mathrm{d}y}{\sqrt{1 - y^2}} = \frac{\mathrm{d}u}{1 + u^2}\). Then \(\mathrm{S}(\frac{1}{\sqrt2}) = \mathrm{T}(1)\), and part (i) with \(x = 1\) gives \(\mathrm{T}(1) = \frac12\mathrm{T}_\infty\).

  3. With \(a = \frac12\) and \(x = \frac13\), \(\frac{x + a}{1 - ax} = 1\), so \(\mathrm{T}(\frac13) = \mathrm{T}(1) - \mathrm{T}(\frac12)\).

  4. \(\frac{1}{1 + u^2} \leq 1\) on \([0, 1]\) and \(\leq \frac{1}{u^2}\) on \([1, x]\), so for \(x \geq 1\), \(\mathrm{T}(x) \leq 1 + (1 - \frac1x) < 2\); for \(0 < x < 1\), \(\mathrm{T}(x) < \mathrm{T}(1) \leq 1\). (The bound \(1 + \int_1^x u^{-2}\,\mathrm{d}u\) is not valid for \(x < 1\): at \(x = \frac12\) it equals \(0\).) \(\mathrm{T}\) is increasing and bounded, so it has a limit.

4.3 \(22/7\) Is Bigger Than \(\pi\)

  1. \(\frac{22}{7} - \pi \approx 0.001264\), between \(\frac{1}{1260} \approx 0.000794\) and \(\frac{1}{630} \approx 0.001587\).

  2. \(\frac{(4!)^2}{9!} = \frac{576}{362\,880} = \frac{1}{630}\).

  3. \(\frac{x(1 - x)^2}{1 + x^2} = x - 2 + \frac{2}{1 + x^2}\), which integrates to \(\frac12 - 2 + \frac\pi2\). Similarly \(\frac{x^2(1 - x)^4}{1 + x^2} = x^4 - 4x^3 + 5x^2 - 4 + \frac{4}{1 + x^2}\), which integrates to \(\frac15 - 1 + \frac53 - 4 + \pi = \pi - \frac{47}{15}\). Both integrals are positive. The integrands are much larger than \(\frac{x^4(1 - x)^4}{1 + x^2}\) (whose maximum is about \(0.003\)), so the errors \(\frac\pi2 - \frac32 \approx 0.07\) and \(\pi - \frac{47}{15} \approx 0.008\) are larger.

  4. Polynomial division leaves the remainder \(\frac{16}{1 + x^2}\), which integrates to \(4\pi\); the integral is \(4\pi - \frac{188684}{15015} \approx 3.6 \times 10^{-6}\), so \(\pi \approx 3.14159174\).

4.4, Beta and the Factorial of a Half

  1. \(u_{2m} = \frac{1 \cdot 3 \cdots (2m - 1)}{2 \cdot 4 \cdots 2m}\cdot\frac\pi2\) and \(u_{2m+1} = \frac{2 \cdot 4 \cdots 2m}{3 \cdot 5 \cdots (2m + 1)}\). Then \(1 < \frac{u_{2m}}{u_{2m+1}} < \frac{u_{2m-1}}{u_{2m+1}} = \frac{2m + 1}{2m}\), so the ratio tends to \(1\), which rearranges to \(\frac\pi2 = \prod_{k \geq 1}\frac{(2k)^2}{(2k - 1)(2k + 1)}\).

  2. Integration by parts gives \(I_n = \frac{n}{n + 1}\int_0^1x^{n+1}(1 - x)^{n-1}\,\mathrm{d}x\), and writing \(x^{n+1}(1 - x)^{n-1} = x^n(1 - x)^{n-1} - x^n(1 - x)^n\) together with symmetry leads to \(I_n = \frac{n}{2(2n + 1)}I_{n-1}\); induction gives \(\frac{(n!)^2}{(2n + 1)!}\). With \(x = \sin^2\theta\), \(I_{1/2} = \int_0^{\pi/2}2\sin^2\theta\cos^2\theta\,\mathrm{d}\theta = \frac\pi8\). The formula suggests \(\bigl((\frac12)!\bigr)^2/2! = \frac\pi8\), so \((\frac12)! = \frac{\sqrt\pi}{2}\) (which is \(\Gamma(\frac32)\)).

  3. Symmetry from \(x \mapsto 1 - x\); the recurrence from \(x^p = x^{p-1} - x^{p-1}(1 - x)\); and with \(x = \frac{t}{1 + t}\), \(1 - x = \frac{1}{1 + t}\) and \(\mathrm{d}x = \frac{\mathrm{d}t}{(1 + t)^2}\). The integral is \(\mathrm{b}(\frac52, \frac72)\); using the recurrence and symmetry to reduce to \(\mathrm{b}(\frac12, \frac12) = \pi\) gives \(\frac{3\pi}{256}\).

  4. From part (i)’s explicit value, \(u_{2m} = \frac{(2m)!}{(2^mm!)^2}\cdot\frac\pi2 = \binom{2m}{m}\frac{\pi}{2^{2m+1}}\). Then \(2mu_{2m}^2 \to \frac\pi2\) gives \(\binom{2m}{m}^2 \approx \frac{4^{2m}}{\pi m}\). For \(m = 10\): \(\binom{20}{10} = 184\,756\), against \(\frac{4^{10}}{\sqrt{10\pi}} \approx 187\,079\) (about \(1.3\%\) high).

4.5Sophomore’s Dream

  1. \(x^{-x} = e^{-x\ln x} = \sum_{n \geq 0}\frac{(-x\ln x)^n}{n!}\), and \(\int_0^1\frac{x^n(-\ln x)^n}{n!}\,\mathrm{d}x = \frac{1}{(n + 1)^{n+1}}\) (substitute \(x = e^{-u}\)). So the integral is \(\sum_{n \geq 1}n^{-n} \approx 1.2913\).

  2. \(\frac{\mathrm{d}}{\mathrm{d}x}x^x = x^x(\ln x + 1)\), zero at \(x = \frac1e\); the value is \((e^{-1})^{e^{-1}} = e^{-1/e} \approx 0.692\).

  3. The terms are \(\frac{1}{n^n}\). Stopping after \(7\) terms gives error less than \(\frac{1}{8^8} \approx 6 \times 10^{-8}\), enough; after \(6\) terms the bound \(\frac{1}{7^7} \approx 1.2 \times 10^{-6}\) is not. So \(7\) terms.

  4. By parts: \(\int_0^1x^2\ln x\,\mathrm{d}x = \bigl[\frac{x^3\ln x}{3}\bigr]_0^1 - \int_0^1\frac{x^2}{3}\,\mathrm{d}x = -\frac19\). In general \(\int_0^1x^n\ln x\,\mathrm{d}x = -\frac{1}{(n + 1)^2}\), and \(\frac{\ln x}{1 - x} = \sum_{n \geq 0}x^n\ln x\).

4.6With No Formula

  1. Differentiate: \(\frac{\mathrm{d}}{\mathrm{d}x}\frac{e^x}{x + 1} = \frac{xe^x}{(x + 1)^2}\), and \(\frac{\mathrm{d}}{\mathrm{d}x}\frac{(x - 1)e^x}{x + 1} = e^x\Bigl(\frac{x - 1}{x + 1} + \frac{2}{(x + 1)^2}\Bigr) = \frac{(x^2 + 1)e^x}{(x + 1)^2}\).

  2. \(\frac{\mathrm{d}}{\mathrm{d}x}\bigl(\mathrm{P}e^{-x^2}\bigr) = (\mathrm{P}' - 2x\mathrm{P})e^{-x^2}\), and \(\mathrm{P}' - 2x\mathrm{P}\) has degree \(\deg\mathrm{P} + 1 \geq 1\) (for \(\mathrm{P} \neq 0\)), so it cannot equal \(1\).

  3. If \(\mathrm{R} = \mathrm{P}/\mathrm{Q}\) (in lowest terms) had a pole of order \(k \geq 1\) at \(0\), then \(\mathrm{R}' + \mathrm{R}\) would have a pole of order \(k + 1 \geq 2\) there, but \(\frac1x\) has a pole of order \(1\). If \(\mathrm{R}\) has no pole at \(0\), neither has \(\mathrm{R}' + \mathrm{R}\). Either way \((\mathrm{R}e^x)' \neq \frac{e^x}{x}\).

  4. Differentiating \(\frac{\mathrm{P}e^x}{x + 1}\) gives \(e^x\frac{(x + 1)\mathrm{P}' + x\mathrm{P}}{(x + 1)^2}\). At \(x = -1\): \(\mathrm{f}(-1) = -\mathrm{P}(-1)\), and \(\mathrm{f}' = (x + 1)\mathrm{P}'' + (x + 1)\mathrm{P}' + \mathrm{P}\) gives \(\mathrm{f}'(-1) = \mathrm{P}(-1)\). For \(x^3 - 2\): \(-3 + 3 = 0\); for \(x\): \(-1 + 1 = 0\); for \(x^2 + 1\): \(2 - 2 = 0\). The condition is also sufficient: the map \(\mathrm{P} \mapsto (x + 1)\mathrm{P}' + x\mathrm{P}\) from polynomials of degree less than \(d\) to degree at most \(d\) is injective, so its image has dimension \(d\), and it lies inside the \(d\)-dimensional space of \(\mathrm{f}\) with \(\mathrm{f}(-1) + \mathrm{f}'(-1) = 0\); so it is that whole space.

4.7Calculus of Variations

  1. With \(y = \cos\frac{\pi x}{2}\), \(J = \frac{\pi^2}{4}\int_0^1\sin^2 - a^2\int_0^1\cos^2 = \frac12\bigl(\frac{\pi^2}{4} - a^2\bigr) < 0\).

  2. \(J(y + \varepsilon\eta) = J(y) + 2\varepsilon\int_0^1(y'\eta' - a^2y\eta) + \varepsilon^2J(\eta)\); a minimum at \(\varepsilon = 0\) forces the linear term to vanish. Integrating by parts, \(-y'(0)\eta(0) - \int_0^1(y'' + a^2y)\eta = 0\) for every \(\eta\) with \(\eta(1) = 0\), which forces \(y'' + a^2y = 0\) and \(y'(0) = 0\).

  3. With \(x = Lu\), \(\int_0^L\bigl((y')^2 - a^2y^2\bigr)\,\mathrm{d}x = \frac1L\int_0^1\bigl((Y')^2 - (aL)^2Y^2\bigr)\,\mathrm{d}u\), so the condition is \(aL \leq \frac\pi2\). (At \(aL = \frac\pi2\) the integral is still never negative, as in the main text, but \(y = \cos\frac{\pi x}{2L}\) makes it zero; for \(aL > \frac\pi2\) that same function makes it negative.)

  4. The cycloid is \(x = R(\theta - \sin\theta)\), \(y = R(1 - \cos\theta)\). For the tautochrone, see Section 11.4: in terms of arc length the motion is exactly simple harmonic.

4.8a Spherical Loaf

  1. \(V/A = \frac{\frac43\pi a^3}{4\pi a^2} = \frac a3\). But a remaining piece of height \(t\) has \(A = 2\pi at\) and \(V = \frac13\pi t^2(3a - t)\), so \(V/A = \frac{t(3a - t)}{6a}\), which is largest, \(\frac{3a}{8}\), at \(t = \frac32a\): bigger than \(\frac a3\).

  2. The band has height \(2R\sin23.4^\circ\) out of the sphere’s \(2R\), so the fraction is \(\sin23.4^\circ \approx 0.40\).

  3. For \(y = \sqrt x\), \(y\sqrt{1 + (y')^2} = \sqrt{x + \frac14}\), not constant. \(y\sqrt{1 + (y')^2} = c\) gives \((y')^2 = \frac{c^2}{y^2} - 1\), whose solutions are \(y = c\) (a cylinder) and the circles \((x - x_0)^2 + y^2 = c^2\) (spheres).

  4. The sphere has volume \(\frac43\pi a^3\) and the cylinder \(\pi a^2 \cdot 2a = 2\pi a^3\); the ratio is \(\frac23\).

4.9’s Theorem

  1. \(\frac12\int_0^{2\pi}(p\cos t \cdot q\cos t + q\sin t \cdot p\sin t)\,\mathrm{d}t = \frac12 \cdot 2\pi pq = \pi pq\).

  2. The triangles formed by joining the ends of the two chords are similar (equal angles subtended by the same arcs), so \(PA \cdot PB = PC \cdot PD\). For a circle of radius \(R\) with \(P\) at distance \(r\) from the centre, the diameter through \(P\) gives \((R - r)(R + r)\), so \(ab = R^2 - r^2\) and the ring has area \(\pi R^2 - \pi r^2 = \pi ab\).

  3. If \(a = b\) then \(f = \pi(a - b) = 0\), and the ring’s area is \(\pi a^2 = \frac{\pi L^2}{4}\): the area of the circle with the rod as diameter.

  4. Along the two sides through \(O\), \(x\,\mathrm{d}y - y\,\mathrm{d}x = 0\). On the third side, parametrised by \((x_1, y_1) + s(x_2 - x_1, y_2 - y_1)\) for \(0 \leq s \leq 1\), it is \((x_1y_2 - x_2y_1)\,\mathrm{d}s\). So the area is \(\frac12|x_1y_2 - x_2y_1|\).
