These are brief answers and hints, not full solutions: they give the result and the key step, so that you can check your own work. Try each exercise properly before looking.

6.1 Polynomials Whose Roots Are Roots of Unity

  1. \((x - 1)(x + 1) = x^2 - 1\) and \((x^2 + x + 1)(x^2 - x + 1) = x^4 + x^2 + 1\), whose product is \(x^6 - 1\). Similarly \(x^{12} - 1 = (x^6 - 1)(x^6 + 1)\) and \(x^6 + 1 = (x^2 + 1)(x^4 - x^2 + 1) = \mathrm{C}_4\mathrm{C}_{12}\).

  2. The divisors of \(2p\) are \(1\), \(2\), \(p\), \(2p\), so \(\mathrm{C}_{2p} = \frac{x^{2p} - 1}{(x - 1)(x + 1)\mathrm{C}_p(x)} = \frac{x^p + 1}{x + 1}\). And \(\mathrm{C}_p(-x) = \frac{(-x)^p - 1}{-x - 1} = \frac{x^p + 1}{x + 1}\) since \(p\) is odd. For \(p = 3\): \(\mathrm{C}_6 = x^2 - x + 1 = \mathrm{C}_3(-x)\).

  3. The numbers up to \(p^k\) that share a factor with \(p^k\) are the \(p^{k-1}\) multiples of \(p\). The primitive \(p^k\)th roots are the roots of \(x^{p^k} - 1\) that are not roots of \(x^{p^{k-1}} - 1\), so \(\mathrm{C}_{p^k} = \frac{x^{p^k} - 1}{x^{p^{k-1}} - 1} = \mathrm{C}_p\bigl(x^{p^{k-1}}\bigr)\). So \(\mathrm{C}_9 = x^6 + x^3 + 1\).

  4. \(\mathrm{C}_{15} = \frac{(x^{15} - 1)(x - 1)}{(x^3 - 1)(x^5 - 1)}\). Check by multiplying out that \((x - 1)(x^2 + x + 1)(x^4 + x^3 + x^2 + x + 1)\) times the stated octic is \(x^{15} - 1\).

6.2 Gauss’s 17-gon

  1. \(\eta + \eta'\) is the sum of all six non-real seventh roots, \(-1\). Expanding \(\eta\eta'\) gives nine terms \(\alpha^{a+b}\) with exponents \(4, 6, 0, 5, 0, 1, 0, 2, 3\) (mod \(7\)): three \(1\)s and each non-real root once, so \(\eta\eta' = 3 - 1 = 2\). So \(\eta\), \(\eta'\) are \(\frac{-1 \pm \mathrm{i}\sqrt7}{2}\). The real part of \(\eta\) gives the cosine sum. Its imaginary part is \(\sin\frac{2\pi}{7} + \sin\frac{4\pi}{7} - \sin\frac{\pi}{7}\), which is positive since \(\sin\frac{4\pi}{7} = \sin\frac{3\pi}{7} > \sin\frac\pi7\); so it is \(+\frac{\sqrt7}{2}\).

  2. With \(\zeta = \mathrm{e}^{2\pi\mathrm{i}/5}\), the periods \(\zeta + \zeta^4 = 2\cos\frac{2\pi}{5}\) and \(\zeta^2 + \zeta^3\) have sum \(-1\) and product \(-1\), so they are roots of \(t^2 + t - 1 = 0\), and the positive one gives \(\cos\frac{2\pi}{5} = \frac{\sqrt5 - 1}{4}\). To construct: in a unit circle, a right triangle with legs \(1\) and \(\frac12\) has hypotenuse \(\frac{\sqrt5}{2}\); subtract \(\frac12\) and halve to get \(\cos\frac{2\pi}{5}\). The perpendicular to the axis at that distance meets the circle at a vertex adjacent to \((1, 0)\); step this chord round the circle.

  3. Both are \(-1.28078\) to five decimal places.

  4. The powers of \(3\) are \(3, 9, 10, 13, 5, 15, 11, 16, 14, 8, 7, 4, 12, 2, 6, 1\): all sixteen. The powers of \(2\) repeat after eight steps (\(2^8 = 256 \equiv 1\)) and give \(\{1, 2, 4, 8, 9, 13, 15, 16\}\), the non-zero squares modulo \(17\).

6.3 A Polynomial for \(\sqrt2 + \sqrt3 + \sqrt5\)

  1. \(y^3 = 2\sqrt2 + 6\sqrt3 + 9\sqrt2 + 3\sqrt3 = 11\sqrt2 + 9\sqrt3\), and \(9y = 9\sqrt2 + 9\sqrt3\), so \(y^3 - 9y = 2\sqrt2\). Then \(\sqrt3 = y - \sqrt2\) and \(\sqrt6 = \sqrt2\sqrt3\) are polynomials in \(y\) too.

  2. Put \(x - \sqrt2 = \sqrt[3]3\) and cube: \(x^3 + 6x - 3 = \sqrt2(3x^2 + 2)\). Squaring gives \(x^6 - 6x^4 - 6x^3 + 12x^2 - 36x + 1 = 0\).

  3. The only possible rational roots are \(\pm1\), and neither works. Since there is no \(x^3\) term, a factorisation into monic quadratics has the form \((x^2 + ax + b)(x^2 - ax + c)\), with \(a(c - b) = 0\), \(b + c - a^2 = -10\) and \(bc = 1\). If \(a = 0\) then \(b + c = -10\) and \(bc = 1\), impossible in integers; if \(b = c = \pm1\) then \(a^2 = 12\) or \(8\), also impossible. So the quartic is irreducible and \(\sqrt2 + \sqrt3\) has degree \(4\).

  4. From De Moivre, \(\cos3\theta = 4\cos^3\theta - 3\cos\theta\); with \(\theta = 20^\circ\), \(\frac12 = 4c^3 - 3c\). The candidates \(\pm1, \pm\frac12, \pm\frac14, \pm\frac18\) all fail. So \(\cos20^\circ\) has degree \(3\), but every constructible length has degree a power of \(2\), so \(20^\circ\) cannot be constructed from \(60^\circ\).

6.4 Solving the Quartic

  1. \(y_1y_2 + y_2y_3 + y_3y_1\) is the sum of the twelve terms \(\alpha^2\beta\gamma\) (one squared root times two others). And \(\bigl(\sum\alpha\bigr)\bigl(\sum\alpha\beta\gamma\bigr)\) is those twelve terms plus \(4\alpha\beta\gamma\delta\). So the sum is \((-p)(-r) - 4s\).

  2. Matching coefficients gives \(a + b = 1\), \(a\alpha + b\beta = 0\) and \(a\alpha^2 + b\beta^2 = -p\), solvable when \(\alpha \neq \beta\), which is what the two conditions guarantee: \(p \neq 0\) makes the equation for \(t\) a genuine quadratic (if \(p = 0\) it collapses to \(-qt = 0\), with the single root \(0\)), and \(q^2 \neq 4p^3\) makes its discriminant \(q^2 - 4p^3\) non-zero. For \(x^3 - 24x + 48\): \(p = 8\), \(q = 48\), and \(8t^2 - 48t + 64 = 0\) gives \(\alpha = 2\), \(\beta = 4\). Then \(\bigl(\frac{x - 2}{x - 4}\bigr)^3 = -\frac ba = \frac\alpha\beta = \frac12\), so \(x - 2 = 2^{-1/3}(x - 4)\), which rearranges to the given root, \(x \approx -5.6946\).

  3. The resolvent cubic is \(y^3 - 7y^2 + 16y - 12 = (y - 3)(y - 2)^2\). The root \(y = 3\) leads to \((x^2 - 2x + 1)(x^2 - 2x + 2)\), so the roots are \(1\) (twice) and \(1 \pm \mathrm{i}\).

  4. Swap within either pair or not (\(4\) choices), and swap the two pairs or not (\(2\) choices): the identity, \((\alpha\beta)\), \((\gamma\delta)\), \((\alpha\beta)(\gamma\delta)\), \((\alpha\gamma)(\beta\delta)\), \((\alpha\delta)(\beta\gamma)\), \((\alpha\gamma\beta\delta)\) and \((\alpha\delta\beta\gamma)\). This is a copy of the symmetry group of a square.

6.5 Differentiation from Axioms

  1. Constants still give \(0\), and by rule (i) and induction \(\lozenge x^n = x^{n-1}\lozenge x + x\lozenge x^{n-1} = nx^n\). By linearity \(\lozenge\mathrm{h} = x\mathrm{h}'\).

  2. \(\lozenge\mathrm{f} = \frac{\mathrm{f}}{\mathrm{g}}\lozenge\mathrm{g} + \mathrm{g}\lozenge\frac{\mathrm{f}}{\mathrm{g}}\), so \(\lozenge\frac{\mathrm{f}}{\mathrm{g}} = \frac{\mathrm{g}\lozenge\mathrm{f} - \mathrm{f}\lozenge\mathrm{g}}{\mathrm{g}^2}\).

  3. If \(\mathrm{f} = (x - a)^2\mathrm{g}\) then \(\mathrm{f}' = (x - a)\bigl(2\mathrm{g} + (x - a)\mathrm{g}'\bigr)\). A repeated root of \(x^n - 1\) would be a root of \(nx^{n-1}\), so it would be \(0\); but \(0\) is not a root of \(x^n - 1\).

  4. \((2 + \varepsilon)^2 + 1 = 5 + 4\varepsilon\), and \((5 + 4\varepsilon)^3 = 125 + 300\varepsilon\). So \(f(2) = 125\) and \(f'(2) = 300\); the chain rule gives \(3(x^2 + 1)^2 \cdot 2x = 3 \cdot 25 \cdot 4 = 300\).

6.6 Unions of Subgroups

  1. With \(V = \{e, a, b, c\}\): \(a^2 = b^2 = c^2 = e\) and the product of any two of \(a\), \(b\), \(c\) is the third. Every element is its own inverse. In \(\{1, \mathrm{i}, -1, -\mathrm{i}\}\), \(\mathrm{i}\) has inverse \(-\mathrm{i}\), so the groups are different.

  2. If \(g\) lay in a proper subgroup \(H\), then so would every power of \(g\), so \(H\) would be the whole group.

  3. \(1\) is neither even nor a multiple of \(3\). More generally, \(\mathbb{Z}\) is cyclic (generated by \(1\)), so by the previous exercise it is not the union of any number of proper subgroups.

  4. The line \(y = mx\) meets \(y = x^2\) only at \(x = 0\) and \(x = m\), and the line \(x = 0\) only at the origin. So \(k\) lines contain at most \(k\) of the infinitely many points \((t, t^2)\) with \(t \neq 0\).

6.7 The Quaternion Group

  1. \(C\circ B = (\mathrm{i}, 0)\circ(0, 1) = (0, \mathrm{i}) = D\), and \(B\circ C = (0, 1)\circ(\mathrm{i}, 0) = (0, \mathrm{i}^*) = (0, -\mathrm{i}) = H\).

  2. \(A\) has order \(1\) and \(E\) order \(2\); each of the other six squares to \(E\), so has order \(4\). The square’s symmetry group has five elements of order \(2\) (four reflections and the half-turn), so the groups are not isomorphic.

  3. \(\det M = z_1z_1^* + z_2z_2^* = |z_1|^2 + |z_2|^2\), which is a sum of four real squares. Since \(M(z)M(w)\) is the matrix of \(z\circ w\), multiplying determinants writes \((a_1^2 + \cdots + a_4^2)(b_1^2 + \cdots + b_4^2)\) as \(|u_1|^2 + |u_2|^2\), again four squares.

  4. The subgroups are \(\{A\}\), \(\{A, E\}\), \(\{A, E, C, G\}\), \(\{A, E, B, F\}\), \(\{A, E, D, H\}\) and \(Q_8\). Every element other than \(A\) has \(E\) as a power, so any subgroup other than \(\{A\}\) contains \(E\). The three subgroups of order \(4\) together contain all eight elements.

6.8 A Group of Singular Matrices

  1. \(\mathbf{M}_a\mathbf{M}_b = \mathbf{M}_{2ab}\), and \(2(2ab) = (2a)(2b)\). The map is one-to-one and onto the non-zero reals.

  2. \(\begin{pmatrix} a & b \\ 0 & 0 \end{pmatrix}\begin{pmatrix} c & d \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} ac & ad \\ 0 & 0 \end{pmatrix}\) with \(ac \neq 0\), so the set is closed. Every \(\begin{pmatrix} 1 & e \\ 0 & 0 \end{pmatrix}\) is a left identity. But \(\mathbf{XE} = \mathbf{X}\) with \(\mathbf{E} = \begin{pmatrix} e & f \\ 0 & 0 \end{pmatrix}\) needs \(e = 1\) and \(f = b/a\), which depends on \(\mathbf{X}\): there is no right identity, so no identity, and no group.

  3. \(\mathbf{0}\), \(\mathbf{I}\), and the matrices \(\begin{pmatrix} a & b \\ c & 1 - a \end{pmatrix}\) with \(bc = a(1 - a)\) (trace \(1\), determinant \(0\)). These are the projections of the plane onto one line along another.

  4. The matrix \(\mathbf{J}_a\) with all entries \(a\) satisfies \(\mathbf{J}_a\mathbf{J}_b = \mathbf{J}_{nab}\). The identity is \(\mathbf{J}_{1/n}\) and the inverse of \(\mathbf{J}_a\) is \(\mathbf{J}_{1/(n^2a)}\).
