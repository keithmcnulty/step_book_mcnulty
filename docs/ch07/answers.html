Answers to Try This Next

These are brief answers and hints, not full solutions: they give the result and the key step, so that you can check your own work. Try each exercise properly before looking.

7.1That Fail for Matrices

  1. Comparing \(\mathbf{XP}\) and \(\mathbf{PX}\) with \(\mathbf{X} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\) forces \(c = 0\) and \(a = d\): the matrices \(\begin{pmatrix} a & b \\ 0 & a \end{pmatrix}\).

  2. Cayley–Hamilton gives \(\mathbf{N}^2 = t\mathbf{N} - d\mathbf{I}\), so \(t\mathbf{N} = d\mathbf{I}\). If \(t \neq 0\) then \(\mathbf{N}\) is a multiple of \(\mathbf{I}\), and \(\mathbf{N}^2 = \mathbf{0}\) forces \(\mathbf{N} = \mathbf{0}\), contradicting \(t \neq 0\). So \(t = 0\), and then \(d = 0\). The answer: \(\begin{pmatrix} a & b \\ c & -a \end{pmatrix}\) with \(a^2 + bc = 0\).

  3. The diagonal entries of the square are \(\cos^2\theta + \sin^2\theta = 1\) and the off-diagonal ones are \(0\). The fixed vector is \((\cos\frac\theta2, \sin\frac\theta2)\), so it reflects in the line through the origin at angle \(\frac\theta2\).

  4. With \(\mathbf{M} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\), \(\mathbf{M}^2 = \begin{pmatrix} a^2 + bc & b(a + d) \\ c(a + d) & d^2 + bc \end{pmatrix}\); subtract \((a + d)\mathbf{M}\) and add \((ad - bc)\mathbf{I}\) to get \(\mathbf{0}\).

7.2Without Turning

  1. \(\mathbf{Mu} = \lambda\mathbf{u}\) with \(\mathbf{u} \neq \mathbf{0}\) needs \(\det(\mathbf{M} - \lambda\mathbf{I}) = 0\), which is the quadratic. Here the trace is \(6\) and the determinant is \(\frac{4}{25}(54 - 4) = 8\), so \(\lambda^2 - 6\lambda + 8 = 0\): \(\lambda = 2\) (for \((1, 2)\)) and \(4\) (for \((2, -1)\)).

  2. \(\mathbf{v} \cdot \mathbf{Mu} = \lambda\,\mathbf{v} \cdot \mathbf{u}\), and since \(\mathbf{M}\) is symmetric, \(\mathbf{v} \cdot \mathbf{Mu} = \mathbf{Mv} \cdot \mathbf{u} = \mu\,\mathbf{v} \cdot \mathbf{u}\). So \((\lambda - \mu)\,\mathbf{u} \cdot \mathbf{v} = 0\).

  3. The characteristic equation \(\lambda^2 - 2\lambda\cos\theta + 1 = 0\) has discriminant \(-4\sin^2\theta\), negative unless \(\theta\) is a multiple of \(\pi\). The eigenvalues are \(\mathrm{e}^{\pm\mathrm{i}\theta}\).

  4. \((1, 0) = \frac15(1, 2) + \frac25(2, -1)\), so \(T^n(1, 0) = \frac{2^n}{5}(1, 2) + \frac{2 \cdot 4^n}{5}(2, -1) = \frac15\bigl(2^n + 4^{n+1},\ 2^{n+1} - 2 \cdot 4^n\bigr)\). For \(n = 1\) this is \((\frac{18}{5}, -\frac45)\), as it should be.

7.3Makes a Determinant

  1. \((\det\mathbf{MN})^3 = (\det\mathbf{M})^3(\det\mathbf{N})^3\), and \((\det\mathbf{J})^3 = -1 \neq 1\). The function \(|\det\mathbf{M}|\) is multiplicative, but \(|\det\mathbf{J}| = 1\).

  2. \(\begin{pmatrix} a & \lambda a \\ c & \lambda c \end{pmatrix} = \begin{pmatrix} a & 0 \\ c & 0 \end{pmatrix}\begin{pmatrix} 1 & \lambda \\ 0 & 0 \end{pmatrix}\), and the second factor has second row \(0\) times its first, so \(\mathrm{f}\) of it is \(0\).

  3. \(\begin{pmatrix} k & 0 \\ 0 & 1 \end{pmatrix} = \mathbf{JK}_k\mathbf{J}\), so its value is \(\mathrm{f}(\mathbf{J})^2\mathrm{f}(\mathbf{K}_k) = \mathrm{f}(\mathbf{K}_k)\). And \(\mathbf{K}_k\mathbf{K}_l = \mathbf{K}_{kl}\).

  4. Row reduction writes any invertible matrix as a product of elementary matrices: row swaps (\(\mathbf{J}\)), row scalings (\(\mathbf{K}_k\) or \(\mathbf{JK}_k\mathbf{J}\)), and shears (\(\begin{pmatrix} 1 & t \\ 0 & 1 \end{pmatrix}\) or its conjugate by \(\mathbf{J}\)). Shears have \(\mathrm{f} = 1\) (as in part (iv), using \(\mathbf{K}^{-1}\mathbf{PK}\)). Also \(\mathbf{J}\) is a product of shears and \(\mathbf{K}_{-1}\), so \(\mathrm{f}(\mathbf{K}_{-1}) = \mathrm{f}(\mathbf{J}) = -1\). Hence \(\mathrm{f}(\mathbf{M}) = \mathrm{g}(\det\mathbf{M})\) where \(\mathrm{g}(k) = \mathrm{f}(\mathbf{K}_k)\); for singular \(\mathbf{M}\), \(\mathrm{f}(\mathbf{M}) = 0\) by part (iii).

7.4That Return to the Start

  1. \(|1 + \mathrm{e}^{\mathrm{i}\phi}|^2 = 2 + 2\cos\phi = 1\) gives \(\phi = \pm\frac{2\pi}{3}\), so \(\mathbf{R}^3 = \mathbf{I}\). For \(\mathbf{S}\): its eigenvalues are cube roots of \(1\). If both were \(1\), then, since \(x^3 - 1\) has distinct roots, \(\mathbf{S}\) would be diagonalisable and equal to \(\mathbf{I}\). Non-real eigenvalues of a real matrix come in conjugate pairs, so they are \(\mathrm{e}^{\pm2\pi\mathrm{i}/3}\): \(\det\mathbf{S} = 1\) and \(\operatorname{tr}\mathbf{S} = -1\).

  2. The eigenvalues must be the primitive sixth roots \(\mathrm{e}^{\pm\mathrm{i}\pi/3}\) (any other choice of sixth roots, paired with conjugates, gives \(\mathbf{M}^2 = \mathbf{I}\) or \(\mathbf{M}^3 = \mathbf{I}\)). So \(\operatorname{tr}\mathbf{M} = 1\) and \(\det\mathbf{M} = 1\).

  3. The eigenvalues are roots of unity with product \(1\), so they are \(\mathrm{e}^{\pm\mathrm{i}\theta}\) (or both \(\pm1\)), and the trace \(2\cos\theta\) is an integer in \([-2, 2]\). Example of order \(6\): \(\begin{pmatrix} 1 & -1 \\ 1 & 0 \end{pmatrix}\).

  4. \(\mathbf{M}^3 = (t^2 - d)\mathbf{M} - td\mathbf{I}\) and \(\mathbf{M}^4 = (t^3 - 2td)\mathbf{M} - d(t^2 - d)\mathbf{I}\). For \(\mathbf{M}^4 = -\mathbf{I}\) (\(\mathbf{M}\) cannot be a multiple of \(\mathbf{I}\)), \(t(t^2 - 2d) = 0\) and \(d(t^2 - d) = 1\). \(t = 0\) gives \(-d^2 = 1\), impossible; so \(t^2 = 2d\), \(d^2 = 1\), and \(d = 1\), \(t^2 = 2\).

7.5in Three Dimensions

  1. \(z \mapsto a + \mathrm{e}^{\mathrm{i}\theta}(z - a)\). The composite is \(z \mapsto \mathrm{e}^{\mathrm{i}(\theta + \phi)}z + k\) with \(k = \mathrm{e}^{\mathrm{i}\phi}a(1 - \mathrm{e}^{\mathrm{i}\theta}) + b(1 - \mathrm{e}^{\mathrm{i}\phi})\); if \(\mathrm{e}^{\mathrm{i}(\theta+\phi)} \neq 1\) it has the fixed point \(c = \frac{k}{1 - \mathrm{e}^{\mathrm{i}(\theta+\phi)}}\). If \(\theta + \phi = 2\pi\) it is the translation by \((b - a)(1 - \mathrm{e}^{-\mathrm{i}\theta})\).

  2. \(\begin{pmatrix} 0 & 0 & 1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}\): it fixes \((1, 1, 1)\), has trace \(0 = 1 + 2\cos120^\circ\), and sends \(\mathbf{i} \to \mathbf{j} \to \mathbf{k} \to \mathbf{i}\).

  3. \(\mathbf{K}^2\mathbf{r} = \mathbf{n} \times (\mathbf{n} \times \mathbf{r}) = (\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\), and then \(\mathbf{K}^3\mathbf{r} = \mathbf{n} \times \bigl((\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\bigr) = -\mathbf{Kr}\). In the series, the odd powers give \((\theta - \frac{\theta^3}{3!} + \cdots)\mathbf{K} = \sin\theta\,\mathbf{K}\) and the even powers (from \(\mathbf{K}^2\) on) give \((\frac{\theta^2}{2!} - \frac{\theta^4}{4!} + \cdots)\mathbf{K}^2 = (1 - \cos\theta)\mathbf{K}^2\).

  4. The composite fixes every point of the line of intersection, and has determinant \((-1)^2 = 1\). In each plane perpendicular to that line it is the product of two reflections in lines at angle \(\alpha\), which is a rotation by \(2\alpha\).

7.6Rotations and Relativity

  1. The entries of \(T(u)T(w)\) are \(\cosh u\cosh w + \sinh u\sinh w = \cosh(u + w)\) and \(\sinh u\cosh w + \cosh u\sinh w = \sinh(u + w)\). So \(T(u)^{-1} = T(-u)\).

  2. \(\tanh u = 0.8\) gives \(u = \frac12\ln\frac{1.8}{0.2} = \ln3 \approx 1.099\) and \(\cosh u = \frac12(3 + \frac13) = \frac53\). On the ship, \(10 \times \frac35 = 6\) years pass.

  3. The area is \(\frac12\oint(x\,\mathrm{d}y - y\,\mathrm{d}x)\). The straight sides contribute nothing, and along the hyperbola, with \(x = \cosh s\), \(y = \sinh s\), the integrand is \((\cosh^2s - \sinh^2s)\,\mathrm{d}s = \mathrm{d}s\), giving \(\frac v2\). \(T\) has determinant \(\cosh^2u - \sinh^2u = 1\), so it preserves area; it maps the hyperbola to itself and moves the point with parameter \(v\) to \(v + u\).

  4. \(x' + y' = (\cosh u + \sinh u)(x + y) = \mathrm{e}^up\) and \(x' - y' = \mathrm{e}^{-u}q\); also \(x^2 - y^2 = pq\). In these coordinates \(T\) is a squeeze: a stretch by \(\mathrm{e}^u\) along the asymptote \(y = x\) and a compression by \(\mathrm{e}^{-u}\) along \(y = -x\), which slides points along each hyperbola \(pq =\) constant.

7.7That Never Change

  1. \(\dot a = -Ct = -tc\), \(\dot d = Ct = tc\), \(\dot c = 0\), and \(\dot b = (A - D)t - Ct^3 = t(a - d)\), matching \(\mathbf{MN} - \mathbf{NM} = t\begin{pmatrix} -c & a - d \\ 0 & c \end{pmatrix}\).

  2. \(\dot{\mathbf{M}} = -\mathbf{S}^{-1}\dot{\mathbf{S}}\mathbf{S}^{-1}\mathbf{M}_0\mathbf{S} + \mathbf{S}^{-1}\mathbf{M}_0\dot{\mathbf{S}} = -\mathbf{NM} + \mathbf{MN}\), using \(\dot{\mathbf{S}} = \mathbf{SN}\).

  3. \(\mathbf{N} = \mathbf{M}^{-1}\dot{\mathbf{M}} = \begin{pmatrix} 2 & 0 \\ 0 & -1 \end{pmatrix}\), and \(\ln\det\mathbf{M} = 2t - t = t\), whose derivative is \(1 = \operatorname{tr}\mathbf{N}\).

  4. \(\frac{\mathrm{d}}{\mathrm{d}t}\operatorname{tr}(\mathbf{M}^k) = \sum_j\operatorname{tr}(\mathbf{M}^j\dot{\mathbf{M}}\mathbf{M}^{k-1-j}) = k\operatorname{tr}(\mathbf{M}^{k-1}\dot{\mathbf{M}})\) by cycling, and \(\operatorname{tr}(\mathbf{M}^{k-1}(\mathbf{MN} - \mathbf{NM})) = \operatorname{tr}(\mathbf{M}^k\mathbf{N}) - \operatorname{tr}(\mathbf{M}^{k-1}\mathbf{NM}) = 0\), again by cycling.

7.8Squares

  1. \((L_1, L_2, L_3, L_4) = (1, 4, 4, 4)\), and \(1 + 16 + 16 + 16 = 49\). This is a different representation from \(7^2 + 0^2 + 0^2 + 0^2\).

  2. With \(c = d = r = s = 0\): \(L_1 = ap - bq\), \(L_2 = aq + bp\), \(L_3 = L_4 = 0\), which is \((a^2 + b^2)(p^2 + q^2) = (ap - bq)^2 + (aq + bp)^2\).

  3. Squares are \(0\), \(1\) or \(4\) modulo \(8\). Sums of three of these give \(0, 1, 2, 3, 4, 5, 6\) modulo \(8\), never \(7\).

  4. \(2 = (\pm1)^2 + (\pm1)^2 + 0^2 + 0^2\): choose the two non-zero places (\(6\) ways) and their signs (\(4\) ways), giving \(24\). Since \(2\) is not divisible by \(4\), Jacobi’s formula gives \(8\sigma(2) = 8 \times 3 = 24\).

7.9Five Platonic Solids

  1. With \(h = 2m + 2n - mn\), \(V = \frac{4m}{h}\), \(E = \frac{2mn}{h}\) and \(F = \frac{4n}{h}\); swapping \(m\) and \(n\) swaps \(V\) and \(F\). The cube and octahedron are dual, as are the dodecahedron and icosahedron; the tetrahedron is self-dual.

  2. \(F = 32\), \(E = \frac12(12 \cdot 5 + 20 \cdot 6) = 90\) and \(V = \frac13(180) = 60\), and \(60 - 90 + 32 = 2\). In general, with \(P\) pentagons and \(H\) hexagons, \(E = \frac12(5P + 6H)\) and \(V = \frac13(5P + 6H)\), so \(V - E + F = -\frac16(5P + 6H) + P + H = \frac P6\). This equals \(2\), so \(P = 12\).

  3. Divide the top and bottom (which have holes) into four trapezia each. Then \(V = 16\), \(F = 4 + 4 + 4 + 4 = 16\) and \(E = 12 + 12 + 8 = 32\), so \(V - E + F = 0\).

  4. \(180^\circ n(1 - \frac2m) < 360^\circ\) is \(n(m - 2) < 2m\), that is, \(mn - 2m - 2n < 0\), or \((m - 2)(n - 2) < 4\). With \(m, n \geq 3\) the solutions are \((3, 3)\), \((3, 4)\), \((4, 3)\), \((3, 5)\) and \((5, 3)\).
