Chapter 8 · Differential Equations and Dynamical Systems

Answers to Try This Next

These are brief answers and hints, not full solutions: they give the result and the key step, so that you can check your own work. Try each exercise properly before looking.

8.1Solutions Aren’t Unique

  1. With \(y = v^2\): \(2vv' = \alpha v - \beta v^2\), so \(v' = \frac12(\alpha - \beta v)\) and \(y_1 = \frac{\alpha^2}{\beta^2}\bigl(1 - \mathrm{e}^{-\beta t/2}\bigr)^2\). With \(y = v^3\): \(v' = \frac13(\alpha - \beta v)\) and \(y_1 = \frac{\alpha^3}{\beta^3}\bigl(1 - \mathrm{e}^{-\beta t/3}\bigr)^3\). The constant \(y = 0\) makes both sides zero; dividing by \(v\) in the derivation threw it away.

  2. \(2\sqrt h = 2\sqrt{h_0} - kt\), so \(h = \bigl(\sqrt{h_0} - \frac12kt\bigr)^2\), and the bucket is empty at \(T = \frac{2\sqrt{h_0}}{k}\). Both \(h \equiv 0\) and \(h = \frac{k^2}{4}(T - t)^2\) for \(t \leq T\), \(h = 0\) for \(t \geq T\), satisfy the equation and are zero from \(T\) on: looking at an empty bucket, you cannot tell when it emptied.

  3. \(\frac{\mathrm{d}}{\mathrm{d}x}(y\mathrm{e}^{-2x}) = (y' - 2y)\mathrm{e}^{-2x} = 0\), so \(y = C\mathrm{e}^{2x}\) and \(y(0) = 0\) forces \(C = 0\). The function \(2y\) is Lipschitz (it changes by at most \(2|y_1 - y_2|\)), while \(2\sqrt y\) has infinite slope at \(0\).

  4. For any \(b \leq 0 \leq a\) (allowing \(b = -\infty\) or \(a = \infty\)): \(y = (x - b)^3\) for \(x < b\), \(y = 0\) for \(b \leq x \leq a\), and \(y = (x - a)^3\) for \(x > a\). The case \(a = b = 0\) is \(y = x^3\).

8.2Without Solving

  1. \(\frac{\mathrm{d}}{\mathrm{d}x}\bigl((y')^2 + y^2\bigr) = 2y'(y'' + y) = 0\), so \((y')^2 + y^2 = A^2\) and \(|y| \leq A\). The exact solution is \(A\cos x\).

  2. \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl((\theta')^2 - 2\cos\theta\bigr) = 2\theta'(\theta'' + \sin\theta) = 0\). Starting at rest, \((\theta')^2 = 2(\cos\theta - \cos\theta_0) \geq 0\), so \(\cos\theta \geq \cos\theta_0\); for \(|\theta_0| < \pi\), continuity keeps \(\theta\) in \([-|\theta_0|, |\theta_0|]\).

  3. \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl((y')^2 + y^2\bigr) = 2y'(y'' + y) = -4k(y')^2 \leq 0\). It does tend to zero, but the monotonicity alone does not show this: you need, for example, the explicit solutions, whose exponents \(-k \pm \sqrt{k^2 - 1}\) have negative real part.

  4. \((y')^2 - \frac12y^4\) is constant, equal to \(-\frac12\). This gives \((y')^2 = \frac12(y^4 - 1)\), which bounds nothing: the “potential” \(-\frac12y^4\) has no well to trap \(y\), and in fact \(y\) blows up in finite time.

8.3a Population

  1. The equation is \(x' = \alpha^2 - (x - K)^2\), which becomes \(y' = y(2\alpha - y)\). With \(w = \frac1y\), \(w' = 1 - 2\alpha w\), so \(w = \frac{1}{2\alpha} + C\mathrm{e}^{-2\alpha t}\). If \(y(0) < 0\) then \(w(0) < 0 < \frac{1}{2\alpha}\), so \(w\) passes through \(0\) in finite time and \(y \to -\infty\); \(x\) reaches \(0\) before that.

  2. With \(z = x - K\), \(z' = -(z^2 + \beta^2)\), so \(\tan^{-1}\frac z\beta = \tan^{-1}\frac K\beta - \beta t\). The population reaches zero (\(z = -K\)) at \(t = \frac2\beta\tan^{-1}\frac K\beta\).

  3. \(x' = x(2K - h - x)\) has equilibria \(0\) and \(2K - h\). For \(h < 2K\) this is the logistic equation with a positive carrying capacity, and every positive solution tends to \(2K - h\). The catch falls as the population falls, so it can never drive the population to zero.

  4. \(x = K + K\tanh Kt\), and \(\tanh Kt = \frac12\) gives \(t = \frac{1}{K}\tanh^{-1}\frac12 = \frac{\ln3}{2K}\).

8.4onto a Circle

  1. The angle \(\psi\) between the curve and the radius satisfies \(\tan\psi = \frac{r}{\mathrm{d}r/\mathrm{d}\theta} = -1\), the same at every point: the curve meets every ray at \(45^\circ\).

  2. \(x\,\mathrm{d}x + y\,\mathrm{d}y = \frac12\,\mathrm{d}(x^2 + y^2) = r\,\mathrm{d}r\). And \(x\,\mathrm{d}y - y\,\mathrm{d}x = r\cos\theta(\sin\theta\,\mathrm{d}r + r\cos\theta\,\mathrm{d}\theta) - r\sin\theta(\cos\theta\,\mathrm{d}r - r\sin\theta\,\mathrm{d}\theta) = r^2\,\mathrm{d}\theta\).

  3. With \(s = r^2\), \(\dot s = 2s(1 - s)\), a logistic equation, so \(s \to 1\) for any \(s(0) > 0\). In Cartesian form: \(\dot x = x(1 - x^2 - y^2) - y\), \(\dot y = y(1 - x^2 - y^2) + x\).

  4. \(\dot r = r(r - 1)(r - 2)\), \(\dot\theta = 1\). Between \(0\) and \(1\), \(\dot r > 0\); between \(1\) and \(2\), \(\dot r < 0\); beyond \(2\), \(\dot r > 0\). So \(r = 1\) attracts and \(r = 2\) repels.

8.5Chasing Greyhounds

  1. By symmetry the dogs always form a square. \(A\) runs along \(AB\) at speed \(v\), closing the gap at rate \(v\); \(B\) runs along \(BC\), which is perpendicular to \(AB\), and so does not change the distance to first order. So \(AB\) shrinks at rate exactly \(v\), from \(s\) to \(0\), in time \(\frac sv\).

  2. \(r = \lambda\mathrm{e}^{-\sqrt3\theta}\). The gap closes at rate \(v - v\cos120^\circ = \frac32v\), so they meet after time \(\frac{2s}{3v}\), each having run \(\frac{2s}{3}\) (which agrees with \(\frac{s}{2\sin^2(\pi/n)}\) for \(n = 3\)).

  3. Each turn multiplies \(r\) by \(\mathrm{e}^{-2\pi} \approx \frac{1}{535}\): after one turn, about \(19\) cm. After two turns, about \(0.35\) mm, so two full turns suffice.

  4. The two dogs run straight at each other and meet in the middle after time \(\frac{s}{2v}\). The formula breaks down: \(\tan\frac\pi2\) is infinite, matching the fact that there is no turning at all.

8.6Quantum Oscillator

  1. This is a direct (if tedious) differentiation; alternatively, it follows from Exercise 4. With \(2\lambda = \omega\), \(\int y_0y_2 = \int(2\omega x^2 - 1)\mathrm{e}^{-\omega x^2}\,\mathrm{d}x = 2\omega \cdot \frac{1}{2\omega}\sqrt{\frac\pi\omega} - \sqrt{\frac\pi\omega} = 0\).

  2. \(y'' = (4\lambda^2x^2 - 2\lambda)y\), so the equation needs \(4\lambda^2 = \omega^2\) and \(2\lambda = (2\nu + 1)\omega\). With \(\lambda = \frac\omega2 > 0\) (for decay), \(\nu = 0\).

  3. \(\frac{\mathrm{d}}{\mathrm{d}x}(y_my_n' - y_ny_m') = y_my_n'' - y_ny_m'' = (m^2 - n^2)y_my_n\). Integrate from \(0\) to \(\pi\): the left side gives \(0\) because \(y_m\) and \(y_n\) vanish at both ends, and \(m^2 \neq n^2\).

  4. Write \(c = (2n + 1)\omega\), so \(y_n'' = (\omega^2x^2 - c)y_n\). Differentiating \(z = \omega xy_n - y_n'\) twice and using this (and its derivative) gives \(z'' - \omega^2x^2z = -(c + 2\omega)z\), and \(c + 2\omega = (2n + 3)\omega\). From \(y_0 = \mathrm{e}^{-\omega x^2/2}\): \(2\omega x\mathrm{e}^{-\omega x^2/2}\), then \(2\omega(2\omega x^2 - 1)\mathrm{e}^{-\omega x^2/2}\), which are multiples of \(y_1\) and \(y_2\).

8.7You Can Solve

  1. (a) By induction: if \(0 < x < 1\) then \(0 < x(1 - x) \leq \frac14\), so \(0 < kx(1 - x) < 1\). (b) \(a = ka(1 - a)\) gives \(k = \frac{1}{1 - a}\). (c) With \(x_1 = ka(1 - a) = ab\), the condition \(x_2 = a\) is \(kab(1 - ab) = a\); using \(k = \frac{b}{1 - a}\) this becomes \(ab^3 - b^2 + 1 - a = 0\). The root \(b = 1\) is the fixed point (\(x_1 = a\)), so factor it out: \(ab^2 + (a - 1)b + (a - 1) = 0\); solving for \(b\) gives \(k = \frac{b}{1 - a}\). Equivalently, the two points of a \(2\)-cycle are the roots of \(k^2x^2 - k(k + 1)x + (k + 1) = 0\), whose discriminant \(k^2(k + 1)(k - 3)\) is positive only when \(k > 3\).

  2. \(p = -1\), \(q = 0\), \(r = -2\): \(4pr = 8 = 8 + 2q - q^2\). Matching coefficients gives \(\alpha = \frac4p = -4\) and \(\beta = \frac{q - 4}{2p} = 2\), so \(v_n = 2 - 4\sin^2(2^n\theta) = 2\cos(2^{n+1}\theta)\), which is \(2\cos(2^n\phi)\) with \(\phi = 2\theta\).

  3. \(u_3 = u_0\) needs \(\sin^2 8\theta = \sin^2\theta\), so \(8\theta = \pm\theta + k\pi\). With \(\theta = \frac\pi7\): the cycle \(\sin^2\frac\pi7 \to \sin^2\frac{2\pi}{7} \to \sin^2\frac{4\pi}{7} \to \sin^2\frac{8\pi}{7} = \sin^2\frac\pi7\). With \(\theta = \frac\pi9\): \(\sin^2\frac\pi9\), \(\sin^2\frac{2\pi}9\), \(\sin^2\frac{4\pi}{9}\). The map \(u \mapsto u_3\) has \(2^3 = 8\) fixed points; two of them (\(0\) and \(\frac34\)) are fixed points of the map itself, leaving \(6\) points of period exactly \(3\): two \(3\)-cycles.

  4. Each step doubles \(\theta\), which loses one binary digit of accuracy, so after roughly \(50\) steps the computed values bear no relation to the true ones. They are not useless: the computed sequence stays close to a true orbit from a slightly different starting point (the shadowing property), so its statistics are still right.

8.8Three Implies Chaos

  1. With \(a\), \(b\), \(c > 0\) and \(d < 0\): \(b = 7 - 2a\), \(c = 7 - 2b\), \(d = 7 - 2c\), \(a = 7 + 2d\). Solving gives \(17a = 49\), so the cycle is \(\frac{49}{17} \to \frac{21}{17} \to \frac{77}{17} \to -\frac{35}{17} \to \frac{49}{17}\), with three points in \(I_2 = [1, 5]\) and one in \(I_1 = [-3, 1]\).

  2. The point found has itinerary \(I_2, I_2, \ldots, I_2, I_1\) (with \(n - 1 \geq 3\) steps in \(I_2\)). The cycle \(1 \to 5 \to -3\) cannot follow this: \(-3\) is not in \(I_2\), so neither \(1\) (whose second image is \(-3\)) nor \(5\) (whose first image is \(-3\)) nor \(-3\) itself can be the point.

  3. The covering diagram is \([1, 2] \to [3, 4], [4, 5]\); \([2, 3] \to [4, 5]\); \([3, 4] \to [2, 3], [3, 4]\); \([4, 5] \to [1, 2]\). The only loop of length \(3\) is \([3, 4] \to [3, 4] \to [3, 4]\), which gives the fixed point, not a \(3\)-cycle.

  4. With \(x = 14y - 7\), \(\frac{\mathrm{f}(x) + 7}{14} = 1 - |2y - 1|\), the tent map. Doubling shifts the binary digits left; if the digit shifted out was \(1\), the result is \(2 - 2y\), which flips the remaining digits. The \(3\)-cycles are \(\frac27 \to \frac47 \to \frac67\) and \(\frac29 \to \frac49 \to \frac89\) (that is, \(x = -3, 1, 5\) and \(x = -\frac{35}{9}, -\frac79, \frac{49}{9}\)); in binary \(\frac27 = 0.\overline{010}\) and \(\frac29 = 0.\overline{001110}\).
