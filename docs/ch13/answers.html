Chapter 13 · Statistics and Randomness in the World

Answers to Try This Next

These are brief answers and hints, not full solutions: they give the result and the key step, so that you can check your own work. Try each exercise properly before looking.

13.1 Reading the Headlines

  1. \(1 - \sum_{k=0}^{6}\mathrm{e}^{-2.96}\frac{2.96^k}{k!} \approx 0.0315\), so seven or more deaths happen on about \(11\) days a year. \(\mathrm{P}(X \geq 9) \approx 0.0035\): about one day a year.

  2. Deaths are \(150K\) with \(K\) Poisson with mean \(1.2\): mean \(180\), variance \(150^2 \times 1.2 = 27\,000\), standard deviation about \(164\). A year with \(125\) deaths or fewer is a year with no crashes, which has probability \(e^{-1.2} \approx 0.30\): entirely ordinary. But exactly \(125\) deaths is impossible in this model, since deaths come only in multiples of \(150\). The mean and standard deviation do not show this: clustering makes the distribution lumpy, with all its probability on \(0\), \(150\), \(300\), and so on.

  3. \(z = \frac{1349.5 - 1080}{33} \approx 8.2\): a probability of order \(10^{-16}\). A steady rate cannot explain \(1350\); something really changed (or the way deaths were counted did).

  4. For example: (i) “Totals alone cannot say whether flying or walking is safer”; (ii) “Air deaths in 1990 within the normal range”; (iii) “Seven pedestrian deaths on Tuesday: a bad day, but one that happens about eleven times a year”; (iv) “Pedestrian deaths up sharply in 1990: cause must be investigated”.

13.2 Counting Voles

  1. \(\frac{p_N}{p_{N-1}} = \frac{(N - M)(N - C)}{N(N - M - C + R)}\), which is at least \(1\) exactly when \(NR \leq MC\). So \(p_N\) increases up to \(N = \frac{MC}{R}\) and then decreases, and the maximum is at its integer part.

  2. Count committees of \(c\) from \(a\) women and \(b\) men by the number \(j\) of women: \(\binom aj\binom{b}{c - j}\) for each \(j\).

  3. \(\frac{\mathrm{d}}{\mathrm{d}p}\bigl(h\ln p + (n - h)\ln(1 - p)\bigr) = \frac hp - \frac{n - h}{1 - p} = 0\) gives \(p = \frac hn\).

  4. With \(R = 0\), \(p_N\) increases for ever, and the estimate is infinite. The method only works if the second sample contains enough marked animals; with few recaptures the estimate is very unstable.

13.3 The German Tank Problem

  1. With \(M\) the maximum, \(\mathrm{E}(M) = \frac{nN}{n + 1}\) and \(\mathrm{Var}(M) = \frac{nN^2}{(n + 1)^2(n + 2)}\), so \(\mathrm{E}(M - N)^2 = \frac{2N^2}{(n + 1)(n + 2)}\). This is \(\frac{2n}{n + 1}\) times \(\mathrm{Var}(Z_1) = \frac{N^2}{n(n + 2)}\): worse. The best multiple is \(c = \frac{N\mathrm{E}(M)}{\mathrm{E}(M^2)} = \frac{n + 2}{n + 1}\), with mean squared error \(\frac{N^2}{(n + 1)^2}\), slightly better than \(Z_1\).

  2. \(\mathrm{E}(\min) = \frac{N}{n + 1}\), and \(\min\) has the same variance as \(M\), so \(\mathrm{Var}\bigl((n + 1)\min\bigr) = \frac{nN^2}{n + 2}\). This does not shrink as \(n\) grows: a poor estimator.

  3. The maximum is at most \(m\) exactly when all \(k\) numbers come from \(\{1, \ldots, m\}\). For \(k = 1\) the estimator is \(2X - 1\), with mean \(2 \cdot \frac{N + 1}{2} - 1 = N\).

  4. \(98 + \frac{98}{5} - 1 = 116.6\): about \(117\) tanks.

13.4 Mean or Median?

  1. Choose which value is the median (\(2n + 1\) ways) and which \(n\) of the rest are below it (\(\binom{2n}{n}\) ways). The probability is \((2n + 1)\binom{2n}{n}y^n(1 - y)^n\,\delta y = \frac{(2n + 1)!}{(n!)^2}y^n(1 - y)^n\,\delta y\).

  2. \(\mathrm{Var}(Y) = \frac{1}{4(2n + 3)} = \frac{1}{20}\) and \(\mathrm{Var}(\bar X) = \frac{1}{12(2n + 1)} = \frac{1}{36}\). The mean is better.

  3. \(\mathrm{Var}(\max) = \mathrm{Var}(\min) = \frac{m}{(m + 1)^2(m + 2)}\) and \(\mathrm{Cov}(\max, \min) = \frac{1}{(m + 1)^2(m + 2)}\), giving \(\frac{1}{2(m + 1)(m + 2)}\). This shrinks like \(\frac{1}{m^2}\), much faster than the mean’s \(\frac{1}{12m}\): for uniform data the extremes carry the information, as with the tanks.

  4. The mean is about \(18.6\), wrecked by one typing error; the median is \(10.1\), unaffected.

13.5 Asking Awkward Questions

  1. Let \(t = ap + bq\), the probability of a true answer. “Yes” has probability \(\frac12t + \frac12(1 - t) = \frac12\), so \(\mathrm{P}(\text{heads} \mid \text{yes}) = t\), which is \(\frac12\) exactly when \(2t = 1\). If the same twin answers twice, “yes” then “no” has probability \(pa(1 - a) + qb(1 - b)\) whether the coin showed heads or tails, so the posterior is \(\frac12\). Two “yes” answers have probabilities \(pa^2 + qb^2\) (heads) and \(p(1 - a)^2 + q(1 - b)^2\) (tails), which are equal exactly when \(2(ap + bq) = 1\).

  2. \(\mathrm{P}(\text{yes}) = \frac34\pi + \frac14(1 - \pi)\), so \(\hat\pi = \frac{0.4 - 0.25}{0.5} = 0.3\). The standard error is \(\frac{\sqrt{0.4 \times 0.6/400}}{0.5} \approx 0.049\).

  3. \(\mathrm{E}(Y^2) = \sum_c\mathrm{P}(C = c)\bigl(\mathrm{Var}(Y \mid c) + \mathrm{E}(Y \mid c)^2\bigr)\); subtracting \(\mathrm{E}(Y)^2 = \bigl(\sum_c\mathrm{P}(C = c)\mathrm{E}(Y \mid c)\bigr)^2\) gives \(\mathrm{E}(\mathrm{Var}(Y \mid C)) + \mathrm{Var}(\mathrm{E}(Y \mid C))\).

  4. \(Z_2\) is close to \(\frac n6\) (heads) or \(\frac{5n}{6}\) (tails), each with probability \(\frac12\). So \(\mathrm{P}(Z_2 > \frac n2) \to \frac12\), although \(Z_2\) is almost never near \(\frac n2\).

13.6 Errors That Add Up

  1. Each truncation error is uniform on \((-1, 0]\); adding \(\frac12\) to each makes it uniform on \((-\frac12, \frac12]\), exactly like rounding. So the corrected VOZ is as good as LEP.

  2. Each error is uniform on \((-0.05, 0.05)\), with variance \(\frac{0.1^2}{12}\), so the total has standard deviation \(\sqrt{10\,000 \times 0.01/12} \approx 2.9\).

  3. \(3000 \times 250 \times 0.0005 = 375\) points.

  4. For two errors, \(1 - |x|\) on \([-1, 1]\). For three: \(\frac34 - x^2\) for \(|x| \leq \frac12\) and \(\frac12\bigl(\frac32 - |x|\bigr)^2\) for \(\frac12 \leq |x| \leq \frac32\), already close to a normal curve.

13.7 Manufacturing Correlation

  1. For standardised variables, \(\mathrm{Var}(X_1 + X_2 + X_3) = 3 + 6\rho \geq 0\), so \(\rho \geq -\frac12\). For \(n\) variables, \(n + n(n - 1)\rho \geq 0\) gives \(\rho \geq -\frac{1}{n - 1}\).

  2. With \(b = \frac{\rho_{23} - \rho_{12}\rho_{13}}{\sqrt{1 - \rho_{12}^2}}\), \((1 - \rho_{12}^2)(1 - \rho_{13}^2 - b^2) = 1 - \rho_{12}^2 - \rho_{13}^2 - \rho_{23}^2 + 2\rho_{12}\rho_{13}\rho_{23} = \det R\). Since \(1 - \rho_{12}^2 > 0\), the two conditions are equivalent.

  3. \(\mathrm{Var} = \frac14(0.04 + 0.09 + 0.12\rho)\): standard deviations \(0.05\), \(0.18\) and \(0.25\) for \(\rho = -1\), \(0\), \(1\). Unless the shares are perfectly correlated, the mix is less risky than the average of the two risks (\(0.25\)).

  4. \(Z_2 = \dfrac{Y_2 - \rho_{12}Y_1}{\sqrt{1 - \rho_{12}^2}}\).
