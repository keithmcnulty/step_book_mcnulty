第1章 · 数論と証明

「次の一歩」の解答

ここに示すのは簡潔な答えとヒントであり、完全な解答ではない。結果と鍵となる段階を示してあるので、自分の答えを確かめるのに使ってほしい。見る前に、それぞれの演習問題にきちんと取り組むこと。

1.1 素数を生み出す工場

  1. 素数（prime）が \(p_1, \ldots, p_k\) ですべてだと仮定すると、\(p_1\cdots p_k + 1\) はこのリストにない素因数（prime factor）をもち、矛盾（contradiction）が生じる。フェルマー数（Fermat number）を用いた証明は構成的（constructive）である。どの2つも互いに素（pairwise coprime）な無限個の数 \(F_0, F_1, \ldots\) を具体的に示し、そのそれぞれが新しい素数を与えるからである。

  2. \(n \geq 2\) のとき \(2^n\) は \(4\) の倍数なので \(2^{2^n} = 16^{2^{n-2}}\) であり、\(16\) の累乗はどれも一の位が \(6\) である。したがって \(F_n\) の一の位は \(7\) である。

  3. (a) 数学的帰納法（induction）による：\(a_{n+1} - 1 = a_n(a_n - 1) = a_n \cdot a_1\cdots a_{n-1}\)。(b) \(a_m\) と \(a_n\)（\(m < n\)）の公約数（common factor）は \(a_1\cdots a_{n-1} = a_n - 1\) と \(a_n\) をともに割り切るので \(1\) である。よって各項は、他のどの項とも共有しない素因数をもつ。(c) \(\frac{1}{a_n} = \frac{1}{a_n - 1} - \frac{1}{a_{n+1} - 1}\) であり、和は次々に打ち消し合って（telescoping）\(1 - \frac{1}{a_{n+1} - 1}\) となる。

  4. (a) \(p \mid F_n\) より \(2^{2^n} \equiv -1\) である。両辺を2乗すると \(2^{2^{n+1}} \equiv 1\) となる。(b) \(d\) は \(2^e \equiv 1\) を満たすすべての \(e\) を割り切るので \(d \mid 2^{n+1}\) である。また（\(p\) は奇数なので）\(2^{2^n} \equiv -1 \not\equiv 1\) であるから \(d \nmid 2^n\) である。よって \(d = 2^{n+1}\) である。(c) \(2^{p-1} \equiv 1\) なので \(2^{n+1} \mid p - 1\) である。(d) \(641 = 64 \times 10 + 1\)。\(641\) 未満で \(64k + 1\) の形の素数は \(193\)、\(257\)、\(449\)、\(577\) である。試すべき候補はわずか4つであり、こうしてオイラー（Euler）は \(641\) を見つけた。

  5. \(n\) 番目の素数は、\(F_0, \ldots, F_{n-1}\) の素因数のうち最大のもの以下であるから、\(p_n \leq F_{n-1} = 2^{2^{n-1}} + 1\) である。\(n = 5\) のときこの上界は \(65\,537\) であるが、\(p_5 = 11\) である。正しいが、極めて弱い評価である。

1.2 素数はどれほどまばらか？

  1. \(P_{1,10} = 210\)、\(P_{1,20} = 9\,699\,690\)、\(P_{1,30} = 6\,469\,693\,230\) である。\(4^{30} \approx 1.15 \times 10^{18}\) および \(e^{30} \approx 1.07 \times 10^{13}\) と比べると、この積は \(4^n\) よりはるかに小さく、おおよそ \(e^n\) のように増大する（実際 \(\ln P_{1,n} \sim n\) であり、これは素数定理（Prime Number Theorem）の一つの形である）。

  2. \(\binom{2m}{k+1}\big/\binom{2m}{k} = \frac{2m - k}{k + 1}\) であり、これはちょうど \(k < m\) のときに \(1\) を超えるので、二項係数（binomial coefficient）は中央まで増加し、その後減少する。和が \(4^m\) となる \(2m + 1\) 個の項のうち最大のものは、それらの平均以上である。

  3. \((\sqrt n, n]\) に含まれる素数はどれも \(\sqrt n\) を超え、それらの積は \(4^n\) より小さいので、\((\sqrt n)^{\pi(n) - \pi(\sqrt n)} < 4^n\) である。両辺の対数をとればよい。\(2\ln4 \approx 2.77\) かつ \(\pi(\sqrt n) \leq \sqrt n\) なので、求める評価が従う。この評価は正しい形 \(n/\ln n\) をもつが、定数は真の値 \(1\) ではなく \(2.8\) である。

  4. 素数 \(2, 3, 5, 7, 13, 23, 43, 83\) を用いる。どれも直前の素数の2倍より小さい。\(n \leq 50\) である任意の \(n\) に対して、このリストで \(n\) より大きい最初の素数は、直前の素数（これは \(n\) 以下である）の2倍より小さいので、\(n\) と \(2n\) の間にある。

1.3 最小の反例

  1. \(k\sqrt3\) が整数となる最小の正の整数 \(k\) があるとすると、\(k' = (\sqrt3 - 1)k\) はそれより小さい正の整数であり、しかも \(k'\sqrt3 = 3k - k\sqrt3\) は整数である。ここでは数 \(\sqrt3 - 1\) が \(\sqrt2 - 1\) の役割を果たしている。

  2. \(0 < \sqrt N - m < 1\) とすると、\(k' = (\sqrt N - m)k\) は \(k\) より小さい正の整数であり、\(k'\sqrt N = kN - mk\sqrt N\) は整数である。これは矛盾である。

  3. \(N = 4\) のとき \(m = 2 = \sqrt4\) なので \(\sqrt N - m = 0\) となり、\(k' = 0\) は正の整数ではない。「\(0 < \sqrt N - m\)」という段階が成り立たない。

  4. 図において、一辺 \(a\) の正方形の内部で重なり合う一辺 \(b\) の2つの正方形は、一辺 \(2b - a\) の中央の正方形を2重に覆い、一辺 \(a - b\) の2つの正方形を覆わずに残す。代数的には \((2b - a)^2 - 2(a - b)^2 = 2b^2 - a^2 = 0\) である。

1.4 \(e\) は無理数であり、\(e^2\) もまた無理数である

  1. \(\frac1e = \frac pq\) とすると、\(\frac1e = \sum_{k \geq 0}\frac{(-1)^k}{k!}\) の両辺に \(q!\) を掛ける。\(k \leq q\) の項は整数であり、残りの和 \(\sum_{k > q}(-1)^kq!/k!\) は項が減少する交代級数（alternating series）なので、その絶対値は \(0\) と \(\frac{1}{q+1}\) の間に厳密にある。よって \(q!/e\) は整数ではなく、矛盾である。

  2. \(\sin 1 = \frac pq\) とすると、\(2n + 1 \geq q\) として両辺に \((2n + 1)!\) を掛ける。左辺は整数であり、級数の \(\frac{1}{(2n+1)!}\) までの項も整数である。残りの和は交代級数で、その初項の大きさは \(\frac{1}{(2n+2)(2n+3)} < 1\) なので、整数ではない。

  3. この方法には、\(\frac{1}{k!}\) のように、残りの和が分母の増大よりも速く小さくなる、有理数の項からなる級数が必要である。\(\pi\) についてはそのような級数は知られていない。ニーヴン（Niven）の証明は \(\int_0^\pi\frac{x^n(\pi - x)^n}{n!}\sin x\,\mathrm{d}x\) を用いる。もし \(\pi\) が有理数ならば、これは十分大きな \(n\) に対して \(1\) より小さい正の整数となってしまう。

  4. \(x^2 - (e + \pi)x + e\pi\) の根は \(e\) と \(\pi\) である。\(e + \pi\) と \(e\pi\) がともに代数的（algebraic）であれば、\(\pi\) は代数的な係数をもつ多項式の根となり、したがって代数的となって、リンデマン（Lindemann）の定理に矛盾する。

1.5 無限降下法

  1. \(3 \mid a\) である。\(a = 3a_1\) とおくと \(9a_1^3 + b^3 = 3c^3\) となるので \(3 \mid b\)、さらに \(3a_1^3 + 9b_1^3 = c^3\) となるので \(3 \mid c\) であり、\((a_1, b_1, c_1)\) はより小さい解となる。これが無限降下法（descent）である。\(p^4 + 2q^4 = 5r^4\) について：4乗数は \(5\) を法として（modulo）\(0\) か \(1\) である（一の位が \(0\)、\(1\)、\(5\)、\(6\) のいずれかである）ので、\(p^4 + 2q^4 \equiv 0\) から \(5 \mid p\) かつ \(5 \mid q\) が導かれる。すると \(5^4 \mid 5r^4\) なので \(5 \mid r\) となり、再び無限降下法が使える。

  2. 平方数は \(4\) を法として \(0\) か \(1\) なので、\(x^2 + y^2\) は \(0\)、\(1\)、\(2\) のいずれかであり、\(3\) になることはない。

  3. 有理点（rational point）\((\frac ac, \frac bc)\) があれば、\(c \neq 0\) で \(a^2 + b^2 = 3c^2\) となるが、これは小問 (iii) で否定されている。

  4. \(x\)、\(y\) を固定すると、この方程式は2次方程式 \(z^2 - 3xyz + (x^2 + y^2) = 0\) であり、その2つの根の和は \(3xy\) である。\((1,1,1)\) から \((1,1,2)\) が得られる。\((1, 2)\) の反対側にある \(1\) を置き換えると \(3 \cdot 1 \cdot 2 - 1 = 5\) となり、\((1,2,5)\) が得られる。続いて \((1,5,13)\) と \((2,5,29)\) が得られる。

1.6 二つの平方数の和

  1. 平方数は \(4\) を法として \(0\) か \(1\) なので、2つの平方数の和が \(4\) を法として \(3\) になることはない。

  2. \(65 = 1^2 + 8^2 = 4^2 + 7^2\)、\(85 = 2^2 + 9^2 = 6^2 + 7^2\) である。\(65 = (2 + \mathrm{i})(2 - \mathrm{i})(3 + 2\mathrm{i})(3 - 2\mathrm{i})\) と分解すると、\((2 + \mathrm{i})(3 + 2\mathrm{i}) = 4 + 7\mathrm{i}\)、\((2 + \mathrm{i})(3 - 2\mathrm{i}) = 8 - \mathrm{i}\) となる。同様に \(85\) については、\((2 + \mathrm{i})(4 \pm \mathrm{i})\) から \(7 + 6\mathrm{i}\) と \(9 - 2\mathrm{i}\) が得られる。

  3. \(1105 = 4^2 + 33^2 = 9^2 + 32^2 = 12^2 + 31^2 = 23^2 + 24^2\) である。\(5\)、\(13\)、\(17\) はそれぞれ、ガウス整数（Gaussian integer）とその共役（conjugate）の積に分解する。各組から因数を1つずつ選ぶと \(8\) 個の積が得られ、それらは互いに共役なもの同士（同じ平方和を与える）で対になるので、\(4\) 個が残る。

  4. 絶対値の2乗をとると \(9 = (a^2 + b^2)(c^2 + d^2)\) となる。\(3\) は2つの平方数の和ではないので、一方の因数は \(1\) である。

1.7 因数分解が破綻するとき

  1. \(693 = 9 \times 77 = 21 \times 33\) であり、4つの因数はすべて \(S\) 素数である。作り方：\(4k + 3\) の形の4つの素数 \(p, q, r, s\) をとる。すると \((pq)(rs) = (pr)(qs)\) により、\(S\) 素数への2通りの分解が得られる。

  2. \(E\) 素数は \(2 \pmod 4\) である数である（2つの偶数の積にはなりえないからである）。\(60 = 2 \times 30 = 6 \times 10\)。

  3. \(N(zw) = N(z)N(w)\) は \((ac - 5bd)^2 + 5(ad + bc)^2\) を展開すれば確かめられる。\(a^2 + 5b^2\) が \(2\) や \(3\) になることはない。\(N(2) = 4\)、\(N(3) = 9\)、\(N(1 \pm \sqrt{-5}) = 6\) なので、単数（unit）でない元への分解には、ノルム（norm）が \(2\) または \(3\) の因数が必要になる。

  4. 2通りの異なる分解 \(p_1\cdots p_r = q_1\cdots q_s\) をもつ最小の数を \(n\) とする。ユークリッド（Euclid）の補題により \(p_1\) はある \(q_j\) を割り切るので、\(p_1 = q_j\) である。これを約すと、2通りの異なる分解をもつより小さい数が得られ、矛盾する。

1.8 有理数を数える

  1. \(\frac35\)：親をたどると \((3, 5) \leftarrow (3, 2) \leftarrow (1, 2) \leftarrow (1, 1)\) となり、位置は \(1 \to 2 \to 5 \to 10\) なので \(f(10) = \frac35\) である。\(\frac53\)：\((5, 3) \leftarrow (2, 3) \leftarrow (2, 1) \leftarrow (1, 1)\) であり、位置は \(1 \to 3 \to 6 \to 13\) なので \(f(13) = \frac53\) である。

  2. Newman の規則 \(x_{n+1} = \frac{1}{2\lfloor x_n\rfloor - x_n + 1}\) からは \(1\)、\(\frac12\)、\(2\)、\(\frac13\)、\(\frac32\)、\(\frac23\)、\(3\)、\(\frac14\)、\(\frac43\)、\(\frac35\) が得られ、これは \(f(1), \ldots, f(10)\) と一致する。

  3. \(n\) 番目の数の小数第 \(n\) 位が \(5\) でなければ、新しい数の小数第 \(n\) 位を \(5\) とし、\(5\) ならば \(4\) とする。こうしてできる小数はリストのどの数とも異なり、しかも \(0\) と \(9\) を避けているので小数展開がただ1通りであるから、確かに異なる数である。

  4. すべての正の整数は、\(2\) の累乗と奇数の積 \(2^{m-1}(2n - 1)\) としてただ1通りに表せるので、\((m, n) \mapsto 2^{m-1}(2n - 1)\) は全単射（bijection）である。

1.9 三次曲線の接線

  1. \(y = t(x + 1)\) を \(x^2 + y^2 = 1\) に代入すると \((1 + t^2)x^2 + 2t^2x + t^2 - 1 = 0\) となり、その根は \(-1\) と \(\frac{1 - t^2}{1 + t^2}\) である。\(t = \frac qp\) とするとその点は \(\bigl(\frac{p^2 - q^2}{p^2 + q^2}, \frac{2pq}{p^2 + q^2}\bigr)\) となり、三つ組 \((p^2 - q^2, 2pq, p^2 + q^2)\) が得られる。

  2. 直線は \(x + y = 3\) であり、\(x^3 + (3 - x)^3 = 9\) は \(9x^2 - 27x + 18 = 0\) に帰着する。3次の項が打ち消し合い、\(x = 1, 2\) だけが残るのである。この直線は漸近線（asymptote）\(y = -x\) に平行であり、第3の交点は無限遠にある。

  3. 接線（tangent）の傾きは \(\frac{x^2}{y^2} = \frac{289}{400}\) であり、接線は曲線と再び \(\bigl(-\frac{188479}{90391}, -\frac{36520}{90391}\bigr)\) で交わる。分母を払うと \(188479^3 = 36520^3 + 90391^3 + 180782^3\) となる。

  4. この直線は \(x^3 + y^3 = 1729\) と再び \(\bigl(-\frac{37}{3}, \frac{46}{3}\bigr)\) で交わるので、\(46^3 = 37^3 + 27 \times 1729 = 37^3 + 3^3 + 36^3\) である（\(27 = 3^3\) と \(27 \times 1728 = 36^3\) を用いた）。
