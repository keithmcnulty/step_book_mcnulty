素数を生み出す工場

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第1章章全体のPDF
問題

STEP II 2002、第3問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/02-s2-q3

導入

素数（prime）が無限に存在することは、ほぼ間違いなくすでに知っているだろう。ユークリッド（Euclid）が紀元前300年頃に証明したもので、誰もが最初に出会う証明の一つである。では、なぜ STEP の問題がそれをもう一度証明させるのだろうか。

それは、この証明がまったく異なる仕組みで働くからである。ユークリッドの議論は「素数の有限なリストを一つ与えよ。それが不完全であることを示してみせよう」というものである。一方この証明は「ここに、あらかじめ書き下された一つの具体的な数列がある。そのどの項も、他のどの項にも含まれない素数を含んでいる」と主張する。これは新しい素数を次々と生み出す機械であり、それが機能する理由は、問題が導いてくれる美しく単純な恒等式にある。

その途中で、フェルマー本人さえも欺いた数に出会うことになる。

取りかかる前に

まず問題を一通り読み、その構成に注目しよう。四つの段階からなっている。

  1. いくつかの例を計算する。

  2. パターンを見つけ（というより、教えてもらい）、それらの例で確かめる。

  3. そのパターンを一般に証明する。

  4. そのパターンを二度使う。まず公約数（common factor）についての結論を導き、次に素数についての結論を導く。

この「例 \(\to\) 予想（conjecture） \(\to\) 証明 \(\to\) 帰結」という構造は、実際に多くの数学が行われる方法そのものであり、STEP の問題もしばしばこの流れに従う。これに気づいたら、前半の小問は単なる準備運動ではないことが多い。後で必要になる直観を養う場所なのである。

最後の行は無限に多くの素数について問うている。中ほどでは公約数について問うている。「どの二つのフェルマー数も共通の約数をもたない」ことと「素数は無限に存在する」こととは、いったいどうつながりうるのだろうか。

この問いを心に留めておこう。後で戻ってくる。

順を追って解く

段階 1 数の感触をつかむ

記法に注意しよう。\(2^{2^n}\) は \(2^{(2^n)}\) を意味し、\((2^2)^n\) ではない。指数そのものが2の累乗なので、これらの数は非常に速く大きくなる。 \[\begin{aligned} F_0 &= 2^{1} + 1 = 3, &\qquad F_2 &= 2^{4} + 1 = 17,\\ F_1 &= 2^{2} + 1 = 5, &\qquad F_3 &= 2^{8} + 1 = 257. \end{aligned}\]

これら四つの数について、何に気づくだろうか。

すべて素数である。（\(257\) を確かめよう。これは \(2, 3, 5, 7, 11\) のいずれでも、また \(13\) でも割り切れず、\(17^2 = 289 > 257\) なので、ここで調べるのをやめてよい。）次の \(F_4 = 2^{16} + 1 = 65537\) も素数である。ピエール・ド・フェルマー（Pierre de Fermat）は1640年にまさにこのことに気づき、この形の数はすべて素数であると予想した。このことを覚えておこう。彼が正しかったかどうかは後で見る。

段階 2 恒等式を確かめる

次に、小さな \(k\) について \((*)\) を確かめよう。

  • \(k = 1\)：左辺は単に \(F_0 = 3\) であり、\(F_1 - 2 = 3\) である。

  • \(k = 2\)：\(F_0 F_1 = 3 \times 5 = 15\) であり、\(F_2 - 2 = 15\) である。

  • \(k = 3\)：\(F_0 F_1 F_2 = 15 \times 17 = 255\) であり、\(F_3 - 2 = 255\) である。

\(k = 2\) から \(k = 3\) への移り変わりを見てみよう。\(15\) に \(17\) を掛けて \(255\) を得た。フェルマー数（Fermat number）の言葉で言えば、\((F_2 - 2) \times F_2\) を計算して \(F_3 - 2\) を得たことになる。これは偶然だろうか。

この観察こそが、証明全体の縮図である。なぜそれが成り立つはずなのかを見ていこう。

段階 3 恒等式を証明する

先を読む前に、 \[(F_k - 2)\, F_k = F_{k+1} - 2.\] を直接示してみよう。 ヒント：すべてを2の累乗で表してみよ。\(F_k - 2\) はどのような形をしているか。

\(F_k - 2 = 2^{2^k} - 1\) かつ \(F_k = 2^{2^k} + 1\) であるから、 \[(F_k - 2)\, F_k = \bigl(2^{2^k} - 1\bigr)\bigl(2^{2^k} + 1\bigr).\]

これは \((a - 1)(a + 1)\) の形の積である。これは何に等しいか。

これは平方の差（difference of two squares）\(a^2 - 1\) である。\(a = 2^{2^k}\) とすると、 \[a^2 = \bigl(2^{2^k}\bigr)^2 = 2^{2 \cdot 2^k} = 2^{2^{k+1}},\] したがって \[(F_k - 2)\, F_k = 2^{2^{k+1}} - 1 = F_{k+1} - 2. \tag{$\dagger$}\] これが原動力である。2乗することが何をしているかに注目しよう。2乗は指数を2倍にし、\(2^k\) を2倍すると \(2^{k+1}\) になる。フェルマー数の定義は、平方の差による因数分解にぴったり合うように作られているのである。

ここまで来れば、帰納法（induction）はほとんど自動的である。

帰納法のステップでは、正確には何を示す必要があるか。

ある \(k \geq 1\) について \((*)\)、すなわち \[F_0 F_1 \cdots F_{k-1} = F_k - 2,\] が成り立つと仮定し、\(k + 1\) についても成り立つこと、すなわち \[F_0 F_1 \cdots F_{k-1} F_k = F_{k+1} - 2.\] を示したい。仮定の両辺に \(F_k\) を掛け、\((\dagger)\) を用いると \[F_0 F_1 \cdots F_{k-1} F_k = (F_k - 2)\, F_k = F_{k+1} - 2.\] となる。\(k = 1\) はすでに確かめたので、数学的帰納法により \((*)\) はすべての \(k \geq 1\) について成り立つ。■

帰納法をまったく使わずに済ませることはできただろうか。

できる。その方法を見ておく価値がある。\(F_0 - 2 = 1\) から出発して、\((\dagger)\) を繰り返し適用すると \[F_k - 2 = (F_{k-1} - 2) F_{k-1} = (F_{k-2} - 2) F_{k-2} F_{k-1} = \cdots = (F_0 - 2)\, F_0 F_1 \cdots F_{k-1}.\] となる。\(F_0 - 2 = 1\) であるから、これで示された。この「展開」は実は同じ帰納法をすべて書き下したものにすぎないが、こちらのほうが見通しやすいと感じる人もいる。

段階 4 共通の約数はない

\(m \neq n\) ならば \(F_m\) と \(F_n\) が \(1\) より大きい公約数をもたないことを示したい。

ある数 \(d\) が \(F_m\) と \(F_n\) の両方を割り切るとし、\(m < n\) とする。\(F_m\) は \((*)\) のどこに現れるか。

\((*)\) で \(k = n\) とすると \[F_0 F_1 \cdots F_m \cdots F_{n-1} = F_n - 2.\] \(m < n\) であるから、\(F_m\) は左辺の因数の一つである。よって \(d\) が \(F_m\) を割り切るならば、\(d\) は左辺全体を割り切る。すなわち、\(d\) は \(F_n - 2\) を割り切る。

さて、\(d\) は \(F_n\) と \(F_n - 2\) の両方を割り切る。ほかに何を割り切らなければならないか。

それらの差である。\(d\) は \(F_n - (F_n - 2) = 2\) を割り切る。よって \(d = 1\) または \(d = 2\) である。

\(d\) は \(2\) でありうるか。

ありえない。どのフェルマー数も2の累乗に1を加えたものなので奇数である。したがって \(d = 1\) であり、相異なる二つのフェルマー数が \(1\) より大きい共通の約数をもつことはない。■

数学者はこれを、フェルマー数はどの二つも互いに素（pairwise coprime）であるという。

段階 5 素数は無限に存在する

ここで、最初に立てた問いに戻ろう。

\(1\) より大きいすべての整数は、少なくとも一つの素因数（prime factor）をもつ。各フェルマー数から素因数を一つずつ選ぶ。選んだ素数について何が言えるか。

\(p_n\) を \(F_n\) を割り切る任意の素数とする。もしこれらのうち二つが等しい、たとえば \(m \neq n\) で \(p_m = p_n\) であるとすると、その素数は \(F_m\) と \(F_n\) の \(1\) より大きい公約数となるが、これは先ほど不可能であると示した。したがって素数 \[p_0,\; p_1,\; p_2,\; p_3,\; \ldots\] はすべて相異なる。フェルマー数は無限に存在するので、相異なる素数も無限に存在する。■

各フェルマー数をどの素数が割り切るのかを知る必要はまったくなかったし、フェルマー数自身が素数かどうかさえ知る必要がなかったことに注目しよう。必要だったのは、それらが決して共通の約数をもたないということだけである。各フェルマー数は、他のどれも使えない素数を少なくとも一つ「使い切る」ことを強いられているのである。

振り返り

何がこの議論をうまく機能させたのかを立ち止まって確かめておく価値がある。同じ考え方は本書で何度も現れるからである。

  • 例は飾りではなかった。\(15 \times 17 = 255\) が「\((F_2 - 2) \times F_2 = F_3 - 2\)」であると見抜くことこそが、鍵となる考え方だったのである。問題が小さな場合を与えてくれたら、数値が一致するかどうかだけでなく、各ステップが何をしているのかを問おう。

  • 一つの恒等式がすべての仕事をした。すべては \((a-1)(a+1) = a^2 - 1\) から流れ出た。難しそうに見える STEP の問題は、しばしば一つの単純な代数計算によって動いている。

  • 最後の議論は大きさではなく構造についてのものである。新しい素数を一つも見つけることなく、素数が無限に存在することを証明した。その代わりに、無限個の数の族を作り上げるには無限に多くの素数が必要であることを示したのである。

背後にある数学

フェルマーは正しかったか

正しくなかった。1732年、レオンハルト・オイラー（Leonhard Euler）は \[F_5 = 2^{32} + 1 = 4\,294\,967\,297 = 641 \times 6\,700\,417.\] であることを示した。オイラーは偶然 \(641\) を見つけたのではない。彼は \(F_n\) の素因数はきわめて特殊な形をしていなければならないこと（\(n = 5\) のときは、\(64\) の倍数に1を加えた数でなければならないこと）を証明し、それによって候補を大幅に絞り込んだのである。このことは演習 4で自分で証明できる。

それ以来、これまでに調べることができた \(F_5\) から \(F_{32}\) までのすべてのフェルマー数は、合成数（composite）であることが判明している。知られている限りでは、\(F_0\) から \(F_4\) までが唯一のフェルマー素数かもしれないが、それを証明できた者はいない。これは正真正銘の未解決問題である。

愉快なひねりは、私たちの証明はそのことをまったく気にしないという点である。素数であれ合成数であれ、フェルマー数はやはり無限に多くの素数を生み出すのである。

フェルマー素数と多角形の作図

フェルマー素数は、まったく思いがけない場所に現れる。古代ギリシャ人は定規とコンパスで正三角形と正五角形を作図する方法を知っていたが、\(3 = F_0\) かつ \(5 = F_1\) であることに注目しよう。二千年もの間、辺の数が素数であるそれ以外の正多角形を作図できた者はいなかった。そして1796年、19歳のカール・フリードリヒ・ガウス（Carl Friedrich Gauss）が正17角形の作図法を示した。そして \(17 = F_2\) である。

ガウスはさらに進んだ。正 \(N\) 角形が定規とコンパスで作図できるのは、\(N\) が2の累乗と相異なるフェルマー素数の積であるときであり、かつそのときに限る。（Pierre Wantzel が1837年に証明を完成させた。）つまり、どの多角形が作図できるかは、フェルマー素数がいくつあるかに依存するのである。ガウスの17角形の背後にある鍵となる計算には 第 6.2 節（STEP II 1991, Question 4）で出会うことになる。そして物語の全貌は、大学の学部課程の白眉の一つであるガロア理論（Galois theory）に属している。

一つの定理、多くの証明

数学者はなぜ同じ定理を何度も証明しようとするのだろうか。それは、異なる証明が異なることを明らかにするからである。この証明は通常、クリスティアン・ゴールドバッハ（Christian Goldbach）が1730年にオイラーに宛てた手紙によるものとされるが、これは、1より大きい整数からなり、どの二つも互いに素であるような任意の無限数列が、無限に多くの素数の存在を導くことを示している。フェルマー数はその便利な一例にすぎない。（演習 3で別の例を扱う。）

この証明はまた、ユークリッドの証明よりも多くのことを教えてくれる。素数 \(p_0, p_1, \ldots, p_{n-1}\) は \(n\) 個の相異なる素数であり、それぞれ \(F_{n-1}\) 以下である。したがって、\(2^{2^{n-1}} + 1\) 以下の素数は少なくとも \(n\) 個ある。これは素数がどのように分布しているかについての定量的（quantitative）な主張である。非常に弱い主張ではある（実際にはずっと良いことが成り立つ）が、素数がどのようにまばらになっていくかを正確に記述する、19世紀数学の偉大な成果の一つである素数定理（Prime Number Theorem）への第一歩なのである。第 1.2 節 でその次の一歩を踏み出す。

思考のスキル

構造的な性質から議論を組み立てる

種類Aの対象が無限に存在することを示すには、種類Bの対象を無限に見つけ、そのそれぞれが自分専用の種類Aの対象を必要とするようにせよ。

ここではA = 素数、B = フェルマー数であり、「自分専用のものを必要とする」とは「他のどれとも共有しない素因数をもつ」ことを意味する。同じパターンは、数え上げの議論や、線形代数（無限に多くの一次独立なベクトルがあれば次元は無限になる）、そして解析学にも現れる。

また、帰納法、とりわけ「\(k\) から \(k+1\) へのステップは実際に何をしているのか」と問う習慣も練習した。この問いは、形式的なひな形よりも役に立つことが多い。

次の一歩

  1. ユークリッドの証明。素数が無限に存在することのユークリッドによる証明を書き出せ。それはどのような意味で「背理法（contradiction）による」証明であり、フェルマー数による証明はどのような意味で「構成的（constructive）」な証明であるか。

  2. 一の位の数字。\(n \geq 2\) のとき、フェルマー数 \(F_n\) の一の位は \(7\) であることを示せ。

  3. シルベスター（Sylvester）の数列。\(a_1 = 2\)、\(a_{n+1} = a_n^2 - a_n + 1\) と定める。この数列は \(2, 3, 7, 43, 1807, \ldots\) と始まる。

    1. \(a_{n+1} - 1 = a_1 a_2 \cdots a_n\) を示せ。

    2. 各項はどの二つも互いに素であることを導き、それにより素数が無限に存在することの別証明を与えよ。

    3. 発展 \(\dfrac{1}{a_1} + \dfrac{1}{a_2} + \cdots + \dfrac{1}{a_n} = 1 - \dfrac{1}{a_{n+1} - 1}\) を示せ。

  4. オイラーの技法。この問題ではフェルマーの小定理（Fermat’s Little Theorem）を用いる。すなわち、\(p\) が素数で \(p \nmid a\) ならば \(a^{p-1} \equiv 1 \pmod{p}\) である。素数 \(p\) が \(F_n\) を割り切るとする。

    1. \(2^{2^n} \equiv -1 \pmod p\) を示し、それにより \(2^{2^{n+1}} \equiv 1 \pmod p\) を示せ。

    2. \(d\) を \(2^d \equiv 1 \pmod p\) を満たす最小の正の整数とする。\(d\) は \(2^{n+1}\) を割り切るが \(2^n\) は割り切らないことを示し、\(d = 2^{n+1}\) であると結論せよ。

    3. フェルマーの小定理を用いて、\(d\) が \(p - 1\) を割り切ることを示せ。それにより \(p \equiv 1 \pmod{2^{n+1}}\) を導け。

    4. \(n = 5\) のとき、これは \(F_5\) の任意の素因数が \(64k + 1\) の形をしていることを意味する。\(641\) がこの形であることを確かめよ。\(641\) より小さいこの形の素数はいくつあるか。

  5. 素数の上界。一つの定理、多くの証明の議論を用いて、\(n\) 番目の素数は \(2^{2^{n-1}} + 1\) 以下であることを示せ。\(n = 5\) のとき、この上界はどの程度良いか。

さらに学ぶために

  • Martin Aigner & Günter M. Ziegler, Proofs from THE BOOK（Springer）、第 1 章「Six proofs of the infinity of primes」（素数が無限に存在することの六つの証明）。この証明が、ユークリッドの証明や、位相空間論を用いるものを含む他の四つの証明とともに収められている。大学入学前に読める最良の本の一つである。

  • Harold Davenport, The Higher Arithmetic（Cambridge University Press）、第 1–2 章。素数と素因数分解への見事な筆致の入門書であり、大学入学前の夏に読むのに理想的である。

  • Michal Křížek, Florian Luca & Lawrence Somer, 17 Lectures on Fermat Numbers（Springer, 2001）。オイラーによる因数分解からガウスの多角形まで、フェルマー数のすべてが書かれている。最初のほうの章を拾い読みするとよい。

  • Ian Stewart, Why Beauty Is Truth（Basic Books）、ガウスについての章。17角形の物語が一般読者向けに語られている。
