第1章 \(\cdot\) 序論

なぜ整数なのか

数学は科学の女王であり、数論は数学の女王である。

— カール・フリードリヒ・ガウス（Carl Friedrich Gauss）

整数（whole numbers）は、誰もが最初に出会う数学的対象である。字が読めるようになる前から、私たちは数を数えることを覚えた。それにもかかわらず、整数についてのごく単純な問いが、恐ろしく難しいことがある。2 より大きいすべての偶数は、2つの素数（prime）の和で表せるだろうか。答えは誰にもわからない。クリスティアン・ゴールドバッハ（Christian Goldbach）が1742年にこの問いを立て、コンピュータは \(4 \times 10^{18}\) を超えるところまで確かめたが、いまだに証明されていない。\(11\) と \(13\)、\(101\) と \(103\) のように、差が 2 である素数の組は無限に存在するだろうか。これも誰にもわからない。もっとも2013年には、ほとんど無名の数学者であった張益唐（Yitang Zhang）が、差が高々 \(70\) 百万である素数の組が無限に存在することを証明して世界を驚かせた。この値はその後 \(246\) まで引き下げられている。ピエール・ド・フェルマー（Pierre de Fermat）は1637年、\(n \geq 3\) のとき \(x^n + y^n = z^n\) は正の整数解をもたない、と本の余白に書き付けた。アンドリュー・ワイルズ（Andrew Wiles）が1994年にフェルマーの正しさを証明するまでには、350年以上の歳月と、これまでに生み出された中でも最も高度な数学のいくつかが必要であった。

子どもにも理解できる問いと、何世紀もかかりうる答え。この組み合わせこそが、数論（number theory）を病みつきにさせるものである。そしてこれは、数論がつねに証明（proof）の訓練の場であり続けてきた理由でもある。整数は無限に存在するので、すべての場合を確かめることはできない。そのようなときは、すべての場合を一度に扱える論証を見つけなければならない。これから先の数学人生で使うことになる証明の技法の多くは、もともと整数についての問いを通して磨かれたものである。

純粋で、役に立たず、そしてインターネットを支えるもの

1940年、ケンブリッジの数学者ハーディ（G. H. Hardy）は、数論はあらゆる数学の中で最も純粋なものであり、日常生活からあまりにかけ離れているので実用には使えず、したがって有害な用途にも使えない、といくらか誇らしげに書いた。これほど見当違いの予言もなかなかない。オンラインで買い物をするとき、安全なメッセージを送るとき、スマートフォンのロックを解除するとき、私たちは数論に頼っている。RSA 暗号（1977年）は、2つの大きな素数を掛け合わせるのは簡単だが、その積からもとの素数を復元するのは絶望的に難しいと考えられている、という事実に基づいている。現代の暗号方式は、この章の最後に登場する曲線そのものの算術を利用している。18世紀と19世紀の「役に立たない」数学は、21世紀の安全を支えるものとなったのである。

大学で出会うもの

大学で数学を学ぶなら、数論は最初に訪れる場所のひとつであり、最後に行き着く場所のひとつでもある。

  • 最初の学期には、ほぼ間違いなく「数と集合（Numbers and Sets）」や「数学の基礎（Foundations）」といった名前の講義を受けることになる。そこでは証明をきちんと書く方法を学ぶが、その素材の多くは数論である。帰納法（induction）、ユークリッドの互除法（Euclidean algorithm）、合同算術（modular arithmetic）、フェルマーの小定理（Fermat’s Little Theorem）、中国剰余定理（Chinese Remainder Theorem）、そして無限集合の中には他より大きいものがあるという驚くべき事実などである。

  • 群論（group theory）では（通常は1年目に学ぶ）、数論の多くの事実が、対称性についてのただひとつの定理、すなわちラグランジュの定理（Lagrange’s Theorem）の影であることを知るだろう。

  • 2年目には、数論の講義で、平方剰余の相互法則（quadratic reciprocity、ガウスの「黄金定理」）、連分数（continued fractions）、ペル方程式（Pell’s equation）を扱うのが普通である。

  • その先にはさらに進むことができる。ガウス整数（Gaussian integers）のような新しい数の体系によって素因数分解の一意性（unique factorisation）を救い出す代数的整数論（algebraic number theory）、微積分と複素解析（complex analysis）を用いて素数を数える解析的整数論（analytic number theory）、そしてフェルマーの最終定理（Fermat’s Last Theorem）の証明や、賞金100万ドルの7つのミレニアム懸賞問題（Millennium Prize Problems）のひとつの背後にある楕円曲線（elliptic curves）の理論である。

この章を貫く問い

この章の9つの STEP の問題は、3つの大きな問いのまわりを巡っている。問題に取り組む間、これらを頭の片隅に置いておいてほしい。章の最後で再びこれらに立ち返る。

  1. 素数はいくつあり、どのように分布しているのか。 素数が無限に存在することは誰もが知っている。しかし、素数はどれほどまばらになっていくのか。そして、どのような論証がそれを教えてくれるのか。

  2. ある数が分数ではないことは、どうすれば証明できるのか。 ある数が有理数（rational）であることを示すには、例をひとつ挙げればよい。しかし無理数（irrational）であることを示すには、無限に多くの可能性を排除しなければならない。そんなことがいったいどうすればできるのか。

  3. どの方程式が整数解をもつのか。そして、数の体系を変えると何が起こるのか。 方程式が解をまったくもたないことを示せる場合もある。また、整数を理解する最善の方法が、整数の外に出て、複素数の世界や曲線の上に踏み出すことである場合もある。

証明についての章

これら3つの問いの底には、第4のテーマが流れている。それはどのように証明するかである。各節は、異なる証明の方法が実際に働くところを示すという理由もあって選ばれており、全体として大学1年生にとって十分な道具箱になっている。
