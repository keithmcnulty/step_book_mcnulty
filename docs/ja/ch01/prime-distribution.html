素数はどれほどまばらか？

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第1章章全体のPDF
問題

STEP III 2016、第5問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/16-s3-q5

導入

第 1.1 節 では、素数（prime）が無限に存在することを見た。しかし「無限に存在する」というのは大ざっぱな主張である。素数は確かにまばらになっていく。\(100\) 未満の素数は \(25\) 個あるが、\(900\) と \(1000\) の間には \(14\) 個しかない。では、素数はどの程度まばらになるのだろうか。

この問題で証明するのは、一見ごく控えめな事実である。\(n\) 以下のすべての素数を掛け合わせると、その積は \(4^n\) より小さい。しかしこの何気ない不等式（inequality）こそが「どの程度まばらか」という問いに答えるための最初の本格的な一歩であり、1932年に若きポール・エルデシュ（Paul Erdős）が与えた、数学で最も有名な短い証明の一つにおける鍵となる補題（lemma）なのである。

取りかかる前に

記号 \(P_{r,s}\) は煩わしく見えるが、考え方は単純で、ある範囲にある素数を掛け合わせるだけである。例をしっかり理解しておこう。\(P_{3,7}\) は \(3\) より大きく \(7\) 以下の素数、すなわち \(5\) と \(7\) を用いるので、\(35\) となる。

小問 (iv) では、すべての \(n \geq 2\) について命題を証明することが求められている。小問 (iii) では、\(2m\) までのすべての \(k\) について命題が成り立つと仮定している。これはどのような帰納法（induction）だろうか。

これは強い帰納法（strong induction）である。\(n\) の場合を証明するために、直前の場合だけでなく、それ以前のすべての場合を仮定してよい。このことを覚えておこう。問題がこのように構成されているのはそのためである。

順を追って解く

段階 1 二項係数（binomial coefficient）はそれほど大きくない

\((1+x)^{2m+1}\) の二項展開（binomial expansion）で \(x = 1\) とおくと何が得られるか。

次が得られる。 \[2^{2m+1} = \binom{2m+1}{0} + \binom{2m+1}{1} + \cdots + \binom{2m+1}{2m+1}.\] すべての項は正なので、どの項も \(2^{2m+1}\) より小さい。しかしこれでは少し足りない。欲しいのは \(2^{2m}\)、つまりその半分である。

パスカルの三角形（Pascal’s triangle）は左右対称である。和の中で \(\binom{2m+1}{m}\) と等しい項は他にどれか。

対称性より \(\binom{2m+1}{m} = \binom{2m+1}{m+1}\) であり、これらは和の中の異なる2つの項である（\(m \neq m+1\) だから）。したがって \[2\binom{2m+1}{m} = \binom{2m+1}{m} + \binom{2m+1}{m+1} < 2^{2m+1},\] となる。和には \(\binom{2m+1}{0} = 1\) など他の正の項も含まれているので、不等号は等号を含まない。\(2\) で割ると \(\binom{2m+1}{m} < 2^{2m}\) を得る。■

段階 2 その二項係数を割り切る素数はどれか

二項係数を書き下すと、 \[\binom{2m+1}{m} = \frac{(2m+1)!}{m!\,(m+1)!} = \frac{(m+2)(m+3)\cdots(2m+1)}{m!}.\]

\(p\) を \(m + 1 < p \leq 2m+1\) を満たす素数とする。\(p\) は分子を割り切るか。分母を割り切ることはあり得るか。

分子 \((m+2)(m+3)\cdots(2m+1)\) は因数の一つとして \(p\) 自身を含むので、\(p\) はこれを割り切る。分母 \(m!\) はすべて \(p\) より小さい数の積である。\(p\) は素数なので、どれも \(p\) で割り切れない数の積を割り切ることはできない。よって \(p\) は分子を割り切るが分母は割り切らず、したがって二項係数全体（これが整数であることを思い出そう）を割り切る。

これで、この範囲にある各素数が \(\binom{2m+1}{m}\) を割り切ることがわかった。では、なぜそれらの積 \(P_{m+1,2m+1}\) もこれを割り切るといえるのか。（注意：\(4\) と \(6\) がともにある数を割り切っても、\(24\) がその数を割り切るとは限らない。）

違いは、ここでの素数が相異なる素数であることにある。相異なる素数 \(p_1, p_2, \ldots\) がそれぞれ \(N\) を割り切るならば、それらの積も \(N\) を割り切る。実際、\(N = p_1 N_1\) と書くと、\(p_2\) は \(p_1 N_1\) を割り切るが \(p_1\) は割り切らないので、\(N_1\) を割り切る。以下同様である。（ここでは、素数がある積を割り切るならばその因数のいずれかを割り切る、という事実を用いている。この事実には少し立ち止まって敬意を払う価値がある。第 1.7 節 では、これに相当する性質が成り立たない世界を紹介する。）

よって \(P_{m+1,2m+1}\) は \(\binom{2m+1}{m}\) を割り切り、正の数の約数はその数を超えないので、 \[P_{m+1,\,2m+1} \leq \binom{2m+1}{m} < 2^{2m}. \qed\]

段階 3 積を分割する

\(2m+1\) 以下のすべての素数の積 \(P_{1,2m+1}\) を、すでにわかっている積からどのように組み立てられるか。

\(2m+1\) 以下の素数を、\(m+1\) 以下のものと \(m+1\) より大きいものに分ける。 \[P_{1,2m+1} = P_{1,m+1} \times P_{m+1,2m+1}.\] 2つ目の因数は段階 2 より \(2^{2m} = 4^m\) より小さい。1つ目については、\(2\) から \(2m\) までのすべての \(k\) について \(P_{1,k} < 4^k\) を仮定してよく、\(k = m+1\) はこの範囲に入っている（\(m \geq 1\) より \(2 \leq m+1 \leq 2m\) だから）。したがって \[P_{1,2m+1} < 4^{m+1} \times 4^{m} = 4^{2m+1}. \qed\] ここで強い帰納法がその真価を発揮する。\(2m+1\) の場合を扱うのに必要だったのは、直前の場合ではなく、およそ半分の大きさである \(m+1\) の場合だったのである。

段階 4 すべての \(n\)

小問 (iii) は奇数を扱っている。偶数 \(n = 2m+2\) の場合はどうなるか。それは素数だろうか。

まず出発点を確認する。\(P_{1,2} = 2 < 16\)、\(P_{1,3} = 6 < 64\) である。次に、\(n \geq 4\) として、\(2\) から \(n-1\) までのすべての \(k\) について \(P_{1,k} < 4^k\) が成り立つと仮定する。

  • \(n\) が偶数ならば、\(n\) は（\(2\) より大きいので）素数ではなく、\(n\) 以下の素数は \(n-1\) 以下の素数と同じである。よって \(P_{1,n} = P_{1,n-1} < 4^{n-1} < 4^n\) となる。

  • \(n\) が奇数ならば、\(m \geq 2\) として \(n = 2m+1\) と書く。すると小問 (iii) により直ちに \(P_{1,n} < 4^n\) を得る。

強い帰納法により、すべての \(n \geq 2\) について \(P_{1,n} < 4^n\) が成り立つ。■

振り返り

  • 二項係数は数論的な情報を担っている。 \(\binom{2m+1}{m}\) は（\(4^m\) 未満という）小さな一つの数でありながら、多くの素数で割り切れざるを得ない。多くの素数を小さな数に押し込むことで、それらの素数がそれほど多くはあり得ないことがわかるのである。

  • 問題が自らを半分にするとき、強い帰納法は自然な道具である。 \(2m+1\) の場合は \(m+1\) の場合に依存していた。

  • 小さな場合は別に確認する必要がある。 帰納法が回り始めるのは \(n \geq 4\) からなので、\(n = 2\) と \(3\) は手で確かめなければならなかった。

背後にある数学

\(4^n\) から素数定理（Prime Number Theorem）へ

結果の対数（logarithm）をとると \(\ln P_{1,n} < n \ln 4\)、すなわち \[\sum_{p \leq n} \ln p < (\ln 4)\, n \approx 1.39\,n .\] となる。1850年代にパフヌティ・チェビシェフ（Pafnuty Chebyshev）は、まさにこの種の評価を上からも下からも証明し、\(\sum_{p \leq n} \ln p\) が \(n\) に比例して増大することを示した。ガウス（Gauss）はそれ以前、およそ 15 歳のときにすでに、数表から \(n\) 以下の素数の個数はおよそ \(n / \ln n\) であると予想していた。これが素数定理となり、1896年にジャック・アダマール（Jacques Hadamard）とシャルル・ド・ラ・ヴァレ・プーサン（Charles de la Vallée Poussin）が複素解析（complex analysis）を用いてついに証明した。対数の形で述べると \[\sum_{p \leq n} \ln p \sim n,\] であり、したがって \(n\) 以下の素数の積はおよそ \(e^n\) である。我々の上界 \(4^n\) はまったく的外れではない。図 1.2.1 に3つすべてを示す。

ベルトランの仮説（Bertrand’s postulate）

1845年にジョゼフ・ベルトラン（Joseph Bertrand）は、すべての \(n \geq 1\) について \(n\) と \(2n\) の間に必ず素数が存在すると予想した。チェビシェフは1852年にこれを証明した。その80年後、19 歳のポール・エルデシュが美しい初等的証明を見いだした。その鍵となる要素は、この問題の補題と、中央二項係数 \(\binom{2n}{n}\) を割り切る素数がどれかを注意深く調べることである。Martin Aigner と Günter Ziegler は、数学で最も優美な証明を集めた Proofs from THE BOOK の第 2 章としてこの証明を選んだ。

この先へ

素数の正確な分布は、リーマンゼータ関数（Riemann zeta function） \[\zeta(s) = 1 + \frac{1}{2^s} + \frac{1}{3^s} + \cdots,\] の零点によって支配されている。この関数には 第 2.4 節 で、ずっと控えめな姿で出会うことになる。そこでは \(\zeta(2) = \pi^2/6\) である。これらの零点がどこにあるかを正確に予言するリーマン予想（Riemann Hypothesis）が正しければ、素数定理の誤差を可能な限り厳しく押さえ込むことができる。これはおそらく数学で最も有名な未解決問題であり、ミレニアム懸賞問題（Millennium Prize Problems）の一つでもある。

思考のスキル

強い帰納法と、巧妙な対象から情報を引き出すこと

\(n\) の場合が \(n-1\) よりずっと小さい場合に依存するときは、それ以前のすべての場合を一度に仮定せよ。

ここでのもう一つの考え方はより繊細で、数論（number theory）に極めて特徴的なものである。ある範囲のすべての素数について何かを示すには、それらの素数のどれもが割り切らなければならず、しかもそれほど大きくないことも示せるような一つの対象（ここでは二項係数）を見つけるのである。

次の一歩

  1. 数の感覚をつかむ。 \(n = 10, 20, 30\) について \(P_{1,n}\) を計算し、\(4^n\) および \(e^n\) と比較せよ。（ここでは電卓を使ってよい。）

  2. 中央二項係数。 \(\binom{2m}{m}\) が \((1+1)^{2m}\) の展開における \(2m+1\) 個の項の中で最大であることを示し、\(\binom{2m}{m} \geq \dfrac{4^m}{2m+1}\) を導け。

  3. 素数はそれほど多くない。 \(\pi(n)\) を \(n\) 以下の素数の個数とする。\(\sqrt n\) と \(n\) の間にある素数はすべて \(\sqrt n\) より大きく、それらの積は \(P_{1,n} < 4^n\) 以下である。これより \[\pi(n) - \pi(\sqrt n) < \frac{2\ln 4}{\ln n}\, n ,\] を導き、さらに \(\pi(n) < 2.8\, n/\ln n + \sqrt n\) を導け。これを素数定理の \(\pi(n) \approx n / \ln n\) と比較せよ。

  4. ベルトランの仮説を確かめる。 \(n = 1, 2, \ldots, 50\) のそれぞれについて \(n\) と \(2n\) の間にある素数を見つけることで、ベルトランの仮説を確かめよ。各素数が直前の素数の2倍未満であるような短い素数のリストを使って、効率よく確かめられるだろうか。

さらに学ぶために

  • Aigner & Ziegler, Proofs from THE BOOK、第 2 章「Bertrand’s postulate」（ベルトランの仮説）。

  • Marcus du Sautoy, The Music of the Primes（Fourth Estate）。素数定理とリーマン予想の歴史を一般向けに描いた本。

  • G. J. O. Jameson, The Prime Number Theorem（Cambridge University Press）。厳密でありながら平易で、学部生向けに書かれている。最初の数章は A レベル（A level、英国の大学入学資格試験）程度の微積分しか必要としない。
