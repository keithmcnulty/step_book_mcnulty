1.6

二つの平方数の和

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第1章章全体のPDF
問題

STEP II 2023、第7問

先に進む前に問題を読んでおこう。問題は、OCRが配布している2023年のSTEP問題一式（zipファイル）のSTEP IIに収録されている： www.ocr.org.uk/Images/707102-2023-past-papers.zip

導入

どのような整数が2つの平方数の和（sum of two squares）として表せるだろうか。\(5 = 1^2 + 2^2\) や \(13 = 2^2 + 3^2\) は表せるが、\(3\)、\(7\)、\(21\) は表せない。ここで不思議な事実がある。\(65 = 5 \times 13\) は、\(1^2 + 8^2\) と \(4^2 + 7^2\) という2通りの異なる方法で2つの平方数の和として表せるのである。このような数を2つ掛け合わせると、なぜまたこのような数になるのか。そして、なぜ2通りになるのか。

答えは思いがけない方向からやってくる。この問題では、整数の世界を離れて複素数を扱うことが求められる。複素数の世界では2つの平方数の和は単純なものとなり、一見すると不可解な計算もほとんど機械的なものになる。

取りかかる前に

\(a\) と \(b\) を整数として \(z = a + \mathrm{i}b\) とするとき、\(|z|^2\) は何か。

それは \(a^2 + b^2\)、すなわち2つの平方数の和である。したがって「\(N\) は2つの平方数の和である」とは、ちょうど「実部と虚部がともに整数であるような複素数 \(z\) を用いて \(N = |z|^2\) と書ける」ということである。このような複素数はガウス整数（Gaussian integers）とよばれる。この言い換えをしっかり覚えておいてほしい。問題全体がこれにかかっている。

順を追って解く

段階 1 絶対値は掛け算される

\(zw\) を \(a\)、\(b\)、\(c\)、\(d\) を用いて書き表せ。\(|zw|^2\) について何を示せばよいか。

\(zw = (ac - bd) + \mathrm{i}(ad + bc)\) であるから、 \[|zw|^2 = (ac - bd)^2 + (ad + bc)^2 = a^2c^2 + b^2d^2 + a^2d^2 + b^2c^2,\] となる。交差項 \(-2abcd\) と \(+2abcd\) が打ち消し合うからである。そしてこれは因数分解できる。 \[a^2c^2 + b^2d^2 + a^2d^2 + b^2c^2 = (a^2 + b^2)(c^2 + d^2) = |z|^2|w|^2.\] 平方根をとって、\(|zw| = |z||w|\) を得る。■

これを整数についての主張として読んでみよう。 \[(a^2 + b^2)(c^2 + d^2) = (ac - bd)^2 + (ad + bc)^2. \tag{$\star$}\] 2つの平方数の和どうしの積は、2つの平方数の和である。しかも、その2つの平方数が何であるかを複素数が正確に教えてくれるのである。

段階 2 これを使う

小問 (ii)：\(5 = |2 + \mathrm{i}|^2\) であり、\(221 = 10^2 + 11^2 = |10 + 11\mathrm{i}|^2\) である。そこで掛け合わせると、 \[(2 + \mathrm{i})(10 + 11\mathrm{i}) = 20 + 22\mathrm{i} + 10\mathrm{i} - 11 = 9 + 32\mathrm{i},\] となり、\(5 \times 221 = 9^2 + 32^2\) を得る。（検算：\(81 + 1024 = 1105\)。）

代わりに \(10 + 11\mathrm{i}\) に \(2 - \mathrm{i}\) を掛けるとどうなるか。これは \(2 + \mathrm{i}\) と同じ絶対値（modulus）をもつ。

\((2 - \mathrm{i})(10 + 11\mathrm{i}) = 20 + 22\mathrm{i} - 10\mathrm{i} + 11 = 31 + 12\mathrm{i}\) であるから、\(1105 = 31^2 + 12^2\) とも表せる。\(2 + \mathrm{i}\) を選ぶか、その共役（conjugate）を選ぶかによって、異なる表し方が得られるのである。これで導入で述べた \(65\) の2通りの表し方が説明できる（図 1.6.1）。すなわち \(65 = |(2+\mathrm{i})(3+2\mathrm{i})|^2 = |4 + 7\mathrm{i}|^2\) と \(65 = |(2-\mathrm{i})(3+2\mathrm{i})|^2 = |8 + \mathrm{i}|^2\) である。

段階 3 まず因数分解する

\(8045\) の末尾は \(5\) である。このことから何がわかるか。

\(8045 = 5 \times 1609\) である。\(1609\) を2つの平方数の和として表す必要があるが、\(1609\) のすぐ下の平方数を試していけば、すぐに \(1609 = 40^2 + 3^2\) が見つかる。すると \[(2 + \mathrm{i})(40 + 3\mathrm{i}) = 77 + 46\mathrm{i}, \qquad\text{よって}\qquad 8045 = 77^2 + 46^2,\] となり、共役を用いれば \(8045 = 83^2 + 34^2\) も得られる。

小問 (iv) はもっと速く片付く。\(36 = 6^2 + 0^2\) であり、\(6\) を掛けることは単に拡大するだけなので、\(36 \times 50805 = 612^2 + 1206^2\) となる。

段階 4 3通りの表し方

\(25\) は2つの平方数の和として2通り以上に表せる。符号の違いと入れ替えを除いて、絶対値が \(5\) のガウス整数はいくつあるか。

\(25 = 5^2 + 0^2 = 3^2 + 4^2\) であり、これらは \(5\)、\(3 + 4\mathrm{i}\)、\(3 - 4\mathrm{i}\) に対応する。次に \(1002082\) について考える。\(1001^2 = 1002001\) であるから、\(1002082 = 1001^2 + 9^2\) である。\(1001 + 9\mathrm{i}\) に3つのそれぞれを掛けると、次のようになる。 \[\begin{aligned} 5\,(1001 + 9\mathrm{i}) &= 5005 + 45\mathrm{i}, \\ (3 + 4\mathrm{i})(1001 + 9\mathrm{i}) &= 2967 + 4031\mathrm{i}, \\ (3 - 4\mathrm{i})(1001 + 9\mathrm{i}) &= 3039 - 3977\mathrm{i}. \end{aligned}\] よって、3つの組 \((r, s)\) は \((45, 5005)\)、\((2967, 4031)\)、\((3039, 3977)\) である。

段階 5 割り算

小問 (vi) では、この仕組みを逆向きに動かす。\(109 = 10^2 + 3^2\) と \(1002037 = 1001^2 + 6^2\) はわかっている。探索をせずに、\(9193\) を2つの平方数の和として表すにはどうすればよいだろうか。

ガウス整数を掛けると絶対値が掛け算されるのなら、割ると絶対値も割り算されるはずである。試してみると \[\frac{1001 + 6\mathrm{i}}{10 + 3\mathrm{i}} = \frac{(1001 + 6\mathrm{i})(10 - 3\mathrm{i})}{109} = \frac{10028 - 2943\mathrm{i}}{109} = 92 - 27\mathrm{i}.\] 割り切れるので、\(9193 = 92^2 + 27^2\) である。（検算：\(8464 + 729 = 9193\)。）

代わりに \(10 - 3\mathrm{i}\) で割るとどうなるか。

\((1001 + 6\mathrm{i})(10 + 3\mathrm{i})/109 = (9992 + 3063\mathrm{i})/109\) となり、\(9992/109\) は整数ではないから、これはガウス整数ではない。2つの「\(109\) の因数」のうち一方だけが \(1001 + 6\mathrm{i}\) を割り切るのであり、これはちょうど、与えられた整数を割り切る素数が一部の素数に限られるのと同じである。ガウス整数には、それ自身の素数とそれ自身の素因数分解があるのである。

振り返り

  • 言い換え、解き、言い戻す。「2つの平方数の和」は「ガウス整数の絶対値の2乗」になった。その言葉で考えると、問題はやさしかった。

  • まず因数分解する。どの小問も、大きな数をより小さな数に分解し、その表し方を簡単に見つけることから始まった。

  • 共役が新しい答えを与える。表し方の個数は、ある因数とその共役のどちらを選ぶか、その選び方が何通りあるかによって決まる。

背後にある数学

フェルマーの二平方定理

どのような素数が2つの平方数の和になるだろうか。\(2 = 1^2 + 1^2\)、\(5\)、\(13\)、\(17\)、\(29\)、\(37\)、\(41\) はそうであり、\(3\)、\(7\)、\(11\)、\(19\)、\(23\)、\(31\) はそうではない。規則はこうである。\(2\) を除けば、素数が2つの平方数の和になるのは、それを \(4\) で割った余りが \(1\) であるとき、かつそのときに限る。フェルマー（Fermat）は1640年にこれを述べ、オイラー（Euler）が1749年に証明した。ガウス整数の言葉でいえば、これは次のことを意味する。素数 \(p \equiv 1 \pmod 4\) は \(p = (a + b\mathrm{i})(a - b\mathrm{i})\) と分解する（split）が、素数 \(p \equiv 3 \pmod 4\) は素数のままである。たとえば \(5 = (2 + \mathrm{i})(2 - \mathrm{i})\) であるが、\(3\) はまったく因数分解できない。

1990年、ドン・ザギエ（Don Zagier）は二平方定理の証明を発表した。それはたった1文の長さであることで有名である。この証明は解説つきで Proofs from THE BOOK に収められている。

独自の素数をもつ新しい数の体系

ガウス（Gauss）は、ガウス整数が通常の整数と驚くほどよく似た振る舞いをすることに気づいた。除法の原理（division algorithm）とユークリッドの互除法（Euclidean algorithm）があり、すべてのガウス整数はガウス素数（Gaussian prime）の積に（\(\pm1\) や \(\pm\mathrm{i}\) を掛ける違いを除いて）一意的に分解される。これを \((\star)\) と組み合わせると、ある数が2つの平方数の和として何通りに表せるかを、その素因数分解（prime factorisation）だけから正確に数えることができる。

大学では、これは代数的整数論（algebraic number theory）への入り口となる。代数的整数論とは、通常の整数を理解するために \(\mathbb{Z}[\mathrm{i}]\) や \(\mathbb{Z}[\sqrt{-5}]\) のような数の体系を研究する分野である。第 1.7 節 では、この分野がなぜ生み出される必要があったのかを示す。このような体系のすべてがガウス整数ほど行儀がよいわけではないのである。

四平方とその先

すべての正の整数は4つの平方数の和である（ラグランジュ（Lagrange）、1770年）。その証明は \((\star)\) の四平方版に基づいており、それは \((\star)\) が複素数から得られるのと同じようにして、ハミルトン（Hamilton）の四元数（quaternions）から得られる。これは 第 7.8 節 で扱う。

思考のスキル

舞台を変える

ある数の体系では扱いにくい問題も、より大きな体系では自然なものになることがある。

2つの平方数の和は、整数の中では扱いにくいが、複素数の中では単なる絶対値にすぎない。数学者はこのようにして絶えず数の体系を拡張してきた。整数から有理数へ、有理数から実数へ、実数から複素数へ。拡張のたびに、古い問題のいくつかがやさしくなるのである。

次の一歩

  1. 障害。\(4k + 3\) の形の数は2つの平方数の和にならないことを示せ。（\(4\) を法として平方数はどうなるか？）

  2. 2通り。\(65\) と \(85\) をそれぞれ2つの平方数の和として2通りに表し、その答えをガウス整数を用いて説明せよ。

  3. 4通り。\(1105 = 5 \times 13 \times 17\) である。\(1105\) を2つの正の平方数の和として表す4通りの異なる方法を求めよ。なぜ4通りなのか。

  4. ガウス素数。 発展 \(a, b, c, d\) を整数として \(3 = (a + b\mathrm{i})(c + d\mathrm{i})\) ならば、一方の因数の絶対値は \(1\) であることを示せ。（絶対値の2乗をとれ。）これにより、\(3\) がガウス素数であることがわかる。

さらに学ぶために

  • John Stillwell, Elements of Number Theory（Springer）。歴史を交えながら、ガウス整数とその先へと積み上げていく。

  • Aigner & Ziegler, Proofs from THE BOOK、第 4 章 “Representing numbers as sums of two squares”（数を2つの平方数の和として表す）。

  • Joseph Silverman, A Friendly Introduction to Number Theory、平方和とガウス整数に関する章。
