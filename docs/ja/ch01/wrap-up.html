第1章 · 数論と証明

本章で学んだこと

本章の冒頭で、整数について三つの問いを立て、その根底に流れる四つ目のテーマ、すなわち「どのように証明するか」を扱うと約束した。九つの STEP の問題を通して、どこまで到達できたかを確かめてみよう。

1. 素数はいくつあり、どのように分布しているか

第 1.1 節 では、新しい素数（prime）を一つも見つけることなく、素数が無限に存在することを証明した。互いに共通の因数をもたない数の無限族、すなわちフェルマー（Fermat）数（Fermat numbers）を構成したのである。そのため、それぞれの数は自分だけの素数を必要とする。これは大きさではなく構造についての証明である。

第 1.2 節 ではさらに進んで、\(n\) 以下のすべての素数の積が \(4^n\) より小さいことを示した。これは本章で初めての定量的（quantitative）な主張であり、素数がどれほど密に詰まりうるかを制限するものである。対数をとると、これは \(\sum_{p \leq n} \ln p < 1.39\,n\) を意味する。一方、素数定理（Prime Number Theorem）によれば、真の値はおよそ \(n\) である。STEP レベルの議論でも、すでにかなり近いところまで迫っていたのである。

まだ行っていないのは、素数がどのように分布しているかを正確に求めることである。これはリーマン（Riemann）ゼータ関数（Riemann zeta function）によって支配されており、それを精密に述べたものがリーマン予想（Riemann Hypothesis）、すなわち数学で最も有名な未解決問題である。読者はいまや、それが何についての問題なのかを理解するのに十分な知識をもっている。

2. ある数が分数でないことはどのように証明できるか

まったく異なる三つの方法を見た。

  • 最小のものをとる（第 1.3 節）。もし \(\sqrt2\) が分数であれば、\(k\sqrt2\) を整数にする最小の正の整数 \(k\) が存在する。しかしそのとき \((\sqrt2 - 1)k\) はそれより小さな整数となる。同じ議論で立方根も扱うことができた。

  • 整数を 0 と 1 の間に閉じ込める（第 1.4 節）。もし \(e\) や \(e^2\) が分数であれば、階乗を掛けることで \(0\) と \(1\) の間に厳密に挟まれた整数が得られてしまう。これは、\(e\) と \(\pi\) が超越数（transcendental）であることを示したエルミート（Hermite）とリンデマン（Lindemann）の証明の背後にある考え方である。

  • 起こりえない整除関係を見つける（第 1.5 節、演習 3）。\(x^2 + y^2 = 3\) 上に有理点（rational point）が存在しないことを示すのは、\(x\) が有理数のとき \(\sqrt{3 - x^2}\) が決して有理数にならないことを示すのと同じである。

そして、まだわかっていないことがどれほど多いかも学んだ。\(e + \pi\) が無理数（irrational）であることさえ、いまだに誰も証明できていないのである。

3. どの方程式が整数解をもつか

答えが存在しないである場合もある。第 1.5 節 では、それを証明するフェルマーの方法を見た。すなわち、どんな解からもより小さな解が際限なく作られてしまうというものである。うまく選んだ素数を法（modulo）として考えることで、どの整除関係を利用すればよいかがわかった。

答えが存在し、しかもそれを作り出す仕組みがあるという場合もある。第 1.6 節 では、複素数によって二つの平方数の和が乗法の規則に変わった。第 1.9 節 では、三次曲線の接線から \(20^3 = 17^3 + 14^3 + 7^3\) が得られた。

そして、正しい一手が数の体系を変えることである場合もある。ガウス整数（Gaussian integers）を用いると、二つの平方数の和は簡単に扱えた。しかし 第 1.7 節 は警告を与えた。一見まったく妥当に見える体系でも、数が二通りの異なる方法で「素数」に分解されうるのである。1847年に無視されたこの警告は、イデアル（ideal）と現代代数学の誕生へとつながった。

第 1.8 節 はさらに独自のひねりを加えた。整数よりはるかに多く存在するように思える分数も、一つずつ並べ上げることができるのである。無限には、最初に見えるよりも多くの構造がある。

4. 証明の道具箱

本章で用いた方法を以下にまとめる。これらはどれも、大学の数学の講義で何度も繰り返し現れるものである。

方法 用いた箇所
数学的帰納法（induction）と強い帰納法（strong induction） フェルマー数（1.1）、素数の積（1.2）
整列性（well-ordering）、最小反例（minimal counterexample） \(\sqrt2\) と \(\sqrt[3]{2}\)（1.3）、分数の列挙（1.8）
無限降下法（infinite descent） 解をもたない方程式（1.5）、互いに素な組（1.8）
背理法（proof by contradiction） 全体を通して、特に 1.3 と 1.4
\(n\) を法とする計算 1.5、1.7
評価とはさみうち（bounding and squeezing） 1.2、1.4
全単射（bijection）の構成 1.8
反例（counterexample）の構成 一意的でない因数分解（1.7）
舞台を変える 複素数（1.6）、幾何（1.9）

問題を振り返ると、STEP の出題者がしばしば最初の一歩を与えてくれていたことに気づくだろう。「二項展開（binomial expansion）を考えることにより…」「複素数 \(2 + \mathrm{i}\) と \(10 + 11\mathrm{i}\) を考えることにより…」といった具合である。大学では、こうした手助けは次第になくなり、正しい最初の一歩を見つけることそのものが求められる技能となる。最良の準備は、まさにこれまで行ってきたことである。すなわち、問題を解き終えたら、そのヒントがなぜうまくいったのかを自問し、次回は自分で思いつけるようにすることである。

次はどこへ

本章のいくつかの話題は、本書の別の箇所でも続いていく。

  • 分数による \(e\) の近似は 第 2.9 節 で再び登場し、リーマンゼータ関数は 第 2.4 節 で \(\zeta(2) = \pi^2/6\) として現れる。

  • ラメ（Lamé）の誤った証明に現れた1の冪根（roots of unity）は 第 5 章 の主題であり、第 1.1 節 で約束したガウス（Gauss）による正17角形の作図は 第 6.2 節 で扱う。

  • 第 1.6 節 の恒等式（identity）の四平方版は、四元数（quaternion）を通じて 第 7.8 節 に登場する。

大学入学前にさらに先へ進みたい人へ

  • Harold Davenport, The Higher Arithmetic：初等整数論（elementary number theory）への入門書として、一冊選ぶならこれが最良である。

  • Aigner & Ziegler, Proofs from THE BOOK：第 1–4 章、第 8 章、第 17 章は本章と直接つながっている。

  • Joseph Silverman, A Friendly Introduction to Number Theory：本章の内容のほぼすべてとそれ以上を、ゆっくりとしたペースで扱っている。

  • Marcus du Sautoy, The Music of the Primes（邦題『素数の音楽』）と Simon Singh, Fermat’s Last Theorem（邦題『フェルマーの最終定理』）：数学の背後にある人間の物語である。

整数論には人を引き込む性質がある。その問いは初日に尋ねられるほど単純でありながら、一生をかけて取り組めるほど深い。本章のいくつかの節を読んで、この先どうなるのかを知りたくなったのであれば、それこそがまさに本章の狙いである。
