第2章 · 数列・級数・収束

「次の一歩」の解答

これらは完全な解答ではなく、簡潔な答えとヒントである。結果と鍵となるステップを示してあるので、自分の答えを確かめるのに使ってほしい。答えを見る前に、各問題にしっかり取り組むこと。

2.1 「いずれは」とは何を意味するか

  1. \((1 + x)^n = 1 + nx + \binom n2x^2 + \cdots\) の項はすべて非負であるから、\((1 + x)^n \geq 1 + nx > nx\) である。\(y = 1 + x\) とおくと、\(n > K/(y - 1)\) ならば \(y^n > n(y - 1) > K\) となる。次の項を用いると \(y^n > \binom n2(y - 1)^2\) であるから、\(n > 1 + 2K/(y - 1)^2\) ならば \(y^n/n > \frac12(n - 1)(y - 1)^2 > K\) となる。

  2. \(n \geq m_1\) で \(s_n \leq t_n\) が成り立ち、\(n \geq m_2\) で \(t_n \leq s_n\) が成り立つならば、\(n \geq \max(m_1, m_2)\) で \(s_n = t_n\) である。

  3. たとえば、偶数 \(n\) に対して \(s_n = n + 0.6\)、奇数 \(n\) に対して \(s_n = n\) とし、奇数 \(n\) に対して \(t_n = n + 0.6\)、偶数 \(n\) に対して \(t_n = n\) とすればよい。どちらも増加し、それぞれが他方を無限回上回る。

  4. \(n \geq 4\) のとき \(2^n \leq n!\) である（帰納法（induction）による：\(2^{n+1} = 2 \cdot 2^n \leq (n + 1)\,n!\)）。\(n^{10} \leq 2^n\) については、\(2\) から \(58\) までのすべての \(n\) で不等式は成り立たず、\(n \geq 59\) のすべてで成り立つ。よって最小の \(m\) は \(59\) である。

2.2 極限としての黄金比

  1. 帰納法による：\(u_1 = 1 = F_2/F_1\) であり、\(u_n = F_{n+1}/F_n\) ならば \(u_{n+1} = 1 + F_n/F_{n+1} = F_{n+2}/F_{n+1}\) である。

  2. \(\varphi - 1 = 1/\varphi\) であるから、\(u_{n+1} - \varphi = \frac{1}{u_n} - \frac1\varphi = -\frac{u_n - \varphi}{\varphi u_n}\) である。\(u_n \geq 1\) より \(|u_{n+1} - \varphi| \leq |u_n - \varphi|/\varphi\) であり、さらに \(|u_1 - \varphi| < 1\) であるから、\(|u_n - \varphi| \leq \varphi^{-(n-1)}\) となる。

  3. \(\psi = \frac{1 - \sqrt5}{2}\) は \(\psi^2 = \psi + 1\) を満たすので、\(1 + 1/\psi = \psi\) である。逆向きにたどると \(u_{n-1} = \frac{1}{u_n - 1}\) であり、\(0\) から始めると \(-1, -\frac12, -\frac23, -\frac35, -\frac58, \ldots\) が得られる。すなわち、ある \(k \geq 1\) に対して \(u_1 = -F_{k-1}/F_k\) である。これらの値は \(\psi\) に近づく。

  4. 不動点（fixed point）は \(v = 1 + \frac{1}{1 + v}\)、すなわち \(v^2 = 2\) を満たす。誤差には毎回 \(-\frac{1}{(1 + v_n)(1 + \sqrt2)}\) が掛かり、その大きさは高々 \(\frac{1}{2(1 + \sqrt2)}\) であるから、\(v_n \to \sqrt2\) である。また、\(\sqrt2 = 1 + \cfrac{1}{2 + \cfrac{1}{2 + \cdots}}\) である。

2.3 発散する級数と、収束するその親戚

  1. \(\ln N + 0.5772 = 10\) より \(N \approx 12\,400\) である。\(100\) を超えるにはおよそ \(e^{99.4} \approx 1.5 \times 10^{43}\) 項が必要である。

  2. \(k = 2\) のとき、ブロック \(n\) は高々 \(2^n \cdot 4^{-n} = 2^{-n}\) であるから、和は高々 \(\sum_{n \geq 0}2^{-n} = 2\) である。\(1 + \frac14 + \frac19\) を正確に足し、\(r = 4\) 以降のブロックを \(\frac14 + \frac18 + \cdots = \frac12\) で上から評価すると、約 \(1.86\) が得られる（真の値は \(\frac{\pi^2}{6} \approx 1.645\) である）。

  3. \(1/(r\ln r)\) については、\(2^n\) から \(2^{n+1} - 1\) までのブロックは少なくとも \(\frac{2^n}{2^{n+1}(n + 1)\ln 2} = \frac{1}{2(n + 1)\ln2}\) であり、これらの和は調和級数（harmonic series）と同様に振る舞うので発散（divergence）する。\(1/(r(\ln r)^2)\) については、ブロックは高々 \(\frac{1}{n^2(\ln2)^2}\) であり、\(\sum\frac{1}{n^2}\) は収束（convergence）する。

  4. 使える数字は、最上位の桁が \(7\) 通り、それ以外の各桁が \(8\) 通りであるから、使える \(d\) 桁の数は高々 \(7 \cdot 8^{d-1}\) 個であり、それぞれ \(10^{d-1}\) 以上である。よって和は高々 \(\sum_{d \geq 1}7(0.8)^{d-1} = \frac{7}{1 - 0.8} = 35\) である。

2.4 \(\pi^2/6\)

  1. 値 \(\tan^2 = 1/\cot^2\) は係数を逆順にした多項式（reversed polynomial）\(\sum_j(-1)^j\binom{2n+1}{2j+1}y^j\) の根であり、その根の和は \(\binom{2n+1}{2n-1} = n(2n + 1)\) である。さらに \(\mathrm{cosec}^2 = 1 + \cot^2\) より \(n + \frac{n(2n - 1)}{3} = \frac{2n(n + 1)}{3}\) が得られる。

  2. 偶数番目の項の和は \(\frac14\sum\frac{1}{m^2} = \frac{\pi^2}{24}\) であるから、奇数番目の項の和は \(\frac{\pi^2}{6} - \frac{\pi^2}{24} = \frac{\pi^2}{8}\) である。

  3. 根について \(e_1 = \frac{n(2n - 1)}{3}\)、\(e_2 = \binom{2n+1}{5}\big/\binom{2n+1}{1}\) であり、\(\sum\cot^4 = e_1^2 - 2e_2 = \frac{n(2n - 1)(4n^2 + 10n - 9)}{45}\) が得られる。\(\cot^4\theta < \theta^{-4} < (1 + \cot^2\theta)^2\) ではさみうち（squeezing）をして \(n \to \infty\) とすると、\(\frac{\pi^4}{90}\) が得られる。

  4. 下からの評価により \(\sum_{m \leq n}\frac{1}{m^2} > \frac{\pi^2n(2n - 1)}{3(2n + 1)^2}\) であるから、誤差は \(\frac{\pi^2(6n + 1)}{6(2n + 1)^2} < \frac{\pi^2}{4n}\) より小さい。これにより \(n \geq 2468\) で精度 \(0.001\) が保証される。実際には \(n \approx 1000\) で十分である。

2.5 ヴィエトの無限積

  1. \(\sin\theta = 2\sin\frac\theta2\cos\frac\theta2\) を繰り返し用いると、積は次々に打ち消し合う（telescopes）。\(n \to \infty\) とし（このとき \(2^n\sin(\alpha/2^n) \to \alpha\)）、\(\cos\frac\pi4 = \sqrt{\frac12}\) と \(\cos\frac\theta2 = \sqrt{\frac12 + \frac12\cos\theta}\) を用いて \(\alpha = \frac\pi2\) とおけばよい。

  2. \(\frac{\sin(\pi/3)}{\pi/3} = \frac{3\sqrt3}{2\pi} = \cos\frac\pi6\cos\frac\pi{12}\cos\frac\pi{24}\cdots\) であり、\(\cos\frac\pi6 = \frac{\sqrt3}{2}\)、\(\cos\frac{\pi}{12} = \frac{\sqrt{2 + \sqrt3}}{2} = \frac{\sqrt6 + \sqrt2}{4}\) である。

  3. \(8\) 個の因子で \(3.14157\) が得られ、四捨五入すると \(3.1416\) となる。\(n\) 個の因子を掛けた後の誤差はおよそ \(\frac{\pi^3}{6 \cdot 4^{n+1}}\) である。省かれた因子が \(\cos\frac{\pi}{2^{j+1}} \approx 1 - \frac{\pi^2}{2 \cdot 4^{j+1}}\) だからである。各因子は誤差をおよそ \(4\) で割り、\(\log_{10}4 \approx 0.6\) である。

  4. \(x = \ln a\) とすると、同じ議論により\[\frac{a - 1}{\ln a} = \prod_{j \geq 1}\frac{1 + a^{1/2^j}}{2},\]が得られるので、\(\frac{1}{\ln3} = \frac12\prod_{j \geq 1}\frac{1 + 3^{1/2^j}}{2}\) である。七つの因子で \(0.906\) が得られ、四捨五入すると \(0.91\) となる（真の値は \(0.9102\) である）。この場合、因子は \(1 + \frac{\ln3}{2^{j+1}}\) のように \(1\) に近づくので、新しい因子は誤差を半分にするだけである（約 \(0.3\) 桁）。一方、ヴィエト（Viète）の因子は \(1 - \frac{\pi^2}{2 \cdot 4^{j+1}}\) のように \(1\) に近づき、誤差を四分の一にする。

2.6 算術幾何平均

  1. \(x_{n+1} - y_{n+1} = \frac12(\sqrt{x_n} - \sqrt{y_n})^2 = \frac{(x_n - y_n)^2}{2(\sqrt{x_n} + \sqrt{y_n})^2}\) であり、\((\sqrt{x_n} + \sqrt{y_n})^2 \geq 4y_n \geq 4y_0\) である。

  2. \(M(2, 1) = 1.456791\) である。三回のステップの後には、\(x_3\) と \(y_3\) はすでに小数第七位まで一致する。

  3. 反復の各ステップで値は \(\lambda\) 倍されるので、\(M(\lambda x, \lambda y) = \lambda M(x, y)\) である。積分において \(x = \lambda u\) と置換すると \(\mathrm{I}(\lambda p, \lambda q) = \lambda^{-1}\mathrm{I}(p, q)\) が得られる。\(\mathrm{I} = \frac{\pi}{2M}\) の両辺はともに \(\lambda^{-1}\) 倍される。

  4. \(M(1, \cos 30^\circ) \approx 0.9318\) であるから、周期（period）は \(1.073\) 倍に長くなる。すなわち約 \(7.32\%\) 長くなる。

2.7 6桁か、600桁か

  1. \((p^2 + 2q^2)^2 - 2(2pq)^2 = (p^2 - 2q^2)^2 = 1\) である。また、\(577^2 - 2 \times 408^2 = 332\,929 - 332\,928 = 1\) である。

  2. \(y_{n+1} = \frac{2y_n^3 + 2}{3y_n^2}\) であり、\(y_{n+1} - \alpha = \frac{2y^3 - 3\alpha y^2 + \alpha^3}{3y^2} = \frac{(y - \alpha)^2(2y + \alpha)}{3y^2}\) である。\(y > \alpha\) ならば \(\frac{2y + \alpha}{3y^2} < \frac{3y}{3y^2} = \frac1y < \frac1\alpha\) である。

  3. \(y - \frac{1/y - a}{-1/y^2} = y + y - ay^2 = y(2 - ay)\) であり、\(1 - ay(2 - ay) = (1 - ay)^2\) である。

  4. \(y - \frac{y^{1/3}}{\frac13y^{-2/3}} = y - 3y = -2y\) である。誤差の公式が成り立つには、根の近くで \(\mathrm{f}'\) が零でなく、\(\mathrm{f}''\) が有界であることが必要である。ここでは \(\mathrm{f}'\) は \(0\) で無限大となる。

2.8 2乗して2を引く

  1. \((2\cos u)^2 - 2 = 2\cos2u\) であるから、帰納法により \(x_n = 2\cos(2^{n-1}\theta)\) である。\(x_3 = a\) となるには \(4\theta \equiv \pm\theta\)、すなわち \(3\theta\) または \(5\theta \equiv 0 \pmod{2\pi}\) が必要である。\(x_2 = a\) となる場合（不動点 \(a = 2\) と \(a = -1\)）は除外するので、\(\theta = \frac{2\pi}{5}, \frac{4\pi}{5}\) が残り、\(a = \frac{\sqrt5 - 1}{2}\) または \(a = -\frac{\sqrt5 + 1}{2}\) となる。これらは \(2\)-サイクルをなす二点である。

  2. \(M_5\) に対しては、数列は \(4\)、\(14\)、\(194 \equiv 8\)、\(62 \equiv 0\) となり、素数（prime）である。\(M_{11}\) に対しては \(4\)、\(14\)、\(194\)、\(788\)、\(701\)、\(119\)、\(1877\)、\(240\)、\(282\)、\(1736 \neq 0\) となり、合成数（composite）である。実際、\(2047 = 23 \times 89\) である。

  3. \(A = t - \frac1t = \frac32\) より \(t = 2\)、\(a = \frac52\) である。このとき \(x_2 = \frac{17}{4}\)、\(y_1 = \frac{Ax_1}{x_2} = \frac{15}{17}\) であり、\(\frac{\sqrt{x_2^2 - 4}}{x_2} = \frac{15/4}{17/4} = \frac{15}{17}\) である。

  4. \(x_k = t^{2^{k-1}} + t^{-2^{k-1}}\) であり、\(x_1\cdots x_n\) に \(t - t^{-1}\) を掛けると次々に打ち消し合って \(t^{2^n} - t^{-2^n}\) となる。和は \((t - t^{-1})\sum_{n \geq 1}\bigl(\frac{1}{t^{2^n} - 1} - \frac{1}{t^{2^{n+1}} - 1}\bigr) = \frac{t - t^{-1}}{t^2 - 1} = \frac1t\) となる。\(a = 3\) のとき \(t = \frac{3 + \sqrt5}{2}\)、\(\frac1t \approx 0.3820\) であり、級数 \(\frac13 + \frac1{21} + \frac{1}{987} + \cdots\) もこれと一致する。

2.9 e に迫る分数

  1. \(T_0 = e - 1\)、\(T_1 = 3 - e\)、\(T_2 = 7e - 19\)、\(T_3 = 193 - 71e\)、\(T_4 = 1001e - 2721\) であり、これから \(\frac{19}{7}\)、\(\frac{193}{71}\)、\(\frac{2721}{1001}\) が得られる。\(b_n = b_{n-2} - 2(2n - 1)b_{n-1}\) であり、（帰納的に）\(b_{n-1}\) は \(b_{n-2}\) と逆の符号をもつから、\(b_n\) は \(b_{n-2}\) と同じ符号をもつ。

  2. \(t(1 - t) \leq \frac14\) であるから \(T_n < \frac{e}{4^nn!}\) である。\(-a_n/b_n\) の誤差は \(T_n/|b_n|\) であり、今度は \(4^n\) 倍改善される。

  3. \(e = \frac pq\) ならば、\(qT_n = qa_n + pb_n\) は整数である。\(T_n > 0\) よりこれは正の整数であり、したがって \(1\) 以上である。しかし \(n\) が大きいとき \(qT_n < \frac{qe}{n!} < 1\) である。

  4. 部分積分（integration by parts）を二回行うと（境界項は消える）、\(U_n = \frac14\bigl(U_{n-2} - 2(2n - 1)U_{n-1}\bigr)\) となり、\(U_0 = \frac{e^2 - 1}{2}\)、\(U_1 = \frac12\) である。したがって整数 \(A_n\)、\(B_n\) を用いて \(2^{2n+1}U_n = A_n + B_ne^2\) と表され、一方で \(0 < U_n < \frac{e^2}{4^nn!}\) である。\(e^2 = \frac pq\) ならば、\(q2^{2n+1}U_n\) は \(\frac{2qe^2}{n!}\) より小さい正の整数となるが、\(n\) が大きいときこれは不可能である。よってこの議論により、\(e^2\) が無理数（irrational）であることが確かに示される。
