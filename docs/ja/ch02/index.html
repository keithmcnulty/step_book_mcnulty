第2章 \(\cdot\) 序論

無限を飼いならす

無限！　これほど深く人間の精神を揺り動かした問いはほかにない。

— ヒルベルト（David Hilbert）

2500年前、エレアのゼノン（Zeno of Elea）は運動が不可能であると論じた。部屋を横切って歩くには、まず半分まで歩き、次に残りの半分を歩き、さらにその半分を歩き、と永遠に続けなければならない。これは無限個の作業であり、有限の時間で終えられるはずがない、というのである。人は実際に部屋を横切れるのだから、ゼノンが間違っていることは誰もが知っていた。しかし、彼がなぜ間違っているのかを正確に説明できる者は、非常に長い間いなかった。答えは、無限和 \(\frac12 + \frac14 + \frac18 + \cdots\) が有限の値 \(1\) をもつということである。だが、そもそも無限個の数を足し合わせて何かになるとは、どういう意味なのだろうか。

この問いは二千年にわたって数学の中心にあり続けた。17世紀にニュートン（Newton）とライプニッツ（Leibniz）はこの問いの上に微積分（calculus）を築いたが、ついに完全な答えを出すことはなかった。その後継者たちは見事な結果を生み出す一方で、とんでもない誤りも生み出した。史上最高の計算家であるオイラー（Euler）は、平然と \(1 - 1 + 1 - 1 + \cdots = \frac12\) と書いた。また別の者たちは、同じ無限級数（infinite series）について互いに矛盾することを「証明」した。正しい結果と誤った結果を区別できるほど精密な定義を数学者が手にしたのは、19世紀になって、コーシー（Cauchy）やワイエルシュトラス（Weierstrass）らの仕事によってであった。それらの定義こそが本章の主題である。

なぜ重要なのか

あなたがこれから計算に使うほとんどすべての数は、何かの極限（limit）である。電卓は \(\sqrt2\) や \(\pi\) や \(e\) そのものを知っているわけではない。電卓が知っているのは、それらにどんどん近づいていく手順であり、十分近づいたところで計算を止めるのである。手順がどれくらい速く近づくかを理解しているかどうかが、1ミリ秒で終わるアルゴリズムと永遠に終わらないアルゴリズムとの違いを生む。同じ考え方は、天気予報、航空機の設計、金融商品の価格付けに使われるコンピュータ・シミュレーションの基盤にもなっている。そして最も純粋な側面では、極限の研究は数学で最も美しい公式のいくつかへと導く。本章では \[1 + \frac14 + \frac19 + \frac1{16} + \cdots = \frac{\pi^2}{6},\] を証明する。これはオイラーを有名にした結果であり、今なおほとんど魔法のように見える。

大学で出会うもの

ほとんどすべての大学で、解析学（Analysis）は最初に履修する科目の一つであり、多くの学生にとって最大の衝撃となる。学校の数学では極限を計算することを学ぶが、解析学では精密な定義から出発して、極限についての事柄を証明することを学ぶ。数列（sequence）が収束する（converge）とはどういうことかを、第 2.1 節 に登場する「任意の \(\varepsilon > 0\) に対して」と「\(N\) が存在して」という言い回しを用いて定義する。有界な単調増加数列（bounded increasing sequence）はすべて収束することを証明し、それが実数のもつ性質である完備性（completeness）に依存しており、有理数にはこの性質がないことを知るだろう。級数（series）の収束判定法を学び、さらに同じ考え方を用いて、連続性、微分、積分に厳密な意味を与える。

その後の科目は、この土台の上にさまざまな方向へと発展していく。数値解析（numerical analysis）は、近似がどれくらい速く収束するか、そしてどうすればより速くできるかを問う（第 2.7 節、第 2.6 節）。力学系（dynamical systems）は、ある規則を何度も繰り返し適用したときに何が起こるかを研究する。極限に到達することもあれば、カオスを生み出すこともある（第 2.2 節、第 2.8 節）。複素解析（complex analysis）は、なぜ \(\pi\) がこれほど多くの無限和や無限積に現れるのかを説明する（第 2.4 節、第 2.5 節）。そして解析的整数論（analytic number theory）は、第 2.9 節 のように、極限を用いて整数に関する問いに答える。

本章を貫く問い

三つの大きな問い

  1. 無限の過程が答えをもつとはどういうことか。数列が極限に「近づく」こと、あるいは無限和がある数に「なる」ことを、どうすれば正確に言い表せるか。

  2. 何に収束するかを知らずに、収束することをどうやって証明できるか。そして、極限が存在することがわかったら、それをどうやって求めるか。

  3. どれくらい速いか。二つの過程が同じ極限をもちながら、まったく異なる速さでそこに近づくことがある。それはなぜか、そしてその速さをどう測るか。

最初の節（第 2.1 節）は言葉についての節であり、数学者が「いずれは」ということをどのように正確に表現するかを扱う。続く五つの節は有名な極限を扱う。連分数（continued fraction）としての黄金比（golden ratio）、発散する級数とその収束する親戚、\(\pi^2/6\)、\(2/\pi\) に対するヴィエト（Viète）の積、そしてガウス（Gauss）の算術幾何平均（arithmetic–geometric mean）である。最後の三つの節は速さと構造を扱う。一次収束と二次収束の比較、爆発するかカオス的にさまようかのどちらかになる反復、そして \(e\) に迫っていく積分の族である。

本章の読み方

第 1 章と同様に、各節は出題されたままの STEP の問題から始まる。読み進める前に、まず自分で解いてみてほしい。本章の問題では、どの道具を使うべきかが問題文に示されていることが多い（「〜を考えることにより」「〜の定理を用いてよい」など）。解き進めながら、同じ少数の道具がいかに繰り返し現れるかに注目してほしい。大学では、それを自分で選ばなければならないからである。

いくつかの問題では、極限が存在すること、あるいは無限和や無限積が収束することを仮定するよう求められる。そのような場合には、それを証明するために何が必要かを各節で説明する。「明らかにうまくいく」と「うまくいくことを証明できる」との間の隔たりを意識することが、解析学者のように考えるための第一歩である。
