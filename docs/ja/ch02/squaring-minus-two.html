2.8

2乗して2を引く

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第2章章全体のPDF
問題

STEP III 2021、第8問

先に進む前に問題を読んでおこう。問題は、OCRが配布している2021年のSTEP問題一式（zipファイル）のSTEP IIIに収録されている： www.ocr.org.uk/Images/696588-2021-past-papers.zip

導入

「2乗して \(2\) を引く」というのは、数列（sequence）を生成する規則としてはほとんど最も単純なものである。ところがこの規則は、実数直線を二つの世界に分けてしまう。\([-2, 2]\) の外から出発すると、数は指数関数よりも速く無限大へと爆発する。内側から出発すると、数は永遠にその中に閉じ込められ、ある厳密な意味で完全に予測不可能な仕方でさまよい続ける。これはカオス（chaos）の最も単純な例の一つである。

同じ規則を非常に大きな整数で実行したものが、ルーカス–レーマー判定法（Lucas–Lehmer test）の心臓部である。これはメルセンヌ数 \(2^p - 1\) が素数であるかどうかを効率よく判定する方法であり、現在の記録となっている素数をはじめ、既知の最大級の素数のほとんどを発見してきた。本問では発散する側の話を探究し、数列を完全に解けるものにする隠れた公式を見つける。

取りかかる前に

いくつかの初期値で試してみよう。\(a = 3\) のとき：\(3, 7, 47, 2207, \ldots\)。\(a = 1\) のとき：\(1, -1, -1, -1, \ldots\)。\(a = 0\) のとき：\(0, -2, 2, 2, 2, \ldots\)。\(a = 0.3\) のとき：\(0.3, -1.91, 1.648, 0.716, -1.487, 0.211, \ldots\)。

\([-2, 2]\) の中の数が決して外へ逃げ出せないのはなぜか。\(-2 \leq x \leq 2\) のとき、\(x^2 - 2\) の最大値と最小値はいくらか。

\(-2 \leq x \leq 2\) ならば \(0 \leq x^2 \leq 4\) であるから、\(-2 \leq x^2 - 2 \leq 2\) となる。区間 \([-2, 2]\) はそれ自身の中へ写される。これが小問 (ii) の半分になる。

順を追って解く

段階 1 発散

小問 (i) には \(4^{n-1}\) が現れており、\(2\) からの超過分が各ステップで少なくとも4倍になることを示唆している。\(x_n = 2 + d\) とおく。\(x_{n+1}\) を \(d\) で表すとどうなるか。

\(x_{n+1} = (2 + d)^2 - 2 = 2 + 4d + d^2\) である。したがって \(d \geq 0\) ならば、新しい \(2\) からの超過分は \(4d + d^2 \geq 4d\) である。

ここで数学的帰納法（induction）を用いる。\(n = 1\) のとき、\(x_1 = a = 2 + 4^0(a - 2)\) である。\(x_n \geq 2 + 4^{n-1}(a - 2)\) ならば、\(d = x_n - 2 \geq 4^{n-1}(a - 2) \geq 0\) であるから、 \[x_{n+1} - 2 \geq 4d \geq 4^n (a - 2). \qed\]

段階 2 \(|a| > 2\) のとき、かつそのときに限り発散する

「〜のとき、かつそのときに限り」（if and only if）とは、二つの別々の証明が必要だということである。小問 (i) でほぼ得られているのはどちらの向きで、何が足りないか。

\(|a| > 2\) ならば：\(a > 2\) のときは、小問 (i) より \(x_n \geq 2 + 4^{n-1}(a - 2) \to \infty\) である。\(a < -2\) のときは、最初の1ステップで符号が定まる。すなわち \(x_2 = a^2 - 2 > 4 - 2 = 2\) であり、\(x_2\) 以降の数列は \(x_2 > 2\) から出発した同じ数列であるから、無限大に発散する。

逆向き：\(|a| \leq 2\) ならば \(a \in [-2, 2]\) であり、上で見たことからすべての項が \([-2, 2]\) にとどまる。有界（bounded）な数列は無限大に発散し得ない。■

段階 3 隠れた公式

小問 (iii) は手ごわそうに見える。取りかかる前に、\(x_n\) の公式を見つけておく価値がある。

\(a > 2\) ならば、\(a = t + \dfrac1t\) となる数 \(t > 1\) が存在する（なぜか）。\(x_2\) と \(x_3\) を \(t\) で表すとどうなるか。

関数 \(t + 1/t\) は、\(t\) が \(1\) から \(\infty\) まで動くとき \(2\) から \(\infty\) まで増加するので、どの \(a > 2\) もこの形に書ける。すると \[x_2 = \left(t + \frac1t\right)^2 - 2 = t^2 + \frac{1}{t^2}, \qquad x_3 = \left(t^2 + \frac1{t^2}\right)^2 - 2 = t^4 + \frac1{t^4},\] であり、帰納法により \[x_n = t^{2^{n-1}} + t^{-2^{n-1}}.\] 2乗して \(2\) を引くことは、単に指数を2倍することにすぎない。これで問題は扱いやすくなる。

段階 4 積が次々に打ち消し合う

\(\left(t - \frac1t\right)\left(t + \frac1t\right)\) はいくらか。その結果に \(t^2 + \frac1{t^2}\) を掛けるとどうなるか。

\(\left(t - \frac1t\right)\left(t + \frac1t\right) = t^2 - \frac1{t^2}\) であり、さらに \(\left(t^2 - \frac1{t^2}\right)\left(t^2 + \frac1{t^2}\right) = t^4 - \frac1{t^4}\) であり、以下同様である。各因子 \(x_k\) は、二つのべきの差における指数を2倍する。したがって \[\left(t - \frac1t\right) x_1 x_2 \cdots x_n = t^{2^n} - t^{-2^n}.\]

\(x_{n+1}^2 - 4\) を \(t\) で表し、この積と比べよ。

\[x_{n+1}^2 - 4 = \left(t^{2^n} + t^{-2^n}\right)^2 - 4 = \left(t^{2^n} - t^{-2^n}\right)^2.\] \(t > 1\) より \(t^{2^n} - t^{-2^n} > 0\) であるから、\(\sqrt{x_{n+1}^2 - 4} = t^{2^n} - t^{-2^n} = \left(t - \frac1t\right) x_1 x_2 \cdots x_n\) である。よって \[\frac{\sqrt{x_{n+1}^2 - 4}}{x_{n+1}} = \frac{\left(t - \frac1t\right) x_1 \cdots x_n}{x_{n+1}},\] であり、これがすべての \(n\) について \(y_n\) に等しくなるのは、ちょうど \(A = t - \frac1t\) のときである。最後に、\(\left(t - \frac1t\right)^2 = \left(t + \frac1t\right)^2 - 4 = a^2 - 4\) であるから、条件は \(A = \sqrt{a^2 - 4}\)、すなわち \[a = \sqrt{A^2 + 4}.\] である（\(A > 0\) であるから、これは要求どおり \(2\) より大きい）。■

段階 5 \(y_n\) は収束するか

この \(a\) の値に対して、 \[y_n = \frac{\sqrt{x_{n+1}^2 - 4}}{x_{n+1}} = \sqrt{1 - \frac{4}{x_{n+1}^2}}.\] 小問 (ii) より \(x_{n+1} \to \infty\) であるから、\(\frac{4}{x_{n+1}^2} \to 0\) となり、\(y_n \to 1\) である。数列は \(1\) に収束する。■

つまり無限積（infinite product）\(x_1 x_2 x_3 \cdots\) は、\(x_{n+1}/A\) とちょうど同じ速さで増大する。急速に増大する項の積について、その正確な増大の速さが求められたのである。

振り返り

  • 不変領域（invariant region）。\([-2, 2]\) はそれ自身の中へ写され、この一つの事実だけで小問 (ii) の半分が片づく。

  • 線形化（linearise）する置き換え。\(a = t + 1/t\) と書くことで、「2乗して \(2\) を引く」が「指数を2倍する」に変わった。込み入った非線形のふるまいが単純なものになったのである。

  • 再び、次々に打ち消し合う（telescoping）構造。第 2.5 節 の積と同様に、多くの因子の積が、各因子が次の因子とうまくかみ合うことによってつぶれた。

背後にある数学

秩序とカオス

\([-2, 2]\) の内側では何が起こるのか。そこでは \(a = t + 1/t\) はうまくいかない（\(|a| \geq 2\) が必要である）が、三角関数による類似がうまくいく。\(a = 2\cos\theta\) と書くのである。すると \(x_2 = 4\cos^2\theta - 2 = 2\cos 2\theta\) であり、一般に \[x_n = 2\cos\bigl(2^{n-1}\theta\bigr).\] となる。つまり区間の内側では、この写像（map）は単に角を2倍するだけである。無害に聞こえるが、角の2倍はカオス的である。\(\theta/\pi\) を2進法（binary）で書くと、2倍することは小数点を1桁右へずらし、先頭の桁を捨てることにあたる。\(50\) ステップ後には \(x_n\) は \(\theta/\pi\) の2進展開の第 \(51\) 桁に依存するので、初期値の誤差が \(10^{-15}\)（一般的なコンピュータの精度）であっても、\(50\) ステップ後の答えはまったく信頼できなくなる。この初期値鋭敏性（sensitive dependence on initial conditions）こそがカオスの特徴であり、図 2.8.1 に示されている。写像 \(x \mapsto x^2 - 2\) は、変数変換によって有名なロジスティック写像（logistic map）\(x \mapsto 4x(1 - x)\) と同値であり、これには 第 8.7 節 で再会する。

最大の素数を見つける

メルセンヌ数（Mersenne number）とは \(M_p = 2^p - 1\) のことである。1876年にエドゥアール・リュカ（Édouard Lucas）が発見し、1930年にデリック・レーマー（Derrick Lehmer）が完成させた、\(M_p\) が素数かどうか（\(p\) は奇素数）を判定する見事な方法がある。\(s_0 = 4\) から出発し、毎回 \(M_p\) を法として簡約しながら、2乗して \(2\) を引くことを繰り返す。このとき \[M_p \text{ は素数} \iff s_{p-2} \equiv 0 \pmod{M_p}.\] \(M_7 = 127\) の場合：\(s = 4, 14, 194 \equiv 67, 67^2 - 2 \equiv 42, 42^2 - 2 \equiv 111, 111^2 - 2 \equiv 0\) であるから、\(127\) は素数である。本問との関係は置き換えにある。\(t = 2 + \sqrt3\) とすると \(4 = t + 1/t\) であるから、\(s_k = (2+\sqrt3)^{2^k} + (2-\sqrt3)^{2^k}\) となり、判定法の証明では 第 1.6 節 のガウス整数（Gaussian integers）とよく似た、\(a + b\sqrt3\) の形の数の算術を用いる。各ステップで必要なのは2乗1回だけなので、この判定法は極めて高速である。既知の最大級の素数のほとんどが、現在の記録保持者も含めてメルセンヌ素数であるのはこのためである（すべてがそうではない。\(a^{2^n} + 1\) のような他の特別な形にも、それぞれ独自の高速判定法がある）。執筆時点での記録は2024年に発見された \(2^{136279841} - 1\) であり、\(41\) 百万桁を超える数である。

マンデルブロ集合

\(-2\) を任意の定数 \(c\) に置き換え、複素数も許すことにする：\(z \mapsto z^2 + c\)。\(0\) の軌道が有界にとどまるような \(c\) 全体の集合がマンデルブロ集合（Mandelbrot set）である。本問の写像は \(c = -2\) であり、これはマンデルブロ集合の最も左の点である。そして軌道が有界にとどまる初期値全体の集合（そのジュリア集合（Julia set））は、小問 (ii) で見つけた区間 \([-2, 2]\) にちょうど一致する。他のほとんどすべての \(c\) に対しては、この集合はフラクタル（fractal）になる。

思考のスキル

変数を変換して写像を単純にする

反復が複雑に見えるときは、それを2倍や定数の加算のような単純なものに変える置き換えを探せ。

ここでは \(x = t + 1/t\) や \(x = 2\cos\theta\) によって、\(x \mapsto x^2 - 2\) が2倍に変わった。力学系（dynamical systems）の理論ではこれを共役（conjugacy）と呼び、それを見つけることが系を完全に理解する鍵となることが多い。

次の一歩

  1. 区間の内側。\(a = 2\cos\theta\) ならば \(x_n = 2\cos(2^{n-1}\theta)\) であることを証明せよ。\(x_3 = a\) であるが \(x_2 \neq a\) となる \(a\) の値をすべて求めよ（ヒント：\(2\pi\) を法として \(4\theta \equiv \pm\theta\) となればよい）。

  2. 手計算によるルーカス–レーマー判定法。この判定法を用いて、\(M_5 = 31\) は素数であり、\(M_{11} = 2047\) は素数でないことを示せ（\(M_{11}\) では9ステップが必要であり、電卓があると便利である。\(2047\) を素因数分解して結論を確かめよ）。

  3. 具体例。\(A = \frac{3}{2}\) とする。\(a\) と \(t\) を求め、公式 \(y_1 = \sqrt{x_2^2 - 4}/x_2\) を数値的に確かめよ。

  4. 次々に打ち消し合う和。 発展 \(a = t + 1/t\)、\(t > 1\) のとき、 \[\frac{1}{x_1 x_2 \cdots x_n} = \frac{t - t^{-1}}{t^{2^n} - t^{-2^n}}.\] であることを示せ。恒等式 \(\dfrac{1}{z - 1} - \dfrac{1}{z^2 - 1} = \dfrac{z}{z^2 - 1}\) を \(z = t^{2^n}\) として用いて、 \[\frac{1}{x_1} + \frac{1}{x_1 x_2} + \frac{1}{x_1 x_2 x_3} + \cdots = \frac1t.\] を導け。\(a = 3\) のときにこれを数値的に確かめよ。
