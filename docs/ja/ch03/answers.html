第3章 · 関数・不等式・厳密さ

「次の一歩」の解答

ここに載せるのは完全な解答ではなく、簡潔な答えとヒントである。結果と鍵となる手順を示しているので、自分の答案を確かめるのに使ってほしい。答えを見る前に、それぞれの演習問題にしっかり取り組むこと。

3.1 誤りを見抜け

  1. \(x\) が \(-1\) から \(1\) まで動くとき、\(x\) は \(0\) を通過し、そこでは \(t = 1/x\) が定義されない。つまり、この置換（substitution）は区間上で連続（continuous）でない。正しくは \(\int_{-1}^1\frac{\mathrm{d}x}{(1 + x^2)^2} = \frac12 + \frac\pi4\)（\(x = \tan\theta\) とおく）であり、一方 \(\int_{-1}^1\frac{-t^2}{(1 + t^2)^2}\,\mathrm{d}t = \frac12 - \frac\pi4\) である。

  2. (a) 正しい。両辺の対数はともに \(\ln a\ln b\) である。(b) 誤り。\(\theta = 0\) のとき \(\cos0 = 1 \neq \sin1\) である。（実際、\(|\sin\theta \pm \cos\theta| \leq \sqrt2 < \frac\pi2\) であるから、両者が等しくなることはない。）(c) 誤り。定数でない多項式は有界でなく（unbounded）、また定数が \(1\) と \(-1\) の両方から \(10^{-6}\) 以内にあることはできない。(d) 正しい。相加相乗平均の不等式（AM–GM）より \(x^4 + x^{-4} \geq 2\) であり、等号は \(x = 1\) のとき成り立つ。

  3. \(n = 1\) から \(n = 2\) への段階が成り立たない。2頭の馬では、「最初の \(1\) 頭」と「最後の \(1\) 頭」が重ならない。

  4. \(\int_\varepsilon^1x^{-1/2}\,\mathrm{d}x = 2 - 2\sqrt\varepsilon \to 2\) であるから、対称性により積分は（極限として）存在し、その値は \(4\) である。

3.2 相加・相乗平均を逆向きに

  1. \(a_1, \ldots, a_{n-1}\) の平均が \(A\)、幾何平均（geometric mean）が \(G\) であるとき、\(n\) 番目の数として \(A\) を加える。平均は \(A\) のままなので \((G^{n-1}A)^{1/n} \leq A\) となり、これから \(G \leq A\) が得られる。

  2. この \(n + 1\) 個の数の平均は \(1 + \frac{1}{n+1}\)、幾何平均は \((1 + \frac1n)^{n/(n+1)}\) であり、すべてが等しいわけではないので、不等式は等号なしで成り立つ。両辺を \(n + 1\) 乗せよ。

  3. 各面の面積は \(ab\), \(bc\), \(ca\) であり、\(S = 2(ab + bc + ca)\) である。相加相乗平均の不等式より \(\frac S6 \geq (abc)^{2/3} = V^{2/3}\) であり、等号は \(ab = bc = ca\)、すなわち立方体のときに成り立つ。

  4. \(1/a_i\) に相加相乗平均の不等式を用いると \(\frac1n\sum\frac1{a_i} \geq \frac1G\) となる。両辺の逆数をとれ。

3.3 凸性の威力

  1. \(\mathrm{f}'' < 0\) ならば傾きは減少するので、曲線は各弦（chord）の上側にある。\(t = \frac13\) とすると、\(\mathrm{f}\bigl(\frac{u + v + w}{3}\bigr) \geq \frac13\mathrm{f}(u) + \frac23\mathrm{f}\bigl(\frac{v + w}{2}\bigr) \geq \frac13\bigl(\mathrm{f}(u) + \mathrm{f}(v) + \mathrm{f}(w)\bigr)\) である。

  2. \((\ln\sin x)'' = -\mathrm{cosec}^2x < 0\) であるから、\(\ln\sin\) は \((0, \pi)\) で凹（concave）である。イェンセンの不等式（Jensen）より \(\frac13\ln(\sin A\sin B\sin C) \leq \ln\sin\frac\pi3\) となるので、積は高々 \(\bigl(\frac{\sqrt3}{2}\bigr)^3\) である。

  3. \((0, \frac\pi2)\) 上で \((\tan x)'' = 2\sec^2x\tan x > 0\) である。イェンセンの不等式より \(\tan A + \tan B + \tan C \geq 3\tan\frac\pi3 = 3\sqrt3\) となる。

  4. \((x^2)'' = 2 > 0\) である。イェンセンの不等式からこの不等式が得られ、これは分散（variance）\(\frac1n\sum a_i^2 - \bar a^2\) が非負であることを表している。

3.4 不等式を証明する面積

  1. \([0, \frac\pi2]\) 上の \(\mathrm{f} = \sin\) について、等号は \(b = \mathrm{f}(a)\) のとき成り立つ。\(a = \arcsin t\), \(b = t\) とすると、\(t\arcsin t = (1 - \cos(\arcsin t)) + \int_0^t\arcsin y\,\mathrm{d}y\) である。結果の右辺を微分すると \(\arcsin t + \frac{t}{\sqrt{1 - t^2}} - \frac{t}{\sqrt{1 - t^2}} = \arcsin t\) となる。

  2. \(p = q = 2\) としたヤングの不等式（Young’s inequality）より \(ab \leq \frac12(a^2 + b^2)\) である。\(\sum a_i^2 = \sum b_i^2 = 1\) ならば、これらを足し合わせて \(\sum a_ib_i \leq 1\) を得る。一般の場合は、これを \(a_i/\sqrt{\sum a_j^2}\) と \(b_i/\sqrt{\sum b_j^2}\) に適用すればよい。

  3. \(\int_0^a(e^x - 1)\,\mathrm{d}x = e^a - 1 - a\) および \(\int_0^b\ln(1 + y)\,\mathrm{d}y = (1 + b)\ln(1 + b) - b\) である。等号は \(b = e^a - 1\) のとき成り立つ。

  4. \(t = 1\) のとき \(1.571\) 対 \(1\)、\(t = 2\) のとき \(0.524\) 対 \(0.268\)、\(t = 10\) のとき \(0.1002\) 対 \(0.0501\) である。\(t\) が大きいとき、\(t - \sqrt{t^2 - 1} = \frac{1}{t + \sqrt{t^2 - 1}} \approx \frac{1}{2t}\) である。この評価は \(a = 0\) の場合から得られるもので、そのとき \((*)\) は単に \(0 \leq \int_0^b\arcsin y\,\mathrm{d}y\) を述べているにすぎない。\(b\) が小さいとき、この面積はおよそ \(\frac{b^2}{2}\) であり、これは \(b\arcsin b \approx b^2\) の半分であるから、これを捨てることで因子 \(2\) を失うのである。

3.5 \(\pi^e\) か \(e^\pi\) か？

  1. \(n^m = m^n\) は \(h(n) = h(m)\) を意味する。\(h\) は \((1, e)\) で増加し、その後は減少するので、2つのうち一方は \(e\) より小さい。それは \(2\) でなければならず（\(h(1) = 0\) という値は再びとられないから）、するともう一方は \(4\) である。よって、そのような組は \(\{2, 4\}\) のみである。

  2. \(e < 3 < \pi\) であり、そこで \(h\) は減少するので \(h(3) > h(\pi)\)、すなわち \(3^\pi > \pi^3\) である。\(\frac94\) と \(\sqrt5\) はともに \(e\) より小さく、\(\frac94 > \sqrt5\) であるから \(h(\frac94) > h(\sqrt5)\) となり、2つ目が得られる。\(1 < x < 2\) のとき、\(3 < x + 2 < 4\) であるから \(h(x) < h(2) = h(4) < h(x + 2)\) となり、\(x^{x+2} < (x + 2)^x\) である。最後に、\(9^{\sqrt2} = 3^{2\sqrt2}\) および \(\sqrt2^{\,9} = 16\sqrt2 = (2\sqrt2)^3\) である。\(e^2 < 8\) であるから \(e < 2\sqrt2 < 3\) であり、そこで \(h\) は減少するので \(h(2\sqrt2) > h(3)\) となる。これより \((2\sqrt2)^3 > 3^{2\sqrt2}\) が得られ、\(\sqrt2^{\,9}\) の方が大きい。

  3. \(e^{\pi/e - 1} > \frac\pi e\) であるから \(e^{\pi/e} > \pi\) である。両辺を \(e\) 乗せよ。

3.6 傾きの上界

  1. 両辺は \(x = -1, 0, 1\) で一致する二次式（quadratic）であるから、等しい（ラグランジュ補間（Lagrange interpolation））。微分すると \(\mathrm{f}(-1)(x - \frac12) - 2\mathrm{f}(0)x + \mathrm{f}(1)(x + \frac12)\) が得られる。

  2. \([-1, 1]\) 上で \(|\mathrm{f}'(x)| \leq |x - \frac12| + 2|x| + |x + \frac12| \leq 4\) であり、等号が成り立つのは \(x = \pm1\) のときに限られ、しかも \(\mathrm{f}(1)\), \(\mathrm{f}(-1)\), \(-\mathrm{f}(0)\) がすべて \(1\) に等しいか、すべて \(-1\) に等しいときに限られる。二次式はこれら3つの値で決まるので、\(\pm(2x^2 - 1)\) が得られる。

  3. \(T_3(\cos\theta) = \cos3\theta\) から \(4x^3 - 3x\) が得られ、\(T_3'(1) = 12 - 3 = 9\) である。\(\cos(n + 1)\theta + \cos(n - 1)\theta = 2\cos\theta\cos n\theta\) から \(T_{n+1} = 2xT_n - T_{n-1}\) が得られ、\(T_4 = 8x^4 - 8x^2 + 1\) である。

  4. \(-\sin\theta\,T_n'(\cos\theta) = -n\sin n\theta\) である。\(\theta \to 0\) のとき \(\frac{n\sin n\theta}{\sin\theta} \to n^2\) となる。

3.7 \(\pi^2 \leq 10\)

  1. \(\int_0^\pi\mathrm{f}^2 = \frac{\pi^9}{630}\) および \(\int_0^\pi(\mathrm{f}')^2 = \frac{2\pi^7}{105}\) であるから、\((*)\) より \(\pi^2 \leq 12\) が得られる。この四次式（quartic）は \(\sin x\) と比べて両端付近では平らすぎ、中央では尖りすぎているので、大きさに対する傾きの比が最適な値から遠くなる。

  2. \(\int_0^\pi(\sin x + \sin2x)^2 = \frac\pi2 + \frac\pi2 = \pi\)（交差項の積分は \(0\) である）であり、\(\int_0^\pi(\cos x + 2\cos2x)^2 = \frac\pi2 + 2\pi = \frac{5\pi}{2}\) である。

  3. \(\mathrm{g}(x) = \mathrm{f}(\pi x/L)\) とおく。左辺は \(\frac L\pi\) 倍になり、\(\int(\mathrm{g}')^2\) は \(\frac{\pi}{L}\) 倍になる。弦の振動では、最低振動数は \(\frac1L\) に比例する。すなわち、弦の長さを半分にすると音の高さ（振動数）は2倍になる。

  4. 評価 \(\pi^2 \leq \int(\mathrm{f}')^2\big/\!\int\mathrm{f}^2\)（適切な単位で）は \(\lambda \approx 1.133/\pi^2\) で最小となり、\(\pi^2 \leq 9.86975\) が得られる。真の値は \(9.86960\) である。

3.8 加法定理から関数を決める

  1. \(x = y = 0\) とおくと \(\mathrm{g}(0) = 0\) が得られる。\(y\) について微分して \(y = 0\) とおくと \(\mathrm{g}'(x) = k(1 + \mathrm{g}(x)^2)\) となるので、\(\frac{\mathrm{d}}{\mathrm{d}x}\arctan\mathrm{g}(x) = k\) であり、\(\mathrm{g}(x) = \tan kx\) である。

  2. \(y\) について微分すると \(\mathrm{f}'(x + y) = \mathrm{f}'(y)\) となるので、\(\mathrm{f}'\) は定数 \(k\) である。また \(\mathrm{f}(0) = 0\) である（\(x = y = 0\) とおく）。

  3. \(\mathrm{f}(x) = \mathrm{f}(x/2)^2 \geq 0\) であり、\(\mathrm{f}\) が \(0\) になることはない（もしそうなれば、至るところで \(0\) になる）。数学的帰納法（induction）より \(\mathrm{f}(n) = a^n\) である。\(\mathrm{f}(1/n)^n = \mathrm{f}(1) = a\) と \(\mathrm{f}(1/n) > 0\) から \(a^{1/n}\) が得られ、さらに \(\mathrm{f}(m/n) = \mathrm{f}(1/n)^m\) である。連続性がなければ、無理数における値には何の制約もない。実際、「ハメル基底（Hamel basis）」を用いて構成される、\(a^x\) ではない奇妙な解が存在する。

  4. 1回の噴射ごとにラピディティ（rapidity）\(\phi = \operatorname{artanh}\frac12\) が加わるので、\(k\) 回噴射した後の速さは \(\tanh k\phi = \frac{3^k - 1}{3^k + 1}\) である。すなわち \(0.8c\)、\(\frac{13}{14}c \approx 0.929c\)、\(\frac{40}{41}c \approx 0.976c\) となる。

3.9 新しい関数を発明する

  1. \(x = -1\) のとき \(x^2 - 2^x = \frac12 > 0\) であり、\(x = 0\) のときこれは \(-1\) である。よって負の解が存在する。\(x = -2u/\ln2\) とおくと、\(x^2 = 2^x\) は（\(x < 0\) であるから \(x = -2^{x/2}\) として）\(ue^u = \frac{\ln2}{2}\) となる。よって \(u = \mathrm{g}\bigl(\frac{\ln2}{2}\bigr)\) であり、\(x \approx -0.7667\) である。

  2. \(\mathrm{g}'e^{\mathrm{g}}(1 + \mathrm{g}) = 1\) であり、\(e^{\mathrm{g}} = x/\mathrm{g}\) である。\(x = -\frac1e\) のとき \(\mathrm{g} = -1\) であり、傾きは無限大である（グラフはそこで垂直になる）。

  3. \(x = we^w\) とおくと \(\mathrm{d}x = (1 + w)e^w\,\mathrm{d}w\) であり、\(w\) は \(0\) から \(1\) まで動く。よって \(\int_0^1w(1 + w)e^w\,\mathrm{d}w = \bigl[(w^2 - w + 1)e^w\bigr]_0^1 = e - 1\) である。

  4. \(T = \sqrt2^{\,T}\) は \(\frac{\ln T}{T} = \frac{\ln2}{2}\) を意味するので、\(T = 2\) または \(4\) である。項 \(1.414, 1.633, 1.761, \ldots\) は増加し、\(2\) 未満にとどまる（\(t_n < 2\) ならば \(t_{n+1} < \sqrt2^{\,2} = 2\)）ので、\(T = 2\) である。不動点（fixed point）\(4\) は反発的（repelling）である。
