第3章 \(\cdot\) 序論

正しさを確かめる

数学は理解するものではない。ただ慣れるものである。

— ジョン・フォン・ノイマン（John von Neumann）

\(1 = 2\) の「証明」を一つ示そう。\(a = b\) とする。このとき \(a^2 = ab\) であるから \(a^2 - b^2 = ab - b^2\) となり、これを因数分解すると \((a + b)(a - b) = b(a - b)\) である。両辺の \(a - b\) を約分すると \(a + b = b\) となり、\(a = b\) であるからこれは \(2b = b\) を意味し、したがって \(2 = 1\) である。

おそらく問題点には気づいたであろう。\(a = b\) であるから、「\(a - b\) を約分する」ことは \(0\) で割ることにほかならない。しかし、どの段階もいかにもっともらしく見えたか、そして誤りがいかにたやすくありふれた操作の中に隠れていたかに注意してほしい。実際の数学における実際の誤りがこれほど明白であることはまれであり、史上最も偉大な数学者たちでさえそうした誤りに欺かれてきた。本章のテーマは、そうした誤りを見抜くための思考の習慣である。すなわち、正確な定義、定理の慎重な使用、そしてあまりに簡単すぎるように見える論証に対する健全な疑いである。

なぜ厳密さが重要なのか

学校での数学は、主として答えを求めることである。大学での数学は、主として自分の答えが正しいと知ること、そしてそれを他人に納得させられることである。この転換は学校の数学と大学の数学のあいだにある最大の変化であり、戸惑いを覚えることもあるだろう。「明らかに」成り立つことを証明するのに、なぜ1ページも費やすのか、と。

その答えは、「明らか」というものが当てにならないからである。解析学（analysis）の歴史は、明らかに見えたのに誤っていた結果であふれている。たとえば、連続関数（continuous function）は、孤立した数点を除けば微分可能（differentiable）でなければならないという主張（アンペール（André-Marie Ampère）は1806年にその「証明」を発表したが、1872年にワイエルシュトラス（Weierstrass）はいたるところで微分可能でない連続関数を発見した）、連続関数の収束する和は連続であるという主張（コーシー（Cauchy）はこれを信じていたが、アーベル（Abel）が反例（counterexample）を見つけた）、収束する級数（convergent series）の項は和を変えずに並べ替えることができるという主張（一般にはできない）などである。厳密さ（rigour）は杓子定規な細かさではない。正しいものと、もっともらしいだけのものとを見分ける唯一の確かな方法なのである。

不等式：解析学の道具

本章の第二のテーマは不等式（inequality）である。学校の数学では、ほとんどの結果は等式、すなわち「これはあれに等しい」という形をしている。解析学では、ほとんどの結果は不等式、すなわち「これは高々あれである」という形をしている。数列が収束することを証明するには、誤差がどんな許容値よりも小さいことを示す。積分が存在することを証明するには、ある和が有界であることを示す。近似がどれほど良いかを評価するには、誤差を上から押さえる。プロの解析学者は等式よりもはるかに多くの時間を不等式の証明に費やしており、本章で出会う古典的な不等式（AM–GM、イェンセン（Jensen）、ヤング（Young）、ヘルダー（Hölder）、コーシー–シュワルツ（Cauchy–Schwarz））は、まさに商売道具なのである。

これらの不等式は、それ自体としても目を見張るものである。関数に関するたった一つの不等式が、うまく選んだ例と組み合わせることで \(\pi^2 \leq 10\) を証明する（第 3.7 節）。対数関数のグラフの形に関する事実から、\(\pi^e\) と \(e^\pi\) のどちらが大きいかが決着する（第 3.5 節）。ある化学者が抱いた測定誤差に関する疑問が、数学で最も重要な多項式のいくつかへとつながっていく（第 3.6 節）。

大学で出会うもの

厳密さは、大学1年次の解析学のテーマであり、また数と集合（Numbers and Sets）や基礎（Foundations）などと呼ばれることの多い、証明を正確に書く方法を学ぶ講義のテーマでもある。そこでは連続性と微分可能性の形式的な定義に出会い、また正確な仮定をもつ定理（中間値の定理（intermediate value theorem）、平均値の定理（mean value theorem）、最大値・最小値の定理（extreme value theorem））に出会う。これらの定理では仮定が本当に重要である。さらに進んだ講義では、本章の不等式がそれぞれ一つの分野へと発展していく。関数解析（functional analysis）は、第 3.4 節 や 第 3.7 節 に出てくるような積分によって測られる関数の空間を研究する。凸解析（convex analysis）や最適化（optimisation）は 第 3.3 節 から生まれる。近似理論（approximation theory）は 第 3.6 節 から生まれる。そして 第 3.9 節 に出てくるような特殊関数（special functions）は、応用数学や物理学のいたるところに現れる。

本章を貫く問い

三つの大きな問い

  1. 論証が正しいことをどうやって知るのか？もっともらしい論証が破綻するよくあるパターンにはどのようなものがあり、それをどう確かめればよいのか。

  2. 不等式はどうやって証明するのか？古典的な不等式はどこから来るのか、そしてどれを使うべきかをどう選ぶのか。

  3. 関数とは、本当のところ何なのか？関数を、式によってではなく、その関数がもつ性質によって定義することはできるのか。また、既存の関数では足りないとき、新しい関数を作り出すことはできるのか。

本章はまず誤りを見つけることから始まり（第 3.1 節）、続いて古典的な不等式を、それぞれ異なる角度から扱っていく。風変わりな帰納法（induction）、凸性（convexity）、面積、グラフの形、多項式補間（polynomial interpolation）、そしてテスト関数（test function）である。最後に、性質によって定義される関数を扱う二つの節で締めくくる。加法定理（addition law）から定まる \(e^x\) と \(\tanh x\)、そして逆関数として定義されるまったく新しい関数である。
