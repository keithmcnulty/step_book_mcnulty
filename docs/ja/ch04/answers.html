第4章 · きちんと学ぶ微分積分学

「次の一歩」の解答

以下は略解とヒントであり、完全な解答ではない。結果と鍵となるステップを示してあるので、自分の答えの確認に用いてほしい。答えを見る前に、各問題にきちんと取り組むこと。

4.1 積分とは何か？

  1. この和は、\([1, 2]\) 上で \(y = \mathrm{f}(x)\) の下にある幅 \(\frac1n\) の \(n\) 個の長方形の面積の総和である。\(\mathrm{f}(x) = \frac1x\) とすると、\(\frac1n\sum\frac{1}{1 + m/n} = \sum\frac{1}{n + m} \to \ln2\) となる。2番目の和は \(\frac1n\sum\frac{1}{1 + (m/n)^2} \to \int_0^1\frac{\mathrm{d}x}{1 + x^2} = \frac\pi4\) である。

  2. \(n\) 個の帯に分けたときの上和（upper sum）は \(\frac an\sum_{r=1}^{n}\bigl(\frac{ra}{n}\bigr)^2 = \frac{a^3(n + 1)(2n + 1)}{6n^2}\) であり、下和（lower sum）は最初の因数の \(n + 1\) を \(n - 1\) に置き換えたものである。いずれも \(\frac{a^3}{3}\) に収束する。

  3. 各項は次々に打ち消し合う（telescope）：\(r(r + 1)\cdots(r + k) - (r - 1)r\cdots(r + k - 1) = (k + 1)\,r(r + 1)\cdots(r + k - 1)\)。

  4. \(\sum_{r=1}^nr^5 = \frac{n^2(n + 1)^2(2n^2 + 2n - 1)}{12}\)。

4.2 積分から三角関数を構成する

  1. 導関数（derivative）は \(-\mathrm{f}(a - x)\mathrm{f}(x) + \mathrm{f}(a - x)\mathrm{f}(x) = 0\) であるから、\(\mathrm{f}(a - x)\mathrm{f}(x) = \mathrm{f}(a)\) である。ここで \(a = x + y\) とおけばよい。余弦（cosine）については、\(y\) を固定して \(p(x) = \mathrm{c}(x + y) - \mathrm{c}(x)\mathrm{c}(y) + \mathrm{s}(x)\mathrm{s}(y)\)、\(q(x) = \mathrm{s}(x + y) - \mathrm{s}(x)\mathrm{c}(y) - \mathrm{c}(x)\mathrm{s}(y)\) とおく。すると \(p' = -q\)、\(q' = p\) となるから \(p^2 + q^2\) は定数であり、\(x = 0\) でその値は \(0\) である。

  2. \(\frac{\mathrm{d}y}{\mathrm{d}u} = (1 + u^2)^{-3/2}\)、\(\sqrt{1 - y^2} = (1 + u^2)^{-1/2}\) であるから、\(\frac{\mathrm{d}y}{\sqrt{1 - y^2}} = \frac{\mathrm{d}u}{1 + u^2}\) となる。よって \(\mathrm{S}(\frac{1}{\sqrt2}) = \mathrm{T}(1)\) であり、小問 (i) で \(x = 1\) とすると \(\mathrm{T}(1) = \frac12\mathrm{T}_\infty\) が得られる。

  3. \(a = \frac12\)、\(x = \frac13\) とすると \(\frac{x + a}{1 - ax} = 1\) となるので、\(\mathrm{T}(\frac13) = \mathrm{T}(1) - \mathrm{T}(\frac12)\) である。

  4. \([0, 1]\) 上で \(\frac{1}{1 + u^2} \leq 1\)、\([1, x]\) 上で \(\leq \frac{1}{u^2}\) であるから、\(x \geq 1\) のとき \(\mathrm{T}(x) \leq 1 + (1 - \frac1x) < 2\) であり、\(0 < x < 1\) のとき \(\mathrm{T}(x) < \mathrm{T}(1) \leq 1\) である。（評価 \(1 + \int_1^x u^{-2}\,\mathrm{d}u\) は \(x < 1\) では成り立たない。\(x = \frac12\) ではこれは \(0\) に等しい。）\(\mathrm{T}\) は増加かつ有界（bounded）であるから、極限（limit）をもつ。

4.3 \(22/7\) は \(\pi\) より大きい

  1. \(\frac{22}{7} - \pi \approx 0.001264\) であり、これは \(\frac{1}{1260} \approx 0.000794\) と \(\frac{1}{630} \approx 0.001587\) の間にある。

  2. \(\frac{(4!)^2}{9!} = \frac{576}{362\,880} = \frac{1}{630}\)。

  3. \(\frac{x(1 - x)^2}{1 + x^2} = x - 2 + \frac{2}{1 + x^2}\) であり、これを積分すると \(\frac12 - 2 + \frac\pi2\) となる。同様に \(\frac{x^2(1 - x)^4}{1 + x^2} = x^4 - 4x^3 + 5x^2 - 4 + \frac{4}{1 + x^2}\) であり、これを積分すると \(\frac15 - 1 + \frac53 - 4 + \pi = \pi - \frac{47}{15}\) となる。どちらの積分も正である。これらの被積分関数（integrand）は \(\frac{x^4(1 - x)^4}{1 + x^2}\)（その最大値は約 \(0.003\)）よりずっと大きいので、誤差 \(\frac\pi2 - \frac32 \approx 0.07\) および \(\pi - \frac{47}{15} \approx 0.008\) も大きくなる。

  4. 多項式の割り算（polynomial division）を行うと剰余（remainder）\(\frac{16}{1 + x^2}\) が残り、これを積分すると \(4\pi\) になる。積分の値は \(4\pi - \frac{188684}{15015} \approx 3.6 \times 10^{-6}\) であるから、\(\pi \approx 3.14159174\) である。

4.4 ウォリス、ベータ、そして二分の一の階乗

  1. \(u_{2m} = \frac{1 \cdot 3 \cdots (2m - 1)}{2 \cdot 4 \cdots 2m}\cdot\frac\pi2\)、\(u_{2m+1} = \frac{2 \cdot 4 \cdots 2m}{3 \cdot 5 \cdots (2m + 1)}\) である。すると \(1 < \frac{u_{2m}}{u_{2m+1}} < \frac{u_{2m-1}}{u_{2m+1}} = \frac{2m + 1}{2m}\) であるから、この比は \(1\) に収束し、これを整理すると \(\frac\pi2 = \prod_{k \geq 1}\frac{(2k)^2}{(2k - 1)(2k + 1)}\) となる。

  2. 部分積分（integration by parts）により \(I_n = \frac{n}{n + 1}\int_0^1x^{n+1}(1 - x)^{n-1}\,\mathrm{d}x\) が得られ、\(x^{n+1}(1 - x)^{n-1} = x^n(1 - x)^{n-1} - x^n(1 - x)^n\) と書いて対称性（symmetry）を用いると \(I_n = \frac{n}{2(2n + 1)}I_{n-1}\) が導かれる。帰納法（induction）により \(\frac{(n!)^2}{(2n + 1)!}\) を得る。\(x = \sin^2\theta\) とおくと \(I_{1/2} = \int_0^{\pi/2}2\sin^2\theta\cos^2\theta\,\mathrm{d}\theta = \frac\pi8\) である。この公式からは \(\bigl((\frac12)!\bigr)^2/2! = \frac\pi8\) が示唆されるので、\((\frac12)! = \frac{\sqrt\pi}{2}\)（これは \(\Gamma(\frac32)\) である）となる。

  3. 対称性は \(x \mapsto 1 - x\) から、漸化式（recurrence）は \(x^p = x^{p-1} - x^{p-1}(1 - x)\) から得られる。また \(x = \frac{t}{1 + t}\) とおくと \(1 - x = \frac{1}{1 + t}\)、\(\mathrm{d}x = \frac{\mathrm{d}t}{(1 + t)^2}\) である。この積分は \(\mathrm{b}(\frac52, \frac72)\) であり、漸化式と対称性を用いて \(\mathrm{b}(\frac12, \frac12) = \pi\) に帰着させると \(\frac{3\pi}{256}\) を得る。

  4. 小問 (i) で求めた明示的な値から、\(u_{2m} = \frac{(2m)!}{(2^mm!)^2}\cdot\frac\pi2 = \binom{2m}{m}\frac{\pi}{2^{2m+1}}\) である。さらに \(2mu_{2m}^2 \to \frac\pi2\) から \(\binom{2m}{m}^2 \approx \frac{4^{2m}}{\pi m}\) が得られる。\(m = 10\) のとき、\(\binom{20}{10} = 184\,756\) に対して \(\frac{4^{10}}{\sqrt{10\pi}} \approx 187\,079\)（約 \(1.3\%\) 大きい）である。

4.5 2年生の夢

  1. \(x^{-x} = e^{-x\ln x} = \sum_{n \geq 0}\frac{(-x\ln x)^n}{n!}\) であり、\(\int_0^1\frac{x^n(-\ln x)^n}{n!}\,\mathrm{d}x = \frac{1}{(n + 1)^{n+1}}\) である（\(x = e^{-u}\) と置換（substitution）する）。よってこの積分は \(\sum_{n \geq 1}n^{-n} \approx 1.2913\) である。

  2. \(\frac{\mathrm{d}}{\mathrm{d}x}x^x = x^x(\ln x + 1)\) であり、これは \(x = \frac1e\) で \(0\) になる。そのときの値は \((e^{-1})^{e^{-1}} = e^{-1/e} \approx 0.692\) である。

  3. 各項は \(\frac{1}{n^n}\) である。\(7\) 項で打ち切ると誤差は \(\frac{1}{8^8} \approx 6 \times 10^{-8}\) より小さく、これで十分である。\(6\) 項で打ち切った場合の評価 \(\frac{1}{7^7} \approx 1.2 \times 10^{-6}\) では足りない。よって \(7\) 項必要である。

  4. 部分積分により、\(\int_0^1x^2\ln x\,\mathrm{d}x = \bigl[\frac{x^3\ln x}{3}\bigr]_0^1 - \int_0^1\frac{x^2}{3}\,\mathrm{d}x = -\frac19\) である。一般に \(\int_0^1x^n\ln x\,\mathrm{d}x = -\frac{1}{(n + 1)^2}\) であり、また \(\frac{\ln x}{1 - x} = \sum_{n \geq 0}x^n\ln x\) である。

4.6 公式で表せない積分

  1. 微分すると、\(\frac{\mathrm{d}}{\mathrm{d}x}\frac{e^x}{x + 1} = \frac{xe^x}{(x + 1)^2}\)、また \(\frac{\mathrm{d}}{\mathrm{d}x}\frac{(x - 1)e^x}{x + 1} = e^x\Bigl(\frac{x - 1}{x + 1} + \frac{2}{(x + 1)^2}\Bigr) = \frac{(x^2 + 1)e^x}{(x + 1)^2}\) である。

  2. \(\frac{\mathrm{d}}{\mathrm{d}x}\bigl(\mathrm{P}e^{-x^2}\bigr) = (\mathrm{P}' - 2x\mathrm{P})e^{-x^2}\) であり、\(\mathrm{P}' - 2x\mathrm{P}\) の次数（degree）は（\(\mathrm{P} \neq 0\) のとき）\(\deg\mathrm{P} + 1 \geq 1\) であるから、これが \(1\) に等しくなることはない。

  3. \(\mathrm{R} = \mathrm{P}/\mathrm{Q}\)（既約な形）が \(0\) において位数（order）\(k \geq 1\) の極（pole）をもつとすると、\(\mathrm{R}' + \mathrm{R}\) はそこで位数 \(k + 1 \geq 2\) の極をもつが、\(\frac1x\) の極の位数は \(1\) である。\(\mathrm{R}\) が \(0\) に極をもたなければ、\(\mathrm{R}' + \mathrm{R}\) も極をもたない。いずれにせよ \((\mathrm{R}e^x)' \neq \frac{e^x}{x}\) である。

  4. \(\frac{\mathrm{P}e^x}{x + 1}\) を微分すると \(e^x\frac{(x + 1)\mathrm{P}' + x\mathrm{P}}{(x + 1)^2}\) となる。\(x = -1\) において \(\mathrm{f}(-1) = -\mathrm{P}(-1)\) であり、\(\mathrm{f}' = (x + 1)\mathrm{P}'' + (x + 1)\mathrm{P}' + \mathrm{P}\) から \(\mathrm{f}'(-1) = \mathrm{P}(-1)\) を得る。\(x^3 - 2\) については \(-3 + 3 = 0\)、\(x\) については \(-1 + 1 = 0\)、\(x^2 + 1\) については \(2 - 2 = 0\) である。この条件は十分条件でもある。次数 \(d\) 未満の多項式から次数 \(d\) 以下の多項式への写像 \(\mathrm{P} \mapsto (x + 1)\mathrm{P}' + x\mathrm{P}\) は単射（injective）であるから、その像（image）の次元（dimension）は \(d\) である。そしてこの像は、\(\mathrm{f}(-1) + \mathrm{f}'(-1) = 0\) を満たす \(\mathrm{f}\) 全体のなす \(d\) 次元空間に含まれるので、その空間全体に一致する。

4.7 変分法

  1. \(y = \cos\frac{\pi x}{2}\) とすると、\(J = \frac{\pi^2}{4}\int_0^1\sin^2 - a^2\int_0^1\cos^2 = \frac12\bigl(\frac{\pi^2}{4} - a^2\bigr) < 0\) である。

  2. \(J(y + \varepsilon\eta) = J(y) + 2\varepsilon\int_0^1(y'\eta' - a^2y\eta) + \varepsilon^2J(\eta)\) である。\(\varepsilon = 0\) で最小となるためには、1次の項（linear term）が消えなければならない。部分積分すると、\(\eta(1) = 0\) を満たすすべての \(\eta\) に対して \(-y'(0)\eta(0) - \int_0^1(y'' + a^2y)\eta = 0\) となり、これから \(y'' + a^2y = 0\) かつ \(y'(0) = 0\) が従う。

  3. \(x = Lu\) とおくと \(\int_0^L\bigl((y')^2 - a^2y^2\bigr)\,\mathrm{d}x = \frac1L\int_0^1\bigl((Y')^2 - (aL)^2Y^2\bigr)\,\mathrm{d}u\) であるから、条件は \(aL \leq \frac\pi2\) である。（\(aL = \frac\pi2\) のときも本文と同様に積分が負になることはないが、\(y = \cos\frac{\pi x}{2L}\) のときに \(0\) となる。\(aL > \frac\pi2\) のときは、同じ関数によって積分は負になる。）

  4. サイクロイド（cycloid）は \(x = R(\theta - \sin\theta)\)、\(y = R(1 - \cos\theta)\) である。等時曲線（tautochrone）については 第 11.4 節 を参照のこと。弧長（arc length）を用いて表すと、運動はちょうど単振動（simple harmonic motion）になる。

4.8 球形のパンを切る

  1. \(V/A = \frac{\frac43\pi a^3}{4\pi a^2} = \frac a3\) である。しかし、高さ \(t\) の残りの部分については \(A = 2\pi at\)、\(V = \frac13\pi t^2(3a - t)\) であるから \(V/A = \frac{t(3a - t)}{6a}\) となり、これは \(t = \frac32a\) のとき最大値 \(\frac{3a}{8}\) をとる。これは \(\frac a3\) より大きい。

  2. この帯の高さは、球の高さ \(2R\) のうち \(2R\sin23.4^\circ\) であるから、その割合は \(\sin23.4^\circ \approx 0.40\) である。

  3. \(y = \sqrt x\) のとき \(y\sqrt{1 + (y')^2} = \sqrt{x + \frac14}\) であり、定数ではない。\(y\sqrt{1 + (y')^2} = c\) からは \((y')^2 = \frac{c^2}{y^2} - 1\) が得られ、その解は \(y = c\)（円柱（cylinder））と円 \((x - x_0)^2 + y^2 = c^2\)（球）である。

  4. 球の体積は \(\frac43\pi a^3\)、円柱の体積は \(\pi a^2 \cdot 2a = 2\pi a^3\) であり、その比は \(\frac23\) である。

4.9 ホールディッチの定理

  1. \(\frac12\int_0^{2\pi}(p\cos t \cdot q\cos t + q\sin t \cdot p\sin t)\,\mathrm{d}t = \frac12 \cdot 2\pi pq = \pi pq\)。

  2. 2本の弦（chord）の端点を結んでできる三角形は相似（similar）である（同じ弧に対する角は等しい）から、\(PA \cdot PB = PC \cdot PD\) である。半径 \(R\) の円において \(P\) が中心から距離 \(r\) にあるとき、\(P\) を通る直径を考えると \((R - r)(R + r)\) となるので、\(ab = R^2 - r^2\) であり、環状領域（ring）の面積は \(\pi R^2 - \pi r^2 = \pi ab\) である。

  3. \(a = b\) ならば \(f = \pi(a - b) = 0\) であり、環状領域の面積は \(\pi a^2 = \frac{\pi L^2}{4}\) となる。これは棒を直径とする円の面積である。

  4. \(O\) を通る2辺に沿っては \(x\,\mathrm{d}y - y\,\mathrm{d}x = 0\) である。3番目の辺を \(0 \leq s \leq 1\) として \((x_1, y_1) + s(x_2 - x_1, y_2 - y_1)\) と媒介変数表示（parametrisation）すると、これは \((x_1y_2 - x_2y_1)\,\mathrm{d}s\) となる。よって面積は \(\frac12|x_1y_2 - x_2y_1|\) である。
