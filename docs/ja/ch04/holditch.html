ホールディッチの定理

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第4章章全体のPDF
問題

STEP III 2011、第5問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/11-s3-q5

導入

任意の卵形の曲線をとる。凸（convex）でありさえすれば形は何でもよい。その内側で一定の長さの棒を、両端を曲線上に保ったまま一周させる。棒の上に一点を印し、棒を長さ \(a\) と \(b\) の部分に分ける。棒が一周すると、この点はひとまわり小さな卵形を描く。二つの曲線にはさまれた環状の領域の面積はいくらか。

驚くべきことに、答えはもとの曲線の形によらず \(\pi ab\) である。細長い卵形でも、卵の形でも、丸みを帯びた三角形でも、環状の領域の面積はつねに同じであり、棒の上の点の位置だけで決まる。この結果は 1858 年に、ケンブリッジ大学ゴンヴィル・アンド・キーズ・カレッジ（Gonville and Caius College, Cambridge）のフェローであった Hamnet Holditch 牧師によって発見されたもので、初等幾何学において最も意外な定理の一つである。この問題では、面積を表すただ一つの公式を用いてこれを証明する。

取りかかる前に

最も簡単な場合に定理を確かめよ。\(\mathcal{C}\) が半径 \(R\) の円であるとき、\(P\) はどのような曲線を描くか。また、環状の領域の面積はいくらか。

対称性により、\(P\) は同じ中心をもつ、ある半径 \(r\) の円を描く。棒 \(AB\) は \(P\) を通る大きい円の弦（chord）であり、方べきの定理（intersecting chords theorem、「power of a point」とも呼ばれる）によれば、\(P\) を通る任意の弦について \(PA \times PB = R^2 - r^2\) が成り立つ。よって \(ab = R^2 - r^2\) であり、環状の領域の面積は \(\pi R^2 - \pi r^2 = \pi ab\) となる。定理は、これが円に限らずすべての凸曲線について成り立つと主張しているのである。

順を追って解く

段階 1 座標から面積を求める

\(x = r\cos\theta\)、\(y = r\sin\theta\) とし、これらはすべて \(t\) の関数であるとする。ドットが \(\frac{\mathrm{d}}{\mathrm{d}t}\) を表すとき、\(x\dot y - y\dot x\) を計算せよ。

\(\dot x = \dot r\cos\theta - r\sin\theta\,\dot\theta\)、\(\dot y = \dot r\sin\theta + r\cos\theta\,\dot\theta\) である。したがって \[x\dot y - y\dot x = r\cos\theta\,(\dot r\sin\theta + r\cos\theta\,\dot\theta) - r\sin\theta\,(\dot r\cos\theta - r\sin\theta\,\dot\theta) = r^2\dot\theta.\] よって \(\frac12\int r^2\,\mathrm{d}\theta = \frac12\int r^2\dot\theta\,\mathrm{d}t = \frac12\int (x\dot y - y\dot x)\,\mathrm{d}t\) である。■

この公式には極座標（polar coordinates）は必要なく、媒介変数（parameter）の関数としての直交座標の位置さえあればよい。点が \(O\) を囲む閉曲線を反時計回りに一周するとき、この公式は曲線の内部の面積を与える。

段階 2 棒の両端

棒は \(A\) から \(B\) へ向かって \((\cos t, \sin t)\) の方向を向いており、\(P\) は \(A\) から距離 \(a\)、\(B\) から距離 \(b\) の位置にある。よって \[A = (x - a\cos t,\; y - a\sin t), \qquad B = (x + b\cos t,\; y + b\sin t).\]

段階 3 \(OA\) が掃く面積

\((*)\) を \(A\) に適用せよ。\(x_A\dot y_A - y_A\dot x_A\) を展開し、項を \(a\) の累乗ごとに整理せよ。

\(x_A = x - a\cos t\)、\(y_A = y - a\sin t\) とすると、\(\dot x_A = \dot x + a\sin t\)、\(\dot y_A = \dot y - a\cos t\) である。展開すると \[\begin{aligned} x_A\dot y_A - y_A\dot x_A &= (x - a\cos t)(\dot y - a\cos t) - (y - a\sin t)(\dot x + a\sin t) \\ &= (x\dot y - y\dot x) + a^2(\cos^2 t + \sin^2 t) - a\bigl[(x + \dot y)\cos t + (y - \dot x)\sin t\bigr]. \end{aligned}\] \(0\) から \(2\pi\) まで積分して半分にすると、第1項は \([P]\) を、第2項は \(\frac12 a^2 \cdot 2\pi = \pi a^2\) を、第3項は \(-af\) を与える。よって \[[A] = [P] + \pi a^2 - af. \qed\]

次に \([B]\) を求めよ。（ヒント：\(B\) は、\(A\) の式の \(a\) を何に置き換えれば得られるか。）

\(B = (x + b\cos t, y + b\sin t)\) は、\(A\) の式で \(a\) を \(-b\) に置き換えたものである。よって \[[B] = [P] + \pi b^2 + bf.\]

段階 4 \(f\) を消去する

\(A\) も \(B\) も同じ曲線 \(\mathcal{C}\) を一周する。このことから \([A]\) と \([B]\) について何がわかるか。

\(t\) が \(0\) から \(2\pi\) まで動くとき、\(A\) と \(B\) はいずれも \(\mathcal{C}\) を反時計回りに一周するので、\([A] = [B] = \text{面積}(\mathcal{C})\) である。二つの式を等置すると \[\pi a^2 - af = \pi b^2 + bf \quad\Longrightarrow\quad f(a + b) = \pi(a^2 - b^2) \quad\Longrightarrow\quad f = \pi(a - b).\] \(P\) は \(\mathcal{D}\) を一周するので \([P] = \text{面積}(\mathcal{D})\) であり、 \[\text{面積}(\mathcal{C}) - \text{面積}(\mathcal{D}) = [A] - [P] = \pi a^2 - a\pi(a - b) = \pi ab. \qed\] 曲線の形に依存する謎めいた量 \(f\) は、一度も計算されなかった。消去されたのである。

振り返り

  • 問題に合った公式。面積の公式 \((*)\) に必要なのは、媒介変数の関数としての座標だけであった。これはまさに棒の運動を記述する方法そのものである。

  • 二つの式に一つの未知量。\(f\) は計算できなかったが、\(f\) を含む等式が二つあったので、連立方程式を解くときのように \(f\) を消去できた。

  • まず特別な場合を試す。円の場合を調べたことで、取りかかる前に答え \(\pi ab\) が得られ、目指すべきものがわかった。

背後にある数学

グリーンの定理とプラニメータ

公式 \((*)\) はグリーンの定理（Green’s theorem）の特別な場合である。グリーンの定理は、閉曲線に沿った積分と、その内部の領域上の積分とを結びつける。面積に関する形では、曲線で囲まれた面積は \(\frac12\oint(x\,\mathrm{d}y - y\,\mathrm{d}x)\) であると述べており、これは境界を一周するだけで計算できる積分である。技術者たちはこれをプラニメータ（planimeter、面積計）として利用した。プラニメータは 19 世紀に発明された機械式の器具で（最も成功したのは Jakob Amsler による 1854 年の設計である）、地図や図面上の図形の境界を指針でなぞると、車輪が囲まれた面積を記録する。プラニメータは、デジタルな方法に取って代わられるまで、土地の面積の測定や、インジケータ線図から蒸気機関のする仕事を求める計算など、さまざまな用途に用いられた。Holditch の定理はこれと密接に関係しており、棒はプラニメータの腕のようなものである。

細かな条件

Holditch は条件にあまり注意を払わずに定理を述べたが、実際にはいくつかの条件が必要である。棒は両端を曲線上に保ったまま一周できなければならず、また描かれる曲線 \(\mathcal{D}\) は一度だけなぞられる単純閉曲線（simple closed curve）でなければならない。\(\mathcal{C}\) の幅に比べて棒が長すぎると、\(\mathcal{D}\) は自分自身と交わることがあり、公式が与える「面積」は、ある領域を二重に、あるいは負の符号をつけて数えてしまう。この問題では、\(\mathcal{D}\) が \(O\) を含む凸曲線であると仮定することで、こうした難点を避けている。定理が成り立つ条件を正確に突き止めることは、美しいアイデアをいかに厳密なものにしなければならないかを示すよい例であり、これは第 3 章のテーマでもある。

思考のスキル

計算できないものは消去する

ある量が複雑すぎて計算できないときは、それを含む二つの異なる等式を探し、その量を消去せよ。

ここでは \(f\) は曲線のあらゆる細部に依存していたが、\([A]\) と \([B]\) の両方の式に現れ、\([A] = [B]\) という事実によって消えた。答え \(\pi ab\) が曲線によらないものになりえたのは、曲線に依存する部分が打ち消し合ったからにほかならない。

次の一歩

  1. 楕円の面積。\(x = p\cos t\)、\(y = q\sin t\) として \((*)\) を用い、半軸の長さが \(p\) と \(q\) の楕円の面積が \(\pi pq\) であることを示せ。

  2. 円の場合。方べきの定理を証明せよ。すなわち、円の二本の弦が \(P\) で交わるとき、それぞれの弦が分けられてできる二つの線分の長さの積は等しいことを示せ。これを用いて、円に対する Holditch の定理を導け。

  3. 中点。\(f = \pi(a - b)\) から、\(P\) が棒の中点（midpoint）であるとき \(f = 0\) となることを示せ。このとき、環状の領域の面積を棒の長さ \(L\) を用いて表せ。

  4. 三角形。 発展 頂点が \((0, 0)\)、\((x_1, y_1)\)、\((x_2, y_2)\) である三角形の境界をなぞることにより、\((*)\) を用いてその面積を求め、それが \(\frac12|x_1y_2 - x_2y_1|\) に等しいことを示せ。これは任意の多角形の面積を与える「靴ひも公式」（shoelace formula）の出発点である。

さらに学ぶために

  • Mark Levi, The Mathematical Mechanic（Princeton University Press）。棒や車輪やばねを使った物理的な推論によって数学の結果を証明する本であり、この節の精神に通じる。

  • H. M. Schey, Div, Grad, Curl, and All That（Norton）。グリーンの定理を含む、ベクトル解析への気軽な入門書。

  • Hamnet Holditch,「Geometrical theorem」, Quarterly Journal of Pure and Applied Mathematics 2 (1858)。原論文。短い一段落だけのもので、細かな条件は一切書かれていない。
