4.6

公式で表せない積分

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第4章章全体のPDF
問題

STEP III 2016、第3問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/16-s3-q3

導入

微分（differentiation）は機械的な作業である。規則があり、通常の部品から組み立てられた関数であれば、その規則を当てはめるだけで微分できる。積分（integration）はそうはいかない。どんな技法も受けつけない積分に出会い、自分の工夫が足りないだけなのかと悩んだ経験は誰にでもあるだろう。実は、その答えが「誰にも工夫のしようがない、なぜなら公式が存在しないからだ」ということもある。

この問題は、ある特別な場合についてそのことを証明する。積分 \(\int \frac{e^x}{x+1}\,\mathrm{d}x\) は面積としては確かに存在する。しかし、それを（有理関数（rational function））\(\times\, e^x\) という形、すなわち部分積分（integration by parts）から予想される形に書くことはできない。何かを見つけるのではなく、何かが不可能であることを証明するというのは、それまでとは異なる、きわめて数学らしい営みである。

取りかかる前に

\(\int \mathrm{f}(x)e^x\,\mathrm{d}x = \frac{\mathrm{P}}{\mathrm{Q}}e^x + C\) であるとすると、\(\mathrm{P}\) と \(\mathrm{Q}\) はどのような等式を満たさなければならないか。（右辺を微分してみよ。）

微分すると \(\dfrac{\mathrm{d}}{\mathrm{d}x}\left(\dfrac{\mathrm{P}}{\mathrm{Q}}e^x\right) = \dfrac{\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q}}{\mathrm{Q}^2}\,e^x\) となり、これが \(\mathrm{f}(x)e^x\) に等しくなければならない。したがって、問題全体は多項式（polynomial）の恒等式（identity） \[\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q} = \mathrm{f}\,\mathrm{Q}^2.\] についての問題になる。積分についての問いが、多項式、すなわちその因数と次数についての問いに変わったのである。

順を追って解く

段階 1 因数 \(x + 1\)

\(\mathrm{f}(x) = \dfrac{x^3 - 2}{(x+1)^2}\) のとき、恒等式の両辺に \((x+1)^2\) を掛けると \[(x+1)^2\bigl(\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q}\bigr) = (x^3 - 2)\,\mathrm{Q}^2. \tag{$\dagger$}\]

\((\dagger)\) に \(x = -1\) を代入せよ。何が起こらなければならないか。

左辺は \(x = -1\) で \(0\) である。右辺は \((-1 - 2)\,\mathrm{Q}(-1)^2 = -3\,\mathrm{Q}(-1)^2\) である。よって \(\mathrm{Q}(-1) = 0\) であり、因数定理（factor theorem）により \(x + 1\) は \(\mathrm{Q}\) の因数である。■

段階 2 次数

\(\mathrm{P}\) の次数（degree）を \(p\)、\(\mathrm{Q}\) の次数を \(q\) とする。

\(\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q}\) において、次数が最も高い項はどれか。それは他の項と打ち消し合いうるか。

\(\mathrm{P}\mathrm{Q}\) の次数は \(p + q\) であり、\(\mathrm{P}'\mathrm{Q}\) と \(\mathrm{P}\mathrm{Q}'\) の次数は高々 \(p + q - 1\) である。よって \((\dagger)\) の左辺の次数はちょうど \(2 + p + q\) であり、右辺の次数は \(3 + 2q\) である。両者を等しいとおいて \(p = q + 1\) を得る。■

段階 3 \(\mathrm{P}\) を求める

\(\mathrm{Q} = x + 1\) のとき \(\mathrm{Q}' = 1\) であり、\(\mathrm{P}\) の次数は \(2\) である。\((\dagger)\) を \((x + 1)^2\) で割ると \[\mathrm{P}'(x + 1) - \mathrm{P} + \mathrm{P}(x + 1) = x^3 - 2, \qquad\text{すなわち、}\qquad (x + 1)\mathrm{P}' + x\mathrm{P} = x^3 - 2.\] \(\mathrm{P} = \alpha x^2 + \beta x + \gamma\) とおいてみる。左辺は \[(x + 1)(2\alpha x + \beta) + \alpha x^3 + \beta x^2 + \gamma x = \alpha x^3 + (2\alpha + \beta)x^2 + (2\alpha + \beta + \gamma)x + \beta.\] となる。\(x^3 - 2\) と係数を比較すると、\(\alpha = 1\)、\(2\alpha + \beta = 0\) より \(\beta = -2\)、さらに \(\gamma = 0\) である。定数項 \(\beta = -2\) とも矛盾しない。よって \[\mathrm{P}(x) = x^2 - 2x, \qquad \int \frac{x^3 - 2}{(x+1)^2}\,e^x\,\mathrm{d}x = \frac{x^2 - 2x}{x + 1}\,e^x + C. \qed\] （望むなら微分して確かめてみよ。商の微分法のよい練習になる。）

段階 4 不可能性

次に、\(\mathrm{P}\) と \(\mathrm{Q}\) が共通因数をもたないとして、\(\int \frac{e^x}{x+1}\,\mathrm{d}x = \frac{\mathrm{P}}{\mathrm{Q}}e^x + C\) と仮定する。恒等式は \[(x + 1)\bigl(\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q}\bigr) = \mathrm{Q}^2.\] となる。段階 1 と同様に、\(x = -1\) を代入すると \(\mathrm{Q}(-1) = 0\) がわかる。\(\mathrm{Q} = (x+1)^k\mathrm{R}\) と書く。ただし \(k \geq 1\)、\(\mathrm{R}(-1) \neq 0\) である（因数 \(x + 1\) をできるだけ多くくくり出す）。

\(\mathrm{Q} = (x+1)^k\mathrm{R}\) を代入し、因数 \((x + 1)\) をできるだけ多く約分してから、\(x = -1\) を代入せよ。\(\mathrm{P}(-1)\) について何がわかるか。

このとき \(\mathrm{Q}' = k(x+1)^{k-1}\mathrm{R} + (x+1)^k\mathrm{R}'\) であり、 \[\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q} = (x+1)^{k-1}\Bigl[(x+1)\bigl(\mathrm{P}'\mathrm{R} - \mathrm{P}\mathrm{R}' + \mathrm{P}\mathrm{R}\bigr) - k\mathrm{P}\mathrm{R}\Bigr].\] となる。よって恒等式は \((x+1)^k\bigl[(x+1)(\mathrm{P}'\mathrm{R} - \mathrm{P}\mathrm{R}' + \mathrm{P}\mathrm{R}) - k\mathrm{P}\mathrm{R}\bigr] = (x+1)^{2k}\mathrm{R}^2\) となる。\((x+1)^k\) で割ると \[(x+1)\bigl(\mathrm{P}'\mathrm{R} - \mathrm{P}\mathrm{R}' + \mathrm{P}\mathrm{R}\bigr) - k\mathrm{P}\mathrm{R} = (x+1)^k\mathrm{R}^2.\] \(k \geq 1\) であるから、\(x = -1\) とすると \(-k\,\mathrm{P}(-1)\mathrm{R}(-1) = 0\) を得る。\(k \neq 0\) かつ \(\mathrm{R}(-1) \neq 0\) であるから、\(\mathrm{P}(-1) = 0\) でなければならない。しかしそうすると \(x + 1\) は \(\mathrm{P}\) と \(\mathrm{Q}\) の両方を割り切り、両者が共通因数をもたないという仮定に矛盾する。よって、そのような \(\mathrm{P}\) と \(\mathrm{Q}\) は存在しない。■

振り返り

  • 代数の言葉に翻訳する。「これはこの形で積分できるか」という問いが、「この多項式の恒等式は解をもつか」という問いになった。

  • 特別な点で値を求める。\(x = -1\) を代入することで、因数についての情報を3度にわたって引き出した。

  • 既約分数を用いた背理法。第 1.3 節 の \(\sqrt2\) の場合と同じく、分数が既約（lowest terms）であると仮定し、共通因数を見つけることで矛盾を導いた。これが背理法（proof by contradiction）である。

背後にある数学

極と対数

小問 (ii) の背後には単純な描像がある。被積分関数 \(\frac{e^x}{x+1}\) は \(x = -1\) に1位の極（simple pole）をもつ。すなわち、その近くでは \(\frac{e^{-1}}{x+1}\) のように振る舞う。\(\frac{1}{x+1}\) を積分すると \(\ln|x+1|\) になるから、原始関数（antiderivative）は \(-1\) の近くで \(e^{-1}\ln|x+1|\) のように振る舞い、対数的に \(-\infty\) へ向かうはずである（図 4.6.1）。ところが、有理関数に \(e^x\) を掛けたものは \((x+1)^{-k}\) のようなべきの形でしか発散できず、その導関数は位数 \(k + 1 \geq 2\) の極をもち、1位の極になることはない。対数的な振る舞いは有理関数からは生み出せないのである。段階 4 の代数的議論は、この観察を厳密にしたものである。これに対して小問 (i) では、被積分関数は2位の極（double pole）をもつ。これはまさに1位の極をもつ関数の導関数の姿であり、そのため有理的な答えが可能だったのである。

リウヴィルとリッシュのアルゴリズム

1830年代、ジョゼフ・リウヴィル（Joseph Liouville）は、どのような積分が初等関数（elementary functions。多項式、指数関数、対数関数、累乗根、三角関数から通常の演算によって組み立てられる関数）で表せるかについての理論を築いた。その成果の一つによれば、\(\mathrm{f}\) と \(\mathrm{g}\) が有理関数で \(\mathrm{g}\) が定数でないとき、\(\int \mathrm{f}(x)e^{\mathrm{g}(x)}\,\mathrm{d}x\) が初等関数となるのは、ある有理関数 \(\mathrm{R}\) によって \(\mathrm{R}(x)e^{\mathrm{g}(x)}\)（に定数を加えたもの）に等しい場合に限る。（\(\mathrm{g}\) に関する条件は重要である。\(\mathrm{g} = 0\)、\(\mathrm{f}(x) = \frac1x\) のとき積分は \(\ln|x|\) であり、これは初等関数ではあるが有理関数ではない。）したがって、有理的な形を否定したこの問題は、実は \(\int \frac{e^x}{x+1}\,\mathrm{d}x\) がそもそも初等関数ではないことを証明しているのである。同じ定理の変形版により、\(\int e^{-x^2}\,\mathrm{d}x\) や \(\int \frac{\sin x}{x}\,\mathrm{d}x\) も初等関数でないことが示される。1969年、Robert Risch はリウヴィルの考えをアルゴリズムに仕立て上げた。これは広いクラスの関数について、初等的な積分が存在するかどうかを判定し、存在すればそれを求めるものである。その変形版は数式処理システム（computer algebra systems）の内部で動いている。

特殊関数

積分が初等的な形をもたないとき、数学者はそれに名前をつけ、新しい関数として研究する。第 3.9 節 でランベルト（Lambert）の W 関数を扱ったのと同じである。ここでの積分は本質的に指数積分（exponential integral）\(\mathrm{Ei}(x)\) である。これは熱伝導に現れるほか、対数積分（logarithmic integral）\(\mathrm{li}(x) = \mathrm{Ei}(\ln x)\) にも現れる。対数積分は、\(x\) 以下の素数の個数に対する最良の簡単な近似式である（第 1.2 節）。\(x < 0\) のときは \(\int_{-\infty}^x \frac{e^t}{t}\,\mathrm{d}t\) である。\(x > 0\) のときは、この積分は \(t = 0\) の無限に高い尖りを通過してしまうので、尖りのまわりの小さな区間 \((-\varepsilon, \varepsilon)\) を取り除いて \(\varepsilon \to 0\) とすることで \(\mathrm{Ei}(x)\) を定義する。これがコーシー（Cauchy）の主値（Cauchy principal value）である。

思考のスキル

不可能性を証明する

何かができないことを示すには、それができると仮定し、その仮定を正確な代数の言葉に翻訳し、矛盾を導く。

難しいのは翻訳の部分、すなわち「できる」とは正確には何を意味するのかを言い表すことである。ここでは、それは「共通因数をもたない多項式 \(\mathrm{P}\)、\(\mathrm{Q}\) でこの恒等式を満たすものが存在する」ことを意味した。数学における最も深い結果の多くは、この種の不可能性の証明である。

次の一歩

  1. うまくいく二つの例。\(\displaystyle\int \frac{x e^x}{(x+1)^2}\,\mathrm{d}x = \frac{e^x}{x+1} + C\) および \(\displaystyle\int \frac{(x^2 + 1)e^x}{(x+1)^2}\,\mathrm{d}x = \frac{x - 1}{x + 1}\,e^x + C\) を示せ。

  2. ガウス型関数。\(\displaystyle\int e^{-x^2}\,\mathrm{d}x = \mathrm{P}(x)e^{-x^2} + C\) となる多項式 \(\mathrm{P}\) は存在しないことを示せ。（ヒント：微分して次数を比較せよ。）

  3. もう一つの極。小問 (ii) の議論を応用して、\(\displaystyle\int \frac{e^x}{x}\,\mathrm{d}x\) は \(\frac{\mathrm{P}(x)}{\mathrm{Q}(x)}e^x + C\) の形ではないことを示せ。

  4. どのようなときに可能か。\(\mathrm{f}\) を多項式とし、ある多項式 \(\mathrm{P}\) について \(\displaystyle\int \frac{\mathrm{f}(x)}{(x+1)^2}\,e^x\,\mathrm{d}x = \frac{\mathrm{P}(x)}{x+1}\,e^x + C\) が成り立つとする。\((x+1)\mathrm{P}' + x\mathrm{P} = \mathrm{f}\) を示し、この式とその導関数の \(x = -1\) における値を考えることで、\(\mathrm{f}(-1) + \mathrm{f}'(-1) = 0\) を示せ。この条件が \(\mathrm{f}(x) = x^3 - 2\) および練習問題 1 の例について成り立つことを確かめよ。 発展 この条件が十分条件でもあることを示せるか。

さらに学ぶために

  • Brian Conrad, “Impossibility theorems for elementary integration”（初等積分の不可能性定理）。リウヴィルの定理を例とともに解説した講義ノートで、無料で入手できる。

  • Elena Anne Marchisotto & Gholam-Ali Zakeri, “An invitation to integration in finite terms”（有限の形での積分への招待）、The College Mathematics Journal 25 (1994)。リウヴィルの理論へのやさしい入門。

  • Manuel Bronstein, Symbolic Integration I（Springer）（記号積分 I）。数式処理システムが実際にどのように積分を行うかを解説している。上級者向け。
