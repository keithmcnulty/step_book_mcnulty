4.2

積分から三角関数を構成する

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第4章章全体のPDF
問題

STEP III 2017、第6問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/17-s3-q6

導入

\(\pi\) とは何だろうか。学校では、円周の長さと直径の比が \(\pi\) であり、\(\sin\) と \(\cos\) は三角形によって定義される。幾何学としてはそれで十分であるが、厄介な疑問が残る。曲線に沿った「長さ」とは正確には何なのか。なぜ \(\sin x\) はあのようなマクローリン級数（Maclaurin series）をもつのか。加法定理（addition formula）が、図に描ける角だけでなくすべての角で成り立つことを、どうやって知るのか。

この問題は、まったく異なる入り口を示してくれる。三角形も円も忘れてしまおう。出発点はただ一つの積分 \(\mathrm{T}(x) = \int_0^x \frac{\mathrm{d}u}{1+u^2}\) であり、これに必要なのは 第 4.1 節 で扱った積分の定義だけである。\(\pi\) を \(2\mathrm{T}_\infty\) と定義する。そして置換（substitution）だけを用いて、\(\mathrm{T}(\sqrt3) = \frac{\pi}{3}\) と \(\mathrm{T}(\sqrt2 - 1) = \frac{\pi}{8}\) を証明する。これらは、\(\arctan\sqrt3 = 60^\circ\) および \(\tan 22\tfrac12^\circ = \sqrt2 - 1\) として知られている事実である。三角法を無から作り直すのである。

取りかかる前に

実は \(\mathrm{T}(x) = \arctan x\) であり、\(\mathrm{T}_\infty = \frac\pi2\) であることを、読者はひそかに知っている。問題はこの知識を使うことを禁じており、そこにこそ意味がある。すべてを積分から導かなければならないのである。とはいえ、ひそかな知識は有用な道しるべになる。

小問 (i) と (ii) は、それぞれどの三角関数の恒等式（identity）に対応しているだろうか。（\(\arctan x + \arctan\frac1x\) と、\(\tan(A + B)\) の公式を考えてみよ。）

小問 (i) は \(\arctan x + \arctan\frac1x = \frac\pi2\) である。小問 (ii) は加法定理 \(\tan(A + B) = \frac{\tan A + \tan B}{1 - \tan A\tan B}\) が姿を変えたものである。すなわち、\(u = \tan A\)、\(a = \tan B\) とおけば \(v = \tan(A + B)\) となる。この問題では、これらの恒等式を幾何学を一切使わずに積分から証明する。

順を追って解く

段階 1 反転 \(u \mapsto 1/u\)

\(\mathrm{T}(x)\) において \(u = 1/w\) と置換する。すると \(\mathrm{d}u = -\mathrm{d}w/w^2\) であり、\(\dfrac{1}{1 + u^2} = \dfrac{w^2}{w^2 + 1}\) であるから、 \[\mathrm{T}(x) = \int_{\infty}^{1/x} \frac{w^2}{w^2 + 1}\cdot\left(-\frac{1}{w^2}\right)\mathrm{d}w = \int_{1/x}^{\infty} \frac{\mathrm{d}w}{1 + w^2} = \mathrm{T}_\infty - \mathrm{T}(x^{-1}). \qed\] 言い換えれば、\(\frac{1}{1+u^2}\) のグラフの下の \(0\) から \(x\) までの面積は、\(\frac1x\) から \(\infty\) までの面積に等しい（図 4.2.1）。

段階 2 加法の置換

\(v = \dfrac{u + a}{1 - au}\) を商の微分法（quotient rule）で微分せよ。次に \(1 + v^2\) を一つの分数として計算し、両者を比べよ。

\[\begin{aligned} \frac{\mathrm{d}v}{\mathrm{d}u} &= \frac{(1 - au) + a(u + a)}{(1 - au)^2} = \frac{1 + a^2}{(1 - au)^2}, \\ 1 + v^2 &= \frac{(1 - au)^2 + (u + a)^2}{(1 - au)^2} = \frac{(1 + a^2)(1 + u^2)}{(1 - au)^2}. \end{aligned}\] 割り算をすると、\(\dfrac{1 + v^2}{1 + u^2} = \dfrac{1 + a^2}{(1 - au)^2} = \dfrac{\mathrm{d}v}{\mathrm{d}u}\) である。■

これは \(\dfrac{\mathrm{d}u}{1 + u^2} = \dfrac{\mathrm{d}v}{1 + v^2}\) ということである。つまり、置換 \(u \mapsto v\) は被積分関数（integrand）をまったく変えない。では、\(\mathrm{T}(x)\) の積分区間の端はどうなるだろうか。

\(u\) が \(0\) から \(x\) まで動くとき（\(x < \frac1a\) とする。このとき区間全体で \(1 - au > 0\) であり、\(v\) は連続かつ増加する）、\(v\) は \(a\) から \(\frac{x + a}{1 - ax}\) まで動く。したがって \[\mathrm{T}(x) = \int_0^x \frac{\mathrm{d}u}{1 + u^2} = \int_a^{(x+a)/(1-ax)} \frac{\mathrm{d}v}{1 + v^2} = \mathrm{T}\!\left(\frac{x + a}{1 - ax}\right) - \mathrm{T}(a). \qed\]

段階 3 さらに二つの恒等式

小問 (i) と二回組み合わせると、 \[\mathrm{T}(x^{-1}) = \mathrm{T}_\infty - \mathrm{T}(x) = \mathrm{T}_\infty - \mathrm{T}\!\left(\frac{x + a}{1 - ax}\right) + \mathrm{T}(a) = 2\mathrm{T}_\infty - \mathrm{T}\!\left(\frac{x + a}{1 - ax}\right) - \mathrm{T}(a^{-1}). \qed\] ここで文字を置き換える。\(y = 1/x\)、\(b = 1/a\) とおく。条件 \(x < 1/a\) は \(1/y < b\)、すなわち \(y > 1/b\) となり、 \[\frac{x + a}{1 - ax} = \frac{1/y + 1/b}{1 - 1/(by)} = \frac{b + y}{by - 1}.\] よって \(\mathrm{T}(y) = 2\mathrm{T}_\infty - \mathrm{T}\!\left(\dfrac{y + b}{by - 1}\right) - \mathrm{T}(b)\) である。■

段階 4 特殊値

最後の恒等式において、引数 \(\frac{y + b}{by - 1}\) が \(y\) 自身に等しくなるように \(y\) と \(b\) を選べ。何が得られるだろうか。

\(y = b = \sqrt3\) とする。このとき \(y > \frac1b\) であり、\(\dfrac{\sqrt3 + \sqrt3}{3 - 1} = \sqrt3\) である。恒等式は \(\mathrm{T}(\sqrt3) = 2\mathrm{T}_\infty - 2\mathrm{T}(\sqrt3)\) となるので、 \[\mathrm{T}(\sqrt3) = \tfrac23\mathrm{T}_\infty. \qed\]

\(\sqrt2 - 1\) については、加法の恒等式で \(x = a = \sqrt2 - 1\) としてみよ。\(\frac{2x}{1 - x^2}\) はいくつになるか。また、\(\mathrm{T}(1)\) はいくつか。

\(x = a = \sqrt2 - 1\) とすると（\(x^2 = 3 - 2\sqrt2 < 1\) であるから \(x < \frac1a\) が成り立つ）、加法の恒等式により \(2\mathrm{T}(x) = \mathrm{T}\!\left(\frac{2x}{1 - x^2}\right)\) となる。ここで \(1 - x^2 = 2\sqrt2 - 2 = 2(\sqrt2 - 1) = 2x\) であるから \(\frac{2x}{1 - x^2} = 1\) であり、\(2\mathrm{T}(\sqrt2 - 1) = \mathrm{T}(1)\) を得る。最後に、小問 (i) で \(x = 1\) とすると \(\mathrm{T}(1) = \mathrm{T}_\infty - \mathrm{T}(1)\) となるから、\(\mathrm{T}(1) = \frac12\mathrm{T}_\infty\) である。したがって \[\mathrm{T}(\sqrt2 - 1) = \tfrac14\mathrm{T}_\infty. \qed\]

振り返り

  • 被積分関数を保つ置換。鍵となる二つのステップでは、どちらも \(\frac{\mathrm{d}u}{1+u^2}\) を変えない置換を用いた。動いたのは積分区間の端だけである。積分のこのような「対称性」は強力な道具である。

  • 不動点。\(\mathrm{T}(\sqrt3)\) の値は、ある式がそれ自身に等しくなるような数を選ぶことで得られた。こうして恒等式が方程式に変わったのである。

  • 定義は解析学から得られる。三角形は一度も使わなかったが、それでも \(\frac\pi3\) と \(\frac\pi8\) を導き出せた（\(\pi\) は \(2\mathrm{T}_\infty\) として定義した）。

背後にある数学

初等関数を構成する

厳密な解析学の講義では、関数 \(\exp\)、\(\sin\)、\(\cos\)、\(\ln\) の存在を単に仮定することはできない。それらは構成されなければならず、その性質も証明されなければならない。標準的な方法は三つある。冪級数（power series）によって定義する方法（\(\sin x = x - \frac{x^3}{3!} + \cdots\)）。演習問題にある1986年の見本問題のように、微分方程式（differential equation）の解として定義する方法（\(\mathrm{f}' = \mathrm{f}\)、\(\mathrm{f}(0) = 1\) によって \(\exp\) が定まる）。あるいは、ここで行ったように、逆関数（inverse function）を積分で定義する方法である。すなわち \(\ln x = \int_1^x \frac{\mathrm{d}u}{u}\)、\(\arctan x = \int_0^x \frac{\mathrm{d}u}{1+u^2}\) とし、そのうえで \(\pi = 2\int_0^\infty \frac{\mathrm{d}u}{1+u^2}\) と定義する。どの方法にもそれぞれの長所があり、これらがすべて同じ関数を与えることを証明するのは、やりがいのある演習である。第 3.8 節 の関数方程式（functional equation）による方法と比べてみよ。

円を越えて：楕円積分

積分による方法は、三角形による方法では不可能な形で一般化できる。1718年、ジュリオ・ファニャーノ（Giulio Fagnano）は8の字形の曲線であるレムニスケート（lemniscate）の弧長（arc length）を研究した。これは \(\int_0^x \frac{\mathrm{d}u}{\sqrt{1 - u^4}}\) に帰着する。ファニャーノは、ちょうど我々の置換が \(\mathrm{T}\) を2倍にしたように、弧を2倍にする置換を発見した。1751年にファニャーノの研究を読んだオイラー（Euler）は完全な加法定理を見いだし、これがやがてアーベル（Abel）とヤコビ（Jacobi）を経て、楕円関数（elliptic function）の理論へとつながった。楕円関数とはこのような積分の逆関数であり、\(\sin\) と \(\cos\) が円に対してもつ役割を、レムニスケートに対して果たすものである。同じ積分には、ガウス（Gauss）の算術幾何平均（AGM）に関する研究（第 2.6 節）でも出会った。楕円関数は今日、数論（number theory）の中心にある。第 1.9 節 の楕円曲線（elliptic curve）は、その幾何学的な影である。

\(\pi\) を計算する

加法の恒等式は、\(\pi\) を計算するための最も有名な公式群の基礎でもある。これを繰り返し適用すると、たとえば \(\mathrm{T}(1) = 4\mathrm{T}(\frac15) - \mathrm{T}(\frac{1}{239})\) が示される。これが1706年のマチン（Machin）の公式である。級数 \(\mathrm{T}(x) = x - \frac{x^3}{3} + \frac{x^5}{5} - \cdots\) と組み合わせることで、この公式は \(\pi\) の \(100\) 桁を与え、その後2世紀半にわたって最良の方法であり続けた。これが 第 5.1 節 の主題である。

思考のスキル

積分の対称性

被積分関数を変えない置換を探せ。それらは、その積分が定める関数についての恒等式に変わる。

ここでは \(u \mapsto 1/u\) と \(u \mapsto \frac{u+a}{1-au}\) が \(\frac{\mathrm{d}u}{1+u^2}\) を保ち、それぞれ反転の公式と加法定理を与える。同じ考え方をほかの積分に適用したものが、特殊関数（special functions）の理論の根底にある。

次の一歩

  1. 指数関数と余弦関数。STEP II Specimen paper、第6問 に挑戦せよ。この問題は、指数関数と余弦関数の加法定理を、それらの微分方程式だけから導く。（ヒント：余弦関数については、0 になるはずの二つの組合せを見つけ、それらの平方の和が一定であることを示せ。）

  2. 逆正弦関数。STEP III 2007、第7問 に挑戦せよ。この問題は、逆正弦関数（inverse sine）をこの節の積分と同じように扱い、置換によって両者を結びつける。

  3. 初期のマチン型公式。加法の恒等式を用いて、\(\mathrm{T}(\frac12) + \mathrm{T}(\frac13) = \mathrm{T}(1) = \frac12\mathrm{T}_\infty\) を示せ。

  4. \(\mathrm{T}_\infty\) は有限である。すべての \(x \geq 1\) に対して \(\mathrm{T}(x) \leq 1 + \int_1^x \frac{\mathrm{d}u}{u^2} < 2\) であることを示し、\(0 < x < 1\) に対しても \(\mathrm{T}(x) < 2\) となる理由を説明せよ。さらに、単調収束定理（monotone convergence theorem）（第 2.2 節）から \(\mathrm{T}_\infty\) が存在することを導け。

さらに学ぶために

  • Tom Körner, Calculus for the Ambitious（Cambridge University Press）。初等関数を厳密に構成し、さまざまな方法について論じている。

  • Walter Rudin, Principles of Mathematical Analysis（McGraw-Hill）。邦訳『現代解析学』。有名な「baby Rudin」である。第8章の序論では、冪級数から \(\exp\)、\(\sin\)、\(\cos\) をわずか数ページで見事に構成している。上級向け。

  • Victor Prasolov & Yuri Solovyev, Elliptic Functions and Elliptic Integrals（American Mathematical Society）。レムニスケートがどこへつながっていくのかを知りたい人に。上級向け。
