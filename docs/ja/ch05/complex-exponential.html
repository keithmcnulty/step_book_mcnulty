写像としての複素指数関数

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第5章章全体のPDF
問題

STEP II 1997、第5問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/97-s2-q5

導入

指数関数（exponential function）は、曲線 \(y = e^x\) としてよく知っているであろう。しかし、複素変数の関数は曲線として描くことができない。入力は平面上の点であり、出力もまた平面上の点だからである。これを思い描くには、写像（map）として捉えればよい。すなわち、一方の平面のすべての点を他方の平面の点へと移し、その過程で引き伸ばしたり曲げたりする変換である。

問題の式は \(z = e^{u}(\cos v + \mathrm{i}\sin v) = e^{u + \mathrm{i}v} = e^w\) である。写像として見ると、複素指数関数は驚くべきことをする。平面の水平な帯状領域を巻き上げて平面全体（原点を除く）にし、鉛直な直線を円に巻きつけ、水平な直線を半直線として広げるのである。さらに、巻きつくために一対一（one-to-one）ではない。各点に無限個の点が移るのである。これこそが、複素対数関数が「多価」（multi-valued）である理由であり、複素解析（complex analysis）で最初に出会う驚きの一つである。

取りかかる前に

\(z = e^u(\cos v + \mathrm{i}\sin v)\) の絶対値（modulus）と偏角（argument）を \(u\) と \(v\) で表すとどうなるか。

\(|z| = e^u\) であり、\(\arg z = v\)（\(2\pi\) の整数倍の差を除いて）である。したがって、\(w\) の実部 \(u\) は原点からの距離を指数的に定め、虚部 \(v\) は方向を定める。この一つの観察で、問題のほぼすべての部分に答えられる。

順を追って解く

段階 1 \(e^w = \mathrm{i}e\) を解く

\(\mathrm{i}e\) の絶対値と偏角は何か。

\(|\mathrm{i}e| = e\) かつ \(\arg(\mathrm{i}e) = \frac\pi2\) である。よって \(e^u = e\) すなわち \(u = 1\) であり、任意の整数 \(k\) に対して \(v = \frac\pi2 + 2k\pi\) であればよい。解は \[w = 1 + \mathrm{i}\left(\tfrac\pi2 + 2k\pi\right), \qquad k \in \mathbb{Z}.\] である。解は無限個あり、縦方向に \(2\pi\) ずつ間隔をあけて並んでいる。

段階 2 格子線の像

鉛直な直線 \(u = c\) の上では、\(v\) が変化しても \(|z| = e^c\) は一定である。したがって像は原点を中心とする半径 \(e^c\) の円であり、\(v\) がすべての実数を動くとき、この円を無限回なぞる。

水平な直線 \(v = d\) の上では、\(\arg z = d\) は一定で、\(|z| = e^u\) はすべての正の値をとる。したがって像は、原点から角 \(d\) の方向に伸びる開いた半直線（ray）であり、原点そのものは含まない。直線 \(v = d\) と \(v = d + 2\pi\) は同じ半直線を与える。

段階 3 一対一となる部分

第1象限 \(x > 0\), \(y > 0\) に移る点 \(w\) はどれか。その集合が大きすぎて、第1象限と一対一に対応しないのはなぜか。

\(z\) が開いた第1象限にあるのは、絶対値は任意で、\(\arg z\) が（\(2\pi\) を法として）\(0\) と \(\frac\pi2\) の間に厳密にあるとき、かつそのときに限る。したがって \(w\) は \(0 < v < \frac\pi2\) または \(2\pi < v < \frac{5\pi}{2}\) または …を満たさなければならない。これは無限個の水平な帯状領域であり、それぞれが第1象限全体の上に移る。一つの帯状領域の内部では \(u\) と \(v\) は \(|z|\) と \(\arg z\) によって一意に定まるので、どの帯状領域も第1象限と一対一に対応する。よって次のようにとればよい。 \[W_1 = \{u + \mathrm{i}v : 0 < v < \tfrac\pi2\}, \qquad W_2 = \{u + \mathrm{i}v : 2\pi < v < \tfrac{5\pi}{2}\}.\]

次に、穴あき円板 \(0 < |z| < 1\) と一対一に対応する \(w\) 平面の集合を二つ求めよ。

\(|z| < 1\) は \(e^u < 1\)、すなわち \(u < 0\) を意味する。また、すべての偏角がちょうど一度ずつ覆われなければならないので、\(v\) は長さがちょうど \(2\pi\) で、一方の端点を含み他方を含まない区間を動けばよい。たとえば \[W_3 = \{u + \mathrm{i}v : u < 0,\ 0 \leq v < 2\pi\}, \qquad W_4 = \{u + \mathrm{i}v : u < 0,\ -\pi < v \leq \pi\}.\] である。これらは一方の辺を含み他方の辺を含まない半帯状領域である。（両方の辺を含めると正の実軸上の点に二度到達し、どちらも含めなければそれらの点に到達しない。）■

振り返り

  • 絶対値と偏角が変数を分離する。 \(|e^w| = e^{\mathrm{Re}\,w}\) かつ \(\arg e^w = \mathrm{Im}\,w\) であるから、\(w\) の実部と虚部はそれぞれ独立に距離と方向を定める。

  • 複素関数を写像として思い描く。 格子線の行き先を追うことで、グラフとして描けない関数の姿がはっきりと見えてくる。

  • 周期性は単射性を壊す。 \(e^{w + 2\pi\mathrm{i}} = e^w\) であるから、この写像は多対一であり、逆関数をもつためには高さ \(2\pi\) の帯状領域に制限しなければならない。

背後にある数学

複素対数関数

実数直線上では、\(\ln\) は \(\exp\) の逆関数である。複素平面では、各 \(z \neq 0\) に対して \(e^w = z\) は \(2\pi\mathrm{i}\) の整数倍ずつ異なる無限個の解 \(w\) をもつので、「\(\log z\)」は一つの数ではない。本当の関数を得るには分枝（branch）を選ばなければならない。これは \(W_3\) や \(W_4\) のような帯状領域を選ぶことである。主枝（principal branch）は \(-\pi < \arg z \leq \pi\) をとるものである。どの分枝にも、原点から伸びる半直線に沿ってどこかに不連続な跳びがあり、これを分枝切断（branch cut）という。リーマン（Bernhard Riemann）は1851年の学位論文において、対数関数が平面上に住むと考えるのをやめることでこの問題を解決した。対数関数は無限に続くらせん階段、すなわちリーマン面（Riemann surface）の上に住み、その上では一価かつ滑らかなのである。リーマン面は今日、幾何学、整数論、弦理論の中心をなしている。

角は保たれる

図 5.7.1 をもう一度見てみよう。鉛直と水平の格子線は直角に交わり、それらが移った先の円と半直線も直角に交わっている。これは偶然ではない。複素関数は、導関数が \(0\) でないところではどこでも、曲線どうしのなす角を保つのである。このような写像を等角写像（conformal map）という。局所的には、等角写像は回転と拡大縮小にすぎず、それはまさに複素数 \(f'(z)\) を掛けることが行う操作である。等角写像は、複雑な領域を答えのわかっている単純な領域に変換することで、流体の流れ、静電気学、熱伝導の問題を解くのに用いられる。

メルカトルの地図

ここで、この節と 第 4.8 節 を結ぶ意外な事実を紹介しよう。1569年のメルカトル（Gerardus Mercator）の地図は、一定の方位角で進む航路が直線になるように作られており、そのためには角を保つ必要がある。まず地球を（北極から）立体射影（stereographic projection）で平面に写し、次に複素対数をとると、その結果はちょうどメルカトル図法になる。\(\log\) によって半直線と円がそれぞれ水平と鉛直の直線になるのと同じように、経線は鉛直な直線に、緯線は水平な直線になるのである。この節の指数写像を逆向きにたどったものが、航海士の海図の数学なのである。

思考のスキル

関数を変換として視覚化する

関数をグラフとして描けないときは、その関数が何をするかを描け。単純な曲線の格子を追い、それらがどこへ行くかを見よ。

複素関数では、水平な直線と鉛直な直線、あるいは円と半直線の像を調べれば、たいていすべてがわかる。写像が図形に何をするかというこの考え方は、幾何学と解析学の全体を貫いている。

次の一歩

  1. 方程式を解く。 \(e^w = -1\) を満たす複素数 \(w\) をすべて求めよ。また、\(e^w = 1 + \mathrm{i}\) を満たす \(w\) をすべて求めよ。

  2. 正方形の像。 頂点が \(0\), \(1\), \(1 + \mathrm{i}\), \(\mathrm{i}\) である正方形の \(z = e^w\) による像を求め、図示せよ。

  3. 直角。 円 \(|z| = e^c\) と半直線 \(\arg z = d\) が直角に交わることを直接示し、これが直線 \(u = c\) と \(v = d\) が垂直であることと整合する理由を説明せよ。

  4. 2乗。 \(c\) と \(d\) を \(0\) でない実数とする。写像 \(z \mapsto z^2\) による直線 \(x = c\) と \(y = d\) の像を求めよ。それらが放物線であり、交わる点ではどこでも直角に交わることを示せ。（\(c = 0\) または \(d = 0\) のときはどうなるか。）

さらに学ぶために

  • Tristan Needham, Visual Complex Analysis (Oxford University Press)。第 2 章と第 4 章で、指数関数、対数関数、等角写像を見事な図とともに扱っている。

  • Hilary Priestley, Introduction to Complex Analysis (Oxford University Press)。大学初年級向けのわかりやすい教科書である。

  • Ian Stewart & David Tall, Complex Analysis (Cambridge University Press)。幾何学に重点を置いた、もう一つの優れた大学向け入門書である。
