フェルマー点

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第5章章全体のPDF
問題

STEP III 2000、第3問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/00-s3-q3

導入

3つの村を結ぶ道路網を、できるだけ短く作りたい。分岐点はどこに置けばよいだろうか。1640年ごろ、フェルマー（Pierre de Fermat）は、三角形の内部の点 \(P\) で \(PA + PB + PC\) を最小にするものを求める問題を提起し、トリチェリ（Evangelista Torricelli）がこれを解いた。答えは、3つの辺がいずれも \(120^\circ\) の角をなして見える点である。

この問題では、複素数（complex number）を用いて、その点を求める美しい作図法を証明する。三角形の各辺の外側に正三角形（equilateral triangle）を作り、新しくできた各頂点を、もとの三角形の向かい合う頂点と結ぶ。すると3本の直線は1点で交わる。これがフェルマー点（Fermat point）である。しかも3本の線分の長さはすべて等しく、その長さが道路の総延長の最小値になっている。複素数と、\(e^{\mathrm{i}\pi/3}\) に関するひとつの恒等式を使えば、全体はわずか数行の計算で済む。

取りかかる前に

\(A\)、\(B\)、\(C\) はどこにあるか。それぞれの偏角はいくらか。\(OA\)、\(OB\)、\(OC\) は互いにどのような角をなすか。

\(A = p\) は実軸の正の部分にある（偏角（argument）は \(0^\circ\)）。\(B = q\alpha^2 = qe^{2\pi\mathrm{i}/3}\) の偏角は \(120^\circ\) である。\(C = -r\alpha = re^{\mathrm{i}\pi}e^{\mathrm{i}\pi/3}\) の偏角は \(240^\circ\) である。したがって原点は三角形の内部の点であり、そこから3つの頂点は互いに \(120^\circ\) の角をなす方向に、それぞれ距離 \(p\)、\(q\)、\(r\) のところに見える。つまり、作り方からして原点こそがフェルマー点なのである。この問題は、正三角形を用いた作図によってこの点が求まることを示すものである。

順を追って解く

段階 1 鍵となる恒等式

\(\alpha^3 = e^{\mathrm{i}\pi} = -1\) であるから、\(\alpha\) は \(z^3 + 1 = (z + 1)(z^2 - z + 1)\) の根である。\(\alpha \neq -1\) より \(\alpha^2 - \alpha + 1 = 0\)、すなわち \(1 + \alpha^2 = \alpha\) である。■

ここから導かれる2つの式が役に立つ。\(1 - \alpha = -\alpha^2\) と \(\alpha - \alpha^2 = 1\) である。また \(1 - \alpha = \frac12 - \frac{\sqrt3}{2}\mathrm{i} = e^{-\mathrm{i}\pi/3}\) であり、これは \(\alpha\) の共役複素数（complex conjugate）である。

段階 2 回転としての正三角形

三角形 \(CAN\) は正三角形で、頂点は時計回りに名前がつけられている。\(C\) に立ったとき、\(A\) からどうすれば \(N\) に移れるか。\(N - C\) を \(A - C\) を用いて表せ。

\(C\)、\(A\)、\(N\) の順に時計回りに進むので、点 \(N\) は \(A\) を \(C\) のまわりに時計回りに \(60^\circ\) 回転（rotation）させて得られる。\(e^{-\mathrm{i}\pi/3} = 1 - \alpha\) を掛けることは時計回りに \(60^\circ\) 回転させることであるから、 \[\begin{aligned} N = C + (1 - \alpha)(A - C) &= -r\alpha + (1 - \alpha)(p + r\alpha) \\ &= (1 - \alpha)p + r(\alpha - \alpha^2 - \alpha) = (1 - \alpha)p - \alpha^2r. \qed \end{aligned}\] （反時計回りではなく時計回りに回転させることで、\(N\) は \(CA\) に関して原点と反対側、すなわち三角形の外側に置かれる。）

同じ方法で \(L\) と \(M\) を求め、小問1の恒等式を用いて簡単にせよ。

同様に \(L = A + (1 - \alpha)(B - A)\)、\(M = B + (1 - \alpha)(C - B)\) であるから、 \[\begin{aligned} L &= p + (1 - \alpha)(q\alpha^2 - p) = \alpha p + (\alpha^2 - \alpha^3)q = \alpha p + (\alpha^2 + 1)q = \alpha(p + q), \\ M &= q\alpha^2 + (1 - \alpha)(-r\alpha - q\alpha^2) = q\alpha^3 + r(\alpha^2 - \alpha) = -q - r. \end{aligned}\] さらに \(1 - \alpha = -\alpha^2\) を用いると、\(N = -\alpha^2p - \alpha^2r = -\alpha^2(p + r)\) である。

段階 3 原点を通る3本の直線

\(L = \alpha(p + q)\) と \(C = -r\alpha\) を比べよ。何に気づくか。\(M\) と \(A\)、\(N\) と \(B\) についても同じことをせよ。

\(L\) は \(\alpha\) の正の実数倍であり、\(C\) は \(\alpha\) の負の実数倍である。したがって \(L\) と \(C\) は \(O\) を通る同一直線上で \(O\) をはさんで反対側にあり、線分 \(LC\) は原点を通る。その長さは \(|L - C| = |\alpha|(p + q + r) = p + q + r\) である。

同様に、\(M = -(q + r)\) と \(A = p\) は実軸上で \(O\) をはさんで反対側にあるので、\(MA\) は \(O\) を通り、長さは \(p + q + r\) である。また \(N = -\alpha^2(p + r)\) と \(B = q\alpha^2\) は、\(O\) を通り \(\alpha^2\) の方向に伸びる直線上で互いに反対側にあるので、\(NB\) は \(O\) を通り、長さは \(p + q + r\) である。■

振り返り

  • 回転は掛け算である。正三角形を作ることは、ある頂点を別の頂点のまわりに \(60^\circ\) 回転させることであり、それは \(e^{\pm\mathrm{i}\pi/3}\) を掛けることにほかならない。

  • 座標の巧みな選び方。フェルマー点を原点に置き、頂点を \(1\)、\(\alpha^2\)、\(-\alpha\) の方向に並べたことで、すべての式が劇的に簡単になった。

  • ひとつの恒等式を繰り返し使う。式の簡略化はすべて \(\alpha^2 - \alpha + 1 = 0\) と \(\alpha^3 = -1\) から得られた。

背後にある数学

フェルマー点で距離の和が最小になる理由

なぜ \(PA + PB + PC\) は、各辺が \(120^\circ\) の角をなして見える点で最小になるのだろうか。ここに見事な論法がある。図全体を \(B\) のまわりに \(60^\circ\) 回転させ、\(A\) を \(L'\)（\(AB\) 上に作った正三角形の頂点）に、\(P\) を \(P'\) に移す。三角形 \(BPP'\) は正三角形であるから \(PB = PP'\) であり、また \(PA = P'L'\) である。よって \(PA + PB + PC = L'P' + P'P + PC\) となり、これは \(L'\) から \(C\) へ至る折れ線の長さである。これは \(|L'C|\) 以上であり、等号が成り立つのは折れ線がまっすぐなとき、すなわち \(P\) における角がすべて \(120^\circ\) のときに限る。したがって総延長の最小値は、問題で求めたとおり \(|LC| = p + q + r\) である。（これは三角形のどの角も \(120^\circ\) より小さい場合に成り立つ。そうでない場合、最小となるのは鈍角（obtuse angle）の頂点である。）

石けん膜とシュタイナー木

3本の杭（\(A\)、\(B\)、\(C\) を表す）をつけた枠を石けん水に浸すと、石けん膜は表面張力（surface tension）によるエネルギーを最小にしようとして、フェルマー点で \(120^\circ\) の角をなして交わる3枚の膜を作る。点の数がもっと多い場合、それらを結ぶ最短のネットワークはシュタイナー木（Steiner tree）であり、3本の辺が \(120^\circ\) で交わる分岐点が新たに加わる。シュタイナー木を求めることは一般には計算量的に難しい（NP困難（NP-hard）な問題である）が、道路網やパイプライン、コンピュータチップの配線の設計など、実用上重要である。

ナポレオンの定理

同じ配置には、もうひとつの宝石が隠れている。任意の三角形の各辺の上に作った3つの正三角形の中心は、正三角形をなすのである。これは伝統的にナポレオン・ボナパルト（Napoleon Bonaparte、熱心なアマチュア数学者であった）の功績とされ、ナポレオンの定理（Napoleon’s theorem）と呼ばれるが、彼が発見したという証拠はない。この定理も、\(1 + \alpha^2 = \alpha\) を用いれば複素数で短く証明できる。

思考のスキル

問題に合った座標を選ぶ

最も重要な点を原点に置き、問題の対称性に合わせて配置せよ。うまく選べば、計算はほとんど自明になる。

ここでは原点をフェルマー点とし、3つの頂点は（符号を除いて）\(-1\) の3乗根の方向に並んでいた。ほかの座標を使えば、同じ計算がはるかに煩雑になったであろう。

次の一歩

  1. 頂点の名前のつけ方を確かめる。正三角形の頂点を反時計回りに名づけた（内側に作った）場合、3本の直線は一般には \(O\) を通らないことを示せ。

  2. ナポレオンの定理。正三角形 \(ABL\) の中心が \(\frac13(A + B + L)\) であることを示せ。上で求めた式を用いて、3つの中心が正三角形をなすことを示せ。

  3. 最小値。\(p = 2\)、\(q = 1.4\)、\(r = 1.1\) のとき、\(P\) を各頂点および重心（centroid）\(\frac13(A + B + C)\) に置いて \(PA + PB + PC\) を計算し、いずれも \(4.5\) より大きいことを確かめよ。

  4. 正三角形の判定。\(z_1\)、\(z_2\)、\(z_3\) が（どちらの向きであれ）正三角形をなすための必要十分条件は \(z_1^2 + z_2^2 + z_3^2 = z_1z_2 + z_2z_3 + z_3z_1\) であることを示せ。

さらに学ぶために

  • Richard Courant & Herbert Robbins, What Is Mathematics?（Oxford University Press）。邦題『数学とは何か』。第7章でフェルマー点、シュタイナー木、石けん膜を論じている。

  • Liang-shin Hahn, Complex Numbers and Geometry（Mathematical Association of America）。多くの幾何の定理を、まさにこの水準の複素数を用いて証明している。

  • Tristan Needham, Visual Complex Analysis（Oxford University Press）。邦題『ヴィジュアル複素解析』。第1章にナポレオンの定理をはじめとする幾何の結果が収められている。
