5.4

正多角形の中の距離

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第5章章全体のPDF
問題

STEP III 2016、第7問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/16-s3-q7

導入

半径 \(1\) の円に内接する正七角形を描く。ひとつの頂点から他の頂点へ6本の弦（chord）を引き、その長さを測る。6本の長さをすべて掛け合わせると、答えはちょうど \(7\) になる。正 \(100\) 角形では、ひとつの頂点から引いた \(99\) 本の弦の長さの積はちょうど \(100\) である。

なぜこれほどきれいな結果が成り立つのだろうか。弦の長さそのものは複雑である（\(2\sin\frac{\pi}{7}\) 、 \(2\sin\frac{2\pi}{7}\) など）。この問題は、この結果がある単純な代数的恒等式、すなわち \(z^n - 1\) の1の冪根（roots of unity）による因数分解（factorisation）の幾何学的な影であること、そして平面上の距離が複素数の絶対値（modulus）であることを示している。

取りかかる前に

多角形の頂点を \(n\) 乗して1になる複素数、すなわち \(X_k = \omega^k\) に置く。点 \(P\) が \(z\) であるとき、 \(|PX_k|\) を \(z\) で表すとどうなるか。すると、すべての距離の積はどうなるか。

\(|PX_k| = |z - \omega^k|\) であり、これらすべての積は \(|(z - 1)(z - \omega)\cdots(z - \omega^{n-1})|\) である。問題の最初の部分によれば、これは \(|z^n - 1|\) に等しい。 \(n\) 個の距離の積が、ひとつの絶対値になったのである。あとは \(z\) をうまく選ぶだけである。

順を追って解く

段階 1 因数分解

各 \(\omega^k\) は \((\omega^k)^n = (\omega^n)^k = 1\) を満たすので、 \(1, \omega, \ldots, \omega^{n-1}\) は \(z^n - 1\) の根である。これらは互いに異なる（偏角 \(\frac{2\pi k}{n}\) が \(0\) 以上 \(2\pi\) 未満の範囲で互いに異なる）ので、これらは最高次の係数が \(1\) であるこの \(n\) 次多項式（polynomial）の \(n\) 個の根のすべてであり、 \(z^n - 1 = \prod_{k=0}^{n-1}(z - \omega^k)\) が成り立つ。■

段階 2 垂直二等分線上の点

\(X_k = \omega^k\) となるように図を回転させる。 \(X_0 = 1\) と \(X_1 = \omega\) から等距離にある点全体は \(X_0X_1\) の垂直二等分線（perpendicular bisector）をなし、これは \(O\) を通り角 \(\frac\pi n\) をなす直線である。

したがって、ある実数 \(t\) （正でも負でもよい）を用いて \(P\) は \(z = te^{\mathrm{i}\pi/n}\) と表され、 \(|OP| = |t|\) である。 \(z^n\) はどうなるか。

\(z^n = t^ne^{\mathrm{i}\pi} = -t^n\) である。よって \[|PX_0| \times \cdots \times |PX_{n-1}| = |z^n - 1| = |{-t^n} - 1| = |t^n + 1|.\] \(n\) が偶数ならば \(t^n = |t|^n \geq 0\) であるから、これは \(|OP|^n + 1\) である。■

\(n\) が奇数のときはどうなるか。 \(t > 0\) の場合と \(t < 0\) の場合を分けて考え、それぞれの場合が幾何学的に何を意味するかを述べよ。

\(n\) が奇数ならば、 \(t^n\) は \(t\) と同じ符号をもつ。

  • \(t \geq 0\) 、すなわち \(P\) が \(O\) に関して \(X_0X_1\) の中点と同じ側にあるとき、積は \(|OP|^n + 1\) である。

  • \(t < 0\) 、すなわち \(P\) が \(O\) に関して反対側（辺 \(X_0X_1\) に向かい合う頂点の側）にあるとき、 \(t^n = -|OP|^n\) であり、積は \(\bigl|1 - |OP|^n\bigr|\) である。

\(n\) が奇数のとき、 \(O\) を通り \(X_0X_1\) に垂直な直線は、反対側にあるひとつの頂点を通る。2番目の場合、 \(P\) がその頂点であるとき（ \(|OP| = 1\) ）積は0になるが、これは当然である。そのとき距離のひとつが0になるからである。

段階 3 頂点から引いた弦

今度は \(P = X_0\) であり、距離のひとつ \(|X_0X_0|\) が0なので、 \(|z^n - 1| = 0\) は役に立たない。 \(\omega, \omega^2, \ldots, \omega^{n-1}\) を根にもち、 \(1\) を根にもたない多項式は何か。

\(z^n - 1\) を \(z - 1\) で割ると \[(z - \omega)(z - \omega^2)\cdots(z - \omega^{n-1}) = \frac{z^n - 1}{z - 1} = 1 + z + z^2 + \cdots + z^{n-1}.\] 右辺は多項式なので、この式はすべての \(z\) について成り立ち、 \(z = 1\) でも成り立つ。そのとき右辺は \(n\) に等しい。 \(z = 1\) で絶対値をとると \[|X_0X_1| \times |X_0X_2| \times \cdots \times |X_0X_{n-1}| = |1 - \omega|\,|1 - \omega^2|\cdots|1 - \omega^{n-1}| = n. \qed\]

振り返り

  • 距離は絶対値である。 \(|PX_k| = |z - \omega^k|\) であるから、距離の積は積の絶対値であり、その積は閉じた形で表せた。

  • 対称性を使って座標を選ぶ。 頂点が1の冪根になるように回転させ、 \(O\) を通る対称軸を使うことで、 \(z^n\) が簡単に計算できた。

  • 代入の前に0になる因数を約分する。 第 5.3 節 と同様に、注目する点で0になる因数を割り去ることで、代入が可能になった。

背後にある数学

コーツの定理

小問 (i) はロジャー・コーツ（Roger Cotes）の定理である。コーツはケンブリッジの才気あふれる若き数学者で、ニュートン（Newton）の『Principia』（プリンキピア）第2版を編集し、1716年に三十三歳で亡くなった（ニュートンは「彼が生きていたなら、我々は何事かを知りえたであろう」と述べた）。コーツは、 \(P\) が \(O\) から正 \(n\) 角形の頂点を通る半直線上にあるとき、 \(P\) から各頂点までの距離の積は \(\bigl||OP|^n - 1\bigr|\) であり、 \(P\) が辺の中点を通る半直線上にあるときは \(|OP|^n + 1\) であることを発見した。彼はこれを用いて、複素数を使わずに \(x^n \pm 1\) を実数係数の2次式の積に因数分解した。これは有理関数の積分に必要だったのである。この定理は彼の死後、1722年に出版された。

正弦の積

\(|1 - \omega^k| = |e^{-\mathrm{i}\pi k/n} - e^{\mathrm{i}\pi k/n}| = 2\sin\frac{k\pi}{n}\) であるから、小問 (ii) は \[\prod_{k=1}^{n-1}\sin\frac{k\pi}{n} = \frac{n}{2^{n-1}}\] を意味する。これは 第 5.3 節 の余弦の積と対をなすものである。関連する積から \(z^n - 1\) の判別式（discriminant）が得られる。すなわち、相異なる \(n\) 乗して1になる複素数のすべての組の間の距離の2乗の積は \(n^n\) である。判別式は多項式の根がどれだけ離れているかを測るもので、多項式の代数や数体の代数において中心的な役割を果たす。これについては第6章で取り上げる。

静電気学と等間隔配置

物理的な解釈もある。円周上に \(n\) 個の等しい電荷を置く。ポテンシャルエネルギー（2次元静電気学の対数ポテンシャルによる）を最小にする配置は正多角形であり、そのエネルギーにはまさに \(\sum\ln|X_jX_k|\) 、すなわち距離の積の対数が現れる。「できるだけ散らばった」点は、数値解析（第 3.6 節 。そこでは最良の補間点が正多角形から \(x = \cos\theta\) によって得られる）やランダム行列の理論において重要である。

思考のスキル

複素数を使って幾何を代数に変える

平面上の点は複素数であり、距離は絶対値であり、正多角形は1の冪根である。距離の積は多項式の絶対値になる。

この翻訳によって、 \(z^n - 1\) の因数分解のような代数的恒等式で、直接見抜くのが非常に難しい幾何学的事実を証明できるようになる。

次の一歩

  1. 小さな場合を確かめる。 正方形（ \(n = 4\) ）と正三角形（ \(n = 3\) ）について、小問 (ii) を直接確かめよ。

  2. 頂点を通る場合。 \(P\) が \(O\) から \(X_0\) を通る半直線上にあるとき、 \(|PX_0| \times \cdots \times |PX_{n-1}| = \bigl||OP|^n - 1\bigr|\) であることを示せ。

  3. 平均距離。 小問 (ii) と 第 3.2 節 の相加相乗平均の不等式（AM–GM inequality）を用いて、 \(X_0\) から引いた \(n - 1\) 本の弦の長さの平均が \(n^{1/(n-1)}\) 以上であることを示せ。 \(n = 6\) のときの実際の平均 \(\frac{1}{n-1}\sum_k 2\sin\frac{k\pi}{n}\) を求め、比較せよ。

  4. すべての弦。 発展 単位円に内接する正 \(n\) 角形の \(\binom n2\) 本の弦すべての長さの積が \(n^{n/2}\) であることを示せ。

さらに学ぶために

  • Tristan Needham, Visual Complex Analysis (Oxford University Press)。複素数を用いた幾何を、美しい図版とともに解説している。

  • Ross Honsberger, Mathematical Gems (Mathematical Association of America)。正多角形に関する優美な問題がいくつか収められている。

  • Ronald Gowing, Roger Cotes: Natural Philosopher (Cambridge University Press)。コーツとその数学についての伝記である。
