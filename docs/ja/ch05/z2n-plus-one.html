5.3

\(z^{2n} + 1\) の因数分解

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第5章章全体のPDF
問題

STEP III 2013、第4問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/13-s3-q4

導入

\(\cos\frac{\pi}{8}\cos\frac{3\pi}{8}\cos\frac{5\pi}{8}\cos\frac{7\pi}{8}\) の値はいくらだろうか。各因数は入れ子になった平方根を含む扱いにくい数だが、積はちょうど \(\frac18\) になる。等間隔の角における余弦の積は、このように何度でも簡単な数に帰着する。本問はその理由を明らかにするものである。鍵は、これらの角を多項式の根の偏角（argument）とみなし、多項式を因数分解（factorise）し、巧みに選んだ値を代入することにある。

複素数の範囲では、すべての多項式は一次因数（linear factor）の積に完全に因数分解される。実数の範囲では、実数でない根は共役（conjugate）な組として現れ、それらが組み合わさって実数係数の二次因数になる。ここではどちらの事実も見ることができる。とくに後者によって、実数解を一つももたない \(z^{2n} + 1\) を、実数係数の二次式の積として書くことができるのである。

取りかかる前に

\(z^{2n} = -1\) の解は複素平面（complex plane）上のどこにあるか。\(n = 2\) と \(n = 4\) の場合について図示せよ。

解はすべて絶対値（modulus）が \(1\) であり、偏角 \(\theta\) は \(2n\theta = \pi + 2m\pi\) を満たすので、\(\theta\) は \(\frac{\pi}{2n}\) の奇数倍である。これらは単位円（unit circle）上の正 \(2n\) 角形をなし、どの頂点も実軸上にないような向きに回転している（図 5.3.1）。これらは、実軸に関して互いに鏡像となる共役な組 \(e^{\pm\mathrm{i}\theta}\) に分かれる。

順を追って解く

段階 1 共役な組から実数係数の二次式が得られる

\((z - e^{\mathrm{i}\theta})(z - e^{-\mathrm{i}\theta}) = z^2 - (e^{\mathrm{i}\theta} + e^{-\mathrm{i}\theta})z + 1 = z^2 - 2z\cos\theta + 1\).■

段階 2 因数分解

\(-\pi < \theta \leq \pi\) を満たす \(-1\) の \(2n\)th 乗根は \(e^{\pm\mathrm{i}\theta_k}\) であり、ここで \[\theta_k = \frac{(2k - 1)\pi}{2n}, \qquad k = 1, 2, \ldots, n.\] である。これらは \(2n\) 個の相異なる数で、いずれも \(2n\) 次多項式 \(z^{2n} + 1\) の根であるから、これらが根のすべてであり、 \[z^{2n} + 1 = \prod_{k=1}^{n}(z - e^{\mathrm{i}\theta_k})(z - e^{-\mathrm{i}\theta_k}) = \prod_{k=1}^{n}\bigl(z^2 - 2z\cos\theta_k + 1\bigr). \qed\]

段階 3 \(z = \mathrm{i}\) を代入する

\(\mathrm{i}^2 - 2\mathrm{i}\cos\theta + 1\) はいくらか。また、\(n\) が偶数のとき \(\mathrm{i}^{2n} + 1\) はいくらか。

各因数は \[\mathrm{i}^2 - 2\mathrm{i}\cos\theta_k + 1 = -2\mathrm{i}\cos\theta_k,\] となるので、右辺は \((-2\mathrm{i})^n\prod_k\cos\theta_k\) である。左辺は \(\mathrm{i}^{2n} + 1 = (-1)^n + 1\) であり、\(n\) が偶数のときこれは \(2\) である。さらに \(n\) が偶数のとき、 \[(-2\mathrm{i})^n = 2^n(-\mathrm{i})^n = 2^n\bigl((-\mathrm{i})^2\bigr)^{n/2} = 2^n(-1)^{n/2}.\] したがって \[\prod_{k=1}^{n}\cos\theta_k = \frac{2}{2^n(-1)^{n/2}} = (-1)^{\frac12 n}2^{1-n}. \qed\] \(n = 4\) とすると、これは導入で見た積 \((-1)^2 2^{-3} = \frac18\) になる。

段階 4 \(n\) が奇数のとき

\(n\) が奇数のとき、角 \(\theta_k\) のうち一つは \(\frac\pi2\) に等しい。それはどれか。また、そのために \(z = \mathrm{i}\) の代入がこのままでは役に立たないのはなぜか。

\(k = \frac{n+1}{2}\) のとき \(\theta_k = \frac{n\pi}{2n} = \frac\pi2\) であるから、その因数は \(z^2 + 1\) となり、これは \(z = \mathrm{i}\) で消える。すると両辺はともに \(0\) となり、何の情報も得られない。これを回避するには、先にこの因数で割っておけばよい。与えられた恒等式はまさにそれを行っている。

因数分解の両辺を \(1 + z^2\) で割り、\(z = \mathrm{i}\) を代入して整理せよ。残った余弦を組にする必要がある。

因数 \(z^2 + 1\)（\(k = \frac{n+1}{2}\) の項）で割ると、 \[1 - z^2 + z^4 - \cdots + z^{2n-2} = \prod_{k \neq \frac{n+1}{2}}\bigl(z^2 - 2z\cos\theta_k + 1\bigr).\] \(z = \mathrm{i}\) では、左辺の各項は \((-z^2)^j = 1^j = 1\) であり、項は \(n\) 個あるので、左辺は \(n\) である。右辺は \((-2\mathrm{i})^{n-1}\prod_{k \neq \frac{n+1}{2}}\cos\theta_k\) である。\(n - 1\) は偶数なので、\((-2\mathrm{i})^{n-1} = 2^{n-1}(-1)^{(n-1)/2}\) である。

ここで角を組にする。\(\theta_{n+1-k} = \pi - \theta_k\) であるから、\(\cos\theta_{n+1-k} = -\cos\theta_k\) である。残った \(n - 1\) 個の因数は、このような組を \(\frac{n-1}{2}\) 個なし（\(k = 1, \ldots, \frac{n-1}{2}\)）、各組は \(-\cos^2\theta_k\) を与える。よって \[n = 2^{n-1}(-1)^{(n-1)/2}\cdot(-1)^{(n-1)/2}\prod_{k=1}^{(n-1)/2}\cos^2\theta_k = 2^{n-1}\prod_{k=1}^{(n-1)/2}\cos^2\theta_k,\] となり、\(\prod\cos^2\theta_k = n2^{1-n}\) が得られる。最後の因数（\(k = \frac{n-1}{2}\)）は、問題文にあるとおり \(\cos^2\frac{(n-2)\pi}{2n}\) である。■

\(n = 3\) で確かめよう：\(\cos^2\frac\pi6 = \frac34 = 3 \cdot 2^{-2}\)。

振り返り

  • 根がわかれば多項式がわかる。多項式は根によって（定数倍を除いて）決まるので、\(z^{2n} + 1\) の根を列挙することでその因数分解が得られた。

  • 巧みな値を代入する。\(z = \mathrm{i}\) とおくと、各二次因数が余弦の定数倍になった。

  • 代入して \(0 = 0\) になったら、先に割る。\(n\) が奇数のときは一つの因数が \(z = \mathrm{i}\) で消えるので、代入の前にそれを取り除いた。

背後にある数学

代数学の基本定理

\(z^{2n} + 1\) が \(\mathbb{C}\) 上で一次因数の積に完全に因数分解できることは、代数学の基本定理（fundamental theorem of algebra）の特別な場合である。すなわち、複素数係数の定数でない多項式はすべて複素数の根をもち、したがって一次因数の積に完全に因数分解される。広く受け入れられた最初の証明は、ガウス（Gauss）が1799年の博士論文で与えたものであり、彼はその後も何度かこの定理に立ち返って新たな証明を与えた。この定理の帰結として、実数係数の多項式はすべて実数係数の一次因数と二次因数の積に因数分解される。実数でない根は、段階 1で見たとおり共役な組として現れるからである。この定理は名前こそ「代数学」だが、中身は解析学的である。どの証明も連続性など実数の何らかの性質を用いており、最も鮮やかな証明の一つを、複素解析（complex analysis）の最初の講義で目にすることになるだろう。

正弦と余弦の積

この方法からは、恒等式の一群が得られる。\(z^n - 1\) を \(z^{2n} + 1\) の代わりに用いると \[\prod_{k=1}^{n-1}\sin\frac{k\pi}{n} = \frac{n}{2^{n-1}},\] が得られる。これは幾何学的な形で 第 5.4 節 において証明されている。このような恒等式は、振動系の解析（ばねでつながれた \(n\) 個の質点の振動数には \(\sin\frac{k\pi}{2(n+1)}\) が現れる）や、数え上げの問題（ある種のグラフの全域木（spanning tree）の個数や、長方形のドミノタイリング（domino tiling）の数は余弦の積で与えられる）に現れる。\(m \times n\) の長方形のドミノタイリングの数に対するカステレイン（Kasteleyn）の1961年の公式は、\(\cos^2\frac{j\pi}{m+1}\) と \(\cos^2\frac{k\pi}{n+1}\) を含む式の二重積である。

思考のスキル

根から積へ

等間隔の角における三角関数の値の積を求めるには、それらが簡単な多項式の根から来ていることを見抜き、因数分解して、都合のよい値を代入せよ。

値の選び方こそが腕の見せどころである。ここでは \(z = \mathrm{i}\) によって各二次因数が余弦になった。別の値（たとえば \(z = 1\) や \(z = -1\)）を選べば、別の恒等式が得られる。

次の一歩

  1. 七角形にまつわる積。小問 (ii) で \(n = 7\) として、\(\cos\frac{\pi}{14}\cos\frac{3\pi}{14}\cos\frac{5\pi}{14} = \frac{\sqrt7}{8}\) を示せ。次に、\(\cos\frac{\pi}{7}\cos\frac{2\pi}{7}\cos\frac{3\pi}{7} = \frac18\) を示せ。（ヒント：\(\cos\theta = \sin(\frac\pi2 - \theta)\) を使って角を関係づけるか、恒等式 \(\sin 2x = 2\sin x\cos x\) を繰り返し用いよ。）

  2. 別の代入。因数分解に \(z = 1\) を代入して、 \[\prod_{k=1}^{n}\sin\frac{(2k-1)\pi}{4n} = 2^{\frac12 - n}.\] を示せ。

  3. \(z^6 + 1\) を因数分解する。\(z^6 + 1\) を実数係数の三つの二次式の積で表し、展開して答えを確かめよ。

  4. 正弦。\(z^{2n} - 1\) を同様に因数分解し、\(z^2 - 1\) で割ることにより、 \[\prod_{k=1}^{n-1}\sin\frac{k\pi}{2n} = \frac{\sqrt n}{2^{n-1}}.\] を示せ。

さらに学ぶために

  • Tristan Needham, Visual Complex Analysis（Oxford University Press）。第 2章で1の冪根（roots of unity）と多項式を、美しい図とともに扱っている。

  • Benjamin Fine & Gerhard Rosenberger, The Fundamental Theorem of Algebra（Springer）。解析学、代数学、位相幾何学によるこの定理のいくつかの証明を、学部生向けに解説している。

  • Paul Nahin, An Imaginary Tale（Princeton University Press）。\(\sqrt{-1}\) の歴史。1の冪根とその応用も扱っている。
