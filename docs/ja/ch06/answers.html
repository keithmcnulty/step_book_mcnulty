第6章 · 代数と構造

「次の一歩」の解答

これらは完全な解答ではなく、簡潔な答えとヒントである。結果と鍵となる手順を示してあるので、自分の解答を確かめるのに使ってほしい。答えを見る前に、まずそれぞれの演習問題にきちんと取り組むこと。

6.1 1の累乗根を根にもつ多項式

  1. \((x - 1)(x + 1) = x^2 - 1\) かつ \((x^2 + x + 1)(x^2 - x + 1) = x^4 + x^2 + 1\) であり、これらの積は \(x^6 - 1\) である。同様に \(x^{12} - 1 = (x^6 - 1)(x^6 + 1)\) であり、\(x^6 + 1 = (x^2 + 1)(x^4 - x^2 + 1) = \mathrm{C}_4\mathrm{C}_{12}\) である。

  2. \(2p\) の約数（divisor）は \(1\), \(2\), \(p\), \(2p\) であるから、\(\mathrm{C}_{2p} = \frac{x^{2p} - 1}{(x - 1)(x + 1)\mathrm{C}_p(x)} = \frac{x^p + 1}{x + 1}\) である。また、\(p\) は奇数であるから \(\mathrm{C}_p(-x) = \frac{(-x)^p - 1}{-x - 1} = \frac{x^p + 1}{x + 1}\) である。\(p = 3\) のとき：\(\mathrm{C}_6 = x^2 - x + 1 = \mathrm{C}_3(-x)\)。

  3. \(p^k\) 以下の数のうち \(p^k\) と共通の因数をもつものは、\(p\) の倍数 \(p^{k-1}\) 個である。原始 \(p^k\) 乗根（primitive \(p^k\)th root）は、\(x^{p^k} - 1\) の根のうち \(x^{p^{k-1}} - 1\) の根でないものであるから、\(\mathrm{C}_{p^k} = \frac{x^{p^k} - 1}{x^{p^{k-1}} - 1} = \mathrm{C}_p\bigl(x^{p^{k-1}}\bigr)\) である。よって \(\mathrm{C}_9 = x^6 + x^3 + 1\) である。

  4. \(\mathrm{C}_{15} = \frac{(x^{15} - 1)(x - 1)}{(x^3 - 1)(x^5 - 1)}\) である。\((x - 1)(x^2 + x + 1)(x^4 + x^3 + x^2 + x + 1)\) に問題文の8次式（octic）を掛けると \(x^{15} - 1\) になることを、展開して確かめよ。

6.2 ガウスの正17角形

  1. \(\eta + \eta'\) は実数でない6つの7乗根すべての和であり、\(-1\) である。\(\eta\eta'\) を展開すると、指数が \(4, 6, 0, 5, 0, 1, 0, 2, 3\) (mod \(7\)) である9つの項 \(\alpha^{a+b}\) が得られる。すなわち \(1\) が3つと、実数でない各根が1回ずつ現れるので、\(\eta\eta' = 3 - 1 = 2\) である。よって \(\eta\), \(\eta'\) は \(\frac{-1 \pm \mathrm{i}\sqrt7}{2}\) である。\(\eta\) の実部から余弦の和が得られる。\(\eta\) の虚部は \(\sin\frac{2\pi}{7} + \sin\frac{4\pi}{7} - \sin\frac{\pi}{7}\) であり、\(\sin\frac{4\pi}{7} = \sin\frac{3\pi}{7} > \sin\frac\pi7\) であるから正である。したがって虚部は \(+\frac{\sqrt7}{2}\) である。

  2. \(\zeta = \mathrm{e}^{2\pi\mathrm{i}/5}\) とすると、周期（period）\(\zeta + \zeta^4 = 2\cos\frac{2\pi}{5}\) と \(\zeta^2 + \zeta^3\) の和は \(-1\)、積は \(-1\) であるから、これらは \(t^2 + t - 1 = 0\) の根であり、正のほうから \(\cos\frac{2\pi}{5} = \frac{\sqrt5 - 1}{4}\) が得られる。作図（construction）するには：単位円の中で、直角をはさむ2辺が \(1\) と \(\frac12\) である直角三角形の斜辺は \(\frac{\sqrt5}{2}\) である。これから \(\frac12\) を引いて半分にすると \(\cos\frac{2\pi}{5}\) が得られる。その距離の点で軸に立てた垂線は、\((1, 0)\) に隣り合う頂点で円と交わる。この弦を円周に沿って順に移していけばよい。

  3. どちらも小数第5位までで \(-1.28078\) である。

  4. \(3\) のべきは \(3, 9, 10, 13, 5, 15, 11, 16, 14, 8, 7, 4, 12, 2, 6, 1\) であり、16個すべてが現れる。\(2\) のべきは8回で繰り返し（\(2^8 = 256 \equiv 1\)）、\(\{1, 2, 4, 8, 9, 13, 15, 16\}\) を与える。これは \(17\) を法（modulo）とする0でない平方数全体である。

6.3 \(\sqrt2 + \sqrt3 + \sqrt5\) を根にもつ多項式

  1. \(y^3 = 2\sqrt2 + 6\sqrt3 + 9\sqrt2 + 3\sqrt3 = 11\sqrt2 + 9\sqrt3\) であり、\(9y = 9\sqrt2 + 9\sqrt3\) であるから、\(y^3 - 9y = 2\sqrt2\) である。すると \(\sqrt3 = y - \sqrt2\) と \(\sqrt6 = \sqrt2\sqrt3\) も \(y\) の多項式（polynomial）で表される。

  2. \(x - \sqrt2 = \sqrt[3]3\) とおいて両辺を3乗すると、\(x^3 + 6x - 3 = \sqrt2(3x^2 + 2)\) となる。さらに2乗すると \(x^6 - 6x^4 - 6x^3 + 12x^2 - 36x + 1 = 0\) が得られる。

  3. 有理数解の候補は \(\pm1\) だけであり、どちらも解ではない。\(x^3\) の項がないので、モニック（monic）な2次式への因数分解は \((x^2 + ax + b)(x^2 - ax + c)\) の形になり、\(a(c - b) = 0\)、\(b + c - a^2 = -10\)、\(bc = 1\) となる。\(a = 0\) ならば \(b + c = -10\) かつ \(bc = 1\) となるが、これは整数では不可能である。\(b = c = \pm1\) ならば \(a^2 = 12\) または \(8\) となり、これも不可能である。よってこの4次式は既約（irreducible）であり、\(\sqrt2 + \sqrt3\) の次数（degree）は \(4\) である。

  4. ド・モアブル（De Moivre）の定理より \(\cos3\theta = 4\cos^3\theta - 3\cos\theta\) であり、\(\theta = 20^\circ\) とすると \(\frac12 = 4c^3 - 3c\) となる。候補 \(\pm1, \pm\frac12, \pm\frac14, \pm\frac18\) はどれも解ではない。よって \(\cos20^\circ\) の次数は \(3\) であるが、作図可能な（constructible）長さの次数はすべて \(2\) のべきであるから、\(60^\circ\) から \(20^\circ\) を作図することはできない。

6.4 四次方程式を解く

  1. \(y_1y_2 + y_2y_3 + y_3y_1\) は12個の項 \(\alpha^2\beta\gamma\)（1つの根の2乗とほかの2つの根の積）の和である。また \(\bigl(\sum\alpha\bigr)\bigl(\sum\alpha\beta\gamma\bigr)\) は、この12個の項に \(4\alpha\beta\gamma\delta\) を加えたものである。よってこの和は \((-p)(-r) - 4s\) である。

  2. 係数を比較すると \(a + b = 1\)、\(a\alpha + b\beta = 0\)、\(a\alpha^2 + b\beta^2 = -p\) が得られ、これは \(\alpha \neq \beta\) のとき解ける。2つの条件が保証しているのはまさにこのことである。\(p \neq 0\) により \(t\) の方程式は真の2次方程式になり（\(p = 0\) ならば \(-qt = 0\) に退化し、根は \(0\) だけになる）、\(q^2 \neq 4p^3\) によりその判別式（discriminant）\(q^2 - 4p^3\) は0でなくなる。\(x^3 - 24x + 48\) では \(p = 8\)、\(q = 48\) であり、\(8t^2 - 48t + 64 = 0\) から \(\alpha = 2\)、\(\beta = 4\) が得られる。すると \(\bigl(\frac{x - 2}{x - 4}\bigr)^3 = -\frac ba = \frac\alpha\beta = \frac12\) であるから \(x - 2 = 2^{-1/3}(x - 4)\) となり、これを整理すると与えられた根 \(x \approx -5.6946\) が得られる。

  3. 分解3次式（resolvent cubic）は \(y^3 - 7y^2 + 16y - 12 = (y - 3)(y - 2)^2\) である。根 \(y = 3\) から \((x^2 - 2x + 1)(x^2 - 2x + 2)\) が導かれるので、根は \(1\)（2回）と \(1 \pm \mathrm{i}\) である。

  4. どちらかの組の中で入れ替えるか否か（\(4\) 通り）、2つの組どうしを入れ替えるか否か（\(2\) 通り）により、恒等置換、\((\alpha\beta)\)、\((\gamma\delta)\)、\((\alpha\beta)(\gamma\delta)\)、\((\alpha\gamma)(\beta\delta)\)、\((\alpha\delta)(\beta\gamma)\)、\((\alpha\gamma\beta\delta)\)、\((\alpha\delta\beta\gamma)\) が得られる。これは正方形の対称群（symmetry group）と同じ構造をもつ群である。

6.5 公理から考える微分

  1. 定数は依然として \(0\) に写り、規則 (i) と帰納法（induction）により \(\lozenge x^n = x^{n-1}\lozenge x + x\lozenge x^{n-1} = nx^n\) である。線形性（linearity）により \(\lozenge\mathrm{h} = x\mathrm{h}'\) である。

  2. \(\lozenge\mathrm{f} = \frac{\mathrm{f}}{\mathrm{g}}\lozenge\mathrm{g} + \mathrm{g}\lozenge\frac{\mathrm{f}}{\mathrm{g}}\) であるから、\(\lozenge\frac{\mathrm{f}}{\mathrm{g}} = \frac{\mathrm{g}\lozenge\mathrm{f} - \mathrm{f}\lozenge\mathrm{g}}{\mathrm{g}^2}\) である。

  3. \(\mathrm{f} = (x - a)^2\mathrm{g}\) ならば \(\mathrm{f}' = (x - a)\bigl(2\mathrm{g} + (x - a)\mathrm{g}'\bigr)\) である。\(x^n - 1\) の重根（repeated root）は \(nx^{n-1}\) の根でもあるはずなので \(0\) となるが、\(0\) は \(x^n - 1\) の根ではない。

  4. \((2 + \varepsilon)^2 + 1 = 5 + 4\varepsilon\) であり、\((5 + 4\varepsilon)^3 = 125 + 300\varepsilon\) である。よって \(f(2) = 125\)、\(f'(2) = 300\) である。合成関数の微分法（chain rule）によっても \(3(x^2 + 1)^2 \cdot 2x = 3 \cdot 25 \cdot 4 = 300\) となる。

6.6 部分群の和集合

  1. \(V = \{e, a, b, c\}\) とすると、\(a^2 = b^2 = c^2 = e\) であり、\(a\), \(b\), \(c\) のうちどの2つの積も残りの1つになる。どの元も自分自身が逆元（inverse）である。\(\{1, \mathrm{i}, -1, -\mathrm{i}\}\) では \(\mathrm{i}\) の逆元は \(-\mathrm{i}\) であるから、この2つの群（group）は異なる。

  2. \(g\) が真部分群（proper subgroup）\(H\) に含まれるならば、\(g\) のすべてのべきも \(H\) に含まれるので、\(H\) は群全体になってしまう。

  3. \(1\) は偶数でも \(3\) の倍数でもない。より一般に、\(\mathbb{Z}\) は（\(1\) で生成される）巡回群（cyclic group）であるから、前の演習問題により、いくつの真部分群の和集合（union）にもならない。

  4. 直線 \(y = mx\) が \(y = x^2\) と交わるのは \(x = 0\) と \(x = m\) だけであり、直線 \(x = 0\) が交わるのは原点だけである。よって \(k\) 本の直線は、\(t \neq 0\) である無数の点 \((t, t^2)\) のうち高々 \(k\) 個しか含まない。

6.7 四元数群

  1. \(C\circ B = (\mathrm{i}, 0)\circ(0, 1) = (0, \mathrm{i}) = D\) であり、\(B\circ C = (0, 1)\circ(\mathrm{i}, 0) = (0, \mathrm{i}^*) = (0, -\mathrm{i}) = H\) である。

  2. \(A\) の位数（order）は \(1\)、\(E\) の位数は \(2\) である。残りの6つはどれも2乗すると \(E\) になるので、位数は \(4\) である。正方形の対称群には位数 \(2\) の元が5つ（4つの鏡映と半回転）あるので、2つの群は同型（isomorphic）ではない。

  3. \(\det M = z_1z_1^* + z_2z_2^* = |z_1|^2 + |z_2|^2\) であり、これは4つの実数の平方の和である。\(M(z)M(w)\) は \(z\circ w\) の行列であるから、行列式（determinant）を掛け合わせると \((a_1^2 + \cdots + a_4^2)(b_1^2 + \cdots + b_4^2)\) は \(|u_1|^2 + |u_2|^2\) と表され、これもまた4つの平方の和である。

  4. 部分群は \(\{A\}\)、\(\{A, E\}\)、\(\{A, E, C, G\}\)、\(\{A, E, B, F\}\)、\(\{A, E, D, H\}\)、\(Q_8\) である。\(A\) 以外のどの元もそのべきとして \(E\) をもつので、\(\{A\}\) 以外のどの部分群も \(E\) を含む。位数 \(4\) の3つの部分群を合わせると、8つの元すべてを含む。

6.8 特異行列からなる群

  1. \(\mathbf{M}_a\mathbf{M}_b = \mathbf{M}_{2ab}\) であり、\(2(2ab) = (2a)(2b)\) である。この写像は一対一（one-to-one）であり、0でない実数全体への全射（onto）である。

  2. \(\begin{pmatrix} a & b \\ 0 & 0 \end{pmatrix}\begin{pmatrix} c & d \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} ac & ad \\ 0 & 0 \end{pmatrix}\) であり \(ac \neq 0\) であるから、この集合は閉じている（closed）。\(\begin{pmatrix} 1 & e \\ 0 & 0 \end{pmatrix}\) の形の行列はすべて左単位元（left identity）である。しかし \(\mathbf{E} = \begin{pmatrix} e & f \\ 0 & 0 \end{pmatrix}\) として \(\mathbf{XE} = \mathbf{X}\) となるには \(e = 1\) かつ \(f = b/a\) が必要であり、これは \(\mathbf{X}\) に依存する。よって右単位元は存在せず、単位元も存在しないので、群ではない。

  3. \(\mathbf{0}\)、\(\mathbf{I}\)、および \(bc = a(1 - a)\) を満たす行列 \(\begin{pmatrix} a & b \\ c & 1 - a \end{pmatrix}\)（トレース \(1\)、行列式 \(0\)）である。これらは、平面をある直線へ別の直線に沿って写す射影（projection）である。

  4. 成分がすべて \(a\) である行列 \(\mathbf{J}_a\) は \(\mathbf{J}_a\mathbf{J}_b = \mathbf{J}_{nab}\) を満たす。単位元は \(\mathbf{J}_{1/n}\) であり、\(\mathbf{J}_a\) の逆元は \(\mathbf{J}_{1/(n^2a)}\) である。
