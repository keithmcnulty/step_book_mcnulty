6.1

1の累乗根を根にもつ多項式

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第6章章全体のPDF
問題

STEP III 2010、第3問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/10-s3-q3

導入

1 の \(n\) 乗根（\(n\)th roots of unity）、すなわち \(z^n = 1\) の解は、正 \(n\) 角形の頂点に並んでいる。しかし、それらはすべて同じ性質をもつわけではない。たとえば 1 の \(12\) 乗根のうち、\(1\) はすでに 1 の 1 乗根であり、\(-1\) は 1 の平方根、\(\mathrm{i}\) は 4 乗根である。12 個のうち 4 個だけ、すなわち原始的（primitive）なものだけが、\(1\) に戻るまでに 12 ステップすべてを必要とする。

1 の冪根を、必要なステップ数によって分類し、それぞれの類から多項式を作ると、円分多項式（cyclotomic polynomials、ギリシャ語で「円を分割する」の意）が得られる。素数が整数の基本的な構成要素であるのと同じように、円分多項式は \(z^n - 1\) の基本的な構成要素である。円分多項式は、ガウス（Gauss）による正 \(17\) 角形の作図（第 6.2 節）や 1 の冪根フィルター（第 5.2 節）、さらには現代整数論の多くの部分の背後にある。

取りかかる前に

1 の \(n\) 乗根はどれも \(z^n = 1\) を満たす。しかし、\(1\) を与える最小の正の冪は \(n\) より小さいかもしれない。四つの 1 の 4 乗根 \(1\), \(\mathrm{i}\), \(-1\), \(-\mathrm{i}\) のそれぞれについて、その最小の冪はいくつか？

\(1^1 = 1\)、\((-1)^2 = 1\) であり、\(\mathrm{i}^4 = (-\mathrm{i})^4 = 1\) で、これより小さい冪では \(1\) にならない。したがって最小の冪はそれぞれ \(1\), \(4\), \(2\), \(4\) である。この最小の冪をその 1 の冪根の位数（order）とよび、原始 \(n\) 乗根とはちょうど位数が \(n\) であるもののことである。この問題全体を通じて鍵となる事実は、どの 1 の冪根もただ一つの位数をもつということである。

順を追って解く

段階 1 最初のいくつか

原始 4 乗根は \(\mathrm{i}\) と \(-\mathrm{i}\) であるから、\(\mathrm{C}_4(x) = (x - \mathrm{i})(x + \mathrm{i}) = x^2 + 1\) である。■

位数が \(1\), \(2\), \(3\), \(5\) および \(6\) である 1 の冪根はそれぞれどれか？（1 の \(6\) 乗根を図示し、位数によって分類してみよ。）

位数 \(1\)：\(1\) のみであるから、\(\mathrm{C}_1(x) = x - 1\)。位数 \(2\)：\(-1\) のみであるから、\(\mathrm{C}_2(x) = x + 1\)。

位数 \(3\)：\(1\) 以外の 1 の 3 乗根、すなわち \(\frac{x^3 - 1}{x - 1}\) の根である。よって \(\mathrm{C}_3(x) = x^2 + x + 1\)。

位数 \(5\)：\(1\) 以外の 5 乗根であり、これは \(\frac{x^5 - 1}{x - 1}\) の根であるから、\(\mathrm{C}_5(x) = x^4 + x^3 + x^2 + x + 1\)。

位数 \(6\)：6 乗根 \(e^{k\pi\mathrm{i}/3}\), \(k = 0, \ldots, 5\) のうち、\(k = 0\), \(3\) のものは位数がそれぞれ \(1\), \(2\) であり、\(k = 2\), \(4\) のものは位数 \(3\) である。残るのは \(e^{\pm\pi\mathrm{i}/3}\) であるから、 \[\mathrm{C}_6(x) = (x - e^{\mathrm{i}\pi/3})(x - e^{-\mathrm{i}\pi/3}) = x^2 - 2x\cos\tfrac\pi3 + 1 = x^2 - x + 1. \qed\]

段階 2 \(x^4 + 1\) を与える \(n\) はどれか？

\(x^4 + 1 = 0\) の根は \(x^4 = -1\) を満たすので、\(x^8 = 1\) であるが \(x^4 \neq 1\) である。その位数は \(8\) を割り切るが \(4\) を割り切らないので、\(8\) である。逆に、位数 \(8\) の根は \(x^8 = 1\), \(x^4 \neq 1\) を満たすので、\(x^4 = -1\) である。原始 \(8\) 乗根は 4 個あり、\(x^4 + 1\) の根も 4 個あるから、\(n = 8\) である。■

段階 3 素数の場合

\(p\) が素数ならば、1 の \(p\) 乗根の位数は \(p\) を割り切るので、\(1\) または \(p\) である。したがって \(1\) 以外の \(p\) 乗根はすべて原始的であり、 \[\mathrm{C}_p(x) = \frac{x^p - 1}{x - 1} = x^{p-1} + x^{p-2} + \cdots + x + 1. \qed\]

段階 4 円分多項式は他の二つの円分多項式の積にならない

\(\mathrm{C}_q = \mathrm{C}_r\mathrm{C}_s\) と仮定する。\(\mathrm{C}_r\) の根を一つとる。その位数はいくつか？ この恒等式はその位数について何を教えてくれるか？ そこから何が導かれるか？

\(\mathrm{C}_r\) の根（\(e^{2\pi\mathrm{i}/r}\) は原始的であるから、少なくとも一つは存在する）はどれも \(\mathrm{C}_r\mathrm{C}_s = \mathrm{C}_q\) の根であるから、位数は \(q\) である。しかしその位数は \(r\) でもあり、1 の冪根の位数はただ一つであるから、\(r = q\) である。すると \(\mathrm{C}_q = \mathrm{C}_q\,\mathrm{C}_s\) となり、\(\mathrm{C}_q\) は零多項式ではないから、\(\mathrm{C}_s = 1\) である。しかし \(\mathrm{C}_s\) は少なくとも一つの根 \(e^{2\pi\mathrm{i}/s}\) をもつので、これは不可能である。よって、このような \(q\), \(r\), \(s\) は存在しない。■

振り返り

  • 位数で分類する。どの 1 の冪根もただ一つの位数をもち、位数でまとめることで \(z^n - 1\) の根は互いに交わらない類に分かれる。

  • 根によって多項式を定める。各 \(\mathrm{C}_n\) は、どの数がその根であるかを正確に述べることで決定された。

  • 一意性から不可能性が導かれる。小問 (iv) で必要だったのは、一つの根が二つの異なる位数をもつことはない、というただ一つの考え方だけであった。

背後にある数学

\(x^n - 1\) の因数分解

1 の \(n\) 乗根はどれも、\(n\) を割り切るある位数 \(d\) をもつ。また \(d \mid n\) のとき、位数 \(d\) の 1 の \(d\) 乗根はどれも 1 の \(n\) 乗根である。したがって \(x^n - 1\) の根は位数によって類に分かれ、 \[x^n - 1 = \prod_{d \mid n}\mathrm{C}_d(x)\] が得られる。たとえば \(x^6 - 1 = \mathrm{C}_1\mathrm{C}_2\mathrm{C}_3\mathrm{C}_6 = (x - 1)(x + 1)(x^2 + x + 1)(x^2 - x + 1)\) である。図 6.1.1 は、12 個の 1 の \(12\) 乗根をこのように分類したものである。原始 \(n\) 乗根の個数、すなわち \(\mathrm{C}_n\) の次数は、\(1\) から \(n\) までの \(k\) のうち \(n\) と共通因数をもたないものの個数であり、これがオイラーのトーシェント関数（Euler’s totient function）\(\varphi(n)\) である。次数を比較すると、恒等式 \(\sum_{d \mid n}\varphi(d) = n\) が得られる。

整数係数と、ある意外な事実

定義からは明らかではないが、どの円分多項式も整数係数をもつ。（\(x^n - 1\) の因数分解と数学的帰納法（induction）を用いる。\(\mathrm{C}_n\) は \(x^n - 1\) をそれ以前の円分多項式の積で割ったものであり、整数係数の多項式をモニック（monic、最高次の係数が 1）な整数係数多項式で筆算により割っても、係数は整数のままである。）長い間、知られていた例はすべて係数が \(0\), \(1\), \(-1\) のいずれかであった。最初の例外は \(\mathrm{C}_{105}\) で、これは項 \(-2x^7\) を含み、1883 年に Migotti によって発見された。\(105 = 3 \times 5 \times 7\) は、相異なる三つの奇素因数をもつ最小の数である。実は、円分多項式の係数はいくらでも大きくなりうる。

既約性

小問 (iv) は、円分多項式が他の二つの円分多項式の積にならないことを示している。実はもっと強いことが成り立つ。\(\mathrm{C}_n\) は、より低い次数の有理数係数多項式の積にはまったく因数分解できないのである。ガウスはこれを \(n\) が素数の場合に証明し（これは大学の最初の代数の講義で学ぶアイゼンシュタインの判定法（Eisenstein’s criterion）から導かれる）、クロネッカー（Kronecker）とデデキント（Dedekind）が一般の \(n\) の場合に証明した。この既約性（irreducibility）こそが、円分多項式を 1 の冪根に関連する多項式の中の「素数」たらしめているものであり、1 の冪根のガロア理論（Galois theory）の出発点でもある。

思考のスキル

分類してから組み立てる

問題に現れる対象を、ただ一つに定まる明確な不変量（invariant）によって類に分け、類ごとに構造を組み立てよ。

ここでの不変量は 1 の冪根の位数であった。各根はちょうど一つの位数をもつので類は重ならず、\(x^n - 1\) はそれらの類にわたる積に分解される。同じパターン（一意的な不変量が互いに交わらない分解を与えること）は、素因数分解（prime factorisation）や有限アーベル群（finite abelian groups）の分類の根底にもある。

次の一歩

  1. 因数分解を確かめる。\((x - 1)(x + 1)(x^2 + x + 1)(x^2 - x + 1) = x^6 - 1\) であること、および \(x^{12} - 1\) が図 6.1.1 のように因数分解されることを確かめよ。

  2. 素数の 2 倍。\(p\) が奇素数ならば \(\mathrm{C}_{2p}(x) = \mathrm{C}_p(-x)\) であることを示せ。\(p = 3\) の場合にこれを確かめよ。

  3. トーシェント関数。素数 \(p\) に対して \(\varphi(p^k) = p^k - p^{k-1}\) であること、および \(\mathrm{C}_{p^k}(x) = \mathrm{C}_p\bigl(x^{p^{k-1}}\bigr)\) であることを示せ。これを用いて \(\mathrm{C}_9\) を求めよ。

  4. 少し長い問題。 発展 \(x^{15} - 1 = \mathrm{C}_1\mathrm{C}_3\mathrm{C}_5\mathrm{C}_{15}\) を用いて、\(\mathrm{C}_{15}(x) = x^8 - x^7 + x^5 - x^4 + x^3 - x + 1\) であることを示せ。

さらに学ぶために

  • Ian Stewart, Galois Theory（CRC Press）。学部生向けの標準的な入門書（『ガロア理論』）。円分多項式と正多角形が早い段階で登場する。

  • Harold Davenport, The Higher Arithmetic（Cambridge University Press）。1 の冪根とその算術を扱っている（『高等算術』）。

  • Marcus du Sautoy, Finding Moonshine（Fourth Estate）。対称性と群論についての一般向けの読み物で、ガロアの物語も含まれている。
