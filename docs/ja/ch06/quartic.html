6.4

四次方程式を解く

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第6章章全体のPDF
問題

STEP III 2017、第3問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/17-s3-q3

導入

二次方程式（quadratic equation）の解の公式は誰もが学ぶ。三次方程式（cubic）や四次方程式（quartic）にも解の公式は存在する。それらは16世紀のイタリアで、秘密の勝負と先取権をめぐる激しい論争のさなかに発見された。ジェロラモ・カルダーノ（Gerolamo Cardano）は1545年の著書 Ars Magna（『アルス・マグナ』）で両方の解法を発表した。三次方程式の解法はニコロ・タルタリア（Niccolò Tartaglia）から得たもので、タルタリアはカルダーノに秘密を守ると誓わせていた。四次方程式の解法はカルダーノ自身の弟子ロドヴィコ・フェラーリ（Lodovico Ferrari）によるものである。その後およそ三百年にわたって、数学者たちは五次方程式（quintic）の解の公式を探し求めたが、ついに見つけることはできなかった。

この問題は四次方程式を解く仕掛けを示しており、しかもその仕掛けには深い意味がある。四つの根を、考えられる三通りの方法で二つずつ組にし、そこから三つの新しい量を作る。この三つの量はある三次方程式を満たし、それは解くことができる。そしてこれらの量から元の根が求まるのである。これがなぜうまくいくのか、すなわち四つの根は三つの量に帰着できるのに、五つの根は同じように帰着できないのはなぜか、という問いこそが、ガロア（Galois）を群論（group theory）の創始へと導いたのである。

取りかかる前に

四つの対象 \(\alpha, \beta, \gamma, \delta\) を二つの組に分ける方法は何通りあるか。

三通りある。\(\{\alpha\beta, \gamma\delta\}\)、\(\{\alpha\gamma, \beta\delta\}\)、\(\{\alpha\delta, \beta\gamma\}\) である（図 6.4.1）。問題に現れる三つの量 \(\alpha\beta + \gamma\delta\) などは、これら三つの組分けに対応している。四つの根をどのように並べ替えても、三つの組分けが互いに入れ替わるだけである。したがって、三つの量についての対称式（symmetric expression）はどれも四つの根についての対称式であり、\(p\), \(q\), \(r\), \(s\) を用いて表せる。これが、三つの量が \(p\), \(q\), \(r\), \(s\) のみを含む係数をもつ三次方程式を満たす理由である。

順を追って解く

段階 1 欠けている係数

三次方程式 \(y^3 + Ay^2 + By + C = 0\) において、根の和を \(A\) で表すとどうなるか。また、\((\alpha\beta + \gamma\delta) + (\alpha\gamma + \beta\delta) + (\alpha\delta + \beta\gamma)\) を四次方程式の係数で表すとどうなるか。

三次方程式の根の和は \(-A\) である。三つの量の和は、\(\alpha, \beta, \gamma, \delta\) から二つずつ選んだ積六つすべての和であり、四次式 \(x^4 + px^3 + qx^2 + rx + s\) についてこれは \(q\) に等しい。よって \(A = -q\) である。

段階 2 具体的な三次方程式

\(p = 0\), \(q = 3\), \(r = -6\), \(s = 10\) のとき、三次方程式は \[y^3 - 3y^2 + (0 - 40)y + (120 - 0 - 36) = y^3 - 3y^2 - 40y + 84 = 0.\] となる。

\(84\) の小さな約数を試してみよ。

\(y = 2\) とすると \(8 - 12 - 80 + 84 = 0\) となる。割り算をすると \(y^3 - 3y^2 - 40y + 84 = (y - 2)(y^2 - y - 42) = (y - 2)(y - 7)(y + 6)\) である。最大の根は \(7\) なので、\(\alpha\beta + \gamma\delta = 7\) である。■

段階 3 根の組

\((\alpha + \beta)(\gamma + \delta) = \alpha\gamma + \alpha\delta + \beta\gamma + \beta\delta\) であり、これは二つずつの積六つすべての和から \(\alpha\beta + \gamma\delta\) を引いたもの、すなわち \(q - 7 = 3 - 7 = -4\) である。

また \(\alpha\beta \cdot \gamma\delta = \alpha\beta\gamma\delta = s = 10\) である。よって \(\alpha\beta\) と \(\gamma\delta\) は和が \(7\)、積が \(10\) であり、\(t^2 - 7t + 10 = (t - 2)(t - 5)\) の根である。\(\alpha\beta > \gamma\delta\) とすると、\(\alpha\beta = 5\), \(\gamma\delta = 2\) である。■

段階 4 四次方程式を解く

\(\alpha + \beta\) と \(\gamma + \delta\) を求めよ。両者の和（\(p\) から）と積（段階 3 から）はわかっている。どちらがどちらかを決めるには \(r\) を用いよ。

\(\alpha + \beta + \gamma + \delta = -p = 0\) かつ \((\alpha + \beta)(\gamma + \delta) = -4\) なので、\(\{\alpha + \beta, \gamma + \delta\} = \{2, -2\}\) である。係数 \(r\) からは三つずつの積四つの和が得られる：\(\alpha\beta\gamma + \alpha\beta\delta + \alpha\gamma\delta + \beta\gamma\delta = -r = 6\)。これは \(\alpha\beta(\gamma + \delta) + \gamma\delta(\alpha + \beta) = 5(\gamma + \delta) + 2(\alpha + \beta)\) と書ける。\(\alpha + \beta = 2\) ならばこれは \(-10 + 4 = -6\) となり、\(\alpha + \beta = -2\) ならば \(10 - 4 = 6\) となる。よって \(\alpha + \beta = -2\), \(\gamma + \delta = 2\) である。

すると \(\alpha\), \(\beta\) は \(t^2 + 2t + 5 = 0\) の根であり、\(-1 \pm 2\mathrm{i}\) となる。また \(\gamma\), \(\delta\) は \(t^2 - 2t + 2 = 0\) の根であり、\(1 \pm \mathrm{i}\) となる。四つの根は \[x = -1 \pm 2\mathrm{i}, \qquad x = 1 \pm \mathrm{i}. \qed\] である。 検算：\((x^2 + 2x + 5)(x^2 - 2x + 2) = x^4 + 3x^2 - 6x + 10\)。

振り返り

  • 対称式。 どの段階でも、解と係数の関係（relations between roots and coefficients）、すなわち根の和や積を用いた。

  • 次数を下げる。 四次方程式の問題が三次方程式（分解三次方程式（resolvent cubic））に、さらに二つの二次方程式になった。

  • すべての情報を使う。 \(p\) と \(q\) から和と積が得られ、\(s\) によって \(\alpha\beta\) と \(\gamma\delta\) が分けられ、\(r\) によってどの組がどちらの和に対応するかが決まった。

背後にある数学

仕掛けがうまくいく理由：根の置換

1770年、ジョゼフ＝ルイ・ラグランジュ（Joseph-Louis Lagrange）は、三次方程式や四次方程式の解法がなぜうまくいくのかを問い、その答えを根の置換（permutation）に見いだした。四つの根を並べ替える方法は \(24\) 通りある。そのどれによっても、三つの量 \(y_1 = \alpha\beta + \gamma\delta\), \(y_2 = \alpha\gamma + \beta\delta\), \(y_3 = \alpha\delta + \beta\gamma\) は互いに入れ替わるだけである。四つの根の並べ替えはそれぞれ、三つの組分けの並べ替えを引き起こすのである（図 6.4.1）。したがって、これらの量は根について対称な係数をもつ次数 \(3\) の多項式を満たす。現代の言葉でいえば、対称群（symmetric group）\(S_4\)（\(24\) 個の置換すべて）から \(S_3\)（組分けの \(6\) 個の置換）への全射な群準同型（group homomorphism）が存在し、それこそが四次方程式を三次方程式に帰着できる理由である。

五次方程式

五つの根の場合について、ラグランジュは根の置換のもとで少数の値しかとらない同様の量を探したが、役に立つものは見つからなかった。1799年にパオロ・ルフィニ（Paolo Ruffini）が、そして1824年にニールス・ヘンリック・アーベル（Niels Henrik Abel）が（証明を完成させて）、四則演算と冪根（radicals）だけを用いた五次方程式の根の一般的な公式は存在しないことを示した。その数年後、エヴァリスト・ガロアは、どの多項式が冪根によって解けるのかを正確に説明した。それは、根の対称性のなす群がある特定の仕方でより単純な部分に分解できるような多項式である。対称群 \(S_4\) はそのように分解できる（\(S_3\) やより小さな群を経由して）が、\(S_5\) はできない。\(S_5\) には、それ以上分解できない大きさ \(60\) の「単純」（simple）な部分が含まれているからである。ガロアは1832年、二十歳で決闘により命を落とす前夜に、自らの理論を急いで書き上げた。この理論は今日、数学の学位課程における至宝の一つであり、通常は三年次に学ぶ。

三次方程式を解く

三次方程式そのものも同様の仕掛けで解ける。被約三次式（depressed cubic）\(x^3 - 3px + q\) を二つの完全立方（perfect cube）の組み合わせとして書くと、二次方程式に帰着される。これが演習にある2011年の問題の方法であり、カルダーノの公式と同値である。三次方程式が三つの実数解をもつときでも、この公式は途中で複素数（complex numbers）を必要とする。この現象が、数学者たちに複素数を真剣に扱うことを迫ったのである（第 5 章の導入を参照）。

思考のスキル

対称性が複雑さを減らす

根から作ったいくつかの量が、根を置換したときに互いに入れ替わるだけならば、それらの量は係数を計算できるより低い次数の多項式を満たす。

これがガロア理論（Galois theory）の萌芽である。すなわち、方程式を理解するには、その根の対称性を理解せよ、ということである。

次の一歩

  1. 三次方程式を確かめる。 \(y_1 = \alpha\beta + \gamma\delta\) などとするとき、\(y_1y_2 + y_2y_3 + y_3y_1 = pr - 4s\) であることを確かめよ。（展開して、\(\sum\alpha = -p\), \(\sum\alpha\beta\gamma = -r\), \(\alpha\beta\gamma\delta = s\) を用いよ。）

  2. 立方の和としての三次方程式。 STEP III 2011、第3問 に取り組んでみよ。この問題は、三次式を二つの立方の組み合わせとして書くことで三次方程式を解くもので、本節とはまったく異なる道筋である。答えを数値的に確かめよ。

  3. もう一つの四次方程式。 本節の方法を用いて \(x^4 - 4x^3 + 7x^2 - 6x + 2 = 0\) を解け。（分解三次方程式の根の一つは小さな整数である。）

  4. 置換を数える。 \(\alpha, \beta, \gamma, \delta\) の \(24\) 個の置換のうち、組分け \(\{\alpha\beta, \gamma\delta\}\) を自分自身に移すものをすべて求めよ。それが \(8\) 個あることを示せ。（これらは \(S_4\) の部分群（subgroup）をなす。）

さらに学ぶために

  • Mario Livio, The Equation That Couldn’t Be Solved (Simon & Schuster)。五次方程式と群論誕生の物語を、一般の読者向けに描いたもの。

  • Ian Stewart, Why Beauty Is Truth: A History of Symmetry (Basic Books)。バビロニアの方程式からガロア、そしてその先までを扱う。

  • Ian Stewart, Galois Theory (CRC Press)。学部生向けの教科書で、まさにこの内容を扱う歴史的な序章がある。
