第6章 · 代数と構造

これまでに学んだこと

本章は、代数学が方程式を解くことから構造を調べることへと移り変わったことから出発し、三つの問いを立てた。何から何が作れるのか、方程式の解の公式はなぜうまくいくのか、そして抽象化によって何が得られるのか、である。本章の八つの問題が示したことを以下にまとめる。

1. 何から何が作れるか？

第 6.3 節 では、冪根（radical）を一つずつ消去することで、\(\sqrt2 + \sqrt3\)、\(\sqrt2 + \sqrt3 + \sqrt5\)、\(\sqrt[3]2 + \sqrt[3]3\) を根にもつ多項式を求めた。その次数（degree）はそれぞれ \(4\)、\(8\)、\(9\) であった。これらの次数は不変量（invariant）であり、その数が生成する体（field）の次数にほかならない。体の塔（tower of fields）を上るにつれて次数は掛け算で積み重なるので、平方根だけでたどり着ける数の次数は \(2\) の冪になる。このただ一つの事実から、立方体の倍積（doubling the cube）が不可能であること（\(\sqrt[3]2\) の次数は \(3\) である）、そして \(60^\circ\) の角は三等分（trisection）できないことが証明される。

逆の方向として、第 6.2 節 では何かが作図できる仕組みを見た。\(1\) の \(17\) 乗根（roots of unity）をガウス（Gauss）の周期に分けると、和 \(\cos\frac{2\pi}{17} + \cos\frac{4\pi}{17} + \cos\frac{8\pi}{17} + \cos\frac{16\pi}{17}\) は \(\frac{-1 + \sqrt{17}}{4}\) を根にもつ二次方程式を満たした。さらに三つの二次方程式を経て \(\cos\frac{2\pi}{17}\) に至り、こうして正 \(17\) 角形の作図が得られる。これら二つの節の土台にあったのが、第 6.1 節 の円分多項式（cyclotomic polynomial）である。円分多項式は \(x^n - 1\) を構成する基本単位であり、\(1\) の冪根をその位数（order）によって分類することで得られた。

2. 方程式の解の公式はなぜうまくいくのか？

第 6.4 節 では四次方程式（quartic）の秘密を明らかにした。四つの根から、根の組の作り方それぞれに対応する三つの量 \(\alpha\beta + \gamma\delta\)、\(\alpha\gamma + \beta\delta\)、\(\alpha\delta + \beta\gamma\) を作る。根をどのように並べ替えても、これら三つの量が入れ替わるだけなので、これらは係数のわかっている三次方程式（cubic）を満たす。その三次方程式を解き、続いて二つの二次方程式を解けば根が得られた。ラグランジュ（Lagrange）は、これがうまくいくのは四つの対象の置換（permutation）が三通りの組分けにどう作用するかによることを見抜いた。ガロア（Galois）は、五つの根に対してこれがうまくいかないのは、五つの対象の置換全体のなす群（group）が、それ以上分解できない部分を含んでいるからだと見抜いた。解の公式とは、群の構造が落とす影なのである。

3. 抽象化によって何が得られるか？

最後の四つの節では、対象をそれが従う規則によって記述した。

  • 第 6.5 節 では、四つの規則（加法性（additivity）、積の法則（product rule）、定数についての規則、\(\lozenge x = 1\)）によって、極限を一切使わずに、ある演算が微分でなければならないことが導かれた。同じ規則が、現代のソフトウェアにおける自動微分（automatic differentiation）を支えている。

  • 第 6.6 節 では、群の公理（group axioms）から出発するわずか三行の議論によって、どんな群も二つの真部分群（proper subgroup）の和集合にはならないことが、すべての群について一度に示された。

  • 第 6.7 節 では、複素数の組に対する奇妙な演算が、実はハミルトン（Hamilton）の四元数（quaternion）の乗法であることがわかり、それを行列で表すことで結合法則（associativity）が自動的に成り立った。

  • 第 6.8 節 では、群の定義を文字どおりに読むことで、特異行列（singular matrix）からなる群が得られた。その単位元（identity）は単位行列ではなく、しかもその群は「本当は」\(0\) でない実数全体のなす群が姿を変えたものであった。

いずれの場合も、抽象的な見方によって、計算だけでは見えにくくなっていたであろう事柄が説明されたのである。

4. 代数学の道具箱

手法 使った場面
ただ一つに定まる不変量による分類 \(1\) の冪根の位数による分類（6.1）
和と積から二次方程式を作る ガウス周期（6.2）、四次方程式（6.4）
積和公式（product-to-sum formulas） 正 \(17\) 角形（6.2）
冪根の消去 最小多項式（minimal polynomial）（6.3）
次数と塔法則（tower law） 作図の不可能性（6.3）
根の対称式（symmetric functions） 分解三次方程式（resolvent cubic）（6.4）
公理による演算の決定 導分（derivation）（6.5）
群の公理からの議論 部分群の和集合（6.6）
行列表現（matrix representation） 四元数（6.7）
同型（isomorphism） 特異行列からなる群（6.8）

この先へ

  • 四元数は、第 7.8 節 のラグランジュの四平方定理（four-square theorem）へとつながる。

  • 独自の規則をもつ代数的対象としての行列は、第 7章の主題である。

  • ガウス整数（Gaussian integers）のように、素因数分解（factorisation）が一意に定まらないことがある数の体系の算術は、第 1.7 節 のテーマであった。

大学に入る前にさらに先へ進みたい人のために

  • Mario Livio, The Equation That Couldn’t Be Solved：五次方程式（quintic）、ガロア、そして群論の誕生を描く。

  • Nathan Carter, Visual Group Theory：図を通して群を学ぶ。最初に読むのに理想的な一冊。

  • M. A. Armstrong, Groups and Symmetry：幾何学を土台にした大学初年級の講義。

  • Ian Stewart, Galois Theory：物語の全貌に挑む準備ができたときに。

ガロアは決闘の末に二十歳で世を去り、数十ページの原稿を遺した。数学の世界がそれを理解するには何十年もの歳月を要した。ガロアが見抜いたのは、方程式の最も深い秘密はその係数ではなく、解のもつ対称性の中にあるということであった。異なるものに同じ名前を与え、それらが共有する構造を調べるというこの洞察は、今や数学のあらゆる分野に行き渡っている。読者はそれが多項式、多角形、四元数、行列の中で働く様子を見てきた。大学に進めば、ほとんどあらゆる場所でそれに出会うことになるだろう。
