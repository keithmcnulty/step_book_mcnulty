第7章 · 線形代数と幾何

「次の一歩」の解答

以下は完全な解答ではなく、簡潔な答えとヒントである。自分の解答を確かめられるよう、結果と鍵となる段階を示してある。見る前に、まずそれぞれの問題にきちんと取り組んでほしい。

7.1 行列では成り立たない法則

  1. \(\mathbf{X} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\) として \(\mathbf{XP}\) と \(\mathbf{PX}\) を比較すると、\(c = 0\) かつ \(a = d\) でなければならない。すなわち行列 \(\begin{pmatrix} a & b \\ 0 & a \end{pmatrix}\) である。

  2. ケイリー・ハミルトンの定理（Cayley–Hamilton theorem）より \(\mathbf{N}^2 = t\mathbf{N} - d\mathbf{I}\) であるから、\(t\mathbf{N} = d\mathbf{I}\) となる。\(t \neq 0\) ならば \(\mathbf{N}\) は \(\mathbf{I}\) の定数倍であり、\(\mathbf{N}^2 = \mathbf{0}\) から \(\mathbf{N} = \mathbf{0}\) となって \(t \neq 0\) に矛盾する。よって \(t = 0\) であり、このとき \(d = 0\) である。答えは \(a^2 + bc = 0\) を満たす \(\begin{pmatrix} a & b \\ c & -a \end{pmatrix}\) である。

  3. 2乗した行列の対角成分は \(\cos^2\theta + \sin^2\theta = 1\)、非対角成分は \(0\) である。不動ベクトルは \((\cos\frac\theta2, \sin\frac\theta2)\) であるから、これは原点を通り角 \(\frac\theta2\) をなす直線に関する鏡映（reflection）である。

  4. \(\mathbf{M} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\) とすると \(\mathbf{M}^2 = \begin{pmatrix} a^2 + bc & b(a + d) \\ c(a + d) & d^2 + bc \end{pmatrix}\) である。これから \((a + d)\mathbf{M}\) を引き、\((ad - bc)\mathbf{I}\) を加えると \(\mathbf{0}\) になる。

7.2 向きを変えずに伸ばす

  1. \(\mathbf{u} \neq \mathbf{0}\) で \(\mathbf{Mu} = \lambda\mathbf{u}\) となるためには \(\det(\mathbf{M} - \lambda\mathbf{I}) = 0\) が必要であり、これがその2次方程式である。ここではトレース（trace）が \(6\)、行列式（determinant）が \(\frac{4}{25}(54 - 4) = 8\) であるから、\(\lambda^2 - 6\lambda + 8 = 0\) となる。固有値（eigenvalue）は \(\lambda = 2\)（\((1, 2)\) に対して）と \(4\)（\((2, -1)\) に対して）である。

  2. \(\mathbf{v} \cdot \mathbf{Mu} = \lambda\,\mathbf{v} \cdot \mathbf{u}\) であり、\(\mathbf{M}\) は対称行列（symmetric matrix）であるから \(\mathbf{v} \cdot \mathbf{Mu} = \mathbf{Mv} \cdot \mathbf{u} = \mu\,\mathbf{v} \cdot \mathbf{u}\) である。したがって \((\lambda - \mu)\,\mathbf{u} \cdot \mathbf{v} = 0\) となる。

  3. 特性方程式（characteristic equation）\(\lambda^2 - 2\lambda\cos\theta + 1 = 0\) の判別式（discriminant）は \(-4\sin^2\theta\) であり、\(\theta\) が \(\pi\) の整数倍でない限り負である。固有値は \(\mathrm{e}^{\pm\mathrm{i}\theta}\) である。

  4. \((1, 0) = \frac15(1, 2) + \frac25(2, -1)\) であるから、\(T^n(1, 0) = \frac{2^n}{5}(1, 2) + \frac{2 \cdot 4^n}{5}(2, -1) = \frac15\bigl(2^n + 4^{n+1},\ 2^{n+1} - 2 \cdot 4^n\bigr)\) である。\(n = 1\) のとき、これは期待どおり \((\frac{18}{5}, -\frac45)\) となる。

7.3 行列式を行列式たらしめるもの

  1. \((\det\mathbf{MN})^3 = (\det\mathbf{M})^3(\det\mathbf{N})^3\) であるが、\((\det\mathbf{J})^3 = -1 \neq 1\) である。関数 \(|\det\mathbf{M}|\) は乗法的（multiplicative）であるが、\(|\det\mathbf{J}| = 1\) である。

  2. \(\begin{pmatrix} a & \lambda a \\ c & \lambda c \end{pmatrix} = \begin{pmatrix} a & 0 \\ c & 0 \end{pmatrix}\begin{pmatrix} 1 & \lambda \\ 0 & 0 \end{pmatrix}\) であり、2番目の因子の第2行は第1行の \(0\) 倍であるから、その \(\mathrm{f}\) の値は \(0\) である。

  3. \(\begin{pmatrix} k & 0 \\ 0 & 1 \end{pmatrix} = \mathbf{JK}_k\mathbf{J}\) であるから、その値は \(\mathrm{f}(\mathbf{J})^2\mathrm{f}(\mathbf{K}_k) = \mathrm{f}(\mathbf{K}_k)\) である。また \(\mathbf{K}_k\mathbf{K}_l = \mathbf{K}_{kl}\) である。

  4. 行基本変形（row reduction）により、任意の正則（invertible）行列は基本行列（elementary matrix）の積として表される。基本行列とは、行の入れ替え（\(\mathbf{J}\)）、行の定数倍（\(\mathbf{K}_k\) または \(\mathbf{JK}_k\mathbf{J}\)）、せん断（shear）（\(\begin{pmatrix} 1 & t \\ 0 & 1 \end{pmatrix}\) またはその \(\mathbf{J}\) による共役）である。せん断は \(\mathrm{f} = 1\) を満たす（小問 (iv) と同様に、\(\mathbf{K}^{-1}\mathbf{PK}\) を用いる）。また \(\mathbf{J}\) はせん断と \(\mathbf{K}_{-1}\) の積であるから、\(\mathrm{f}(\mathbf{K}_{-1}) = \mathrm{f}(\mathbf{J}) = -1\) である。よって \(\mathrm{g}(k) = \mathrm{f}(\mathbf{K}_k)\) とおくと \(\mathrm{f}(\mathbf{M}) = \mathrm{g}(\det\mathbf{M})\) である。特異（singular）な \(\mathbf{M}\) については、小問 (iii) より \(\mathrm{f}(\mathbf{M}) = 0\) である。

7.4 もとに戻る行列

  1. \(|1 + \mathrm{e}^{\mathrm{i}\phi}|^2 = 2 + 2\cos\phi = 1\) より \(\phi = \pm\frac{2\pi}{3}\) であるから、\(\mathbf{R}^3 = \mathbf{I}\) である。\(\mathbf{S}\) について：その固有値は \(1\) の3乗根である。もし両方とも \(1\) ならば、\(x^3 - 1\) は相異なる根をもつので、\(\mathbf{S}\) は対角化可能（diagonalisable）であり、\(\mathbf{I}\) に等しくなる。実行列の実数でない固有値は共役（conjugate）な組で現れるから、固有値は \(\mathrm{e}^{\pm2\pi\mathrm{i}/3}\) であり、\(\det\mathbf{S} = 1\)、\(\operatorname{tr}\mathbf{S} = -1\) である。

  2. 固有値は原始6乗根（primitive sixth root）\(\mathrm{e}^{\pm\mathrm{i}\pi/3}\) でなければならない（6乗根をほかに選んで共役と組にすると、\(\mathbf{M}^2 = \mathbf{I}\) または \(\mathbf{M}^3 = \mathbf{I}\) となる）。よって \(\operatorname{tr}\mathbf{M} = 1\)、\(\det\mathbf{M} = 1\) である。

  3. 固有値は積が \(1\) である1の冪根（root of unity）であるから、\(\mathrm{e}^{\pm\mathrm{i}\theta}\)（または両方とも \(\pm1\)）であり、トレース \(2\cos\theta\) は \([-2, 2]\) に属する整数である。位数（order）\(6\) の例：\(\begin{pmatrix} 1 & -1 \\ 1 & 0 \end{pmatrix}\)。

  4. \(\mathbf{M}^3 = (t^2 - d)\mathbf{M} - td\mathbf{I}\)、\(\mathbf{M}^4 = (t^3 - 2td)\mathbf{M} - d(t^2 - d)\mathbf{I}\) である。\(\mathbf{M}^4 = -\mathbf{I}\) となるためには（\(\mathbf{M}\) は \(\mathbf{I}\) の定数倍ではありえないので）、\(t(t^2 - 2d) = 0\) かつ \(d(t^2 - d) = 1\) である。\(t = 0\) とすると \(-d^2 = 1\) となり不可能である。よって \(t^2 = 2d\)、\(d^2 = 1\) であり、\(d = 1\)、\(t^2 = 2\) である。

7.5 三次元の回転

  1. \(z \mapsto a + \mathrm{e}^{\mathrm{i}\theta}(z - a)\) である。合成（composite）は \(z \mapsto \mathrm{e}^{\mathrm{i}(\theta + \phi)}z + k\)、ただし \(k = \mathrm{e}^{\mathrm{i}\phi}a(1 - \mathrm{e}^{\mathrm{i}\theta}) + b(1 - \mathrm{e}^{\mathrm{i}\phi})\) である。\(\mathrm{e}^{\mathrm{i}(\theta+\phi)} \neq 1\) ならば、これは不動点（fixed point）\(c = \frac{k}{1 - \mathrm{e}^{\mathrm{i}(\theta+\phi)}}\) をもつ。\(\theta + \phi = 2\pi\) ならば、これは \((b - a)(1 - \mathrm{e}^{-\mathrm{i}\theta})\) による平行移動（translation）である。

  2. \(\begin{pmatrix} 0 & 0 & 1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}\)：これは \((1, 1, 1)\) を固定し、トレースは \(0 = 1 + 2\cos120^\circ\) であり、\(\mathbf{i} \to \mathbf{j} \to \mathbf{k} \to \mathbf{i}\) と移す。

  3. \(\mathbf{K}^2\mathbf{r} = \mathbf{n} \times (\mathbf{n} \times \mathbf{r}) = (\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\) であり、さらに \(\mathbf{K}^3\mathbf{r} = \mathbf{n} \times \bigl((\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\bigr) = -\mathbf{Kr}\) である。級数において、奇数乗の項からは \((\theta - \frac{\theta^3}{3!} + \cdots)\mathbf{K} = \sin\theta\,\mathbf{K}\) が、偶数乗の項（\(\mathbf{K}^2\) 以降）からは \((\frac{\theta^2}{2!} - \frac{\theta^4}{4!} + \cdots)\mathbf{K}^2 = (1 - \cos\theta)\mathbf{K}^2\) が得られる。

  4. 合成は交線上のすべての点を固定し、行列式は \((-1)^2 = 1\) である。その交線に垂直な各平面上では、これは角 \(\alpha\) をなす2直線に関する鏡映の積であり、\(2\alpha\) の回転である。

7.6 双曲的回転と相対性理論

  1. \(T(u)T(w)\) の成分は \(\cosh u\cosh w + \sinh u\sinh w = \cosh(u + w)\) および \(\sinh u\cosh w + \cosh u\sinh w = \sinh(u + w)\) である。よって \(T(u)^{-1} = T(-u)\) である。

  2. \(\tanh u = 0.8\) より \(u = \frac12\ln\frac{1.8}{0.2} = \ln3 \approx 1.099\)、\(\cosh u = \frac12(3 + \frac13) = \frac53\) である。宇宙船上では \(10 \times \frac35 = 6\) 年が経過する。

  3. 面積は \(\frac12\oint(x\,\mathrm{d}y - y\,\mathrm{d}x)\) である。直線の辺からの寄与はなく、双曲線（hyperbola）に沿っては \(x = \cosh s\)、\(y = \sinh s\) として被積分関数が \((\cosh^2s - \sinh^2s)\,\mathrm{d}s = \mathrm{d}s\) となるので、\(\frac v2\) が得られる。\(T\) の行列式は \(\cosh^2u - \sinh^2u = 1\) であるから、\(T\) は面積を保つ。また \(T\) は双曲線をそれ自身に移し、パラメータ \(v\) の点を \(v + u\) の点に移す。

  4. \(x' + y' = (\cosh u + \sinh u)(x + y) = \mathrm{e}^up\)、\(x' - y' = \mathrm{e}^{-u}q\) であり、また \(x^2 - y^2 = pq\) である。この座標では \(T\) はスクイーズ写像（squeeze mapping）である。すなわち漸近線（asymptote）\(y = x\) に沿って \(\mathrm{e}^u\) 倍に引き伸ばし、\(y = -x\) に沿って \(\mathrm{e}^{-u}\) 倍に縮める写像であり、各双曲線 \(pq =\) 一定 に沿って点を滑らせる。

7.7 決して変わらない量

  1. \(\dot a = -Ct = -tc\)、\(\dot d = Ct = tc\)、\(\dot c = 0\)、\(\dot b = (A - D)t - Ct^3 = t(a - d)\) であり、これは \(\mathbf{MN} - \mathbf{NM} = t\begin{pmatrix} -c & a - d \\ 0 & c \end{pmatrix}\) と一致する。

  2. \(\dot{\mathbf{S}} = \mathbf{SN}\) を用いると、\(\dot{\mathbf{M}} = -\mathbf{S}^{-1}\dot{\mathbf{S}}\mathbf{S}^{-1}\mathbf{M}_0\mathbf{S} + \mathbf{S}^{-1}\mathbf{M}_0\dot{\mathbf{S}} = -\mathbf{NM} + \mathbf{MN}\) である。

  3. \(\mathbf{N} = \mathbf{M}^{-1}\dot{\mathbf{M}} = \begin{pmatrix} 2 & 0 \\ 0 & -1 \end{pmatrix}\) であり、\(\ln\det\mathbf{M} = 2t - t = t\) で、その導関数は \(1 = \operatorname{tr}\mathbf{N}\) である。

  4. トレースの巡回性（cyclic property）により \(\frac{\mathrm{d}}{\mathrm{d}t}\operatorname{tr}(\mathbf{M}^k) = \sum_j\operatorname{tr}(\mathbf{M}^j\dot{\mathbf{M}}\mathbf{M}^{k-1-j}) = k\operatorname{tr}(\mathbf{M}^{k-1}\dot{\mathbf{M}})\) であり、再び巡回性により \(\operatorname{tr}(\mathbf{M}^{k-1}(\mathbf{MN} - \mathbf{NM})) = \operatorname{tr}(\mathbf{M}^k\mathbf{N}) - \operatorname{tr}(\mathbf{M}^{k-1}\mathbf{NM}) = 0\) である。

7.8 四つの平方数

  1. \((L_1, L_2, L_3, L_4) = (1, 4, 4, 4)\) であり、\(1 + 16 + 16 + 16 = 49\) である。これは \(7^2 + 0^2 + 0^2 + 0^2\) とは異なる表し方である。

  2. \(c = d = r = s = 0\) とすると、\(L_1 = ap - bq\)、\(L_2 = aq + bp\)、\(L_3 = L_4 = 0\) となり、これは \((a^2 + b^2)(p^2 + q^2) = (ap - bq)^2 + (aq + bp)^2\) である。

  3. 平方数は \(8\) を法として（modulo \(8\)）\(0\)、\(1\)、\(4\) のいずれかである。これらを3つ足した和は \(8\) を法として \(0, 1, 2, 3, 4, 5, 6\) となり、決して \(7\) にはならない。

  4. \(2 = (\pm1)^2 + (\pm1)^2 + 0^2 + 0^2\) である。0でない2つの位置の選び方が（\(6\) 通り）、それらの符号の選び方が（\(4\) 通り）あり、計 \(24\) 通りとなる。\(2\) は \(4\) で割り切れないから、ヤコビ（Jacobi）の公式により \(8\sigma(2) = 8 \times 3 = 24\) である。

7.9 正多面体はただ五つ

  1. \(h = 2m + 2n - mn\) とすると、\(V = \frac{4m}{h}\)、\(E = \frac{2mn}{h}\)、\(F = \frac{4n}{h}\) である。\(m\) と \(n\) を入れ替えると \(V\) と \(F\) が入れ替わる。立方体と正八面体は互いに双対（dual）であり、正十二面体と正二十面体も同様である。正四面体は自己双対（self-dual）である。

  2. \(F = 32\)、\(E = \frac12(12 \cdot 5 + 20 \cdot 6) = 90\)、\(V = \frac13(180) = 60\) であり、\(60 - 90 + 32 = 2\) である。一般に、五角形が \(P\) 個、六角形が \(H\) 個のとき、\(E = \frac12(5P + 6H)\)、\(V = \frac13(5P + 6H)\) であるから、\(V - E + F = -\frac16(5P + 6H) + P + H = \frac P6\) となる。これが \(2\) に等しいので、\(P = 12\) である。

  3. （穴の開いた）上面と底面をそれぞれ4つの台形（trapezium）に分割する。すると \(V = 16\)、\(F = 4 + 4 + 4 + 4 = 16\)、\(E = 12 + 12 + 8 = 32\) となり、\(V - E + F = 0\) である。

  4. \(180^\circ n(1 - \frac2m) < 360^\circ\) は \(n(m - 2) < 2m\)、すなわち \(mn - 2m - 2n < 0\)、つまり \((m - 2)(n - 2) < 4\) である。\(m, n \geq 3\) のもとで、解は \((3, 3)\)、\((3, 4)\)、\((4, 3)\)、\((3, 5)\)、\((5, 3)\) である。
