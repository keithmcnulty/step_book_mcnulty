第7章 \(\cdot\) 序論

空間の変換

われわれは基底を用いずに考え、基底を用いずに書く。だが、いざという段になると、研究室の扉を閉めて猛烈な勢いで行列の計算をするのだ。

— アーヴィング・カプランスキー（Irving Kaplansky）、自身とポール・ハルモス（Paul Halmos）の線形代数への取り組み方について

学校では、行列はふつう連立方程式（simultaneous equations）を解くための道具として、あるいは点を変換するための手順として登場する。すなわち、行列に列ベクトル（column vector）を掛け、新しい座標を読み取るというものである。どちらも役に立つが、これらの見方は、行列が数学で最も重要な考え方の一つである理由を覆い隠してしまう。行列とは線形変換（linear transformation）、すなわち空間を引き伸ばし、回転し、鏡映し、ずらす（剪断する）方法である。そして行列は、数と同じように足したり、掛けたり、累乗したり、微分したりすることができる。ところが、行列は数とは違う。その積は掛ける順序に依存し、零でない行列どうしを掛けて零になることもある。さらに行列には、隠れた不変量（invariant）——トレース（trace）、行列式（determinant）、固有値（eigenvalue）——があり、それらは行列がどのように書き表されるかによらず、その本質的なふるまいをとらえている。

線形代数はなぜ重要か

線形代数（linear algebra）は、おそらく数学の中で最も広く使われている分野である。ビデオゲームから映画のアニメーションに至るまで、あらゆるコンピュータグラフィックスのエンジンは行列を掛け合わせる機械である。キャラクターのあらゆる回転も、あらゆるカメラアングルも、あらゆる透視投影も、一つの行列なのである。インターネットの検索エンジンや推薦システムは、固有ベクトル（eigenvector）の上に築かれている。技術者は橋や建物の振動数を固有値から求め、統計学者はデータの中の主要なパターンを固有値によって見つけ出す。量子力学は、すべて線形代数の言葉で書かれている。そして現代の機械学習は、その核心において、膨大な量の行列の掛け算にほかならない。

この遍在性には理由がある。線形の問題は完全に解くことのできる問題であり、ほとんどすべての非線形の問題は、十分に拡大して見れば線形に見える。これが微積分の考え方であり、それはつまり、線形代数がほとんどあらゆるものの局所的なふるまいを記述する言語だということである。

大学で出会うこと

線形代数は、解析学（analysis）と並んで大学1年目の二本柱の一つである。ベクトル空間（vector space）——足し算とスカラー倍ができる集合のことで、平面や3次元空間はその最初の例にすぎない——と、それらの間の線形写像（linear map）に出会い、行列とは座標を用いて書き表した線形写像にすぎないことを学ぶ。行列式、固有値と固有ベクトル、そして対称行列は回転によって対角化（diagonalise）できることを述べるスペクトル定理（spectral theorem）を学ぶ。その後の講義では、これらがいたるところで使われる。微分方程式（第 8 章）において、幾何学（回転や鏡映が群をなす）において、連続的な対称性を記述するリー群（Lie group）の理論において、そして無限次元の線形代数である関数解析（functional analysis）においてである。

この章を貫く問い

三つの大きな問い

  1. 行列はどのような点で数に似ていて、どのような点で異なるのか？ 算術のどの規則が生き残り、どの規則が成り立たなくなるのか？

  2. 行列は実際には何をしているのか？ 変換の幾何をどのようにして見ることができ、どのような数が座標によらずにそれをとらえるのか？

  3. 何が変わらずに保たれるのか？ 変換や運動によってどのような量が保存され、それらは何を教えてくれるのか？

この章は行列の代数の規則（第 7.1 節）から始まり、続いて変換の幾何へと進む。固有ベクトル、行列式、有限位数（finite order）の行列、3次元の回転、そして特殊相対性理論（special relativity）の双曲的回転（hyperbolic rotation）である。さらに、時間発展する行列の保存量（conserved quantity）、行列式から得られる四平方恒等式（four-square identity）を扱い、最後に、数え上げの議論であるオイラー（Euler）の公式によって正多面体（Platonic solids）を分類して締めくくる。

この章の読み方

この章に出てくるすべての行列について、それが何をするのかを図に描いてみよう。単位正方形、単位円、あるいはいくつかのベクトルをとり、それらの像をスケッチするのである。2分ほどのスケッチで、計算を始める前に答え（固有ベクトル、反例、不変な直線）が見えてくることがよくあり、また後で計算を検算する助けにもなる。
