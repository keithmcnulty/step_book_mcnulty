7.5

三次元の回転

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第7章章全体のPDF
問題

STEP III 2022、第7問

先に進む前に問題を読んでおこう。問題は、OCRが配布している2022年のSTEP問題一式（zipファイル）のSTEP IIIに収録されている： www.ocr.org.uk/Images/696587-2022-past-papers.zip

導入

2次元では、点の回転（rotation）は簡単である。\(e^{\mathrm{i}\theta}\) を掛ければよい。3次元ではずっと難しくなる。掛けるべき1つの複素数は存在せず、異なる軸のまわりの回転は可換（commute）ではない。しかも「点 \((1, 2, 2)\) を通る軸のまわりに \(37^\circ\) 回転する」という行列を書き下すのは、いかにも骨が折れそうに見える。

この問題では、任意の軸と任意の角に対するその行列を、外積（cross product）から組み立てる。得られる結果はロドリゲスの回転公式（Rodrigues’ rotation formula）であり、1840年にオランド・ロドリゲス（Olinde Rodrigues）が発表したものである。この公式はロボット工学、コンピュータグラフィックス、宇宙機の航法で日常的に使われており、美しい事実を明らかにしてくれる。すなわち、\(\mathbf{n}\) との外積をとることは「\(\mathbf{n}\) のまわりの \(90^\circ\) 回転」であり、\(\mathbf{n}\) のまわりのあらゆる回転はそこから組み立てられる。ちょうど \(e^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta\) が \(\mathrm{i}\) を掛ける操作から組み立てられているのと同じである。

取りかかる前に

\(\mathbf{r}\) が \(\mathbf{n}\) に垂直なとき、\(\mathbf{n} \times \mathbf{r}\) は幾何学的にどのように見えるか。\(\mathbf{r}\) が \(\mathbf{n}\) に平行なときはどうか。

\(\mathbf{r} \parallel \mathbf{n}\) ならば \(\mathbf{n} \times \mathbf{r} = \mathbf{0}\) である。\(\mathbf{r} \perp \mathbf{n}\) ならば、\(\mathbf{n} \times \mathbf{r}\) は \(\mathbf{r}\) と同じ長さをもち（\(|\mathbf{n}| = 1\) でなす角が \(90^\circ\) だから）、両者に垂直であり、右手の法則（right-hand rule）により、\(\mathbf{r}\) を \(\mathbf{n}\) のまわりに（\(\mathbf{n}\) の先から見て）反時計回りに \(90^\circ\) 回転したものである。したがって \(\mathrm{f}\) は \(\mathbf{r}\) の \(\mathbf{n}\) 方向の成分（component）を消し、垂直な成分を \(90^\circ\) 回転させる。この描像で問題全体が説明できる。

順を追って解く

段階 1 2回外積をとる

\(\mathrm{f}(\mathbf{r}) = \mathbf{n} \times \mathbf{r} = (bz - cy,\ cx - az,\ ay - bx)\) である。これにもう一度 \(\mathbf{n} = (a, b, c)\) との外積をとると、\(\mathrm{f}(\mathrm{f}(\mathbf{r}))\) の \(x\) 成分は \[b(ay - bx) - c(cx - az) = -x(b^2 + c^2) + aby + acz. \qed\] \(a^2 + b^2 + c^2 = 1\) より、これは \(-x(1 - a^2) + aby + acz = a(ax + by + cz) - x\) となり、\((\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\) の \(x\) 成分に等しい。ほかの成分も対称性から同様に得られるので、\(\mathrm{f}(\mathrm{f}(\mathbf{r})) = (\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\) である。■

\(\mathbf{r} = \mathbf{r}_\parallel + \mathbf{r}_\perp\) と書く。ここで \(\mathbf{r}_\parallel = (\mathbf{n}.\mathbf{r})\mathbf{n}\) は \(\mathbf{n}\) 方向の成分である。\(\mathrm{f}(\mathrm{f}(\mathbf{r}))\) をこれらを用いて表すとどうなるか。

\(\mathrm{f}(\mathrm{f}(\mathbf{r})) = \mathbf{r}_\parallel - \mathbf{r} = -\mathbf{r}_\perp\) である。\(\mathrm{f}\) を2回施すと、平行な部分は消え、垂直な部分は \(\mathbf{n}\) のまわりに \(180^\circ\) 回転する。これは単に向きを反転させることにほかならない（図 7.5.1）。これは \(\mathrm{i}^2 = -1\) の類似である。

段階 2 回転

\(\mathrm{g}(\mathbf{n})\) を計算せよ。次に、\(\mathbf{r} \perp \mathbf{n}\) のとき、そのような \(\mathbf{r}\) に対して \(\mathrm{f}(\mathrm{f}(\mathbf{r})) = -\mathbf{r}\) となることを用いて \(\mathrm{g}(\mathbf{r})\) を計算せよ。

\(\mathrm{f}(\mathbf{n}) = \mathbf{n} \times \mathbf{n} = \mathbf{0}\) より \(\mathrm{g}(\mathbf{n}) = \mathbf{n}\) である。つまり軸は動かない。\(\mathbf{r} \perp \mathbf{n}\) ならば \(\mathrm{f}(\mathrm{f}(\mathbf{r})) = -\mathbf{r}\) であり、 \[\mathrm{g}(\mathbf{r}) = \mathbf{r} + \sin\theta\,(\mathbf{n} \times \mathbf{r}) - (1 - \cos\theta)\mathbf{r} = \cos\theta\,\mathbf{r} + \sin\theta\,(\mathbf{n} \times \mathbf{r}).\] \(\mathbf{n} \times \mathbf{r}\) は \(\mathbf{r}\) を \(\mathbf{n}\) のまわりに \(90^\circ\) 回したもので長さも等しいから、これは \(\mathbf{r}\) を \(\mathbf{n}\) のまわりに角 \(\theta\) だけ回転したものであり、平面における \((\cos\theta + \mathrm{i}\sin\theta)z\) とまったく同じである。\(\mathrm{g}\) は線形（linear）であり、どのベクトルも \(\mathbf{n}\) の実数倍と \(\mathbf{n}\) に垂直なベクトルの和として表せるので、\(\mathrm{g}\) は原点を通り \(\mathbf{n}\) 方向を向く軸のまわりの角 \(\theta\) の回転である（\(\mathbf{n}\) の先端から見て反時計回り）。■

段階 3 鏡映

小問 (i) を用いて \(\mathrm{h}(\mathbf{s}) = -\mathbf{s} - 2\mathrm{f}(\mathrm{f}(\mathbf{s}))\) を簡単にせよ。\(\mathbf{n}\) 方向のベクトルと、\(\mathbf{n}\) に垂直なベクトルは、それぞれどう変換されるか。

\(\mathrm{h}(\mathbf{s}) = -\mathbf{s} - 2\bigl((\mathbf{n}.\mathbf{s})\mathbf{n} - \mathbf{s}\bigr) = \mathbf{s} - 2(\mathbf{n}.\mathbf{s})\mathbf{n}\) である。\(\mathbf{n}\) に垂直なベクトルは変わらず、\(\mathrm{h}(\mathbf{n}) = -\mathbf{n}\) となる。よって \(\mathrm{h}\) は原点を通り \(\mathbf{n}\) に垂直な平面に関する鏡映（reflection）である。■

振り返り

  • 平行な部分と垂直な部分に分解する。 \(\mathbf{r}\) を \(\mathbf{n}\) に沿う成分とそれを横切る成分に分けた途端、どの段階も明快になった。

  • 線形性が作業を減らす。 線形写像（linear map）を特定するには、うまく選んだいくつかのベクトルをどう写すかがわかれば十分である。

  • 複素数の類似。 \(\mathbf{n}\) に垂直なベクトルの上では、\(\mathrm{f}\) は \(\mathrm{i}\) を掛ける操作のようにふるまう。すなわち \(\mathrm{f}^2 = -1\) であり、\(\mathrm{g} = \cos\theta + \sin\theta\,\mathrm{f}\) である。

背後にある数学

オイラーの回転定理

原点を固定する3次元空間の回転はすべて、原点を通るある軸のまわりの回転である。これはオイラー（Euler）が1775年に証明した。行列の言葉でいえば、\(3 \times 3\) の回転行列はすべて固有値（eigenvalue）\(1\) の固有ベクトル（eigenvector）をもち、それが軸である。ロドリゲスの公式はその逆を与える。すなわち、任意の軸 \(\mathbf{n}\) と角 \(\theta\) に対して、回転行列は \[\mathbf{R} = \mathbf{I} + \sin\theta\,\mathbf{K} + (1 - \cos\theta)\,\mathbf{K}^2, \qquad \mathbf{K} = \begin{pmatrix} 0 & -c & b \\ c & 0 & -a \\ -b & a & 0 \end{pmatrix},\] で与えられる。ここで \(\mathbf{K}\) は \(\mathbf{r} \mapsto \mathbf{n} \times \mathbf{r}\) の行列である。\(\mathbf{K}^3 = -\mathbf{K}\) であるから、指数級数（exponential series）\(e^{\theta\mathbf{K}} = \mathbf{I} + \theta\mathbf{K} + \frac{\theta^2}{2!}\mathbf{K}^2 + \cdots\) はちょうどこの公式にまとまる。これは \(e^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta\) の3次元版である。回転と「無限小回転」\(\mathbf{K}\) の指数関数とのこの結びつきが、リー群（Lie groups）の理論の出発点である。

回転は可換ではない

本を水平に持ち、鉛直な軸のまわりに \(90^\circ\) 回転させてから、水平な軸のまわりに \(90^\circ\) 回転させてみよう。次に最初からやり直し、2つの回転を逆の順序で行う。本は異なる位置に落ち着く。2次元とは異なり、3次元における回転の合成（composition）は可換ではない。これが 第 6.7 節 の四元数（quaternions）が役に立つ理由の1つである。\(\mathbf{n}\) のまわりの角 \(\theta\) の回転は四元数 \(\cos\frac\theta2 + \sin\frac\theta2(a\mathrm{i} + b\mathrm{j} + c\mathrm{k})\) に対応し、回転の合成は四元数の積になり、非可換性がはじめから組み込まれている。ロドリゲス自身は1840年の論文で、ハミルトン（Hamilton）が四元数を考案する3年前に、回転の合成公式を見いだしていた。

思考のスキル

不変な部分に分ける

変換を理解するには、その変換が単純に扱う部分に空間を分けよ。ここでは、軸（そのまま残る）と、それに垂直な平面（回転する）である。

これは 第 7.2 節 の固有ベクトルと同じ考え方である。変換が保つ部分空間を見つけ、それぞれの部分の上で変換を調べるのである。

次の一歩

  1. 平面の回転。 STEP III 2017、第2問 に挑戦せよ。複素数を用いて、平面の2つの回転を合成すると、1つの例外を除いて回転になることを示す問題である。その例外を見つけ、そのとき合成が何になるかを求めよ。

  2. 具体的な回転。 方向 \((1, 1, 1)\) の軸のまわりの \(120^\circ\) 回転の行列を求めよ。それが座標軸を巡回的に入れ替えることを示せ。

  3. \(\mathbf{K}\) のべき。 \(\mathbf{K}^2\mathbf{r} = (\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\) および \(\mathbf{K}^3 = -\mathbf{K}\) を示し、指数級数からロドリゲスの公式を導け。

  4. 2回の鏡映で回転になる。 原点を通り、互いに角 \(\alpha\) をなす2つの平面に関して順に鏡映を行うと、それらの交線のまわりの角 \(2\alpha\) の回転になることを示せ。

さらに学ぶために

  • Simon Altmann, Rotations, Quaternions, and Double Groups（Dover）。3次元の回転についての決定版で、ロドリゲスの貢献も扱っている。

  • Simon Altmann, 「Hamilton, Rodrigues, and the quaternion scandal」, Mathematics Magazine 62 (1989)。短く生き生きとした歴史の読み物。

  • John Stillwell, Naive Lie Theory（Springer）。学部生向けに回転、四元数、リー群を解説している。
