第7章 · 線形代数と幾何

学んだこと

本章は、行列（matrix）とはそれ自体で独自の性格をもつ空間の変換である、という話から始まり、三つの問いを立てた。行列は数とどこが似ていてどこが違うのか、行列は実際に何をしているのか、そして何が変わらずに保たれるのか、である。本章の九つの問題が明らかにしたことをここでまとめる。

1. 行列は数とどこが似ていて、どこが違うのか

行列は足し算もかけ算もできるが、第 7.1 節 では、なじみのある規則のうちどれが成り立たなくなるかを見た。かけ算は可換（commutative）ではないので、\((\mathbf{A} - \mathbf{B})(\mathbf{A} + \mathbf{B})\) は \(\mathbf{A}^2 - \mathbf{B}^2\) になるとは限らない。零因子（zero divisor）が存在するので、\(\mathbf{AB} = \mathbf{0}\) であっても \(\mathbf{BA} = \mathbf{0}\) とは限らない。さらに、行列の二次方程式は無限に多くの解をもちうる。こうした規則の破れには、いずれも行列が平面に対して何をするかという観点から幾何学的な説明がついた。一方で決定的に重要なのは、行列式（determinant）が積を保つこと、すなわち \(\det(\mathbf{AB}) = \det\mathbf{A}\det\mathbf{B}\) が成り立つことである。第 7.3 節 では、この性質が本質的に行列式を特徴づけることを示し、第 7.8 節 ではこれを用いてオイラー（Euler）の四平方恒等式（four-square identity）を証明した。これは、すべての自然数は四つの平方数の和で表せるというラグランジュ（Lagrange）の定理の鍵となる段階である。

2. 行列は実際に何をしているのか

いくつかの節では、適切な視点を見つけることでこの問いに答えた。

  • 固有ベクトル（eigenvector）（第 7.2 節）は、行列によって向きが変わらない方向である。固有ベクトルを座標軸にとると、対称行列（symmetric matrix）は単なる引き伸ばしにすぎず、円の像は楕円（ellipse）となって、その軸と面積を直接読み取ることができる。

  • 行列式（第 7.3 節）は符号付きの面積の拡大率である。ずれ変換（shear）は面積を保ち、入れ替えは向き（orientation）を反転させ、特異行列（singular matrix）は平面を押しつぶして平らにしてしまう。

  • トレースと行列式（第 7.4 節）は、ケイリー・ハミルトンの定理（Cayley–Hamilton theorem）を通して、行列が数回の操作の後に単位行列（identity）に戻るかどうかを決定する。\(\mathbf{M}^8 = \mathbf{I}\) をみたす行列は回転とは限らないが、それは斜交座標で見た回転なのである。そして整数行列のトレース（trace）は整数であるから、結晶は五回対称性をもちえない。

  • 三次元の回転（第 7.5 節）は、ロドリゲスの公式（Rodrigues’ formula）によって外積（cross product）から組み立てられる。これは \(e^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta\) の三次元版である。

  • 双曲線回転（hyperbolic rotation）（第 7.6 節）は、点を双曲線に沿って動かし、その双曲角を足し合わせる。これは特殊相対性理論（special relativity）におけるローレンツ・ブースト（Lorentz boost）であり、その不変直線は光の経路である。

3. 何が変わらずに保たれるのか

不変量（invariant）はいたるところに現れた。回転は \(x^2 + y^2\) を保ち、ローレンツ・ブーストは \(x^2 - y^2\) を保ち、相似な行列（similar matrices）は同じトレースと行列式をもつ。第 7.7 節 では、\(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\) にしたがって時間発展する行列は、成分がどれほど変化してもトレースと行列式、したがって固有値（eigenvalue）を一定に保った。これがソリトン（soliton）の保存則（conservation law）の背後にある仕組みである。そして 第 7.9 節 では、不変量は \(V - E + F = 2\) という一つの数であった。これはすべての凸多面体（convex polyhedron）について成り立ち、正多面体をわずか五種類に絞り込む。この数、すなわちオイラー標数（Euler characteristic）は、位相幾何学（topology）における最初の不変量の一つであった。

この先へ

  • 第 13.7 節 では、共分散行列（covariance matrix）の固有ベクトルが統計学に登場する。

大学入学前にさらに先へ進みたい人へ

  • 3Blue1Brown, Essence of Linear Algebra（線形代数の本質）：行列が何をしているのかを見せてくれる無料の動画シリーズ。まずはこれを見るとよい。

  • Gilbert Strang, Introduction to Linear Algebra（線形代数入門）：理解と応用を強く重視した、定番の入門書。

  • Sheldon Axler, Linear Algebra Done Right：線形写像（linear map）を中心に据えた、より抽象的なアプローチ。オンラインで無料公開されている。

  • David Richeson, Euler’s Gem（オイラーの宝石）：オイラーの公式と位相幾何学の誕生。

カプランスキー（Kaplansky）は冗談めかして、自分とハルモス（Halmos）は座標を使わずに考えるが、人目のないところでは行列を使って「猛烈に」計算している、と語った。この言葉は本章が示そうとしてきたことをよく表している。行列は具体的で計算可能なものだが、あらゆる計算の背後には幾何学（引き伸ばし、回転、射影（projection）、ブースト）があり、さらにそれをどう書き表すかによらない不変量がある。この二つの見方の間を自在に行き来できるようになることは、数学者が身につけうる最も価値のあるスキルの一つである。
