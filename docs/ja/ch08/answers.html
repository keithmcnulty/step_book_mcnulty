第8章 · 微分方程式と力学系

「次の一歩」の解答

ここに載せるのは完全な解答ではなく、簡潔な答えとヒントである。結果と鍵となるステップを示しているので、自分の解答を確かめるのに使ってほしい。答えを見る前に、それぞれの問題にきちんと取り組むこと。

8.1 解が一意でないとき

  1. \(y = v^2\) とおくと \(2vv' = \alpha v - \beta v^2\) となるので、\(v' = \frac12(\alpha - \beta v)\) であり、\(y_1 = \frac{\alpha^2}{\beta^2}\bigl(1 - \mathrm{e}^{-\beta t/2}\bigr)^2\) である。\(y = v^3\) とおくと \(v' = \frac13(\alpha - \beta v)\) であり、\(y_1 = \frac{\alpha^3}{\beta^3}\bigl(1 - \mathrm{e}^{-\beta t/3}\bigr)^3\) である。定数関数 \(y = 0\) は両辺をともに \(0\) にする。導出の途中で \(v\) で割ったときに、この解が失われたのである。

  2. \(2\sqrt h = 2\sqrt{h_0} - kt\) より \(h = \bigl(\sqrt{h_0} - \frac12kt\bigr)^2\) であり、バケツは \(T = \frac{2\sqrt{h_0}}{k}\) で空になる。\(h \equiv 0\) と、\(t \leq T\) で \(h = \frac{k^2}{4}(T - t)^2\)、\(t \geq T\) で \(h = 0\) とする関数は、どちらも方程式を満たし、\(T\) 以降は \(0\) である。空のバケツを見ても、それがいつ空になったのかはわからないのである。

  3. \(\frac{\mathrm{d}}{\mathrm{d}x}(y\mathrm{e}^{-2x}) = (y' - 2y)\mathrm{e}^{-2x} = 0\) より \(y = C\mathrm{e}^{2x}\) であり、\(y(0) = 0\) から \(C = 0\) が従う。関数 \(2y\) はリプシッツ連続（Lipschitz）である（変化量は高々 \(2|y_1 - y_2|\)）。一方、\(2\sqrt y\) は \(0\) で傾きが無限大になる。

  4. 任意の \(b \leq 0 \leq a\)（\(b = -\infty\) や \(a = \infty\) も許す）に対して、\(x < b\) で \(y = (x - b)^3\)、\(b \leq x \leq a\) で \(y = 0\)、\(x > a\) で \(y = (x - a)^3\) とすればよい。\(a = b = 0\) の場合が \(y = x^3\) である。

8.2 解かずに評価する

  1. \(\frac{\mathrm{d}}{\mathrm{d}x}\bigl((y')^2 + y^2\bigr) = 2y'(y'' + y) = 0\) より \((y')^2 + y^2 = A^2\) となり、\(|y| \leq A\) である。厳密解は \(A\cos x\) である。

  2. \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl((\theta')^2 - 2\cos\theta\bigr) = 2\theta'(\theta'' + \sin\theta) = 0\) である。静止状態から始めると \((\theta')^2 = 2(\cos\theta - \cos\theta_0) \geq 0\) なので、\(\cos\theta \geq \cos\theta_0\) である。\(|\theta_0| < \pi\) ならば、連続性により \(\theta\) は \([-|\theta_0|, |\theta_0|]\) にとどまる。\(|\theta_0| = \pi\) のときは、振り子（pendulum）は真上を向いた状態で釣り合い、そのままとどまる。\(|\theta_0| > \pi\)、たとえば \(\theta_0 = \frac{3\pi}{2}\) ならば、\(\theta''(0) = -\sin\frac{3\pi}{2} = 1 > 0\) なので、\(\theta\) は増加し始める。このとき振り子の実際の角度は \(\theta_0 - 2\pi = -\frac\pi2\) であり、そこから測って \(\pm\frac\pi2\) の間を振れるのである。

  3. \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl((y')^2 + y^2\bigr) = 2y'(y'' + y) = -4k(y')^2 \leq 0\) である。実際に \(0\) に収束（tend to zero）するが、単調性（monotonicity）だけではこれは示せない。たとえば明示的な解が必要であり、その指数 \(-k \pm \sqrt{k^2 - 1}\) の実部は負である。

  4. \((y')^2 - \frac12y^4\) は定数であり、\(-\frac12\) に等しい。これから \((y')^2 = \frac12(y^4 - 1)\) が得られるが、これは何の上界も与えない。「ポテンシャル」\(-\frac12y^4\) には \(y\) を閉じ込める井戸がなく、実際 \(y\) は有限時間で発散（blow up）する。

8.3 個体群の収穫

  1. 方程式は \(x' = \alpha^2 - (x - K)^2\) であり、これは \(y' = y(2\alpha - y)\) となる。\(w = \frac1y\) とおくと \(w' = 1 - 2\alpha w\) なので、\(w = \frac{1}{2\alpha} + C\mathrm{e}^{-2\alpha t}\) である。\(y(0) < 0\) ならば \(w(0) < 0 < \frac{1}{2\alpha}\) なので、\(w\) は有限時間で \(0\) を通過し、\(y \to -\infty\) となる。\(x\) はそれより前に \(0\) に達する。

  2. \(z = x - K\) とおくと \(z' = -(z^2 + \beta^2)\) なので、\(\tan^{-1}\frac z\beta = \tan^{-1}\frac K\beta - \beta t\) である。個体数は \(t = \frac2\beta\tan^{-1}\frac K\beta\) で \(0\)（\(z = -K\)）に達する。

  3. \(x' = x(2K - h - x)\) の平衡点（equilibrium）は \(0\) と \(2K - h\) である。\(h < 2K\) のとき、これは正の環境収容力（carrying capacity）をもつロジスティック方程式（logistic equation）であり、正の解はすべて \(2K - h\) に収束する。漁獲量は個体数が減るにつれて減るので、個体数を \(0\) に追い込むことは決してない。

  4. \(x = K + K\tanh Kt\) であり、\(\tanh Kt = \frac12\) より \(t = \frac{1}{K}\tanh^{-1}\frac12 = \frac{\ln3}{2K}\) である。

8.4 渦を巻いて円に近づく

  1. 曲線と動径のなす角 \(\psi\) は \(\tan\psi = \frac{r}{\mathrm{d}r/\mathrm{d}\theta} = -1\) を満たし、これはすべての点で同じである。つまり、曲線はすべての半直線と \(45^\circ\) で交わる。

  2. \(x\,\mathrm{d}x + y\,\mathrm{d}y = \frac12\,\mathrm{d}(x^2 + y^2) = r\,\mathrm{d}r\) である。また、\(x\,\mathrm{d}y - y\,\mathrm{d}x = r\cos\theta(\sin\theta\,\mathrm{d}r + r\cos\theta\,\mathrm{d}\theta) - r\sin\theta(\cos\theta\,\mathrm{d}r - r\sin\theta\,\mathrm{d}\theta) = r^2\,\mathrm{d}\theta\) である。

  3. \(s = r^2\) とおくと \(\dot s = 2s(1 - s)\) というロジスティック方程式になるので、任意の \(s(0) > 0\) に対して \(s \to 1\) となる。直交座標（Cartesian coordinates）で書くと、\(\dot x = x(1 - x^2 - y^2) - y\)、\(\dot y = y(1 - x^2 - y^2) + x\) である。

  4. \(\dot r = r(r - 1)(r - 2)\)、\(\dot\theta = 1\) である。\(0\) と \(1\) の間では \(\dot r > 0\)、\(1\) と \(2\) の間では \(\dot r < 0\)、\(2\) より外側では \(\dot r > 0\) である。したがって \(r = 1\) は吸引的であり、\(r = 2\) は反発的である。

8.5 グレイハウンドを追うグレイハウンド

  1. 対称性により、犬たちは常に正方形をなす。\(A\) は \(AB\) に沿って速さ \(v\) で走るので、距離を \(v\) の割合で縮める。\(B\) は \(AB\) に垂直な \(BC\) に沿って走るので、1次の範囲では距離を変えない。したがって \(AB\) はちょうど \(v\) の割合で \(s\) から \(0\) まで縮み、それにかかる時間は \(\frac sv\) である。

  2. \(r = \lambda\mathrm{e}^{-\sqrt3\theta}\) である。距離は \(v - v\cos120^\circ = \frac32v\) の割合で縮むので、時間 \(\frac{2s}{3v}\) 後に出会い、それぞれ \(\frac{2s}{3}\) だけ走る（これは \(n = 3\) のときの \(\frac{s}{2\sin^2(\pi/n)}\) と一致する）。

  3. 1周するごとに \(r\) は \(\mathrm{e}^{-2\pi} \approx \frac{1}{535}\) 倍になる。1周後には約 \(19\) cm、2周後には約 \(0.35\) mm となるので、2周で十分である。

  4. 2匹の犬は互いに向かってまっすぐ走り、時間 \(\frac{s}{2v}\) 後に中央で出会う。このとき公式は破綻する。\(\tan\frac\pi2\) は無限大であり、これはまったく回転しないという事実に対応している。

8.6 量子振動子

  1. これは（面倒ではあるが）直接の微分計算である。あるいは問4から従う。\(2\lambda = \omega\) のとき、\(\int y_0y_2 = \int(2\omega x^2 - 1)\mathrm{e}^{-\omega x^2}\,\mathrm{d}x = 2\omega \cdot \frac{1}{2\omega}\sqrt{\frac\pi\omega} - \sqrt{\frac\pi\omega} = 0\) である。

  2. \(y'' = (4\lambda^2x^2 - 2\lambda)y\) なので、方程式が成り立つには \(4\lambda^2 = \omega^2\) かつ \(2\lambda = (2\nu + 1)\omega\) が必要である。（減衰するように）\(\lambda = \frac\omega2 > 0\) とすると、\(\nu = 0\) である。

  3. \(\frac{\mathrm{d}}{\mathrm{d}x}(y_my_n' - y_ny_m') = y_my_n'' - y_ny_m'' = (m^2 - n^2)y_my_n\) である。これを \(0\) から \(\pi\) まで積分する。\(y_m\) と \(y_n\) は両端で \(0\) になるので左辺は \(0\) となり、また \(m^2 \neq n^2\) である。

  4. \(c = (2n + 1)\omega\) とおくと、\(y_n'' = (\omega^2x^2 - c)y_n\) である。\(z = \omega xy_n - y_n'\) を2回微分し、この式（とその導関数）を用いると \(z'' - \omega^2x^2z = -(c + 2\omega)z\) が得られ、\(c + 2\omega = (2n + 3)\omega\) である。\(y_0 = \mathrm{e}^{-\omega x^2/2}\) から、\(2\omega x\mathrm{e}^{-\omega x^2/2}\)、続いて \(2\omega(2\omega x^2 - 1)\mathrm{e}^{-\omega x^2/2}\) が得られ、これらはそれぞれ \(y_1\) と \(y_2\) の定数倍である。

8.7 解けるカオス

  1. (i) 数学的帰納法（induction）による。\(0 < x < 1\) ならば \(0 < x(1 - x) \leq \frac14\) なので、\(0 < kx(1 - x) < 1\) である。(ii) \(a = ka(1 - a)\) より \(k = \frac{1}{1 - a}\) である。(iii) \(x_1 = ka(1 - a) = ab\) とすると、条件 \(x_2 = a\) は \(kab(1 - ab) = a\) となる。\(k = \frac{b}{1 - a}\) を用いると、これは \(ab^3 - b^2 + 1 - a = 0\) となる。根 \(b = 1\) は不動点（fixed point）（\(x_1 = a\)）に対応するので、これを因数としてくくり出すと \(ab^2 + (a - 1)b + (a - 1) = 0\) となる。これを \(b\) について解けば、\(k = \frac{b}{1 - a}\) が得られる。同じことを別の形で言えば、\(2\)-周期軌道（2-cycle）の2点は \(k^2x^2 - k(k + 1)x + (k + 1) = 0\) の根であり、その判別式（discriminant）\(k^2(k + 1)(k - 3)\) は \(k > 3\) のときに限り正である。

  2. \(p = -1\)、\(q = 0\)、\(r = -2\) のとき、\(4pr = 8 = 8 + 2q - q^2\) である。係数を比較すると \(\alpha = \frac4p = -4\)、\(\beta = \frac{q - 4}{2p} = 2\) となるので、\(v_n = 2 - 4\sin^2(2^n\theta) = 2\cos(2^{n+1}\theta)\) であり、これは \(\phi = 2\theta\) とした \(2\cos(2^n\phi)\) である。

  3. \(u_3 = u_0\) となるには \(\sin^2 8\theta = \sin^2\theta\) が必要なので、\(8\theta = \pm\theta + k\pi\) である。\(\theta = \frac\pi7\) のとき、周期軌道は \(\sin^2\frac\pi7 \to \sin^2\frac{2\pi}{7} \to \sin^2\frac{4\pi}{7} \to \sin^2\frac{8\pi}{7} = \sin^2\frac\pi7\) である。\(\theta = \frac\pi9\) のときは \(\sin^2\frac\pi9\)、\(\sin^2\frac{2\pi}9\)、\(\sin^2\frac{4\pi}{9}\) である。写像 \(u \mapsto u_3\) は \(2^3 = 8\) 個の不動点をもつ。そのうち2個（\(0\) と \(\frac34\)）は元の写像自身の不動点なので、ちょうど周期 \(3\) の点が \(6\) 個残る。すなわち、\(3\)-周期軌道が2つある。

  4. 各ステップで \(\theta\) は2倍になり、そのたびに精度が2進数で1桁ずつ失われるので、およそ \(50\) ステップ後には、計算値は真の値と何の関係もなくなる。それでも計算値は無意味ではない。計算された数列は、わずかに異なる初期値から出発した真の軌道（orbit）の近くにとどまる（シャドーイング性（shadowing property））ので、その統計的性質は依然として正しいのである。

8.8 周期3ならばカオス

  1. \(a\)、\(b\)、\(c > 0\)、\(d < 0\) とすると、\(b = 7 - 2a\)、\(c = 7 - 2b\)、\(d = 7 - 2c\)、\(a = 7 + 2d\) である。これを解くと \(17a = 49\) となるので、周期軌道は \(\frac{49}{17} \to \frac{21}{17} \to \frac{77}{17} \to -\frac{35}{17} \to \frac{49}{17}\) であり、3点が \(I_2 = [1, 5]\) に、1点が \(I_1 = [-3, 1]\) に属する。

  2. 見つかった点の遍歴（itinerary）は \(I_2, I_2, \ldots, I_2, I_1\)（\(I_2\) にいるステップが \(n - 1 \geq 3\) 回）である。周期軌道 \(1 \to 5 \to -3\) はこの遍歴をたどれない。\(-3\) は \(I_2\) に属さないので、\(1\)（2番目の像が \(-3\)）も、\(5\)（最初の像が \(-3\)）も、\(-3\) 自身も、その点ではありえない。

  3. 被覆図（covering diagram）は、\([1, 2] \to [3, 4], [4, 5]\)、\([2, 3] \to [4, 5]\)、\([3, 4] \to [2, 3], [3, 4]\)、\([4, 5] \to [1, 2]\) である。長さ \(3\) のループは \([3, 4] \to [3, 4] \to [3, 4]\) ただ1つであり、これが与えるのは不動点であって、\(3\)-周期軌道ではない。

  4. \(x = 14y - 7\) とおくと \(\frac{\mathrm{f}(x) + 7}{14} = 1 - |2y - 1|\) となり、これはテント写像（tent map）である。2倍すると2進数の各桁が左にずれる。押し出された桁が \(1\) ならば結果は \(2 - 2y\) となり、これは残りの桁を反転させる。\(3\)-周期軌道は \(\frac27 \to \frac47 \to \frac67\) と \(\frac29 \to \frac49 \to \frac89\)（すなわち \(x = -3, 1, 5\) と \(x = -\frac{35}{9}, -\frac79, \frac{49}{9}\)）であり、2進数では \(\frac27 = 0.\overline{010}\)、\(\frac29 = 0.\overline{001110}\) である。
