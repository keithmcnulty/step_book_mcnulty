問題

STEP III 2015、第8問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/15-s3-q8

導入

自然界の多くの系は、どのように始まったかによらず、規則正しいリズムに落ち着いていく。心臓の鼓動、コオロギの鳴き声、一定の力で弓を引いたバイオリンの弦、捕食者と被食者の個体数の周期などがその例である。少し乱しても、それらは同じリズムに戻ってくる。微分方程式（differential equation）の言葉でいえば、それらの解は閉じたループに近づいていく。このループを極限サイクル（limit cycle）という。

この問題では、極限サイクルを一つ実際に構成する。方程式は \(x\) と \(y\) のままでは手に負えないように見えるが、極座標（polar coordinates）に移ると解ける形にまで簡単になる。そして解は、内側からも外側からも単位円に巻きつくように近づく螺旋であることがわかる。問題の対称性に合った座標を選ぶという鍵となる一手は、本書を通じて繰り返し用いてきたものである。

取りかかる前に

どちらの方程式にも、\(x\,\mathrm{d}x + y\,\mathrm{d}y\) と \(x\,\mathrm{d}y - y\,\mathrm{d}x\) という組合せが形を変えて含まれている。これらは極座標ではどう表されるか。

\(r^2 = x^2 + y^2\) であるから、微分すると \(x\,\mathrm{d}x + y\,\mathrm{d}y = r\,\mathrm{d}r\) が得られる。また \(x\,\mathrm{d}y - y\,\mathrm{d}x = r^2\,\mathrm{d}\theta\) である（これは第 4.9 節の面積公式である）。この二つの恒等式のおかげで、変数変換はほとんど苦労なく行える。方程式を、これらの組合せだけが現れるように書き直せばよい。

順を追って解く

段階 1 小問 (i) を極座標で

方程式を \((y + x)\,\mathrm{d}y - (y - x)\,\mathrm{d}x = 0\) と書き、整理し直すと \[(x\,\mathrm{d}x + y\,\mathrm{d}y) + (x\,\mathrm{d}y - y\,\mathrm{d}x) = 0.\]

展開して、この整理が正しいことを確かめよ。次に、上の二つの恒等式を用いよ。

\((y + x)\,\mathrm{d}y - (y - x)\,\mathrm{d}x = y\,\mathrm{d}y + x\,\mathrm{d}y - y\,\mathrm{d}x + x\,\mathrm{d}x\) であり、これは上の式そのものである。極座標で表すと \(r\,\mathrm{d}r + r^2\,\mathrm{d}\theta = 0\) となり、\(r^2\,\mathrm{d}\theta\) で割ると（\(r > 0\) として） \[\frac{\mathrm{d}r}{\mathrm{d}\theta} + r = 0. \qed\] 解は \(r = Ce^{-\theta}\) である。これは対数螺旋（logarithmic spiral）であり、\(\theta\) が増加すると原点に向かって巻き込み、\(\theta\) が減少すると無限遠へ広がっていく。

段階 2 小問 (ii)

新しい方程式は、元の方程式に \(x^2 + y^2 = r^2\) を含む項を付け加えたものである。同じように書き直して、\(\frac{\mathrm{d}r}{\mathrm{d}\theta}\) を求めよ。

方程式は \(\bigl(y + x - xr^2\bigr)\,\mathrm{d}y - \bigl(y - x - yr^2\bigr)\,\mathrm{d}x = 0\)、すなわち \[\bigl[(y + x)\,\mathrm{d}y - (y - x)\,\mathrm{d}x\bigr] - r^2\bigl(x\,\mathrm{d}y - y\,\mathrm{d}x\bigr) = 0.\] 最初の括弧は前と同じく \(r\,\mathrm{d}r + r^2\,\mathrm{d}\theta\) であり、二つ目の括弧は \(r^2\,\mathrm{d}\theta\) である。よって \(r\,\mathrm{d}r + r^2(1 - r^2)\,\mathrm{d}\theta = 0\) となり、 \[\frac{\mathrm{d}r}{\mathrm{d}\theta} = r^3 - r.\]

これは \(r\) について線形ではないが、\(u = r^{-2}\) については線形になる。\(u\) はどのような方程式を満たすか。

\(u = r^{-2}\) とおくと、\(\frac{\mathrm{d}u}{\mathrm{d}\theta} = -2r^{-3}\frac{\mathrm{d}r}{\mathrm{d}\theta} = -2r^{-3}(r^3 - r) = -2 + 2u\) である。よって \(\frac{\mathrm{d}u}{\mathrm{d}\theta} - 2u = -2\) であり、その解は \(u = 1 + Ae^{2\theta}\) である。したがって \[r^2 = \frac{1}{1 + Ae^{2\theta}}. \qed\]

段階 3 3種類の解

  • \(A = 0\) のとき：\(r = 1\) である。単位円は解である。

  • \(A > 0\) のとき：常に \(r < 1\) である。\(\theta \to -\infty\) のとき \(r \to 1\)、\(\theta \to +\infty\) のとき \(r \to 0\) である。曲線は円と原点の間を螺旋を描いて進む。

  • \(A < 0\) のとき：\(r > 1\) であり、この式が意味をもつのは \(1 + Ae^{2\theta} > 0\)、すなわち \(\theta < \frac12\ln\left(-\frac1A\right)\) の範囲だけである。\(\theta \to -\infty\) のとき \(r \to 1\)、\(\theta\) がその上限に近づくとき \(r \to \infty\) である。曲線は円と無限遠の間を螺旋を描いて進む。

こうして、どの解曲線も \(\theta \to -\infty\) のとき、内側または外側から単位円に近づく（図 8.4.1）。

振り返り

  • 対称性を利用する。方程式はすべての方向を同等に扱っており、極座標によってそのことがはっきり見えるようになった。

  • 定番の組合せを見抜く。\(x\,\mathrm{d}x + y\,\mathrm{d}y = r\,\mathrm{d}r\) と \(x\,\mathrm{d}y - y\,\mathrm{d}x = r^2\,\mathrm{d}\theta\) が仕事の大部分を担った。

  • 置換によって線形化する。非線形方程式 \(r' = r^3 - r\) は、\(u = r^{-2}\) について線形になった（ベルヌーイ型微分方程式（Bernoulli equation））。

背後にある数学

極限サイクル

アンリ・ポアンカレ（Henri Poincaré）は1880年代、平面上の微分方程式の定性的な振る舞いを研究する中で極限サイクルを導入した。問題の方程式を、平面上を動く点の軌跡を記述するものと解釈してみよう。単位円は孤立した閉軌道（closed orbit）であり、その近くの軌道はすべてそれに向かって巻きついていく（時間の向きによっては、それから離れていく）。1926年、オランダの技術者 Balthasar van der Pol は真空管を含む電気回路に極限サイクルを見いだし、同様の方程式が心臓の鼓動を記述すると提唱した。極限サイクルは、自律的に維持される安定なリズムをもつあらゆる系のモデルとなる。概日時計、神経インパルス、捕食者と被食者の個体数の周期などである。

平面にカオスはない

ポアンカレ–ベンディクソンの定理（Poincaré–Bendixson theorem）によれば、平面上の滑らかな系において、有界な領域にとどまり、平衡点（equilibrium）に近づかない軌道は、必ず閉軌道に近づく。したがって2次元では、長時間の振る舞いは平衡点とサイクルに限られる。軌道は互いに交われないので、カオス（chaos）が入り込む余地はないのである。カオスには少なくとも3次元が必要であり、これは1963年にエドワード・ローレンツ（Edward Lorenz）が、対流を表す有名な3変数のモデル（「バタフライ」）によって発見したことである。離散時間では、第 8.7 節で見るように、1次元でさえカオスが起こりうる。

未解決問題

1900年、ダフィット・ヒルベルト（David Hilbert）は第16問題の一部として、次のように問うた。\(P\) と \(Q\) が \(n\) 次の多項式であるとき、系 \(x' = P(x, y)\)、\(y' = Q(x, y)\) がもちうる極限サイクルの個数の最大値はいくつか。これは \(n = 2\) の場合でさえいまだにわかっていない。この場合、極限サイクルを4個もつ系は知られているが、それより多く存在しうるかどうかはわかっていない。ヒルベルトの問題のうち、完全に未解決のまま残っているごく少数の一つである。

思考のスキル

対称性に合わせて座標を変える

問題が回転対称性をもつなら極座標を用いよ。別の対称性をもつなら、それを尊重する座標を見つけよ。

適切な座標によって、手に負えない方程式が変数分離形に変わり、解の幾何学的な姿（円と螺旋）も一目瞭然になった。

次の一歩

  1. 螺旋。小問 (i) の解 \(r = e^{-\theta}\) について、曲線が原点から出るすべての半直線と同じ角度 \(45^\circ\) で交わることを示せ。（対数螺旋が等角螺旋（equiangular spiral）とも呼ばれるのはこのためである。）

  2. 極座標の恒等式。\(x\,\mathrm{d}x + y\,\mathrm{d}y = r\,\mathrm{d}r\) および \(x\,\mathrm{d}y - y\,\mathrm{d}x = r^2\,\mathrm{d}\theta\) を証明せよ。

  3. 時間に関する系。系 \(\dot r = r(1 - r^2)\)、\(\dot\theta = 1\) を考える。\(r(0) > 0\) であるすべての解が、\(t \to \infty\) のとき単位円に近づくことを示せ。また、この系を \(x\) と \(y\) で表せ。

  4. 二つのサイクル。\(\dot r = f(r)\)、\(\dot\theta = 1\) の形の系で、\(r = 1\) と \(r = 2\) に極限サイクルをもち、一方が引き寄せ、他方が反発するものを求めよ。

さらに学ぶために

  • Steven Strogatz, Nonlinear Dynamics and Chaos（CRC Press）。『非線形力学とカオス』。第 7章で極限サイクルとポアンカレ–ベンディクソンの定理を扱っている。

  • Steven Strogatz, Sync（Hyperion）。自然界のリズムと同期についての一般向けの本。

  • James Gleick, Chaos: Making a New Science（Penguin）。ローレンツとカオスの発見の物語。
