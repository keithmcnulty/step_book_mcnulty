9.4

関数としての数列

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第9章章全体のPDF
問題

STEP I 2016、第8問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/16-s1-q8

導入

電卓で \(1/89\) を計算してみよう。\(0.011235955\ldots\) となる。数字は \(0, 1, 1, 2, 3, 5\) と始まり、これはフィボナッチ数（Fibonacci numbers）である。これは偶然だろうか。偶然ではない。この問題はその理由を明らかにする。

ここで使う考え方は、組合せ論（combinatorics）で最も強力なものの一つである。無限数列をとり、その項を冪級数（power series）の係数として用いることで、数列全体を一つの関数にまとめてしまうのである。すると数列についての事実は関数についての事実となり、代数や微積分を使って扱えるようになる。ハーバート・ウィルフ（Herbert Wilf）はこれを印象的な言葉で表した。「母関数とは、数列を並べて見せるために吊るす物干しロープである。」

取りかかる前に

母関数（generating function）が \(\dfrac{1}{1 - x}\) である数列は何か。\(\dfrac{1}{1 - 2x}\) ではどうか。数列の母関数に \(x\) を掛けると、数列はどうなるか。

等比級数（geometric series）\(\frac{1}{1 - x} = 1 + x + x^2 + \cdots\) は数列 \(1, 1, 1, \ldots\) の母関数であり、\(\frac{1}{1 - 2x} = 1 + 2x + 4x^2 + \cdots\) は \(2\) の冪の母関数である。\(x\) を掛けると、すべての項が一つずつ後ろにずれる。\(x \cdot \frac{1}{1-x} = x + x^2 + \cdots\) は \(0, 1, 1, 1, \ldots\) の母関数である。

順を追って解く

段階 1 自然数と三角数

\((1 - x)^{-2}\) を二項級数で展開せよ。\(x^n\) の係数は何か。

二項級数（binomial series）により \[(1 - x)^{-2} = 1 + 2x + 3x^2 + 4x^3 + \cdots = \sum_{n \geq 0}(n + 1)x^n,\] であるから、\(x(1 - x)^{-2} = x + 2x^2 + 3x^3 + \cdots = \sum n x^n\) となる。これは \(u_n = n\) の母関数である。

同様に、\((1 - x)^{-3}\) における \(x^n\) の係数は \(\frac{(-3)(-4)\cdots(-3-n+1)}{n!}(-1)^n = \frac{(n + 1)(n + 2)}{2}\) であるから、 \[x(1 - x)^{-3} = \sum_{n \geq 1}\frac{n(n + 1)}{2}\,x^n = x + 3x^2 + 6x^3 + 10x^4 + \cdots,\] となり、これは三角数（triangle numbers）\(u_n = \frac12 n(n + 1)\) の母関数である。

\(n^2\) を \(n\) と \(\frac12n(n + 1)\) を用いて表すにはどうすればよいか。

\(n^2 = 2 \cdot \frac12 n(n + 1) - n\) であり、母関数は数列と同じように足し合わせられるので、 \[\sum n^2 x^n = \frac{2x}{(1 - x)^3} - \frac{x}{(1 - x)^2} = \frac{2x - x(1 - x)}{(1 - x)^3} = \frac{x(1 + x)}{(1 - x)^3}. \qed\]

段階 2 漸化式が方程式になる

\(u_n = ku_{n-1}\) の両辺に \(x^n\) を掛け、\(n \geq 1\) のすべての \(n\) について足し合わせよ。各辺は \(\mathrm{f}\) を用いてどう表されるか。

左辺は \(\sum_{n \geq 1}u_nx^n = \mathrm{f}(x) - u_0 = \mathrm{f}(x) - a\) である。右辺は \(kx\sum_{n \geq 1}u_{n-1}x^{n-1} = kx\,\mathrm{f}(x)\) である。よって \(\mathrm{f}(x) = a + kx\,\mathrm{f}(x)\) であり、 \[\mathrm{f}(x) = \frac{a}{1 - kx}. \qed\] もちろん \(u_n = ak^n\) である。\(\frac{a}{1 - kx}\) を等比級数として展開すれば、このことが確かめられる。

段階 3 フィボナッチ数

漸化式（recurrence）\(u_n = u_{n-1} + u_{n-2}\)（\(n \geq 2\)）にも同じことを行う。 \[\sum_{n \geq 2}u_nx^n = x\sum_{n \geq 2}u_{n-1}x^{n-1} + x^2\sum_{n \geq 2}u_{n-2}x^{n-2},\] すなわち \[\mathrm{f}(x) - u_0 - u_1x = x\bigl(\mathrm{f}(x) - u_0\bigr) + x^2\,\mathrm{f}(x).\] \(u_0 = 0\)、\(u_1 = 1\) とすると、これは \(\mathrm{f}(x) - x = x\,\mathrm{f}(x) + x^2\,\mathrm{f}(x)\) を意味するので、 \[\mathrm{f}(x) = \frac{x}{1 - x - x^2}. \qed\]

段階 4 \(1/89\) の説明

収束（convergence）の問題は無視して（ここでは問題ない。この級数は \(|x| < 0.618\) で収束する）、\(\mathrm{f}\) に \(x = \frac{1}{10}\) を代入せよ。何が得られるか。

\[\frac{1}{10}F_1 + \frac{1}{100}F_2 + \frac{1}{1000}F_3 + \cdots = \mathrm{f}\Bigl(\frac{1}{10}\Bigr) = \frac{1/10}{1 - 1/10 - 1/100} = \frac{10}{89}.\] \(10\) で割ると \(\frac{1}{89} = \sum F_n/10^{n+1}\) となる。フィボナッチ数が小数の各位に順に置かれ、\(9\) より大きくなると互いに重なり合う（図 9.4.1）。\(1/89\) の最初のほうの桁にはフィボナッチ数が現れるが、後のほうの桁は繰り上がりによってぼやけてしまう。

振り返り

  • 数列を関数に変える。無限数列全体が一つの有理関数（rational function）になった。

  • 漸化式は方程式になる。\(x^n\) を掛けて和をとることで、規則 \(u_n = u_{n-1} + u_{n-2}\) が、代数的に解ける \(\mathrm{f}\) についての方程式に変わった。

  • 古いものから新しいものを作る。母関数を足したり、ずらしたり、微分したりすることで、一から始めることなく新しい母関数が得られた。

背後にある数学

母関数から公式へ

母関数は数列を符号化するだけではない。数列を求めることもできる。分母は \(1 - x - x^2 = (1 - \varphi x)(1 - \psi x)\) と因数分解される。ここで \(\varphi = \frac{1 + \sqrt5}{2}\) と \(\psi = \frac{1 - \sqrt5}{2}\) は \(t^2 = t + 1\) の解である。部分分数分解（partial fractions）により \[\frac{x}{1 - x - x^2} = \frac{1}{\sqrt5}\Bigl(\frac{1}{1 - \varphi x} - \frac{1}{1 - \psi x}\Bigr),\] となり、それぞれの分数を等比級数として展開すると \[F_n = \frac{\varphi^n - \psi^n}{\sqrt5}.\] これがビネ（Binet）の公式である。\(|\psi| < 1\) であるから第 2 項は非常に小さく、したがって \(F_n\) は \(\varphi^n/\sqrt5\) に最も近い整数である。また、隣り合うフィボナッチ数の比は黄金比（golden ratio）に収束する（第 2.2 節 の主題である）。同じ方法で、定数係数の線形漸化式（linear recurrence）はどれも解くことができる。演習には STEP I 2004 の例を含めてある。

母関数がこれほど役に立つ理由

真の威力は掛け算をするときに現れる。積 \(\mathrm{f}(x)\mathrm{g}(x)\) における \(x^n\) の係数は \(\sum_k u_kv_{n-k}\) であり、これは \(n\) を二つの部分に分けるすべての方法にわたる和である。これはまさに、二つの部品から組み立てられたものを数えるのに必要なものである。続く二つの節では、これを用いて両替の方法の数を数え（第 9.5 節）、普通のさいころと同じ目の和の分布をもつ、奇妙な目のさいころを見つける（第 9.6 節）。確率論では、同じ考え方から確率母関数（probability generating function）が得られ、独立な確率変数（independent random variables）の和を積に変える。

ド・モアブル、オイラー、ラプラス

アブラーム・ド・モアブル（Abraham de Moivre）は 1720 年代に、本質的には上の方法によって、母関数を用いて線形漸化式を解いた。レオンハルト・オイラー（Leonhard Euler）は 1748 年に、自然数の分割（partitions）を研究するために母関数を用い、ピエール＝シモン・ラプラス（Pierre-Simon Laplace）は母関数を著書 Théorie analytique des probabilités（『確率の解析的理論』、1812 年）の基礎に据えた。20 世紀には母関数は組合せ論の中心的な道具となり、現在では解析的な方法（母関数を複素変数（complex variable）の関数として調べること）により、厳密に解くにはあまりに複雑な数え上げの問題に対しても、精密な評価が得られるようになっている。

思考のスキル

表現を変える

数列についての問題は、その数列を関数や行列や図に変えると易しくなることがある。

母関数は漸化式を代数に、数え上げを掛け算に翻訳する。大学ではこうした翻訳に数多く出会うだろう。フーリエ級数（Fourier series）は関数を数列に変え、ラプラス変換（Laplace transform）は微分方程式（differential equation）を代数に変え、行列（matrix）は幾何を計算に変える。

次の一歩

  1. 2 桁ずつ。STEP II 2022、第3問 （OCRが配布している2022年の問題一式、zipファイル） に挑戦せよ。\(\frac{1}{89}\) の小数展開がフィボナッチ数で始まる理由を説明し、さらに、小数展開にこのパターンが 2 桁ずつ現れる分数を求める問題である。

  2. 漸化式を解く。STEP I 2004、第7問 に挑戦せよ。母関数と部分分数分解を用いて線形漸化式を解き、次にその方法を逆向きにたどる問題である。

  3. 数を数える。\(\frac{1}{9801} = 0.00\,01\,02\,03\,04\ldots\) となり、2 桁ずつの区切りが 1 ずつ増えていくことを示せ。このパターンが最初に崩れるのはどこか。また、それはなぜか。

  4. 平方の和。\(\frac{1}{1-x}\mathrm{f}(x)\) が部分和（partial sums）\(u_0 + u_1 + \cdots + u_n\) の母関数であることを説明せよ。このことと小問 (i) の答えを用いて、\(1^2 + 2^2 + \cdots + n^2\) の公式を求めよ。

さらに学ぶために

  • Herbert Wilf, generatingfunctionology（A K Peters、オンラインで無料公開）。母関数への古典的な入門書。この節の後に読むには第 1 章が最適である。

  • Ronald Graham, Donald Knuth & Oren Patashnik, Concrete Mathematics（Addison-Wesley、邦訳『コンピュータの数学』）、第 7 章。

  • Philippe Flajolet & Robert Sedgewick, Analytic Combinatorics（Cambridge University Press、オンラインで無料公開。『解析的組合せ論』）。大学 1 年の水準をはるかに超えるが、冒頭の数ページを読めば、この分野がどこへ向かうのかがわかる。
