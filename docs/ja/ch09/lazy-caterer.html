9.1

平面を分割する直線

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第9章章全体のPDF
問題

STEP II 1990、第4問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/90-s2-q4

導入

ピースの大きさがそろっていなくてよいなら、\(n\) 回のまっすぐな切れ目でピザを何切れに分けられるだろうか。1 回切れば \(2\) 切れ、2 回で \(4\) 切れ、3 回で \(7\) 切れ（\(8\) ではない。実際に試してみよ）、4 回で \(11\) 切れである。数列 \(1, 2, 4, 7, 11, 16, \ldots\) は怠惰な仕出し屋の数列（lazy caterer’s sequence）として知られており、この問題はその一般項を求めるものである。

この問題は、組合せ論（combinatorics）全体を貫く手法への最初の入門となる。すべてを一度に数えようとしてはならない。その代わりに、対象を一つ増やしたときに何が変わるかを問うのである。そして答えは、第 7.9 節 でプラトンの立体とともに出会ったオイラー（Euler）の公式 \(V - E + F = 2\) の特別な場合であることがわかる。

取りかかる前に

直線を一般の位置（general position）に保ちながら（どの 2 本も平行でなく、どの 3 本も 1 点を通らない）、\(n = 1, 2, 3, 4\) の場合を丁寧に描け。それぞれの場合について、線分（segment）と領域（region）の個数を数えよ。規則性を推測できるだろうか。

次のようになるはずである。

\(n\) \(0\) \(1\) \(2\) \(3\) \(4\)
線分 \(0\) \(1\) \(4\) \(9\) \(16\)
領域 \(1\) \(2\) \(4\) \(7\) \(11\)

線分の個数は \(n^2\) のように見える。領域の個数は \(1, 2, 3, 4\) ずつ増えている。つまり、階差が自然数になっている。

順を追って解く

段階 1 線分を数える

1 本の直線に注目せよ。他の直線のうち何本がそれと交わり、それを何個の部分に分けるか。

各直線は他の \(n - 1\) 本の直線のそれぞれと交わり（どれもその直線と平行ではない）、しかも交点は \(n - 1\) 個の相異なる点である（どの 3 本も 1 点で交わらない）。これら \(n - 1\) 個の点は、その直線を \(n\) 個の線分に分ける。両端にある 2 つの無限に伸びる部分と、その間にある \(n - 2\) 個の有限の線分である。直線が \(n\) 本あるので、全体では \[n \times n = n^2 \text{ 個の線分}. \qed\] となる。これは直接的な数え上げであり、帰納法（induction）は必要ない。線分を直線ごとに数えたのである。

段階 2 直線を 1 本加えると何が起こるか

\(n - 1\) 本の直線が引かれているとし、そこに \(n\) 本目を加える。新しい直線は他の直線によって \(n\) 個の線分に分けられる。各線分は、それが通過する領域に対して何をするか。

新しい直線を引くと、その \(n\) 個の線分はそれぞれ既存の領域の一つを通り抜け、それを 2 つに分ける（図 9.1.1）。異なる線分は異なる領域にある。なぜなら、ある領域から別の領域へ移るには、新しい直線は既存の直線と交わらなければならないからである。したがって、\(n\) 本目の直線を加えると、領域の個数はちょうど \(n\) だけ増える。 \[R(n) = R(n - 1) + n.\]

段階 3 漸化式を解く

\(R(0) = 1\)（直線がなければ領域は 1 つ）から出発すると、 \[R(n) = 1 + (1 + 2 + \cdots + n) = 1 + \frac{n(n + 1)}{2} = \frac{n^2 + n + 2}{2}.\] これを帰納法の形で述べると次のようになる。\(\frac12(1 + 1 + 2) = 2\) であるから、\(n = 1\) のとき公式は成り立つ。また、\(R(n - 1) = \frac12\bigl((n - 1)^2 + (n - 1) + 2\bigr) = \frac12(n^2 - n + 2)\) ならば、\(R(n) = \frac12(n^2 - n + 2) + n = \frac12(n^2 + n + 2)\) である。■

振り返り

  • 一度に一つずつ数える。線分は直線ごとに数え、領域は新しい直線 1 本が付け加えるものによって数えた。

  • 幾何的な一歩を漸化式に変える。「新しい線分はそれぞれ 1 つの領域を分ける」という観察が、\(R(n) = R(n - 1) + n\) になった。

  • 一般の位置は重要である。平行な直線や、1 点を通る 3 本の直線があると、領域の数は少なくなる。それぞれの仮定がどこで使われたかを確かめよ。

背後にある数学

姿を変えたオイラーの公式

ここでは第二の証明を示す。これは答えを単に導くだけでなく、その理由を説明するものである。直線の配置を地図とみなそう。交点を頂点（vertex）、線分を辺（edge）、領域を面（face）とする。頂点は \(V = \binom{n}{2}\) 個（直線の各組に 1 つ）、辺は \(E = n^2\) 本ある。無限に伸びる線分には端が 1 つしかないので、それらがすべて集まる「無限遠」の頂点を 1 つ追加する。すると、図は球面上に描かれた地図になる（平面を球に巻きつけ、無限遠が頂上にくる様子を想像せよ）。第 7.9 節 のオイラーの公式 \(V - E + F = 2\) から \[\Bigl(\binom{n}{2} + 1\Bigr) - n^2 + F = 2, \qquad\text{よって}\qquad F = n^2 - \frac{n(n - 1)}{2} + 1 = \frac{n^2 + n + 2}{2}.\] まったく異なる方向から、同じ数が得られた。領域はまた、種類によってきれいに分けられる。そのうち \(2n\) 個は非有界であり（隣り合う無限半直線の各組の間に 1 つずつ）、残りの \(\frac12(n^2 + n + 2) - 2n = \binom{n - 1}{2}\) 個は有界である。

二項係数と高次元

この公式は \[R(n) = \binom{n}{0} + \binom{n}{1} + \binom{n}{2},\] と書くことができ、これは偶然ではない。どの直線も水平にならないように図を回転させる。下に有界な領域には最低点があり、それは交点でなければならない。また、各交点はちょうど 1 つの領域（そのすぐ上にある領域）の最低点である。これにより、直線の各組に 1 つずつ、\(\binom{n}{2}\) 個の領域が得られる。それ以外の領域はどこまでも下に伸びているので、すべての交点よりはるか下に引いた水平線と交わる。\(n\) 本の直線はその水平線を \(n + 1\) 個の区間に分け、そのような領域のそれぞれに 1 つずつ区間がある。合計で \(\binom{n}{2} + n + 1\) となる。3 次元では、一般の位置にある \(n\) 枚の平面は空間を \[\binom{n}{0} + \binom{n}{1} + \binom{n}{2} + \binom{n}{3} = \frac{n^3 + 5n + 6}{6}\] 個の部分に分け（ケーキ数（cake numbers）\(1, 2, 4, 8, 15, 26, \ldots\)）、この規則性はあらゆる次元で続く。証明は同じ帰納法である。新しい平面は他の平面によって、平面上の直線と同じ配置の領域に分けられ、それらの領域のそれぞれが空間の一部分を 2 つに分ける。

シュタイナーと超平面配置

直線や平面によって分けられる領域の個数の公式は、1826 年にヤコブ・シュタイナー（Jakob Steiner）によって発見された。今日、これは超平面配置（hyperplane arrangements）の理論の出発点となっている。この理論は、一般の位置にないものも含め、直線、平面、およびそれらの高次元版の任意の集まりが作る領域を数えるものである。1975 年の Thomas Zaslavsky による注目すべき定理は、どの超平面どうしが交わるかを記述する多項式を用いて、任意の配置の領域の個数を数える。同じ考え方は機械学習にも現れる。「ReLU」ユニットで構成されたニューラルネットワークは、超平面によって入力空間を領域に分け、その領域の個数は、ネットワークがどれほど複雑な関数を表現できるかの尺度となる。

思考のスキル

一つ増やしたときに何が変わるかを問う

\(n\) 個の対象からなる配置を数えるには、それを \(n - 1\) 個の配置と比べよ。全体よりも変化のほうがはるかに数えやすいことが多い。

これは、証明のためだけでなく発見のための道具として帰納法を使うことである。組合せ論で最もよく使われる手の一つであり、幾何的な問題を解くことのできる漸化式に変えてくれる。

次の一歩

  1. 円。どの 2 つも 2 点で交わり、どの 3 つも 1 点を通らない \(n\) 個の円は、平面を \(n^2 - n + 2\) 個の領域に分けることを示せ。

  2. 平行な直線。\(n\) 本の直線のうち \(k\) 本が互いにすべて平行である（それ以外は一般の位置にある）とき、領域はいくつあるか。

  3. ケーキ数。一般の位置にある \(n\) 枚の平面が空間を \(\frac16(n^3 + 5n + 6)\) 個の領域に分けることを、帰納法によって証明せよ。

  4. 崩れる規則性。円周上に \(n\) 個の点をとり、すべての 2 点の組を弦で結ぶ。ただし、円の内部でどの 3 本の弦も 1 点を通らないものとする。\(n = 1, 2, 3, 4, 5\) のとき、領域は \(1, 2, 4, 8, 16\) 個になる。\(n = 6\) のときの領域の個数を数えよ。（ヒント：オイラーの公式を用いよ。4 点の組それぞれから交点が 1 つできる。）その個数が \(1 + \binom{n}{2} + \binom{n}{4}\) であることを示せ。

さらに学ぶために

  • Ronald Graham, Donald Knuth & Oren Patashnik, Concrete Mathematics（Addison-Wesley）、第 1 章。まさにこの問題と、その「ピザ」版および「ジグ」版から始まる。

  • Miklós Bóna, A Walk Through Combinatorics（World Scientific）。親しみやすい入門書で、帰納法、グラフ、オイラーの公式の章がある。

  • Richard Guy, “The strong law of small numbers”、American Mathematical Monthly 95 (1988)。一見明らかに見えて実は誤りである規則性が数多く紹介されており、演習問題の円の問題も含まれている。
