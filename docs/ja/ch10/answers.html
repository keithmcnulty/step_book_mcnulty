第10章 · 保存則・衝突・重力

「次の一歩」の解答

以下は完全な解答ではなく、簡潔な答えとヒントである。自分の解答を確かめられるように、結果と鍵となる一歩を示してある。答えを見る前に、まずは各問題にきちんと取り組んでほしい。

10.1 ニュートンのゆりかご

  1. すべての衝突が終わった後では、動いている粒子のすぐ後ろに、それより遅い粒子が続くことはない。したがって、ちょうど1個だけが動くなら、それは \(A_n\) である。しかし \(\lambda \neq 1\) のとき、\(\lambda mv = mu\) と \(\lambda mv^2 = mu^2\) は両立しない。\(A_{n-1}\) と \(A_n\) だけが動くなら、方程式は \(m\) と \(\lambda m\) の衝突の方程式になり、\(A_{n-1}\) の速度は \(\frac{1 - \lambda}{1 + \lambda}u < 0\) となる。ところがそうすると、それは \(A_{n-2}\) に衝突してしまう。3個の粒子が動く場合は、小問 (ii) とまったく同様に否定される。動く2個は、速さ \(\frac{\lambda - 1}{\lambda + 1}u\) で後ろ向きに進む \(A_0\) と、速さ \(\frac{2u}{\lambda + 1}\) で前向きに進む \(A_n\) である。

  2. 等しいビー玉どうしは速度を交換するので、速さ \(u\) は \(A_n\) まで受け渡される。次に \(A_n\) が \(A_{n+1}\) に衝突する。\(A_{n+1}\) は速さ \(\frac{2u}{1 + \lambda}\) で離れ、\(A_n\) は速さ \(\frac{\lambda - 1}{\lambda + 1}u\) で跳ね返る。この後ろ向きの速度は列を逆にたどって \(A_0\) まで受け渡され、\(A_0\) はその速さで後ろ向きに離れていく。

  3. 「2個が速さ \(u\) で飛び出す」場合、運動量（momentum）は \(2mu\)、エネルギーは \(mu^2\) で、衝突前と同じである。それ以上衝突が起こらない別の解として、最後の3個の球がそれぞれ \(\frac u3\)、\(\frac u3\)、\(\frac{4u}{3}\) で動き出すものがある（検算：合計は \(2u\)、2乗の合計は \(2u^2\)）。実際のニュートンのゆりかごが前者を選ぶのは、球どうしがわずかに離れていて、衝突が1組ずつ起こるからである。

  4. 速さは \(A_n\) まで受け渡され、\(A_n\) はより軽い \(A_{n+1}\) に衝突する。\(A_{n+1}\) は速さ \(\frac{2u}{1 + \lambda}\) で離れ、\(A_n\) はそれより遅い速さ \(\frac{1 - \lambda}{1 + \lambda}u\) で後に続く。ほかには何も動かない。

10.2 重ねたボールの効果

  1. 球は速さ \(U = \sqrt{2gH}\) で床に達し、速さ \(eU\) で跳ね返って高さ \(e^2H\) まで上がる。小さい球を上に載せた場合、速さ \(eU\) で上昇する大きい球が、速さ \(U\) で下降する小さい球と出会う。運動量保存と反発係数（coefficient of restitution）の式から、小さい球の上向きの速さは \(w = U\frac{Me(2 + e) - m}{M + m}\) となる。その中心は高さ \(2R + r = 0.45\) から出発して \(4.5\) まで上がるので、\(\frac{w^2}{2g} = 4.05\) であり、\(\frac wU = \sqrt{\frac{4.05}{1.8}} = 1.5\) となる。\(e = \frac23\) のとき \(\frac{16}{9}M - m = 1.5(M + m)\) であるから、\(M = 9m\) を得る。

  2. 運動量保存と反発係数の式から、\(P_1\) の速さは \(\frac{1 + e}{1 + \lambda}u\) となる。各衝突は同じ質量比でこれを繰り返すので、\(P_n\) は速さ \(\bigl(\frac{1 + e}{1 + \lambda}\bigr)^nu\) で動く。速さ \(s\) の粒子は、次の粒子に衝突した後に速さ \(\frac{1 - \lambda e}{1 + \lambda}s\) となり、衝突された粒子のほうは、自身の次の衝突によって速さ \(\frac{(1 + e)(1 - \lambda e)}{(1 + \lambda)^2}s\) まで減速される。\(\lambda e < 1\) のとき、1番目の粒子が2番目の粒子に再び追いつくのは \(\frac{1 - \lambda e}{1 + \lambda} > \frac{(1 + e)(1 - \lambda e)}{(1 + \lambda)^2}\)、すなわち \(\lambda > e\) のときに限る。よって \(e > \lambda\) ならば、各粒子は1回衝突され、1回衝突する。\(\lambda e = 1\) ならば、各粒子は次の粒子に衝突した後、その場で停止する。

  3. 一番下の球は速さ \(U\) で跳ね返り、（速さ \(U\) で下降している）真ん中の球と出会う。相対速度は \(2U\) なので、真ん中の球は速さ \(3U\) で離れる。一番上の球は相対速度 \(4U\) でこれと出会い、速さ \(7U\) で離れて高さ \(49H\) まで上がる。一般に \(u_{j+1} = 2u_j + U\) であるから、\(u_j + U = 2^jU\) となる。

  4. 弾性衝突（elastic collision）では運動エネルギー（kinetic energy）が保存される。\(A\) のエネルギーは \(\frac12m\bigl(\frac{2\lambda}{1 + \lambda}\bigr)^{2n}u^2\) であり、最初のエネルギーは \(\frac12\lambda^nmu^2\) である。\(\frac{4\lambda}{(1 + \lambda)^2} < 1\) なので、\(A\) がもともとあった以上のエネルギーを得ることは決してない。重い粒子はそれぞれ速さの \(\frac{\lambda - 1}{\lambda + 1}\) 倍を保って前向きに動き続け、残りのエネルギーを持ち続ける。

10.3 ロケットと大砲

  1. 一度にすべて発射する場合、\(Mu = nm(v - u)\) より \(u = \frac{nmv}{M + nm}\) である。1個ずつ発射する場合、第 \(r\) 回目の発射で \(\bigl(M + (n - r + 1)m\bigr)(u_r - u_{r-1}) = mv\) となるので、\(u_n = \sum_{j=1}^n\frac{mv}{M + jm}\) であり、最後の項を除くすべての項は \(\frac{mv}{M + nm}\) より大きい。したがって \(u_n > u\) である。

  2. 運動量保存より \(M(1 + bx)v = MV\) である。すると \((1 + bx)\frac{\mathrm{d}x}{\mathrm{d}t} = V\) なので、\(x + \frac12bx^2 = Vt\) であり、\(x = \frac{\sqrt{1 + 2bVt} - 1}{b}\) となる。力が働く場合は、\(\frac{\mathrm{d}}{\mathrm{d}t}\bigl(M(1 + bx)v\bigr) = Mf\) から \((1 + bx)v = ft + V\) を得る。一定の速さ \(c\) で動くには \(x = ct\) かつ \((1 + bct)c = ft + V\) が必要なので、\(c = V\) かつ \(bV^2 = f\) である。そうでなければ \(x + \frac12bx^2 = \frac12ft^2 + Vt\) となるので、\(x \sim t\sqrt{f/b}\) であり、\(v \to \sqrt{f/b}\) となる。

  3. 1段式では \(v\ln10 \approx 2.30v\) である。2段式では \(v\ln\frac{10}{5.5} + v\ln\frac{5}{0.5} \approx 0.60v + 2.30v = 2.90v\) である。

  4. \(0 \leq s \leq x\) のとき \(\frac{1}{1 + x} \leq \frac{1}{1 + s} \leq 1\) である。これを \([0, x]\) で積分すればよい。

10.4 分子とピストン

  1. 漸化式（recurrence relation）は順に打ち消し合って \(d_n = \frac{(v + u)d_1}{v + (2n - 1)u}\) となるので、\(v_nd_n = \frac{(v + 2nu)(v + u)d_1}{v + (2n - 1)u}\) であり、これは \((v + u)d_1\) を \(\frac{u(v + u)d_1}{v + (2n - 1)u} \to 0\) だけ上回る。

  2. \(u\) を \(-u\) に置き換える。後退するピストンで跳ね返るたびに \(2u\) だけ失うので、（粒子がまだピストンに追いつける間は）\(v_n = v - 2nu\)、\(d_n = \frac{(v - u)d_1}{v - (2n - 1)u}\) であり、\(v_nd_n = \frac{(v - 2nu)(v - u)d_1}{v - (2n - 1)u}\) となる。これもやはり \((v - u)d_1\) に近い。

  3. \(v = u\) のとき \(v_n = (2n + 1)u\) である。第 \(n\) 回目の衝突で運動量は \(m(v_{n-1} + v_n) = 4nmu\) だけ変化し、\(t_n = \frac{d_1}{un(n + 1)}\) なので、平均の力は \(\frac{4mu^2n^2(n + 1)}{d_1}\) であり、その大きさは \(n^3\) の程度である。各周期での仕事はおよそ力 \(\times\ ut_n\)、すなわちほぼ \(4nmu^2\) であり、これらを足し合わせると無限大になる。ピストンを奥まで押し込むには無限の仕事が必要になるのであり、これは分子のエネルギー \(\frac12m(2n + 1)^2u^2\) が限りなく大きくなることと対応している。

  4. 不変量（invariant）は \(\oint p\,\mathrm{d}q = 2\int_0^h m\sqrt{2g(h - z)}\,\mathrm{d}z \propto h^{3/2}\) である。ここで \(h\) は床から測った跳ね上がりの高さである。したがって床がゆっくり上昇するとき、\(h^{3/2}\)（同じことであるが \(v^3\)、あるいはエネルギーと周期の積）はほぼ一定に保たれる。

10.5 有限時間に無限回の跳ね返り

  1. 正弦定理（sine rule）より \(M_1N_1 = \frac{OM_1\sin30^\circ}{\sin\theta}\) であり、続く各区間は比 \(\rho = \frac{\sin(\theta - 30^\circ)}{\sin\theta} < 1\) で縮んでいく。合計は \(\frac{M_1N_1}{1 - \rho} = \frac{OM_1}{2\bigl(\sin\theta - \sin(\theta - 30^\circ)\bigr)} = \frac{OM_1}{4\sin15^\circ\cos(\theta - 15^\circ)}\) である。

  2. 三角形 \(OM_1N_1\) の角から \(\varphi = \theta - \alpha\) を得る。時間の比は \(\frac{\rho}{k} = \frac{\sin(\theta - \alpha)\cos(\theta - \alpha)}{\sin\theta\cos\theta} = \frac{\sin(2\theta - 2\alpha)}{\sin2\theta}\) であり、これが \(1\) より小さくなるのは、ちょうど \(\alpha < \theta < 45^\circ + \frac12\alpha\) のときである。

  3. くさびをその壁で折り返していくと、経路は1本の直線に展開される。\(O\) のまわりにはくさびの複製が12個収まり、\(O\) を通らない直線はそのうち高々6個しか横切らない。したがって、粒子が \(O\) に向けてまっすぐ打ち出されない限り、跳ね返りは有限回で終わり、粒子は外へ抜け出す。

  4. まず \(t_0 = \sqrt{2/9.8} \approx 0.452\) 秒間落下する。各回の跳ね返りは \(2e^kt_0\) だけ続くので、全時間は \(t_0\bigl(1 + \frac{2e}{1 - e}\bigr) = 9t_0 \approx 4.07\) 秒である。移動距離は \(1 + 2\sum_{k \geq 1}e^{2k} = 1 + \frac{2(0.64)}{0.36} \approx 4.56\) m である。

10.6 二体が一体になる

  1. 糸は張ったままで、相対速度は糸に垂直であり、その大きさは一定値 \(u\) なので、\(\theta = \frac{ut}{r}\) である。運動量保存より \(my + MY = mut\) となる。\(A = G - \frac{M}{m + M}\overrightarrow{AB}\) かつ \(\overrightarrow{AB} = r(\cos\theta, -\sin\theta)\) であるから、\(y = \frac{1}{m + M}\bigl(mut + Mr\sin\frac{ut}{r}\bigr)\) である。すると \(\dot y = \frac{u}{m + M}\bigl(m + M\cos\frac{ut}{r}\bigr)\) であり、これは \(\cos\frac{ut}{r} < -\frac mM\) のとき負になる。これは \(M > m\) ならば起こりうる。

  2. 今度は \(\ddot z = -\frac{3}{z^3}\) なので、（\(z = 1\)、\(\dot z = -1\) を用いて）\(\dot z^2 = \frac{3}{z^2} - 2\) である。\(w = z^2\) とおくと \(\ddot w = 2\dot z^2 + 2z\ddot z = -4\) なので、\(z^2 = 1 - 2t - 2t^2\) となる。2つが衝突するのは \(t = \frac{\sqrt3 - 1}{2} \approx 0.366\) のときである。

  3. \(\mathbf{p} = (1, 0)\)、\(\mathbf{q} = (-1, \sqrt3)\) とすると \(z^2 = 4t^2 - 2t + 1 = |\mathbf{p} + \mathbf{q}t|^2\) である。これは \((1, 0)\) を通り方向 \((-1, \sqrt3)\) をもつ直線であり、\(\theta = \tan^{-1}\frac{\sqrt3t}{1 - t}\) である。すると \(z^2\dot\theta = |\mathbf{p} \times \mathbf{q}| = \sqrt3\) となる。この斥力は、角運動量（angular momentum）\(h = \sqrt3\) をもつ平面内の自由運動における「遠心力（centrifugal）」項 \(\frac{h^2}{z^3}\) そのものである。

  4. 2つの星は重心（centre of mass）からそれぞれ距離 \(\frac{m_2a}{m_1 + m_2}\) と \(\frac{m_1a}{m_1 + m_2}\) の位置にある。1つ目の星について \(\frac{Gm_1m_2}{a^2} = m_1\omega^2\frac{m_2a}{m_1 + m_2}\) なので、\(\omega^2 = \frac{G(m_1 + m_2)}{a^3}\) であり、\(T = \frac{2\pi}{\omega}\) である。

10.7 球殻の内部の重力

  1. 外側（\(b > a\)）では、段階3と同じ積分を \(s\) について \(b - a\) から \(b + a\) まで行うことになり、\(\frac{GM}{b^2}\) を得る。中身の詰まった球は同心の球殻の和集合であり、各球殻はその質量が中心に集まっているかのように働く。

  2. \(r = R\cos^2\alpha\) とおくと \(\frac1r - \frac1R = \frac{\tan^2\alpha}{R}\) なので、速さは \(\sqrt{2GM/R}\tan\alpha\) である。すると \(\mathrm{d}t = \frac{2R\sin\alpha\cos\alpha\,\mathrm{d}\alpha}{\sqrt{2GM/R}\tan\alpha} = \sqrt{\frac{R^3}{2GM}}\,2\cos^2\alpha\,\mathrm{d}\alpha\) となるので、これを積分すればよい。

  3. （殻定理（shell theorem）により）引力を及ぼすのは半径 \(b\) の内側にある質量 \(M\frac{b^3}{a^3}\) だけであり、引力は \(\frac{GMb}{a^3}\) となる。これは \(\omega^2 = \frac{GM}{a^3}\) の単振動（simple harmonic motion）であり、\(a = 6.37 \times 10^6\) m、\(GM = 3.99 \times 10^{14}\) m\(^3\) s\(^{-2}\) とすると、周期は \(2\pi\sqrt{a^3/GM} \approx 84\) 分である。半径 \(a\) の人工衛星では \(\omega^2a = \frac{GM}{a^2}\) であり、同じ \(\omega\) となる。

  4. 成り立たない。\(\frac{1}{s^3}\) の場合、被積分関数はもはや定数に簡単化されず、球殻の近い側が勝つ。すなわち、粒子は球殻の最も近い部分のほうへ引かれる。厳密な打ち消し合いが起こるのは逆二乗則（inverse-square law）の場合だけである（球殻の微小部分の面積は \(s^2\) に比例して増え、力の減少をちょうど相殺する）。

10.8 三角形をなす三つの星

  1. 各星は中心から \(\frac{a}{\sqrt2}\) の距離にある。隣り合う2つの星は、中心向きの成分の合計が \(\frac{2\gamma m^2}{a^2}\cos45^\circ = \frac{\sqrt2\gamma m^2}{a^2}\) の引力を及ぼし、向かい側の星は \(\frac{\gamma m^2}{2a^2}\) の引力を及ぼす。\(\frac{\gamma m^2}{a^2}\bigl(\sqrt2 + \frac12\bigr) = m\omega^2\frac{a}{\sqrt2}\) とおくと、\(\omega^2 = \frac{(4 + \sqrt2)\gamma m}{2a^3}\) を得る。

  2. 中心では引力が打ち消し合うので、惑星は平衡（equilibrium）の状態にある。星を結ぶ直線に沿っては不安定である。一方の星に向かって距離 \(x\) だけ動くと、およそ \(\frac{32\gamma Mx}{a^3}\) の外向きの合力が働く。公転面に垂直な方向には安定であり、およそ \(\frac{16\gamma Mz}{a^3}\) の復元力が働く。（公転面内で直線に垂直な方向には重力が復元力として働くが、回転によってこの運動は不安定な方向の運動と結びついてしまう。）

  3. \(m_1\) に働く力は \(\frac{\gamma m_1}{a^3}\bigl(m_2(P_2 - P_1) + m_3(P_3 - P_1)\bigr)\) である。\(m_1P_1 + m_2P_2 + m_3P_3 = (m_1 + m_2 + m_3)G\) であるから、これは \(\frac{\gamma m_1(m_1 + m_2 + m_3)}{a^3}(G - P_1)\) となる。どの星も、\(G\) からの距離に比例し、しかも同じ比例定数で \(G\) のほうへ引かれるので、すべての星が \(\omega^2 = \frac{\gamma(m_1 + m_2 + m_3)}{a^3}\) で剛体のように回転できる。

  4. \(k\) 個先の星は距離 \(2R\sin\frac{k\pi}{n}\) の位置にあり、その引力の中心向きの成分は \(\sin\frac{k\pi}{n}\) 倍である。よって \(m\omega^2R = \frac{\gamma m^2}{4R^2}\sum_{k=1}^{n-1}\frac{1}{\sin(k\pi/n)}\) であり、\(\omega^2 = \frac{\gamma m}{4R^3}\sum_{k=1}^{n-1}\frac{1}{\sin(k\pi/n)}\) を得る。\(n = 3\)、\(R = \frac{a}{\sqrt3}\) のとき、これは \(\frac{3\gamma m}{a^3}\) となる。
