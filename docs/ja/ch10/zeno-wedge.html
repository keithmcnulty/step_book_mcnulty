10.5

有限時間に無限回の跳ね返り

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第10章章全体のPDF
問題

STEP III 2002、第11問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/02-s3-q11

導入

エレアのゼノン（Zeno of Elea）は、壁には決してたどり着けないと論じた。まず距離の半分を進まなければならず、次に残りの半分を進まなければならず、これが永遠に続くからである。このパラドックスの解決、すなわち無限に多くの段階が有限の合計時間で済みうるということは、収束（converge）する無限級数（infinite series）にほかならない。この問題はゼノンのパラドックスを現実のものにしている。くさびの角に向かって滑っていくパックは、壁で無限回はね返るにもかかわらず、有限の時間で角に到達するのである。

自然界でも同じことが起こる。はね返り係数（coefficient of restitution）が \(1\) より小さいボールを床ではずませると、有限の時間内に無限回はずんだのち静止する。粒状体（granular materials）（砂、穀物、雪）のコンピュータ・シミュレーションでは、この「非弾性崩壊（inelastic collapse）」が実際に厄介な問題となる。コンピュータは有限の時間内に無限回の衝突を処理するよう求められてしまうからである。

取りかかる前に

はね返り係数 \(e\) のなめらかな壁に粒子が衝突するとき、速度の壁に沿った成分はどうなるか。壁に垂直な成分はどうなるか。

なめらかな壁は壁に沿った方向には力を及ぼさないので、速度の壁に平行な成分は変わらない。垂直な成分は向きが逆になり、\(e\) 倍される。したがって、粒子が壁と角 \(\alpha\) をなして到達し、角 \(\beta\) をなして離れるとすると、 \[\tan\beta = e\tan\alpha,\] であり、平行な成分は変わらないので、（入射の速さ）\(\cos\alpha\) =（反射の速さ）\(\cos\beta\) が成り立つ。

順を追って解く

段階 1 離れる角

粒子は壁 \(OA\) 上の点 \(M_1\) に、\(OA\) と角 \(\theta\)（\(O\) から遠い側で測る）をなして到達する。粒子は \(OA\) とどのような角 \(\varphi\) をなして離れるか。三角形 \(OM_1N_1\) を用いて、\(\varphi\) を \(\theta\) で表せ。

粒子は \(M_1\) を \(O\) の側に向かって、壁と角 \(\varphi\) をなして離れるので、角 \(OM_1N_1\) は \(\varphi\) である。三角形 \(OM_1N_1\) において、\(O\) における角は \(30^\circ\) である。\(N_1\) において角 \(M_1N_1B\) は \(\theta\) であり、\(O\)、\(N_1\)、\(B\) は一直線上にあるので、角 \(ON_1M_1\) は \(180^\circ - \theta\) である。三角形の内角の和は \(180^\circ\) であるから、 \[30^\circ + \varphi + (180^\circ - \theta) = 180^\circ, \qquad\text{よって}\qquad \varphi = \theta - 30^\circ.\] （特に \(\theta > 30^\circ\) である。）はね返りの法則 \(\tan\varphi = e\tan\theta\) から \[e = \frac{\tan(\theta - 30^\circ)}{\tan\theta},\] が得られ、平行な成分の保存 \(u_1\cos\theta = v_1\cos\varphi\) から \[\frac{v_1}{u_1} = \frac{\cos\theta}{\cos(\theta - 30^\circ)}. \qed\] が得られる。

段階 2 同じパターンの繰り返し

\(N_1\) において、粒子は壁 \(OB\) と角 \(\theta\)（\(O\) から遠い側で測る）をなして到達する。これを \(M_1\) への到達と比べよ。次に何が起こるか。

\(N_1\) における状況は、\(M_1\) における状況の鏡像である。粒子は \(O\) から遠い側で、壁と角 \(\theta\) をなして壁に出会う。したがって粒子は角 \(\theta - 30^\circ\) をなして離れ、再び \(OA\) に角 \(\theta\) をなして出会い、これが永遠に続く。どのはね返りも最初のはね返りを縮小した写しである。三角形 \(OM_kN_k\)、\(ON_kM_{k+1}\)、… はそれぞれ直前の三角形と相似であり（図 10.5.1）、速さはどのはね返りでも同じ倍率で掛けられる。

段階 3 二つの比

\(O\) からの距離は、一つのはね返りから次のはね返りまでにどんな倍率 \(\rho\) で縮むか。速さはどんな倍率 \(k\) で縮むか。では、各区間にかかる時間はどんな倍率で縮むか。

三角形 \(OM_1N_1\) における正弦定理（sine rule）から \[\rho = \frac{ON_1}{OM_1} = \frac{\sin\varphi}{\sin(180^\circ - \theta)} = \frac{\sin(\theta - 30^\circ)}{\sin\theta}.\] 次の三角形のすべての長さはこの三角形の長さの \(\rho\) 倍なので、経路の各区間の長さは直前の区間の \(\rho\) 倍である。速さは各はね返りで \(k = \frac{\cos\theta}{\cos(\theta - 30^\circ)}\) 倍される。時間は長さを速さで割ったものなので、各区間にかかる時間は直前の区間の \[\frac{\rho}{k} = \frac{\sin(\theta - 30^\circ)\cos(\theta - 30^\circ)}{\sin\theta\cos\theta} = \frac{\sin(2\theta - 60^\circ)}{\sin 2\theta}\] 倍である。

段階 4 等比級数

合計時間は \(T_1(1 + r + r^2 + \cdots)\) である。ここで \(T_1\) は最初の区間にかかる時間であり、\(r = \frac{\sin(2\theta - 60^\circ)}{\sin 2\theta}\) である。これは \(0 < r < 1\) ならば有限である。

\(\sin(2\theta - 60^\circ) < \sin 2\theta\) となるのはどのようなときか。恒等式 \(\sin X - \sin Y = 2\cos\tfrac12(X + Y)\sin\tfrac12(X - Y)\) を用いよ。

\[\sin 2\theta - \sin(2\theta - 60^\circ) = 2\cos(2\theta - 30^\circ)\sin 30^\circ = \cos(2\theta - 30^\circ),\] これは \(2\theta - 30^\circ < 90^\circ\)、すなわち \(\theta < 60^\circ\) のとき正である。また \(\theta > 30^\circ\) より \(r > 0\) である。したがって \(30^\circ < \theta < 60^\circ\) のとき、この等比級数（geometric series）は収束する。粒子は無限回はね返り、\(O\) からの距離は毎回倍率 \(\rho < 1\) で縮み、有限の時間 \(\frac{T_1}{1 - r}\) の後に \(O\) に到達する。■

振り返り

  • 自己相似性（self-similarity）。一つのはね返りを理解すれば、それ以降のはね返りはすべてその縮小された写しなので、無限に続く過程全体が二つの比に帰着した。

  • 比を正しく組み合わせる。距離は \(\rho\) 倍、速さは \(k\) 倍に縮むので、時間は \(\rho/k\) 倍に縮む。

  • 無限回の出来事、有限の合計。公比が \(1\) より小さい等比級数は収束する。

背後にある数学

\(\theta \geq 60^\circ\) のとき

\(\theta = 60^\circ\) のとき、比はちょうど \(1\) である。どの区間にも同じ時間がかかり、粒子は \(O\) にいくらでも近づくものの、決して到達しない。（速さと区間の長さがどちらも同じ倍率で縮むためである。）\(\theta > 60^\circ\) のときは、区間にかかる時間はどんどん長くなる。いずれの場合も粒子は \(O\) に近づき、無限回はね返るが、有限の時間で到達するのは \(\theta < 60^\circ\) のときだけである。値 \(e = \tan 30^\circ/\tan 60^\circ = \frac13\) がその境目である。

はずむボールと非弾性崩壊

同じ現象の最も簡単な例として、床に落としたボールは高さ \(e^2H\) まで上がり、次に \(e^4H\) まで上がり、と続く。はね返りの間隔はそれぞれのはね返りでの速さに比例し、速さは倍率 \(e\) で縮むので、合計時間は等比級数になる。最初の落下にかかる時間を \(T_0 = \sqrt{2H/g}\) とすると、ボールは \[T_0 + 2eT_0 + 2e^2T_0 + \cdots = T_0\,\frac{1 + e}{1 - e}.\] の後にはずむのをやめる。無限回はずんで、そして静止するのである。1992年、Sean McNamara と William Young は、一直線上に並んだ多数の非弾性粒子のシミュレーションでも同じことが起こることを示した。粒子の集団が有限の時間内に無限回の衝突を起こしうるのであり、これが「非弾性崩壊」である。砂や粒状流のシミュレーションでは、これを避けるための特別な規則を組み込まなければならない。また、この現象は粒状気体が自発的にクラスターを形成する理由の説明にも役立っている。

ゼノンと収束

紀元前450年頃のゼノンのパラドックスは、二千年にわたって哲学者たちを悩ませた。数学的な解決、すなわち無限和が有限の値をもちうるということが厳密にされたのは、ようやく19世紀になってからである。このとき、コーシー（Cauchy）、ワイエルシュトラス（Weierstrass）らが極限を用いて収束を定義した（第 2章の主題である）。この問題の驚くべき点は、過程が物理的に無限であることである。有限の時間内に、本当に無限回の衝突が起こるのである。多角形の中のビリヤードや衝突する粒子の運動を研究する数学者は、このような振る舞いをゼノン現象と呼ぶ。これは、衝突する剛体球の系がすべての時刻にわたって矛盾なく定まった運動をもつことを証明する際の難所の一つである。

思考のスキル

無限に続く過程を足し合わせる

過程が一定の倍率で繰り返されるとき、加法的な量（時間、距離、エネルギー）の合計は等比級数になる。収束するかどうかは公比から判定する。

ここでの鍵は、正しい比を見つけることであった。距離の比でも速さの比でもなく、時間の比である。大学では、同じ推論が反復法の収束、フラクタルの理論、そして問題を繰り返し半分にするアルゴリズムの解析を支配している。

次の一歩

  1. 移動距離の合計。\(30^\circ\) と \(90^\circ\) の間のすべての \(\theta\) について、\(M_1\) から \(O\) までに移動する距離の合計が有限であることを示し、それを \(OM_1\) と \(\theta\) で表せ。

  2. ほかのくさび。\(30^\circ\) の代わりに角 \(\alpha\) のくさびについて、この問題をもう一度考えよ。\(\varphi = \theta - \alpha\) を示し、粒子が有限の時間で \(O\) に到達するための \(\theta\) の条件を求めよ。

  3. 弾性的な壁。\(e = 1\) のとき、粒子が \(O\) に到達することはあるか。（ヒント：くさびをその壁に関して繰り返し折り返し、経路が直線になるようにせよ。\(30^\circ\) のくさびの写しは \(O\) のまわりにいくつ収まるか。）

  4. はずむボール。ボールを高さ \(1\) m から \(e = 0.8\) で落とす。ボールはどれだけの時間はずみ続け、合計でどれだけの距離を移動するか。（\(g = 9.8\) m s\(^{-2}\) とせよ。）

さらに学ぶために

  • David Morin, Introduction to Classical Mechanics（Cambridge University Press）、第5章。はずむボールや無限に続く衝突の列に関する問題がいくつか収められている。

  • Sean McNamara & William Young, 「Inelastic collapse and clumping in a one-dimensional granular medium」, Physics of Fluids A 4 (1992).

  • Serge Tabachnikov, Geometry and Billiards（American Mathematical Society、オンラインで無料公開）。ビリヤードの数学を扱い、演習問題で用いた折り返しの技法も含まれている。
