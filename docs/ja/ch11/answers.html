第11章 · 振動・回転・運動する座標系

「次の一歩」の解答

以下は簡潔な解答とヒントであり、完全な解答ではない。結果と鍵となるステップを示しているので、自分の答えの確認に使ってほしい。答えを見る前に、それぞれの問題にきちんと取り組むこと。

11.1 共鳴

  1. エレベーターの座標系（frame of reference）では、重力は実質的に \(g - f\) となり、糸のばね定数（stiffness）は \(\frac{mg}{a}\) である（\(mg\) のもとで \(a\) だけ伸びるから）。よって \(\ddot y + \frac gay = g - f\) であり、はじめに \(y = a\), \(\dot y = 0\) である。新しいつり合いの位置（equilibrium）は \(a - \frac{af}{g}\) なので、\(y = a - \frac{af}{g}(1 - \cos\omega t)\) となる。振幅（amplitude）は \(\frac{af}{g}\) であり、最小の伸び \(a(1 - \frac{2f}{g})\) は正である。エレベーターの加速が止まると、つり合いの位置は \(a\) に戻り、粒子は変位 \(-\frac{af}{g}(1 - \cos\omega T)\) の位置にあって、速度 \(-\frac{af}{g}\omega\sin\omega T\) をもつ。新しい振幅は \(\frac{af}{g}\sqrt{(1 - \cos\omega T)^2 + \sin^2\omega T} = \frac{2af}{g}\bigl|\sin\frac12\omega T\bigr|\) である。

  2. \(x = Ct\cos nt\) とすると \(\ddot x + n^2x = -2Cn\sin nt\) となるので、\(C = -\frac{nb}{2}\) である。初期条件を満たすように \(\frac b2\sin nt\) を加えると、\(x = \frac b2(\sin nt - nt\cos nt)\) となる。問題文の式に \(p\) についてロピタルの定理（L’Hôpital’s rule）を適用すると、\(p \to n\) のとき同じ結果が得られる。

  3. \(n\sin pt - p\sin nt = n(\sin pt - \sin nt) + (n - p)\sin nt = 2n\cos\frac{(n + p)t}{2}\sin\frac{(p - n)t}{2} + (n - p)\sin nt\) である。第2項は小さい。第1項は、ゆっくり変化する包絡線（envelope）\(\bigl|\sin\frac{(n - p)t}{2}\bigr|\) の内側での速い振動であり、この包絡線は \(\frac{2\pi}{n - p}\) ごとに繰り返す。

  4. 振幅は \(\frac{F}{\sqrt{(n^2 - p^2)^2 + 4k^2p^2}}\) である。分母を \(p^2\) について最小化すると \(-2(n^2 - p^2) + 4k^2 = 0\) となるので、\(p^2 = n^2 - 2k^2\) である。

11.2 基準振動

  1. 微分すると、エネルギーの変化率は \(\dot x\bigl(m\ddot x + \frac\lambda a(2x + y)\bigr) + \dot y\bigl(m\ddot y + \frac\lambda a(x + 2y)\bigr) = 0\) である。\(u = x - y\), \(v = x + y\) とおくと、エネルギーは \(\bigl(\frac m4\dot u^2 + \frac{\lambda}{4a}u^2\bigr) + \bigl(\frac m4\dot v^2 + \frac{3\lambda}{4a}v^2\bigr)\) となり、それぞれの括弧は単振動子（simple harmonic oscillator）のエネルギーなので、それぞれが一定である。

  2. 周期（period）\(\frac{2\pi}{\omega}\) の場合：\(x = -y\) かつ \(\dot x = -\dot y\) から始める（こうすると \(v \equiv 0\) となる）。周期 \(\frac{2\pi}{\sqrt3\omega}\) の場合：\(x = y\) かつ \(\dot x = \dot y\) から始める。

  3. \(X\) にはたらく力は \(-\frac\lambda ax - \frac\mu a(x + y)\) である。振動モード（mode）\(x - y\) は依然として \(\omega^2 = \frac{\lambda}{ma}\) をもち、\(x + y\) は \(\frac{\lambda + 2\mu}{ma}\) をもつようになる。すべての運動が周期的になるのは、ちょうど振動数（frequency）の比 \(\sqrt{1 + 2\mu/\lambda}\) が有理数であるときである。

  4. 行列は \(\frac km\begin{pmatrix} 2 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 2 \end{pmatrix}\) であり、\(2 - \sqrt2\), \(2\), \(2 + \sqrt2\) に対する固有ベクトル（eigenvector）はそれぞれ \((1, \sqrt2, 1)\), \((1, 0, -1)\), \((1, -\sqrt2, 1)\) である。各モードは次のとおりである：3つすべてが同じ向きに振れ、真ん中が最も大きく振れる。外側の2つが逆向きに振れ、真ん中は静止している。真ん中が外側の2つと逆向きに振れる。

11.3 本当の振り子

  1. エネルギー：\(\frac12m\dot x^2 + \frac{\lambda}{2a}\bigl(\sqrt{x^2 + a^2} - a\bigr)^2 = \frac12mv^2\)。最大変位では \(\sqrt{x^2 + a^2} = a + \frac vk\) なので、\(x_{\max} = \sqrt{\frac{2av}{k} + \frac{v^2}{k^2}}\) である。\(v\) が小さいとき、伸びはおよそ \(\frac{x^2}{2a}\) なので、\(\dot x^2 \approx v^2 - \frac{k^2x^4}{4a^2}\) となる。\(x = Xu\), \(X = \sqrt{2av/k}\) とおくと、周期 \(4\int_0^X\frac{\mathrm{d}x}{\dot x}\) は \(\frac{4X}{v}\int_0^1\frac{\mathrm{d}u}{\sqrt{1 - u^4}}\) となる。復元力（restoring force）は \(x\) ではなく \(x^3\) に比例する（\(x = 0\) で糸はちょうど自然長にある）ので、単振動の極限は存在しない。

  2. \(m = \sin^2\frac\gamma2 \approx \frac{\gamma^2}{4} - \frac{\gamma^4}{48}\) として、\((1 - m\sin^2\phi)^{-1/2} \approx 1 + \frac m2\sin^2\phi + \frac{3m^2}{8}\sin^4\phi\) である。\(\phi\) について平均をとると \(1 + \frac m4 + \frac{9m^2}{64}\) となり、\(\gamma^4\) の項は \(-\frac{1}{192} + \frac{9}{1024} = \frac{11}{3072}\) である。

  3. \(1\) と \(\cos45^\circ = 0.70711\) から始めると、\((0.85355, 0.84090)\)、次に \((0.84722, 0.84720)\)、さらに \(0.847213\) となる。周期の倍率は \(\frac{1}{0.847213} = 1.18034\) である。

  4. 周期の倍率は \(\frac{1}{16}(\gamma_5^2 - \gamma_4^2) \approx 1.71 \times 10^{-4}\)（ラジアンで計算）だけ変化するので、時計は1日におよそ \(15\) 秒遅れる。

11.4 等時曲線

  1. \(y = \frac{s^2}{4k}\) なので \(\ddot s = -g\frac{\mathrm{d}y}{\mathrm{d}s} = -\frac{g}{2k}s\) となり、これは \(\omega^2 = \frac{g}{2k}\) の単振動である。\(s_0 = 2\sqrt{kh}\) から、\(V\) での速さは \(\omega s_0 = \sqrt{2gh}\) である。

  2. お椀は長さ \(R\) の振り子（pendulum）である。小さな高さから放すと、底までの時間は \(\frac\pi2\sqrt{R/g}\) である。縁（\(\gamma = 90^\circ\)）から放すと、その \(1.180\) 倍、およそ \(1.85\sqrt{R/g}\) となる。

  3. はい。両者は4分の1周期後に \(V\) に達し、そこで衝突する。どのような速度で離れても、それぞれは \(s\) について同じ周期の単振動を行うので、ちょうど半周期後にそれぞれ \(V\) に戻り、再び \(V\) で衝突する。（\(V\) で静止したまま残された粒子は、単にそこにとどまる。）

  4. \(x = R(\theta - \sin\theta)\), \(y = R(1 - \cos\theta)\) とすると \(\mathrm{d}s = 2R\sin\frac\theta2\,\mathrm{d}\theta\) なので、1つの弧（arch）の長さは \(\int_0^{2\pi}2R\sin\frac\theta2\,\mathrm{d}\theta = 8R\) である。面積は \(\int y\,\mathrm{d}x = R^2\int_0^{2\pi}(1 - \cos\theta)^2\,\mathrm{d}\theta = 3\pi R^2\) である。

11.5 加速する列車の中の重力

  1. 客車の座標系では、単位質量あたり \(a\) の後ろ向き（南向き）の力がはたらき、これは発射の向きである。飛行時間を \(\frac{2V\sin\theta}{g}\) として、到達距離（range）は \(\frac{V^2}{g}\bigl(\sin2\theta + \frac ag(1 - \cos2\theta)\bigr)\) である。その導関数が \(0\) になるのは \(\tan2\theta = -\frac ga\) のときなので、\(2\theta \approx \frac\pi2 + \frac ag\) である。最大値は \(\frac{V^2}{g}\bigl(\sqrt{1 + a^2/g^2} + \frac ag\bigr) \approx \frac{V^2}{g} + \frac{V^2a}{g^2}\) である。

  2. \(x = ut\cos\theta - \frac12ft^2\) であり、\(t = \frac{2u\sin\theta}{g}\) で着地し、そのとき \(x = \frac{2u^2\sin\theta}{g^2}(g\cos\theta - f\sin\theta)\) である。水平方向の速度 \(u\cos\theta - ft\) が着地前に負になるのは \(\tan\theta > \frac{g}{2f}\) のときなので、\(\alpha = \tan^{-1}\frac{g}{2f}\) である。\(f = g\), \(\theta = 45^\circ\) のとき、加速度は初速度とちょうど逆向きである：投射体は直線 \(y = x\) に沿ってまっすぐ上がり、止まり、まっすぐ \(O\) に戻ってくる。

  3. 実効的な重力（effective gravity）は、下向きの \(g\) と後ろ向きの \(a\) を合わせたものである。自由表面（free surface）はこれに垂直なので、\(\tan^{-1}\frac ag\) だけ傾く。

  4. 実効的な重力の大きさは \(\sqrt{g^2 + a^2}\) であり、\(x = \frac{ak}{2g}\) で傾きは \(\frac ag\)、曲率半径（radius of curvature）は \(\rho = \frac{k}{2}\bigl(1 + \frac{a^2}{g^2}\bigr)^{3/2}\) である。周期は \(2\pi\sqrt{\rho/\sqrt{g^2 + a^2}} = 2\pi\sqrt{\frac{k(g^2 + a^2)}{2g^3}}\) であり、\(a = 0\) のとき \(2\pi\sqrt{\frac{k}{2g}}\) に帰着する。

11.6 バックスピン

  1. 摩擦は接点にはたらくので、その点のまわりの角運動量（angular momentum）は保存される：\(maV + \frac25ma^2\frac Va = mav_0 + \frac25ma^2\omega_0\)。よって \(V = \frac{5v_0 + 2a\omega_0}{7}\) であり、これが \(v_0\) を超えるのは \(\frac{v_0}{a\omega_0} < 1\) のときである。

  2. \(V = \frac57v_0\) である。最終的なエネルギーは \(\frac12m\bigl(\frac57v_0\bigr)^2\bigl(1 + \frac25\bigr) = \frac57 \cdot \frac12mv_0^2\) なので、エネルギーの \(\frac27\) が失われる。

  3. \(I = ma^2\) として同じ議論をすると \(V = \frac12(v_0 - a\omega_0)\) となる。\(V = -\frac{v_0}{7}\) とおくと \(\frac{v_0}{a\omega_0} = \frac79\) を得る。

  4. 中心から高さ \(h\) のところに撃力（impulse）\(J\) を加えると、\(mv = J\) かつ \(\frac25ma^2\omega = Jh\) となる。転がる（rolling）ためには \(v = a\omega\) が必要なので、\(h = \frac25a\) である。

11.7 棒の中のシンプソンの公式

  1. \(\frac16\bigl(1 + 4 \cdot \frac45 + \frac12\bigr) = \frac{47}{60} \approx 0.7833\) であり、これを \(\frac\pi4 \approx 0.7854\) と比べる。\(\int_{-1}^1\) に対して、公式 \(\frac13\bigl(\mathrm{f}(-1) + 4\mathrm{f}(0) + \mathrm{f}(1)\bigr)\) は \(x^3\) に対して \(0\)、\(x^2\) に対して \(\frac23\) を与える（どちらも正確）が、\(x^4\) に対しても \(\frac23\) を与えてしまい、その積分は \(\frac25\) である。

  2. 角度 \(\psi\) の軸のまわりの慣性モーメント（moment of inertia）は二次形式（quadratic form）\(A\cos^2\psi + B\sin^2\psi + 2C\sin\psi\cos\psi\) である。\(\psi \mapsto \psi + 90^\circ\) に関する不変性から \(A = B\) かつ \(C = 0\) が従うので、どの軸についても同じ値となる：それは辺に平行な軸のまわりの値 \(\frac13Ma^2\) である。

  3. 面積の \(\frac13\) をそれぞれの中点に置くと、三角形上であらゆる二次式が正確に積分される（直角三角形上で \(1\), \(x\), \(x^2\), \(xy\) を確かめよ）。よって3つの粒子は、薄板（lamina）と同じ質量、重心（centre of mass）、二次モーメント（second moment）をもつ。

  4. 各方向について、\(-a\), \(0\), \(a\) における棒の重み \(\frac16\), \(\frac23\), \(\frac16\) の積をとる：頂点に \(\frac{M}{216}\)、辺の中点に \(\frac{M}{54}\)、面の中心に \(\frac{2M}{27}\)、中心に \(\frac{8M}{27}\) である。中心を通り辺に平行な軸のまわりでは \(I = M\bigl(\frac{a^2}{3} + \frac{a^2}{3}\bigr) = \frac23Ma^2\) である。平行軸の定理（parallel axis theorem）により、辺のまわりでは \(\frac23Ma^2 + M(\sqrt2a)^2 = \frac83Ma^2\) となる。

11.8 傾いたつり合い

  1. 共通の面から円錐（cone）の側に向かって測ると、\(G\) は \(\frac{-\frac23 \cdot \frac{3a}{8} + \frac\lambda3 \cdot \frac{\lambda a}{4}}{\frac23 + \frac\lambda3} = \frac{a(\lambda^2 - 3)}{4(2 + \lambda)}\) にある。半球上では、接点における法線は常に面の中心を通るので、\(G\) がその中心より下にあるとき、すなわち \(\lambda < \sqrt3\) のとき、おもちゃは起き上がる。横倒しになったとき、おもちゃは円錐の母線（generator）と縁でテーブルに接し、\(G\) を通る鉛直線が頂点と縁の間にあればその状態にとどまる。そのためには \(G\) の高さが \(-\frac a\lambda\) 以上であることが必要であり、これは \(\lambda^3 + \lambda + 8 > 0\) に帰着する：これは常に成り立つ。

  2. 一様な球では、あらゆる点がつり合いの位置である（中立（neutral））。重心が中心からわずかにずれていれば、つり合いの位置はちょうど2つになる：\(G\) が最も低いとき（安定（stable））と、\(G\) が最も高いとき（不安定（unstable））である。

  3. つり合いの位置は法線が中心を通るところ、すなわち軸の4つの端で生じる。短軸（minor axis）の端で静止するのは安定であり（\(G\) ができるだけ低い）、長軸（major axis）の端では不安定である。

  4. 対称性により \(G\) は原点にある。\(n = 2\) のとき \(Y = r\bigl(\frac12 - p^2\bigr)\) であり、傾いたつり合いでは法線が \(G\) を通る必要があるので、\(Y = 0\) かつ \(p = \frac{1}{\sqrt2}\) である。そこでの傾きは \(-\sqrt2\) なので、\(\overrightarrow{AB}\) は \(\tan^{-1}\sqrt2 \approx 54.7^\circ\) だけ傾き、もう一方の放物面（paraboloid）上で静止するときは \(125.3^\circ\) となる。両者は \(x\) 軸に関して互いに鏡映であり、これが傾きが対になる理由である。

11.9 安全放物線

  1. 各粒子は \(ut\,\hat{\mathbf{n}} - \frac12gt^2\mathbf{j}\) にあり、これは \(-\frac12gt^2\mathbf{j}\) を中心とする半径 \(ut\) の球面である。\((0, \frac{u^2}{2g})\) から水平に発射された粒子は \(y = \frac{u^2}{2g} - \frac{gx^2}{2u^2}\) に沿って動く：これはちょうど安全放物線（parabola of safety）である。角度 \(\alpha\) で発射された粒子は、時刻 \(\frac{u}{g\sin\alpha}\) に \(x = \frac{u^2}{g\tan\alpha}\) でこれに接する。水平に発射された粒子はそこへ達するのに \(\frac{x}{u}\) かかるので、時刻 \(\frac{u(1 - \cos\alpha)}{g\sin\alpha} = \frac ug\tan\frac\alpha2\) に発射されなければならない（これには、接点が地面より上にあるように \(\alpha \geq 45^\circ\) であることが必要である）。

  2. 直線と安全放物線が交わるのは \(R\sin\beta = \frac{u^2}{2g} - \frac{gR^2\cos^2\beta}{2u^2}\) のところであり、\(R = \frac{u^2}{g(1 + \sin\beta)}\) を得る。最大のときは問題3の2つの角が一致するので、最適な角は二等分線の方向、すなわち \(45^\circ + \frac12\beta\) である。

  3. \(\lambda = \tan\theta\) とおくと、2つの値は \(\lambda_1 + \lambda_2 = \frac{2u^2}{gx}\) および \(\lambda_1\lambda_2 = 1 + \frac{2u^2y}{gx^2}\) を満たす。よって \(\tan(\theta_1 + \theta_2) = -\frac xy\) であり、\(\theta_1 + \theta_2 = 90^\circ + \varphi\) となる。ここで \(\varphi\) は \(OP\) の仰角（elevation）である。\(OP\) と鉛直線の二等分線は \(\frac12(90^\circ + \varphi)\) の角をなす。

  4. 頂点は \(\bigl(\frac{u^2}{2g}\sin2\theta, \frac{u^2}{2g}\sin^2\theta\bigr)\) にあり、焦点距離（focal length）は \(\frac{u^2\cos^2\theta}{2g}\) なので、焦点（focus）の高さは \(\frac{u^2}{2g}(\sin^2\theta - \cos^2\theta)\) である。\(O\) からの距離は \(\theta\) によらず \(\frac{u^2}{2g}\) である。

11.10 こちらへ戻ってくるボール

  1. \(u = g = 1\) となる単位系で \(\frac{\mathrm{d}}{\mathrm{d}t}OP^2 = t(t^2 - 3t\sin\alpha + 2)\) であり、その根は \(t \approx 1.050\)（極大（local maximum）、\(OP \approx 0.516\frac{u^2}{g}\)）と \(t \approx 1.904\)（極小（local minimum）、\(OP \approx 0.336\frac{u^2}{g}\)）である。ボールは \(t \approx 1.970\) で着地する。

  2. 斜面に沿った方向と斜面に垂直な方向に分解すると、\(OP^2 = u^2t^2 - ugt^3\sin(\alpha' + \beta) + \frac14g^2t^4\) となる。ここで \(\alpha'\) は斜面から測った角である。これは水平な地面の場合の式で \(\alpha = \alpha' + \beta\) としたものである。よって条件 \(\sin(\alpha' + \beta) > \frac{2\sqrt2}{3}\) は水平面から測った角に関するものであり、斜面から測ると、臨界角は \(70.5^\circ - \beta\) に下がる（ただし、ボールがまだ着地していなければである）。

  3. 小さくなる。空気抵抗（drag）は水平方向の運動を弱め、下降をより急にするので、ボールはより鉛直に近い向きで落ちて戻ってくる。そのため \(OP\) が縮みやすくなる。

  4. \(OP^2\) の式は着地点を含まないので、\(OP\) がある時間減少するのは、前と同じくちょうど \(\sin\alpha > \frac{2\sqrt2}{3}\) のときである（そして飛行時間が長くなるので、減少する段階は必ず着地前に起こる）。やがて落下が支配的になり、\(OP\) は増加する。

11.11 野手はどのように捕球するか

  1. 彼女が \(D_0\) に立ち、打者（batsman）から遠ざかる向きに速度 \(v\) で走るとすると、ボールは彼女の前方 \(D_0 + vt - Ut\) の距離にある。捕球するには \(D_0 + vT = UT\) が必要であり、そのとき距離は \((U - v)(T - t)\) なので、\(\tan\theta = \frac{gt}{2(U - v)}\) となり、やはり一次式である。ボールが彼女の後方に落ちるなら、\(UT > D_0\) かつ \(v > 0\) である：彼女は後ろへ走る。

  2. \(\theta = \tan^{-1}\frac{gt}{2U}\) なので \(\dot\theta = \frac{g/2U}{1 + (gt/2U)^2}\) となり、これは減少する。\(\tan\theta\) が一次式になるのは、高さ \(\frac12gt(T - t)\) と距離 \(U(T - t)\) が共通因数 \(T - t\) をもつからである。

  3. はい。彼女の目の高さを基準としたボールの高さは、捕球の時点で \(0\) となる二次式なので、\((T - t)(c + dt)\) と因数分解される。これを \(U(T - t)\) で割ると一次関数が残る（これは負から始まる：彼女は最初、下を見る）。

  4. いいえ。空気抵抗があると、水平距離は \(\frac Uk(\mathrm{e}^{-kt} - \mathrm{e}^{-kT})\) となり、高さはこれに \(t\) の一次関数を掛けたものにはならないので、\(\tan\theta\) はもはや一次式ではない。

11.12 ゴムひもの上のアリ

  1. \(\frac{x}{a + ut} = \frac1k\ln\frac{a + ut}{a}\) であり、これは \(t = \frac au(\mathrm{e}^{k/2} - 1)\) で \(\frac12\) となる。\(\frac T2 = \frac{a}{2u}(\mathrm{e}^{k/2} - 1)(\mathrm{e}^{k/2} + 1)\) であり、\(\frac12(\mathrm{e}^{k/2} + 1) > 1\) なので、これは \(\frac T2\) より前である。

  2. \(\frac{\mathrm{d}}{\mathrm{d}t}\frac xL = \frac vL = \frac va\mathrm{e}^{-\lambda t}\) なので \(\frac xL = \frac{v}{a\lambda}(1 - \mathrm{e}^{-\lambda t})\) となり、これが \(1\) に達するのは \(v > \lambda a\) のときに限る。

  3. \(\frac xL = v\int_0^t\frac{\mathrm{d}s}{a + \frac12bs^2}\) であり、これは \(\frac{v\pi}{\sqrt{2ab}}\) に収束（converge）する。よってアリが到達するのは \(v > \frac{\sqrt{2ab}}{\pi}\) のときに限る。

  4. \(\frac{H_N}{100\,000} = \frac{1}{100}\) が必要なので、\(H_N = 1000\) であり、\(N \approx \mathrm{e}^{999.4} \approx 10^{434}\) 秒である。

11.13 除雪車問題

  1. 正午から時間 \(t\) 後の積雪の深さは \(t + t_0\) に比例するので、進んだ距離は \(c\ln\frac{t + t_0}{t_0}\) である。条件 \(x(1) = 2\) と \(x(2) = 3\) から \(\bigl(1 + \frac{1}{t_0}\bigr)^3 = \bigl(1 + \frac{2}{t_0}\bigr)^2\) を得る。\(u = \frac{1}{t_0}\) とおくとこれは \(u^2 - u - 1 = 0\) に帰着するので、\(u = \frac{1 + \sqrt5}{2}\) であり、\(t_0 \approx 0.618\) 時間である：雪が降り始めたのはおよそ 11:23 である。

  2. \(\frac{\mathrm{d}t}{\mathrm{d}y} = \frac{\alpha h}{k}\mathrm{e}^{\alpha y} - \frac{\alpha h}{k}\mathrm{e}^{\alpha y} + \alpha\bigl(T - \frac{\alpha hy}{k}\bigr)\mathrm{e}^{\alpha y}\) であり、\(\alpha\bigl(t - (\mathrm{e}^{\alpha y} - 1)\frac hk\bigr)\) もこれと同じである。

  3. 間隔は \(\bigl(T - \frac{\alpha hy}{k}\bigr)\mathrm{e}^{\alpha y}\) であり、その導関数は \(y = \frac{kT - h}{\alpha h}\) で \(0\) になる。\(kT > h\) ならば、間隔はそこまで増加し、その後 \(y = \frac{kT}{\alpha h}\) で \(0\) まで縮む。\(kT \leq h\) ならば、導関数 \(\alpha\mathrm{e}^{\alpha y}\bigl(T - \frac hk - \frac{\alpha hy}{k}\bigr)\) はすべての \(y > 0\) で負なので、間隔は最初から縮む。2台目の除雪車（snowplough）は深さ \(k \times\)（間隔）の雪に直面する。これが同じ場所で1台目が出会った雪より深い間は、2台目はさらに遅れていく。

  4. \(\frac1\alpha\frac{\mathrm{d}t_3}{\mathrm{d}y} = t_3 - t_2(y)\) である。\(t_3 = t_2 + g\) とおくと \(g = \mathrm{e}^{\alpha y}\bigl(T - \alpha Ty + \frac{\alpha^2hy^2}{2k}\bigr)\) を得る。\(kT \geq 2h\) ならば、これは2台目が1台目に追いつく前に \(y = \frac{k}{\alpha h}\bigl(T - \sqrt{T^2 - 2hT/k}\bigr)\) で \(0\) となる。\(kT < 2h\) ならば、先に2台目が1台目に追いつく。

11.14 懸垂線ではなく放物線

  1. はい。水平方向の張力（tension）\(H\) は依然として一定であり、中央の区間の傾きは \(0\) で、そこから傾きは \(\frac wH\) ずつ増えていく。水平な区間の中点から \(x\) を測ると、\(k\) 番目の継ぎ目は \(x = (k - \frac12)h\) にあり、最も低い継ぎ目より \(\frac{wh}{2H}k(k - 1)\) だけ高い。これは \(\frac{w}{2Hh}\bigl(x^2 - \frac{h^2}{4}\bigr)\) であり、放物線である。

  2. 張力は \(\sqrt{H^2 + V^2}\) であり、鉛直成分 \(V\) が最大のところで最大となる：それは両端の区間であり、そこで \(V\) は荷重の半分 \(\frac{(2n + 1)w}{2}\) を支える。よって \(T_{\max} = \sqrt{H^2 + \frac14(2n + 1)^2w^2}\) である。

  3. \(y' = \sinh\frac xc\) であり、\(y'' = \frac1c\cosh\frac xc = \frac1c\sqrt{1 + \sinh^2\frac xc}\) である。長さは \(\int_0^X\cosh\frac xc\,\mathrm{d}x = c\sinh\frac Xc\) である。

  4. たるみ \(s\) の浅い曲線では、懸垂線（catenary）と放物線の長さはどちらもおよそ \(2d + \frac{4s^2}{3d}\) なので、どちらも \(s \approx \sqrt{\frac32d(L - d)}\) を与える。両者は \(s^4\) の次数でしか違わない。ほとんどぴんと張った鎖では、その差はガリレオ（Galileo）が測定できたどんなものよりもはるかに小さい。
