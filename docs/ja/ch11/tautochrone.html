11.4

等時曲線

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第11章章全体のPDF
問題

STEP III 1994、第9問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/94-s3-q9

導入

お椀の内側で、2つのビー玉を同時に放す。1つは縁の近くから、もう1つは底のすぐ上からである。どちらが先に底に着くだろうか。普通のお椀では、低いところから出発した方がたいてい先に着く。ところが、どこから出発しても必ず同時に到着するお椀が存在する。それが等時曲線（tautochrone、ギリシャ語で「同じ時間」の意）であり、その断面はサイクロイド（cycloid）、すなわち転がる車輪の縁上の1点が描く曲線である。

ホイヘンス（Huygens）は1659年にこのことを発見し、振れ幅によらない周期をもつ振り子時計の設計に用いて、第 11.3 節 で見た欠点を正した。この問題では、正しい変数、つまり水平方向の位置ではなく曲線に沿った距離を選ぶことで、等時性を数行で証明する。

取りかかる前に

お椀はなめらかである。粒子にはどのような力がはたらき、そのうちどれが仕事をするか。

重力と垂直抗力（normal reaction）である。垂直抗力は面に垂直であり、したがって運動の向きにも垂直なので、仕事をしない。仕事をするのは重力だけであり、エネルギーは保存される。

順を追って解く

段階 1 曲線に沿ったエネルギー

\(s\) は弧長（arc length）なので、面に沿った粒子の速さは \(\bigl|\frac{\mathrm{d}s}{\mathrm{d}t}\bigr|\) である。エネルギー保存則（conservation of energy）より \(\frac12m\dot s^2 + mgy =\) 定数となるので、\(\dot s^2 + 2gy\) は一定である。■

段階 2 \(s\) についての単振動

\(s = 2\sqrt{ky}\) を用いて、\(y\) を \(s\) の関数で置き換えよ。得られる方程式はどのような運動を表すか。

\(y = \frac{s^2}{4k}\) であるから、エネルギーの式は \[\dot s^2 + \frac{g}{2k}s^2 = \text{定数} = \frac{g}{2k}s_0^2,\] となる。ここで \(s_0 = 2\sqrt{kh}\) は出発点での弧長である（粒子は静止状態から出発する）。微分すると \(2\dot s\ddot s + \frac gk s\dot s = 0\) となるので、 \[\ddot s = -\frac{g}{2k}\,s.\] これは変数 \(s\) についての単振動（simple harmonic motion）であり、振幅（amplitude）によらず \(\omega^2 = \frac{g}{2k}\) である。すなわち \(s = s_0\cos\omega t\) となる。

段階 3 底に着くまでの時間

粒子は周期（period）の4分の1の時間ののちに \(V\)（\(s = 0\) となる点）に到達する。その時間は \[\frac{\pi}{2\omega} = \frac\pi2\sqrt{\frac{2k}{g}} = \pi\sqrt{\frac{k}{2g}},\] であり、\(h\) によらない。■

なぜうまくいくのだろうか。曲線に沿った「復元力」（restoring force）は \(g\) と傾きの積 \(g\frac{\mathrm{d}y}{\mathrm{d}s} = \frac{g}{2k}s\) であり、曲線に沿って測った底からの距離にちょうど比例する。これこそが単振動を特徴づける性質である。高いところから出発した粒子は進む距離が長いが、そのぶん比例して強く押されるのである。

段階 4 2つの粒子

粒子はいつ \(V\) に到達し、そのときの速さはいくらか。運動量が大きいのはどちらか。

両者は同じ時刻 \(T = \pi\sqrt{k/(2g)}\) に、互いに反対側から \(V\) に到達する。\(V\) における速さは \(\omega\) と \(s\) についての振幅の積であり、\(\sqrt{\text{高さ}}\) に比例する。\(h\) から放した重い方の粒子の \(V\) での速さを \(U\) とすると、\(\alpha^2h\) から放した軽い方の粒子の速さは \(\alpha U\) である。両者の運動量（momentum）は互いに逆向きの \(\alpha m \cdot U\) と \(m \cdot \alpha U\) であり、大きさが等しく向きが反対である。衝突時の運動量の総和は \(0\) である。

運動量の総和が \(0\) で反発係数が \(\alpha\) のとき、衝突直後の速度はどうなるか。

運動量の総和は \(0\) のままなので、衝突後も2つの粒子は大きさの等しい運動量をもって互いに逆向きに動き、その相対速度の大きさは近づく速さ \(\alpha U + U\) の \(\alpha\) 倍である。軽い方の粒子（質量 \(\alpha m\)）の衝突後の速さを \(w\) とすると、重い方（質量 \(m\)）の速さは \(\alpha w\) であり、\(w + \alpha w = \alpha(1 + \alpha)U\) となるので \(w = \alpha U\) である。各粒子は速さが \(\alpha\) 倍になって跳ね返る。質量 \(\alpha m\) の粒子は速さ \(\alpha U\) で、質量 \(m\) の粒子は速さ \(\alpha^2U\) で離れていく。

段階 5 運動の全体像

各粒子はそれぞれ自分の側を登り返し、高さは \(\alpha^2\) 倍に減る（高さは速さの2乗に比例するからである）。質量 \(\alpha m\) の粒子は \(\alpha^2h\) まで、質量 \(m\) の粒子は \(\alpha^4h\) まで登る。等時性により、両者は時間 \(2T\) 後のまったく同じ瞬間に再び \(V\) に戻り、そのときの運動量はやはり大きさが等しく向きが反対である。同じ衝突が、すべての速さを \(\alpha\) 倍にして再び起こる。したがって次のことがわかる。

  • 粒子は常に \(V\) で、時刻 \(T, 3T, 5T, \ldots\) に衝突する。

  • \(n\) 回目の衝突の後、粒子は高さ \(\alpha^{2n}h\) と \(\alpha^{2n+2}h\) まで上がる。

  • 運動は等比級数的に減衰していくが、決して止まらない。衝突は無限回起こり、いつまでも続く。■

振り返り

  • 自然な変数を選ぶ。弧長 \(s\) で表すと、運動はちょうど単振動になる。\(x\) や \(y\) で表すと複雑になってしまう。

  • エネルギーから方程式が得られる。エネルギーの式を微分すると、運動方程式が直接得られた。

  • 時間についての対称性。底までの道のりはどれも同じ時間がかかるので、2つの粒子はいつまでも同期し、衝突はまったく同じように繰り返された。

背後にある数学

なぜサイクロイドなのか

直線の下側を転がる半径 \(R\) の車輪は、サイクロイド \(x = R(t + \sin t)\), \(y = R(1 - \cos t)\) を描く。このとき \(\frac{\mathrm{d}x}{\mathrm{d}t} = R(1 + \cos t)\), \(\frac{\mathrm{d}y}{\mathrm{d}t} = R\sin t\) なので、曲線に沿った速さは \(R\sqrt{2 + 2\cos t} = 2R\cos\frac t2\) である。積分すると底からの弧長は \(s = 4R\sin\frac t2\) であり、一方 \(y = 2R\sin^2\frac t2\) である。よって \(s^2 = 8Ry\) となり、サイクロイドはまさに \(k = 2R\) として \(s = 2\sqrt{ky}\) を満たす曲線である。逆に、復元力が \(s\) に比例するという条件から、曲線はサイクロイドでなければならないことが導かれる。

最速降下曲線

1696年、ヨハン・ベルヌーイ（Johann Bernoulli）はヨーロッパの数学者たちに次の問題を挑戦状として出した。ある点から、それより低い（真下ではない）点へ、ビーズが最短時間で滑り降りるのはどのような曲線に沿うときか。その答えである最速降下曲線（brachistochrone）もまたサイクロイドである。ニュートン（Newton）は問題を受け取ったその晩のうちに解いたと言われている。彼は解答を匿名で発表したが、ベルヌーイは「爪を見れば獅子とわかるように」その作者を見抜いた。この問題は、第 4.7 節 で出会った変分法（calculus of variations）、すなわち積分で定義される量を最小にする曲線を求める理論の、出発点となった例である。

ホイヘンスのサイクロイド時計

ホイヘンスは、単振り子の周期が振幅に依存するため、単振り子が正確な時を刻まないことを知っていた。著書 Horologium Oscillatorium（『振り子時計』、1673年）で、彼はおもりをサイクロイドに沿って動かす方法を示した。サイクロイドの形をした2枚の曲がった「頬板」の間に糸を吊るすと、糸は頬板に巻きつきながら、おもり自身がサイクロイドを描くように動くのである（サイクロイドの伸開線（involute）もまたサイクロイドである）。実際には、頬板は摩擦によって、取り除く誤差よりも大きな誤差を生んでしまったため、時計職人たちは代わりに振れ幅を小さく保つことにした。しかしホイヘンスの解析は縮閉線（evolute）と伸開線の理論を生み出し、彼の著書は17世紀の力学における偉大な業績の1つとなった。

思考のスキル

運動が単純になる変数を見つける

曲線に沿った運動は、曲線に沿った距離で表すと最も単純になることが多い。方程式が線形になる変数を探そう。

大学では、これはラグランジュ力学（Lagrangian mechanics）における一般化座標（generalised coordinates）の考え方になる。系の配置を記述する変数であれば何を用いてもよく、それをうまく選ぶことで問題が解けるようになることがある。

次の一歩

  1. 異なる高さ。等時曲線のお椀の中で、粒子を高さ \(h\) から放す。\(V\) での速さが、エネルギー保存則から当然そうなるべきとおり \(\sqrt{2gh}\) であることを示し、それが \(\omega s_0\) と一致することを確かめよ。

  2. 普通のお椀。半径 \(R\) の半球形のお椀で、低い位置から底に着くまでの時間と、縁から底に着くまでの時間を比較せよ。どちらが長いか。（第 11.3 節 の結果を用いよ。）

  3. 等しい質量。問題の後半を、等しい質量 \(m\) をもち高さ \(h_1\) と \(h_2\) から放す2つの粒子、反発係数 \(e\) の場合についてやり直せ。2つの粒子は依然として常に \(V\) で衝突するか。

  4. サイクロイドの弧長。サイクロイドの1つのアーチの長さが \(8R\) であり、その下の面積が \(3\pi R^2\)、つまり転がる円の面積の3倍であることを示せ。

さらに学ぶために

  • George Simmons, Differential Equations with Applications and Historical Notes（CRC Press）。等時曲線と最速降下曲線を、その歴史とともに扱っている。

  • E. A. Whitman, 「Some historical notes on the cycloid」, American Mathematical Monthly 50 (1943)。サイクロイドがなぜ「幾何学者のヘレネ」と呼ばれたのかを述べている。

  • Paul Nahin, When Least Is Best（Princeton University Press）。最速降下曲線をはじめとする最適化問題を、歴史とともに語っている。
