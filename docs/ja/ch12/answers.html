第12章 · 確率

「次の一歩」の解答

ここに載せるのは簡単な答えとヒントであり、完全な解答ではない。結果と鍵となる一歩を示すので、自分の解答の確認に使ってほしい。答えを見る前に、まずそれぞれの問題にきちんと取り組むこと。

12.1 正確な条件付け

  1. (iv) と (v) のどちらでも、残りの \(k - 1\) 枚の円盤は、残っている \(b + n - 1\) 枚（そのうち \(n - 1\) 枚に番号がついている）から無作為に選ばれたものである。したがって、どちらも \(\frac{(n - 1)\binom{b}{k-2}}{\binom{b+n-1}{k-1}}\) に等しい。(vi) の答えは \(\frac{\binom n2\binom{b}{k-2}}{\binom{b+n}{k} - \binom bk}\) である。\(N = b + n\) とおくと、両者が一致するのは \((2N - nk)\binom{N-1}{k-1} = 2k\binom bk\) のときに限る。これが起こるのは、\((b, n, k) = (2, 4, 3)\)、\((3, 3, 4)\)、\((6, 11, 3)\) のような特殊な場合か、自明な場合として \(n = 2\) ですべての円盤を取り出すときだけである。問題で与えられた値ではこれは成り立たない。

  2. 2人の子どもについて、同様に確からしい（性別、曜日）の組は \(14^2 = 196\) 通りあり、そのうち少なくとも1人が火曜日生まれの男の子であるものは \(196 - 13^2 = 27\) 通りである。そのうち2人とも男の子であるものは \(7^2 - 6^2 = 13\) 通りである。よって、求める確率は \(\frac{13}{27}\) である。

  3. ドア1を選んだとする。車がドア1の後ろにあれば（確率 \(\frac13\)）、選び直すと負ける。車がドア2または3の後ろにあれば、司会者はもう一方のヤギのドアを開けるしかなく、選び直すと勝つ。その確率は \(\frac23\) である。司会者が無作為にドアを開け、たまたまヤギが出た場合には、見たことを条件とすると、「自分のドアの後ろに車がある」と「もう一方の閉じたドアの後ろに車がある」は同様に確からしく、確率は \(\frac12\) である。

  4. \(\mathrm{P}(\geq2 \mid \geq1) = \frac{1 - \mathrm{P}(0) - \mathrm{P}(1)}{1 - \mathrm{P}(0)} \approx 0.370\) であるが、\(\mathrm{P}(\geq2 \mid \text{スペードのエース}) = 1 - \binom{48}{12}\big/\binom{51}{12} \approx 0.561\) である。どのエースであるかを知ると、2枚目のエースがある可能性が高くなる。

12.2 基準率の誤謬

  1. 2人がともに「遺体がある」と言う確率は、実際にある場合は \(pq\)、ない場合は \((1 - p)(1 - q)\) である。事前オッズ（prior odds）が \(1 : 1\) のとき、事後確率（posterior probability）は \(\frac{pq}{pq + (1 - p)(1 - q)} = \frac{pq}{1 - p - q + 2pq}\) である。後半については、「\(A\) がある」は同様に確からしい3つの場合のうち2つで正しいので、\(\mathrm{P}(\text{両方} \mid \text{両者の証言が } A) = \frac{pq}{2pq + (1 - p)(1 - q)}\) となる。

  2. \(0.9\pi > \frac{1}{11}(1 - \pi)\)、すなわち \(\pi > \frac{10}{109} \approx 9.2\%\) であればよい。

  3. AL の陽性結果が1回出るごとに、オッズは \(\frac{0.9}{1/11} = 9.9\) 倍になる。事前オッズ \(\frac{1}{99}\) から始めると、陽性1回の後はオッズ \(0.1\)（確率 \(\frac{1}{11}\)）、2回の後はオッズ \(0.99\)（確率は約 \(0.497\)）、3回の後はオッズ \(9.8\)（確率は約 \(0.907\)）となる。

  4. その病気をもつ \(100\) 人のうち \(99\) 人が陽性となり、もたない \(999\,900\) 人のうち約 \(9999\) 人が陽性となる。よって、病気の可能性があると告げられるのは約 \(10\,100\) 人であり、そのうち実際に病気であるのは \(99\) 人（約 \(1\%\)）にすぎない。

12.3 「ランダム」とは何を意味するか？

  1. 弦（chord）が内接正三角形の1辺 \(\sqrt3a\) より長くなるのは、次のときである。遠い側の端点が、近い側の端点の反対側にある円周の3分の1の弧上にあるとき（\(\frac13\)）。\(O\) からの距離が \(\frac a2\) より小さいとき（\(\frac12\)）。中点が半径 \(\frac a2\) の円の内部にあるとき（\(\frac14\)）。

  2. 中点が \(C\) である弦は \(OC\) に垂直なので、\(C\) を通り角 \(t = \frac\pi2\) をなす弦であり、\(L(\frac\pi2) = \frac{4a}{3}\bigl(0 + \frac12\sec^2\frac\pi4\bigr) = \frac{4a}{3}\) となる。

  3. 長さは \(2\sqrt{a^2 - d^2}\) であり、その平均（mean）は \(\frac2a\int_0^a\sqrt{a^2 - d^2}\,\mathrm{d}d = \frac2a \cdot \frac{\pi a^2}{4} = \frac{\pi a}{2}\) である。

  4. 端点を無作為に選ぶ場合：\(\frac{2}{\pi\sqrt{4a^2 - \ell^2}}\)。距離を無作為に選ぶ場合：\(\frac{\ell}{2a\sqrt{4a^2 - \ell^2}}\)。中点を無作為に選ぶ場合：\(\frac{\ell}{2a^2}\)。

12.4 二つずつなら独立、全体では独立でない

  1. 展開すると \(\mathrm{E}(XY) - \mathrm{E}(X)\mathrm{E}(Y) = (a - pq)(x_1 - x_2)(y_1 - y_2)\) となるので、\(a = pq\) である。残りの3つのセルもこれに従って決まり、独立性（independence）が得られる。例：\((0, 0)\) に確率 \(\frac13\)、\((\pm1, \pm1)\) のそれぞれに確率 \(\frac16\) を置く。周辺分布（marginal distribution）はどちらも一様で \(\mathrm{E}(AB) = 0\) であるが、\(\mathrm{P}(A = 0, B = 1) = 0 \neq \frac19\) である。

  2. 組は \(21\) 個あり、それぞれ確率 \(\frac16\) で一致し、その指示変数（indicator variable）は対ごとに独立（pairwise independent）である。よって、平均は \(3.5\)、分散（variance）は \(21 \cdot \frac16 \cdot \frac56 \approx 2.92\)、標準偏差（standard deviation）は約 \(1.71\) である。得点 \(7\) は平均より標準偏差の約2倍だけ上にある。

  3. 平均は \(\binom k2\frac{1}{365}\) である。指示変数はさいころの場合とまったく同じように対ごとに独立なので、分散は \(\binom k2\frac{1}{365}\cdot\frac{364}{365}\) である。（ただし、互いに独立（mutually independent）ではない。\(1, 2\) と \(2, 3\) が一致すれば、\(1, 3\) も一致する。）

  4. 同様に確からしい8個の結果をとり、\(A = B = \{1, 2, 3, 4\}\)、\(C = \{1, 5, 6, 7\}\) とする。すると \(\mathrm{P}(A \cap B \cap C) = \frac18\) であるが、\(\mathrm{P}(A \cap B) = \frac12 \neq \frac14\) である。

12.5 最後の乗客の座席

  1. すべての \(n \geq 3\) について \(\frac13\) である。最後の席は \(S_1\)、\(S_2\)、\(S_n\) のいずれかとなり、どの無作為な選択もこれら3つを対称に扱う。

  2. \(T_1\) が \(S_1\) に座れば、誰も自分の席を追われない。\(T_1\) が \(S_3\) に座れば、\(T_1\) と \(T_3\) が追われる。\(T_1\) が \(S_2\) に座れば、\(T_2\) が選ぶことになり、\(S_1\) を選べば追われるのは \(2\) 人、\(S_3\) を選べば \(3\) 人である。期待値（expectation）は \(\frac13\bigl(0 + 2 + \frac52\bigr) = \frac32\) であり、公式から得られる \(\frac23 + \frac13 + \frac12\) と一致する。

  3. \(r \geq 2\) に対して \(P_r = \frac12\) とすると、\(\frac1n\bigl(1 + \frac{n - 2}{2}\bigr) = \frac12\) となるので、漸化式（recurrence relation）は \(P_n = \frac12\) と矛盾しない。

  4. 最後に空いている席は必ず \(S_1\) か \(S_n\) である（それ以外の \(S_k\) は、遅くとも \(T_k\) が搭乗する時点までに埋まっている）。よって、それが \(S_n\) でなければ \(S_1\) である。

12.6 もう1枚の硬貨

  1. Bob の最初の \(n + 1\) 回の投げを \(H'\)、最後の1回を \(X\) とする。Bob が勝つのは、\(H' > H_A\) のとき、または \(H' = H_A\) かつ \(X\) が表のときである。よって確率は \(\mathrm{P}(H' > H_A) + \frac12\mathrm{P}(H' = H_A)\) であり、硬貨が1枚多い場合の結果から \(\mathrm{P}(H' > H_A) = \frac12\) である。

  2. いいえ。\(n = 0\) のとき、Bob は確率 \(p\) で勝つ。鮮やかな証明は表と裏を入れ替えるが、それが対称性（symmetry）になるのは公平な硬貨の場合だけである。

  3. \(H_A = H_B\) となるのは、ちょうど \(H_A + (\text{Bob の裏の回数}) = n\) のときであり、これは \(\mathrm{B}(2n, \frac12)\) に従う確率変数が \(n\) に等しいということである。値は \(\frac12\)、\(\frac38\)、\(\frac{5}{16}\) である。

  4. いいえ。6の目は \(p = \frac16\) の硬貨のようなものである。\(n = 0\) のとき確率は \(\frac16\) であり、一般に \(\frac12\) より小さい。

12.7 勝ち抜き戦で誰と誰が当たるか

  1. 第 \(k\) ラウンドには \(2^{n-k}\) 試合があり、対称性から、各試合が \(\binom{2^n}{2}\) 組のどの組の対戦になるかは同様に確からしい。大会全体の \(2^n - 1\) 試合について足し合わせると、\(\frac{2^n - 1}{\binom{2^n}{2}} = \frac{2}{2^n}\) となる。

  2. いいえ。固定された組み合わせ表に無作為に配置しても対称性は保たれ、同じ数え方が適用できる。

  3. 第 \(k\) ラウンドでの \(X\) の対戦相手は \(2^{k-1}\) 人のグループから出てきて、その各人がグループを勝ち抜く可能性は等しい。よって、\(Y\) がその対戦相手である確率は \(\frac{2^{k-1}}{2^n - 1} \cdot \frac{1}{2^{k-1}} = \frac{1}{2^n - 1}\) であり、\(n\) ラウンド全体での合計は \(\frac{n}{2^n - 1}\) である。

  4. 試合数は \(\binom{2n}{2} = n(2n - 1)\) である。すべての組が対戦するので、確率は \(1\) である。

12.8 ペニーのゲーム

  1. HHT が勝つのは、最初の2回が HH の場合だけである。そうでなければ HH が揃う前に T が出て、THH が先に現れるしかない。よって、HHT が勝つ確率は \(\frac14\) である。4人全員で行う場合：HH の後は HHT が必ず勝ち、TT の後は TTH が必ず勝つ。HT と TH からは、HTT と THH の勝つ確率は \(\frac23\) と \(\frac13\)（またはその逆）なので、各プレイヤーの勝つ確率は \(\frac14 \cdot 1\) または \(\frac14\bigl(\frac23 + \frac13\bigr)\)、すなわち \(\frac14\) である。TTH は確率 \(\frac23\) で THH に勝つ（小問 (i)）。

  2. HH について：\(e_0 = 1 + \frac12e_{\mathrm{H}} + \frac12e_0\) かつ \(e_{\mathrm{H}} = 1 + \frac12e_0\) より、\(e_0 = 6\) である。HT について：いったん H が出たら T を待てばよく（平均2回）、最初の H までにも平均2回かかるので、\(4\) である。

  3. HHH と TTT は、THH と HTT に確率 \(\frac78\) で負ける。HHT と TTH は、THH と HTT に確率 \(\frac34\) で負ける。残りの4つ（HTH、HTT、THH、THT）は、それぞれ HHT、HHT、TTH、TTH に確率 \(\frac23\) で負ける。最もたやすく負かされるのは HHH と TTT である。

  4. \(A =\) HTT、\(B =\) HHT とすると、相関（correlation）は \(AA = 4\)、\(AB = 0\)、\(BB = 4\)、\(BA = 2\) である。\(B\) が勝つオッズは \((AA - AB) : (BB - BA) = 4 : 2\)、すなわち確率 \(\frac23\) である。

12.9 偏った硬貨から公平な判定を

  1. ラウンド数は幾何分布（geometric distribution）に従い、その平均は小問 (i) では \(\frac{1}{p^2 + q^2}\)、フォン・ノイマン（von Neumann）の方法（HT または TH）では \(\frac{1}{2pq}\) である。\(p^2 + q^2 - 2pq = (p - q)^2\) なので、\(p \neq \frac12\) であればつねにフォン・ノイマンの方法のほうが遅い。ただし、公平なのはこちらである。

  2. フォン・ノイマンの方法を使って公平なビットを作る。それを2つずつ取り、\(00\)、\(01\)、\(10\) で3つの選択肢を選び、\(11\) ならやり直す。

  3. 投げた結果を1回ずつ、二進展開（binary expansion）\(\frac13 = 0.010101\ldots\) と比べる（H を \(1\)、T を \(0\) と読む）。初めて異なる回で、投げた結果が桁の数字より小さい（\(1\) に対して T）なら「表」、そうでなければ「裏」と宣言する。こうすると、ちょうど確率 \(\frac13\) で表となり、投げる回数は平均 \(2\) 回である。

  4. 決着のつかないラウンドの後には、一方の面が2枚、もう一方の面が1枚出ており、この過程はこの2つの状態の上のマルコフ連鎖（Markov chain）になる。これを解くと \(\mathrm{P}(\text{ホテル}) = \frac{p^3}{p^3 + q^3}\) となり、\(p = \frac12\) のときは \(\frac12\) である。そのときは公平であるが、それ以外では公平でない。

12.10 ひもの端を結ぶ

  1. 最初の結びで輪ができる確率は \(\frac13\) であり（他の3つの端のうち1つが同じひもの端である）、最後の結びでは必ず輪ができる。輪の数は確率 \(\frac13\) で \(2\)、確率 \(\frac23\) で \(1\) であり、平均は \(\frac43\) である。

  2. ひもが \(k\) 本残っているとき、結びで輪ができない確率は \(1 - \frac{1}{2k - 1}\) である。積 \(\prod_{k=2}^{n}\frac{2k - 2}{2k - 1}\) は \(\frac{4^n}{2n\binom{2n}{n}}\) に等しく、これはおよそ \(\frac{\sqrt{\pi n}}{2n} = \sqrt{\frac{\pi}{4n}}\) である。

  3. 要素 \(1, 2, \ldots, n\) を順に挿入する。要素 \(k\) は新しい巡回（cycle）を始める（確率 \(\frac1k\)）か、それより前の \(k - 1\) 個の要素のどれかの後に置かれる。指示変数を足し合わせると \(H_n\) が得られる。

  4. 順に行う結びのそれぞれについての輪の指示変数は、確率 \(\frac{1}{2k - 1}\) の独立な変数なので、分散は \(\sum\frac{1}{2k - 1}\bigl(1 - \frac{1}{2k - 1}\bigr)\) である。また、\(\sum_{k \geq 1}\frac{1}{(2k - 1)^2} = \frac{\pi^2}{6} - \frac14 \cdot \frac{\pi^2}{6} = \frac{\pi^2}{8}\) である。

12.11 切手、カップ、そして \(e\)

  1. \(\sum_{k \geq 2}\frac{k - 1}{k!}t^k = t\mathrm{e}^t - (\mathrm{e}^t - 1) = 1 + (t - 1)\mathrm{e}^t\) である。微分すると \(\mathrm{E}(N) = \mathrm{G}'(1) = \mathrm{e}\)、\(\mathrm{E}(N(N - 1)) = \mathrm{G}''(1) = 2\mathrm{e}\) となるので、\(\mathrm{Var}(N) = 3\mathrm{e} - \mathrm{e}^2\) である。

  2. \(\mathrm{P}(N = j)\) は \(k = 0, \ldots, j - 1\) に対する \(\mathrm{P}(N > k)\) に現れる、すなわち \(j\) 回現れる。ここで \(\mathrm{P}(N > k) = \frac{1}{k!}\) なので、\(\mathrm{E}(N) = \sum\frac{1}{k!} = \mathrm{e}\) である。

  3. まったく変わらない。カップが1つなら、Jim は必ず正しく「当てる」。価格の期待値はやはり \(\mathrm{e}\) である。

  4. \(\int_0^1\frac{(1 - u)^2}{2}\,\mathrm{d}u = \frac16\) である。一般に、\(u_k = u\) での切り口は \(1 - u\) 倍に縮小された \((k - 1)\) 次元単体（simplex）なので、\(V_k = V_{k-1}\int_0^1(1 - u)^{k-1}\,\mathrm{d}u = \frac{V_{k-1}}{k}\) である。

12.12 いつ探すのをやめるか

  1. 一番大きいものが位置 \(k \geq 2\) にあるとき、それが手に入るのは、ちょうど最初のアイスクリームが最初の \(k - 1\) 個の中で一番大きいときであり、その確率は \(\frac{1}{k - 1}\) である。\(k\) について平均すると \(\frac1n\sum_{k=2}^n\frac{1}{k - 1}\) となり、\(n = 4\) のときこれは \(\frac{11}{24}\) である。\(24\) 通りの並びを書き出すと、2番目、3番目、4番目に大きいものが手に入る確率は、それぞれ \(\frac{7}{24}\)、\(\frac16\)、\(\frac{1}{12}\) である。

  2. \(r = 0, 1, 2, 3\) 人を見送ると、確率はそれぞれ \(\frac14\)、\(\frac{11}{24}\)、\(\frac{5}{12}\)、\(\frac14\) となる。よって、1人を見送るのがよく、成功確率は \(\frac{11}{24}\) である。

  3. 最初の \(n\) 人の中で最良の者が上位2人に入る確率は \(\frac nN + \frac nN\cdot\frac{N - n}{N - 1}\) であり、\(n\) が小さいときは \(\frac nN\) のほぼ2倍である。上位2人のどちらでもよいなら、決断する前に見る候補者の数を少なくしてよい。（この目標に対する最良の戦略の成功確率は約 \(0.57\) である。）

  4. \(\mathrm{P}(r) = \frac rN\sum_{k=r}^{N-1}\frac1k\) とすると、\(N = 10\) では \(r = 2, 3, 4\) に対して \(0.366\)、\(0.399\)、\(0.398\) となり、\(N = 100\) では \(r = 36, 37, 38\) に対して \(0.3710\)、\(0.3710\)、\(0.3708\) となって、\(r = 37\) がわずかに上回る。

12.13 三つ巴の決闘

  1. Algernon が外した場合、Bertie は Cuthbert を狙って投げる。当たれば（\(\frac35\)）、Algernon と Bertie の対決で Algernon が先に投げることになり、Bertie が勝つ確率は \(1 - \frac{2/5}{2/5 + 3/5 - 6/25} = \frac{9}{19}\) である。外せば Cuthbert が Bertie に当て、その後は Algernon が先に当てない限り（\(\frac35\)）Cuthbert が勝つ。よって、Bertie が勝つ確率は \(\frac35 \cdot \frac{9}{19} = \frac{135}{475}\)、Cuthbert が勝つ確率は \(\frac25 \cdot \frac35 = \frac{114}{475}\) である。

  2. すべての \(a < 1\) に対してである。わざと外すと \(\frac35\cdot\frac{a}{a + \frac35 - \frac35a} + \frac25a\) となる。Cuthbert に当てると \(1 - \frac{3/5}{3/5 + a - \frac35a}\) となり（その後は Bertie が Cuthbert を狙って先に投げる）、これはつねに小さい。Bertie に当てると \(0\) である。

  3. いいえ。Bertie が Algernon を狙って当てれば、次に Cuthbert が Bertie に当てる。外しても、やはり Cuthbert が Bertie に当てる。どちらにしても Bertie には何も残らず、Cuthbert を狙えば得られる \(\frac{27}{95}\) に及ばない。

  4. \(p + (1 - p)(1 - r)p\) であり、これは等比級数全体の和 \(\frac{p}{p + r - pr}\) より小さい。

12.14 混合戦略

  1. \(b = (\frac14, \frac12, \frac14)\) のとき \(X = Y = Z = 0\) なので、B はどの戦略に対しても \(0\) を得る。\((\frac13, \frac13, \frac13)\) に対しては、A の得点の期待値は予想 \(1\)、\(2\)、\(3\) に対してそれぞれ \(-\frac13\)、\(0\)、\(\frac13\) なので、A はつねに \(3\) と予想すべきである。

  2. 利得行列（payoff matrix）は対角成分が \(0\)、それ以外が \(\pm1\) であり、3つの戦略を巡回的に入れ替えても変わらないので、最適戦略は \((\frac13, \frac13, \frac13)\) である。問題では、差が \(1\) の場合と \(2\) の場合で罰点が異なるので、戦略は入れ替え可能ではない。

  3. \(X\), \(Y\), \(Z \geq 0\) かつ \(X + 2Y + Z = 0\) ならば、3つとも \(0\) である。これより \(b_1 = b_3\)、\(b_2 = 2b_3\) が導かれる。

  4. 今度は \(X = -b_2 + 3b_3\)、\(Y = b_1 - b_3\)、\(Z = -3b_1 + b_2\) であり、\(X + 3Y + Z = 0\) である。3つすべてを \(0\) とおくと \((\frac15, \frac35, \frac15)\) が得られる。

12.15 絶滅か爆発か

  1. 絶滅確率（extinction probability）は、\([0, 1]\) における \(s = (q + ps)^2\) の最小の根である。根は \(1\) と \(\bigl(\frac qp\bigr)^2\) であり、後者が \(1\) より小さくなるのはちょうど \(p > \frac12\) のときである。

  2. \(X_{n-1}\) が与えられたとき、\(X_n\) の平均は \(2pX_{n-1}\)、分散は \(2pqX_{n-1}\) なので、\(\mathrm{Var}(X_n) = \mathrm{E}(2pqX_{n-1}) + (2p)^2\mathrm{Var}(X_{n-1})\) である。\(p = \frac12\) のとき、\(\mathrm{Var}(X_n) = \mathrm{Var}(X_{n-1}) + \frac12\) なので、\(\mathrm{Var}(X_n) = \frac n2\) である。

  3. 第 \(n\) 世代までに絶滅するとは、第1世代の各粒子の系統が \(n - 1\) 世代以内に途絶えることである。\(p = \frac34\) のとき、\(e_1 = 0.0625\)、\(e_2 \approx 0.0881\)、\(e_3 \approx 0.0999\) であり、\(\frac19 \approx 0.111\) に向かって増加する。

  4. \(s = \frac14(1 + s + s^2 + s^3)\) は \((s - 1)(s^2 + 2s - 1) = 0\) と因数分解できるので、絶滅確率は \(\sqrt2 - 1 \approx 0.414\) である。

12.16 マルコフ連鎖を順向きにも逆向きにも

  1. 対称性から \(p_B = p_D\) であり、さらに \(p_A = \frac13 + \frac23p_B\)、\(p_B = \frac13p_A + \frac13p_C\)、\(p_C = \frac23p_B\) である。よって \(p_A = \frac{7}{15}\) となる。\(A\) から出発して \(C\) を訪れずに \(A\) で抜け出す確率は、\(x_A = \frac13 + \frac23x_B\) かつ \(x_B = \frac13x_A\) より、\(x_A = \frac37\) である。条件付き確率は \(\frac{3/7}{7/15} = \frac{45}{49}\) である。

  2. 第1行に \(P\) を掛けると \((0.19, 0.33, 0.48)\) となる。

  3. トレース（trace）は \(1.3\)、行列式（determinant）は \(0.02\) であり、\(1\) は固有値（eigenvalue）である（各行の和が \(1\) だから）。残りの2つは和が \(0.3\)、積が \(0.02\) なので、\(0.2\) と \(0.1\) である。

  4. \(a_1p_{12} = \frac{1}{20}\) であるが \(a_2p_{21} = \frac{1}{15}\) なので、この連鎖は可逆（reversible）ではない。時間を逆向きにたどると、推移確率が異なる（小問 (iii) の \(q_{ij}\) は \(p_{ij}\) と異なる）。

12.17 バナッハのマッチ箱

  1. 2回目に手を伸ばしたのが1回目と同じ種類であれば、そこで空であることに気づく（\(N = 2\)）。そうでなければもう一方のお菓子を取り、3回目に手を伸ばしたときに空の袋に気づく。よって \(N = 2\) または \(3\) であり、確率はそれぞれ \(\frac12\) である。

  2. \(n = 1\) のとき：\(\frac12 + \frac12 = 1\)。\(n = 2\) のとき：\(\frac{6}{16} + \frac{6}{16} + \frac{4}{16} = 1\)。

  3. \(\binom{2n - 1}{n}2^{-(2n-1)} = \frac12\binom{2n}{n} \cdot 2 \cdot 4^{-n} = \binom{2n}{n}4^{-n}\) である。

  4. 残っているタフィーとミントの個数について第1段階で場合分けする再帰を立てると、\(\frac{64}{81} \approx 0.79\) が得られる。

12.18 無記憶性

  1. \(\mathrm{P}(\min > t) = \mathrm{e}^{-\lambda_1t}\mathrm{e}^{-\lambda_2t}\) である。次のバスまでの待ち時間は、1分あたりの率が \(\frac{1}{15} + \frac{1}{30} = \frac{1}{10}\) の指数分布（exponential distribution）に従うので、その中央値（median）は \(10\ln2 \approx 6.9\) 分である。

  2. \(\mathrm{P}(Y \geq k) = (1 - p)^k\) なので、比は \((1 - p)^n\) である。

  3. \(t\) を含む間隔は、直前のバスまでさかのぼる時間と次のバスまでの時間からなり、（\(t\) が大きいとき）どちらも平均 \(\frac1\lambda\) の指数分布に従うので、その長さの期待値は \(\frac2\lambda\) である。長い間隔ほど、与えられた時刻を含みやすい。

  4. \([0, 1]\) 上で \(\frac{\lambda\mathrm{e}^{-\lambda z}}{1 - \mathrm{e}^{-\lambda}}\) である。\(\lambda = 1\) のときは約 \(1.58\) から \(0.58\) へゆるやかに減少し、\(\lambda = 5\) のときは \(0\) の近くに集中して、約 \(5.03\) から \(0.03\) へ減少する。

12.19 平面上のランダムな点

  1. \(1 - \mathrm{e}^{-\pi ky^2} = \frac12\) より中央値は \(\sqrt{\frac{\ln2}{\pi k}} \approx \frac{0.470}{\sqrt k}\) であり、平均 \(\frac{1}{2\sqrt k}\) より少し小さい。

  2. \(\mathrm{P}(Y_2 > y) = \mathrm{e}^{-\pi ky^2}(1 + \pi ky^2)\) なので、確率密度関数（probability density function）は \(2\pi^2k^2y^3\mathrm{e}^{-\pi ky^2}\) である。

  3. 極座標（polar coordinates）では、\(R\) の確率密度関数は \(\frac{1}{2\pi\sigma^2}\mathrm{e}^{-r^2/(2\sigma^2)} \cdot 2\pi r\) である。これは \(\sigma^2 = \frac{1}{2\pi k}\) のときスーパーマーケットの分布と一致する。

  4. \(k = 4 \times 10^{-4}\) per m\(^2\) のとき、完全に無作為な配置からは平均 \(\frac{1}{2\sqrt k} = 25\) m が予測される。観測された \(35\) m はこれより大きいので、木は密集しているのではなく、（競合によって）間隔をあけて並んでいることが示唆される。

12.20 ビュフォンの針

  1. 針を短い断片に切り分ける。交差回数の期待値は加法的であり、各断片は長さに比例して寄与するので、\(a\) がいくつであっても合計は \(\frac{2a}{\pi b}\) である。

  2. 同じ加法性（ビュフォン（Buffon）のヌードル）により、やはり \(\frac{2a}{\pi b}\) である。

  3. 中心はどの辺からも \(r\) 以上離れていなければならないので、\(\frac{(s - 2r)^2}{s^2}\) である。

  4. \(\frac{1808}{3408} \approx \frac{5}{3\pi}\) より \(\pi \approx \frac{5 \times 3408}{3 \times 1808} = \frac{17\,040}{5424} = \frac{355}{113}\) となる。出来すぎていて怪しい。

12.21 棒を折る

  1. 三角形ができるには、どの断片も \(\frac12\) より短くなければならない。折る点を表す単位正方形の中で、これは面積 \(\frac14\) の領域を切り取る。

  2. 最初に折る点が \(x < \frac12\) にあり（もう一方の場合も対称である）、長いほうの断片 \(1 - x\) を一様に折るとする。新しい2つの断片がどちらも \(\frac12\) より短くなければならず、その確率は \(\frac{x}{1 - x}\) である。よって答えは \(2\int_0^{1/2}\frac{x}{1 - x}\,\mathrm{d}x = 2\ln2 - 1\) である。

  3. \(C\) における角が鈍角になるのは \((2 - x - y)^2 > x^2 + y^2\)、すなわち \(y < \frac{2 - 2x}{2 - x}\) のときである。この曲線と \(x + y = 1\) の間の面積は \(\frac32 - 2\ln2\) なので、確率は \(3 - 4\ln2\) であり、\(B\) の場合と同じである。これは偶然ではない。3辺はそれぞれ \(1\) 以下で和が \(2\) となるように一様に分布しているので、互いに入れ替え可能である。よって \(\mathrm{P}(\text{鈍角}) = 9 - 12\ln2 \approx 0.68\) である。

  4. 包除原理（inclusion–exclusion principle）により、最長の断片 \(M\) について \(\mathrm{P}(M > m) = 3(1 - m)^2 - 3(1 - 2m)_+^2 + (1 - 3m)_+^2\) が成り立つ。ここで \(x_+ = \max(x, 0)\) である。\([0, 1]\) で積分すると \(\mathrm{E}(M) = 1 - \frac12 + \frac19 = \frac{11}{18}\) が得られる。

12.22 平均をもたない分布

  1. \(\mathrm{P}(\tan\Theta \leq k) = \frac1\pi\bigl(\tan^{-1}k + \frac\pi2\bigr)\) であり、微分すると \(\frac{1}{\pi(1 + k^2)}\) が得られる。

  2. \(U\) と \(V\) を入れ替えても回転対称な確率密度関数は変わらないので、\(\frac VU\) は \(\frac UV\) と同じ分布に従う。

  3. 確率密度関数は対称なので中央値は \(0\) であり、\(\mathrm{P}(C \leq 1) = \frac12 + \frac1\pi\tan^{-1}1 = \frac34\) である。

  4. \(\frac{1}{2\pi}\mathrm{e}^{-r^2/2}\,r\,\mathrm{d}r\,\mathrm{d}\theta\) であり、\(s = r^2\) とおくとこれは \(\frac{1}{2\pi}\,\mathrm{d}\theta \cdot \frac12\mathrm{e}^{-s/2}\,\mathrm{d}s\) となる。角は一様分布に従い、\(R^2\) は平均 \(2\) の指数分布に従い、両者は独立である。

12.23 確率から導くスターリングの公式

  1. \(\sqrt{20\pi}(10/\mathrm{e})^{10} \approx 3\,598\,696\)（約 \(0.8\%\) 小さい）、\(\sqrt{40\pi}(20/\mathrm{e})^{20} \approx 2.4228 \times 10^{18}\)（約 \(0.4\%\) 小さい）である。

  2. \(\frac{(2n)!}{(n!)^2} \approx \frac{\sqrt{4\pi n}(2n/\mathrm{e})^{2n}}{2\pi n(n/\mathrm{e})^{2n}} = \frac{4^n}{\sqrt{\pi n}}\) である。

  3. \(100\log_{10}\frac{100}{\mathrm{e}} + \frac12\log_{10}(200\pi) \approx 157.97\) なので、\(100!\) は \(158\) 桁である。

  4. \(\binom{1000}{500}2^{-1000} \approx \frac{1}{\sqrt{500\pi}} \approx 0.0252\) である。

12.24 中心極限定理

  1. 畳み込み（convolution）を計算すると \(\frac14\int\mathrm{e}^{-|x| - |y - x|}\,\mathrm{d}x = \frac14(1 + |y|)\mathrm{e}^{-|y|}\) となる。分散は \(2 + 2 = 4\) である。

  2. \(\mathrm{E}(\mathrm{e}^{\theta X}) = \frac12(\mathrm{e}^{\theta/2} + \mathrm{e}^{-\theta/2}) = \cosh\frac\theta2\) である。標準化された和 \(\frac{2}{\sqrt n}\sum X_i\) の積率母関数（moment generating function）は \(\cosh^n\frac{\theta}{\sqrt n}\) であり、その対数は \(n\ln\bigl(1 + \frac{\theta^2}{2n} + \cdots\bigr) \to \frac{\theta^2}{2}\) となる。

  3. \(Y\) を独立な2つの \(\Gamma(82, 1)\) 確率変数の差として表し、数値積分すると \(\mathrm{P}(|Y| \geq 25) \approx 0.051\) が得られる。正規近似（normal approximation）は非常によい。

  4. 積率母関数は存在せず、平均さえ存在しない。実際、\(n\) 個の独立なコーシー分布（Cauchy distribution）に従う変数の平均は、それ自身がコーシー分布に従う。平均をとっても、まったく集中しないのである。

12.25 多数の中の最大値

  1. \(n\) 個の寿命のうち最初の1つは平均時間 \(\frac{1}{n\lambda}\) の後に尽きる。その後は \(n - 1\) 個が残り、新たに始まったのと同じ状況になる。以下同様である。よって \(\mathrm{E}(Y) = \frac1\lambda\bigl(\frac1n + \frac{1}{n - 1} + \cdots + 1\bigr)\) である。

  2. \(\mathrm{P}(\min > t) = (\mathrm{e}^{-\lambda t})^n = \mathrm{e}^{-n\lambda t}\) である。

  3. \((1 - \mathrm{e}^{-\lambda y})^n = \frac12\) より \(\lambda y = -\ln(1 - 2^{-1/n})\) である。\(n = 10\) のときこれは \(2.704\) であり、近似値 \(\ln10 - \ln\ln2 \approx 2.669\) と比べられる。

  4. \(\mathrm{P}(M \leq m) = m^n\) なので、\(\mathrm{P}\bigl(n(1 - M) > s\bigr) = \bigl(1 - \frac sn\bigr)^n \to \mathrm{e}^{-s}\) である。これはワイブル型（Weibull type）である。変数は上に有界であり、最大値はその上界に押し寄せるように集まる。
