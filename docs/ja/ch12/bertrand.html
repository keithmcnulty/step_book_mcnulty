問題

STEP III 2022、第12問

先に進む前に問題を読んでおこう。問題は、OCRが配布している2022年のSTEP問題一式（zipファイル）のSTEP IIIに収録されている： www.ocr.org.uk/Images/696587-2022-past-papers.zip

導入

「円の弦（chord）を無作為に1本選ぶ。その長さの期待値（expected value）はいくらか。」この問いには答えがありそうに聞こえる。しかし「無作為に」が何を意味するかを決めるまでは、答えは存在しない。円周上に無作為に2点をとって結べば、長さの期待値は \(\frac{4a}{\pi} \approx 1.27a\) である。円の内部に無作為に1点をとり、その点を通る方向を無作為に選べば、答えは \(\frac{16a}{3\pi} \approx 1.70a\) となる。どちらも「無作為な弦」の選び方としてまったく妥当である。

これがベルトランの逆説（Bertrand’s paradox）であり、ジョゼフ・ベルトラン（Joseph Bertrand）が1889年に警告として発表したものである。確率は、確率的な試行が明確に指定されて初めて定まる。この逆説は、20世紀に築かれた確率論の厳密な基礎へと数学者たちを向かわせる一因となった。その基礎においては、あらゆる確率は厳密に定義された結果の空間の上で考えられる。

取りかかる前に

角 \(AOB\) が \(\theta\) のとき、弦 \(AB\) の長さはいくらか。（\(O\) から垂線を下ろしてみよ。）

\(O\) からの垂線は弦と角をともに二等分するので、\(AB = 2a\sin\frac\theta2\) である。

順を追って解く

段階 1 円周上の2点

\[\mathrm{E}(AB) = \frac{1}{2\pi}\int_0^{2\pi}2a\sin\frac\theta2\,\mathrm{d}\theta = \frac{a}{\pi}\Bigl[-2\cos\frac\theta2\Bigr]_0^{2\pi} = \frac{a}{\pi}\cdot 4 = \frac{4a}{\pi}. \qed\]

段階 2 内部の無作為な点

\(0 \leq r \leq a\) に対して \(\mathrm{P}(R \leq r)\) はいくらか。微分して確率密度を求めよ。

\(\mathrm{P}(R \leq r)\) は半径 \(r\) の円板の面積を円板全体の面積で割ったもの、すなわち \(\frac{r^2}{a^2}\) である。したがって \(R\) は \([0, a]\) 上で確率密度（density）\(\frac{2r}{a^2}\) をもつ。（中心から遠い点ほど選ばれやすい。そこにより多くの面積があるからである。）

\(C\) を通る弦が \(OC\) と角 \(t\) をなすとする。この弦は \(O\) からどれだけ離れているか。

\(O\) からこの直線までの距離は \(R\sin t\) なので、弦の長さは \(2\sqrt{a^2 - R^2\sin^2t}\) である。

段階 3 \(C\) について平均する

\(s = \sin t\) とおくと、 \[\begin{aligned} L(t) &= \int_0^a 2\sqrt{a^2 - r^2s^2}\cdot\frac{2r}{a^2}\,\mathrm{d}r = \frac{4}{a^2}\Bigl[-\frac{(a^2 - r^2s^2)^{3/2}}{3s^2}\Bigr]_0^a \\ &= \frac{4}{a^2}\cdot\frac{a^3 - a^3(1 - s^2)^{3/2}}{3s^2} = \frac{4a(1 - \cos^3t)}{3\sin^2t}. \qed \end{aligned}\]

\(1 - \cos^3t\) と \(\sin^2t = 1 - \cos^2t\) を因数分解せよ。何が約分できるか。

\(c = \cos t\) とおくと \(\frac{1 - c^3}{1 - c^2} = \frac{(1 - c)(1 + c + c^2)}{(1 - c)(1 + c)} = \frac{1 + c + c^2}{1 + c} = c + \frac{1}{1 + c}\) であり、また \(1 + \cos t = 2\cos^2\frac t2\) である。よって \[L(t) = \frac{4a}{3}\Bigl(\cos t + \tfrac12\sec^2\tfrac t2\Bigr). \qed\]

段階 4 方向も無作為に

\[\begin{aligned} \mathrm{E}\bigl(L(T)\bigr) &= \frac2\pi\int_0^{\pi/2}\frac{4a}{3}\Bigl(\cos t + \tfrac12\sec^2\tfrac t2\Bigr)\mathrm{d}t \\ &= \frac{8a}{3\pi}\Bigl[\sin t + \tan\tfrac t2\Bigr]_0^{\pi/2} = \frac{8a}{3\pi}(1 + 1) = \frac{16a}{3\pi}. \qed \end{aligned}\]

振り返り

  • 試行を指定する。「無作為な弦」は各小問で明確な手順となり、手順ごとに異なる答えが得られた。

  • 面積から確率密度を得る。\(\mathrm{P}(R \leq r)\) は幾何から直接得られ、それを微分すると確率密度が得られた。

  • 段階的に平均する。まず（\(t\) を固定して）\(C\) の位置について平均し、次に \(t\) について平均した。

背後にある数学

ベルトランの3つの答え

ベルトラン自身の問いは、無作為な弦が内接正三角形（inscribed equilateral triangle）の1辺 \(\sqrt3a\) より長くなる確率はいくらか、というものであった。彼は3つの方法と3つの答えを示した。

  • 無作為な端点：一方の端点を固定する。もう一方の端点が円周の中央の3分の1にあれば、弦は長い。確率は \(\frac13\)。

  • 無作為な半径とその上の無作為な点を中点とする：\(O\) からの距離が \(\frac a2\) より小さければ、弦は長い。確率は \(\frac12\)。

  • 円板内のどこかに無作為な中点をとる：中点が \(O\) から \(\frac a2\) 以内にあれば、弦は長い。確率は \(\frac14\)。

それぞれの方法は弦の集合の上の異なる確率分布であり、矛盾はない。これらは異なる問いに答えているのである。教訓は、「一様に無作為に」という言葉は選んだパラメータ付け（parametrisation）に対してのみ意味をもち、連続的な集合に対しては、自然なパラメータ付けがただ1つに定まることはふつうない、ということである。

正しい答えはあるのか

1973年、物理学者のエドウィン・ジェインズ（Edwin Jaynes）は、2番目の方法こそが「正しい」と論じた。その根拠は、円を少し動かしたり拡大縮小したりしても答えは変わるべきではない、というものである。無作為な弦とは、床に描いた円の上にストローを投げたようなものであるべきだ、というわけである。この不変性（invariance）をもつのは、中心からの距離が一様な分布だけであり、実際にストローを投げる実験でも \(\frac12\) が確かめられている。正しい分布とはその状況の対称性を尊重するものである、という同じ考え方が、無作為な直線の数学である積分幾何学（integral geometry）の根底にあり、これは第 12.20 節のビュフォン（Buffon）の針も説明する。

逆説から公理へ

ベルトランは弦の逆説を『Calcul des probabilités』（1889年）で発表した。その目的の一部は、彼が「幾何学的確率」の軽率な使い方とみなしたものを皮肉ることであった。アンリ・ポアンカレ（Henri Poincaré）もこれを論じている。1900年、ダフィット・ヒルベルト（David Hilbert）は新世紀に向けた有名な問題の中に確率の公理化（axiomatisation）を挙げ、1933年にアンドレイ・コルモゴロフ（Andrey Kolmogorov）がこれを解決した。確率とは結果の空間の上の測度であり、「無作為な」対象についての問いはすべて、まずどの空間とどの測度を用いるかを述べなければならない。ベルトランの逆説は、なぜそれが必要なのかを示す標準的な例である。

思考のスキル

確率的な試行を定義する

確率を計算する前に、無作為な対象がどのように生成されるかを正確に述べよ。記述が異なれば答えも異なりうる。

大学では、あらゆる確率の計算は標本空間（sample space）と確率測度（probability measure）から始まる。統計学や物理学では、しばしば対称性によって正しい無作為性のモデルを選ぶことが、仕事の大きな部分を占める。

次の一歩

  1. ベルトランの確率。上の3つの確率 \(\frac13\)、\(\frac12\)、\(\frac14\) を確かめよ。

  2. もう1つの平均。弦の中点を円板内で一様に選ぶとき（右の図）、長さの期待値が \(\frac{4a}{3}\) であることを示せ。（ヒント：これは \(L(\frac\pi2)\) である。なぜか。）

  3. 無作為な距離。\(O\) から弦までの距離が \([0, a]\) 上で一様であるとき、長さの期待値が \(\frac{\pi a}{2}\) であることを示せ。

  4. 3つの方法、3つの分布。3つの方法それぞれについて、\([0, 2a]\) 上での弦の長さ \(\ell\) の確率密度を求めよ。

さらに学ぶために

  • Edwin Jaynes, “The well-posed problem”, Foundations of Physics 3 (1973). 不変性による議論。読みやすく、刺激的である。

  • Gábor Székely, Paradoxes in Probability Theory and Mathematical Statistics (Reidel). ベルトランの逆説をはじめ、多くの逆説を扱う。

  • Daniel Klain & Gian-Carlo Rota, Introduction to Geometric Probability (Cambridge University Press). 積分幾何学。いずれ読むときのために。
