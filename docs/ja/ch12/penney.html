問題

STEP III 2001、第13問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/01-s3-q13

導入

あなたと友人がそれぞれ硬貨投げ \(3\) 回分の列を1つずつ選び、どちらかの列が現れるまで硬貨を投げ続ける。\(3\) 回分の列はどれも、どの時点においても等しい確率（probability）で現れるのだから、どれを選んでも同じくらい有利なはずではないか。まったくそうではない。友人がどの列を選んでも、あなたはそれに勝つ列を選ぶことができ、ときには \(7\) 対 \(1\) という差をつけることさえできる。

これは Penney のゲーム（Penney’s game）であり、1969年に Walter Penney が考案したものである。この問題では、\(A\) が \(B\) に勝ち、\(B\) が \(C\) に勝ち、\(C\) が \(D\) に勝ち、\(D\) が \(A\) に勝つことを示す。じゃんけんのような循環である。「勝つ」という関係は推移的（transitive）ではない。後から選ぶ者は、長い目で見れば常に勝つことができるのである。

取りかかる前に

ここまでの投げの結果が TT で終わっていて、まだどちらも勝っていないとする。TTH より先に THH が現れることはありうるか。

TT の状態から T が続く限り、最後の \(2\) 回は TT のままであり、最初の H が出た時点で TTH が完成する。THH が現れるには TH が必要だが、TH は T の後に H が出ることでしか生じず、その H によってすでに TTH が完成してしまう。したがって、いったん TT が現れれば \(A\) の勝ちである。

順を追って解く

段階 1 状態

どちらの列も \(2\) 回の投げでは完成しない。\(2\) 回投げた後、それぞれの状態から次の \(1\) 回はどのような効果をもつか。

ゲームの行方は最後の \(2\) 回の結果だけで決まるので、状態（state）（最後の \(2\) 回の結果）を追跡すればよい。

  • TT から：\(A\) が勝つ（上で示した）。よって \(p_{\mathrm{TT}} = 1\) である。

  • HT から：次の \(1\) 回で TH か TT になる。よって \(p_{\mathrm{HT}} = \frac12p_{\mathrm{TH}} + \frac12p_{\mathrm{TT}}\) である。

  • TH から：H が出れば THH が完成し（\(B\) の勝ち）、T が出れば HT になる。よって \(p_{\mathrm{TH}} = \frac12 \cdot 0 + \frac12p_{\mathrm{HT}}\) である。

  • HH から：H が出れば再び HH、T が出れば HT になる。よって \(p_{\mathrm{HH}} = \frac12p_{\mathrm{HH}} + \frac12p_{\mathrm{HT}}\) であり、\(p_{\mathrm{HH}} = p_{\mathrm{HT}}\) を得る。

段階 2 解く

\(p_{\mathrm{TH}} = \frac12p_{\mathrm{HT}}\) を HT の式に代入すると \(p_{\mathrm{HT}} = \frac14p_{\mathrm{HT}} + \frac12\) となるので、\(p_{\mathrm{HT}} = \frac23\)、\(p_{\mathrm{HH}} = \frac23\)、\(p_{\mathrm{TH}} = \frac13\) である。\(4\) つの初期状態はそれぞれ確率 \(\frac14\) で生じるから、 \[\mathrm{P}(A \text{ が勝つ}) = \tfrac14\bigl(\tfrac23 + \tfrac23 + \tfrac13 + 1\bigr) = \tfrac23. \qed\]

段階 3 \(B\) 対 \(C\)

\(C\) は HHT を、\(B\) は THH を望んでいる。\(C\) が勝つのはどのようなときか。（最初の HH の直前に何がなければならないかを見よ。）

最初の \(2\) 回が HH であれば、その後に出る最初の T によって、THH が現れる前に HHT が完成する。\(C\) の勝ちである。そうでなければ、HH が初めて現れるより前のどこかに T があるので、最初の HH の直前は必ず T である。その瞬間に THH が現れ、これは（HH の後に T を必要とする）HHT より先である。したがって \(C\) が勝つのはゲームが HH で始まるときに限られ、 \[\mathrm{P}(B \text{ が勝つ}) = \tfrac34. \qed\]

段階 4 循環

同じ方法（あるいは「背後にある数学」の節で述べる近道）により、\(C\)（HHT）は確率 \(\frac23\) で \(D\)（HTT）に勝ち、\(D\)（HTT）は確率 \(\frac34\) で \(A\)（TTH）に勝つことがわかる。後者は、ステージ 3 で表と裏を入れ替えた鏡像である。よって \[A \text{ が勝つ相手は } B, \qquad B \text{ が勝つ相手は } C, \qquad C \text{ が勝つ相手は } D, \qquad D \text{ が勝つ相手は } A. \qed\]

振り返り

  • 適切な状態を選ぶ。重要なのは最後の \(2\) 回だけだったので、\(4\) つの状態と \(4\) つの方程式でゲーム全体を捉えることができた。

  • 第一ステップ解析。各方程式は次の \(1\) 回の結果で条件づけたものである。ある状態からの確率は、次の \(1\) 回で移る先についての平均である。

  • 決定的な事象を探す。ステージ 3 では、「最初の HH の直前は T である」という事実によって、方程式を使わずに勝敗が決まった。

背後にある数学

なぜ有利な列があるのか

\(3\) 回分の列はどれも、どの位置においても等しい確率で現れ、それぞれの期待（expected）待ち時間（waiting time）は容易に計算できる。しかし待ち時間は列によって異なる。TTH は平均 \(8\) 回で現れるが、TTT は平均 \(14\) 回かかる。自分自身と重なりをもつ列（TTT のように、惜しくも TTH となると \(2\) 回分の進捗が無駄になるもの）は現れるのが遅いのである。そして \(2\) つの列の競争で重要なのは、それぞれが相手の列とどう重なるかである。THH が HHT に勝つのは、HHT のどの出現も（一番最初を除けば）直前に T があり、つまりその時点で THH がちょうど現れているからである。後から選ぶ者の秘訣は常に同じである。相手の列の最初の \(2\) つの記号をとり、その前に相手の列の真ん中の記号の反対を置けばよい。

コンウェイの公式

ジョン・コンウェイ（John Conway）は、この勝率について驚くべき公式を発見した。長さ \(n\) の \(2\) つの列 \(X\), \(Y\) に対して、相関（correlation）\(XY\) を \(n\) 桁の \(2\) 進数として次のように定める。左から読んで第 \(i\) 桁は、\(X\) の第 \(i\) 記号から始まる部分が、それと同じ長さの \(Y\) の先頭部分に一致すれば \(1\) とする。このとき、\(X\) より先に \(Y\) が現れる勝率の比は \[(XX - XY) : (YY - YX).\] である。\(X =\) HHT, \(Y =\) THH の場合、\(XX = 100_2 = 4\)（HHT 全体だけが自分自身と一致する）、\(XY = 001_2 = 1\)（HHT の最後の T だけが THH の先頭と一致する）、\(YY = 100_2 = 4\)、\(YX = 011_2 = 3\)（THH の末尾の HH と H がともに HHT の先頭と一致する）である。よって THH が先に現れる勝率の比は \((4 - 1) : (4 - 3) = 3 : 1\) であり、これはステージ 3 の \(\frac34\) である。コンウェイの公式は任意の長さ、任意の文字集合の列に対して成り立ち、その証明にはマルチンゲール（martingale）の理論が用いられる。列が現れることに賭けるギャンブラーたちがいるカジノを想像し、公平なゲームの期待利益は \(0\) であるという事実を使うのである。

Penney とガードナー

Walter Penney は1969年、Journal of Recreational Mathematics 誌の短い記事でこのゲームを紹介した。マーティン・ガードナー（Martin Gardner）は1974年、Scientific American 誌の連載コラムでこれを有名にし、そこにはコンウェイが発見したものの発表していなかったコンウェイの公式も含まれていた。この種の非推移的な関係（エフロン（Efron）のサイコロもその一例で、サイコロ \(A\) が \(B\) に勝ち、\(B\) が \(C\) に勝ち、\(C\) が \(D\) に勝ち、\(D\) が \(A\) に勝つ）は繰り返し驚きを生む源であり、多数派の選好が循環しうる投票理論においても重要である。これがコンドルセ（Condorcet）のパラドックス（Condorcet’s paradox）である。

思考のスキル

第一ステップ解析

状態の間を移り変わる過程について確率や期待値（expectation）を求めるには、最初の \(1\) ステップで条件づけよ。そうすれば、状態ごとに \(1\) つの一次方程式が得られる。

これはマルコフ連鎖（Markov chain）の基本的な手法であり、第 12.16 節 や、大学の確率論の講義全体を通じて出会うことになる。同じ方法で、ある状態に別の状態より先に到達する確率、吸収（absorption）までの期待時間、賭けの問題における破産（ruin）の確率を求めることができる。

次の一歩

  1. 4 人同時に。STEP II 2015、第12問 に挑戦せよ。\(4\) 人が同時に行う Penney のゲームである。

  2. 待ち時間。HH が初めて現れるまでの投げの回数の期待値は \(6\)、HT の場合は \(4\) であることを示せ。（第一ステップ解析を用いよ。）

  3. 最善の応手。長さ \(3\) の \(8\) つの列それぞれについて、それに最大の確率で勝つ列を求めよ。最も簡単に負かされる列はどれか。

  4. コンウェイの公式。コンウェイの公式を用いて、HHT が確率 \(\frac23\) で HTT に勝つことを確かめよ。

さらに学ぶために

  • Martin Gardner, Time Travel and Other Mathematical Bewilderments（W. H. Freeman）。Penney のゲームとコンウェイの公式を収録している。

  • Ronald Graham, Donald Knuth & Oren Patashnik, Concrete Mathematics（Addison-Wesley）、8.4 節。母関数（generating function）を用いた Penney のゲームの扱い。

  • David Williams, Probability with Martingales（Cambridge University Press）。マルチンゲールによる証明。将来のために。
