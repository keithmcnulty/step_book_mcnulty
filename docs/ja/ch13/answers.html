第13章 · 世界における統計とランダムネス

「次の一歩」の解答

ここに載せているのは完全な解答ではなく、簡潔な答えとヒントである。結果と鍵となるステップを示しているので、自分の解答を確かめるのに使ってほしい。答えを見る前に、まずそれぞれの問題にしっかり取り組むこと。

13.1 見出しを読み解く

  1. \(1 - \sum_{k=0}^{6}\mathrm{e}^{-2.96}\frac{2.96^k}{k!} \approx 0.0315\) である。したがって、7人以上が死亡する日は年に約 \(11\) 日ある。\(\mathrm{P}(X \geq 9) \approx 0.0035\) であり、これは年に約1日である。

  2. 死者数は \(150K\) であり、\(K\) は平均（mean）\(1.2\) のポアソン分布（Poisson distribution）に従う。平均は \(180\)、分散（variance）は \(150^2 \times 1.2 = 27\,000\)、標準偏差（standard deviation）は約 \(164\) である。死者が \(125\) 人以下の年とは墜落事故が1件もない年のことであり、その確率は \(e^{-1.2} \approx 0.30\) なので、まったく珍しいことではない。しかし、このモデルでは死者がちょうど \(125\) 人になることはありえない。死者数は \(150\) の倍数でしか生じないからである。平均と標準偏差からはこのことはわからない。集中（clustering）があると分布はとびとびになり、確率はすべて \(0\)、\(150\)、\(300\)、…… に集まるのである。

  3. \(z = \frac{1349.5 - 1080}{33} \approx 8.2\) であり、確率は \(10^{-16}\) 程度である。一定の発生率では \(1350\) を説明できない。何かが本当に変化したのである（あるいは死者の数え方が変わったのである）。

  4. たとえば次のようになる。(i)「総数だけでは、飛行機と徒歩のどちらが安全かはわからない」、(ii)「1990年の航空事故死者数は通常の範囲内」、(iii)「火曜日の歩行者死亡7人：ひどい日だが、年に約11回は起こること」、(iv)「1990年、歩行者の死者が急増：原因の究明が必要」。

13.2 ハタネズミを数える

  1. \(\frac{p_N}{p_{N-1}} = \frac{(N - M)(N - C)}{N(N - M - C + R)}\) であり、これが \(1\) 以上となるのは \(NR \leq MC\) のとき、かつそのときに限る。したがって \(p_N\) は \(N = \frac{MC}{R}\) まで増加し、その後は減少する。最大値をとるのは、この値の整数部分においてである。

  2. \(a\) 人の女性と \(b\) 人の男性から \(c\) 人の委員会を選ぶ方法を、含まれる女性の人数 \(j\) ごとに数える。各 \(j\) について \(\binom aj\binom{b}{c - j}\) 通りである。

  3. \(\frac{\mathrm{d}}{\mathrm{d}p}\bigl(h\ln p + (n - h)\ln(1 - p)\bigr) = \frac hp - \frac{n - h}{1 - p} = 0\) より \(p = \frac hn\) が得られる。

  4. \(R = 0\) のとき \(p_N\) はどこまでも増加し続け、推定値（estimate）は無限大になる。この方法は、2回目の標本に標識された個体が十分に含まれている場合にしか機能しない。再捕獲数が少ないと、推定値は非常に不安定になる。

13.3 ドイツ戦車問題

  1. 最大値を \(M\) とすると、\(\mathrm{E}(M) = \frac{nN}{n + 1}\)、\(\mathrm{Var}(M) = \frac{nN^2}{(n + 1)^2(n + 2)}\) なので、\(\mathrm{E}(M - N)^2 = \frac{2N^2}{(n + 1)(n + 2)}\) である。これは \(\mathrm{Var}(Z_1) = \frac{N^2}{n(n + 2)}\) の \(\frac{2n}{n + 1}\) 倍であり、より悪い。最良の定数倍は \(c = \frac{N\mathrm{E}(M)}{\mathrm{E}(M^2)} = \frac{n + 2}{n + 1}\) であり、そのときの平均二乗誤差（mean squared error）は \(\frac{N^2}{(n + 1)^2}\) で、\(Z_1\) よりわずかに良い。

  2. \(\mathrm{E}(\min) = \frac{N}{n + 1}\) であり、\(\min\) は \(M\) と同じ分散をもつので、\(\mathrm{Var}\bigl((n + 1)\min\bigr) = \frac{nN^2}{n + 2}\) である。これは \(n\) が大きくなっても小さくならないので、よくない推定量（estimator）である。

  3. 最大値が \(m\) 以下となるのは、\(k\) 個の数がすべて \(\{1, \ldots, m\}\) から選ばれるとき、かつそのときに限る。\(k = 1\) のとき推定量は \(2X - 1\) であり、その平均は \(2 \cdot \frac{N + 1}{2} - 1 = N\) である。

  4. \(98 + \frac{98}{5} - 1 = 116.6\) であり、戦車は約 \(117\) 両である。

13.4 平均か中央値か？

  1. どの値を中央値（median）とするか（\(2n + 1\) 通り）と、残りのうちどの \(n\) 個をそれより小さい値とするか（\(\binom{2n}{n}\) 通り）を選ぶ。確率は \((2n + 1)\binom{2n}{n}y^n(1 - y)^n\,\delta y = \frac{(2n + 1)!}{(n!)^2}y^n(1 - y)^n\,\delta y\) である。

  2. \(\mathrm{Var}(Y) = \frac{1}{4(2n + 3)} = \frac{1}{20}\)、\(\mathrm{Var}(\bar X) = \frac{1}{12(2n + 1)} = \frac{1}{36}\) である。平均のほうが優れている。

  3. \(\mathrm{Var}(\max) = \mathrm{Var}(\min) = \frac{m}{(m + 1)^2(m + 2)}\)、\(\mathrm{Cov}(\max, \min) = \frac{1}{(m + 1)^2(m + 2)}\) であり、これより \(\frac{1}{2(m + 1)(m + 2)}\) が得られる。これは \(\frac{1}{m^2}\) のように小さくなり、平均の \(\frac{1}{12m}\) よりはるかに速い。一様分布（uniform distribution）に従うデータでは、戦車の場合と同じく、両端の値が情報を担っているのである。

  4. 平均は約 \(18.6\) であり、ただ1つの入力ミスによって台無しになっている。中央値は \(10.1\) であり、影響を受けない。

13.5 答えにくい質問をする

  1. 真実の回答が得られる確率を \(t = ap + bq\) とする。「はい」の確率は \(\frac12t + \frac12(1 - t) = \frac12\) なので、\(\mathrm{P}(\text{表} \mid \text{はい}) = t\) であり、これが \(\frac12\) となるのは \(2t = 1\) のとき、かつそのときに限る。同じ双子の一方が2回答える場合、「はい」の次に「いいえ」となる確率は、硬貨が表であっても裏であっても \(pa(1 - a) + qb(1 - b)\) なので、事後確率（posterior probability）は \(\frac12\) である。2回とも「はい」となる確率は、表のとき \(pa^2 + qb^2\)、裏のとき \(p(1 - a)^2 + q(1 - b)^2\) であり、これらが等しいのは \(2(ap + bq) = 1\) のとき、かつそのときに限る。

  2. \(\mathrm{P}(\text{はい}) = \frac34\pi + \frac14(1 - \pi)\) なので、\(\hat\pi = \frac{0.4 - 0.25}{0.5} = 0.3\) である。標準誤差（standard error）は \(\frac{\sqrt{0.4 \times 0.6/400}}{0.5} \approx 0.049\) である。

  3. \(\mathrm{E}(Y^2) = \sum_c\mathrm{P}(C = c)\bigl(\mathrm{Var}(Y \mid c) + \mathrm{E}(Y \mid c)^2\bigr)\) である。ここから \(\mathrm{E}(Y)^2 = \bigl(\sum_c\mathrm{P}(C = c)\mathrm{E}(Y \mid c)\bigr)^2\) を引くと、\(\mathrm{E}(\mathrm{Var}(Y \mid C)) + \mathrm{Var}(\mathrm{E}(Y \mid C))\) が得られる。

  4. \(Z_2\) はそれぞれ確率 \(\frac12\) で、\(\frac n6\) に近い値（表）または \(\frac{5n}{6}\) に近い値（裏）をとる。したがって \(\mathrm{P}(Z_2 > \frac n2) \to \frac12\) となるが、\(Z_2\) が \(\frac n2\) の近くの値をとることはほとんどない。

13.6 積み重なる誤差

  1. 切り捨て（truncation）による各誤差は \((-1, 0]\) 上の一様分布に従う。それぞれに \(\frac12\) を加えると \((-\frac12, \frac12]\) 上の一様分布となり、四捨五入（rounding）とまったく同じになる。したがって、補正した VOZ は LEP と同等によい。

  2. 各誤差は \((-0.05, 0.05)\) 上の一様分布に従い、分散は \(\frac{0.1^2}{12}\) なので、合計の標準偏差は \(\sqrt{10\,000 \times 0.01/12} \approx 2.9\) である。

  3. \(3000 \times 250 \times 0.0005 = 375\) 点である。

  4. 誤差が2つのときは、\([-1, 1]\) 上で \(1 - |x|\) となる。3つのときは、\(|x| \leq \frac12\) で \(\frac34 - x^2\)、\(\frac12 \leq |x| \leq \frac32\) で \(\frac12\bigl(\frac32 - |x|\bigr)^2\) となり、すでに正規分布（normal distribution）の曲線に近い。

13.7 相関をつくり出す

  1. 標準化された（standardised）変数に対しては \(\mathrm{Var}(X_1 + X_2 + X_3) = 3 + 6\rho \geq 0\) なので、\(\rho \geq -\frac12\) である。\(n\) 個の変数の場合は、\(n + n(n - 1)\rho \geq 0\) より \(\rho \geq -\frac{1}{n - 1}\) が得られる。

  2. \(b = \frac{\rho_{23} - \rho_{12}\rho_{13}}{\sqrt{1 - \rho_{12}^2}}\) とすると、\((1 - \rho_{12}^2)(1 - \rho_{13}^2 - b^2) = 1 - \rho_{12}^2 - \rho_{13}^2 - \rho_{23}^2 + 2\rho_{12}\rho_{13}\rho_{23} = \det R\) である。\(1 - \rho_{12}^2 > 0\) なので、2つの条件は同値である。

  3. \(\mathrm{Var} = \frac14(0.04 + 0.09 + 0.12\rho)\) であり、\(\rho = -1\)、\(0\)、\(1\) に対して標準偏差はそれぞれ \(0.05\)、\(0.18\)、\(0.25\) である。2つの株が完全に相関（perfectly correlated）していない限り、組み合わせたもののリスクは2つのリスクの平均（\(0.25\)）より小さい。

  4. \(Z_2 = \dfrac{Y_2 - \rho_{12}Y_1}{\sqrt{1 - \rho_{12}^2}}\) である。
