13.7

相関をつくり出す

ワークシート問題へのリンク、ヒント、大学の数学、演習問題 第13章章全体のPDF
問題

STEP III 2010、第13問

先に進む前に問題を読んでおこう。問題は STEP Support Programme の問題データベースにある： step.maths.org/questions/10-s3-q13

導入

ある銀行が、株式のポートフォリオ（portfolio）で損失を出す可能性がどの程度あるかを知りたいとする。株価は連動して動く。ある株が下がれば、ほかの株も下がる傾向がある。起こりうる将来を何千通りもシミュレーションするには、銀行はちょうど正しい形で相関した乱数を生成しなければならない。独立（independent）な確率変数（random variable）から出発して、指定された相関（correlation）をもつ確率変数をどうやって作ればよいだろうか。

この問題は、3つの変数についてその作り方を一歩ずつ示している。新しい変数はそれぞれ、それまでの独立な材料の組合せに、分散（variance）を補うための新たな独立な材料を1つ加えたものである。この構成は、姿を変えた線形代数の有名な道具であるコレスキー分解（Cholesky decomposition）であり、また隠れた制約も明らかにする。すなわち、どんな相関の組でも実現できるわけではないのである。

出題範囲についての注意

共分散と相関は、2019年に STEP の出題範囲から外された。共分散（covariance）は \(\mathrm{Cov}(U, V) = \mathrm{E}(UV) - \mathrm{E}(U)\mathrm{E}(V)\) であり、独立な変数に対しては \(0\) となる。また各引数について線形である：\(\mathrm{Cov}(aU + bV, W) = a\,\mathrm{Cov}(U, W) + b\,\mathrm{Cov}(V, W)\)。さらに \(\mathrm{Var}(U) = \mathrm{Cov}(U, U)\) が成り立つ。相関は常に \(-1\) 以上 \(1\) 以下である。

取りかかる前に

\(Z_1\) と \(Z_2\) は独立である。その共分散はいくらか。したがって相関はいくらか。

独立な変数は \(\mathrm{E}(Z_1Z_2) = \mathrm{E}(Z_1)\,\mathrm{E}(Z_2)\) を満たす。よって共分散は \(0\) であり、\(\mathrm{Corr}(Z_1, Z_2) = 0\) である。

順を追って解く

段階 1 2つの変数

\(\mathrm{E}(Y_2) = 0\) である。\(Z_1\) と \(Z_2\) は独立で分散が \(1\) なので、 \[\mathrm{Var}(Y_2) = \rho_{12}^2 + (1 - \rho_{12}^2) = 1, \qquad \mathrm{Cov}(Y_1, Y_2) = \mathrm{Cov}\bigl(Z_1, \rho_{12}Z_1 + \sqrt{1 - \rho_{12}^2}\,Z_2\bigr) = \rho_{12}.\] 分散はどちらも \(1\) なので、\(\mathrm{Corr}(Y_1, Y_2) = \rho_{12}\) である。■

\(Z_1\) と \(Z_2\) を直交する単位ベクトルとみなそう。\(Y_2\) はどこにあるか。\(Y_1\) と \(Y_2\) のなす角の余弦はいくらか。

\(Y_2 = \rho_{12}Z_1 + \sqrt{1 - \rho_{12}^2}\,Z_2\) は、\(Z_1 = Y_1\) と角 \(\theta\) をなす単位ベクトルである。ただし \(\cos\theta = \rho_{12}\) である。相関とは、変数をベクトルとみなしたときの、それらのなす角の余弦なのである（図 13.7.1）。

段階 2 3つ目の変数

3つの条件 \(\mathrm{Var}(Y_3) = 1\), \(\mathrm{Cov}(Y_1, Y_3) = \rho_{13}\), \(\mathrm{Cov}(Y_2, Y_3) = \rho_{23}\) を \(a\), \(b\), \(c\) を用いて書き表せ。

線形性と独立性を用いると、 \[a^2 + b^2 + c^2 = 1, \qquad a = \rho_{13}, \qquad \rho_{12}a + \sqrt{1 - \rho_{12}^2}\,b = \rho_{23}.\] よって \[a = \rho_{13}, \qquad b = \frac{\rho_{23} - \rho_{12}\rho_{13}}{\sqrt{1 - \rho_{12}^2}}, \qquad c = \sqrt{1 - \rho_{13}^2 - \frac{(\rho_{23} - \rho_{12}\rho_{13})^2}{1 - \rho_{12}^2}}. \qed\] （\(c \geq 0\) なので、負でない平方根をとる。）

段階 3 任意の平均と分散

定数倍と平行移動は相関を変えないので、 \[X_i = \mu_i + \sigma_iY_i \qquad (i = 1, 2, 3)\] は平均 \(\mu_i\)、分散 \(\sigma_i^2\)、相関 \(\rho_{ij}\) をもつ。■

\(c\) の式では、根号の中の量が負でないことが必要である。\(\rho_{12} = \rho_{13} = \rho_{23} = -0.6\) を試してみよう。何がうまくいかないだろうか。また、3つの変数が互いにどれも強い負の相関をもつことはできない、というのはなぜ納得のいくことなのだろうか。

振り返り

  • 変数を1つずつ積み上げる。新しい変数はそれぞれ、それまでの材料をちょうどよい量だけ取り込み、新たな独立な材料を1つ加えたものであった。

  • 共分散は線形である。すべての条件が、係数についての簡単な方程式になった。

  • 相関は余弦である。標準化した変数を単位ベクトルとみなすと、相関は角度になる。

背後にある数学

コレスキー分解

行列の形で書くと、この構成は \(\mathbf{Y} = L\mathbf{Z}\) と表される。ここで \(L\) は下三角（lower triangular）行列 \[L = \begin{pmatrix} 1 & 0 & 0 \\ \rho_{12} & \sqrt{1 - \rho_{12}^2} & 0 \\ a & b & c \end{pmatrix},\] であり、\(\mathbf{Y}\) の相関行列（correlation matrix）は \(R = LL^{\mathsf T}\) となる。対称行列を \(LL^{\mathsf T}\) の形に書くことをコレスキー分解という。これはフランスの軍の技術者アンドレ＝ルイ・コレスキー（André-Louis Cholesky）が1910年ごろ、測地測量の方程式を解くために見いだしたものである（第一次世界大戦で本人が戦死した後に発表された）。この分解は \(R\) が正定値（positive definite）であればいつでも可能であり、その計算は私たちが手で行ったこととまったく同じである。すなわち、各行を順に解いていくのである。これは、金融、工学、気候モデリングにおいて相関のある変数をシミュレーションする標準的な方法である。

どのような相関が可能か

\(c\) の根号の中の数は負であってはならない。展開すると、その条件は \[1 - \rho_{12}^2 - \rho_{13}^2 - \rho_{23}^2 + 2\rho_{12}\rho_{13}\rho_{23} \geq 0,\] となり、これは相関行列の行列式（determinant）が負でないという条件である。幾何学的にいえば、2つずつのなす角が \(\theta_{ij}\)（ただし \(\cos\theta_{ij} = \rho_{ij}\)）である3つの単位ベクトルが、実際に空間の中で両立しなければならないということである。もし \(\rho_{12} = \rho_{13} = \rho_{23} = -0.6\) ならば、角はすべて約 \(127^\circ\) であり、互いに \(127^\circ\) をなす3つのベクトルには、和が \(360^\circ\) を超える角が必要になってしまう。これは不可能である。一般に、ある行列が相関行列となりうるのは、それが半正定値（positive semi-definite）、すなわちすべての固有値（eigenvalue）が負でない場合に限られる（第 7.2 節）。相関を不完全なデータから個別に推定すると、この条件が成り立たないことがあり、そのとき統計学者は最も近い有効な相関行列を求めなければならない。この問題は2002年に Nicholas Higham によって解決された。

ゴルトン、ピアソンと相関

フランシス・ゴルトン（Francis Galton）は1888年、親と子の身長がどのように関係しているかを研究する中で相関を導入し、1896年にはカール・ピアソン（Karl Pearson）がこの問題で用いられている積率（product moment）の公式を与えた。ゴルトンは平均への回帰（regression to the mean）にも気づいていた（第 13.1 節）。ピアソンは1911年、ユニバーシティ・カレッジ・ロンドン（University College London）に世界初の大学の統計学科を創設した。「相関は因果を意味しない」という警句は、相関そのものとほとんど同じくらい古い。

思考のスキル

新たな独立な材料を使って、一歩ずつ構成する

指定された関係をもつ対象を作るには、それらを1つずつ加えていき、それぞれを、それまでに作ったものの組合せに新しく独立なものを加えたものとせよ。

これは線形代数のグラム–シュミットの直交化法（Gram–Schmidt process）を逆向きにたどったものであり、またコレスキー分解でもある。大学では、最小二乗法（least squares）、多変量正規分布（multivariate normal distribution）の理論、確率過程のシミュレーションなどに現れる。

次の一歩

  1. 不可能な相関。3つの確率変数が2つずつすべて相関 \(\rho\) をもつことは、\(\rho \geq -\frac12\) でない限り不可能であることを示せ。\(n\) 個の変数の場合、対応する主張はどうなるか。

  2. 行列式を確かめる。\(R\) を \(3 \times 3\) の相関行列とするとき、\(1 - \rho_{13}^2 - b^2 \geq 0\) が \(\det R \geq 0\) と同値であることを示せ。

  3. ポートフォリオのリスク。2つの株の収益率の標準偏差（standard deviation）が \(\sigma_1 = 0.2\) と \(\sigma_2 = 0.3\) で、相関が \(\rho\) であるとする。それぞれに半分ずつ投資したポートフォリオの標準偏差を、\(\rho = -1\), \(0\), \(1\) のそれぞれについて求めよ。分散投資（diversification）によって何が得られるか。

  4. 材料を復元する。問題文のように \(Y_1\), \(Y_2\) が与えられたとき、\(Z_2\) を \(Y_1\) と \(Y_2\) を用いて表せ。（これがグラム–シュミットの1ステップである。）

さらに学ぶために

  • Gilbert Strang, Introduction to Linear Algebra（Wellesley-Cambridge）。正定値行列とコレスキー分解について。

  • Paul Glasserman, Monte Carlo Methods in Financial Engineering（Springer）。相関のある変数を実際にシミュレーションする方法。高度だが、最初のほうの章は読みやすい。

  • Theodore Porter, Karl Pearson: The Scientific Life in a Statistical Age（Princeton University Press）。
