用語集

大学の数学には独自の語彙があり、その多くは読者にとって初めて目にするものであろう。この用語集は、本書に現れる語のうち学校ではまず出会わないものを集め、それぞれに短い説明を付け、役に立つ場合にはその考え方が使われている節、あるいはきちんと説明されている節を示したものである。説明は理解の手がかりとなることを意図したものであって、厳密な定義ではない。注意深い定義をもつ語については、示した節でその定義を与えている。

集合、関数、証明のようにすでになじみのある語もいくつかあるが、大学ではこれらを学校よりも注意深く用いるので、その理由から収録している。項目中で斜体で示した語には、それ自身の項目がある。

A

断熱不変量（adiabatic invariant）

系をゆっくりと変化させたとき、ほぼ一定に保たれる量。ゆっくりと圧縮されるシリンダーの中で跳ね返る分子は、その速さとシリンダーの長さの積をほぼ一定に保つ（第 10.4 節）。

代数的数（algebraic number）

整数係数（正、負、零のいずれでもよい）で、すべてが零ではない多項式方程式の根となる数。\(\sqrt2\)、\(\mathrm{i}\)、\(\frac12(1 + \sqrt5)\) は代数的数である。代数的数でない数は超越数である（第 6.3 節）。

解析学（analysis）

微積分に厳密な基礎を与える数学の分野。極限、連続性、微分、積分、無限級数を、すべて正確に定義し、第一原理から証明する。第2章から第4章はその入門である。

角運動量（angular momentum）

運動量の回転版。軸のまわりを回転する物体については、慣性モーメントと角速度の積であり、外部からの回転させる作用がなければ保存される（第 11.6 節）。

算術幾何平均（arithmetic–geometric mean）

2つの数の組を、その相加平均と相乗平均の組で置き換えることを繰り返して得られる2つの数列の共通の極限。驚くほど速く収束する（第 2.6 節）。

結合的（associative）

演算 \(\ast\) が結合的であるとは、すべての \(a\)、\(b\)、\(c\) に対して \((a \ast b) \ast c = a \ast (b \ast c)\) が成り立つことであり、このとき括弧を省略できる。数の加法と乗法は結合的であるが、減法はそうではない。

漸近的（asymptotic）

2つの式が漸近的であるとは、\(n \to \infty\) のときそれらの比が \(1\) に近づくことであり、\(f(n) \sim g(n)\) と書く。スターリング（Stirling）の公式は \(n! \sim \sqrt{2\pi n}\,(n/\mathrm{e})^n\) を主張するが、両辺の差は限りなく大きくなる（第 12.23 節）。

公理（axiom）

証明なしに出発点として認め、そこから他のすべてを導く命題。大学の代数学の多くは、短い公理の一覧から出発し、そこから何が導かれるかを問う（第 7.3 節、第 6.5 節）。

B

基底段階（base case）

帰納法による証明の最初の段階。最小の値、通常は \(n = 0\) または \(n = 1\) について命題が正しいことを確かめる。続いて帰納段階で、ある値で正しければ次の値でも正しいことを示す。

基準率の誤り（base-rate fallacy）

そもそもそれがどれほどありふれたものであったかを無視し、証拠だけから何かの確率を判断してしまう誤り。病気が十分にまれであれば、精度の高い検査で陽性と出ても、誤った警報である可能性のほうが高いことがある。そうなるかどうかは、病気がどれほどまれで、検査がどれほど正確かによって決まる（第 12.2 節）。

基底（basis）

空間のどのベクトルもそれらの一次結合としてただ1通りに表せるようなベクトルの集合。平面では \(\mathbf{i}\) と \(\mathbf{j}\) が基底をなし、平行でない任意の2つのベクトルの組も基底をなす。基底に含まれるベクトルの個数がその空間の次元である（第 6.3 節）。

ベイズの定理（Bayes’ theorem）

条件付き確率の向きを逆にする規則：\(\mathrm{P}(A \mid B) = \mathrm{P}(B \mid A)\,\mathrm{P}(A)/\mathrm{P}(B)\)。証拠に照らして信念をどう更新すればよいかを教えてくれる（第 12.2 節）。

偏り（bias）

推定量が偏っているとは、多くの標本にわたって平均すると高すぎたり低すぎたりすることである。期待値が推定しようとしている量にちょうど等しいとき、その推定量は不偏であるという（第 13.3 節）。

全単射（bijection）

一対一の対応。一方の集合のすべての元を、もう一方の集合のちょうど1つの元と組にし、どちら側にも余りが出ないような規則。2つの有限集合の大きさが等しいのは、それらの間に全単射が存在するときであり、かつそのときに限る。無限集合の大きさはこの考え方で定義される（第 1.8 節、第 9.10 節）。

二項演算（binary operation）

2つの対象を組み合わせて3つめの対象を与える規則。数の加法、行列の乗法、関数の合成などがその例である。

界（bound）

数の集合や数列の上界とは、そのどれもがそれを超えないような数のことであり、下界とは、そのどれもがそれを下回らないような数のことである。上界と下界の両方をもつ数列は有界であるという（第 2.2 節）。

分岐過程（branching process）

各個体が互いに独立に、ランダムな数の子孫をもつような個体群のモデル。中心となる問いは家系が絶えるかどうかであり、その答えは確率母関数から得られる（第 12.15 節）。

C

変分法（calculus of variations）

未知のものが関数や曲線全体であり、それをある量ができるだけ小さく、あるいはできるだけ大きくなるように選ぶ問題の研究。最短経路、最速で滑り降りる曲線、最大の面積を囲む曲線などがその例である（第 4.7 節）。

懸垂線（catenary）

垂れ下がった鎖の形で、\(y = a\cosh(x/a)\) のグラフである。放物線のように見えるが、放物線ではない（第 11.14 節）。

コーシー分布（Cauchy distribution）

釣鐘形のグラフをもつ連続分布で、裾が非常に重いために平均をもたない。この分布からの標本の平均は、1回の観測値と比べて少しも信頼できるものにならない（第 12.22 節）。コーシー（Cauchy）にちなむ。

中心極限定理（central limit theorem）

同じ分布に従い分散が有限である多数の独立な確率的な量の和は、適切に平行移動し尺度を調整すると、その共通の分布が何であっても近似的に正規分布に従う、という定理。分布が異なる量についても、そのうちの少数が和を支配しない限り、成り立つ形がある。釣鐘形の曲線があらゆるところに現れる理由を説明する（第 12.24 節）。

カオス（chaos）

決定論的な系の振る舞いで、初期点にきわめて敏感なため、長期的な予測が事実上不可能になるもの。非常に近い2つの初期点が、まったく異なる未来へとつながる（第 8.7 節、第 8.8 節）。

閉じている（closed）

集合がある演算について閉じているとは、集合の2つの元を組み合わせると常にその集合の元が得られることである。偶数全体は加法について閉じているが、奇数全体はそうではない。

可換（commutative）

演算 \(\ast\) が可換であるとは、常に \(a \ast b = b \ast a\) が成り立つことである。数の乗法は可換であるが、行列の乗法や四元数の乗法はそうではない（第 7.1 節、第 6.7 節）。

完備性（completeness）

実数がすき間をもたないという性質。すなわち、上に有界な増加数列はすべて実数に収束する。分数の列が \(\sqrt2\) に近づいていくことがあるので、有理数はこの性質をもたない。解析学の多くはこの性質に基づいている（第 2.2 節）。

合同（congruence）

\(a \equiv b \pmod n\) は「\(n\) を法として \(a\) は \(b\) と合同である」と読み、\(a\) と \(b\) を \(n\) で割った余りが等しいことを意味する。同値な言い方をすれば、\(n\) が \(a - b\) を割り切ることである。合同式を用いた計算を合同算術という（第 1.5 節）。

予想（conjecture）

正しいと信じられているが、まだ証明されていない命題。

保存則（conservation law）

エネルギー、運動量、角運動量のような量が、系の時間発展によって変化しないという主張。保存則を使うと、細部を追わずに問題を解けることが多い（第 10.1 節）。

連続（continuous）

関数が連続であるとは、入力の小さな変化が出力の小さな変化しか生まないことである。くだけた言い方をすれば、そのグラフをペンを紙から離さずに描けることである。正確には、\(x \to a\) のとき \(\mathrm{f}(x) \to \mathrm{f}(a)\) となるならば、\(\mathrm{f}\) は \(a\) で連続である（第 3.1 節、第 8.8 節）。

背理法（proof by contradiction）

命題が偽であると仮定し、そこから不可能なことを導く証明。典型例は \(\sqrt2\) が無理数であることの証明である（第 1.3 節）。

対偶（contrapositive）

「\(P\) ならば \(Q\)」の対偶は「\(Q\) でないならば \(P\) でない」である。この2つの命題は論理的に同値であり、対偶を証明するほうが易しいことが多い。これは逆「\(Q\) ならば \(P\)」とは異なり、逆は偽であることも十分ありうる。

収束する（converge）

数列が収束するとは、その項がある定まった数、すなわちその極限に、いくらでも近づき、しかも近いままであり続けることである。級数が収束するとは、その部分和が収束することである。収束しない数列や級数は発散するという（第 2.1 節、第 2.3 節）。

凸（convex）

関数が凸であるとは、\(x^2\) や \(\mathrm{e}^x\) のように、グラフ上の任意の2点を結ぶ弦がグラフ上またはグラフより上にあることである。相加相乗平均の不等式（AM–GM）をはじめ、多くの不等式が凸性から導かれる（第 3.3 節）。

系（corollary）

証明したばかりの定理からすぐに導かれる結果。

相関（correlation）

\(-1\) と \(1\) の間の数で、2つの確率的な量が直線的な関係にどれだけ近いかを測るもの。共分散を2つの標準偏差で割って尺度を調整したものである（第 13.7 節）。

可算（countable）

集合が可算であるとは、その元を1番目、2番目、3番目、……と、場合によっては限りなく、並べ上げられることである。整数全体、そして意外なことに分数全体も可算であるが、実数全体は可算ではない（第 1.8 節）。

反例（counterexample）

一般的な命題が偽であることを示すただ1つの例。主張を支持する例がどれほど多くても、反例が1つあればその主張を否定するのに十分である。

共分散（covariance）

\(\mathrm{Cov}(X, Y) = \mathrm{E}(XY) - \mathrm{E}(X)\mathrm{E}(Y)\) であり、2つの確率的な量がどのように連動して変化するかを測るもの。独立な量については零になるが、共分散が零であっても独立であるとは限らない（第 12.4 節、第 13.7 節）。

サイクル（cycle）

関数を繰り返し適用したときに順に巡る点の集合：\(x_1 \mapsto x_2 \mapsto \cdots \mapsto x_n \mapsto x_1\)。数 \(n\) をその周期といい、これらの点を周期点という（第 8.8 節）。

サイクロイド（cycloid）

転がる車輪の縁上の1点が描く曲線。上下を逆さにすると、最速降下曲線であると同時に、どこから滑り降りても同じ時間がかかる曲線でもある（第 11.4 節）。

円分多項式（cyclotomic polynomial）

根がちょうど1の原始 \(n\) 乗根全体であるような多項式 \(\Phi_n(x)\)。整数係数をもち既約であって、\(x^n - 1\) は \(n\) のすべての約数 \(d\) についての \(\Phi_d(x)\) の積に等しい。たとえば \(x^4 - 1 = (x - 1)(x + 1)(x^2 + 1)\) である（第 6.1 節）。

D

完全順列（derangement）

どの要素ももとの位置にとどまらないような、並びの並べ替え（第 9.8 節）。

導分（derivation）

関数（あるいは他の対象）に対する演算 \(D\) で、\(D(f + g) = Df + Dg\) と積の法則 \(D(fg) = f\,Dg + g\,Df\) を満たすもの。微分が標準的な例であり、微分の性質の多くはこの2つの規則だけから導かれる（第 6.5 節）。

行列式（determinant）

正方行列から計算される数で、対応する変換が面積や体積を何倍にするかを表す。行列が逆行列をもたないとき、かつそのときに限り零になる（第 7.3 節）。

微分可能（differentiable）

関数がある点で微分可能であるとは、そこでグラフがきちんと定まった接線をもち、導関数を定める極限が存在することである。微分可能な関数はすべて連続であるが、逆は成り立たない。\(|x|\) は連続であるが、\(0\) で微分可能ではない。

次元（dimension）

基底に含まれるベクトルの個数。すなわち、ベクトル空間における独立な方向の数。

発散する（diverge）

収束するを参照。

力学系（dynamical system）

系の状態が時間とともにどう変化するかを記述する規則で、一歩ずつ変化するもの（\(x_{n+1} = \mathrm{f}(x_n)\) で定義される数列）と、連続的に変化するもの（微分方程式）がある。第8章はこれを扱う。

E

固有値、固有ベクトル（eigenvalue, eigenvector）

零でないベクトル \(\mathbf{v}\) が行列 \(\mathbf{M}\) の固有ベクトルであるとは、ある数 \(\lambda\) に対して \(\mathbf{M}\mathbf{v} = \lambda\mathbf{v}\) が成り立つことであり、この数を固有値という。すなわち、変換は \(\mathbf{v}\) の向きを変えずに伸縮する（第 7.2 節）。

包絡線（envelope）

曲線の族のすべての曲線に接する曲線。一定の速さで投げたボールのすべての軌道の包絡線は安全放物線であり、ボールが到達しうる領域の境界になっている（第 11.9 節）。

平衡（equilibrium）

変化しない系の状態。小さな乱れが小さいままであれば安定であり、さらに摩擦のある振り子の場合のように乱れが減衰して消えるならば漸近安定である。摩擦のない振り子がまっすぐ下に垂れた状態は安定であるが、小さく押すと永久に揺れ続ける。小さな乱れのうちに増大するものがあれば不安定である（第 8.3 節、第 11.8 節）。

推定量（estimator）

個体群の大きさや分布の平均のような未知の量の推測値を、データから計算する規則（第 13.3 節）。

オイラー標数（Euler characteristic）

\(V\) 個の頂点、\(E\) 本の辺、\(F\) 個の面をもつ多面体に対する数 \(V - E + F\) で、穴のない多面体では常に \(2\) になる（第 7.9 節）。オイラー（Euler）にちなむ。

存在証明（existence proof）

何かが存在することの証明で、それをどうやって見つけるかを必ずしも示さないもの。鳩の巣原理と中間値の定理はいずれも存在証明を与える。

期待値（expectation）

確率的な量 \(X\) の平均値で、\(\mathrm{E}(X)\) と書く。多数回の独立な繰り返しにおける長期的な平均である。期待値は加法的であり、\(X\) と \(Y\) が独立であってもなくても \(\mathrm{E}(X + Y) = \mathrm{E}(X) + \mathrm{E}(Y)\) が成り立つ（第 9.11 節）。

極値原理（extremal principle）

ある種類の対象のうち最小のもの、最大のもの、最初のもの、最後のものに注目し、それが結論か矛盾のどちらかを導く性質をもつことを示す戦略（第 1.3 節）。

F

体（field）

通常の規則がすべて成り立つもとで、加法、減法、乗法、除法（零による除法を除く）ができる数の体系。有理数、実数、複素数はいずれも体であり、素数を法とする整数も体である。整数は、常に割り算ができるとは限らないので体ではない（第 6.3 節）。

体の拡大（field extension）

小さい体を含む大きい体。たとえば、\(a\)、\(b\) を有理数とする数 \(a + b\sqrt2\) の全体は有理数全体を含む。その次数とは、小さい体上のベクトル空間としての次元である（第 6.3 節）。

不動点（fixed point）

\(\mathrm{f}(x) = x\) を満たす点 \(x\) で、関数がその場所から動かさない点。グラフ上では、不動点は \(y = \mathrm{f}(x)\) が \(y = x\) と交わるところである（第 2.2 節、第 8.8 節）。

座標系（frame of reference）

位置や運動を測る立場。慣性系とはニュートン（Newton）の第1法則が成り立つ座標系のことである。加速している列車のような加速度系では、余分な力がはたらいているように見える（第 11.5 節）。

関数（function）

ある集合（定義域）の各元に、別の集合（終域）のちょうど1つの元を対応させる規則。大学では関数と式は同じものではない。多くの重要な関数は式をもたず、関数を定めない式もある。

関数方程式（functional equation）

\(\mathrm{f}(x + y) = \mathrm{f}(x)\mathrm{f}(y)\) のように、未知のものが関数である方程式（第 3.8 節）。

代数学の基本定理（fundamental theorem of algebra）

複素数係数をもつ次数 \(1\) 以上の多項式はすべて複素数の根をもち、したがって複素数の範囲で一次因数の積に完全に分解される。

G

ガンマ関数（gamma function）

階乗を整数でない数に拡張する関数 \(\Gamma\)。整数 \(n\) に対して \(\Gamma(n + 1) = n!\) であり、\(\Gamma(\frac12) = \sqrt\pi\) である。後者は、ある意味で \((-\frac12)! = \sqrt\pi\) であることを述べている（第 4.4 節）。

ガウス整数（Gaussian integer）

\(a\) と \(b\) を整数とする複素数 \(a + b\mathrm{i}\)。通常の整数とよく似た振る舞いをし、独自の素数と素因数分解の一意性をもつ（第 1.6 節）。ガウス（Gauss）にちなむ。

母関数（generating function）

係数が数列の項であるような冪級数 \(a_0 + a_1x + a_2x^2 + \cdots\)。乗法などの級数に対する演算が、数列に対する有用な演算に対応する（第 9.4 節）。確率母関数はランダムな整数の確率に対してこれを行うものであり（第 9.6 節、第 12.15 節）、積率母関数はその近い親戚である（第 12.24 節）。

群（group）

結合的で、単位元をもち、すべての元に逆元が存在するような二項演算を備えた集合。図形の対称性全体は群をなし、零でない複素数全体も乗法について群をなす。群は対称性の言語である（第 6.6 節、第 6.7 節）。

H

双曲幾何学（hyperbolic geometry）

与えられた直線上にない点を通り、その直線と決して交わらない直線が無限に多く存在し、三角形の内角の和が \(\pi\) より小さくなる幾何学。距離の測り方を適切に定めた円板がそのモデルとなる（第 5.8 節）。

I

単位元、恒等式（identity）

演算 \(\ast\) の単位元とは、すべての \(a\) に対して \(e \ast a = a \ast e = a\) を満たす元 \(e\) のことである。加法では \(0\)、乗法では \(1\)、行列の乗法では単位行列 \(\mathbf{I}\) がそれにあたる。これとは別に、恒等式とは、\(\cos^2\theta + \sin^2\theta \equiv 1\) のように、変数のすべての値に対して成り立つ等式のことである。

〜のとき、かつそのときに限り（if and only if）

「\(P\) であるのは \(Q\) であるとき、かつそのときに限る」は、しばしば「\(P\) iff \(Q\)」や \(P \iff Q\) と書かれ、\(P\) と \(Q\) がともに真であるか、ともに偽であることを意味する。これを証明するには、両方向それぞれについて1つずつ、2つの議論が必要である。

独立（independent）

2つの事象が独立であるとは、一方が起こったことを知っても他方の確率が変わらないこと、すなわち \(\mathrm{P}(A \cap B) = \mathrm{P}(A)\mathrm{P}(B)\) が成り立つことである。3つ以上の事象は、全体としては独立でなくても、どの2つも独立であることがある（第 12.4 節）。

数学的帰納法（induction）

すべての整数 \(n\) について命題を証明する方法。最初の値について証明し（基底段階）、次に、ある値で正しければ必ず次の値でも正しいことを証明する（帰納段階）。強い帰納法では、帰納段階で直前の値だけでなく、それより小さいすべての値についての命題を用いてよい（第 1.2 節）。

無限降下法（infinite descent）

背理法の一形態。問題の整数解があればそれより小さい解が得られ、したがって正の整数の限りなく減少する列が得られることを示す。そのような列は存在しえない（第 1.5 節）。

中間値の定理（intermediate value theorem）

連続関数が値 \(a\) と \(b\) をとるならば、その間のすべての値をとる。したがって、符号が変わる連続関数は必ず根をもつ（第 8.8 節）。

不変量（invariant）

ある過程が進む間、あるいはある変換のもとで変化しない量。不変量を見つけることは、何かが不可能であることを証明したり、すべての段階を追わずに問題を解いたりするための最も強力な方法の1つである（第 7.7 節、第 10.4 節）。

逆元、逆関数（inverse）

単位元 \(e\) をもつ演算に関する元 \(a\) の逆元とは、\(a \ast b = b \ast a = e\) を満たす元 \(b\) のことである。逆関数は関数の作用を元に戻すもので、\(\mathrm{f}^{-1}(\mathrm{f}(x)) = x\) が成り立つ。

無理数（irrational）

\(\sqrt2\)、\(\pi\)、\(\mathrm{e}\) のように、\(p\) と \(q\) を整数（\(q \neq 0\)）とする分数 \(\frac pq\) の形に書けない実数（第 1.4 節）。

既約（irreducible）

多項式が既約であるとは、同じ種類の係数をもつ、より次数の低い2つの多項式の積として書けないことである。\(x^2 - 2\) は有理数の範囲では既約であるが、実数の範囲では \((x - \sqrt2)(x + \sqrt2)\) と因数分解される（第 6.1 節）。

同型（isomorphic）

2つの群などの2つの構造が同型であるとは、それらの間に演算をぴったり対応させる全単射が存在することである。つまり、ラベルが異なるだけで同じ構造である（第 6.7 節、第 6.8 節）。

反復（iteration）

同じ関数を何度も繰り返し適用し、\(x_1 = \mathrm{f}(x_0)\)、\(x_2 = \mathrm{f}(x_1)\)、……とすること。数列 \(x_0\)、\(x_1\)、\(x_2\)、… を \(x_0\) の軌道という（第 8.7 節）。

L

大数の法則（law of large numbers）

確率的な量の多数回の独立な繰り返しの平均は、期待値が存在するならば、その期待値に近づくという定理（第 12.22 節）。

補題（lemma）

主として、より大きな定理へ向かう一段階として証明される結果。

極限（limit）

数列や関数がいくらでも近づき、しかも近いままであり続ける値。この考え方を正確にしたことは19世紀の数学の偉大な業績の1つであり、解析学の出発点である（第 2.1 節）。

リミットサイクル（limit cycle）

系の運動における閉じたループで、近くの運動がそれに向かって（あるいはそれから離れて）渦を巻くもの。心臓の鼓動や時計の規則正しいリズムがその例である（第 8.4 節）。

線形写像（linear map）

ベクトル空間の間の関数 \(T\) で、\(T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})\) と \(T(\lambda\mathbf{u}) = \lambda T(\mathbf{u})\) を満たすもの。線形写像はすべて行列で表すことができ、線形代数はこれを研究する分野である（第 7.2 節）。

ロジスティック写像（logistic map）

規則 \(u_{n+1} = ru_n(1 - u_n)\) で、食料の供給によって制限される個体群の簡単なモデルであり、カオスの標準的な例である（第 8.7 節）。

M

マルコフ連鎖（Markov chain）

状態の間を一歩ずつ移動するランダムな過程で、次の一歩の確率が、その過程がどのようにしてそこに至ったかによらず、現在の状態だけで決まるもの（第 12.16 節）。マルコフ（Markov）にちなむ。

最尤法（maximum likelihood）

未知の量を推定する方法の1つで、観測されたデータが最も起こりやすくなる値を選ぶ（第 13.2 節）。

無記憶性（memoryless）

ランダムな待ち時間が無記憶性をもつとは、すでにどれだけ長く待っていても、残りの待ち時間が最初と同じ分布に従うことである。指数分布は、無記憶性をもつ唯一の連続分布である（第 12.18 節）。

最小多項式（minimal polynomial）

有理数係数で最高次の係数が \(1\) であり、与えられた代数的数を根にもつ多項式のうち、次数が最も低いもの。\(\sqrt2\) の最小多項式は \(x^2 - 2\) である（第 6.3 節）。

合同算術（modular arithmetic）

合同を参照。

慣性モーメント（moment of inertia）

質量の回転版。物体の軸のまわりの回転の速さを変えることがどれほど難しいかを表す量である。質量がどれだけあるかだけでなく、その質量が軸からどれだけ離れているかによっても決まる（第 11.7 節）。

単調（monotonic）

数列や関数が単調であるとは、決して減少しない（増加）か、決して増加しない（減少）ことである。有界な単調数列は必ず収束する（第 2.2 節、第 11.10 節）。

N

必要十分（necessary and sufficient）

\(P\) なしに \(Q\) が起こりえないとき（\(Q \Rightarrow P\)）、\(P\) は \(Q\) の必要条件であるという。\(P\) が \(Q\) を保証するとき（\(P \Rightarrow Q\)）、十分条件であるという。その両方である条件は \(Q\) と同値である。

基準振動（normal modes）

系のすべての部分が同じ振動数でそろって動くような、特別な振動のパターン。系のどの振動も、その基準振動の組み合わせである（第 11.2 節）。

O

位数（order）

群の元 \(g\) の位数とは、\(g^n\) が単位元となるような最小の正の整数 \(n\) のこと、すなわち、もとに戻るまでに何回適用しなければならないかを表す数である（第 7.4 節）。加法に関する整数全体における数 \(1\) のように、そのような \(n\) が存在しないとき、\(g\) は無限位数をもつという。有限群の位数とは、その群の元の個数である。

直交（orthogonal）

垂直であること。大学ではこの語はベクトル以外にも拡張して用いられ、適切な範囲で \(\int \mathrm{f}(x)\mathrm{g}(x)\,\mathrm{d}x = 0\) となるとき、2つの関数 \(\mathrm{f}\) と \(\mathrm{g}\) は直交するということがある（第 8.6 節）。

P

パラメータ（parameter）

ロジスティック写像における \(r\) のように、1つの問題の中では固定されているが、問題ごとに変わりうる量。STEP の問題の多くは、答えがパラメータにどのように依存するかを問う。

部分和（partial sum）

級数の最初の \(n\) 項の和 \(a_1 + a_2 + \cdots + a_n\)。部分和が収束するとき、級数は収束する（第 2.3 節）。

鳩の巣原理（pigeonhole principle）

\(n\) 個より多い対象を \(n\) 個の箱に入れると、少なくとも2つの対象を含む箱がある。単純ではあるが、驚くべき存在の結果をいくつも証明する（第 9.2 節）。

ポアソン過程（Poisson process）

時間または空間の中で、ランダムに、互いに独立に、一定の平均の割合で起こる事象のモデル。放射性崩壊、電話の着信、空の星などがその例である（第 12.19 節、第 12.18 節）。ポアソン（Poisson）にちなむ。

1の原始冪根（primitive root of unity）

1の \(n\) 乗根であって、その累乗によって1の \(n\) 乗根 \(n\) 個がすべて得られるもの。同値な言い方をすれば、より小さいどの \(m\) に対しても1の \(m\) 乗根にならないものである（第 6.1 節）。

確率密度関数（probability density function）

連続的な確率的な量に対して、区間上の積分がその区間に値をとる確率を与える関数 \(\mathrm{f}\)。

証明（proof）

定義、公理、すでに証明された結果から出発して、命題が正しいことを示す完全な論理的議論。大学では、正しい答えを与える計算であっても、各段階が正当化されていなければ証明ではない。

Q

四元数（quaternions）

1843年にハミルトン（William Rowan Hamilton）が発見した数の体系で、\(\mathrm{i}\)、\(\mathrm{j}\)、\(\mathrm{k}\) と書かれる \(-1\) の3つの平方根によって複素数を拡張したものであり、これらは \(\mathrm{i}^2 = \mathrm{j}^2 = \mathrm{k}^2 = \mathrm{i}\mathrm{j}\mathrm{k} = -1\) を満たす。その乗法は可換ではない。3次元の回転を記述するのに用いられる（第 6.7 節、第 7.5 節）。

R

確率変数（random variable）

硬貨を10回投げたときの表の回数のように、ランダムな試行の結果によって値が定まる量。

ランダムウォーク（random walk）

硬貨を投げた結果に応じて1マス左か右に動くコマのように、ランダムな歩みを次々につなげてできる経路（第 9.10 節、第 12.17 節）。

ラピディティ（rapidity）

特殊相対性理論における速さの尺度で、速度とは異なり、同じ向きの運動を組み合わせるときに単純に足し合わされるもの。\(c\) を光速とすると、速度 \(v\) のラピディティは \(\operatorname{artanh}(v/c)\) である（第 7.6 節）。

漸化式（recurrence relation）

フィボナッチ数（Fibonacci numbers）に対する \(F_{n+1} = F_n + F_{n-1}\) のように、数列の各項をそれより前の項で表す等式。

共鳴（resonance）

ぶらんこに乗った子どもをぶらんこの揺れに合わせて押すときのように、系自身の固有振動数で、あるいはそれに近い振動数で周期的に押されたときに生じる大きな応答（第 11.1 節）。

リーマン積分（Riemann integral）

積分の正確な定義で、細い長方形の面積の和の極限として、その極限が存在するときに定めるもの（第 4.1 節）。リーマン（Riemann）にちなむ。

厳密性（rigour）

すべての段階が正当化され、明らかに見えるとか、試した例で正しかったとかいう理由で何かを当然とみなすことのない議論の水準（第3章）。

1の冪根（root of unity）

複素数 \(z\) で、ある正の整数 \(n\) に対して \(z^n = 1\) を満たすもの。1の \(n\) 乗根は \(k = 0\)、\(1\)、…、\(n - 1\) に対する \(\mathrm{e}^{2\pi\mathrm{i}k/n}\) であり、これらは単位円上で正 \(n\) 角形をなす（第 5.2 節）。

S

標本空間（sample space）

ランダムな試行のすべての起こりうる結果の集合。事象はその部分集合である（第 12.1 節）。

集合（set）

対象の集まり（その対象を元という）を1つのものとして考えたもの。元の順序は問題にならず、重複も問題にならない。\(\{1, 2, 3\}\) と \(\{3, 1, 2, 2\}\) は同じ集合である。

単振動（simple harmonic motion）

加速度が定点からの変位に比例し、その定点に向かう運動で、\(\ddot x = -\omega^2x\) と表される。解は \(x = A\cos(\omega t + \varepsilon)\) であり、周期 \(2\pi/\omega\) は振れの大きさによらない（第 11.4 節）。

安定、不安定（stable, unstable）

平衡を参照。

スターリングの公式（Stirling’s formula）

近似式 \(n! \approx \sqrt{2\pi n}\,(n/\mathrm{e})^n\) で、\(n\) が大きくなるにつれて相対誤差が零に近づく（第 12.23 節）。

部分群（subgroup）

群の部分集合で、同じ演算のもとでそれ自身が群になるもの（第 6.6 節）。

対称性による議論（symmetry argument）

問題の中に2つの量を区別するものが何もないことから、それらが等しくなければならないと結論する議論。うまい対称性の議論は、何ページもの計算に取って代わることがある（第 12.5 節）。

T

定理（theorem）

証明された重要な命題。それほど重要でない結果は命題、定理への途中で証明される結果は補題、すぐに導かれる帰結は系と呼ばれることが多い。

トレース（trace）

正方行列の主対角線上の成分の和。行列式と同様に、行列を別の基底に関して書き直しても変わらず、固有値の和に等しい（第 7.4 節、第 7.7 節）。

超越数（transcendental）

代数的数でない数。すなわち、すべてが零ではない整数係数のどんな多項式方程式の根にもならない数である。\(\mathrm{e}\) と \(\pi\) は超越数であるが、それを証明するのは難しい（第 1.4 節）。

三角不等式（triangle inequality）

実数、複素数、ベクトルに対する \(|a + b| \leq |a| + |b|\)。三角形の1辺の長さが、他の2辺の長さの和を超えることはない、ということである。

U

素因数分解の一意性（unique factorisation）

\(1\) より大きいすべての整数が、因数の順序の違いを除いてただ1通りに素数の積として書けるという性質。見かけほど明らかなことではなく、これが成り立たない数の体系もある（第 1.7 節）。

一意性定理（uniqueness theorem）

問題の解が1つしかないことを述べる定理。微分方程式では、方程式の性質がよくないと一意性が成り立たないことがあり、そのとき1つの初期点からいくつもの異なる未来が生じる（第 8.1 節）。

V

ベクトル空間（vector space）

ベクトルと呼ばれる対象の集まりで、平面上の矢印についてのなじみのある規則に従って、互いに足し合わせたり数を掛けたりできるもの。多項式全体、関数全体、多くの微分方程式の解全体はいずれもベクトル空間をなすので、それらに線形代数の方法を適用できる（第 6.3 節）。

W

矛盾なく定義される（well-defined）

対象や規則が矛盾なく定義されているとは、その定義が本当にあいまいさのないただ1つのものを指定していること、たとえば、途中で行った任意の選択に依存しないことである。

整列原理（well-ordering principle）

正の整数からなる空でない集合はすべて最小の元をもつ。これは帰納法の原理と同値であり、「最小の反例をとる」で始まるすべての議論の背後にある（第 1.3 節）。

一般性を失わずに（without loss of generality）

しばしば WLOG と略される言い回しで、他の場合はラベルを付け替えれば同じになるので、議論では1つの場合だけを考える、という意味である。「一般性を失わずに \(a \leq b\) としてよい」とは、\(a > b\) の場合には両者の名前を入れ替えればよい、という意味である。
