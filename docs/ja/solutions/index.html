Beyond STEP

詳細解答

1987年から2025年までのすべてのSTEPの問題の詳しい解答。それぞれ印刷用のPDFである。

解答を開く前に、まずは問題に本気で取り組んでほしい。STEP は苦闘に報いる試験であり、早すぎる段階で読んだ解答は、1時間取り組んだ後に読んだ解答よりもはるかに得るものが少ない。各解答は鍵となるアイデアから始まるので、そこだけを読んで問題に戻ることもできる。

問題そのものはここには掲載していない。各問題のリンクは公式の出典につながっている。2018年までの試験については STEP Support Programme の問題データベースに、2019年以降については OCR のダウンロード（その年の試験問題をまとめた zip ファイル）につながる。本書で詳しい解説を行っている問題については、§ のリンクから該当する節へ移動でき、ヒント、ワークシート、その背後にある大学数学を見ることができる。

各年の解答は、表紙、目次、その年の全試験の解答をまとめた1冊の本としても提供している。年の見出しの下にあるリンクを利用してほしい。

すべての解答は数値的に検算してあるが、これだけ多くの解答があれば多少の誤りは避けられない。おかしいと思うところがあれば、自分の計算を信じて注意深く確かめてほしい。 誤りの指摘は、GitHub の issue として大いに歓迎する。
