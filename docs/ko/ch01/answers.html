제1장 · 정수론과 증명

더 도전하기 해답

여기에 실린 것은 완전한 풀이가 아니라 간단한 답과 힌트이다. 결과와 핵심 단계를 제시하므로 자신의 풀이를 확인하는 데 쓸 수 있다. 답을 보기 전에 각 연습문제를 제대로 풀어 보라.

1.1 소수 공장

  1. \(p_1, \ldots, p_k\)가 소수(prime) 전부라고 가정하자. 그러면 \(p_1\cdots p_k + 1\)은 이 목록에 없는 소인수(prime factor)를 가지므로 모순(contradiction)이다. 페르마 수(Fermat number)를 이용한 증명은 구성적(constructive)이다. 이 증명은 쌍마다 서로소(pairwise coprime)인 수 \(F_0, F_1, \ldots\)을 무한히 많이 제시하고, 이들 각각이 새로운 소수를 하나씩 제공한다.

  2. \(n \geq 2\)이면 \(2^n\)은 \(4\)의 배수이므로 \(2^{2^n} = 16^{2^{n-2}}\)이고, \(16\)의 거듭제곱은 모두 일의 자리가 \(6\)이다. 따라서 \(F_n\)의 일의 자리는 \(7\)이다.

  3. (a) 수학적 귀납법(induction): \(a_{n+1} - 1 = a_n(a_n - 1) = a_n \cdot a_1\cdots a_{n-1}\). (b) \(a_m\)과 \(a_n\) (\(m < n\))의 공약수는 \(a_1\cdots a_{n-1} = a_n - 1\)과 \(a_n\)을 모두 나누므로 \(1\)이다. 따라서 각 항은 다른 어떤 항과도 공유하지 않는 소인수를 가진다. (c) \(\frac{1}{a_n} = \frac{1}{a_n - 1} - \frac{1}{a_{n+1} - 1}\)이고, 이 합은 망원급수(telescoping series)처럼 소거되어 \(1 - \frac{1}{a_{n+1} - 1}\)이 된다.

  4. (a) \(p \mid F_n\)이면 \(2^{2^n} \equiv -1\)이고, 양변을 제곱하면 \(2^{2^{n+1}} \equiv 1\)이다. (b) \(d\)는 \(2^e \equiv 1\)을 만족하는 모든 \(e\)를 나누므로 \(d \mid 2^{n+1}\)이다. 한편 \(2^{2^n} \equiv -1 \not\equiv 1\)이므로(\(p\)가 홀수이므로) \(d \nmid 2^n\)이다. 따라서 \(d = 2^{n+1}\)이다. (c) \(2^{p-1} \equiv 1\)이므로 \(2^{n+1} \mid p - 1\)이다. (d) \(641 = 64 \times 10 + 1\)이다. \(641\)보다 작은 \(64k + 1\) 꼴의 소수는 \(193\), \(257\), \(449\), \(577\)이다. 시험해 볼 후보가 네 개뿐이며, 오일러(Euler)는 이렇게 하여 \(641\)을 찾았다.

  5. \(n\)번째 소수는 \(F_0, \ldots, F_{n-1}\)의 소인수 중 가장 큰 것 이하이므로 \(p_n \leq F_{n-1} = 2^{2^{n-1}} + 1\)이다. \(n = 5\)일 때 이 상계는 \(65\,537\)인데 \(p_5 = 11\)이다. 옳은 부등식이지만 극도로 약하다.

1.2 소수는 얼마나 드문드문 흩어져 있는가?

  1. \(P_{1,10} = 210\), \(P_{1,20} = 9\,699\,690\), \(P_{1,30} = 6\,469\,693\,230\)이다. \(4^{30} \approx 1.15 \times 10^{18}\), \(e^{30} \approx 1.07 \times 10^{13}\)과 비교해 보자. 이 곱은 \(4^n\)보다 훨씬 작고 대략 \(e^n\)처럼 증가한다(실제로 \(\ln P_{1,n} \sim n\)이며, 이는 소수 정리(Prime Number Theorem)의 한 형태이다).

  2. \(\binom{2m}{k+1}\big/\binom{2m}{k} = \frac{2m - k}{k + 1}\)이고, 이 값은 정확히 \(k < m\)일 때 \(1\)보다 크다. 따라서 이항계수(binomial coefficient)는 가운데까지 증가했다가 그 뒤로 감소한다. 합이 \(4^m\)인 \(2m + 1\)개의 항 중 가장 큰 것은 이들의 평균 이상이다.

  3. \((\sqrt n, n]\)에 있는 소수는 각각 \(\sqrt n\)보다 크고 그 곱은 \(4^n\)보다 작으므로 \((\sqrt n)^{\pi(n) - \pi(\sqrt n)} < 4^n\)이다. 양변에 로그를 취하라. \(2\ln4 \approx 2.77\)이고 \(\pi(\sqrt n) \leq \sqrt n\)이므로 원하는 부등식이 따라 나온다. 이 상계는 올바른 꼴 \(n/\ln n\)을 가지며, 다만 상수가 참값 \(1\) 대신 \(2.8\)이다.

  4. 각각 바로 앞 소수의 두 배보다 작은 소수 \(2, 3, 5, 7, 13, 23, 43, 83\)을 사용한다. \(n \leq 50\)인 임의의 \(n\)에 대해, 이 목록에서 \(n\)보다 큰 첫 소수는 바로 앞 소수의 두 배보다 작고, 그 앞 소수는 \(n\) 이하이므로, 이 소수는 \(n\)과 \(2n\) 사이에 있다.

1.3 가장 작은 반례

  1. \(k\sqrt3\)이 정수가 되는 가장 작은 양의 정수 \(k\)가 있다면, \(k' = (\sqrt3 - 1)k\)는 더 작은 양의 정수이고 \(k'\sqrt3 = 3k - k\sqrt3\)도 정수이다. 여기서는 \(\sqrt3 - 1\)이 \(\sqrt2 - 1\)의 역할을 한다.

  2. \(0 < \sqrt N - m < 1\)이면 \(k' = (\sqrt N - m)k\)는 \(k\)보다 작은 양의 정수이고, \(k'\sqrt N = kN - mk\sqrt N\)은 정수이므로 모순이다.

  3. \(N = 4\)이면 \(m = 2 = \sqrt4\)이므로 \(\sqrt N - m = 0\)이고, \(k' = 0\)은 양의 정수가 아니다. “\(0 < \sqrt N - m\)”이라는 단계가 성립하지 않는다.

  4. 그림에서, 한 변이 \(a\)인 정사각형 안에 겹쳐 놓인 한 변이 \(b\)인 두 정사각형은 한 변이 \(2b - a\)인 가운데 정사각형을 두 번 덮고, 한 변이 \(a - b\)인 두 정사각형을 덮지 않은 채로 남긴다. 식으로 쓰면 \((2b - a)^2 - 2(a - b)^2 = 2b^2 - a^2 = 0\)이다.

1.4 \(e\)는 무리수이고, \(e^2\)도 그렇다

  1. \(\frac1e = \frac pq\)라면 \(\frac1e = \sum_{k \geq 0}\frac{(-1)^k}{k!}\)의 양변에 \(q!\)을 곱한다. \(k \leq q\)인 항은 정수이고, 꼬리 \(\sum_{k > q}(-1)^kq!/k!\)는 항의 크기가 감소하는 교대급수(alternating series)이므로 그 절댓값은 \(0\)과 \(\frac{1}{q+1}\) 사이에 엄격하게 놓인다. 따라서 \(q!/e\)는 정수가 아니므로 모순이다.

  2. \(\sin 1 = \frac pq\)라면 \(2n + 1 \geq q\)인 \((2n + 1)!\)을 곱한다. 좌변은 정수이고, 급수의 항 중 \(\frac{1}{(2n+1)!}\)까지도 정수가 된다. 꼬리는 첫 항의 크기가 \(\frac{1}{(2n+2)(2n+3)} < 1\)인 교대급수이므로 정수가 아니다.

  3. 이 방법에는 \(\frac{1}{k!}\)처럼 꼬리가 분모가 커지는 속도보다 빨리 줄어드는, 유리수(rational) 항으로 이루어진 급수가 필요한데, \(\pi\)에 대해서는 그런 급수가 알려져 있지 않다. 니븐(Niven)의 증명은 \(\int_0^\pi\frac{x^n(\pi - x)^n}{n!}\sin x\,\mathrm{d}x\)를 이용한다. \(\pi\)가 유리수라면 큰 \(n\)에 대해 이 값은 \(1\)보다 작은 양의 정수가 되어야 한다.

  4. \(x^2 - (e + \pi)x + e\pi\)의 근은 \(e\)와 \(\pi\)이다. \(e + \pi\)와 \(e\pi\)가 모두 대수적(algebraic)이라면 \(\pi\)는 대수적 계수를 갖는 다항식의 근이 되므로 대수적 수가 되어, 린데만 정리(Lindemann’s theorem)에 모순이다.

1.5 무한 강하법

  1. \(3 \mid a\)이다. \(a = 3a_1\)로 쓰면 \(9a_1^3 + b^3 = 3c^3\)이므로 \(3 \mid b\)이고, 그러면 \(3a_1^3 + 9b_1^3 = c^3\)이므로 \(3 \mid c\)이다. 따라서 \((a_1, b_1, c_1)\)은 더 작은 해이며, 이것이 무한 강하법(descent)이다. \(p^4 + 2q^4 = 5r^4\)의 경우: 네제곱수는 \(5\)를 법으로(modulo) \(0\) 또는 \(1\)이다(일의 자리가 \(0\), \(1\), \(5\), \(6\) 중 하나이다). 따라서 \(p^4 + 2q^4 \equiv 0\)이면 \(5 \mid p\)이고 \(5 \mid q\)이어야 한다. 그러면 \(5^4 \mid 5r^4\)이므로 \(5 \mid r\)이고, 다시 무한 강하법을 적용한다.

  2. 제곱수는 \(4\)를 법으로 \(0\) 또는 \(1\)이므로 \(x^2 + y^2\)은 \(0\), \(1\), \(2\) 중 하나이고 결코 \(3\)이 아니다.

  3. 유리점(rational point) \((\frac ac, \frac bc)\)가 있다면 \(c \neq 0\)인 \(a^2 + b^2 = 3c^2\)이 성립하게 되는데, 이는 소문항 (iii)에서 배제된다.

  4. \(x\), \(y\)를 고정하면 이 방정식은 이차방정식 \(z^2 - 3xyz + (x^2 + y^2) = 0\)이고, 두 근의 합은 \(3xy\)이다. \((1,1,1)\)에서 시작하면 \((1,1,2)\)를 얻는다. \((1, 2)\)의 맞은편에 있는 \(1\)을 바꾸면 \(3 \cdot 1 \cdot 2 - 1 = 5\)이므로 \((1,2,5)\)를 얻고, 이어서 \((1,5,13)\)과 \((2,5,29)\)를 얻는다.

1.6 두 제곱수의 합

  1. 제곱수는 \(4\)를 법으로 \(0\) 또는 \(1\)이므로, 두 제곱수의 합은 \(4\)를 법으로 결코 \(3\)이 아니다.

  2. \(65 = 1^2 + 8^2 = 4^2 + 7^2\)이고 \(85 = 2^2 + 9^2 = 6^2 + 7^2\)이다. \(65 = (2 + \mathrm{i})(2 - \mathrm{i})(3 + 2\mathrm{i})(3 - 2\mathrm{i})\)로 쓰면 \((2 + \mathrm{i})(3 + 2\mathrm{i}) = 4 + 7\mathrm{i}\)이고 \((2 + \mathrm{i})(3 - 2\mathrm{i}) = 8 - \mathrm{i}\)이다. 마찬가지로 \(85\)에 대해서는 \((2 + \mathrm{i})(4 \pm \mathrm{i})\)에서 \(7 + 6\mathrm{i}\)와 \(9 - 2\mathrm{i}\)를 얻는다.

  3. \(1105 = 4^2 + 33^2 = 9^2 + 32^2 = 12^2 + 31^2 = 23^2 + 24^2\)이다. \(5\), \(13\), \(17\)은 각각 가우스 정수(Gaussian integer)와 그 켤레(conjugate)의 곱으로 분해된다. 각 쌍에서 인수를 하나씩 고르면 \(8\)개의 곱이 생기는데, 이들은 서로 켤레인 것끼리 짝지어지므로(같은 두 제곱수의 합을 준다) \(4\)개가 남는다.

  4. 절댓값(modulus)의 제곱을 취하면 \(9 = (a^2 + b^2)(c^2 + d^2)\)이다. \(3\)은 두 제곱수의 합이 아니므로 두 인수 중 하나는 \(1\)이다.

1.7 인수분해가 무너질 때

  1. \(693 = 9 \times 77 = 21 \times 33\)이며, 네 인수 모두 \(S\)-소수이다. 만드는 법: \(4k + 3\) 꼴의 소수 네 개 \(p, q, r, s\)를 잡으면 \((pq)(rs) = (pr)(qs)\)에서 \(S\)-소수로의 두 가지 인수분해(factorisation)를 얻는다.

  2. \(E\)-소수는 \(2 \pmod 4\)인 수들이다(두 짝수의 곱으로 나타낼 수 없기 때문이다). \(60 = 2 \times 30 = 6 \times 10\)이다.

  3. \((ac - 5bd)^2 + 5(ad + bc)^2\)을 전개하면 \(N(zw) = N(z)N(w)\)이다. \(a^2 + 5b^2\)은 결코 \(2\)나 \(3\)이 아니다. \(N(2) = 4\), \(N(3) = 9\), \(N(1 \pm \sqrt{-5}) = 6\)이므로, 단원(unit)이 아닌 수들로 인수분해하려면 노름(norm)이 \(2\) 또는 \(3\)인 인수가 필요하다.

  4. 서로 다른 두 가지 인수분해 \(p_1\cdots p_r = q_1\cdots q_s\)를 갖는 가장 작은 수를 \(n\)이라 하자. 유클리드 보조정리(Euclid’s lemma)에 의해 \(p_1\)은 어떤 \(q_j\)를 나누므로 \(p_1 = q_j\)이다. 이를 약분하면 서로 다른 두 가지 인수분해를 갖는 더 작은 수가 생기므로 모순이다.

1.8 유리수 세기

  1. \(\frac35\): 부모를 거슬러 올라가면 \((3, 5) \leftarrow (3, 2) \leftarrow (1, 2) \leftarrow (1, 1)\)이고, 위치는 \(1 \to 2 \to 5 \to 10\)이므로 \(f(10) = \frac35\)이다. \(\frac53\): \((5, 3) \leftarrow (2, 3) \leftarrow (2, 1) \leftarrow (1, 1)\)이고, 위치는 \(1 \to 3 \to 6 \to 13\)이므로 \(f(13) = \frac53\)이다.

  2. Newman의 규칙 \(x_{n+1} = \frac{1}{2\lfloor x_n\rfloor - x_n + 1}\)을 적용하면 \(1\), \(\frac12\), \(2\), \(\frac13\), \(\frac32\), \(\frac23\), \(3\), \(\frac14\), \(\frac43\), \(\frac35\)를 얻으며, 이는 \(f(1), \ldots, f(10)\)과 일치한다.

  3. \(n\)번째 수의 \(n\)번째 자리 숫자가 \(5\)이면 \(4\)를, 그렇지 않으면 \(5\)를 \(n\)번째 자리 숫자로 고른다. 이렇게 만든 십진 소수(decimal)는 목록의 모든 수와 다르며, \(0\)과 \(9\)를 피했으므로 십진 전개가 하나뿐이어서 실제로 다른 수이다.

  4. 모든 양의 정수는 \(2\)의 거듭제곱과 홀수의 곱 \(2^{m-1}(2n - 1)\)로 유일하게 나타나므로, \((m, n) \mapsto 2^{m-1}(2n - 1)\)은 전단사(bijection)이다.

1.9 삼차곡선의 접선

  1. \(y = t(x + 1)\)을 \(x^2 + y^2 = 1\)에 대입하면 \((1 + t^2)x^2 + 2t^2x + t^2 - 1 = 0\)이고, 근은 \(-1\)과 \(\frac{1 - t^2}{1 + t^2}\)이다. \(t = \frac qp\)로 두면 그 점은 \(\bigl(\frac{p^2 - q^2}{p^2 + q^2}, \frac{2pq}{p^2 + q^2}\bigr)\)이고, 이로부터 세 쌍 \((p^2 - q^2, 2pq, p^2 + q^2)\)을 얻는다.

  2. 직선은 \(x + y = 3\)이고, \(x^3 + (3 - x)^3 = 9\)는 \(9x^2 - 27x + 18 = 0\)으로 정리된다. 삼차항이 소거되어 \(x = 1, 2\)만 남는다. 이 직선은 점근선(asymptote) \(y = -x\)와 평행하며, 세 번째 교점은 무한히 먼 곳에 있다.

  3. 접선(tangent)의 기울기(gradient)는 \(\frac{x^2}{y^2} = \frac{289}{400}\)이고, 접선은 곡선과 \(\bigl(-\frac{188479}{90391}, -\frac{36520}{90391}\bigr)\)에서 다시 만난다. 분모를 없애면 \(188479^3 = 36520^3 + 90391^3 + 180782^3\)이다.

  4. 직선은 \(x^3 + y^3 = 1729\)와 \(\bigl(-\frac{37}{3}, \frac{46}{3}\bigr)\)에서 다시 만나므로 \(46^3 = 37^3 + 27 \times 1729 = 37^3 + 3^3 + 36^3\)이다(\(27 = 3^3\)과 \(27 \times 1728 = 36^3\)을 이용했다).
