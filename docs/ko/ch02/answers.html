더 도전하기 해답

여기 실린 것은 완전한 풀이가 아니라 간단한 답과 힌트이다. 결과와 핵심 단계를 제시하므로 자신의 풀이를 확인하는 데 쓸 수 있다. 답을 보기 전에 각 연습문제를 먼저 제대로 풀어 보라.

2.1 “결국”이란 무슨 뜻인가

  1. \((1 + x)^n = 1 + nx + \binom n2x^2 + \cdots\)의 모든 항은 음이 아니므로 \((1 + x)^n \geq 1 + nx > nx\)이다. \(y = 1 + x\)로 두면, \(n > K/(y - 1)\)이기만 하면 \(y^n > n(y - 1) > K\)이다. 그다음 항을 이용하면 \(y^n > \binom n2(y - 1)^2\)이므로, \(n > 1 + 2K/(y - 1)^2\)이기만 하면 \(y^n/n > \frac12(n - 1)(y - 1)^2 > K\)이다.

  2. \(n \geq m_1\)에서 \(s_n \leq t_n\)이고 \(n \geq m_2\)에서 \(t_n \leq s_n\)이면, \(n \geq \max(m_1, m_2)\)에서 \(s_n = t_n\)이다.

  3. 예를 들어 \(n\)이 짝수일 때 \(s_n = n + 0.6\), \(n\)이 홀수일 때 \(s_n = n\)으로 두고, \(n\)이 홀수일 때 \(t_n = n + 0.6\), \(n\)이 짝수일 때 \(t_n = n\)으로 둔다. 두 수열은 모두 증가하고, 각 수열이 다른 수열보다 큰 경우가 무한히 많다.

  4. \(n \geq 4\)이면 \(2^n \leq n!\)이다(귀납법(induction)으로: \(2^{n+1} = 2 \cdot 2^n \leq (n + 1)\,n!\)). \(n^{10} \leq 2^n\)의 경우, 이 부등식은 \(2\)부터 \(58\)까지의 모든 \(n\)에서 성립하지 않고 모든 \(n \geq 59\)에서 성립하므로, 가장 작은 \(m\)은 \(59\)이다.

2.2 극한으로서의 황금비

  1. 귀납법: \(u_1 = 1 = F_2/F_1\)이고, \(u_n = F_{n+1}/F_n\)이면 \(u_{n+1} = 1 + F_n/F_{n+1} = F_{n+2}/F_{n+1}\)이다.

  2. \(\varphi - 1 = 1/\varphi\)이므로 \(u_{n+1} - \varphi = \frac{1}{u_n} - \frac1\varphi = -\frac{u_n - \varphi}{\varphi u_n}\)이다. \(u_n \geq 1\)이므로 \(|u_{n+1} - \varphi| \leq |u_n - \varphi|/\varphi\)이고, \(|u_1 - \varphi| < 1\)이므로 \(|u_n - \varphi| \leq \varphi^{-(n-1)}\)이다.

  3. \(\psi = \frac{1 - \sqrt5}{2}\)는 \(\psi^2 = \psi + 1\)을 만족하므로 \(1 + 1/\psi = \psi\)이다. 거꾸로 거슬러 올라가면 \(u_{n-1} = \frac{1}{u_n - 1}\)이다. \(0\)에서 시작하면 \(-1, -\frac12, -\frac23, -\frac35, -\frac58, \ldots\)을 얻는다. 즉 어떤 \(k \geq 1\)에 대해 \(u_1 = -F_{k-1}/F_k\)이다. 이 값들은 \(\psi\)에 가까워진다.

  4. 고정점(fixed point)은 \(v = 1 + \frac{1}{1 + v}\), 즉 \(v^2 = 2\)를 만족한다. 오차(error)에는 매번 \(-\frac{1}{(1 + v_n)(1 + \sqrt2)}\)가 곱해지고 그 크기는 많아야 \(\frac{1}{2(1 + \sqrt2)}\)이므로 \(v_n \to \sqrt2\)이다. 또한 \(\sqrt2 = 1 + \cfrac{1}{2 + \cfrac{1}{2 + \cdots}}\)이다.

2.3 발산하는 급수와 수렴하는 그 사촌

  1. \(\ln N + 0.5772 = 10\)에서 \(N \approx 12\,400\)을 얻는다. \(100\)을 넘으려면 약 \(e^{99.4} \approx 1.5 \times 10^{43}\)개의 항이 필요하다.

  2. \(k = 2\)일 때 블록 \(n\)은 많아야 \(2^n \cdot 4^{-n} = 2^{-n}\)이므로, 합은 많아야 \(\sum_{n \geq 0}2^{-n} = 2\)이다. \(1 + \frac14 + \frac19\)를 정확히 더하고 \(r = 4\)부터의 블록들을 \(\frac14 + \frac18 + \cdots = \frac12\)로 위에서 어림하면 약 \(1.86\)을 얻는다. (참값은 \(\frac{\pi^2}{6} \approx 1.645\)이다.)

  3. \(1/(r\ln r)\)의 경우 \(2^n\)부터 \(2^{n+1} - 1\)까지의 블록은 적어도 \(\frac{2^n}{2^{n+1}(n + 1)\ln 2} = \frac{1}{2(n + 1)\ln2}\)이고, 이 값들은 조화급수(harmonic series)처럼 더해지므로 발산(divergence)한다. \(1/(r(\ln r)^2)\)의 경우 블록은 많아야 \(\frac{1}{n^2(\ln2)^2}\)이고, \(\sum\frac{1}{n^2}\)은 수렴(convergence)한다.

  4. 허용되는 숫자: 맨 앞자리에는 \(7\)가지, 나머지 각 자리에는 \(8\)가지 선택이 있으므로, 허용되는 \(d\)자리 수는 많아야 \(7 \cdot 8^{d-1}\)개이고 각각은 적어도 \(10^{d-1}\)이다. 따라서 합은 많아야 \(\sum_{d \geq 1}7(0.8)^{d-1} = \frac{7}{1 - 0.8} = 35\)이다.

2.4 \(\pi^2/6\)

  1. 수 \(\tan^2 = 1/\cot^2\)들은 계수를 거꾸로 배열한 다항식(reversed polynomial) \(\sum_j(-1)^j\binom{2n+1}{2j+1}y^j\)의 근(roots)이고, 이 근들의 합은 \(\binom{2n+1}{2n-1} = n(2n + 1)\)이다. 그러면 \(\mathrm{cosec}^2 = 1 + \cot^2\)에서 \(n + \frac{n(2n - 1)}{3} = \frac{2n(n + 1)}{3}\)을 얻는다.

  2. 짝수 번째 항들의 합은 \(\frac14\sum\frac{1}{m^2} = \frac{\pi^2}{24}\)이므로, 홀수 번째 항들의 합은 \(\frac{\pi^2}{6} - \frac{\pi^2}{24} = \frac{\pi^2}{8}\)이다.

  3. 근들에 대해 \(e_1 = \frac{n(2n - 1)}{3}\)이고 \(e_2 = \binom{2n+1}{5}\big/\binom{2n+1}{1}\)이므로 \(\sum\cot^4 = e_1^2 - 2e_2 = \frac{n(2n - 1)(4n^2 + 10n - 9)}{45}\)이다. \(\cot^4\theta < \theta^{-4} < (1 + \cot^2\theta)^2\)로 조이고(squeezing) \(n \to \infty\)로 보내면 \(\frac{\pi^4}{90}\)을 얻는다.

  4. 하한(lower bound)에서 \(\sum_{m \leq n}\frac{1}{m^2} > \frac{\pi^2n(2n - 1)}{3(2n + 1)^2}\)이므로, 오차는 \(\frac{\pi^2(6n + 1)}{6(2n + 1)^2} < \frac{\pi^2}{4n}\)보다 작다. 이로써 \(n \geq 2468\)이면 정확도 \(0.001\)이 보장된다. 실제로는 \(n \approx 1000\)이면 충분하다.

2.5 비에트의 곱

  1. \(\sin\theta = 2\sin\frac\theta2\cos\frac\theta2\)를 반복해서 쓰면 곱이 연쇄적으로 소거된다(telescopes). \(n \to \infty\)로 보내고(그러면 \(2^n\sin(\alpha/2^n) \to \alpha\)이다) \(\alpha = \frac\pi2\)로 둔 뒤, \(\cos\frac\pi4 = \sqrt{\frac12}\)와 \(\cos\frac\theta2 = \sqrt{\frac12 + \frac12\cos\theta}\)를 이용한다.

  2. \(\frac{\sin(\pi/3)}{\pi/3} = \frac{3\sqrt3}{2\pi} = \cos\frac\pi6\cos\frac\pi{12}\cos\frac\pi{24}\cdots\)이고, 여기서 \(\cos\frac\pi6 = \frac{\sqrt3}{2}\), \(\cos\frac{\pi}{12} = \frac{\sqrt{2 + \sqrt3}}{2} = \frac{\sqrt6 + \sqrt2}{4}\)이다.

  3. 인수 \(8\)개로 \(3.14157\)을 얻고, 이를 반올림하면 \(3.1416\)이다. 인수 \(n\)개를 곱한 뒤의 오차는 약 \(\frac{\pi^3}{6 \cdot 4^{n+1}}\)인데, 생략된 인수들이 \(\cos\frac{\pi}{2^{j+1}} \approx 1 - \frac{\pi^2}{2 \cdot 4^{j+1}}\)이기 때문이다. 즉 인수 하나가 오차를 약 \(4\)로 나누며, \(\log_{10}4 \approx 0.6\)이다.

  4. \(x = \ln a\)로 두면 같은 논증으로\[\frac{a - 1}{\ln a} = \prod_{j \geq 1}\frac{1 + a^{1/2^j}}{2},\]를 얻으므로 \(\frac{1}{\ln3} = \frac12\prod_{j \geq 1}\frac{1 + 3^{1/2^j}}{2}\)이다. 인수 일곱 개로 \(0.906\)을 얻고, 이를 반올림하면 \(0.91\)이다(참값은 \(0.9102\)이다). 여기서는 인수들이 \(1 + \frac{\ln3}{2^{j+1}}\)처럼 \(1\)에 다가가므로 새 인수 하나는 오차를 절반으로 줄일 뿐이다(약 \(0.3\)자리). 반면 비에트(Viète)의 인수들은 \(1 - \frac{\pi^2}{2 \cdot 4^{j+1}}\)처럼 \(1\)에 다가가며 오차를 4분의 1로 줄인다.

2.6 산술–기하 평균

  1. \(x_{n+1} - y_{n+1} = \frac12(\sqrt{x_n} - \sqrt{y_n})^2 = \frac{(x_n - y_n)^2}{2(\sqrt{x_n} + \sqrt{y_n})^2}\)이고, \((\sqrt{x_n} + \sqrt{y_n})^2 \geq 4y_n \geq 4y_0\)이다.

  2. \(M(2, 1) = 1.456791\)이다. 세 단계만 지나도 \(x_3\)과 \(y_3\)은 이미 소수점 아래 일곱째 자리까지 일치한다.

  3. 반복의 모든 단계가 \(\lambda\)배로 바뀌므로 \(M(\lambda x, \lambda y) = \lambda M(x, y)\)이다. 적분에 \(x = \lambda u\)를 대입하면 \(\mathrm{I}(\lambda p, \lambda q) = \lambda^{-1}\mathrm{I}(p, q)\)를 얻는다. \(\mathrm{I} = \frac{\pi}{2M}\)의 양변은 모두 \(\lambda^{-1}\)배가 된다.

  4. \(M(1, \cos 30^\circ) \approx 0.9318\)이므로 주기(period)는 \(1.073\)배, 즉 약 \(7.32\%\) 길어진다.

2.7 여섯 자리인가, 육백 자리인가

  1. \((p^2 + 2q^2)^2 - 2(2pq)^2 = (p^2 - 2q^2)^2 = 1\)이고, \(577^2 - 2 \times 408^2 = 332\,929 - 332\,928 = 1\)이다.

  2. \(y_{n+1} = \frac{2y_n^3 + 2}{3y_n^2}\)이고 \(y_{n+1} - \alpha = \frac{2y^3 - 3\alpha y^2 + \alpha^3}{3y^2} = \frac{(y - \alpha)^2(2y + \alpha)}{3y^2}\)이다. \(y > \alpha\)이면 \(\frac{2y + \alpha}{3y^2} < \frac{3y}{3y^2} = \frac1y < \frac1\alpha\)이다.

  3. \(y - \frac{1/y - a}{-1/y^2} = y + y - ay^2 = y(2 - ay)\)이고, \(1 - ay(2 - ay) = (1 - ay)^2\)이다.

  4. \(y - \frac{y^{1/3}}{\frac13y^{-2/3}} = y - 3y = -2y\)이다. 오차 공식이 성립하려면 근 근처에서 \(\mathrm{f}'\)이 0이 아니고 \(\mathrm{f}''\)이 유계(bounded)여야 한다. 여기서는 \(\mathrm{f}'\)이 \(0\)에서 무한대이다.

2.8 제곱하고 2 빼기

  1. \((2\cos u)^2 - 2 = 2\cos2u\)이므로 귀납법으로 \(x_n = 2\cos(2^{n-1}\theta)\)를 얻는다. \(x_3 = a\)이려면 \(4\theta \equiv \pm\theta\), 즉 \(3\theta\) 또는 \(5\theta \equiv 0 \pmod{2\pi}\)이어야 한다. \(x_2 = a\)인 경우(고정점 \(a = 2\)와 \(a = -1\))를 제외하면 \(\theta = \frac{2\pi}{5}, \frac{4\pi}{5}\)가 남는다. 즉 \(a = \frac{\sqrt5 - 1}{2}\) 또는 \(a = -\frac{\sqrt5 + 1}{2}\)이고, 이 둘은 \(2\)-주기(2-cycle)의 두 점이다.

  2. \(M_5\)의 경우 수열은 \(4\), \(14\), \(194 \equiv 8\), \(62 \equiv 0\)이므로 소수(prime)이다. \(M_{11}\)의 경우 수열은 \(4\), \(14\), \(194\), \(788\), \(701\), \(119\), \(1877\), \(240\), \(282\), \(1736 \neq 0\)이므로 합성수(composite)이고, 실제로 \(2047 = 23 \times 89\)이다.

  3. \(A = t - \frac1t = \frac32\)에서 \(t = 2\), \(a = \frac52\)를 얻는다. 그러면 \(x_2 = \frac{17}{4}\), \(y_1 = \frac{Ax_1}{x_2} = \frac{15}{17}\)이고, \(\frac{\sqrt{x_2^2 - 4}}{x_2} = \frac{15/4}{17/4} = \frac{15}{17}\)이다.

  4. \(x_k = t^{2^{k-1}} + t^{-2^{k-1}}\)이고, \(x_1\cdots x_n\)에 \(t - t^{-1}\)을 곱하면 연쇄적으로 소거되어 \(t^{2^n} - t^{-2^n}\)이 된다. 합은 \((t - t^{-1})\sum_{n \geq 1}\bigl(\frac{1}{t^{2^n} - 1} - \frac{1}{t^{2^{n+1}} - 1}\bigr) = \frac{t - t^{-1}}{t^2 - 1} = \frac1t\)가 된다. \(a = 3\)일 때 \(t = \frac{3 + \sqrt5}{2}\)이고 \(\frac1t \approx 0.3820\)이며, 급수 \(\frac13 + \frac1{21} + \frac{1}{987} + \cdots\)도 이와 일치한다.

2.9 e에 다가가는 분수들

  1. \(T_0 = e - 1\), \(T_1 = 3 - e\), \(T_2 = 7e - 19\), \(T_3 = 193 - 71e\), \(T_4 = 1001e - 2721\)이므로 \(\frac{19}{7}\), \(\frac{193}{71}\), \(\frac{2721}{1001}\)을 얻는다. \(b_n = b_{n-2} - 2(2n - 1)b_{n-1}\)이고 (귀납적으로) \(b_{n-1}\)의 부호가 \(b_{n-2}\)와 반대이므로, \(b_n\)의 부호는 \(b_{n-2}\)와 같다.

  2. \(t(1 - t) \leq \frac14\)이므로 \(T_n < \frac{e}{4^nn!}\)이다. \(-a_n/b_n\)의 오차는 \(T_n/|b_n|\)이고, 이제 \(4^n\)배만큼 개선된다.

  3. \(e = \frac pq\)라면 \(qT_n = qa_n + pb_n\)은 정수(integer)이다. \(T_n > 0\)이므로 이는 양의 정수이고, 따라서 적어도 \(1\)이다. 그러나 \(n\)이 크면 \(qT_n < \frac{qe}{n!} < 1\)이다.

  4. 부분적분(integration by parts)을 두 번 하면(경계항(boundary terms)은 사라진다) \(U_n = \frac14\bigl(U_{n-2} - 2(2n - 1)U_{n-1}\bigr)\)이고, \(U_0 = \frac{e^2 - 1}{2}\), \(U_1 = \frac12\)이다. 따라서 어떤 정수 \(A_n\), \(B_n\)에 대해 \(2^{2n+1}U_n = A_n + B_ne^2\)이고, 한편 \(0 < U_n < \frac{e^2}{4^nn!}\)이다. \(e^2 = \frac pq\)라면 \(q2^{2n+1}U_n\)은 \(\frac{2qe^2}{n!}\)보다 작은 양의 정수인데, \(n\)이 크면 이는 불가능하다. 따라서 이 논증은 실제로 \(e^2\)이 무리수(irrational)임을 증명한다.
