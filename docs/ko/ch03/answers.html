제3장 · 함수, 부등식, 그리고 엄밀함

더 도전하기 해답

다음은 완전한 풀이가 아니라 간단한 답과 힌트이다. 결과와 핵심 단계만 제시하므로 이를 이용해 자신의 풀이를 확인할 수 있다. 답을 보기 전에 각 연습문제를 제대로 풀어 보아라.

3.1 오류 찾기

  1. \(x\)가 \(-1\)에서 \(1\)까지 움직이는 동안 \(0\)을 지나는데, 그곳에서 \(t = 1/x\)는 정의되지 않는다. 즉 치환(substitution)이 이 구간에서 연속(continuous)이 아니다. 올바르게 계산하면 \(\int_{-1}^1\frac{\mathrm{d}x}{(1 + x^2)^2} = \frac12 + \frac\pi4\)이고(\(x = \tan\theta\)를 이용한다), 반면 \(\int_{-1}^1\frac{-t^2}{(1 + t^2)^2}\,\mathrm{d}t = \frac12 - \frac\pi4\)이다.

  2. (a) 참: 양변의 로그(logarithm)가 모두 \(\ln a\ln b\)이다. (b) 거짓: \(\theta = 0\)에서 \(\cos0 = 1 \neq \sin1\)이다. (실제로 \(|\sin\theta \pm \cos\theta| \leq \sqrt2 < \frac\pi2\)이므로 두 값은 결코 같지 않다.) (c) 거짓: 상수가 아닌 다항식(polynomial)은 유계(bounded)가 아니고, 상수는 \(1\)과 \(-1\) 모두에 \(10^{-6}\) 이내로 가까울 수 없다. (d) 참: 산술-기하 평균 부등식(AM–GM)에 의해 \(x^4 + x^{-4} \geq 2\)이고, 등호는 \(x = 1\)일 때 성립한다.

  3. \(n = 1\)에서 \(n = 2\)로 넘어가는 단계가 성립하지 않는다. 말 두 마리에서 “앞의 \(1\)마리”와 “뒤의 \(1\)마리”는 겹치지 않는다.

  4. \(\int_\varepsilon^1x^{-1/2}\,\mathrm{d}x = 2 - 2\sqrt\varepsilon \to 2\)이므로, 대칭성에 의해 이 적분은 (극한으로서) 존재하고 그 값은 \(4\)이다.

3.2 AM–GM, 거꾸로

  1. \(a_1, \ldots, a_{n-1}\)의 평균(mean)이 \(A\), 기하평균(geometric mean)이 \(G\)라 하고, \(n\)번째 수로 \(A\)를 추가한다. 평균은 여전히 \(A\)이므로 \((G^{n-1}A)^{1/n} \leq A\)이고, 이로부터 \(G \leq A\)를 얻는다.

  2. 이 \(n + 1\)개의 수는 평균이 \(1 + \frac{1}{n+1}\), 기하평균이 \((1 + \frac1n)^{n/(n+1)}\)이고, 모두 같지는 않으므로 등호가 없는 엄격한 부등식(strict inequality)이 성립한다. 양변을 \(n + 1\)제곱한다.

  3. 각 면의 넓이는 \(ab\), \(bc\), \(ca\)이고 \(S = 2(ab + bc + ca)\)이다. 산술-기하 평균 부등식에 의해 \(\frac S6 \geq (abc)^{2/3} = V^{2/3}\)이고, 등호는 \(ab = bc = ca\), 즉 정육면체일 때 성립한다.

  4. \(1/a_i\)에 산술-기하 평균 부등식을 적용하면 \(\frac1n\sum\frac1{a_i} \geq \frac1G\)이다. 양변의 역수를 취한다.

3.3 볼록성의 힘

  1. \(\mathrm{f}'' < 0\)이면 기울기가 감소하므로 곡선은 각 현(chord)보다 위에 있다. \(t = \frac13\)으로 두면 \(\mathrm{f}\bigl(\frac{u + v + w}{3}\bigr) \geq \frac13\mathrm{f}(u) + \frac23\mathrm{f}\bigl(\frac{v + w}{2}\bigr) \geq \frac13\bigl(\mathrm{f}(u) + \mathrm{f}(v) + \mathrm{f}(w)\bigr)\)이다.

  2. \((\ln\sin x)'' = -\mathrm{cosec}^2x < 0\)이므로 \(\ln\sin\)은 \((0, \pi)\)에서 오목(concave)하다. 옌센(Jensen) 부등식에 의해 \(\frac13\ln(\sin A\sin B\sin C) \leq \ln\sin\frac\pi3\)이므로, 곱은 최대 \(\bigl(\frac{\sqrt3}{2}\bigr)^3\)이다.

  3. \((0, \frac\pi2)\)에서 \((\tan x)'' = 2\sec^2x\tan x > 0\)이므로, 옌센 부등식에 의해 \(\tan A + \tan B + \tan C \geq 3\tan\frac\pi3 = 3\sqrt3\)이다.

  4. \((x^2)'' = 2 > 0\)이므로 옌센 부등식에 의해 주어진 부등식이 성립한다. 이 부등식은 분산(variance) \(\frac1n\sum a_i^2 - \bar a^2\)이 음이 아니라는 뜻이다.

3.4 부등식을 증명하는 넓이

  1. \([0, \frac\pi2]\)에서 \(\mathrm{f} = \sin\)으로 두면 \(b = \mathrm{f}(a)\)일 때 등호가 성립한다. \(a = \arcsin t\), \(b = t\)로 두면 \(t\arcsin t = (1 - \cos(\arcsin t)) + \int_0^t\arcsin y\,\mathrm{d}y\)이다. 결과의 우변을 미분하면 \(\arcsin t + \frac{t}{\sqrt{1 - t^2}} - \frac{t}{\sqrt{1 - t^2}} = \arcsin t\)이다.

  2. \(p = q = 2\)인 영(Young) 부등식에 의해 \(ab \leq \frac12(a^2 + b^2)\)이다. \(\sum a_i^2 = \sum b_i^2 = 1\)이면 이를 모두 더하여 \(\sum a_ib_i \leq 1\)을 얻는다. 일반적인 경우에는 \(a_i/\sqrt{\sum a_j^2}\)와 \(b_i/\sqrt{\sum b_j^2}\)에 이를 적용한다.

  3. \(\int_0^a(e^x - 1)\,\mathrm{d}x = e^a - 1 - a\)이고 \(\int_0^b\ln(1 + y)\,\mathrm{d}y = (1 + b)\ln(1 + b) - b\)이다. 등호는 \(b = e^a - 1\)일 때 성립한다.

  4. \(t = 1\): \(1.571\) 대 \(1\); \(t = 2\): \(0.524\) 대 \(0.268\); \(t = 10\): \(0.1002\) 대 \(0.0501\). \(t\)가 크면 \(t - \sqrt{t^2 - 1} = \frac{1}{t + \sqrt{t^2 - 1}} \approx \frac{1}{2t}\)이다. 이 한계(bound)는 \(a = 0\)에서 나오는데, 이때 \((*)\)는 단지 \(0 \leq \int_0^b\arcsin y\,\mathrm{d}y\)라는 것만 말해 준다. \(b\)가 작으면 이 넓이는 약 \(\frac{b^2}{2}\)로 \(b\arcsin b \approx b^2\)의 절반이며, 이를 버리면 인수 \(2\)를 잃게 된다.

3.5 \(\pi^e\)인가, \(e^\pi\)인가?

  1. \(n^m = m^n\)은 \(h(n) = h(m)\)을 뜻한다. \(h\)는 \((1, e)\)에서 증가하고 그 이후로는 감소하므로 두 수 중 하나는 \(e\)보다 작다. (\(h(1) = 0\)이라는 값은 다시 나타나지 않으므로) 그 수는 \(2\)여야 하고, 그러면 다른 하나는 \(4\)이다. 가능한 쌍은 \(\{2, 4\}\)뿐이다.

  2. \(e < 3 < \pi\)이고 그 범위에서 \(h\)는 감소하므로 \(h(3) > h(\pi)\), 즉 \(3^\pi > \pi^3\)이다. \(\frac94\)와 \(\sqrt5\)는 모두 \(e\)보다 작고 \(\frac94 > \sqrt5\)이므로 \(h(\frac94) > h(\sqrt5)\)이며, 이로부터 두 번째 부등식을 얻는다. \(1 < x < 2\)일 때는 \(3 < x + 2 < 4\)이므로 \(h(x) < h(2) = h(4) < h(x + 2)\)이고, 따라서 \(x^{x+2} < (x + 2)^x\)이다. 마지막으로 \(9^{\sqrt2} = 3^{2\sqrt2}\)이고 \(\sqrt2^{\,9} = 16\sqrt2 = (2\sqrt2)^3\)이다. \(e^2 < 8\)이므로 \(e < 2\sqrt2 < 3\)이고, 이 범위에서 \(h\)는 감소하므로 \(h(2\sqrt2) > h(3)\)이다. 이로부터 \((2\sqrt2)^3 > 3^{2\sqrt2}\)를 얻으므로 \(\sqrt2^{\,9}\)이 더 크다.

  3. \(e^{\pi/e - 1} > \frac\pi e\)이므로 \(e^{\pi/e} > \pi\)이다. 양변을 \(e\)제곱한다.

3.6 기울기의 한계

  1. 양변은 모두 이차식(quadratic)이고 \(x = -1, 0, 1\)에서 값이 같으므로 서로 같다(라그랑주 보간법, Lagrange interpolation). 미분하면 \(\mathrm{f}(-1)(x - \frac12) - 2\mathrm{f}(0)x + \mathrm{f}(1)(x + \frac12)\)를 얻는다.

  2. \([-1, 1]\)에서 \(|\mathrm{f}'(x)| \leq |x - \frac12| + 2|x| + |x + \frac12| \leq 4\)이고, 등호는 \(x = \pm1\)에서만, 그리고 \(\mathrm{f}(1)\), \(\mathrm{f}(-1)\), \(-\mathrm{f}(0)\)이 모두 \(1\)이거나 모두 \(-1\)일 때만 성립한다. 이차식은 이 세 값으로 결정되므로 \(\pm(2x^2 - 1)\)을 얻는다.

  3. \(T_3(\cos\theta) = \cos3\theta\)로부터 \(4x^3 - 3x\)를 얻고, \(T_3'(1) = 12 - 3 = 9\)이다. \(\cos(n + 1)\theta + \cos(n - 1)\theta = 2\cos\theta\cos n\theta\)로부터 \(T_{n+1} = 2xT_n - T_{n-1}\)이고, \(T_4 = 8x^4 - 8x^2 + 1\)이다.

  4. \(-\sin\theta\,T_n'(\cos\theta) = -n\sin n\theta\)이다. \(\theta \to 0\)일 때 \(\frac{n\sin n\theta}{\sin\theta} \to n^2\)이다.

3.7 \(\pi^2 \leq 10\)

  1. \(\int_0^\pi\mathrm{f}^2 = \frac{\pi^9}{630}\)이고 \(\int_0^\pi(\mathrm{f}')^2 = \frac{2\pi^7}{105}\)이므로, \((*)\)로부터 \(\pi^2 \leq 12\)를 얻는다. 이 사차식(quartic)은 \(\sin x\)에 비해 양 끝 근처에서는 너무 평평하고 가운데에서는 너무 뾰족하므로, 크기에 대한 기울기의 비가 최적값에서 더 멀리 떨어져 있다.

  2. \(\int_0^\pi(\sin x + \sin2x)^2 = \frac\pi2 + \frac\pi2 = \pi\)이고(교차항(cross term)의 적분은 \(0\)이다), \(\int_0^\pi(\cos x + 2\cos2x)^2 = \frac\pi2 + 2\pi = \frac{5\pi}{2}\)이다.

  3. \(\mathrm{g}(x) = \mathrm{f}(\pi x/L)\)로 둔다. 좌변은 \(\frac L\pi\)배가 되고 \(\int(\mathrm{g}')^2\)은 \(\frac{\pi}{L}\)배가 된다. 현의 경우 가장 낮은 진동수(frequency)는 \(\frac1L\)에 비례한다. 즉 길이를 절반으로 줄이면 음높이(진동수)가 두 배가 된다.

  4. 한계 \(\pi^2 \leq \int(\mathrm{f}')^2\big/\!\int\mathrm{f}^2\)(적당한 단위에서)는 \(\lambda \approx 1.133/\pi^2\)에서 최소가 되며, 이때 \(\pi^2 \leq 9.86975\)를 얻는다. 참값은 \(9.86960\)이다.

3.8 덧셈 법칙으로 정해지는 함수

  1. \(x = y = 0\)을 대입하면 \(\mathrm{g}(0) = 0\)이다. \(y\)에 대해 미분하고 \(y = 0\)을 대입하면 \(\mathrm{g}'(x) = k(1 + \mathrm{g}(x)^2)\)이므로 \(\frac{\mathrm{d}}{\mathrm{d}x}\arctan\mathrm{g}(x) = k\)이고 \(\mathrm{g}(x) = \tan kx\)이다.

  2. \(y\)에 대해 미분하면 \(\mathrm{f}'(x + y) = \mathrm{f}'(y)\)이므로 \(\mathrm{f}'\)은 상수 \(k\)이다. 또한 (\(x = y = 0\)을 대입하면) \(\mathrm{f}(0) = 0\)이다.

  3. \(\mathrm{f}(x) = \mathrm{f}(x/2)^2 \geq 0\)이고, \(\mathrm{f}\)는 결코 \(0\)이 되지 않는다(그렇지 않으면 모든 곳에서 \(0\)이 된다). 수학적 귀납법(induction)으로 \(\mathrm{f}(n) = a^n\)을 얻는다. \(\mathrm{f}(1/n) > 0\)이고 \(\mathrm{f}(1/n)^n = \mathrm{f}(1) = a\)이므로 \(a^{1/n}\)을 얻고, 그러면 \(\mathrm{f}(m/n) = \mathrm{f}(1/n)^m\)이다. 연속성이 없으면 무리수(irrational)에서의 값은 아무런 제약을 받지 않는다. “하멜 기저(Hamel basis)”를 이용해 만든, \(a^x\)가 아닌 이상한 해들이 존재한다.

  4. 한 번 발사할 때마다 래피디티(rapidity) \(\phi = \operatorname{artanh}\frac12\)가 더해지므로, \(k\)번 발사한 후의 속력은 \(\tanh k\phi = \frac{3^k - 1}{3^k + 1}\)이다. 즉 \(0.8c\), \(\frac{13}{14}c \approx 0.929c\), \(\frac{40}{41}c \approx 0.976c\)이다.

3.9 새로운 함수 만들기

  1. \(x = -1\)에서 \(x^2 - 2^x = \frac12 > 0\)이고 \(x = 0\)에서는 \(-1\)이므로 음의 근이 존재한다. \(x = -2u/\ln2\)로 두면 (\(x < 0\)이므로 \(x = -2^{x/2}\)로 택하여) \(x^2 = 2^x\)는 \(ue^u = \frac{\ln2}{2}\)가 되므로, \(u = \mathrm{g}\bigl(\frac{\ln2}{2}\bigr)\)이고 \(x \approx -0.7667\)이다.

  2. \(\mathrm{g}'e^{\mathrm{g}}(1 + \mathrm{g}) = 1\)이고 \(e^{\mathrm{g}} = x/\mathrm{g}\)이다. \(x = -\frac1e\)에서 \(\mathrm{g} = -1\)이고 기울기는 무한대이다(그래프가 그 점에서 수직이다).

  3. \(x = we^w\)로 두면 \(\mathrm{d}x = (1 + w)e^w\,\mathrm{d}w\)이고 \(w\)는 \(0\)에서 \(1\)까지 변한다. 따라서 \(\int_0^1w(1 + w)e^w\,\mathrm{d}w = \bigl[(w^2 - w + 1)e^w\bigr]_0^1 = e - 1\)이다.

  4. \(T = \sqrt2^{\,T}\)는 \(\frac{\ln T}{T} = \frac{\ln2}{2}\)를 뜻하므로 \(T = 2\) 또는 \(4\)이다. 항 \(1.414, 1.633, 1.761, \ldots\)은 증가하면서 \(2\)보다 작게 유지되므로(\(t_n < 2\)이면 \(t_{n+1} < \sqrt2^{\,2} = 2\)이다) \(T = 2\)이다. 고정점(fixed point) \(4\)는 밀어내는(repelling) 고정점이다.
