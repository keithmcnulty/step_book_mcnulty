제4장 · 제대로 하는 미적분

더 도전하기 해답

다음은 완전한 풀이가 아니라 간단한 답과 힌트이다. 결과와 핵심 단계만 제시하므로 자신의 풀이를 확인하는 데 쓸 수 있다. 답을 보기 전에 각 연습문제를 제대로 풀어 보아라.

4.1 적분이란 무엇인가?

  1. 이 합은 \([1, 2]\)에서 \(y = \mathrm{f}(x)\) 아래에 놓인 너비 \(\frac1n\)인 직사각형 \(n\)개의 넓이를 모두 더한 것이다. \(\mathrm{f}(x) = \frac1x\)로 두면 \(\frac1n\sum\frac{1}{1 + m/n} = \sum\frac{1}{n + m} \to \ln2\)이다. 두 번째 합은 \(\frac1n\sum\frac{1}{1 + (m/n)^2} \to \int_0^1\frac{\mathrm{d}x}{1 + x^2} = \frac\pi4\)이다.

  2. 띠 \(n\)개로 만든 상합(upper sum)은 \(\frac an\sum_{r=1}^{n}\bigl(\frac{ra}{n}\bigr)^2 = \frac{a^3(n + 1)(2n + 1)}{6n^2}\)이고, 하합(lower sum)은 첫 번째 인수에서 \(n + 1\) 대신 \(n - 1\)을 넣은 것과 같다. 둘 다 \(\frac{a^3}{3}\)에 수렴한다.

  3. 각 항이 연쇄적으로 소거된다(telescope): \(r(r + 1)\cdots(r + k) - (r - 1)r\cdots(r + k - 1) = (k + 1)\,r(r + 1)\cdots(r + k - 1)\).

  4. \(\sum_{r=1}^nr^5 = \frac{n^2(n + 1)^2(2n^2 + 2n - 1)}{12}\).

4.2 적분으로 삼각함수 세우기

  1. 도함수(derivative)는 \(-\mathrm{f}(a - x)\mathrm{f}(x) + \mathrm{f}(a - x)\mathrm{f}(x) = 0\)이므로 \(\mathrm{f}(a - x)\mathrm{f}(x) = \mathrm{f}(a)\)이다. 여기에 \(a = x + y\)를 대입한다. 코사인의 경우, \(y\)를 고정하고 \(p(x) = \mathrm{c}(x + y) - \mathrm{c}(x)\mathrm{c}(y) + \mathrm{s}(x)\mathrm{s}(y)\), \(q(x) = \mathrm{s}(x + y) - \mathrm{s}(x)\mathrm{c}(y) - \mathrm{c}(x)\mathrm{s}(y)\)로 두자. 그러면 \(p' = -q\), \(q' = p\)이므로 \(p^2 + q^2\)은 상수이고, \(x = 0\)에서 그 값은 \(0\)이다.

  2. \(\frac{\mathrm{d}y}{\mathrm{d}u} = (1 + u^2)^{-3/2}\)이고 \(\sqrt{1 - y^2} = (1 + u^2)^{-1/2}\)이므로 \(\frac{\mathrm{d}y}{\sqrt{1 - y^2}} = \frac{\mathrm{d}u}{1 + u^2}\)이다. 그러면 \(\mathrm{S}(\frac{1}{\sqrt2}) = \mathrm{T}(1)\)이고, 소문항 (i)에 \(x = 1\)을 넣으면 \(\mathrm{T}(1) = \frac12\mathrm{T}_\infty\)를 얻는다.

  3. \(a = \frac12\), \(x = \frac13\)으로 두면 \(\frac{x + a}{1 - ax} = 1\)이므로 \(\mathrm{T}(\frac13) = \mathrm{T}(1) - \mathrm{T}(\frac12)\)이다.

  4. \([0, 1]\)에서 \(\frac{1}{1 + u^2} \leq 1\)이고 \([1, x]\)에서 \(\leq \frac{1}{u^2}\)이므로, \(x \geq 1\)이면 \(\mathrm{T}(x) \leq 1 + (1 - \frac1x) < 2\)이고, \(0 < x < 1\)이면 \(\mathrm{T}(x) < \mathrm{T}(1) \leq 1\)이다. (상계 \(1 + \int_1^x u^{-2}\,\mathrm{d}u\)는 \(x < 1\)일 때 성립하지 않는다. \(x = \frac12\)에서 그 값은 \(0\)이다.) \(\mathrm{T}\)는 증가(increasing)하고 유계(bounded)이므로 극한(limit)을 가진다.

4.3 \(22/7\)은 \(\pi\)보다 크다

  1. \(\frac{22}{7} - \pi \approx 0.001264\)로, \(\frac{1}{1260} \approx 0.000794\)와 \(\frac{1}{630} \approx 0.001587\) 사이에 있다.

  2. \(\frac{(4!)^2}{9!} = \frac{576}{362\,880} = \frac{1}{630}\).

  3. \(\frac{x(1 - x)^2}{1 + x^2} = x - 2 + \frac{2}{1 + x^2}\)이고, 이를 적분하면 \(\frac12 - 2 + \frac\pi2\)이다. 마찬가지로 \(\frac{x^2(1 - x)^4}{1 + x^2} = x^4 - 4x^3 + 5x^2 - 4 + \frac{4}{1 + x^2}\)이고, 이를 적분하면 \(\frac15 - 1 + \frac53 - 4 + \pi = \pi - \frac{47}{15}\)이다. 두 적분 모두 양수이다. 이 피적분함수(integrand)들은 \(\frac{x^4(1 - x)^4}{1 + x^2}\)(최댓값이 약 \(0.003\))보다 훨씬 크므로, 오차 \(\frac\pi2 - \frac32 \approx 0.07\)과 \(\pi - \frac{47}{15} \approx 0.008\)도 더 크다.

  4. 다항식 나눗셈(polynomial division)을 하면 나머지(remainder) \(\frac{16}{1 + x^2}\)가 남고, 이를 적분하면 \(4\pi\)이다. 적분값은 \(4\pi - \frac{188684}{15015} \approx 3.6 \times 10^{-6}\)이므로 \(\pi \approx 3.14159174\)이다.

4.4 월리스, 베타 함수, 그리고 1/2의 계승

  1. \(u_{2m} = \frac{1 \cdot 3 \cdots (2m - 1)}{2 \cdot 4 \cdots 2m}\cdot\frac\pi2\)이고 \(u_{2m+1} = \frac{2 \cdot 4 \cdots 2m}{3 \cdot 5 \cdots (2m + 1)}\)이다. 그러면 \(1 < \frac{u_{2m}}{u_{2m+1}} < \frac{u_{2m-1}}{u_{2m+1}} = \frac{2m + 1}{2m}\)이므로 이 비는 \(1\)에 수렴하고, 이를 정리하면 \(\frac\pi2 = \prod_{k \geq 1}\frac{(2k)^2}{(2k - 1)(2k + 1)}\)이 된다.

  2. 부분적분(integration by parts)을 하면 \(I_n = \frac{n}{n + 1}\int_0^1x^{n+1}(1 - x)^{n-1}\,\mathrm{d}x\)를 얻고, \(x^{n+1}(1 - x)^{n-1} = x^n(1 - x)^{n-1} - x^n(1 - x)^n\)으로 쓴 뒤 대칭성(symmetry)을 함께 이용하면 \(I_n = \frac{n}{2(2n + 1)}I_{n-1}\)에 이른다. 귀납법(induction)을 적용하면 \(\frac{(n!)^2}{(2n + 1)!}\)이라는 결과를 얻는다. \(x = \sin^2\theta\)로 치환하면 \(I_{1/2} = \int_0^{\pi/2}2\sin^2\theta\cos^2\theta\,\mathrm{d}\theta = \frac\pi8\)이다. 이 공식대로라면 \(\bigl((\frac12)!\bigr)^2/2! = \frac\pi8\)일 것이므로 \((\frac12)! = \frac{\sqrt\pi}{2}\)이다(이는 \(\Gamma(\frac32)\)이다).

  3. 대칭성은 \(x \mapsto 1 - x\)로부터, 점화식(recurrence)은 \(x^p = x^{p-1} - x^{p-1}(1 - x)\)로부터 얻는다. 또 \(x = \frac{t}{1 + t}\)로 치환하면 \(1 - x = \frac{1}{1 + t}\), \(\mathrm{d}x = \frac{\mathrm{d}t}{(1 + t)^2}\)이다. 주어진 적분은 \(\mathrm{b}(\frac52, \frac72)\)이고, 점화식과 대칭성을 써서 \(\mathrm{b}(\frac12, \frac12) = \pi\)로 줄여 나가면 \(\frac{3\pi}{256}\)을 얻는다.

  4. 소문항 (i)에서 구한 명시적인 값으로부터 \(u_{2m} = \frac{(2m)!}{(2^mm!)^2}\cdot\frac\pi2 = \binom{2m}{m}\frac{\pi}{2^{2m+1}}\)이다. 그러면 \(2mu_{2m}^2 \to \frac\pi2\)로부터 \(\binom{2m}{m}^2 \approx \frac{4^{2m}}{\pi m}\)을 얻는다. \(m = 10\)이면 \(\binom{20}{10} = 184\,756\)인데, \(\frac{4^{10}}{\sqrt{10\pi}} \approx 187\,079\)이다(약 \(1.3\%\) 크다).

4.5 2학년생의 꿈

  1. \(x^{-x} = e^{-x\ln x} = \sum_{n \geq 0}\frac{(-x\ln x)^n}{n!}\)이고, \(\int_0^1\frac{x^n(-\ln x)^n}{n!}\,\mathrm{d}x = \frac{1}{(n + 1)^{n+1}}\)이다(\(x = e^{-u}\)로 치환한다). 따라서 적분값은 \(\sum_{n \geq 1}n^{-n} \approx 1.2913\)이다.

  2. \(\frac{\mathrm{d}}{\mathrm{d}x}x^x = x^x(\ln x + 1)\)이고, 이는 \(x = \frac1e\)에서 \(0\)이다. 그때의 값은 \((e^{-1})^{e^{-1}} = e^{-1/e} \approx 0.692\)이다.

  3. 각 항은 \(\frac{1}{n^n}\)이다. \(7\)개 항까지 더하고 멈추면 오차가 \(\frac{1}{8^8} \approx 6 \times 10^{-8}\)보다 작아 충분하지만, \(6\)개 항까지만 더하면 상계 \(\frac{1}{7^7} \approx 1.2 \times 10^{-6}\)으로는 충분하지 않다. 따라서 \(7\)개 항이 필요하다.

  4. 부분적분으로 계산하면 \(\int_0^1x^2\ln x\,\mathrm{d}x = \bigl[\frac{x^3\ln x}{3}\bigr]_0^1 - \int_0^1\frac{x^2}{3}\,\mathrm{d}x = -\frac19\)이다. 일반적으로 \(\int_0^1x^n\ln x\,\mathrm{d}x = -\frac{1}{(n + 1)^2}\)이고, \(\frac{\ln x}{1 - x} = \sum_{n \geq 0}x^n\ln x\)이다.

4.6 공식으로 나타낼 수 없는 적분

  1. 미분하면 \(\frac{\mathrm{d}}{\mathrm{d}x}\frac{e^x}{x + 1} = \frac{xe^x}{(x + 1)^2}\)이고, \(\frac{\mathrm{d}}{\mathrm{d}x}\frac{(x - 1)e^x}{x + 1} = e^x\Bigl(\frac{x - 1}{x + 1} + \frac{2}{(x + 1)^2}\Bigr) = \frac{(x^2 + 1)e^x}{(x + 1)^2}\)이다.

  2. \(\frac{\mathrm{d}}{\mathrm{d}x}\bigl(\mathrm{P}e^{-x^2}\bigr) = (\mathrm{P}' - 2x\mathrm{P})e^{-x^2}\)이고, \(\mathrm{P}' - 2x\mathrm{P}\)의 차수(degree)는 \(\deg\mathrm{P} + 1 \geq 1\)이므로(\(\mathrm{P} \neq 0\)일 때) \(1\)이 될 수 없다.

  3. \(\mathrm{R} = \mathrm{P}/\mathrm{Q}\)(기약 형태(lowest terms))가 \(0\)에서 위수(order)가 \(k \geq 1\)인 극(pole)을 가진다면, \(\mathrm{R}' + \mathrm{R}\)는 그곳에서 위수가 \(k + 1 \geq 2\)인 극을 가진다. 그런데 \(\frac1x\)는 위수가 \(1\)인 극을 가진다. \(\mathrm{R}\)가 \(0\)에서 극을 가지지 않으면 \(\mathrm{R}' + \mathrm{R}\)도 극을 가지지 않는다. 어느 경우든 \((\mathrm{R}e^x)' \neq \frac{e^x}{x}\)이다.

  4. \(\frac{\mathrm{P}e^x}{x + 1}\)을 미분하면 \(e^x\frac{(x + 1)\mathrm{P}' + x\mathrm{P}}{(x + 1)^2}\)이다. \(x = -1\)에서 \(\mathrm{f}(-1) = -\mathrm{P}(-1)\)이고, \(\mathrm{f}' = (x + 1)\mathrm{P}'' + (x + 1)\mathrm{P}' + \mathrm{P}\)로부터 \(\mathrm{f}'(-1) = \mathrm{P}(-1)\)이다. \(x^3 - 2\)의 경우 \(-3 + 3 = 0\), \(x\)의 경우 \(-1 + 1 = 0\), \(x^2 + 1\)의 경우 \(2 - 2 = 0\)이다. 이 조건은 충분조건이기도 하다. 차수가 \(d\) 미만인 다항식에서 차수가 \(d\) 이하인 다항식으로 가는 사상 \(\mathrm{P} \mapsto (x + 1)\mathrm{P}' + x\mathrm{P}\)는 단사(injective)이므로 그 상(image)의 차원(dimension)은 \(d\)이고, 이 상은 \(\mathrm{f}(-1) + \mathrm{f}'(-1) = 0\)을 만족하는 \(\mathrm{f}\)들이 이루는 \(d\)차원 공간 안에 있다. 따라서 상은 그 공간 전체이다.

4.7 변분법

  1. \(y = \cos\frac{\pi x}{2}\)로 두면 \(J = \frac{\pi^2}{4}\int_0^1\sin^2 - a^2\int_0^1\cos^2 = \frac12\bigl(\frac{\pi^2}{4} - a^2\bigr) < 0\)이다.

  2. \(J(y + \varepsilon\eta) = J(y) + 2\varepsilon\int_0^1(y'\eta' - a^2y\eta) + \varepsilon^2J(\eta)\)이다. \(\varepsilon = 0\)에서 최솟값을 가지려면 일차항이 \(0\)이어야 한다. 부분적분하면 \(\eta(1) = 0\)인 모든 \(\eta\)에 대해 \(-y'(0)\eta(0) - \int_0^1(y'' + a^2y)\eta = 0\)이고, 이로부터 \(y'' + a^2y = 0\), \(y'(0) = 0\)이어야 한다.

  3. \(x = Lu\)로 두면 \(\int_0^L\bigl((y')^2 - a^2y^2\bigr)\,\mathrm{d}x = \frac1L\int_0^1\bigl((Y')^2 - (aL)^2Y^2\bigr)\,\mathrm{d}u\)이므로 조건은 \(aL \leq \frac\pi2\)이다. (\(aL = \frac\pi2\)일 때에도 본문에서처럼 적분은 결코 음수가 되지 않지만, \(y = \cos\frac{\pi x}{2L}\)이면 \(0\)이 된다. \(aL > \frac\pi2\)이면 바로 그 함수에 대해 적분이 음수가 된다.)

  4. 사이클로이드(cycloid)는 \(x = R(\theta - \sin\theta)\), \(y = R(1 - \cos\theta)\)이다. 등시곡선(tautochrone)에 대해서는 11.4 절을 보라. 호의 길이(arc length)로 나타내면 그 운동은 정확히 단진동(simple harmonic motion)이다.

4.8 공 모양 빵 자르기

  1. \(V/A = \frac{\frac43\pi a^3}{4\pi a^2} = \frac a3\)이다. 그러나 높이가 \(t\)인 남은 조각은 \(A = 2\pi at\), \(V = \frac13\pi t^2(3a - t)\)이므로 \(V/A = \frac{t(3a - t)}{6a}\)이고, 이는 \(t = \frac32a\)일 때 최댓값 \(\frac{3a}{8}\)을 가진다. 이 값은 \(\frac a3\)보다 크다.

  2. 띠의 높이는 구 전체의 높이 \(2R\) 가운데 \(2R\sin23.4^\circ\)이므로, 그 비율은 \(\sin23.4^\circ \approx 0.40\)이다.

  3. \(y = \sqrt x\)이면 \(y\sqrt{1 + (y')^2} = \sqrt{x + \frac14}\)로 상수가 아니다. \(y\sqrt{1 + (y')^2} = c\)로부터 \((y')^2 = \frac{c^2}{y^2} - 1\)을 얻고, 그 해는 \(y = c\)(원기둥(cylinder))와 원 \((x - x_0)^2 + y^2 = c^2\)(구)이다.

  4. 구의 부피는 \(\frac43\pi a^3\), 원기둥의 부피는 \(\pi a^2 \cdot 2a = 2\pi a^3\)이므로 그 비는 \(\frac23\)이다.

4.9 홀디치의 정리

  1. \(\frac12\int_0^{2\pi}(p\cos t \cdot q\cos t + q\sin t \cdot p\sin t)\,\mathrm{d}t = \frac12 \cdot 2\pi pq = \pi pq\).

  2. 두 현(chord)의 끝점을 이어 만든 삼각형들은 닮음(similar)이므로(같은 호에 대한 원주각은 같다) \(PA \cdot PB = PC \cdot PD\)이다. 반지름이 \(R\)인 원에서 \(P\)가 중심으로부터 거리 \(r\)에 있을 때, \(P\)를 지나는 지름을 택하면 \((R - r)(R + r)\)이 되므로 \(ab = R^2 - r^2\)이고, 고리의 넓이는 \(\pi R^2 - \pi r^2 = \pi ab\)이다.

  3. \(a = b\)이면 \(f = \pi(a - b) = 0\)이고, 고리의 넓이는 \(\pi a^2 = \frac{\pi L^2}{4}\)로, 막대를 지름으로 하는 원의 넓이와 같다.

  4. \(O\)를 지나는 두 변을 따라서는 \(x\,\mathrm{d}y - y\,\mathrm{d}x = 0\)이다. 세 번째 변을 \(0 \leq s \leq 1\)에 대해 \((x_1, y_1) + s(x_2 - x_1, y_2 - y_1)\)로 매개화(parametrise)하면 그 값은 \((x_1y_2 - x_2y_1)\,\mathrm{d}s\)이다. 따라서 넓이는 \(\frac12|x_1y_2 - x_2y_1|\)이다.
