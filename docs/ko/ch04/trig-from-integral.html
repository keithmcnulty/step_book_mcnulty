4.2

적분으로 삼각함수 세우기

학습지문제 링크, 힌트, 대학 수학과 연습문제 제4장장 전체 PDF
문제

STEP III 2017, 문제 6

계속 읽기 전에 문제를 먼저 읽어 보자. 문제는 STEP Support Programme의 문제 데이터베이스에 있다: step.maths.org/questions/17-s3-q6

도입

\(\pi\)란 무엇인가? 학교에서는 원의 둘레와 지름의 비로 배우고, \(\sin\)과 \(\cos\)는 삼각형으로 정의한다. 기하학에서는 이것으로 충분하지만, 곤란한 질문이 남는다. 곡선을 따라 잰 “길이”란 정확히 무엇인가? \(\sin x\)의 매클로린 급수(Maclaurin series)는 왜 그런 꼴인가? 덧셈정리(addition formula)가 그림으로 그릴 수 있는 각뿐 아니라 모든 각에서 성립한다는 것을 어떻게 아는가?

이 문제는 전혀 다른 길을 보여 준다. 삼각형과 원은 잊어버리자. 4.1 절에서 다룬 적분(integral)의 정의 말고는 아무것도 필요 없는 적분 하나, \(\mathrm{T}(x) = \int_0^x \frac{\mathrm{d}u}{1+u^2}\)에서 출발한다. \(\pi\)를 \(2\mathrm{T}_\infty\)로 정의한다. 그런 다음 치환(substitution)만을 써서 \(\mathrm{T}(\sqrt3) = \frac{\pi}{3}\)과 \(\mathrm{T}(\sqrt2 - 1) = \frac{\pi}{8}\)을 증명한다. 이는 여러분이 \(\arctan\sqrt3 = 60^\circ\), \(\tan 22\tfrac12^\circ = \sqrt2 - 1\)로 알고 있는 사실이다. 아무것도 없는 데서 삼각법을 다시 세우는 것이다.

시작하기 전에

여러분은 사실 \(\mathrm{T}(x) = \arctan x\)이고 \(\mathrm{T}_\infty = \frac\pi2\)임을 알고 있다. 문제는 이 사실을 쓰지 못하게 하며, 바로 그것이 핵심이다. 모든 것은 적분에서 나와야 한다. 하지만 이 숨은 지식은 좋은 길잡이가 된다.

소문항 (i)과 (ii)는 각각 어떤 삼각함수 항등식에 대응하는가? (\(\arctan x + \arctan\frac1x\), 그리고 \(\tan(A + B)\)의 공식을 떠올려 보라.)

소문항 (i)은 \(\arctan x + \arctan\frac1x = \frac\pi2\)이다. 소문항 (ii)는 덧셈정리 \(\tan(A + B) = \frac{\tan A + \tan B}{1 - \tan A\tan B}\)가 모습을 바꾼 것이다. 즉 \(u = \tan A\), \(a = \tan B\)로 두면 \(v = \tan(A + B)\)이다. 이 문제는 이 항등식들을 기하학 없이 적분으로부터 증명한다.

차근차근 풀기

단계 1 반사 \(u \mapsto 1/u\)

\(\mathrm{T}(x)\)에 \(u = 1/w\)를 치환한다. 그러면 \(\mathrm{d}u = -\mathrm{d}w/w^2\)이고 \(\dfrac{1}{1 + u^2} = \dfrac{w^2}{w^2 + 1}\)이므로 \[\mathrm{T}(x) = \int_{\infty}^{1/x} \frac{w^2}{w^2 + 1}\cdot\left(-\frac{1}{w^2}\right)\mathrm{d}w = \int_{1/x}^{\infty} \frac{\mathrm{d}w}{1 + w^2} = \mathrm{T}_\infty - \mathrm{T}(x^{-1}). \qed\] 다시 말해, \(\frac{1}{1+u^2}\) 아래에서 \(0\)부터 \(x\)까지의 넓이는 \(\frac1x\)부터 \(\infty\)까지의 넓이와 같다(그림 4.2.1).

단계 2 덧셈 치환

몫의 미분법(quotient rule)으로 \(v = \dfrac{u + a}{1 - au}\)를 미분하라. 그다음 \(1 + v^2\)을 하나의 분수로 계산하여 비교해 보라.

\[\begin{aligned} \frac{\mathrm{d}v}{\mathrm{d}u} &= \frac{(1 - au) + a(u + a)}{(1 - au)^2} = \frac{1 + a^2}{(1 - au)^2}, \\ 1 + v^2 &= \frac{(1 - au)^2 + (u + a)^2}{(1 - au)^2} = \frac{(1 + a^2)(1 + u^2)}{(1 - au)^2}. \end{aligned}\] 나누면 \(\dfrac{1 + v^2}{1 + u^2} = \dfrac{1 + a^2}{(1 - au)^2} = \dfrac{\mathrm{d}v}{\mathrm{d}u}\)이다.■

이 식은 \(\dfrac{\mathrm{d}u}{1 + u^2} = \dfrac{\mathrm{d}v}{1 + v^2}\)라는 뜻이다. 따라서 치환 \(u \mapsto v\)는 피적분함수(integrand)를 전혀 바꾸지 않는다. 그렇다면 이 치환은 \(\mathrm{T}(x)\)의 적분 구간 끝값을 어떻게 바꾸는가?

\(u\)가 \(0\)부터 \(x\)까지 움직일 때(\(x < \frac1a\)이므로 구간 전체에서 \(1 - au > 0\)이고, \(v\)는 연속이며 증가한다), \(v\)는 \(a\)부터 \(\frac{x + a}{1 - ax}\)까지 움직인다. 따라서 \[\mathrm{T}(x) = \int_0^x \frac{\mathrm{d}u}{1 + u^2} = \int_a^{(x+a)/(1-ax)} \frac{\mathrm{d}v}{1 + v^2} = \mathrm{T}\!\left(\frac{x + a}{1 - ax}\right) - \mathrm{T}(a). \qed\]

단계 3 두 가지 항등식 더

소문항 (i)과 두 번 결합하면 \[\mathrm{T}(x^{-1}) = \mathrm{T}_\infty - \mathrm{T}(x) = \mathrm{T}_\infty - \mathrm{T}\!\left(\frac{x + a}{1 - ax}\right) + \mathrm{T}(a) = 2\mathrm{T}_\infty - \mathrm{T}\!\left(\frac{x + a}{1 - ax}\right) - \mathrm{T}(a^{-1}). \qed\] 이제 문자를 바꾼다. \(y = 1/x\), \(b = 1/a\)로 두자. 조건 \(x < 1/a\)는 \(1/y < b\), 즉 \(y > 1/b\)가 되고 \[\frac{x + a}{1 - ax} = \frac{1/y + 1/b}{1 - 1/(by)} = \frac{b + y}{by - 1}.\] 따라서 \(\mathrm{T}(y) = 2\mathrm{T}_\infty - \mathrm{T}\!\left(\dfrac{y + b}{by - 1}\right) - \mathrm{T}(b)\)이다.■

단계 4 특수한 값

마지막 항등식에서 \(\frac{y + b}{by - 1}\)이 \(y\) 자신과 같아지도록 \(y\)와 \(b\)를 골라 보라. 무엇을 얻는가?

\(y = b = \sqrt3\)으로 두자. 그러면 \(y > \frac1b\)이고 \(\dfrac{\sqrt3 + \sqrt3}{3 - 1} = \sqrt3\)이다. 항등식은 \(\mathrm{T}(\sqrt3) = 2\mathrm{T}_\infty - 2\mathrm{T}(\sqrt3)\)이 되므로 \[\mathrm{T}(\sqrt3) = \tfrac23\mathrm{T}_\infty. \qed\]

\(\sqrt2 - 1\)에 대해서는 덧셈 항등식에 \(x = a = \sqrt2 - 1\)을 넣어 보라. \(\frac{2x}{1 - x^2}\)은 무엇인가? 그리고 \(\mathrm{T}(1)\)은 무엇인가?

\(x = a = \sqrt2 - 1\)로 두면(\(x^2 = 3 - 2\sqrt2 < 1\)이므로 \(x < \frac1a\)이다) 덧셈 항등식에서 \(2\mathrm{T}(x) = \mathrm{T}\!\left(\frac{2x}{1 - x^2}\right)\)이다. 그런데 \(1 - x^2 = 2\sqrt2 - 2 = 2(\sqrt2 - 1) = 2x\)이므로 \(\frac{2x}{1 - x^2} = 1\)이고, \(2\mathrm{T}(\sqrt2 - 1) = \mathrm{T}(1)\)이다. 마지막으로 소문항 (i)에 \(x = 1\)을 넣으면 \(\mathrm{T}(1) = \mathrm{T}_\infty - \mathrm{T}(1)\)이므로 \(\mathrm{T}(1) = \frac12\mathrm{T}_\infty\)이다. 그러므로 \[\mathrm{T}(\sqrt2 - 1) = \tfrac14\mathrm{T}_\infty. \qed\]

돌아보기

  • 피적분함수를 보존하는 치환. 두 핵심 단계 모두 \(\frac{\mathrm{d}u}{1+u^2}\)을 바꾸지 않는 치환을 썼고, 움직인 것은 적분 구간의 끝값뿐이었다. 적분의 이러한 “대칭”은 강력한 도구이다.

  • 고정점(fixed point). \(\mathrm{T}(\sqrt3)\)의 값은 어떤 식이 자기 자신과 같아지도록 수를 골라서 얻었다. 그렇게 하여 항등식이 방정식으로 바뀌었다.

  • 정의는 해석학에서 올 수 있다. 삼각형은 한 번도 쓰지 않았지만 \(\frac\pi3\)과 \(\frac\pi8\)을 되찾았다(\(\pi\)를 \(2\mathrm{T}_\infty\)로 정의했을 때).

숨은 수학

초등함수 세우기

엄밀한 해석학 강의에서는 \(\exp\), \(\sin\), \(\cos\), \(\ln\) 같은 함수를 그냥 주어진 것으로 가정할 수 없다. 이 함수들을 구성하고 그 성질을 증명해야 한다. 표준적인 방법은 세 가지이다. 거듭제곱급수(power series)로 정의할 수 있다(\(\sin x = x - \frac{x^3}{3!} + \cdots\)). 연습문제에 있는 1986년 예시 문제(specimen question)처럼 미분방정식(differential equation)의 해로 정의할 수도 있다(\(\mathrm{f}' = \mathrm{f}\), \(\mathrm{f}(0) = 1\)이 \(\exp\)를 정의한다). 또는 여기서처럼 역함수(inverse function)를 적분으로 정의할 수 있다. 즉 \(\ln x = \int_1^x \frac{\mathrm{d}u}{u}\), \(\arctan x = \int_0^x \frac{\mathrm{d}u}{1+u^2}\)로 정의하고, \(\pi = 2\int_0^\infty \frac{\mathrm{d}u}{1+u^2}\)로 정의한다. 각 방법에는 저마다 장점이 있으며, 세 방법이 모두 같은 함수를 준다는 것을 증명하는 일은 보람 있는 연습이다. 3.8 절의 함수방정식(functional equation)을 이용한 방법과도 비교해 보라.

원 너머로: 타원적분

적분을 이용한 방법은 삼각형을 이용한 방법으로는 불가능한 방식으로 일반화된다. 1718년 Giulio Fagnano는 8자 모양의 곡선인 렘니스케이트(lemniscate)의 호의 길이(arc length)를 연구했는데, 이는 \(\int_0^x \frac{\mathrm{d}u}{\sqrt{1 - u^4}}\)으로 이어진다. 그는 우리의 치환이 \(\mathrm{T}\)를 두 배로 만든 것처럼 호를 두 배로 만드는 치환을 찾아냈다. 1751년 Fagnano의 연구를 읽은 오일러(Euler)는 완전한 덧셈정리를 찾았고, 이는 결국 아벨(Abel)과 야코비(Jacobi)를 거쳐 타원함수(elliptic function)의 이론으로 이어졌다. 타원함수란 이와 같은 적분의 역함수로, 원에 대한 \(\sin\)과 \(\cos\)의 역할을 렘니스케이트에 대해 하는 함수이다. 같은 적분을 산술기하평균(AGM)에 관한 가우스(Gauss)의 연구에서도 만난 바 있다(2.6 절). 오늘날 타원함수는 정수론(number theory)의 중심에 있으며, 1.9 절의 타원곡선(elliptic curve)은 그 기하학적 그림자이다.

\(\pi\) 계산하기

덧셈 항등식은 \(\pi\)를 계산하는 가장 유명한 공식들의 바탕이기도 하다. 예를 들어 이를 거듭 적용하면 \(\mathrm{T}(1) = 4\mathrm{T}(\frac15) - \mathrm{T}(\frac{1}{239})\)임을 보일 수 있는데, 이것이 1706년의 마친(Machin)의 공식이다. 이 공식을 급수 \(\mathrm{T}(x) = x - \frac{x^3}{3} + \frac{x^5}{5} - \cdots\)와 결합하여 \(\pi\)의 \(100\)자리를 얻었고, 이 방법은 두 세기 반 동안 으뜸가는 방법으로 쓰였다. 이것이 5.1 절의 주제이다.

사고 기술

적분의 대칭

피적분함수를 바꾸지 않는 치환을 찾아라. 그런 치환은 적분이 정의하는 함수의 항등식으로 바뀐다.

여기서는 \(u \mapsto 1/u\)와 \(u \mapsto \frac{u+a}{1-au}\)가 \(\frac{\mathrm{d}u}{1+u^2}\)을 보존하며, 각각 반사 공식과 덧셈정리를 준다. 같은 아이디어를 다른 적분에 적용한 것이 특수함수 이론의 바탕을 이룬다.

더 도전하기

  1. 지수함수와 코사인. STEP II Specimen paper, 문제 6를 풀어 보라. 이 문제는 지수함수와 코사인의 덧셈정리를 오직 그 미분방정식만으로 이끌어 낸다. (힌트: 코사인의 경우, 0이 되어야 할 두 식을 찾고 그 제곱의 합이 상수임을 보여라.)

  2. 역사인 함수. STEP III 2007, 문제 7을 풀어 보라. 이 문제는 역사인 함수를 이 절의 적분과 같은 방식으로 다루고, 치환으로 둘을 연결한다.

  3. 초기의 마친형 공식. 덧셈 항등식을 이용하여 \(\mathrm{T}(\frac12) + \mathrm{T}(\frac13) = \mathrm{T}(1) = \frac12\mathrm{T}_\infty\)임을 보여라.

  4. \(\mathrm{T}_\infty\)는 유한하다. 모든 \(x \geq 1\)에 대해 \(\mathrm{T}(x) \leq 1 + \int_1^x \frac{\mathrm{d}u}{u^2} < 2\)임을 보이고, \(0 < x < 1\)에서도 \(\mathrm{T}(x) < 2\)인 이유를 설명한 다음, 단조수렴정리(monotone convergence theorem, 2.2 절)로부터 \(\mathrm{T}_\infty\)가 존재함을 이끌어 내라.

  • Tom Körner, Calculus for the Ambitious (Cambridge University Press). 여러 방법을 논의하면서 초등함수를 엄밀하게 세운다.

  • Walter Rudin, Principles of Mathematical Analysis (McGraw-Hill). 유명한 “베이비 루딘(baby Rudin)”이다. 8장의 머리말에서 몇 쪽 안 되는 우아한 서술로 거듭제곱급수에서 \(\exp\), \(\sin\), \(\cos\)를 구성한다. 고급.

  • Victor Prasolov & Yuri Solovyev, Elliptic Functions and Elliptic Integrals (American Mathematical Society). 렘니스케이트가 어디로 이어지는지 알고 싶은 독자를 위한 책이다. 고급.
