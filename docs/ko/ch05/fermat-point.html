페르마 점

학습지문제 링크, 힌트, 대학 수학과 연습문제 제5장장 전체 PDF
문제

STEP III 2000, 문제 3

계속 읽기 전에 문제를 먼저 읽어 보자. 문제는 STEP Support Programme의 문제 데이터베이스에 있다: step.maths.org/questions/00-s3-q3

도입

세 마을이 서로를 모두 잇는 도로망을 가능한 한 짧게 건설하려 한다. 교차점은 어디에 두어야 할까? 1640년경 페르마(Pierre de Fermat)는 삼각형 내부에서 \(PA + PB + PC\)를 최소로 하는 점 \(P\)를 찾는 문제를 제기했고, 토리첼리(Evangelista Torricelli)가 이를 풀었다. 그 점은 세 변이 모두 \(120^\circ\)의 각으로 보이는 점이다.

이 문제는 복소수(complex numbers)를 이용하여 그 점을 작도하는 아름다운 방법을 증명한다. 삼각형의 각 변 위에 바깥쪽으로 정삼각형(equilateral triangle)을 세우고, 새로 생긴 각 꼭짓점을 원래 삼각형의 마주 보는 꼭짓점과 잇는다. 세 직선은 한 점, 곧 페르마 점(Fermat point)에서 만나며, 세 선분의 길이는 모두 같고 그 길이가 바로 도로 총길이의 최솟값이다. 복소수와 \(e^{\mathrm{i}\pi/3}\)에 관한 항등식 하나만 있으면 전체 논증은 몇 줄의 대수 계산으로 끝난다.

시작하기 전에

\(A\), \(B\), \(C\)는 어디에 있는가? 각각의 편각(argument)은 무엇인가? \(OA\), \(OB\), \(OC\)가 서로 이루는 각은 얼마인가?

\(A = p\)는 양의 실수축(real axis) 위에 있다(편각 \(0^\circ\)). \(B = q\alpha^2 = qe^{2\pi\mathrm{i}/3}\)의 편각은 \(120^\circ\)이다. \(C = -r\alpha = re^{\mathrm{i}\pi}e^{\mathrm{i}\pi/3}\)의 편각은 \(240^\circ\)이다. 따라서 원점은 삼각형 내부의 점으로, 이 점에서 세 꼭짓점은 서로 \(120^\circ\)의 각을 이루며 보이고, 각 꼭짓점까지의 거리는 \(p\), \(q\), \(r\)이다. 원점은 구성상 바로 페르마 점이다. 이 문제는 정삼각형 작도가 이 점을 찾아낸다는 것을 보이는 것이다.

차근차근 풀기

단계 1 핵심 항등식

\(\alpha^3 = e^{\mathrm{i}\pi} = -1\)이므로 \(\alpha\)는 \(z^3 + 1 = (z + 1)(z^2 - z + 1)\)의 근이다. \(\alpha \neq -1\)이므로 \(\alpha^2 - \alpha + 1 = 0\), 즉 \(1 + \alpha^2 = \alpha\)이다.■

여기서 유용한 두 결과가 나온다. \(1 - \alpha = -\alpha^2\)이고, \(\alpha - \alpha^2 = 1\)이다. 또한 \(1 - \alpha = \frac12 - \frac{\sqrt3}{2}\mathrm{i} = e^{-\mathrm{i}\pi/3}\)은 \(\alpha\)의 켤레복소수(complex conjugate)이다.

단계 2 회전으로 본 정삼각형

삼각형 \(CAN\)은 꼭짓점을 시계 방향으로 이름 붙인 정삼각형이다. \(C\)에 서 있다면 \(A\)에서 \(N\)으로 어떻게 갈 수 있는가? \(N - C\)를 \(A - C\)로 나타내어라.

\(C\), \(A\), \(N\) 순으로 시계 방향으로 돌면, 점 \(N\)은 \(A\)를 \(C\)를 중심으로 시계 방향으로 \(60^\circ\) 회전(rotation)시켜 얻는다. \(e^{-\mathrm{i}\pi/3} = 1 - \alpha\)를 곱하면 시계 방향으로 \(60^\circ\) 회전하므로 \[\begin{aligned} N = C + (1 - \alpha)(A - C) &= -r\alpha + (1 - \alpha)(p + r\alpha) \\ &= (1 - \alpha)p + r(\alpha - \alpha^2 - \alpha) = (1 - \alpha)p - \alpha^2r. \qed \end{aligned}\] (반시계 방향이 아니라 시계 방향으로 회전시키므로 \(N\)은 \(CA\)에 대해 원점의 반대편, 즉 삼각형 바깥에 놓인다.)

같은 방법으로 \(L\)과 \(M\)을 구하고, 1단계의 항등식을 이용하여 간단히 하여라.

마찬가지로 \(L = A + (1 - \alpha)(B - A)\)이고 \(M = B + (1 - \alpha)(C - B)\)이다. \[\begin{aligned} L &= p + (1 - \alpha)(q\alpha^2 - p) = \alpha p + (\alpha^2 - \alpha^3)q = \alpha p + (\alpha^2 + 1)q = \alpha(p + q), \\ M &= q\alpha^2 + (1 - \alpha)(-r\alpha - q\alpha^2) = q\alpha^3 + r(\alpha^2 - \alpha) = -q - r. \end{aligned}\] 그리고 \(1 - \alpha = -\alpha^2\)을 이용하면 \(N = -\alpha^2p - \alpha^2r = -\alpha^2(p + r)\)이다.

단계 3 원점을 지나는 세 직선

\(L = \alpha(p + q)\)와 \(C = -r\alpha\)를 비교해 보라. 무엇을 알 수 있는가? \(M\)과 \(A\), \(N\)과 \(B\)에 대해서도 같은 방법으로 해 보라.

\(L\)은 \(\alpha\)의 양의 실수배이고 \(C\)는 \(\alpha\)의 음의 실수배이다. 따라서 \(L\)과 \(C\)는 \(O\)를 지나는 같은 직선 위에서 \(O\)의 양쪽에 놓이고, 선분 \(LC\)는 원점을 지나며 그 길이는 \(|L - C| = |\alpha|(p + q + r) = p + q + r\)이다.

마찬가지로 \(M = -(q + r)\)과 \(A = p\)는 실수축 위에서 \(O\)의 양쪽에 놓이므로, \(MA\)는 \(O\)를 지나고 길이는 \(p + q + r\)이다. 또 \(N = -\alpha^2(p + r)\)과 \(B = q\alpha^2\)은 \(O\)를 지나고 방향이 \(\alpha^2\)인 직선 위에서 서로 반대편에 놓이므로, \(NB\)는 \(O\)를 지나고 길이는 \(p + q + r\)이다.■

돌아보기

  • 회전은 곱셈이다. 정삼각형을 세운다는 것은 한 꼭짓점을 다른 꼭짓점을 중심으로 \(60^\circ\) 회전시킨다는 뜻이고, 이는 \(e^{\pm\mathrm{i}\pi/3}\)을 곱하는 것이다.

  • 영리한 좌표 선택. 페르마 점을 원점에 두고 꼭짓점들을 \(1\), \(\alpha^2\), \(-\alpha\) 방향에 놓았더니 모든 식이 간단히 정리되었다.

  • 하나의 항등식을 거듭 사용하기. 모든 식의 간단히 하기는 \(\alpha^2 - \alpha + 1 = 0\)과 \(\alpha^3 = -1\)에서 나왔다.

숨은 수학

페르마 점이 거리의 합을 최소로 하는 이유

왜 \(PA + PB + PC\)는 각 변이 \(120^\circ\)의 각으로 보이는 점에서 가장 작아야 할까? 멋진 논증이 하나 있다. 전체 그림을 \(B\)를 중심으로 \(60^\circ\) 회전시켜 \(A\)를 \(L'\)(\(AB\) 위에 세운 정삼각형의 꼭짓점)으로, \(P\)를 \(P'\)으로 보낸다. 삼각형 \(BPP'\)은 정삼각형이므로 \(PB = PP'\)이고, \(PA = P'L'\)이다. 그러면 \(PA + PB + PC = L'P' + P'P + PC\)이고, 이는 \(L'\)에서 \(C\)로 가는 경로의 길이이다. 이 값은 \(|L'C|\) 이상이며, 등호는 경로가 직선일 때, 즉 \(P\)에서의 각이 \(120^\circ\)일 때 정확히 성립한다. 따라서 총길이의 최솟값은 문제에서 구한 대로 \(|LC| = p + q + r\)이다. (이 논증은 삼각형의 모든 각이 \(120^\circ\)보다 작을 때 성립한다. 그렇지 않으면 최솟값은 둔각인 꼭짓점에서 나온다.)

비누막과 슈타이너 트리

세 개의 말뚝(\(A\), \(B\), \(C\)를 나타낸다)이 달린 틀을 비눗물에 담갔다 꺼내면, 비누막은 표면장력(surface tension) 에너지를 최소로 하면서 페르마 점에서 \(120^\circ\)로 만나는 세 개의 벽을 이룬다. 점이 더 많을 때 이들을 잇는 가장 짧은 연결망은 슈타이너 트리(Steiner tree)로, 세 변이 \(120^\circ\)로 만나는 교차점이 추가로 생긴다. 슈타이너 트리를 찾는 일은 일반적으로 계산상 어렵지만(NP-난해(NP-hard) 문제이다), 도로망, 송유관, 컴퓨터 칩의 배선을 설계할 때 실제로 중요하다.

나폴레옹 정리(Napoleon’s theorem)

같은 그림 속에는 또 하나의 보석이 숨어 있다. 임의의 삼각형의 세 변 위에 세운 세 정삼각형의 중심은 정삼각형을 이룬다. 이 정리는 전통적으로 나폴레옹 보나파르트(Napoleon Bonaparte, 열성적인 아마추어 수학자였다)의 업적으로 알려져 있지만, 그가 이것을 발견했다는 증거는 없다. 이 정리 역시 \(1 + \alpha^2 = \alpha\)를 이용하면 복소수로 짧게 증명할 수 있다.

사고 기술

문제에 맞는 좌표를 고르라

가장 중요한 점을 원점에 두고, 문제의 대칭성에 맞추어 배치하라. 좋은 선택을 하면 대수 계산이 거의 자명해질 수 있다.

여기서 원점은 페르마 점이었고, 세 꼭짓점은 (부호를 제외하면) \(-1\)의 세제곱근(cube roots) 방향에 놓였다. 다른 좌표를 썼다면 같은 계산이 훨씬 복잡해졌을 것이다.

더 도전하기

  1. 이름 붙인 순서 확인하기. 정삼각형의 꼭짓점을 반시계 방향으로 이름 붙이면(즉 안쪽으로 세우면) 세 직선이 일반적으로 \(O\)를 지나지 않음을 보여라.

  2. 나폴레옹 정리. 정삼각형 \(ABL\)의 중심이 \(\frac13(A + B + L)\)임을 보여라. 위에서 구한 식들을 이용하여 세 중심이 정삼각형을 이룸을 보여라.

  3. 최솟값. \(p = 2\), \(q = 1.4\), \(r = 1.1\)일 때, \(P\)가 각 꼭짓점에 있을 때와 무게중심(centroid) \(\frac13(A + B + C)\)에 있을 때 \(PA + PB + PC\)를 계산하고, 모두 \(4.5\)보다 큼을 확인하여라.

  4. 정삼각형 판정법. \(z_1\), \(z_2\), \(z_3\)이 (어느 방향으로든) 정삼각형을 이루기 위한 필요충분조건(if and only if)이 \(z_1^2 + z_2^2 + z_3^2 = z_1z_2 + z_2z_3 + z_3z_1\)임을 보여라.
