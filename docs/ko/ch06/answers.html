제6장 · 대수와 구조

더 도전하기 해답

여기 실린 것은 완전한 풀이가 아니라 간단한 답과 힌트이다. 결과와 핵심 단계를 제시하므로 자신의 풀이를 확인하는 데 쓸 수 있다. 답을 보기 전에 각 문제를 제대로 풀어 보라.

6.1 근이 모두 단위근인 다항식

  1. \((x - 1)(x + 1) = x^2 - 1\)이고 \((x^2 + x + 1)(x^2 - x + 1) = x^4 + x^2 + 1\)이며, 이 둘의 곱은 \(x^6 - 1\)이다. 마찬가지로 \(x^{12} - 1 = (x^6 - 1)(x^6 + 1)\)이고 \(x^6 + 1 = (x^2 + 1)(x^4 - x^2 + 1) = \mathrm{C}_4\mathrm{C}_{12}\)이다.

  2. \(2p\)의 약수(divisor)는 \(1\), \(2\), \(p\), \(2p\)이므로 \(\mathrm{C}_{2p} = \frac{x^{2p} - 1}{(x - 1)(x + 1)\mathrm{C}_p(x)} = \frac{x^p + 1}{x + 1}\)이다. 또한 \(p\)가 홀수이므로 \(\mathrm{C}_p(-x) = \frac{(-x)^p - 1}{-x - 1} = \frac{x^p + 1}{x + 1}\)이다. \(p = 3\)이면 \(\mathrm{C}_6 = x^2 - x + 1 = \mathrm{C}_3(-x)\)이다.

  3. \(p^k\) 이하의 수 중에서 \(p^k\)와 공통인 인수를 갖는 것은 \(p\)의 배수 \(p^{k-1}\)개이다. 원시 \(p^k\)제곱근(primitive \(p^k\)th root)은 \(x^{p^k} - 1\)의 근 중에서 \(x^{p^{k-1}} - 1\)의 근이 아닌 것이므로 \(\mathrm{C}_{p^k} = \frac{x^{p^k} - 1}{x^{p^{k-1}} - 1} = \mathrm{C}_p\bigl(x^{p^{k-1}}\bigr)\)이다. 따라서 \(\mathrm{C}_9 = x^6 + x^3 + 1\)이다.

  4. \(\mathrm{C}_{15} = \frac{(x^{15} - 1)(x - 1)}{(x^3 - 1)(x^5 - 1)}\)이다. \((x - 1)(x^2 + x + 1)(x^4 + x^3 + x^2 + x + 1)\)에 주어진 8차식(octic)을 곱하면 \(x^{15} - 1\)이 됨을 전개하여 확인하라.

6.2 가우스의 정17각형

  1. \(\eta + \eta'\)은 실수가 아닌 7제곱근(seventh root) 여섯 개의 합이므로 \(-1\)이다. \(\eta\eta'\)을 전개하면 지수가 \(4, 6, 0, 5, 0, 1, 0, 2, 3\) (mod \(7\))인 아홉 개의 항 \(\alpha^{a+b}\)가 나온다. 즉 \(1\)이 세 개이고 실수가 아닌 근이 각각 한 번씩 나오므로 \(\eta\eta' = 3 - 1 = 2\)이다. 따라서 \(\eta\), \(\eta'\)은 \(\frac{-1 \pm \mathrm{i}\sqrt7}{2}\)이다. \(\eta\)의 실수부(real part)에서 코사인의 합을 얻는다. \(\eta\)의 허수부(imaginary part)는 \(\sin\frac{2\pi}{7} + \sin\frac{4\pi}{7} - \sin\frac{\pi}{7}\)이고, \(\sin\frac{4\pi}{7} = \sin\frac{3\pi}{7} > \sin\frac\pi7\)이므로 양수이다. 따라서 허수부는 \(+\frac{\sqrt7}{2}\)이다.

  2. \(\zeta = \mathrm{e}^{2\pi\mathrm{i}/5}\)라 하면, 주기(period) \(\zeta + \zeta^4 = 2\cos\frac{2\pi}{5}\)와 \(\zeta^2 + \zeta^3\)의 합은 \(-1\), 곱은 \(-1\)이므로 이 둘은 \(t^2 + t - 1 = 0\)의 근이고, 그중 양수인 것에서 \(\cos\frac{2\pi}{5} = \frac{\sqrt5 - 1}{4}\)를 얻는다. 작도하려면 다음과 같이 한다. 단위원에서 직각을 낀 두 변의 길이가 \(1\)과 \(\frac12\)인 직각삼각형의 빗변(hypotenuse)은 \(\frac{\sqrt5}{2}\)이다. 여기서 \(\frac12\)을 빼고 반으로 나누면 \(\cos\frac{2\pi}{5}\)를 얻는다. 그 거리에서 축에 수직인 직선은 \((1, 0)\)에 이웃한 꼭짓점에서 원과 만난다. 이 현(chord)을 원을 따라 차례로 옮겨 가면 된다.

  3. 둘 다 소수점 아래 다섯째 자리까지 \(-1.28078\)이다.

  4. \(3\)의 거듭제곱은 \(3, 9, 10, 13, 5, 15, 11, 16, 14, 8, 7, 4, 12, 2, 6, 1\)로, 열여섯 개가 모두 나온다. \(2\)의 거듭제곱은 여덟 단계마다 반복되며(\(2^8 = 256 \equiv 1\)) \(\{1, 2, 4, 8, 9, 13, 15, 16\}\)을 주는데, 이는 \(17\)을 법으로 하는 0이 아닌 제곱수(square modulo 17)이다.

6.3 \(\sqrt2 + \sqrt3 + \sqrt5\)를 근으로 갖는 다항식

  1. \(y^3 = 2\sqrt2 + 6\sqrt3 + 9\sqrt2 + 3\sqrt3 = 11\sqrt2 + 9\sqrt3\)이고 \(9y = 9\sqrt2 + 9\sqrt3\)이므로 \(y^3 - 9y = 2\sqrt2\)이다. 그러면 \(\sqrt3 = y - \sqrt2\)와 \(\sqrt6 = \sqrt2\sqrt3\)도 \(y\)에 대한 다항식이다.

  2. \(x - \sqrt2 = \sqrt[3]3\)으로 놓고 세제곱하면 \(x^3 + 6x - 3 = \sqrt2(3x^2 + 2)\)이다. 이를 제곱하면 \(x^6 - 6x^4 - 6x^3 + 12x^2 - 36x + 1 = 0\)을 얻는다.

  3. 가능한 유리근(rational root)은 \(\pm1\)뿐인데, 어느 것도 근이 아니다. \(x^3\)항이 없으므로 최고차항의 계수가 1인(monic) 이차식 두 개로 인수분해하면 \((x^2 + ax + b)(x^2 - ax + c)\) 꼴이 되고, \(a(c - b) = 0\), \(b + c - a^2 = -10\), \(bc = 1\)이다. \(a = 0\)이면 \(b + c = -10\), \(bc = 1\)인데, 이는 정수에서 불가능하다. \(b = c = \pm1\)이면 \(a^2 = 12\) 또는 \(8\)이 되어 역시 불가능하다. 따라서 이 사차식은 기약(irreducible)이고 \(\sqrt2 + \sqrt3\)의 차수(degree)는 \(4\)이다.

  4. 드무아브르(De Moivre)의 정리에서 \(\cos3\theta = 4\cos^3\theta - 3\cos\theta\)이고, \(\theta = 20^\circ\)로 두면 \(\frac12 = 4c^3 - 3c\)이다. 후보 \(\pm1, \pm\frac12, \pm\frac14, \pm\frac18\)는 모두 근이 아니다. 따라서 \(\cos20^\circ\)의 차수는 \(3\)이다. 그런데 작도 가능한(constructible) 길이는 모두 차수가 \(2\)의 거듭제곱이므로, \(60^\circ\)로부터 \(20^\circ\)를 작도할 수 없다.

6.4 사차방정식 풀기

  1. \(y_1y_2 + y_2y_3 + y_3y_1\)은 \(\alpha^2\beta\gamma\) 꼴의 열두 항(한 근의 제곱에 다른 두 근을 곱한 것)의 합이다. 그리고 \(\bigl(\sum\alpha\bigr)\bigl(\sum\alpha\beta\gamma\bigr)\)는 이 열두 항에 \(4\alpha\beta\gamma\delta\)를 더한 것이다. 따라서 그 합은 \((-p)(-r) - 4s\)이다.

  2. 계수를 비교하면 \(a + b = 1\), \(a\alpha + b\beta = 0\), \(a\alpha^2 + b\beta^2 = -p\)를 얻는다. 이는 \(\alpha \neq \beta\)일 때 풀 수 있는데, 바로 두 조건이 이를 보장한다. \(p \neq 0\)이면 \(t\)에 대한 방정식이 진짜 이차방정식이 되고(\(p = 0\)이면 \(-qt = 0\)으로 줄어들어 근이 \(0\) 하나뿐이다), \(q^2 \neq 4p^3\)이면 그 판별식(discriminant) \(q^2 - 4p^3\)이 0이 아니다. \(x^3 - 24x + 48\)의 경우 \(p = 8\), \(q = 48\)이고, \(8t^2 - 48t + 64 = 0\)에서 \(\alpha = 2\), \(\beta = 4\)이다. 그러면 \(\bigl(\frac{x - 2}{x - 4}\bigr)^3 = -\frac ba = \frac\alpha\beta = \frac12\)이므로 \(x - 2 = 2^{-1/3}(x - 4)\)이고, 이를 정리하면 주어진 근 \(x \approx -5.6946\)을 얻는다.

  3. 분해 삼차식(resolvent cubic)은 \(y^3 - 7y^2 + 16y - 12 = (y - 3)(y - 2)^2\)이다. 근 \(y = 3\)에서 \((x^2 - 2x + 1)(x^2 - 2x + 2)\)를 얻으므로 근은 \(1\)(두 번)과 \(1 \pm \mathrm{i}\)이다.

  4. 각 쌍 안에서 바꿀지 말지(\(4\)가지), 그리고 두 쌍끼리 바꿀지 말지(\(2\)가지)를 정한다. 즉 항등치환(identity), \((\alpha\beta)\), \((\gamma\delta)\), \((\alpha\beta)(\gamma\delta)\), \((\alpha\gamma)(\beta\delta)\), \((\alpha\delta)(\beta\gamma)\), \((\alpha\gamma\beta\delta)\), \((\alpha\delta\beta\gamma)\)이다. 이는 정사각형의 대칭군(symmetry group)과 똑같은 구조이다.

6.5 공리에서 출발하는 미분

  1. 상수는 여전히 \(0\)이 되고, 규칙 (i)과 귀납법(induction)에 의해 \(\lozenge x^n = x^{n-1}\lozenge x + x\lozenge x^{n-1} = nx^n\)이다. 선형성(linearity)에 의해 \(\lozenge\mathrm{h} = x\mathrm{h}'\)이다.

  2. \(\lozenge\mathrm{f} = \frac{\mathrm{f}}{\mathrm{g}}\lozenge\mathrm{g} + \mathrm{g}\lozenge\frac{\mathrm{f}}{\mathrm{g}}\)이므로 \(\lozenge\frac{\mathrm{f}}{\mathrm{g}} = \frac{\mathrm{g}\lozenge\mathrm{f} - \mathrm{f}\lozenge\mathrm{g}}{\mathrm{g}^2}\)이다.

  3. \(\mathrm{f} = (x - a)^2\mathrm{g}\)이면 \(\mathrm{f}' = (x - a)\bigl(2\mathrm{g} + (x - a)\mathrm{g}'\bigr)\)이다. \(x^n - 1\)의 중근(repeated root)은 \(nx^{n-1}\)의 근이어야 하므로 \(0\)이어야 한다. 그러나 \(0\)은 \(x^n - 1\)의 근이 아니다.

  4. \((2 + \varepsilon)^2 + 1 = 5 + 4\varepsilon\)이고 \((5 + 4\varepsilon)^3 = 125 + 300\varepsilon\)이다. 따라서 \(f(2) = 125\), \(f'(2) = 300\)이다. 연쇄법칙(chain rule)으로 계산하면 \(3(x^2 + 1)^2 \cdot 2x = 3 \cdot 25 \cdot 4 = 300\)이다.

6.6 부분군의 합집합

  1. \(V = \{e, a, b, c\}\)에서 \(a^2 = b^2 = c^2 = e\)이고, \(a\), \(b\), \(c\) 중 어느 두 개의 곱도 나머지 하나이다. 모든 원소가 자기 자신의 역원(inverse)이다. \(\{1, \mathrm{i}, -1, -\mathrm{i}\}\)에서는 \(\mathrm{i}\)의 역원이 \(-\mathrm{i}\)이므로 두 군은 서로 다르다.

  2. \(g\)가 진부분군(proper subgroup) \(H\)에 속한다면 \(g\)의 모든 거듭제곱도 \(H\)에 속하므로, \(H\)는 군 전체가 되어 버린다.

  3. \(1\)은 짝수도 아니고 \(3\)의 배수도 아니다. 더 일반적으로, \(\mathbb{Z}\)는 순환군(cyclic group)이므로(\(1\)로 생성된다) 앞의 문제에 의해 진부분군을 몇 개 모으더라도 그 합집합(union)이 될 수 없다.

  4. 직선 \(y = mx\)는 \(y = x^2\)와 \(x = 0\)과 \(x = m\)에서만 만나고, 직선 \(x = 0\)은 원점에서만 만난다. 따라서 \(k\)개의 직선은 \(t \neq 0\)인 무수히 많은 점 \((t, t^2)\) 중 많아야 \(k\)개만 포함한다.

6.7 사원수군

  1. \(C\circ B = (\mathrm{i}, 0)\circ(0, 1) = (0, \mathrm{i}) = D\)이고, \(B\circ C = (0, 1)\circ(\mathrm{i}, 0) = (0, \mathrm{i}^*) = (0, -\mathrm{i}) = H\)이다.

  2. \(A\)의 위수(order)는 \(1\), \(E\)의 위수는 \(2\)이다. 나머지 여섯 원소는 각각 제곱하면 \(E\)이므로 위수가 \(4\)이다. 정사각형의 대칭군에는 위수가 \(2\)인 원소가 다섯 개(반사 네 개와 반 바퀴 회전) 있으므로 두 군은 동형(isomorphic)이 아니다.

  3. 행렬식(determinant)은 \(\det M = z_1z_1^* + z_2z_2^* = |z_1|^2 + |z_2|^2\)이고, 이는 네 실수의 제곱의 합이다. \(M(z)M(w)\)는 \(z\circ w\)의 행렬이므로, 행렬식을 곱하면 \((a_1^2 + \cdots + a_4^2)(b_1^2 + \cdots + b_4^2)\)를 \(|u_1|^2 + |u_2|^2\), 즉 다시 네 제곱수의 합으로 나타낼 수 있다.

  4. 부분군은 \(\{A\}\), \(\{A, E\}\), \(\{A, E, C, G\}\), \(\{A, E, B, F\}\), \(\{A, E, D, H\}\), \(Q_8\)이다. \(A\)가 아닌 모든 원소는 거듭제곱하면 \(E\)가 나오므로, \(\{A\}\)가 아닌 모든 부분군은 \(E\)를 포함한다. 위수가 \(4\)인 세 부분군을 합치면 여덟 원소가 모두 들어 있다.

6.8 특이행렬로 이루어진 군

  1. \(\mathbf{M}_a\mathbf{M}_b = \mathbf{M}_{2ab}\)이고 \(2(2ab) = (2a)(2b)\)이다. 이 사상(map)은 일대일(one-to-one)이며 0이 아닌 실수 전체 위로의(onto) 사상이다.

  2. \(\begin{pmatrix} a & b \\ 0 & 0 \end{pmatrix}\begin{pmatrix} c & d \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} ac & ad \\ 0 & 0 \end{pmatrix}\)이고 \(ac \neq 0\)이므로 이 집합은 닫혀 있다(closed). 모든 \(\begin{pmatrix} 1 & e \\ 0 & 0 \end{pmatrix}\)는 왼쪽 항등원(left identity)이다. 그러나 \(\mathbf{E} = \begin{pmatrix} e & f \\ 0 & 0 \end{pmatrix}\)에 대해 \(\mathbf{XE} = \mathbf{X}\)가 되려면 \(e = 1\), \(f = b/a\)여야 하고, 이는 \(\mathbf{X}\)에 따라 달라진다. 따라서 오른쪽 항등원이 없으므로 항등원이 없고, 군이 아니다.

  3. \(\mathbf{0}\), \(\mathbf{I}\), 그리고 \(bc = a(1 - a)\)인 행렬 \(\begin{pmatrix} a & b \\ c & 1 - a \end{pmatrix}\)(대각합(trace)이 \(1\), 행렬식이 \(0\))이다. 이들은 평면을 한 직선 위로 다른 직선을 따라 보내는 사영(projection)이다.

  4. 모든 성분이 \(a\)인 행렬 \(\mathbf{J}_a\)는 \(\mathbf{J}_a\mathbf{J}_b = \mathbf{J}_{nab}\)를 만족한다. 항등원은 \(\mathbf{J}_{1/n}\)이고 \(\mathbf{J}_a\)의 역원은 \(\mathbf{J}_{1/(n^2a)}\)이다.
