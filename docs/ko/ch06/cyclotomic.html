6.1

근이 모두 단위근인 다항식

학습지문제 링크, 힌트, 대학 수학과 연습문제 제6장장 전체 PDF
문제

STEP III 2010, 문제 3

계속 읽기 전에 문제를 먼저 읽어 보자. 문제는 STEP Support Programme의 문제 데이터베이스에 있다: step.maths.org/questions/10-s3-q3

도입

\(n\)차 단위근(roots of unity), 즉 \(z^n = 1\)의 해는 정\(n\)각형의 꼭짓점에 놓인다. 그러나 이들이 모두 같은 성격인 것은 아니다. 예를 들어 \(12\)차 단위근 가운데 \(1\)은 이미 1차 단위근이고, \(-1\)은 2차 단위근이며, \(\mathrm{i}\)는 4차 단위근이다. 열두 개 가운데 원시(primitive) 단위근인 네 개만이 열두 걸음을 모두 거쳐야 \(1\)로 돌아온다.

단위근을 필요한 걸음 수에 따라 분류하고 각 부류마다 다항식을 하나씩 만들면 원분다항식(cyclotomic polynomials)을 얻는다(그리스어로 “원을 나눈다”는 뜻이다). 소수가 자연수를 이루는 기본 구성 요소이듯이 원분다항식은 \(z^n - 1\)을 이루는 기본 구성 요소이며, 가우스(Gauss)의 정\(17\)각형 작도(6.2 절), 단위근 필터(5.2 절), 그리고 현대 정수론의 많은 부분의 바탕에 놓여 있다.

시작하기 전에

모든 \(n\)차 단위근은 \(z^n = 1\)을 만족한다. 그러나 \(1\)이 되는 가장 작은 양의 거듭제곱 지수는 \(n\)보다 작을 수도 있다. 네 개의 4차 단위근 \(1\), \(\mathrm{i}\), \(-1\), \(-\mathrm{i}\) 각각에 대하여 그 가장 작은 지수는 무엇인가?

\(1^1 = 1\), \((-1)^2 = 1\)이고, \(\mathrm{i}^4 = (-\mathrm{i})^4 = 1\)이며 이보다 작은 지수로는 성립하지 않는다. 따라서 가장 작은 지수는 각각 \(1\), \(4\), \(2\), \(4\)이다. 이 가장 작은 지수를 단위근의 위수(order)라 하며, 원시 \(n\)차 단위근은 바로 위수가 \(n\)인 단위근이다. 이 문제 전체의 핵심이 되는 사실은 모든 단위근의 위수는 정확히 하나로 정해진다는 것이다.

차근차근 풀기

단계 1 처음 몇 개

원시 4차 단위근은 \(\mathrm{i}\)와 \(-\mathrm{i}\)이므로 \(\mathrm{C}_4(x) = (x - \mathrm{i})(x + \mathrm{i}) = x^2 + 1\)이다.■

위수가 \(1\), \(2\), \(3\), \(5\), \(6\)인 단위근은 각각 무엇인가? (\(6\)차 단위근을 그려 보고 위수에 따라 분류해 보아라.)

위수 \(1\): \(1\)뿐이므로 \(\mathrm{C}_1(x) = x - 1\)이다. 위수 \(2\): \(-1\)뿐이므로 \(\mathrm{C}_2(x) = x + 1\)이다.

위수 \(3\): \(1\)이 아닌 3차 단위근, 즉 \(\frac{x^3 - 1}{x - 1}\)의 근이다. 따라서 \(\mathrm{C}_3(x) = x^2 + x + 1\)이다.

위수 \(5\): \(1\)이 아닌 5차 단위근으로, 이들은 \(\frac{x^5 - 1}{x - 1}\)의 근이다. 따라서 \(\mathrm{C}_5(x) = x^4 + x^3 + x^2 + x + 1\)이다.

위수 \(6\): 6차 단위근 \(e^{k\pi\mathrm{i}/3}\), \(k = 0, \ldots, 5\) 가운데 \(k = 0\), \(3\)인 것의 위수는 각각 \(1\), \(2\)이고, \(k = 2\), \(4\)인 것의 위수는 \(3\)이다. 남는 것은 \(e^{\pm\pi\mathrm{i}/3}\)이므로 \[\mathrm{C}_6(x) = (x - e^{\mathrm{i}\pi/3})(x - e^{-\mathrm{i}\pi/3}) = x^2 - 2x\cos\tfrac\pi3 + 1 = x^2 - x + 1. \qed\]

단계 2 어떤 \(n\)에서 \(x^4 + 1\)이 나오는가?

\(x^4 + 1 = 0\)의 근은 \(x^4 = -1\)을 만족하므로 \(x^8 = 1\)이지만 \(x^4 \neq 1\)이다. 따라서 그 위수는 \(8\)의 약수이지만 \(4\)의 약수는 아니므로 \(8\)이다. 역으로 위수가 \(8\)인 근은 \(x^8 = 1\), \(x^4 \neq 1\)을 만족하므로 \(x^4 = -1\)이다. 원시 \(8\)차 단위근은 네 개이고 \(x^4 + 1\)의 근도 네 개이므로 \(n = 8\)이다.■

단계 3 소수

\(p\)가 소수(prime)이면 \(p\)차 단위근의 위수는 \(p\)의 약수이므로 \(1\) 또는 \(p\)이다. 따라서 \(1\)을 제외한 모든 \(p\)차 단위근은 원시 단위근이고, \[\mathrm{C}_p(x) = \frac{x^p - 1}{x - 1} = x^{p-1} + x^{p-2} + \cdots + x + 1. \qed\]

단계 4 어떤 원분다항식도 다른 두 원분다항식의 곱이 아니다

\(\mathrm{C}_q = \mathrm{C}_r\mathrm{C}_s\)라고 하자. \(\mathrm{C}_r\)의 근 하나를 잡자. 그 위수는 무엇인가? 이 항등식은 그 위수에 대해 무엇을 말해 주는가? 그 결과 무엇이 강제되는가?

\(\mathrm{C}_r\)의 모든 근(\(e^{2\pi\mathrm{i}/r}\)이 원시 단위근이므로 근은 적어도 하나 있다)은 \(\mathrm{C}_r\mathrm{C}_s = \mathrm{C}_q\)의 근이므로 위수가 \(q\)이다. 그런데 이 근의 위수는 \(r\)이기도 하고, 단위근의 위수는 하나뿐이므로 \(r = q\)이다. 그러면 \(\mathrm{C}_q = \mathrm{C}_q\,\mathrm{C}_s\)이고, \(\mathrm{C}_q\)는 영다항식이 아니므로 \(\mathrm{C}_s = 1\)이다. 그러나 \(\mathrm{C}_s\)는 적어도 하나의 근 \(e^{2\pi\mathrm{i}/s}\)를 가지므로 이는 불가능하다. 따라서 그러한 \(q\), \(r\), \(s\)는 존재하지 않는다.■

돌아보기

  • 위수에 따라 분류하라. 모든 단위근은 유일한 위수를 가지며, 위수에 따라 묶으면 \(z^n - 1\)의 근이 서로소인 부류들로 나뉜다.

  • 근으로 다항식을 정의하라. 각 \(\mathrm{C}_n\)은 어떤 수들이 정확히 그 근인지를 밝힘으로써 결정되었다.

  • 유일성에서 불가능성이 나온다. 소문항 (iv)에는 단 하나의 아이디어만 필요했다. 하나의 근이 서로 다른 두 위수를 가질 수는 없다는 것이다.

숨은 수학

\(x^n - 1\)의 인수분해

모든 \(n\)차 단위근은 \(n\)의 약수인 어떤 위수 \(d\)를 가지며, \(d\)차 단위근 가운데 위수가 \(d\)인 것은 \(d \mid n\)일 때 모두 \(n\)차 단위근이다. 따라서 \(x^n - 1\)의 근은 위수에 따라 여러 부류로 나뉘고, 다음을 얻는다. \[x^n - 1 = \prod_{d \mid n}\mathrm{C}_d(x).\] 예를 들어 \(x^6 - 1 = \mathrm{C}_1\mathrm{C}_2\mathrm{C}_3\mathrm{C}_6 = (x - 1)(x + 1)(x^2 + x + 1)(x^2 - x + 1)\)이다. 그림 6.1.1은 열두 개의 \(12\)차 단위근을 이런 방식으로 분류한 것이다. 원시 \(n\)차 단위근의 개수, 즉 \(\mathrm{C}_n\)의 차수는 \(k\) 가운데 \(1\)과 \(n\) 사이에 있으면서 \(n\)과 공약수가 없는 것의 개수이며, 이것이 바로 오일러 피 함수(Euler’s totient function) \(\varphi(n)\)이다. 차수를 비교하면 항등식 \(\sum_{d \mid n}\varphi(d) = n\)을 얻는다.

정수 계수, 그리고 뜻밖의 사실

정의만 보아서는 분명하지 않지만, 모든 원분다항식의 계수는 정수이다. (\(x^n - 1\)의 인수분해와 수학적 귀납법(induction)을 이용한다. \(\mathrm{C}_n\)은 \(x^n - 1\)을 그보다 앞선 원분다항식들의 곱으로 나눈 것이고, 정수 계수 다항식을 최고차항의 계수가 \(1\)인(monic) 정수 계수 다항식으로 나누는 다항식의 나눗셈에서는 계수가 계속 정수로 남는다.) 오랫동안 알려진 모든 예는 계수가 \(0\), \(1\), \(-1\)뿐이었다. 첫 번째 예외는 1883년 Migotti가 발견한 \(\mathrm{C}_{105}\)로, 이 다항식에는 \(-2x^7\)이라는 항이 있다. \(105 = 3 \times 5 \times 7\)은 서로 다른 홀수 소인수를 세 개 가지는 가장 작은 수이다. 사실 원분다항식의 계수는 원하는 만큼 크게 만들 수 있다.

기약성

소문항 (iv)는 어떤 원분다항식도 다른 두 원분다항식의 곱이 아님을 보여 준다. 실제로는 훨씬 강한 사실이 성립한다. \(\mathrm{C}_n\)은 유리수 계수를 가진 더 낮은 차수의 다항식들로 전혀 인수분해되지 않는다. 가우스는 소수 \(n\)에 대하여 이를 증명했고(이는 대학 첫 대수학 강의에서 배우게 될 아이젠슈타인 판정법(Eisenstein’s criterion)에서 나온다), 크로네커(Kronecker)와 데데킨트(Dedekind)는 일반적인 \(n\)에 대하여 증명했다. 이 기약성(irreducibility) 덕분에 원분다항식은 단위근과 관련된 다항식 가운데 “소수”의 역할을 하며, 이는 단위근에 대한 갈루아(Galois) 이론의 출발점이 된다.

사고 기술

분류한 다음 쌓아 올리기

문제 속의 대상들을 하나의 잘 정의된 불변량(invariant)에 따라 부류로 나누고, 부류별로 구조를 쌓아 올려라.

여기서 불변량은 단위근의 위수였다. 각 근의 위수가 정확히 하나이므로 부류들은 겹치지 않으며, \(x^n - 1\)은 이 부류들에 걸친 곱으로 분해된다. 같은 패턴(유일한 불변량이 서로소인 분해를 낳는 것)이 소인수분해와 유한 아벨 군(finite abelian groups)의 분류의 바탕에도 놓여 있다.

더 도전하기

  1. 인수분해 확인하기. \((x - 1)(x + 1)(x^2 + x + 1)(x^2 - x + 1) = x^6 - 1\)임을 확인하고, \(x^{12} - 1\)이 그림 6.1.1에서처럼 인수분해됨을 확인하여라.

  2. 소수의 두 배. \(p\)가 홀수인 소수이면 \(\mathrm{C}_{2p}(x) = \mathrm{C}_p(-x)\)임을 보여라. \(p = 3\)일 때 이를 확인하여라.

  3. 오일러 피 함수. 소수 \(p\)에 대하여 \(\varphi(p^k) = p^k - p^{k-1}\)이고 \(\mathrm{C}_{p^k}(x) = \mathrm{C}_p\bigl(x^{p^{k-1}}\bigr)\)임을 보여라. 이를 이용하여 \(\mathrm{C}_9\)를 구하여라.

  4. 조금 긴 문제. 심화 \(x^{15} - 1 = \mathrm{C}_1\mathrm{C}_3\mathrm{C}_5\mathrm{C}_{15}\)를 이용하여 \(\mathrm{C}_{15}(x) = x^8 - x^7 + x^5 - x^4 + x^3 - x + 1\)임을 보여라.
