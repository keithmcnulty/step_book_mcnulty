제8장 · 미분방정식과 동역학계

더 도전하기 해답

이 해답은 완전한 풀이가 아니라 간단한 답과 힌트이다. 결과와 핵심 단계만 제시하므로, 스스로 푼 것을 확인하는 데 쓰면 된다. 해답을 보기 전에 먼저 각 연습문제를 제대로 풀어 보도록 하자.

8.1 해가 유일하지 않을 때

  1. \(y = v^2\)로 두면 \(2vv' = \alpha v - \beta v^2\)이므로 \(v' = \frac12(\alpha - \beta v)\)이고 \(y_1 = \frac{\alpha^2}{\beta^2}\bigl(1 - \mathrm{e}^{-\beta t/2}\bigr)^2\)이다. \(y = v^3\)으로 두면 \(v' = \frac13(\alpha - \beta v)\)이고 \(y_1 = \frac{\alpha^3}{\beta^3}\bigl(1 - \mathrm{e}^{-\beta t/3}\bigr)^3\)이다. 상수 함수 \(y = 0\)도 양변을 모두 0으로 만든다. 유도 과정에서 \(v\)로 나눌 때 이 해가 버려진 것이다.

  2. \(2\sqrt h = 2\sqrt{h_0} - kt\)이므로 \(h = \bigl(\sqrt{h_0} - \frac12kt\bigr)^2\)이고, 양동이는 \(T = \frac{2\sqrt{h_0}}{k}\)에서 빈다. \(h \equiv 0\)과, \(t \leq T\)에서 \(h = \frac{k^2}{4}(T - t)^2\)이고 \(t \geq T\)에서 \(h = 0\)인 함수는 모두 방정식을 만족하며 \(T\) 이후로 0이다. 빈 양동이를 보고는 언제 비었는지 알 수 없다.

  3. \(\frac{\mathrm{d}}{\mathrm{d}x}(y\mathrm{e}^{-2x}) = (y' - 2y)\mathrm{e}^{-2x} = 0\)이므로 \(y = C\mathrm{e}^{2x}\)이고, \(y(0) = 0\)에서 \(C = 0\)이어야 한다. 함수 \(2y\)는 립시츠(Lipschitz) 조건을 만족하지만(변화량이 많아야 \(2|y_1 - y_2|\)이다), \(2\sqrt y\)는 \(0\)에서 기울기가 무한대이다.

  4. 임의의 \(b \leq 0 \leq a\)에 대하여(\(b = -\infty\) 또는 \(a = \infty\)도 허용한다) \(x < b\)에서 \(y = (x - b)^3\), \(b \leq x \leq a\)에서 \(y = 0\), \(x > a\)에서 \(y = (x - a)^3\)이다. \(a = b = 0\)인 경우가 \(y = x^3\)이다.

8.2 풀지 않고 범위 구하기

  1. \(\frac{\mathrm{d}}{\mathrm{d}x}\bigl((y')^2 + y^2\bigr) = 2y'(y'' + y) = 0\)이므로 \((y')^2 + y^2 = A^2\)이고 \(|y| \leq A\)이다. 정확한 해는 \(A\cos x\)이다.

  2. \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl((\theta')^2 - 2\cos\theta\bigr) = 2\theta'(\theta'' + \sin\theta) = 0\)이다. 정지 상태에서 출발하면 \((\theta')^2 = 2(\cos\theta - \cos\theta_0) \geq 0\)이므로 \(\cos\theta \geq \cos\theta_0\)이다. \(|\theta_0| < \pi\)이면 연속성(continuity)에 의해 \(\theta\)는 \([-|\theta_0|, |\theta_0|]\) 안에 머물고, \(|\theta_0| = \pi\)이면 진자(pendulum)는 거꾸로 선 채 균형을 이루어 그대로 머문다. \(|\theta_0| > \pi\)이면, 예를 들어 \(\theta_0 = \frac{3\pi}{2}\)이면 \(\theta''(0) = -\sin\frac{3\pi}{2} = 1 > 0\)이므로 \(\theta\)는 증가하면서 출발한다. 진자는 실제로는 각도 \(\theta_0 - 2\pi = -\frac\pi2\)에 있으며, 그 위치를 기준으로 잰 \(\pm\frac\pi2\) 사이에서 흔들린다.

  3. \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl((y')^2 + y^2\bigr) = 2y'(y'' + y) = -4k(y')^2 \leq 0\)이다. 실제로 0으로 수렴하지만, 단조성(monotonicity)만으로는 이를 보일 수 없다. 예를 들어 지수 \(-k \pm \sqrt{k^2 - 1}\)의 실수부가 음수인 명시적인 해가 필요하다.

  4. \((y')^2 - \frac12y^4\)는 상수이고 그 값은 \(-\frac12\)이다. 이로부터 \((y')^2 = \frac12(y^4 - 1)\)을 얻는데, 이것으로는 아무것도 유계로 만들 수 없다. “퍼텐셜(potential)” \(-\frac12y^4\)에는 \(y\)를 가둘 우물이 없으며, 실제로 \(y\)는 유한 시간 안에 발산한다(blows up).

8.3 개체군 수확하기

  1. 방정식은 \(x' = \alpha^2 - (x - K)^2\)이고, 이는 \(y' = y(2\alpha - y)\)가 된다. \(w = \frac1y\)로 두면 \(w' = 1 - 2\alpha w\)이므로 \(w = \frac{1}{2\alpha} + C\mathrm{e}^{-2\alpha t}\)이다. \(y(0) < 0\)이면 \(w(0) < 0 < \frac{1}{2\alpha}\)이므로 \(w\)는 유한 시간 안에 \(0\)을 지나고 \(y \to -\infty\)이다. \(x\)는 그 전에 \(0\)에 도달한다.

  2. \(z = x - K\)로 두면 \(z' = -(z^2 + \beta^2)\)이므로 \(\tan^{-1}\frac z\beta = \tan^{-1}\frac K\beta - \beta t\)이다. 개체 수는 \(t = \frac2\beta\tan^{-1}\frac K\beta\)에서 0(\(z = -K\))에 도달한다.

  3. \(x' = x(2K - h - x)\)는 평형점(equilibrium) \(0\)과 \(2K - h\)를 가진다. \(h < 2K\)이면 이는 양의 환경 수용력(carrying capacity)을 가진 로지스틱 방정식(logistic equation)이며, 모든 양의 해는 \(2K - h\)로 수렴한다. 개체 수가 줄면 어획량도 줄어들므로, 어획이 개체 수를 0으로 몰아갈 수는 없다.

  4. \(x = K + K\tanh Kt\)이고, \(\tanh Kt = \frac12\)에서 \(t = \frac{1}{K}\tanh^{-1}\frac12 = \frac{\ln3}{2K}\)이다.

8.4 원으로 감겨드는 나선

  1. 곡선과 반지름 사이의 각 \(\psi\)는 \(\tan\psi = \frac{r}{\mathrm{d}r/\mathrm{d}\theta} = -1\)을 만족하며, 이 값은 모든 점에서 같다. 즉 곡선은 모든 반직선과 \(45^\circ\)로 만난다.

  2. \(x\,\mathrm{d}x + y\,\mathrm{d}y = \frac12\,\mathrm{d}(x^2 + y^2) = r\,\mathrm{d}r\)이다. 또한 \(x\,\mathrm{d}y - y\,\mathrm{d}x = r\cos\theta(\sin\theta\,\mathrm{d}r + r\cos\theta\,\mathrm{d}\theta) - r\sin\theta(\cos\theta\,\mathrm{d}r - r\sin\theta\,\mathrm{d}\theta) = r^2\,\mathrm{d}\theta\)이다.

  3. \(s = r^2\)으로 두면 \(\dot s = 2s(1 - s)\), 즉 로지스틱 방정식이므로 임의의 \(s(0) > 0\)에 대하여 \(s \to 1\)이다. 직교좌표(Cartesian) 형태로 쓰면 \(\dot x = x(1 - x^2 - y^2) - y\), \(\dot y = y(1 - x^2 - y^2) + x\)이다.

  4. \(\dot r = r(r - 1)(r - 2)\), \(\dot\theta = 1\)이다. \(0\)과 \(1\) 사이에서는 \(\dot r > 0\)이고, \(1\)과 \(2\) 사이에서는 \(\dot r < 0\)이며, \(2\)보다 크면 \(\dot r > 0\)이다. 따라서 \(r = 1\)은 끌어당기고(attracting) \(r = 2\)는 밀어낸다(repelling).

8.5 그레이하운드를 쫓는 그레이하운드

  1. 대칭성에 의해 개들은 항상 정사각형을 이룬다. \(A\)는 \(AB\)를 따라 속력 \(v\)로 달리므로 간격을 비율 \(v\)로 줄인다. \(B\)는 \(AB\)에 수직인 \(BC\)를 따라 달리므로 1차 근사에서 거리를 바꾸지 않는다. 따라서 \(AB\)는 정확히 비율 \(v\)로 \(s\)에서 \(0\)까지 줄어들고, 걸리는 시간은 \(\frac sv\)이다.

  2. \(r = \lambda\mathrm{e}^{-\sqrt3\theta}\)이다. 간격은 비율 \(v - v\cos120^\circ = \frac32v\)로 줄어들므로, 시간 \(\frac{2s}{3v}\) 후에 만나며 각자 \(\frac{2s}{3}\)를 달린다(이는 \(n = 3\)일 때의 \(\frac{s}{2\sin^2(\pi/n)}\)와 일치한다).

  3. 한 바퀴 돌 때마다 \(r\)에 \(\mathrm{e}^{-2\pi} \approx \frac{1}{535}\)가 곱해진다. 한 바퀴 후에는 약 \(19\) cm이고, 두 바퀴 후에는 약 \(0.35\) mm이므로 두 바퀴면 충분하다.

  4. 두 개는 서로를 향해 곧장 달려 시간 \(\frac{s}{2v}\) 후에 가운데에서 만난다. 이때 공식은 성립하지 않는다. \(\tan\frac\pi2\)가 무한대인데, 이는 회전이 전혀 없다는 사실과 맞아떨어진다.

8.6 양자 진동자

  1. (지루하기는 하지만) 직접 미분하면 된다. 또는 연습문제 4에서 따라 나온다. \(2\lambda = \omega\)이면 \(\int y_0y_2 = \int(2\omega x^2 - 1)\mathrm{e}^{-\omega x^2}\,\mathrm{d}x = 2\omega \cdot \frac{1}{2\omega}\sqrt{\frac\pi\omega} - \sqrt{\frac\pi\omega} = 0\)이다.

  2. \(y'' = (4\lambda^2x^2 - 2\lambda)y\)이므로, 방정식이 성립하려면 \(4\lambda^2 = \omega^2\)이고 \(2\lambda = (2\nu + 1)\omega\)이어야 한다. (감쇠하려면) \(\lambda = \frac\omega2 > 0\)이어야 하므로 \(\nu = 0\)이다.

  3. \(\frac{\mathrm{d}}{\mathrm{d}x}(y_my_n' - y_ny_m') = y_my_n'' - y_ny_m'' = (m^2 - n^2)y_my_n\)이다. 이를 \(0\)에서 \(\pi\)까지 적분한다. \(y_m\)과 \(y_n\)이 양 끝에서 0이므로 좌변은 \(0\)이 되고, \(m^2 \neq n^2\)이다.

  4. \(c = (2n + 1)\omega\)로 쓰면 \(y_n'' = (\omega^2x^2 - c)y_n\)이다. \(z = \omega xy_n - y_n'\)을 두 번 미분하고 이 식(과 그 도함수)을 이용하면 \(z'' - \omega^2x^2z = -(c + 2\omega)z\)를 얻으며, \(c + 2\omega = (2n + 3)\omega\)이다. \(y_0 = \mathrm{e}^{-\omega x^2/2}\)에서 출발하면 \(2\omega x\mathrm{e}^{-\omega x^2/2}\), 그다음 \(2\omega(2\omega x^2 - 1)\mathrm{e}^{-\omega x^2/2}\)를 얻는데, 이들은 각각 \(y_1\)과 \(y_2\)의 상수배이다.

8.7 풀 수 있는 혼돈

  1. (i) 수학적 귀납법(induction)으로 보인다. \(0 < x < 1\)이면 \(0 < x(1 - x) \leq \frac14\)이므로 \(0 < kx(1 - x) < 1\)이다. (ii) \(a = ka(1 - a)\)에서 \(k = \frac{1}{1 - a}\)이다. (iii) \(x_1 = ka(1 - a) = ab\)로 두면 조건 \(x_2 = a\)는 \(kab(1 - ab) = a\)이다. \(k = \frac{b}{1 - a}\)를 이용하면 이는 \(ab^3 - b^2 + 1 - a = 0\)이 된다. 근 \(b = 1\)은 고정점(fixed point)(\(x_1 = a\))에 해당하므로 이를 인수로 묶어 내면 \(ab^2 + (a - 1)b + (a - 1) = 0\)이다. 이를 \(b\)에 대해 풀면 \(k = \frac{b}{1 - a}\)를 얻는다. 같은 말로, \(2\)-순환(cycle)의 두 점은 \(k^2x^2 - k(k + 1)x + (k + 1) = 0\)의 근이며, 그 판별식(discriminant) \(k^2(k + 1)(k - 3)\)은 \(k > 3\)일 때에만 양수이다.

  2. \(p = -1\), \(q = 0\), \(r = -2\)이면 \(4pr = 8 = 8 + 2q - q^2\)이다. 계수를 비교하면 \(\alpha = \frac4p = -4\)이고 \(\beta = \frac{q - 4}{2p} = 2\)이므로 \(v_n = 2 - 4\sin^2(2^n\theta) = 2\cos(2^{n+1}\theta)\)이며, 이는 \(\phi = 2\theta\)일 때의 \(2\cos(2^n\phi)\)이다.

  3. \(u_3 = u_0\)이려면 \(\sin^2 8\theta = \sin^2\theta\)이어야 하므로 \(8\theta = \pm\theta + k\pi\)이다. \(\theta = \frac\pi7\)이면 순환 \(\sin^2\frac\pi7 \to \sin^2\frac{2\pi}{7} \to \sin^2\frac{4\pi}{7} \to \sin^2\frac{8\pi}{7} = \sin^2\frac\pi7\)이 생긴다. \(\theta = \frac\pi9\)이면 \(\sin^2\frac\pi9\), \(\sin^2\frac{2\pi}9\), \(\sin^2\frac{4\pi}{9}\)이다. 사상(map) \(u \mapsto u_3\)은 \(2^3 = 8\)개의 고정점을 가진다. 그중 두 개(\(0\)과 \(\frac34\))는 사상 자체의 고정점이므로, 정확히 주기(period) \(3\)인 점 \(6\)개, 즉 \(3\)-순환 두 개가 남는다.

  4. 각 단계에서 \(\theta\)가 두 배가 되어 정확도가 이진(binary) 자릿수 하나만큼 줄어들므로, 대략 \(50\)단계 후에는 계산된 값이 참값과 아무 관계가 없어진다. 그렇다고 쓸모없는 것은 아니다. 계산된 수열은 약간 다른 출발점에서 시작한 참 궤도(orbit)에 가깝게 머물므로(추적(shadowing) 성질), 그 통계적 성질은 여전히 옳다.

8.8 주기 3이면 혼돈이다

  1. \(a\), \(b\), \(c > 0\)이고 \(d < 0\)이면 \(b = 7 - 2a\), \(c = 7 - 2b\), \(d = 7 - 2c\), \(a = 7 + 2d\)이다. 이를 풀면 \(17a = 49\)이므로 순환은 \(\frac{49}{17} \to \frac{21}{17} \to \frac{77}{17} \to -\frac{35}{17} \to \frac{49}{17}\)이고, 세 점은 \(I_2 = [1, 5]\)에, 한 점은 \(I_1 = [-3, 1]\)에 있다.

  2. 찾은 점의 경로(itinerary)는 \(I_2, I_2, \ldots, I_2, I_1\)이다(\(I_2\)에서 \(n - 1 \geq 3\)단계). 순환 \(1 \to 5 \to -3\)은 이 경로를 따를 수 없다. \(-3\)은 \(I_2\)에 속하지 않으므로, \(1\)(두 번째 상이 \(-3\))도, \(5\)(첫 번째 상이 \(-3\))도, \(-3\) 자신도 그 점이 될 수 없다.

  3. 덮음 그림(covering diagram)은 \([1, 2] \to [3, 4], [4, 5]\); \([2, 3] \to [4, 5]\); \([3, 4] \to [2, 3], [3, 4]\); \([4, 5] \to [1, 2]\)이다. 길이 \(3\)인 고리는 \([3, 4] \to [3, 4] \to [3, 4]\)뿐이며, 이는 \(3\)-순환이 아니라 고정점을 준다.

  4. \(x = 14y - 7\)로 두면 \(\frac{\mathrm{f}(x) + 7}{14} = 1 - |2y - 1|\), 즉 텐트 사상(tent map)이다. 두 배를 하면 이진 자릿수가 왼쪽으로 한 칸 이동한다. 밀려 나간 자릿수가 \(1\)이면 결과는 \(2 - 2y\)이고, 이는 나머지 자릿수를 뒤집는다. \(3\)-순환은 \(\frac27 \to \frac47 \to \frac67\)과 \(\frac29 \to \frac49 \to \frac89\)이며(즉 \(x = -3, 1, 5\)와 \(x = -\frac{35}{9}, -\frac79, \frac{49}{9}\)), 이진법으로 나타내면 \(\frac27 = 0.\overline{010}\)이고 \(\frac29 = 0.\overline{001110}\)이다.
