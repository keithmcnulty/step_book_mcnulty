한 세트 모두 모으기

학습지문제 링크, 힌트, 대학 수학과 연습문제 제9장장 전체 PDF
문제

STEP II 1994, 문제 13

계속 읽기 전에 문제를 먼저 읽어 보자. 문제는 STEP Support Programme의 문제 데이터베이스에 있다: step.maths.org/questions/94-s2-q13

도입

어떤 축구 스티커 앨범에는 모아야 할 스티커가 \(600\)장 있고, 스티커는 한 장씩 무작위로 판매된다. 앨범을 다 채우려면 스티커를 몇 장 사야 한다고 기대할 수 있을까? 처음 몇백 장은 금방 모인다. 거의 모든 스티커가 새것이기 때문이다. 그러나 앨범이 채워질수록 새 스티커는 점점 드물어지고, 마지막 한 장만 해도 평균 \(600\)번을 사야 나온다. 전체는 약 \(4200\)장으로, 앨범 크기의 일곱 배에 이른다.

이것이 쿠폰 수집가 문제(coupon collector’s problem)이다. 그 답은 두 가지 아이디어를 결합한다. 하나는 성공할 때까지의 대기 시간이고, 다른 하나는 \(\ln n\)처럼 증가하는 조화급수(harmonic series) \(1 + \frac12 + \frac13 + \cdots\)이다. 조화급수가 발산한다는 것은 2.3 절에서 보았다. 여기서는 바로 그 느린 증가가 수집을 완성하는 데 치러야 하는 대가이다.

시작하기 전에

각 봉지에서 독립적으로 확률 \(p\)로 새 카드가 나온다면, 첫 번째 새 카드가 나올 때까지(그 봉지 포함) 뜯는 봉지 수의 기댓값은 얼마인가?

봉지 수 \(X\)는 기하분포(geometric distribution) \(\mathrm{P}(X = k) = (1 - p)^{k-1}p\)를 따른다. 그 기댓값(expectation)은 \(\frac1p\)이다. (이를 빠르게 확인하는 방법 하나: 봉지 하나를 뜯고, 확률 \(1 - p\)로 처음 상태로 돌아가므로 \(\mathrm{E}(X) = 1 + (1 - p)\mathrm{E}(X)\)이다.) 새 카드가 세 번에 한 번꼴로 나온다면, 세 봉지를 기다릴 것으로 기대된다.

차근차근 풀기

단계 1 새 카드 기다리기

이미 서로 다른 카드 \(r\)장을 가지고 있다면, 한 봉지에서 새 카드가 나올 확률은 이전 봉지들과 독립적으로 \(\frac{n - r}{n}\)이다. 따라서 다음 새 카드가 나올 때까지 뜯는 봉지 수의 기댓값은 \[\frac{1}{(n - r)/n} = \frac{n}{n - r}. \qed\]

단계 2 합과 적분 비교하기

구간 \(r \leq x \leq r + 1\)에서 \(\frac1x\)는 어떤 두 값 사이에 있는가? 이것은 곡선 아래의 넓이에 대해 무엇을 말해 주는가?

\(\frac1x\)는 감소하므로 \([r, r + 1]\)에서 \(\frac{1}{r+1} \leq \frac1x \leq \frac1r\)이다. 길이가 \(1\)인 구간에서 적분하면 \[\frac{1}{r + 1} \leq \int_r^{r+1}\frac{\mathrm{d}x}{x} \leq \frac1r. \qed\] 그림으로 보면(그림 9.11.1) 곡선 아래의 넓이가 높이 \(\frac{1}{r+1}\)인 직사각형과 높이 \(\frac1r\)인 직사각형 사이에 끼어 있다. 이것을 \(r = 1\)부터 \(r = n - 1\)까지 더하면 적분들이 이어져 \(\int_1^n\frac{\mathrm{d}x}{x} = \ln n\)이 되고, 따라서 \[\frac12 + \frac13 + \cdots + \frac1n \leq \ln n \leq 1 + \frac12 + \cdots + \frac{1}{n - 1}. \qed\]

단계 3 세트 완성하기

전체 봉지 수는 첫 번째 카드, 두 번째 새 카드 등을 기다리는 대기 시간들의 합이다. 그 기댓값은 얼마인가?

서로 다른 카드 \(r\)장에서 \(r + 1\)장이 되기까지 필요한 봉지 수를 \(X_r\)라 하자. 전체는 \(X_0 + X_1 + \cdots + X_{n-1}\)이고, 기댓값은 더해지므로 \[\mathrm{E}(\text{전체}) = \sum_{r=0}^{n-1}\frac{n}{n - r} = n\Bigl(\frac1n + \frac{1}{n - 1} + \cdots + 1\Bigr) = nH_n,\] 이다. 여기서 \(H_n = 1 + \frac12 + \cdots + \frac1n\)은 \(n\)번째 조화수(harmonic number)이다. 2단계에서 \(\ln n + \frac1n \leq H_n \leq \ln n + 1\)이므로, \(n\)이 클 때 \(H_n\)은 대략 \(\ln n\)이고, 나는 대략 \[n\ln n \text{ 봉지}. \qed\] 를 먹어야 한다고 예상해야 한다.

돌아보기

  • 긴 기다림을 단계로 나누어라. 전체 시간은 \(n\)개의 대기 시간으로 나뉘었고, 각각은 단순한 기하분포 형태였다.

  • 기댓값은 더할 수 있다. 전체의 분포는 전혀 필요하지 않았고, 각 조각의 기댓값만 있으면 되었다.

  • 합을 적분과 비교하라. 그림을 통해 계산할 수 없는 합을 오차가 최대 \(1\)인 로그로 바꾸었다.

숨은 수학

이 추정은 얼마나 정확한가?

비교를 더 정밀하게 할 수 있다. 그림 9.11.1에서 곡선과 위쪽 직사각형 사이의 색칠된 틈들은 넓이의 합이 유한하므로, \(H_n - \ln n\)은 어떤 극한으로 수렴(converge)한다. \[\gamma = \lim_{n \to \infty}(H_n - \ln n) = 0.5772156649\ldots,\] 이것이 오일러 상수(Euler’s constant)이다. (\(\gamma\)가 유리수(rational)인지는 아무도 모른다.) 따라서 봉지 수의 기댓값은 \(n\ln n + \gamma n + \frac12 + \cdots\)이다. 스티커 \(600\)장짜리 앨범의 경우 \(600 \times (\ln 600 + 0.577) \approx 4185\)로, 도입에서 말한 수치가 바로 이것이다.

시간은 어디에 쓰이는가? 각 단계는 매우 불균등하다. 세트의 처음 절반을 모으는 데는 약 \(n\ln 2 \approx 0.69n\)봉지밖에 들지 않지만, 마지막 카드 하나에만 평균 \(n\)봉지가 든다. 노력의 대부분은 마지막 몇 장에 들어가며, 그래서 수집가들은 중복된 카드를 서로 교환한다.

집중

기댓값은 시작일 뿐이다. 전체는 얼마나 변동하는가? 전체의 분산(variance)은 \(\sum n r/(n - r)^2\)이고, 이는 약 \(\frac{\pi^2}{6}n^2\)이다(2.4 절에서 나온 합 \(\sum 1/k^2 = \pi^2/6\)이 등장한다). 따라서 표준편차(standard deviation)는 약 \(1.28n\)으로, \(n\)이 클 때 평균 \(n\ln n\)보다 훨씬 작다. 즉 전체는 평균 주위에 집중(concentrated)되어 있다. 폴 에르되시(Paul Erdős)와 알프레드 레니(Alfréd Rényi)는 1961년에 더 정확하게, 전체에서 \(n\ln n\)을 빼고 \(n\)으로 나눈 값이 극한분포(limiting distribution)를 가지며, 그것이 굼벨 분포(Gumbel distribution)임을 보였다. 굼벨 분포는 많은 확률적인 양 가운데 가장 큰 값을 기술하는 분포이기도 하다(12.25 절).

어디에나 있는 쿠폰

이 문제는 아브라암 드무아브르(Abraham de Moivre, 1712)와 라플라스(Laplace)까지 거슬러 올라간다. 오늘날 이 문제는 여러 모습으로 나타난다. 시스템의 모든 부품을 점검하려면 무작위 검사가 몇 번 필요한가? 네트워크 위의 랜덤 워크(random walk)가 모든 노드를 방문할 때까지 얼마나 걸리는가? 컴퓨터 해시 테이블(hash table)을 몇 번 탐색해야 하는가? 어느 경우든 답에는 \(n\ln n\)이 들어 있다. 생물학에서는 같은 계산으로 유전체 전체를 덮는 데 필요한 염기서열 분석 “리드(reads)”의 수를 추정한다.

사고 기술

기댓값의 선형성

합의 기댓값은 기댓값의 합이며, 이는 각 조각이 독립(independent)이든 아니든 성립한다. 복잡한 확률적인 양을 단순한 조각들로 나누어라.

이것은 확률에서 가장 유용한 사실 가운데 하나인 기댓값의 선형성(linearity of expectation)이다. 여기서는 쿠폰 수집가 문제를 \(n\)개의 기하분포 대기로 환원했고, 9.8 절에서는 아무 계산 없이 일치하는 개수의 기댓값을 구해 주었다. 대학에서는 같은 아이디어가 알고리즘 분석과 조합론(combinatorics)의 확률적 방법(probabilistic method)을 뒷받침한다.

더 도전하기

  1. 세트의 절반. (\(n\)이 짝수일 때) 서로 다른 카드 \(\frac n2\)장을 모으는 데 필요한 봉지 수의 기댓값이 \(n(H_n - H_{n/2})\)이고, 이것이 약 \(n\ln 2\)임을 보여라.

  2. 서로 다른 카드. \(k\)봉지를 뜯은 뒤 가지고 있는 서로 다른 카드 수의 기댓값이 \(n\bigl(1 - (1 - \frac1n)^k\bigr)\)임을 보여라. (힌트: 각 카드에 대해 그 카드를 가지고 있을 확률을 구하고, 모두 더하라.) 대략 몇 봉지를 뜯으면 세트의 \(95\%\)를 얻는가?

  3. 두 수집가. 두 아이가 같은 세트를 모으면서 봉지를 함께 나누어, 한 아이에게 중복인 카드가 다른 아이에게는 새 카드가 될 수 있다. 두 세트를 모두 완성하는 데 필요한 봉지 수의 기댓값이 약 \(n(\ln n + \ln\ln n)\)임을 보여라. (이 문제는 더 어렵다. 먼저 이것이 \(2n\ln n\)보다 훨씬 작다는 것을 납득해 보라.)

  4. 더 정밀한 한계. 직사각형 대신 사다리꼴 공식(trapezium rule)의 그림을 이용하여 \(H_n - \ln n\)이 감소하고 \(H_n - \ln n - \frac{1}{2n}\)이 증가함을 보여라. 작은 \(n\) 값들로부터 \(0.5 < \gamma < 0.7\)을 이끌어 내라.

  • Julian Havil, Gamma: Exploring Euler’s Constant (Princeton University Press). \(\gamma\)와 조화급수에 관한 모든 것을 쉽게 읽을 수 있는 수준으로 다룬다.
