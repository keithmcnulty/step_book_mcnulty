9.4

함수로서의 수열

학습지문제 링크, 힌트, 대학 수학과 연습문제 제9장장 전체 PDF
문제

STEP I 2016, 문제 8

계속 읽기 전에 문제를 먼저 읽어 보자. 문제는 STEP Support Programme의 문제 데이터베이스에 있다: step.maths.org/questions/16-s1-q8

도입

계산기로 \(1/89\)를 계산해 보자: \(0.011235955\ldots\). 숫자들이 \(0, 1, 1, 2, 3, 5\)로 시작하는데, 이것은 피보나치 수(Fibonacci numbers)이다. 우연일까? 우연이 아니며, 이 문제가 그 이유를 설명해 준다.

이 아이디어는 조합론(combinatorics)에서 가장 강력한 것 가운데 하나이다. 무한수열(infinite sequence)을 하나 잡아, 그 항들을 멱급수(power series)의 계수로 사용하여 하나의 함수로 묶는다. 그러면 수열에 관한 사실이 함수에 관한 사실이 되고, 여기에 대수와 미적분을 사용할 수 있다. Herbert Wilf는 이를 인상적으로 표현했다: “생성함수(generating function)는 수열을 걸어 놓고 보여 주는 빨랫줄이다.”

시작하기 전에

생성함수가 \(\dfrac{1}{1 - x}\)인 수열은 무엇인가? \(\dfrac{1}{1 - 2x}\)는 어떤가? 생성함수에 \(x\)를 곱하면 수열은 어떻게 되는가?

등비급수(geometric series) \(\frac{1}{1 - x} = 1 + x + x^2 + \cdots\)는 \(1, 1, 1, \ldots\)의 생성함수이고, \(\frac{1}{1 - 2x} = 1 + 2x + 4x^2 + \cdots\)는 \(2\)의 거듭제곱들의 생성함수이다. \(x\)를 곱하면 모든 항이 한 자리씩 뒤로 밀린다: \(x \cdot \frac{1}{1-x} = x + x^2 + \cdots\)는 \(0, 1, 1, 1, \ldots\)의 생성함수이다.

차근차근 풀기

단계 1 자연수와 삼각수

이항급수(binomial series)로 \((1 - x)^{-2}\)를 전개하라. \(x^n\)의 계수는 무엇인가?

이항급수에 의해 \[(1 - x)^{-2} = 1 + 2x + 3x^2 + 4x^3 + \cdots = \sum_{n \geq 0}(n + 1)x^n,\] 이므로 \(x(1 - x)^{-2} = x + 2x^2 + 3x^3 + \cdots = \sum n x^n\)이다. 이것이 \(u_n = n\)의 생성함수이다.

마찬가지로 \((1 - x)^{-3}\)에서 \(x^n\)의 계수는 \(\frac{(-3)(-4)\cdots(-3-n+1)}{n!}(-1)^n = \frac{(n + 1)(n + 2)}{2}\)이므로 \[x(1 - x)^{-3} = \sum_{n \geq 1}\frac{n(n + 1)}{2}\,x^n = x + 3x^2 + 6x^3 + 10x^4 + \cdots,\] 이고, 이것이 삼각수(triangle numbers) \(u_n = \frac12 n(n + 1)\)의 생성함수이다.

\(n^2\)을 \(n\)과 \(\frac12n(n + 1)\)로 어떻게 나타낼 수 있는가?

\(n^2 = 2 \cdot \frac12 n(n + 1) - n\)이고, 생성함수는 수열과 똑같이 더해지므로 \[\sum n^2 x^n = \frac{2x}{(1 - x)^3} - \frac{x}{(1 - x)^2} = \frac{2x - x(1 - x)}{(1 - x)^3} = \frac{x(1 + x)}{(1 - x)^3}. \qed\]

단계 2 점화식이 방정식이 된다

\(u_n = ku_{n-1}\)에 \(x^n\)을 곱하고 모든 \(n \geq 1\)에 대하여 더하라. 각 변을 \(\mathrm{f}\)로 나타내면 무엇인가?

좌변은 \(\sum_{n \geq 1}u_nx^n = \mathrm{f}(x) - u_0 = \mathrm{f}(x) - a\)이다. 우변은 \(kx\sum_{n \geq 1}u_{n-1}x^{n-1} = kx\,\mathrm{f}(x)\)이다. 따라서 \(\mathrm{f}(x) = a + kx\,\mathrm{f}(x)\)이고, \[\mathrm{f}(x) = \frac{a}{1 - kx}. \qed\] 물론 \(u_n = ak^n\)이다. \(\frac{a}{1 - kx}\)를 등비급수로 전개하면 이를 확인할 수 있다.

단계 3 피보나치 수

\(n \geq 2\)에 대하여 \(u_n = u_{n-1} + u_{n-2}\)에도 같은 일을 한다: \[\sum_{n \geq 2}u_nx^n = x\sum_{n \geq 2}u_{n-1}x^{n-1} + x^2\sum_{n \geq 2}u_{n-2}x^{n-2},\] 즉, \[\mathrm{f}(x) - u_0 - u_1x = x\bigl(\mathrm{f}(x) - u_0\bigr) + x^2\,\mathrm{f}(x).\] \(u_0 = 0\), \(u_1 = 1\)이므로 이 식은 \(\mathrm{f}(x) - x = x\,\mathrm{f}(x) + x^2\,\mathrm{f}(x)\)가 되고, 따라서 \[\mathrm{f}(x) = \frac{x}{1 - x - x^2}. \qed\]

단계 4 \(1/89\)의 설명

수렴(convergence)은 무시하고(여기서는 괜찮다: 이 급수는 \(|x| < 0.618\)에서 수렴한다), \(\mathrm{f}\)에 \(x = \frac{1}{10}\)을 대입하라. 무엇을 얻는가?

\[\frac{1}{10}F_1 + \frac{1}{100}F_2 + \frac{1}{1000}F_3 + \cdots = \mathrm{f}\Bigl(\frac{1}{10}\Bigr) = \frac{1/10}{1 - 1/10 - 1/100} = \frac{10}{89}.\] \(10\)으로 나누면 \(\frac{1}{89} = \sum F_n/10^{n+1}\)이다. 피보나치 수들이 소수점 아래 연속된 자리에 차례로 놓이고, \(9\)보다 커지면 서로 겹친다(그림 9.4.1). \(1/89\)의 앞쪽 숫자들에는 피보나치 수가 보이지만, 뒤쪽 숫자들은 자리올림(carrying) 때문에 흐려진다.

돌아보기

  • 수열을 함수로 바꾼다. 무한수열 전체가 하나의 유리함수(rational function)가 되었다.

  • 점화식(recurrence)이 방정식이 된다. \(x^n\)을 곱하고 더하면 규칙 \(u_n = u_{n-1} + u_{n-2}\)가 대수로 풀 수 있는 \(\mathrm{f}\)에 관한 방정식으로 바뀌었다.

  • 옛것에서 새것을 만든다. 생성함수를 더하고, 밀고, 미분하여 처음부터 다시 시작하지 않고도 새로운 생성함수를 얻었다.

숨은 수학

생성함수에서 공식으로

생성함수는 수열을 담아 두기만 하는 것이 아니라, 수열을 구해 낼 수도 있다. 분모는 \(1 - x - x^2 = (1 - \varphi x)(1 - \psi x)\)로 인수분해되는데, 여기서 \(\varphi = \frac{1 + \sqrt5}{2}\)와 \(\psi = \frac{1 - \sqrt5}{2}\)는 \(t^2 = t + 1\)의 근이다. 부분분수(partial fractions)로 분해하면 \[\frac{x}{1 - x - x^2} = \frac{1}{\sqrt5}\Bigl(\frac{1}{1 - \varphi x} - \frac{1}{1 - \psi x}\Bigr),\] 이고, 각 분수를 등비급수로 전개하면 \[F_n = \frac{\varphi^n - \psi^n}{\sqrt5}.\] 이것이 비네(Binet) 공식이다. \(|\psi| < 1\)이므로 둘째 항은 매우 작고, 따라서 \(F_n\)은 \(\varphi^n/\sqrt5\)에 가장 가까운 정수이며, 연속한 피보나치 수의 비는 황금비(golden ratio)로 수렴한다(2.2 절의 주제이다). 같은 방법으로 상수계수 선형 점화식(linear recurrence with constant coefficients)을 모두 풀 수 있다. 연습문제에 STEP I 2004의 예가 있다.

생성함수가 그토록 쓸모 있는 이유

진짜 힘은 곱셈에서 드러난다. 곱 \(\mathrm{f}(x)\mathrm{g}(x)\)에서 \(x^n\)의 계수는 \(\sum_k u_kv_{n-k}\)인데, 이는 \(n\)을 두 부분으로 나누는 모든 방법에 대하여 더한 것이다. 두 조각으로 이루어진 것을 셀 때 정확히 필요한 것이 이것이다. 다음 두 절에서는 이를 이용하여 거스름돈을 만드는 방법의 수를 세고(9.5 절), 보통 주사위와 합의 분포가 같은 이상한 눈의 주사위를 찾는다(9.6 절). 확률에서는 같은 아이디어로 확률생성함수(probability generating function)를 얻는데, 이는 독립 확률변수(independent random variables)의 합을 곱으로 바꾼다.

드무아브르, 오일러, 라플라스

아브라함 드무아브르(Abraham de Moivre)는 1720년대에 생성함수를 사용하여 선형 점화식을 풀었는데, 본질적으로 위의 방법이었다. 레온하르트 오일러(Leonhard Euler)는 1748년에 자연수의 분할(partitions)을 연구하는 데 생성함수를 사용했고, 피에르시몽 라플라스(Pierre-Simon Laplace)는 생성함수를 그의 저서 Théorie analytique des probabilités(확률의 해석적 이론, 1812)의 토대로 삼았다. 20세기에 생성함수는 조합론의 중심이 되었고, 오늘날에는 해석적 방법(생성함수를 복소변수(complex variable)의 함수로 연구하는 것)으로 정확히 풀기에는 너무 복잡한 세기 문제에 대해서도 정밀한 추정을 얻는다.

사고 기술

표현을 바꾸어라

수열에 관한 문제는 수열을 함수, 행렬, 또는 그림으로 바꾸면 쉬워질 수 있다.

생성함수는 점화식을 대수로, 세기를 곱셈으로 옮긴다. 대학에서는 이런 옮기기를 많이 만나게 된다: 푸리에 급수(Fourier series)는 함수를 수열로 바꾸고, 라플라스 변환(Laplace transform)은 미분방정식(differential equation)을 대수로 바꾸며, 행렬(matrix)은 기하를 산술로 바꾼다.
