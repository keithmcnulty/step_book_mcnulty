제10장 · 보존 법칙, 충돌, 그리고 중력

더 도전하기 해답

여기 실린 것은 완전한 풀이가 아니라 간단한 답과 힌트이다. 결과와 핵심 단계를 제시하므로 자신의 풀이를 확인하는 데 쓸 수 있다. 답을 보기 전에 각 연습문제를 먼저 제대로 풀어 보아라.

10.1 뉴턴의 요람

  1. 모든 충돌(collision)이 끝난 뒤에는 움직이는 입자 뒤를 더 느린 입자가 따라갈 수 없다. 따라서 정확히 하나만 움직인다면 그것은 \(A_n\)이고, \(\lambda mv = mu\), \(\lambda mv^2 = mu^2\)는 \(\lambda \neq 1\)일 때 서로 모순이다. \(A_{n-1}\)과 \(A_n\)만 움직인다면 방정식은 \(m\)과 \(\lambda m\) 사이의 충돌 방정식이 되고, 이로부터 \(A_{n-1}\)의 속도는 \(\frac{1 - \lambda}{1 + \lambda}u < 0\)이다. 그러나 그러면 이 입자는 \(A_{n-2}\)와 부딪치게 된다. 세 입자가 움직이는 경우는 소문항 (ii)와 똑같은 방법으로 배제된다. 움직이는 두 입자는 뒤쪽으로 \(\frac{\lambda - 1}{\lambda + 1}u\)로 움직이는 \(A_0\)과, 앞쪽으로 \(\frac{2u}{\lambda + 1}\)로 움직이는 \(A_n\)이다.

  2. 질량이 같은 구슬끼리는 속도를 서로 맞바꾸므로 속력 \(u\)는 \(A_n\)까지 전달된다. 그다음 \(A_n\)이 \(A_{n+1}\)과 부딪친다. \(A_{n+1}\)은 \(\frac{2u}{1 + \lambda}\)로 떠나고 \(A_n\)은 \(\frac{\lambda - 1}{\lambda + 1}u\)로 튕겨 나온다. 이 뒤쪽 방향의 속도는 줄을 따라 다시 \(A_0\)까지 전달되고, 이 구슬은 그 속력으로 뒤쪽으로 떠난다.

  3. “두 개가 \(u\)로 튀어 나가는” 경우는 운동량(momentum) \(2mu\)와 에너지 \(mu^2\)를 가지며, 이는 처음과 같다. 더 이상의 충돌이 없는 또 다른 해도 있다. 마지막 세 공이 \(\frac u3\), \(\frac u3\), \(\frac{4u}{3}\)로 움직여 나가는 것이다(확인: 합계 \(2u\), 제곱의 합 \(2u^2\)). 실제 요람 장치가 첫 번째 해를 택하는 것은 공들이 완전히 맞닿아 있지 않아서 충돌이 한 번에 한 쌍씩 일어나기 때문이다.

  4. 속력은 \(A_n\)까지 전달되고, 이 구슬이 더 가벼운 \(A_{n+1}\)과 부딪친다. \(A_{n+1}\)은 \(\frac{2u}{1 + \lambda}\)로 떠나고 \(A_n\)은 그보다 느린 \(\frac{1 - \lambda}{1 + \lambda}u\)로 뒤따른다. 다른 것은 움직이지 않는다.

10.2 포갠 공 효과

  1. 공은 \(U = \sqrt{2gH}\)의 속력으로 바닥에 닿고 \(eU\)로 튀어 올라 \(e^2H\)만큼 올라간다. 작은 공을 위에 올리면, \(eU\)로 올라가는 큰 공이 \(U\)로 내려오는 작은 공과 만난다. 운동량과 반발 법칙(restitution)으로부터 작은 공의 위쪽 속력은 \(w = U\frac{Me(2 + e) - m}{M + m}\)이다. 작은 공의 중심은 \(2R + r = 0.45\)에서 출발하여 \(4.5\)까지 올라가므로 \(\frac{w^2}{2g} = 4.05\)이고 \(\frac wU = \sqrt{\frac{4.05}{1.8}} = 1.5\)이다. \(e = \frac23\)이면 \(\frac{16}{9}M - m = 1.5(M + m)\)이므로 \(M = 9m\)이다.

  2. 운동량과 반발 법칙으로부터 \(P_1\)의 속력은 \(\frac{1 + e}{1 + \lambda}u\)이다. 각 충돌은 같은 질량비로 이를 되풀이하므로 \(P_n\)은 \(\bigl(\frac{1 + e}{1 + \lambda}\bigr)^nu\)로 움직인다. 속력이 \(s\)인 입자는 다음 입자와 충돌한 뒤 \(\frac{1 - \lambda e}{1 + \lambda}s\)의 속력이 남고, 다음 입자는 그 자신의 다음 충돌로 \(\frac{(1 + e)(1 - \lambda e)}{(1 + \lambda)^2}s\)로 느려진다. \(\lambda e < 1\)일 때 첫 번째 입자가 두 번째 입자를 다시 따라잡는 것은 \(\frac{1 - \lambda e}{1 + \lambda} > \frac{(1 + e)(1 - \lambda e)}{(1 + \lambda)^2}\), 즉 \(\lambda > e\)일 때뿐이다. 따라서 \(e > \lambda\)이면 각 입자는 한 번 맞고 한 번 친다. \(\lambda e = 1\)이면 각 입자는 다음 입자와 충돌한 뒤 그 자리에 멈춘다.

  3. 맨 아래 공은 \(U\)로 튀어 올라 (\(U\)로 내려오는) 가운데 공과 만난다. 상대 속력이 \(2U\)이므로 가운데 공은 \(3U\)로 떠난다. 맨 위 공은 상대 속력 \(4U\)로 이 공과 만나 \(7U\)로 떠나며, \(49H\)만큼 올라간다. 일반적으로 \(u_{j+1} = 2u_j + U\)이므로 \(u_j + U = 2^jU\)이다.

  4. 탄성 충돌(elastic collision)은 운동에너지(kinetic energy)를 보존한다. \(A\)의 에너지는 \(\frac12m\bigl(\frac{2\lambda}{1 + \lambda}\bigr)^{2n}u^2\)이고 처음 에너지는 \(\frac12\lambda^nmu^2\)이며, \(\frac{4\lambda}{(1 + \lambda)^2} < 1\)이므로 \(A\)는 원래 있던 것보다 더 많이 가져가지 않는다. 무거운 입자들은 각자 자기 속력의 \(\frac{\lambda - 1}{\lambda + 1}\)만큼을 유지하며 계속 앞으로 움직이고, 나머지 에너지를 간직한다.

10.3 로켓과 대포

  1. 한꺼번에 쏘면 \(Mu = nm(v - u)\)이므로 \(u = \frac{nmv}{M + nm}\)이다. 하나씩 쏘면 \(r\)번째 발사에서 \(\bigl(M + (n - r + 1)m\bigr)(u_r - u_{r-1}) = mv\)이므로 \(u_n = \sum_{j=1}^n\frac{mv}{M + jm}\)이고, 마지막 항을 제외한 모든 항이 \(\frac{mv}{M + nm}\)보다 크다. 따라서 \(u_n > u\)이다.

  2. 운동량: \(M(1 + bx)v = MV\). 따라서 \((1 + bx)\frac{\mathrm{d}x}{\mathrm{d}t} = V\)이므로 \(x + \frac12bx^2 = Vt\)이고 \(x = \frac{\sqrt{1 + 2bVt} - 1}{b}\)이다. 힘이 작용하면 \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl(M(1 + bx)v\bigr) = Mf\)로부터 \((1 + bx)v = ft + V\)를 얻는다. 속력이 일정한 값 \(c\)이려면 \(x = ct\)이고 \((1 + bct)c = ft + V\)이어야 하므로 \(c = V\), \(bV^2 = f\)이다. 그렇지 않으면 \(x + \frac12bx^2 = \frac12ft^2 + Vt\)이므로 \(x \sim t\sqrt{f/b}\)이고 \(v \to \sqrt{f/b}\)이다.

  3. 1단 로켓: \(v\ln10 \approx 2.30v\). 2단 로켓: \(v\ln\frac{10}{5.5} + v\ln\frac{5}{0.5} \approx 0.60v + 2.30v = 2.90v\).

  4. \(0 \leq s \leq x\)일 때 \(\frac{1}{1 + x} \leq \frac{1}{1 + s} \leq 1\)이다. 이를 \([0, x]\)에서 적분(integrate)하면 된다.

10.4 분자 하나와 피스톤

  1. 점화식(recurrence)은 연쇄적으로 소거되어 \(d_n = \frac{(v + u)d_1}{v + (2n - 1)u}\)이 되므로 \(v_nd_n = \frac{(v + 2nu)(v + u)d_1}{v + (2n - 1)u}\)이고, 이는 \((v + u)d_1\)보다 \(\frac{u(v + u)d_1}{v + (2n - 1)u} \to 0\)만큼 크다.

  2. \(u\)를 \(-u\)로 바꾼다. 물러나는 피스톤에서 한 번 튕길 때마다 \(2u\)를 잃으므로 (입자가 아직 피스톤을 따라잡을 수 있는 동안) \(v_n = v - 2nu\)이고, \(d_n = \frac{(v - u)d_1}{v - (2n - 1)u}\), \(v_nd_n = \frac{(v - 2nu)(v - u)d_1}{v - (2n - 1)u}\)이며, 이번에도 \((v - u)d_1\)에 가깝다.

  3. \(v = u\)이면 \(v_n = (2n + 1)u\)이다. \(n\)번째 충돌에서 운동량은 \(m(v_{n-1} + v_n) = 4nmu\)만큼 변하고 \(t_n = \frac{d_1}{un(n + 1)}\)이므로 평균 힘은 \(\frac{4mu^2n^2(n + 1)}{d_1}\)로, \(n^3\) 정도의 크기이다. 각 주기에서 한 일은 대략 힘 \(\times\ ut_n\), 곧 약 \(4nmu^2\)이고, 이들을 모두 더하면 무한대가 된다. 피스톤을 끝까지 밀어 넣으려면 무한한 일이 필요하며, 이는 분자의 에너지 \(\frac12m(2n + 1)^2u^2\)이 한없이 커지는 것과 같다.

  4. 불변량(invariant)은 \(\oint p\,\mathrm{d}q = 2\int_0^h m\sqrt{2g(h - z)}\,\mathrm{d}z \propto h^{3/2}\)이고, 여기서 \(h\)는 바닥으로부터 튀어 오르는 높이이다. 따라서 바닥이 천천히 올라갈 때 \(h^{3/2}\)(동치로 \(v^3\), 또는 에너지와 주기의 곱)은 거의 일정하게 유지된다.

10.5 유한한 시간 동안 무한 번 튀어 오르기

  1. 사인 법칙(sine rule)에 의해 \(M_1N_1 = \frac{OM_1\sin30^\circ}{\sin\theta}\)이고, 이어지는 구간은 \(\rho = \frac{\sin(\theta - 30^\circ)}{\sin\theta} < 1\)의 비율로 줄어든다. 전체 길이는 \(\frac{M_1N_1}{1 - \rho} = \frac{OM_1}{2\bigl(\sin\theta - \sin(\theta - 30^\circ)\bigr)} = \frac{OM_1}{4\sin15^\circ\cos(\theta - 15^\circ)}\)이다.

  2. 삼각형 \(OM_1N_1\)의 각으로부터 \(\varphi = \theta - \alpha\)이다. 시간의 비는 \(\frac{\rho}{k} = \frac{\sin(\theta - \alpha)\cos(\theta - \alpha)}{\sin\theta\cos\theta} = \frac{\sin(2\theta - 2\alpha)}{\sin2\theta}\)이고, 이 값은 정확히 \(\alpha < \theta < 45^\circ + \frac12\alpha\)일 때 \(1\)보다 작다.

  3. 쐐기를 그 벽에 대하여 반사시키면 경로가 펼쳐져 직선이 된다. 쐐기 열두 개가 \(O\) 둘레에 꼭 맞게 들어가고, \(O\)를 지나지 않는 직선은 그중 많아야 여섯 개를 가로지른다. 따라서 입자를 \(O\) 쪽으로 정확히 겨냥하지 않는 한, 입자는 유한 번만 튕긴 뒤 빠져나간다.

  4. 공은 먼저 \(t_0 = \sqrt{2/9.8} \approx 0.452\) s 동안 떨어진다. 각 튀어 오름은 \(2e^kt_0\) 동안 지속되므로 전체 시간은 \(t_0\bigl(1 + \frac{2e}{1 - e}\bigr) = 9t_0 \approx 4.07\) s이다. 이동 거리는 \(1 + 2\sum_{k \geq 1}e^{2k} = 1 + \frac{2(0.64)}{0.36} \approx 4.56\) m이다.

10.6 두 물체가 하나가 되다

  1. 줄은 팽팽하게 유지되고 상대 속도는 줄에 수직이며 크기가 \(u\)로 일정하므로 \(\theta = \frac{ut}{r}\)이다. 운동량으로부터 \(my + MY = mut\)이다. \(A = G - \frac{M}{m + M}\overrightarrow{AB}\)이고 \(\overrightarrow{AB} = r(\cos\theta, -\sin\theta)\)이므로 \(y = \frac{1}{m + M}\bigl(mut + Mr\sin\frac{ut}{r}\bigr)\)이다. 그러면 \(\dot y = \frac{u}{m + M}\bigl(m + M\cos\frac{ut}{r}\bigr)\)이고, 이는 \(\cos\frac{ut}{r} < -\frac mM\)일 때 음수이며, 이런 일은 \(M > m\)이면 일어날 수 있다.

  2. 이제 \(\ddot z = -\frac{3}{z^3}\)이므로 (\(z = 1\), \(\dot z = -1\)을 이용하면) \(\dot z^2 = \frac{3}{z^2} - 2\)이다. \(w = z^2\)이라 하면 \(\ddot w = 2\dot z^2 + 2z\ddot z = -4\)이므로 \(z^2 = 1 - 2t - 2t^2\)이다. 두 물체는 \(t = \frac{\sqrt3 - 1}{2} \approx 0.366\)일 때 충돌한다.

  3. \(\mathbf{p} = (1, 0)\), \(\mathbf{q} = (-1, \sqrt3)\)이라 하면 \(z^2 = 4t^2 - 2t + 1 = |\mathbf{p} + \mathbf{q}t|^2\)이다. 즉 \((1, 0)\)을 지나고 방향이 \((-1, \sqrt3)\)인 직선이며, \(\theta = \tan^{-1}\frac{\sqrt3t}{1 - t}\)이다. 그러면 \(z^2\dot\theta = |\mathbf{p} \times \mathbf{q}| = \sqrt3\)이다. 이 척력은 각운동량(angular momentum)이 \(h = \sqrt3\)인 평면 위 자유 운동의 “원심(centrifugal)” 항 \(\frac{h^2}{z^3}\)과 정확히 같다.

  4. 두 별은 질량중심(centre of mass)으로부터 각각 \(\frac{m_2a}{m_1 + m_2}\)와 \(\frac{m_1a}{m_1 + m_2}\)만큼 떨어져 있다. 첫 번째 별에 대해 \(\frac{Gm_1m_2}{a^2} = m_1\omega^2\frac{m_2a}{m_1 + m_2}\)이므로 \(\omega^2 = \frac{G(m_1 + m_2)}{a^3}\)이고 \(T = \frac{2\pi}{\omega}\)이다.

10.7 구 껍질 안의 중력

  1. 바깥(\(b > a\))에서는 3단계와 같은 적분이 \(s\)에 대해 \(b - a\)에서 \(b + a\)까지 이루어지며, 그 결과는 \(\frac{GM}{b^2}\)이다. 속이 찬 구는 동심 구껍질들의 합집합이고, 각 껍질은 질량이 중심에 모여 있는 것처럼 작용한다.

  2. \(r = R\cos^2\alpha\)라 하면 \(\frac1r - \frac1R = \frac{\tan^2\alpha}{R}\)이므로 속력은 \(\sqrt{2GM/R}\tan\alpha\)이다. 그러면 \(\mathrm{d}t = \frac{2R\sin\alpha\cos\alpha\,\mathrm{d}\alpha}{\sqrt{2GM/R}\tan\alpha} = \sqrt{\frac{R^3}{2GM}}\,2\cos^2\alpha\,\mathrm{d}\alpha\)이다. 이를 적분한다.

  3. (껍질 정리(shell theorem)에 의해) 반지름 \(b\) 안쪽의 질량, 즉 \(M\frac{b^3}{a^3}\)만 끌어당기므로 \(\frac{GMb}{a^3}\)을 얻는다. 이는 \(\omega^2 = \frac{GM}{a^3}\)인 단진동(simple harmonic motion)이며, \(a = 6.37 \times 10^6\) m, \(GM = 3.99 \times 10^{14}\) m\(^3\) s\(^{-2}\)일 때 주기는 \(2\pi\sqrt{a^3/GM} \approx 84\)분이다. 반지름 \(a\)에 있는 인공위성은 \(\omega^2a = \frac{GM}{a^2}\)이므로 같은 \(\omega\)를 가진다.

  4. 그렇지 않다. \(\frac{1}{s^3}\)이면 피적분 함수가 더 이상 상수로 간단해지지 않고, 껍질의 가까운 쪽이 이긴다. 즉 입자는 껍질의 가장 가까운 부분 쪽으로 끌려간다. 역제곱 법칙(inverse-square law)만이 정확한 상쇄를 준다(껍질 조각의 넓이가 \(s^2\)처럼 커져서 힘의 감소를 정확히 상쇄한다).

10.8 삼각형을 이룬 세 별

  1. 각 별은 중심에서 \(\frac{a}{\sqrt2}\)만큼 떨어져 있다. 이웃한 두 별은 중심 쪽으로 합계 성분 \(\frac{2\gamma m^2}{a^2}\cos45^\circ = \frac{\sqrt2\gamma m^2}{a^2}\)으로 끌어당기고, 맞은편 별은 \(\frac{\gamma m^2}{2a^2}\)으로 끌어당긴다. \(\frac{\gamma m^2}{a^2}\bigl(\sqrt2 + \frac12\bigr) = m\omega^2\frac{a}{\sqrt2}\)로 놓으면 \(\omega^2 = \frac{(4 + \sqrt2)\gamma m}{2a^3}\)이다.

  2. 중심에서는 인력들이 상쇄되므로 행성은 평형(equilibrium) 상태에 있다. 별들을 잇는 직선을 따라서는 불안정(unstable)하다. 한 별 쪽으로 거리 \(x\)만큼 움직이면 바깥쪽으로 약 \(\frac{32\gamma Mx}{a^3}\)의 알짜힘이 생긴다. 궤도면에 수직인 방향으로는 안정(stable)하며, 복원력은 약 \(\frac{16\gamma Mz}{a^3}\)이다. (궤도면 안에서 그 직선에 수직인 방향으로는 중력이 복원력으로 작용하지만, 회전 때문에 이 운동이 불안정한 방향과 결합된다.)

  3. \(m_1\)에 작용하는 힘은 \(\frac{\gamma m_1}{a^3}\bigl(m_2(P_2 - P_1) + m_3(P_3 - P_1)\bigr)\)이다. \(m_1P_1 + m_2P_2 + m_3P_3 = (m_1 + m_2 + m_3)G\)이므로 이 힘은 \(\frac{\gamma m_1(m_1 + m_2 + m_3)}{a^3}(G - P_1)\)이다. 모든 별이 같은 상수로, \(G\)로부터의 거리에 비례하여 \(G\) 쪽으로 끌리므로, 모두가 \(\omega^2 = \frac{\gamma(m_1 + m_2 + m_3)}{a^3}\)으로 강체처럼 회전할 수 있다.

  4. \(k\)칸 떨어진 별까지의 거리는 \(2R\sin\frac{k\pi}{n}\)이고, 그 인력은 중심 쪽으로 \(\sin\frac{k\pi}{n}\)의 비율만큼 성분을 가진다. 따라서 \(m\omega^2R = \frac{\gamma m^2}{4R^2}\sum_{k=1}^{n-1}\frac{1}{\sin(k\pi/n)}\)이므로 \(\omega^2 = \frac{\gamma m}{4R^3}\sum_{k=1}^{n-1}\frac{1}{\sin(k\pi/n)}\)이다. \(n = 3\), \(R = \frac{a}{\sqrt3}\)이면 이 값은 \(\frac{3\gamma m}{a^3}\)이다.
