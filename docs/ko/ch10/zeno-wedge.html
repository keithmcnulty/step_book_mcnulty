10.5

유한한 시간 동안 무한 번 튀어 오르기

학습지문제 링크, 힌트, 대학 수학과 연습문제 제10장장 전체 PDF
문제

STEP III 2002, 문제 11

계속 읽기 전에 문제를 먼저 읽어 보자. 문제는 STEP Support Programme의 문제 데이터베이스에 있다: step.maths.org/questions/02-s3-q11

도입

엘레아의 제논(Zeno of Elea)은 사람이 결코 벽에 닿을 수 없다고 주장했다. 먼저 거리의 절반을 가야 하고, 그다음에는 남은 거리의 절반을 가야 하며, 이런 일이 끝없이 이어지기 때문이다. 무한히 많은 단계가 유한한 총시간 안에 끝날 수 있다는 해결책은 바로 수렴하는(converge) 무한급수(infinite series)이다. 이 문제는 제논의 역설(Zeno’s paradox)을 실제로 구현한 것이다. 쐐기의 꼭짓점을 향해 미끄러져 들어가는 퍽(puck)은 벽에 무한히 많이 부딪혀 튀지만, 유한한 시간 뒤에 꼭짓점에 도달한다.

자연에서도 이런 일이 일어난다. 반발계수(coefficient of restitution)가 \(1\)보다 작은 공을 바닥에 튀기면, 공은 유한한 시간 동안 무한히 많이 튄 뒤 멈춘다. 입상 물질(granular materials, 모래, 곡물, 눈 등)의 컴퓨터 시뮬레이션에서는 이러한 “비탄성 붕괴(inelastic collapse)”가 실제로 골칫거리이다. 컴퓨터가 유한한 시간 안에 무한히 많은 충돌을 처리해야 하기 때문이다.

시작하기 전에

입자가 반발계수 \(e\)인 매끄러운 벽에 부딪힐 때, 속도의 벽 방향 성분은 어떻게 되는가? 벽에 수직인 성분은 어떻게 되는가?

매끄러운 벽은 벽 방향으로 힘을 작용하지 않으므로, 속도의 벽에 평행한 성분은 변하지 않는다. 수직 성분은 방향이 반대로 바뀌고 \(e\)배가 된다. 따라서 입자가 벽과 각 \(\alpha\)를 이루며 들어와서 각 \(\beta\)를 이루며 나간다면 \[\tan\beta = e\tan\alpha,\] 이고, 평행 성분이 변하지 않으므로 (들어올 때의 속력)\(\cos\alpha\) = (나갈 때의 속력)\(\cos\beta\)이다.

차근차근 풀기

단계 1 튀어 나가는 각

입자가 벽 \(OA\)와 각 \(\theta\)를 이루며 \(M_1\)에 도달한다(각은 \(O\)에서 먼 쪽에서 잰다). 입자는 \(OA\)와 어떤 각 \(\varphi\)를 이루며 튀어 나가는가? 삼각형 \(OM_1N_1\)을 이용하여 \(\varphi\)를 \(\theta\)로 나타내어라.

입자는 \(M_1\)에서 \(O\) 쪽을 향해 벽과 각 \(\varphi\)를 이루며 튀어 나가므로, 각 \(OM_1N_1\)은 \(\varphi\)이다. 삼각형 \(OM_1N_1\)에서 \(O\)에서의 각은 \(30^\circ\)이다. \(N_1\)에서 각 \(M_1N_1B\)는 \(\theta\)이고 \(O\), \(N_1\), \(B\)가 한 직선 위에 있으므로, 각 \(ON_1M_1\)은 \(180^\circ - \theta\)이다. 삼각형의 세 각의 합은 \(180^\circ\)이므로 \[30^\circ + \varphi + (180^\circ - \theta) = 180^\circ, \qquad\text{따라서}\qquad \varphi = \theta - 30^\circ.\] (특히 \(\theta > 30^\circ\)이다.) 그러면 반발 법칙 \(\tan\varphi = e\tan\theta\)로부터 \[e = \frac{\tan(\theta - 30^\circ)}{\tan\theta},\] 를 얻고, 평행 성분의 보존 \(u_1\cos\theta = v_1\cos\varphi\)로부터 \[\frac{v_1}{u_1} = \frac{\cos\theta}{\cos(\theta - 30^\circ)}. \qed\] 를 얻는다.

단계 2 반복되는 패턴

\(N_1\)에서 입자는 벽 \(OB\)와 각 \(\theta\)를 이루며 도달하며, 이 각은 \(O\)에서 먼 쪽에서 잰 것이다. 이를 \(M_1\)에 도달할 때와 비교해 보아라. 그다음에는 어떤 일이 일어나는가?

\(N_1\)에서의 상황은 \(M_1\)에서의 상황을 거울에 비춘 것과 같다. 입자가 \(O\)에서 먼 쪽에서 각 \(\theta\)를 이루며 벽에 부딪힌다. 따라서 입자는 각 \(\theta - 30^\circ\)를 이루며 튀어 나가 다시 각 \(\theta\)를 이루며 \(OA\)에 부딪히고, 이런 일이 끝없이 이어진다. 모든 튕김은 첫 번째 튕김을 확대·축소한 복사본이다. 각 삼각형 \(OM_kN_k\), \(ON_kM_{k+1}\), … 는 바로 앞의 삼각형과 닮음(similar)이고(그림 10.5.1), 속력은 튕길 때마다 같은 비율로 곱해진다.

단계 3 두 개의 비

한 번 튕긴 뒤 다음에 튕길 때까지 \(O\)로부터의 거리는 어떤 비율 \(\rho\)로 줄어드는가? 속력은 어떤 비율 \(k\)로 줄어드는가? 그렇다면 각 구간을 지나는 데 걸리는 시간은 어떤 비율로 줄어드는가?

삼각형 \(OM_1N_1\)에서 사인법칙(sine rule)을 쓰면 \[\rho = \frac{ON_1}{OM_1} = \frac{\sin\varphi}{\sin(180^\circ - \theta)} = \frac{\sin(\theta - 30^\circ)}{\sin\theta}.\] 이다. 다음 삼각형의 모든 길이는 이 삼각형의 길이의 \(\rho\)배이므로, 경로의 각 구간의 길이는 앞 구간의 \(\rho\)배이다. 속력은 튕길 때마다 \(k = \frac{\cos\theta}{\cos(\theta - 30^\circ)}\)배가 된다. 시간은 길이를 속력으로 나눈 것이므로, 각 구간에 걸리는 시간은 앞 구간에 걸린 시간의 \[\frac{\rho}{k} = \frac{\sin(\theta - 30^\circ)\cos(\theta - 30^\circ)}{\sin\theta\cos\theta} = \frac{\sin(2\theta - 60^\circ)}{\sin 2\theta}\] 배이다.

단계 4 등비급수

총시간은 \(T_1(1 + r + r^2 + \cdots)\)이다. 여기서 \(T_1\)은 첫 구간에 걸리는 시간이고 \(r = \frac{\sin(2\theta - 60^\circ)}{\sin 2\theta}\)이다. 이 등비급수(geometric series)는 \(0 < r < 1\)이면 유한하다.

\(\sin(2\theta - 60^\circ) < \sin 2\theta\)는 언제 성립하는가? 항등식 \(\sin X - \sin Y = 2\cos\tfrac12(X + Y)\sin\tfrac12(X - Y)\)를 이용하여라.

\[\sin 2\theta - \sin(2\theta - 60^\circ) = 2\cos(2\theta - 30^\circ)\sin 30^\circ = \cos(2\theta - 30^\circ),\] 이 값은 \(2\theta - 30^\circ < 90^\circ\)일 때, 즉 \(\theta < 60^\circ\)일 때 양수이다. 또 \(\theta > 30^\circ\)이므로 \(r > 0\)이다. 따라서 \(30^\circ < \theta < 60^\circ\)이면 급수가 수렴한다. 입자는 무한히 많이 튕기고, \(O\)로부터의 거리는 매번 비율 \(\rho < 1\)로 줄어들며, 유한한 시간 \(\frac{T_1}{1 - r}\) 뒤에 \(O\)에 도달한다.■

돌아보기

  • 자기 닮음(self-similarity). 한 번의 튕김을 이해하고 나면 그 뒤의 모든 튕김은 축소된 복사본이므로, 무한한 과정 전체가 두 개의 비로 정리되었다.

  • 비를 올바르게 결합하기. 거리는 \(\rho\)배, 속력은 \(k\)배로 줄어들므로 시간은 \(\rho/k\)배로 줄어든다.

  • 무한히 많은 사건, 유한한 합. 공비가 \(1\)보다 작은 등비급수는 수렴한다.

숨은 수학

\(\theta \geq 60^\circ\)일 때

\(\theta = 60^\circ\)이면 비가 정확히 \(1\)이다. 모든 구간에 같은 시간이 걸리므로, 입자는 \(O\)에 한없이 가까워지기는 하지만 결코 도달하지 못한다. (속력과 구간의 길이가 같은 비율로 줄어들기 때문이다.) \(\theta > 60^\circ\)이면 구간을 지나는 시간이 점점 길어진다. 어느 경우든 입자는 \(O\)에 가까워지며 무한히 많이 튕기지만, 유한한 시간 안에 도달하는 것은 \(\theta < 60^\circ\)일 때뿐이다. 값 \(e = \tan 30^\circ/\tan 60^\circ = \frac13\)이 그 경계이다.

튀는 공과 비탄성 붕괴

같은 현상의 가장 간단한 예는 다음과 같다. 바닥에 떨어뜨린 공은 높이 \(e^2H\)까지 올라가고, 그다음에는 \(e^4H\)까지 올라가며, 이런 식으로 계속된다. 튕김 사이의 시간은 각 튕김에서의 속력에 비례하고, 이 속력은 매번 \(e\)배로 줄어들므로 총시간은 등비급수가 된다. 첫 낙하에 걸리는 시간을 \(T_0 = \sqrt{2H/g}\)라 하면, 공은 \[T_0 + 2eT_0 + 2e^2T_0 + \cdots = T_0\,\frac{1 + e}{1 - e}.\] 뒤에 튀기를 멈춘다. 무한히 많이 튄 다음 정지하는 것이다. 1992년 Sean McNamara와 William Young은 한 직선 위에 놓인 많은 비탄성 입자의 시뮬레이션에서도 같은 일이 일어남을 보였다. 입자 무리가 유한한 시간 안에 무한히 많은 충돌을 겪을 수 있는데, 이것이 “비탄성 붕괴”이다. 모래와 입상 흐름의 시뮬레이션에는 이를 피하기 위한 특별한 규칙이 들어가야 하며, 이 현상은 입상 기체가 저절로 덩어리를 이루는 이유를 설명하는 데 도움이 된다.

제논과 수렴

기원전 450년 무렵에 나온 제논의 역설은 이천 년 동안 철학자들을 괴롭혔다. 무한한 합이 유한한 값을 가질 수 있다는 수학적 해결은 19세기에 이르러서야 엄밀해졌는데, 이때 코시(Cauchy), 바이어슈트라스(Weierstrass) 등이 극한(제2장의 주제)을 이용하여 수렴을 정의하였다. 이 문제의 놀라운 점은 과정이 물리적으로 무한하다는 것이다. 유한한 시간 안에 실제로 무한히 많은 충돌이 일어난다. 다각형 안의 당구(billiards)와 충돌하는 입자의 운동을 연구하는 수학자들은 이러한 거동을 제논 현상(Zeno phenomenon)이라 부르며, 이는 충돌하는 단단한 구들의 계가 모든 시간에 대해 잘 정의된 운동을 가진다는 것을 증명할 때 나타나는 미묘한 문제 가운데 하나이다.

사고 기술

무한한 과정을 합하기

과정이 일정한 배율로 반복될 때, 더할 수 있는 양(시간, 거리, 에너지)의 총합은 등비급수이다. 수렴 여부는 공비로 판단한다.

여기서 핵심은 올바른 비를 찾는 것이었다. 거리의 비도, 속력의 비도 아닌 시간의 비이다. 대학에서는 같은 추론이 반복법의 수렴, 프랙털 이론, 그리고 문제를 반복해서 절반으로 나누는 알고리즘의 분석을 지배한다.

더 도전하기

  1. 총 이동 거리. \(M_1\)에서 \(O\)까지 이동한 총거리가 \(30^\circ\)와 \(90^\circ\) 사이의 모든 \(\theta\)에 대해 유한함을 보이고, 이를 \(OM_1\)과 \(\theta\)로 나타내어라.

  2. 다른 쐐기. \(30^\circ\) 대신 각이 \(\alpha\)인 쐐기에 대해 문제를 다시 풀어라. \(\varphi = \theta - \alpha\)임을 보이고, 입자가 유한한 시간 안에 \(O\)에 도달하기 위한 \(\theta\)의 조건을 구하여라.

  3. 완전 탄성 벽. \(e = 1\)이면 입자가 \(O\)에 도달할 수 있는가? (힌트: 쐐기를 그 벽에 대해 거듭 대칭이동하여 경로가 직선이 되게 하여라. \(O\) 둘레에 \(30^\circ\) 쐐기가 몇 개 들어가는가?)

  4. 튀는 공. 공을 높이 \(1\) m에서 \(e = 0.8\)로 떨어뜨린다. 공은 얼마 동안 튀며, 총 얼마의 거리를 이동하는가? (\(g = 9.8\) m s\(^{-2}\)로 하여라.)
