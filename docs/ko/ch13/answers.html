제13장 · 세상 속의 통계와 무작위성

더 도전하기 해답

이것은 완전한 풀이가 아니라 간단한 답과 힌트이다. 결과와 핵심 단계를 제시하므로 자신의 풀이를 확인하는 데 쓸 수 있다. 답을 보기 전에 각 연습문제를 제대로 풀어 보아라.

13.1 신문 머리기사 읽기

  1. \(1 - \sum_{k=0}^{6}\mathrm{e}^{-2.96}\frac{2.96^k}{k!} \approx 0.0315\)이므로, 사망자가 일곱 명 이상인 날은 1년에 약 \(11\)일이다. \(\mathrm{P}(X \geq 9) \approx 0.0035\)이므로 이런 날은 1년에 약 하루이다.

  2. 사망자 수는 \(150K\)이고, \(K\)는 평균(mean)이 \(1.2\)인 포아송(Poisson) 분포를 따른다. 평균은 \(180\), 분산(variance)은 \(150^2 \times 1.2 = 27\,000\), 표준편차(standard deviation)는 약 \(164\)이다. 사망자가 \(125\)명 이하인 해는 추락 사고가 한 번도 없는 해이고, 그 확률은 \(e^{-1.2} \approx 0.30\)이므로 전혀 이상할 것이 없다. 그러나 이 모형에서 사망자가 정확히 \(125\)명인 것은 불가능하다. 사망자는 \(150\)의 배수로만 생기기 때문이다. 평균과 표준편차로는 이 사실이 드러나지 않는다. 군집(clustering) 때문에 분포가 울퉁불퉁해져서, 모든 확률이 \(0\), \(150\), \(300\) 등에 몰려 있다.

  3. \(z = \frac{1349.5 - 1080}{33} \approx 8.2\)이므로 확률은 \(10^{-16}\) 정도이다. 일정한 비율로는 \(1350\)을 설명할 수 없다. 무언가가 실제로 바뀌었다(또는 사망자를 세는 방식이 바뀌었다).

  4. 예를 들면 다음과 같다. (i) “총계만으로는 비행기와 걷기 중 어느 쪽이 더 안전한지 알 수 없다”; (ii) “1990년 항공 사고 사망자, 정상 범위 안”; (iii) “화요일 보행자 사망 7명: 나쁜 날이지만 1년에 약 열한 번 있는 일”; (iv) “1990년 보행자 사망 급증: 원인 조사 필요”.

13.2 들쥐 세기

  1. \(\frac{p_N}{p_{N-1}} = \frac{(N - M)(N - C)}{N(N - M - C + R)}\)이고, 이 값은 \(NR \leq MC\)일 때 그리고 그때에만 \(1\) 이상이다. 따라서 \(p_N\)은 \(N = \frac{MC}{R}\)까지 증가하다가 그 뒤로 감소하며, 최댓값은 이 값의 정수 부분에서 나온다.

  2. \(a\)명의 여자와 \(b\)명의 남자 중에서 \(c\)명으로 이루어진 위원회의 수를 여자의 수 \(j\)에 따라 나누어 센다. 각 \(j\)에 대하여 \(\binom aj\binom{b}{c - j}\)가지이다.

  3. \(\frac{\mathrm{d}}{\mathrm{d}p}\bigl(h\ln p + (n - h)\ln(1 - p)\bigr) = \frac hp - \frac{n - h}{1 - p} = 0\)에서 \(p = \frac hn\)을 얻는다.

  4. \(R = 0\)이면 \(p_N\)은 끝없이 증가하고, 추정값(estimate)은 무한대가 된다. 이 방법은 두 번째 표본에 표지된 동물이 충분히 들어 있을 때에만 통한다. 다시 잡힌 개체가 적으면 추정값이 매우 불안정하다.

13.3 독일 전차 문제

  1. 최댓값을 \(M\)이라 하면 \(\mathrm{E}(M) = \frac{nN}{n + 1}\), \(\mathrm{Var}(M) = \frac{nN^2}{(n + 1)^2(n + 2)}\)이므로 \(\mathrm{E}(M - N)^2 = \frac{2N^2}{(n + 1)(n + 2)}\)이다. 이것은 \(\mathrm{Var}(Z_1) = \frac{N^2}{n(n + 2)}\)의 \(\frac{2n}{n + 1}\)배이므로 더 나쁘다. 가장 좋은 배수는 \(c = \frac{N\mathrm{E}(M)}{\mathrm{E}(M^2)} = \frac{n + 2}{n + 1}\)이고, 이때 평균제곱오차(mean squared error)는 \(\frac{N^2}{(n + 1)^2}\)로 \(Z_1\)보다 약간 더 좋다.

  2. \(\mathrm{E}(\min) = \frac{N}{n + 1}\)이고 \(\min\)의 분산은 \(M\)의 분산과 같으므로 \(\mathrm{Var}\bigl((n + 1)\min\bigr) = \frac{nN^2}{n + 2}\)이다. 이 값은 \(n\)이 커져도 줄어들지 않으므로, 좋지 않은 추정량(estimator)이다.

  3. 최댓값이 \(m\) 이하인 것은 \(k\)개의 수가 모두 \(\{1, \ldots, m\}\)에서 나올 때 그리고 그때에만이다. \(k = 1\)이면 추정량은 \(2X - 1\)이고, 그 평균은 \(2 \cdot \frac{N + 1}{2} - 1 = N\)이다.

  4. \(98 + \frac{98}{5} - 1 = 116.6\)이므로 탱크는 약 \(117\)대이다.

13.4 평균인가, 중앙값인가?

  1. 어느 값이 중앙값(median)인지 고르고(\(2n + 1\)가지), 나머지 중 어느 \(n\)개가 그보다 작은지 고른다(\(\binom{2n}{n}\)가지). 따라서 확률은 \((2n + 1)\binom{2n}{n}y^n(1 - y)^n\,\delta y = \frac{(2n + 1)!}{(n!)^2}y^n(1 - y)^n\,\delta y\)이다.

  2. \(\mathrm{Var}(Y) = \frac{1}{4(2n + 3)} = \frac{1}{20}\)이고 \(\mathrm{Var}(\bar X) = \frac{1}{12(2n + 1)} = \frac{1}{36}\)이다. 평균이 더 좋다.

  3. \(\mathrm{Var}(\max) = \mathrm{Var}(\min) = \frac{m}{(m + 1)^2(m + 2)}\)이고 \(\mathrm{Cov}(\max, \min) = \frac{1}{(m + 1)^2(m + 2)}\)이므로 \(\frac{1}{2(m + 1)(m + 2)}\)를 얻는다. 이 값은 \(\frac{1}{m^2}\)처럼 줄어들어, 평균의 \(\frac{1}{12m}\)보다 훨씬 빠르게 작아진다. 균등분포(uniform distribution)를 따르는 자료에서는 탱크 문제에서처럼 양 끝값이 정보를 담고 있다.

  4. 평균은 약 \(18.6\)으로, 오타 하나 때문에 망가진다. 중앙값은 \(10.1\)로, 영향을 받지 않는다.

13.5 곤란한 질문 던지기

  1. 참인 답을 할 확률을 \(t = ap + bq\)라 하자. “예”라고 답할 확률은 \(\frac12t + \frac12(1 - t) = \frac12\)이므로 \(\mathrm{P}(\text{앞면} \mid \text{예}) = t\)이고, 이것은 \(2t = 1\)일 때 그리고 그때에만 \(\frac12\)이다. 같은 쌍둥이가 두 번 답하면, “예” 다음에 “아니요”라고 답할 확률은 동전이 앞면이든 뒷면이든 \(pa(1 - a) + qb(1 - b)\)이므로 사후확률(posterior probability)은 \(\frac12\)이다. 두 번 모두 “예”라고 답할 확률은 \(pa^2 + qb^2\)(앞면)와 \(p(1 - a)^2 + q(1 - b)^2\)(뒷면)이고, 이 둘은 \(2(ap + bq) = 1\)일 때 그리고 그때에만 같다.

  2. \(\mathrm{P}(\text{예}) = \frac34\pi + \frac14(1 - \pi)\)이므로 \(\hat\pi = \frac{0.4 - 0.25}{0.5} = 0.3\)이다. 표준오차(standard error)는 \(\frac{\sqrt{0.4 \times 0.6/400}}{0.5} \approx 0.049\)이다.

  3. \(\mathrm{E}(Y^2) = \sum_c\mathrm{P}(C = c)\bigl(\mathrm{Var}(Y \mid c) + \mathrm{E}(Y \mid c)^2\bigr)\)이다. 여기서 \(\mathrm{E}(Y)^2 = \bigl(\sum_c\mathrm{P}(C = c)\mathrm{E}(Y \mid c)\bigr)^2\)을 빼면 \(\mathrm{E}(\mathrm{Var}(Y \mid C)) + \mathrm{Var}(\mathrm{E}(Y \mid C))\)를 얻는다.

  4. \(Z_2\)는 각각 확률 \(\frac12\)로 \(\frac n6\)(앞면) 또는 \(\frac{5n}{6}\)(뒷면)에 가깝다. 따라서 \(Z_2\)가 \(\frac n2\) 근처에 있는 일은 거의 없는데도 \(\mathrm{P}(Z_2 > \frac n2) \to \frac12\)이다.

13.6 쌓이는 오차

  1. 각 버림 오차(truncation error)는 \((-1, 0]\)에서 균등분포를 따른다. 각각에 \(\frac12\)를 더하면 \((-\frac12, \frac12]\)에서 균등분포를 따르게 되어, 반올림(rounding)과 똑같아진다. 따라서 보정한 VOZ는 LEP만큼 좋다.

  2. 각 오차는 \((-0.05, 0.05)\)에서 균등분포를 따르고 분산은 \(\frac{0.1^2}{12}\)이므로, 합의 표준편차는 \(\sqrt{10\,000 \times 0.01/12} \approx 2.9\)이다.

  3. \(3000 \times 250 \times 0.0005 = 375\)점이다.

  4. 오차가 두 개이면 \([-1, 1]\)에서 \(1 - |x|\)이다. 세 개이면 \(|x| \leq \frac12\)에서 \(\frac34 - x^2\)이고 \(\frac12 \leq |x| \leq \frac32\)에서 \(\frac12\bigl(\frac32 - |x|\bigr)^2\)이며, 이미 정규분포(normal distribution) 곡선에 가깝다.

13.7 상관관계 만들어 내기

  1. 표준화된(standardised) 변수에 대하여 \(\mathrm{Var}(X_1 + X_2 + X_3) = 3 + 6\rho \geq 0\)이므로 \(\rho \geq -\frac12\)이다. \(n\)개의 변수에 대해서는 \(n + n(n - 1)\rho \geq 0\)에서 \(\rho \geq -\frac{1}{n - 1}\)을 얻는다.

  2. \(b = \frac{\rho_{23} - \rho_{12}\rho_{13}}{\sqrt{1 - \rho_{12}^2}}\)라 하면 \((1 - \rho_{12}^2)(1 - \rho_{13}^2 - b^2) = 1 - \rho_{12}^2 - \rho_{13}^2 - \rho_{23}^2 + 2\rho_{12}\rho_{13}\rho_{23} = \det R\)이다. \(1 - \rho_{12}^2 > 0\)이므로 두 조건은 동치이다.

  3. \(\mathrm{Var} = \frac14(0.04 + 0.09 + 0.12\rho)\)이므로, \(\rho = -1\), \(0\), \(1\)일 때 표준편차는 각각 \(0.05\), \(0.18\), \(0.25\)이다. 두 주식이 완전한 상관관계(perfectly correlated)에 있지 않은 한, 두 주식을 섞어 보유하는 것은 두 위험의 평균(\(0.25\))보다 덜 위험하다.

  4. \(Z_2 = \dfrac{Y_2 - \rho_{12}Y_1}{\sqrt{1 - \rho_{12}^2}}\).
