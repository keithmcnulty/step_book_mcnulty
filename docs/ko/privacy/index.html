Beyond STEP

개인정보 보호

Beyond STEP은 무료 책이다. 책을 읽는 데 계정이 필요하지 않으며, 이 사이트는 어떤 개인정보도 요구하거나 저장하지 않는다.

방문 분석

동의하면 이 사이트는 Google Analytics(측정 ID G-M8RDPR4MXR)를 사용해 방문을 집계한다. 집계하는 내용은 어떤 페이지를 읽었는지, 어떤 PDF와 학습지를 내려받았는지, 사이트에서 무엇을 검색했는지, 그리고 방문자가 대략 어디에서 왔는지(국가, 기기 유형, 이곳으로 연결한 사이트)이다. 이를 위해 Google Analytics는 브라우저에 쿠키를 저장한다. 이 정보는 책의 어느 부분이 유용한지 파악하고 책을 개선하는 데에만 쓰이며, 광고에 쓰이지 않고 다른 어떤 데이터와도 결합되지 않는다.

영국 법(전자통신 개인정보 보호 규정(Privacy and Electronic Communications Regulations) 및 영국 GDPR)에 따르면 분석용 쿠키와 같은 필수적이지 않은 쿠키는 설정하기 전에 동의를 받아야 한다. 이 사이트가 먼저 동의를 묻는 것은 이 때문이다. “동의”를 선택하지 않으면 아무것도 수집하지 않는다. “거부”를 선택하거나 아무것도 선택하지 않으면 Google Analytics 스크립트를 전혀 불러오지 않으며 분석용 쿠키도 설정하지 않는다. 선택한 내용은 브라우저의 로컬 저장소에 기억되므로 페이지마다 다시 묻지 않는다.

모든 페이지 아래쪽에 있는 쿠키 설정 링크에서 언제든지 선택을 바꿀 수 있다. 동의를 철회하면 분석용 쿠키가 삭제된다. Google의 개인정보처리방침은 policies.google.com/privacy에서 볼 수 있다.

뉴스레터

홈페이지의 구독 신청란은 구독 버튼을 눌렀을 때에만 입력한 이메일 주소를 The STEP Up을 운영하는 Substack에 보낸다. 그 전에는 Substack에서 아무것도 불러오지 않는다. Substack의 개인정보 처리방침은 substack.com/privacy에 있다.

호스팅

이 사이트는 GitHub Pages에서 호스팅된다. GitHub Pages는 다른 웹 서버와 마찬가지로 보안을 위해 IP 주소 등 기본적인 기술 정보를 서버 로그에 기록한다. 자세한 내용은 GitHub 개인정보 처리방침을 참고한다. 수식은 MathJax로 표시하며, 검색 페이지는 MiniSearch 라이브러리를 사용한다. 둘 다 jsDelivr 콘텐츠 전송 네트워크에서 불러온다.

연락처

질문이나 오류 수정은 GitHub 이슈로 언제든 환영한다.

이 판은 영어 원문을 기계로 번역한 것으로, 아직 한국어를 모국어로 하는 수학 교사의 검토를 거치지 않았다. 내용이 분명하지 않은 곳에서는 영어 원문을 기준으로 한다.
