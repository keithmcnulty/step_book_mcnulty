Beyond STEP

검색

    이 판은 영어 원문을 기계로 번역한 것으로, 아직 한국어를 모국어로 하는 수학 교사의 검토를 거치지 않았다. 내용이 분명하지 않은 곳에서는 영어 원문을 기준으로 한다.

    본문, 풀이, 그림, 연습문제: Keith McNulty. CC0 1.0에 따라 퍼블릭 도메인으로 공개한다. 오류 수정은 GitHub 이슈로 알려 주면 고맙겠다.

    STEP 문제의 저작권은 © Cambridge University Press & Assessment에 있으며 CC0 공개 대상에 포함되지 않는다. 문제는 여기에 수록하지 않았으며, 각 절에서 공식 출처의 해당 문제로 연결된다.
