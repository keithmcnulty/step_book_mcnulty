延伸练习答案

以下只是简短的答案和提示，并非完整解答：只列出结果和关键步骤，方便你核对自己的做法。请先认真做过每一道练习，然后才看答案。

1.1 质数工厂

  1. 假设 \(p_1, \ldots, p_k\) 就是全部的质数（prime）；那么 \(p_1\cdots p_k + 1\) 有一个不在此列之中的质因数（prime factor），矛盾（contradiction）。用费马数（Fermat number）的证明则是构造性（constructive）的：它具体给出无穷多个两两互质（pairwise coprime）的数 \(F_0, F_1, \ldots\)，每一个都提供一个新的质数。

  2. 当 \(n \geq 2\) 时，\(2^n\) 是 \(4\) 的倍数，所以 \(2^{2^n} = 16^{2^{n-2}}\)，而 \(16\) 的任何次幂的末位数字都是 \(6\)。因此 \(F_n\) 的末位数字是 \(7\)。

  3. (a) 用归纳法（induction）：\(a_{n+1} - 1 = a_n(a_n - 1) = a_n \cdot a_1\cdots a_{n-1}\)。(b) \(a_m\) 与 \(a_n\)（\(m < n\)）的公因数必整除 \(a_1\cdots a_{n-1} = a_n - 1\) 和 \(a_n\)，所以只能是 \(1\)；每一项都有一个不与其他项共有的质因数。(c) \(\frac{1}{a_n} = \frac{1}{a_n - 1} - \frac{1}{a_{n+1} - 1}\)；求和时各项裂项相消（telescope），得 \(1 - \frac{1}{a_{n+1} - 1}\)。

  4. (a) 由 \(p \mid F_n\) 得 \(2^{2^n} \equiv -1\)；两边平方得 \(2^{2^{n+1}} \equiv 1\)。(b) 凡满足 \(2^e \equiv 1\) 的 \(e\) 都能被 \(d\) 整除，所以 \(d \mid 2^{n+1}\)；又因为 \(2^{2^n} \equiv -1 \not\equiv 1\)（因 \(p\) 是奇数），所以 \(d \nmid 2^n\)。故 \(d = 2^{n+1}\)。(c) \(2^{p-1} \equiv 1\)，所以 \(2^{n+1} \mid p - 1\)。(d) \(641 = 64 \times 10 + 1\)。小于 \(641\) 而形如 \(64k + 1\) 的质数有 \(193\)、\(257\)、\(449\) 和 \(577\)：只需试四个候选数，欧拉（Euler）正是这样找到 \(641\) 的。

  5. 第 \(n\) 个质数不会超过 \(F_0, \ldots, F_{n-1}\) 之中任何一个数的最大质因数，所以 \(p_n \leq F_{n-1} = 2^{2^{n-1}} + 1\)。当 \(n = 5\) 时，这个上界是 \(65\,537\)，而 \(p_5 = 11\)：结论正确，但极为粗疏。

1.2 质数分布得有多稀疏？

  1. \(P_{1,10} = 210\)，\(P_{1,20} = 9\,699\,690\)，\(P_{1,30} = 6\,469\,693\,230\)。与 \(4^{30} \approx 1.15 \times 10^{18}\) 和 \(e^{30} \approx 1.07 \times 10^{13}\) 比较：这个乘积远小于 \(4^n\)，增长速度大致与 \(e^n\) 相若（事实上 \(\ln P_{1,n} \sim n\)，这是质数定理（Prime Number Theorem）的一种形式）。

  2. \(\binom{2m}{k+1}\big/\binom{2m}{k} = \frac{2m - k}{k + 1}\)，此值大于 \(1\) 当且仅当 \(k < m\)，所以各系数先递增至中间一项，然后递减。\(2m + 1\) 项之和为 \(4^m\)，其中最大的一项至少等于它们的平均值。

  3. 区间 \((\sqrt n, n]\) 内的质数每个都大于 \(\sqrt n\)，而它们的乘积小于 \(4^n\)，所以 \((\sqrt n)^{\pi(n) - \pi(\sqrt n)} < 4^n\)；两边取对数（logarithm）。由于 \(2\ln4 \approx 2.77\) 且 \(\pi(\sqrt n) \leq \sqrt n\)，即得所求的上界。它具有正确的形式 \(n/\ln n\)，只是常数为 \(2.8\)，而非真正的 \(1\)。

  4. 取质数 \(2, 3, 5, 7, 13, 23, 43, 83\)，其中每一个都小于前一个的两倍。对任意 \(n \leq 50\)，此列中第一个大于 \(n\) 的质数小于前一个质数的两倍，而前一个质数不超过 \(n\)，所以它介乎 \(n\) 与 \(2n\) 之间。

1.3 最小反例

  1. 设 \(k\) 是使 \(k\sqrt3\) 为整数的最小正整数，则 \(k' = (\sqrt3 - 1)k\) 是一个更小的正整数，而且 \(k'\sqrt3 = 3k - k\sqrt3\) 是整数。这里 \(\sqrt3 - 1\) 所起的作用，与 \(\sqrt2 - 1\) 相同。

  2. 由于 \(0 < \sqrt N - m < 1\)，\(k' = (\sqrt N - m)k\) 是一个小于 \(k\) 的正整数，而 \(k'\sqrt N = kN - mk\sqrt N\) 是整数：矛盾。

  3. 当 \(N = 4\) 时，\(m = 2 = \sqrt4\)，所以 \(\sqrt N - m = 0\)，而 \(k' = 0\) 并非正整数。“\(0 < \sqrt N - m\)”这一步不成立。

  4. 在图中，边长为 \(a\) 的正方形内有两个边长为 \(b\) 的正方形互相重叠，它们把中央一个边长为 \(2b - a\) 的正方形覆盖了两次，并留下两个边长为 \(a - b\) 的正方形未被覆盖。用代数表示，就是 \((2b - a)^2 - 2(a - b)^2 = 2b^2 - a^2 = 0\)。

1.4 \(e\) 是无理数，\(e^2\) 也是

  1. 若 \(\frac1e = \frac pq\)，把 \(\frac1e = \sum_{k \geq 0}\frac{(-1)^k}{k!}\) 乘以 \(q!\)。\(k \leq q\) 的各项都是整数，而尾部 \(\sum_{k > q}(-1)^kq!/k!\) 是各项递减的交错级数（alternating series），所以其绝对值严格介乎 \(0\) 与 \(\frac{1}{q+1}\) 之间。因此 \(q!/e\) 不是整数：矛盾。

  2. 若 \(\sin 1 = \frac pq\)，取 \(2n + 1 \geq q\)，两边乘以 \((2n + 1)!\)。左边是整数，级数中直至 \(\frac{1}{(2n+1)!}\) 的各项也是整数；尾部是交错级数，首项的大小为 \(\frac{1}{(2n+2)(2n+3)} < 1\)，所以它不是整数。

  3. 这个方法需要一个各项均为有理数（rational）的级数，而且其尾部缩小的速度要比分母增长的速度快，就像 \(\frac{1}{k!}\) 那样；对于 \(\pi\)，目前并不知道有这样的级数。Niven 的证明用到 \(\int_0^\pi\frac{x^n(\pi - x)^n}{n!}\sin x\,\mathrm{d}x\)：假如 \(\pi\) 是有理数，当 \(n\) 足够大时，这个积分就会是一个小于 \(1\) 的正整数。

  4. \(x^2 - (e + \pi)x + e\pi\) 的根是 \(e\) 和 \(\pi\)。假如 \(e + \pi\) 和 \(e\pi\) 都是代数数（algebraic number），\(\pi\) 就是一个代数系数多项式的根，因而也是代数数，这与林德曼（Lindemann）定理矛盾。

1.5 无穷递降法

  1. \(3 \mid a\)；设 \(a = 3a_1\)，得 \(9a_1^3 + b^3 = 3c^3\)，所以 \(3 \mid b\)，于是 \(3a_1^3 + 9b_1^3 = c^3\)，所以 \(3 \mid c\)，而 \((a_1, b_1, c_1)\) 是一个更小的解：这就是递降（descent）。至于 \(p^4 + 2q^4 = 5r^4\)：四次方数模（modulo）\(5\) 只能是 \(0\) 或 \(1\)（它们的末位数字是 \(0\)、\(1\)、\(5\) 或 \(6\)），所以 \(p^4 + 2q^4 \equiv 0\) 迫使 \(5 \mid p\) 且 \(5 \mid q\)；于是 \(5^4 \mid 5r^4\)，所以 \(5 \mid r\)，同样可以递降。

  2. 平方数模 \(4\) 只能是 \(0\) 或 \(1\)，所以 \(x^2 + y^2\) 只能是 \(0\)、\(1\) 或 \(2\)，绝不会是 \(3\)。

  3. 若有有理点 \((\frac ac, \frac bc)\)，便会得到 \(a^2 + b^2 = 3c^2\)，其中 \(c \neq 0\)，而第 (iii) 部分已排除这个可能。

  4. 固定 \(x\)、\(y\) 时，方程是二次方程 \(z^2 - 3xyz + (x^2 + y^2) = 0\)，其两根之和为 \(3xy\)。由 \((1,1,1)\) 出发：得 \((1,1,2)\)；把 \((1, 2)\) 所对的那个 \(1\) 换掉，得 \(3 \cdot 1 \cdot 2 - 1 = 5\)，即 \((1,2,5)\)；然后是 \((1,5,13)\) 和 \((2,5,29)\)。

1.6 两个平方数之和

  1. 平方数模 \(4\) 只能是 \(0\) 或 \(1\)，所以两个平方数之和模 \(4\) 绝不会是 \(3\)。

  2. \(65 = 1^2 + 8^2 = 4^2 + 7^2\) 及 \(85 = 2^2 + 9^2 = 6^2 + 7^2\)。利用 \(65 = (2 + \mathrm{i})(2 - \mathrm{i})(3 + 2\mathrm{i})(3 - 2\mathrm{i})\)：\((2 + \mathrm{i})(3 + 2\mathrm{i}) = 4 + 7\mathrm{i}\) 及 \((2 + \mathrm{i})(3 - 2\mathrm{i}) = 8 - \mathrm{i}\)。同理，对于 \(85\)，\((2 + \mathrm{i})(4 \pm \mathrm{i})\) 给出 \(7 + 6\mathrm{i}\) 和 \(9 - 2\mathrm{i}\)。

  3. \(1105 = 4^2 + 33^2 = 9^2 + 32^2 = 12^2 + 31^2 = 23^2 + 24^2\)。\(5\)、\(13\)、\(17\) 各自都可分解为一个高斯整数（Gaussian integer）与其共轭（conjugate）之积；从每一对中各选一个因数，共得 \(8\) 个乘积，它们两两互为共轭（给出相同的平方和），所以剩下 \(4\) 个。

  4. 取模的平方，得 \(9 = (a^2 + b^2)(c^2 + d^2)\)。由于 \(3\) 不是两个平方数之和，其中一个因数必为 \(1\)。

1.7 因数分解失效之时

  1. \(693 = 9 \times 77 = 21 \times 33\)，四个因数全是 \(S\)-质数。方法：取四个形如 \(4k + 3\) 的质数 \(p, q, r, s\)；那么 \((pq)(rs) = (pr)(qs)\) 就给出两种分解为 \(S\)-质数的方式。

  2. \(E\)-质数就是形如 \(2 \pmod 4\) 的数（它们不可能是两个偶数之积）。\(60 = 2 \times 30 = 6 \times 10\)。

  3. 展开 \((ac - 5bd)^2 + 5(ad + bc)^2\) 即得 \(N(zw) = N(z)N(w)\)。\(a^2 + 5b^2\) 绝不会等于 \(2\) 或 \(3\)。由于 \(N(2) = 4\)、\(N(3) = 9\) 及 \(N(1 \pm \sqrt{-5}) = 6\)，若要分解为非单位（non-unit）之积，就需要一个范数（norm）为 \(2\) 或 \(3\) 的因数。

  4. 设 \(n\) 是具有两种不同分解 \(p_1\cdots p_r = q_1\cdots q_s\) 的最小的数。根据欧几里得（Euclid）引理，\(p_1\) 整除某个 \(q_j\)，所以 \(p_1 = q_j\)；约去后得到一个更小而又有两种不同分解的数，矛盾。

1.8 计数有理数

  1. \(\frac35\)：逐级追溯其父节点，\((3, 5) \leftarrow (3, 2) \leftarrow (1, 2) \leftarrow (1, 1)\)，对应的位置为 \(1 \to 2 \to 5 \to 10\)，所以 \(f(10) = \frac35\)。\(\frac53\)：\((5, 3) \leftarrow (2, 3) \leftarrow (2, 1) \leftarrow (1, 1)\)，位置为 \(1 \to 3 \to 6 \to 13\)，所以 \(f(13) = \frac53\)。

  2. Newman 的法则 \(x_{n+1} = \frac{1}{2\lfloor x_n\rfloor - x_n + 1}\) 给出 \(1\)、\(\frac12\)、\(2\)、\(\frac13\)、\(\frac32\)、\(\frac23\)、\(3\)、\(\frac14\)、\(\frac43\)、\(\frac35\)，与 \(f(1), \ldots, f(10)\) 吻合。

  3. 第 \(n\) 位数字一律取 \(5\)，除非第 \(n\) 个数的第 \(n\) 位数字是 \(5\)，这时则取 \(4\)。新的小数与列表中每一个数都不相同，而且由于避开了 \(0\) 和 \(9\)，它只有一种小数展开式，所以确实是一个不同的数。

  4. 每个正整数都可唯一地写成 \(2\) 的幂乘以一个奇数，即 \(2^{m-1}(2n - 1)\)，所以 \((m, n) \mapsto 2^{m-1}(2n - 1)\) 是一个双射（bijection）。

1.9 三次曲线的切线

  1. 把 \(y = t(x + 1)\) 代入 \(x^2 + y^2 = 1\)，得 \((1 + t^2)x^2 + 2t^2x + t^2 - 1 = 0\)，其根为 \(-1\) 和 \(\frac{1 - t^2}{1 + t^2}\)。取 \(t = \frac qp\)，该点为 \(\bigl(\frac{p^2 - q^2}{p^2 + q^2}, \frac{2pq}{p^2 + q^2}\bigr)\)，由此得到三元数组 \((p^2 - q^2, 2pq, p^2 + q^2)\)。

  2. 该直线为 \(x + y = 3\)，而 \(x^3 + (3 - x)^3 = 9\) 可化简为 \(9x^2 - 27x + 18 = 0\)：三次项互相抵消，只剩下 \(x = 1, 2\)。这条直线与渐近线（asymptote）\(y = -x\) 平行，第三个交点在无穷远处。

  3. 切线（tangent）的斜率（gradient）为 \(\frac{x^2}{y^2} = \frac{289}{400}\)，它与曲线再相交于 \(\bigl(-\frac{188479}{90391}, -\frac{36520}{90391}\bigr)\)。去分母后，得 \(188479^3 = 36520^3 + 90391^3 + 180782^3\)。

  4. 该直线与 \(x^3 + y^3 = 1729\) 再相交于 \(\bigl(-\frac{37}{3}, \frac{46}{3}\bigr)\)，所以 \(46^3 = 37^3 + 27 \times 1729 = 37^3 + 3^3 + 36^3\)（这里用到 \(27 = 3^3\) 和 \(27 \times 1728 = 36^3\)）。
