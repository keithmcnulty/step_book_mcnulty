质数分布得有多稀疏？

题目

STEP III 2016，第 5 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/16-s3-q5

引子

在 第 1.1 节 中，我们已看到质数（prime）有无穷多个。但“无穷多个”是个很粗略的说法。质数确实愈来愈稀疏：\(100\) 以下有 \(25\) 个质数，但 \(900\) 与 \(1000\) 之间只有 \(14\) 个。它们究竟会稀疏到甚么程度？

这道题要证明的结论听来相当平凡：把不超过 \(n\) 的所有质数相乘，所得的积小于 \(4^n\)。然而，这个看似平平无奇的不等式（inequality），正是回答“有多稀疏？”的第一步实质进展，也是数学史上最著名的简短证明之一的关键引理（lemma）；该证明出自年轻的保罗·艾狄胥（Paul Erdős）之手，时为 1932 年。

动笔之前

记号 \(P_{r,s}\) 看来有点繁琐，但背后的意思很简单：把某个范围内的质数相乘。务必先弄懂题中的例子。\(P_{3,7}\) 用的是大于 \(3\) 而不超过 \(7\) 的质数，即 \(5\) 和 \(7\)，所以它等于 \(35\)。

第 (iv) 部分要求你对所有 \(n \geq 2\) 证明一个命题。第 (iii) 部分则假设该命题对不超过 \(2m\) 的每一个 \(k\) 都成立。这是哪一种归纳法（induction）？

这是强归纳法（strong induction）：要证明 \(n\) 的情况，你可以假设前面所有情况都成立，而不仅是紧接在前的那一个。请把这一点记在心里；题目之所以这样编排，原因正在于此。

逐步解题

阶段 1 二项式系数不会太大

在 \((1+x)^{2m+1}\) 的二项展开式（binomial expansion）中代入 \(x = 1\)，会得到甚么？

你会得到 \[2^{2m+1} = \binom{2m+1}{0} + \binom{2m+1}{1} + \cdots + \binom{2m+1}{2m+1}.\] 各项都是正数，所以每一项都小于 \(2^{2m+1}\)。这还不够好；我们想要的是 \(2^{2m}\)，即它的一半。

帕斯卡三角形（Pascal’s triangle）是对称的。和式中还有哪一项等于 \(\binom{2m+1}{m}\)？

由对称性，\(\binom{2m+1}{m} = \binom{2m+1}{m+1}\)，而这是和式中两个不同的项（因为 \(m \neq m+1\)）。所以 \[2\binom{2m+1}{m} = \binom{2m+1}{m} + \binom{2m+1}{m+1} < 2^{2m+1},\] 这里是严格不等式，因为和式中还有其他正项，例如 \(\binom{2m+1}{0} = 1\)。两边除以 \(2\)，即得 \(\binom{2m+1}{m} < 2^{2m}\)。■

阶段 2 哪些质数整除这个二项式系数？

把这个二项式系数（binomial coefficient）写出来： \[\binom{2m+1}{m} = \frac{(2m+1)!}{m!\,(m+1)!} = \frac{(m+2)(m+3)\cdots(2m+1)}{m!}.\]

设 \(p\) 为质数，且 \(m + 1 < p \leq 2m+1\)。\(p\) 整除分子吗？它有可能整除分母吗？

分子 \((m+2)(m+3)\cdots(2m+1)\) 的因子当中就有 \(p\) 本身，所以 \(p\) 整除分子。分母 \(m!\) 是若干个数的积，而这些数全都小于 \(p\)；由于 \(p\) 是质数，如果它不能整除其中任何一个数，就不能整除它们的积。因此 \(p\) 整除分子而不整除分母，于是 \(p\) 整除整个二项式系数（别忘记，它是一个整数）。

我们现在知道，这个范围内的每一个质数都整除 \(\binom{2m+1}{m}\)。为甚么由此可知它们的积 \(P_{m+1,2m+1}\) 也整除它？（小心：即使 \(4\) 和 \(6\) 都整除某个数，\(24\) 也不一定整除它。）

分别在于，我们的质数是相异质数。如果相异质数 \(p_1, p_2, \ldots\) 各自整除 \(N\)，那么它们的积也整除 \(N\)：写 \(N = p_1 N_1\)；这时 \(p_2\) 整除 \(p_1 N_1\) 但不整除 \(p_1\)，所以它整除 \(N_1\)；如此类推。（这里用到一个事实：如果一个质数整除某个积，它必整除其中一个因子。这个事实值得我们稍加敬重；第 1.7 节 会展示一个世界，在那里与它相应的命题并不成立。）

所以 \(P_{m+1,2m+1}\) 整除 \(\binom{2m+1}{m}\)，而正数的因数不会大于该数本身，故 \[P_{m+1,\,2m+1} \leq \binom{2m+1}{m} < 2^{2m}. \qed\]

阶段 3 把积拆开

\(P_{1,2m+1}\) 是不超过 \(2m+1\) 的所有质数的积，怎样用我们已经掌握的积把它拼出来？

把不超过 \(2m+1\) 的质数分成两批：不超过 \(m+1\) 的，以及大于 \(m+1\) 的： \[P_{1,2m+1} = P_{1,m+1} \times P_{m+1,2m+1}.\] 由第 2 阶段，第二个因子小于 \(2^{2m} = 4^m\)。至于第一个因子，我们可以假设 \(P_{1,k} < 4^k\) 对由 \(2\) 至 \(2m\) 的每一个 \(k\) 都成立，而 \(k = m+1\) 正在这个范围之内（因为由 \(m \geq 1\) 可得 \(2 \leq m+1 \leq 2m\)）。所以 \[P_{1,2m+1} < 4^{m+1} \times 4^{m} = 4^{2m+1}. \qed\] 强归纳法正是在这里大派用场：要处理 \(2m+1\)，我们需要的是 \(m+1\) 的情况，它的大小约为一半，而不是紧接在前的那个情况。

阶段 4 所有 \(n\)

第 (iii) 部分处理了奇数。对于偶数 \(n = 2m+2\)，情况又如何？它是质数吗？

先验证起始情况：\(P_{1,2} = 2 < 16\) 及 \(P_{1,3} = 6 < 64\)。现在假设 \(P_{1,k} < 4^k\) 对由 \(2\) 至 \(n-1\) 的所有 \(k\) 都成立，其中 \(n \geq 4\)。

  • 若 \(n\) 是偶数，则 \(n\) 不是质数（因为它大于 \(2\)），所以不超过 \(n\) 的质数与不超过 \(n-1\) 的质数完全相同。因此 \(P_{1,n} = P_{1,n-1} < 4^{n-1} < 4^n\)。

  • 若 \(n\) 是奇数，写 \(n = 2m+1\)，其中 \(m \geq 2\)。这时由第 (iii) 部分直接得出 \(P_{1,n} < 4^n\)。

由强归纳法，\(P_{1,n} < 4^n\) 对每一个 \(n \geq 2\) 都成立。■

回顾

  • 二项式系数蕴藏算术信息。\(\binom{2m+1}{m}\) 是单独一个数，它不大（小于 \(4^m\)），却必须被许多质数整除。把许多质数挤进一个不大的数里，就说明这些质数不可能太多。

  • 当问题会把自己减半时，强归纳法是最自然的工具。\(2m+1\) 的情况取决于 \(m+1\) 的情况。

  • 小的情况须另行验证。归纳要到 \(n \geq 4\) 才能开始运作，所以 \(n = 2\) 和 \(3\) 必须亲手计算。

背后的数学

从 \(4^n\) 到质数定理

对结果取对数：\(\ln P_{1,n} < n \ln 4\)，即 \[\sum_{p \leq n} \ln p < (\ln 4)\, n \approx 1.39\,n .\] 在 1850 年代，切比雪夫（Pafnuty Chebyshev）证明了正是这一类的界（bound），而且上界和下界俱备，从而说明 \(\sum_{p \leq n} \ln p\) 的增长与 \(n\) 成正比。高斯（Gauss）在大约 15 岁时，已从数表中猜到不超过 \(n\) 的质数个数大约是 \(n / \ln n\)。这后来成为质数定理（Prime Number Theorem），最终在 1896 年由阿达马（Jacques Hadamard）和德拉瓦莱普桑（Charles de la Vallée Poussin）运用复分析（complex analysis）证明。它的对数形式是 \[\sum_{p \leq n} \ln p \sim n,\] 所以不超过 \(n\) 的质数之积大约是 \(e^n\)。我们的界 \(4^n\) 其实相差不远：图 1.2.1 把三者一并画出。

伯特兰公设

1845 年，伯特兰（Joseph Bertrand）猜想：对每一个 \(n \geq 1\)，在 \(n\) 与 \(2n\) 之间总有一个质数。这就是伯特兰公设（Bertrand’s postulate）。切比雪夫在 1852 年证明了它。八十年后，年仅 19 岁的艾狄胥找到了一个优美的初等证明。它的关键材料，就是本题的引理，再加上仔细考察哪些质数整除中间的二项式系数 \(\binom{2n}{n}\)。Martin Aigner 和 Günter Ziegler 把它选为 Proofs from THE BOOK 的第 2 章，该书汇集了数学中最优雅的证明。

接下来的方向

质数的精确分布，由黎曼 ζ 函数（Riemann zeta function） \[\zeta(s) = 1 + \frac{1}{2^s} + \frac{1}{3^s} + \cdots,\] 的零点（zero）所支配。你会在 第 2.4 节 中遇见这个函数朴素得多的一面，那里有 \(\zeta(2) = \pi^2/6\)。黎曼猜想（Riemann Hypothesis）预测了这些零点的确切位置；它若成立，便能把质数定理中的误差限定得紧无可紧。它也许是数学中最著名的未解难题，也是千禧年大奖难题（Millennium Prize Problems）之一。

思维技巧

强归纳法，以及从巧妙的对象中提取信息

如果 \(n\) 的情况取决于远小于 \(n-1\) 的情况，就一次过假设前面所有情况都成立。

这里的另一个想法较为微妙，也极具数论（number theory）的特色：要证明某个范围内所有质数的某种性质，就找出一个对象（这里是一个二项式系数），使得这些质数每一个都必须整除它，而你又能证明它不会太大。

延伸练习

  1. 感受一下数字。对 \(n = 10, 20, 30\) 计算 \(P_{1,n}\)，并把它与 \(4^n\) 及 \(e^n\) 比较。（这里可以使用计算机。）

  2. 中间的二项式系数。证明 \(\binom{2m}{m}\) 是 \((1+1)^{2m}\) 展开式的 \(2m+1\) 项中最大的一项，并由此推出 \(\binom{2m}{m} \geq \dfrac{4^m}{2m+1}\)。

  3. 质数不会太多。设 \(\pi(n)\) 为不超过 \(n\) 的质数个数。介乎 \(\sqrt n\) 与 \(n\) 之间的每个质数都大于 \(\sqrt n\)，而它们的积至多为 \(P_{1,n} < 4^n\)。由此推出 \[\pi(n) - \pi(\sqrt n) < \frac{2\ln 4}{\ln n}\, n ,\] 从而得出 \(\pi(n) < 2.8\, n/\ln n + \sqrt n\)。把这个结果与质数定理的 \(\pi(n) \approx n / \ln n\) 比较。

  4. 验证伯特兰公设。对 \(n = 1, 2, \ldots, 50\) 验证伯特兰公设，即在每个情况下找出一个介乎 \(n\) 与 \(2n\) 之间的质数。你能否利用一张简短的质数表有效率地完成，使表中每个质数都小于前一个的两倍？
