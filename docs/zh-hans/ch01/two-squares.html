两个平方数之和

题目

STEP II 2023，第 7 题

继续之前，请先阅读题目（原题为英文）。题目载于 OCR 提供下载的 2023 年 STEP 试卷（zip 文件）内的 STEP II 试卷： www.ocr.org.uk/Images/707102-2023-past-papers.zip

引子

哪些整数可以写成两个平方数之和？\(5 = 1^2 + 2^2\) 和 \(13 = 2^2 + 3^2\) 可以，但 \(3\)、\(7\) 和 \(21\) 却不行。这里有一个奇怪的事实：\(65 = 5 \times 13\) 可以用两种不同的方法写成两个平方数之和，即 \(1^2 + 8^2\) 和 \(4^2 + 7^2\)。为甚么两个这样的数相乘，会得出另一个这样的数？又为甚么会有两种写法？

答案来自一个意想不到的方向。这道题目要你放下整数，改用复数（complex number）来思考。在复数的世界里，两平方和变得很简单，一些看似令人摸不着头脑的算术也变得近乎机械化。

动笔之前

若 \(z = a + \mathrm{i}b\)，其中 \(a\) 和 \(b\) 为整数，那么 \(|z|^2\) 是甚么？

它是 \(a^2 + b^2\)，即两个平方数之和。所以“\(N\) 是两个平方数之和”的意思正正就是“存在某个实部（real part）和虚部（imaginary part）皆为整数的复数 \(z\)，使得 \(N = |z|^2\)”。这样的复数称为高斯整数（Gaussian integer）。请牢记这个转译；整道题目都建基于此。

逐步解题

阶段 1 模相乘

以 \(a\)、\(b\)、\(c\)、\(d\) 写出 \(zw\)。关于 \(|zw|^2\)，你需要证明甚么？

我们有 \(zw = (ac - bd) + \mathrm{i}(ad + bc)\)，所以 \[|zw|^2 = (ac - bd)^2 + (ad + bc)^2 = a^2c^2 + b^2d^2 + a^2d^2 + b^2c^2,\] 因为交叉项 \(-2abcd\) 和 \(+2abcd\) 互相抵消。而这个式子可以因式分解（factorise）： \[a^2c^2 + b^2d^2 + a^2d^2 + b^2c^2 = (a^2 + b^2)(c^2 + d^2) = |z|^2|w|^2.\] 取平方根，得 \(|zw| = |z||w|\)。■

现在把它看成一个关于整数的命题： \[(a^2 + b^2)(c^2 + d^2) = (ac - bd)^2 + (ad + bc)^2. \tag{$\star$}\] 两个两平方和的乘积，仍是一个两平方和，而复数更确切地告诉你那两个平方数是甚么。

阶段 2 学以致用

第 (ii) 部分：\(5 = |2 + \mathrm{i}|^2\)，而 \(221 = 10^2 + 11^2 = |10 + 11\mathrm{i}|^2\)。于是相乘： \[(2 + \mathrm{i})(10 + 11\mathrm{i}) = 20 + 22\mathrm{i} + 10\mathrm{i} - 11 = 9 + 32\mathrm{i},\] 得出 \(5 \times 221 = 9^2 + 32^2\)。（验算：\(81 + 1024 = 1105\)。）

如果改为把 \(10 + 11\mathrm{i}\) 乘以 \(2 - \mathrm{i}\)，会怎么样？它的模（modulus）与 \(2 + \mathrm{i}\) 的相同。

\((2 - \mathrm{i})(10 + 11\mathrm{i}) = 20 + 22\mathrm{i} - 10\mathrm{i} + 11 = 31 + 12\mathrm{i}\)，所以同样有 \(1105 = 31^2 + 12^2\)。选用 \(2 + \mathrm{i}\) 还是它的共轭（conjugate），会得出不同的表示法。这就解释了引子中 \(65\) 的两种写法（图 1.6.1）：\(65 = |(2+\mathrm{i})(3+2\mathrm{i})|^2 = |4 + 7\mathrm{i}|^2\) 以及 \(65 = |(2-\mathrm{i})(3+2\mathrm{i})|^2 = |8 + \mathrm{i}|^2\)。

阶段 3 先作因式分解

\(8045\) 的末位数字是 \(5\)。这提示了甚么？

\(8045 = 5 \times 1609\)。我们需要把 \(1609\) 写成两个平方数之和；试试略小于 \(1609\) 的平方数，很快便找到 \(1609 = 40^2 + 3^2\)。于是 \[(2 + \mathrm{i})(40 + 3\mathrm{i}) = 77 + 46\mathrm{i}, \qquad\text{所以}\qquad 8045 = 77^2 + 46^2,\] 而共轭亦给出 \(8045 = 83^2 + 34^2\)。

第 (iv) 部分更快：\(36 = 6^2 + 0^2\)，而乘以 \(6\) 只是按比例放大：\(36 \times 50805 = 612^2 + 1206^2\)。

阶段 4 三种写法

\(25\) 可以用多于一种方法写成两个平方数之和。若不计正负号和次序对调，有多少个高斯整数的模为 \(5\)？

\(25 = 5^2 + 0^2 = 3^2 + 4^2\)，分别对应 \(5\)、\(3 + 4\mathrm{i}\) 和 \(3 - 4\mathrm{i}\)。接着看 \(1002082\)：由于 \(1001^2 = 1002001\)，我们有 \(1002082 = 1001^2 + 9^2\)。把 \(1001 + 9\mathrm{i}\) 分别乘以这三个数，得： \[\begin{aligned} 5\,(1001 + 9\mathrm{i}) &= 5005 + 45\mathrm{i}, \\ (3 + 4\mathrm{i})(1001 + 9\mathrm{i}) &= 2967 + 4031\mathrm{i}, \\ (3 - 4\mathrm{i})(1001 + 9\mathrm{i}) &= 3039 - 3977\mathrm{i}. \end{aligned}\] 所以三对 \((r, s)\) 是 \((45, 5005)\)、\((2967, 4031)\) 和 \((3039, 3977)\)。

阶段 5 除法

第 (vi) 部分把这部机器倒过来运转。我们知道 \(109 = 10^2 + 3^2\) 和 \(1002037 = 1001^2 + 6^2\)。怎样才能不靠搜索，就把 \(9193\) 写成两个平方数之和？

既然高斯整数相乘时模会相乘，那么相除时模就应该相除。试试 \[\frac{1001 + 6\mathrm{i}}{10 + 3\mathrm{i}} = \frac{(1001 + 6\mathrm{i})(10 - 3\mathrm{i})}{109} = \frac{10028 - 2943\mathrm{i}}{109} = 92 - 27\mathrm{i}.\] 刚好整除，所以 \(9193 = 92^2 + 27^2\)。（验算：\(8464 + 729 = 9193\)。）

如果改为除以 \(10 - 3\mathrm{i}\)，会怎么样？

你会得到 \((1001 + 6\mathrm{i})(10 + 3\mathrm{i})/109 = (9992 + 3063\mathrm{i})/109\)，这不是高斯整数，因为 \(9992/109\) 不是整数。在 \(109\) 的两个“因数”之中，只有一个能整除 \(1001 + 6\mathrm{i}\)，正如只有某些质数（prime）能整除一个给定的整数。高斯整数有它们自己的质数，也有它们自己的因式分解。

回顾

  • 转译、求解、再译回来。“两个平方数之和”变成了“高斯整数的模的平方”。用这种语言来说，问题就变得容易。

  • 先作因式分解。每一部分都是先把一个大数拆成较小的数，而这些较小的数的表示法很容易找到。

  • 共轭带来新答案。表示法的数目，取决于有多少种方法选择一个因数或它的共轭。

背后的数学

费马二平方和定理

哪些质数是两个平方数之和？\(2 = 1^2 + 1^2\)、\(5\)、\(13\)、\(17\)、\(29\)、\(37\)、\(41\) 是；\(3\)、\(7\)、\(11\)、\(19\)、\(23\)、\(31\) 则不是。规律是：除 \(2\) 以外，一个质数是两个平方数之和，当且仅当它除以 \(4\) 的余数为 \(1\)。费马（Fermat）于 1640 年提出这个结果；欧拉（Euler）于 1749 年给出证明。用高斯整数的语言来说：质数 \(p \equiv 1 \pmod 4\) 会分裂（split）成 \(p = (a + b\mathrm{i})(a - b\mathrm{i})\)，而质数 \(p \equiv 3 \pmod 4\) 则仍然是质数。例如 \(5 = (2 + \mathrm{i})(2 - \mathrm{i})\)，但 \(3\) 完全无法分解。

1990 年，Don Zagier 发表了二平方和定理的一个证明，它以全长只有一句而闻名。这个证明连同解说收录于 Proofs from THE BOOK。

一个拥有自己质数的新数系

高斯（Gauss）发现，高斯整数的表现与普通整数极为相似。它们有除法算法（division algorithm）和欧几里得算法（Euclidean algorithm），而且每个高斯整数都可以唯一地分解成高斯质数（Gaussian prime）的乘积（不计乘以 \(\pm1\) 或 \(\pm\mathrm{i}\) 的差别）。结合 \((\star)\)，你只需知道一个数的质因数分解，就能准确数出它有多少种方法写成两个平方数之和。

在大学里，这是通往代数数论（algebraic number theory）的大门：研究 \(\mathbb{Z}[\mathrm{i}]\) 或 \(\mathbb{Z}[\sqrt{-5}]\) 这类数系，借此了解普通的整数。第 1.7 节 说明了为甚么需要创立这门学科：并非每个这样的数系都像高斯整数那样规矩。

四个平方数及其他

每个正整数都是四个平方数之和（拉格朗日（Lagrange），1770 年）。证明依赖 \((\star)\) 的四平方版本，它源自哈密顿（Hamilton）的四元数（quaternion），情形就如 \((\star)\) 源自复数一样。你会在 第 7.8 节 见到它。

思维技巧

转换场景

一个问题在某个数系中显得棘手，在一个更大的数系中却可能十分自然。

两平方和在整数中很棘手，在复数中却不过是模而已。数学家经常这样扩大数系：由整数到有理数，由有理数到实数，由实数到复数。每次扩大，都会令一些旧问题变得容易。

延伸练习

  1. 一个障碍。证明没有任何形如 \(4k + 3\) 的数是两个平方数之和。（平方数模 \(4\) 是甚么？）

  2. 两种写法。把 \(65\) 和 \(85\) 各自用两种不同的方法写成两个平方数之和，并用高斯整数解释你的答案。

  3. 四种写法。\(1105 = 5 \times 13 \times 17\)。找出四种不同的方法，把 \(1105\) 写成两个正平方数之和。为甚么是四种？

  4. 高斯质数。 较难 证明若 \(3 = (a + b\mathrm{i})(c + d\mathrm{i})\)，其中 \(a, b, c, d\) 为整数，则其中一个因数的模为 \(1\)。（取模的平方。）这说明 \(3\) 是高斯质数。

延伸阅读

  • John Stillwell, Elements of Number Theory（Springer）。循序渐进讲到高斯整数及更深入的内容，并附历史背景。

  • Aigner & Ziegler, Proofs from THE BOOK，第 4 章，“Representing numbers as sums of two squares”（把数表示为两个平方数之和）。

  • Joseph Silverman, A Friendly Introduction to Number Theory，有关平方和与高斯整数的各章。
