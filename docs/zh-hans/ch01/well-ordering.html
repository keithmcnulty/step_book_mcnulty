STEP III 2015，第 5 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/15-s3-q5

引子

你大概见过 \(\sqrt2\) 是无理数（irrational）的证明：假设 \(\sqrt2 = a/b\) 为最简分数（lowest terms），两边平方，推出 \(a\) 是偶数，继而推出 \(b\) 也是偶数，于是得出矛盾（contradiction）。这是个漂亮的证明，但它依赖一个关于偶数的技巧，而这个技巧看不出可以怎样推广。换成 \(\sqrt[3]{2}\) 又如何？\(\sqrt{7}\) 呢？

本题给出另一个证明，它的核心想法简单得近乎荒谬：看看最小的那一个。在本章里，同一个想法还会改头换面地出现好几次。

动笔之前

这是一道不寻常的 STEP 题目：它给你一个证明的骨架，要你补上当中欠缺的理据。大学生正是这样学习阅读数学的。课本里的证明常常说“显然”或“由此可得”，而你的部分工作，就是查证事实是否真的如此。

第 4 步说“定义 \(k\) 为 \(S\) 中最小的正整数”。我们凭甚么可以这样做？假如 \(S\) 是一个由正实数组成的集合，这样做还可以吗？

任何由正整数组成的非空集合都有最小元素。这称为良序原理（well-ordering principle），它与数学归纳法（mathematical induction）原理等价。对于由正实数组成的集合，这个原理并不成立：集合 \(\{x : x > 0\}\) 就没有最小元素。所以第 4 步既依赖第 3 步（集合必须非空），也依赖 \(S\) 由整数组成这一点。

逐步解题

阶段 1 第 3 步：\(S\) 非空

若 \(\sqrt2 = a/b\)，其中 \(a\) 和 \(b\) 是正整数，你能写出 \(S\) 的一个元素吗？

若 \(\sqrt2 = a/b\)，则 \(b\sqrt2 = a\)，是一个整数。所以 \(b\) 属于 \(S\)，\(S\) 非空。

阶段 2 第 5 步：一个更小的元素

现在 \(k\) 是 \(S\) 的最小元素，所以 \(k\sqrt2\) 是整数，记为 \(j\)。

要证明 \((\sqrt2 - 1)k\) 属于 \(S\)，你必须检查三件事。是哪三件？

我们需要 \((\sqrt2-1)k\) 满足：(a) 是整数；(b) 是正数；(c) 乘以 \(\sqrt2\) 后得到整数。

  • (a) \((\sqrt2 - 1)k = k\sqrt2 - k = j - k\)，是两个整数之差。

  • (b) \(\sqrt2 > 1\)，所以 \(\sqrt2 - 1 > 0\)，因此 \((\sqrt2-1)k > 0\)。

  • (c) \((\sqrt2-1)k \cdot \sqrt2 = 2k - k\sqrt2 = 2k - j\)，是整数。

所以 \((\sqrt2 - 1)k \in S\)。

阶段 3 第 6 步：矛盾

\(\sqrt2 - 1\) 有多大？

由于 \(1 < \sqrt2 < 2\)，我们有 \(0 < \sqrt2 - 1 < 1\)，所以 \((\sqrt2 - 1)k < k\)。我们找到了 \(S\) 的一个元素，它比 \(S\) 的最小元素 \(k\) 还要小。这是不可能的，所以第 1 步的假设不成立：\(\sqrt2\) 是无理数。■

留意我们从头到尾都不需要“最简分数”，也不需要任何关于奇偶数的事实。整个证明只建基于三个事实：\(\sqrt2 \cdot \sqrt2\) 是整数；\(\sqrt2\) 严格地介乎两个连续整数之间；整数具有良序性。

阶段 4 立方根：把两个数联系起来

设 \(c = 2^{1/3}\)，则 \(c^2 = 2^{2/3}\) 且 \(c^3 = 2\)。

若 \(c\) 是有理数（rational），\(c^2\) 是否也是？反过来，若 \(c^2\) 是有理数，你能否只用乘法和除法回到 \(c\)？

若 \(c\) 是有理数，则 \(c^2 = c \times c\) 也是有理数。反之，若 \(c^2\) 是有理数，则 \(2 / c^2 = c^3 / c^2 = c\) 也是有理数。所以 \(2^{1/3}\) 是有理数，当且仅当 \(2^{2/3}\) 是有理数。■

阶段 5 改造论证

在第 (i) 部分，关键在于 \((\sqrt2)^2 = 2\) 是整数，所以把 \(S\) 的元素乘以 \(\sqrt2\) 两次，就会回到整数。对于 \(c = 2^{1/3}\)，你需要乘三次。集合 \(S\) 应该怎样修改？

假设 \(c\) 是有理数，则 \(c^2\) 也是。定义 \[S = \{ n \text{ 为正整数} : nc \text{ 和 } nc^2 \text{ 都是整数} \}.\]

  • \(S\) 非空。若 \(c = a/b\) 且 \(c^2 = a'/b'\)，则 \(bb'\) 属于 \(S\)。

  • 设 \(k\) 为它的最小元素，并考虑 \((c - 1)k\)。我们有 \(1 < c < 2\)（因为 \(1^3 < 2 < 2^3\)），所以 \(0 < (c-1)k < k\)。

  • 它是整数：\((c-1)k = kc - k\)。

  • 乘以 \(c\)：\((c-1)k \cdot c = kc^2 - kc\)，是整数。

  • 乘以 \(c^2\)：\((c-1)k \cdot c^2 = kc^3 - kc^2 = 2k - kc^2\)，是整数。

所以 \((c-1)k \in S\)，而且比 \(k\) 小：矛盾。因此 \(2^{1/3}\) 是无理数，而根据第 4 阶段，\(2^{2/3}\) 也是无理数。■

回顾

  • “取最小的那一个”是一种证明技巧。假设反例存在，取其中最小的一个，再由它造出一个更小的。这称为极端原理（extremal principle），或称最小反例（minimal counterexample）论证。

  • 集合 \(S\) 替我们记帐。我们不必周旋于分子和分母之间，而是把所有“好”的乘数收进同一个集合。

  • 推广，就是追问证明真正行得通的原因。对于 \(\sqrt2\)，需要乘以 \(\sqrt2\) 一次；对于 \(\sqrt[3]{2}\)，则需要乘两次。看出这一点，我们就清楚知道该怎样重新定义 \(S\)。

背后的数学

一个画得出来的证明

第 (i) 部分背后有一幅优美的图，出自 Stanley Tennenbaum。若 \(\sqrt2 = a/b\)，则 \(a^2 = 2b^2\)：一个边长为 \(a\) 的正方形，面积等于两个边长为 \(b\) 的正方形面积之和。如图 1.3.1 所示，把两个边长为 \(b\) 的正方形放在边长为 \(a\) 的正方形的两个对角。它们重叠之处是一个小正方形，另外还有两个小正方形没有被盖住。由于面积相等，重叠部分必定等于两个未被盖住的正方形之和，于是得到一对更小而具有同样性质的整数。整数对不可能无止境地愈变愈小，所以这样的正方形并不存在。这对较小的整数正是 \((2b - a,\; a - b)\)，也就是我们那一步 \((\sqrt2 - 1)k\) 的化身。

良序、归纳与递降

良序原理与归纳法原理在逻辑上等价：两者可以互相推导。到了大学，你会看到两者都被用作自然数的基础。在 第 1.5 节 中，我们会以另一种形式运用同一个原理，那就是费马（Fermat）的无穷递降法（method of infinite descent）：不存在由正整数组成的无穷严格递减数列。

它能走多远？

这个论证可以证明，只要 \(N\) 不是完全平方数（perfect square），\(\sqrt N\) 就是无理数（见练习）；更一般地，一个整数的 \(n\) 次方根要么是整数，要么是无理数。到了大学，这会变成一个关于代数整数（algebraic integers）的命题：若一个有理数满足某个整数系数的首一多项式（monic polynomial）方程，例如 \(x^3 - 2 = 0\)，它就必定是整数。你会在 第 6.3 节 再次遇到这个想法。

相传毕达哥拉斯学派（Pythagoreans）因为希帕索斯（Hippasus）泄露了 \(\sqrt2\) 是无理数而把他淹死，这个传说多半并不属实。属实的是，这个发现迫使希腊数学家把对数的研究与对长度的研究分开；这道裂痕要等到十九世纪，待戴德金（Dedekind）构造出实数，才得以弥合。

思维技巧

极端原理

如果你想证明某件事永远不会发生，就假设它会发生，选出最小（或最大、或最简单）的例子，再用它造出一个更小的例子。

决定“最小”是甚么意思，正是需要创意的一步。在这里，它是使 \(n\sqrt2\) 成为整数的最小的 \(n\)。

延伸练习

  1. 其他平方根。改造这个论证，证明 \(\sqrt3\) 是无理数。哪一个数担当了 \(\sqrt2 - 1\) 的角色？

  2. 所有非平方数。设 \(N\) 为一个不是完全平方数的正整数，并设 \(m\) 为满足 \(m < \sqrt N < m+1\) 的整数。考虑 \((\sqrt N - m)k\)，从而证明 \(\sqrt N\) 是无理数。

  3. 找出漏洞。试把这个论证套用于 \(\sqrt 4\)。究竟是哪一步行不通？

  4. Tennenbaum 的图。利用图 1.3.1 证明：若 \(a^2 = 2b^2\)，则 \((2b-a)^2 = 2(a-b)^2\)。再用代数方法验证这个恒等式。
