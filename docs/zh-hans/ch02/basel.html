\(\pi^2/6\)

工作纸题目连结、提示、大学数学及练习 第 2 章整章的 PDF 版本
题目

STEP III 2018，第 7 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/18-s3-q7

引子

1650 年，Pietro Mengoli 提出了一个简单的问题： \[1 + \frac14 + \frac19 + \frac1{16} + \frac1{25} + \cdots\, ?\] 的值是甚么？各项缩小得够快，足以令这个和收敛（converge）（第 2.3 节 已证明它不超过 \(2\)），但没有人能求出它的值。伯努利（Bernoulli）兄弟试过，却无功而还；雅各布·伯努利（Jacob Bernoulli）更公开恳求他人相助。这个问题后来以伯努利兄弟的家乡命名，称为巴塞尔问题（Basel problem）。

1734 年，年轻的欧拉（Leonhard Euler）解决了这个问题，答案令他一举成名：这个和等于 \(\pi^2/6\)。\(\pi\) 明明是一个关于圆的数，究竟为甚么会出现在平方倒数之和里？本题给出一个完整而严格的证明，所用的工具全部不超出高级程度（A-level）的范围：棣美弗定理（De Moivre’s theorem）、多项式（polynomial）的根之和，以及夹逼（squeeze）。

动笔之前

在处理细节之前，值得先看看整体的计划。

  • 第 (i) 部分构造一个多项式，它的根就是 \(\cot^2\bigl(\frac{m\pi}{2n+1}\bigr)\) 这些数。

  • 第 (ii) 部分利用系数（coefficient），在不知道各个根的情况下把这些根加起来。

  • 第 (iii) 部分利用“当 \(\theta\) 很小时 \(\cot\theta \approx 1/\theta\)”这个事实，把 \(\cot^2\) 值之和变成 \(1/m^2\) 值之和，然后夹逼。

若多项式 \(a_n x^n + a_{n-1} x^{n-1} + \cdots + a_0\) 的根为 \(r_1, \ldots, r_n\)，那么 \(r_1 + \cdots + r_n\) 以系数表示是甚么？

答案是 \(-a_{n-1}/a_n\)。这个事实正是第 (ii) 部分的动力所在。

逐步解题

阶段 1 棣美弗定理

把 \(\cot\theta + \mathrm{i}\) 写成单一分数。你留意到分子有甚么特别？

\(\cot\theta + \mathrm{i} = \dfrac{\cos\theta + \mathrm{i}\sin\theta}{\sin\theta}\)，同样地 \(\cot\theta - \mathrm{i} = \dfrac{\cos\theta - \mathrm{i}\sin\theta}{\sin\theta}\)。根据棣美弗定理， \[(\cot\theta \pm \mathrm{i})^{2n+1} = \frac{\cos(2n+1)\theta \pm \mathrm{i}\sin(2n+1)\theta}{\sin^{2n+1}\theta}.\] 两式相减，余弦项互相抵消，正弦项则变成两倍，再除以 \(2\mathrm{i}\) 便得 \[\frac{\sin(2n+1)\theta}{\sin^{2n+1}\theta}. \qed\]

阶段 2 多项式

现在改用二项式定理（binomial theorem）展开左边。设 \(c = \cot\theta\) 及 \(N = 2n + 1\)。

在 \((c + \mathrm{i})^N - (c - \mathrm{i})^N\) 中，两个二项展开式有哪些项互相抵消，又有哪些项变成两倍？

含 \(\mathrm{i}^j\) 的项在第一个展开式中带 \(+\) 号，在第二个展开式中则带 \((-1)^j\)。因此 \(j\) 为偶数的项互相抵消，\(j\) 为奇数的项变成两倍： \[(c + \mathrm{i})^N - (c - \mathrm{i})^N = 2 \sum_{j \text{ 为奇数}} \binom{N}{j} c^{N-j}\, \mathrm{i}^j.\] 取 \(j = 2k + 1\)，则 \(\mathrm{i}^j = \mathrm{i}\,(-1)^k\) 及 \(c^{N-j} = c^{2n-2k} = (c^2)^{n-k}\)。除以 \(2\mathrm{i}\)，得 \[\frac{\sin(2n+1)\theta}{\sin^{2n+1}\theta} = \binom{2n+1}{1} x^n - \binom{2n+1}{3} x^{n-1} + \cdots + (-1)^n,\] 其中 \(x = \cot^2\theta\)。

左边在哪些 \(\theta\) 的值时等于零？利用这一点找出多项式的 \(n\) 个不同的根。

当 \(\sin(2n+1)\theta = 0\) 而 \(\sin\theta \neq 0\) 时，左边等于零，例如当 \(\theta = \frac{m\pi}{2n+1}\)，其中 \(m = 1, 2, \ldots, n\)。这些角全部严格介乎 \(0\) 与 \(\frac\pi2\) 之间，而 \(\cot\) 在这个范围内为正且严格递减，所以 \(\cot^2\bigl(\frac{m\pi}{2n+1}\bigr)\) 这 \(n\) 个值各不相同。\(n\) 次多项式最多有 \(n\) 个根，所以这些就是它的全部根。■

阶段 3 把根加起来

根之和等于 \(-(\text{以下一项的系数：} x^{n-1}) / (\text{以下一项的系数：} x^n)\)： \[\sum_{m=1}^{n} \cot^2\left( \frac{m\pi}{2n+1} \right) = \frac{\binom{2n+1}{3}}{\binom{2n+1}{1}} = \frac{(2n+1)(2n)(2n-1)}{6\,(2n+1)} = \frac{n(2n-1)}{3}. \qed\] 以 \(n = 1\) 验算：\(\cot^2(\pi/3) = \frac13\)，而 \(\frac{1 \times 1}{3} = \frac13\)。

阶段 4 夹逼

由 \(0 < \sin\theta < \theta < \tan\theta\) 出发，取倒数（不等号方向因而倒转）再平方： \[\cot^2\theta < \frac{1}{\theta^2} < \frac{1}{\sin^2\theta} = 1 + \cot^2\theta.\]

代入 \(\theta = \frac{m\pi}{2n+1}\)，并对 \(m = 1, \ldots, n\) 求和。外侧的两个和变成甚么？中间的和与 \(\sum 1/m^2\) 有甚么关系？

中间的和是 \(\displaystyle\sum_{m=1}^{n} \frac{(2n+1)^2}{m^2 \pi^2}\)。根据第 (ii) 部分，左边的和是 \(\frac{n(2n-1)}{3}\)，而右边的和是 \(n + \frac{n(2n-1)}{3} = \frac{2n(n+1)}{3}\)。各项同乘以 \(\frac{\pi^2}{(2n+1)^2}\)： \[\frac{\pi^2}{3} \cdot \frac{n(2n-1)}{(2n+1)^2} \;<\; \sum_{m=1}^{n} \frac{1}{m^2} \;<\; \frac{\pi^2}{3} \cdot \frac{2n(n+1)}{(2n+1)^2}.\] 当 \(n \to \infty\) 时，\(\frac{n(2n-1)}{(2n+1)^2}\) 和 \(\frac{2n(n+1)}{(2n+1)^2}\) 都趋向 \(\frac24 = \frac12\)（把分子和分母同除以 \(n^2\)）。所以上下两个界都趋向 \(\frac{\pi^2}{6}\)，而部分和（partial sum）被夹在两者之间，亦必定趋向 \(\frac{\pi^2}{6}\)（图 2.4.1）。■

回顾

  • 从系数取得信息。我们始终没有把 \(\cot^2(m\pi/(2n+1))\) 这些根化成任何更简单的形式，却准确地求出了它们的和。

  • 先近似，再夹逼。\(\cot\theta\) 只是近似等于 \(1/\theta\)，但误差在两个方向上都受到精确的不等式控制。

  • 由有限到无限。除了最后一步，每一步处理的都是有限和。无穷和只在我们于不等式中令 \(n \to \infty\) 时才出现，这正是处理无限的稳妥方法。

背后的数学

欧拉的大胆论证

以现代标准来看，欧拉本人在 1734 年的论证并不严格，却令人目眩神迷。一个多项式若以 \(\pm a, \pm b, \pm c, \ldots\) 为根，且在 \(0\) 处取值 \(1\)，便可分解为 \((1 - x^2/a^2)(1 - x^2/b^2)\cdots\)。函数 \(\frac{\sin x}{x}\) 在 \(0\) 处取值 \(1\)，而它的根是 \(\pm\pi, \pm 2\pi, \pm 3\pi, \ldots\)，于是欧拉把它当作一个“无限多项式”，写下 \[\frac{\sin x}{x} = \left(1 - \frac{x^2}{\pi^2}\right)\left(1 - \frac{x^2}{4\pi^2}\right)\left(1 - \frac{x^2}{9\pi^2}\right)\cdots.\] 右边 \(x^2\) 的系数是 \(-\frac{1}{\pi^2}\bigl(1 + \frac14 + \frac19 + \cdots\bigr)\)，而由麦克劳林级数（Maclaurin series）\(\frac{\sin x}{x} = 1 - \frac{x^2}{6} + \cdots\) 可知它是 \(-\frac16\)。两相比较便得 \(\pi^2/6\)。我们这个 STEP 证明正是同一想法的有限而严格的版本：一个多项式，它的根与 \(\pi\) 的倍数息息相关，再加上它的第二个系数。

平方倒数以外

欧拉其后还求出 \(\sum 1/m^4 = \pi^4/90\)、\(\sum 1/m^6 = \pi^6/945\)，而一般而言 \(\sum 1/m^{2k}\) 是 \(\pi^{2k}\) 的有理数倍，当中涉及伯努利数（Bernoulli numbers）。奇数次幂则是另一回事：正如我们在 第 2.3 节 所见，没有人知道 \(\sum 1/m^3\) 的公式。这些和就是黎曼 ζ 函数（Riemann zeta function）的值 \(\zeta(2), \zeta(4), \ldots\)，而这个函数在复数自变量上的表现，支配着质数的分布（第 1.2 节）。

日后在哪里再遇上

在大学里，你会至少再遇到 \(\zeta(2) = \pi^2/6\) 的三个证明：一个来自傅里叶级数（Fourier series）（把函数写成正弦和余弦之和），一个来自二重积分（double integral），还有一个来自复分析（complex analysis）。这个数也在概率中出现：随机选出的两个整数没有公因数的机会是 \(6/\pi^2 \approx 0.61\)。（质数 \(p\) 同时整除两者的概率是 \(1/p^2\)，所以没有任何质数同时整除两者的机会是 \(\prod_p (1 - 1/p^2)\)，而欧拉证明了这个乘积等于 \(1/\zeta(2)\)。）\(\pi\) 在概率极限中的另一次现身，是 第 12.23 节 的主题。

思维技巧

夹逼，以及根的对称函数（symmetric functions）

要求一个极限，可把该量夹在两个极限相同而较简单的式子之间。

而当你需要求一些难缠的数之和（或积）时，不妨试找一个以它们为根的多项式：系数会把这些数的对称组合白白送给你。

延伸练习

  1. 1992 年的版本。试做 STEP III 1992，第 8 题。它利用一个与本节相似的多项式，求出正切平方与余割平方的准确和。（提示：若你知道一个多项式的根是 \(r_i\)，那么哪个多项式的根是 \(1/r_i\)？）

  2. 奇数的平方。由 \(\sum 1/m^2 = \pi^2/6\) 推导出 \(1 + \frac19 + \frac1{25} + \frac1{49} + \cdots = \frac{\pi^2}{8}\)。

  3. 四次方。 较难 利用 \(\sum r_i^2 = (\sum r_i)^2 - 2\sum_{i<j} r_i r_j\) 和多项式的系数，求 \(\sum_{m=1}^{n} \cot^4\bigl(\frac{m\pi}{2n+1}\bigr)\)，并改动夹逼的论证以证明 \(\sum 1/m^4 = \pi^4/90\)。

  4. 有多快？利用第 (iii) 部分的下界，证明 \(\frac{\pi^2}{6} - \sum_{m=1}^{n} \frac{1}{m^2} < \frac{\pi^2}{4n}\)。按这个结果，\(n\) 要多大才能保证部分和与 \(\pi^2/6\) 相差不超过 \(0.001\)？试与真正的误差比较，后者接近 \(1/n\)。
