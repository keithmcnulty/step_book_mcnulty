逐步逼近 e 的分数

引子

怎样才能找到逼近 \(e\) 的好分数？你可以把级数（series）\(1 + 1 + \frac12 + \frac16 + \cdots\) 截断，但以分母的大小来衡量，这样得到的分数并不算特别好。这道题的做法高明得多：它构造出一族积分，每个积分都是形如“整数 \(+\) 整数 \(\times\, e\)”的一个很小的数。如果 \(a + be\) 极小，那么 \(e\) 就非常接近 \(-a/b\)，于是这些积分便为我们送上一连串极佳的分数：\(\frac{19}{7}\)、\(\frac{193}{71}\)、\(\frac{2721}{1001}\)、…

同样的技巧，即找出既很小、又形如“你所关心的那个数的整数组合”的积分，正是数学中一些最深刻的无理性证明背后的想法，包括埃尔米特（Hermite）对 \(e\) 是超越数（transcendental）的证明，以及阿佩里（Apéry）对 \(\zeta(3)\) 是无理数（irrational）的证明。

动笔之前

看看 \([0, 1]\) 上的被积函数（integrand）\(\frac{t^n(1-t)^n}{n!}e^t\)。

\(t(1-t)\) 在 \([0, 1]\) 上的最大值是多少？由此可知，当 \(n\) 增大时 \(T_n\) 的大小会怎样变化？

\(t(1-t)\) 的最大值是 \(\frac14\)，在 \(t = \frac12\) 处取得。所以被积函数至多为 \(\frac{e}{4^n n!}\)，它缩小的速度快得惊人（图 2.9.1）。这个“小”只是故事的一半。另一半，即 \(T_n\) 具有 \(a_n + b_n e\) 这种特殊形式，则来自分部积分法（integration by parts）。

逐步解题

阶段 1 求导两次

设 \(p(t) = t^n(1-t)^n\)。由积法则（product rule）， \[p'(t) = n t^{n-1}(1-t)^n - n t^n(1-t)^{n-1} = n t^{n-1}(1-t)^{n-1}(1 - 2t).\]

再求导一次。你会得到两项；把公因式 \(n t^{n-2}(1-t)^{n-2}\) 抽出来。要配合题目要求的形式，你需要把 \((1 - 2t)^2\) 改写成以 \(t(1-t)\) 表示的式子。怎样做？

用积法则对 \(n\,[t(1-t)]^{n-1}(1 - 2t)\) 求导（留意 \(\frac{\mathrm{d}}{\mathrm{d}t}[t(1-t)] = 1 - 2t\)）： \[\begin{aligned} p''(t) &= n(n-1)[t(1-t)]^{n-2}(1-2t)^2 - 2n[t(1-t)]^{n-1} \\ &= n t^{n-2}(1-t)^{n-2}\Bigl[(n-1)(1-2t)^2 - 2t(1-t)\Bigr]. \end{aligned}\] 现在 \((1 - 2t)^2 = 1 - 4t + 4t^2 = 1 - 4t(1-t)\)，所以方括号内的式子是 \((n-1) - 4(n-1)t(1-t) - 2t(1-t) = (n-1) - 2(2n-1)t(1-t)\)。■

阶段 2 分部积分两次

\(p(t)\) 在 \(t = 0\) 和 \(t = 1\) 处都等于零。当 \(n \geq 2\) 时，\(p'(t)\) 又如何？在对 \(p(t)e^t\) 作分部积分时，这一点为甚么重要？

当 \(n \geq 2\) 时，\(p'(t)\) 含有因式 \(t^{n-1}(1-t)^{n-1}\)，所以它在两个端点也等于零。分部积分两次，每一个边界项都是零： \[\int_0^1 p\, e^t\,\mathrm{d}t = \Bigl[p\,e^t\Bigr]_0^1 - \int_0^1 p'\, e^t\,\mathrm{d}t = -\Bigl[p'\,e^t\Bigr]_0^1 + \int_0^1 p''\, e^t\,\mathrm{d}t = \int_0^1 p''\, e^t\,\mathrm{d}t.\] 由第 1 阶段，\(p''(t) = n(n-1)\,t^{n-2}(1-t)^{n-2} - 2n(2n-1)\,t^{n-1}(1-t)^{n-1}\)。除以 \(n!\)： \[\frac{p''(t)}{n!} = \frac{t^{n-2}(1-t)^{n-2}}{(n-2)!} - 2(2n-1)\frac{t^{n-1}(1-t)^{n-1}}{(n-1)!}.\] 乘以 \(e^t\) 再积分，便得 \(T_n = T_{n-2} - 2(2n-1)T_{n-1}\)。■

阶段 3 整数结构

\(T_0 = \int_0^1 e^t\,\mathrm{d}t = e - 1\)。至于 \(T_1 = \int_0^1 (t - t^2)e^t\,\mathrm{d}t\)，由分部积分得 \(\int_0^1 t e^t\,\mathrm{d}t = 1\) 及 \(\int_0^1 t^2 e^t\,\mathrm{d}t = e - 2\)，所以 \(T_1 = 1 - (e - 2) = 3 - e\)。

\(T_0 = -1 + 1 \cdot e\) 而 \(T_1 = 3 + (-1)\cdot e\)。为甚么每个 \(T_n\) 都必定具有 \(a_n + b_n e\) 的形式，其中 \(a_n\)、\(b_n\) 是整数？

用强归纳法（strong induction）：若 \(T_{n-2} = a_{n-2} + b_{n-2}e\) 及 \(T_{n-1} = a_{n-1} + b_{n-1}e\)，其中系数都是整数，则 \[T_n = \bigl(a_{n-2} - 2(2n-1)a_{n-1}\bigr) + \bigl(b_{n-2} - 2(2n-1)b_{n-1}\bigr)e,\] 而新的系数也是整数。■

阶段 4 很小，因而带来信息

当 \(0 < t < 1\) 时，被积函数是正数，并且 \(t^n(1-t)^n \leq 1\) 及 \(e^t < e\)。所以 \[0 < T_n < \int_0^1 \frac{e}{n!}\,\mathrm{d}t = \frac{e}{n!}.\]

把 \(0 < a_n + b_n e < \dfrac{e}{n!}\) 除以 \(|b_n|\)。这说明 \(e\) 与 \(-a_n/b_n\) 之间的距离如何？

除以 \(|b_n|\)（它是正整数，所以至少是 \(1\)）， \[\left| e - \left(\frac{-a_n}{b_n}\right) \right| = \frac{|a_n + b_n e|}{|b_n|} < \frac{e}{n!\,|b_n|} \leq \frac{e}{n!}.\] 右边趋向 \(0\)，所以 \(-a_n/b_n \to e\)。■

以下是由递推关系（recurrence）算出的头几个分数：

\(n\) 2 3 4 5 6
\(-a_n/b_n\) \(\dfrac{19}{7}\) \(\dfrac{193}{71}\) \(\dfrac{2721}{1001}\) \(\dfrac{49171}{18089}\) \(\dfrac{1084483}{398959}\)
误差 \(4 \times 10^{-3}\) \(3 \times 10^{-5}\) \(1 \times 10^{-7}\) \(3 \times 10^{-10}\) \(5 \times 10^{-13}\)

分数 \(\frac{2721}{1001}\) 准确至小数点后 \(6\) 位，而分母只有四位数。

回顾

  • 分部积分是制造递推关系的机器。由于多项式及其导数在两个端点都等于零，分部积分给出了一个没有边界项的简洁递推关系。

  • 结构与大小并用。递推关系说明 \(T_n\) 具有 \(a_n + b_n e\) 的形式；上界说明它很小。单凭其中任何一项，都无法说明怎样逼近 \(e\)。

  • 不需要的就不要算。题目叫我们不必求出 \(a_n\) 和 \(b_n\) 的值，而论证也从来用不着它们；所需要的只是它们是整数。

背后的数学

\(e\) 是无理数的另一个证明

这道题离一个著名定理只差一步。假设 \(e = p/q\)，其中 \(p, q\) 是正整数。那么 \[q\,T_n = q a_n + b_n p\] 是一个整数。但是 \(0 < q\,T_n < \dfrac{qe}{n!}\)，而当 \(n\) 很大时，右边小于 \(1\)。于是 \(q T_n\) 就会是一个严格介乎 \(0\) 与 \(1\) 之间的整数，这是不可能的。因此 \(e\) 是无理数。这正是 第 1.4 节 中“把一个整数困在 \(0\) 与 \(1\) 之间”的想法，只是这次由积分而不是级数来实现。正是这一类积分，配合 \(t^n(1-t)^n\) 这样的多项式，在 1873 年被夏尔·埃尔米特（Charles Hermite）用来证明 \(e\) 是超越数：它不是任何整系数多项式的根。

连分数

表中的分数不仅是好；它们更属于最佳之列。\(e\) 的连分数（continued fraction）由欧拉（Euler）发现，有一个优美的规律： \[e = [2; 1, 2, 1, 1, 4, 1, 1, 6, 1, 1, 8, \ldots],\] 而它的渐近分数（convergents）是 \(2, 3, \frac83, \frac{11}{4}, \frac{19}{7}, \frac{87}{32}, \frac{106}{39}, \frac{193}{71}, \ldots, \frac{2721}{1001}, \ldots\)。我们的 \(-a_n/b_n\) 恰好是每隔两个取一个的渐近分数。没有任何分母更小的分数能更接近 \(e\)。欧拉发现的这个规律本身就是 \(e\) 是无理数的第一个证明，因为只有有理数才有有限的连分数。

阿佩里的奇迹

1978 年，罗杰·阿佩里（Roger Apéry）宣布证明了 \(\zeta(3) = 1 + \frac18 + \frac1{27} + \cdots\) 是无理数，这是自欧拉以来一直悬而未决的问题（见 第 2.3 节）。他的证明实在太出人意表，以致在场听众起初并不相信。一年后，Frits Beukers 找到一个简短的版本，所用的积分形如 \[\int_0^1\!\!\int_0^1 \frac{-\ln(xy)}{1 - xy}\, P_n(x) P_n(y)\,\mathrm{d}x\,\mathrm{d}y,\] 其中 \(P_n\) 由 \(\frac{\mathrm{d}^n}{\mathrm{d}x^n}\bigl(x^n(1-x)^n\bigr)\) 构造而成。这些积分很小，是正数，并且形如“整数 \(+\) 整数 \(\times\, \zeta(3)\)”再除以一个受控的分母：这正是本题的策略。至于 \(\zeta(5)\) 或 \(e + \pi\) 是否无理数，至今仍然未知。

思维技巧

很小但不是零

如果已知某个量是若干个数的整数组合，又已知它很小但不是零，它就带有信息：关于逼近的信息，有时还有关于无理性的信息。

这个模式就是“结构来自代数，大小来自分析”。它在数论中反复出现，也是分析与代数交汇得最有成果的地方之一。

延伸练习

  1. 运行递推关系。由递推关系计算 \(n = 2, 3, 4\) 时的 \(a_n\) 和 \(b_n\)，并核对表中的分数。证明 \(b_n\) 的正负号交替出现。

  2. 更精确的上界。证明 \(0 < T_n < \dfrac{e}{4^n\, n!}\)。这把 \(-a_n/b_n\) 的误差估计改进了多少？

  3. 无理性的证明。把上面方框中的论证仔细写出来。你究竟在哪一处用到 \(T_n > 0\)？

  4. 换一个权函数。 较难 把 \(e^t\) 换成 \(e^{2t}\)，重做这道题（即 \(U_n = \int_0^1 \frac{t^n(1-t)^n}{n!}e^{2t}\,\mathrm{d}t\)）。求 \(U_n\) 的递推关系，证明 \(U_n\) 是 \(1\) 和 \(e^2\) 的有理系数组合，并探究这个论证是否仍能证明 \(e^2\) 是无理数。（与 第 1.4 节 比较。）

延伸阅读

  • Ivan Niven, Irrational Numbers（Mathematical Association of America）。关于无理性证明的经典小书，当中包括埃尔米特的方法。

  • Alfred van der Poorten, “A proof that Euler missed”, The Mathematical Intelligencer 1 (1979)。生动地记述阿佩里的证明及其所得到的回响。

  • Julian Havil, The Irrationals（Princeton University Press）。一部无理数的历史，为一般数学读者而写。
