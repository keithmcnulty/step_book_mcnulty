第 2 章 \(\cdot\) 引言

驯服无穷

无穷！从来没有别的问题如此深刻地触动人类的心灵。

— 希尔伯特（David Hilbert）

两千五百年前，埃利亚的芝诺（Zeno of Elea）论证说运动是不可能的。要走过一个房间，你必须先走一半路程，然后走余下路程的一半，再走那余下的一半，如此类推，永无止境：这是无穷多项任务，肯定无法在有限时间内完成。人人都知道芝诺错了，因为人们确实能走过房间，但在很长的一段时间里，没有人能确切说出他为甚么错。答案是：无穷和 \(\frac12 + \frac14 + \frac18 + \cdots\) 有一个有限的值，就是 \(1\)。可是，无穷多个数加起来等于某个数，这句话究竟是甚么意思？

这个问题占据数学的核心达两千年之久。十七世纪时，牛顿（Newton）和莱布尼兹（Leibniz）在它之上建立了微积分（calculus），却始终没有真正回答它；他们的后继者既得出了许多精彩的结果，也制造了一些荒谬绝伦的谬论。欧拉（Euler）是有史以来最伟大的计算家，他毫不犹豫地写下 \(1 - 1 + 1 - 1 + \cdots = \frac12\)。另一些人则就同一个无穷级数（infinite series）“证明”出互相矛盾的结论。直到十九世纪，经过柯西（Cauchy）、魏尔斯特拉斯（Weierstrass）等人的努力，数学家才有了足够精确的定义，可以分辨哪些结果是真、哪些是假。这些定义就是本章的主题。

为甚么重要

你一生中用来计算的数，几乎每一个都是某样东西的极限（limit）。你的计算机并不知道 \(\sqrt2\)、\(\pi\) 或 \(e\) 是甚么：它只知道一些能够愈来愈接近这些数的计算步骤，并在足够接近时停下来。明白一套步骤逼近得有多快，正是一毫秒内完成的算法与永远算不完的算法之间的分别。用来预测天气、设计飞机和为金融产品定价的电脑模拟，背后也是同样的想法。而在最纯粹的一面，对极限的研究引出了数学中一些最优美的公式：在本章中，你将会证明 \[1 + \frac14 + \frac19 + \frac1{16} + \cdots = \frac{\pi^2}{6},\] 这个结果令欧拉一举成名，至今看来仍然近乎神奇。

你在大学会遇到甚么

几乎在每一所大学，数学分析（Analysis）都是你最先修读的课程之一，而对许多学生来说，它带来的冲击也最大。在中学数学里，你学的是计算极限；在数学分析里，你学的是从精确的定义出发，证明关于极限的命题。你会定义数列（sequence）收敛（converge）是甚么意思，用的正是 第 2.1 节 中出现的“对于每一个 \(\varepsilon > 0\)”和“存在 \(N\)”这些说法。你会证明每一个有界递增数列都收敛，并发现这有赖于实数的一项性质——完备性（completeness），而有理数并不具备这项性质。你会学习判别级数是否收敛的各种方法，然后运用同样的想法，为连续性、微分和积分赋予严格的意义。

往后的课程会在这个基础上向多个方向发展。数值分析（Numerical analysis）探讨近似值收敛得有多快，以及怎样令它们收敛得更快（第 2.7 节、第 2.6 节）。动力系统（Dynamical systems）研究反复套用同一条规则时会发生甚么事，有时会趋向一个极限，有时则产生混沌（chaos）（第 2.2 节、第 2.8 节）。复分析（Complex analysis）解释了为甚么 \(\pi\) 会在那么多无穷和与无穷乘积中出现（第 2.4 节、第 2.5 节）。而解析数论（analytic number theory）则利用极限来回答关于整数的问题，例如 第 2.9 节。

贯穿本章的问题

三大问题

  1. 一个无穷的过程有答案，是甚么意思？我们怎样才能精确地说一个数列“趋近”某个极限，或者一个无穷和“加起来等于”某个数？

  2. 怎样在不知道极限是甚么的情况下，证明某样东西收敛？而一旦知道极限存在，又怎样把它求出来？

  3. 有多快？两个过程可以有相同的极限，逼近的速度却有天壤之别。为甚么会这样？我们又怎样量度这种速度？

第一节（第 2.1 节）谈的是语言：数学家怎样精确地表达“最终”这个概念。接着的五节谈的是著名的极限：以连分数（continued fraction）表示的黄金比（golden ratio）、一个发散（divergent）级数和它那个收敛的近亲、\(\pi^2/6\)、韦达（Viète）关于 \(2/\pi\) 的乘积，以及高斯（Gauss）的算术几何平均（arithmetic–geometric mean）。最后三节谈的是速度与结构：线性收敛与二次收敛的对比、一个要么爆炸式增长要么混沌地游走的迭代（iteration），以及一族逐步逼近 \(e\) 的积分。

怎样阅读本章

与第 1 章一样，每一节都以一道 STEP 原题开始。请先自己尝试，然后才往下读。本章的题目往往会告诉你该用哪一种工具（“考虑……”、“你可以使用以下定理……”）；在解题的过程中，请留意同样的几种工具出现得有多频密，因为到了大学，你便要自己作出选择。

有好几道题目要求你假设极限存在，或者假设无穷和与无穷乘积收敛。遇到这种情况时，该节会解释要证明这一点还需要些甚么。意识到“这显然行得通”与“我能证明这行得通”之间的差距，是学会像分析学家那样思考的第一步。
