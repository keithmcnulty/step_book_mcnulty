平方再减二

引子

“平方后减二”几乎是可以用来生成数列（sequence）的最简单规则。然而它把实数线分成两个世界。从 \([-2, 2]\) 之外出发，各项会以比指数增长还要快的速度冲向无穷大。从区间之内出发，各项则永远被困在其中，四处游走，而且在一个精确的意义下完全无法预测：这是混沌（chaos）最简单的例子之一。

同一条规则，用在非常大的整数上，就是卢卡斯－莱默检验法（Lucas–Lehmer test）的核心。这是一个高效的检验法，用来判断梅森数（Mersenne number）\(2^p - 1\) 是否质数（prime）；现时的最大质数纪录，以及其他已知最大的质数中的大部分，都是靠它找到的。本题探讨的是故事中“逃逸”的一面，并找出一条隐藏的公式，令这个数列完全可解。

动笔之前

先试几个初始值。取 \(a = 3\)：\(3, 7, 47, 2207, \ldots\) 取 \(a = 1\)：\(1, -1, -1, -1, \ldots\) 取 \(a = 0\)：\(0, -2, 2, 2, 2, \ldots\) 取 \(a = 0.3\)：\(0.3, -1.91, 1.648, 0.716, -1.487, 0.211, \ldots\)

为甚么 \([-2, 2]\) 内的数永远无法逃出去？当 \(-2 \leq x \leq 2\) 时，\(x^2 - 2\) 最大和最小可以是多少？

若 \(-2 \leq x \leq 2\)，则 \(0 \leq x^2 \leq 4\)，所以 \(-2 \leq x^2 - 2 \leq 2\)。区间 \([-2, 2]\) 被映射到它自身之内。这就是第 (ii) 部分的一半。

逐步解题

阶段 1 逃逸

第 (i) 部分出现了 \(4^{n-1}\)，暗示与 \(2\) 的距离每一步至少变成四倍。设 \(x_n = 2 + d\)。以 \(d\) 表示，\(x_{n+1}\) 是甚么？

\(x_{n+1} = (2 + d)^2 - 2 = 2 + 4d + d^2\)。所以若 \(d \geq 0\)，新一项高出 \(2\) 的距离是 \(4d + d^2 \geq 4d\)。

现在用归纳法（induction）。当 \(n = 1\) 时，\(x_1 = a = 2 + 4^0(a - 2)\)。若 \(x_n \geq 2 + 4^{n-1}(a - 2)\)，则 \(d = x_n - 2 \geq 4^{n-1}(a - 2) \geq 0\)，所以 \[x_{n+1} - 2 \geq 4d \geq 4^n (a - 2). \qed\]

阶段 2 逃逸当且仅当 \(|a| > 2\)

“当且仅当”（if and only if）表示要分别作两个证明。第 (i) 部分差不多已经给出哪一个方向？还欠甚么？

若 \(|a| > 2\)：当 \(a > 2\) 时，由第 (i) 部分得 \(x_n \geq 2 + 4^{n-1}(a - 2) \to \infty\)。当 \(a < -2\) 时，第一步已把正负号纠正过来：\(x_2 = a^2 - 2 > 4 - 2 = 2\)，而由 \(x_2\) 开始的数列，就是以 \(x_2 > 2\) 为初始值的同一个数列，所以它趋向无穷大。

仅当：若 \(|a| \leq 2\)，则 \(a \in [-2, 2]\)，由上面的观察可知每一项都留在 \([-2, 2]\) 之内。有界（bounded）的数列不可能趋向无穷大。■

阶段 3 一条隐藏的公式

第 (iii) 部分看来令人却步。在动手之前，值得先找出 \(x_n\) 的公式。

若 \(a > 2\)，则存在一个数 \(t > 1\) 使得 \(a = t + \dfrac1t\)。（为甚么？）以 \(t\) 表示，\(x_2\) 和 \(x_3\) 是甚么？

当 \(t\) 由 \(1\) 增至 \(\infty\) 时，函数 \(t + 1/t\) 由 \(2\) 递增至 \(\infty\)，所以每个 \(a > 2\) 都可以写成这个形式。于是 \[x_2 = \left(t + \frac1t\right)^2 - 2 = t^2 + \frac{1}{t^2}, \qquad x_3 = \left(t^2 + \frac1{t^2}\right)^2 - 2 = t^4 + \frac1{t^4},\] 再由归纳法得 \[x_n = t^{2^{n-1}} + t^{-2^{n-1}}.\] 平方后减 \(2\)，只不过是把指数加倍。这样题目就变得容易处理了。

阶段 4 乘积裂项相消

\(\left(t - \frac1t\right)\left(t + \frac1t\right)\) 是甚么？若把结果再乘以 \(t^2 + \frac1{t^2}\)，会怎样？

\(\left(t - \frac1t\right)\left(t + \frac1t\right) = t^2 - \frac1{t^2}\)，然后 \(\left(t^2 - \frac1{t^2}\right)\left(t^2 + \frac1{t^2}\right) = t^4 - \frac1{t^4}\)，如此类推：每个因子 \(x_k\) 都把两个幂之差中的指数加倍。所以 \[\left(t - \frac1t\right) x_1 x_2 \cdots x_n = t^{2^n} - t^{-2^n}.\]

以 \(t\) 表示并计算 \(x_{n+1}^2 - 4\)，然后与上面的乘积比较。

\[x_{n+1}^2 - 4 = \left(t^{2^n} + t^{-2^n}\right)^2 - 4 = \left(t^{2^n} - t^{-2^n}\right)^2.\] 由于 \(t > 1\)，\(t^{2^n} - t^{-2^n} > 0\)，所以 \(\sqrt{x_{n+1}^2 - 4} = t^{2^n} - t^{-2^n} = \left(t - \frac1t\right) x_1 x_2 \cdots x_n\)。因此 \[\frac{\sqrt{x_{n+1}^2 - 4}}{x_{n+1}} = \frac{\left(t - \frac1t\right) x_1 \cdots x_n}{x_{n+1}},\] 而它对每个 \(n\) 都等于 \(y_n\)，恰好就是 \(A = t - \frac1t\) 的时候。最后，\(\left(t - \frac1t\right)^2 = \left(t + \frac1t\right)^2 - 4 = a^2 - 4\)，所以条件是 \(A = \sqrt{a^2 - 4}\)，即 \[a = \sqrt{A^2 + 4}.\] （因为 \(A > 0\)，这个值大于 \(2\)，符合要求。）■

阶段 5 \(y_n\) 是否收敛？

取这个 \(a\) 值时， \[y_n = \frac{\sqrt{x_{n+1}^2 - 4}}{x_{n+1}} = \sqrt{1 - \frac{4}{x_{n+1}^2}}.\] 由第 (ii) 部分知 \(x_{n+1} \to \infty\)，所以 \(\frac{4}{x_{n+1}^2} \to 0\)，而 \(y_n \to 1\)。数列收敛（converge），极限为 \(1\)。■

所以无穷乘积（infinite product）\(x_1 x_2 x_3 \cdots\) 的增长速度与 \(x_{n+1}/A\) 完全相同：我们找到了一个由急速增长的项所组成的乘积的精确增长率。

回顾

  • 不变区域（invariant region）。\([-2, 2]\) 被映射到它自身之内，单凭这一点就解决了第 (ii) 部分的一半。

  • 把问题线性化的代换（substitution）。写成 \(a = t + 1/t\) 之后，“平方后减 \(2\)”就变成“把指数加倍”。杂乱的非线性行为变得简单。

  • 又是裂项相消（telescoping）。与 第 2.5 节 中的乘积一样，由许多因子组成的乘积之所以能折叠起来，是因为每个因子都与下一个互相配合。

背后的数学

秩序与混沌

在 \([-2, 2]\) 之内会发生甚么事？在那里 \(a = t + 1/t\) 行不通（它需要 \(|a| \geq 2\)），但三角函数的版本却可行：设 \(a = 2\cos\theta\)。则 \(x_2 = 4\cos^2\theta - 2 = 2\cos 2\theta\)，而一般地 \[x_n = 2\cos\bigl(2^{n-1}\theta\bigr).\] 所以在区间之内，这个映射只不过是把角度加倍。听起来无伤大雅，但把角度加倍其实是混沌的。把 \(\theta/\pi\) 写成二进制（binary）：加倍会把二进制小数点向右移一位，并丢掉最前面的一位数字。经过 \(50\) 步之后，\(x_n\) 取决于 \(\theta/\pi\) 的第 \(51\) 位二进制数字，所以初始值若有 \(10^{-15}\) 的误差（一般电脑的精确度），\(50\) 步之后的答案就完全不可靠。这种对初始条件的敏感依赖（sensitive dependence on initial conditions）正是混沌的标志，见图 2.8.1。映射 \(x \mapsto x^2 - 2\) 经变量代换后，等价于著名的逻辑斯谛映射（logistic map）\(x \mapsto 4x(1 - x)\)，我们会在 第 8.7 节 再遇上它。

寻找最大的质数

梅森数是指 \(M_p = 2^p - 1\)。卢卡斯（Édouard Lucas）在 1876 年发现了一个出色的检验法，用来判断 \(M_p\) 是否质数（其中 \(p\) 为奇质数），其后莱默（Derrick Lehmer）在 1930 年把它完善：由 \(s_0 = 4\) 开始，反复平方后减 \(2\)，每次都取模（modulo）\(M_p\) 化简。则 \[M_p \text{ 是质数} \iff s_{p-2} \equiv 0 \pmod{M_p}.\] 以 \(M_7 = 127\) 为例：\(s = 4, 14, 194 \equiv 67, 67^2 - 2 \equiv 42, 42^2 - 2 \equiv 111, 111^2 - 2 \equiv 0\)，所以 \(127\) 是质数。它与本题的联系就在于那个代换：\(4 = t + 1/t\)，其中 \(t = 2 + \sqrt3\)，所以 \(s_k = (2+\sqrt3)^{2^k} + (2-\sqrt3)^{2^k}\)，而检验法的证明用到形如 \(a + b\sqrt3\) 的数的算术，与 第 1.6 节 的高斯整数（Gaussian integers）颇为相似。由于每一步只需要一次平方，这个检验法极为快速，这就是为甚么已知最大的质数中的大部分，包括现时的纪录保持者，都是梅森质数（并非全部都是：其他特殊形式，例如 \(a^{2^n} + 1\)，也有各自的快速检验法）。在本书撰写之时，纪录是 \(2^{136279841} - 1\)，这个数有多于 \(41\) 百万位数字，于 2024 年发现。

曼德博集合

把 \(-2\) 换成任意常数 \(c\)，并容许复数：\(z \mapsto z^2 + c\)。令 \(0\) 的轨道保持有界的所有 \(c\) 所组成的集合，就是曼德博集合（Mandelbrot set）。我们的映射对应 \(c = -2\)，即曼德博集合最左边的一点，而轨道保持有界的初始值所组成的集合（它的茹利亚集合（Julia set））正好是我们在第 (ii) 部分找到的区间 \([-2, 2]\)。对于几乎所有其他的 \(c\)，这个集合都是分形（fractal）。

思维技巧

转换变量，令映射变得简单

若一个迭代（iteration）看来很复杂，就找一个代换，把它变成简单的东西，例如加倍或加上一个常数。

这里 \(x = t + 1/t\) 和 \(x = 2\cos\theta\) 把 \(x \mapsto x^2 - 2\) 变成了加倍。在动力系统（dynamical systems）理论中，这称为共轭（conjugacy），而找到共轭往往是彻底理解一个系统的关键。

延伸练习

  1. 区间之内。证明若 \(a = 2\cos\theta\)，则 \(x_n = 2\cos(2^{n-1}\theta)\)。求所有使得 \(x_3 = a\) 但 \(x_2 \neq a\) 的 \(a\) 值。（提示：你需要 \(4\theta \equiv \pm\theta\)，模 \(2\pi\)。）

  2. 手算卢卡斯－莱默检验法。用这个检验法证明 \(M_5 = 31\) 是质数，而 \(M_{11} = 2047\) 不是。（对 \(M_{11}\) 你需要九步；用计算机会有帮助。把 \(2047\) 作因数分解，以验证你的结论。）

  3. 一个具体例子。取 \(A = \frac{3}{2}\)。求 \(a\) 和 \(t\)，并以数值验证公式 \(y_1 = \sqrt{x_2^2 - 4}/x_2\)。

  4. 裂项相消的和。 较难 设 \(a = t + 1/t\) 且 \(t > 1\)，证明 \[\frac{1}{x_1 x_2 \cdots x_n} = \frac{t - t^{-1}}{t^{2^n} - t^{-2^n}}.\] 利用恒等式 \(\dfrac{1}{z - 1} - \dfrac{1}{z^2 - 1} = \dfrac{z}{z^2 - 1}\)，其中 \(z = t^{2^n}\)，由此推出 \[\frac{1}{x_1} + \frac{1}{x_1 x_2} + \frac{1}{x_1 x_2 x_3} + \cdots = \frac1t.\] 当 \(a = 3\) 时，以数值验证这个结果。
