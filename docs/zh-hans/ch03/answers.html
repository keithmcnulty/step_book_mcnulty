第 3 章 · 函数、不等式与严谨

“延伸练习”答案

以下只是简短的答案和提示，并非完整解答：这里只列出结果和关键步骤，方便你核对自己的做法。请先认真做过每道练习，然后才看答案。

3.1 找出错处

  1. 当 \(x\) 由 \(-1\) 变到 \(1\) 时会经过 \(0\)，而 \(t = 1/x\) 在该处没有定义：这个代换（substitution）在区间上并不连续（continuous）。正确的结果是 \(\int_{-1}^1\frac{\mathrm{d}x}{(1 + x^2)^2} = \frac12 + \frac\pi4\)（用 \(x = \tan\theta\)），而 \(\int_{-1}^1\frac{-t^2}{(1 + t^2)^2}\,\mathrm{d}t = \frac12 - \frac\pi4\)。

  2. (a) 正确：两边的对数（logarithm）都是 \(\ln a\ln b\)。(b) 错误：当 \(\theta = 0\) 时，\(\cos0 = 1 \neq \sin1\)。（事实上两者永不相等，因为 \(|\sin\theta \pm \cos\theta| \leq \sqrt2 < \frac\pi2\)。）(c) 错误：非常数的多项式（polynomial）是无界的，而一个常数不可能同时与 \(1\) 和 \(-1\) 相差不超过 \(10^{-6}\)。(d) 正确：由算术—几何平均不等式（AM–GM），\(x^4 + x^{-4} \geq 2\)，等号在 \(x = 1\) 时成立。

  3. 由 \(n = 1\) 推到 \(n = 2\) 的一步并不成立：两匹马当中的“前 \(1\) 匹”与“后 \(1\) 匹”并不重叠。

  4. \(\int_\varepsilon^1x^{-1/2}\,\mathrm{d}x = 2 - 2\sqrt\varepsilon \to 2\)，所以由对称性，该积分（作为极限）存在，其值为 \(4\)。

3.2 倒过来的 AM–GM

  1. 设 \(a_1, \ldots, a_{n-1}\) 的平均值为 \(A\)，几何平均（geometric mean）为 \(G\)，再加入 \(A\) 作为第 \(n\) 个数。平均值仍然是 \(A\)，所以 \((G^{n-1}A)^{1/n} \leq A\)，由此得 \(G \leq A\)。

  2. 这 \(n + 1\) 个数的平均值为 \(1 + \frac{1}{n+1}\)，几何平均为 \((1 + \frac1n)^{n/(n+1)}\)，而且它们并非全部相等，所以不等式是严格的；把两边同时取 \(n + 1\) 次方即可。

  3. 各个面的面积为 \(ab\)、\(bc\)、\(ca\)，而 \(S = 2(ab + bc + ca)\)。由 AM–GM 得 \(\frac S6 \geq (abc)^{2/3} = V^{2/3}\)，等号在 \(ab = bc = ca\) 时成立，即正方体。

  4. 对 \(1/a_i\) 应用 AM–GM：\(\frac1n\sum\frac1{a_i} \geq \frac1G\)。再取倒数。

3.3 凸性的威力

  1. 若 \(\mathrm{f}'' < 0\)，斜率递减，所以曲线位于每条弦（chord）的上方。取 \(t = \frac13\)：\(\mathrm{f}\bigl(\frac{u + v + w}{3}\bigr) \geq \frac13\mathrm{f}(u) + \frac23\mathrm{f}\bigl(\frac{v + w}{2}\bigr) \geq \frac13\bigl(\mathrm{f}(u) + \mathrm{f}(v) + \mathrm{f}(w)\bigr)\)。

  2. \((\ln\sin x)'' = -\mathrm{cosec}^2x < 0\)，所以 \(\ln\sin\) 在 \((0, \pi)\) 上是凹（concave）函数。由延森不等式（Jensen’s inequality）得 \(\frac13\ln(\sin A\sin B\sin C) \leq \ln\sin\frac\pi3\)，所以该乘积最大为 \(\bigl(\frac{\sqrt3}{2}\bigr)^3\)。

  3. 在 \((0, \frac\pi2)\) 上 \((\tan x)'' = 2\sec^2x\tan x > 0\)；由延森不等式得 \(\tan A + \tan B + \tan C \geq 3\tan\frac\pi3 = 3\sqrt3\)。

  4. \((x^2)'' = 2 > 0\)；由延森不等式即得所求的不等式，它说明 \(\frac1n\sum a_i^2 - \bar a^2\)（即方差（variance））是非负的。

3.4 以面积证明不等式

  1. 取 \(\mathrm{f} = \sin\)，定义在 \([0, \frac\pi2]\) 上，等号在 \(b = \mathrm{f}(a)\) 时成立；取 \(a = \arcsin t\)、\(b = t\)：\(t\arcsin t = (1 - \cos(\arcsin t)) + \int_0^t\arcsin y\,\mathrm{d}y\)。把所得结果的右边求导，得 \(\arcsin t + \frac{t}{\sqrt{1 - t^2}} - \frac{t}{\sqrt{1 - t^2}} = \arcsin t\)。

  2. 在杨氏不等式（Young’s inequality）中取 \(p = q = 2\)，得 \(ab \leq \frac12(a^2 + b^2)\)。若 \(\sum a_i^2 = \sum b_i^2 = 1\)，逐项相加得 \(\sum a_ib_i \leq 1\)。一般情况下，把这个结果应用于 \(a_i/\sqrt{\sum a_j^2}\) 和 \(b_i/\sqrt{\sum b_j^2}\)。

  3. \(\int_0^a(e^x - 1)\,\mathrm{d}x = e^a - 1 - a\)，而 \(\int_0^b\ln(1 + y)\,\mathrm{d}y = (1 + b)\ln(1 + b) - b\)。等号在 \(b = e^a - 1\) 时成立。

  4. \(t = 1\)：\(1.571\) 对 \(1\)；\(t = 2\)：\(0.524\) 对 \(0.268\)；\(t = 10\)：\(0.1002\) 对 \(0.0501\)。当 \(t\) 很大时，\(t - \sqrt{t^2 - 1} = \frac{1}{t + \sqrt{t^2 - 1}} \approx \frac{1}{2t}\)。这个界来自 \(a = 0\) 的情况，此时 \((*)\) 只是说 \(0 \leq \int_0^b\arcsin y\,\mathrm{d}y\)；当 \(b\) 很小时，这块面积约为 \(\frac{b^2}{2}\)，是 \(b\arcsin b \approx b^2\) 的一半，把它舍去便损失了因子 \(2\)。

3.5 \(\pi^e\) 还是 \(e^\pi\)？

  1. \(n^m = m^n\) 即 \(h(n) = h(m)\)。\(h\) 在 \((1, e)\) 上递增，其后递减，所以两数之中有一个小于 \(e\)：它必定是 \(2\)（因为 \(h(1) = 0\) 这个值不会再次取到），于是另一个是 \(4\)。唯一的一对是 \(\{2, 4\}\)。

  2. \(e < 3 < \pi\)，而 \(h\) 在该处递减，所以 \(h(3) > h(\pi)\)，即 \(3^\pi > \pi^3\)。\(\frac94\) 和 \(\sqrt5\) 都小于 \(e\)，而 \(\frac94 > \sqrt5\)，所以 \(h(\frac94) > h(\sqrt5)\)，由此得第二个结果。对于 \(1 < x < 2\)：由于 \(3 < x + 2 < 4\)，有 \(h(x) < h(2) = h(4) < h(x + 2)\)，所以 \(x^{x+2} < (x + 2)^x\)。最后，\(9^{\sqrt2} = 3^{2\sqrt2}\)，而 \(\sqrt2^{\,9} = 16\sqrt2 = (2\sqrt2)^3\)。因为 \(e^2 < 8\)，所以 \(e < 2\sqrt2 < 3\)，而 \(h\) 在该处递减，故 \(h(2\sqrt2) > h(3)\)，由此得 \((2\sqrt2)^3 > 3^{2\sqrt2}\)：\(\sqrt2^{\,9}\) 较大。

  3. \(e^{\pi/e - 1} > \frac\pi e\)，所以 \(e^{\pi/e} > \pi\)；再把两边取 \(e\) 次方。

3.6 斜率的界

  1. 两边都是二次多项式，并且在 \(x = -1, 0, 1\) 处取值相同，所以两者相等（拉格朗日插值（Lagrange interpolation））。求导得 \(\mathrm{f}(-1)(x - \frac12) - 2\mathrm{f}(0)x + \mathrm{f}(1)(x + \frac12)\)。

  2. 在 \([-1, 1]\) 上 \(|\mathrm{f}'(x)| \leq |x - \frac12| + 2|x| + |x + \frac12| \leq 4\)，等号只在 \(x = \pm1\) 时成立，而且必须 \(\mathrm{f}(1)\)、\(\mathrm{f}(-1)\)、\(-\mathrm{f}(0)\) 全部等于 \(1\) 或全部等于 \(-1\)。二次多项式由这三个值唯一确定，于是得 \(\pm(2x^2 - 1)\)。

  3. 由 \(T_3(\cos\theta) = \cos3\theta\) 得 \(4x^3 - 3x\)，而 \(T_3'(1) = 12 - 3 = 9\)。由 \(\cos(n + 1)\theta + \cos(n - 1)\theta = 2\cos\theta\cos n\theta\)，得 \(T_{n+1} = 2xT_n - T_{n-1}\)，以及 \(T_4 = 8x^4 - 8x^2 + 1\)。

  4. \(-\sin\theta\,T_n'(\cos\theta) = -n\sin n\theta\)。当 \(\theta \to 0\) 时，\(\frac{n\sin n\theta}{\sin\theta} \to n^2\)。

3.7 \(\pi^2 \leq 10\)

  1. \(\int_0^\pi\mathrm{f}^2 = \frac{\pi^9}{630}\)，而 \(\int_0^\pi(\mathrm{f}')^2 = \frac{2\pi^7}{105}\)，所以由 \((*)\) 得 \(\pi^2 \leq 12\)。与 \(\sin x\) 相比，这个四次多项式在两端附近过于平坦，在中间又过于尖耸，所以它的斜率与大小之比离最优值较远。

  2. \(\int_0^\pi(\sin x + \sin2x)^2 = \frac\pi2 + \frac\pi2 = \pi\)（交叉项的积分为 \(0\)），而 \(\int_0^\pi(\cos x + 2\cos2x)^2 = \frac\pi2 + 2\pi = \frac{5\pi}{2}\)。

  3. 设 \(\mathrm{g}(x) = \mathrm{f}(\pi x/L)\)。左边按 \(\frac L\pi\) 的比例缩放，而 \(\int(\mathrm{g}')^2\) 则按 \(\frac{\pi}{L}\) 的比例缩放。对弦线而言，最低频率与 \(\frac1L\) 成正比：长度减半，音高便加倍。

  4. 界 \(\pi^2 \leq \int(\mathrm{f}')^2\big/\!\int\mathrm{f}^2\)（采用适当的单位）在 \(\lambda \approx 1.133/\pi^2\) 时取得最小值，由此得 \(\pi^2 \leq 9.86975\)，而真确值为 \(9.86960\)。

3.8 由加法公式决定的函数

  1. 代入 \(x = y = 0\) 得 \(\mathrm{g}(0) = 0\)。对 \(y\) 求导并取 \(y = 0\)，得 \(\mathrm{g}'(x) = k(1 + \mathrm{g}(x)^2)\)，所以 \(\frac{\mathrm{d}}{\mathrm{d}x}\arctan\mathrm{g}(x) = k\)，于是 \(\mathrm{g}(x) = \tan kx\)。

  2. 对 \(y\) 求导得 \(\mathrm{f}'(x + y) = \mathrm{f}'(y)\)，所以 \(\mathrm{f}'\) 是常数 \(k\)；又 \(\mathrm{f}(0) = 0\)（代入 \(x = y = 0\)）。

  3. \(\mathrm{f}(x) = \mathrm{f}(x/2)^2 \geq 0\)，而且 \(\mathrm{f}\) 永不为 \(0\)（否则它处处为 \(0\)）。用归纳法（induction）得 \(\mathrm{f}(n) = a^n\)；由 \(\mathrm{f}(1/n)^n = \mathrm{f}(1) = a\) 及 \(\mathrm{f}(1/n) > 0\) 得 \(a^{1/n}\)；于是 \(\mathrm{f}(m/n) = \mathrm{f}(1/n)^m\)。若没有连续性，函数在无理数处的值便不受限制：存在一些利用“哈默尔基（Hamel basis）”构造出来的奇怪解，它们并不是 \(a^x\)。

  4. 每次点火都使快度（rapidity）增加 \(\phi = \operatorname{artanh}\frac12\)，所以点火 \(k\) 次之后，速率为 \(\tanh k\phi = \frac{3^k - 1}{3^k + 1}\)：\(0.8c\)、\(\frac{13}{14}c \approx 0.929c\) 和 \(\frac{40}{41}c \approx 0.976c\)。

3.9 创造一个新函数

  1. 当 \(x = -1\) 时，\(x^2 - 2^x = \frac12 > 0\)；当 \(x = 0\) 时其值为 \(-1\)：所以有一个负根。设 \(x = -2u/\ln2\)，则 \(x^2 = 2^x\)（其中 \(x < 0\)，取 \(x = -2^{x/2}\)）化为 \(ue^u = \frac{\ln2}{2}\)，所以 \(u = \mathrm{g}\bigl(\frac{\ln2}{2}\bigr)\)，而 \(x \approx -0.7667\)。

  2. \(\mathrm{g}'e^{\mathrm{g}}(1 + \mathrm{g}) = 1\)，而 \(e^{\mathrm{g}} = x/\mathrm{g}\)。当 \(x = -\frac1e\) 时，\(\mathrm{g} = -1\)，斜率为无限大（图像在该处是垂直的）。

  3. 设 \(x = we^w\)，则 \(\mathrm{d}x = (1 + w)e^w\,\mathrm{d}w\)，而 \(w\) 由 \(0\) 变到 \(1\)：\(\int_0^1w(1 + w)e^w\,\mathrm{d}w = \bigl[(w^2 - w + 1)e^w\bigr]_0^1 = e - 1\)。

  4. \(T = \sqrt2^{\,T}\) 即 \(\frac{\ln T}{T} = \frac{\ln2}{2}\)，所以 \(T = 2\) 或 \(4\)。各项 \(1.414, 1.633, 1.761, \ldots\) 递增，并且一直小于 \(2\)（若 \(t_n < 2\)，则 \(t_{n+1} < \sqrt2^{\,2} = 2\)），所以 \(T = 2\)；不动点（fixed point）\(4\) 是排斥（repelling）的。
