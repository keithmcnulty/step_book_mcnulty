第 3 章 \(\cdot\) 引言

把事情做对

在数学里，你并不是理解了甚么，你只是习惯了它们。

— 冯·诺伊曼（John von Neumann）

以下是 \(1 = 2\) 的一个“证明”（proof）。设 \(a = b\)。那么 \(a^2 = ab\)，所以 \(a^2 - b^2 = ab - b^2\)，因式分解后得 \((a + b)(a - b) = b(a - b)\)。约去 \(a - b\) 得 \(a + b = b\)，而由于 \(a = b\)，这就是说 \(2b = b\)，所以 \(2 = 1\)。

你大概已经看出问题所在：由于 \(a = b\)，“约去 \(a - b\)”其实就是除以零。但请留意，每一步看起来都多么合理，而错误又多么容易藏在一个例行的步骤之中。真正的数学里，真正的错误很少这样明显，有史以来最伟大的一些数学家也曾被它们骗倒。本章要谈的，正是能把这些错误揪出来的思考习惯：精确的定义、小心运用定理，以及对看来太过容易的论证抱持适度的怀疑。

为甚么严谨很重要

在中学，数学主要是求出答案。到了大学，数学主要是知道自己的答案是对的，并且能够说服别人。这个转变是中学数学与大学数学之间最大的一个变化，也可能令人不安。一件“显然”成立的事，为甚么要花一整页去证明？

答案是：“显然”并不可靠。分析（analysis）的历史上，满是看似显然、实则错误的结果：连续（continuous）函数除了可能在少数几个孤立点之外必定可导（differentiable）（安培（André-Marie Ampère）在 1806 年发表过一个“证明”；到了 1872 年，魏尔斯特拉斯（Weierstrass）找到一个处处不可导的连续函数）；连续函数的收敛（convergent）和仍然连续（柯西（Cauchy）相信这一点；阿贝尔（Abel）找到了反例（counterexample））；收敛级数（series）的各项可以重新排列而不改变其和（一般而言，不可以）。严谨（rigour）并不是吹毛求疵，而是分辨真确与似是而非的唯一可靠方法。

不等式：分析的基本工具

本章的第二个主题是不等式（inequality）。在中学数学里，大部分结果都是等式：这个等于那个。在分析里，大部分结果都是不等式：这个至多是那个。要证明一个数列收敛，你要证明误差小于任何容许的限度；要证明一个积分存在，你要证明某个和有界；要估计一个近似值有多好，你要给误差定出一个界。专业的分析学家花在证明不等式上的时间，远多于证明等式，而你将在这里遇到的经典不等式（AM–GM、詹森（Jensen）、杨（Young）、赫尔德（Hölder）、柯西—施瓦兹（Cauchy–Schwarz））正是这一行的看家工具。

这些不等式本身也十分精彩。一条关于函数的不等式，配上一个精心挑选的例子，就能证明 \(\pi^2 \leq 10\)（第 3.7 节）。关于对数图像形状的一个事实，就能判定 \(\pi^e\) 与 \(e^\pi\) 哪个较大（第 3.5 节）。一位化学家关于量度误差的提问，引出了数学中最重要的一些多项式（第 3.6 节）。

你在大学会遇到甚么

严谨是大学一年级分析（Analysis）课程的主题，也是另一门常称为数与集合（Numbers and Sets）或数学基础（Foundations）的课程的主题，你会在那里学习怎样精确地书写证明。你会遇到连续性和可导性的正式定义，以及带有精确假设（hypothesis）的定理（介值定理（intermediate value theorem）、中值定理（mean value theorem）、极值定理（extreme value theorem）），而这些假设确实缺一不可。往后的课程会把本章的不等式发展成一门门完整的学科：泛函分析（functional analysis）研究函数空间，并以 第 3.4 节 和 第 3.7 节 中那类积分来量度其中的函数；凸分析（convex analysis）和最优化（optimisation）由 第 3.3 节 发展而来；逼近论（approximation theory）由 第 3.6 节 发展而来；而像 第 3.9 节 中那样的特殊函数（special functions），则在应用数学和物理学中随处可见。

贯穿本章的问题

三个大问题

  1. 怎样知道一个论证是正确的？看似合理的论证通常会在哪些地方出错？又应该怎样检查？

  2. 怎样证明一条不等式？经典不等式从何而来？又怎样选择用哪一条？

  3. 函数究竟是甚么？一个函数可否由它具有的某种性质来定义，而不是由公式来定义？当旧有的函数不够用时，我们可否创造新的函数？

本章以找错开始（第 3.1 节），然后逐一探讨各条经典不等式，每条都从不同的角度切入：一种不寻常的归纳法（induction）、凸性（convexity）、面积、图像的形状、多项式插值（polynomial interpolation）和试验函数（test function）。最后两节讨论由性质定义的函数：由加法定律（addition law）得出的 \(e^x\) 和 \(\tanh x\)，以及一个以反函数（inverse）形式定义的全新函数。
