第 4 章 · 严谨的微积分

延伸练习答案

以下只是简短的答案和提示，并非完整解答：只列出结果和关键步骤，方便你核对自己的做法。请先认真做过每道练习，然后才看答案。

4.1 甚么是积分？

  1. 这个和是 \(y = \mathrm{f}(x)\) 之下、在 \([1, 2]\) 上 \(n\) 个阔度为 \(\frac1n\) 的长方形的总面积。取 \(\mathrm{f}(x) = \frac1x\)，得 \(\frac1n\sum\frac{1}{1 + m/n} = \sum\frac{1}{n + m} \to \ln2\)。第二个和是 \(\frac1n\sum\frac{1}{1 + (m/n)^2} \to \int_0^1\frac{\mathrm{d}x}{1 + x^2} = \frac\pi4\)。

  2. 分成 \(n\) 条时，上和（upper sum）是 \(\frac an\sum_{r=1}^{n}\bigl(\frac{ra}{n}\bigr)^2 = \frac{a^3(n + 1)(2n + 1)}{6n^2}\)，下和（lower sum）则只须把第一个因子中的 \(n + 1\) 换成 \(n - 1\)；两者都趋向 \(\frac{a^3}{3}\)。

  3. 各项可以裂项相消（telescope）：\(r(r + 1)\cdots(r + k) - (r - 1)r\cdots(r + k - 1) = (k + 1)\,r(r + 1)\cdots(r + k - 1)\)。

  4. \(\sum_{r=1}^nr^5 = \frac{n^2(n + 1)^2(2n^2 + 2n - 1)}{12}\)。

4.2 由一个积分建立三角学

  1. 导数（derivative）是 \(-\mathrm{f}(a - x)\mathrm{f}(x) + \mathrm{f}(a - x)\mathrm{f}(x) = 0\)，所以 \(\mathrm{f}(a - x)\mathrm{f}(x) = \mathrm{f}(a)\)；代入 \(a = x + y\) 即可。至于余弦，固定 \(y\)，设 \(p(x) = \mathrm{c}(x + y) - \mathrm{c}(x)\mathrm{c}(y) + \mathrm{s}(x)\mathrm{s}(y)\) 及 \(q(x) = \mathrm{s}(x + y) - \mathrm{s}(x)\mathrm{c}(y) - \mathrm{c}(x)\mathrm{s}(y)\)。于是 \(p' = -q\) 而 \(q' = p\)，所以 \(p^2 + q^2\) 是常数，而它在 \(x = 0\) 时等于 \(0\)。

  2. \(\frac{\mathrm{d}y}{\mathrm{d}u} = (1 + u^2)^{-3/2}\) 而 \(\sqrt{1 - y^2} = (1 + u^2)^{-1/2}\)，所以 \(\frac{\mathrm{d}y}{\sqrt{1 - y^2}} = \frac{\mathrm{d}u}{1 + u^2}\)。于是 \(\mathrm{S}(\frac{1}{\sqrt2}) = \mathrm{T}(1)\)，而在第 (i) 部分取 \(x = 1\) 便得 \(\mathrm{T}(1) = \frac12\mathrm{T}_\infty\)。

  3. 取 \(a = \frac12\) 及 \(x = \frac13\)，则 \(\frac{x + a}{1 - ax} = 1\)，所以 \(\mathrm{T}(\frac13) = \mathrm{T}(1) - \mathrm{T}(\frac12)\)。

  4. 在 \([0, 1]\) 上 \(\frac{1}{1 + u^2} \leq 1\)，在 \([1, x]\) 上则 \(\leq \frac{1}{u^2}\)，所以当 \(x \geq 1\) 时，\(\mathrm{T}(x) \leq 1 + (1 - \frac1x) < 2\)；当 \(0 < x < 1\) 时，\(\mathrm{T}(x) < \mathrm{T}(1) \leq 1\)。（上界 \(1 + \int_1^x u^{-2}\,\mathrm{d}u\) 在 \(x < 1\) 时并不成立：在 \(x = \frac12\) 时它等于 \(0\)。）\(\mathrm{T}\) 递增而且有界（bounded），所以它有极限（limit）。

4.3 \(22/7\) 大于 \(\pi\)

  1. \(\frac{22}{7} - \pi \approx 0.001264\)，介乎 \(\frac{1}{1260} \approx 0.000794\) 与 \(\frac{1}{630} \approx 0.001587\) 之间。

  2. \(\frac{(4!)^2}{9!} = \frac{576}{362\,880} = \frac{1}{630}\)。

  3. \(\frac{x(1 - x)^2}{1 + x^2} = x - 2 + \frac{2}{1 + x^2}\)，积分（integrate）后得 \(\frac12 - 2 + \frac\pi2\)。同样地，\(\frac{x^2(1 - x)^4}{1 + x^2} = x^4 - 4x^3 + 5x^2 - 4 + \frac{4}{1 + x^2}\)，积分后得 \(\frac15 - 1 + \frac53 - 4 + \pi = \pi - \frac{47}{15}\)。两个积分都是正数。这两个被积函数（integrand）远大于 \(\frac{x^4(1 - x)^4}{1 + x^2}\)（其最大值约为 \(0.003\)），所以误差 \(\frac\pi2 - \frac32 \approx 0.07\) 和 \(\pi - \frac{47}{15} \approx 0.008\) 也较大。

  4. 多项式除法（polynomial division）余下 \(\frac{16}{1 + x^2}\)，积分后得 \(4\pi\)；整个积分是 \(4\pi - \frac{188684}{15015} \approx 3.6 \times 10^{-6}\)，所以 \(\pi \approx 3.14159174\)。

4.4 沃利斯、Beta 与二分之一的阶乘

  1. \(u_{2m} = \frac{1 \cdot 3 \cdots (2m - 1)}{2 \cdot 4 \cdots 2m}\cdot\frac\pi2\) 而 \(u_{2m+1} = \frac{2 \cdot 4 \cdots 2m}{3 \cdot 5 \cdots (2m + 1)}\)。于是 \(1 < \frac{u_{2m}}{u_{2m+1}} < \frac{u_{2m-1}}{u_{2m+1}} = \frac{2m + 1}{2m}\)，所以这个比趋向 \(1\)，整理后即得 \(\frac\pi2 = \prod_{k \geq 1}\frac{(2k)^2}{(2k - 1)(2k + 1)}\)。

  2. 分部积分法（integration by parts）给出 \(I_n = \frac{n}{n + 1}\int_0^1x^{n+1}(1 - x)^{n-1}\,\mathrm{d}x\)，再写成 \(x^{n+1}(1 - x)^{n-1} = x^n(1 - x)^{n-1} - x^n(1 - x)^n\) 并利用对称性，便得 \(I_n = \frac{n}{2(2n + 1)}I_{n-1}\)；用归纳法（induction）可得 \(\frac{(n!)^2}{(2n + 1)!}\)。取 \(x = \sin^2\theta\)，得 \(I_{1/2} = \int_0^{\pi/2}2\sin^2\theta\cos^2\theta\,\mathrm{d}\theta = \frac\pi8\)。公式提示 \(\bigl((\frac12)!\bigr)^2/2! = \frac\pi8\)，所以 \((\frac12)! = \frac{\sqrt\pi}{2}\)（即 \(\Gamma(\frac32)\)）。

  3. 对称性来自 \(x \mapsto 1 - x\)；递推关系（recurrence）来自 \(x^p = x^{p-1} - x^{p-1}(1 - x)\)；而取 \(x = \frac{t}{1 + t}\) 时，\(1 - x = \frac{1}{1 + t}\) 且 \(\mathrm{d}x = \frac{\mathrm{d}t}{(1 + t)^2}\)。该积分是 \(\mathrm{b}(\frac52, \frac72)\)；利用递推关系和对称性化简至 \(\mathrm{b}(\frac12, \frac12) = \pi\)，便得 \(\frac{3\pi}{256}\)。

  4. 由第 (i) 部分的显式数值，\(u_{2m} = \frac{(2m)!}{(2^mm!)^2}\cdot\frac\pi2 = \binom{2m}{m}\frac{\pi}{2^{2m+1}}\)。于是由 \(2mu_{2m}^2 \to \frac\pi2\) 得 \(\binom{2m}{m}^2 \approx \frac{4^{2m}}{\pi m}\)。当 \(m = 10\) 时：\(\binom{20}{10} = 184\,756\)，而 \(\frac{4^{10}}{\sqrt{10\pi}} \approx 187\,079\)（高出约 \(1.3\%\)）。

4.5 大二学生之梦

  1. \(x^{-x} = e^{-x\ln x} = \sum_{n \geq 0}\frac{(-x\ln x)^n}{n!}\)，而 \(\int_0^1\frac{x^n(-\ln x)^n}{n!}\,\mathrm{d}x = \frac{1}{(n + 1)^{n+1}}\)（代入 \(x = e^{-u}\)）。所以该积分是 \(\sum_{n \geq 1}n^{-n} \approx 1.2913\)。

  2. \(\frac{\mathrm{d}}{\mathrm{d}x}x^x = x^x(\ln x + 1)\)，在 \(x = \frac1e\) 时为零；其值为 \((e^{-1})^{e^{-1}} = e^{-1/e} \approx 0.692\)。

  3. 各项是 \(\frac{1}{n^n}\)。取 \(7\) 项后停止，误差小于 \(\frac{1}{8^8} \approx 6 \times 10^{-8}\)，已经足够；只取 \(6\) 项的话，上界 \(\frac{1}{7^7} \approx 1.2 \times 10^{-6}\) 并不足够。所以要取 \(7\) 项。

  4. 用分部积分法：\(\int_0^1x^2\ln x\,\mathrm{d}x = \bigl[\frac{x^3\ln x}{3}\bigr]_0^1 - \int_0^1\frac{x^2}{3}\,\mathrm{d}x = -\frac19\)。一般而言 \(\int_0^1x^n\ln x\,\mathrm{d}x = -\frac{1}{(n + 1)^2}\)，而 \(\frac{\ln x}{1 - x} = \sum_{n \geq 0}x^n\ln x\)。

4.6 没有公式的积分

  1. 求导：\(\frac{\mathrm{d}}{\mathrm{d}x}\frac{e^x}{x + 1} = \frac{xe^x}{(x + 1)^2}\)，而 \(\frac{\mathrm{d}}{\mathrm{d}x}\frac{(x - 1)e^x}{x + 1} = e^x\Bigl(\frac{x - 1}{x + 1} + \frac{2}{(x + 1)^2}\Bigr) = \frac{(x^2 + 1)e^x}{(x + 1)^2}\)。

  2. \(\frac{\mathrm{d}}{\mathrm{d}x}\bigl(\mathrm{P}e^{-x^2}\bigr) = (\mathrm{P}' - 2x\mathrm{P})e^{-x^2}\)，而 \(\mathrm{P}' - 2x\mathrm{P}\) 的次数是 \(\deg\mathrm{P} + 1 \geq 1\)（当 \(\mathrm{P} \neq 0\)），所以它不可能等于 \(1\)。

  3. 假如 \(\mathrm{R} = \mathrm{P}/\mathrm{Q}\)（已约至最简）在 \(0\) 处有 \(k \geq 1\) 阶的极点（pole），则 \(\mathrm{R}' + \mathrm{R}\) 在该处会有 \(k + 1 \geq 2\) 阶的极点，但 \(\frac1x\) 的极点只是 \(1\) 阶。假如 \(\mathrm{R}\) 在 \(0\) 处没有极点，则 \(\mathrm{R}' + \mathrm{R}\) 也没有。无论哪种情况，都有 \((\mathrm{R}e^x)' \neq \frac{e^x}{x}\)。

  4. 对 \(\frac{\mathrm{P}e^x}{x + 1}\) 求导，得 \(e^x\frac{(x + 1)\mathrm{P}' + x\mathrm{P}}{(x + 1)^2}\)。在 \(x = -1\) 处：\(\mathrm{f}(-1) = -\mathrm{P}(-1)\)，而由 \(\mathrm{f}' = (x + 1)\mathrm{P}'' + (x + 1)\mathrm{P}' + \mathrm{P}\) 得 \(\mathrm{f}'(-1) = \mathrm{P}(-1)\)。对于 \(x^3 - 2\)：\(-3 + 3 = 0\)；对于 \(x\)：\(-1 + 1 = 0\)；对于 \(x^2 + 1\)：\(2 - 2 = 0\)。这个条件也是充分的：映射 \(\mathrm{P} \mapsto (x + 1)\mathrm{P}' + x\mathrm{P}\) 把次数小于 \(d\) 的多项式映到次数不超过 \(d\) 的多项式，而且是单射（injective），所以它的像（image）的维数（dimension）是 \(d\)，并且包含在由满足 \(\mathrm{f}(-1) + \mathrm{f}'(-1) = 0\) 的 \(\mathrm{f}\) 所组成的 \(d\) 维空间之内；因此像就是整个空间。

4.7 变分法

  1. 取 \(y = \cos\frac{\pi x}{2}\)，得 \(J = \frac{\pi^2}{4}\int_0^1\sin^2 - a^2\int_0^1\cos^2 = \frac12\bigl(\frac{\pi^2}{4} - a^2\bigr) < 0\)。

  2. \(J(y + \varepsilon\eta) = J(y) + 2\varepsilon\int_0^1(y'\eta' - a^2y\eta) + \varepsilon^2J(\eta)\)；要在 \(\varepsilon = 0\) 处取得最小值，线性项必须为零。分部积分后，对每个满足 \(\eta(1) = 0\) 的 \(\eta\) 都有 \(-y'(0)\eta(0) - \int_0^1(y'' + a^2y)\eta = 0\)，由此必有 \(y'' + a^2y = 0\) 及 \(y'(0) = 0\)。

  3. 取 \(x = Lu\)，得 \(\int_0^L\bigl((y')^2 - a^2y^2\bigr)\,\mathrm{d}x = \frac1L\int_0^1\bigl((Y')^2 - (aL)^2Y^2\bigr)\,\mathrm{d}u\)，所以条件是 \(aL \leq \frac\pi2\)。（当 \(aL = \frac\pi2\) 时，正如正文所述，积分仍然不会是负数，但 \(y = \cos\frac{\pi x}{2L}\) 会令它等于零；当 \(aL > \frac\pi2\) 时，同一个函数会令它变成负数。）

  4. 摆线（cycloid）是 \(x = R(\theta - \sin\theta)\), \(y = R(1 - \cos\theta)\)。关于等时曲线（tautochrone），见 第 11.4 节：以弧长（arc length）表示时，该运动恰好是简谐运动（simple harmonic motion）。

4.8 切球形面包

  1. \(V/A = \frac{\frac43\pi a^3}{4\pi a^2} = \frac a3\)。但余下一块高度为 \(t\) 的部分有 \(A = 2\pi at\) 及 \(V = \frac13\pi t^2(3a - t)\)，所以 \(V/A = \frac{t(3a - t)}{6a}\)，它在 \(t = \frac32a\) 时取得最大值 \(\frac{3a}{8}\)：比 \(\frac a3\) 还要大。

  2. 这条带的高度是 \(2R\sin23.4^\circ\)，而球的高度是 \(2R\)，所以所占比例是 \(\sin23.4^\circ \approx 0.40\)。

  3. 对于 \(y = \sqrt x\)，\(y\sqrt{1 + (y')^2} = \sqrt{x + \frac14}\)，并非常数。由 \(y\sqrt{1 + (y')^2} = c\) 得 \((y')^2 = \frac{c^2}{y^2} - 1\)，其解为 \(y = c\)（圆柱）以及圆 \((x - x_0)^2 + y^2 = c^2\)（球）。

  4. 球的体积是 \(\frac43\pi a^3\)，圆柱的体积是 \(\pi a^2 \cdot 2a = 2\pi a^3\)；两者之比是 \(\frac23\)。

4.9 Holditch 定理

  1. \(\frac12\int_0^{2\pi}(p\cos t \cdot q\cos t + q\sin t \cdot p\sin t)\,\mathrm{d}t = \frac12 \cdot 2\pi pq = \pi pq\)。

  2. 把两条弦（chord）的端点连起来所得的两个三角形相似（同弧所对的角相等），所以 \(PA \cdot PB = PC \cdot PD\)。对于半径为 \(R\) 的圆，若 \(P\) 与圆心的距离为 \(r\)，则通过 \(P\) 的直径给出 \((R - r)(R + r)\)，所以 \(ab = R^2 - r^2\)，而圆环的面积是 \(\pi R^2 - \pi r^2 = \pi ab\)。

  3. 若 \(a = b\)，则 \(f = \pi(a - b) = 0\)，而圆环的面积是 \(\pi a^2 = \frac{\pi L^2}{4}\)：即以该杆为直径的圆的面积。

  4. 沿着通过 \(O\) 的两条边，\(x\,\mathrm{d}y - y\,\mathrm{d}x = 0\)。第三条边以 \((x_1, y_1) + s(x_2 - x_1, y_2 - y_1)\)（其中 \(0 \leq s \leq 1\)）作参数表示，在这条边上它等于 \((x_1y_2 - x_2y_1)\,\mathrm{d}s\)。所以面积是 \(\frac12|x_1y_2 - x_2y_1|\)。
