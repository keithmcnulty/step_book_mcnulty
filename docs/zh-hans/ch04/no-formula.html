4.6

没有公式的积分

工作纸题目连结、提示、大学数学及练习 第 4 章整章的 PDF 版本
题目

STEP III 2016，第 3 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/16-s3-q3

引子

求导（differentiation）是机械式的工作：有一套法则可循，任何由常见部件砌成的函数，只要套用这些法则就能求导。积分（integration）却不然。每个学生都遇过各种技巧都攻不破的积分，并怀疑是否只是自己不够聪明。有时答案是：谁也不够聪明，因为根本没有公式。

本题就在一个特殊情况下证明这样的事。积分 \(\int \frac{e^x}{x+1}\,\mathrm{d}x\) 作为面积当然存在，但它不能写成（有理函数）\(\times\, e^x\) 的形式，而这正是用分部积分法（integration by parts）时预期会得到的形式。证明某件事不可能做到，而不是把某样东西找出来，是另一种数学，也极具数学的特色。

动笔之前

若 \(\int \mathrm{f}(x)e^x\,\mathrm{d}x = \frac{\mathrm{P}}{\mathrm{Q}}e^x + C\)，\(\mathrm{P}\) 和 \(\mathrm{Q}\) 必须满足甚么方程？（对右边求导。）

求导得 \(\dfrac{\mathrm{d}}{\mathrm{d}x}\left(\dfrac{\mathrm{P}}{\mathrm{Q}}e^x\right) = \dfrac{\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q}}{\mathrm{Q}^2}\,e^x\)，而这必须等于 \(\mathrm{f}(x)e^x\)。所以整道题目其实围绕着以下的多项式恒等式（polynomial identity）： \[\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q} = \mathrm{f}\,\mathrm{Q}^2.\] 关于积分的问题，就此变成关于多项式的问题：它们的因式和次数。

逐步解题

阶段 1 因式 \(x + 1\)

取 \(\mathrm{f}(x) = \dfrac{x^3 - 2}{(x+1)^2}\)，把恒等式两边同乘 \((x+1)^2\)： \[(x+1)^2\bigl(\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q}\bigr) = (x^3 - 2)\,\mathrm{Q}^2. \tag{$\dagger$}\]

在 \((\dagger)\) 中代入 \(x = -1\)。必然会出现甚么情况？

当 \(x = -1\) 时，左边等于 \(0\)，右边则是 \((-1 - 2)\,\mathrm{Q}(-1)^2 = -3\,\mathrm{Q}(-1)^2\)。所以 \(\mathrm{Q}(-1) = 0\)，而根据因式定理（factor theorem），\(x + 1\) 是 \(\mathrm{Q}\) 的因式。■

阶段 2 次数

设 \(\mathrm{P}\) 的次数（degree）为 \(p\)，\(\mathrm{Q}\) 的次数为 \(q\)。

在 \(\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q}\) 中，哪一项的次数最高？它会被其余各项抵消吗？

\(\mathrm{P}\mathrm{Q}\) 的次数是 \(p + q\)，而 \(\mathrm{P}'\mathrm{Q}\) 和 \(\mathrm{P}\mathrm{Q}'\) 的次数最多是 \(p + q - 1\)。所以 \((\dagger)\) 左边的次数恰好是 \(2 + p + q\)，右边的次数是 \(3 + 2q\)。令两者相等，得 \(p = q + 1\)。■

阶段 3 求 \(\mathrm{P}\)

取 \(\mathrm{Q} = x + 1\)，则 \(\mathrm{Q}' = 1\)，而 \(\mathrm{P}\) 的次数为 \(2\)。把 \((\dagger)\) 除以 \((x + 1)^2\)： \[\mathrm{P}'(x + 1) - \mathrm{P} + \mathrm{P}(x + 1) = x^3 - 2, \qquad\text{即}\qquad (x + 1)\mathrm{P}' + x\mathrm{P} = x^3 - 2.\] 试设 \(\mathrm{P} = \alpha x^2 + \beta x + \gamma\)。左边是 \[(x + 1)(2\alpha x + \beta) + \alpha x^3 + \beta x^2 + \gamma x = \alpha x^3 + (2\alpha + \beta)x^2 + (2\alpha + \beta + \gamma)x + \beta.\] 与 \(x^3 - 2\) 比较系数：\(\alpha = 1\)；\(2\alpha + \beta = 0\)，故 \(\beta = -2\)；于是 \(\gamma = 0\)；常数项 \(\beta = -2\) 亦吻合。所以 \[\mathrm{P}(x) = x^2 - 2x, \qquad \int \frac{x^3 - 2}{(x+1)^2}\,e^x\,\mathrm{d}x = \frac{x^2 - 2x}{x + 1}\,e^x + C. \qed\] （有兴趣的话可以求导验算，这是练习商法则（quotient rule）的好题目。）

阶段 4 一件不可能的事

现在假设 \(\int \frac{e^x}{x+1}\,\mathrm{d}x = \frac{\mathrm{P}}{\mathrm{Q}}e^x + C\)，其中 \(\mathrm{P}\) 和 \(\mathrm{Q}\) 没有公因式（common factor）。恒等式变成 \[(x + 1)\bigl(\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q}\bigr) = \mathrm{Q}^2.\] 一如第 1 阶段，代入 \(x = -1\) 可知 \(\mathrm{Q}(-1) = 0\)。写成 \(\mathrm{Q} = (x+1)^k\mathrm{R}\)，其中 \(k \geq 1\) 且 \(\mathrm{R}(-1) \neq 0\)（即尽量抽出 \(x + 1\) 这个因式）。

代入 \(\mathrm{Q} = (x+1)^k\mathrm{R}\)，尽量约去 \((x + 1)\) 的因式，然后代入 \(x = -1\)。你能得知 \(\mathrm{P}(-1)\) 的甚么性质？

这时 \(\mathrm{Q}' = k(x+1)^{k-1}\mathrm{R} + (x+1)^k\mathrm{R}'\)，而 \[\mathrm{P}'\mathrm{Q} - \mathrm{P}\mathrm{Q}' + \mathrm{P}\mathrm{Q} = (x+1)^{k-1}\Bigl[(x+1)\bigl(\mathrm{P}'\mathrm{R} - \mathrm{P}\mathrm{R}' + \mathrm{P}\mathrm{R}\bigr) - k\mathrm{P}\mathrm{R}\Bigr].\] 所以恒等式变成 \((x+1)^k\bigl[(x+1)(\mathrm{P}'\mathrm{R} - \mathrm{P}\mathrm{R}' + \mathrm{P}\mathrm{R}) - k\mathrm{P}\mathrm{R}\bigr] = (x+1)^{2k}\mathrm{R}^2\)。除以 \((x+1)^k\)： \[(x+1)\bigl(\mathrm{P}'\mathrm{R} - \mathrm{P}\mathrm{R}' + \mathrm{P}\mathrm{R}\bigr) - k\mathrm{P}\mathrm{R} = (x+1)^k\mathrm{R}^2.\] 当 \(x = -1\) 时，由于 \(k \geq 1\)，上式给出 \(-k\,\mathrm{P}(-1)\mathrm{R}(-1) = 0\)。因为 \(k \neq 0\) 且 \(\mathrm{R}(-1) \neq 0\)，必有 \(\mathrm{P}(-1) = 0\)。但这样 \(x + 1\) 就同时整除 \(\mathrm{P}\) 和 \(\mathrm{Q}\)，与两者没有公因式的假设矛盾。所以这样的 \(\mathrm{P}\) 和 \(\mathrm{Q}\) 并不存在。■

回顾

  • 转化为代数。“这个积分能否写成这种形式？”变成了“这个多项式恒等式有没有解？”

  • 在特殊点取值。代入 \(x = -1\) 就得到关于因式的信息，前后共用了三次。

  • 利用最简分数的反证法（proof by contradiction）。正如 第 1.3 节 中处理 \(\sqrt2\) 的做法，先假设分数已约至最简，再找出一个公因式，便得到矛盾。

背后的数学

极点与对数

第 (ii) 部分背后有一幅简单的图像。被积函数（integrand）\(\frac{e^x}{x+1}\) 在 \(x = -1\) 处有一个单极点（simple pole）：在该点附近，它的表现像 \(\frac{e^{-1}}{x+1}\)。对 \(\frac{1}{x+1}\) 积分得 \(\ln|x+1|\)，所以原函数（antiderivative）在 \(-1\) 附近的表现应该像 \(e^{-1}\ln|x+1|\)，以对数的速度趋向 \(-\infty\)（图 4.6.1）。但有理函数乘以 \(e^x\) 只能以幂 \((x+1)^{-k}\) 的方式趋向无穷，其导数因而有一个阶数为 \(k + 1 \geq 2\) 的极点，绝不会是单极点。有理函数无法产生对数式的表现；第 4 阶段的代数运算，正是这个观察的严格版本。相反，在第 (i) 部分，被积函数有一个二阶极点，而这正是带有单极点的函数求导后的模样，所以答案才有可能是有理的。

刘维尔与 Risch 算法

在 1830 年代，刘维尔（Joseph Liouville）建立了一套理论，研究哪些积分可以用初等函数（elementary functions）表示（即由多项式、指数函数、对数函数、根式和三角函数经通常的运算构成的函数）。他的其中一个结果指出：若 \(\mathrm{f}\) 和 \(\mathrm{g}\) 是有理函数而 \(\mathrm{g}\) 不是常数，则 \(\int \mathrm{f}(x)e^{\mathrm{g}(x)}\,\mathrm{d}x\) 只有在等于 \(\mathrm{R}(x)e^{\mathrm{g}(x)}\)（另加一个常数）时才是初等的，其中 \(\mathrm{R}\) 是某个有理函数。（对 \(\mathrm{g}\) 的条件不可或缺：当 \(\mathrm{g} = 0\) 而 \(\mathrm{f}(x) = \frac1x\) 时，积分是 \(\ln|x|\)，它是初等函数，却不是有理函数。）所以本题排除了有理形式，其实就证明了 \(\int \frac{e^x}{x+1}\,\mathrm{d}x\) 根本不是初等函数。同一定理的其他版本可证明 \(\int e^{-x^2}\,\mathrm{d}x\) 和 \(\int \frac{\sin x}{x}\,\mathrm{d}x\) 都不是初等的。1969 年，Robert Risch 把刘维尔的想法发展成一套算法（algorithm），可就一大类函数判定初等积分是否存在，并在存在时把它求出来。电脑代数系统（computer algebra system）内部所用的，就是这套算法的不同版本。

特殊函数

当一个积分没有初等形式时，数学家会给它起个名字，把它当作新的函数来研究，正如我们在 第 3.9 节 中处理朗伯 W 函数（Lambert W function）那样。这里的积分本质上就是指数积分（exponential integral）\(\mathrm{Ei}(x)\)，它出现于热传导问题，也出现于对数积分（logarithmic integral）\(\mathrm{li}(x) = \mathrm{Ei}(\ln x)\) 之中，后者是不超过 \(x\) 的质数（prime）个数的最佳简单近似（第 1.2 节）。当 \(x < 0\) 时，它是 \(\int_{-\infty}^x \frac{e^t}{t}\,\mathrm{d}t\)。当 \(x > 0\) 时，这个积分会穿过 \(t = 0\) 处的无穷尖峰，所以 \(\mathrm{Ei}(x)\) 的定义是先挖去尖峰周围的一个小区间 \((-\varepsilon, \varepsilon)\)，再令 \(\varepsilon \to 0\)：这就是柯西主值（Cauchy principal value）。

思维技巧

证明不可能

要证明某件事做不到，先假设它做得到，把这个假设转化为精确的代数式，然后推出矛盾。

困难在于转化：要为“做得到”的意思找出一个精确的陈述。在这里，它的意思是“存在没有公因式的多项式 \(\mathrm{P}\)、\(\mathrm{Q}\) 满足这个恒等式”。数学中许多最深刻的结果，都是这类不可能性证明。

延伸练习

  1. 两个可行的例子。证明 \(\displaystyle\int \frac{x e^x}{(x+1)^2}\,\mathrm{d}x = \frac{e^x}{x+1} + C\) 及 \(\displaystyle\int \frac{(x^2 + 1)e^x}{(x+1)^2}\,\mathrm{d}x = \frac{x - 1}{x + 1}\,e^x + C\)。

  2. 高斯函数。证明不存在多项式 \(\mathrm{P}\) 使得 \(\displaystyle\int e^{-x^2}\,\mathrm{d}x = \mathrm{P}(x)e^{-x^2} + C\)。（提示：求导后比较次数。）

  3. 另一个极点。仿照第 (ii) 部分的论证，证明 \(\displaystyle\int \frac{e^x}{x}\,\mathrm{d}x\) 不能写成 \(\frac{\mathrm{P}(x)}{\mathrm{Q}(x)}e^x + C\) 的形式。

  4. 何时可行？假设 \(\mathrm{f}\) 是多项式，且对某个多项式 \(\mathrm{P}\) 有 \(\displaystyle\int \frac{\mathrm{f}(x)}{(x+1)^2}\,e^x\,\mathrm{d}x = \frac{\mathrm{P}(x)}{x+1}\,e^x + C\)。证明 \((x+1)\mathrm{P}' + x\mathrm{P} = \mathrm{f}\)，并通过计算此式及其导数在 \(x = -1\) 的值，证明 \(\mathrm{f}(-1) + \mathrm{f}'(-1) = 0\)。验证这个条件对 \(\mathrm{f}(x) = x^3 - 2\) 以及练习 1 的例子都成立。 较难 你能证明这个条件也是充分的吗？

延伸阅读

  • Brian Conrad, “Impossibility theorems for elementary integration”（初等积分的不可能性定理）。可免费取得的讲义，配合例子讲解刘维尔定理。

  • Elena Anne Marchisotto & Gholam-Ali Zakeri, “An invitation to integration in finite terms”（有限形式积分导引），The College Mathematics Journal 25 (1994)。刘维尔理论的浅白入门。

  • Manuel Bronstein, Symbolic Integration I（Springer）。讲述电脑代数系统实际上如何求积分。程度较深。
