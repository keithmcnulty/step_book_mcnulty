5.8

圆盘中隐藏的距离

题目

STEP III 2013，第 6 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/13-s3-q6

引子

乍看之下，这只是一道运算模（modulus）和共轭（conjugate）的练习，最后得出一条模样古怪的不等式。为甚么会有人关心 \(\frac{|z - w|}{|1 - zw^*|}\) 呢？

因为它是一个距离。它不是 \(z\) 与 \(w\) 之间的普通距离，而是另一种几何中的距离：在这种几何里，单位圆盘（unit disc）本身就是一个无限大的完整宇宙，直线是圆弧，三角形的内角和小于 \(180^\circ\)。这就是双曲几何（hyperbolic geometry）。两千年来，人们一直试图证明欧几里得（Euclid）的平行公设（parallel postulate），到了十九世纪才发现这种几何；而本题的不等式，原来正是它的三角不等式（triangle inequality），只是乔装了一番。更令人意外的是，不等式的右边正是狭义相对论（special relativity）中的速度相加公式，我们在 第 3.8 节 已经见过。

动笔之前

怎样从图形看出 \(|z - w| \leq |z| + |w|\)？（把 \(z\) 和 \(-w\) 想成向量。）

\(z - w = z + (-w)\)。先把 \(z\) 画成由原点出发的箭嘴，再把 \(-w\) 画成由 \(z\) 的尖端出发的箭嘴。由原点指向终点的箭嘴就是 \(z - w\)，三支箭嘴组成一个三角形，边长分别为 \(|z|\)、\(|w|\) 和 \(|z - w|\)。三角形任何一边的长度都不超过另外两边之和。

另外要记得，对任何复数 \(a\) 都有 \(|a|^2 = aa^*\)。这样就可以把题目中每一个模都化为代数运算。

逐步解题

阶段 1 展开各个模

展开 \(|z - w|^2 = (z - w)(z^* - w^*)\)，再与 \((|z| + |w|)^2\) 比较。

\(|z - w|^2 = zz^* - zw^* - z^*w + ww^* = |z|^2 + |w|^2 - zw^* - z^*w\)。另一方面，\((|z| + |w|)^2 - E = |z|^2 + 2|z||w| + |w|^2 - zw^* - z^*w - 2|zw|\)，而由于 \(|z||w| = |zw|\)，两者相等。■

\(E = (zw^*) + (zw^*)^* + 2|zw| = 2\,\mathrm{Re}(zw^*) + 2|zw|\)，这是实数。而且根据三角不等式，\(E = (|z| + |w|)^2 - |z - w|^2 \geq 0\)。■

阶段 2 第二条恒等式

\(|1 - zw^*|^2 = (1 - zw^*)(1 - z^*w) = 1 - zw^* - z^*w + |z|^2|w|^2\)，而 \((1 + |zw|)^2 - E = 1 + 2|zw| + |zw|^2 - zw^* - z^*w - 2|zw|\)，两者相等。■

阶段 3 不等式

设 \(A = (|z| + |w|)^2\) 和 \(B = (1 + |zw|)^2\)。把不等式两边平方后，它就是 \(\frac{A - E}{B - E} \leq \frac AB\)。这在甚么时候成立？

所求不等式的两边都是非负的，所以它等价于平方后的不等式 \(\frac{A - E}{B - E} \leq \frac{A}{B}\)。假设 \(B - E = |1 - zw^*|^2 > 0\)，两边乘开： \[(A - E)B \leq A(B - E) \iff -EB \leq -EA \iff E(B - A) \geq 0.\] 由于 \(E \geq 0\)，只要 \(B \geq A\)，即 \(1 + |zw| \geq |z| + |w|\)，上式便成立。

证明 \(1 + |z||w| - |z| - |w|\) 可以因式分解。它在甚么时候非负？

\(1 + |z||w| - |z| - |w| = (1 - |z|)(1 - |w|)\)。若 \(|z| > 1\) 且 \(|w| > 1\)，两个因式都是负数，乘积为正。所以 \(B \geq A\)，不等式成立。■

若改为 \(|z| < 1\) 且 \(|w| < 1\)，两个因式都是正数，乘积同样为正，同一个论证依然适用：是的，不等式在这个情况下也成立。（在这两个情况下都有 \(|zw^*| \neq 1\)，所以 \(1 - zw^* \neq 0\)，左边有定义。）不等式可能不成立的，是混合的情况：一点在单位圆内，另一点在单位圆外。

回顾

  • \(|a|^2 = aa^*\)。每一条恒等式都是由展开共轭的乘积而来。这是用代数方法处理模的标准做法。

  • 归结为一个量的正负。平方并交叉相乘之后，整条不等式只取决于 \((1 - |z|)(1 - |w|)\) 的正负。

  • 检查其他情况。最后一问考虑 \(|z|, |w| < 1\)；同一个因式分解立即给出答案。

背后的数学

非欧几里得几何

两千年来，数学家一直试图由欧几里得的其他公理，证明他的第五公设（过直线外一点，恰好有一条直线与该直线平行）。在 1820 和 1830 年代，罗巴切夫斯基（Nikolai Lobachevsky）、鲍耶（János Bolyai）和（私下研究的）高斯（Gauss）意识到这是办不到的：存在一种完全相容的几何，其中有无限多条平行线。1882 年，庞加莱（Henri Poincaré）在单位圆盘内找到了这种几何的一个优美模型。点就是开圆盘内的点；“直线”是直径，以及与边界圆成直角相交的圆弧；而 \(z\) 与 \(w\) 之间的距离是 \[d(z, w) = 2\tanh^{-1}\rho(z, w), \qquad\text{其中}\qquad \rho(z, w) = \frac{|z - w|}{|1 - zw^*|}.\] 当一点趋近边界圆时，它与圆心的距离趋向无限大：这个圆盘是一整个无限的平面，只是通过一块令影像变形的透镜来观看。

乔装了的三角不等式

对于 \(|z|, |w| < 1\)，题目所证明的其实是以下结果。设 \(|z| = \tanh a\) 和 \(|w| = \tanh b\)，则由 \(0\) 到 \(z\) 和 \(w\) 的双曲距离分别是 \(2a\) 和 \(2b\)。根据 第 3.8 节 中 \(\tanh\) 的加法公式， \[\frac{|z| + |w|}{1 + |zw|} = \frac{\tanh a + \tanh b}{1 + \tanh a\tanh b} = \tanh(a + b).\] 所以该不等式就是 \(\tanh\bigl(\frac12 d(z, w)\bigr) \leq \tanh(a + b)\)，即 \[d(z, w) \leq 2a + 2b = d(z, 0) + d(0, w).\] 这就是双曲距离的三角不等式（图 5.8.1）。相对论的速度相加公式与双曲几何，骨子里是同一回事：狭义相对论中所有可能速度组成的集合，配上适当的距离概念，就是一个双曲空间。我们会在 第 7.6 节 再谈这一点。

圆盘的对称

为甚么 \(\rho\) 是合适的量？对于 \(|a| < 1\)，映射 \(z \mapsto \dfrac{z - a}{1 - a^*z}\) 把单位圆盘映到自身，保持双曲距离不变，并把 \(a\) 移到圆心。它们是平移在双曲几何中的对应物，而 \(\rho(z, w)\) 正是把 \(w\) 移到圆心时的 \(|{\text{映射后的 } z}|\)。这些莫比乌斯变换（Möbius transformation）是复分析（complex analysis）的核心课题。艾雪（M. C. Escher）的木刻版画《圆极限》（Circle Limit），灵感来自数学家考克斯特（H. S. M. Coxeter）的一幅图；画中以全等的鱼和天使镶嵌（tiling）庞加莱圆盘，它们愈近边缘便愈小，因为双曲距离在那里会无限增大。

思维技巧

问一问算式有甚么意义

当某个代数式不断出现时，问一问它是否有某种意义：一个距离、一个角、一个概率、一种对称。

在这里，一个古怪的模之比原来是另一种几何中的距离，而一条古怪的不等式原来是它的三角不等式。认出当中的意义，就能解释结果为何成立，以及它通往何处。

延伸练习

  1. 数值验算。取 \(z = \frac12\) 和 \(w = -\frac12\)。计算不等式的两边。然后计算双曲距离 \(d(z, 0)\)、\(d(0, w)\) 和 \(d(z, w)\)，并验证三角不等式在这里取等号。为甚么？

  2. 混合的情况。求满足 \(|z| < 1 < |w|\) 的 \(z\)、\(w\)，使不等式不成立。

  3. 等距映射（isometry）。设 \(f(z) = \dfrac{z - a}{1 - a^*z}\)，其中 \(|a| < 1\)。证明当 \(|z| = 1\) 时必有 \(|f(z)| = 1\)，并且 \(f(a) = 0\)。证明 \(\rho(f(z), f(w)) = \rho(z, w)\)。

  4. 无限近在咫尺。证明由 \(0\) 到 \(r\)（其中 \(0 < r < 1\)）的双曲距离是 \(\ln\frac{1+r}{1-r}\)，并且当 \(r \to 1\) 时它趋向无限大。一点要多接近边界，才会与圆心相距双曲距离 \(10\)？

延伸阅读

  • Jeremy Gray, Ideas of Space（牛津大学出版社 Oxford University Press）。由欧几里得到爱因斯坦（Einstein）的非欧几里得几何史。
