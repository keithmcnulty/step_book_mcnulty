5.4

正多边形中的距离

工作纸题目连结、提示、大学数学及练习 第 5 章整章的 PDF 版本
题目

STEP III 2016，第 7 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/16-s3-q7

引子

在半径为 \(1\) 的圆内画一个正七边形（regular heptagon）。从其中一个顶点出发，画出连往其余各顶点的六条弦（chord），量度它们的长度，再把这六个长度乘起来。答案恰好是 \(7\)。若换成正 \(100\) 边形，从一个顶点出发的 \(99\) 条弦，长度之积恰好是 \(100\)。

这么简洁的结果，为甚么会成立？各条弦的长度本身并不整齐（\(2\sin\frac{\pi}{7}\)、\(2\sin\frac{2\pi}{7}\) 等等）。这道题目说明，这个结果其实是一个简单代数恒等式在几何上的投影，这个恒等式就是 \(z^n - 1\) 按单位根（roots of unity）所作的因式分解（factorisation）；题目同时说明，平面上的距离就是复数（complex number）的模（modulus）。

动笔之前

把多边形的顶点放在 \(n\) 次单位根上，即 \(X_k = \omega^k\)。若 \(P\) 是点 \(z\)，\(|PX_k|\) 用 \(z\) 表示是甚么？那么所有距离之积又是甚么？

\(|PX_k| = |z - \omega^k|\)，而所有距离之积是 \(|(z - 1)(z - \omega)\cdots(z - \omega^{n-1})|\)，按题目第一部分，这等于 \(|z^n - 1|\)。\(n\) 个距离之积变成了单独一个模。余下的工夫，全在于巧妙地选取 \(z\)。

逐步解题

阶段 1 因式分解

每个 \(\omega^k\) 都满足 \((\omega^k)^n = (\omega^n)^k = 1\)，所以 \(1, \omega, \ldots, \omega^{n-1}\) 都是 \(z^n - 1\) 的根。它们互不相同（它们的辐角（argument）\(\frac{2\pi k}{n}\) 各不相同，且都在 \(0\) 与 \(2\pi\) 之间），所以它们就是这个首项系数（leading coefficient）为 \(1\) 的 \(n\) 次多项式的全部 \(n\) 个根，于是 \(z^n - 1 = \prod_{k=0}^{n-1}(z - \omega^k)\)。■

阶段 2 垂直平分线上的一点

把图形旋转，使得 \(X_k = \omega^k\)。与 \(X_0 = 1\) 和 \(X_1 = \omega\) 等距的点，组成 \(X_0X_1\) 的垂直平分线（perpendicular bisector），即通过 \(O\) 而倾角为 \(\frac\pi n\) 的直线。

所以 \(P\) 就是 \(z = te^{\mathrm{i}\pi/n}\)，其中 \(t\) 是某个实数（可正可负），而 \(|OP| = |t|\)。\(z^n\) 是甚么？

\(z^n = t^ne^{\mathrm{i}\pi} = -t^n\)。所以 \[|PX_0| \times \cdots \times |PX_{n-1}| = |z^n - 1| = |{-t^n} - 1| = |t^n + 1|.\] 若 \(n\) 是偶数，\(t^n = |t|^n \geq 0\)，所以上式等于 \(|OP|^n + 1\)。■

\(n\) 是奇数时又如何？分开考虑 \(t > 0\) 和 \(t < 0\) 两种情况，并说明每种情况在几何上代表甚么。

若 \(n\) 是奇数，\(t^n\) 与 \(t\) 同号。

  • 若 \(t \geq 0\)，即 \(P\) 与 \(X_0X_1\) 的中点位于 \(O\) 的同一侧，则所求之积是 \(|OP|^n + 1\)。

  • 若 \(t < 0\)，即 \(P\) 位于 \(O\) 的另一侧（朝向与边 \(X_0X_1\) 相对的顶点），则 \(t^n = -|OP|^n\)，所求之积是 \(\bigl|1 - |OP|^n\bigr|\)。

当 \(n\) 是奇数时，通过 \(O\) 而垂直于 \(X_0X_1\) 的直线会穿过另一侧的一个顶点；在第二种情况下，当 \(P\) 就是该顶点（\(|OP| = 1\)）时，所求之积等于零，这是理所当然的，因为此时其中一个距离是零。

阶段 3 从一个顶点出发的弦

现在 \(P = X_0\)，其中一个距离 \(|X_0X_0|\) 是零，所以 \(|z^n - 1| = 0\) 派不上用场。哪一个多项式以 \(\omega, \omega^2, \ldots, \omega^{n-1}\) 为根，却不以 \(1\) 为根？

把 \(z^n - 1\) 除以 \(z - 1\)， \[(z - \omega)(z - \omega^2)\cdots(z - \omega^{n-1}) = \frac{z^n - 1}{z - 1} = 1 + z + z^2 + \cdots + z^{n-1}.\] 右边是一个多项式，所以这个等式对所有 \(z\) 都成立，包括 \(z = 1\)，此时它的值是 \(n\)。在 \(z = 1\) 处取模， \[|X_0X_1| \times |X_0X_2| \times \cdots \times |X_0X_{n-1}| = |1 - \omega|\,|1 - \omega^2|\cdots|1 - \omega^{n-1}| = n. \qed\]

回顾

  • 距离就是模。\(|PX_k| = |z - \omega^k|\)，所以距离之积就是积的模，而这个积有闭合形式（closed form）。

  • 利用对称性选取坐标。把图形旋转，使顶点成为单位根，再利用通过 \(O\) 的对称轴，\(z^n\) 便容易计算。

  • 先消去零因子，再代入。一如 第 5.3 节，先除去在所关注的点上等于零的因子，代入才行得通。

背后的数学

科茨定理

第 (i) 部分是科茨（Roger Cotes）的一条定理。科茨是剑桥一位才华横溢的年轻数学家，曾编订牛顿（Newton）《自然哲学的数学原理》（Principia）的第二版，1716 年去世，年仅三十三岁（牛顿曾说：“假如他还在世，我们或许已经学到一点东西了。”）。科茨发现，若 \(P\) 位于由 \(O\) 出发、通过正 \(n\) 边形一个顶点的射线上，则 \(P\) 到各顶点的距离之积是 \(\bigl||OP|^n - 1\bigr|\)；若 \(P\) 位于通过某条边中点的射线上，则这个积是 \(|OP|^n + 1\)。他没有用到复数，就凭这个结果把 \(x^n \pm 1\) 分解成实二次因式，而这正是他计算有理函数（rational function）积分时所需要的。这条定理在他去世后，于 1722 年才发表。

正弦之积

由于 \(|1 - \omega^k| = |e^{-\mathrm{i}\pi k/n} - e^{\mathrm{i}\pi k/n}| = 2\sin\frac{k\pi}{n}\)，第 (ii) 部分说的就是 \[\prod_{k=1}^{n-1}\sin\frac{k\pi}{n} = \frac{n}{2^{n-1}}.\] 这与 第 5.3 节 中的余弦之积互相配对。另一个相关的积给出 \(z^n - 1\) 的判别式（discriminant）：所有成对的相异 \(n\) 次单位根之间距离的平方，乘起来等于 \(n^n\)。判别式量度一个多项式的根彼此相隔多远，在多项式和数域（number field）的代数理论中占有核心地位，我们会在第 6 章讨论。

静电学与等距分布

这个结果还有一个物理上的解读。把 \(n\) 个相等的电荷放在一个圆上；令势能（potential energy）最小的排列（采用二维静电学的对数势）就是正多边形，而能量所涉及的正是 \(\sum\ln|X_jX_k|\)，即距离之积的对数。“分布得尽量疏散”的点，在数值分析（numerical analysis）中十分重要（见 第 3.6 节，当中最佳的插值点是由正多边形经 \(x = \cos\theta\) 得来的），在随机矩阵（random matrix）理论中亦然。

思维技巧

用复数把几何化为代数

平面上的点是复数，距离是模，正多边形是单位根。距离之积就变成多项式的模。

经过这样的转换，像 \(z^n - 1\) 的因式分解这类代数恒等式，便可以用来证明一些很难直接看出的几何事实。

延伸练习

  1. 检查小的情况。就正方形（\(n = 4\)）和等边三角形（\(n = 3\)）直接验证第 (ii) 部分。

  2. 通过顶点。证明：若 \(P\) 位于由 \(O\) 出发、通过 \(X_0\) 的射线上，则 \(|PX_0| \times \cdots \times |PX_{n-1}| = \bigl||OP|^n - 1\bigr|\)。

  3. 平均距离。利用第 (ii) 部分和 第 3.2 节 的算术平均—几何平均不等式（AM–GM inequality），证明从 \(X_0\) 出发的 \(n - 1\) 条弦，平均长度至少是 \(n^{1/(n-1)}\)。就 \(n = 6\) 求出实际的平均值 \(\frac{1}{n-1}\sum_k 2\sin\frac{k\pi}{n}\)，并加以比较。

  4. 所有的弦。 较难 证明：内接于单位圆的正 \(n\) 边形，全部 \(\binom n2\) 条弦的长度之积是 \(n^{n/2}\)。
