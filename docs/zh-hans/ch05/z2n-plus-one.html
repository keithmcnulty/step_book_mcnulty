5.3

因式分解 \(z^{2n} + 1\)

工作纸题目连结、提示、大学数学及练习 第 5 章整章的 PDF 版本
题目

STEP III 2013，第 4 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/13-s3-q4

引子

\(\cos\frac{\pi}{8}\cos\frac{3\pi}{8}\cos\frac{5\pi}{8}\cos\frac{7\pi}{8}\) 等于多少？每个因子都是涉及多重根号的难看数字，但它们的乘积却恰好是 \(\frac18\)。等间隔角度的余弦之积，总是这样化简成简洁的数，而这道题正好解释了个中原因。窍门在于看出这些角度是某个多项式（polynomial）的根（roots）的辐角（argument），把该多项式因式分解（factorise），然后代入（substitute）一个巧妙选取的值。

在复数（complex numbers）范围内，每个多项式都可以完全分解成线性因式（linear factors）。在实数范围内，非实根以共轭对（conjugate pairs）的形式出现，每一对合并成一个实二次因式（real quadratic factor）。这两项事实在本题中都展现出来，而 \(z^{2n} + 1\) 明明完全没有实根，却可以写成实二次式之积，靠的正是第二项事实。

动笔之前

\(z^{2n} = -1\) 的解在复数平面（complex plane）上的甚么位置？试就 \(n = 2\) 和 \(n = 4\) 把它们画出来。

它们的模（modulus）全都是 \(1\)，而辐角 \(\theta\) 满足 \(2n\theta = \pi + 2m\pi\)，所以 \(\theta\) 是 \(\frac{\pi}{2n}\) 的奇数倍。它们在单位圆（unit circle）上构成一个正 \(2n\) 边形，并且旋转到没有任何顶点落在实轴上（图 5.3.1）。它们两两配成共轭对 \(e^{\pm\mathrm{i}\theta}\)，即关于实轴互为镜像。

逐步解题

阶段 1 共轭对给出实二次式

\((z - e^{\mathrm{i}\theta})(z - e^{-\mathrm{i}\theta}) = z^2 - (e^{\mathrm{i}\theta} + e^{-\mathrm{i}\theta})z + 1 = z^2 - 2z\cos\theta + 1\).■

阶段 2 因式分解

满足 \(-\pi < \theta \leq \pi\) 的 \(-1\) 的 \(2n\) 次方根是 \(e^{\pm\mathrm{i}\theta_k}\)，其中 \[\theta_k = \frac{(2k - 1)\pi}{2n}, \qquad k = 1, 2, \ldots, n.\] 这是 \(2n\) 个互不相同的数，全都是 \(2n\) 次多项式 \(z^{2n} + 1\) 的根，所以它们就是该多项式的全部根，于是 \[z^{2n} + 1 = \prod_{k=1}^{n}(z - e^{\mathrm{i}\theta_k})(z - e^{-\mathrm{i}\theta_k}) = \prod_{k=1}^{n}\bigl(z^2 - 2z\cos\theta_k + 1\bigr). \qed\]

阶段 3 代入 \(z = \mathrm{i}\)

\(\mathrm{i}^2 - 2\mathrm{i}\cos\theta + 1\) 等于甚么？当 \(n\) 是偶数时，\(\mathrm{i}^{2n} + 1\) 又等于甚么？

每个因式变成 \[\mathrm{i}^2 - 2\mathrm{i}\cos\theta_k + 1 = -2\mathrm{i}\cos\theta_k,\] 所以右边是 \((-2\mathrm{i})^n\prod_k\cos\theta_k\)。左边是 \(\mathrm{i}^{2n} + 1 = (-1)^n + 1\)，当 \(n\) 是偶数时等于 \(2\)。而对于偶数 \(n\)， \[(-2\mathrm{i})^n = 2^n(-\mathrm{i})^n = 2^n\bigl((-\mathrm{i})^2\bigr)^{n/2} = 2^n(-1)^{n/2}.\] 因此 \[\prod_{k=1}^{n}\cos\theta_k = \frac{2}{2^n(-1)^{n/2}} = (-1)^{\frac12 n}2^{1-n}. \qed\] 当 \(n = 4\) 时，这正是引子中的乘积：\((-1)^2 2^{-3} = \frac18\)。

阶段 4 当 \(n\) 是奇数时

对于奇数 \(n\)，其中一个角 \(\theta_k\) 等于 \(\frac\pi2\)。是哪一个？为甚么这会令代入 \(z = \mathrm{i}\) 这一步在现有形式下毫无用处？

当 \(k = \frac{n+1}{2}\) 时，\(\theta_k = \frac{n\pi}{2n} = \frac\pi2\)，所以该因式是 \(z^2 + 1\)，它在 \(z = \mathrm{i}\) 时等于零；两边都是 \(0\)，我们甚么也得不到。解决办法是先把这个因式除去，而题目给出的恒等式正是这样做的。

把因式分解式的两边除以 \(1 + z^2\)，代入 \(z = \mathrm{i}\)，然后化简。你需要把余下的余弦两两配对。

除以因式 \(z^2 + 1\)（即 \(k = \frac{n+1}{2}\) 的那一项），得 \[1 - z^2 + z^4 - \cdots + z^{2n-2} = \prod_{k \neq \frac{n+1}{2}}\bigl(z^2 - 2z\cos\theta_k + 1\bigr).\] 当 \(z = \mathrm{i}\) 时，左边每一项都是 \((-z^2)^j = 1^j = 1\)，而共有 \(n\) 项，所以左边等于 \(n\)。右边是 \((-2\mathrm{i})^{n-1}\prod_{k \neq \frac{n+1}{2}}\cos\theta_k\)。由于 \(n - 1\) 是偶数，\((-2\mathrm{i})^{n-1} = 2^{n-1}(-1)^{(n-1)/2}\)。

现在把各角配对：\(\theta_{n+1-k} = \pi - \theta_k\)，所以 \(\cos\theta_{n+1-k} = -\cos\theta_k\)。余下的 \(n - 1\) 个因子组成 \(\frac{n-1}{2}\) 个这样的对，其中 \(k = 1, \ldots, \frac{n-1}{2}\)，而每一对贡献 \(-\cos^2\theta_k\)。因此 \[n = 2^{n-1}(-1)^{(n-1)/2}\cdot(-1)^{(n-1)/2}\prod_{k=1}^{(n-1)/2}\cos^2\theta_k = 2^{n-1}\prod_{k=1}^{(n-1)/2}\cos^2\theta_k,\] 从而得到 \(\prod\cos^2\theta_k = n2^{1-n}\)。最后一个因子，即 \(k = \frac{n-1}{2}\) 的那个，是 \(\cos^2\frac{(n-2)\pi}{2n}\)，与题目所写的一致。■

以 \(n = 3\) 验算：\(\cos^2\frac\pi6 = \frac34 = 3 \cdot 2^{-2}\)。

回顾

  • 知道根，就知道多项式。一个多项式由它的根决定（只差一个常数倍），所以列出 \(z^{2n} + 1\) 的根，就得到它的因式分解。

  • 代入一个巧妙的值。取 \(z = \mathrm{i}\)，每个二次因式都变成余弦的倍数。

  • 当代入后得到 \(0 = 0\)，就先做除法。对于奇数 \(n\)，有一个因式在 \(z = \mathrm{i}\) 时等于零，所以我们在代入之前先把它除去。

背后的数学

代数基本定理

\(z^{2n} + 1\) 可以在 \(\mathbb{C}\) 上完全分解成线性因式，这是代数基本定理（fundamental theorem of algebra）的一个特殊情况：每个复系数的非常数多项式都有一个复根，因而可以完全分解成线性因式。高斯（Gauss）在 1799 年的博士论文中给出了第一个获广泛接受的证明，其后又多次重新探讨这条定理，提出新的证明。由此可推出，每个实多项式都可以分解成实线性因式和实二次因式，因为非实根以共轭对的形式出现，正如第 1 步所见。这条定理名为“代数”，实质却属于分析：每个证明都要用到实数的某种性质，例如连续性（continuity），而你会在复分析（complex analysis）的入门课程中见到其中一个最巧妙的证明。

正弦与余弦之积

这个方法可以给出一整族恒等式。以 \(z^n - 1\) 取代 \(z^{2n} + 1\)，就得到 \[\prod_{k=1}^{n-1}\sin\frac{k\pi}{n} = \frac{n}{2^{n-1}},\] 它的几何形式在 第 5.4 节 中有证明。这类恒等式会在振动系统的分析中出现（以弹簧相连的 \(n\) 个质点的频率涉及 \(\sin\frac{k\pi}{2(n+1)}\)），也会在计数问题中出现（某些图的生成树（spanning trees）数目，以及长方形的多米诺骨牌铺砌（domino tilings）数目，都可以用余弦之积表示）。Kasteleyn 在 1961 年提出的 \(m \times n\) 长方形多米诺骨牌铺砌公式，是一个双重乘积，其中各项是含 \(\cos^2\frac{j\pi}{m+1}\) 和 \(\cos^2\frac{k\pi}{n+1}\) 的式子。

思维技巧

从根到乘积

要计算等间隔角度的三角函数值之积，先看出它们来自某个简单多项式的根，再作因式分解，然后代入一个方便的值。

选取甚么值，是一门艺术：本题中 \(z = \mathrm{i}\) 把每个二次因式变成一个余弦。其他选择（例如 \(z = 1\) 或 \(z = -1\)）会给出其他恒等式。

延伸练习

  1. 一个七边形的乘积。利用第 (ii) 部分，取 \(n = 7\)，证明 \(\cos\frac{\pi}{14}\cos\frac{3\pi}{14}\cos\frac{5\pi}{14} = \frac{\sqrt7}{8}\)。然后证明 \(\cos\frac{\pi}{7}\cos\frac{2\pi}{7}\cos\frac{3\pi}{7} = \frac18\)。（提示：利用 \(\cos\theta = \sin(\frac\pi2 - \theta)\) 把各角联系起来，或者反复使用恒等式 \(\sin 2x = 2\sin x\cos x\)。）

  2. 另一个代入。在因式分解式中代入 \(z = 1\)，证明 \[\prod_{k=1}^{n}\sin\frac{(2k-1)\pi}{4n} = 2^{\frac12 - n}.\]

  3. 分解 \(z^6 + 1\)。把 \(z^6 + 1\) 写成三个实二次式之积，并把它们乘开以验算答案。

  4. 正弦。以类似方法分解 \(z^{2n} - 1\)，再除以 \(z^2 - 1\)，证明 \[\prod_{k=1}^{n-1}\sin\frac{k\pi}{2n} = \frac{\sqrt n}{2^{n-1}}.\]
