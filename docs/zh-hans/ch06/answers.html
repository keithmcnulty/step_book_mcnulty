第 6 章 · 代数与结构

延伸练习答案

以下只是简短的答案和提示，并非完整解答：这里只列出结果和关键步骤，方便你核对自己的做法。请先认真做过每一道练习，然后才看答案。

6.1 以单位根为根的多项式

  1. \((x - 1)(x + 1) = x^2 - 1\) 而 \((x^2 + x + 1)(x^2 - x + 1) = x^4 + x^2 + 1\)，两者之积为 \(x^6 - 1\)。同理，\(x^{12} - 1 = (x^6 - 1)(x^6 + 1)\)，而 \(x^6 + 1 = (x^2 + 1)(x^4 - x^2 + 1) = \mathrm{C}_4\mathrm{C}_{12}\)。

  2. \(2p\) 的因数（divisor）为 \(1\)、\(2\)、\(p\)、\(2p\)，所以 \(\mathrm{C}_{2p} = \frac{x^{2p} - 1}{(x - 1)(x + 1)\mathrm{C}_p(x)} = \frac{x^p + 1}{x + 1}\)。另一方面，\(\mathrm{C}_p(-x) = \frac{(-x)^p - 1}{-x - 1} = \frac{x^p + 1}{x + 1}\)，因为 \(p\) 是奇数。当 \(p = 3\) 时：\(\mathrm{C}_6 = x^2 - x + 1 = \mathrm{C}_3(-x)\)。

  3. 不超过 \(p^k\) 而又与 \(p^k\) 有公因数的数，就是那 \(p^{k-1}\) 个 \(p\) 的倍数。本原（primitive）\(p^k\) 次单位根是 \(x^{p^k} - 1\) 的根之中不属于 \(x^{p^{k-1}} - 1\) 的根的那些，所以 \(\mathrm{C}_{p^k} = \frac{x^{p^k} - 1}{x^{p^{k-1}} - 1} = \mathrm{C}_p\bigl(x^{p^{k-1}}\bigr)\)。因此 \(\mathrm{C}_9 = x^6 + x^3 + 1\)。

  4. \(\mathrm{C}_{15} = \frac{(x^{15} - 1)(x - 1)}{(x^3 - 1)(x^5 - 1)}\)。把 \((x - 1)(x^2 + x + 1)(x^4 + x^3 + x^2 + x + 1)\) 与题中给出的八次式相乘并展开，验证结果为 \(x^{15} - 1\)。

6.2 高斯的正十七边形

  1. \(\eta + \eta'\) 是全部六个非实七次单位根之和，即 \(-1\)。展开 \(\eta\eta'\) 得到九项 \(\alpha^{a+b}\)，其指数为 \(4, 6, 0, 5, 0, 1, 0, 2, 3\)（模 \(7\)）：即三个 \(1\)，以及每个非实根各出现一次，所以 \(\eta\eta' = 3 - 1 = 2\)。因此 \(\eta\)、\(\eta'\) 就是 \(\frac{-1 \pm \mathrm{i}\sqrt7}{2}\)。\(\eta\) 的实部给出余弦之和。它的虚部是 \(\sin\frac{2\pi}{7} + \sin\frac{4\pi}{7} - \sin\frac{\pi}{7}\)，由于 \(\sin\frac{4\pi}{7} = \sin\frac{3\pi}{7} > \sin\frac\pi7\)，这个值为正；所以它等于 \(+\frac{\sqrt7}{2}\)。

  2. 设 \(\zeta = \mathrm{e}^{2\pi\mathrm{i}/5}\)，则两个周期（period）\(\zeta + \zeta^4 = 2\cos\frac{2\pi}{5}\) 和 \(\zeta^2 + \zeta^3\) 之和为 \(-1\)，之积为 \(-1\)，所以它们是 \(t^2 + t - 1 = 0\) 的根，而其中的正根给出 \(\cos\frac{2\pi}{5} = \frac{\sqrt5 - 1}{4}\)。作图方法：在单位圆内，两条直角边为 \(1\) 和 \(\frac12\) 的直角三角形，斜边长为 \(\frac{\sqrt5}{2}\)；减去 \(\frac12\) 再取一半，便得 \(\cos\frac{2\pi}{5}\)。在轴上这个距离处作垂线，它与圆相交于一个与 \((1, 0)\) 相邻的顶点；再用这条弦沿圆周逐步截取。

  3. 两者准确至小数点后五位都是 \(-1.28078\)。

  4. \(3\) 的各次幂依次为 \(3, 9, 10, 13, 5, 15, 11, 16, 14, 8, 7, 4, 12, 2, 6, 1\)：十六个数全部出现。\(2\) 的各次幂在八步之后重复（\(2^8 = 256 \equiv 1\)），给出 \(\{1, 2, 4, 8, 9, 13, 15, 16\}\)，即模 \(17\) 的非零平方数。

6.3 以 \(\sqrt2 + \sqrt3 + \sqrt5\) 为根的多项式

  1. \(y^3 = 2\sqrt2 + 6\sqrt3 + 9\sqrt2 + 3\sqrt3 = 11\sqrt2 + 9\sqrt3\)，而 \(9y = 9\sqrt2 + 9\sqrt3\)，所以 \(y^3 - 9y = 2\sqrt2\)。于是 \(\sqrt3 = y - \sqrt2\) 和 \(\sqrt6 = \sqrt2\sqrt3\) 也都是 \(y\) 的多项式。

  2. 设 \(x - \sqrt2 = \sqrt[3]3\) 并取立方：\(x^3 + 6x - 3 = \sqrt2(3x^2 + 2)\)。两边平方得 \(x^6 - 6x^4 - 6x^3 + 12x^2 - 36x + 1 = 0\)。

  3. 可能的有理根只有 \(\pm1\)，而两者都不是根。由于没有 \(x^3\) 项，分解成两个首一（monic）二次式时必定形如 \((x^2 + ax + b)(x^2 - ax + c)\)，其中 \(a(c - b) = 0\)、\(b + c - a^2 = -10\) 及 \(bc = 1\)。若 \(a = 0\)，则 \(b + c = -10\) 且 \(bc = 1\)，在整数范围内不可能；若 \(b = c = \pm1\)，则 \(a^2 = 12\) 或 \(8\)，同样不可能。所以这个四次式不可约（irreducible），而 \(\sqrt2 + \sqrt3\) 的次数（degree）为 \(4\)。

  4. 由棣美弗（De Moivre）定理，\(\cos3\theta = 4\cos^3\theta - 3\cos\theta\)；取 \(\theta = 20^\circ\)，得 \(\frac12 = 4c^3 - 3c\)。候选的有理根 \(\pm1, \pm\frac12, \pm\frac14, \pm\frac18\) 全都不成立。所以 \(\cos20^\circ\) 的次数为 \(3\)，但每个可作图（constructible）长度的次数都是 \(2\) 的幂，因此无法由 \(60^\circ\) 作出 \(20^\circ\)。

6.4 解四次方程

  1. \(y_1y_2 + y_2y_3 + y_3y_1\) 是十二项 \(\alpha^2\beta\gamma\)（一个根的平方乘以另外两个根）之和。而 \(\bigl(\sum\alpha\bigr)\bigl(\sum\alpha\beta\gamma\bigr)\) 则是这十二项再加上 \(4\alpha\beta\gamma\delta\)。所以所求之和为 \((-p)(-r) - 4s\)。

  2. 比较系数得 \(a + b = 1\)、\(a\alpha + b\beta = 0\) 及 \(a\alpha^2 + b\beta^2 = -p\)，当 \(\alpha \neq \beta\) 时有解，而这正是那两个条件所保证的：\(p \neq 0\) 使关于 \(t\) 的方程是真正的二次方程（若 \(p = 0\)，它会退化成 \(-qt = 0\)，只有单一个根 \(0\)），而 \(q^2 \neq 4p^3\) 则使它的判别式（discriminant）\(q^2 - 4p^3\) 不为零。对于 \(x^3 - 24x + 48\)：\(p = 8\)，\(q = 48\)，而 \(8t^2 - 48t + 64 = 0\) 给出 \(\alpha = 2\)，\(\beta = 4\)。于是 \(\bigl(\frac{x - 2}{x - 4}\bigr)^3 = -\frac ba = \frac\alpha\beta = \frac12\)，所以 \(x - 2 = 2^{-1/3}(x - 4)\)，整理后即得题中给出的根，\(x \approx -5.6946\)。

  3. 预解三次式（resolvent cubic）为 \(y^3 - 7y^2 + 16y - 12 = (y - 3)(y - 2)^2\)。由根 \(y = 3\) 得出 \((x^2 - 2x + 1)(x^2 - 2x + 2)\)，所以各根为 \(1\)（二重根）和 \(1 \pm \mathrm{i}\)。

  4. 在每一对之内可以对换或不对换（\(4\) 种选择），两对之间也可以互换或不互换（\(2\) 种选择）：恒等置换、\((\alpha\beta)\)、\((\gamma\delta)\)、\((\alpha\beta)(\gamma\delta)\)、\((\alpha\gamma)(\beta\delta)\)、\((\alpha\delta)(\beta\gamma)\)、\((\alpha\gamma\beta\delta)\) 和 \((\alpha\delta\beta\gamma)\)。这与正方形的对称群（symmetry group）结构完全相同。

6.5 从公理出发的微分法

  1. 常数仍然给出 \(0\)，而由规则 (i) 及归纳法（induction）可得 \(\lozenge x^n = x^{n-1}\lozenge x + x\lozenge x^{n-1} = nx^n\)。再由线性（linearity）得 \(\lozenge\mathrm{h} = x\mathrm{h}'\)。

  2. \(\lozenge\mathrm{f} = \frac{\mathrm{f}}{\mathrm{g}}\lozenge\mathrm{g} + \mathrm{g}\lozenge\frac{\mathrm{f}}{\mathrm{g}}\)，所以 \(\lozenge\frac{\mathrm{f}}{\mathrm{g}} = \frac{\mathrm{g}\lozenge\mathrm{f} - \mathrm{f}\lozenge\mathrm{g}}{\mathrm{g}^2}\)。

  3. 若 \(\mathrm{f} = (x - a)^2\mathrm{g}\)，则 \(\mathrm{f}' = (x - a)\bigl(2\mathrm{g} + (x - a)\mathrm{g}'\bigr)\)。\(x^n - 1\) 的重根（repeated root）必定也是 \(nx^{n-1}\) 的根，所以只能是 \(0\)；但 \(0\) 并不是 \(x^n - 1\) 的根。

  4. \((2 + \varepsilon)^2 + 1 = 5 + 4\varepsilon\)，而 \((5 + 4\varepsilon)^3 = 125 + 300\varepsilon\)。所以 \(f(2) = 125\) 及 \(f'(2) = 300\)；用链式法则（chain rule）则得 \(3(x^2 + 1)^2 \cdot 2x = 3 \cdot 25 \cdot 4 = 300\)。

6.6 子群的并集

  1. 设 \(V = \{e, a, b, c\}\)：\(a^2 = b^2 = c^2 = e\)，而 \(a\)、\(b\)、\(c\) 之中任意两个之积都是第三个。每个元素都是自己的逆元（inverse）。在 \(\{1, \mathrm{i}, -1, -\mathrm{i}\}\) 中，\(\mathrm{i}\) 的逆元是 \(-\mathrm{i}\)，所以这两个群并不相同。

  2. 假如 \(g\) 属于某个真子群（proper subgroup）\(H\)，那么 \(g\) 的每个幂也都属于它，于是 \(H\) 就是整个群。

  3. \(1\) 既不是偶数，也不是 \(3\) 的倍数。更一般地，\(\mathbb{Z}\) 是循环群（cyclic group，由 \(1\) 生成），所以根据上一题，它不是任意多个真子群的并集（union）。

  4. 直线 \(y = mx\) 与 \(y = x^2\) 只相交于 \(x = 0\) 和 \(x = m\) 两处，而直线 \(x = 0\) 与它只相交于原点。所以 \(k\) 条直线最多只能包含 \(k\) 个形如 \((t, t^2)\) 而 \(t \neq 0\) 的点，但这样的点有无穷多个。

6.7 四元数群

  1. \(C\circ B = (\mathrm{i}, 0)\circ(0, 1) = (0, \mathrm{i}) = D\)，而 \(B\circ C = (0, 1)\circ(\mathrm{i}, 0) = (0, \mathrm{i}^*) = (0, -\mathrm{i}) = H\)。

  2. \(A\) 的阶（order）为 \(1\)，\(E\) 的阶为 \(2\)；其余六个元素的平方都是 \(E\)，所以阶为 \(4\)。正方形的对称群有五个阶为 \(2\) 的元素（四个反射和一个半周旋转），所以这两个群并不同构（isomorphic）。

  3. \(\det M = z_1z_1^* + z_2z_2^* = |z_1|^2 + |z_2|^2\)，这是四个实数平方之和。由于 \(M(z)M(w)\) 是 \(z\circ w\) 的矩阵，把行列式（determinant）相乘，便可把 \((a_1^2 + \cdots + a_4^2)(b_1^2 + \cdots + b_4^2)\) 写成 \(|u_1|^2 + |u_2|^2\)，同样是四个平方之和。

  4. 各子群为 \(\{A\}\)、\(\{A, E\}\)、\(\{A, E, C, G\}\)、\(\{A, E, B, F\}\)、\(\{A, E, D, H\}\) 和 \(Q_8\)。除 \(A\) 以外，每个元素都有某个幂等于 \(E\)，所以除 \(\{A\}\) 以外的任何子群都包含 \(E\)。三个阶为 \(4\) 的子群合起来包含了全部八个元素。

6.8 由奇异矩阵组成的群

  1. \(\mathbf{M}_a\mathbf{M}_b = \mathbf{M}_{2ab}\)，而 \(2(2ab) = (2a)(2b)\)。这个映射是一对一（one-to-one）的，并且映成（onto）全体非零实数。

  2. \(\begin{pmatrix} a & b \\ 0 & 0 \end{pmatrix}\begin{pmatrix} c & d \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} ac & ad \\ 0 & 0 \end{pmatrix}\)，其中 \(ac \neq 0\)，所以这个集合是封闭（closed）的。每个 \(\begin{pmatrix} 1 & e \\ 0 & 0 \end{pmatrix}\) 都是左单位元（left identity）。但若要 \(\mathbf{XE} = \mathbf{X}\)，其中 \(\mathbf{E} = \begin{pmatrix} e & f \\ 0 & 0 \end{pmatrix}\)，便需要 \(e = 1\) 及 \(f = b/a\)，而后者取决于 \(\mathbf{X}\)：所以没有右单位元，因而没有单位元，也就不成群。

  3. \(\mathbf{0}\)、\(\mathbf{I}\)，以及满足 \(bc = a(1 - a)\) 的矩阵 \(\begin{pmatrix} a & b \\ c & 1 - a \end{pmatrix}\)（迹（trace）为 \(1\)，行列式为 \(0\)）。这些就是把平面沿一条直线的方向投影（projection）到另一条直线上的变换。

  4. 所有元素均为 \(a\) 的矩阵 \(\mathbf{J}_a\) 满足 \(\mathbf{J}_a\mathbf{J}_b = \mathbf{J}_{nab}\)。单位元是 \(\mathbf{J}_{1/n}\)，而 \(\mathbf{J}_a\) 的逆元是 \(\mathbf{J}_{1/(n^2a)}\)。
