6.1

以单位根为根的多项式

工作纸题目连结、提示、大学数学及练习 第 6 章整章的 PDF 版本
题目

STEP III 2010，第 3 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/10-s3-q3

引子

\(n\) 次单位根（roots of unity），即 \(z^n = 1\) 的解，位于正 \(n\) 边形的各个顶点上。但它们并非全都一样。例如在 \(12\) 次单位根之中，\(1\) 本身已是一次单位根，\(-1\) 是二次单位根，\(\mathrm{i}\) 是四次单位根，而十二个之中只有四个，即本原（primitive）的那些，才需要走足十二步方能回到 \(1\)。

按所需的步数把单位根分类，再由每一类构造一个多项式，便得到分圆多项式（cyclotomic polynomials，此名源自希腊文，意即“分割圆周”）。它们是 \(z^n - 1\) 的基本构件，正如质数是整数的基本构件一样；高斯（Gauss）的正 \(17\) 边形作图法（第 6.2 节）、单位根筛选法（第 5.2 节）以及现代数论中的不少内容，背后都有它们的身影。

动笔之前

每个 \(n\) 次单位根都满足 \(z^n = 1\)。但使它等于 \(1\) 的最小正整数次幂，可能小于 \(n\)。对于四个 4 次单位根 \(1\)、\(\mathrm{i}\)、\(-1\)、\(-\mathrm{i}\)，这个最小的幂次分别是多少？

\(1^1 = 1\)，\((-1)^2 = 1\)，而 \(\mathrm{i}^4 = (-\mathrm{i})^4 = 1\)，且没有更小的幂次可行。所以最小的幂次依次是 \(1\)、\(4\)、\(2\)、\(4\)。这个最小的幂次称为该单位根的阶（order），而本原 \(n\) 次单位根正是阶为 \(n\) 的那些单位根。整道题的关键事实是：每个单位根都恰好有一个阶。

逐步解题

阶段 1 最初的几个

本原 4 次单位根是 \(\mathrm{i}\) 和 \(-\mathrm{i}\)，所以 \(\mathrm{C}_4(x) = (x - \mathrm{i})(x + \mathrm{i}) = x^2 + 1\)。■

哪些单位根的阶是 \(1\)、\(2\)、\(3\)、\(5\) 和 \(6\)？（画出 \(6\) 次单位根，并按阶把它们分类。）

阶为 \(1\)：只有 \(1\)，所以 \(\mathrm{C}_1(x) = x - 1\)。阶为 \(2\)：只有 \(-1\)，所以 \(\mathrm{C}_2(x) = x + 1\)。

阶为 \(3\)：除 \(1\) 以外的三次单位根，即 \(\frac{x^3 - 1}{x - 1}\) 的根。所以 \(\mathrm{C}_3(x) = x^2 + x + 1\)。

阶为 \(5\)：除 \(1\) 以外的五次单位根，它们是 \(\frac{x^5 - 1}{x - 1}\) 的根，所以 \(\mathrm{C}_5(x) = x^4 + x^3 + x^2 + x + 1\)。

阶为 \(6\)：在六次单位根 \(e^{k\pi\mathrm{i}/3}\)，\(k = 0, \ldots, 5\) 之中，\(k = 0\)、\(3\) 的阶分别是 \(1\)、\(2\)，而 \(k = 2\)、\(4\) 的阶是 \(3\)。余下的是 \(e^{\pm\pi\mathrm{i}/3}\)，所以 \[\mathrm{C}_6(x) = (x - e^{\mathrm{i}\pi/3})(x - e^{-\mathrm{i}\pi/3}) = x^2 - 2x\cos\tfrac\pi3 + 1 = x^2 - x + 1. \qed\]

阶段 2 哪个 \(n\) 给出 \(x^4 + 1\)？

\(x^4 + 1 = 0\) 的根满足 \(x^4 = -1\)，所以 \(x^8 = 1\) 但 \(x^4 \neq 1\)。它们的阶整除 \(8\) 但不整除 \(4\)，所以阶是 \(8\)。反过来，阶为 \(8\) 的单位根满足 \(x^8 = 1\)，\(x^4 \neq 1\)，所以 \(x^4 = -1\)。本原 \(8\) 次单位根有四个，\(x^4 + 1\) 的根也有四个，所以 \(n = 8\)。■

阶段 3 质数

若 \(p\) 是质数，则 \(p\) 次单位根的阶整除 \(p\)，所以阶是 \(1\) 或 \(p\)。因此除 \(1\) 以外的每个 \(p\) 次单位根都是本原的，而 \[\mathrm{C}_p(x) = \frac{x^p - 1}{x - 1} = x^{p-1} + x^{p-2} + \cdots + x + 1. \qed\]

阶段 4 没有分圆多项式是另外两个分圆多项式之积

假设 \(\mathrm{C}_q = \mathrm{C}_r\mathrm{C}_s\)。取 \(\mathrm{C}_r\) 的一个根。它的阶是多少？这条恒等式对它的阶有何说法？由此必然得出甚么？

\(\mathrm{C}_r\) 的每个根（至少有一个，因为 \(e^{2\pi\mathrm{i}/r}\) 是本原的）都是 \(\mathrm{C}_r\mathrm{C}_s = \mathrm{C}_q\) 的根，所以它的阶是 \(q\)。但它的阶同时也是 \(r\)，而一个单位根只有一个阶，所以 \(r = q\)。于是 \(\mathrm{C}_q = \mathrm{C}_q\,\mathrm{C}_s\)，又因为 \(\mathrm{C}_q\) 不是零多项式，所以 \(\mathrm{C}_s = 1\)。这是不可能的，因为 \(\mathrm{C}_s\) 至少有一个根 \(e^{2\pi\mathrm{i}/s}\)。所以这样的 \(q\)、\(r\)、\(s\) 并不存在。■

回顾

  • 按阶分类。每个单位根都有唯一的阶，按阶分组便把 \(z^n - 1\) 的根分成互不相交的类。

  • 用根来定义多项式。每个 \(\mathrm{C}_n\) 都是借着确切指明哪些数是它的根而确定下来的。

  • 唯一性带来不可能性。第 (iv) 部分只需要一个想法：一个根不可能有两个不同的阶。

背后的数学

分解 \(x^n - 1\)

每个 \(n\) 次单位根都有某个整除 \(n\) 的阶 \(d\)；而当 \(d \mid n\) 时，每个阶为 \(d\) 的 \(d\) 次单位根都是 \(n\) 次单位根。所以 \(x^n - 1\) 的根按阶分成若干类，由此得到 \[x^n - 1 = \prod_{d \mid n}\mathrm{C}_d(x).\] 例如 \(x^6 - 1 = \mathrm{C}_1\mathrm{C}_2\mathrm{C}_3\mathrm{C}_6 = (x - 1)(x + 1)(x^2 + x + 1)(x^2 - x + 1)\)。图 6.1.1 展示了按这种方式分类的十二个 \(12\) 次单位根。本原 \(n\) 次单位根的个数，亦即 \(\mathrm{C}_n\) 的次数，等于 \(1\) 至 \(n\) 之间与 \(n\) 没有公因数的 \(k\) 的个数，也就是欧拉函数（Euler’s totient function）\(\varphi(n)\)。比较两边的次数，便得到恒等式 \(\sum_{d \mid n}\varphi(d) = n\)。

整数系数，以及一个意外

单看定义并不明显，但每个分圆多项式的系数都是整数。（利用 \(x^n - 1\) 的因式分解和归纳法（induction）：\(\mathrm{C}_n\) 等于 \(x^n - 1\) 除以若干个较早的分圆多项式之积，而以首一（monic）整系数多项式对整系数多项式作长除法，所得系数仍是整数。）在很长一段时间里，所有已知例子的系数都只有 \(0\)、\(1\) 和 \(-1\)。第一个例外是 \(\mathrm{C}_{105}\)，它含有 \(-2x^7\) 这一项，由 Migotti 于 1883 年发现；\(105 = 3 \times 5 \times 7\) 是具有三个相异奇质因数的最小的数。事实上，分圆多项式的系数可以要多大有多大。

不可约性

第 (iv) 部分证明了没有分圆多项式是另外两个分圆多项式之积。其实更强的结论也成立：\(\mathrm{C}_n\) 根本不能分解成次数较低的有理系数多项式之积。高斯对 \(n\) 为质数的情况证明了这一点（它可由艾森斯坦判别法（Eisenstein’s criterion）推出，你会在大学的第一门代数课中遇到），而克罗内克（Kronecker）和戴德金（Dedekind）则证明了一般 \(n\) 的情况。正是这种不可约性（irreducibility），使分圆多项式成为与单位根有关的多项式之中的“质数”，它也是单位根的伽罗瓦理论（Galois theory）的起点。

思维技巧

先分类，后构造

用一个定义明确的不变量（invariant），把问题中的对象分成若干类，然后逐类建立结构。

这里的不变量是单位根的阶。由于每个根恰好有一个阶，各类互不重叠，于是 \(x^n - 1\) 可分解成遍及各类的乘积。同样的模式（由唯一的不变量得出不相交的分解）也是质因数分解和有限阿贝尔群（finite abelian groups）分类的基础。

延伸练习

  1. 检查因式分解。验证 \((x - 1)(x + 1)(x^2 + x + 1)(x^2 - x + 1) = x^6 - 1\)，并验证 \(x^{12} - 1\) 的因式分解如图 6.1.1 所示。

  2. 质数的两倍。证明若 \(p\) 是奇质数，则 \(\mathrm{C}_{2p}(x) = \mathrm{C}_p(-x)\)。就 \(p = 3\) 验证这个结果。

  3. 欧拉函数。证明对于质数 \(p\)，有 \(\varphi(p^k) = p^k - p^{k-1}\)，并且 \(\mathrm{C}_{p^k}(x) = \mathrm{C}_p\bigl(x^{p^{k-1}}\bigr)\)。利用这个结果求 \(\mathrm{C}_9\)。

  4. 较长的一题。 较难 利用 \(x^{15} - 1 = \mathrm{C}_1\mathrm{C}_3\mathrm{C}_5\mathrm{C}_{15}\)，证明 \(\mathrm{C}_{15}(x) = x^8 - x^7 + x^5 - x^4 + x^3 - x + 1\)。
