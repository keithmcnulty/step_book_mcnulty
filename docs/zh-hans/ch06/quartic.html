6.4

解四次方程

工作纸题目连结、提示、大学数学及练习 第 6 章整章的 PDF 版本
题目

STEP III 2017，第 3 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/17-s3-q3

引子

每个学生都学过二次方程（quadratic equation）的求根公式。三次方程（cubic）和四次方程（quartic）其实也有公式；这些公式在十六世纪的意大利被发现，其间充满秘密比试，以及为争夺发现权而起的激烈争执。卡尔达诺（Gerolamo Cardano）在 1545 年出版的《大术》（Ars Magna）中把两者一并发表：三次方程的解法来自塔尔塔利亚（Niccolò Tartaglia），而塔尔塔利亚曾要他发誓保密；四次方程的解法则来自他自己的学生费拉里（Lodovico Ferrari）。此后近三百年，数学家一直苦苦寻找五次方程（quintic）的公式，却始终徒劳无功。

这道题目展示的，正是解开四次方程的那个窍门，而这个窍门背后大有深意。从四个根出发，按三种可能的方式把根两两配对，得出三个新的量。这三个量满足一个三次方程，而三次方程是你解得到的；有了它们，原来的四个根便随之而来。为甚么这个方法行得通？为甚么四个根可以化约为三个量，五个根却不能如法炮制？正是这个问题，引领伽罗瓦（Galois）创立了群论（group theory）。

动笔之前

把四件物件 \(\alpha, \beta, \gamma, \delta\) 分成两对，共有多少种分法？

三种：\(\{\alpha\beta, \gamma\delta\}\)、\(\{\alpha\gamma, \beta\delta\}\) 和 \(\{\alpha\delta, \beta\gamma\}\)（图 6.4.1）。题目中的三个量 \(\alpha\beta + \gamma\delta\) 等等，正好对应这三种配对。把四个根任意重新排列，只会令这三种配对彼此对调，所以这三个量的任何对称式（symmetric expression），都是四个根的对称式，因而可以用 \(p\)、\(q\)、\(r\)、\(s\) 表示。这就是为甚么它们满足一个系数只涉及 \(p\)、\(q\)、\(r\)、\(s\) 的三次方程。

逐步解题

阶段 1 欠缺的系数

在三次方程 \(y^3 + Ay^2 + By + C = 0\) 中，根之和用 \(A\) 表示是甚么？而 \((\alpha\beta + \gamma\delta) + (\alpha\gamma + \beta\delta) + (\alpha\delta + \beta\gamma)\) 用四次方程的系数表示又是甚么？

三次方程的根之和是 \(-A\)。那三个量之和，就是 \(\alpha, \beta, \gamma, \delta\) 中两两相乘所得全部六个积之和；对四次多项式 \(x^4 + px^3 + qx^2 + rx + s\) 而言，这个和是 \(q\)。所以 \(A = -q\)。

阶段 2 具体的三次方程

代入 \(p = 0\)、\(q = 3\)、\(r = -6\)、\(s = 10\)，三次方程是 \[y^3 - 3y^2 + (0 - 40)y + (120 - 0 - 36) = y^3 - 3y^2 - 40y + 84 = 0.\]

试试 \(84\) 的细小因数。

\(y = 2\) 给出 \(8 - 12 - 80 + 84 = 0\)。作除法，得 \(y^3 - 3y^2 - 40y + 84 = (y - 2)(y^2 - y - 42) = (y - 2)(y - 7)(y + 6)\)。最大的根是 \(7\)，所以 \(\alpha\beta + \gamma\delta = 7\)。■

阶段 3 根的配对

\((\alpha + \beta)(\gamma + \delta) = \alpha\gamma + \alpha\delta + \beta\gamma + \beta\delta\)，这是全部六个两两之积的和减去 \(\alpha\beta + \gamma\delta\)，即 \(q - 7 = 3 - 7 = -4\)。

此外 \(\alpha\beta \cdot \gamma\delta = \alpha\beta\gamma\delta = s = 10\)。所以 \(\alpha\beta\) 和 \(\gamma\delta\) 之和为 \(7\)，积为 \(10\)：它们是 \(t^2 - 7t + 10 = (t - 2)(t - 5)\) 的根。由于 \(\alpha\beta > \gamma\delta\)，得 \(\alpha\beta = 5\) 及 \(\gamma\delta = 2\)。■

阶段 4 解四次方程

求 \(\alpha + \beta\) 和 \(\gamma + \delta\)。你已知道它们的和（由 \(p\) 得出）和它们的积（由第 3 步得出）；要判断哪个是哪个，就用 \(r\)。

\(\alpha + \beta + \gamma + \delta = -p = 0\) 而 \((\alpha + \beta)(\gamma + \delta) = -4\)，所以 \(\{\alpha + \beta, \gamma + \delta\} = \{2, -2\}\)。系数 \(r\) 给出四个三根之积的和：\(\alpha\beta\gamma + \alpha\beta\delta + \alpha\gamma\delta + \beta\gamma\delta = -r = 6\)。这可以写成 \(\alpha\beta(\gamma + \delta) + \gamma\delta(\alpha + \beta) = 5(\gamma + \delta) + 2(\alpha + \beta)\)。若 \(\alpha + \beta = 2\)，此式等于 \(-10 + 4 = -6\)；若 \(\alpha + \beta = -2\)，则等于 \(10 - 4 = 6\)。所以 \(\alpha + \beta = -2\) 及 \(\gamma + \delta = 2\)。

于是 \(\alpha\)、\(\beta\) 是 \(t^2 + 2t + 5 = 0\) 的根，即 \(-1 \pm 2\mathrm{i}\)；而 \(\gamma\)、\(\delta\) 是 \(t^2 - 2t + 2 = 0\) 的根，即 \(1 \pm \mathrm{i}\)。四个根是 \[x = -1 \pm 2\mathrm{i}, \qquad x = 1 \pm \mathrm{i}. \qed\] 验算：\((x^2 + 2x + 5)(x^2 - 2x + 2) = x^4 + 3x^2 - 6x + 10\)。

回顾

  • 对称函数（symmetric functions）。每一步都用上了根与系数的关系：根之和与根之积。

  • 降低次数。一个四次方程的问题变成了一个三次方程（即预解三次方程（resolvent cubic）），然后再变成两个二次方程。

  • 用尽每一项资料。\(p\) 和 \(q\) 给出了各个和与积；\(s\) 把 \(\alpha\beta\) 和 \(\gamma\delta\) 分开；\(r\) 则决定了哪一对根配哪一个和。

背后的数学

这个窍门为何行得通：根的置换

1770 年，拉格朗日（Joseph-Louis Lagrange）追问三次和四次方程的解法为何行得通，并在根的置换（permutation）中找到了答案。四个根共有 \(24\) 种重新排列的方式。在所有这些排列之下，三个量 \(y_1 = \alpha\beta + \gamma\delta\)、\(y_2 = \alpha\gamma + \beta\delta\)、\(y_3 = \alpha\delta + \beta\gamma\) 只不过是彼此对调：四个根的每一种重新排列，都引致三种配对的一种重新排列（图 6.4.1）。所以它们满足一个 \(3\) 次多项式，其系数是各根的对称式。用现代的语言来说，从对称群（symmetric group）\(S_4\)（全部 \(24\) 个置换）到 \(S_3\)（三种配对的 \(6\) 个置换）有一个满射的群同态（group homomorphism），这就是四次方程可以化约为三次方程的原因。

五次方程

对于五个根，拉格朗日尝试寻找一个类似的量，使它在根的置换之下只取寥寥几个值，却找不到有用的。1799 年鲁菲尼（Paolo Ruffini）提出证明，1824 年阿贝尔（Niels Henrik Abel）把证明补全，两人证明了：只用四则运算和根式（radicals），并不存在五次方程的一般求根公式。数年之后，伽罗瓦（Évariste Galois）确切地说明了哪些多项式可以用根式求解：就是那些根的对称群能以某种特定方式分解成较简单部分的多项式。对称群 \(S_4\) 可以这样分解（经由 \(S_3\) 和更小的群），但 \(S_5\) 不可以，因为它包含一个大小为 \(60\) 的“单”（simple）部分，无法再进一步分解。1832 年，伽罗瓦在决斗中丧生，年仅二十岁；决斗前一晚，他才匆匆把自己的理论写下来。这套理论如今是数学学位课程中的瑰宝之一，通常在三年级学到。

解三次方程

三次方程本身也可以用类似的窍门求解：把一个缺二次项的三次式（depressed cubic）\(x^3 - 3px + q\) 写成两个完全立方的组合，从而化约为一个二次方程。这就是练习中那道 2011 年题目所用的方法，它与卡尔达诺公式（Cardano’s formula）等价。当三次方程有三个实根时，这条公式在运算途中仍然需要用到复数（complex numbers），正是这个现象迫使数学家认真看待复数（见第 5 章的引言）。

思维技巧

对称性化繁为简

如果由根构造出来的一些量，在根被置换时只是彼此置换，那么它们满足一个次数较低的多项式，而其系数是你可以计算出来的。

这是伽罗瓦理论（Galois theory）的种子：通过理解方程各根的对称性来理解方程本身。

延伸练习

  1. 验证三次方程。验证 \(y_1y_2 + y_2y_3 + y_3y_1 = pr - 4s\)，其中 \(y_1 = \alpha\beta + \gamma\delta\)，余类推。（展开并利用 \(\sum\alpha = -p\)、\(\sum\alpha\beta\gamma = -r\)、\(\alpha\beta\gamma\delta = s\)。）

  2. 把三次式写成立方之和。试做 STEP III 2011，第 3 题。这道题把三次式写成两个立方的组合来求解，与本节的路线截然不同。请用数值方法核对它的答案。

  3. 另一个四次方程。用本节的方法解 \(x^4 - 4x^3 + 7x^2 - 6x + 2 = 0\)。（预解三次方程有一个根是细小的整数。）

  4. 数算置换。在 \(\alpha, \beta, \gamma, \delta\) 的 \(24\) 个置换中，找出所有把配对 \(\{\alpha\beta, \gamma\delta\}\) 变回自身的置换。证明这样的置换共有 \(8\) 个。（它们构成 \(S_4\) 的一个子群（subgroup）。）

延伸阅读

  • Mario Livio, The Equation That Couldn’t Be Solved（Simon & Schuster）。五次方程的故事与群论的诞生，适合一般读者。

  • Ian Stewart, Why Beauty Is Truth: A History of Symmetry（Basic Books）。从巴比伦人的方程讲到伽罗瓦，再到其后的发展。

  • Ian Stewart, Galois Theory（CRC Press）。大学本科教科书，其历史导论所涵盖的正是本节的内容。
