第 7 章 · 线性代数与几何

延伸练习答案

以下只是简短的答案和提示，并非完整解答：这里给出结果和关键步骤，让你核对自己的做法。请先认真做过每道练习，然后才看答案。

7.1 对矩阵不成立的法则

  1. 设 \(\mathbf{X} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\)，比较 \(\mathbf{XP}\) 与 \(\mathbf{PX}\)，必有 \(c = 0\) 及 \(a = d\)：所求的矩阵（matrix）为 \(\begin{pmatrix} a & b \\ 0 & a \end{pmatrix}\)。

  2. 由凯莱－哈密顿定理（Cayley–Hamilton theorem）得 \(\mathbf{N}^2 = t\mathbf{N} - d\mathbf{I}\)，所以 \(t\mathbf{N} = d\mathbf{I}\)。若 \(t \neq 0\)，则 \(\mathbf{N}\) 是 \(\mathbf{I}\) 的倍数，而 \(\mathbf{N}^2 = \mathbf{0}\) 迫使 \(\mathbf{N} = \mathbf{0}\)，与 \(t \neq 0\) 矛盾。所以 \(t = 0\)，从而 \(d = 0\)。答案是：\(\begin{pmatrix} a & b \\ c & -a \end{pmatrix}\)，其中 \(a^2 + bc = 0\)。

  3. 平方后的对角线元素为 \(\cos^2\theta + \sin^2\theta = 1\)，非对角线元素为 \(0\)。保持不变的向量（vector）是 \((\cos\frac\theta2, \sin\frac\theta2)\)，所以它是对通过原点、倾角为 \(\frac\theta2\) 的直线的反射（reflection）。

  4. 设 \(\mathbf{M} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\)，则 \(\mathbf{M}^2 = \begin{pmatrix} a^2 + bc & b(a + d) \\ c(a + d) & d^2 + bc \end{pmatrix}\)；减去 \((a + d)\mathbf{M}\) 再加上 \((ad - bc)\mathbf{I}\)，便得 \(\mathbf{0}\)。

7.2 只伸缩，不转向

  1. \(\mathbf{Mu} = \lambda\mathbf{u}\) 且 \(\mathbf{u} \neq \mathbf{0}\)，必须有 \(\det(\mathbf{M} - \lambda\mathbf{I}) = 0\)，这就是该二次方程。这里迹（trace）为 \(6\)，行列式（determinant）为 \(\frac{4}{25}(54 - 4) = 8\)，所以 \(\lambda^2 - 6\lambda + 8 = 0\)：\(\lambda = 2\)（对应 \((1, 2)\)）和 \(4\)（对应 \((2, -1)\)）。

  2. \(\mathbf{v} \cdot \mathbf{Mu} = \lambda\,\mathbf{v} \cdot \mathbf{u}\)，又因为 \(\mathbf{M}\) 是对称矩阵（symmetric matrix），\(\mathbf{v} \cdot \mathbf{Mu} = \mathbf{Mv} \cdot \mathbf{u} = \mu\,\mathbf{v} \cdot \mathbf{u}\)。所以 \((\lambda - \mu)\,\mathbf{u} \cdot \mathbf{v} = 0\)。

  3. 特征方程（characteristic equation）\(\lambda^2 - 2\lambda\cos\theta + 1 = 0\) 的判别式（discriminant）为 \(-4\sin^2\theta\)，除非 \(\theta\) 是 \(\pi\) 的倍数，否则必为负数。特征值（eigenvalue）是 \(\mathrm{e}^{\pm\mathrm{i}\theta}\)。

  4. \((1, 0) = \frac15(1, 2) + \frac25(2, -1)\)，所以 \(T^n(1, 0) = \frac{2^n}{5}(1, 2) + \frac{2 \cdot 4^n}{5}(2, -1) = \frac15\bigl(2^n + 4^{n+1},\ 2^{n+1} - 2 \cdot 4^n\bigr)\)。当 \(n = 1\) 时，结果是 \((\frac{18}{5}, -\frac45)\)，正如所料。

7.3 甚么才算行列式

  1. \((\det\mathbf{MN})^3 = (\det\mathbf{M})^3(\det\mathbf{N})^3\)，而 \((\det\mathbf{J})^3 = -1 \neq 1\)。函数 \(|\det\mathbf{M}|\) 具有可乘性（multiplicative），但 \(|\det\mathbf{J}| = 1\)。

  2. \(\begin{pmatrix} a & \lambda a \\ c & \lambda c \end{pmatrix} = \begin{pmatrix} a & 0 \\ c & 0 \end{pmatrix}\begin{pmatrix} 1 & \lambda \\ 0 & 0 \end{pmatrix}\)，而第二个因子的第二行是第一行的 \(0\) 倍，所以它的 \(\mathrm{f}\) 值为 \(0\)。

  3. \(\begin{pmatrix} k & 0 \\ 0 & 1 \end{pmatrix} = \mathbf{JK}_k\mathbf{J}\)，所以它的值是 \(\mathrm{f}(\mathbf{J})^2\mathrm{f}(\mathbf{K}_k) = \mathrm{f}(\mathbf{K}_k)\)。另外 \(\mathbf{K}_k\mathbf{K}_l = \mathbf{K}_{kl}\)。

  4. 行简化（row reduction）可把任何可逆矩阵（invertible matrix）写成初等矩阵（elementary matrix）的乘积：行对换（\(\mathbf{J}\)）、行倍乘（\(\mathbf{K}_k\) 或 \(\mathbf{JK}_k\mathbf{J}\)），以及错切（shear）（\(\begin{pmatrix} 1 & t \\ 0 & 1 \end{pmatrix}\) 或它经 \(\mathbf{J}\) 共轭（conjugate）后所得的矩阵）。错切的 \(\mathrm{f} = 1\)（做法如第 (iv) 部分，利用 \(\mathbf{K}^{-1}\mathbf{PK}\)）。此外，\(\mathbf{J}\) 是若干错切与 \(\mathbf{K}_{-1}\) 的乘积，所以 \(\mathrm{f}(\mathbf{K}_{-1}) = \mathrm{f}(\mathbf{J}) = -1\)。因此 \(\mathrm{f}(\mathbf{M}) = \mathrm{g}(\det\mathbf{M})\)，其中 \(\mathrm{g}(k) = \mathrm{f}(\mathbf{K}_k)\)；若 \(\mathbf{M}\) 是奇异矩阵（singular matrix），则由第 (iii) 部分得 \(\mathrm{f}(\mathbf{M}) = 0\)。

7.4 回到起点的矩阵

  1. 由 \(|1 + \mathrm{e}^{\mathrm{i}\phi}|^2 = 2 + 2\cos\phi = 1\) 得 \(\phi = \pm\frac{2\pi}{3}\)，所以 \(\mathbf{R}^3 = \mathbf{I}\)。至于 \(\mathbf{S}\)：它的特征值是 \(1\) 的立方根。假如两个特征值都是 \(1\)，则由于 \(x^3 - 1\) 的根各不相同，\(\mathbf{S}\) 可对角化（diagonalisable），因而等于 \(\mathbf{I}\)。实矩阵的非实数特征值必以共轭对的形式出现，所以特征值是 \(\mathrm{e}^{\pm2\pi\mathrm{i}/3}\)：\(\det\mathbf{S} = 1\) 及 \(\operatorname{tr}\mathbf{S} = -1\)。

  2. 特征值必定是六次本原单位根（primitive sixth roots of unity）\(\mathrm{e}^{\pm\mathrm{i}\pi/3}\)（若选取其他六次单位根并与其共轭配对，都会得出 \(\mathbf{M}^2 = \mathbf{I}\) 或 \(\mathbf{M}^3 = \mathbf{I}\)）。所以 \(\operatorname{tr}\mathbf{M} = 1\) 及 \(\det\mathbf{M} = 1\)。

  3. 特征值是乘积为 \(1\) 的单位根，所以它们是 \(\mathrm{e}^{\pm\mathrm{i}\theta}\)（或同为 \(\pm1\)），而迹 \(2\cos\theta\) 是 \([-2, 2]\) 内的整数。阶（order）为 \(6\) 的例子：\(\begin{pmatrix} 1 & -1 \\ 1 & 0 \end{pmatrix}\)。

  4. \(\mathbf{M}^3 = (t^2 - d)\mathbf{M} - td\mathbf{I}\) 及 \(\mathbf{M}^4 = (t^3 - 2td)\mathbf{M} - d(t^2 - d)\mathbf{I}\)。要使 \(\mathbf{M}^4 = -\mathbf{I}\)（\(\mathbf{M}\) 不可能是 \(\mathbf{I}\) 的倍数），须有 \(t(t^2 - 2d) = 0\) 及 \(d(t^2 - d) = 1\)。\(t = 0\) 给出 \(-d^2 = 1\)，不可能成立；所以 \(t^2 = 2d\)，\(d^2 = 1\)，于是 \(d = 1\)，\(t^2 = 2\)。

7.5 三维空间中的旋转

  1. \(z \mapsto a + \mathrm{e}^{\mathrm{i}\theta}(z - a)\)。复合变换是 \(z \mapsto \mathrm{e}^{\mathrm{i}(\theta + \phi)}z + k\)，其中 \(k = \mathrm{e}^{\mathrm{i}\phi}a(1 - \mathrm{e}^{\mathrm{i}\theta}) + b(1 - \mathrm{e}^{\mathrm{i}\phi})\)；若 \(\mathrm{e}^{\mathrm{i}(\theta+\phi)} \neq 1\)，它有不动点（fixed point）\(c = \frac{k}{1 - \mathrm{e}^{\mathrm{i}(\theta+\phi)}}\)。若 \(\theta + \phi = 2\pi\)，它就是位移为 \((b - a)(1 - \mathrm{e}^{-\mathrm{i}\theta})\) 的平移（translation）。

  2. \(\begin{pmatrix} 0 & 0 & 1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}\)：它保持 \((1, 1, 1)\) 不变，迹为 \(0 = 1 + 2\cos120^\circ\)，并把 \(\mathbf{i} \to \mathbf{j} \to \mathbf{k} \to \mathbf{i}\)。

  3. \(\mathbf{K}^2\mathbf{r} = \mathbf{n} \times (\mathbf{n} \times \mathbf{r}) = (\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\)，于是 \(\mathbf{K}^3\mathbf{r} = \mathbf{n} \times \bigl((\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\bigr) = -\mathbf{Kr}\)。在级数（series）中，奇数次幂给出 \((\theta - \frac{\theta^3}{3!} + \cdots)\mathbf{K} = \sin\theta\,\mathbf{K}\)，偶数次幂（由 \(\mathbf{K}^2\) 起）给出 \((\frac{\theta^2}{2!} - \frac{\theta^4}{4!} + \cdots)\mathbf{K}^2 = (1 - \cos\theta)\mathbf{K}^2\)。

  4. 复合变换保持交线上的每一点不变，而且行列式为 \((-1)^2 = 1\)。在每个垂直于该交线的平面上，它是对两条夹角为 \(\alpha\) 的直线先后作反射的乘积，即转角为 \(2\alpha\) 的旋转（rotation）。

7.6 双曲旋转与相对论

  1. \(T(u)T(w)\) 的元素是 \(\cosh u\cosh w + \sinh u\sinh w = \cosh(u + w)\) 和 \(\sinh u\cosh w + \cosh u\sinh w = \sinh(u + w)\)。所以 \(T(u)^{-1} = T(-u)\)。

  2. 由 \(\tanh u = 0.8\) 得 \(u = \frac12\ln\frac{1.8}{0.2} = \ln3 \approx 1.099\) 及 \(\cosh u = \frac12(3 + \frac13) = \frac53\)。在飞船上，过去的时间是 \(10 \times \frac35 = 6\) 年。

  3. 面积是 \(\frac12\oint(x\,\mathrm{d}y - y\,\mathrm{d}x)\)。两条直边没有贡献；沿着双曲线（hyperbola），取 \(x = \cosh s\)，\(y = \sinh s\)，被积函数（integrand）是 \((\cosh^2s - \sinh^2s)\,\mathrm{d}s = \mathrm{d}s\)，得出 \(\frac v2\)。\(T\) 的行列式为 \(\cosh^2u - \sinh^2u = 1\)，所以它保持面积不变；它把双曲线映射到自身，并把参数为 \(v\) 的点移到参数为 \(v + u\) 的点。

  4. \(x' + y' = (\cosh u + \sinh u)(x + y) = \mathrm{e}^up\) 及 \(x' - y' = \mathrm{e}^{-u}q\)；另外 \(x^2 - y^2 = pq\)。在这组坐标下，\(T\) 是一个挤压映射（squeeze）：沿渐近线（asymptote）\(y = x\) 拉伸 \(\mathrm{e}^u\) 倍，沿 \(y = -x\) 压缩至 \(\mathrm{e}^{-u}\) 倍，使各点沿着每条双曲线 \(pq =\) 常数滑动。

7.7 永恒不变的量

  1. \(\dot a = -Ct = -tc\)，\(\dot d = Ct = tc\)，\(\dot c = 0\)，以及 \(\dot b = (A - D)t - Ct^3 = t(a - d)\)，与 \(\mathbf{MN} - \mathbf{NM} = t\begin{pmatrix} -c & a - d \\ 0 & c \end{pmatrix}\) 吻合。

  2. \(\dot{\mathbf{M}} = -\mathbf{S}^{-1}\dot{\mathbf{S}}\mathbf{S}^{-1}\mathbf{M}_0\mathbf{S} + \mathbf{S}^{-1}\mathbf{M}_0\dot{\mathbf{S}} = -\mathbf{NM} + \mathbf{MN}\)，当中用到 \(\dot{\mathbf{S}} = \mathbf{SN}\)。

  3. \(\mathbf{N} = \mathbf{M}^{-1}\dot{\mathbf{M}} = \begin{pmatrix} 2 & 0 \\ 0 & -1 \end{pmatrix}\)，而 \(\ln\det\mathbf{M} = 2t - t = t\)，其导数（derivative）为 \(1 = \operatorname{tr}\mathbf{N}\)。

  4. 利用迹的循环性质（cyclic property），\(\frac{\mathrm{d}}{\mathrm{d}t}\operatorname{tr}(\mathbf{M}^k) = \sum_j\operatorname{tr}(\mathbf{M}^j\dot{\mathbf{M}}\mathbf{M}^{k-1-j}) = k\operatorname{tr}(\mathbf{M}^{k-1}\dot{\mathbf{M}})\)；再用一次循环性质，\(\operatorname{tr}(\mathbf{M}^{k-1}(\mathbf{MN} - \mathbf{NM})) = \operatorname{tr}(\mathbf{M}^k\mathbf{N}) - \operatorname{tr}(\mathbf{M}^{k-1}\mathbf{NM}) = 0\)。

7.8 四个平方数

  1. \((L_1, L_2, L_3, L_4) = (1, 4, 4, 4)\)，而 \(1 + 16 + 16 + 16 = 49\)。这个表示法与 \(7^2 + 0^2 + 0^2 + 0^2\) 不同。

  2. 取 \(c = d = r = s = 0\)：\(L_1 = ap - bq\)，\(L_2 = aq + bp\)，\(L_3 = L_4 = 0\)，即 \((a^2 + b^2)(p^2 + q^2) = (ap - bq)^2 + (aq + bp)^2\)。

  3. 平方数模（modulo）\(8\) 只可能是 \(0\)、\(1\) 或 \(4\)。三个这样的数之和模 \(8\) 可得 \(0, 1, 2, 3, 4, 5, 6\)，但永远不会是 \(7\)。

  4. \(2 = (\pm1)^2 + (\pm1)^2 + 0^2 + 0^2\)：选出两个非零的位置（\(6\) 种方法）及它们的正负号（\(4\) 种方法），共 \(24\) 种。由于 \(2\) 不能被 \(4\) 整除，雅可比（Jacobi）公式给出 \(8\sigma(2) = 8 \times 3 = 24\)。

7.9 只有五种柏拉图立体

  1. 设 \(h = 2m + 2n - mn\)，则 \(V = \frac{4m}{h}\)，\(E = \frac{2mn}{h}\) 及 \(F = \frac{4n}{h}\)；把 \(m\) 和 \(n\) 对调，\(V\) 和 \(F\) 也随之对调。正方体与正八面体（octahedron）互为对偶（dual），正十二面体（dodecahedron）与正二十面体（icosahedron）亦然；正四面体（tetrahedron）则是自对偶（self-dual）的。

  2. \(F = 32\)，\(E = \frac12(12 \cdot 5 + 20 \cdot 6) = 90\) 及 \(V = \frac13(180) = 60\)，而 \(60 - 90 + 32 = 2\)。一般而言，若有 \(P\) 个五边形和 \(H\) 个六边形，则 \(E = \frac12(5P + 6H)\) 及 \(V = \frac13(5P + 6H)\)，所以 \(V - E + F = -\frac16(5P + 6H) + P + H = \frac P6\)。这个值等于 \(2\)，所以 \(P = 12\)。

  3. 把顶面和底面（两者都有洞）各分成四个梯形（trapezium）。于是 \(V = 16\)，\(F = 4 + 4 + 4 + 4 = 16\) 及 \(E = 12 + 12 + 8 = 32\)，所以 \(V - E + F = 0\)。

  4. \(180^\circ n(1 - \frac2m) < 360^\circ\) 即 \(n(m - 2) < 2m\)，也就是 \(mn - 2m - 2n < 0\)，或 \((m - 2)(n - 2) < 4\)。当 \(m, n \geq 3\) 时，解为 \((3, 3)\)、\((3, 4)\)、\((4, 3)\)、\((3, 5)\) 和 \((5, 3)\)。
