永恒不变的量

题目

STEP III 2024，第 5 题

继续之前，请先阅读题目（原题为英文）。题目载于 OCR 提供下载的 2024 年 STEP 试卷（zip 文件）内的 STEP III 试卷： www.ocr.org.uk/Images/725753-2024-past-papers.zip

引子

物理学中一些最深刻的事实是守恒定律（conservation laws）：无论运动多么复杂，能量、动量和角动量始终保持不变。当一个系统有足够多的守恒量时，它的运动可以精确地解出；守恒量太少时，运动则可能是混沌的。

这道题展示了一种制造守恒量的绝妙方法。若一个矩阵按照 \(\frac{\mathrm{d}\mathbf{M}}{\mathrm{d}t} = \mathbf{MN} - \mathbf{NM}\) 随时间变化，那么无论它的元素变化得多么剧烈，它的迹（trace）和行列式（determinant），以至它的特征值（eigenvalues），都永远不变。这样的一对 \((\mathbf{M}, \mathbf{N})\) 称为拉克斯对（Lax pair），以彼得．拉克斯（Peter Lax）命名。他在 1968 年提出这个想法，用来解释孤立子（solitons）的惊人表现：孤立子是一种孤立波，彼此穿过之后丝毫不变。

动笔之前

表达式 \(\mathbf{MN} - \mathbf{NM}\) 称为 \(\mathbf{M}\) 与 \(\mathbf{N}\) 的交换子（commutator）。它在甚么时候等于零？根据第 (i) 部分，它的迹是多少？

它等于零，当且仅当 \(\mathbf{M}\) 与 \(\mathbf{N}\) 可交换。而根据第 (i) 部分，它的迹是 \(\operatorname{tr}(\mathbf{MN}) - \operatorname{tr}(\mathbf{NM}) = 0\)，恒常如此。这一个事实，就是题目中每一条守恒定律的起点。

逐步解题

阶段 1 迹

设 \(\mathbf{M} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\) 及 \(\mathbf{N} = \begin{pmatrix} p & q \\ r & s \end{pmatrix}\)，则 \(\mathbf{MN}\) 的对角线元素是 \(ap + br\) 和 \(cq + ds\)，所以 \(\operatorname{tr}(\mathbf{MN}) = ap + br + cq + ds\)。把 \(\mathbf{M}\) 与 \(\mathbf{N}\) 的角色对调，得 \(pa + qc + rb + sd\)，结果相同。显然 \(\operatorname{tr}(\mathbf{M} + \mathbf{N}) = \operatorname{tr}\mathbf{M} + \operatorname{tr}\mathbf{N}\)。■

阶段 2 行列式的导数

用积法则求 \(\det\mathbf{M} = ad - bc\) 的导数。然后利用 \(\mathbf{M}^{-1} = \frac{1}{\det\mathbf{M}}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}\)，计算 \(\mathbf{M}^{-1}\frac{\mathrm{d}\mathbf{M}}{\mathrm{d}t}\) 及其迹。

以字母上的一点表示导数，则 \(\frac{\mathrm{d}}{\mathrm{d}t}\det\mathbf{M} = \dot ad + a\dot d - \dot bc - b\dot c\)。而 \[\mathbf{M}^{-1}\dot{\mathbf{M}} = \frac{1}{\det\mathbf{M}}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}\begin{pmatrix} \dot a & \dot b \\ \dot c & \dot d \end{pmatrix}\] 的对角线元素是 \(\frac{d\dot a - b\dot c}{\det\mathbf{M}}\) 和 \(\frac{-c\dot b + a\dot d}{\det\mathbf{M}}\)。两者之和是 \(\frac{1}{\det\mathbf{M}}\frac{\mathrm{d}}{\mathrm{d}t}\det\mathbf{M}\)。■

阶段 3 三个守恒量

对 \(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\) 取迹。至于行列式，则用第 (ii) 部分：\(\mathbf{M}^{-1}(\mathbf{MN} - \mathbf{NM})\) 是甚么？

迹：\(\frac{\mathrm{d}}{\mathrm{d}t}\operatorname{tr}\mathbf{M} = \operatorname{tr}\dot{\mathbf{M}} = \operatorname{tr}(\mathbf{MN}) - \operatorname{tr}(\mathbf{NM}) = 0\)。

行列式：根据第 (ii) 部分， \[\frac{1}{\det\mathbf{M}}\frac{\mathrm{d}}{\mathrm{d}t}\det\mathbf{M} = \operatorname{tr}\bigl(\mathbf{M}^{-1}(\mathbf{MN} - \mathbf{NM})\bigr) = \operatorname{tr}\mathbf{N} - \operatorname{tr}(\mathbf{M}^{-1}\mathbf{NM}) = \operatorname{tr}\mathbf{N} - \operatorname{tr}\mathbf{N} = 0,\] 当中用到第 (i) 部分的以下形式：\(\operatorname{tr}\bigl(\mathbf{M}^{-1}(\mathbf{NM})\bigr) = \operatorname{tr}\bigl((\mathbf{NM})\mathbf{M}^{-1}\bigr) = \operatorname{tr}\mathbf{N}\)。

平方的迹：\(\operatorname{tr}(\mathbf{M}^2) = (\operatorname{tr}\mathbf{M})^2 - 2\det\mathbf{M}\)（见 第 7.4 节），由于两项都是常数，所以它也是常数。■

阶段 4 一个显式解

设 \(\mathbf{N} = t\mathbf{I} + t\mathbf{E}\)，其中 \(\mathbf{E} = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}\)，计算 \(\mathbf{MN} - \mathbf{NM}\)，并写出 \(a\)、\(b\)、\(c\)、\(d\) 所满足的微分方程。按以下次序求解：先解 \(c\)，然后 \(a\) 和 \(d\)，最后 \(b\)。

\(t\mathbf{I}\) 这部分与任何矩阵都可交换，所以 \(\mathbf{MN} - \mathbf{NM} = t(\mathbf{ME} - \mathbf{EM})\)。现在 \(\mathbf{ME} = \begin{pmatrix} 0 & a \\ 0 & c \end{pmatrix}\) 而 \(\mathbf{EM} = \begin{pmatrix} c & d \\ 0 & 0 \end{pmatrix}\)，所以 \[\dot a = -tc, \qquad \dot b = t(a - d), \qquad \dot c = 0, \qquad \dot d = tc.\] 因此 \(c = C\) 是常数；于是 \(a = A - \frac12Ct^2\) 及 \(d = D + \frac12Ct^2\)；继而 \(\dot b = t(A - D - Ct^2)\)，所以 \(b = B + \frac12(A - D)t^2 - \frac14Ct^4\)。故此 \[\mathbf{M} = \begin{pmatrix} A - \frac12Ct^2 & B + \frac12(A - D)t^2 - \frac14Ct^4 \\[0.5ex] C & D + \frac12Ct^2 \end{pmatrix}. \qed\] 验算：迹是 \(A + D\)，而行列式是 \((A - \frac12Ct^2)(D + \frac12Ct^2) - C\bigl(B + \frac12(A - D)t^2 - \frac14Ct^4\bigr) = AD - BC\)，一如所料是常数（图 7.7.1）。

阶段 5 另一条方程

若 \(\dot{\mathbf{M}} = \mathbf{MN}\)，则 \(\mathbf{N} = \mathbf{M}^{-1}\dot{\mathbf{M}}\)，而根据第 (ii) 部分，\(\operatorname{tr}\mathbf{N}\) 就是 \(\det\mathbf{M}\) 的对数导数（logarithmic derivative）。\(\mathbf{M}\) 的迹能否保持不变，而它的行列式却在改变？

当然可以。取 \(\mathbf{M} = \begin{pmatrix} 1 & t \\ t & 1 \end{pmatrix}\)，其中 \(|t| < 1\)（此时 \(\det\mathbf{M} = 1 - t^2 \neq 0\)）。它的迹恒等于 \(2\)。定义 \(\mathbf{N} = \mathbf{M}^{-1}\dot{\mathbf{M}}\)，使得 \(\dot{\mathbf{M}} = \mathbf{MN}\)： \[\mathbf{N} = \frac{1}{1 - t^2}\begin{pmatrix} 1 & -t \\ -t & 1 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} = \frac{1}{1 - t^2}\begin{pmatrix} -t & 1 \\ 1 & -t \end{pmatrix},\] 这是一个非奇异（non-singular）矩阵，而且当 \(t \neq 0\) 时，\(\operatorname{tr}\mathbf{N} = \frac{-2t}{1 - t^2} \neq 0\)。所以答案是否定的，\(\operatorname{tr}\mathbf{N}\) 不一定等于零。■

回顾

  • 交换子的迹等于零。由 \(\operatorname{tr}(\mathbf{MN}) = \operatorname{tr}(\mathbf{NM})\) 出发，每一条守恒定律都随之而来。

  • 对数导数。第 (ii) 部分把行列式的导数化为一个迹，而迹是线性的，容易处理。

  • 在显式解中检查守恒。我们确认了 \(\mathbf{M}(t)\) 的迹和行列式都是常数，借此验算它的公式。

背后的数学

孤立子与拉克斯对

1834 年，苏格兰工程师 John Scott Russell 策马追踪一个沿爱丁堡附近的联合运河（Union Canal）前进的孤立波，追了超过一英里，波形始终没有改变。这类波由科特韦赫－德弗里斯（Korteweg–de Vries，简称 KdV）方程描述。到了 1960 年代，Norman Zabusky 与 Martin Kruskal 的电脑实验显示，两个这样的“孤立子”可以相撞，然后原封不动地离开，仿佛它们是粒子一样。要解释这个现象，需要无穷多个守恒量。彼得．拉克斯在 1968 年证明，KdV 方程可以写成 \(\dot L = LP - PL\)，其中 \(L\) 和 \(P\) 是一对微分算子（differential operators）；于是，与这道题完全一样，\(L\) 的特征值是守恒的，而它们正好提供了那无穷多条守恒定律。拥有拉克斯对的系统称为可积（integrable）系统，它们属于少数可以精确求解的非线性系统。

等谱流

由于 \(\mathbf{M}\) 的迹和行列式决定了它的特征多项式（characteristic polynomial）\(\lambda^2 - (\operatorname{tr}\mathbf{M})\lambda + \det\mathbf{M}\)，\(\mathbf{M}\) 的特征值不随时间改变。流 \(\dot{\mathbf{M}} = [\mathbf{M}, \mathbf{N}]\) 使 \(\mathbf{M}\) 在特征值固定的矩阵所组成的集合之内移动。事实上，解总是具有 \(\mathbf{M}(t) = \mathbf{S}(t)^{-1}\mathbf{M}(0)\mathbf{S}(t)\) 的形式，其中 \(\mathbf{S}(t)\) 是某个可逆矩阵：这个矩阵始终与它的初始值相似（similar）。同一个想法贯穿整个物理学：在量子力学中，可观测量（observable）\(\mathbf{A}\) 按 \(\frac{\mathrm{d}\mathbf{A}}{\mathrm{d}t} = \frac{\mathrm{i}}{\hbar}[\mathbf{H}, \mathbf{A}]\) 演化，其中 \(\mathbf{H}\) 是能量，所以凡是与能量可交换的量都是守恒的。

雅可比公式

第 (ii) 部分对任何大小的可逆矩阵都成立，称为雅可比公式（Jacobi’s formula）。最稳妥的写法是不用对数，写成 \(\frac{\mathrm{d}}{\mathrm{d}t}\det\mathbf{M} = \det\mathbf{M}\,\operatorname{tr}\bigl(\mathbf{M}^{-1}\dot{\mathbf{M}}\bigr)\)，因为 \(\det\mathbf{M}\) 可能是负数；对数形式 \(\frac{\mathrm{d}}{\mathrm{d}t}\ln\det\mathbf{M} = \operatorname{tr}\bigl(\mathbf{M}^{-1}\dot{\mathbf{M}}\bigr)\) 需要 \(\det\mathbf{M} > 0\)（一般情况下则用 \(\ln|\det\mathbf{M}|\)）。由此可得一个推论：若 \(\dot{\mathbf{M}} = \mathbf{AM}\)，其中 \(\mathbf{A}\) 是常数矩阵，则 \(\det\mathbf{M}(t) = e^{t\operatorname{tr}\mathbf{A}}\det\mathbf{M}(0)\)。在微分方程的研究中，这个结果告诉你相空间（phase space）中的体积如何增长或缩小；对于经典力学的方程，这个迹等于零，体积保持不变，这个结果称为刘维尔定理（Liouville’s theorem）。

思维技巧

找出不变的东西

当某样东西在演化时，试找出由它构成而又保持不变的量。这些量限制了运动，并往往揭示出它的结构。

在这里，迹和行列式之所以守恒，是因为变化率是一个交换子。在力学中，守恒量来自对称性（诺特定理，Noether’s theorem），而找出守恒量往往是解题的第一步。

延伸练习

  1. 验算解。通过求导，验证第 4 阶段的矩阵 \(\mathbf{M}(t)\) 满足 \(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\)。

  2. 相似性。证明：若 \(\mathbf{M}(t) = \mathbf{S}^{-1}\mathbf{M}_0\mathbf{S}\)，其中 \(\mathbf{M}_0\) 是常数矩阵，而 \(\mathbf{S}(t)\) 满足 \(\dot{\mathbf{S}} = \mathbf{SN}\)，则 \(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\)。（提示：\(\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{S}^{-1} = -\mathbf{S}^{-1}\dot{\mathbf{S}}\mathbf{S}^{-1}\)。）

  3. 体积增长。设 \(\mathbf{M}(t) = \begin{pmatrix} e^{2t} & 0 \\ 0 & e^{-t} \end{pmatrix}\)。求满足 \(\dot{\mathbf{M}} = \mathbf{MN}\) 的 \(\mathbf{N}\)，并验证 \(\frac{\mathrm{d}}{\mathrm{d}t}\ln\det\mathbf{M} = \operatorname{tr}\mathbf{N}\)。

  4. 更高次幂。直接证明：当 \(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\) 时，对每个正整数 \(k\) 都有 \(\frac{\mathrm{d}}{\mathrm{d}t}\operatorname{tr}(\mathbf{M}^k) = 0\)。
