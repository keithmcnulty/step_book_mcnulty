第 7 章 · 线性代数与几何

我们学到了甚么

本章开首我们说过，矩阵（matrix）是空间的一种变换（transformation），自有其生命；我们还提出了三个问题：矩阵与数有何相似、有何不同，矩阵究竟做了甚么，以及甚么保持不变。以下是本章九道题目所揭示的答案。

1. 矩阵与数有何相似，又有何不同？

矩阵可以相加和相乘，但 第 7.1 节 指出了哪些熟悉的法则不再成立。乘法不符合交换律（commutative law），所以 \((\mathbf{A} - \mathbf{B})(\mathbf{A} + \mathbf{B})\) 未必等于 \(\mathbf{A}^2 - \mathbf{B}^2\)；矩阵中存在零因子（zero divisor），所以 \(\mathbf{AB} = \mathbf{0}\) 并不保证 \(\mathbf{BA} = \mathbf{0}\)；而一条二次矩阵方程可以有无限多个根。每一项法则的失效都有几何解释，可以从这些矩阵对平面的作用来理解。至关重要的是，有一项性质保留了下来：行列式（determinant）可乘，即 \(\det(\mathbf{AB}) = \det\mathbf{A}\det\mathbf{B}\)。第 7.3 节 说明这项性质基本上刻划了行列式，而 第 7.8 节 则用它证明了欧拉（Euler）的四平方恒等式（four-square identity），这正是拉格朗日（Lagrange）定理的关键一步；该定理指出每个正整数都是四个平方数之和。

2. 矩阵究竟做了甚么？

有几节通过找出合适的观点来回答这个问题。

  • 特征向量（eigenvector）（第 7.2 节）是矩阵不会转动的方向。在以特征向量为轴的坐标下，对称矩阵（symmetric matrix）只不过是一个伸缩，而圆的像是一个椭圆，其轴和面积都可以直接读出。

  • 行列式（第 7.3 节）是带正负号的面积比例因子：错切（shear）保持面积不变，对换会把定向（orientation）反转，奇异矩阵（singular matrix）则把平面压扁。

  • 迹（trace）与行列式（第 7.4 节）通过凯莱–哈密顿定理（Cayley–Hamilton theorem），决定一个矩阵会否在若干步之后回到单位矩阵（identity matrix）。满足 \(\mathbf{M}^8 = \mathbf{I}\) 的矩阵未必是旋转；它是在歪斜坐标下看到的旋转。又由于整数矩阵的迹是整数，晶体不可能有五重对称。

  • 三维空间中的旋转（第 7.5 节）可由向量积（cross product）通过罗德里格斯公式（Rodrigues’ formula）构造出来，这是 \(e^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta\) 在三维的对应版本。

  • 双曲旋转（hyperbolic rotation）（第 7.6 节）使点沿双曲线移动，并把它们的双曲角相加。它们就是狭义相对论中的洛伦兹变换（Lorentz boost），而它们的不变直线（invariant line）就是光的路径。

3. 甚么保持不变？

不变量（invariant）无处不在。旋转保持 \(x^2 + y^2\) 不变，洛伦兹变换保持 \(x^2 - y^2\) 不变，而相似矩阵（similar matrices）有相同的迹和行列式。在 第 7.7 节 中，一个按 \(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\) 演化的矩阵，不论其元素如何变化，它的迹和行列式都保持不变，因而它的特征值（eigenvalue）也保持不变：这就是孤立子（soliton）各条守恒定律背后的机制。而在 第 7.9 节 中，不变量是一个数，\(V - E + F = 2\)，它对每个凸多面体（convex polyhedron）都成立，并把正多面体限定为仅有五种。这个数称为欧拉示性数（Euler characteristic），是拓扑学（topology）中最早出现的不变量之一。

如果你想在入读大学之前再走远一点

  • 3Blue1Brown, Essence of Linear Algebra（线性代数的本质）：一套免费的影片系列，展示矩阵究竟做了甚么。请先看这个。

  • Gilbert Strang, Introduction to Linear Algebra（线性代数导论）：经典的入门课程，十分着重理解和应用。

  • Sheldon Axler, Linear Algebra Done Right（线性代数应该这样学）：较为抽象的处理手法，以线性映射（linear map）为中心；可在网上免费阅读。

  • David Richeson, Euler’s Gem（欧拉的瑰宝）：欧拉公式与拓扑学的诞生。

Kaplansky 曾打趣说，他和 Halmos 思考时不用坐标，但关起门来却“拼命地”用矩阵计算。这句话正好道出本章想说明的事：矩阵既具体又可以计算，但每一项计算背后都有几何（一个伸缩、一个旋转、一个投影、一个洛伦兹变换），还有一个不变量，它不取决于你怎样把它写下来。学会在这两种观点之间来回转换，是数学家所能拥有的最宝贵技能之一。
