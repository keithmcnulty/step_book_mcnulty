第 8 章 · 微分方程与动力系统

延伸练习答案

以下只是简短的答案和提示，并非完整解答：只列出结果和关键步骤，方便你核对自己的做法。请先认真做过每道练习，然后才翻看。

8.1 当解不唯一

  1. 设 \(y = v^2\)：\(2vv' = \alpha v - \beta v^2\)，所以 \(v' = \frac12(\alpha - \beta v)\)，而 \(y_1 = \frac{\alpha^2}{\beta^2}\bigl(1 - \mathrm{e}^{-\beta t/2}\bigr)^2\)。设 \(y = v^3\)：\(v' = \frac13(\alpha - \beta v)\)，而 \(y_1 = \frac{\alpha^3}{\beta^3}\bigl(1 - \mathrm{e}^{-\beta t/3}\bigr)^3\)。常数函数 \(y = 0\) 令等式两边都等于零；推导时除以 \(v\)，就把这个解丢掉了。

  2. \(2\sqrt h = 2\sqrt{h_0} - kt\)，所以 \(h = \bigl(\sqrt{h_0} - \frac12kt\bigr)^2\)，水桶在 \(T = \frac{2\sqrt{h_0}}{k}\) 时流干。\(h \equiv 0\)，以及当 \(t \leq T\) 时 \(h = \frac{k^2}{4}(T - t)^2\)、当 \(t \geq T\) 时 \(h = 0\) 的函数，两者都满足方程，而且由 \(T\) 起都等于零：看着一个空桶，你无法知道它是何时流干的。

  3. \(\frac{\mathrm{d}}{\mathrm{d}x}(y\mathrm{e}^{-2x}) = (y' - 2y)\mathrm{e}^{-2x} = 0\)，所以 \(y = C\mathrm{e}^{2x}\)，而 \(y(0) = 0\) 迫使 \(C = 0\)。函数 \(2y\) 满足利普希茨（Lipschitz）条件（它的变化至多为 \(2|y_1 - y_2|\)），而 \(2\sqrt y\) 在 \(0\) 处的斜率为无穷大。

  4. 对任意 \(b \leq 0 \leq a\)（容许 \(b = -\infty\) 或 \(a = \infty\)）：当 \(x < b\) 时 \(y = (x - b)^3\)，当 \(b \leq x \leq a\) 时 \(y = 0\)，当 \(x > a\) 时 \(y = (x - a)^3\)。\(a = b = 0\) 的情况就是 \(y = x^3\)。

8.2 不求解而估界

  1. \(\frac{\mathrm{d}}{\mathrm{d}x}\bigl((y')^2 + y^2\bigr) = 2y'(y'' + y) = 0\)，所以 \((y')^2 + y^2 = A^2\)，因而 \(|y| \leq A\)。精确解是 \(A\cos x\)。

  2. \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl((\theta')^2 - 2\cos\theta\bigr) = 2\theta'(\theta'' + \sin\theta) = 0\)。由静止开始，\((\theta')^2 = 2(\cos\theta - \cos\theta_0) \geq 0\)，所以 \(\cos\theta \geq \cos\theta_0\)；当 \(|\theta_0| < \pi\) 时，连续性（continuity）令 \(\theta\) 留在 \([-|\theta_0|, |\theta_0|]\) 之内，而当 \(|\theta_0| = \pi\) 时，摆倒立平衡，并一直停在那里。若 \(|\theta_0| > \pi\)，例如 \(\theta_0 = \frac{3\pi}{2}\)，则 \(\theta''(0) = -\sin\frac{3\pi}{2} = 1 > 0\)，所以 \(\theta\) 起初递增：摆其实位于角度 \(\theta_0 - 2\pi = -\frac\pi2\)，并在由该处量起的 \(\pm\frac\pi2\) 之间摆动。

  3. \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl((y')^2 + y^2\bigr) = 2y'(y'' + y) = -4k(y')^2 \leq 0\)。它确实趋向零，但单凭单调性（monotonicity）并不足以证明这一点：你还需要其他工具，例如显式解，其指数 \(-k \pm \sqrt{k^2 - 1}\) 的实部为负。

  4. \((y')^2 - \frac12y^4\) 是常数，等于 \(-\frac12\)。由此得 \((y')^2 = \frac12(y^4 - 1)\)，但这给不出任何界：“位能”\(-\frac12y^4\) 没有可以困住 \(y\) 的位阱，而事实上 \(y\) 会在有限时间内趋向无穷（blow up）。

8.3 收获种群

  1. 方程是 \(x' = \alpha^2 - (x - K)^2\)，可化为 \(y' = y(2\alpha - y)\)。设 \(w = \frac1y\)，则 \(w' = 1 - 2\alpha w\)，所以 \(w = \frac{1}{2\alpha} + C\mathrm{e}^{-2\alpha t}\)。若 \(y(0) < 0\)，则 \(w(0) < 0 < \frac{1}{2\alpha}\)，所以 \(w\) 在有限时间内经过 \(0\)，而 \(y \to -\infty\)；\(x\) 在此之前已到达 \(0\)。

  2. 设 \(z = x - K\)，则 \(z' = -(z^2 + \beta^2)\)，所以 \(\tan^{-1}\frac z\beta = \tan^{-1}\frac K\beta - \beta t\)。种群数量在 \(t = \frac2\beta\tan^{-1}\frac K\beta\) 时降至零（\(z = -K\)）。

  3. \(x' = x(2K - h - x)\) 的平衡点（equilibria）是 \(0\) 和 \(2K - h\)。当 \(h < 2K\) 时，这是一条环境承载量（carrying capacity）为正的逻辑斯谛方程（logistic equation），每个正数解都趋向 \(2K - h\)。捕获量随种群数量下降而减少，所以永远不会把种群数量逼至零。

  4. \(x = K + K\tanh Kt\)，而 \(\tanh Kt = \frac12\) 给出 \(t = \frac{1}{K}\tanh^{-1}\frac12 = \frac{\ln3}{2K}\)。

8.4 盘旋趋向圆

  1. 曲线与半径之间的夹角 \(\psi\) 满足 \(\tan\psi = \frac{r}{\mathrm{d}r/\mathrm{d}\theta} = -1\)，在每一点都相同：曲线与每条射线都以 \(45^\circ\) 相交。

  2. \(x\,\mathrm{d}x + y\,\mathrm{d}y = \frac12\,\mathrm{d}(x^2 + y^2) = r\,\mathrm{d}r\)。另外 \(x\,\mathrm{d}y - y\,\mathrm{d}x = r\cos\theta(\sin\theta\,\mathrm{d}r + r\cos\theta\,\mathrm{d}\theta) - r\sin\theta(\cos\theta\,\mathrm{d}r - r\sin\theta\,\mathrm{d}\theta) = r^2\,\mathrm{d}\theta\)。

  3. 设 \(s = r^2\)，则 \(\dot s = 2s(1 - s)\)，是一条逻辑斯谛方程，所以对任意 \(s(0) > 0\) 都有 \(s \to 1\)。写成笛卡儿（Cartesian）形式：\(\dot x = x(1 - x^2 - y^2) - y\)，\(\dot y = y(1 - x^2 - y^2) + x\)。

  4. \(\dot r = r(r - 1)(r - 2)\)，\(\dot\theta = 1\)。在 \(0\) 与 \(1\) 之间，\(\dot r > 0\)；在 \(1\) 与 \(2\) 之间，\(\dot r < 0\)；超过 \(2\) 之后，\(\dot r > 0\)。所以 \(r = 1\) 是吸引的，而 \(r = 2\) 是排斥的。

8.5 格力犬追逐格力犬

  1. 由对称性可知，几只狗始终构成一个正方形。\(A\) 沿 \(AB\) 以速率 \(v\) 奔跑，令距离以速率 \(v\) 缩短；\(B\) 沿 \(BC\) 奔跑，而这个方向垂直于 \(AB\)，所以在一阶近似下不会改变距离。因此 \(AB\) 恰好以速率 \(v\) 缩短，由 \(s\) 减至 \(0\)，需时 \(\frac sv\)。

  2. \(r = \lambda\mathrm{e}^{-\sqrt3\theta}\)。距离以速率 \(v - v\cos120^\circ = \frac32v\) 缩短，所以牠们在时间 \(\frac{2s}{3v}\) 后相遇，每只各跑了 \(\frac{2s}{3}\)（这与 \(\frac{s}{2\sin^2(\pi/n)}\) 在 \(n = 3\) 时的值吻合）。

  3. 每转一圈，\(r\) 就乘以 \(\mathrm{e}^{-2\pi} \approx \frac{1}{535}\)：转一圈后约为 \(19\) cm。转两圈后约为 \(0.35\) mm，所以转足两圈便已足够。

  4. 两只狗笔直地向对方奔跑，在时间 \(\frac{s}{2v}\) 后于中点相遇。公式在此失效：\(\tan\frac\pi2\) 为无穷大，正好对应完全没有转弯这个事实。

8.6 量子振子

  1. 这只需直接求导（虽然颇为繁琐）；另一个做法是由第 4 题推出。取 \(2\lambda = \omega\)，则 \(\int y_0y_2 = \int(2\omega x^2 - 1)\mathrm{e}^{-\omega x^2}\,\mathrm{d}x = 2\omega \cdot \frac{1}{2\omega}\sqrt{\frac\pi\omega} - \sqrt{\frac\pi\omega} = 0\)。

  2. \(y'' = (4\lambda^2x^2 - 2\lambda)y\)，所以方程要求 \(4\lambda^2 = \omega^2\) 及 \(2\lambda = (2\nu + 1)\omega\)。取 \(\lambda = \frac\omega2 > 0\)（使解衰减），得 \(\nu = 0\)。

  3. \(\frac{\mathrm{d}}{\mathrm{d}x}(y_my_n' - y_ny_m') = y_my_n'' - y_ny_m'' = (m^2 - n^2)y_my_n\)。由 \(0\) 积分至 \(\pi\)：因为 \(y_m\) 和 \(y_n\) 在两端都等于零，左边得 \(0\)，而 \(m^2 \neq n^2\)。

  4. 记 \(c = (2n + 1)\omega\)，于是 \(y_n'' = (\omega^2x^2 - c)y_n\)。把 \(z = \omega xy_n - y_n'\) 求导两次，并运用上式（及其导数），得 \(z'' - \omega^2x^2z = -(c + 2\omega)z\)，而 \(c + 2\omega = (2n + 3)\omega\)。由 \(y_0 = \mathrm{e}^{-\omega x^2/2}\) 出发：先得 \(2\omega x\mathrm{e}^{-\omega x^2/2}\)，再得 \(2\omega(2\omega x^2 - 1)\mathrm{e}^{-\omega x^2/2}\)，它们分别是 \(y_1\) 和 \(y_2\) 的倍数。

8.7 可以解出的混沌

  1. (i) 用归纳法（induction）：若 \(0 < x < 1\)，则 \(0 < x(1 - x) \leq \frac14\)，所以 \(0 < kx(1 - x) < 1\)。(ii) \(a = ka(1 - a)\) 给出 \(k = \frac{1}{1 - a}\)。(iii) 由于 \(x_1 = ka(1 - a) = ab\)，条件 \(x_2 = a\) 即 \(kab(1 - ab) = a\)；代入 \(k = \frac{b}{1 - a}\) 后，化为 \(ab^3 - b^2 + 1 - a = 0\)。根 \(b = 1\) 对应不动点（fixed point）（\(x_1 = a\)），所以把它提出来：\(ab^2 + (a - 1)b + (a - 1) = 0\)；解出 \(b\)，便得 \(k = \frac{b}{1 - a}\)。等价的说法是：\(2\)-循环（cycle）的两点是 \(k^2x^2 - k(k + 1)x + (k + 1) = 0\) 的两个根，其判别式（discriminant）\(k^2(k + 1)(k - 3)\) 只在 \(k > 3\) 时为正。

  2. \(p = -1\)，\(q = 0\)，\(r = -2\)：\(4pr = 8 = 8 + 2q - q^2\)。比较系数得 \(\alpha = \frac4p = -4\) 及 \(\beta = \frac{q - 4}{2p} = 2\)，所以 \(v_n = 2 - 4\sin^2(2^n\theta) = 2\cos(2^{n+1}\theta)\)，即 \(2\cos(2^n\phi)\)，其中 \(\phi = 2\theta\)。

  3. \(u_3 = u_0\) 要求 \(\sin^2 8\theta = \sin^2\theta\)，所以 \(8\theta = \pm\theta + k\pi\)。取 \(\theta = \frac\pi7\)：得循环 \(\sin^2\frac\pi7 \to \sin^2\frac{2\pi}{7} \to \sin^2\frac{4\pi}{7} \to \sin^2\frac{8\pi}{7} = \sin^2\frac\pi7\)。取 \(\theta = \frac\pi9\)：\(\sin^2\frac\pi9\)，\(\sin^2\frac{2\pi}9\)，\(\sin^2\frac{4\pi}{9}\)。映射（map）\(u \mapsto u_3\) 有 \(2^3 = 8\) 个不动点；其中两个（\(0\) 和 \(\frac34\)）是原映射本身的不动点，余下 \(6\) 个点的周期恰好是 \(3\)：即两个 \(3\)-循环。

  4. 每一步都把 \(\theta\) 加倍，因而损失一个二进制数位的准确度，所以大约 \(50\) 步之后，计算所得的数值与真实数值已毫无关系。但这些数值并非没有用处：计算所得的数列始终贴近一条由稍为不同的起点出发的真实轨道（orbit）（这就是影随（shadowing）性质），所以它的统计特性仍然正确。

8.8 周期三蕴含混沌

  1. 设 \(a\)、\(b\)、\(c > 0\) 而 \(d < 0\)：\(b = 7 - 2a\)，\(c = 7 - 2b\)，\(d = 7 - 2c\)，\(a = 7 + 2d\)。解得 \(17a = 49\)，所以循环是 \(\frac{49}{17} \to \frac{21}{17} \to \frac{77}{17} \to -\frac{35}{17} \to \frac{49}{17}\)，其中三点在 \(I_2 = [1, 5]\) 内，一点在 \(I_1 = [-3, 1]\) 内。

  2. 所找到的点的行程（itinerary）是 \(I_2, I_2, \ldots, I_2, I_1\)（其中有 \(n - 1 \geq 3\) 步在 \(I_2\) 内）。循环 \(1 \to 5 \to -3\) 不可能依循这个行程：\(-3\) 不在 \(I_2\) 内，所以 \(1\)（它的第二个像是 \(-3\)）、\(5\)（它的第一个像是 \(-3\)）以及 \(-3\) 本身，都不可能是该点。

  3. 覆盖图（covering diagram）是 \([1, 2] \to [3, 4], [4, 5]\)；\([2, 3] \to [4, 5]\)；\([3, 4] \to [2, 3], [3, 4]\)；\([4, 5] \to [1, 2]\)。长度为 \(3\) 的回路只有 \([3, 4] \to [3, 4] \to [3, 4]\)，它给出的是不动点，而不是 \(3\)-循环。

  4. 设 \(x = 14y - 7\)，则 \(\frac{\mathrm{f}(x) + 7}{14} = 1 - |2y - 1|\)，即帐篷映射（tent map）。加倍会把二进制数位向左移一位；若移出的数位是 \(1\)，结果便是 \(2 - 2y\)，即把余下的数位逐一反转。\(3\)-循环有 \(\frac27 \to \frac47 \to \frac67\) 和 \(\frac29 \to \frac49 \to \frac89\)（即 \(x = -3, 1, 5\) 和 \(x = -\frac{35}{9}, -\frac79, \frac{49}{9}\)）；以二进制表示，\(\frac27 = 0.\overline{010}\) 而 \(\frac29 = 0.\overline{001110}\)。
