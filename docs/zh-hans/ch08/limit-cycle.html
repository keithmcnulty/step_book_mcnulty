盘旋趋向圆

题目

STEP III 2015，第 8 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/15-s3-q8

引子

自然界中有许多系统，无论起始状态如何，最终都会进入同一种规律的节奏：心脏的跳动、蟋蟀的鸣叫、稳定拉奏的小提琴弦、捕食者与猎物的种群数量周期。稍加扰动，它们又会回到原来的节奏。用微分方程（differential equation）的语言来说，它们的解会趋近一条闭合曲线，称为极限环（limit cycle）。

这道题目正是要构造一个极限环。方程以 \(x\) 和 \(y\) 表示时看似无从入手，但换成极坐标（polar coordinates）后，就化简成可以求解的形式，而且各个解原来都会从内侧和外侧盘旋着贴近单位圆。当中的关键一步，是选取与问题的对称性（symmetry）相配的坐标，这也是本书一直沿用的手法。

动笔之前

两条方程其实都暗藏 \(x\,\mathrm{d}x + y\,\mathrm{d}y\) 和 \(x\,\mathrm{d}y - y\,\mathrm{d}x\) 这两个组合。它们在极坐标中是甚么？

由于 \(r^2 = x^2 + y^2\)，求导后得 \(x\,\mathrm{d}x + y\,\mathrm{d}y = r\,\mathrm{d}r\)。另外 \(x\,\mathrm{d}y - y\,\mathrm{d}x = r^2\,\mathrm{d}\theta\)（这就是 第 4.9 节 中的面积公式）。有了这两条恒等式（identity），变量代换（change of variables）几乎毫不费力：只要把方程改写成只含这两个组合的形式即可。

逐步解题

阶段 1 以极坐标处理第 (i) 部分

把方程写成 \((y + x)\,\mathrm{d}y - (y - x)\,\mathrm{d}x = 0\)，再重新整理： \[(x\,\mathrm{d}x + y\,\mathrm{d}y) + (x\,\mathrm{d}y - y\,\mathrm{d}x) = 0.\]

展开算式，验证以上的整理无误。然后运用上面两条恒等式。

\((y + x)\,\mathrm{d}y - (y - x)\,\mathrm{d}x = y\,\mathrm{d}y + x\,\mathrm{d}y - y\,\mathrm{d}x + x\,\mathrm{d}x\)，正是上面的算式。化成极坐标形式就是 \(r\,\mathrm{d}r + r^2\,\mathrm{d}\theta = 0\)，两边除以 \(r^2\,\mathrm{d}\theta\)（其中 \(r > 0\)），得 \[\frac{\mathrm{d}r}{\mathrm{d}\theta} + r = 0. \qed\] 方程的解是 \(r = Ce^{-\theta}\)：这些是对数螺线（logarithmic spiral），随着 \(\theta\) 增加而向原点卷入，随着 \(\theta\) 减少而向无穷远处卷出。

阶段 2 第 (ii) 部分

新方程是在旧方程之上，加入含有 \(x^2 + y^2 = r^2\) 的额外项。用同样的方法改写，并求出 \(\frac{\mathrm{d}r}{\mathrm{d}\theta}\)。

方程是 \(\bigl(y + x - xr^2\bigr)\,\mathrm{d}y - \bigl(y - x - yr^2\bigr)\,\mathrm{d}x = 0\)，即 \[\bigl[(y + x)\,\mathrm{d}y - (y - x)\,\mathrm{d}x\bigr] - r^2\bigl(x\,\mathrm{d}y - y\,\mathrm{d}x\bigr) = 0.\] 第一个括号和之前一样，等于 \(r\,\mathrm{d}r + r^2\,\mathrm{d}\theta\)，第二个括号则是 \(r^2\,\mathrm{d}\theta\)。因此 \(r\,\mathrm{d}r + r^2(1 - r^2)\,\mathrm{d}\theta = 0\)，由此得 \[\frac{\mathrm{d}r}{\mathrm{d}\theta} = r^3 - r.\]

这条方程对 \(r\) 而言并非线性（linear），但换成 \(u = r^{-2}\) 后就变成线性。\(u\) 满足甚么方程？

设 \(u = r^{-2}\)，则 \(\frac{\mathrm{d}u}{\mathrm{d}\theta} = -2r^{-3}\frac{\mathrm{d}r}{\mathrm{d}\theta} = -2r^{-3}(r^3 - r) = -2 + 2u\)。所以 \(\frac{\mathrm{d}u}{\mathrm{d}\theta} - 2u = -2\)，其解为 \(u = 1 + Ae^{2\theta}\)。因此 \[r^2 = \frac{1}{1 + Ae^{2\theta}}. \qed\]

阶段 3 三类解

  • \(A = 0\)：\(r = 1\)。单位圆是一个解。

  • \(A > 0\)：恒有 \(r < 1\)。当 \(\theta \to -\infty\) 时，\(r \to 1\)；当 \(\theta \to +\infty\) 时，\(r \to 0\)。曲线在圆与原点之间盘旋。

  • \(A < 0\)：\(r > 1\)，而且公式只在 \(1 + Ae^{2\theta} > 0\) 时才有意义，即 \(\theta < \frac12\ln\left(-\frac1A\right)\)。当 \(\theta \to -\infty\) 时，\(r \to 1\)；当 \(\theta\) 趋近该上界时，\(r \to \infty\)。曲线在圆与无穷远之间盘旋。

所以当 \(\theta \to -\infty\) 时，每条解曲线都会从内侧或外侧趋近单位圆（图 8.4.1）。

回顾

  • 善用对称性。这些方程对所有方向一视同仁，而极坐标令这一点显露出来。

  • 认出标准组合。\(x\,\mathrm{d}x + y\,\mathrm{d}y = r\,\mathrm{d}r\) 和 \(x\,\mathrm{d}y - y\,\mathrm{d}x = r^2\,\mathrm{d}\theta\) 完成了大部分工作。

  • 代换可使方程线性化。非线性方程 \(r' = r^3 - r\) 换成 \(u = r^{-2}\) 后变成线性（这是一条伯努利方程（Bernoulli equation））。

背后的数学

极限环

庞加莱（Henri Poincaré）在 1880 年代研究平面上微分方程的定性行为时，引入了极限环。不妨把题目中的方程理解为描述一个点在平面上运动的路径。单位圆是一条孤立的闭轨道（closed orbit），附近的每条轨道都会缠绕着向它靠近（或远离它，视乎时间的方向而定）。1926 年，荷兰工程师 Balthasar van der Pol 在一个装有真空管的电路中发现了极限环，并提出类似的方程可以描述心脏的跳动。凡是具有自持而稳定节奏的系统，都可以用极限环作为模型：生理时钟、神经脉冲、捕食者与猎物种群数量的周期。

平面上没有混沌

庞加莱–本迪克松定理（Poincaré–Bendixson theorem）指出，对于平面上的光滑系统，如果一条轨道一直留在某个有界区域内，又不趋近任何平衡点（equilibrium），它就必定趋近一条闭轨道。所以在二维的情况下，长期行为只限于平衡点和环：混沌（chaos）没有容身之处，因为轨道不能相交。混沌至少需要三维，正如洛伦兹（Edward Lorenz）在 1963 年以他那著名的三变量对流模型（“蝴蝶”）所发现的那样。至于离散时间的情况，我们会在 第 8.7 节 看到，即使只有一维，混沌也可能出现。

一个未解决的问题

1900 年，希尔伯特（David Hilbert）在他的第十六问题中问道：当 \(P\) 和 \(Q\) 是 \(n\) 次多项式时，系统 \(x' = P(x, y)\)，\(y' = Q(x, y)\) 最多可以有多少个极限环？即使是 \(n = 2\) 的情况，答案至今仍然未知：已知有些系统具有四个极限环，但是否可能有更多，则无人知晓。在希尔伯特的问题之中，这是极少数至今仍然完全悬而未决的一个。

思维技巧

转换坐标以配合对称性

如果问题具有旋转对称性，就用极坐标；如果具有其他对称性，就找出与之相配的坐标。

合适的坐标把一条难以处理的方程变成可分离变量（separable）的方程，并令解的几何形状（圆和螺线）一目了然。

延伸练习

  1. 螺线。对于第 (i) 部分的解 \(r = e^{-\theta}\)，证明曲线与每条由原点出发的射线都以相同的角度 \(45^\circ\) 相交。（这就是对数螺线又称为等角螺线（equiangular spiral）的原因。）

  2. 极坐标恒等式。证明 \(x\,\mathrm{d}x + y\,\mathrm{d}y = r\,\mathrm{d}r\) 和 \(x\,\mathrm{d}y - y\,\mathrm{d}x = r^2\,\mathrm{d}\theta\)。

  3. 随时间变化的系统。考虑系统 \(\dot r = r(1 - r^2)\)，\(\dot\theta = 1\)。证明当 \(t \to \infty\) 时，每个满足 \(r(0) > 0\) 的解都趋近单位圆。把这个系统以 \(x\) 和 \(y\) 表示。

  4. 两个环。找出一个形如 \(\dot r = f(r)\)，\(\dot\theta = 1\) 的系统，使它有两个极限环，分别位于 \(r = 1\) 和 \(r = 2\)，其中一个是吸引的（attracting），另一个是排斥的（repelling）。
