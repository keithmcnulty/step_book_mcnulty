题目

STEP III 1988，第 10 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/88-s3-q10

引子

四只狗分别站在一块正方形田地的四个角上，每只狗都追赶牠左边的那一只。牠们会在哪里相遇？要花多少时间？所走的路径又是怎样的？这些路径是优美的螺线，绕着中心转无穷多圈，然而每只狗只跑了有限的距离，恰好等于正方形的边长。

这是一个追逐问题（pursuit problem），这类问题最早由 Pierre Bouguer 于 1732 年研究，当时考虑的是一艘船追赶海盗船的情形。令问题得以解决的诀窍是对称性（symmetry）：发生在一只狗身上的事，同样发生在其余各只身上，所以四只狗始终构成一个正方形。一旦看出这一点，微分方程（differential equation）几乎就自然而然地写出来了。

动笔之前

根据对称性，四只狗在每一刻构成甚么形状？它的中心在哪里？

把整个情形绕正方形的中心旋转四分之一圈（即 \(A \to B \to C \to D \to A\)），情形保持不变，所以四只狗始终构成一个正方形，而且中心始终是同一点 \(O\)。这个正方形一边旋转一边缩小，但始终是正方形。特别地，\(A\) 和 \(B\) 与 \(O\) 的距离始终同为 \(r\)，而 \(OB\) 始终比 \(OA\) 超前四分之一圈。

逐步解题

阶段 1 运动的方向

\(A\) 朝着 \(B\) 跑。在三角形 \(OAB\) 中，\(AB\) 与 \(AO\)（指向中心的方向）所成的角是多少？

三角形 \(OAB\) 中 \(OA = OB\)，且在 \(O\) 处是直角，所以其余两个角都是 \(45^\circ\)。因此 \(A\) 的速度（velocity）大小为 \(v\)，方向与向内的径向（radial）方向成 \(45^\circ\)，并且偏向 \(B\) 的一方，即 \(\theta\) 增加的方向（假设我们标记角度时，令 \(B\) 位于 \(A\) 的逆时针方向）。

阶段 2 微分方程

把 \(A\) 的速度分解为径向和横向（transverse）两部分。在极坐标（polar coordinates）中，径向速度是 \(\dot r\)，横向速度是 \(r\dot\theta\)。

径向分量（向内）是 \(v\cos45^\circ\)，横向分量是 \(v\sin45^\circ\)，所以 \[\dot r = -\frac{v}{\sqrt2}, \qquad r\dot\theta = \frac{v}{\sqrt2}.\] 两式相除，得 \(\dfrac{\mathrm{d}r}{\mathrm{d}\theta} = \dfrac{\dot r}{\dot\theta} = -r\)，所以 \(r = \lambda e^{-\theta}\)，其中若最初 \(\theta = 0\)，则 \(\lambda\) 是最初与中心的距离。■

阶段 3 \(n\) 只狗

对于正 \(n\) 边形，三角形 \(OAB\) 中在 \(O\) 处的角是多少？\(AB\) 与 \(AO\) 所成的角是多少？重复第 2 阶段的做法。

在 \(O\) 处的角是 \(\frac{2\pi}{n}\)，所以两个相等的底角是 \(\frac12\bigl(\pi - \frac{2\pi}{n}\bigr) = \frac\pi2 - \frac\pi n\)。速度与向内的半径所成的角就是这个角，所以 \[\dot r = -v\cos\left(\frac\pi2 - \frac\pi n\right) = -v\sin\frac\pi n, \qquad r\dot\theta = v\sin\left(\frac\pi2 - \frac\pi n\right) = v\cos\frac\pi n.\] 因此 \(\dfrac{\mathrm{d}r}{\mathrm{d}\theta} = -r\tan\dfrac\pi n\)，于是 \[r = \lambda e^{-\theta\tan(\pi/n)}. \qed\] 当 \(n = 4\) 时，\(\tan\frac\pi4 = 1\)，这就回到正方形的情形。

回顾

  • 对称性把多个物体化为一个。四只互相影响的狗，变成了一个遵从简单法则的质点（particle），因为整个布局始终是正方形。

  • 绕中心的运动宜用极坐标。速度的径向和横向分量 \(\dot r\) 和 \(r\dot\theta\) 直接给出了方程。

  • 相除以消去时间。比值 \(\dot r/\dot\theta\) 给出了路径的形状，而毋须知道何时到达每一点。

背后的数学

无穷多圈，有限距离

径向速率 \(\dot r = -v\sin\frac\pi n\) 是常数，所以各只狗在时间 \(T = \frac{r_0}{v\sin(\pi/n)}\) 之后到达中心，每只狗跑过的距离是 \(vT = \frac{r_0}{\sin(\pi/n)}\)。对于边长为 \(s\) 的正 \(n\) 边形，\(r_0 = \frac{s}{2\sin(\pi/n)}\)，所以每只狗跑过的距离是 \[\frac{s}{2\sin^2(\pi/n)}.\] 对于四只狗，这恰好是 \(s\)：每只狗跑过的距离正好是一条边的长度。（这里有一个巧妙的看法：\(B\) 的速度始终与 \(AB\) 垂直，所以它不会改变距离 \(AB\)；只有 \(A\) 以速率 \(v\) 沿着 \(AB\) 笔直前进的运动才会缩短两者的距离，而这个距离最初是 \(s\)。）对于三只狗，距离是 \(\frac23s\)；对于六只狗，距离是 \(2s\)。然而在每一种情形下，螺线都绕着中心转无穷多圈，因为当 \(r \to 0\) 时 \(\theta \to \infty\)。一条长度有限却转了无穷多圈的曲线并不是悖论：那些圈缩小得足够快。

对数螺线

曲线 \(r = \lambda e^{-k\theta}\) 称为对数螺线（logarithmic spiral）或等角螺线（equiangular spiral）：它与每一条从中心出发的射线相交的角度都相同。它出现在大自然之中，例如鹦鹉螺的壳和某些星系的旋臂，因为保持形状不变的生长就会产生这种曲线。雅各布·伯努利（Jacob Bernoulli）对它极为着迷，甚至要求把它刻在自己的墓碑上，并附上格言 Eadem mutata resurgo（“纵然改变，我仍将依旧复起”），指的是它在任何尺度下看起来都一样。结果石匠刻的却是一条阿基米德螺线（Archimedean spiral）。

实际中的追逐

“纯追逐”（pure pursuit），即始终笔直朝着目标前进，是导弹或捕食者最简单的导引法则。但它并不是最好的：朝着目标将会到达的位置前进（“比例导引”，proportional navigation）更有效率，而现代导弹以及某些捕食者（例如蜻蜓和隼）实际上正是这样做的。追逐与逃避的数学在二十世纪自成一门学科，名为微分博弈（differential games）。

思维技巧

利用对称性简化多体问题

如果一个系统具有对称性，而其法则又不破坏这种对称性，那么对称性就会一直保持下去，你只需追踪其中一部分。

这个想法能解决力学和动力学中的许多问题；它是对称与守恒（conservation）之间深刻联系的一个简单例子。

延伸练习

  1. 巧妙的论证。仔细解释为何在四只狗的问题中，距离 \(AB\) 恰好以速率 \(v\) 减少，并由此推出四只狗在时间 \(s/v\) 之后相遇。

  2. 三只狗。三只狗从边长为 \(s\) 的等边三角形的三个角出发。求每条路径的方程、牠们相遇所需的时间，以及每只狗跑过的距离。

  3. 转了多少圈？设四只狗出发时距离中心 \(100\) m，牠们转了完整一圈之后距离中心多近？转了多少个完整的圈之后，牠们与中心的距离在 \(1\) mm 以内？

  4. 两只狗。当 \(n = 2\)（两只狗面对面）时会怎样？公式是否仍然有意义？
