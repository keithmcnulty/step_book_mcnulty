8.6

量子振子

题目

STEP III 1988，第 7 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/88-s3-q7

引子

系在弹簧上的质点，振动的能量可以随你喜欢：把它拉开少许也好，拉开很远也好。但在 1900 年，普朗克（Max Planck）发现，要解释高温物体所发出的光的颜色，唯一的办法是假定振动中的原子只能具有某些特定的能量，每级相差一个固定的大小。在原子的尺度上，能量是一份一份的，称为量子（quanta）。二十五年后，量子力学（quantum mechanics）解释了个中原因。

这道题目正包含了这个解释。题中的微分方程（differential equation）经过单位转换后，就是一个量子粒子处于弹簧式势能中的薛定谔方程（Schrödinger equation），亦即量子谐振子（quantum harmonic oscillator）。只有当能量取某些特殊的值时，它才有性质良好的解，即在无穷远处衰减至零的解；这些能量值以 \(n = 0, 1, 2, \ldots\) 标记，彼此等距排列。而且不同的 \(n\) 所对应的解是正交（orthogonal）的：它们乘积的积分为零，就像傅里叶级数（Fourier series）中的 \(\sin mx\) 与 \(\sin nx\) 一样。量子谐振子是研究分子、固体和光的物理学的起点。

动笔之前

为甚么像 \(e^{-\lambda x^2}\) 这样的函数会是一个合理的猜测？当 \(x \to \pm\infty\) 时，\(e^{-\lambda x^2}\) 及其导数会怎样？

当 \(|x|\) 很大时，方程主要由 \(y'' \approx \omega^2x^2y\) 支配，而高斯函数（Gaussian）\(e^{-\lambda x^2}\) 在 \(x\) 很大时满足 \(y'' \approx 4\lambda^2x^2y\)，只要 \(4\lambda^2 = \omega^2\)，两者便吻合。若 \(\lambda > 0\)，高斯函数及其所有导数衰减至 \(0\) 的速度比 \(x\) 的任何次幂都要快。因此边界条件（boundary conditions）会自动成立；真正要下工夫的，是令函数符合方程。

逐步解题

阶段 1 基态

把 \(y_0 = e^{-\lambda x^2}\) 求导两次，代入 \(n = 0\) 时的方程，然后比较 \(x^2\) 的系数和常数项。

\(y_0' = -2\lambda xe^{-\lambda x^2}\)，而 \(y_0'' = (4\lambda^2x^2 - 2\lambda)e^{-\lambda x^2}\)。\(n = 0\) 时的方程要求 \[4\lambda^2x^2 - 2\lambda - \omega^2x^2 = -\omega\] 对所有 \(x\) 成立。比较系数（match coefficients）：\(4\lambda^2 = \omega^2\) 及 \(2\lambda = \omega\)。取 \(\lambda = \frac\omega2\) 时两式同时成立（取 \(\lambda > 0\)，使得 \(y_0 \to 0\)）。而且当 \(x \to \pm\infty\) 时，\(y_0\)、\(y_0' \to 0\)。■

阶段 2 第一激发态

\(y_1 = xe^{-\lambda x^2}\) 满足 \(y_1' = (1 - 2\lambda x^2)e^{-\lambda x^2}\) 及 \(y_1'' = (4\lambda^2x^3 - 6\lambda x)e^{-\lambda x^2}\)。\(n = 1\) 时的方程要求 \[4\lambda^2x^3 - 6\lambda x - \omega^2x^3 = -3\omega x,\] 而同样取 \(\lambda = \frac\omega2\) 时此式成立。\(y_1\) 与 \(y_1'\) 同样在 \(\pm\infty\) 处衰减至零。■

阶段 3 一个恒等式

用积法则（product rule）对 \(y_my_n' - y_ny_m'\) 求导。四项之中有两项互相抵销。然后利用微分方程代换 \(y_n''\) 和 \(y_m''\)。

\(\dfrac{\mathrm{d}}{\mathrm{d}x}(y_my_n' - y_ny_m') = y_m'y_n' + y_my_n'' - y_n'y_m' - y_ny_m'' = y_my_n'' - y_ny_m''\)。由方程可得 \(y_n'' = \bigl(\omega^2x^2 - (2n + 1)\omega\bigr)y_n\)，对 \(m\) 亦有类似的式子。所以 \[y_my_n'' - y_ny_m'' = y_my_n\bigl[\omega^2x^2 - (2n + 1)\omega - \omega^2x^2 + (2m + 1)\omega\bigr] = 2(m - n)\omega y_my_n. \qed\]

阶段 4 正交性

把恒等式由 \(-\infty\) 积分至 \(\infty\)。左方是甚么？

左方积分后得 \(\bigl[y_my_n' - y_ny_m'\bigr]_{-\infty}^{\infty} = 0 - 0 = 0\)，因为每个 \(y\) 和 \(y'\) 在两端都趋向 \(0\)。所以 \(2(m - n)\omega\int_{-\infty}^{\infty}y_my_n\,\mathrm{d}x = 0\)，而由于 \(m \neq n\) 及 \(\omega > 0\)， \[\int_{-\infty}^{\infty}y_m(x)y_n(x)\,\mathrm{d}x = 0. \qed\] 对于 \(y_0\) 和 \(y_1\)，这一点很容易直接看出：\(y_0y_1 = xe^{-\omega x^2}\) 是奇函数（odd function）。但这个恒等式毋须知道函数本身是甚么，便一举证明了每一对解都正交。

回顾

  • 比较系数。代入猜测的形式，并要求方程对所有 \(x\) 成立，便确定了 \(\lambda\)。

  • 朗斯基行列式（Wronskian）的技巧。\(y_my_n' - y_ny_m'\) 这个组合求导后，其中的二阶导数可以用方程代换，余下的式子十分简单。

  • 边界条件消去边界项。解在无穷远处衰减，令左方积分后为零，从而得出正交性。

背后的数学

薛定谔方程

1926 年，薛定谔（Erwin Schrödinger）提出，量子粒子可用波函数（wave function）\(\psi(x)\) 来描述；若粒子的能量为 \(E\)，并处于势能 \(V(x)\) 之中，则波函数满足 \[-\frac{\hbar^2}{2m}\psi'' + V(x)\psi = E\psi.\] 对于弹簧，\(V(x) = \frac12m\Omega^2x^2\)，把 \(x\) 重新标度后，这正是题目中的方程，其中 \(E = \bigl(n + \frac12\bigr)\hbar\Omega\)。物理上要求 \(\psi\) 在无穷远处衰减至零（这样粒子才确实身处某处），而只有这些能量才能满足这个要求：这就是量子化（quantisation），是由数学自然推导出来的结果。留意最低的能量并不是零，而是 \(\frac12\hbar\Omega\)：量子谐振子永远不可能完全静止。这种零点能（zero-point energy）真实存在，而且可以量度；正因如此，液态氦在常压下即使到了绝对零度也不会凝固。

埃尔米特函数与施图姆－刘维尔理论

通解为 \(y_n = H_n(\sqrt\omega x)e^{-\omega x^2/2}\)，其中 \(H_n\) 是一个 \(n\) 次多项式，称为埃尔米特多项式（Hermite polynomial）（图 8.6.1）。正交性并非这条方程独有。只要一条方程可以写成 \((py')' + qy = -\lambda wy\) 并配上适当的边界条件，属于不同 \(\lambda\) 值的解便互相正交，所用的论证与第 4 阶段完全相同。这就是施图姆－刘维尔理论（Sturm–Liouville theory，1830 年代），它涵盖了傅里叶级数中的正弦函数（第 3.7 节）、鼓面的振动、静电学中的勒让德多项式（Legendre polynomials），以及氢原子的波函数。第 4.7 节 的特征值问题（eigenvalue problem）是另一个例子：在那里求得的临界值就是特征值 \(\lambda\)，而那些正交函数就是系统固有的“模态”（modes）。

思维技巧

由恒等式得出正交性

要证明相关方程的两个解正交，可找出一个恰当导数（exact derivative），使它的积分因边界条件而为零，而它本身又等于两个解的乘积的某个倍数。

这比直接计算积分有力得多：它一次过适用于每一对解，即使你无法把解写出来也行。

延伸练习

  1. 下一个态。证明 \(y_2 = (4\lambda x^2 - 1)e^{-\lambda x^2}\)（其中 \(\lambda = \frac\omega2\)）满足 \(n = 2\) 时的方程。利用 \(\int_{-\infty}^\infty e^{-\omega x^2}\,\mathrm{d}x = \sqrt{\pi/\omega}\) 及 \(\int_{-\infty}^\infty x^2e^{-\omega x^2}\,\mathrm{d}x = \frac{1}{2\omega}\sqrt{\pi/\omega}\)，直接验证 \(\int_{-\infty}^\infty y_0y_2\,\mathrm{d}x = 0\)。

  2. 没有其他能量。把 \(n\) 换成一般的数 \(\nu\)，并尝试 \(y = e^{-\lambda x^2}\)。证明只有当 \(\nu = 0\) 时它才是解。（事实上，只有当 \(\nu\) 是非负整数时，才存在衰减的解。）

  3. 正弦波。由 \(y'' = -n^2y\) 及 \(y(0) = y(\pi) = 0\) 出发，用同样的方法证明当 \(m \neq n\) 时 \(\int_0^\pi \sin mx\sin nx\,\mathrm{d}x = 0\)。

  4. 阶梯。证明若 \(y_n\) 是方程的解，则 \(y_{n+1} = \omega xy_n - y_n'\) 是把 \(n\) 换成 \(n + 1\) 后的方程的解。利用这个结果，由 \(y_0\) 生成 \(y_1\) 和 \(y_2\)。（这就是量子力学中的“升算符”（raising operator）。）
