集齐一套

题目

STEP II 1994，第 13 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/94-s2-q13

引子

一本足球贴纸簿要集齐 \(600\) 张贴纸，贴纸每次随机发售一张。要贴满整本贴纸簿，你预计要买多少张贴纸？最初几百张很快到手，因为几乎每一张都是新的。但贴纸簿愈贴愈满，新贴纸就愈来愈罕有，单是最后一张，平均就要买 \(600\) 次。总数大约是 \(4200\) 张，是贴纸簿大小的七倍。

这就是集券问题（coupon collector’s problem）。它的答案结合了两个想法：等候一次成功所需的时间，以及调和级数（harmonic series）\(1 + \frac12 + \frac13 + \cdots\)，后者的增长与 \(\ln n\) 相若。你在 第 2.3 节 见过调和级数发散（diverge）；在这里，它那缓慢的增长正正就是集齐一套收藏品所要付出的代价。

动笔之前

如果每包各自独立地以概率 \(p\) 开出一张新卡，那么直至开出第一张新卡为止（连这一包计算在内），你开包数目的期望值（expectation）是多少？

开包数目 \(X\) 服从几何分布（geometric distribution）：\(\mathrm{P}(X = k) = (1 - p)^{k-1}p\)。它的期望值是 \(\frac1p\)。（有一个快捷的看法：\(\mathrm{E}(X) = 1 + (1 - p)\mathrm{E}(X)\)，因为你先开一包，然后有 \(1 - p\) 的概率回到起点。）如果有三分之一的机会开出新卡，你预计要等三包。

逐步解题

阶段 1 等候一张新卡

手上已有 \(r\) 张不同的卡时，一包开出新卡的概率是 \(\frac{n - r}{n}\)，与之前各包独立。因此，直至开出下一张新卡为止，所需包数的期望值是 \[\frac{1}{(n - r)/n} = \frac{n}{n - r}. \qed\]

阶段 2 比较和与积分

在区间 \(r \leq x \leq r + 1\) 上，\(\frac1x\) 介乎哪两个值之间？这对曲线下的面积有甚么启示？

由于 \(\frac1x\) 是递减的，在 \([r, r + 1]\) 上有 \(\frac{1}{r+1} \leq \frac1x \leq \frac1r\)。在长度为 \(1\) 的区间上积分，得 \[\frac{1}{r + 1} \leq \int_r^{r+1}\frac{\mathrm{d}x}{x} \leq \frac1r. \qed\] 用图来看（图 9.11.1）：曲线下的面积夹在高度为 \(\frac{1}{r+1}\) 的长方形与高度为 \(\frac1r\) 的长方形之间。把这些不等式由 \(r = 1\) 加到 \(r = n - 1\)，各个积分便连接成 \(\int_1^n\frac{\mathrm{d}x}{x} = \ln n\)，于是 \[\frac12 + \frac13 + \cdots + \frac1n \leq \ln n \leq 1 + \frac12 + \cdots + \frac{1}{n - 1}. \qed\]

阶段 3 集齐全套

总包数是等候第一张卡、第二张新卡……各段等候时间之和。它的期望值是多少？

设 \(X_r\) 为由 \(r\) 张不同的卡增至 \(r + 1\) 张所需的包数。总数是 \(X_0 + X_1 + \cdots + X_{n-1}\)，而期望值可以相加，所以 \[\mathrm{E}(\text{总数}) = \sum_{r=0}^{n-1}\frac{n}{n - r} = n\Bigl(\frac1n + \frac{1}{n - 1} + \cdots + 1\Bigr) = nH_n,\] 其中 \(H_n = 1 + \frac12 + \cdots + \frac1n\) 是第 \(n\) 个调和数（harmonic number）。由第 2 步，\(\ln n + \frac1n \leq H_n \leq \ln n + 1\)，所以当 \(n\) 很大时 \(H_n\) 约为 \(\ln n\)，而我预计大约要吃掉 \[n\ln n \text{ 包}. \qed\]

回顾

  • 把漫长的等候分成多个阶段。总时间拆成 \(n\) 段等候时间，每一段都属于简单的几何分布。

  • 期望值可以相加。我们从头到尾都不需要总数的分布，只需要各部分的期望值。

  • 比较和与积分。那幅图把一个我们无法求值的和化成一个对数，误差至多为 \(1\)。

背后的数学

这个估计有多准确？

这个比较还可以再精确一些。图 9.11.1 中曲线与上方长方形之间的阴影空隙，总面积是有限的，所以 \(H_n - \ln n\) 趋向一个极限， \[\gamma = \lim_{n \to \infty}(H_n - \ln n) = 0.5772156649\ldots,\] 即欧拉常数。（没有人知道 \(\gamma\) 是否有理数。）因此包数的期望值是 \(n\ln n + \gamma n + \frac12 + \cdots\)。以 \(600\) 张贴纸的贴纸簿为例，\(600 \times (\ln 600 + 0.577) \approx 4185\)，这就是引子中所引述的数字。

时间都花到哪里去了？各个阶段极不平均。集齐全套的前一半只需大约 \(n\ln 2 \approx 0.69n\) 包，而单是最后一张卡，平均就要 \(n\) 包。大部分工夫都花在最后几张卡上，这正是收藏者要互相交换重复卡的原因。

集中现象

期望值只是个开始：总数的变动有多大？总数的方差（variance）是 \(\sum n r/(n - r)^2\)，约为 \(\frac{\pi^2}{6}n^2\)（第 2.4 节 中的和 \(\sum 1/k^2 = \pi^2/6\) 在这里出现了）。所以标准差（standard deviation）约为 \(1.28n\)，当 \(n\) 很大时远小于平均值 \(n\ln n\)：总数集中在其平均值附近。艾狄胥（Paul Erdős）和雷尼（Alfréd Rényi）在 1961 年证明了一个更精确的结果：总数减去 \(n\ln n\) 再除以 \(n\)，会有一个极限分布（limiting distribution），即耿贝尔分布（Gumbel distribution），这个分布也描述了许多随机量之中最大的一个（第 12.25 节）。

无处不在的集券问题

这个问题可追溯至棣莫弗（Abraham de Moivre，1712 年）和拉普拉斯（Laplace）。如今它以许多不同的面貌出现。要检查一个系统的每个组件，需要做多少次随机测试？在一个网络上进行随机漫步（random walk），要多久才会走遍每个节点？电脑的杂凑表（hash table）要探查多少次？每一种情况的答案都涉及 \(n\ln n\)。在生物学中，同样的计算可用来估计要有多少个定序“读段”（reads）才能覆盖整个基因组。

思维技巧

期望值的线性性质（linearity of expectation）

和的期望值等于期望值之和，不论各部分是否独立。把一个复杂的随机量拆成简单的部分。

这是概率论中最有用的事实之一。在这里，它把集券问题简化为 \(n\) 段几何等候；在 第 9.8 节 中，它不用任何计算就给出了配对数目的期望值。到了大学，同一个想法推动着算法分析，以及组合数学中的概率方法（probabilistic method）。

延伸练习

  1. 半套。证明集齐 \(\frac n2\) 张不同的卡（\(n\) 为偶数）所需包数的期望值是 \(n(H_n - H_{n/2})\)，并且这个值约为 \(n\ln 2\)。

  2. 不同的卡。证明开了 \(k\) 包之后，你手上不同的卡的数目的期望值是 \(n\bigl(1 - (1 - \frac1n)^k\bigr)\)。（提示：对每一张卡，求出你拥有它的概率，然后相加。）大约要开多少包，才能得到全套的 \(95\%\)？

  3. 两位收藏者。两个小孩收集同一套卡，并共用所开的各包，因此对其中一人来说是重复的卡，对另一人来说可能是新的。证明集齐两套所需包数的期望值约为 \(n(\ln n + \ln\ln n)\)。（这题较难；先说服自己这个数目远小于 \(2n\ln n\)。）

  4. 更精确的界。改用梯形法则（trapezium rule）的图像而不用长方形，证明 \(H_n - \ln n\) 是递减的，而 \(H_n - \ln n - \frac{1}{2n}\) 是递增的。由较小的 \(n\) 值推导出 \(0.5 < \gamma < 0.7\)。
