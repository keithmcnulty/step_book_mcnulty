9.4

把数列看成函数

工作纸题目连结、提示、大学数学及练习 第 9 章整章的 PDF 版本
题目

STEP I 2016，第 8 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/16-s1-q8

引子

用计算机算一算 \(1/89\)：\(0.011235955\ldots\)。开首的数字是 \(0, 1, 1, 2, 3, 5\)，正是斐波那契数（Fibonacci numbers）。这是巧合吗？不是，而这道题目正好解释了原因。

这个想法是组合数学（combinatorics）中最强大的想法之一。取一个无穷数列，把各项用作幂级数（power series）的系数，从而把整个数列包装成单一个函数。这样，关于数列的事实就变成关于函数的事实，你便可以用代数和微积分来处理。Herbert Wilf 有一句令人难忘的话：“生成函数（generating function）是一条晾衣绳，我们把一列数字挂在上面展示。”

动笔之前

哪个数列的生成函数是 \(\dfrac{1}{1 - x}\)？\(\dfrac{1}{1 - 2x}\) 又如何？如果把一个数列的生成函数乘以 \(x\)，数列会有甚么变化？

等比级数（geometric series）\(\frac{1}{1 - x} = 1 + x + x^2 + \cdots\) 是 \(1, 1, 1, \ldots\) 的生成函数，而 \(\frac{1}{1 - 2x} = 1 + 2x + 4x^2 + \cdots\) 则是 \(2\) 的各次幂的生成函数。乘以 \(x\) 会把每一项向后移一位：\(x \cdot \frac{1}{1-x} = x + x^2 + \cdots\) 对应的数列是 \(0, 1, 1, 1, \ldots\)。

逐步解题

阶段 1 自然数与三角形数

用二项级数（binomial series）展开 \((1 - x)^{-2}\)。\(x^n\) 的系数是甚么？

由二项级数可得 \[(1 - x)^{-2} = 1 + 2x + 3x^2 + 4x^3 + \cdots = \sum_{n \geq 0}(n + 1)x^n,\] 所以 \(x(1 - x)^{-2} = x + 2x^2 + 3x^3 + \cdots = \sum n x^n\)：这就是 \(u_n = n\) 的生成函数。

同样地，\((1 - x)^{-3}\) 中 \(x^n\) 的系数是 \(\frac{(-3)(-4)\cdots(-3-n+1)}{n!}(-1)^n = \frac{(n + 1)(n + 2)}{2}\)，所以 \[x(1 - x)^{-3} = \sum_{n \geq 1}\frac{n(n + 1)}{2}\,x^n = x + 3x^2 + 6x^3 + 10x^4 + \cdots,\] 这就是三角形数（triangle numbers）\(u_n = \frac12 n(n + 1)\) 的生成函数。

怎样用 \(n\) 和 \(\frac12n(n + 1)\) 来表示 \(n^2\)？

由于 \(n^2 = 2 \cdot \frac12 n(n + 1) - n\)，而生成函数可以像数列一样相加， \[\sum n^2 x^n = \frac{2x}{(1 - x)^3} - \frac{x}{(1 - x)^2} = \frac{2x - x(1 - x)}{(1 - x)^3} = \frac{x(1 + x)}{(1 - x)^3}. \qed\]

阶段 2 递推关系变成方程

把 \(u_n = ku_{n-1}\) 乘以 \(x^n\)，然后对所有 \(n \geq 1\) 求和。两边用 \(\mathrm{f}\) 表示，分别是甚么？

左边是 \(\sum_{n \geq 1}u_nx^n = \mathrm{f}(x) - u_0 = \mathrm{f}(x) - a\)。右边是 \(kx\sum_{n \geq 1}u_{n-1}x^{n-1} = kx\,\mathrm{f}(x)\)。所以 \(\mathrm{f}(x) = a + kx\,\mathrm{f}(x)\)，于是 \[\mathrm{f}(x) = \frac{a}{1 - kx}. \qed\] 当然，\(u_n = ak^n\)；把 \(\frac{a}{1 - kx}\) 展开成等比级数，便可确认这一点。

阶段 3 斐波那契数

对 \(u_n = u_{n-1} + u_{n-2}\)（其中 \(n \geq 2\)）作同样的处理： \[\sum_{n \geq 2}u_nx^n = x\sum_{n \geq 2}u_{n-1}x^{n-1} + x^2\sum_{n \geq 2}u_{n-2}x^{n-2},\] 即 \[\mathrm{f}(x) - u_0 - u_1x = x\bigl(\mathrm{f}(x) - u_0\bigr) + x^2\,\mathrm{f}(x).\] 代入 \(u_0 = 0\) 和 \(u_1 = 1\)，上式即 \(\mathrm{f}(x) - x = x\,\mathrm{f}(x) + x^2\,\mathrm{f}(x)\)，所以 \[\mathrm{f}(x) = \frac{x}{1 - x - x^2}. \qed\]

阶段 4 解释 \(1/89\)

暂且不理收敛（convergence）的问题（这里没有问题：级数在 \(|x| < 0.618\) 时收敛），把 \(x = \frac{1}{10}\) 代入 \(\mathrm{f}\)。你得到甚么？

\[\frac{1}{10}F_1 + \frac{1}{100}F_2 + \frac{1}{1000}F_3 + \cdots = \mathrm{f}\Bigl(\frac{1}{10}\Bigr) = \frac{1/10}{1 - 1/10 - 1/100} = \frac{10}{89}.\] 除以 \(10\)，得 \(\frac{1}{89} = \sum F_n/10^{n+1}\)。斐波那契数依次放在相继的小数位上，当它们大于 \(9\) 时便会互相重叠（图 9.4.1）。\(1/89\) 开首的数字显示出斐波那契数；其后的数字则因进位而变得模糊。

回顾

  • 把数列变成函数。整个无穷数列变成了一个有理函数（rational function）。

  • 递推关系变成方程。乘以 \(x^n\) 再求和，便把规则 \(u_n = u_{n-1} + u_{n-2}\) 变成一条关于 \(\mathrm{f}\) 的方程，可以用代数方法解出。

  • 从旧的造出新的。把生成函数相加、平移和求导，便能得出新的生成函数，无须从头做起。

背后的数学

从生成函数到公式

生成函数不只是把数列编码：它还可以把数列解出来。分母可以因式分解为 \(1 - x - x^2 = (1 - \varphi x)(1 - \psi x)\)，其中 \(\varphi = \frac{1 + \sqrt5}{2}\) 和 \(\psi = \frac{1 - \sqrt5}{2}\) 是 \(t^2 = t + 1\) 的根。由部分分式（partial fractions）可得 \[\frac{x}{1 - x - x^2} = \frac{1}{\sqrt5}\Bigl(\frac{1}{1 - \varphi x} - \frac{1}{1 - \psi x}\Bigr),\] 再把每个分式展开成等比级数， \[F_n = \frac{\varphi^n - \psi^n}{\sqrt5}.\] 这就是比内公式（Binet’s formula）。由于 \(|\psi| < 1\)，第二项非常小，所以 \(F_n\) 是最接近 \(\varphi^n/\sqrt5\) 的整数，而相邻两个斐波那契数之比趋向黄金比（golden ratio）（这是 第 2.2 节 的主题）。同一方法可以解任何常系数线性递推关系（linear recurrence with constant coefficients）；练习中有一个来自 STEP I 2004 的例子。

生成函数为何如此有用

真正的威力在相乘时才显现出来。乘积 \(\mathrm{f}(x)\mathrm{g}(x)\) 中 \(x^n\) 的系数是 \(\sum_k u_kv_{n-k}\)，即对所有把 \(n\) 拆成两部分的方法求和。要数算由两个部分组成的东西，这正是我们所需要的。接下来的两节会用它来数算找换零钱的方法（第 9.5 节），以及找出点数古怪、但总和的分布与普通骰子相同的骰子（第 9.6 节）。在概率中，同一想法给出概率生成函数（probability generating function），它把独立随机变量之和变成乘积。

棣莫弗、欧拉与拉普拉斯

棣莫弗（Abraham de Moivre）在 1720 年代用生成函数来解线性递推关系，所用的方法基本上就是上面的方法。欧拉（Leonhard Euler）在 1748 年用它们来研究整数的分拆（partitions），而拉普拉斯（Pierre-Simon Laplace）则以它们作为其著作 Théorie analytique des probabilités（1812）的基础。到了二十世纪，生成函数成为组合数学的核心，而解析方法（把生成函数看成复变量的函数来研究）如今能为复杂得无法精确求解的计数问题给出精确的估计。

思维技巧

转换表示方式

一个关于数列的问题，在把数列变成函数、矩阵或图形之后，可能会变得容易。

生成函数把递推关系翻译成代数，把计数翻译成乘法。在大学里你会遇到许多这类翻译：傅里叶级数（Fourier series）把函数变成数列，拉普拉斯变换（Laplace transforms）把微分方程变成代数，而矩阵则把几何变成算术。

延伸练习

  1. 每次两位数字。试做 STEP II 2022，第 3 题 （载于 OCR 提供下载的 2022 年试卷 zip 文件内）。它解释了为何 \(\frac{1}{89}\) 的小数展开式以斐波那契数开首，并要求找出一个分数，其小数每次两位数字地显示这个规律。

  2. 解递推关系。试做 STEP I 2004，第 7 题。它用生成函数和部分分式解一个线性递推关系，然后把这个方法倒过来做。

  3. 逐一数数。证明 \(\frac{1}{9801} = 0.00\,01\,02\,03\,04\ldots\)，其中每两位数字为一组，逐一向上数。这个规律最先在哪里出错？为甚么？

  4. 平方和。解释为何 \(\frac{1}{1-x}\mathrm{f}(x)\) 是部分和 \(u_0 + u_1 + \cdots + u_n\) 的生成函数。利用这一点和第 (i) 部分的答案，求 \(1^2 + 2^2 + \cdots + n^2\) 的公式。
