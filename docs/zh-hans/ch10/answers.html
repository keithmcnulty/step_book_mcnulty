第 10 章 · 守恒定律、碰撞与引力

延伸练习答案

以下只是简短的答案和提示，并非完整解答：只列出结果和关键步骤，方便你核对自己的做法。每道练习请先认真做过，然后才看答案。

10.1 牛顿摆

  1. 所有碰撞（collision）结束后，运动中的质点后面不可能跟着一个较慢的质点。因此，若恰好只有一个质点在动，它必定是 \(A_n\)，而 \(\lambda mv = mu\)、\(\lambda mv^2 = mu^2\) 在 \(\lambda \neq 1\) 时互相矛盾。若只有 \(A_{n-1}\) 和 \(A_n\) 在动，则方程与质量为 \(m\) 和 \(\lambda m\) 的两个质点相碰时的方程相同，得出 \(A_{n-1}\) 的速度为 \(\frac{1 - \lambda}{1 + \lambda}u < 0\)；但这样它便会撞上 \(A_{n-2}\)。有三个质点在动的情况，可完全仿照第 (ii) 部分排除。在动的两个质点是 \(A_0\)（以 \(\frac{\lambda - 1}{\lambda + 1}u\) 向后运动）和 \(A_n\)（以 \(\frac{2u}{\lambda + 1}\) 向前运动）。

  2. 质量相等的弹珠相碰时会交换速度，所以速率 \(u\) 一直传到 \(A_n\)。之后 \(A_n\) 撞上 \(A_{n+1}\)：\(A_{n+1}\) 以 \(\frac{2u}{1 + \lambda}\) 离开，而 \(A_n\) 则以 \(\frac{\lambda - 1}{\lambda + 1}u\) 反弹。这个向后的速度沿着整列弹珠传回 \(A_0\)，使它以该速率向后离开。

  3. “两球以 \(u\) 弹出”所带的动量（momentum）是 \(2mu\)，能量是 \(mu^2\)，与碰撞前相同。另一个解（之后不再有碰撞）是：最后三个球分别以 \(\frac u3\)、\(\frac u3\) 和 \(\frac{4u}{3}\) 离开（验算：总和为 \(2u\)，平方和为 \(2u^2\)）。真实的牛顿摆选择第一个解，是因为各球之间并非完全贴紧，所以碰撞是一对一对地先后发生的。

  4. 速率一直传到 \(A_n\)，它再撞上较轻的 \(A_{n+1}\)：\(A_{n+1}\) 以 \(\frac{2u}{1 + \lambda}\) 离开，而 \(A_n\) 则以较慢的 \(\frac{1 - \lambda}{1 + \lambda}u\) 跟在后面。其余质点全都不动。

10.2 叠球效应

  1. 球以 \(U = \sqrt{2gH}\) 到达地面，再以 \(eU\) 反弹，上升 \(e^2H\)。把小球放在上面时：大球以 \(eU\) 向上运动，遇上以 \(U\) 向下运动的小球。由动量守恒和恢复系数（restitution）的关系，可得小球向上的速率为 \(w = U\frac{Me(2 + e) - m}{M + m}\)。小球球心由 \(2R + r = 0.45\) 出发，升至 \(4.5\)，所以 \(\frac{w^2}{2g} = 4.05\)，而 \(\frac wU = \sqrt{\frac{4.05}{1.8}} = 1.5\)。代入 \(e = \frac23\)，得 \(\frac{16}{9}M - m = 1.5(M + m)\)，于是 \(M = 9m\)。

  2. 由动量守恒和恢复系数的关系，\(P_1\) 的速率为 \(\frac{1 + e}{1 + \lambda}u\)；每次碰撞的质量比都相同，情况重复出现，所以 \(P_n\) 以 \(\bigl(\frac{1 + e}{1 + \lambda}\bigr)^nu\) 运动。速率为 \(s\) 的质点撞上下一个质点后，余下的速率为 \(\frac{1 - \lambda e}{1 + \lambda}s\)，而下一个质点经过自己的下一次碰撞后，速率减至 \(\frac{(1 + e)(1 - \lambda e)}{(1 + \lambda)^2}s\)。当 \(\lambda e < 1\) 时，前者只有在 \(\frac{1 - \lambda e}{1 + \lambda} > \frac{(1 + e)(1 - \lambda e)}{(1 + \lambda)^2}\) 时才会再次追上后者，即 \(\lambda > e\)；所以若 \(e > \lambda\)，每个质点只会被撞一次，也只会撞别的质点一次。若 \(\lambda e = 1\)，每个质点撞上下一个之后便立即停下。

  3. 最底的球以 \(U\) 反弹，遇上中间的球（正以 \(U\) 向下运动）：相对速率为 \(2U\)，所以中间的球以 \(3U\) 离开。最上面的球与它相遇时相对速率为 \(4U\)，于是以 \(7U\) 离开，上升 \(49H\)。一般而言 \(u_{j+1} = 2u_j + U\)，所以 \(u_j + U = 2^jU\)。

  4. 弹性碰撞（elastic collision）中动能（kinetic energy）守恒。\(A\) 的能量是 \(\frac12m\bigl(\frac{2\lambda}{1 + \lambda}\bigr)^{2n}u^2\)，而最初的能量是 \(\frac12\lambda^nmu^2\)，又因 \(\frac{4\lambda}{(1 + \lambda)^2} < 1\)，所以 \(A\) 得到的能量永远不会多于原有的总能量。较重的质点继续向前运动，各自保留原来速率的 \(\frac{\lambda - 1}{\lambda + 1}\) 倍，余下的能量便留在它们身上。

10.3 火箭与枪炮

  1. 一次过全部发射：\(Mu = nm(v - u)\)，所以 \(u = \frac{nmv}{M + nm}\)。逐个发射：第 \(r\) 次发射给出 \(\bigl(M + (n - r + 1)m\bigr)(u_r - u_{r-1}) = mv\)，所以 \(u_n = \sum_{j=1}^n\frac{mv}{M + jm}\)，而除最后一项外，每一项都大于 \(\frac{mv}{M + nm}\)。因此 \(u_n > u\)。

  2. 动量：\(M(1 + bx)v = MV\)。于是 \((1 + bx)\frac{\mathrm{d}x}{\mathrm{d}t} = V\)，所以 \(x + \frac12bx^2 = Vt\)，而 \(x = \frac{\sqrt{1 + 2bVt} - 1}{b}\)。有外力时，\(\frac{\mathrm{d}}{\mathrm{d}t}\bigl(M(1 + bx)v\bigr) = Mf\) 给出 \((1 + bx)v = ft + V\)。若速率为常数 \(c\)，则须有 \(x = ct\) 及 \((1 + bct)c = ft + V\)，所以 \(c = V\) 且 \(bV^2 = f\)。否则 \(x + \frac12bx^2 = \frac12ft^2 + Vt\)，所以 \(x \sim t\sqrt{f/b}\)，而 \(v \to \sqrt{f/b}\)。

  3. 单级：\(v\ln10 \approx 2.30v\)。两级：\(v\ln\frac{10}{5.5} + v\ln\frac{5}{0.5} \approx 0.60v + 2.30v = 2.90v\)。

  4. 当 \(0 \leq s \leq x\) 时，\(\frac{1}{1 + x} \leq \frac{1}{1 + s} \leq 1\)；在 \([0, x]\) 上积分即可。

10.4 一个分子与一个活塞

  1. 这个递推关系（recurrence）逐项相消后得 \(d_n = \frac{(v + u)d_1}{v + (2n - 1)u}\)，所以 \(v_nd_n = \frac{(v + 2nu)(v + u)d_1}{v + (2n - 1)u}\)，它比 \((v + u)d_1\) 大 \(\frac{u(v + u)d_1}{v + (2n - 1)u} \to 0\)。

  2. 把 \(u\) 换成 \(-u\)：每次从后退中的活塞反弹，速率都减少 \(2u\)，所以 \(v_n = v - 2nu\)（只要质点仍能追上活塞），\(d_n = \frac{(v - u)d_1}{v - (2n - 1)u}\)，而 \(v_nd_n = \frac{(v - 2nu)(v - u)d_1}{v - (2n - 1)u}\)，同样接近 \((v - u)d_1\)。

  3. 当 \(v = u\) 时，\(v_n = (2n + 1)u\)。第 \(n\) 次碰撞时动量的改变量为 \(m(v_{n-1} + v_n) = 4nmu\)，而 \(t_n = \frac{d_1}{un(n + 1)}\)，所以平均力为 \(\frac{4mu^2n^2(n + 1)}{d_1}\)，量级为 \(n^3\)。每个循环所作的功约为力 \(\times\ ut_n\)，大约是 \(4nmu^2\)，这些功加起来是无穷大：要把活塞完全推到底，需要无穷多的功，正如分子的能量 \(\frac12m(2n + 1)^2u^2\) 会无止境地增长一样。

  4. 不变量（invariant）是 \(\oint p\,\mathrm{d}q = 2\int_0^h m\sqrt{2g(h - z)}\,\mathrm{d}z \propto h^{3/2}\)，其中 \(h\) 是弹跳离地板的高度。所以当地板缓慢上升时，\(h^{3/2}\)（等价地说，即 \(v^3\)，或能量乘以周期）几乎保持不变。

10.5 有限时间内的无限次反弹

  1. 由正弦定理（sine rule），\(M_1N_1 = \frac{OM_1\sin30^\circ}{\sin\theta}\)，而相继各段路程按比率 \(\rho = \frac{\sin(\theta - 30^\circ)}{\sin\theta} < 1\) 缩短。总和为 \(\frac{M_1N_1}{1 - \rho} = \frac{OM_1}{2\bigl(\sin\theta - \sin(\theta - 30^\circ)\bigr)} = \frac{OM_1}{4\sin15^\circ\cos(\theta - 15^\circ)}\)。

  2. 由三角形 \(OM_1N_1\) 的各角可得 \(\varphi = \theta - \alpha\)。时间之比为 \(\frac{\rho}{k} = \frac{\sin(\theta - \alpha)\cos(\theta - \alpha)}{\sin\theta\cos\theta} = \frac{\sin(2\theta - 2\alpha)}{\sin2\theta}\)，它小于 \(1\) 当且仅当 \(\alpha < \theta < 45^\circ + \frac12\alpha\)。

  3. 把楔形沿它的壁反射，可将路径展开成一条直线。围绕 \(O\) 刚好可放十二个楔形，而一条不通过 \(O\) 的直线最多穿过其中六个。所以质点只会反弹有限次，然后逃离，除非它正对着 \(O\) 射去。

  4. 它首先下落 \(t_0 = \sqrt{2/9.8} \approx 0.452\) s。每次弹跳历时 \(2e^kt_0\)，所以总时间为 \(t_0\bigl(1 + \frac{2e}{1 - e}\bigr) = 9t_0 \approx 4.07\) s。总路程为 \(1 + 2\sum_{k \geq 1}e^{2k} = 1 + \frac{2(0.64)}{0.36} \approx 4.56\) m。

10.6 二体化为一体

  1. 绳子保持拉紧，相对速度与绳子垂直，大小恒为 \(u\)，所以 \(\theta = \frac{ut}{r}\)。由动量可得 \(my + MY = mut\)。利用 \(A = G - \frac{M}{m + M}\overrightarrow{AB}\) 和 \(\overrightarrow{AB} = r(\cos\theta, -\sin\theta)\)，得 \(y = \frac{1}{m + M}\bigl(mut + Mr\sin\frac{ut}{r}\bigr)\)。于是 \(\dot y = \frac{u}{m + M}\bigl(m + M\cos\frac{ut}{r}\bigr)\)，它在 \(\cos\frac{ut}{r} < -\frac mM\) 时为负，而这在 \(M > m\) 时才有可能。

  2. 现在 \(\ddot z = -\frac{3}{z^3}\)，所以 \(\dot z^2 = \frac{3}{z^2} - 2\)（利用 \(z = 1\)、\(\dot z = -1\)）。设 \(w = z^2\)，则 \(\ddot w = 2\dot z^2 + 2z\ddot z = -4\)，所以 \(z^2 = 1 - 2t - 2t^2\)。两者在 \(t = \frac{\sqrt3 - 1}{2} \approx 0.366\) 时相撞。

  3. \(z^2 = 4t^2 - 2t + 1 = |\mathbf{p} + \mathbf{q}t|^2\)，其中 \(\mathbf{p} = (1, 0)\)，\(\mathbf{q} = (-1, \sqrt3)\)：这是通过 \((1, 0)\)、方向为 \((-1, \sqrt3)\) 的直线，而 \(\theta = \tan^{-1}\frac{\sqrt3t}{1 - t}\)。于是 \(z^2\dot\theta = |\mathbf{p} \times \mathbf{q}| = \sqrt3\)。这个斥力正好就是平面上自由运动的“离心”项 \(\frac{h^2}{z^3}\)，其角动量（angular momentum）为 \(h = \sqrt3\)。

  4. 两颗星与质心（centre of mass）的距离分别为 \(\frac{m_2a}{m_1 + m_2}\) 和 \(\frac{m_1a}{m_1 + m_2}\)。对第一颗星，\(\frac{Gm_1m_2}{a^2} = m_1\omega^2\frac{m_2a}{m_1 + m_2}\)，所以 \(\omega^2 = \frac{G(m_1 + m_2)}{a^3}\)，而 \(T = \frac{2\pi}{\omega}\)。

10.7 球壳内的引力

  1. 在球壳外（\(b > a\)），与第 3 阶段相同的积分改为对 \(s\) 由 \(b - a\) 积至 \(b + a\)，结果是 \(\frac{GM}{b^2}\)。实心球是多个同心球壳的并集，每个球壳的作用都如同其质量集中于球心。

  2. 设 \(r = R\cos^2\alpha\)，则 \(\frac1r - \frac1R = \frac{\tan^2\alpha}{R}\)，所以速率为 \(\sqrt{2GM/R}\tan\alpha\)。于是 \(\mathrm{d}t = \frac{2R\sin\alpha\cos\alpha\,\mathrm{d}\alpha}{\sqrt{2GM/R}\tan\alpha} = \sqrt{\frac{R^3}{2GM}}\,2\cos^2\alpha\,\mathrm{d}\alpha\)；再积分即可。

  3. 根据球壳定理（shell theorem），只有半径 \(b\) 以内的质量（即 \(M\frac{b^3}{a^3}\)）产生引力，结果是 \(\frac{GMb}{a^3}\)。这是简谐运动（simple harmonic motion），其中 \(\omega^2 = \frac{GM}{a^3}\)，周期为 \(2\pi\sqrt{a^3/GM} \approx 84\) 分钟，这里取 \(a = 6.37 \times 10^6\) m 及 \(GM = 3.99 \times 10^{14}\) m\(^3\) s\(^{-2}\)。在半径 \(a\) 处运行的卫星满足 \(\omega^2a = \frac{GM}{a^2}\)：\(\omega\) 相同。

  4. 不会。换成 \(\frac{1}{s^3}\) 后，被积函数不再化简为常数，球壳较近的一侧占了上风：质点会被拉向球壳最近的部分。只有平方反比定律（inverse-square law）才会完全抵消（球壳上一小块的面积按 \(s^2\) 增长，刚好抵消引力的减弱）。

10.8 排成三角形的三颗恒星

  1. 每颗星与中心的距离为 \(\frac{a}{\sqrt2}\)。相邻两颗星的引力指向中心的分量合共为 \(\frac{2\gamma m^2}{a^2}\cos45^\circ = \frac{\sqrt2\gamma m^2}{a^2}\)，而对面那颗星的引力为 \(\frac{\gamma m^2}{2a^2}\)。令 \(\frac{\gamma m^2}{a^2}\bigl(\sqrt2 + \frac12\bigr) = m\omega^2\frac{a}{\sqrt2}\)，得 \(\omega^2 = \frac{(4 + \sqrt2)\gamma m}{2a^3}\)。

  2. 在中心处各引力互相抵消，所以行星处于平衡（equilibrium）。沿着两颗星的连线方向，平衡是不稳定的：向其中一颗星移动距离 \(x\)，便会受到约为 \(\frac{32\gamma Mx}{a^3}\) 的向外净力。在垂直于轨道平面的方向，平衡是稳定的，回复力约为 \(\frac{16\gamma Mz}{a^3}\)。（在轨道平面内垂直于连线的方向，引力有回复作用，但旋转会把这个方向的运动与不稳定的方向耦合起来。）

  3. 作用于 \(m_1\) 的力为 \(\frac{\gamma m_1}{a^3}\bigl(m_2(P_2 - P_1) + m_3(P_3 - P_1)\bigr)\)。由于 \(m_1P_1 + m_2P_2 + m_3P_3 = (m_1 + m_2 + m_3)G\)，这个力等于 \(\frac{\gamma m_1(m_1 + m_2 + m_3)}{a^3}(G - P_1)\)。每颗星都被拉向 \(G\)，引力与它跟 \(G\) 的距离成正比，而且比例常数相同，所以三颗星可以像刚体一样一起旋转，其中 \(\omega^2 = \frac{\gamma(m_1 + m_2 + m_3)}{a^3}\)。

  4. 相隔 \(k\) 个位置的那颗星，距离为 \(2R\sin\frac{k\pi}{n}\)，其引力指向中心的分量占 \(\sin\frac{k\pi}{n}\)。所以 \(m\omega^2R = \frac{\gamma m^2}{4R^2}\sum_{k=1}^{n-1}\frac{1}{\sin(k\pi/n)}\)，得 \(\omega^2 = \frac{\gamma m}{4R^3}\sum_{k=1}^{n-1}\frac{1}{\sin(k\pi/n)}\)。当 \(n = 3\)、\(R = \frac{a}{\sqrt3}\) 时，结果是 \(\frac{3\gamma m}{a^3}\)。
