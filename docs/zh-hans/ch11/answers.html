第 11 章 · 振动、转动与运动参考系

延伸练习答案

以下只是简短的答案和提示，并非完整解答：只列出结果和关键步骤，让你核对自己的做法。请先认真做完每道练习，然后才翻看。

11.1 共振

  1. 在升降机的参考系（frame）中，重力实际上相当于 \(g - f\)，而弦线的劲度（stiffness）是 \(\frac{mg}{a}\)（在 \(mg\) 的作用下它伸长 \(a\)）。因此 \(\ddot y + \frac gay = g - f\)，开始时 \(y = a\)、\(\dot y = 0\)。新的平衡位置（equilibrium）是 \(a - \frac{af}{g}\)，所以 \(y = a - \frac{af}{g}(1 - \cos\omega t)\)：振幅（amplitude）为 \(\frac{af}{g}\)，而最小伸长量 \(a(1 - \frac{2f}{g})\) 是正数。升降机停止加速时，平衡位置回到 \(a\)，此时质点的位移是 \(-\frac{af}{g}(1 - \cos\omega T)\)，速度是 \(-\frac{af}{g}\omega\sin\omega T\)。新的振幅是 \(\frac{af}{g}\sqrt{(1 - \cos\omega T)^2 + \sin^2\omega T} = \frac{2af}{g}\bigl|\sin\frac12\omega T\bigr|\)。

  2. 由 \(x = Ct\cos nt\) 得 \(\ddot x + n^2x = -2Cn\sin nt\)，所以 \(C = -\frac{nb}{2}\)。再加上 \(\frac b2\sin nt\) 以符合初始条件：\(x = \frac b2(\sin nt - nt\cos nt)\)。对题目中的公式就 \(p\) 使用洛必达法则（L’Hôpital’s rule），当 \(p \to n\) 时会得到相同的结果。

  3. \(n\sin pt - p\sin nt = n(\sin pt - \sin nt) + (n - p)\sin nt = 2n\cos\frac{(n + p)t}{2}\sin\frac{(p - n)t}{2} + (n - p)\sin nt\)。第二项很小。第一项是一个快速振荡，被包在缓慢变化的包络（envelope）\(\bigl|\sin\frac{(n - p)t}{2}\bigr|\) 之内，而这个包络每隔 \(\frac{2\pi}{n - p}\) 重复一次。

  4. 振幅是 \(\frac{F}{\sqrt{(n^2 - p^2)^2 + 4k^2p^2}}\)。把分母对 \(p^2\) 求极小：\(-2(n^2 - p^2) + 4k^2 = 0\)，所以 \(p^2 = n^2 - 2k^2\)。

11.2 简正模式

  1. 求导后，能量的变化率是 \(\dot x\bigl(m\ddot x + \frac\lambda a(2x + y)\bigr) + \dot y\bigl(m\ddot y + \frac\lambda a(x + 2y)\bigr) = 0\)。设 \(u = x - y\) 及 \(v = x + y\)，能量便是 \(\bigl(\frac m4\dot u^2 + \frac{\lambda}{4a}u^2\bigr) + \bigl(\frac m4\dot v^2 + \frac{3\lambda}{4a}v^2\bigr)\)，每个括号都是一个简谐振子（simple harmonic oscillator）的能量，所以各自都是常数。

  2. 周期 \(\frac{2\pi}{\omega}\)：以 \(x = -y\) 及 \(\dot x = -\dot y\) 开始（使得 \(v \equiv 0\)）。周期 \(\frac{2\pi}{\sqrt3\omega}\)：以 \(x = y\) 及 \(\dot x = \dot y\) 开始。

  3. 作用于 \(X\) 的力是 \(-\frac\lambda ax - \frac\mu a(x + y)\)。模式（mode）\(x - y\) 仍然有 \(\omega^2 = \frac{\lambda}{ma}\)，而 \(x + y\) 现在则是 \(\frac{\lambda + 2\mu}{ma}\)。当且仅当频率之比 \(\sqrt{1 + 2\mu/\lambda}\) 是有理数时，所有运动都是周期性的。

  4. 矩阵是 \(\frac km\begin{pmatrix} 2 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 2 \end{pmatrix}\)，特征向量（eigenvector）为 \((1, \sqrt2, 1)\)、\((1, 0, -1)\) 和 \((1, -\sqrt2, 1)\)，分别对应 \(2 - \sqrt2\)、\(2\) 和 \(2 + \sqrt2\)。三个模式是：三者一同摆动，中间的摆幅最大；外侧两个反向摆动，中间的静止不动；以及中间的与外侧两个反向摆动。

11.3 真实的摆

  1. 能量：\(\frac12m\dot x^2 + \frac{\lambda}{2a}\bigl(\sqrt{x^2 + a^2} - a\bigr)^2 = \frac12mv^2\)。位移最大时 \(\sqrt{x^2 + a^2} = a + \frac vk\)，所以 \(x_{\max} = \sqrt{\frac{2av}{k} + \frac{v^2}{k^2}}\)。当 \(v\) 很小时，伸长量约为 \(\frac{x^2}{2a}\)，所以 \(\dot x^2 \approx v^2 - \frac{k^2x^4}{4a^2}\)。设 \(x = Xu\) 及 \(X = \sqrt{2av/k}\)，周期 \(4\int_0^X\frac{\mathrm{d}x}{\dot x}\) 便化为 \(\frac{4X}{v}\int_0^1\frac{\mathrm{d}u}{\sqrt{1 - u^4}}\)。回复力（restoring force）与 \(x^3\) 成正比，而不是与 \(x\) 成正比（在 \(x = 0\) 时弦线刚好处于自然长度），所以不存在简谐极限。

  2. \((1 - m\sin^2\phi)^{-1/2} \approx 1 + \frac m2\sin^2\phi + \frac{3m^2}{8}\sin^4\phi\)，其中 \(m = \sin^2\frac\gamma2 \approx \frac{\gamma^2}{4} - \frac{\gamma^4}{48}\)。对 \(\phi\) 取平均得 \(1 + \frac m4 + \frac{9m^2}{64}\)，而 \(\gamma^4\) 项是 \(-\frac{1}{192} + \frac{9}{1024} = \frac{11}{3072}\)。

  3. 由 \(1\) 和 \(\cos45^\circ = 0.70711\) 开始：\((0.85355, 0.84090)\)，然后 \((0.84722, 0.84720)\)，然后 \(0.847213\)。周期因子是 \(\frac{1}{0.847213} = 1.18034\)。

  4. 周期因子的变化是 \(\frac{1}{16}(\gamma_5^2 - \gamma_4^2) \approx 1.71 \times 10^{-4}\)（以弧度计），所以时钟每天大约慢 \(15\) 秒。

11.4 等时曲线

  1. 由于 \(y = \frac{s^2}{4k}\)，\(\ddot s = -g\frac{\mathrm{d}y}{\mathrm{d}s} = -\frac{g}{2k}s\)：这是 \(\omega^2 = \frac{g}{2k}\) 的简谐运动（simple harmonic motion）。由 \(s_0 = 2\sqrt{kh}\) 出发，在 \(V\) 处的速率是 \(\omega s_0 = \sqrt{2gh}\)。

  2. 这个碗相当于一个长度为 \(R\) 的摆。从很小的高度出发，到达底部所需的时间是 \(\frac\pi2\sqrt{R/g}\)。从碗边（\(\gamma = 90^\circ\)）出发，所需时间是这个值的 \(1.180\) 倍，约为 \(1.85\sqrt{R/g}\)。

  3. 会。两者都在四分之一周期后到达 \(V\)，并在该处碰撞。无论它们碰撞后以甚么速度离开，各自都以 \(s\) 作简谐运动，而且周期相同，所以各自恰好在半个周期后回到 \(V\)，并再次在 \(V\) 碰撞。（碰撞后静止于 \(V\) 的质点则会一直留在该处。）

  4. 设 \(x = R(\theta - \sin\theta)\) 及 \(y = R(1 - \cos\theta)\)，则 \(\mathrm{d}s = 2R\sin\frac\theta2\,\mathrm{d}\theta\)，所以一拱的长度是 \(\int_0^{2\pi}2R\sin\frac\theta2\,\mathrm{d}\theta = 8R\)。面积是 \(\int y\,\mathrm{d}x = R^2\int_0^{2\pi}(1 - \cos\theta)^2\,\mathrm{d}\theta = 3\pi R^2\)。

11.5 加速火车中的重力

  1. 在车厢的参考系中，每单位质量受到一个向后（向南）的力 \(a\)，方向与发射方向相同。飞行时间为 \(\frac{2V\sin\theta}{g}\)，所以射程是 \(\frac{V^2}{g}\bigl(\sin2\theta + \frac ag(1 - \cos2\theta)\bigr)\)。当 \(\tan2\theta = -\frac ga\) 时它的导数为零，所以 \(2\theta \approx \frac\pi2 + \frac ag\)。极大值是 \(\frac{V^2}{g}\bigl(\sqrt{1 + a^2/g^2} + \frac ag\bigr) \approx \frac{V^2}{g} + \frac{V^2a}{g^2}\)。

  2. \(x = ut\cos\theta - \frac12ft^2\)，在 \(t = \frac{2u\sin\theta}{g}\) 时着地，着地点为 \(x = \frac{2u^2\sin\theta}{g^2}(g\cos\theta - f\sin\theta)\)。若 \(\tan\theta > \frac{g}{2f}\)，水平速度 \(u\cos\theta - ft\) 会在着地前变为负数，所以 \(\alpha = \tan^{-1}\frac{g}{2f}\)。当 \(f = g\) 及 \(\theta = 45^\circ\) 时，加速度刚好与初速度方向相反：抛体（projectile）沿直线 \(y = x\) 笔直向上，停下，然后沿原路直接返回 \(O\)。

  3. 有效重力（effective gravity）是向下的 \(g\) 加上向后的 \(a\)。自由液面与它垂直，所以倾斜的角度是 \(\tan^{-1}\frac ag\)。

  4. 有效重力的大小是 \(\sqrt{g^2 + a^2}\)，在 \(x = \frac{ak}{2g}\) 处斜率是 \(\frac ag\)，曲率半径（radius of curvature）是 \(\rho = \frac{k}{2}\bigl(1 + \frac{a^2}{g^2}\bigr)^{3/2}\)。周期是 \(2\pi\sqrt{\rho/\sqrt{g^2 + a^2}} = 2\pi\sqrt{\frac{k(g^2 + a^2)}{2g^3}}\)，当 \(a = 0\) 时简化为 \(2\pi\sqrt{\frac{k}{2g}}\)。

11.6 后旋

  1. 摩擦力作用于接触点，所以对该点的角动量（angular momentum）守恒：\(maV + \frac25ma^2\frac Va = mav_0 + \frac25ma^2\omega_0\)。因此 \(V = \frac{5v_0 + 2a\omega_0}{7}\)，当 \(\frac{v_0}{a\omega_0} < 1\) 时它大于 \(v_0\)。

  2. \(V = \frac57v_0\)。最终能量是 \(\frac12m\bigl(\frac57v_0\bigr)^2\bigl(1 + \frac25\bigr) = \frac57 \cdot \frac12mv_0^2\)，所以损失了 \(\frac27\) 的能量。

  3. 以 \(I = ma^2\) 重复同一论证，得 \(V = \frac12(v_0 - a\omega_0)\)。令 \(V = -\frac{v_0}{7}\)，得 \(\frac{v_0}{a\omega_0} = \frac79\)。

  4. 在球心上方高度 \(h\) 处施加冲量（impulse）\(J\)，得 \(mv = J\) 及 \(\frac25ma^2\omega = Jh\)。滚动需要 \(v = a\omega\)，所以 \(h = \frac25a\)。

11.7 杆中的辛普森法则

  1. \(\frac16\bigl(1 + 4 \cdot \frac45 + \frac12\bigr) = \frac{47}{60} \approx 0.7833\)，而 \(\frac\pi4 \approx 0.7854\)。对于 \(\int_{-1}^1\)，法则 \(\frac13\bigl(\mathrm{f}(-1) + 4\mathrm{f}(0) + \mathrm{f}(1)\bigr)\) 对 \(x^3\) 给出 \(0\)，对 \(x^2\) 给出 \(\frac23\)（两者都是准确值），但对 \(x^4\) 给出 \(\frac23\)，而它的积分其实是 \(\frac25\)。

  2. 对于与基准方向成角 \(\psi\) 的轴，转动惯量（moment of inertia）是一个二次型（quadratic form）\(A\cos^2\psi + B\sin^2\psi + 2C\sin\psi\cos\psi\)。在 \(\psi \mapsto \psi + 90^\circ\) 之下不变，迫使 \(A = B\) 及 \(C = 0\)，所以对每一条轴都相同：\(\frac13Ma^2\)，即对平行于一边的轴的值。

  3. 在每边中点各放置 \(\frac13\) 的面积，便能准确地在三角形上积分任何二次式（可在直角三角形上验证 \(1\)、\(x\)、\(x^2\)、\(xy\)）。所以这三个质点与该薄片（lamina）有相同的质量、质心（centre of mass）和二阶矩（second moments）。

  4. 在每个方向上，取杆在 \(-a\)、\(0\)、\(a\) 处的权重 \(\frac16\)、\(\frac23\)、\(\frac16\) 的乘积：顶点处为 \(\frac{M}{216}\)，棱的中点处为 \(\frac{M}{54}\)，面心处为 \(\frac{2M}{27}\)，中心处为 \(\frac{8M}{27}\)。对通过中心且平行于一条棱的轴，\(I = M\bigl(\frac{a^2}{3} + \frac{a^2}{3}\bigr) = \frac23Ma^2\)。根据平行轴定理（parallel axis theorem），对一条棱的转动惯量是 \(\frac23Ma^2 + M(\sqrt2a)^2 = \frac83Ma^2\)。

11.8 倾斜的平衡

  1. 由公共面起向圆锥方向量度，\(G\) 位于 \(\frac{-\frac23 \cdot \frac{3a}{8} + \frac\lambda3 \cdot \frac{\lambda a}{4}}{\frac23 + \frac\lambda3} = \frac{a(\lambda^2 - 3)}{4(2 + \lambda)}\)。在半球上，接触点处的法线必定通过该面的中心，所以当 \(G\) 低于该中心，即 \(\lambda < \sqrt3\) 时，玩具会自行回正。侧卧时，玩具沿圆锥的一条母线（generator）及在边缘处与桌面接触；若通过 \(G\) 的铅垂线落在顶点与边缘之间，它便会停留在那里。这需要 \(G\) 的高度至少为 \(-\frac a\lambda\)，化简后即 \(\lambda^3 + \lambda + 8 > 0\)：恒成立。

  2. 均匀球体上的每一点都是平衡位置（随遇平衡）。若质心稍微偏离球心，便只有两个：\(G\) 在最低处（稳定）和 \(G\) 在最高处（不稳定）。

  3. 平衡出现在法线通过中心之处：即两轴的四个端点。靠在短轴的一端是稳定的（\(G\) 尽可能低）；靠在长轴的一端则不稳定。

  4. 由对称性，\(G\) 在原点。当 \(n = 2\) 时，\(Y = r\bigl(\frac12 - p^2\bigr)\)，而倾斜平衡需要法线通过 \(G\)，所以 \(Y = 0\) 及 \(p = \frac{1}{\sqrt2}\)。该处的斜率是 \(-\sqrt2\)，所以 \(\overrightarrow{AB}\) 倾斜的角度是 \(\tan^{-1}\sqrt2 \approx 54.7^\circ\)，若靠在另一个抛物面上则是 \(125.3^\circ\)。两者互为关于 \(x\) 轴的反射，这就是倾斜角成对出现的原因。

11.9 安全抛物线

  1. 每个质点位于 \(ut\,\hat{\mathbf{n}} - \frac12gt^2\mathbf{j}\)，即在以 \(-\frac12gt^2\mathbf{j}\) 为球心、半径为 \(ut\) 的球面上。从 \((0, \frac{u^2}{2g})\) 水平射出的质点沿 \(y = \frac{u^2}{2g} - \frac{gx^2}{2u^2}\) 运动：这正是安全抛物线（parabola of safety）。以角 \(\alpha\) 射出的质点在时间 \(\frac{u}{g\sin\alpha}\) 于 \(x = \frac{u^2}{g\tan\alpha}\) 处与它相切；水平射出的质点需时 \(\frac{x}{u}\) 到达该处，所以它必须在时间 \(\frac{u(1 - \cos\alpha)}{g\sin\alpha} = \frac ug\tan\frac\alpha2\) 发射（这需要 \(\alpha \geq 45^\circ\)，使切点在地面之上）。

  2. 该直线与安全抛物线相交于 \(R\sin\beta = \frac{u^2}{2g} - \frac{gR^2\cos^2\beta}{2u^2}\) 之处，得 \(R = \frac{u^2}{g(1 + \sin\beta)}\)。在极大值处，练习 3 的两个角重合，所以最佳角度是角平分线的方向，即 \(45^\circ + \frac12\beta\)。

  3. 设 \(\lambda = \tan\theta\)，两个值满足 \(\lambda_1 + \lambda_2 = \frac{2u^2}{gx}\) 及 \(\lambda_1\lambda_2 = 1 + \frac{2u^2y}{gx^2}\)。所以 \(\tan(\theta_1 + \theta_2) = -\frac xy\) 及 \(\theta_1 + \theta_2 = 90^\circ + \varphi\)，其中 \(\varphi\) 是 \(OP\) 的仰角。\(OP\) 与铅垂线的角平分线位于 \(\frac12(90^\circ + \varphi)\)。

  4. 顶点位于 \(\bigl(\frac{u^2}{2g}\sin2\theta, \frac{u^2}{2g}\sin^2\theta\bigr)\)，焦距（focal length）是 \(\frac{u^2\cos^2\theta}{2g}\)，所以焦点（focus）的高度是 \(\frac{u^2}{2g}(\sin^2\theta - \cos^2\theta)\)。无论 \(\theta\) 是多少，它与 \(O\) 的距离都是 \(\frac{u^2}{2g}\)。

11.10 会朝你飞回来的球

  1. 取单位使 \(u = g = 1\)，则 \(\frac{\mathrm{d}}{\mathrm{d}t}OP^2 = t(t^2 - 3t\sin\alpha + 2)\)，其根为 \(t \approx 1.050\)（局部极大，\(OP \approx 0.516\frac{u^2}{g}\)）和 \(t \approx 1.904\)（局部极小，\(OP \approx 0.336\frac{u^2}{g}\)）。球在 \(t \approx 1.970\) 着地。

  2. 沿斜面及垂直于斜面方向分解，\(OP^2 = u^2t^2 - ugt^3\sin(\alpha' + \beta) + \frac14g^2t^4\)，其中 \(\alpha'\) 由斜面起量度。这就是平地的公式，只是 \(\alpha = \alpha' + \beta\)。所以条件 \(\sin(\alpha' + \beta) > \frac{2\sqrt2}{3}\) 所涉及的是与水平所成的角；若由斜面起量度，临界角便降至 \(70.5^\circ - \beta\)（前提是球尚未着地）。

  3. 较小。阻力（drag）抵消水平运动，并使下降变得更陡，所以球落回时更接近铅垂方向，令 \(OP\) 更容易缩短。

  4. \(OP^2\) 的公式不涉及着地点，所以与之前一样，当且仅当 \(\sin\alpha > \frac{2\sqrt2}{3}\) 时，\(OP\) 会有一段时间递减（而飞行时间较长，意味着递减阶段必定在着地之前出现）。最终下落占主导，\(OP\) 便会递增。

11.11 外野手如何接球

  1. 若她站在 \(D_0\) 处，并以速度 \(v\) 背离击球手（batsman）跑动，球便在她前方 \(D_0 + vt - Ut\) 的距离处。要接到球，她需要 \(D_0 + vT = UT\)，这时距离是 \((U - v)(T - t)\)，所以 \(\tan\theta = \frac{gt}{2(U - v)}\)，同样是线性的。若球落在她身后，则 \(UT > D_0\) 及 \(v > 0\)：她向后跑。

  2. \(\theta = \tan^{-1}\frac{gt}{2U}\)，所以 \(\dot\theta = \frac{g/2U}{1 + (gt/2U)^2}\)，它是递减的。\(\tan\theta\) 之所以是线性的，是因为高度 \(\frac12gt(T - t)\) 和距离 \(U(T - t)\) 有公因式 \(T - t\)。

  3. 会。相对于她眼睛的高度是一个在接球时刻为零的二次式，所以可因式分解为 \((T - t)(c + dt)\)；除以 \(U(T - t)\) 后剩下一个线性函数（它起初是负数：她最初要向下看）。

  4. 不会。有阻力时，水平距离是 \(\frac Uk(\mathrm{e}^{-kt} - \mathrm{e}^{-kT})\)，而高度并不等于它乘以 \(t\) 的一个线性函数，所以 \(\tan\theta\) 不再是线性的。

11.12 橡皮绳上的蚂蚁

  1. \(\frac{x}{a + ut} = \frac1k\ln\frac{a + ut}{a}\)，它在 \(t = \frac au(\mathrm{e}^{k/2} - 1)\) 时等于 \(\frac12\)。由于 \(\frac T2 = \frac{a}{2u}(\mathrm{e}^{k/2} - 1)(\mathrm{e}^{k/2} + 1)\) 而 \(\frac12(\mathrm{e}^{k/2} + 1) > 1\)，这个时刻在 \(\frac T2\) 之前。

  2. \(\frac{\mathrm{d}}{\mathrm{d}t}\frac xL = \frac vL = \frac va\mathrm{e}^{-\lambda t}\)，所以 \(\frac xL = \frac{v}{a\lambda}(1 - \mathrm{e}^{-\lambda t})\)，只有当 \(v > \lambda a\) 时才会达到 \(1\)。

  3. \(\frac xL = v\int_0^t\frac{\mathrm{d}s}{a + \frac12bs^2}\)，它趋向 \(\frac{v\pi}{\sqrt{2ab}}\)。所以只有当 \(v > \frac{\sqrt{2ab}}{\pi}\) 时，蚂蚁才会到达。

  4. 这需要 \(\frac{H_N}{100\,000} = \frac{1}{100}\)，所以 \(H_N = 1000\)，而 \(N \approx \mathrm{e}^{999.4} \approx 10^{434}\) 秒。

11.13 铲雪车问题

  1. 正午后时间 \(t\) 的积雪深度与 \(t + t_0\) 成正比，所以铲雪车走过的距离是 \(c\ln\frac{t + t_0}{t_0}\)。条件 \(x(1) = 2\) 及 \(x(2) = 3\) 给出 \(\bigl(1 + \frac{1}{t_0}\bigr)^3 = \bigl(1 + \frac{2}{t_0}\bigr)^2\)。设 \(u = \frac{1}{t_0}\)，这便化简为 \(u^2 - u - 1 = 0\)，所以 \(u = \frac{1 + \sqrt5}{2}\) 及 \(t_0 \approx 0.618\) 小时：大约在 11:23 开始下雪。

  2. \(\frac{\mathrm{d}t}{\mathrm{d}y} = \frac{\alpha h}{k}\mathrm{e}^{\alpha y} - \frac{\alpha h}{k}\mathrm{e}^{\alpha y} + \alpha\bigl(T - \frac{\alpha hy}{k}\bigr)\mathrm{e}^{\alpha y}\)，而 \(\alpha\bigl(t - (\mathrm{e}^{\alpha y} - 1)\frac hk\bigr)\) 与它相同。

  3. 时间差距是 \(\bigl(T - \frac{\alpha hy}{k}\bigr)\mathrm{e}^{\alpha y}\)，它的导数在 \(y = \frac{kT - h}{\alpha h}\) 处为零。若 \(kT > h\)，差距会一直增大到该处，然后缩小，在 \(y = \frac{kT}{\alpha h}\) 处减至 \(0\)。若 \(kT \leq h\)，导数 \(\alpha\mathrm{e}^{\alpha y}\bigl(T - \frac hk - \frac{\alpha hy}{k}\bigr)\) 对所有 \(y > 0\) 都是负数，所以差距从一开始便缩小。第二辆铲雪车面对的积雪深度是 \(k \times\)（差距）；只要这比第一辆铲雪车在同一地点遇到的积雪深，它便会落后得更远。

  4. \(\frac1\alpha\frac{\mathrm{d}t_3}{\mathrm{d}y} = t_3 - t_2(y)\)。写成 \(t_3 = t_2 + g\)，得 \(g = \mathrm{e}^{\alpha y}\bigl(T - \alpha Ty + \frac{\alpha^2hy^2}{2k}\bigr)\)。若 \(kT \geq 2h\)，它在 \(y = \frac{k}{\alpha h}\bigl(T - \sqrt{T^2 - 2hT/k}\bigr)\) 处为零，早于第二辆铲雪车追上第一辆之处；若 \(kT < 2h\)，则第二辆会先追上第一辆。

11.14 是抛物线，不是悬链线

  1. 是。水平张力 \(H\) 仍然是常数，中间一段的斜率为 \(0\)，其后斜率每次递增 \(\frac wH\)。以水平一段的中点为起点量度 \(x\)，第 \(k\) 个接点位于 \(x = (k - \frac12)h\)，比最低的接点高出 \(\frac{wh}{2H}k(k - 1)\)，即 \(\frac{w}{2Hh}\bigl(x^2 - \frac{h^2}{4}\bigr)\)：是一条抛物线。

  2. 张力是 \(\sqrt{H^2 + V^2}\)，在垂直分量 \(V\) 最大之处最大：即在两端的一段，该处 \(V\) 承托一半的负载，即 \(\frac{(2n + 1)w}{2}\)。所以 \(T_{\max} = \sqrt{H^2 + \frac14(2n + 1)^2w^2}\)。

  3. \(y' = \sinh\frac xc\) 及 \(y'' = \frac1c\cosh\frac xc = \frac1c\sqrt{1 + \sinh^2\frac xc}\)。长度是 \(\int_0^X\cosh\frac xc\,\mathrm{d}x = c\sinh\frac Xc\)。

  4. 对于垂度（sag）为 \(s\) 的平缓曲线，悬链线（catenary）和抛物线的长度都约为 \(2d + \frac{4s^2}{3d}\)，所以两者都给出 \(s \approx \sqrt{\frac32d(L - d)}\)；它们只在 \(s^4\) 阶才有分别。对于一条几乎拉紧的链，这个差别远小于伽利略（Galileo）所能量度的任何数值。
