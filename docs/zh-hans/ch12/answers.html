第 12 章 · 概率

延伸练习答案

以下只是简短的答案和提示，并非完整解答：它们给出结果和关键步骤，方便你核对自己的做法。请先认真做过每道练习，然后才看答案。

12.1 精确地取条件

  1. 在 (iv) 和 (v) 中，其余 \(k - 1\) 块圆片都是从余下的 \(b + n - 1\) 块中随机抽出的，其中 \(n - 1\) 块有编号，所以两者都等于 \(\frac{(n - 1)\binom{b}{k-2}}{\binom{b+n-1}{k-1}}\)。(vi) 的答案是 \(\frac{\binom n2\binom{b}{k-2}}{\binom{b+n}{k} - \binom bk}\)。设 \(N = b + n\)，两者只在 \((2N - nk)\binom{N-1}{k-1} = 2k\binom bk\) 时才相等。这只会在个别特殊情况下发生，例如 \((b, n, k) = (2, 4, 3)\)、\((3, 3, 4)\) 或 \((6, 11, 3)\)，又或者是 \(n = 2\) 而所有圆片都被抽出这种平凡情况。对于题目所给的数值，等式并不成立。

  2. 两个孩子的（性别，星期几）组合共有 \(14^2 = 196\) 种，各种组合可能性相等，其中 \(196 - 13^2 = 27\) 种包含至少一个星期二出生的男孩。在这些组合之中，\(7^2 - 6^2 = 13\) 种是两个男孩。所以概率是 \(\frac{13}{27}\)。

  3. 你选了 1 号门。若汽车在 1 号门后（概率 \(\frac13\)），换门会输；若汽车在 2 号或 3 号门后，主持人必须打开另一扇后面是山羊的门，换门便会赢：概率为 \(\frac23\)。若主持人随机打开一扇门，而门后碰巧是山羊，那么根据你所见，“汽车在你选的门后”和“汽车在另一扇关着的门后”这两个结果的可能性相等：概率为 \(\frac12\)。

  4. \(\mathrm{P}(\geq2 \mid \geq1) = \frac{1 - \mathrm{P}(0) - \mathrm{P}(1)}{1 - \mathrm{P}(0)} \approx 0.370\)，但 \(\mathrm{P}(\geq2 \mid \text{葵扇 A}) = 1 - \binom{48}{12}\big/\binom{51}{12} \approx 0.561\)。知道是哪一张 A，会令手上有第二张 A 的可能性增加。

12.2 基本比率谬误

  1. 若尸体在那里，两者都说“有尸体”的概率是 \(pq\)；若不在，则是 \((1 - p)(1 - q)\)。先验胜算（prior odds）为 \(1 : 1\)，所以后验概率（posterior probability）是 \(\frac{pq}{pq + (1 - p)(1 - q)} = \frac{pq}{1 - p - q + 2pq}\)。至于第二部分，在三种可能性相等的情况中，有两种情况下“\(A\) 在那里”为真，所以 \(\mathrm{P}(\text{两者都在} \mid \text{两者都说 } A) = \frac{pq}{2pq + (1 - p)(1 - q)}\)。

  2. 我们需要 \(0.9\pi > \frac{1}{11}(1 - \pi)\)，即 \(\pi > \frac{10}{109} \approx 9.2\%\)。

  3. 每一次 AL 测试呈阳性，都会把胜算乘以 \(\frac{0.9}{1/11} = 9.9\)。由先验胜算 \(\frac{1}{99}\) 开始：一次阳性之后，胜算为 \(0.1\)（概率 \(\frac{1}{11}\)）；两次之后，胜算为 \(0.99\)（概率约 \(0.497\)）；三次之后，胜算为 \(9.8\)（概率约 \(0.907\)）。

  4. 在 \(100\) 名患者之中，\(99\) 人测试呈阳性；在 \(999\,900\) 名没有患病的人之中，约有 \(9999\) 人呈阳性。所以约有 \(10\,100\) 人被告知可能患病，而当中只有 \(99\) 人（约 \(1\%\)）真正患病。

12.3 “随机”是甚么意思？

  1. 弦（chord）比内接等边三角形的边长 \(\sqrt3a\) 长的条件分别是：它的远端落在与近端相对的那三分之一圆周上（\(\frac13\)）；它与 \(O\) 的距离小于 \(\frac a2\)（\(\frac12\)）；它的中点落在半径为 \(\frac a2\) 的圆内（\(\frac14\)）。

  2. 以 \(C\) 为中点的弦垂直于 \(OC\)，所以它就是通过 \(C\) 而角度为 \(t = \frac\pi2\) 的弦，而 \(L(\frac\pi2) = \frac{4a}{3}\bigl(0 + \frac12\sec^2\frac\pi4\bigr) = \frac{4a}{3}\)。

  3. 弦长为 \(2\sqrt{a^2 - d^2}\)，平均值为 \(\frac2a\int_0^a\sqrt{a^2 - d^2}\,\mathrm{d}d = \frac2a \cdot \frac{\pi a^2}{4} = \frac{\pi a}{2}\)。

  4. 随机端点：\(\frac{2}{\pi\sqrt{4a^2 - \ell^2}}\)。随机距离：\(\frac{\ell}{2a\sqrt{4a^2 - \ell^2}}\)。随机中点：\(\frac{\ell}{2a^2}\)。

12.4 两两独立，却非相互独立

  1. 展开后得 \(\mathrm{E}(XY) - \mathrm{E}(X)\mathrm{E}(Y) = (a - pq)(x_1 - x_2)(y_1 - y_2)\)，所以 \(a = pq\)；其余三格随之确定，于是两者独立。例子：在 \((0, 0)\) 放概率 \(\frac13\)，在 \((\pm1, \pm1)\) 各点放概率 \(\frac16\)。两个边际分布（marginal distribution）都是均匀的，而且 \(\mathrm{E}(AB) = 0\)，但 \(\mathrm{P}(A = 0, B = 1) = 0 \neq \frac19\)。

  2. 共有 \(21\) 对，每对相同的概率是 \(\frac16\)，而各指示变量（indicator）两两独立（pairwise independent）。所以平均值是 \(3.5\)，方差（variance）是 \(21 \cdot \frac16 \cdot \frac56 \approx 2.92\)，标准差约为 \(1.71\)。得分 \(7\) 大约比平均值高出两个标准差。

  3. 平均值是 \(\binom k2\frac{1}{365}\)。各指示变量两两独立，与骰子的情况完全一样，所以方差是 \(\binom k2\frac{1}{365}\cdot\frac{364}{365}\)。（它们并非相互独立（mutually independent）：若 \(1, 2\) 相同，\(2, 3\) 也相同，则 \(1, 3\) 亦相同。）

  4. 取八个可能性相等的结果，\(A = B = \{1, 2, 3, 4\}\)，\(C = \{1, 5, 6, 7\}\)。那么 \(\mathrm{P}(A \cap B \cap C) = \frac18\)，但 \(\mathrm{P}(A \cap B) = \frac12 \neq \frac14\)。

12.5 最后一位乘客的座位

  1. 对所有 \(n \geq 3\)，答案都是 \(\frac13\)。最后一个座位现在是 \(S_1\)、\(S_2\) 和 \(S_n\) 其中之一，而每一次随机选择对这三个座位都是对称的。

  2. 若 \(T_1\) 坐了 \(S_1\)，没有人要让位。若 \(T_1\) 坐了 \(S_3\)，则 \(T_1\) 和 \(T_3\) 都坐错了位。若 \(T_1\) 坐了 \(S_2\)，便由 \(T_2\) 选择：选 \(S_1\) 有 \(2\) 人坐错位，选 \(S_3\) 则有 \(3\) 人。期望值（expectation）是 \(\frac13\bigl(0 + 2 + \frac52\bigr) = \frac32\)，与公式给出的 \(\frac23 + \frac13 + \frac12\) 一致。

  3. 当 \(r \geq 2\) 时 \(P_r = \frac12\)，于是 \(\frac1n\bigl(1 + \frac{n - 2}{2}\bigr) = \frac12\)，所以递推关系（recurrence）与 \(P_n = \frac12\) 相容。

  4. 最后一个空位必定是 \(S_1\) 或 \(S_n\)（任何其他 \(S_k\) 最迟在 \(T_k\) 登机时已被占去）。所以若它不是 \(S_n\)，就是 \(S_1\)。

12.6 多一枚硬币

  1. 设 \(H'\) 为 Bob 首 \(n + 1\) 次掷币的结果，\(X\) 为他最后一次掷币的结果。若 \(H' > H_A\)，或者 \(H' = H_A\) 而 \(X\) 是正面，Bob 便胜出。所以概率是 \(\mathrm{P}(H' > H_A) + \frac12\mathrm{P}(H' = H_A)\)，而根据“多一枚硬币”的结果，\(\mathrm{P}(H' > H_A) = \frac12\)。

  2. 不成立。当 \(n = 0\) 时，Bob 胜出的概率是 \(p\)。那个巧妙的证明把正面和反面对调，而这只有对公平硬币才是一种对称。

  3. \(H_A = H_B\) 恰好在 \(H_A + (\text{Bob 的反面数目}) = n\) 时成立，即一个 \(\mathrm{B}(2n, \frac12)\) 变量等于 \(n\)。数值：\(\frac12\)、\(\frac38\)、\(\frac{5}{16}\)。

  4. 不成立：掷出六点就像一枚 \(p = \frac16\) 的硬币。当 \(n = 0\) 时概率是 \(\frac16\)，而一般而言概率低于 \(\frac12\)。

12.7 淘汰赛中谁会遇上谁

  1. 第 \(k\) 轮有 \(2^{n-k}\) 场比赛，而根据对称性，每场比赛由 \(\binom{2^n}{2}\) 对球员中任何一对对赛的可能性都相等。把整个淘汰赛的 \(2^n - 1\) 场比赛加起来，得 \(\frac{2^n - 1}{\binom{2^n}{2}} = \frac{2}{2^n}\)。

  2. 不会：在固定的对阵表中随机编排位置，对称性依然保持，同样的计数方法仍然适用。

  3. \(X\) 在第 \(k\) 轮的对手来自一组 \(2^{k-1}\) 名球员，每人从该组胜出的可能性相等。所以 \(Y\) 是该对手的概率为 \(\frac{2^{k-1}}{2^n - 1} \cdot \frac{1}{2^{k-1}} = \frac{1}{2^n - 1}\)，而 \(n\) 轮的总和是 \(\frac{n}{2^n - 1}\)。

  4. 共有 \(\binom{2n}{2} = n(2n - 1)\) 场比赛；每一对都会相遇，所以概率是 \(1\)。

12.8 Penney 游戏

  1. HHT 只有在头两次掷出 HH 时才会胜出；否则在凑成 HH 之前已出现一个 T，THH 必定先出现。所以 HHT 胜出的概率是 \(\frac14\)。四人一起玩时：HH 之后，HHT 必胜；TT 之后，TTH 必胜；由 HT 和 TH 开始，HTT 和 THH 的胜出机会分别是 \(\frac23\) 和 \(\frac13\)（或倒过来），于是每名玩家的胜出概率是 \(\frac14 \cdot 1\) 或 \(\frac14\bigl(\frac23 + \frac13\bigr)\)，即 \(\frac14\)。TTH 击败 THH 的概率是 \(\frac23\)（第 (i) 部分）。

  2. 对于 HH：\(e_0 = 1 + \frac12e_{\mathrm{H}} + \frac12e_0\) 及 \(e_{\mathrm{H}} = 1 + \frac12e_0\)，得 \(e_0 = 6\)。对于 HT：一旦有了一个 H，便等待一个 T（平均掷两次），而第一个 H 平均要掷两次：共 \(4\) 次。

  3. HHH 和 TTT 分别被 THH 和 HTT 击败，概率为 \(\frac78\)；HHT 和 TTH 分别被 THH 和 HTT 击败，概率为 \(\frac34\)；其余四个（HTH、HTT、THH、THT）分别被 HHT、HHT、TTH、TTH 击败，概率为 \(\frac23\)。HHH 和 TTT 最容易被击败。

  4. 设 \(A =\) HTT，\(B =\) HHT，各相关数（correlation）为 \(AA = 4\)、\(AB = 0\)、\(BB = 4\)、\(BA = 2\)。\(B\) 胜出的胜算是 \((AA - AB) : (BB - BA) = 4 : 2\)，即概率为 \(\frac23\)。

12.9 用不公平的硬币作公平的决定

  1. 所需轮数服从几何分布（geometric distribution）：第 (i) 部分的平均值是 \(\frac{1}{p^2 + q^2}\)，而冯·诺伊曼（von Neumann）的方法（HT 或 TH）的平均值是 \(\frac{1}{2pq}\)。由于 \(p^2 + q^2 - 2pq = (p - q)^2\)，对所有 \(p \neq \frac12\)，冯·诺伊曼的方法都较慢。不过，公平的却是它。

  2. 用冯·诺伊曼的技巧制造公平的位元（bit）。每次取两个：\(00\)、\(01\) 和 \(10\) 分别代表三个选项，\(11\) 则表示重新开始。

  3. 把掷币结果逐次与二进制展开式 \(\frac13 = 0.010101\ldots\) 比较（把 H 读作 \(1\)，T 读作 \(0\)）。在第一次出现不同的那一掷，若掷币结果小于该位数字（T 对着 \(1\)），便宣布“正面”，否则宣布“反面”。这样得出正面的概率恰好是 \(\frac13\)，平均用 \(2\) 次掷币。

  4. 在未能决定的一轮之后，其中一面有两个，另一面有一个，而整个过程是这两个状态上的马可夫链（Markov chain）。解之得 \(\mathrm{P}(\text{酒店}) = \frac{p^3}{p^3 + q^3}\)，当 \(p = \frac12\) 时等于 \(\frac12\)：这时是公平的，其他情况则不然。

12.10 把绳头系起来

  1. 第一次打结形成一个环的概率是 \(\frac13\)（其余三个绳端之中，有一个属于同一条绳），而最后一次打结则必定形成一个环。环的数目：\(2\) 个的概率是 \(\frac13\)，\(1\) 个的概率是 \(\frac23\)；平均值是 \(\frac43\)。

  2. 余下 \(k\) 条绳时，一次打结不形成环的概率是 \(1 - \frac{1}{2k - 1}\)。乘积 \(\prod_{k=2}^{n}\frac{2k - 2}{2k - 1}\) 等于 \(\frac{4^n}{2n\binom{2n}{n}}\)，约为 \(\frac{\sqrt{\pi n}}{2n} = \sqrt{\frac{\pi}{4n}}\)。

  3. 依次插入元素 \(1, 2, \ldots, n\)：元素 \(k\) 要么开始一个新的循环（cycle）（概率 \(\frac1k\)），要么放在之前 \(k - 1\) 个元素其中一个之后。把各指示变量加起来便得 \(H_n\)。

  4. 各次打结的成环指示变量互相独立，概率为 \(\frac{1}{2k - 1}\)，所以方差是 \(\sum\frac{1}{2k - 1}\bigl(1 - \frac{1}{2k - 1}\bigr)\)。另外 \(\sum_{k \geq 1}\frac{1}{(2k - 1)^2} = \frac{\pi^2}{6} - \frac14 \cdot \frac{\pi^2}{6} = \frac{\pi^2}{8}\)。

12.11 邮票、杯子与 \(e\)

  1. \(\sum_{k \geq 2}\frac{k - 1}{k!}t^k = t\mathrm{e}^t - (\mathrm{e}^t - 1) = 1 + (t - 1)\mathrm{e}^t\)。求导后得 \(\mathrm{E}(N) = \mathrm{G}'(1) = \mathrm{e}\) 及 \(\mathrm{E}(N(N - 1)) = \mathrm{G}''(1) = 2\mathrm{e}\)，所以 \(\mathrm{Var}(N) = 3\mathrm{e} - \mathrm{e}^2\)。

  2. \(\mathrm{P}(N = j)\) 在 \(k = 0, \ldots, j - 1\) 的 \(\mathrm{P}(N > k)\) 中出现，即共 \(j\) 次。这里 \(\mathrm{P}(N > k) = \frac{1}{k!}\)，所以 \(\mathrm{E}(N) = \sum\frac{1}{k!} = \mathrm{e}\)。

  3. 完全没有改变：只有一个杯时，Jim 必定“猜”中。期望价格仍然是 \(\mathrm{e}\)。

  4. \(\int_0^1\frac{(1 - u)^2}{2}\,\mathrm{d}u = \frac16\)。一般而言，在 \(u_k = u\) 处的截面是一个按 \(1 - u\) 缩放的 \((k - 1)\) 维单纯形（simplex），所以 \(V_k = V_{k-1}\int_0^1(1 - u)^{k-1}\,\mathrm{d}u = \frac{V_{k-1}}{k}\)。

12.12 何时停止寻找

  1. 若最大的在第 \(k \geq 2\) 位，你恰好在第一个雪糕是首 \(k - 1\) 个之中最大时才会得到它，概率为 \(\frac{1}{k - 1}\)。对 \(k\) 取平均得 \(\frac1n\sum_{k=2}^n\frac{1}{k - 1}\)，当 \(n = 4\) 时是 \(\frac{11}{24}\)。列出全部 \(24\) 种次序，可知得到第二、第三和第四大的概率分别是 \(\frac{7}{24}\)、\(\frac16\) 和 \(\frac{1}{12}\)。

  2. 拒绝 \(r = 0, 1, 2, 3\) 人分别给出 \(\frac14\)、\(\frac{11}{24}\)、\(\frac{5}{12}\)、\(\frac14\)。所以应拒绝一名候选人，成功概率为 \(\frac{11}{24}\)。

  3. 首 \(n\) 人之中最好的一个位列头两名的概率是 \(\frac nN + \frac nN\cdot\frac{N - n}{N - 1}\)，当 \(n\) 很小时接近 \(\frac nN\) 的两倍。若头两名任何一个都可以接受，你便可以少看一些候选人才作决定。（以此为目标的最佳策略，成功概率约为 \(0.57\)。）

  4. 设 \(\mathrm{P}(r) = \frac rN\sum_{k=r}^{N-1}\frac1k\)：当 \(N = 10\) 时，\(r = 2, 3, 4\) 给出 \(0.366\)、\(0.399\)、\(0.398\)；当 \(N = 100\) 时，\(r = 36, 37, 38\) 给出 \(0.3710\)、\(0.3710\)、\(0.3708\)，其中 \(r = 37\) 仅仅领先。

12.13 三人决斗

  1. Algernon 掷失后，Bertie 掷向 Cuthbert。若他掷中（\(\frac35\)），便是 Algernon 对 Bertie，由 Algernon 先掷，Bertie 胜出的概率是 \(1 - \frac{2/5}{2/5 + 3/5 - 6/25} = \frac{9}{19}\)。若他掷失，Cuthbert 会掷中 Bertie，然后除非 Algernon 先掷中（\(\frac35\)），否则 Cuthbert 胜出。所以 Bertie 胜出的概率是 \(\frac35 \cdot \frac{9}{19} = \frac{135}{475}\)，Cuthbert 则是 \(\frac25 \cdot \frac35 = \frac{114}{475}\)。

  2. 对所有 \(a < 1\) 都成立。掷失给出 \(\frac35\cdot\frac{a}{a + \frac35 - \frac35a} + \frac25a\)；掷中 Cuthbert 给出 \(1 - \frac{3/5}{3/5 + a - \frac35a}\)（这时 Bertie 先向他掷），这个值总是较小；掷中 Bertie 则给出 \(0\)。

  3. 不应该。若 Bertie 掷向 Algernon 而掷中，Cuthbert 随即掷中 Bertie；若他掷失，Cuthbert 照样掷中 Bertie。无论如何 Bertie 都一无所得，而掷向 Cuthbert 则有 \(\frac{27}{95}\)。

  4. \(p + (1 - p)(1 - r)p\)，它小于 \(\frac{p}{p + r - pr}\)，即整个等比级数（geometric series）之和。

12.14 混合策略

  1. 取 \(b = (\frac14, \frac12, \frac14)\)，则 \(X = Y = Z = 0\)，所以无论对方怎样做，B 都赢得 \(0\)。对着 \((\frac13, \frac13, \frac13)\)，A 猜 \(1\)、\(2\) 和 \(3\) 的期望赢款分别是 \(-\frac13\)、\(0\) 和 \(\frac13\)，所以 A 应该每次都猜 \(3\)。

  2. 收益矩阵（payoff matrix）的对角线上是 \(0\)，其余位置是 \(\pm1\)，把三个策略循环置换后矩阵不变，所以最优策略是 \((\frac13, \frac13, \frac13)\)。在原题中，相差 \(1\) 和相差 \(2\) 的罚则不同，所以各策略不能互换。

  3. 若 \(X\)、\(Y\)、\(Z \geq 0\) 且 \(X + 2Y + Z = 0\)，则三者都是 \(0\)。由此必有 \(b_1 = b_3\) 及 \(b_2 = 2b_3\)。

  4. 现在 \(X = -b_2 + 3b_3\)、\(Y = b_1 - b_3\) 及 \(Z = -3b_1 + b_2\)，而 \(X + 3Y + Z = 0\)。令三者都等于零，得 \((\frac15, \frac35, \frac15)\)。

12.15 灭绝还是爆发

  1. 灭绝概率（extinction probability）是 \(s = (q + ps)^2\) 在 \([0, 1]\) 内的最小根。两个根是 \(1\) 和 \(\bigl(\frac qp\bigr)^2\)，而第二个根恰好在 \(p > \frac12\) 时小于 \(1\)。

  2. 给定 \(X_{n-1}\)，\(X_n\) 的平均值是 \(2pX_{n-1}\)，方差是 \(2pqX_{n-1}\)，所以 \(\mathrm{Var}(X_n) = \mathrm{E}(2pqX_{n-1}) + (2p)^2\mathrm{Var}(X_{n-1})\)。当 \(p = \frac12\) 时：\(\mathrm{Var}(X_n) = \mathrm{Var}(X_{n-1}) + \frac12\)，所以 \(\mathrm{Var}(X_n) = \frac n2\)。

  3. 在第 \(n\) 代或之前灭绝，表示第一代每一颗粒子的后代都在 \(n - 1\) 代之内消亡。取 \(p = \frac34\)：\(e_1 = 0.0625\)，\(e_2 \approx 0.0881\)，\(e_3 \approx 0.0999\)，递增并趋向 \(\frac19 \approx 0.111\)。

  4. \(s = \frac14(1 + s + s^2 + s^3)\) 可因式分解为 \((s - 1)(s^2 + 2s - 1) = 0\)，所以灭绝概率是 \(\sqrt2 - 1 \approx 0.414\)。

12.16 顺向与逆向的马可夫链

  1. 根据对称性 \(p_B = p_D\)；另外 \(p_A = \frac13 + \frac23p_B\)、\(p_B = \frac13p_A + \frac13p_C\) 及 \(p_C = \frac23p_B\)。所以 \(p_A = \frac{7}{15}\)。由 \(A\) 出发，不经过 \(C\) 而在 \(A\) 离开：\(x_A = \frac13 + \frac23x_B\) 及 \(x_B = \frac13x_A\)，所以 \(x_A = \frac37\)。条件概率是 \(\frac{3/7}{7/15} = \frac{45}{49}\)。

  2. 把第一行乘以 \(P\)：\((0.19, 0.33, 0.48)\)。

  3. 迹（trace）是 \(1.3\)，行列式（determinant）是 \(0.02\)，而 \(1\) 是一个特征值（eigenvalue）（各行之和为 \(1\)）。另外两个特征值之和为 \(0.3\)，积为 \(0.02\)：它们是 \(0.2\) 和 \(0.1\)。

  4. \(a_1p_{12} = \frac{1}{20}\) 但 \(a_2p_{21} = \frac{1}{15}\)，所以这条链不是可逆的（reversible）：倒过来运行时，它的转移概率并不相同（第 (iii) 部分的 \(q_{ij}\) 与 \(p_{ij}\) 不同）。

12.17 巴拿赫的火柴盒

  1. 若第二次伸手要拿的与第一次是同一种，她当下便发现那包已空（\(N = 2\)）；否则她拿走另一颗糖果，并在第三次伸手时发现有一包已空。所以 \(N = 2\) 或 \(3\)，概率各为 \(\frac12\)。

  2. \(n = 1\)：\(\frac12 + \frac12 = 1\)。\(n = 2\)：\(\frac{6}{16} + \frac{6}{16} + \frac{4}{16} = 1\)。

  3. \(\binom{2n - 1}{n}2^{-(2n-1)} = \frac12\binom{2n}{n} \cdot 2 \cdot 4^{-n} = \binom{2n}{n}4^{-n}\)。

  4. 就余下的拖肥糖和薄荷糖数目作首步递推（first-step recursion），得 \(\frac{64}{81} \approx 0.79\)。

12.18 无记忆性

  1. \(\mathrm{P}(\min > t) = \mathrm{e}^{-\lambda_1t}\mathrm{e}^{-\lambda_2t}\)。等候下一班巴士的时间服从指数分布（exponential distribution），率为每分钟 \(\frac{1}{15} + \frac{1}{30} = \frac{1}{10}\)，所以其中位数（median）是 \(10\ln2 \approx 6.9\) 分钟。

  2. \(\mathrm{P}(Y \geq k) = (1 - p)^k\)，所以比值是 \((1 - p)^n\)。

  3. 包含 \(t\) 的那段间隔，由回溯至上一班巴士的时间和前望至下一班巴士的时间组成，两者都服从平均值为 \(\frac1\lambda\) 的指数分布（当 \(t\) 很大时），所以间隔的期望长度是 \(\frac2\lambda\)。较长的间隔较有可能包含某个指定时刻。

  4. 在 \([0, 1]\) 上为 \(\frac{\lambda\mathrm{e}^{-\lambda z}}{1 - \mathrm{e}^{-\lambda}}\)。当 \(\lambda = 1\) 时，它由约 \(1.58\) 缓缓下降至 \(0.58\)；当 \(\lambda = 5\) 时，它集中在 \(0\) 附近，由约 \(5.03\) 下降至 \(0.03\)。

12.19 平面上的随机点

  1. 由 \(1 - \mathrm{e}^{-\pi ky^2} = \frac12\) 得中位数为 \(\sqrt{\frac{\ln2}{\pi k}} \approx \frac{0.470}{\sqrt k}\)，比平均值 \(\frac{1}{2\sqrt k}\) 略小。

  2. \(\mathrm{P}(Y_2 > y) = \mathrm{e}^{-\pi ky^2}(1 + \pi ky^2)\)，所以概率密度（density）是 \(2\pi^2k^2y^3\mathrm{e}^{-\pi ky^2}\)。

  3. 在极坐标下，\(R\) 的密度是 \(\frac{1}{2\pi\sigma^2}\mathrm{e}^{-r^2/(2\sigma^2)} \cdot 2\pi r\)。当 \(\sigma^2 = \frac{1}{2\pi k}\) 时，它与超级市场的分布吻合。

  4. 取 \(k = 4 \times 10^{-4}\) 每 m\(^2\)，完全随机的假设预测平均值为 \(\frac{1}{2\sqrt k} = 25\) m。观察所得的 \(35\) m 较大，这显示树木是互相疏开的（竞争），而不是聚集成丛。

12.20 蒲丰投针

  1. 把针切成很多小段。相交次数的期望值具有可加性，而每一小段的贡献与其长度成正比，所以无论 \(a\) 是多少，总和都是 \(\frac{2a}{\pi b}\)。

  2. 根据同样的可加性（蒲丰投面条，Buffon’s noodle），仍然是 \(\frac{2a}{\pi b}\)。

  3. 圆心与每条边的距离都必须至少为 \(r\)：\(\frac{(s - 2r)^2}{s^2}\)。

  4. 由 \(\frac{1808}{3408} \approx \frac{5}{3\pi}\) 得 \(\pi \approx \frac{5 \times 3408}{3 \times 1808} = \frac{17\,040}{5424} = \frac{355}{113}\)：完美得令人起疑。

12.21 折断一根棒

  1. 要组成三角形，每一段都必须短于 \(\frac12\)。在由折断点组成的单位正方形中，这个条件划出一个面积为 \(\frac14\) 的区域。

  2. 假设第一个折断点在 \(x < \frac12\)（另一情况是对称的），而较长的一段 \(1 - x\) 再被均匀地折断。新的两段都必须短于 \(\frac12\)，其概率为 \(\frac{x}{1 - x}\)。所以答案是 \(2\int_0^{1/2}\frac{x}{1 - x}\,\mathrm{d}x = 2\ln2 - 1\)。

  3. 当 \((2 - x - y)^2 > x^2 + y^2\)，即 \(y < \frac{2 - 2x}{2 - x}\) 时，\(C\) 处的角是钝角。这条曲线与 \(x + y = 1\) 之间的面积是 \(\frac32 - 2\ln2\)，所以概率是 \(3 - 4\ln2\)，与 \(B\) 处的相同。这并非巧合：三条边各自最多为 \(1\)，总和为 \(2\)，并且是均匀分布的，所以它们可以互换。因此 \(\mathrm{P}(\text{钝角三角形}) = 9 - 12\ln2 \approx 0.68\)。

  4. 根据容斥原理（inclusion–exclusion），最长的一段 \(M\) 满足 \(\mathrm{P}(M > m) = 3(1 - m)^2 - 3(1 - 2m)_+^2 + (1 - 3m)_+^2\)，其中 \(x_+ = \max(x, 0)\)。在 \([0, 1]\) 上积分得 \(\mathrm{E}(M) = 1 - \frac12 + \frac19 = \frac{11}{18}\)。

12.22 没有平均值的分布

  1. \(\mathrm{P}(\tan\Theta \leq k) = \frac1\pi\bigl(\tan^{-1}k + \frac\pi2\bigr)\)，求导后得 \(\frac{1}{\pi(1 + k^2)}\)。

  2. 把 \(U\) 和 \(V\) 对调，径向对称的密度保持不变，所以 \(\frac VU\) 与 \(\frac UV\) 有相同的分布。

  3. 密度是对称的，所以中位数是 \(0\)；而 \(\mathrm{P}(C \leq 1) = \frac12 + \frac1\pi\tan^{-1}1 = \frac34\)。

  4. \(\frac{1}{2\pi}\mathrm{e}^{-r^2/2}\,r\,\mathrm{d}r\,\mathrm{d}\theta\)，而令 \(s = r^2\) 后这就是 \(\frac{1}{2\pi}\,\mathrm{d}\theta \cdot \frac12\mathrm{e}^{-s/2}\,\mathrm{d}s\)：角度是均匀分布的，\(R^2\) 服从平均值为 \(2\) 的指数分布，而且两者独立。

12.23 由概率得出斯特灵公式

  1. \(\sqrt{20\pi}(10/\mathrm{e})^{10} \approx 3\,598\,696\)（约低 \(0.8\%\)）及 \(\sqrt{40\pi}(20/\mathrm{e})^{20} \approx 2.4228 \times 10^{18}\)（约低 \(0.4\%\)）。

  2. \(\frac{(2n)!}{(n!)^2} \approx \frac{\sqrt{4\pi n}(2n/\mathrm{e})^{2n}}{2\pi n(n/\mathrm{e})^{2n}} = \frac{4^n}{\sqrt{\pi n}}\)。

  3. \(100\log_{10}\frac{100}{\mathrm{e}} + \frac12\log_{10}(200\pi) \approx 157.97\)，所以 \(100!\) 有 \(158\) 位数字。

  4. \(\binom{1000}{500}2^{-1000} \approx \frac{1}{\sqrt{500\pi}} \approx 0.0252\)。

12.24 中心极限定理

  1. 作卷积（convolution），得 \(\frac14\int\mathrm{e}^{-|x| - |y - x|}\,\mathrm{d}x = \frac14(1 + |y|)\mathrm{e}^{-|y|}\)。方差是 \(2 + 2 = 4\)。

  2. \(\mathrm{E}(\mathrm{e}^{\theta X}) = \frac12(\mathrm{e}^{\theta/2} + \mathrm{e}^{-\theta/2}) = \cosh\frac\theta2\)。标准化后的和 \(\frac{2}{\sqrt n}\sum X_i\) 的母函数（generating function）是 \(\cosh^n\frac{\theta}{\sqrt n}\)，其对数为 \(n\ln\bigl(1 + \frac{\theta^2}{2n} + \cdots\bigr) \to \frac{\theta^2}{2}\)。

  3. 把 \(Y\) 写成两个独立的 \(\Gamma(82, 1)\) 变量之差，再作数值积分，得 \(\mathrm{P}(|Y| \geq 25) \approx 0.051\)：正态近似（normal approximation）非常准确。

  4. 它没有矩母函数（moment generating function），甚至连平均值也没有。事实上，\(n\) 个独立柯西（Cauchy）变量的平均值本身也服从柯西分布：取平均完全不会令它变得集中。

12.25 众多之中的最大值

  1. \(n\) 个寿命之中，最先完结的一个平均需时 \(\frac{1}{n\lambda}\)；之后余下 \(n - 1\) 个，一切重新开始，如此类推。所以 \(\mathrm{E}(Y) = \frac1\lambda\bigl(\frac1n + \frac{1}{n - 1} + \cdots + 1\bigr)\)。

  2. \(\mathrm{P}(\min > t) = (\mathrm{e}^{-\lambda t})^n = \mathrm{e}^{-n\lambda t}\)。

  3. 由 \((1 - \mathrm{e}^{-\lambda y})^n = \frac12\) 得 \(\lambda y = -\ln(1 - 2^{-1/n})\)。当 \(n = 10\) 时这是 \(2.704\)，而近似值为 \(\ln10 - \ln\ln2 \approx 2.669\)。

  4. \(\mathrm{P}(M \leq m) = m^n\)，所以 \(\mathrm{P}\bigl(n(1 - M) > s\bigr) = \bigl(1 - \frac sn\bigr)^n \to \mathrm{e}^{-s}\)。这属于韦布尔（Weibull）型：各变量有上界，而最大值会挤向这个上界。
