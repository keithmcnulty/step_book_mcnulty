灭绝还是爆发

题目

STEP II 2003，第 12 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/03-s2-q12

引子

1873 年，高尔顿（Francis Galton）在《Educational Times》上提出一个问题：为甚么贵族的姓氏那么容易失传？每个男人所生的儿子数目是随机的，而每个儿子都会把姓氏传下去。即使每个男人平均有多于一个儿子，这个姓氏就能永远流传下去吗？这个问题开创了分支过程（branching process）的理论，如今这套理论用来模拟核连锁反应、传染病的扩散、细胞群体的增长，以及突变能否存活下去。

本题建立的是最简单的模型：每个粒子分裂成 \(0\)、\(1\) 或 \(2\) 个粒子。粒子总数的期望值（expectation）按几何级数增长或缩减。但期望值并不是故事的全部。即使期望的粒子总数急剧膨胀，整个族系完全灭绝的概率仍然是正数，而一个漂亮的不动点（fixed point）论证就能把这个概率求出来。

动笔之前

如果某一阶段有两个粒子，下一阶段粒子数目的分布是甚么？

两个粒子各自独立地产生后代，后代数目服从 \(\mathrm{B}(2, p)\)，所以总数服从 \(\mathrm{B}(4, p)\)：共有四次独立的“机会”，每次成功的概率为 \(p\)。

逐步解题

阶段 1 先是两个，然后又是两个

\(\mathrm{P}(X_1 = 2) = p^2\)，然后 \(\mathrm{P}(X_2 = 2 \mid X_1 = 2) = \binom42p^2q^2 = 6p^2q^2\)。所以 \[\mathrm{P}(X_1 = 2, X_2 = 2) = 6p^4q^2. \qed\]

阶段 2 逆向推理

\(X_2 = 2\) 可以有多少种方式发生？（\(X_1\) 可以是甚么？）

要使 \(X_2 = 2\)，可以是 \(X_1 = 1\)（概率为 \(2pq\)），其后产生 \(2\) 个后代（\(p^2\)）；也可以是 \(X_1 = 2\)，其后由 \(\mathrm{B}(4, p)\) 得出 \(2\) 个。（\(X_1 = 0\) 则甚么也不剩。）所以 \(\mathrm{P}(X_2 = 2) = 2p^3q + 6p^4q^2\)，而 \[\mathrm{P}(X_1 = 2 \mid X_2 = 2) = \frac{6p^4q^2}{2p^3q + 6p^4q^2} = \frac{3pq}{1 + 3pq}.\] 令此式等于 \(\frac{9}{25}\)：\(75pq = 9 + 27pq\)，所以 \(pq = \frac{3}{16}\)，即 \(p(1 - p) = \frac{3}{16}\)，由此得 \(p = \frac14\) 或 \(p = \frac34\)。■

阶段 3 粒子总数的期望值

如果在第 \(n - 1\) 阶段有 \(k\) 个粒子，第 \(n\) 阶段粒子数目的期望值是多少？然后对 \(k\) 取平均。

每个粒子平均有 \(\mathrm{E}(X) = 2p\) 个后代，所以 \(k\) 个粒子平均有 \(2pk\) 个后代：\(\mathrm{E}(X_n \mid X_{n-1} = k) = 2pk\)。对 \(k\) 取平均，得 \(\mathrm{E}(X_n) = 2p\,\mathrm{E}(X_{n-1})\)。由于 \(\mathrm{E}(X_0) = 1\)， \[\mathrm{E}(X_n) = (2p)^n.\] 当 \(p = \frac14\) 时，\((2p)^n = 2^{-n} \to 0\)；当 \(p = \frac34\) 时，\((2p)^n = \bigl(\frac32\bigr)^n \to \infty\)。■

回顾

  • 独立二项变量之和。\(k\) 个粒子各自给出 \(\mathrm{B}(2, p)\)，合起来就是 \(\mathrm{B}(2k, p)\)。

  • 时间上的贝叶斯定理（Bayes’ theorem）。\(\mathrm{P}(X_1 = 2 \mid X_2 = 2)\) 是由较后的观察结果逆向推断较早的状态。

  • 条件期望值（conditional expectation）。以上一代的情况为条件，期望值就化成一个等比数列（geometric sequence）。

背后的数学

灭绝的概率

当 \(p = \frac34\) 时，粒子总数的期望值无止境地增长。这是否表示群体一定能存活下去？不一定：如果第一个粒子没有后代（概率为 \(q^2 = \frac{1}{16}\)），这个族系便立即终结。设 \(e\) 为最终灭绝的概率。第一个粒子有 \(k\) 个后代，而每个后代的族系各自独立地以概率 \(e\) 灭绝，所以 \[e = q^2 + 2pq\,e + p^2e^2 = (q + pe)^2 = \mathrm{G}(e),\] 其中 \(\mathrm{G}(s) = (q + ps)^2\) 是后代数目的概率生成函数（probability generating function）。灭绝概率是 \(\mathrm{G}\) 的一个不动点：事实上是最小的非负不动点。当 \(p = \frac34\) 时，由 \((1 + 3e)^2 = 16e\) 得 \(9e^2 - 10e + 1 = 0\)，所以 \(e = \frac19\) 或 \(1\)，而灭绝概率是 \(\frac19\)。当 \(p = \frac14\) 时，在 \([0, 1]\) 内唯一的不动点是 \(e = 1\)：灭绝是必然的（图 12.15.1）。

临界门槛

一般而言，如果后代数目的平均值小于 \(1\)，分支过程必然灭绝；平均值等于 \(1\) 时也是如此，唯一的例外是每个个体都恰好有一个后代的平凡情况（这时族系只是一个接一个地永远延续下去）；如果平均值大于 \(1\)，则分支过程以正概率存活下去。后代数目的平均值就是流行病学中的繁殖数（reproduction number）\(R\)：\(R > 1\) 的疫症有可能大规模爆发，但即使如此，早期的爆发仍可能纯粹因为偶然而无疾而终，其概率正好由上面的不动点方程给出。在核物理学中，如果每次裂变平均恰好引发另一次裂变，连锁反应就处于临界（critical）状态，而操作反应堆的学问，就在于让它一直保持在这个状态。

高尔顿、Watson 与 Bienaymé

高尔顿的问题在 1874 年由 Henry William Watson 牧师作答，但答案有部分是错的：他找到了不动点方程，却漏掉了第二个根，因而断定每个姓氏最终都会失传。其实正确的分析早在 1845 年已由法国统计学家 Irénée-Jules Bienaymé 提出，只是他的研究一直被人遗忘，直到 1970 年代才重见天日。这个模型现在称为高尔顿–Watson 过程（Galton–Watson process，有时称为 Bienaymé–Galton–Watson 过程），是每一门随机过程（random processes）课程中的核心例子。

思维技巧

以第一代为条件

一个会自我更新的过程（每个后代都开始一个独立的、与整个过程相同的复本），必定满足一条以第一步为条件而得出的方程。

方程 \(e = \mathrm{G}(e)\) 是一个不动点问题，与 第 2.2 节 和 第 8.7 节 中遇到的属同一类。在大学里，生成函数和不动点是研究分支过程、随机树和随机网络的主要工具。

延伸练习

  1. 一般情况下的灭绝。设后代数目的分布为 \(\mathrm{B}(2, p)\)，证明当 \(p \leq \frac12\) 时灭绝概率为 \(1\)，而当 \(p > \frac12\) 时灭绝概率为 \(\bigl(\frac qp\bigr)^2\)。

  2. 方差（variance）。证明 \(\mathrm{Var}(X_n)\) 满足 \(\mathrm{Var}(X_n) = (2p)^2\mathrm{Var}(X_{n-1}) + 2pq\,\mathrm{E}(X_{n-1})\)，并求 \(p = \frac12\) 时的方差。

  3. 在第 \(n\) 代或之前灭绝。设 \(e_n = \mathrm{P}(X_n = 0)\)。证明 \(e_n = \mathrm{G}(e_{n-1})\)，并就 \(p = \frac34\) 计算 \(e_1\)、\(e_2\)、\(e_3\)。它们是否趋近 \(\frac19\)？

  4. 姓氏。如果每个男人有 \(0\)、\(1\)、\(2\) 或 \(3\) 个儿子的概率各为 \(\frac14\)，他的姓氏最终失传的概率是多少？

延伸阅读

  • Geoffrey Grimmett & David Stirzaker, Probability and Random Processes（Oxford University Press），论分支过程的一节。

  • Adam Kucharski, The Rules of Contagion（Profile）。讲述繁殖数与疫症爆发，适合一般读者。

  • David Kendall, “Branching processes since 1873”，Journal of the London Mathematical Society 41 (1966)。讲述这段历史，包括 Bienaymé 的贡献。
