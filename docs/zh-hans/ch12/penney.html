12.8

Penney 游戏

工作纸题目连结、提示、大学数学及练习 第 12 章整章的 PDF 版本
题目

STEP III 2001，第 13 题

继续之前，请先阅读题目（原题为英文）。题目载于 STEP Support Programme 的题目资料库： step.maths.org/questions/01-s3-q13

引子

你和朋友各自选定一个由三次掷硬币结果组成的序列，然后不断掷硬币，直至其中一个序列出现为止。在任何一个时刻，每个三次投掷的序列出现的机会都相同，那么无论选哪一个，理应同样好吧？完全不是。无论朋友选哪个序列，你都可以选出一个胜过它的序列，胜算（odds）有时更高达 \(7\) 比 \(1\)。

这就是 Penney 游戏（Penney’s game），由 Walter Penney 于 1969 年发明。本题要证明 \(A\) 胜 \(B\)，\(B\) 胜 \(C\)，\(C\) 胜 \(D\)，而 \(D\) 又胜 \(A\)：这是一个循环，就像包剪揼一样。“胜过”这种关系并不具传递性（transitive）。长远而言，后选的一方总能胜出。

动笔之前

假设至今的投掷结果以 TT 结尾，而且仍未有人胜出。THH 有没有可能比 TTH 先出现？

从 TT 出发，之后每掷出一个 T，最后两次投掷仍然是 TT，而第一个 H 一出现就凑成 TTH。要 THH 出现，必须先有 TH，而 TH 只能由一个 T 后接一个 H 而来，但这个 H 已经凑成了 TTH。所以 TT 一旦出现，\(A\) 必胜。

逐步解题

阶段 1 状态

两个序列都不可能在两次投掷内完成。掷了两次之后，从每个状态（state）出发，下一次投掷会带来甚么结果？

由于游戏只取决于最后两次投掷，我们可以追踪状态（即最后两次投掷的结果）：

  • 从 TT 出发：\(A\) 胜（上面已证），所以 \(p_{\mathrm{TT}} = 1\)。

  • 从 HT 出发：下一次投掷会得出 TH 或 TT，所以 \(p_{\mathrm{HT}} = \frac12p_{\mathrm{TH}} + \frac12p_{\mathrm{TT}}\)。

  • 从 TH 出发：掷出 H 便凑成 THH（\(B\) 胜）；掷出 T 则得出 HT。所以 \(p_{\mathrm{TH}} = \frac12 \cdot 0 + \frac12p_{\mathrm{HT}}\)。

  • 从 HH 出发：掷出 H 仍是 HH；掷出 T 则得出 HT。所以 \(p_{\mathrm{HH}} = \frac12p_{\mathrm{HH}} + \frac12p_{\mathrm{HT}}\)，由此得 \(p_{\mathrm{HH}} = p_{\mathrm{HT}}\)。

阶段 2 求解

把 \(p_{\mathrm{TH}} = \frac12p_{\mathrm{HT}}\) 代入 HT 的方程：\(p_{\mathrm{HT}} = \frac14p_{\mathrm{HT}} + \frac12\)，所以 \(p_{\mathrm{HT}} = \frac23\)、\(p_{\mathrm{HH}} = \frac23\) 及 \(p_{\mathrm{TH}} = \frac13\)。四个起始状态的概率（probability）各为 \(\frac14\)，所以 \[\mathrm{P}(A \text{ 胜}) = \tfrac14\bigl(\tfrac23 + \tfrac23 + \tfrac13 + 1\bigr) = \tfrac23. \qed\]

阶段 3 \(B\) 对 \(C\)

\(C\) 想要 HHT，\(B\) 想要 THH。\(C\) 在甚么情况下胜出？（留意第一个 HH 之前紧接着的必定是甚么。）

如果头两次投掷是 HH，那么其后第一个 T 便凑成 HHT，THH 来不及出现：\(C\) 胜。否则，在 HH 首次出现之前的某处必有一个 T，因此第一个 HH 的前一次投掷必定是 T：THH 就在那一刻出现，早于 HHT（HHT 还需要在 HH 之后再掷出一个 T）。所以只有当游戏以 HH 开始时 \(C\) 才会胜出： \[\mathrm{P}(B \text{ 胜}) = \tfrac34. \qed\]

阶段 4 循环

用同样的方法（或“背后的数学”一节的捷径）可以证明 \(C\)（HHT）胜 \(D\)（HTT）的概率是 \(\frac23\)，而 \(D\)（HTT）胜 \(A\)（TTH）的概率是 \(\frac34\)；后者正是第 3 阶段把正面与反面对调后的镜像。所以 \[A \text{ 胜 } B, \qquad B \text{ 胜 } C, \qquad C \text{ 胜 } D, \qquad D \text{ 胜 } A. \qed\]

回顾

  • 选对状态。只有最后两次投掷才有影响，所以四个状态、四条方程便概括了整个游戏。

  • 首步分析（first-step analysis）。每条方程都是以下一次投掷为条件：从某状态出发的概率，就是下一次投掷所到达的各个状态的概率的平均值。

  • 找出决定性的事件。在第 3 阶段，“第一个 HH 之前是 T”这一点无须列方程便决定了胜负。

背后的数学

为甚么有些序列较好

在任何一个位置，所有三次投掷的序列出现的机会都相同，而每个序列的期望等待时间（expected waiting time）也不难计算。但各序列的等待时间并不相同：TTH 平均要等 \(8\) 次投掷，TTT 却要等 \(14\) 次，因为与自身重叠的序列（例如 TTT，只差一步的 TTH 会令已累积的两次投掷前功尽废）出现得较慢。而在两个序列的竞赛中，关键在于每个序列与对方如何重叠。THH 胜 HHT，是因为 HHT 每次出现（除了在最开头之外），前面都有一个 T，这表示 THH 刚刚已经出现。后选一方的窍门总是一样：取对手序列的头两个符号，再在前面加上与对手中间符号相反的那个符号。

康威公式（Conway’s formula）

约翰·康威发现了一条计算胜算的绝妙公式。对于长度为 \(n\) 的两个序列 \(X\) 和 \(Y\)，定义相关数（correlation）\(XY\) 为一个 \(n\) 位的二进制数：由左至右，若 \(X\) 中由第 \(i\) 个符号开始的部分与 \(Y\) 开头相同长度的部分相同，则第 \(i\) 位为 \(1\)。那么 \(Y\) 比 \(X\) 先出现的胜算是 \[(XX - XY) : (YY - YX).\] 取 \(X =\) HHT 及 \(Y =\) THH：\(XX = 100_2 = 4\)（只有整个 HHT 与自身吻合）；\(XY = 001_2 = 1\)（只有 HHT 末尾的 T 与 THH 的开头吻合）；\(YY = 100_2 = 4\)；而 \(YX = 011_2 = 3\)（THH 末尾的 HH 和 H 都与 HHT 的开头吻合）。所以 THH 先出现的胜算是 \((4 - 1) : (4 - 3) = 3 : 1\)，即第 3 阶段的 \(\frac34\)。康威公式适用于任何长度、任何字母表的序列，其证明用到鞅（martingale）的理论：想像有一间赌场，赌客就序列的出现下注，再利用公平游戏的期望利润为零这一事实。

Penney 与加德纳（Gardner）

Walter Penney 于 1969 年在 Journal of Recreational Mathematics 的一篇短文中介绍了这个游戏。马丁·加德纳于 1974 年在他的 Scientific American 专栏中介绍了它，使它广为人知，文中还包括康威公式，这条公式是康威发现的，但他一直没有发表。这类非传递关系（埃弗龙骰子（Efron’s dice）是另一个例子：骰子 \(A\) 胜 \(B\)，\(B\) 胜 \(C\)，\(C\) 胜 \(D\)，而 \(D\) 胜 \(A\)）一再令人惊讶，在投票理论中也很重要，因为多数人的偏好可以形成循环：这就是孔多塞悖论（Condorcet’s paradox）。

思维技巧

首步分析

若一个过程在各状态之间转移，要求出与它有关的概率或期望值（expectation），可以第一步为条件。这样每个状态都给出一条线性方程。

这是处理马可夫链（Markov chain）的基本技巧，你会在 第 12.16 节 以及大学概率课程中一再遇到。同样的方法可以求出先到达某一状态而非另一状态的概率、被吸收前的期望时间，以及赌博问题中的破产概率。

延伸练习

  1. 四人同场。试做 STEP II 2015，第 12 题：四名玩家同时参与的 Penney 游戏。

  2. 等待时间。证明直至 HH 首次出现的期望投掷次数是 \(6\)，而直至 HT 首次出现的则是 \(4\)。（使用首步分析。）

  3. 最佳对策。对于八个长度为三的序列，逐一找出以最大概率胜过它的序列。哪个序列最容易被击败？

  4. 康威公式。用康威公式验证 HHT 胜 HTT 的概率是 \(\frac23\)。
