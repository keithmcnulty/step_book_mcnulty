第 13 章 · 统计与现实世界中的随机性

延伸练习答案

以下只是简短的答案和提示，并非完整解答：这里只给出结果和关键步骤，方便你核对自己的做法。每道练习都应先认真做过，然后才看答案。

13.1 解读新闻标题

  1. \(1 - \sum_{k=0}^{6}\mathrm{e}^{-2.96}\frac{2.96^k}{k!} \approx 0.0315\)，所以一年之中大约有 \(11\) 天会出现七宗或以上的死亡个案。\(\mathrm{P}(X \geq 9) \approx 0.0035\)：大约一年一天。

  2. 死亡人数为 \(150K\)，其中 \(K\) 服从平均值（mean）为 \(1.2\) 的泊松分布（Poisson distribution）：平均值为 \(180\)，方差（variance）为 \(150^2 \times 1.2 = 27\,000\)，标准差（standard deviation）约为 \(164\)。死亡人数为 \(125\) 或以下的年份，就是没有发生空难的年份，其概率为 \(e^{-1.2} \approx 0.30\)：完全是寻常事。但在这个模型中，死亡人数不可能恰好是 \(125\)，因为死亡人数只能是 \(150\) 的倍数。平均值和标准差都显示不出这一点：个案扎堆出现，令分布变得一团一团，全部概率都集中在 \(0\)、\(150\)、\(300\) 等数值上。

  3. \(z = \frac{1349.5 - 1080}{33} \approx 8.2\)：概率的数量级为 \(10^{-16}\)。稳定不变的发生率无法解释 \(1350\) 这个数字；必定是有些事情真的改变了（又或者是统计死亡人数的方法改变了）。

  4. 例如：(i)“单凭总数，无法判断乘飞机与步行哪样较安全”；(ii)“1990 年空难死亡人数属正常范围”；(iii)“星期二七名行人死亡：不幸的一天，但这样的日子一年约有十一次”；(iv)“1990 年行人死亡人数急升：必须追查原因”。

13.2 计数田鼠

  1. \(\frac{p_N}{p_{N-1}} = \frac{(N - M)(N - C)}{N(N - M - C + R)}\)，而这个比值不小于 \(1\)，当且仅当 \(NR \leq MC\)。所以 \(p_N\) 一直递增至 \(N = \frac{MC}{R}\)，然后递减，而最大值就在该数的整数部分取得。

  2. 从 \(a\) 名女性和 \(b\) 名男性中选出 \(c\) 人组成委员会，按其中女性的人数 \(j\) 来数：对每个 \(j\)，共有 \(\binom aj\binom{b}{c - j}\) 种。

  3. \(\frac{\mathrm{d}}{\mathrm{d}p}\bigl(h\ln p + (n - h)\ln(1 - p)\bigr) = \frac hp - \frac{n - h}{1 - p} = 0\) 给出 \(p = \frac hn\)。

  4. 当 \(R = 0\) 时，\(p_N\) 永远递增，估计值是无限大。这个方法只有在第二个样本中有足够多已标记的动物时才行得通；重复捕获的数目少的话，估计值会非常不稳定。

13.3 德国坦克问题

  1. 设 \(M\) 为最大值，则 \(\mathrm{E}(M) = \frac{nN}{n + 1}\) 及 \(\mathrm{Var}(M) = \frac{nN^2}{(n + 1)^2(n + 2)}\)，所以 \(\mathrm{E}(M - N)^2 = \frac{2N^2}{(n + 1)(n + 2)}\)。这是 \(\mathrm{Var}(Z_1) = \frac{N^2}{n(n + 2)}\) 的 \(\frac{2n}{n + 1}\) 倍：较差。最佳的倍数是 \(c = \frac{N\mathrm{E}(M)}{\mathrm{E}(M^2)} = \frac{n + 2}{n + 1}\)，其均方误差（mean squared error）为 \(\frac{N^2}{(n + 1)^2}\)，比 \(Z_1\) 稍佳。

  2. \(\mathrm{E}(\min) = \frac{N}{n + 1}\)，而 \(\min\) 的方差与 \(M\) 的相同，所以 \(\mathrm{Var}\bigl((n + 1)\min\bigr) = \frac{nN^2}{n + 2}\)。这个方差不会随 \(n\) 增大而缩小：是个差劣的估计量（estimator）。

  3. 最大值不超过 \(m\)，当且仅当全部 \(k\) 个数都来自 \(\{1, \ldots, m\}\)。当 \(k = 1\) 时，估计量是 \(2X - 1\)，其平均值为 \(2 \cdot \frac{N + 1}{2} - 1 = N\)。

  4. \(98 + \frac{98}{5} - 1 = 116.6\)：大约 \(117\) 辆坦克。

13.4 平均数还是中位数？

  1. 先选定哪一个值是中位数（median）（有 \(2n + 1\) 种选法），再选定其余各值中哪 \(n\) 个在它之下（有 \(\binom{2n}{n}\) 种选法）。所求概率为 \((2n + 1)\binom{2n}{n}y^n(1 - y)^n\,\delta y = \frac{(2n + 1)!}{(n!)^2}y^n(1 - y)^n\,\delta y\)。

  2. \(\mathrm{Var}(Y) = \frac{1}{4(2n + 3)} = \frac{1}{20}\) 及 \(\mathrm{Var}(\bar X) = \frac{1}{12(2n + 1)} = \frac{1}{36}\)。平均值较佳。

  3. \(\mathrm{Var}(\max) = \mathrm{Var}(\min) = \frac{m}{(m + 1)^2(m + 2)}\) 及 \(\mathrm{Cov}(\max, \min) = \frac{1}{(m + 1)^2(m + 2)}\)，由此得出 \(\frac{1}{2(m + 1)(m + 2)}\)。它缩小的速度与 \(\frac{1}{m^2}\) 同阶，远快于平均值的 \(\frac{1}{12m}\)：对于均匀分布（uniform distribution）的数据，信息都在极端值之中，与坦克问题的情况一样。

  4. 平均值约为 \(18.6\)，被一个打字错误完全破坏；中位数是 \(10.1\)，不受影响。

13.5 问尴尬的问题

  1. 设 \(t = ap + bq\)，即答案属实的概率。回答“是”的概率为 \(\frac12t + \frac12(1 - t) = \frac12\)，所以 \(\mathrm{P}(\text{正面} \mid \text{是}) = t\)，而它等于 \(\frac12\)，当且仅当 \(2t = 1\)。若由同一名孪生儿回答两次，则不论硬币掷出的是正面还是反面，先答“是”后答“否”的概率都是 \(pa(1 - a) + qb(1 - b)\)，所以后验概率（posterior probability）是 \(\frac12\)。两次都答“是”的概率分别为 \(pa^2 + qb^2\)（正面）和 \(p(1 - a)^2 + q(1 - b)^2\)（反面），两者相等当且仅当 \(2(ap + bq) = 1\)。

  2. \(\mathrm{P}(\text{是}) = \frac34\pi + \frac14(1 - \pi)\)，所以 \(\hat\pi = \frac{0.4 - 0.25}{0.5} = 0.3\)。标准误（standard error）为 \(\frac{\sqrt{0.4 \times 0.6/400}}{0.5} \approx 0.049\)。

  3. \(\mathrm{E}(Y^2) = \sum_c\mathrm{P}(C = c)\bigl(\mathrm{Var}(Y \mid c) + \mathrm{E}(Y \mid c)^2\bigr)\)；减去 \(\mathrm{E}(Y)^2 = \bigl(\sum_c\mathrm{P}(C = c)\mathrm{E}(Y \mid c)\bigr)^2\) 便得 \(\mathrm{E}(\mathrm{Var}(Y \mid C)) + \mathrm{Var}(\mathrm{E}(Y \mid C))\)。

  4. \(Z_2\) 接近 \(\frac n6\)（正面）或 \(\frac{5n}{6}\)（反面），两种情况的概率各为 \(\frac12\)。所以 \(\mathrm{P}(Z_2 > \frac n2) \to \frac12\)，尽管 \(Z_2\) 几乎从不接近 \(\frac n2\)。

13.6 累积起来的误差

  1. 每个截尾误差（truncation error）都在 \((-1, 0]\) 上均匀分布；各加上 \(\frac12\) 后，便在 \((-\frac12, \frac12]\) 上均匀分布，与四舍五入（rounding）的情况完全一样。所以修正后的 VOZ 与 LEP 一样好。

  2. 每个误差都在 \((-0.05, 0.05)\) 上均匀分布，方差为 \(\frac{0.1^2}{12}\)，所以总和的标准差为 \(\sqrt{10\,000 \times 0.01/12} \approx 2.9\)。

  3. \(3000 \times 250 \times 0.0005 = 375\) 点。

  4. 两个误差时，是 \([-1, 1]\) 上的 \(1 - |x|\)。三个误差时：当 \(|x| \leq \frac12\) 时为 \(\frac34 - x^2\)，当 \(\frac12 \leq |x| \leq \frac32\) 时为 \(\frac12\bigl(\frac32 - |x|\bigr)^2\)，已经很接近正态曲线（normal curve）。

13.7 制造相关性

  1. 对于标准化变量（standardised variables），\(\mathrm{Var}(X_1 + X_2 + X_3) = 3 + 6\rho \geq 0\)，所以 \(\rho \geq -\frac12\)。对于 \(n\) 个变量，\(n + n(n - 1)\rho \geq 0\) 给出 \(\rho \geq -\frac{1}{n - 1}\)。

  2. 取 \(b = \frac{\rho_{23} - \rho_{12}\rho_{13}}{\sqrt{1 - \rho_{12}^2}}\)，则 \((1 - \rho_{12}^2)(1 - \rho_{13}^2 - b^2) = 1 - \rho_{12}^2 - \rho_{13}^2 - \rho_{23}^2 + 2\rho_{12}\rho_{13}\rho_{23} = \det R\)。由于 \(1 - \rho_{12}^2 > 0\)，这两个条件等价。

  3. \(\mathrm{Var} = \frac14(0.04 + 0.09 + 0.12\rho)\)：当 \(\rho = -1\)、\(0\)、\(1\) 时，标准差分别为 \(0.05\)、\(0.18\) 和 \(0.25\)。除非两只股票完全相关（perfectly correlated），否则这个组合的风险低于两者风险的平均值（\(0.25\)）。

  4. \(Z_2 = \dfrac{Y_2 - \rho_{12}Y_1}{\sqrt{1 - \rho_{12}^2}}\)。
