隐私

Beyond STEP 是一本免费书籍。阅读时毋须登记帐户，本网站亦不会索取或储存任何个人资料。

分析工具

如果你同意，本网站会使用 Google Analytics（评估 ID：G-M8RDPR4MXR）统计浏览情况：哪些页面有人阅读、哪些 PDF 及工作纸被下载、访客在网站内搜索甚么，以及访客的大致来源（国家、装置类型、连结至本站的网站）。为此，Google Analytics 会在你的浏览器内设置 cookie。这些资料只会用于了解本书哪些部分有用，以及用于改善本书；不会用于广告用途，亦不会与任何其他数据合并。

英国法律（《隐私及电子通讯规例》（Privacy and Electronic Communications Regulations）及英国《通用数据保障条例》（UK GDPR））规定，在设置分析 cookie 等非必要 cookie 之前，必须先取得同意，因此本网站会先征求你的同意。除非你选择“接受”，否则本网站不会收集任何资料。如果你选择“拒绝”，或者没有作出选择，Google Analytics 的程序码便绝不会载入，亦不会设置任何分析 cookie。你的选择会储存在浏览器的本机储存空间内，这样便毋须在每一页再次询问。

你可以随时通过每页底部的 cookie 设置连结更改决定；撤回同意后，分析 cookie 会被移除。Google 本身的隐私权政策载于 policies.google.com/privacy。

电子通讯

首页的登记栏只会在你按下“订阅”时，才把你输入的电子邮件地址传送至营运 The STEP Up 的 Substack。在此之前，本网站不会从 Substack 载入任何内容。Substack 本身的隐私政策载于 substack.com/privacy。

网站寄存

本网站寄存于 GitHub Pages。与任何网页伺服器一样，GitHub Pages 会基于保安理由，在伺服器记录中记下 IP 位址等基本技术资料。详情请参阅 GitHub 的隐私声明。数学公式以 MathJax 显示，搜索页面则使用 MiniSearch 程序库；两者均从 jsDelivr 内容传递网络载入。
