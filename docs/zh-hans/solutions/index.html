详细解答

1987 至 2025 年每一道 STEP 题目的详细解答，每份均为可列印的 PDF。

打开解答之前，请先认真尝试解题：STEP 的收获来自苦思的过程，太早看解答，所学到的远不及苦思一小时后才看那么多。每份解答均以关键思路开首，因此你可以只读这一部分，然后回到题目再试。

本站不会转载题目本身。每个题目连结均通往官方来源：2018 年或以前的试卷连往 STEP Support Programme 的题目资料库，2019 年起的试卷则连往 OCR 的下载页面（该年度试卷的 zip 文件）。如果某道题目在书中有完整的引导式讲解，§ 连结会带你前往该节，当中有提示、工作纸及题目背后的大学数学。

每一年的解答亦另有合订本，附有封面、目录，以及该年度试卷的全部解答：请使用该年度标题下方的连结。

每个答案均已用数值方法核对，但解答数量如此之多，难免会有疏漏：如果发现有可疑之处，请相信自己的演算，并仔细检查。 如有更正，非常欢迎以 GitHub issues 的形式提出。
