Beyond STEP

数学符号

下载 PDF专为列印而排版

数学写作往往以寥寥几个记号承载丰富的意思，而大学讲师所用的许多符号，在中学课本里甚少出现。下面各表按主题列出本书用到的符号，并说明每个符号的含义和读法。入读大学后不出几个星期，其中大部分都会变得习以为常；在此之前，这里可供你随时查阅。

有两项惯例值得一开始就知道。第一，本书依照 STEP 的做法，把某些具有固定含义的字母印成正体而非斜体：\(\mathrm{e}\) 表示自然对数的底，\(\mathrm{i}\) 表示 \(\sqrt{-1}\)，\(\mathrm{d}y/\mathrm{d}x\) 中的 \(\mathrm{d}\)，以及函数的名称，例如 \(\mathrm{f}(x)\) 和 \(\mathrm{P}(A)\)。斜体字母则表示变量。第二，同一个符号在不同场合有时会有不同的意思；\(\equiv\) 和 \(\sim\) 是最常见的例子，表中会在相应位置指出。

逻辑与证明

符号 含义 例子或读法
\(P \Rightarrow Q\) \(P\) 蕴含（implies）\(Q\)：若 \(P\) 成立，则 \(Q\) 亦成立 \(x = 2 \Rightarrow x^2 = 4\)；“\(P\) 蕴含 \(Q\)”
\(P \Leftarrow Q\) \(P\) 由 \(Q\) 所蕴含 “只要 \(Q\) 成立，\(P\) 就成立”
\(P \iff Q\) \(P\) 当且仅当（if and only if）\(Q\)：两者互相蕴含 \(x^2 = 4 \iff x = \pm2\)；亦写作“iff”
\(\forall\) 对所有、对每一个 \(\forall x \in \mathbb{R},\ x^2 \geq 0\)
\(\exists\) 存在 \(\exists\, n \in \mathbb{Z}\) 使得 \(n^2 = 9\)
\(\neg P\) 非 \(P\)，即 \(P\) 的否定（negation） “\(\forall x,\ P(x)\)”的否定是“\(\exists\, x\) 使得 \(\neg P(x)\)”
\(:=\) 定义为 \(\mathrm{f}(x) := x^2 + 1\)
\(\blacksquare\) 证明完毕；亦写作 QED 源自拉丁文 quod erat demonstrandum，意即“这就是所要证明的”

集合与数系

符号 含义 例子或读法
\(\{\,\ldots\}\) 由所列元素组成的集合（set） \(\{1, 2, 3\}\)
\(\{x : \ldots\}\) 所有满足 … 的 \(x\) 所组成的集合；亦写作 \(\{x \mid \ldots\}\) \(\{x : x^2 < 2\}\)；“满足 \(x^2 < 2\) 的 \(x\) 所组成的集合”
\(x \in A\) \(x\) 是 \(A\) 的元素（element） \(\sqrt2 \in \mathbb{R}\)；“\(\sqrt2\) 属于 \(\mathbb{R}\)”
\(x \notin A\) \(x\) 不是 \(A\) 的元素 \(\sqrt2 \notin \mathbb{Q}\)
\(A \subseteq B\) \(A\) 是 \(B\) 的子集（subset）：\(A\) 的每个元素都在 \(B\) 之内 \(\mathbb{Z} \subseteq \mathbb{Q}\)
\(A \cup B\) 并集（union）：属于 \(A\) 或 \(B\)（或同时属于两者）的元素 \(\{1, 2\} \cup \{2, 3\} = \{1, 2, 3\}\)
\(A \cap B\) 交集（intersection）：同时属于 \(A\) 和 \(B\) 的元素 \(\{1, 2\} \cap \{2, 3\} = \{2\}\)
\(A \setminus B\) 属于 \(A\) 但不属于 \(B\) 的元素 \(\{1, 2, 3\} \setminus \{2\} = \{1, 3\}\)
\(A'\) 补集（complement）：所有不属于 \(A\) 的元素 亦写作 \(A^\mathrm{c}\) 或 \(\bar A\)
\(\varnothing\) 空集（empty set），不含任何元素 \(\{x \in \mathbb{R} : x^2 < 0\} = \varnothing\)
\(|A|\) 有限集 \(A\) 的元素个数 \(|\{a, b, c\}| = 3\)
\(A \times B\) 所有数对 \((a, b)\) 所组成的集合，其中 \(a \in A\)，\(b \in B\) \(\mathbb{R} \times \mathbb{R}\) 就是平面，亦写作 \(\mathbb{R}^2\)
\(\mathbb{N}\) 自然数（natural numbers）\(1, 2, 3, \ldots\) 有些作者把 \(0\) 也算在内
\(\mathbb{Z}\) 整数（integers）\(\ldots, -2, -1, 0, 1, 2, \ldots\) 源自德文 Zahlen，意即“数”
\(\mathbb{Q}\) 有理数（rational numbers），即分数 源自 quotient 一字
\(\mathbb{R}\) 实数（real numbers）
\(\mathbb{C}\) 复数（complex numbers）
\(\mathbb{H}\) 四元数（quaternions） 以哈密顿（Hamilton）命名（第 6.7 节）
\(\mathbb{Z}[\mathrm{i}]\) 形如 \(a + b\mathrm{i}\) 的数，其中 \(a, b \in \mathbb{Z}\) 高斯整数（Gaussian integers）（第 1.6 节）
\([a, b]\) 闭区间（closed interval）：\(a \leq x \leq b\) 包含端点
\((a, b)\) 开区间（open interval）：\(a < x < b\) 不包含端点；亦可表示数对或点

数、整除性与近似

符号 含义 例子或读法
\(a \mid b\) \(a\) 整除（divides）\(b\)：\(b\) 是 \(a\) 的整数倍 \(3 \mid 12\)；“\(3\) 整除 \(12\)”
\(a \nmid b\) \(a\) 不整除 \(b\) \(5 \nmid 12\)
\(a \equiv b \pmod n\) \(a\) 与 \(b\) 除以 \(n\) 所得的余数相同 \(17 \equiv 2 \pmod 5\)；“\(17\) 与 \(2\) 模 \(5\) 同余（congruent）”
\(\equiv\) （不带模时）恒等于：对所有值都成立 \((x + 1)^2 \equiv x^2 + 2x + 1\)
\(\lfloor x \rfloor\) 下取整（floor）：\(\leq x\) 的最大整数 \(\lfloor 3.7 \rfloor = 3\)，\(\lfloor -3.7 \rfloor = -4\)
\(\lceil x \rceil\) 上取整（ceiling）：\(\geq x\) 的最小整数 \(\lceil 3.2 \rceil = 4\)
\(n!\) \(n\) 的阶乘（factorial），即 \(1 \times 2 \times \cdots \times n\) 按惯例 \(0! = 1\)
\(\binom{n}{r}\) 二项式系数（binomial coefficient）\(\frac{n!}{r!\,(n - r)!}\) 读作“\(n\) choose \(r\)”；亦写作 \({}^n\mathrm{C}_r\)
\(\approx\) 约等于 \(\pi \approx 3.1416\)
\(\sim\) 渐近于（asymptotic to）：两者之比趋向 \(1\) \(n! \sim \sqrt{2\pi n}\,(n/\mathrm{e})^n\)（但另见概率部分）
\(\propto\) 与……成正比 \(v \propto 1/d\)
\(\pm\), \(\mp\) 正负；负正 \(\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B\)
\(0.\overline{01}\) 循环数字 \(0.\overline{01} = 0.010101\ldots\)

函数

符号 含义 例子或读法
\(\mathrm{f} : A \to B\) \(\mathrm{f}\) 是由集合 \(A\) 到集合 \(B\) 的函数（function） \(\mathrm{f} : \mathbb{R} \to \mathbb{R}\)
\(x \mapsto \ldots\) \(x\) 被送到 … \(x \mapsto x^2 - 2\)；“\(x\) 映射到 \(x^2 - 2\)”
\(\mathrm{f} \circ \mathrm{g}\) 复合（composition）：先作 \(\mathrm{g}\)，再作 \(\mathrm{f}\) \((\mathrm{f} \circ \mathrm{g})(x) = \mathrm{f}(\mathrm{g}(x))\)
\(\mathrm{f}^{-1}\) \(\mathrm{f}\) 的反函数（inverse function） 并非 \(1/\mathrm{f}\)
\(\mathrm{f}^n\) 在本书中，通常指把 \(\mathrm{f}\) 施行 \(n\) 次 \(\mathrm{f}^3(x) = \mathrm{f}(\mathrm{f}(\mathrm{f}(x)))\)；但 \(\sin^2 x\) 表示 \((\sin x)^2\)
\(|x|\) 模（modulus），或绝对值 \(|-3| = 3\)
\(\exp x\) 指数函数（exponential function）\(\mathrm{e}^x\)
\(\ln x\) 自然对数（natural logarithm），以 \(\mathrm{e}\) 为底 在大学里常写作 \(\log x\)
\(\sec\), \(\mathrm{cosec}\), \(\cot\) \(1/\cos\), \(1/\sin\), \(1/\tan\)
\(\arcsin\), \(\arccos\), \(\arctan\) 反三角函数 亦写作 \(\sin^{-1}\) 等
\(\sinh\), \(\cosh\), \(\tanh\) 双曲函数（hyperbolic functions）：\(\sinh x = \frac12(\mathrm{e}^x - \mathrm{e}^{-x})\)，\(\cosh x = \frac12(\mathrm{e}^x + \mathrm{e}^{-x})\)，\(\tanh = \sinh/\cosh\) 读作“shine”（或“sinch”）、“cosh”和“than”（或“tanch”）
\(\operatorname{artanh}\) \(\tanh\) 的反函数 \(\operatorname{artanh} x = \frac12\ln\frac{1 + x}{1 - x}\)
\(\max\), \(\min\) 当中最大者、最小者 \(\max(3, 7) = 7\)
\(\Gamma(x)\) 伽玛函数（gamma function） \(\Gamma(n + 1) = n!\)（第 4.4 节）

求和、极限与微积分

符号 含义 例子或读法
\(\sum\) 求和 \(\sum_{k=1}^n k = \frac12n(n + 1)\)
\(\prod\) 求积 \(\prod_{k=1}^n k = n!\)
\(\infty\) 无穷大：并不是一个数，而是“没有界限”的简写 \(\sum_{k=1}^\infty \frac1{k^2} = \frac{\pi^2}{6}\)
\(x \to a\) \(x\) 趋向 \(a\) 当 \(n \to \infty\) 时，\(\frac1n \to 0\)
\(\lim\) 极限（limit） \(\lim_{x\to0}\frac{\sin x}{x} = 1\)
\(\mathrm{f}'(x)\), \(\mathrm{f}''(x)\) 一阶及二阶导数（derivative） 读作“f dash”或“f prime”
\(\dot x\), \(\ddot x\) 对时间的导数 \(\dot x = \frac{\mathrm{d}x}{\mathrm{d}t}\)；读作“\(x\) dot”、“\(x\) double dot”
\(\frac{\partial f}{\partial x}\) 偏导数（partial derivative）：对 \(x\) 求导，其他变量保持不变 读作“partial \(f\) by partial \(x\)”
\(\int_a^b\) 由 \(a\) 到 \(b\) 的定积分（definite integral）
\(\oint\) 沿闭合回路的积分 \(\oint p\,\mathrm{d}q\)（第 10.4 节）
\(\delta x\), \(\Delta x\) \(x\) 的微小变化；\(x\) 的变化
\(\varepsilon\), \(\delta\) 分析学中惯常用来表示细小正数的记号 “对每个 \(\varepsilon > 0\)，都存在 \(\delta > 0\) 使得 …”

复数

符号 含义 例子或读法
\(\mathrm{i}\) \(-1\) 的一个平方根 工程师写作 \(\mathrm{j}\)
\(\operatorname{Re} z\), \(\operatorname{Im} z\) 实部与虚部 若 \(z = 3 + 4\mathrm{i}\)，则 \(\operatorname{Re} z = 3\)，\(\operatorname{Im} z = 4\)
\(z^*\), \(\bar z\) 共轭复数（complex conjugate） \((3 + 4\mathrm{i})^* = 3 - 4\mathrm{i}\)；两种记法都有人使用
\(|z|\) 模：与 \(0\) 的距离 \(|3 + 4\mathrm{i}| = 5\)
\(\arg z\) 辐角（argument）：由正实轴量起的角 \(\arg \mathrm{i} = \frac\pi2\)
\(\mathrm{e}^{\mathrm{i}\theta}\) \(\cos\theta + \mathrm{i}\sin\theta\) \(\mathrm{e}^{\mathrm{i}\pi} = -1\)
\(\omega\) 惯常表示 1 的一个复立方根（cube root of unity） \(\omega = \mathrm{e}^{2\pi\mathrm{i}/3}\)，\(1 + \omega + \omega^2 = 0\)

向量与矩阵

符号 含义 例子或读法
\(\mathbf{a}\), \(\overrightarrow{AB}\) 向量（vector）；由 \(A\) 到 \(B\) 的向量 手写时作 \(\underline{a}\)
\(\hat{\mathbf{n}}\) 单位向量（unit vector），长度为 \(1\) 读作“\(n\) hat”
\(|\mathbf{a}|\) \(\mathbf{a}\) 的长度（大小）
\(\mathbf{a} \cdot \mathbf{b}\) 纯量积（scalar product），又称点积（dot product） \(\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos\theta\)
\(\mathbf{a} \times \mathbf{b}\) 向量积（vector product），又称叉积（cross product） 同时垂直于 \(\mathbf{a}\) 和 \(\mathbf{b}\)
\(\mathbf{M}\) 矩阵（matrix）
\(\mathbf{I}\) 单位矩阵（identity matrix） 对每个 \(\mathbf{v}\) 都有 \(\mathbf{I}\mathbf{v} = \mathbf{v}\)
\(\mathbf{M}^{-1}\) 逆矩阵（inverse matrix） \(\mathbf{M}\mathbf{M}^{-1} = \mathbf{I}\)
\(\det \mathbf{M}\) \(\mathbf{M}\) 的行列式（determinant） \(\det\begin{pmatrix} a & b \\ c & d\end{pmatrix} = ad - bc\)
\(\operatorname{tr} \mathbf{M}\) 迹（trace）：对角线上各元素之和 \(\operatorname{tr}\begin{pmatrix} a & b \\ c & d\end{pmatrix} = a + d\)
\(\lambda\) 惯常表示特征值（eigenvalue） \(\mathbf{M}\mathbf{v} = \lambda\mathbf{v}\)

概率与统计

符号 含义 例子或读法
\(\mathrm{P}(A)\) 事件 \(A\) 的概率（probability）
\(\mathrm{P}(A \mid B)\) 已知 \(B\) 发生时 \(A\) 的概率 \(\mathrm{P}(A \mid B) = \mathrm{P}(A \cap B)/\mathrm{P}(B)\)；读作“\(A\) given \(B\)”
\(\mathrm{E}(X)\) \(X\) 的期望值（expectation），即平均值 亦写作 \(\mu\)
\(\mathrm{Var}(X)\) \(X\) 的方差（variance） \(\mathrm{E}(X^2) - \mathrm{E}(X)^2\)；亦写作 \(\sigma^2\)
\(\mathrm{Cov}(X, Y)\) 协方差（covariance） \(\mathrm{E}(XY) - \mathrm{E}(X)\mathrm{E}(Y)\)
\(\mathrm{Corr}(X, Y)\) 相关系数（correlation） \(\mathrm{Cov}(X, Y)/\sqrt{\mathrm{Var}(X)\mathrm{Var}(Y)}\)；亦写作 \(\rho\)
\(X \sim \ldots\) \(X\) 的分布为 … \(X \sim \mathrm{B}(16, \frac12)\)；“\(X\) 的分布为 …”
\(\mathrm{B}(n, p)\) 二项分布（binomial distribution） \(n\) 次试验中成功的次数
\(\mathrm{N}(\mu, \sigma^2)\) 正态分布（normal distribution），平均值为 \(\mu\)，方差为 \(\sigma^2\)
\(\mathrm{f}(x)\), \(\mathrm{F}(x)\) 概率密度函数（probability density function）；累积分布函数（cumulative distribution function） \(\mathrm{F}(x) = \mathrm{P}(X \leq x)\)
\(\mathrm{G}(t)\) 概率生成函数（probability generating function） \(\mathrm{G}(t) = \mathrm{E}(t^X)\)
\(\mathrm{M}_X(\theta)\) 矩生成函数（moment generating function） \(\mathrm{M}_X(\theta) = \mathrm{E}(\mathrm{e}^{\theta X})\)
\(\bar x\) 样本的平均值 \(\bar x = \frac1n\sum x_i\)
\(\hat\theta\) 未知量 \(\theta\) 的估计值 读作“theta hat”

希腊字母

希腊字母在数学中随处可见，而且往往有约定俗成的含义。下表列出各字母的小写和大写形式（与罗马字母外形相同的大写字母，例如 alpha 的大写 A，不会用作独立的符号，故此从略）、名称，以及一些常见用途。

字母 名称 常见用途
\(\alpha\) alpha 角；方程的根
\(\beta\) beta 角；方程的根；贝塔函数（beta function）
\(\gamma\), \(\Gamma\) gamma 欧拉（Euler）常数 \(\gamma \approx 0.5772\)；伽玛函数 \(\Gamma\)；在相对论中，\(\gamma = 1/\sqrt{1 - v^2/c^2}\)
\(\delta\), \(\Delta\) delta 微小的量；\(\Delta\) 表示变化，或表示三角形、判别式（discriminant）
\(\varepsilon\), \(\epsilon\) epsilon 微小的正数量；在力学中表示相位角
\(\zeta\) zeta 黎曼（Riemann）zeta 函数，当 \(s > 1\) 时 \(\zeta(s) = \sum_{n=1}^\infty n^{-s}\)（以更高深的方法可推广至 \(s = 1\) 以外的其他值）
\(\eta\) eta 效率；微小的量
\(\theta\), \(\Theta\) theta 角；统计学中的未知参数
\(\iota\) iota 甚少使用
\(\kappa\) kappa 曲率；常数
\(\lambda\), \(\Lambda\) lambda 特征值；参数，例如泊松（Poisson）分布的率；波长
\(\mu\) mu 平均值；摩擦系数
\(\nu\) nu 频率
\(\xi\), \(\Xi\) xi 变量或随机量
\(\pi\), \(\Pi\) pi \(\pi \approx 3.14159\)；\(\Pi\) 表示求积
\(\rho\) rho 密度；相关系数；与原点的距离
\(\sigma\), \(\Sigma\) sigma 标准差；\(\Sigma\) 表示求和
\(\tau\) tau 时间；力矩
\(\upsilon\), \(\Upsilon\) upsilon 甚少使用
\(\phi\), \(\varphi\), \(\Phi\) phi 角；黄金比 \(\phi = \frac12(1 + \sqrt5)\)；快度（rapidity）；\(\Phi\) 表示标准正态分布函数
\(\chi\) chi \(\chi^2\)（卡方，chi-squared）分布
\(\psi\), \(\Psi\) psi 量子力学中的波函数
\(\omega\), \(\Omega\) omega 角速度或角频率；1 的立方根；\(\Omega\) 表示样本空间

力学

符号 含义 例子或读法
\(g\) 重力加速度 在地球表面约为 \(9.8\,\mathrm{m\,s^{-2}}\)
\(G\) 万有引力常数 两个质量之间的力为 \(Gm_1m_2/r^2\)
\(e\) 恢复系数（coefficient of restitution）（以斜体印刷，切勿与 \(\mathrm{e}\) 混淆） 沿碰撞线方向，分离速率 \(= e \times\) 接近速率
\(\omega\) 角速度；角频率 简谐运动（simple harmonic motion）中 \(\ddot x = -\omega^2x\)
\(I\) 转动惯量（moment of inertia） 转动动能 \(\frac12I\omega^2\)（第 11.7 节）
\(c\) 光速 约为 \(3 \times 10^8\,\mathrm{m\,s^{-1}}\)
\(\hbar\) 普朗克（Planck）常数除以 \(2\pi\) 读作“h bar”（第 8.6 节）
