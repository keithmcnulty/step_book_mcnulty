第 1 章 · 數論與證明

延伸練習答案

以下只是簡短的答案和提示，並非完整解答：只列出結果和關鍵步驟，方便你核對自己的做法。請先認真做過每一道練習，然後才看答案。

1.1 質數工廠

  1. 假設 \(p_1, \ldots, p_k\) 就是全部的質數（prime）；那麼 \(p_1\cdots p_k + 1\) 有一個不在此列之中的質因數（prime factor），矛盾（contradiction）。用費馬數（Fermat number）的證明則是構造性（constructive）的：它具體給出無窮多個兩兩互質（pairwise coprime）的數 \(F_0, F_1, \ldots\)，每一個都提供一個新的質數。

  2. 當 \(n \geq 2\) 時，\(2^n\) 是 \(4\) 的倍數，所以 \(2^{2^n} = 16^{2^{n-2}}\)，而 \(16\) 的任何次冪的末位數字都是 \(6\)。因此 \(F_n\) 的末位數字是 \(7\)。

  3. (a) 用歸納法（induction）：\(a_{n+1} - 1 = a_n(a_n - 1) = a_n \cdot a_1\cdots a_{n-1}\)。(b) \(a_m\) 與 \(a_n\)（\(m < n\)）的公因數必整除 \(a_1\cdots a_{n-1} = a_n - 1\) 和 \(a_n\)，所以只能是 \(1\)；每一項都有一個不與其他項共有的質因數。(c) \(\frac{1}{a_n} = \frac{1}{a_n - 1} - \frac{1}{a_{n+1} - 1}\)；求和時各項裂項相消（telescope），得 \(1 - \frac{1}{a_{n+1} - 1}\)。

  4. (a) 由 \(p \mid F_n\) 得 \(2^{2^n} \equiv -1\)；兩邊平方得 \(2^{2^{n+1}} \equiv 1\)。(b) 凡滿足 \(2^e \equiv 1\) 的 \(e\) 都能被 \(d\) 整除，所以 \(d \mid 2^{n+1}\)；又因為 \(2^{2^n} \equiv -1 \not\equiv 1\)（因 \(p\) 是奇數），所以 \(d \nmid 2^n\)。故 \(d = 2^{n+1}\)。(c) \(2^{p-1} \equiv 1\)，所以 \(2^{n+1} \mid p - 1\)。(d) \(641 = 64 \times 10 + 1\)。小於 \(641\) 而形如 \(64k + 1\) 的質數有 \(193\)、\(257\)、\(449\) 和 \(577\)：只需試四個候選數，歐拉（Euler）正是這樣找到 \(641\) 的。

  5. 第 \(n\) 個質數不會超過 \(F_0, \ldots, F_{n-1}\) 之中任何一個數的最大質因數，所以 \(p_n \leq F_{n-1} = 2^{2^{n-1}} + 1\)。當 \(n = 5\) 時，這個上界是 \(65\,537\)，而 \(p_5 = 11\)：結論正確，但極為粗疏。

1.2 質數分佈得有多稀疏？

  1. \(P_{1,10} = 210\)，\(P_{1,20} = 9\,699\,690\)，\(P_{1,30} = 6\,469\,693\,230\)。與 \(4^{30} \approx 1.15 \times 10^{18}\) 和 \(e^{30} \approx 1.07 \times 10^{13}\) 比較：這個乘積遠小於 \(4^n\)，增長速度大致與 \(e^n\) 相若（事實上 \(\ln P_{1,n} \sim n\)，這是質數定理（Prime Number Theorem）的一種形式）。

  2. \(\binom{2m}{k+1}\big/\binom{2m}{k} = \frac{2m - k}{k + 1}\)，此值大於 \(1\) 當且僅當 \(k < m\)，所以各係數先遞增至中間一項，然後遞減。\(2m + 1\) 項之和為 \(4^m\)，其中最大的一項至少等於它們的平均值。

  3. 區間 \((\sqrt n, n]\) 內的質數每個都大於 \(\sqrt n\)，而它們的乘積小於 \(4^n\)，所以 \((\sqrt n)^{\pi(n) - \pi(\sqrt n)} < 4^n\)；兩邊取對數（logarithm）。由於 \(2\ln4 \approx 2.77\) 且 \(\pi(\sqrt n) \leq \sqrt n\)，即得所求的上界。它具有正確的形式 \(n/\ln n\)，只是常數為 \(2.8\)，而非真正的 \(1\)。

  4. 取質數 \(2, 3, 5, 7, 13, 23, 43, 83\)，其中每一個都小於前一個的兩倍。對任意 \(n \leq 50\)，此列中第一個大於 \(n\) 的質數小於前一個質數的兩倍，而前一個質數不超過 \(n\)，所以它介乎 \(n\) 與 \(2n\) 之間。

1.3 最小反例

  1. 設 \(k\) 是使 \(k\sqrt3\) 為整數的最小正整數，則 \(k' = (\sqrt3 - 1)k\) 是一個更小的正整數，而且 \(k'\sqrt3 = 3k - k\sqrt3\) 是整數。這裏 \(\sqrt3 - 1\) 所起的作用，與 \(\sqrt2 - 1\) 相同。

  2. 由於 \(0 < \sqrt N - m < 1\)，\(k' = (\sqrt N - m)k\) 是一個小於 \(k\) 的正整數，而 \(k'\sqrt N = kN - mk\sqrt N\) 是整數：矛盾。

  3. 當 \(N = 4\) 時，\(m = 2 = \sqrt4\)，所以 \(\sqrt N - m = 0\)，而 \(k' = 0\) 並非正整數。「\(0 < \sqrt N - m\)」這一步不成立。

  4. 在圖中，邊長為 \(a\) 的正方形內有兩個邊長為 \(b\) 的正方形互相重疊，它們把中央一個邊長為 \(2b - a\) 的正方形覆蓋了兩次，並留下兩個邊長為 \(a - b\) 的正方形未被覆蓋。用代數表示，就是 \((2b - a)^2 - 2(a - b)^2 = 2b^2 - a^2 = 0\)。

1.4 \(e\) 是無理數，\(e^2\) 也是

  1. 若 \(\frac1e = \frac pq\)，把 \(\frac1e = \sum_{k \geq 0}\frac{(-1)^k}{k!}\) 乘以 \(q!\)。\(k \leq q\) 的各項都是整數，而尾部 \(\sum_{k > q}(-1)^kq!/k!\) 是各項遞減的交錯級數（alternating series），所以其絕對值嚴格介乎 \(0\) 與 \(\frac{1}{q+1}\) 之間。因此 \(q!/e\) 不是整數：矛盾。

  2. 若 \(\sin 1 = \frac pq\)，取 \(2n + 1 \geq q\)，兩邊乘以 \((2n + 1)!\)。左邊是整數，級數中直至 \(\frac{1}{(2n+1)!}\) 的各項也是整數；尾部是交錯級數，首項的大小為 \(\frac{1}{(2n+2)(2n+3)} < 1\)，所以它不是整數。

  3. 這個方法需要一個各項均為有理數（rational）的級數，而且其尾部縮小的速度要比分母增長的速度快，就像 \(\frac{1}{k!}\) 那樣；對於 \(\pi\)，目前並不知道有這樣的級數。Niven 的證明用到 \(\int_0^\pi\frac{x^n(\pi - x)^n}{n!}\sin x\,\mathrm{d}x\)：假如 \(\pi\) 是有理數，當 \(n\) 足夠大時，這個積分就會是一個小於 \(1\) 的正整數。

  4. \(x^2 - (e + \pi)x + e\pi\) 的根是 \(e\) 和 \(\pi\)。假如 \(e + \pi\) 和 \(e\pi\) 都是代數數（algebraic number），\(\pi\) 就是一個代數係數多項式的根，因而也是代數數，這與林德曼（Lindemann）定理矛盾。

1.5 無窮遞降法

  1. \(3 \mid a\)；設 \(a = 3a_1\)，得 \(9a_1^3 + b^3 = 3c^3\)，所以 \(3 \mid b\)，於是 \(3a_1^3 + 9b_1^3 = c^3\)，所以 \(3 \mid c\)，而 \((a_1, b_1, c_1)\) 是一個更小的解：這就是遞降（descent）。至於 \(p^4 + 2q^4 = 5r^4\)：四次方數模（modulo）\(5\) 只能是 \(0\) 或 \(1\)（它們的末位數字是 \(0\)、\(1\)、\(5\) 或 \(6\)），所以 \(p^4 + 2q^4 \equiv 0\) 迫使 \(5 \mid p\) 且 \(5 \mid q\)；於是 \(5^4 \mid 5r^4\)，所以 \(5 \mid r\)，同樣可以遞降。

  2. 平方數模 \(4\) 只能是 \(0\) 或 \(1\)，所以 \(x^2 + y^2\) 只能是 \(0\)、\(1\) 或 \(2\)，絕不會是 \(3\)。

  3. 若有有理點 \((\frac ac, \frac bc)\)，便會得到 \(a^2 + b^2 = 3c^2\)，其中 \(c \neq 0\)，而第 (iii) 部分已排除這個可能。

  4. 固定 \(x\)、\(y\) 時，方程是二次方程 \(z^2 - 3xyz + (x^2 + y^2) = 0\)，其兩根之和為 \(3xy\)。由 \((1,1,1)\) 出發：得 \((1,1,2)\)；把 \((1, 2)\) 所對的那個 \(1\) 換掉，得 \(3 \cdot 1 \cdot 2 - 1 = 5\)，即 \((1,2,5)\)；然後是 \((1,5,13)\) 和 \((2,5,29)\)。

1.6 兩個平方數之和

  1. 平方數模 \(4\) 只能是 \(0\) 或 \(1\)，所以兩個平方數之和模 \(4\) 絕不會是 \(3\)。

  2. \(65 = 1^2 + 8^2 = 4^2 + 7^2\) 及 \(85 = 2^2 + 9^2 = 6^2 + 7^2\)。利用 \(65 = (2 + \mathrm{i})(2 - \mathrm{i})(3 + 2\mathrm{i})(3 - 2\mathrm{i})\)：\((2 + \mathrm{i})(3 + 2\mathrm{i}) = 4 + 7\mathrm{i}\) 及 \((2 + \mathrm{i})(3 - 2\mathrm{i}) = 8 - \mathrm{i}\)。同理，對於 \(85\)，\((2 + \mathrm{i})(4 \pm \mathrm{i})\) 給出 \(7 + 6\mathrm{i}\) 和 \(9 - 2\mathrm{i}\)。

  3. \(1105 = 4^2 + 33^2 = 9^2 + 32^2 = 12^2 + 31^2 = 23^2 + 24^2\)。\(5\)、\(13\)、\(17\) 各自都可分解為一個高斯整數（Gaussian integer）與其共軛（conjugate）之積；從每一對中各選一個因數，共得 \(8\) 個乘積，它們兩兩互為共軛（給出相同的平方和），所以剩下 \(4\) 個。

  4. 取模的平方，得 \(9 = (a^2 + b^2)(c^2 + d^2)\)。由於 \(3\) 不是兩個平方數之和，其中一個因數必為 \(1\)。

1.7 因數分解失效之時

  1. \(693 = 9 \times 77 = 21 \times 33\)，四個因數全是 \(S\)-質數。方法：取四個形如 \(4k + 3\) 的質數 \(p, q, r, s\)；那麼 \((pq)(rs) = (pr)(qs)\) 就給出兩種分解為 \(S\)-質數的方式。

  2. \(E\)-質數就是形如 \(2 \pmod 4\) 的數（它們不可能是兩個偶數之積）。\(60 = 2 \times 30 = 6 \times 10\)。

  3. 展開 \((ac - 5bd)^2 + 5(ad + bc)^2\) 即得 \(N(zw) = N(z)N(w)\)。\(a^2 + 5b^2\) 絕不會等於 \(2\) 或 \(3\)。由於 \(N(2) = 4\)、\(N(3) = 9\) 及 \(N(1 \pm \sqrt{-5}) = 6\)，若要分解為非單位（non-unit）之積，就需要一個範數（norm）為 \(2\) 或 \(3\) 的因數。

  4. 設 \(n\) 是具有兩種不同分解 \(p_1\cdots p_r = q_1\cdots q_s\) 的最小的數。根據歐幾里得（Euclid）引理，\(p_1\) 整除某個 \(q_j\)，所以 \(p_1 = q_j\)；約去後得到一個更小而又有兩種不同分解的數，矛盾。

1.8 點算有理數

  1. \(\frac35\)：逐級追溯其父節點，\((3, 5) \leftarrow (3, 2) \leftarrow (1, 2) \leftarrow (1, 1)\)，對應的位置為 \(1 \to 2 \to 5 \to 10\)，所以 \(f(10) = \frac35\)。\(\frac53\)：\((5, 3) \leftarrow (2, 3) \leftarrow (2, 1) \leftarrow (1, 1)\)，位置為 \(1 \to 3 \to 6 \to 13\)，所以 \(f(13) = \frac53\)。

  2. Newman 的法則 \(x_{n+1} = \frac{1}{2\lfloor x_n\rfloor - x_n + 1}\) 給出 \(1\)、\(\frac12\)、\(2\)、\(\frac13\)、\(\frac32\)、\(\frac23\)、\(3\)、\(\frac14\)、\(\frac43\)、\(\frac35\)，與 \(f(1), \ldots, f(10)\) 吻合。

  3. 第 \(n\) 位數字一律取 \(5\)，除非第 \(n\) 個數的第 \(n\) 位數字是 \(5\)，這時則取 \(4\)。新的小數與列表中每一個數都不相同，而且由於避開了 \(0\) 和 \(9\)，它只有一種小數展開式，所以確實是一個不同的數。

  4. 每個正整數都可唯一地寫成 \(2\) 的冪乘以一個奇數，即 \(2^{m-1}(2n - 1)\)，所以 \((m, n) \mapsto 2^{m-1}(2n - 1)\) 是一個雙射（bijection）。

1.9 三次曲線的切線

  1. 把 \(y = t(x + 1)\) 代入 \(x^2 + y^2 = 1\)，得 \((1 + t^2)x^2 + 2t^2x + t^2 - 1 = 0\)，其根為 \(-1\) 和 \(\frac{1 - t^2}{1 + t^2}\)。取 \(t = \frac qp\)，該點為 \(\bigl(\frac{p^2 - q^2}{p^2 + q^2}, \frac{2pq}{p^2 + q^2}\bigr)\)，由此得到三元數組 \((p^2 - q^2, 2pq, p^2 + q^2)\)。

  2. 該直線為 \(x + y = 3\)，而 \(x^3 + (3 - x)^3 = 9\) 可化簡為 \(9x^2 - 27x + 18 = 0\)：三次項互相抵消，只剩下 \(x = 1, 2\)。這條直線與漸近線（asymptote）\(y = -x\) 平行，第三個交點在無窮遠處。

  3. 切線（tangent）的斜率（gradient）為 \(\frac{x^2}{y^2} = \frac{289}{400}\)，它與曲線再相交於 \(\bigl(-\frac{188479}{90391}, -\frac{36520}{90391}\bigr)\)。去分母後，得 \(188479^3 = 36520^3 + 90391^3 + 180782^3\)。

  4. 該直線與 \(x^3 + y^3 = 1729\) 再相交於 \(\bigl(-\frac{37}{3}, \frac{46}{3}\bigr)\)，所以 \(46^3 = 37^3 + 27 \times 1729 = 37^3 + 3^3 + 36^3\)（這裏用到 \(27 = 3^3\) 和 \(27 \times 1728 = 36^3\)）。
