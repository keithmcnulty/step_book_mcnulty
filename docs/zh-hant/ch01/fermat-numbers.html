質數工廠

工作紙題目連結、提示、大學數學及練習 第 1 章整章的 PDF 版本
題目

STEP II 2002，第 3 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/02-s2-q3

引子

你幾乎肯定早已知道質數（prime）有無窮多個。歐幾里得（Euclid）約在公元前 300 年證明了這件事，這也是每個人最早接觸到的證明之一。那麼，STEP 的題目為甚麼要你再證明一次？

因為這個證明的運作方式完全不同。歐幾里得的論證是說：給我任何一張有限的質數清單，我都能指出它並不完整。而這個證明則說：這裏有一個預先寫好、明確給出的數列（sequence），當中每一個數都含有一個其他各數都沒有的質數。它是一部製造新質數的機器，而它之所以行得通，全靠一條簡潔優美的恆等式（identity），題目會一步一步引領你走向它。

途中你還會遇上一些連費馬（Fermat）本人也被騙倒的數。

動筆之前

先把題目從頭到尾讀一遍，留意它的結構。它分為四個階段：

  1. 計算一些例子；

  2. 找出（其實是題目告訴你）一個規律，並用這些例子驗證；

  3. 證明這個規律在一般情況下成立；

  4. 兩次運用這個規律：先推導出關於公因數（common factor）的結論，再推導出關於質數的結論。

這種「例子 \(\to\) 猜想 \(\to\) 證明 \(\to\) 推論」的結構，正是許多數學研究的實際做法，STEP 的題目也經常依循這個模式。遇到這種結構時，開頭的部分通常不只是熱身：你日後需要的直覺，正是在那裏建立的。

最後一行問的是無窮多個質數，中間問的是公因數。「任何兩個費馬數（Fermat number）都沒有公因數」和「質數有無窮多個」之間，究竟有甚麼關係？

請記住這個問題，我們稍後會回來討論。

逐步解題

階段 1 熟習這些數

要小心記號：\(2^{2^n}\) 是指 \(2^{(2^n)}\)，而不是 \((2^2)^n\)。指數（exponent）本身就是 2 的冪，所以這些數增長得非常快。 \[\begin{aligned} F_0 &= 2^{1} + 1 = 3, &\qquad F_2 &= 2^{4} + 1 = 17,\\ F_1 &= 2^{2} + 1 = 5, &\qquad F_3 &= 2^{8} + 1 = 257. \end{aligned}\]

這四個數有甚麼值得留意的地方？

它們全是質數。（驗證 \(257\)：它不能被 \(2, 3, 5, 7, 11\) 或 \(13\) 整除，而 \(17^2 = 289 > 257\)，所以可以就此停下。）下一個數 \(F_4 = 2^{16} + 1 = 65537\) 也是質數。皮埃爾．德．費馬在 1640 年正正注意到這一點，並猜想（conjecture）所有這種形式的數都是質數。請把這件事記在心裏，稍後我們會看看他是否猜對了。

階段 2 驗證恆等式

現在就較小的 \(k\) 驗證 \((*)\)：

  • \(k = 1\)：左邊只有 \(F_0 = 3\)，而 \(F_1 - 2 = 3\)。

  • \(k = 2\)：\(F_0 F_1 = 3 \times 5 = 15\)，而 \(F_2 - 2 = 15\)。

  • \(k = 3\)：\(F_0 F_1 F_2 = 15 \times 17 = 255\)，而 \(F_3 - 2 = 255\)。

看看由 \(k = 2\) 到 \(k = 3\) 的那一步。我們把 \(15\) 乘以 \(17\)，得到 \(255\)。用費馬數來表達，就是計算了 \((F_2 - 2) \times F_2\)，結果得到 \(F_3 - 2\)。這是巧合嗎？

這個觀察就是整個證明的縮影。讓我們看看它為甚麼應該成立。

階段 3 證明恆等式

繼續讀下去之前，試試直接證明 \[(F_k - 2)\, F_k = F_{k+1} - 2.\] 提示：把所有東西都用 2 的冪來表示。\(F_k - 2\) 是甚麼樣子的？

我們有 \(F_k - 2 = 2^{2^k} - 1\) 和 \(F_k = 2^{2^k} + 1\)，所以 \[(F_k - 2)\, F_k = \bigl(2^{2^k} - 1\bigr)\bigl(2^{2^k} + 1\bigr).\]

這是一個形如 \((a - 1)(a + 1)\) 的乘積。它等於甚麼？

它是平方差（difference of two squares）\(a^2 - 1\)。取 \(a = 2^{2^k}\)，則 \[a^2 = \bigl(2^{2^k}\bigr)^2 = 2^{2 \cdot 2^k} = 2^{2^{k+1}},\] 所以 \[(F_k - 2)\, F_k = 2^{2^{k+1}} - 1 = F_{k+1} - 2. \tag{$\dagger$}\] 這就是整部機器的引擎。留意平方的作用：它把指數加倍，而 \(2^k\) 加倍後就是 \(2^{k+1}\)。費馬數的定義與平方差的因式分解（factorisation）配合得天衣無縫。

這樣一來，歸納法（induction）幾乎是水到渠成。

在歸納步驟中，我們究竟要證明甚麼？

假設 \((*)\) 對某個 \(k \geq 1\) 成立，即 \[F_0 F_1 \cdots F_{k-1} = F_k - 2,\] 而我們想證明它對 \(k + 1\) 也成立： \[F_0 F_1 \cdots F_{k-1} F_k = F_{k+1} - 2.\] 把假設的等式兩邊同乘以 \(F_k\)，再運用 \((\dagger)\)： \[F_0 F_1 \cdots F_{k-1} F_k = (F_k - 2)\, F_k = F_{k+1} - 2.\] 我們已經驗證了 \(k = 1\) 的情況，所以根據歸納法，\((*)\) 對所有 \(k \geq 1\) 都成立。■

我們能否完全不用歸納法？

可以，而且值得看看怎樣做。由 \(F_0 - 2 = 1\) 出發，反覆運用 \((\dagger)\)： \[F_k - 2 = (F_{k-1} - 2) F_{k-1} = (F_{k-2} - 2) F_{k-2} F_{k-1} = \cdots = (F_0 - 2)\, F_0 F_1 \cdots F_{k-1}.\] 由於 \(F_0 - 2 = 1\)，證明便完成了。這種「逐層展開」的做法，其實就是把同一個歸納法完整地寫出來，不過有些人會覺得這樣更容易看明白。

階段 4 沒有公因數

我們想證明：若 \(m \neq n\)，則 \(F_m\) 與 \(F_n\) 沒有大於 \(1\) 的公因數。

假設某個數 \(d\) 同時整除 \(F_m\) 和 \(F_n\)，其中 \(m < n\)。\(F_m\) 在 \((*)\) 的哪個位置出現？

在 \((*)\) 中取 \(k = n\)： \[F_0 F_1 \cdots F_m \cdots F_{n-1} = F_n - 2.\] 由於 \(m < n\)，\(F_m\) 是左邊其中一個因數。所以若 \(d\) 整除 \(F_m\)，則 \(d\) 整除整個左邊；也就是說，\(d\) 整除 \(F_n - 2\)。

現在 \(d\) 既整除 \(F_n\)，又整除 \(F_n - 2\)。它還必定整除甚麼？

它們的差：\(d\) 整除 \(F_n - (F_n - 2) = 2\)。所以 \(d = 1\) 或 \(d = 2\)。

\(d\) 可以是 \(2\) 嗎？

不可以：每個費馬數都是 2 的冪加 1，所以是奇數。因此 \(d = 1\)，即任何兩個不同的費馬數都沒有大於 \(1\) 的公因數。■

數學家會說費馬數兩兩互質（pairwise coprime）。

階段 5 無窮多個質數

現在回到我們一開始提出的問題。

每個大於 \(1\) 的整數都至少有一個質因數（prime factor）。從每個費馬數中各選一個質因數。對於你選出的這些質數，你能說些甚麼？

設 \(p_n\) 為任意一個整除 \(F_n\) 的質數。假如其中兩個相等，例如 \(p_m = p_n\) 而 \(m \neq n\)，那麼這個質數就是 \(F_m\) 與 \(F_n\) 的一個大於 \(1\) 的公因數，但我們剛剛證明了這是不可能的。所以質數 \[p_0,\; p_1,\; p_2,\; p_3,\; \ldots\] 全都互不相同。費馬數有無窮多個，所以不同的質數也有無窮多個。■

留意我們從來不需要知道每個費馬數是被哪一個質數整除，甚至不需要知道費馬數本身是不是質數。我們只需要知道它們永遠沒有公因數。每個費馬數都必須「用掉」至少一個其他費馬數不能用的質數。

回顧

值得停下來看看這道題成功的關鍵何在，因為同樣的想法會在本書中多次重現。

  • 例子並不是裝飾。看出 \(15 \times 17 = 255\) 其實是「\((F_2 - 2) \times F_2 = F_3 - 2\)」，正是關鍵思路。當題目給你一些簡單情況時，要問每一步在做甚麼，而不只是看數字是否吻合。

  • 一條恆等式完成了所有工作。一切都源自 \((a-1)(a+1) = a^2 - 1\)。看似艱深的 STEP 題目，往往只是由一小段簡單的代數推動。

  • 最後的論證着眼於結構，而非大小。我們證明了質數有無窮多個，卻沒有找出任何一個新的質數。我們證明的是：要構成這個無窮的數族，必須用上無窮多個質數。

背後的數學

費馬猜對了嗎？

沒有。1732 年，萊昂哈德．歐拉證明了 \[F_5 = 2^{32} + 1 = 4\,294\,967\,297 = 641 \times 6\,700\,417.\] 歐拉並不是靠運氣找到 \(641\) 的。他證明了 \(F_n\) 的任何質因數都必定具有一種非常特殊的形式（當 \(n = 5\) 時，它必定是 \(64\) 的倍數加一），從而大幅減少了需要考慮的可能。你可以在練習 4 中親自證明這一點。

自此以後，凡是有人成功檢驗過的費馬數，由 \(F_5\) 到 \(F_{32}\)，結果全都是合成數（composite）。就目前所知，\(F_0\) 至 \(F_4\) 可能是僅有的費馬質數，但沒有人能夠證明這一點。這是一個貨真價實的未解難題。

妙就妙在我們的證明完全不受影響。不論是質數還是合成數，費馬數依然能產生無窮多個質數。

費馬質數與正多邊形作圖

費馬質數會在一個相當意想不到的地方出現。古希臘人懂得用直尺和圓規作出等邊三角形和正五邊形，而請留意 \(3 = F_0\) 和 \(5 = F_1\)。其後兩千年間，沒有人能作出其他邊數為質數的正多邊形（regular polygon）。到了 1796 年，年僅 19 歲的卡爾．弗里德里希．高斯（Gauss）示範了怎樣作出正十七邊形，而 \(17 = F_2\)。

高斯更進一步：正 \(N\) 邊形可以用直尺和圓規作出，當且僅當 \(N\) 是 2 的冪乘以若干個互不相同的費馬質數。（Pierre Wantzel 在 1837 年補全了這個證明。）所以哪些正多邊形可以作圖，取決於費馬質數有多少個。你會在 第 6.2 節（STEP II 1991，第 4 題）遇到高斯正十七邊形背後的關鍵計算，而完整的來龍去脈則屬於伽羅瓦理論（Galois theory），那是大學本科數學課程的精華之一。

一個定理，多種證明

數學家為甚麼要不厭其煩地把同一個定理證明多於一次？因為不同的證明會揭示不同的東西。這個證明一般歸功於克里斯蒂安．哥德巴赫（Goldbach）在 1730 年寫給歐拉的一封信，它表明：任何一個由大於 1 的整數組成、各項兩兩互質的無窮數列，都必然帶來無窮多個質數。費馬數只是其中一個方便的例子。（練習 3 給出另一個例子。）

它給出的結論也比歐幾里得的證明更多。質數 \(p_0, p_1, \ldots, p_{n-1}\) 是 \(n\) 個不同的質數，每個都不超過 \(F_{n-1}\)。所以不大於 \(2^{2^{n-1}} + 1\) 的質數至少有 \(n\) 個。這是一個關於質數如何分佈的定量陳述。它非常弱（實際情況要好得多），但它是邁向十九世紀數學其中一項偉大成果的第一步，那就是質數定理（Prime Number Theorem），它精確地描述了質數怎樣變得越來越稀疏。第 1.2 節 會踏出下一步。

思維技巧

從結構性質出發建立論證

要證明 A 類對象有無窮多個，可以找出無窮多個 B 類對象，而每個 B 類對象都需要一個專屬於自己的 A 類對象。

這裏 A = 質數，B = 費馬數，而「需要一個專屬於自己的」是指「有一個不與其他任何一個共用的質因數」。同樣的模式也出現在計數論證、線性代數（linear algebra）（無窮多個線性獨立的向量必然導致無窮維）和分析（analysis）之中。

你也練習了歸納法，尤其是養成追問「由 \(k\) 到 \(k+1\) 的那一步實際上做了甚麼？」的習慣。這個問題往往比形式上的範本更有用。

延伸練習

  1. 歐幾里得的版本。寫出歐幾里得對「質數有無窮多個」的證明。它在甚麼意義上是「反證法」（by contradiction），而費馬數的證明又在甚麼意義上是「構造性」（constructive）的？

  2. 末位數字。證明當 \(n \geq 2\) 時，費馬數 \(F_n\) 的末位數字是 \(7\)。

  3. 西爾維斯特（Sylvester）數列。定義 \(a_1 = 2\) 及 \(a_{n+1} = a_n^2 - a_n + 1\)，於是數列的開頭幾項是 \(2, 3, 7, 43, 1807, \ldots\)

    1. 證明 \(a_{n+1} - 1 = a_1 a_2 \cdots a_n\)。

    2. 由此推導出各項兩兩互質，從而給出「質數有無窮多個」的另一個證明。

    3. 較難 證明 \(\dfrac{1}{a_1} + \dfrac{1}{a_2} + \cdots + \dfrac{1}{a_n} = 1 - \dfrac{1}{a_{n+1} - 1}\)。

  4. 歐拉的妙着。本題需要用到費馬小定理（Fermat’s Little Theorem）：若 \(p\) 是質數且 \(p \nmid a\)，則 \(a^{p-1} \equiv 1 \pmod{p}\)。假設質數 \(p\) 整除 \(F_n\)。

    1. 證明 \(2^{2^n} \equiv -1 \pmod p\)，從而證明 \(2^{2^{n+1}} \equiv 1 \pmod p\)。

    2. 設 \(d\) 為滿足 \(2^d \equiv 1 \pmod p\) 的最小正整數。證明 \(d\) 整除 \(2^{n+1}\) 但不整除 \(2^n\)，並由此得出 \(d = 2^{n+1}\)。

    3. 利用費馬小定理，證明 \(d\) 整除 \(p - 1\)。由此推導出 \(p \equiv 1 \pmod{2^{n+1}}\)。

    4. 當 \(n = 5\) 時，這表示 \(F_5\) 的任何質因數都具有 \(64k + 1\) 的形式。驗證 \(641\) 確實如此。小於 \(641\) 而又具有這種形式的質數有多少個？

  5. 質數的一個上界。利用一個定理，多種證明中的論證，證明第 \(n\) 個質數不超過 \(2^{2^{n-1}} + 1\)。當 \(n = 5\) 時，這個上界有多準確？

延伸閱讀

  • Martin Aigner & Günter M. Ziegler, Proofs from THE BOOK（Springer），第 1 章「Six proofs of the infinity of primes」（質數無窮性的六個證明）。書中除了這個證明外，還收錄了歐幾里得的證明和另外四個證明，其中一個用上了拓撲學（topology）。這是入讀大學前最值得一讀的書之一。

  • Harold Davenport, The Higher Arithmetic（Cambridge University Press），第 1–2 章。一本文筆優美的入門書，介紹質數與因數分解，最適合在入讀大學前的暑假閱讀。

  • Michal Křížek, Florian Luca & Lawrence Somer, 17 Lectures on Fermat Numbers（Springer，2001）。關於費馬數的一切，由歐拉的分解到高斯的正多邊形，應有盡有。不妨翻翻開首幾章。

  • Ian Stewart, Why Beauty Is Truth（Basic Books），關於高斯的一章。以一般讀者為對象，講述正十七邊形的故事。
