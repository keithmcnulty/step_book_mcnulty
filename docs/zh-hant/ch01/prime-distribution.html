質數分佈得有多稀疏？

工作紙題目連結、提示、大學數學及練習 第 1 章整章的 PDF 版本
題目

STEP III 2016，第 5 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/16-s3-q5

引子

在 第 1.1 節 中，我們已看到質數（prime）有無窮多個。但「無窮多個」是個很粗略的說法。質數確實愈來愈稀疏：\(100\) 以下有 \(25\) 個質數，但 \(900\) 與 \(1000\) 之間只有 \(14\) 個。它們究竟會稀疏到甚麼程度？

這道題要證明的結論聽來相當平凡：把不超過 \(n\) 的所有質數相乘，所得的積小於 \(4^n\)。然而，這個看似平平無奇的不等式（inequality），正是回答「有多稀疏？」的第一步實質進展，也是數學史上最著名的簡短證明之一的關鍵引理（lemma）；該證明出自年輕的保羅·艾狄胥（Paul Erdős）之手，時為 1932 年。

動筆之前

記號 \(P_{r,s}\) 看來有點繁瑣，但背後的意思很簡單：把某個範圍內的質數相乘。務必先弄懂題中的例子。\(P_{3,7}\) 用的是大於 \(3\) 而不超過 \(7\) 的質數，即 \(5\) 和 \(7\)，所以它等於 \(35\)。

第 (iv) 部分要求你對所有 \(n \geq 2\) 證明一個命題。第 (iii) 部分則假設該命題對不超過 \(2m\) 的每一個 \(k\) 都成立。這是哪一種歸納法（induction）？

這是強歸納法（strong induction）：要證明 \(n\) 的情況，你可以假設前面所有情況都成立，而不僅是緊接在前的那一個。請把這一點記在心裏；題目之所以這樣編排，原因正在於此。

逐步解題

階段 1 二項式係數不會太大

在 \((1+x)^{2m+1}\) 的二項展開式（binomial expansion）中代入 \(x = 1\)，會得到甚麼？

你會得到 \[2^{2m+1} = \binom{2m+1}{0} + \binom{2m+1}{1} + \cdots + \binom{2m+1}{2m+1}.\] 各項都是正數，所以每一項都小於 \(2^{2m+1}\)。這還不夠好；我們想要的是 \(2^{2m}\)，即它的一半。

帕斯卡三角形（Pascal’s triangle）是對稱的。和式中還有哪一項等於 \(\binom{2m+1}{m}\)？

由對稱性，\(\binom{2m+1}{m} = \binom{2m+1}{m+1}\)，而這是和式中兩個不同的項（因為 \(m \neq m+1\)）。所以 \[2\binom{2m+1}{m} = \binom{2m+1}{m} + \binom{2m+1}{m+1} < 2^{2m+1},\] 這裏是嚴格不等式，因為和式中還有其他正項，例如 \(\binom{2m+1}{0} = 1\)。兩邊除以 \(2\)，即得 \(\binom{2m+1}{m} < 2^{2m}\)。■

階段 2 哪些質數整除這個二項式係數？

把這個二項式係數（binomial coefficient）寫出來： \[\binom{2m+1}{m} = \frac{(2m+1)!}{m!\,(m+1)!} = \frac{(m+2)(m+3)\cdots(2m+1)}{m!}.\]

設 \(p\) 為質數，且 \(m + 1 < p \leq 2m+1\)。\(p\) 整除分子嗎？它有可能整除分母嗎？

分子 \((m+2)(m+3)\cdots(2m+1)\) 的因子當中就有 \(p\) 本身，所以 \(p\) 整除分子。分母 \(m!\) 是若干個數的積，而這些數全都小於 \(p\)；由於 \(p\) 是質數，如果它不能整除其中任何一個數，就不能整除它們的積。因此 \(p\) 整除分子而不整除分母，於是 \(p\) 整除整個二項式係數（別忘記，它是一個整數）。

我們現在知道，這個範圍內的每一個質數都整除 \(\binom{2m+1}{m}\)。為甚麼由此可知它們的積 \(P_{m+1,2m+1}\) 也整除它？（小心：即使 \(4\) 和 \(6\) 都整除某個數，\(24\) 也不一定整除它。）

分別在於，我們的質數是相異質數。如果相異質數 \(p_1, p_2, \ldots\) 各自整除 \(N\)，那麼它們的積也整除 \(N\)：寫 \(N = p_1 N_1\)；這時 \(p_2\) 整除 \(p_1 N_1\) 但不整除 \(p_1\)，所以它整除 \(N_1\)；如此類推。（這裏用到一個事實：如果一個質數整除某個積，它必整除其中一個因子。這個事實值得我們稍加敬重；第 1.7 節 會展示一個世界，在那裏與它相應的命題並不成立。）

所以 \(P_{m+1,2m+1}\) 整除 \(\binom{2m+1}{m}\)，而正數的因數不會大於該數本身，故 \[P_{m+1,\,2m+1} \leq \binom{2m+1}{m} < 2^{2m}. \qed\]

階段 3 把積拆開

\(P_{1,2m+1}\) 是不超過 \(2m+1\) 的所有質數的積，怎樣用我們已經掌握的積把它拼出來？

把不超過 \(2m+1\) 的質數分成兩批：不超過 \(m+1\) 的，以及大於 \(m+1\) 的： \[P_{1,2m+1} = P_{1,m+1} \times P_{m+1,2m+1}.\] 由第 2 階段，第二個因子小於 \(2^{2m} = 4^m\)。至於第一個因子，我們可以假設 \(P_{1,k} < 4^k\) 對由 \(2\) 至 \(2m\) 的每一個 \(k\) 都成立，而 \(k = m+1\) 正在這個範圍之內（因為由 \(m \geq 1\) 可得 \(2 \leq m+1 \leq 2m\)）。所以 \[P_{1,2m+1} < 4^{m+1} \times 4^{m} = 4^{2m+1}. \qed\] 強歸納法正是在這裏大派用場：要處理 \(2m+1\)，我們需要的是 \(m+1\) 的情況，它的大小約為一半，而不是緊接在前的那個情況。

階段 4 所有 \(n\)

第 (iii) 部分處理了奇數。對於偶數 \(n = 2m+2\)，情況又如何？它是質數嗎？

先驗證起始情況：\(P_{1,2} = 2 < 16\) 及 \(P_{1,3} = 6 < 64\)。現在假設 \(P_{1,k} < 4^k\) 對由 \(2\) 至 \(n-1\) 的所有 \(k\) 都成立，其中 \(n \geq 4\)。

  • 若 \(n\) 是偶數，則 \(n\) 不是質數（因為它大於 \(2\)），所以不超過 \(n\) 的質數與不超過 \(n-1\) 的質數完全相同。因此 \(P_{1,n} = P_{1,n-1} < 4^{n-1} < 4^n\)。

  • 若 \(n\) 是奇數，寫 \(n = 2m+1\)，其中 \(m \geq 2\)。這時由第 (iii) 部分直接得出 \(P_{1,n} < 4^n\)。

由強歸納法，\(P_{1,n} < 4^n\) 對每一個 \(n \geq 2\) 都成立。■

回顧

  • 二項式係數蘊藏算術資訊。\(\binom{2m+1}{m}\) 是單獨一個數，它不大（小於 \(4^m\)），卻必須被許多質數整除。把許多質數擠進一個不大的數裏，就說明這些質數不可能太多。

  • 當問題會把自己減半時，強歸納法是最自然的工具。\(2m+1\) 的情況取決於 \(m+1\) 的情況。

  • 小的情況須另行驗證。歸納要到 \(n \geq 4\) 才能開始運作，所以 \(n = 2\) 和 \(3\) 必須親手計算。

背後的數學

從 \(4^n\) 到質數定理

對結果取對數：\(\ln P_{1,n} < n \ln 4\)，即 \[\sum_{p \leq n} \ln p < (\ln 4)\, n \approx 1.39\,n .\] 在 1850 年代，切比雪夫（Pafnuty Chebyshev）證明了正是這一類的界（bound），而且上界和下界俱備，從而說明 \(\sum_{p \leq n} \ln p\) 的增長與 \(n\) 成正比。高斯（Gauss）在大約 15 歲時，已從數表中猜到不超過 \(n\) 的質數個數大約是 \(n / \ln n\)。這後來成為質數定理（Prime Number Theorem），最終在 1896 年由阿達馬（Jacques Hadamard）和德拉瓦萊普桑（Charles de la Vallée Poussin）運用複分析（complex analysis）證明。它的對數形式是 \[\sum_{p \leq n} \ln p \sim n,\] 所以不超過 \(n\) 的質數之積大約是 \(e^n\)。我們的界 \(4^n\) 其實相差不遠：圖 1.2.1 把三者一併畫出。

伯特蘭公設

1845 年，伯特蘭（Joseph Bertrand）猜想：對每一個 \(n \geq 1\)，在 \(n\) 與 \(2n\) 之間總有一個質數。這就是伯特蘭公設（Bertrand’s postulate）。切比雪夫在 1852 年證明了它。八十年後，年僅 19 歲的艾狄胥找到了一個優美的初等證明。它的關鍵材料，就是本題的引理，再加上仔細考察哪些質數整除中間的二項式係數 \(\binom{2n}{n}\)。Martin Aigner 和 Günter Ziegler 把它選為 Proofs from THE BOOK 的第 2 章，該書匯集了數學中最優雅的證明。

接下來的方向

質數的精確分佈，由黎曼 ζ 函數（Riemann zeta function） \[\zeta(s) = 1 + \frac{1}{2^s} + \frac{1}{3^s} + \cdots,\] 的零點（zero）所支配。你會在 第 2.4 節 中遇見這個函數樸素得多的一面，那裏有 \(\zeta(2) = \pi^2/6\)。黎曼猜想（Riemann Hypothesis）預測了這些零點的確切位置；它若成立，便能把質數定理中的誤差限定得緊無可緊。它也許是數學中最著名的未解難題，也是千禧年大獎難題（Millennium Prize Problems）之一。

思維技巧

強歸納法，以及從巧妙的對象中提取資訊

如果 \(n\) 的情況取決於遠小於 \(n-1\) 的情況，就一次過假設前面所有情況都成立。

這裏的另一個想法較為微妙，也極具數論（number theory）的特色：要證明某個範圍內所有質數的某種性質，就找出一個對象（這裏是一個二項式係數），使得這些質數每一個都必須整除它，而你又能證明它不會太大。

延伸練習

  1. 感受一下數字。對 \(n = 10, 20, 30\) 計算 \(P_{1,n}\)，並把它與 \(4^n\) 及 \(e^n\) 比較。（這裏可以使用計算機。）

  2. 中間的二項式係數。證明 \(\binom{2m}{m}\) 是 \((1+1)^{2m}\) 展開式的 \(2m+1\) 項中最大的一項，並由此推出 \(\binom{2m}{m} \geq \dfrac{4^m}{2m+1}\)。

  3. 質數不會太多。設 \(\pi(n)\) 為不超過 \(n\) 的質數個數。介乎 \(\sqrt n\) 與 \(n\) 之間的每個質數都大於 \(\sqrt n\)，而它們的積至多為 \(P_{1,n} < 4^n\)。由此推出 \[\pi(n) - \pi(\sqrt n) < \frac{2\ln 4}{\ln n}\, n ,\] 從而得出 \(\pi(n) < 2.8\, n/\ln n + \sqrt n\)。把這個結果與質數定理的 \(\pi(n) \approx n / \ln n\) 比較。

  4. 驗證伯特蘭公設。對 \(n = 1, 2, \ldots, 50\) 驗證伯特蘭公設，即在每個情況下找出一個介乎 \(n\) 與 \(2n\) 之間的質數。你能否利用一張簡短的質數表有效率地完成，使表中每個質數都小於前一個的兩倍？
