最小反例

題目

STEP III 2015，第 5 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/15-s3-q5

引子

你大概見過 \(\sqrt2\) 是無理數（irrational）的證明：假設 \(\sqrt2 = a/b\) 為最簡分數（lowest terms），兩邊平方，推出 \(a\) 是偶數，繼而推出 \(b\) 也是偶數，於是得出矛盾（contradiction）。這是個漂亮的證明，但它依賴一個關於偶數的技巧，而這個技巧看不出可以怎樣推廣。換成 \(\sqrt[3]{2}\) 又如何？\(\sqrt{7}\) 呢？

本題給出另一個證明，它的核心想法簡單得近乎荒謬：看看最小的那一個。在本章裏，同一個想法還會改頭換面地出現好幾次。

動筆之前

這是一道不尋常的 STEP 題目：它給你一個證明的骨架，要你補上當中欠缺的理據。大學生正是這樣學習閱讀數學的。課本裏的證明常常說「顯然」或「由此可得」，而你的部分工作，就是查證事實是否真的如此。

第 4 步說「定義 \(k\) 為 \(S\) 中最小的正整數」。我們憑甚麼可以這樣做？假如 \(S\) 是一個由正實數組成的集合，這樣做還可以嗎？

任何由正整數組成的非空集合都有最小元素。這稱為良序原理（well-ordering principle），它與數學歸納法（mathematical induction）原理等價。對於由正實數組成的集合，這個原理並不成立：集合 \(\{x : x > 0\}\) 就沒有最小元素。所以第 4 步既依賴第 3 步（集合必須非空），也依賴 \(S\) 由整數組成這一點。

逐步解題

階段 1 第 3 步：\(S\) 非空

若 \(\sqrt2 = a/b\)，其中 \(a\) 和 \(b\) 是正整數，你能寫出 \(S\) 的一個元素嗎？

若 \(\sqrt2 = a/b\)，則 \(b\sqrt2 = a\)，是一個整數。所以 \(b\) 屬於 \(S\)，\(S\) 非空。

階段 2 第 5 步：一個更小的元素

現在 \(k\) 是 \(S\) 的最小元素，所以 \(k\sqrt2\) 是整數，記為 \(j\)。

要證明 \((\sqrt2 - 1)k\) 屬於 \(S\)，你必須檢查三件事。是哪三件？

我們需要 \((\sqrt2-1)k\) 滿足：(a) 是整數；(b) 是正數；(c) 乘以 \(\sqrt2\) 後得到整數。

  • (a) \((\sqrt2 - 1)k = k\sqrt2 - k = j - k\)，是兩個整數之差。

  • (b) \(\sqrt2 > 1\)，所以 \(\sqrt2 - 1 > 0\)，因此 \((\sqrt2-1)k > 0\)。

  • (c) \((\sqrt2-1)k \cdot \sqrt2 = 2k - k\sqrt2 = 2k - j\)，是整數。

所以 \((\sqrt2 - 1)k \in S\)。

階段 3 第 6 步：矛盾

\(\sqrt2 - 1\) 有多大？

由於 \(1 < \sqrt2 < 2\)，我們有 \(0 < \sqrt2 - 1 < 1\)，所以 \((\sqrt2 - 1)k < k\)。我們找到了 \(S\) 的一個元素，它比 \(S\) 的最小元素 \(k\) 還要小。這是不可能的，所以第 1 步的假設不成立：\(\sqrt2\) 是無理數。■

留意我們從頭到尾都不需要「最簡分數」，也不需要任何關於奇偶數的事實。整個證明只建基於三個事實：\(\sqrt2 \cdot \sqrt2\) 是整數；\(\sqrt2\) 嚴格地介乎兩個連續整數之間；整數具有良序性。

階段 4 立方根：把兩個數聯繫起來

設 \(c = 2^{1/3}\)，則 \(c^2 = 2^{2/3}\) 且 \(c^3 = 2\)。

若 \(c\) 是有理數（rational），\(c^2\) 是否也是？反過來，若 \(c^2\) 是有理數，你能否只用乘法和除法回到 \(c\)？

若 \(c\) 是有理數，則 \(c^2 = c \times c\) 也是有理數。反之，若 \(c^2\) 是有理數，則 \(2 / c^2 = c^3 / c^2 = c\) 也是有理數。所以 \(2^{1/3}\) 是有理數，當且僅當 \(2^{2/3}\) 是有理數。■

階段 5 改造論證

在第 (i) 部分，關鍵在於 \((\sqrt2)^2 = 2\) 是整數，所以把 \(S\) 的元素乘以 \(\sqrt2\) 兩次，就會回到整數。對於 \(c = 2^{1/3}\)，你需要乘三次。集合 \(S\) 應該怎樣修改？

假設 \(c\) 是有理數，則 \(c^2\) 也是。定義 \[S = \{ n \text{ 為正整數} : nc \text{ 和 } nc^2 \text{ 都是整數} \}.\]

  • \(S\) 非空。若 \(c = a/b\) 且 \(c^2 = a'/b'\)，則 \(bb'\) 屬於 \(S\)。

  • 設 \(k\) 為它的最小元素，並考慮 \((c - 1)k\)。我們有 \(1 < c < 2\)（因為 \(1^3 < 2 < 2^3\)），所以 \(0 < (c-1)k < k\)。

  • 它是整數：\((c-1)k = kc - k\)。

  • 乘以 \(c\)：\((c-1)k \cdot c = kc^2 - kc\)，是整數。

  • 乘以 \(c^2\)：\((c-1)k \cdot c^2 = kc^3 - kc^2 = 2k - kc^2\)，是整數。

所以 \((c-1)k \in S\)，而且比 \(k\) 小：矛盾。因此 \(2^{1/3}\) 是無理數，而根據第 4 階段，\(2^{2/3}\) 也是無理數。■

回顧

  • 「取最小的那一個」是一種證明技巧。假設反例存在，取其中最小的一個，再由它造出一個更小的。這稱為極端原理（extremal principle），或稱最小反例（minimal counterexample）論證。

  • 集合 \(S\) 替我們記帳。我們不必周旋於分子和分母之間，而是把所有「好」的乘數收進同一個集合。

  • 推廣，就是追問證明真正行得通的原因。對於 \(\sqrt2\)，需要乘以 \(\sqrt2\) 一次；對於 \(\sqrt[3]{2}\)，則需要乘兩次。看出這一點，我們就清楚知道該怎樣重新定義 \(S\)。

背後的數學

一個畫得出來的證明

第 (i) 部分背後有一幅優美的圖，出自 Stanley Tennenbaum。若 \(\sqrt2 = a/b\)，則 \(a^2 = 2b^2\)：一個邊長為 \(a\) 的正方形，面積等於兩個邊長為 \(b\) 的正方形面積之和。如圖 1.3.1 所示，把兩個邊長為 \(b\) 的正方形放在邊長為 \(a\) 的正方形的兩個對角。它們重疊之處是一個小正方形，另外還有兩個小正方形沒有被蓋住。由於面積相等，重疊部分必定等於兩個未被蓋住的正方形之和，於是得到一對更小而具有同樣性質的整數。整數對不可能無止境地愈變愈小，所以這樣的正方形並不存在。這對較小的整數正是 \((2b - a,\; a - b)\)，也就是我們那一步 \((\sqrt2 - 1)k\) 的化身。

良序、歸納與遞降

良序原理與歸納法原理在邏輯上等價：兩者可以互相推導。到了大學，你會看到兩者都被用作自然數的基礎。在 第 1.5 節 中，我們會以另一種形式運用同一個原理，那就是費馬（Fermat）的無窮遞降法（method of infinite descent）：不存在由正整數組成的無窮嚴格遞減數列。

它能走多遠？

這個論證可以證明，只要 \(N\) 不是完全平方數（perfect square），\(\sqrt N\) 就是無理數（見練習）；更一般地，一個整數的 \(n\) 次方根要麼是整數，要麼是無理數。到了大學，這會變成一個關於代數整數（algebraic integers）的命題：若一個有理數滿足某個整數係數的首一多項式（monic polynomial）方程，例如 \(x^3 - 2 = 0\)，它就必定是整數。你會在 第 6.3 節 再次遇到這個想法。

相傳畢達哥拉斯學派（Pythagoreans）因為希帕索斯（Hippasus）洩露了 \(\sqrt2\) 是無理數而把他淹死，這個傳說多半並不屬實。屬實的是，這個發現迫使希臘數學家把對數的研究與對長度的研究分開；這道裂痕要等到十九世紀，待戴德金（Dedekind）構造出實數，才得以彌合。

思維技巧

極端原理

如果你想證明某件事永遠不會發生，就假設它會發生，選出最小（或最大、或最簡單）的例子，再用它造出一個更小的例子。

決定「最小」是甚麼意思，正是需要創意的一步。在這裏，它是使 \(n\sqrt2\) 成為整數的最小的 \(n\)。

延伸練習

  1. 其他平方根。改造這個論證，證明 \(\sqrt3\) 是無理數。哪一個數擔當了 \(\sqrt2 - 1\) 的角色？

  2. 所有非平方數。設 \(N\) 為一個不是完全平方數的正整數，並設 \(m\) 為滿足 \(m < \sqrt N < m+1\) 的整數。考慮 \((\sqrt N - m)k\)，從而證明 \(\sqrt N\) 是無理數。

  3. 找出漏洞。試把這個論證套用於 \(\sqrt 4\)。究竟是哪一步行不通？

  4. Tennenbaum 的圖。利用圖 1.3.1 證明：若 \(a^2 = 2b^2\)，則 \((2b-a)^2 = 2(a-b)^2\)。再用代數方法驗證這個恆等式。

  • R. P. Burn, A Pathway into Number Theory（Cambridge University Press）。全書由精心編排次序的問題組成，是修讀大學一年級課程前的理想準備。

  • John Conway & Joseph Shipman, “Extreme proofs I: the irrationality of \(\sqrt2\)”（Mathematical Intelligencer，2013）。同一個事實的多個證明，比較得妙趣橫生。
