第 2 章 · 數列、級數與收斂

延伸練習答案

以下只是簡短的答案和提示，並非完整解答：這裏只給出結果和關鍵步驟，方便你核對自己的做法。請先認真做過每一道練習，然後才翻看。

2.1 「最終」是甚麼意思

  1. \((1 + x)^n = 1 + nx + \binom n2x^2 + \cdots\) 的各項均為非負，所以 \((1 + x)^n \geq 1 + nx > nx\)。設 \(y = 1 + x\)，則只要 \(n > K/(y - 1)\)，便有 \(y^n > n(y - 1) > K\)。利用下一項，\(y^n > \binom n2(y - 1)^2\)，所以只要 \(n > 1 + 2K/(y - 1)^2\)，便有 \(y^n/n > \frac12(n - 1)(y - 1)^2 > K\)。

  2. 若當 \(n \geq m_1\) 時 \(s_n \leq t_n\)，而當 \(n \geq m_2\) 時 \(t_n \leq s_n\)，則當 \(n \geq \max(m_1, m_2)\) 時 \(s_n = t_n\)。

  3. 例如：當 \(n\) 為偶數時 \(s_n = n + 0.6\)，當 \(n\) 為奇數時 \(s_n = n\)；而當 \(n\) 為奇數時 \(t_n = n + 0.6\)，當 \(n\) 為偶數時 \(t_n = n\)。兩個數列（sequence）都是遞增的，而且各自都有無限多次大於對方。

  4. 當 \(n \geq 4\) 時 \(2^n \leq n!\)（用歸納法（induction）：\(2^{n+1} = 2 \cdot 2^n \leq (n + 1)\,n!\)）。至於 \(n^{10} \leq 2^n\)，這個不等式對由 \(2\) 至 \(58\) 的每一個 \(n\) 都不成立，而對所有 \(n \geq 59\) 都成立，所以最小的 \(m\) 是 \(59\)。

2.2 作為極限的黃金比例

  1. 用歸納法：\(u_1 = 1 = F_2/F_1\)，而若 \(u_n = F_{n+1}/F_n\)，則 \(u_{n+1} = 1 + F_n/F_{n+1} = F_{n+2}/F_{n+1}\)。

  2. 由於 \(\varphi - 1 = 1/\varphi\)，\(u_{n+1} - \varphi = \frac{1}{u_n} - \frac1\varphi = -\frac{u_n - \varphi}{\varphi u_n}\)。因為 \(u_n \geq 1\)，所以 \(|u_{n+1} - \varphi| \leq |u_n - \varphi|/\varphi\)，又 \(|u_1 - \varphi| < 1\)，故 \(|u_n - \varphi| \leq \varphi^{-(n-1)}\)。

  3. \(\psi = \frac{1 - \sqrt5}{2}\) 滿足 \(\psi^2 = \psi + 1\)，所以 \(1 + 1/\psi = \psi\)。倒推回去，\(u_{n-1} = \frac{1}{u_n - 1}\)：由 \(0\) 出發，得到 \(-1, -\frac12, -\frac23, -\frac35, -\frac58, \ldots\)，即對某個 \(k \geq 1\) 有 \(u_1 = -F_{k-1}/F_k\)。這些數值趨近 \(\psi\)。

  4. 不動點（fixed point）滿足 \(v = 1 + \frac{1}{1 + v}\)，即 \(v^2 = 2\)。誤差每次乘以 \(-\frac{1}{(1 + v_n)(1 + \sqrt2)}\)，其大小不超過 \(\frac{1}{2(1 + \sqrt2)}\)，所以 \(v_n \to \sqrt2\)。並且 \(\sqrt2 = 1 + \cfrac{1}{2 + \cfrac{1}{2 + \cdots}}\)。

2.3 一個發散級數與它的收斂近親

  1. 由 \(\ln N + 0.5772 = 10\) 得 \(N \approx 12\,400\)；要超過 \(100\)，大約需要 \(e^{99.4} \approx 1.5 \times 10^{43}\) 項。

  2. 取 \(k = 2\)，第 \(n\) 組之和不超過 \(2^n \cdot 4^{-n} = 2^{-n}\)，所以總和不超過 \(\sum_{n \geq 0}2^{-n} = 2\)。把 \(1 + \frac14 + \frac19\) 準確加起來，再以 \(\frac14 + \frac18 + \cdots = \frac12\) 作為由 \(r = 4\) 起各組的上界，便得到約 \(1.86\)。（真確值是 \(\frac{\pi^2}{6} \approx 1.645\)。）

  3. 對於 \(1/(r\ln r)\)，由 \(2^n\) 至 \(2^{n+1} - 1\) 的一組之和至少是 \(\frac{2^n}{2^{n+1}(n + 1)\ln 2} = \frac{1}{2(n + 1)\ln2}\)，而這些數之和的表現與調和級數（harmonic series）相同：級數發散（divergence）。對於 \(1/(r(\ln r)^2)\)，該組之和不超過 \(\frac{1}{n^2(\ln2)^2}\)，而 \(\sum\frac{1}{n^2}\) 收斂（converges）。

  4. 可用的數字：首位數字有 \(7\) 個選擇，其餘每一位各有 \(8\) 個選擇，所以符合條件的 \(d\) 位數最多有 \(7 \cdot 8^{d-1}\) 個，而每個都至少是 \(10^{d-1}\)。總和不超過 \(\sum_{d \geq 1}7(0.8)^{d-1} = \frac{7}{1 - 0.8} = 35\)。

2.4 \(\pi^2/6\)

  1. 各個 \(\tan^2 = 1/\cot^2\) 的值是倒序多項式 \(\sum_j(-1)^j\binom{2n+1}{2j+1}y^j\) 的根（roots），其根之和為 \(\binom{2n+1}{2n-1} = n(2n + 1)\)。然後由 \(\mathrm{cosec}^2 = 1 + \cot^2\) 得 \(n + \frac{n(2n - 1)}{3} = \frac{2n(n + 1)}{3}\)。

  2. 偶數項之和為 \(\frac14\sum\frac{1}{m^2} = \frac{\pi^2}{24}\)，所以奇數項之和為 \(\frac{\pi^2}{6} - \frac{\pi^2}{24} = \frac{\pi^2}{8}\)。

  3. 這些根滿足 \(e_1 = \frac{n(2n - 1)}{3}\) 和 \(e_2 = \binom{2n+1}{5}\big/\binom{2n+1}{1}\)，由此得 \(\sum\cot^4 = e_1^2 - 2e_2 = \frac{n(2n - 1)(4n^2 + 10n - 9)}{45}\)。利用 \(\cot^4\theta < \theta^{-4} < (1 + \cot^2\theta)^2\) 作夾逼（squeezing），再令 \(n \to \infty\)，便得到 \(\frac{\pi^4}{90}\)。

  4. 由下界得 \(\sum_{m \leq n}\frac{1}{m^2} > \frac{\pi^2n(2n - 1)}{3(2n + 1)^2}\)，所以誤差小於 \(\frac{\pi^2(6n + 1)}{6(2n + 1)^2} < \frac{\pi^2}{4n}\)。這保證了當 \(n \geq 2468\) 時準確度達到 \(0.001\)；事實上 \(n \approx 1000\) 已經足夠。

2.5 韋達乘積

  1. 反覆使用 \(\sin\theta = 2\sin\frac\theta2\cos\frac\theta2\)：乘積會逐項相消（telescopes）。令 \(n \to \infty\)（於是 \(2^n\sin(\alpha/2^n) \to \alpha\)），並取 \(\alpha = \frac\pi2\)，再利用 \(\cos\frac\pi4 = \sqrt{\frac12}\) 和 \(\cos\frac\theta2 = \sqrt{\frac12 + \frac12\cos\theta}\)。

  2. \(\frac{\sin(\pi/3)}{\pi/3} = \frac{3\sqrt3}{2\pi} = \cos\frac\pi6\cos\frac\pi{12}\cos\frac\pi{24}\cdots\)，其中 \(\cos\frac\pi6 = \frac{\sqrt3}{2}\)，而 \(\cos\frac{\pi}{12} = \frac{\sqrt{2 + \sqrt3}}{2} = \frac{\sqrt6 + \sqrt2}{4}\)。

  3. 取 \(8\) 個因子得 \(3.14157\)，四捨五入後是 \(3.1416\)。取 \(n\) 個因子後，誤差約為 \(\frac{\pi^3}{6 \cdot 4^{n+1}}\)，因為被略去的因子是 \(\cos\frac{\pi}{2^{j+1}} \approx 1 - \frac{\pi^2}{2 \cdot 4^{j+1}}\)：每多一個因子，誤差約縮小至原來的 \(4\) 分之一，而 \(\log_{10}4 \approx 0.6\)。

  4. 設 \(x = \ln a\)，同樣的論證給出\[\frac{a - 1}{\ln a} = \prod_{j \geq 1}\frac{1 + a^{1/2^j}}{2},\]所以 \(\frac{1}{\ln3} = \frac12\prod_{j \geq 1}\frac{1 + 3^{1/2^j}}{2}\)。取七個因子得 \(0.906\)，四捨五入後是 \(0.91\)（真確值是 \(0.9102\)）。這裏的因子趨近 \(1\) 的方式如同 \(1 + \frac{\ln3}{2^{j+1}}\)，所以每多一個因子只能把誤差減半（約 \(0.3\) 位數字）；而韋達（Viète）的因子趨近 \(1\) 的方式如同 \(1 - \frac{\pi^2}{2 \cdot 4^{j+1}}\)，每次把誤差縮小至四分之一。

2.6 算術幾何平均

  1. \(x_{n+1} - y_{n+1} = \frac12(\sqrt{x_n} - \sqrt{y_n})^2 = \frac{(x_n - y_n)^2}{2(\sqrt{x_n} + \sqrt{y_n})^2}\)，而 \((\sqrt{x_n} + \sqrt{y_n})^2 \geq 4y_n \geq 4y_0\)。

  2. \(M(2, 1) = 1.456791\)；三步之後，\(x_3\) 與 \(y_3\) 已經有七位小數相同。

  3. 迭代（iteration）的每一步都按 \(\lambda\) 的比例縮放，所以 \(M(\lambda x, \lambda y) = \lambda M(x, y)\)。在積分中代入 \(x = \lambda u\)，得 \(\mathrm{I}(\lambda p, \lambda q) = \lambda^{-1}\mathrm{I}(p, q)\)。\(\mathrm{I} = \frac{\pi}{2M}\) 的兩邊都按 \(\lambda^{-1}\) 的比例縮放。

  4. \(M(1, \cos 30^\circ) \approx 0.9318\)，所以週期變長至原來的 \(1.073\) 倍：即長了約 \(7.32\%\)。

2.7 六位還是六百位

  1. \((p^2 + 2q^2)^2 - 2(2pq)^2 = (p^2 - 2q^2)^2 = 1\)；並且 \(577^2 - 2 \times 408^2 = 332\,929 - 332\,928 = 1\)。

  2. \(y_{n+1} = \frac{2y_n^3 + 2}{3y_n^2}\)，而 \(y_{n+1} - \alpha = \frac{2y^3 - 3\alpha y^2 + \alpha^3}{3y^2} = \frac{(y - \alpha)^2(2y + \alpha)}{3y^2}\)。若 \(y > \alpha\)，則 \(\frac{2y + \alpha}{3y^2} < \frac{3y}{3y^2} = \frac1y < \frac1\alpha\)。

  3. \(y - \frac{1/y - a}{-1/y^2} = y + y - ay^2 = y(2 - ay)\)，而 \(1 - ay(2 - ay) = (1 - ay)^2\)。

  4. \(y - \frac{y^{1/3}}{\frac13y^{-2/3}} = y - 3y = -2y\)。誤差公式要求在根的附近 \(\mathrm{f}'\) 不等於零，而且 \(\mathrm{f}''\) 有界（bounded）；但這裏 \(\mathrm{f}'\) 在 \(0\) 處是無限大。

2.8 平方再減二

  1. \((2\cos u)^2 - 2 = 2\cos2u\)，所以由歸納法得 \(x_n = 2\cos(2^{n-1}\theta)\)。\(x_3 = a\) 需要 \(4\theta \equiv \pm\theta\)：即 \(3\theta\) 或 \(5\theta \equiv 0 \pmod{2\pi}\)。排除 \(x_2 = a\) 的情況（不動點 \(a = 2\) 和 \(a = -1\)）後，剩下 \(\theta = \frac{2\pi}{5}, \frac{4\pi}{5}\)：即 \(a = \frac{\sqrt5 - 1}{2}\) 或 \(a = -\frac{\sqrt5 + 1}{2}\)，也就是一個 \(2\)-循環（cycle）的兩個點。

  2. 對於 \(M_5\)，數列是 \(4\)，\(14\)，\(194 \equiv 8\)，\(62 \equiv 0\)：是質數（prime）。對於 \(M_{11}\)，數列是 \(4\)，\(14\)，\(194\)，\(788\)，\(701\)，\(119\)，\(1877\)，\(240\)，\(282\)，\(1736 \neq 0\)：是合成數（composite），而事實上 \(2047 = 23 \times 89\)。

  3. 由 \(A = t - \frac1t = \frac32\) 得 \(t = 2\) 和 \(a = \frac52\)。於是 \(x_2 = \frac{17}{4}\)，\(y_1 = \frac{Ax_1}{x_2} = \frac{15}{17}\)，而 \(\frac{\sqrt{x_2^2 - 4}}{x_2} = \frac{15/4}{17/4} = \frac{15}{17}\)。

  4. \(x_k = t^{2^{k-1}} + t^{-2^{k-1}}\)，而把 \(x_1\cdots x_n\) 乘以 \(t - t^{-1}\) 後，逐項相消得 \(t^{2^n} - t^{-2^n}\)。所求之和變成 \((t - t^{-1})\sum_{n \geq 1}\bigl(\frac{1}{t^{2^n} - 1} - \frac{1}{t^{2^{n+1}} - 1}\bigr) = \frac{t - t^{-1}}{t^2 - 1} = \frac1t\)。當 \(a = 3\) 時，\(t = \frac{3 + \sqrt5}{2}\) 而 \(\frac1t \approx 0.3820\)；級數 \(\frac13 + \frac1{21} + \frac{1}{987} + \cdots\) 與此吻合。

2.9 逐步逼近 e 的分數

  1. \(T_0 = e - 1\)，\(T_1 = 3 - e\)，\(T_2 = 7e - 19\)，\(T_3 = 193 - 71e\)，\(T_4 = 1001e - 2721\)，由此得到 \(\frac{19}{7}\)，\(\frac{193}{71}\)，\(\frac{2721}{1001}\)。由於 \(b_n = b_{n-2} - 2(2n - 1)b_{n-1}\)，而（按歸納法）\(b_{n-1}\) 與 \(b_{n-2}\) 異號，所以 \(b_n\) 與 \(b_{n-2}\) 同號。

  2. \(t(1 - t) \leq \frac14\)，所以 \(T_n < \frac{e}{4^nn!}\)；\(-a_n/b_n\) 的誤差是 \(T_n/|b_n|\)，現在改進了 \(4^n\) 倍。

  3. 若 \(e = \frac pq\)，則 \(qT_n = qa_n + pb_n\) 是整數。由 \(T_n > 0\) 可知它是正整數，所以至少是 \(1\)；但當 \(n\) 足夠大時，\(qT_n < \frac{qe}{n!} < 1\)。

  4. 分部積分（integration by parts）兩次（邊界項為零），得 \(U_n = \frac14\bigl(U_{n-2} - 2(2n - 1)U_{n-1}\bigr)\)，其中 \(U_0 = \frac{e^2 - 1}{2}\) 和 \(U_1 = \frac12\)。所以 \(2^{2n+1}U_n = A_n + B_ne^2\)，其中 \(A_n\)，\(B_n\) 為整數，而 \(0 < U_n < \frac{e^2}{4^nn!}\)。若 \(e^2 = \frac pq\)，則 \(q2^{2n+1}U_n\) 是一個小於 \(\frac{2qe^2}{n!}\) 的正整數，當 \(n\) 足夠大時這是不可能的。所以這個論證確實證明了 \(e^2\) 是無理數（irrational）。
