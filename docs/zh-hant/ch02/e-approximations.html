逐步逼近 e 的分數

引子

怎樣才能找到逼近 \(e\) 的好分數？你可以把級數（series）\(1 + 1 + \frac12 + \frac16 + \cdots\) 截斷，但以分母的大小來衡量，這樣得到的分數並不算特別好。這道題的做法高明得多：它構造出一族積分，每個積分都是形如「整數 \(+\) 整數 \(\times\, e\)」的一個很小的數。如果 \(a + be\) 極小，那麼 \(e\) 就非常接近 \(-a/b\)，於是這些積分便為我們送上一連串極佳的分數：\(\frac{19}{7}\)、\(\frac{193}{71}\)、\(\frac{2721}{1001}\)、…

同樣的技巧，即找出既很小、又形如「你所關心的那個數的整數組合」的積分，正是數學中一些最深刻的無理性證明背後的想法，包括埃爾米特（Hermite）對 \(e\) 是超越數（transcendental）的證明，以及阿佩里（Apéry）對 \(\zeta(3)\) 是無理數（irrational）的證明。

動筆之前

看看 \([0, 1]\) 上的被積函數（integrand）\(\frac{t^n(1-t)^n}{n!}e^t\)。

\(t(1-t)\) 在 \([0, 1]\) 上的最大值是多少？由此可知，當 \(n\) 增大時 \(T_n\) 的大小會怎樣變化？

\(t(1-t)\) 的最大值是 \(\frac14\)，在 \(t = \frac12\) 處取得。所以被積函數至多為 \(\frac{e}{4^n n!}\)，它縮小的速度快得驚人（圖 2.9.1）。這個「小」只是故事的一半。另一半，即 \(T_n\) 具有 \(a_n + b_n e\) 這種特殊形式，則來自分部積分法（integration by parts）。

逐步解題

階段 1 求導兩次

設 \(p(t) = t^n(1-t)^n\)。由積法則（product rule）， \[p'(t) = n t^{n-1}(1-t)^n - n t^n(1-t)^{n-1} = n t^{n-1}(1-t)^{n-1}(1 - 2t).\]

再求導一次。你會得到兩項；把公因式 \(n t^{n-2}(1-t)^{n-2}\) 抽出來。要配合題目要求的形式，你需要把 \((1 - 2t)^2\) 改寫成以 \(t(1-t)\) 表示的式子。怎樣做？

用積法則對 \(n\,[t(1-t)]^{n-1}(1 - 2t)\) 求導（留意 \(\frac{\mathrm{d}}{\mathrm{d}t}[t(1-t)] = 1 - 2t\)）： \[\begin{aligned} p''(t) &= n(n-1)[t(1-t)]^{n-2}(1-2t)^2 - 2n[t(1-t)]^{n-1} \\ &= n t^{n-2}(1-t)^{n-2}\Bigl[(n-1)(1-2t)^2 - 2t(1-t)\Bigr]. \end{aligned}\] 現在 \((1 - 2t)^2 = 1 - 4t + 4t^2 = 1 - 4t(1-t)\)，所以方括號內的式子是 \((n-1) - 4(n-1)t(1-t) - 2t(1-t) = (n-1) - 2(2n-1)t(1-t)\)。■

階段 2 分部積分兩次

\(p(t)\) 在 \(t = 0\) 和 \(t = 1\) 處都等於零。當 \(n \geq 2\) 時，\(p'(t)\) 又如何？在對 \(p(t)e^t\) 作分部積分時，這一點為甚麼重要？

當 \(n \geq 2\) 時，\(p'(t)\) 含有因式 \(t^{n-1}(1-t)^{n-1}\)，所以它在兩個端點也等於零。分部積分兩次，每一個邊界項都是零： \[\int_0^1 p\, e^t\,\mathrm{d}t = \Bigl[p\,e^t\Bigr]_0^1 - \int_0^1 p'\, e^t\,\mathrm{d}t = -\Bigl[p'\,e^t\Bigr]_0^1 + \int_0^1 p''\, e^t\,\mathrm{d}t = \int_0^1 p''\, e^t\,\mathrm{d}t.\] 由第 1 階段，\(p''(t) = n(n-1)\,t^{n-2}(1-t)^{n-2} - 2n(2n-1)\,t^{n-1}(1-t)^{n-1}\)。除以 \(n!\)： \[\frac{p''(t)}{n!} = \frac{t^{n-2}(1-t)^{n-2}}{(n-2)!} - 2(2n-1)\frac{t^{n-1}(1-t)^{n-1}}{(n-1)!}.\] 乘以 \(e^t\) 再積分，便得 \(T_n = T_{n-2} - 2(2n-1)T_{n-1}\)。■

階段 3 整數結構

\(T_0 = \int_0^1 e^t\,\mathrm{d}t = e - 1\)。至於 \(T_1 = \int_0^1 (t - t^2)e^t\,\mathrm{d}t\)，由分部積分得 \(\int_0^1 t e^t\,\mathrm{d}t = 1\) 及 \(\int_0^1 t^2 e^t\,\mathrm{d}t = e - 2\)，所以 \(T_1 = 1 - (e - 2) = 3 - e\)。

\(T_0 = -1 + 1 \cdot e\) 而 \(T_1 = 3 + (-1)\cdot e\)。為甚麼每個 \(T_n\) 都必定具有 \(a_n + b_n e\) 的形式，其中 \(a_n\)、\(b_n\) 是整數？

用強歸納法（strong induction）：若 \(T_{n-2} = a_{n-2} + b_{n-2}e\) 及 \(T_{n-1} = a_{n-1} + b_{n-1}e\)，其中係數都是整數，則 \[T_n = \bigl(a_{n-2} - 2(2n-1)a_{n-1}\bigr) + \bigl(b_{n-2} - 2(2n-1)b_{n-1}\bigr)e,\] 而新的係數也是整數。■

階段 4 很小，因而帶來資訊

當 \(0 < t < 1\) 時，被積函數是正數，並且 \(t^n(1-t)^n \leq 1\) 及 \(e^t < e\)。所以 \[0 < T_n < \int_0^1 \frac{e}{n!}\,\mathrm{d}t = \frac{e}{n!}.\]

把 \(0 < a_n + b_n e < \dfrac{e}{n!}\) 除以 \(|b_n|\)。這說明 \(e\) 與 \(-a_n/b_n\) 之間的距離如何？

除以 \(|b_n|\)（它是正整數，所以至少是 \(1\)）， \[\left| e - \left(\frac{-a_n}{b_n}\right) \right| = \frac{|a_n + b_n e|}{|b_n|} < \frac{e}{n!\,|b_n|} \leq \frac{e}{n!}.\] 右邊趨向 \(0\)，所以 \(-a_n/b_n \to e\)。■

以下是由遞推關係（recurrence）算出的頭幾個分數：

\(n\) 2 3 4 5 6
\(-a_n/b_n\) \(\dfrac{19}{7}\) \(\dfrac{193}{71}\) \(\dfrac{2721}{1001}\) \(\dfrac{49171}{18089}\) \(\dfrac{1084483}{398959}\)
誤差 \(4 \times 10^{-3}\) \(3 \times 10^{-5}\) \(1 \times 10^{-7}\) \(3 \times 10^{-10}\) \(5 \times 10^{-13}\)

分數 \(\frac{2721}{1001}\) 準確至小數點後 \(6\) 位，而分母只有四位數。

回顧

  • 分部積分是製造遞推關係的機器。由於多項式及其導數在兩個端點都等於零，分部積分給出了一個沒有邊界項的簡潔遞推關係。

  • 結構與大小並用。遞推關係說明 \(T_n\) 具有 \(a_n + b_n e\) 的形式；上界說明它很小。單憑其中任何一項，都無法說明怎樣逼近 \(e\)。

  • 不需要的就不要算。題目叫我們不必求出 \(a_n\) 和 \(b_n\) 的值，而論證也從來用不着它們；所需要的只是它們是整數。

背後的數學

\(e\) 是無理數的另一個證明

這道題離一個著名定理只差一步。假設 \(e = p/q\)，其中 \(p, q\) 是正整數。那麼 \[q\,T_n = q a_n + b_n p\] 是一個整數。但是 \(0 < q\,T_n < \dfrac{qe}{n!}\)，而當 \(n\) 很大時，右邊小於 \(1\)。於是 \(q T_n\) 就會是一個嚴格介乎 \(0\) 與 \(1\) 之間的整數，這是不可能的。因此 \(e\) 是無理數。這正是 第 1.4 節 中「把一個整數困在 \(0\) 與 \(1\) 之間」的想法，只是這次由積分而不是級數來實現。正是這一類積分，配合 \(t^n(1-t)^n\) 這樣的多項式，在 1873 年被夏爾·埃爾米特（Charles Hermite）用來證明 \(e\) 是超越數：它不是任何整係數多項式的根。

連分數

表中的分數不僅是好；它們更屬於最佳之列。\(e\) 的連分數（continued fraction）由歐拉（Euler）發現，有一個優美的規律： \[e = [2; 1, 2, 1, 1, 4, 1, 1, 6, 1, 1, 8, \ldots],\] 而它的漸近分數（convergents）是 \(2, 3, \frac83, \frac{11}{4}, \frac{19}{7}, \frac{87}{32}, \frac{106}{39}, \frac{193}{71}, \ldots, \frac{2721}{1001}, \ldots\)。我們的 \(-a_n/b_n\) 恰好是每隔兩個取一個的漸近分數。沒有任何分母更小的分數能更接近 \(e\)。歐拉發現的這個規律本身就是 \(e\) 是無理數的第一個證明，因為只有有理數才有有限的連分數。

阿佩里的奇蹟

1978 年，羅傑·阿佩里（Roger Apéry）宣佈證明了 \(\zeta(3) = 1 + \frac18 + \frac1{27} + \cdots\) 是無理數，這是自歐拉以來一直懸而未決的問題（見 第 2.3 節）。他的證明實在太出人意表，以致在場聽眾起初並不相信。一年後，Frits Beukers 找到一個簡短的版本，所用的積分形如 \[\int_0^1\!\!\int_0^1 \frac{-\ln(xy)}{1 - xy}\, P_n(x) P_n(y)\,\mathrm{d}x\,\mathrm{d}y,\] 其中 \(P_n\) 由 \(\frac{\mathrm{d}^n}{\mathrm{d}x^n}\bigl(x^n(1-x)^n\bigr)\) 構造而成。這些積分很小，是正數，並且形如「整數 \(+\) 整數 \(\times\, \zeta(3)\)」再除以一個受控的分母：這正是本題的策略。至於 \(\zeta(5)\) 或 \(e + \pi\) 是否無理數，至今仍然未知。

思維技巧

很小但不是零

如果已知某個量是若干個數的整數組合，又已知它很小但不是零，它就帶有資訊：關於逼近的資訊，有時還有關於無理性的資訊。

這個模式就是「結構來自代數，大小來自分析」。它在數論中反覆出現，也是分析與代數交匯得最有成果的地方之一。

延伸練習

  1. 運行遞推關係。由遞推關係計算 \(n = 2, 3, 4\) 時的 \(a_n\) 和 \(b_n\)，並核對表中的分數。證明 \(b_n\) 的正負號交替出現。

  2. 更精確的上界。證明 \(0 < T_n < \dfrac{e}{4^n\, n!}\)。這把 \(-a_n/b_n\) 的誤差估計改進了多少？

  3. 無理性的證明。把上面方框中的論證仔細寫出來。你究竟在哪一處用到 \(T_n > 0\)？

  4. 換一個權函數。 較難 把 \(e^t\) 換成 \(e^{2t}\)，重做這道題（即 \(U_n = \int_0^1 \frac{t^n(1-t)^n}{n!}e^{2t}\,\mathrm{d}t\)）。求 \(U_n\) 的遞推關係，證明 \(U_n\) 是 \(1\) 和 \(e^2\) 的有理係數組合，並探究這個論證是否仍能證明 \(e^2\) 是無理數。（與 第 1.4 節 比較。）

延伸閱讀

  • Ivan Niven, Irrational Numbers（Mathematical Association of America）。關於無理性證明的經典小書，當中包括埃爾米特的方法。

  • Alfred van der Poorten, 「A proof that Euler missed」, The Mathematical Intelligencer 1 (1979)。生動地記述阿佩里的證明及其所得到的迴響。

  • Julian Havil, The Irrationals（Princeton University Press）。一部無理數的歷史，為一般數學讀者而寫。
