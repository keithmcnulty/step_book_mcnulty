平方再減二

引子

「平方後減二」幾乎是可以用來生成數列（sequence）的最簡單規則。然而它把實數線分成兩個世界。從 \([-2, 2]\) 之外出發，各項會以比指數增長還要快的速度衝向無窮大。從區間之內出發，各項則永遠被困在其中，四處遊走，而且在一個精確的意義下完全無法預測：這是混沌（chaos）最簡單的例子之一。

同一條規則，用在非常大的整數上，就是盧卡斯－萊默檢驗法（Lucas–Lehmer test）的核心。這是一個高效的檢驗法，用來判斷梅森數（Mersenne number）\(2^p - 1\) 是否質數（prime）；現時的最大質數紀錄，以及其他已知最大的質數中的大部分，都是靠它找到的。本題探討的是故事中「逃逸」的一面，並找出一條隱藏的公式，令這個數列完全可解。

動筆之前

先試幾個初始值。取 \(a = 3\)：\(3, 7, 47, 2207, \ldots\) 取 \(a = 1\)：\(1, -1, -1, -1, \ldots\) 取 \(a = 0\)：\(0, -2, 2, 2, 2, \ldots\) 取 \(a = 0.3\)：\(0.3, -1.91, 1.648, 0.716, -1.487, 0.211, \ldots\)

為甚麼 \([-2, 2]\) 內的數永遠無法逃出去？當 \(-2 \leq x \leq 2\) 時，\(x^2 - 2\) 最大和最小可以是多少？

若 \(-2 \leq x \leq 2\)，則 \(0 \leq x^2 \leq 4\)，所以 \(-2 \leq x^2 - 2 \leq 2\)。區間 \([-2, 2]\) 被映射到它自身之內。這就是第 (ii) 部分的一半。

逐步解題

階段 1 逃逸

第 (i) 部分出現了 \(4^{n-1}\)，暗示與 \(2\) 的距離每一步至少變成四倍。設 \(x_n = 2 + d\)。以 \(d\) 表示，\(x_{n+1}\) 是甚麼？

\(x_{n+1} = (2 + d)^2 - 2 = 2 + 4d + d^2\)。所以若 \(d \geq 0\)，新一項高出 \(2\) 的距離是 \(4d + d^2 \geq 4d\)。

現在用歸納法（induction）。當 \(n = 1\) 時，\(x_1 = a = 2 + 4^0(a - 2)\)。若 \(x_n \geq 2 + 4^{n-1}(a - 2)\)，則 \(d = x_n - 2 \geq 4^{n-1}(a - 2) \geq 0\)，所以 \[x_{n+1} - 2 \geq 4d \geq 4^n (a - 2). \qed\]

階段 2 逃逸當且僅當 \(|a| > 2\)

「當且僅當」（if and only if）表示要分別作兩個證明。第 (i) 部分差不多已經給出哪一個方向？還欠甚麼？

若 \(|a| > 2\)：當 \(a > 2\) 時，由第 (i) 部分得 \(x_n \geq 2 + 4^{n-1}(a - 2) \to \infty\)。當 \(a < -2\) 時，第一步已把正負號糾正過來：\(x_2 = a^2 - 2 > 4 - 2 = 2\)，而由 \(x_2\) 開始的數列，就是以 \(x_2 > 2\) 為初始值的同一個數列，所以它趨向無窮大。

僅當：若 \(|a| \leq 2\)，則 \(a \in [-2, 2]\)，由上面的觀察可知每一項都留在 \([-2, 2]\) 之內。有界（bounded）的數列不可能趨向無窮大。■

階段 3 一條隱藏的公式

第 (iii) 部分看來令人卻步。在動手之前，值得先找出 \(x_n\) 的公式。

若 \(a > 2\)，則存在一個數 \(t > 1\) 使得 \(a = t + \dfrac1t\)。（為甚麼？）以 \(t\) 表示，\(x_2\) 和 \(x_3\) 是甚麼？

當 \(t\) 由 \(1\) 增至 \(\infty\) 時，函數 \(t + 1/t\) 由 \(2\) 遞增至 \(\infty\)，所以每個 \(a > 2\) 都可以寫成這個形式。於是 \[x_2 = \left(t + \frac1t\right)^2 - 2 = t^2 + \frac{1}{t^2}, \qquad x_3 = \left(t^2 + \frac1{t^2}\right)^2 - 2 = t^4 + \frac1{t^4},\] 再由歸納法得 \[x_n = t^{2^{n-1}} + t^{-2^{n-1}}.\] 平方後減 \(2\)，只不過是把指數加倍。這樣題目就變得容易處理了。

階段 4 乘積裂項相消

\(\left(t - \frac1t\right)\left(t + \frac1t\right)\) 是甚麼？若把結果再乘以 \(t^2 + \frac1{t^2}\)，會怎樣？

\(\left(t - \frac1t\right)\left(t + \frac1t\right) = t^2 - \frac1{t^2}\)，然後 \(\left(t^2 - \frac1{t^2}\right)\left(t^2 + \frac1{t^2}\right) = t^4 - \frac1{t^4}\)，如此類推：每個因子 \(x_k\) 都把兩個冪之差中的指數加倍。所以 \[\left(t - \frac1t\right) x_1 x_2 \cdots x_n = t^{2^n} - t^{-2^n}.\]

以 \(t\) 表示並計算 \(x_{n+1}^2 - 4\)，然後與上面的乘積比較。

\[x_{n+1}^2 - 4 = \left(t^{2^n} + t^{-2^n}\right)^2 - 4 = \left(t^{2^n} - t^{-2^n}\right)^2.\] 由於 \(t > 1\)，\(t^{2^n} - t^{-2^n} > 0\)，所以 \(\sqrt{x_{n+1}^2 - 4} = t^{2^n} - t^{-2^n} = \left(t - \frac1t\right) x_1 x_2 \cdots x_n\)。因此 \[\frac{\sqrt{x_{n+1}^2 - 4}}{x_{n+1}} = \frac{\left(t - \frac1t\right) x_1 \cdots x_n}{x_{n+1}},\] 而它對每個 \(n\) 都等於 \(y_n\)，恰好就是 \(A = t - \frac1t\) 的時候。最後，\(\left(t - \frac1t\right)^2 = \left(t + \frac1t\right)^2 - 4 = a^2 - 4\)，所以條件是 \(A = \sqrt{a^2 - 4}\)，即 \[a = \sqrt{A^2 + 4}.\] （因為 \(A > 0\)，這個值大於 \(2\)，符合要求。）■

階段 5 \(y_n\) 是否收斂？

取這個 \(a\) 值時， \[y_n = \frac{\sqrt{x_{n+1}^2 - 4}}{x_{n+1}} = \sqrt{1 - \frac{4}{x_{n+1}^2}}.\] 由第 (ii) 部分知 \(x_{n+1} \to \infty\)，所以 \(\frac{4}{x_{n+1}^2} \to 0\)，而 \(y_n \to 1\)。數列收斂（converge），極限為 \(1\)。■

所以無窮乘積（infinite product）\(x_1 x_2 x_3 \cdots\) 的增長速度與 \(x_{n+1}/A\) 完全相同：我們找到了一個由急速增長的項所組成的乘積的精確增長率。

回顧

  • 不變區域（invariant region）。\([-2, 2]\) 被映射到它自身之內，單憑這一點就解決了第 (ii) 部分的一半。

  • 把問題線性化的代換（substitution）。寫成 \(a = t + 1/t\) 之後，「平方後減 \(2\)」就變成「把指數加倍」。雜亂的非線性行為變得簡單。

  • 又是裂項相消（telescoping）。與 第 2.5 節 中的乘積一樣，由許多因子組成的乘積之所以能摺疊起來，是因為每個因子都與下一個互相配合。

背後的數學

秩序與混沌

在 \([-2, 2]\) 之內會發生甚麼事？在那裏 \(a = t + 1/t\) 行不通（它需要 \(|a| \geq 2\)），但三角函數的版本卻可行：設 \(a = 2\cos\theta\)。則 \(x_2 = 4\cos^2\theta - 2 = 2\cos 2\theta\)，而一般地 \[x_n = 2\cos\bigl(2^{n-1}\theta\bigr).\] 所以在區間之內，這個映射只不過是把角度加倍。聽起來無傷大雅，但把角度加倍其實是混沌的。把 \(\theta/\pi\) 寫成二進制（binary）：加倍會把二進制小數點向右移一位，並丟掉最前面的一位數字。經過 \(50\) 步之後，\(x_n\) 取決於 \(\theta/\pi\) 的第 \(51\) 位二進制數字，所以初始值若有 \(10^{-15}\) 的誤差（一般電腦的精確度），\(50\) 步之後的答案就完全不可靠。這種對初始條件的敏感依賴（sensitive dependence on initial conditions）正是混沌的標誌，見圖 2.8.1。映射 \(x \mapsto x^2 - 2\) 經變數代換後，等價於著名的邏輯斯諦映射（logistic map）\(x \mapsto 4x(1 - x)\)，我們會在 第 8.7 節 再遇上它。

尋找最大的質數

梅森數是指 \(M_p = 2^p - 1\)。盧卡斯（Édouard Lucas）在 1876 年發現了一個出色的檢驗法，用來判斷 \(M_p\) 是否質數（其中 \(p\) 為奇質數），其後萊默（Derrick Lehmer）在 1930 年把它完善：由 \(s_0 = 4\) 開始，反覆平方後減 \(2\)，每次都取模（modulo）\(M_p\) 化簡。則 \[M_p \text{ 是質數} \iff s_{p-2} \equiv 0 \pmod{M_p}.\] 以 \(M_7 = 127\) 為例：\(s = 4, 14, 194 \equiv 67, 67^2 - 2 \equiv 42, 42^2 - 2 \equiv 111, 111^2 - 2 \equiv 0\)，所以 \(127\) 是質數。它與本題的聯繫就在於那個代換：\(4 = t + 1/t\)，其中 \(t = 2 + \sqrt3\)，所以 \(s_k = (2+\sqrt3)^{2^k} + (2-\sqrt3)^{2^k}\)，而檢驗法的證明用到形如 \(a + b\sqrt3\) 的數的算術，與 第 1.6 節 的高斯整數（Gaussian integers）頗為相似。由於每一步只需要一次平方，這個檢驗法極為快速，這就是為甚麼已知最大的質數中的大部分，包括現時的紀錄保持者，都是梅森質數（並非全部都是：其他特殊形式，例如 \(a^{2^n} + 1\)，也有各自的快速檢驗法）。在本書撰寫之時，紀錄是 \(2^{136279841} - 1\)，這個數有多於 \(41\) 百萬位數字，於 2024 年發現。

曼德博集合

把 \(-2\) 換成任意常數 \(c\)，並容許複數：\(z \mapsto z^2 + c\)。令 \(0\) 的軌道保持有界的所有 \(c\) 所組成的集合，就是曼德博集合（Mandelbrot set）。我們的映射對應 \(c = -2\)，即曼德博集合最左邊的一點，而軌道保持有界的初始值所組成的集合（它的茹利亞集合（Julia set））正好是我們在第 (ii) 部分找到的區間 \([-2, 2]\)。對於幾乎所有其他的 \(c\)，這個集合都是分形（fractal）。

思維技巧

轉換變數，令映射變得簡單

若一個迭代（iteration）看來很複雜，就找一個代換，把它變成簡單的東西，例如加倍或加上一個常數。

這裏 \(x = t + 1/t\) 和 \(x = 2\cos\theta\) 把 \(x \mapsto x^2 - 2\) 變成了加倍。在動力系統（dynamical systems）理論中，這稱為共軛（conjugacy），而找到共軛往往是徹底理解一個系統的關鍵。

延伸練習

  1. 區間之內。證明若 \(a = 2\cos\theta\)，則 \(x_n = 2\cos(2^{n-1}\theta)\)。求所有使得 \(x_3 = a\) 但 \(x_2 \neq a\) 的 \(a\) 值。（提示：你需要 \(4\theta \equiv \pm\theta\)，模 \(2\pi\)。）

  2. 手算盧卡斯－萊默檢驗法。用這個檢驗法證明 \(M_5 = 31\) 是質數，而 \(M_{11} = 2047\) 不是。（對 \(M_{11}\) 你需要九步；用計算機會有幫助。把 \(2047\) 作因數分解，以驗證你的結論。）

  3. 一個具體例子。取 \(A = \frac{3}{2}\)。求 \(a\) 和 \(t\)，並以數值驗證公式 \(y_1 = \sqrt{x_2^2 - 4}/x_2\)。

  4. 裂項相消的和。 較難 設 \(a = t + 1/t\) 且 \(t > 1\)，證明 \[\frac{1}{x_1 x_2 \cdots x_n} = \frac{t - t^{-1}}{t^{2^n} - t^{-2^n}}.\] 利用恆等式 \(\dfrac{1}{z - 1} - \dfrac{1}{z^2 - 1} = \dfrac{z}{z^2 - 1}\)，其中 \(z = t^{2^n}\)，由此推出 \[\frac{1}{x_1} + \frac{1}{x_1 x_2} + \frac{1}{x_1 x_2 x_3} + \cdots = \frac1t.\] 當 \(a = 3\) 時，以數值驗證這個結果。
