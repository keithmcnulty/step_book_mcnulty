第 3 章 · 函數、不等式與嚴謹

「延伸練習」答案

以下只是簡短的答案和提示，並非完整解答：這裏只列出結果和關鍵步驟，方便你核對自己的做法。請先認真做過每道練習，然後才看答案。

3.1 找出錯處

  1. 當 \(x\) 由 \(-1\) 變到 \(1\) 時會經過 \(0\)，而 \(t = 1/x\) 在該處沒有定義：這個代換（substitution）在區間上並不連續（continuous）。正確的結果是 \(\int_{-1}^1\frac{\mathrm{d}x}{(1 + x^2)^2} = \frac12 + \frac\pi4\)（用 \(x = \tan\theta\)），而 \(\int_{-1}^1\frac{-t^2}{(1 + t^2)^2}\,\mathrm{d}t = \frac12 - \frac\pi4\)。

  2. (a) 正確：兩邊的對數（logarithm）都是 \(\ln a\ln b\)。(b) 錯誤：當 \(\theta = 0\) 時，\(\cos0 = 1 \neq \sin1\)。（事實上兩者永不相等，因為 \(|\sin\theta \pm \cos\theta| \leq \sqrt2 < \frac\pi2\)。）(c) 錯誤：非常數的多項式（polynomial）是無界的，而一個常數不可能同時與 \(1\) 和 \(-1\) 相差不超過 \(10^{-6}\)。(d) 正確：由算術—幾何平均不等式（AM–GM），\(x^4 + x^{-4} \geq 2\)，等號在 \(x = 1\) 時成立。

  3. 由 \(n = 1\) 推到 \(n = 2\) 的一步並不成立：兩匹馬當中的「前 \(1\) 匹」與「後 \(1\) 匹」並不重疊。

  4. \(\int_\varepsilon^1x^{-1/2}\,\mathrm{d}x = 2 - 2\sqrt\varepsilon \to 2\)，所以由對稱性，該積分（作為極限）存在，其值為 \(4\)。

3.2 倒過來的 AM–GM

  1. 設 \(a_1, \ldots, a_{n-1}\) 的平均值為 \(A\)，幾何平均（geometric mean）為 \(G\)，再加入 \(A\) 作為第 \(n\) 個數。平均值仍然是 \(A\)，所以 \((G^{n-1}A)^{1/n} \leq A\)，由此得 \(G \leq A\)。

  2. 這 \(n + 1\) 個數的平均值為 \(1 + \frac{1}{n+1}\)，幾何平均為 \((1 + \frac1n)^{n/(n+1)}\)，而且它們並非全部相等，所以不等式是嚴格的；把兩邊同時取 \(n + 1\) 次方即可。

  3. 各個面的面積為 \(ab\)、\(bc\)、\(ca\)，而 \(S = 2(ab + bc + ca)\)。由 AM–GM 得 \(\frac S6 \geq (abc)^{2/3} = V^{2/3}\)，等號在 \(ab = bc = ca\) 時成立，即正方體。

  4. 對 \(1/a_i\) 應用 AM–GM：\(\frac1n\sum\frac1{a_i} \geq \frac1G\)。再取倒數。

3.3 凸性的威力

  1. 若 \(\mathrm{f}'' < 0\)，斜率遞減，所以曲線位於每條弦（chord）的上方。取 \(t = \frac13\)：\(\mathrm{f}\bigl(\frac{u + v + w}{3}\bigr) \geq \frac13\mathrm{f}(u) + \frac23\mathrm{f}\bigl(\frac{v + w}{2}\bigr) \geq \frac13\bigl(\mathrm{f}(u) + \mathrm{f}(v) + \mathrm{f}(w)\bigr)\)。

  2. \((\ln\sin x)'' = -\mathrm{cosec}^2x < 0\)，所以 \(\ln\sin\) 在 \((0, \pi)\) 上是凹（concave）函數。由延森不等式（Jensen’s inequality）得 \(\frac13\ln(\sin A\sin B\sin C) \leq \ln\sin\frac\pi3\)，所以該乘積最大為 \(\bigl(\frac{\sqrt3}{2}\bigr)^3\)。

  3. 在 \((0, \frac\pi2)\) 上 \((\tan x)'' = 2\sec^2x\tan x > 0\)；由延森不等式得 \(\tan A + \tan B + \tan C \geq 3\tan\frac\pi3 = 3\sqrt3\)。

  4. \((x^2)'' = 2 > 0\)；由延森不等式即得所求的不等式，它說明 \(\frac1n\sum a_i^2 - \bar a^2\)（即方差（variance））是非負的。

3.4 以面積證明不等式

  1. 取 \(\mathrm{f} = \sin\)，定義在 \([0, \frac\pi2]\) 上，等號在 \(b = \mathrm{f}(a)\) 時成立；取 \(a = \arcsin t\)、\(b = t\)：\(t\arcsin t = (1 - \cos(\arcsin t)) + \int_0^t\arcsin y\,\mathrm{d}y\)。把所得結果的右邊求導，得 \(\arcsin t + \frac{t}{\sqrt{1 - t^2}} - \frac{t}{\sqrt{1 - t^2}} = \arcsin t\)。

  2. 在楊氏不等式（Young’s inequality）中取 \(p = q = 2\)，得 \(ab \leq \frac12(a^2 + b^2)\)。若 \(\sum a_i^2 = \sum b_i^2 = 1\)，逐項相加得 \(\sum a_ib_i \leq 1\)。一般情況下，把這個結果應用於 \(a_i/\sqrt{\sum a_j^2}\) 和 \(b_i/\sqrt{\sum b_j^2}\)。

  3. \(\int_0^a(e^x - 1)\,\mathrm{d}x = e^a - 1 - a\)，而 \(\int_0^b\ln(1 + y)\,\mathrm{d}y = (1 + b)\ln(1 + b) - b\)。等號在 \(b = e^a - 1\) 時成立。

  4. \(t = 1\)：\(1.571\) 對 \(1\)；\(t = 2\)：\(0.524\) 對 \(0.268\)；\(t = 10\)：\(0.1002\) 對 \(0.0501\)。當 \(t\) 很大時，\(t - \sqrt{t^2 - 1} = \frac{1}{t + \sqrt{t^2 - 1}} \approx \frac{1}{2t}\)。這個界來自 \(a = 0\) 的情況，此時 \((*)\) 只是說 \(0 \leq \int_0^b\arcsin y\,\mathrm{d}y\)；當 \(b\) 很小時，這塊面積約為 \(\frac{b^2}{2}\)，是 \(b\arcsin b \approx b^2\) 的一半，把它捨去便損失了因子 \(2\)。

3.5 \(\pi^e\) 還是 \(e^\pi\)？

  1. \(n^m = m^n\) 即 \(h(n) = h(m)\)。\(h\) 在 \((1, e)\) 上遞增，其後遞減，所以兩數之中有一個小於 \(e\)：它必定是 \(2\)（因為 \(h(1) = 0\) 這個值不會再次取到），於是另一個是 \(4\)。唯一的一對是 \(\{2, 4\}\)。

  2. \(e < 3 < \pi\)，而 \(h\) 在該處遞減，所以 \(h(3) > h(\pi)\)，即 \(3^\pi > \pi^3\)。\(\frac94\) 和 \(\sqrt5\) 都小於 \(e\)，而 \(\frac94 > \sqrt5\)，所以 \(h(\frac94) > h(\sqrt5)\)，由此得第二個結果。對於 \(1 < x < 2\)：由於 \(3 < x + 2 < 4\)，有 \(h(x) < h(2) = h(4) < h(x + 2)\)，所以 \(x^{x+2} < (x + 2)^x\)。最後，\(9^{\sqrt2} = 3^{2\sqrt2}\)，而 \(\sqrt2^{\,9} = 16\sqrt2 = (2\sqrt2)^3\)。因為 \(e^2 < 8\)，所以 \(e < 2\sqrt2 < 3\)，而 \(h\) 在該處遞減，故 \(h(2\sqrt2) > h(3)\)，由此得 \((2\sqrt2)^3 > 3^{2\sqrt2}\)：\(\sqrt2^{\,9}\) 較大。

  3. \(e^{\pi/e - 1} > \frac\pi e\)，所以 \(e^{\pi/e} > \pi\)；再把兩邊取 \(e\) 次方。

3.6 斜率的界

  1. 兩邊都是二次多項式，並且在 \(x = -1, 0, 1\) 處取值相同，所以兩者相等（拉格朗日插值（Lagrange interpolation））。求導得 \(\mathrm{f}(-1)(x - \frac12) - 2\mathrm{f}(0)x + \mathrm{f}(1)(x + \frac12)\)。

  2. 在 \([-1, 1]\) 上 \(|\mathrm{f}'(x)| \leq |x - \frac12| + 2|x| + |x + \frac12| \leq 4\)，等號只在 \(x = \pm1\) 時成立，而且必須 \(\mathrm{f}(1)\)、\(\mathrm{f}(-1)\)、\(-\mathrm{f}(0)\) 全部等於 \(1\) 或全部等於 \(-1\)。二次多項式由這三個值唯一確定，於是得 \(\pm(2x^2 - 1)\)。

  3. 由 \(T_3(\cos\theta) = \cos3\theta\) 得 \(4x^3 - 3x\)，而 \(T_3'(1) = 12 - 3 = 9\)。由 \(\cos(n + 1)\theta + \cos(n - 1)\theta = 2\cos\theta\cos n\theta\)，得 \(T_{n+1} = 2xT_n - T_{n-1}\)，以及 \(T_4 = 8x^4 - 8x^2 + 1\)。

  4. \(-\sin\theta\,T_n'(\cos\theta) = -n\sin n\theta\)。當 \(\theta \to 0\) 時，\(\frac{n\sin n\theta}{\sin\theta} \to n^2\)。

3.7 \(\pi^2 \leq 10\)

  1. \(\int_0^\pi\mathrm{f}^2 = \frac{\pi^9}{630}\)，而 \(\int_0^\pi(\mathrm{f}')^2 = \frac{2\pi^7}{105}\)，所以由 \((*)\) 得 \(\pi^2 \leq 12\)。與 \(\sin x\) 相比，這個四次多項式在兩端附近過於平坦，在中間又過於尖聳，所以它的斜率與大小之比離最優值較遠。

  2. \(\int_0^\pi(\sin x + \sin2x)^2 = \frac\pi2 + \frac\pi2 = \pi\)（交叉項的積分為 \(0\)），而 \(\int_0^\pi(\cos x + 2\cos2x)^2 = \frac\pi2 + 2\pi = \frac{5\pi}{2}\)。

  3. 設 \(\mathrm{g}(x) = \mathrm{f}(\pi x/L)\)。左邊按 \(\frac L\pi\) 的比例縮放，而 \(\int(\mathrm{g}')^2\) 則按 \(\frac{\pi}{L}\) 的比例縮放。對弦線而言，最低頻率與 \(\frac1L\) 成正比：長度減半，音高便加倍。

  4. 界 \(\pi^2 \leq \int(\mathrm{f}')^2\big/\!\int\mathrm{f}^2\)（採用適當的單位）在 \(\lambda \approx 1.133/\pi^2\) 時取得最小值，由此得 \(\pi^2 \leq 9.86975\)，而真確值為 \(9.86960\)。

3.8 由加法公式決定的函數

  1. 代入 \(x = y = 0\) 得 \(\mathrm{g}(0) = 0\)。對 \(y\) 求導並取 \(y = 0\)，得 \(\mathrm{g}'(x) = k(1 + \mathrm{g}(x)^2)\)，所以 \(\frac{\mathrm{d}}{\mathrm{d}x}\arctan\mathrm{g}(x) = k\)，於是 \(\mathrm{g}(x) = \tan kx\)。

  2. 對 \(y\) 求導得 \(\mathrm{f}'(x + y) = \mathrm{f}'(y)\)，所以 \(\mathrm{f}'\) 是常數 \(k\)；又 \(\mathrm{f}(0) = 0\)（代入 \(x = y = 0\)）。

  3. \(\mathrm{f}(x) = \mathrm{f}(x/2)^2 \geq 0\)，而且 \(\mathrm{f}\) 永不為 \(0\)（否則它處處為 \(0\)）。用歸納法（induction）得 \(\mathrm{f}(n) = a^n\)；由 \(\mathrm{f}(1/n)^n = \mathrm{f}(1) = a\) 及 \(\mathrm{f}(1/n) > 0\) 得 \(a^{1/n}\)；於是 \(\mathrm{f}(m/n) = \mathrm{f}(1/n)^m\)。若沒有連續性，函數在無理數處的值便不受限制：存在一些利用「哈默爾基（Hamel basis）」構造出來的奇怪解，它們並不是 \(a^x\)。

  4. 每次點火都使快度（rapidity）增加 \(\phi = \operatorname{artanh}\frac12\)，所以點火 \(k\) 次之後，速率為 \(\tanh k\phi = \frac{3^k - 1}{3^k + 1}\)：\(0.8c\)、\(\frac{13}{14}c \approx 0.929c\) 和 \(\frac{40}{41}c \approx 0.976c\)。

3.9 創造一個新函數

  1. 當 \(x = -1\) 時，\(x^2 - 2^x = \frac12 > 0\)；當 \(x = 0\) 時其值為 \(-1\)：所以有一個負根。設 \(x = -2u/\ln2\)，則 \(x^2 = 2^x\)（其中 \(x < 0\)，取 \(x = -2^{x/2}\)）化為 \(ue^u = \frac{\ln2}{2}\)，所以 \(u = \mathrm{g}\bigl(\frac{\ln2}{2}\bigr)\)，而 \(x \approx -0.7667\)。

  2. \(\mathrm{g}'e^{\mathrm{g}}(1 + \mathrm{g}) = 1\)，而 \(e^{\mathrm{g}} = x/\mathrm{g}\)。當 \(x = -\frac1e\) 時，\(\mathrm{g} = -1\)，斜率為無限大（圖像在該處是垂直的）。

  3. 設 \(x = we^w\)，則 \(\mathrm{d}x = (1 + w)e^w\,\mathrm{d}w\)，而 \(w\) 由 \(0\) 變到 \(1\)：\(\int_0^1w(1 + w)e^w\,\mathrm{d}w = \bigl[(w^2 - w + 1)e^w\bigr]_0^1 = e - 1\)。

  4. \(T = \sqrt2^{\,T}\) 即 \(\frac{\ln T}{T} = \frac{\ln2}{2}\)，所以 \(T = 2\) 或 \(4\)。各項 \(1.414, 1.633, 1.761, \ldots\) 遞增，並且一直小於 \(2\)（若 \(t_n < 2\)，則 \(t_{n+1} < \sqrt2^{\,2} = 2\)），所以 \(T = 2\)；不動點（fixed point）\(4\) 是排斥（repelling）的。
