第 3 章 \(\cdot\) 引言

把事情做對

在數學裏，你並不是理解了甚麼，你只是習慣了它們。

— 馮·諾伊曼（John von Neumann）

以下是 \(1 = 2\) 的一個「證明」（proof）。設 \(a = b\)。那麼 \(a^2 = ab\)，所以 \(a^2 - b^2 = ab - b^2\)，因式分解後得 \((a + b)(a - b) = b(a - b)\)。約去 \(a - b\) 得 \(a + b = b\)，而由於 \(a = b\)，這就是說 \(2b = b\)，所以 \(2 = 1\)。

你大概已經看出問題所在：由於 \(a = b\)，「約去 \(a - b\)」其實就是除以零。但請留意，每一步看起來都多麼合理，而錯誤又多麼容易藏在一個例行的步驟之中。真正的數學裏，真正的錯誤很少這樣明顯，有史以來最偉大的一些數學家也曾被它們騙倒。本章要談的，正是能把這些錯誤揪出來的思考習慣：精確的定義、小心運用定理，以及對看來太過容易的論證抱持適度的懷疑。

為甚麼嚴謹很重要

在中學，數學主要是求出答案。到了大學，數學主要是知道自己的答案是對的，並且能夠說服別人。這個轉變是中學數學與大學數學之間最大的一個變化，也可能令人不安。一件「顯然」成立的事，為甚麼要花一整頁去證明？

答案是：「顯然」並不可靠。分析（analysis）的歷史上，滿是看似顯然、實則錯誤的結果：連續（continuous）函數除了可能在少數幾個孤立點之外必定可導（differentiable）（安培（André-Marie Ampère）在 1806 年發表過一個「證明」；到了 1872 年，魏爾斯特拉斯（Weierstrass）找到一個處處不可導的連續函數）；連續函數的收斂（convergent）和仍然連續（柯西（Cauchy）相信這一點；阿貝爾（Abel）找到了反例（counterexample））；收斂級數（series）的各項可以重新排列而不改變其和（一般而言，不可以）。嚴謹（rigour）並不是吹毛求疵，而是分辨真確與似是而非的唯一可靠方法。

不等式：分析的基本工具

本章的第二個主題是不等式（inequality）。在中學數學裏，大部分結果都是等式：這個等於那個。在分析裏，大部分結果都是不等式：這個至多是那個。要證明一個數列收斂，你要證明誤差小於任何容許的限度；要證明一個積分存在，你要證明某個和有界；要估計一個近似值有多好，你要給誤差定出一個界。專業的分析學家花在證明不等式上的時間，遠多於證明等式，而你將在這裏遇到的經典不等式（AM–GM、詹森（Jensen）、楊（Young）、赫爾德（Hölder）、柯西—施瓦茲（Cauchy–Schwarz））正是這一行的看家工具。

這些不等式本身也十分精彩。一條關於函數的不等式，配上一個精心挑選的例子，就能證明 \(\pi^2 \leq 10\)（第 3.7 節）。關於對數圖像形狀的一個事實，就能判定 \(\pi^e\) 與 \(e^\pi\) 哪個較大（第 3.5 節）。一位化學家關於量度誤差的提問，引出了數學中最重要的一些多項式（第 3.6 節）。

你在大學會遇到甚麼

嚴謹是大學一年級分析（Analysis）課程的主題，也是另一門常稱為數與集合（Numbers and Sets）或數學基礎（Foundations）的課程的主題，你會在那裏學習怎樣精確地書寫證明。你會遇到連續性和可導性的正式定義，以及帶有精確假設（hypothesis）的定理（介值定理（intermediate value theorem）、中值定理（mean value theorem）、極值定理（extreme value theorem）），而這些假設確實缺一不可。往後的課程會把本章的不等式發展成一門門完整的學科：泛函分析（functional analysis）研究函數空間，並以 第 3.4 節 和 第 3.7 節 中那類積分來量度其中的函數；凸分析（convex analysis）和最優化（optimisation）由 第 3.3 節 發展而來；逼近論（approximation theory）由 第 3.6 節 發展而來；而像 第 3.9 節 中那樣的特殊函數（special functions），則在應用數學和物理學中隨處可見。

貫穿本章的問題

三個大問題

  1. 怎樣知道一個論證是正確的？看似合理的論證通常會在哪些地方出錯？又應該怎樣檢查？

  2. 怎樣證明一條不等式？經典不等式從何而來？又怎樣選擇用哪一條？

  3. 函數究竟是甚麼？一個函數可否由它具有的某種性質來定義，而不是由公式來定義？當舊有的函數不夠用時，我們可否創造新的函數？

本章以找錯開始（第 3.1 節），然後逐一探討各條經典不等式，每條都從不同的角度切入：一種不尋常的歸納法（induction）、凸性（convexity）、面積、圖像的形狀、多項式插值（polynomial interpolation）和試驗函數（test function）。最後兩節討論由性質定義的函數：由加法定律（addition law）得出的 \(e^x\) 和 \(\tanh x\)，以及一個以反函數（inverse）形式定義的全新函數。
