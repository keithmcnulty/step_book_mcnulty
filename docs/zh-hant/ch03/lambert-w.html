創造一個新函數

引子

你能解 \(e^{-x} = 5x\) 嗎？計算機上沒有任何一個函數幫得上忙。移項整理也無濟於事：\(x\) 同時困在指數函數的裏面和外面。你可以用試誤法（trial and improvement）求出數值答案，但並沒有甚麼「公式」。

真的沒有嗎？這道題踏出了大膽的一步：如果某一族方程無法用已知的函數解出來，那就發明一個新函數來解它們。數學家當年正是這樣得到 \(\sqrt{x}\)（\(x^2\) 的反函數）、\(\ln x\)（\(e^x\) 的反函數）和 \(\arcsin x\) 的。這裏的新函數是 \(xe^x\) 的反函數（inverse function），現稱為蘭伯特 W 函數（Lambert W function）。有了它，從 \(x^x = 10\) 到一條物理定律，範圍廣得出人意料的各種方程都可以精確地解出來。

動筆之前

「解」一條方程，究竟是甚麼意思？\(x = \sqrt{2}\) 是 \(x^2 = 2\) 的解，還是只不過是那個解的名字？

兩者皆是。\(\sqrt2\) 是「平方等於 \(2\) 的那個正數」的名字；我們接受它作為答案，是因為函數 \(\sqrt{\phantom{x}}\) 已為人熟知、容易計算，而且性質清楚。一個答案算不算「公式」，取決於我們約定了為哪些函數命名。這道題為這份名單再添一個。

逐步解題

階段 1 曲線 \(y = xe^x\)

\(\frac{\mathrm{d}y}{\mathrm{d}x} = e^x + xe^x = (1 + x)e^x\)，它只在 \(x = -1\) 處為零，此時 \(y = -e^{-1}\)。導數（derivative）在 \(x < -1\) 時為負，在 \(x > -1\) 時為正，所以這是一個極小值（minimum）。

當 \(x \to +\infty\) 和 \(x \to -\infty\) 時，\(xe^x\) 會怎樣？曲線在哪裏與坐標軸相交？

當 \(x \to \infty\) 時，\(xe^x \to \infty\)。當 \(x \to -\infty\) 時，\(xe^x \to 0\)（從下方趨近），因為指數衰減勝過線性增長。曲線通過原點。所以它從負 \(x\) 軸的稍下方進來，下降至極小點 \((-1, -\frac1e)\)，然後上升穿過 \((0, 0)\)，再急速向上（圖 3.9.1）。

階段 2 反函數

要有反函數，\(\mathrm{f}\) 必須是一對一（one-to-one）的，所以必須把它限制在一個嚴格遞增（strictly increasing）或嚴格遞減的區域上。包含右邊部分的最大區間是 \([-1, \infty)\)，所以 \(a = -1\)。在 \([-1, \infty)\) 上，\(\mathrm{f}\) 由 \(-\frac1e\) 遞增至 \(\infty\)，所以反函數 \(\mathrm{g}\) 定義在 \([-\frac1e, \infty)\) 上，由 \(\mathrm{g}(-\frac1e) = -1\) 開始遞增，經過 \(\mathrm{g}(0) = 0\)，並且增長緩慢（當 \(x\) 很大時，比 \(\ln x\) 還要慢）。它的圖像是 \(y = xe^x\) 右邊部分關於直線 \(y = x\) 的反射，在 \((-\frac1e, -1)\) 處有一條垂直切線。

\(\mathrm{g}\) 的定義性質是 \[\mathrm{g}(z)\,e^{\mathrm{g}(z)} = z, \qquad \mathrm{g}(z) \geq -1.\] 所以 (iii) 中每一部分的策略都一樣：把方程整理成 \((\text{某個式子})\,e^{(\text{同一個式子})} = (\text{一個數})\) 的形式。

階段 3 四條方程

(a) \(e^{-x} = 5x\)。乘以 \(e^x\) 再除以 \(5\)：\(xe^x = \frac15\)。所以 \(x = \mathrm{g}\bigl(\frac15\bigr) \approx 0.169\)。由於 \(xe^x\) 在 \(x < 0\) 時為負，任何根都是正數，而 \(xe^x\) 在 \(x > 0\) 時遞增，所以這是唯一的根。

在 (b) 和 (c) 中，未知數以 \(x\ln x\) 的形式出現。用甚麼代換（substitution）可以把 \(x\ln x\) 變成 \(ue^u\) 的形式？

設 \(x = e^u\)，則 \(\ln x = u\)，而 \(x\ln x = ue^u\)。

(b) \(2x\ln x + 1 = 0\) 變成 \(ue^u = -\frac12\)。但對所有實數 \(u\) 都有 \(ue^u \geq -\frac1e \approx -0.368\)，而 \(-\frac12 < -\frac1e\)。所以沒有實根。

(c) \(3x\ln x + 1 = 0\) 變成 \(ue^u = -\frac13\)，而 \(-\frac1e < -\frac13 < 0\)。高度為 \(-\frac13\) 的水平線與 \(y = ue^u\) 相交兩次，在極小點 \(u = -1\) 的兩側各一次。右邊的根是 \(u = \mathrm{g}\bigl(-\frac13\bigr)\)，由此得 \[x = e^{\mathrm{g}(-1/3)} \approx 0.538.\] 另一個根滿足 \(u < -1 < \mathrm{g}\bigl(-\frac13\bigr)\)，而 \(x = e^u\) 隨 \(u\) 遞增，所以我們找到的根是兩者之中較大的一個。（另一個約為 \(0.220\)。）

現在試做 (d)，\(x = 3\ln x\)。（提示：兩邊取指數，設法湊成 \((\text{某個式子})\,e^{\text{某個式子}}\) 的形式，其中「某個式子」是 \(x\) 的倍數。）

(d) \(x = 3\ln x\) 即 \(e^{x/3} = x\)，所以 \(xe^{-x/3} = 1\)，再乘以 \(-\frac13\)， \[\left(-\frac x3\right)e^{-x/3} = -\frac13.\] 所以 \(-\frac x3\) 是在 (c) 中找到的 \(ue^u = -\frac13\) 的兩個解之一。取由 \(\mathrm{g}\) 給出的那一個，\(x = -3\,\mathrm{g}\bigl(-\frac13\bigr) \approx 1.857\)。另一個根來自另一個解 \(u < \mathrm{g}(-\frac13)\)，它給出較大的 \(x = -3u\)。所以這一次我們找到的根是兩者之中較小的一個。（另一個約為 \(4.536\)。）■

階段 4 \(x^x = 10\)

取對數，\(x\ln x = \ln 10\)。設 \(x = e^u\)，這就是 \(ue^u = \ln 10\)，所以 \(u = \mathrm{g}(\ln 10)\)，而 \[x = e^{\mathrm{g}(\ln 10)} \approx 2.506.\] 由於 \(\mathrm{g}(z)e^{\mathrm{g}(z)} = z\)，我們也可以把它寫成 \(x = \dfrac{\ln 10}{\mathrm{g}(\ln 10)}\)。■

回顧

  • 為缺少的函數命名。當一條方程無法用已知函數解出時，把一個新函數定義為反函數，是正當的做法，而且往往富有啟發性。

  • 整理成標準形式。(iii) 和 (iv) 的每一部分最終都歸結為 \(ue^u = \text{常數}\)，用的是 \(x = e^u\) 或 \(u = -\frac x3\) 之類的代換。

  • 用圖像數根的個數。\(ue^u = c\) 有零個、一個還是兩個解，只取決於 \(c\) 相對於極小值 \(-\frac1e\) 的位置。

背後的數學

歷史悠久、名字卻很新的函數

蘭伯特（Johann Heinrich Lambert）在 1758 年研究過這類方程，歐拉（Euler）在 1783 年作了進一步的研究。但這個函數一直沒有標準名稱，直到 1990 年代，電腦代數系統（computer algebra system）Maple 的開發者需要為它起一個名字。1996 年，Robert Corless、Gaston Gonnet、David Hare、David Jeffrey 和 Donald Knuth 發表了論文「On the Lambert W function」，匯集了它的性質和應用。這篇論文已被引用數千次，而 W 現已內置於大多數數學軟件之中。題目中的函數 \(\mathrm{g}\) 是主分支（principal branch）\(W_0\)；圖 3.9.1 中的虛線，即給出 (c) 和 (d) 中第二個根的那條曲線，是另一個實分支 \(W_{-1}\)。

W 出現在哪裏

  • 維恩位移定律（Wien’s displacement law）。熱的物體輻射最強的波長與其溫度成反比。當中的常數來自解方程 \(5(1 - e^{-x}) = x\)，其正數解為 \(x = 5 + W\bigl(-5e^{-5}\bigr) \approx 4.965\)。這就是為甚麼約 \(5800\) K 的太陽看起來是黃白色，而溫度較低的紅矮星看起來是紅色。

  • 冪塔（power tower）。無窮冪塔 \(x^{x^{x^{\cdot^{\cdot^{\cdot}}}}}\) 在 \(e^{-e} \leq x \leq e^{1/e}\) 時收斂（converge），其值為 \(\dfrac{W(-\ln x)}{-\ln x}\)。

  • 人口與傳染病模型。在最簡單的模型中，一場傳染病的最終規模，以及某些增長模型中達到指定人口所需的時間，都由 W 給出。

初等函數

\(W\) 真的是新函數嗎？還是可以用 \(\exp\)、\(\ln\)、根式和三角函數寫出來？它確實是新的：一條可追溯至 1830 年代劉維爾（Joseph Liouville）的定理表明，\(W\) 不是初等函數（elementary function）。同一套理論還表明，一些看似平平無奇的積分，例如 \(\int e^{-x^2}\,\mathrm{d}x\)，無法用初等函數表示，這就是為甚麼正態分佈（normal distribution）需要自己專用的特殊函數。

思維技巧

以反函數作為解

方程 \(\mathrm{f}(x) = c\) 的解是 \(x = \mathrm{f}^{-1}(c)\)，前提是把 \(\mathrm{f}\) 限制成一對一的函數。這個限制決定了你得到的是哪一個解。

許多看似不同的方程，其實是同一條方程的不同偽裝；找出能揭示共同形式的代換，就是關鍵的一步。

延伸練習

  1. 二、四，還有一個。方程 \(x^2 = 2^x\) 有顯而易見的解 \(x = 2\) 和 \(x = 4\)（比較 第 3.5 節）。證明它還有一個負數解，而這個解是 \[x = -\frac{2}{\ln 2}\,\mathrm{g}\!\left(\frac{\ln 2}{2}\right) \approx -0.767.\]

  2. 一個導數。對 \(\mathrm{g}(x)e^{\mathrm{g}(x)} = x\) 作隱函數微分（implicit differentiation），證明當 \(x \neq 0\) 時， \[\mathrm{g}'(x) = \frac{\mathrm{g}(x)}{x\bigl(1 + \mathrm{g}(x)\bigr)}.\] 在 \(x = -\frac1e\) 處會怎樣？

  3. 一個積分。利用代換 \(x = we^w\) 證明 \(\displaystyle\int_0^e \mathrm{g}(x)\,\mathrm{d}x = e - 1\)。

  4. 冪塔。假設冪塔 \(T = \sqrt2^{\sqrt2^{\sqrt2^{\cdots}}}\) 收斂，證明 \(T = \sqrt2^{\,T}\)，並由此推出 \(T = 2\) 或 \(T = 4\)。究竟是哪一個？（計算數列 \(t_1 = \sqrt2\)、\(t_{n+1} = \sqrt2^{\,t_n}\) 的頭幾項，並想想 第 2.2 節 中的蛛網圖（cobweb diagram）。）

延伸閱讀

  • Robert Corless et al., “On the Lambert W function”，Advances in Computational Mathematics 5 (1996)。為這個函數命名的論文。讀完本節之後，論文的頭幾節應可讀懂。

  • Brian Hayes, “Why W?”，American Scientist 93 (2005)。一篇生動的文章，講述這個函數的歷史和用途。可在網上免費閱讀。

  • Brian Conrad, “Impossibility theorems for elementary integration”。網上可找到的講義，解釋劉維爾的理論。程度較深。
