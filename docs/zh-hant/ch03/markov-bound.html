3.6

斜率的界

工作紙題目連結、提示、大學數學及練習 第 3 章整章的 PDF 版本
題目

STEP I 1988，第 7 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/88-s1-q7

引子

假如你知道一個函數在某個區間上的值總是介乎 \(-1\) 與 \(1\) 之間，你能否說出它有多陡？對一般的函數來說，答案是不能：\(\sin(1000x)\) 的值介乎 \(-1\) 與 \(1\) 之間，但它的斜率可以大至 \(1000\)。不過二次函數（quadratic）不可能這樣擺動。這道題目要證明的是：一個困在方框 \(|x| \leq 1\)、\(|y| \leq 1\) 之內的二次函數，在方框內的斜率永遠不會大於 \(4\)，而且 \(4\) 已是最佳的界。

這個問題的來歷出人意表。1887 年，以元素週期表聞名的化學家門捷列夫（Dmitri Mendeleev）正在研究溶液的密度如何隨濃度變化，並用二次函數擬合他的數據。他需要知道數據中的誤差對曲線斜率的影響最壞可以有多大，於是證明了與本題完全相同的結果。兩年後，年輕的馬可夫（Andrei Markov）解決了任意次數多項式（polynomial）的一般問題，而答案直接引出了數學中最重要的一些多項式。

動筆之前

\(\mathrm{f}'(x)\) 的公式只用到 \(\mathrm{f}\) 的三個值：在 \(-1\)、\(0\) 和 \(1\) 的值。為甚麼三個值就足以確定一個二次函數的導數（derivative）？

二次函數有三個係數，所以只要知道它在任意三點的值，就能把它確定下來。它的導數同樣是由這些係數決定的函數，因此必定可以用這三個值表示出來。題中的公式正好告訴你怎樣表示。而這恰恰是你所需要的，因為假設 \(|\mathrm{f}(x)| \leq 1\) 告訴你的是 \(\mathrm{f}\) 的值，而結論談的卻是它的導數。

逐步解題

階段 1 公式

\(\mathrm{f}(1) = a + b + c\)，\(\mathrm{f}(-1) = a - b + c\)，而 \(\mathrm{f}(0) = c\)。所以右方是 \[(a + b + c)\left(x + \tfrac12\right) + (a - b + c)\left(x - \tfrac12\right) - 2cx.\] \(x\) 的係數是 \((a + b + c) + (a - b + c) - 2c = 2a\)，常數項是 \(\frac12(a + b + c) - \frac12(a - b + c) = b\)。所以右方等於 \(2ax + b = \mathrm{f}'(x)\)。■

階段 2 上界

對公式取絕對值，然後運用三角不等式（triangle inequality），再配合 \(|\mathrm{f}(1)|, |\mathrm{f}(-1)|, |\mathrm{f}(0)| \leq 1\)。你會得到 \(|\mathrm{f}'(x)|\) 的甚麼上界（寫成 \(x\) 的函數）？

根據三角不等式 \(|u + v + w| \leq |u| + |v| + |w|\)， \[|\mathrm{f}'(x)| \leq |\mathrm{f}(1)|\,\bigl|x + \tfrac12\bigr| + |\mathrm{f}(-1)|\,\bigl|x - \tfrac12\bigr| + 2|\mathrm{f}(0)|\,|x| \leq \bigl|x + \tfrac12\bigr| + \bigl|x - \tfrac12\bigr| + 2|x|.\]

證明當 \(|x| \leq 1\) 時，\(\bigl|x + \tfrac12\bigr| + \bigl|x - \tfrac12\bigr| + 2|x| \leq 4\)。（按正負號分情況討論。）

若 \(|x| \leq \frac12\)，則 \(x + \frac12 \geq 0\) 而 \(x - \frac12 \leq 0\)，所以 \(\bigl|x + \tfrac12\bigr| + \bigl|x - \tfrac12\bigr| = (x + \tfrac12) - (x - \tfrac12) = 1\)，總和是 \(1 + 2|x| \leq 2\)。

若 \(\frac12 \leq |x| \leq 1\)，兩個括號的正負號都與 \(x\) 相同，所以 \(\bigl|x + \tfrac12\bigr| + \bigl|x - \tfrac12\bigr| = 2|x|\)，總和是 \(4|x| \leq 4\)。

無論哪種情況，都有 \(|\mathrm{f}'(x)| \leq 4\)。■

這個上界只會在 \(x = \pm1\) 處達到；在區間中間的一半，斜率最多只是 \(2\)。

階段 3 一個極端例子

要在 \(x = 1\) 處達到上界，第 2 階段中的每個不等式都必須取等號。\(\mathrm{f}(1)\)、\(\mathrm{f}(-1)\) 和 \(\mathrm{f}(0)\) 必須取甚麼值？正負號又是甚麼？

在 \(x = 1\) 處，公式是 \(\mathrm{f}'(1) = \frac32\mathrm{f}(1) + \frac12\mathrm{f}(-1) - 2\mathrm{f}(0)\)。要令它等於 \(4\)，我們需要 \(\mathrm{f}(1) = 1\)、\(\mathrm{f}(-1) = 1\) 和 \(\mathrm{f}(0) = -1\)。通過 \((-1, 1)\)、\((0, -1)\) 和 \((1, 1)\) 的二次函數是 \[\mathrm{f}(x) = 2x^2 - 1,\] 所以 \(a = 2\)，\(b = 0\)，\(c = -1\)。在 \(|x| \leq 1\) 上，\(x^2 \in [0, 1]\)，所以 \(2x^2 - 1 \in [-1, 1]\)，而 \(\mathrm{f}'(1) = 4\)。■

回顧

  • 用已知的量表示想求的量。公式把導數改寫成 \(\mathrm{f}\) 的值，而假設提供的資料正正在這些值上。

  • 三角不等式。用各項絕對值之和來估計一個和的上界，是分析學（analysis）中最常見的手法之一。

  • 從等號成立的條件找出極值情況。追問每個不等式何時取等號，就直接得出例子 \(2x^2 - 1\)。

背後的數學

馬可夫不等式與切比雪夫多項式

馬可夫在 1889 年證明：若 \(p\) 是 \(n\) 次多項式，且在 \([-1, 1]\) 上 \(|p(x)| \leq 1\)，則 \[|p'(x)| \leq n^2 \qquad\text{當 } |x| \leq 1.\] 當 \(n = 2\) 時，這就是我們的上界 \(4\)。極端情況是切比雪夫多項式（Chebyshev polynomials）\(T_n\)，其定義為 \[T_n(\cos\theta) = \cos n\theta.\] 例如 \(\cos 2\theta = 2\cos^2\theta - 1\) 給出 \(T_2(x) = 2x^2 - 1\)，即我們的極端二次函數；而 \(\cos 3\theta = 4\cos^3\theta - 3\cos\theta\) 給出 \(T_3(x) = 4x^3 - 3x\)。由於 \(T_n(x) = \cos n\theta\)，這些多項式在 \(-1\) 與 \(1\) 之間來回振盪的次數，已是 \(n\) 次多項式所能做到的最多，而且它們在兩端也是最陡的（圖 3.6.1）。馬可夫的弟弟 Vladimir 在 1892 年把結果推廣到高階導數。

插值

題目中的公式是拉格朗日插值（Lagrange interpolation）的一個例子：已知函數在若干點的值，寫出通過這些點而次數最低的唯一多項式，再用它來逼近該函數或其導數。這裏的三個點是 \(-1, 0, 1\)。這類公式在數值分析（numerical analysis）中無處不在，例如用來從量度所得的數據估計導數。馬可夫不等式就是隨之而來的警告：函數值的小誤差，在導數中最多可以被放大 \(n^2\) 倍，這正是門捷列夫當年擔心的問題。

切比雪夫多項式的實際應用

切比雪夫多項式是逼近理論（approximation theory）的主力工具。在 \(T_n\) 的根處對函數插值，而不是在等距的點上插值，可以把誤差控制住；若用等距的點，高次插值在區間兩端附近可以錯得非常離譜（龍格現象，Runge’s phenomenon）。那些把函數計算至機器精度極限、或以極高準確度求解微分方程（differential equation）的軟件，內部往往使用切比雪夫展開式。

思維技巧

用已知的量表示未知的量

如果假設告訴你的是某一類量，而結論談的是另一類量，就去找一個把兩者連繫起來的恆等式，然後逐項估計上界。

得到一個界之後，還要問它是否最佳。沿着等號成立的情況倒推回去，通常會把你帶到極端例子，而極端例子本身往往就很值得研究。

延伸練習

  1. 一般的想法。證明若 \(\mathrm{f}\) 是二次函數，則 \(\mathrm{f}(x) = \mathrm{f}(-1)\dfrac{x(x-1)}{2} + \mathrm{f}(0)(1 - x^2) + \mathrm{f}(1)\dfrac{x(x+1)}{2}\)，然後求導，重新得出題目中的公式。

  2. 唯一性。 較難 證明在 \([-1, 1]\) 上滿足 \(|\mathrm{f}(x)| \leq 1\)、且在 \([-1, 1]\) 內某處有 \(|\mathrm{f}'(x)| = 4\) 的二次函數，只有 \(\pm(2x^2 - 1)\)。

  3. 切比雪夫多項式。利用 \(\cos 3\theta = 4\cos^3\theta - 3\cos\theta\) 驗證 \(T_3(x) = 4x^3 - 3x\)，並驗證 \(T_3'(1) = 9\)。證明 \(T_{n+1}(x) = 2xT_n(x) - T_{n-1}(x)\)，並求 \(T_4\)。

  4. \(T_n\) 的斜率。把 \(T_n(\cos\theta) = \cos n\theta\) 對 \(\theta\) 求導，證明 \(T_n'(\cos\theta) = \dfrac{n\sin n\theta}{\sin\theta}\)，再令 \(\theta \to 0\)，推導出 \(T_n'(1) = n^2\)。

延伸閱讀

  • Lloyd N. Trefethen, Approximation Theory and Approximation Practice（SIAM）。一本出色的現代著作，講述切比雪夫多項式與插值，能力強的中學生也讀得懂，全書穿插電腦實驗。

  • Peter Borwein & Tamás Erdélyi, Polynomials and Polynomial Inequalities（Springer）。想了解馬可夫不等式及其相關結果的來龍去脈，可讀此書。程度較深。

  • George M. Phillips, Interpolation and Approximation by Polynomials（Springer）。一本大學本科教科書，涵蓋拉格朗日插值、切比雪夫多項式和馬可夫型不等式。
