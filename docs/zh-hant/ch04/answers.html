第 4 章 · 嚴謹的微積分

延伸練習答案

以下只是簡短的答案和提示，並非完整解答：只列出結果和關鍵步驟，方便你核對自己的做法。請先認真做過每道練習，然後才看答案。

4.1 甚麼是積分？

  1. 這個和是 \(y = \mathrm{f}(x)\) 之下、在 \([1, 2]\) 上 \(n\) 個闊度為 \(\frac1n\) 的長方形的總面積。取 \(\mathrm{f}(x) = \frac1x\)，得 \(\frac1n\sum\frac{1}{1 + m/n} = \sum\frac{1}{n + m} \to \ln2\)。第二個和是 \(\frac1n\sum\frac{1}{1 + (m/n)^2} \to \int_0^1\frac{\mathrm{d}x}{1 + x^2} = \frac\pi4\)。

  2. 分成 \(n\) 條時，上和（upper sum）是 \(\frac an\sum_{r=1}^{n}\bigl(\frac{ra}{n}\bigr)^2 = \frac{a^3(n + 1)(2n + 1)}{6n^2}\)，下和（lower sum）則只須把第一個因子中的 \(n + 1\) 換成 \(n - 1\)；兩者都趨向 \(\frac{a^3}{3}\)。

  3. 各項可以裂項相消（telescope）：\(r(r + 1)\cdots(r + k) - (r - 1)r\cdots(r + k - 1) = (k + 1)\,r(r + 1)\cdots(r + k - 1)\)。

  4. \(\sum_{r=1}^nr^5 = \frac{n^2(n + 1)^2(2n^2 + 2n - 1)}{12}\)。

4.2 由一個積分建立三角學

  1. 導數（derivative）是 \(-\mathrm{f}(a - x)\mathrm{f}(x) + \mathrm{f}(a - x)\mathrm{f}(x) = 0\)，所以 \(\mathrm{f}(a - x)\mathrm{f}(x) = \mathrm{f}(a)\)；代入 \(a = x + y\) 即可。至於餘弦，固定 \(y\)，設 \(p(x) = \mathrm{c}(x + y) - \mathrm{c}(x)\mathrm{c}(y) + \mathrm{s}(x)\mathrm{s}(y)\) 及 \(q(x) = \mathrm{s}(x + y) - \mathrm{s}(x)\mathrm{c}(y) - \mathrm{c}(x)\mathrm{s}(y)\)。於是 \(p' = -q\) 而 \(q' = p\)，所以 \(p^2 + q^2\) 是常數，而它在 \(x = 0\) 時等於 \(0\)。

  2. \(\frac{\mathrm{d}y}{\mathrm{d}u} = (1 + u^2)^{-3/2}\) 而 \(\sqrt{1 - y^2} = (1 + u^2)^{-1/2}\)，所以 \(\frac{\mathrm{d}y}{\sqrt{1 - y^2}} = \frac{\mathrm{d}u}{1 + u^2}\)。於是 \(\mathrm{S}(\frac{1}{\sqrt2}) = \mathrm{T}(1)\)，而在第 (i) 部分取 \(x = 1\) 便得 \(\mathrm{T}(1) = \frac12\mathrm{T}_\infty\)。

  3. 取 \(a = \frac12\) 及 \(x = \frac13\)，則 \(\frac{x + a}{1 - ax} = 1\)，所以 \(\mathrm{T}(\frac13) = \mathrm{T}(1) - \mathrm{T}(\frac12)\)。

  4. 在 \([0, 1]\) 上 \(\frac{1}{1 + u^2} \leq 1\)，在 \([1, x]\) 上則 \(\leq \frac{1}{u^2}\)，所以當 \(x \geq 1\) 時，\(\mathrm{T}(x) \leq 1 + (1 - \frac1x) < 2\)；當 \(0 < x < 1\) 時，\(\mathrm{T}(x) < \mathrm{T}(1) \leq 1\)。（上界 \(1 + \int_1^x u^{-2}\,\mathrm{d}u\) 在 \(x < 1\) 時並不成立：在 \(x = \frac12\) 時它等於 \(0\)。）\(\mathrm{T}\) 遞增而且有界（bounded），所以它有極限（limit）。

4.3 \(22/7\) 大於 \(\pi\)

  1. \(\frac{22}{7} - \pi \approx 0.001264\)，介乎 \(\frac{1}{1260} \approx 0.000794\) 與 \(\frac{1}{630} \approx 0.001587\) 之間。

  2. \(\frac{(4!)^2}{9!} = \frac{576}{362\,880} = \frac{1}{630}\)。

  3. \(\frac{x(1 - x)^2}{1 + x^2} = x - 2 + \frac{2}{1 + x^2}\)，積分（integrate）後得 \(\frac12 - 2 + \frac\pi2\)。同樣地，\(\frac{x^2(1 - x)^4}{1 + x^2} = x^4 - 4x^3 + 5x^2 - 4 + \frac{4}{1 + x^2}\)，積分後得 \(\frac15 - 1 + \frac53 - 4 + \pi = \pi - \frac{47}{15}\)。兩個積分都是正數。這兩個被積函數（integrand）遠大於 \(\frac{x^4(1 - x)^4}{1 + x^2}\)（其最大值約為 \(0.003\)），所以誤差 \(\frac\pi2 - \frac32 \approx 0.07\) 和 \(\pi - \frac{47}{15} \approx 0.008\) 也較大。

  4. 多項式除法（polynomial division）餘下 \(\frac{16}{1 + x^2}\)，積分後得 \(4\pi\)；整個積分是 \(4\pi - \frac{188684}{15015} \approx 3.6 \times 10^{-6}\)，所以 \(\pi \approx 3.14159174\)。

4.4 沃利斯、Beta 與二分之一的階乘

  1. \(u_{2m} = \frac{1 \cdot 3 \cdots (2m - 1)}{2 \cdot 4 \cdots 2m}\cdot\frac\pi2\) 而 \(u_{2m+1} = \frac{2 \cdot 4 \cdots 2m}{3 \cdot 5 \cdots (2m + 1)}\)。於是 \(1 < \frac{u_{2m}}{u_{2m+1}} < \frac{u_{2m-1}}{u_{2m+1}} = \frac{2m + 1}{2m}\)，所以這個比趨向 \(1\)，整理後即得 \(\frac\pi2 = \prod_{k \geq 1}\frac{(2k)^2}{(2k - 1)(2k + 1)}\)。

  2. 分部積分法（integration by parts）給出 \(I_n = \frac{n}{n + 1}\int_0^1x^{n+1}(1 - x)^{n-1}\,\mathrm{d}x\)，再寫成 \(x^{n+1}(1 - x)^{n-1} = x^n(1 - x)^{n-1} - x^n(1 - x)^n\) 並利用對稱性，便得 \(I_n = \frac{n}{2(2n + 1)}I_{n-1}\)；用歸納法（induction）可得 \(\frac{(n!)^2}{(2n + 1)!}\)。取 \(x = \sin^2\theta\)，得 \(I_{1/2} = \int_0^{\pi/2}2\sin^2\theta\cos^2\theta\,\mathrm{d}\theta = \frac\pi8\)。公式提示 \(\bigl((\frac12)!\bigr)^2/2! = \frac\pi8\)，所以 \((\frac12)! = \frac{\sqrt\pi}{2}\)（即 \(\Gamma(\frac32)\)）。

  3. 對稱性來自 \(x \mapsto 1 - x\)；遞推關係（recurrence）來自 \(x^p = x^{p-1} - x^{p-1}(1 - x)\)；而取 \(x = \frac{t}{1 + t}\) 時，\(1 - x = \frac{1}{1 + t}\) 且 \(\mathrm{d}x = \frac{\mathrm{d}t}{(1 + t)^2}\)。該積分是 \(\mathrm{b}(\frac52, \frac72)\)；利用遞推關係和對稱性化簡至 \(\mathrm{b}(\frac12, \frac12) = \pi\)，便得 \(\frac{3\pi}{256}\)。

  4. 由第 (i) 部分的顯式數值，\(u_{2m} = \frac{(2m)!}{(2^mm!)^2}\cdot\frac\pi2 = \binom{2m}{m}\frac{\pi}{2^{2m+1}}\)。於是由 \(2mu_{2m}^2 \to \frac\pi2\) 得 \(\binom{2m}{m}^2 \approx \frac{4^{2m}}{\pi m}\)。當 \(m = 10\) 時：\(\binom{20}{10} = 184\,756\)，而 \(\frac{4^{10}}{\sqrt{10\pi}} \approx 187\,079\)（高出約 \(1.3\%\)）。

4.5 大二學生之夢

  1. \(x^{-x} = e^{-x\ln x} = \sum_{n \geq 0}\frac{(-x\ln x)^n}{n!}\)，而 \(\int_0^1\frac{x^n(-\ln x)^n}{n!}\,\mathrm{d}x = \frac{1}{(n + 1)^{n+1}}\)（代入 \(x = e^{-u}\)）。所以該積分是 \(\sum_{n \geq 1}n^{-n} \approx 1.2913\)。

  2. \(\frac{\mathrm{d}}{\mathrm{d}x}x^x = x^x(\ln x + 1)\)，在 \(x = \frac1e\) 時為零；其值為 \((e^{-1})^{e^{-1}} = e^{-1/e} \approx 0.692\)。

  3. 各項是 \(\frac{1}{n^n}\)。取 \(7\) 項後停止，誤差小於 \(\frac{1}{8^8} \approx 6 \times 10^{-8}\)，已經足夠；只取 \(6\) 項的話，上界 \(\frac{1}{7^7} \approx 1.2 \times 10^{-6}\) 並不足夠。所以要取 \(7\) 項。

  4. 用分部積分法：\(\int_0^1x^2\ln x\,\mathrm{d}x = \bigl[\frac{x^3\ln x}{3}\bigr]_0^1 - \int_0^1\frac{x^2}{3}\,\mathrm{d}x = -\frac19\)。一般而言 \(\int_0^1x^n\ln x\,\mathrm{d}x = -\frac{1}{(n + 1)^2}\)，而 \(\frac{\ln x}{1 - x} = \sum_{n \geq 0}x^n\ln x\)。

4.6 沒有公式的積分

  1. 求導：\(\frac{\mathrm{d}}{\mathrm{d}x}\frac{e^x}{x + 1} = \frac{xe^x}{(x + 1)^2}\)，而 \(\frac{\mathrm{d}}{\mathrm{d}x}\frac{(x - 1)e^x}{x + 1} = e^x\Bigl(\frac{x - 1}{x + 1} + \frac{2}{(x + 1)^2}\Bigr) = \frac{(x^2 + 1)e^x}{(x + 1)^2}\)。

  2. \(\frac{\mathrm{d}}{\mathrm{d}x}\bigl(\mathrm{P}e^{-x^2}\bigr) = (\mathrm{P}' - 2x\mathrm{P})e^{-x^2}\)，而 \(\mathrm{P}' - 2x\mathrm{P}\) 的次數是 \(\deg\mathrm{P} + 1 \geq 1\)（當 \(\mathrm{P} \neq 0\)），所以它不可能等於 \(1\)。

  3. 假如 \(\mathrm{R} = \mathrm{P}/\mathrm{Q}\)（已約至最簡）在 \(0\) 處有 \(k \geq 1\) 階的極點（pole），則 \(\mathrm{R}' + \mathrm{R}\) 在該處會有 \(k + 1 \geq 2\) 階的極點，但 \(\frac1x\) 的極點只是 \(1\) 階。假如 \(\mathrm{R}\) 在 \(0\) 處沒有極點，則 \(\mathrm{R}' + \mathrm{R}\) 也沒有。無論哪種情況，都有 \((\mathrm{R}e^x)' \neq \frac{e^x}{x}\)。

  4. 對 \(\frac{\mathrm{P}e^x}{x + 1}\) 求導，得 \(e^x\frac{(x + 1)\mathrm{P}' + x\mathrm{P}}{(x + 1)^2}\)。在 \(x = -1\) 處：\(\mathrm{f}(-1) = -\mathrm{P}(-1)\)，而由 \(\mathrm{f}' = (x + 1)\mathrm{P}'' + (x + 1)\mathrm{P}' + \mathrm{P}\) 得 \(\mathrm{f}'(-1) = \mathrm{P}(-1)\)。對於 \(x^3 - 2\)：\(-3 + 3 = 0\)；對於 \(x\)：\(-1 + 1 = 0\)；對於 \(x^2 + 1\)：\(2 - 2 = 0\)。這個條件也是充分的：映射 \(\mathrm{P} \mapsto (x + 1)\mathrm{P}' + x\mathrm{P}\) 把次數小於 \(d\) 的多項式映到次數不超過 \(d\) 的多項式，而且是單射（injective），所以它的像（image）的維數（dimension）是 \(d\)，並且包含在由滿足 \(\mathrm{f}(-1) + \mathrm{f}'(-1) = 0\) 的 \(\mathrm{f}\) 所組成的 \(d\) 維空間之內；因此像就是整個空間。

4.7 變分法

  1. 取 \(y = \cos\frac{\pi x}{2}\)，得 \(J = \frac{\pi^2}{4}\int_0^1\sin^2 - a^2\int_0^1\cos^2 = \frac12\bigl(\frac{\pi^2}{4} - a^2\bigr) < 0\)。

  2. \(J(y + \varepsilon\eta) = J(y) + 2\varepsilon\int_0^1(y'\eta' - a^2y\eta) + \varepsilon^2J(\eta)\)；要在 \(\varepsilon = 0\) 處取得最小值，線性項必須為零。分部積分後，對每個滿足 \(\eta(1) = 0\) 的 \(\eta\) 都有 \(-y'(0)\eta(0) - \int_0^1(y'' + a^2y)\eta = 0\)，由此必有 \(y'' + a^2y = 0\) 及 \(y'(0) = 0\)。

  3. 取 \(x = Lu\)，得 \(\int_0^L\bigl((y')^2 - a^2y^2\bigr)\,\mathrm{d}x = \frac1L\int_0^1\bigl((Y')^2 - (aL)^2Y^2\bigr)\,\mathrm{d}u\)，所以條件是 \(aL \leq \frac\pi2\)。（當 \(aL = \frac\pi2\) 時，正如正文所述，積分仍然不會是負數，但 \(y = \cos\frac{\pi x}{2L}\) 會令它等於零；當 \(aL > \frac\pi2\) 時，同一個函數會令它變成負數。）

  4. 擺線（cycloid）是 \(x = R(\theta - \sin\theta)\), \(y = R(1 - \cos\theta)\)。關於等時曲線（tautochrone），見 第 11.4 節：以弧長（arc length）表示時，該運動恰好是簡諧運動（simple harmonic motion）。

4.8 切球形麵包

  1. \(V/A = \frac{\frac43\pi a^3}{4\pi a^2} = \frac a3\)。但餘下一塊高度為 \(t\) 的部分有 \(A = 2\pi at\) 及 \(V = \frac13\pi t^2(3a - t)\)，所以 \(V/A = \frac{t(3a - t)}{6a}\)，它在 \(t = \frac32a\) 時取得最大值 \(\frac{3a}{8}\)：比 \(\frac a3\) 還要大。

  2. 這條帶的高度是 \(2R\sin23.4^\circ\)，而球的高度是 \(2R\)，所以所佔比例是 \(\sin23.4^\circ \approx 0.40\)。

  3. 對於 \(y = \sqrt x\)，\(y\sqrt{1 + (y')^2} = \sqrt{x + \frac14}\)，並非常數。由 \(y\sqrt{1 + (y')^2} = c\) 得 \((y')^2 = \frac{c^2}{y^2} - 1\)，其解為 \(y = c\)（圓柱）以及圓 \((x - x_0)^2 + y^2 = c^2\)（球）。

  4. 球的體積是 \(\frac43\pi a^3\)，圓柱的體積是 \(\pi a^2 \cdot 2a = 2\pi a^3\)；兩者之比是 \(\frac23\)。

4.9 Holditch 定理

  1. \(\frac12\int_0^{2\pi}(p\cos t \cdot q\cos t + q\sin t \cdot p\sin t)\,\mathrm{d}t = \frac12 \cdot 2\pi pq = \pi pq\)。

  2. 把兩條弦（chord）的端點連起來所得的兩個三角形相似（同弧所對的角相等），所以 \(PA \cdot PB = PC \cdot PD\)。對於半徑為 \(R\) 的圓，若 \(P\) 與圓心的距離為 \(r\)，則通過 \(P\) 的直徑給出 \((R - r)(R + r)\)，所以 \(ab = R^2 - r^2\)，而圓環的面積是 \(\pi R^2 - \pi r^2 = \pi ab\)。

  3. 若 \(a = b\)，則 \(f = \pi(a - b) = 0\)，而圓環的面積是 \(\pi a^2 = \frac{\pi L^2}{4}\)：即以該桿為直徑的圓的面積。

  4. 沿着通過 \(O\) 的兩條邊，\(x\,\mathrm{d}y - y\,\mathrm{d}x = 0\)。第三條邊以 \((x_1, y_1) + s(x_2 - x_1, y_2 - y_1)\)（其中 \(0 \leq s \leq 1\)）作參數表示，在這條邊上它等於 \((x_1y_2 - x_2y_1)\,\mathrm{d}s\)。所以面積是 \(\frac12|x_1y_2 - x_2y_1|\)。
