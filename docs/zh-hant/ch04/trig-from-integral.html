由一個積分建立三角學

工作紙題目連結、提示、大學數學及練習 第 4 章整章的 PDF 版本
題目

STEP III 2017，第 6 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/17-s3-q6

引子

\(\pi\) 究竟是甚麼？在中學，它是圓周與直徑之比，而 \(\sin\) 和 \(\cos\) 則用三角形來定義。這對幾何來說已經足夠，卻留下了一些棘手的問題。沿着曲線的「長度」到底是甚麼？為甚麼 \(\sin x\) 的麥克勞林級數（Maclaurin series）偏偏是那個樣子？我們又怎樣知道加法公式（addition formulas）對所有角都成立，而不只限於畫得出來的角？

這道題展示了一條截然不同的入門途徑。忘掉三角形和圓吧。只從一個積分 \(\mathrm{T}(x) = \int_0^x \frac{\mathrm{d}u}{1+u^2}\) 出發，它所需要的不過是 第 4.1 節 中積分的定義。把 \(\pi\) 定義為 \(2\mathrm{T}_\infty\)。然後只用代換法（substitution），證明 \(\mathrm{T}(\sqrt3) = \frac{\pi}{3}\) 和 \(\mathrm{T}(\sqrt2 - 1) = \frac{\pi}{8}\)，也就是你所熟悉的 \(\arctan\sqrt3 = 60^\circ\) 和 \(\tan 22\tfrac12^\circ = \sqrt2 - 1\)。三角學就這樣從無到有地重建起來。

動筆之前

你心裏其實知道 \(\mathrm{T}(x) = \arctan x\) 和 \(\mathrm{T}_\infty = \frac\pi2\)。題目不准你使用這些事實，而這正是用意所在：一切都必須由積分推導出來。不過，這點心照不宣的知識是很有用的嚮導。

第 (i) 和第 (ii) 部分分別對應哪些三角恆等式（trigonometric identities）？（想想 \(\arctan x + \arctan\frac1x\)，以及 \(\tan(A + B)\) 的公式。）

第 (i) 部分就是 \(\arctan x + \arctan\frac1x = \frac\pi2\)。第 (ii) 部分則是喬裝了的加法公式 \(\tan(A + B) = \frac{\tan A + \tan B}{1 - \tan A\tan B}\)：設 \(u = \tan A\) 和 \(a = \tan B\)，則 \(v = \tan(A + B)\)。這道題不靠任何幾何，單憑積分就證明了這些恆等式。

逐步解題

階段 1 反射 \(u \mapsto 1/u\)

在 \(\mathrm{T}(x)\) 中代入 \(u = 1/w\)。於是 \(\mathrm{d}u = -\mathrm{d}w/w^2\)，而 \(\dfrac{1}{1 + u^2} = \dfrac{w^2}{w^2 + 1}\)，所以 \[\mathrm{T}(x) = \int_{\infty}^{1/x} \frac{w^2}{w^2 + 1}\cdot\left(-\frac{1}{w^2}\right)\mathrm{d}w = \int_{1/x}^{\infty} \frac{\mathrm{d}w}{1 + w^2} = \mathrm{T}_\infty - \mathrm{T}(x^{-1}). \qed\] 換句話說，\(\frac{1}{1+u^2}\) 之下由 \(0\) 到 \(x\) 的面積，等於由 \(\frac1x\) 到 \(\infty\) 的面積（圖 4.2.1）。

階段 2 加法代換

用商法則（quotient rule）對 \(v = \dfrac{u + a}{1 - au}\) 求導。然後把 \(1 + v^2\) 化成單一分式，再作比較。

\[\begin{aligned} \frac{\mathrm{d}v}{\mathrm{d}u} &= \frac{(1 - au) + a(u + a)}{(1 - au)^2} = \frac{1 + a^2}{(1 - au)^2}, \\ 1 + v^2 &= \frac{(1 - au)^2 + (u + a)^2}{(1 - au)^2} = \frac{(1 + a^2)(1 + u^2)}{(1 - au)^2}. \end{aligned}\] 兩式相除，得 \(\dfrac{1 + v^2}{1 + u^2} = \dfrac{1 + a^2}{(1 - au)^2} = \dfrac{\mathrm{d}v}{\mathrm{d}u}\)。■

這表示 \(\dfrac{\mathrm{d}u}{1 + u^2} = \dfrac{\mathrm{d}v}{1 + v^2}\)。所以代換 \(u \mapsto v\) 完全沒有改變被積函數（integrand）。那麼它對 \(\mathrm{T}(x)\) 的積分上下限有甚麼影響？

當 \(u\) 由 \(0\) 變到 \(x\) 時（其中 \(x < \frac1a\)，故 \(1 - au > 0\) 始終成立，而 \(v\) 連續且遞增），\(v\) 由 \(a\) 變到 \(\frac{x + a}{1 - ax}\)。所以 \[\mathrm{T}(x) = \int_0^x \frac{\mathrm{d}u}{1 + u^2} = \int_a^{(x+a)/(1-ax)} \frac{\mathrm{d}v}{1 + v^2} = \mathrm{T}\!\left(\frac{x + a}{1 - ax}\right) - \mathrm{T}(a). \qed\]

階段 3 再多兩個恆等式

結合第 (i) 部分，並使用兩次： \[\mathrm{T}(x^{-1}) = \mathrm{T}_\infty - \mathrm{T}(x) = \mathrm{T}_\infty - \mathrm{T}\!\left(\frac{x + a}{1 - ax}\right) + \mathrm{T}(a) = 2\mathrm{T}_\infty - \mathrm{T}\!\left(\frac{x + a}{1 - ax}\right) - \mathrm{T}(a^{-1}). \qed\] 現在更換變數名稱：設 \(y = 1/x\) 和 \(b = 1/a\)。條件 \(x < 1/a\) 變成 \(1/y < b\)，即 \(y > 1/b\)，而 \[\frac{x + a}{1 - ax} = \frac{1/y + 1/b}{1 - 1/(by)} = \frac{b + y}{by - 1}.\] 所以 \(\mathrm{T}(y) = 2\mathrm{T}_\infty - \mathrm{T}\!\left(\dfrac{y + b}{by - 1}\right) - \mathrm{T}(b)\)。■

階段 4 特殊值

在最後一個恆等式中選取 \(y\) 和 \(b\)，使自變量 \(\frac{y + b}{by - 1}\) 剛好等於 \(y\) 本身。你會得到甚麼？

取 \(y = b = \sqrt3\)：這時 \(y > \frac1b\)，而 \(\dfrac{\sqrt3 + \sqrt3}{3 - 1} = \sqrt3\)。恆等式變成 \(\mathrm{T}(\sqrt3) = 2\mathrm{T}_\infty - 2\mathrm{T}(\sqrt3)\)，所以 \[\mathrm{T}(\sqrt3) = \tfrac23\mathrm{T}_\infty. \qed\]

至於 \(\sqrt2 - 1\)，試在加法恆等式中取 \(x = a = \sqrt2 - 1\)。\(\frac{2x}{1 - x^2}\) 是多少？\(\mathrm{T}(1)\) 又是多少？

取 \(x = a = \sqrt2 - 1\)（由於 \(x^2 = 3 - 2\sqrt2 < 1\)，故 \(x < \frac1a\)），加法恆等式給出 \(2\mathrm{T}(x) = \mathrm{T}\!\left(\frac{2x}{1 - x^2}\right)\)。而 \(1 - x^2 = 2\sqrt2 - 2 = 2(\sqrt2 - 1) = 2x\)，所以 \(\frac{2x}{1 - x^2} = 1\)，於是 \(2\mathrm{T}(\sqrt2 - 1) = \mathrm{T}(1)\)。最後，在第 (i) 部分取 \(x = 1\)，得 \(\mathrm{T}(1) = \mathrm{T}_\infty - \mathrm{T}(1)\)，所以 \(\mathrm{T}(1) = \frac12\mathrm{T}_\infty\)。因此 \[\mathrm{T}(\sqrt2 - 1) = \tfrac14\mathrm{T}_\infty. \qed\]

回顧

  • 保持被積函數不變的代換。兩個關鍵步驟所用的代換，都令 \(\frac{\mathrm{d}u}{1+u^2}\) 保持不變，只有積分上下限移動了。積分的這類「對稱性」（symmetry）威力強大。

  • 不動點（fixed point）。\(\mathrm{T}(\sqrt3)\) 的值，來自選取適當的數，使某個表達式等於它本身，於是恆等式變成了方程。

  • 定義可以來自分析。我們從沒有用過三角形，卻重新得到了 \(\frac\pi3\) 和 \(\frac\pi8\)（其中 \(\pi\) 定義為 \(2\mathrm{T}_\infty\)）。

背後的數學

建構初等函數

在嚴格的分析課程中，函數 \(\exp\)、\(\sin\)、\(\cos\) 和 \(\ln\) 不能隨便假設存在；它們必須被建構出來，其性質也必須加以證明。標準的做法有三種。你可以用冪級數（power series）來定義它們（\(\sin x = x - \frac{x^3}{3!} + \cdots\)）。你可以把它們定義為微分方程（differential equation）的解，就如練習中那道 1986 年樣本試卷的題目（\(\mathrm{f}' = \mathrm{f}\)、\(\mathrm{f}(0) = 1\) 定義了 \(\exp\)）。你也可以像這裏一樣，用積分來定義反函數（inverse function）：\(\ln x = \int_1^x \frac{\mathrm{d}u}{u}\) 和 \(\arctan x = \int_0^x \frac{\mathrm{d}u}{1+u^2}\)，然後定義 \(\pi = 2\int_0^\infty \frac{\mathrm{d}u}{1+u^2}\)。每種做法各有所長，而證明它們全都給出相同的函數，是一道令人滿足的練習。試與 第 3.8 節 的函數方程（functional equation）做法比較。

圓以外：橢圓積分

積分的做法可以推廣，而三角形的做法卻做不到。1718 年，Giulio Fagnano 研究雙紐線（lemniscate）這條 8 字形曲線的弧長（arc length），由此引出 \(\int_0^x \frac{\mathrm{d}u}{\sqrt{1 - u^4}}\)，並找到一個能把弧長加倍的代換，正如我們的代換把 \(\mathrm{T}\) 加倍一樣。歐拉（Euler）在 1751 年讀到 Fagnano 的著作，找出了完整的加法公式；這最終經由阿貝爾（Abel）和雅可比（Jacobi），發展成橢圓函數（elliptic functions）的理論：橢圓函數就是這類積分的反函數，它們之於雙紐線，正如 \(\sin\) 和 \(\cos\) 之於圓。我們在高斯（Gauss）關於算術幾何平均（AGM）的工作中（第 2.6 節）遇過同一個積分。橢圓函數如今是數論的核心；第 1.9 節 的橢圓曲線（elliptic curves）就是它們在幾何上的投影。

計算 \(\pi\)

加法恆等式也是計算 \(\pi\) 的那些最著名公式的基礎。舉例說，反覆運用它可以證明 \(\mathrm{T}(1) = 4\mathrm{T}(\frac15) - \mathrm{T}(\frac{1}{239})\)，這就是 1706 年的梅欽公式（Machin’s formula）；配合級數 \(\mathrm{T}(x) = x - \frac{x^3}{3} + \frac{x^5}{5} - \cdots\)，它算出了 \(\pi\) 的 \(100\) 位數字，並在其後兩個半世紀一直是首選的方法。這是 第 5.1 節 的主題。

思維技巧

積分的對稱性

尋找令被積函數保持不變的代換。它們會化為該積分所定義的函數的恆等式。

這裏 \(u \mapsto 1/u\) 和 \(u \mapsto \frac{u+a}{1-au}\) 都保持 \(\frac{\mathrm{d}u}{1+u^2}\) 不變，並分別給出反射公式和加法公式。同一個想法用於其他積分，正是特殊函數（special functions）理論的基礎。

延伸練習

  1. 指數函數與餘弦。試做 STEP II Specimen paper，第 6 題。這道題只憑指數函數和餘弦各自的微分方程，推導出它們的加法公式。（提示：對於餘弦，找出兩個理應為零的組合，並證明它們的平方和是常數。）

  2. 反正弦。試做 STEP III 2007，第 7 題。這道題用處理本節積分的同一手法來處理反正弦（inverse sine），並以一個代換把兩者聯繫起來。

  3. 一條早期的梅欽型公式。利用加法恆等式證明 \(\mathrm{T}(\frac12) + \mathrm{T}(\frac13) = \mathrm{T}(1) = \frac12\mathrm{T}_\infty\)。

  4. \(\mathrm{T}_\infty\) 是有限的。證明對所有 \(x \geq 1\) 都有 \(\mathrm{T}(x) \leq 1 + \int_1^x \frac{\mathrm{d}u}{u^2} < 2\)，解釋為甚麼當 \(0 < x < 1\) 時同樣有 \(\mathrm{T}(x) < 2\)，並由單調收斂定理（monotone convergence theorem）（第 2.2 節）推斷 \(\mathrm{T}_\infty\) 存在。

延伸閱讀

  • Tom Körner, Calculus for the Ambitious（Cambridge University Press）。嚴格地建構初等函數，並討論各種不同的做法。

  • Walter Rudin, Principles of Mathematical Analysis（McGraw-Hill）。即著名的「baby Rudin」；第 8 章的引言只用寥寥數頁，便優雅地由冪級數建構出 \(\exp\)、\(\sin\) 和 \(\cos\)。程度較深。

  • Victor Prasolov & Yuri Solovyev, Elliptic Functions and Elliptic Integrals（American Mathematical Society）。想知道雙紐線通往何處，可讀此書。程度較深。
