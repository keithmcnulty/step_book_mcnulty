4.3

\(22/7\) 大於 \(\pi\)

工作紙題目連結、提示、大學數學及練習 第 4 章整章的 PDF 版本
題目

STEP I 1997，第 6 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/97-s1-q6

引子

一代又一代的學生都聽過 \(\pi\)「大約是 \(\frac{22}{7}\)」這個說法。這是一個非常好的近似值（approximation）：\(\frac{22}{7} = 3.142857\ldots\)，而 \(\pi = 3.141592\ldots\)。但 \(\frac{22}{7}\) 究竟是偏大還是偏小？你又能否證明這一點，而不是單靠查閱 \(\pi\) 的各位數字？那些數字畢竟是要別人先計算出來的。

這道題給出了整個數學之中最優雅的證明之一。只需一個正函數的積分（integral），其值因而必定為正，而它竟然恰好等於 \(\frac{22}{7} - \pi\)。被積函數（integrand）為正，積分便為正，所以 \(\frac{22}{7} > \pi\)。整個證明只需寥寥數行，而且精巧得被人當作謎題印在數學 T 恤上。

動筆之前

為甚麼 \(\int_0^1 \frac{\text{多項式}}{1+x^2}\,\mathrm{d}x\) 會算出 \(\pi\) 來？這種形式的積分之中，哪一個簡單的積分本身就給出 \(\pi\)？

\(\int_0^1 \frac{\mathrm{d}x}{1+x^2} = \arctan 1 = \frac\pi4\)。把一個多項式（polynomial）除以 \(1 + x^2\)，會得到一個多項式商式（quotient）（其積分是一個有理數），再加上一個常數餘式（remainder）除以 \(1 + x^2\)（其積分是 \(\pi\) 的有理數倍）。題目的第一部分正是要你做這個除法。

逐步解題

階段 1 多項式除法

先展開：\((1 - x)^4 = 1 - 4x + 6x^2 - 4x^3 + x^4\)，所以 \[x^4(1-x)^4 = x^8 - 4x^7 + 6x^6 - 4x^5 + x^4.\]

把它除以 \(x^2 + 1\)，可以用長除法（long division），也可以用比較係數（comparing coefficients）的方法。餘式是甚麼？

在 \((a_6x^6 + \cdots + a_0)(x^2 + 1) + b\) 中由最高次項開始比較係數：\(a_6 = 1\)；\(a_5 = -4\)；\(a_4 + a_6 = 6\)，所以 \(a_4 = 5\)；\(a_3 + a_5 = -4\)，所以 \(a_3 = 0\)；\(a_2 + a_4 = 1\)，所以 \(a_2 = -4\)；\(a_1 + a_3 = 0\)，所以 \(a_1 = 0\)；\(a_0 + a_2 = 0\)，所以 \(a_0 = 4\)；最後 \(a_1 = 0\)（\(x\) 的係數）及 \(a_0 + b = 0\)，所以 \(b = -4\)。即是說， \[x^4(1-x)^4 = (x^6 - 4x^5 + 5x^4 - 4x^2 + 4)(x^2 + 1) - 4.\]

階段 2 計算積分

除以 \(1 + x^2\)，得 \[\frac{x^4(1-x)^4}{1+x^2} = x^6 - 4x^5 + 5x^4 - 4x^2 + 4 - \frac{4}{1+x^2},\] 所以 \[\int_0^1 \frac{x^4(1-x)^4}{1+x^2}\,\mathrm{d}x = \frac17 - \frac46 + \frac55 - \frac43 + 4 - 4\cdot\frac\pi4 = \frac17 - \frac23 + 1 - \frac43 + 4 - \pi.\] 由於 \(-\frac23 - \frac43 = -2\)，有理數部分是 \(\frac17 + 3 = \frac{22}{7}\)，因此積分等於 \(\frac{22}{7} - \pi\)。■

階段 3 估計積分的界

被積函數在 \((0, 1)\) 上為正，所以立即得到 \(\frac{22}{7} > \pi\)。要得到 \(\pi\) 的下界（lower bound），我們需要這個積分的上界（upper bound）。\(\frac{1}{1+x^2}\) 在 \([0, 1]\) 上最大可以有多大？

在 \([0, 1]\) 上，\(1 \leq 1 + x^2 \leq 2\)，所以 \[\tfrac12 x^4(1-x)^4 \leq \frac{x^4(1-x)^4}{1+x^2} \leq x^4(1-x)^4,\] 而且除了在端點之外，不等式（inequality）都是嚴格成立的。

計算 \(\int_0^1 x^4(1-x)^4\,\mathrm{d}x\)，然後完成證明。

把展開式逐項積分， \[\int_0^1 x^4(1-x)^4\,\mathrm{d}x = \frac19 - \frac48 + \frac67 - \frac46 + \frac15 = \frac{1}{630}.\] （以 \(2520\) 為公分母：\(280 - 1260 + 2160 - 1680 + 504 = 4\)，而 \(\frac{4}{2520} = \frac{1}{630}\)。）所以 \[0 < \frac{22}{7} - \pi < \frac{1}{630},\] 亦即 \(\frac{22}{7} > \pi > \frac{22}{7} - \frac{1}{630}\)。■

以數值計算，\(\frac{22}{7} - \frac{1}{630} = 3.14127\ldots\)，所以我們已證明 \(3.1412 < \pi < 3.1429\)。若同時用上左邊的不等式，便有 \(\frac{1}{1260} < \frac{22}{7} - \pi\)，這把上界改進為 \(\pi < 3.14207\)。

回顧

  • 以正值證明不等式。正函數的積分為正。一旦認出積分等於 \(\frac{22}{7} - \pi\)，不等式便立即成立。

  • 被積函數愈小，界愈精確。因子 \(x^4(1-x)^4\) 在 \([0, 1]\) 上極小（最多只有 \(\frac{1}{256}\)），這使積分很小，所得的界也就很精確。

  • 有理數加上 \(\pi\) 的倍數。正如 第 2.9 節 所見，一個形如「有理數 \(+\) 某常數的有理數倍」的積分，若其值很小，便給出該常數的一個良好有理近似值。

背後的數學

一個有來歷的證明

阿基米德（Archimedes）約於公元前 250 年證明了 \(\frac{223}{71} < \pi < \frac{22}{7}\)，方法是計算圓內接和圓外切正 \(96\) 邊形的周界（可與 第 2.5 節 中的多邊形比較）。積分證明則晚近得多。它由 D. P. Dalzell 於 1944 年發表，其後在 1968 年被選為美國大學本科生普特南數學競賽（Putnam competition）的題目，因而廣為人知。它的迷人之處在於完全不需要任何數值計算：不等式 \(\frac{22}{7} > \pi\) 直接來自「正函數的積分為正」這個事實。

用同一思路得出更佳的近似值

這個方法可以推廣。以 \(x^8(1-x)^8\) 取代 \(x^4(1-x)^4\)，同樣的除法給出 \[\int_0^1 \frac{x^8(1-x)^8}{1+x^2}\,\mathrm{d}x = 4\pi - \frac{188684}{15015},\] 由此證明 \(\pi > \frac{47171}{15015} = 3.1415917\ldots\)，準確至六位有效數字（significant figures）。2009 年，Stephen Lucas 找到了多族這類被積函數非負的積分，它們能證明關於其他著名近似值的不等式，其中包括準確至七位有效數字的 \(\frac{355}{113}\)。

近似值與無理性

為甚麼 \(\pi\) 會有 \(\frac{22}{7}\) 和 \(\frac{355}{113}\) 這樣好的分數近似值？每個無理數（irrational number）都有無窮多個分數 \(\frac pq\) 與它相距不超過 \(\frac{1}{q^2}\)，而 \(\pi\) 碰巧在很早的階段就有幾個特別好的，因為它的連分數（continued fraction）\([3; 7, 15, 1, 292, \ldots]\) 含有 \(292\) 這個很大的項（見 第 2.2 節）。像本題這樣的積分，若令其愈來愈小，便是另一類證明的起點：這類證明指出某些數不可能被分數逼近得太好，因而是無理數。Ivan Niven 那個著名的、只有一頁的 \(\pi\) 是無理數的證明（1947 年），用的就是 \(\frac{x^n(1-x)^n}{n!}\sin(\pi x)\) 的積分，它們是 第 2.9 節 中那些積分的三角函數近親。

思維技巧

把不等式寫成某個正值函數的積分

要證明 \(A > B\)，可找一個積分等於 \(A - B\) 的正函數。

這樣便把一個不等式化為一個恆等式（identity）再加上一個顯然的事實。這是分析學（analysis）中最有用的技巧之一；同一思路，以平方和取代積分，就在 第 3.2 節 中證明了算術平均—幾何平均不等式（AM–GM）。

延伸練習

  1. 核對數字。計算 \(\frac{22}{7} - \pi\) 至四位有效數字，並確認它介乎 \(\frac{1}{1260}\) 與 \(\frac{1}{630}\) 之間。

  2. 一個 Beta 積分。利用公式 \(\int_0^1 x^n(1-x)^n\,\mathrm{d}x = \frac{(n!)^2}{(2n+1)!}\)（在 第 4.4 節 中證明）驗證 \(\int_0^1 x^4(1-x)^4\,\mathrm{d}x = \frac{1}{630}\)。

  3. 一個偏小的近似值。證明 \[\int_0^1 \frac{x(1-x)^2}{1+x^2}\,\mathrm{d}x = \frac\pi2 - \frac32 \quad\text{及}\quad \int_0^1 \frac{x^2(1-x)^4}{1+x^2}\,\mathrm{d}x = \pi - \frac{47}{15},\] 並由此推出 \(\pi > 3\) 及 \(\pi > \frac{47}{15}\)。為甚麼這些近似值不及 \(\frac{22}{7}\) 準確？

  4. 更進一步。 較難 驗證上文給出的 \(\int_0^1 \frac{x^8(1-x)^8}{1+x^2}\,\mathrm{d}x\) 的恆等式。（除法可以交給電腦代數系統去做；重點是看出餘式是 \(16\)，從而得出 \(4\pi\)。）

延伸閱讀

  • Petr Beckmann, A History of \(\pi\)（St Martin’s Press）。詳細講述阿基米德的多邊形方法，另有許多其他內容。

  • Stephen Lucas, “Approximations to \(\pi\) derived from integrals with nonnegative integrands”, American Mathematical Monthly 116 (2009)。篇幅短小，容易閱讀。

  • Ivan Niven, Irrational Numbers（Mathematical Association of America）。收錄了 Niven 對 \(\pi\) 是無理數的證明。
