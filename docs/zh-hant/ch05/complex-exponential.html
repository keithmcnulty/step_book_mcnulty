5.7

作為映射的複指數函數

工作紙題目連結、提示、大學數學及練習 第 5 章整章的 PDF 版本
題目

STEP II 1997，第 5 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/97-s2-q5

引子

你所認識的指數函數（exponential function）是一條曲線 \(y = e^x\)。但複變數的函數卻無法畫成曲線：它的輸入是平面上的一點，輸出也是平面上的一點。要想像這樣的函數，應把它看成一個映射（map），也就是一個變換（transformation）：它把一個平面上的每一點搬到另一個平面上的某一點，沿途把圖形拉伸、彎曲。

題目中的公式是 \(z = e^{u}(\cos v + \mathrm{i}\sin v) = e^{u + \mathrm{i}v} = e^w\)。作為映射來看，複指數函數（complex exponential）做了一件奇妙的事：它把平面上的一條水平帶狀區域捲成整個平面（除去原點），把鉛垂線繞成圓，把水平線鋪成射線。又因為它是繞圈捲起來的，所以它不是一對一（one-to-one）的：每一點都有無窮多個點映到它那裏。這正是複對數（complex logarithm）「多值」（multi-valued）的原因，也是複分析（complex analysis）最早帶來的驚奇之一。

動筆之前

\(z = e^u(\cos v + \mathrm{i}\sin v)\) 的模（modulus）和輻角（argument）用 \(u\) 和 \(v\) 表示是甚麼？

\(|z| = e^u\)，而 \(\arg z = v\)（可相差 \(2\pi\) 的倍數）。所以 \(w\) 的實部 \(u\) 以指數方式控制與原點的距離，而虛部 \(v\) 則控制方向。單憑這一點觀察，題目幾乎每一部分都能解答。

逐步解題

階段 1 解 \(e^w = \mathrm{i}e\)

\(\mathrm{i}e\) 的模和輻角是甚麼？

\(|\mathrm{i}e| = e\)，而 \(\arg(\mathrm{i}e) = \frac\pi2\)。所以我們需要 \(e^u = e\)，得 \(u = 1\)，並且 \(v = \frac\pi2 + 2k\pi\)，其中 \(k\) 為任意整數。方程的解為 \[w = 1 + \mathrm{i}\left(\tfrac\pi2 + 2k\pi\right), \qquad k \in \mathbb{Z}.\] 解有無窮多個，沿鉛垂方向每隔 \(2\pi\) 有一個。

階段 2 格線的像

在鉛垂線 \(u = c\) 上，\(|z| = e^c\) 固定不變，而 \(v\) 則在變動：它的像（image）是以原點為圓心、半徑為 \(e^c\) 的圓，當 \(v\) 取遍所有實數時，這個圓被繞了無窮多圈。

在水平線 \(v = d\) 上，\(\arg z = d\) 固定不變，而 \(|z| = e^u\) 取遍所有正值：它的像是由原點出發、方向角為 \(d\) 的開射線（半直線），不包括原點本身。直線 \(v = d\) 與 \(v = d + 2\pi\) 給出同一條射線。

階段 3 一對一的部分

哪些點 \(w\) 會映入第一象限 \(x > 0\)、\(y > 0\)？為甚麼這個集合太大，不能與該象限構成一一對應（one-to-one correspondence）？

\(z\) 位於開的第一象限，當且僅當 \(\arg z\) 嚴格介乎 \(0\) 與 \(\frac\pi2\) 之間（模 \(2\pi\)），而模可取任意值。所以 \(w\) 必須滿足 \(0 < v < \frac\pi2\) 或 \(2\pi < v < \frac{5\pi}{2}\) 或 …：共有無窮多條水平帶狀區域，每一條都映滿整個象限。任取其中一條，它都與該象限一一對應，因為在一條帶狀區域之內，\(u\) 和 \(v\) 由 \(|z|\) 和 \(\arg z\) 唯一確定。所以我們可以取 \[W_1 = \{u + \mathrm{i}v : 0 < v < \tfrac\pi2\}, \qquad W_2 = \{u + \mathrm{i}v : 2\pi < v < \tfrac{5\pi}{2}\}.\]

現在試在 \(w\) 平面上找出兩個集合，使它們各自與去心圓盤（punctured disc）\(0 < |z| < 1\) 一一對應。

\(|z| < 1\) 即 \(e^u < 1\)，亦即 \(u < 0\)；而每一個輻角都必須恰好被覆蓋一次，所以 \(v\) 的取值範圍應是一個長度恰為 \(2\pi\) 的區間，包括其中一個端點而不包括另一個。例如 \[W_3 = \{u + \mathrm{i}v : u < 0,\ 0 \leq v < 2\pi\}, \qquad W_4 = \{u + \mathrm{i}v : u < 0,\ -\pi < v \leq \pi\}.\] 這些都是半帶狀區域，一條邊包括在內，另一條邊不包括在內。（若兩條邊都包括在內，正實軸上的點便會被映到兩次；若兩條邊都不包括，這些點便會被遺漏。）■

回顧

  • 模和輻角把變數分開。\(|e^w| = e^{\mathrm{Re}\,w}\)，而 \(\arg e^w = \mathrm{Im}\,w\)，所以 \(w\) 的實部和虛部分別獨立地控制距離和方向。

  • 把複函數想像成映射。追蹤格線被映到哪裏，便能清楚看見一個無法畫成圖像的函數的面貌。

  • 周期性破壞單射性（injectivity）。\(e^{w + 2\pi\mathrm{i}} = e^w\)，所以這個映射是多對一的，必須限制在一條高度為 \(2\pi\) 的帶狀區域上，才有反函數。

背後的數學

複對數

在實數線上，\(\ln\) 是 \(\exp\) 的反函數。在複平面上，對每一個 \(z \neq 0\)，方程 \(e^w = z\) 都有無窮多個解 \(w\)，彼此相差 \(2\pi\mathrm{i}\) 的倍數，所以「\(\log z\)」並不是單獨一個數。要得到一個真正的函數，就必須選定一個分支（branch），也就是選定一條像 \(W_3\) 或 \(W_4\) 那樣的帶狀區域：主分支（principal branch）取 \(-\pi < \arg z \leq \pi\)。每一個分支都必然在某處有跳躍，跳躍發生在由原點出發的一條射線上，這條射線稱為分支割線（branch cut）。黎曼（Bernhard Riemann）在 1851 年的博士論文中提出了解決辦法：不再堅持對數函數要定義在一個平面上。它其實定義在一道無窮的螺旋樓梯上，即一個黎曼曲面（Riemann surface）；在這個曲面上，對數函數是單值而且光滑的。時至今日，黎曼曲面在幾何、數論和弦論中都佔有核心地位。

角度保持不變

再看一次圖 5.7.1。鉛垂和水平的格線相交成直角，它們變成的圓和射線也是如此。這並非巧合：凡是複函數的導數不為零之處，該函數都會保持曲線之間的夾角不變。這樣的映射稱為保角（conformal）映射。在局部範圍內，保角映射不過是一次旋轉加上一次縮放，而這正是乘以複數 \(f'(z)\) 所起的作用。保角映射可用來解決流體流動、靜電學和熱傳導的問題，方法是把一個複雜的區域變換成一個答案已知的簡單區域。

麥卡托地圖

這裏有一個意想不到的發現，把本節與 第 4.8 節 連繫起來。麥卡托（Gerardus Mercator）在 1569 年繪製的地圖，設計的目的是令羅盤方位恆定的航線成為一條直線，這就要求地圖保持角度不變。如果你先把地球以球極投影（stereographic projection）的方式（從北極出發）投影到一個平面上，然後取複對數，所得的結果恰好就是麥卡托投影：經線變成鉛垂線，緯線變成水平線，正如射線和圓在 \(\log\) 之下變成水平線和鉛垂線一樣。把本節的指數映射倒過來運行，就是航海圖背後的數學。

思維技巧

把函數想像成變換

當一個函數無法畫成圖像時，就把它所做的事畫出來：取一組由簡單曲線組成的格網，看看它們被映到哪裏。

對於複函數，水平線和鉛垂線的像，或者圓和射線的像，往往已能說明一切。這種着眼於映射如何改變圖形的思考方式，貫穿整個幾何與分析。

延伸練習

  1. 解方程。求所有滿足 \(e^w = -1\) 的複數 \(w\)，以及所有滿足 \(e^w = 1 + \mathrm{i}\) 的 \(w\)。

  2. 正方形的像。求頂點為 \(0\)、\(1\)、\(1 + \mathrm{i}\) 和 \(\mathrm{i}\) 的正方形在 \(z = e^w\) 之下的像，並畫出草圖。

  3. 直角。直接證明圓 \(|z| = e^c\) 與射線 \(\arg z = d\) 相交成直角，並解釋為甚麼這與直線 \(u = c\) 和 \(v = d\) 互相垂直是一致的。

  4. 平方。設 \(c\) 和 \(d\) 為非零實數。求直線 \(x = c\) 和 \(y = d\) 在映射 \(z \mapsto z^2\) 之下的像。證明它們都是拋物線，並且凡相交之處都相交成直角。（若 \(c = 0\) 或 \(d = 0\)，情況會怎樣？）
