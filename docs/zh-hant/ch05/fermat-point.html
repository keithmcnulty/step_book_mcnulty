費馬點

工作紙題目連結、提示、大學數學及練習 第 5 章整章的 PDF 版本
題目

STEP III 2000，第 3 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/00-s3-q3

引子

三條村莊想興建一個把它們全部連接起來的道路網絡，而且路程愈短愈好。交匯處應該設在哪裏？大約在 1640 年，費馬（Pierre de Fermat）提出了這樣一個問題：在三角形內找出使 \(PA + PB + PC\) 最小的點 \(P\)。托里拆利（Evangelista Torricelli）解決了這個問題：從這一點望向三條邊，所見的角都是 \(120^\circ\)。

本題利用複數（complex numbers）來證明這一點的一個漂亮作圖法。在三角形的每條邊上向外作一個等邊三角形（equilateral triangle），再把每個新頂點與原三角形中相對的頂點連起來。這三條直線相交於同一點，即費馬點（Fermat point），而且三條線段的長度都相同，這個長度正是道路總長的最小值。有了複數，再加上一條關於 \(e^{\mathrm{i}\pi/3}\) 的恆等式，整件事只需幾行代數運算。

動筆之前

\(A\)、\(B\) 和 \(C\) 在哪裏？它們的輻角（argument）是多少？\(OA\)、\(OB\) 和 \(OC\) 彼此之間的夾角是多少？

\(A = p\) 位於正實軸上（輻角為 \(0^\circ\)）。\(B = q\alpha^2 = qe^{2\pi\mathrm{i}/3}\) 的輻角是 \(120^\circ\)。\(C = -r\alpha = re^{\mathrm{i}\pi}e^{\mathrm{i}\pi/3}\) 的輻角是 \(240^\circ\)。因此原點是三角形內的一點，從這一點望向三個頂點，方向兩兩相隔 \(120^\circ\)，距離分別是 \(p\)、\(q\) 和 \(r\)。按照這個設定，原點就是費馬點；本題要證明的，是等邊三角形作圖法確實能找到它。

逐步解題

階段 1 關鍵恆等式

\(\alpha^3 = e^{\mathrm{i}\pi} = -1\)，所以 \(\alpha\) 是 \(z^3 + 1 = (z + 1)(z^2 - z + 1)\) 的一個根。由於 \(\alpha \neq -1\)，故 \(\alpha^2 - \alpha + 1 = 0\)，即 \(1 + \alpha^2 = \alpha\)。■

有兩個推論稍後會用得着：\(1 - \alpha = -\alpha^2\)，以及 \(\alpha - \alpha^2 = 1\)。此外，\(1 - \alpha = \frac12 - \frac{\sqrt3}{2}\mathrm{i} = e^{-\mathrm{i}\pi/3}\)，即 \(\alpha\) 的共軛複數（complex conjugate）。

階段 2 把等邊三角形看成旋轉

三角形 \(CAN\) 是等邊三角形，頂點按順時針方向標記。假如你站在 \(C\)，怎樣從 \(A\) 走到 \(N\)？試以 \(A - C\) 表示 \(N - C\)。

按順時針方向依次經過 \(C\)、\(A\)、\(N\)，可知點 \(N\) 是把 \(A\) 繞 \(C\) 順時針旋轉（rotation）\(60^\circ\) 而得。乘以 \(e^{-\mathrm{i}\pi/3} = 1 - \alpha\) 相當於順時針旋轉 \(60^\circ\)，所以 \[\begin{aligned} N = C + (1 - \alpha)(A - C) &= -r\alpha + (1 - \alpha)(p + r\alpha) \\ &= (1 - \alpha)p + r(\alpha - \alpha^2 - \alpha) = (1 - \alpha)p - \alpha^2r. \qed \end{aligned}\] （順時針而非逆時針旋轉，會使 \(N\) 落在 \(CA\) 的另一側，與原點分處兩邊，即在三角形之外。）

用同樣的方法求出 \(L\) 和 \(M\)，並利用第 1 階段的恆等式化簡。

同理，\(L = A + (1 - \alpha)(B - A)\) 及 \(M = B + (1 - \alpha)(C - B)\)： \[\begin{aligned} L &= p + (1 - \alpha)(q\alpha^2 - p) = \alpha p + (\alpha^2 - \alpha^3)q = \alpha p + (\alpha^2 + 1)q = \alpha(p + q), \\ M &= q\alpha^2 + (1 - \alpha)(-r\alpha - q\alpha^2) = q\alpha^3 + r(\alpha^2 - \alpha) = -q - r. \end{aligned}\] 再利用 \(1 - \alpha = -\alpha^2\)，可得 \(N = -\alpha^2p - \alpha^2r = -\alpha^2(p + r)\)。

階段 3 三條通過原點的直線

比較 \(L = \alpha(p + q)\) 與 \(C = -r\alpha\)。你留意到甚麼？對 \(M\) 與 \(A\)，以及 \(N\) 與 \(B\)，也作同樣的比較。

\(L\) 是 \(\alpha\) 的正數倍，而 \(C\) 是 \(\alpha\) 的負數倍。所以 \(L\) 和 \(C\) 分別位於 \(O\) 的兩側，並且在同一條通過 \(O\) 的直線上；線段 \(LC\) 因而通過原點，長度為 \(|L - C| = |\alpha|(p + q + r) = p + q + r\)。

同樣地，\(M = -(q + r)\) 和 \(A = p\) 都在實軸上，分別位於 \(O\) 的兩側，所以 \(MA\) 通過 \(O\)，長度為 \(p + q + r\)。而 \(N = -\alpha^2(p + r)\) 和 \(B = q\alpha^2\) 都在通過 \(O\)、方向為 \(\alpha^2\) 的直線上，並且分處兩側，所以 \(NB\) 通過 \(O\)，長度為 \(p + q + r\)。■

回顧

  • 旋轉即乘法。作等邊三角形，就是把一個頂點繞另一個頂點旋轉 \(60^\circ\)，也就是乘以 \(e^{\pm\mathrm{i}\pi/3}\)。

  • 巧選坐標。把費馬點放在原點，並讓各頂點沿 \(1\)、\(\alpha^2\)、\(-\alpha\) 這三個方向排列，每條算式都隨即大幅簡化。

  • 一條恆等式，反覆使用。每一步化簡都來自 \(\alpha^2 - \alpha + 1 = 0\) 和 \(\alpha^3 = -1\)。

背後的數學

為甚麼費馬點使距離最小

為甚麼 \(PA + PB + PC\) 會在各邊所對的角均為 \(120^\circ\) 的那一點取得最小值？以下是一個精彩的論證。把整幅圖繞 \(B\) 旋轉 \(60^\circ\)，把 \(A\) 送到 \(L'\)（即 \(AB\) 上等邊三角形的頂點），把 \(P\) 送到 \(P'\)。三角形 \(BPP'\) 是等邊三角形，所以 \(PB = PP'\)，而且 \(PA = P'L'\)。於是 \(PA + PB + PC = L'P' + P'P + PC\)，這是一條由 \(L'\) 到 \(C\) 的路徑的長度。它至少等於 \(|L'C|\)，而等號恰好在路徑成一直線時成立，這種情況出現於 \(P\) 處的各個角均為 \(120^\circ\) 之時。所以總長度的最小值是 \(|LC| = p + q + r\)，與題目所得的結果一致。（這個論證成立的前提是三角形的每個角都小於 \(120^\circ\)；否則最小值會在鈍角的頂點取得。）

肥皂膜與斯坦納樹

把一個裝有三根小釘（代表 \(A\)、\(B\)、\(C\)）的框架浸入肥皂水中：肥皂膜會令其表面張力能量減至最小，形成三面薄壁，在費馬點以 \(120^\circ\) 相交。若有更多的點，最短的連接網絡是一棵斯坦納樹（Steiner tree），其中有額外的交匯點，每個交匯點都有三條邊以 \(120^\circ\) 相交。一般而言，求斯坦納樹在計算上十分困難（這是一個 NP 困難（NP-hard）問題），但它們在實際應用中相當重要，例如設計道路網絡、管道網絡以及電腦晶片上的線路。

拿破崙定理

同一個圖形中還藏着另一件瑰寶：在任意三角形的三邊上所作的三個等邊三角形，它們的中心構成一個等邊三角形。傳統上這個結果歸功於拿破崙（Napoleon Bonaparte）（他是一位熱衷數學的業餘愛好者），不過並無證據顯示這是他發現的。這個定理同樣可以用複數簡短地證明，用到的正是 \(1 + \alpha^2 = \alpha\)。

思維技巧

選擇切合問題的坐標

把最重要的點放在原點，並按照問題的對稱性來安排各個方向。選得好，代數運算幾乎可以變得輕而易舉。

在這裏，原點就是費馬點，而三個頂點分別位於 \(-1\) 的三個立方根的方向上（或相差一個正負號）。若改用其他坐標，同樣的計算會繁複得多。

延伸練習

  1. 檢查字母次序。證明若各等邊三角形的頂點按逆時針方向標記（即向內作），則三條直線一般不會通過 \(O\)。

  2. 拿破崙定理。證明等邊三角形 \(ABL\) 的中心是 \(\frac13(A + B + L)\)。利用上文的表達式，證明三個中心構成一個等邊三角形。

  3. 最小值。取 \(p = 2\)，\(q = 1.4\)，\(r = 1.1\)，分別就 \(P\) 位於每個頂點以及位於形心（centroid）\(\frac13(A + B + C)\) 的情況計算 \(PA + PB + PC\)，並驗證所得的值全部大於 \(4.5\)。

  4. 等邊三角形的判別法。證明 \(z_1\)、\(z_2\)、\(z_3\) 構成等邊三角形（不論方向），當且僅當 \(z_1^2 + z_2^2 + z_3^2 = z_1z_2 + z_2z_3 + z_3z_1\)。
