5.8

圓盤中隱藏的距離

工作紙題目連結、提示、大學數學及練習 第 5 章整章的 PDF 版本
題目

STEP III 2013，第 6 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/13-s3-q6

引子

乍看之下，這只是一道運算模（modulus）和共軛（conjugate）的練習，最後得出一條模樣古怪的不等式。為甚麼會有人關心 \(\frac{|z - w|}{|1 - zw^*|}\) 呢？

因為它是一個距離。它不是 \(z\) 與 \(w\) 之間的普通距離，而是另一種幾何中的距離：在這種幾何裏，單位圓盤（unit disc）本身就是一個無限大的完整宇宙，直線是圓弧，三角形的內角和小於 \(180^\circ\)。這就是雙曲幾何（hyperbolic geometry）。兩千年來，人們一直試圖證明歐幾里得（Euclid）的平行公設（parallel postulate），到了十九世紀才發現這種幾何；而本題的不等式，原來正是它的三角不等式（triangle inequality），只是喬裝了一番。更令人意外的是，不等式的右邊正是狹義相對論（special relativity）中的速度相加公式，我們在 第 3.8 節 已經見過。

動筆之前

怎樣從圖形看出 \(|z - w| \leq |z| + |w|\)？（把 \(z\) 和 \(-w\) 想成向量。）

\(z - w = z + (-w)\)。先把 \(z\) 畫成由原點出發的箭嘴，再把 \(-w\) 畫成由 \(z\) 的尖端出發的箭嘴。由原點指向終點的箭嘴就是 \(z - w\)，三支箭嘴組成一個三角形，邊長分別為 \(|z|\)、\(|w|\) 和 \(|z - w|\)。三角形任何一邊的長度都不超過另外兩邊之和。

另外要記得，對任何複數 \(a\) 都有 \(|a|^2 = aa^*\)。這樣就可以把題目中每一個模都化為代數運算。

逐步解題

階段 1 展開各個模

展開 \(|z - w|^2 = (z - w)(z^* - w^*)\)，再與 \((|z| + |w|)^2\) 比較。

\(|z - w|^2 = zz^* - zw^* - z^*w + ww^* = |z|^2 + |w|^2 - zw^* - z^*w\)。另一方面，\((|z| + |w|)^2 - E = |z|^2 + 2|z||w| + |w|^2 - zw^* - z^*w - 2|zw|\)，而由於 \(|z||w| = |zw|\)，兩者相等。■

\(E = (zw^*) + (zw^*)^* + 2|zw| = 2\,\mathrm{Re}(zw^*) + 2|zw|\)，這是實數。而且根據三角不等式，\(E = (|z| + |w|)^2 - |z - w|^2 \geq 0\)。■

階段 2 第二條恆等式

\(|1 - zw^*|^2 = (1 - zw^*)(1 - z^*w) = 1 - zw^* - z^*w + |z|^2|w|^2\)，而 \((1 + |zw|)^2 - E = 1 + 2|zw| + |zw|^2 - zw^* - z^*w - 2|zw|\)，兩者相等。■

階段 3 不等式

設 \(A = (|z| + |w|)^2\) 和 \(B = (1 + |zw|)^2\)。把不等式兩邊平方後，它就是 \(\frac{A - E}{B - E} \leq \frac AB\)。這在甚麼時候成立？

所求不等式的兩邊都是非負的，所以它等價於平方後的不等式 \(\frac{A - E}{B - E} \leq \frac{A}{B}\)。假設 \(B - E = |1 - zw^*|^2 > 0\)，兩邊乘開： \[(A - E)B \leq A(B - E) \iff -EB \leq -EA \iff E(B - A) \geq 0.\] 由於 \(E \geq 0\)，只要 \(B \geq A\)，即 \(1 + |zw| \geq |z| + |w|\)，上式便成立。

證明 \(1 + |z||w| - |z| - |w|\) 可以因式分解。它在甚麼時候非負？

\(1 + |z||w| - |z| - |w| = (1 - |z|)(1 - |w|)\)。若 \(|z| > 1\) 且 \(|w| > 1\)，兩個因式都是負數，乘積為正。所以 \(B \geq A\)，不等式成立。■

若改為 \(|z| < 1\) 且 \(|w| < 1\)，兩個因式都是正數，乘積同樣為正，同一個論證依然適用：是的，不等式在這個情況下也成立。（在這兩個情況下都有 \(|zw^*| \neq 1\)，所以 \(1 - zw^* \neq 0\)，左邊有定義。）不等式可能不成立的，是混合的情況：一點在單位圓內，另一點在單位圓外。

回顧

  • \(|a|^2 = aa^*\)。每一條恆等式都是由展開共軛的乘積而來。這是用代數方法處理模的標準做法。

  • 歸結為一個量的正負。平方並交叉相乘之後，整條不等式只取決於 \((1 - |z|)(1 - |w|)\) 的正負。

  • 檢查其他情況。最後一問考慮 \(|z|, |w| < 1\)；同一個因式分解立即給出答案。

背後的數學

非歐幾里得幾何

兩千年來，數學家一直試圖由歐幾里得的其他公理，證明他的第五公設（過直線外一點，恰好有一條直線與該直線平行）。在 1820 和 1830 年代，羅巴切夫斯基（Nikolai Lobachevsky）、鮑耶（János Bolyai）和（私下研究的）高斯（Gauss）意識到這是辦不到的：存在一種完全相容的幾何，其中有無限多條平行線。1882 年，龐加萊（Henri Poincaré）在單位圓盤內找到了這種幾何的一個優美模型。點就是開圓盤內的點；「直線」是直徑，以及與邊界圓成直角相交的圓弧；而 \(z\) 與 \(w\) 之間的距離是 \[d(z, w) = 2\tanh^{-1}\rho(z, w), \qquad\text{其中}\qquad \rho(z, w) = \frac{|z - w|}{|1 - zw^*|}.\] 當一點趨近邊界圓時，它與圓心的距離趨向無限大：這個圓盤是一整個無限的平面，只是透過一塊令影像變形的透鏡來觀看。

喬裝了的三角不等式

對於 \(|z|, |w| < 1\)，題目所證明的其實是以下結果。設 \(|z| = \tanh a\) 和 \(|w| = \tanh b\)，則由 \(0\) 到 \(z\) 和 \(w\) 的雙曲距離分別是 \(2a\) 和 \(2b\)。根據 第 3.8 節 中 \(\tanh\) 的加法公式， \[\frac{|z| + |w|}{1 + |zw|} = \frac{\tanh a + \tanh b}{1 + \tanh a\tanh b} = \tanh(a + b).\] 所以該不等式就是 \(\tanh\bigl(\frac12 d(z, w)\bigr) \leq \tanh(a + b)\)，即 \[d(z, w) \leq 2a + 2b = d(z, 0) + d(0, w).\] 這就是雙曲距離的三角不等式（圖 5.8.1）。相對論的速度相加公式與雙曲幾何，骨子裏是同一回事：狹義相對論中所有可能速度組成的集合，配上適當的距離概念，就是一個雙曲空間。我們會在 第 7.6 節 再談這一點。

圓盤的對稱

為甚麼 \(\rho\) 是合適的量？對於 \(|a| < 1\)，映射 \(z \mapsto \dfrac{z - a}{1 - a^*z}\) 把單位圓盤映到自身，保持雙曲距離不變，並把 \(a\) 移到圓心。它們是平移在雙曲幾何中的對應物，而 \(\rho(z, w)\) 正是把 \(w\) 移到圓心時的 \(|{\text{映射後的 } z}|\)。這些莫比烏斯變換（Möbius transformation）是複分析（complex analysis）的核心課題。艾雪（M. C. Escher）的木刻版畫《圓極限》（Circle Limit），靈感來自數學家考克斯特（H. S. M. Coxeter）的一幅圖；畫中以全等的魚和天使鑲嵌（tiling）龐加萊圓盤，它們愈近邊緣便愈小，因為雙曲距離在那裏會無限增大。

思維技巧

問一問算式有甚麼意義

當某個代數式不斷出現時，問一問它是否有某種意義：一個距離、一個角、一個概率、一種對稱。

在這裏，一個古怪的模之比原來是另一種幾何中的距離，而一條古怪的不等式原來是它的三角不等式。認出當中的意義，就能解釋結果為何成立，以及它通往何處。

延伸練習

  1. 數值驗算。取 \(z = \frac12\) 和 \(w = -\frac12\)。計算不等式的兩邊。然後計算雙曲距離 \(d(z, 0)\)、\(d(0, w)\) 和 \(d(z, w)\)，並驗證三角不等式在這裏取等號。為甚麼？

  2. 混合的情況。求滿足 \(|z| < 1 < |w|\) 的 \(z\)、\(w\)，使不等式不成立。

  3. 等距映射（isometry）。設 \(f(z) = \dfrac{z - a}{1 - a^*z}\)，其中 \(|a| < 1\)。證明當 \(|z| = 1\) 時必有 \(|f(z)| = 1\)，並且 \(f(a) = 0\)。證明 \(\rho(f(z), f(w)) = \rho(z, w)\)。

  4. 無限近在咫尺。證明由 \(0\) 到 \(r\)（其中 \(0 < r < 1\)）的雙曲距離是 \(\ln\frac{1+r}{1-r}\)，並且當 \(r \to 1\) 時它趨向無限大。一點要多接近邊界，才會與圓心相距雙曲距離 \(10\)？

延伸閱讀

  • Caroline Series, “Hyperbolic geometry” lecture notes（華威大學 University of Warwick，可免費取得）。一份清晰的入門課程講義，由龐加萊圓盤講起。

  • Jeremy Gray, Ideas of Space（牛津大學出版社 Oxford University Press）。由歐幾里得到愛因斯坦（Einstein）的非歐幾里得幾何史。

  • Tristan Needham, Visual Complex Analysis（牛津大學出版社 Oxford University Press）。第 6 章講述非歐幾里得幾何和莫比烏斯變換，並配有精美的插圖。
