5.3

因式分解 \(z^{2n} + 1\)

工作紙題目連結、提示、大學數學及練習 第 5 章整章的 PDF 版本
題目

STEP III 2013，第 4 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/13-s3-q4

引子

\(\cos\frac{\pi}{8}\cos\frac{3\pi}{8}\cos\frac{5\pi}{8}\cos\frac{7\pi}{8}\) 等於多少？每個因子都是涉及多重根號的難看數字，但它們的乘積卻恰好是 \(\frac18\)。等間隔角度的餘弦之積，總是這樣化簡成簡潔的數，而這道題正好解釋了箇中原因。竅門在於看出這些角度是某個多項式（polynomial）的根（roots）的輻角（argument），把該多項式因式分解（factorise），然後代入（substitute）一個巧妙選取的值。

在複數（complex numbers）範圍內，每個多項式都可以完全分解成線性因式（linear factors）。在實數範圍內，非實根以共軛對（conjugate pairs）的形式出現，每一對合併成一個實二次因式（real quadratic factor）。這兩項事實在本題中都展現出來，而 \(z^{2n} + 1\) 明明完全沒有實根，卻可以寫成實二次式之積，靠的正是第二項事實。

動筆之前

\(z^{2n} = -1\) 的解在複數平面（complex plane）上的甚麼位置？試就 \(n = 2\) 和 \(n = 4\) 把它們畫出來。

它們的模（modulus）全都是 \(1\)，而輻角 \(\theta\) 滿足 \(2n\theta = \pi + 2m\pi\)，所以 \(\theta\) 是 \(\frac{\pi}{2n}\) 的奇數倍。它們在單位圓（unit circle）上構成一個正 \(2n\) 邊形，並且旋轉到沒有任何頂點落在實軸上（圖 5.3.1）。它們兩兩配成共軛對 \(e^{\pm\mathrm{i}\theta}\)，即關於實軸互為鏡像。

逐步解題

階段 1 共軛對給出實二次式

\((z - e^{\mathrm{i}\theta})(z - e^{-\mathrm{i}\theta}) = z^2 - (e^{\mathrm{i}\theta} + e^{-\mathrm{i}\theta})z + 1 = z^2 - 2z\cos\theta + 1\).■

階段 2 因式分解

滿足 \(-\pi < \theta \leq \pi\) 的 \(-1\) 的 \(2n\) 次方根是 \(e^{\pm\mathrm{i}\theta_k}\)，其中 \[\theta_k = \frac{(2k - 1)\pi}{2n}, \qquad k = 1, 2, \ldots, n.\] 這是 \(2n\) 個互不相同的數，全都是 \(2n\) 次多項式 \(z^{2n} + 1\) 的根，所以它們就是該多項式的全部根，於是 \[z^{2n} + 1 = \prod_{k=1}^{n}(z - e^{\mathrm{i}\theta_k})(z - e^{-\mathrm{i}\theta_k}) = \prod_{k=1}^{n}\bigl(z^2 - 2z\cos\theta_k + 1\bigr). \qed\]

階段 3 代入 \(z = \mathrm{i}\)

\(\mathrm{i}^2 - 2\mathrm{i}\cos\theta + 1\) 等於甚麼？當 \(n\) 是偶數時，\(\mathrm{i}^{2n} + 1\) 又等於甚麼？

每個因式變成 \[\mathrm{i}^2 - 2\mathrm{i}\cos\theta_k + 1 = -2\mathrm{i}\cos\theta_k,\] 所以右邊是 \((-2\mathrm{i})^n\prod_k\cos\theta_k\)。左邊是 \(\mathrm{i}^{2n} + 1 = (-1)^n + 1\)，當 \(n\) 是偶數時等於 \(2\)。而對於偶數 \(n\)， \[(-2\mathrm{i})^n = 2^n(-\mathrm{i})^n = 2^n\bigl((-\mathrm{i})^2\bigr)^{n/2} = 2^n(-1)^{n/2}.\] 因此 \[\prod_{k=1}^{n}\cos\theta_k = \frac{2}{2^n(-1)^{n/2}} = (-1)^{\frac12 n}2^{1-n}. \qed\] 當 \(n = 4\) 時，這正是引子中的乘積：\((-1)^2 2^{-3} = \frac18\)。

階段 4 當 \(n\) 是奇數時

對於奇數 \(n\)，其中一個角 \(\theta_k\) 等於 \(\frac\pi2\)。是哪一個？為甚麼這會令代入 \(z = \mathrm{i}\) 這一步在現有形式下毫無用處？

當 \(k = \frac{n+1}{2}\) 時，\(\theta_k = \frac{n\pi}{2n} = \frac\pi2\)，所以該因式是 \(z^2 + 1\)，它在 \(z = \mathrm{i}\) 時等於零；兩邊都是 \(0\)，我們甚麼也得不到。解決辦法是先把這個因式除去，而題目給出的恆等式正是這樣做的。

把因式分解式的兩邊除以 \(1 + z^2\)，代入 \(z = \mathrm{i}\)，然後化簡。你需要把餘下的餘弦兩兩配對。

除以因式 \(z^2 + 1\)（即 \(k = \frac{n+1}{2}\) 的那一項），得 \[1 - z^2 + z^4 - \cdots + z^{2n-2} = \prod_{k \neq \frac{n+1}{2}}\bigl(z^2 - 2z\cos\theta_k + 1\bigr).\] 當 \(z = \mathrm{i}\) 時，左邊每一項都是 \((-z^2)^j = 1^j = 1\)，而共有 \(n\) 項，所以左邊等於 \(n\)。右邊是 \((-2\mathrm{i})^{n-1}\prod_{k \neq \frac{n+1}{2}}\cos\theta_k\)。由於 \(n - 1\) 是偶數，\((-2\mathrm{i})^{n-1} = 2^{n-1}(-1)^{(n-1)/2}\)。

現在把各角配對：\(\theta_{n+1-k} = \pi - \theta_k\)，所以 \(\cos\theta_{n+1-k} = -\cos\theta_k\)。餘下的 \(n - 1\) 個因子組成 \(\frac{n-1}{2}\) 個這樣的對，其中 \(k = 1, \ldots, \frac{n-1}{2}\)，而每一對貢獻 \(-\cos^2\theta_k\)。因此 \[n = 2^{n-1}(-1)^{(n-1)/2}\cdot(-1)^{(n-1)/2}\prod_{k=1}^{(n-1)/2}\cos^2\theta_k = 2^{n-1}\prod_{k=1}^{(n-1)/2}\cos^2\theta_k,\] 從而得到 \(\prod\cos^2\theta_k = n2^{1-n}\)。最後一個因子，即 \(k = \frac{n-1}{2}\) 的那個，是 \(\cos^2\frac{(n-2)\pi}{2n}\)，與題目所寫的一致。■

以 \(n = 3\) 驗算：\(\cos^2\frac\pi6 = \frac34 = 3 \cdot 2^{-2}\)。

回顧

  • 知道根，就知道多項式。一個多項式由它的根決定（只差一個常數倍），所以列出 \(z^{2n} + 1\) 的根，就得到它的因式分解。

  • 代入一個巧妙的值。取 \(z = \mathrm{i}\)，每個二次因式都變成餘弦的倍數。

  • 當代入後得到 \(0 = 0\)，就先做除法。對於奇數 \(n\)，有一個因式在 \(z = \mathrm{i}\) 時等於零，所以我們在代入之前先把它除去。

背後的數學

代數基本定理

\(z^{2n} + 1\) 可以在 \(\mathbb{C}\) 上完全分解成線性因式，這是代數基本定理（fundamental theorem of algebra）的一個特殊情況：每個複係數的非常數多項式都有一個複根，因而可以完全分解成線性因式。高斯（Gauss）在 1799 年的博士論文中給出了第一個獲廣泛接受的證明，其後又多次重新探討這條定理，提出新的證明。由此可推出，每個實多項式都可以分解成實線性因式和實二次因式，因為非實根以共軛對的形式出現，正如第 1 步所見。這條定理名為「代數」，實質卻屬於分析：每個證明都要用到實數的某種性質，例如連續性（continuity），而你會在複分析（complex analysis）的入門課程中見到其中一個最巧妙的證明。

正弦與餘弦之積

這個方法可以給出一整族恆等式。以 \(z^n - 1\) 取代 \(z^{2n} + 1\)，就得到 \[\prod_{k=1}^{n-1}\sin\frac{k\pi}{n} = \frac{n}{2^{n-1}},\] 它的幾何形式在 第 5.4 節 中有證明。這類恆等式會在振動系統的分析中出現（以彈簧相連的 \(n\) 個質點的頻率涉及 \(\sin\frac{k\pi}{2(n+1)}\)），也會在計數問題中出現（某些圖的生成樹（spanning trees）數目，以及長方形的多米諾骨牌鋪砌（domino tilings）數目，都可以用餘弦之積表示）。Kasteleyn 在 1961 年提出的 \(m \times n\) 長方形多米諾骨牌鋪砌公式，是一個雙重乘積，其中各項是含 \(\cos^2\frac{j\pi}{m+1}\) 和 \(\cos^2\frac{k\pi}{n+1}\) 的式子。

思維技巧

從根到乘積

要計算等間隔角度的三角函數值之積，先看出它們來自某個簡單多項式的根，再作因式分解，然後代入一個方便的值。

選取甚麼值，是一門藝術：本題中 \(z = \mathrm{i}\) 把每個二次因式變成一個餘弦。其他選擇（例如 \(z = 1\) 或 \(z = -1\)）會給出其他恆等式。

延伸練習

  1. 一個七邊形的乘積。利用第 (ii) 部分，取 \(n = 7\)，證明 \(\cos\frac{\pi}{14}\cos\frac{3\pi}{14}\cos\frac{5\pi}{14} = \frac{\sqrt7}{8}\)。然後證明 \(\cos\frac{\pi}{7}\cos\frac{2\pi}{7}\cos\frac{3\pi}{7} = \frac18\)。（提示：利用 \(\cos\theta = \sin(\frac\pi2 - \theta)\) 把各角聯繫起來，或者反覆使用恆等式 \(\sin 2x = 2\sin x\cos x\)。）

  2. 另一個代入。在因式分解式中代入 \(z = 1\)，證明 \[\prod_{k=1}^{n}\sin\frac{(2k-1)\pi}{4n} = 2^{\frac12 - n}.\]

  3. 分解 \(z^6 + 1\)。把 \(z^6 + 1\) 寫成三個實二次式之積，並把它們乘開以驗算答案。

  4. 正弦。以類似方法分解 \(z^{2n} - 1\)，再除以 \(z^2 - 1\)，證明 \[\prod_{k=1}^{n-1}\sin\frac{k\pi}{2n} = \frac{\sqrt n}{2^{n-1}}.\]

  • Benjamin Fine & Gerhard Rosenberger, The Fundamental Theorem of Algebra（Springer）。收錄這條定理的多個證明，分別來自分析、代數和拓撲，為大學本科生而寫。
