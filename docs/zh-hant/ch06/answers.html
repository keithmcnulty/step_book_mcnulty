第 6 章 · 代數與結構

延伸練習答案

以下只是簡短的答案和提示，並非完整解答：這裏只列出結果和關鍵步驟，方便你核對自己的做法。請先認真做過每一道練習，然後才看答案。

6.1 以單位根為根的多項式

  1. \((x - 1)(x + 1) = x^2 - 1\) 而 \((x^2 + x + 1)(x^2 - x + 1) = x^4 + x^2 + 1\)，兩者之積為 \(x^6 - 1\)。同理，\(x^{12} - 1 = (x^6 - 1)(x^6 + 1)\)，而 \(x^6 + 1 = (x^2 + 1)(x^4 - x^2 + 1) = \mathrm{C}_4\mathrm{C}_{12}\)。

  2. \(2p\) 的因數（divisor）為 \(1\)、\(2\)、\(p\)、\(2p\)，所以 \(\mathrm{C}_{2p} = \frac{x^{2p} - 1}{(x - 1)(x + 1)\mathrm{C}_p(x)} = \frac{x^p + 1}{x + 1}\)。另一方面，\(\mathrm{C}_p(-x) = \frac{(-x)^p - 1}{-x - 1} = \frac{x^p + 1}{x + 1}\)，因為 \(p\) 是奇數。當 \(p = 3\) 時：\(\mathrm{C}_6 = x^2 - x + 1 = \mathrm{C}_3(-x)\)。

  3. 不超過 \(p^k\) 而又與 \(p^k\) 有公因數的數，就是那 \(p^{k-1}\) 個 \(p\) 的倍數。本原（primitive）\(p^k\) 次單位根是 \(x^{p^k} - 1\) 的根之中不屬於 \(x^{p^{k-1}} - 1\) 的根的那些，所以 \(\mathrm{C}_{p^k} = \frac{x^{p^k} - 1}{x^{p^{k-1}} - 1} = \mathrm{C}_p\bigl(x^{p^{k-1}}\bigr)\)。因此 \(\mathrm{C}_9 = x^6 + x^3 + 1\)。

  4. \(\mathrm{C}_{15} = \frac{(x^{15} - 1)(x - 1)}{(x^3 - 1)(x^5 - 1)}\)。把 \((x - 1)(x^2 + x + 1)(x^4 + x^3 + x^2 + x + 1)\) 與題中給出的八次式相乘並展開，驗證結果為 \(x^{15} - 1\)。

6.2 高斯的正十七邊形

  1. \(\eta + \eta'\) 是全部六個非實七次單位根之和，即 \(-1\)。展開 \(\eta\eta'\) 得到九項 \(\alpha^{a+b}\)，其指數為 \(4, 6, 0, 5, 0, 1, 0, 2, 3\)（模 \(7\)）：即三個 \(1\)，以及每個非實根各出現一次，所以 \(\eta\eta' = 3 - 1 = 2\)。因此 \(\eta\)、\(\eta'\) 就是 \(\frac{-1 \pm \mathrm{i}\sqrt7}{2}\)。\(\eta\) 的實部給出餘弦之和。它的虛部是 \(\sin\frac{2\pi}{7} + \sin\frac{4\pi}{7} - \sin\frac{\pi}{7}\)，由於 \(\sin\frac{4\pi}{7} = \sin\frac{3\pi}{7} > \sin\frac\pi7\)，這個值為正；所以它等於 \(+\frac{\sqrt7}{2}\)。

  2. 設 \(\zeta = \mathrm{e}^{2\pi\mathrm{i}/5}\)，則兩個週期（period）\(\zeta + \zeta^4 = 2\cos\frac{2\pi}{5}\) 和 \(\zeta^2 + \zeta^3\) 之和為 \(-1\)，之積為 \(-1\)，所以它們是 \(t^2 + t - 1 = 0\) 的根，而其中的正根給出 \(\cos\frac{2\pi}{5} = \frac{\sqrt5 - 1}{4}\)。作圖方法：在單位圓內，兩條直角邊為 \(1\) 和 \(\frac12\) 的直角三角形，斜邊長為 \(\frac{\sqrt5}{2}\)；減去 \(\frac12\) 再取一半，便得 \(\cos\frac{2\pi}{5}\)。在軸上這個距離處作垂線，它與圓相交於一個與 \((1, 0)\) 相鄰的頂點；再用這條弦沿圓周逐步截取。

  3. 兩者準確至小數點後五位都是 \(-1.28078\)。

  4. \(3\) 的各次冪依次為 \(3, 9, 10, 13, 5, 15, 11, 16, 14, 8, 7, 4, 12, 2, 6, 1\)：十六個數全部出現。\(2\) 的各次冪在八步之後重複（\(2^8 = 256 \equiv 1\)），給出 \(\{1, 2, 4, 8, 9, 13, 15, 16\}\)，即模 \(17\) 的非零平方數。

6.3 以 \(\sqrt2 + \sqrt3 + \sqrt5\) 為根的多項式

  1. \(y^3 = 2\sqrt2 + 6\sqrt3 + 9\sqrt2 + 3\sqrt3 = 11\sqrt2 + 9\sqrt3\)，而 \(9y = 9\sqrt2 + 9\sqrt3\)，所以 \(y^3 - 9y = 2\sqrt2\)。於是 \(\sqrt3 = y - \sqrt2\) 和 \(\sqrt6 = \sqrt2\sqrt3\) 也都是 \(y\) 的多項式。

  2. 設 \(x - \sqrt2 = \sqrt[3]3\) 並取立方：\(x^3 + 6x - 3 = \sqrt2(3x^2 + 2)\)。兩邊平方得 \(x^6 - 6x^4 - 6x^3 + 12x^2 - 36x + 1 = 0\)。

  3. 可能的有理根只有 \(\pm1\)，而兩者都不是根。由於沒有 \(x^3\) 項，分解成兩個首一（monic）二次式時必定形如 \((x^2 + ax + b)(x^2 - ax + c)\)，其中 \(a(c - b) = 0\)、\(b + c - a^2 = -10\) 及 \(bc = 1\)。若 \(a = 0\)，則 \(b + c = -10\) 且 \(bc = 1\)，在整數範圍內不可能；若 \(b = c = \pm1\)，則 \(a^2 = 12\) 或 \(8\)，同樣不可能。所以這個四次式不可約（irreducible），而 \(\sqrt2 + \sqrt3\) 的次數（degree）為 \(4\)。

  4. 由棣美弗（De Moivre）定理，\(\cos3\theta = 4\cos^3\theta - 3\cos\theta\)；取 \(\theta = 20^\circ\)，得 \(\frac12 = 4c^3 - 3c\)。候選的有理根 \(\pm1, \pm\frac12, \pm\frac14, \pm\frac18\) 全都不成立。所以 \(\cos20^\circ\) 的次數為 \(3\)，但每個可作圖（constructible）長度的次數都是 \(2\) 的冪，因此無法由 \(60^\circ\) 作出 \(20^\circ\)。

6.4 解四次方程

  1. \(y_1y_2 + y_2y_3 + y_3y_1\) 是十二項 \(\alpha^2\beta\gamma\)（一個根的平方乘以另外兩個根）之和。而 \(\bigl(\sum\alpha\bigr)\bigl(\sum\alpha\beta\gamma\bigr)\) 則是這十二項再加上 \(4\alpha\beta\gamma\delta\)。所以所求之和為 \((-p)(-r) - 4s\)。

  2. 比較係數得 \(a + b = 1\)、\(a\alpha + b\beta = 0\) 及 \(a\alpha^2 + b\beta^2 = -p\)，當 \(\alpha \neq \beta\) 時有解，而這正是那兩個條件所保證的：\(p \neq 0\) 使關於 \(t\) 的方程是真正的二次方程（若 \(p = 0\)，它會退化成 \(-qt = 0\)，只有單一個根 \(0\)），而 \(q^2 \neq 4p^3\) 則使它的判別式（discriminant）\(q^2 - 4p^3\) 不為零。對於 \(x^3 - 24x + 48\)：\(p = 8\)，\(q = 48\)，而 \(8t^2 - 48t + 64 = 0\) 給出 \(\alpha = 2\)，\(\beta = 4\)。於是 \(\bigl(\frac{x - 2}{x - 4}\bigr)^3 = -\frac ba = \frac\alpha\beta = \frac12\)，所以 \(x - 2 = 2^{-1/3}(x - 4)\)，整理後即得題中給出的根，\(x \approx -5.6946\)。

  3. 預解三次式（resolvent cubic）為 \(y^3 - 7y^2 + 16y - 12 = (y - 3)(y - 2)^2\)。由根 \(y = 3\) 得出 \((x^2 - 2x + 1)(x^2 - 2x + 2)\)，所以各根為 \(1\)（二重根）和 \(1 \pm \mathrm{i}\)。

  4. 在每一對之內可以對換或不對換（\(4\) 種選擇），兩對之間也可以互換或不互換（\(2\) 種選擇）：恆等置換、\((\alpha\beta)\)、\((\gamma\delta)\)、\((\alpha\beta)(\gamma\delta)\)、\((\alpha\gamma)(\beta\delta)\)、\((\alpha\delta)(\beta\gamma)\)、\((\alpha\gamma\beta\delta)\) 和 \((\alpha\delta\beta\gamma)\)。這與正方形的對稱羣（symmetry group）結構完全相同。

6.5 從公理出發的微分法

  1. 常數仍然給出 \(0\)，而由規則 (i) 及歸納法（induction）可得 \(\lozenge x^n = x^{n-1}\lozenge x + x\lozenge x^{n-1} = nx^n\)。再由線性（linearity）得 \(\lozenge\mathrm{h} = x\mathrm{h}'\)。

  2. \(\lozenge\mathrm{f} = \frac{\mathrm{f}}{\mathrm{g}}\lozenge\mathrm{g} + \mathrm{g}\lozenge\frac{\mathrm{f}}{\mathrm{g}}\)，所以 \(\lozenge\frac{\mathrm{f}}{\mathrm{g}} = \frac{\mathrm{g}\lozenge\mathrm{f} - \mathrm{f}\lozenge\mathrm{g}}{\mathrm{g}^2}\)。

  3. 若 \(\mathrm{f} = (x - a)^2\mathrm{g}\)，則 \(\mathrm{f}' = (x - a)\bigl(2\mathrm{g} + (x - a)\mathrm{g}'\bigr)\)。\(x^n - 1\) 的重根（repeated root）必定也是 \(nx^{n-1}\) 的根，所以只能是 \(0\)；但 \(0\) 並不是 \(x^n - 1\) 的根。

  4. \((2 + \varepsilon)^2 + 1 = 5 + 4\varepsilon\)，而 \((5 + 4\varepsilon)^3 = 125 + 300\varepsilon\)。所以 \(f(2) = 125\) 及 \(f'(2) = 300\)；用鏈式法則（chain rule）則得 \(3(x^2 + 1)^2 \cdot 2x = 3 \cdot 25 \cdot 4 = 300\)。

6.6 子羣的併集

  1. 設 \(V = \{e, a, b, c\}\)：\(a^2 = b^2 = c^2 = e\)，而 \(a\)、\(b\)、\(c\) 之中任意兩個之積都是第三個。每個元素都是自己的逆元（inverse）。在 \(\{1, \mathrm{i}, -1, -\mathrm{i}\}\) 中，\(\mathrm{i}\) 的逆元是 \(-\mathrm{i}\)，所以這兩個羣並不相同。

  2. 假如 \(g\) 屬於某個真子羣（proper subgroup）\(H\)，那麼 \(g\) 的每個冪也都屬於它，於是 \(H\) 就是整個羣。

  3. \(1\) 既不是偶數，也不是 \(3\) 的倍數。更一般地，\(\mathbb{Z}\) 是循環羣（cyclic group，由 \(1\) 生成），所以根據上一題，它不是任意多個真子羣的並集（union）。

  4. 直線 \(y = mx\) 與 \(y = x^2\) 只相交於 \(x = 0\) 和 \(x = m\) 兩處，而直線 \(x = 0\) 與它只相交於原點。所以 \(k\) 條直線最多只能包含 \(k\) 個形如 \((t, t^2)\) 而 \(t \neq 0\) 的點，但這樣的點有無窮多個。

6.7 四元數羣

  1. \(C\circ B = (\mathrm{i}, 0)\circ(0, 1) = (0, \mathrm{i}) = D\)，而 \(B\circ C = (0, 1)\circ(\mathrm{i}, 0) = (0, \mathrm{i}^*) = (0, -\mathrm{i}) = H\)。

  2. \(A\) 的階（order）為 \(1\)，\(E\) 的階為 \(2\)；其餘六個元素的平方都是 \(E\)，所以階為 \(4\)。正方形的對稱羣有五個階為 \(2\) 的元素（四個反射和一個半周旋轉），所以這兩個羣並不同構（isomorphic）。

  3. \(\det M = z_1z_1^* + z_2z_2^* = |z_1|^2 + |z_2|^2\)，這是四個實數平方之和。由於 \(M(z)M(w)\) 是 \(z\circ w\) 的矩陣，把行列式（determinant）相乘，便可把 \((a_1^2 + \cdots + a_4^2)(b_1^2 + \cdots + b_4^2)\) 寫成 \(|u_1|^2 + |u_2|^2\)，同樣是四個平方之和。

  4. 各子羣為 \(\{A\}\)、\(\{A, E\}\)、\(\{A, E, C, G\}\)、\(\{A, E, B, F\}\)、\(\{A, E, D, H\}\) 和 \(Q_8\)。除 \(A\) 以外，每個元素都有某個冪等於 \(E\)，所以除 \(\{A\}\) 以外的任何子羣都包含 \(E\)。三個階為 \(4\) 的子羣合起來包含了全部八個元素。

6.8 由奇異矩陣組成的羣

  1. \(\mathbf{M}_a\mathbf{M}_b = \mathbf{M}_{2ab}\)，而 \(2(2ab) = (2a)(2b)\)。這個映射是一對一（one-to-one）的，並且映成（onto）全體非零實數。

  2. \(\begin{pmatrix} a & b \\ 0 & 0 \end{pmatrix}\begin{pmatrix} c & d \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} ac & ad \\ 0 & 0 \end{pmatrix}\)，其中 \(ac \neq 0\)，所以這個集合是封閉（closed）的。每個 \(\begin{pmatrix} 1 & e \\ 0 & 0 \end{pmatrix}\) 都是左單位元（left identity）。但若要 \(\mathbf{XE} = \mathbf{X}\)，其中 \(\mathbf{E} = \begin{pmatrix} e & f \\ 0 & 0 \end{pmatrix}\)，便需要 \(e = 1\) 及 \(f = b/a\)，而後者取決於 \(\mathbf{X}\)：所以沒有右單位元，因而沒有單位元，也就不成羣。

  3. \(\mathbf{0}\)、\(\mathbf{I}\)，以及滿足 \(bc = a(1 - a)\) 的矩陣 \(\begin{pmatrix} a & b \\ c & 1 - a \end{pmatrix}\)（跡（trace）為 \(1\)，行列式為 \(0\)）。這些就是把平面沿一條直線的方向投影（projection）到另一條直線上的變換。

  4. 所有元素均為 \(a\) 的矩陣 \(\mathbf{J}_a\) 滿足 \(\mathbf{J}_a\mathbf{J}_b = \mathbf{J}_{nab}\)。單位元是 \(\mathbf{J}_{1/n}\)，而 \(\mathbf{J}_a\) 的逆元是 \(\mathbf{J}_{1/(n^2a)}\)。
