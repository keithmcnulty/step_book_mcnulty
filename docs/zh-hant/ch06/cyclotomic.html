6.1

以單位根為根的多項式

題目

STEP III 2010，第 3 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/10-s3-q3

引子

\(n\) 次單位根（roots of unity），即 \(z^n = 1\) 的解，位於正 \(n\) 邊形的各個頂點上。但它們並非全都一樣。例如在 \(12\) 次單位根之中，\(1\) 本身已是一次單位根，\(-1\) 是二次單位根，\(\mathrm{i}\) 是四次單位根，而十二個之中只有四個，即本原（primitive）的那些，才需要走足十二步方能回到 \(1\)。

按所需的步數把單位根分類，再由每一類構造一個多項式，便得到分圓多項式（cyclotomic polynomials，此名源自希臘文，意即「分割圓周」）。它們是 \(z^n - 1\) 的基本構件，正如質數是整數的基本構件一樣；高斯（Gauss）的正 \(17\) 邊形作圖法（第 6.2 節）、單位根篩選法（第 5.2 節）以及現代數論中的不少內容，背後都有它們的身影。

動筆之前

每個 \(n\) 次單位根都滿足 \(z^n = 1\)。但使它等於 \(1\) 的最小正整數次冪，可能小於 \(n\)。對於四個 4 次單位根 \(1\)、\(\mathrm{i}\)、\(-1\)、\(-\mathrm{i}\)，這個最小的冪次分別是多少？

\(1^1 = 1\)，\((-1)^2 = 1\)，而 \(\mathrm{i}^4 = (-\mathrm{i})^4 = 1\)，且沒有更小的冪次可行。所以最小的冪次依次是 \(1\)、\(4\)、\(2\)、\(4\)。這個最小的冪次稱為該單位根的階（order），而本原 \(n\) 次單位根正是階為 \(n\) 的那些單位根。整道題的關鍵事實是：每個單位根都恰好有一個階。

逐步解題

階段 1 最初的幾個

本原 4 次單位根是 \(\mathrm{i}\) 和 \(-\mathrm{i}\)，所以 \(\mathrm{C}_4(x) = (x - \mathrm{i})(x + \mathrm{i}) = x^2 + 1\)。■

哪些單位根的階是 \(1\)、\(2\)、\(3\)、\(5\) 和 \(6\)？（畫出 \(6\) 次單位根，並按階把它們分類。）

階為 \(1\)：只有 \(1\)，所以 \(\mathrm{C}_1(x) = x - 1\)。階為 \(2\)：只有 \(-1\)，所以 \(\mathrm{C}_2(x) = x + 1\)。

階為 \(3\)：除 \(1\) 以外的三次單位根，即 \(\frac{x^3 - 1}{x - 1}\) 的根。所以 \(\mathrm{C}_3(x) = x^2 + x + 1\)。

階為 \(5\)：除 \(1\) 以外的五次單位根，它們是 \(\frac{x^5 - 1}{x - 1}\) 的根，所以 \(\mathrm{C}_5(x) = x^4 + x^3 + x^2 + x + 1\)。

階為 \(6\)：在六次單位根 \(e^{k\pi\mathrm{i}/3}\)，\(k = 0, \ldots, 5\) 之中，\(k = 0\)、\(3\) 的階分別是 \(1\)、\(2\)，而 \(k = 2\)、\(4\) 的階是 \(3\)。餘下的是 \(e^{\pm\pi\mathrm{i}/3}\)，所以 \[\mathrm{C}_6(x) = (x - e^{\mathrm{i}\pi/3})(x - e^{-\mathrm{i}\pi/3}) = x^2 - 2x\cos\tfrac\pi3 + 1 = x^2 - x + 1. \qed\]

階段 2 哪個 \(n\) 給出 \(x^4 + 1\)？

\(x^4 + 1 = 0\) 的根滿足 \(x^4 = -1\)，所以 \(x^8 = 1\) 但 \(x^4 \neq 1\)。它們的階整除 \(8\) 但不整除 \(4\)，所以階是 \(8\)。反過來，階為 \(8\) 的單位根滿足 \(x^8 = 1\)，\(x^4 \neq 1\)，所以 \(x^4 = -1\)。本原 \(8\) 次單位根有四個，\(x^4 + 1\) 的根也有四個，所以 \(n = 8\)。■

階段 3 質數

若 \(p\) 是質數，則 \(p\) 次單位根的階整除 \(p\)，所以階是 \(1\) 或 \(p\)。因此除 \(1\) 以外的每個 \(p\) 次單位根都是本原的，而 \[\mathrm{C}_p(x) = \frac{x^p - 1}{x - 1} = x^{p-1} + x^{p-2} + \cdots + x + 1. \qed\]

階段 4 沒有分圓多項式是另外兩個分圓多項式之積

假設 \(\mathrm{C}_q = \mathrm{C}_r\mathrm{C}_s\)。取 \(\mathrm{C}_r\) 的一個根。它的階是多少？這條恆等式對它的階有何說法？由此必然得出甚麼？

\(\mathrm{C}_r\) 的每個根（至少有一個，因為 \(e^{2\pi\mathrm{i}/r}\) 是本原的）都是 \(\mathrm{C}_r\mathrm{C}_s = \mathrm{C}_q\) 的根，所以它的階是 \(q\)。但它的階同時也是 \(r\)，而一個單位根只有一個階，所以 \(r = q\)。於是 \(\mathrm{C}_q = \mathrm{C}_q\,\mathrm{C}_s\)，又因為 \(\mathrm{C}_q\) 不是零多項式，所以 \(\mathrm{C}_s = 1\)。這是不可能的，因為 \(\mathrm{C}_s\) 至少有一個根 \(e^{2\pi\mathrm{i}/s}\)。所以這樣的 \(q\)、\(r\)、\(s\) 並不存在。■

回顧

  • 按階分類。每個單位根都有唯一的階，按階分組便把 \(z^n - 1\) 的根分成互不相交的類。

  • 用根來定義多項式。每個 \(\mathrm{C}_n\) 都是藉着確切指明哪些數是它的根而確定下來的。

  • 唯一性帶來不可能性。第 (iv) 部分只需要一個想法：一個根不可能有兩個不同的階。

背後的數學

分解 \(x^n - 1\)

每個 \(n\) 次單位根都有某個整除 \(n\) 的階 \(d\)；而當 \(d \mid n\) 時，每個階為 \(d\) 的 \(d\) 次單位根都是 \(n\) 次單位根。所以 \(x^n - 1\) 的根按階分成若干類，由此得到 \[x^n - 1 = \prod_{d \mid n}\mathrm{C}_d(x).\] 例如 \(x^6 - 1 = \mathrm{C}_1\mathrm{C}_2\mathrm{C}_3\mathrm{C}_6 = (x - 1)(x + 1)(x^2 + x + 1)(x^2 - x + 1)\)。圖 6.1.1 展示了按這種方式分類的十二個 \(12\) 次單位根。本原 \(n\) 次單位根的個數，亦即 \(\mathrm{C}_n\) 的次數，等於 \(1\) 至 \(n\) 之間與 \(n\) 沒有公因數的 \(k\) 的個數，也就是歐拉函數（Euler’s totient function）\(\varphi(n)\)。比較兩邊的次數，便得到恆等式 \(\sum_{d \mid n}\varphi(d) = n\)。

整數係數，以及一個意外

單看定義並不明顯，但每個分圓多項式的係數都是整數。（利用 \(x^n - 1\) 的因式分解和歸納法（induction）：\(\mathrm{C}_n\) 等於 \(x^n - 1\) 除以若干個較早的分圓多項式之積，而以首一（monic）整係數多項式對整係數多項式作長除法，所得係數仍是整數。）在很長一段時間裏，所有已知例子的係數都只有 \(0\)、\(1\) 和 \(-1\)。第一個例外是 \(\mathrm{C}_{105}\)，它含有 \(-2x^7\) 這一項，由 Migotti 於 1883 年發現；\(105 = 3 \times 5 \times 7\) 是具有三個相異奇質因數的最小的數。事實上，分圓多項式的係數可以要多大有多大。

不可約性

第 (iv) 部分證明了沒有分圓多項式是另外兩個分圓多項式之積。其實更強的結論也成立：\(\mathrm{C}_n\) 根本不能分解成次數較低的有理係數多項式之積。高斯對 \(n\) 為質數的情況證明了這一點（它可由艾森斯坦判別法（Eisenstein’s criterion）推出，你會在大學的第一門代數課中遇到），而克羅內克（Kronecker）和戴德金（Dedekind）則證明了一般 \(n\) 的情況。正是這種不可約性（irreducibility），使分圓多項式成為與單位根有關的多項式之中的「質數」，它也是單位根的伽羅瓦理論（Galois theory）的起點。

思維技巧

先分類，後構造

用一個定義明確的不變量（invariant），把問題中的對象分成若干類，然後逐類建立結構。

這裏的不變量是單位根的階。由於每個根恰好有一個階，各類互不重疊，於是 \(x^n - 1\) 可分解成遍及各類的乘積。同樣的模式（由唯一的不變量得出不相交的分解）也是質因數分解和有限阿貝爾羣（finite abelian groups）分類的基礎。

延伸練習

  1. 檢查因式分解。驗證 \((x - 1)(x + 1)(x^2 + x + 1)(x^2 - x + 1) = x^6 - 1\)，並驗證 \(x^{12} - 1\) 的因式分解如圖 6.1.1 所示。

  2. 質數的兩倍。證明若 \(p\) 是奇質數，則 \(\mathrm{C}_{2p}(x) = \mathrm{C}_p(-x)\)。就 \(p = 3\) 驗證這個結果。

  3. 歐拉函數。證明對於質數 \(p\)，有 \(\varphi(p^k) = p^k - p^{k-1}\)，並且 \(\mathrm{C}_{p^k}(x) = \mathrm{C}_p\bigl(x^{p^{k-1}}\bigr)\)。利用這個結果求 \(\mathrm{C}_9\)。

  4. 較長的一題。 較難 利用 \(x^{15} - 1 = \mathrm{C}_1\mathrm{C}_3\mathrm{C}_5\mathrm{C}_{15}\)，證明 \(\mathrm{C}_{15}(x) = x^8 - x^7 + x^5 - x^4 + x^3 - x + 1\)。
