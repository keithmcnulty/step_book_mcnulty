6.4

解四次方程

題目

STEP III 2017，第 3 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/17-s3-q3

引子

每個學生都學過二次方程（quadratic equation）的求根公式。三次方程（cubic）和四次方程（quartic）其實也有公式；這些公式在十六世紀的意大利被發現，其間充滿祕密比試，以及為爭奪發現權而起的激烈爭執。卡爾達諾（Gerolamo Cardano）在 1545 年出版的《大術》（Ars Magna）中把兩者一併發表：三次方程的解法來自塔爾塔利亞（Niccolò Tartaglia），而塔爾塔利亞曾要他發誓保密；四次方程的解法則來自他自己的學生費拉里（Lodovico Ferrari）。此後近三百年，數學家一直苦苦尋找五次方程（quintic）的公式，卻始終徒勞無功。

這道題目展示的，正是解開四次方程的那個竅門，而這個竅門背後大有深意。從四個根出發，按三種可能的方式把根兩兩配對，得出三個新的量。這三個量滿足一個三次方程，而三次方程是你解得到的；有了它們，原來的四個根便隨之而來。為甚麼這個方法行得通？為甚麼四個根可以化約為三個量，五個根卻不能如法炮製？正是這個問題，引領伽羅瓦（Galois）創立了羣論（group theory）。

動筆之前

把四件物件 \(\alpha, \beta, \gamma, \delta\) 分成兩對，共有多少種分法？

三種：\(\{\alpha\beta, \gamma\delta\}\)、\(\{\alpha\gamma, \beta\delta\}\) 和 \(\{\alpha\delta, \beta\gamma\}\)（圖 6.4.1）。題目中的三個量 \(\alpha\beta + \gamma\delta\) 等等，正好對應這三種配對。把四個根任意重新排列，只會令這三種配對彼此對調，所以這三個量的任何對稱式（symmetric expression），都是四個根的對稱式，因而可以用 \(p\)、\(q\)、\(r\)、\(s\) 表示。這就是為甚麼它們滿足一個係數只涉及 \(p\)、\(q\)、\(r\)、\(s\) 的三次方程。

逐步解題

階段 1 欠缺的係數

在三次方程 \(y^3 + Ay^2 + By + C = 0\) 中，根之和用 \(A\) 表示是甚麼？而 \((\alpha\beta + \gamma\delta) + (\alpha\gamma + \beta\delta) + (\alpha\delta + \beta\gamma)\) 用四次方程的係數表示又是甚麼？

三次方程的根之和是 \(-A\)。那三個量之和，就是 \(\alpha, \beta, \gamma, \delta\) 中兩兩相乘所得全部六個積之和；對四次多項式 \(x^4 + px^3 + qx^2 + rx + s\) 而言，這個和是 \(q\)。所以 \(A = -q\)。

階段 2 具體的三次方程

代入 \(p = 0\)、\(q = 3\)、\(r = -6\)、\(s = 10\)，三次方程是 \[y^3 - 3y^2 + (0 - 40)y + (120 - 0 - 36) = y^3 - 3y^2 - 40y + 84 = 0.\]

試試 \(84\) 的細小因數。

\(y = 2\) 給出 \(8 - 12 - 80 + 84 = 0\)。作除法，得 \(y^3 - 3y^2 - 40y + 84 = (y - 2)(y^2 - y - 42) = (y - 2)(y - 7)(y + 6)\)。最大的根是 \(7\)，所以 \(\alpha\beta + \gamma\delta = 7\)。■

階段 3 根的配對

\((\alpha + \beta)(\gamma + \delta) = \alpha\gamma + \alpha\delta + \beta\gamma + \beta\delta\)，這是全部六個兩兩之積的和減去 \(\alpha\beta + \gamma\delta\)，即 \(q - 7 = 3 - 7 = -4\)。

此外 \(\alpha\beta \cdot \gamma\delta = \alpha\beta\gamma\delta = s = 10\)。所以 \(\alpha\beta\) 和 \(\gamma\delta\) 之和為 \(7\)，積為 \(10\)：它們是 \(t^2 - 7t + 10 = (t - 2)(t - 5)\) 的根。由於 \(\alpha\beta > \gamma\delta\)，得 \(\alpha\beta = 5\) 及 \(\gamma\delta = 2\)。■

階段 4 解四次方程

求 \(\alpha + \beta\) 和 \(\gamma + \delta\)。你已知道它們的和（由 \(p\) 得出）和它們的積（由第 3 步得出）；要判斷哪個是哪個，就用 \(r\)。

\(\alpha + \beta + \gamma + \delta = -p = 0\) 而 \((\alpha + \beta)(\gamma + \delta) = -4\)，所以 \(\{\alpha + \beta, \gamma + \delta\} = \{2, -2\}\)。係數 \(r\) 給出四個三根之積的和：\(\alpha\beta\gamma + \alpha\beta\delta + \alpha\gamma\delta + \beta\gamma\delta = -r = 6\)。這可以寫成 \(\alpha\beta(\gamma + \delta) + \gamma\delta(\alpha + \beta) = 5(\gamma + \delta) + 2(\alpha + \beta)\)。若 \(\alpha + \beta = 2\)，此式等於 \(-10 + 4 = -6\)；若 \(\alpha + \beta = -2\)，則等於 \(10 - 4 = 6\)。所以 \(\alpha + \beta = -2\) 及 \(\gamma + \delta = 2\)。

於是 \(\alpha\)、\(\beta\) 是 \(t^2 + 2t + 5 = 0\) 的根，即 \(-1 \pm 2\mathrm{i}\)；而 \(\gamma\)、\(\delta\) 是 \(t^2 - 2t + 2 = 0\) 的根，即 \(1 \pm \mathrm{i}\)。四個根是 \[x = -1 \pm 2\mathrm{i}, \qquad x = 1 \pm \mathrm{i}. \qed\] 驗算：\((x^2 + 2x + 5)(x^2 - 2x + 2) = x^4 + 3x^2 - 6x + 10\)。

回顧

  • 對稱函數（symmetric functions）。每一步都用上了根與係數的關係：根之和與根之積。

  • 降低次數。一個四次方程的問題變成了一個三次方程（即預解三次方程（resolvent cubic）），然後再變成兩個二次方程。

  • 用盡每一項資料。\(p\) 和 \(q\) 給出了各個和與積；\(s\) 把 \(\alpha\beta\) 和 \(\gamma\delta\) 分開；\(r\) 則決定了哪一對根配哪一個和。

背後的數學

這個竅門為何行得通：根的置換

1770 年，拉格朗日（Joseph-Louis Lagrange）追問三次和四次方程的解法為何行得通，並在根的置換（permutation）中找到了答案。四個根共有 \(24\) 種重新排列的方式。在所有這些排列之下，三個量 \(y_1 = \alpha\beta + \gamma\delta\)、\(y_2 = \alpha\gamma + \beta\delta\)、\(y_3 = \alpha\delta + \beta\gamma\) 只不過是彼此對調：四個根的每一種重新排列，都引致三種配對的一種重新排列（圖 6.4.1）。所以它們滿足一個 \(3\) 次多項式，其係數是各根的對稱式。用現代的語言來說，從對稱羣（symmetric group）\(S_4\)（全部 \(24\) 個置換）到 \(S_3\)（三種配對的 \(6\) 個置換）有一個滿射的羣同態（group homomorphism），這就是四次方程可以化約為三次方程的原因。

五次方程

對於五個根，拉格朗日嘗試尋找一個類似的量，使它在根的置換之下只取寥寥幾個值，卻找不到有用的。1799 年魯菲尼（Paolo Ruffini）提出證明，1824 年阿貝爾（Niels Henrik Abel）把證明補全，兩人證明了：只用四則運算和根式（radicals），並不存在五次方程的一般求根公式。數年之後，伽羅瓦（Évariste Galois）確切地說明了哪些多項式可以用根式求解：就是那些根的對稱羣能以某種特定方式分解成較簡單部分的多項式。對稱羣 \(S_4\) 可以這樣分解（經由 \(S_3\) 和更小的羣），但 \(S_5\) 不可以，因為它包含一個大小為 \(60\) 的「單」（simple）部分，無法再進一步分解。1832 年，伽羅瓦在決鬥中喪生，年僅二十歲；決鬥前一晚，他才匆匆把自己的理論寫下來。這套理論如今是數學學位課程中的瑰寶之一，通常在三年級學到。

解三次方程

三次方程本身也可以用類似的竅門求解：把一個缺二次項的三次式（depressed cubic）\(x^3 - 3px + q\) 寫成兩個完全立方的組合，從而化約為一個二次方程。這就是練習中那道 2011 年題目所用的方法，它與卡爾達諾公式（Cardano’s formula）等價。當三次方程有三個實根時，這條公式在運算途中仍然需要用到複數（complex numbers），正是這個現象迫使數學家認真看待複數（見第 5 章的引言）。

思維技巧

對稱性化繁為簡

如果由根構造出來的一些量，在根被置換時只是彼此置換，那麼它們滿足一個次數較低的多項式，而其係數是你可以計算出來的。

這是伽羅瓦理論（Galois theory）的種子：透過理解方程各根的對稱性來理解方程本身。

延伸練習

  1. 驗證三次方程。驗證 \(y_1y_2 + y_2y_3 + y_3y_1 = pr - 4s\)，其中 \(y_1 = \alpha\beta + \gamma\delta\)，餘類推。（展開並利用 \(\sum\alpha = -p\)、\(\sum\alpha\beta\gamma = -r\)、\(\alpha\beta\gamma\delta = s\)。）

  2. 把三次式寫成立方之和。試做 STEP III 2011，第 3 題。這道題把三次式寫成兩個立方的組合來求解，與本節的路線截然不同。請用數值方法核對它的答案。

  3. 另一個四次方程。用本節的方法解 \(x^4 - 4x^3 + 7x^2 - 6x + 2 = 0\)。（預解三次方程有一個根是細小的整數。）

  4. 數算置換。在 \(\alpha, \beta, \gamma, \delta\) 的 \(24\) 個置換中，找出所有把配對 \(\{\alpha\beta, \gamma\delta\}\) 變回自身的置換。證明這樣的置換共有 \(8\) 個。（它們構成 \(S_4\) 的一個子羣（subgroup）。）

延伸閱讀

  • Mario Livio, The Equation That Couldn’t Be Solved（Simon & Schuster）。五次方程的故事與羣論的誕生，適合一般讀者。

  • Ian Stewart, Why Beauty Is Truth: A History of Symmetry（Basic Books）。從巴比倫人的方程講到伽羅瓦，再到其後的發展。

  • Ian Stewart, Galois Theory（CRC Press）。大學本科教科書，其歷史導論所涵蓋的正是本節的內容。
