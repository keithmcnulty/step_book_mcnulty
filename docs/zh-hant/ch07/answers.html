第 7 章 · 線性代數與幾何

延伸練習答案

以下只是簡短的答案和提示，並非完整解答：這裏給出結果和關鍵步驟，讓你核對自己的做法。請先認真做過每道練習，然後才看答案。

7.1 對矩陣不成立的法則

  1. 設 \(\mathbf{X} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\)，比較 \(\mathbf{XP}\) 與 \(\mathbf{PX}\)，必有 \(c = 0\) 及 \(a = d\)：所求的矩陣（matrix）為 \(\begin{pmatrix} a & b \\ 0 & a \end{pmatrix}\)。

  2. 由凱萊－哈密頓定理（Cayley–Hamilton theorem）得 \(\mathbf{N}^2 = t\mathbf{N} - d\mathbf{I}\)，所以 \(t\mathbf{N} = d\mathbf{I}\)。若 \(t \neq 0\)，則 \(\mathbf{N}\) 是 \(\mathbf{I}\) 的倍數，而 \(\mathbf{N}^2 = \mathbf{0}\) 迫使 \(\mathbf{N} = \mathbf{0}\)，與 \(t \neq 0\) 矛盾。所以 \(t = 0\)，從而 \(d = 0\)。答案是：\(\begin{pmatrix} a & b \\ c & -a \end{pmatrix}\)，其中 \(a^2 + bc = 0\)。

  3. 平方後的對角線元素為 \(\cos^2\theta + \sin^2\theta = 1\)，非對角線元素為 \(0\)。保持不變的向量（vector）是 \((\cos\frac\theta2, \sin\frac\theta2)\)，所以它是對通過原點、傾角為 \(\frac\theta2\) 的直線的反射（reflection）。

  4. 設 \(\mathbf{M} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\)，則 \(\mathbf{M}^2 = \begin{pmatrix} a^2 + bc & b(a + d) \\ c(a + d) & d^2 + bc \end{pmatrix}\)；減去 \((a + d)\mathbf{M}\) 再加上 \((ad - bc)\mathbf{I}\)，便得 \(\mathbf{0}\)。

7.2 只伸縮，不轉向

  1. \(\mathbf{Mu} = \lambda\mathbf{u}\) 且 \(\mathbf{u} \neq \mathbf{0}\)，必須有 \(\det(\mathbf{M} - \lambda\mathbf{I}) = 0\)，這就是該二次方程。這裏跡（trace）為 \(6\)，行列式（determinant）為 \(\frac{4}{25}(54 - 4) = 8\)，所以 \(\lambda^2 - 6\lambda + 8 = 0\)：\(\lambda = 2\)（對應 \((1, 2)\)）和 \(4\)（對應 \((2, -1)\)）。

  2. \(\mathbf{v} \cdot \mathbf{Mu} = \lambda\,\mathbf{v} \cdot \mathbf{u}\)，又因為 \(\mathbf{M}\) 是對稱矩陣（symmetric matrix），\(\mathbf{v} \cdot \mathbf{Mu} = \mathbf{Mv} \cdot \mathbf{u} = \mu\,\mathbf{v} \cdot \mathbf{u}\)。所以 \((\lambda - \mu)\,\mathbf{u} \cdot \mathbf{v} = 0\)。

  3. 特徵方程（characteristic equation）\(\lambda^2 - 2\lambda\cos\theta + 1 = 0\) 的判別式（discriminant）為 \(-4\sin^2\theta\)，除非 \(\theta\) 是 \(\pi\) 的倍數，否則必為負數。特徵值（eigenvalue）是 \(\mathrm{e}^{\pm\mathrm{i}\theta}\)。

  4. \((1, 0) = \frac15(1, 2) + \frac25(2, -1)\)，所以 \(T^n(1, 0) = \frac{2^n}{5}(1, 2) + \frac{2 \cdot 4^n}{5}(2, -1) = \frac15\bigl(2^n + 4^{n+1},\ 2^{n+1} - 2 \cdot 4^n\bigr)\)。當 \(n = 1\) 時，結果是 \((\frac{18}{5}, -\frac45)\)，正如所料。

7.3 甚麼才算行列式

  1. \((\det\mathbf{MN})^3 = (\det\mathbf{M})^3(\det\mathbf{N})^3\)，而 \((\det\mathbf{J})^3 = -1 \neq 1\)。函數 \(|\det\mathbf{M}|\) 具有可乘性（multiplicative），但 \(|\det\mathbf{J}| = 1\)。

  2. \(\begin{pmatrix} a & \lambda a \\ c & \lambda c \end{pmatrix} = \begin{pmatrix} a & 0 \\ c & 0 \end{pmatrix}\begin{pmatrix} 1 & \lambda \\ 0 & 0 \end{pmatrix}\)，而第二個因子的第二行是第一行的 \(0\) 倍，所以它的 \(\mathrm{f}\) 值為 \(0\)。

  3. \(\begin{pmatrix} k & 0 \\ 0 & 1 \end{pmatrix} = \mathbf{JK}_k\mathbf{J}\)，所以它的值是 \(\mathrm{f}(\mathbf{J})^2\mathrm{f}(\mathbf{K}_k) = \mathrm{f}(\mathbf{K}_k)\)。另外 \(\mathbf{K}_k\mathbf{K}_l = \mathbf{K}_{kl}\)。

  4. 行簡化（row reduction）可把任何可逆矩陣（invertible matrix）寫成初等矩陣（elementary matrix）的乘積：行對換（\(\mathbf{J}\)）、行倍乘（\(\mathbf{K}_k\) 或 \(\mathbf{JK}_k\mathbf{J}\)），以及錯切（shear）（\(\begin{pmatrix} 1 & t \\ 0 & 1 \end{pmatrix}\) 或它經 \(\mathbf{J}\) 共軛（conjugate）後所得的矩陣）。錯切的 \(\mathrm{f} = 1\)（做法如第 (iv) 部分，利用 \(\mathbf{K}^{-1}\mathbf{PK}\)）。此外，\(\mathbf{J}\) 是若干錯切與 \(\mathbf{K}_{-1}\) 的乘積，所以 \(\mathrm{f}(\mathbf{K}_{-1}) = \mathrm{f}(\mathbf{J}) = -1\)。因此 \(\mathrm{f}(\mathbf{M}) = \mathrm{g}(\det\mathbf{M})\)，其中 \(\mathrm{g}(k) = \mathrm{f}(\mathbf{K}_k)\)；若 \(\mathbf{M}\) 是奇異矩陣（singular matrix），則由第 (iii) 部分得 \(\mathrm{f}(\mathbf{M}) = 0\)。

7.4 回到起點的矩陣

  1. 由 \(|1 + \mathrm{e}^{\mathrm{i}\phi}|^2 = 2 + 2\cos\phi = 1\) 得 \(\phi = \pm\frac{2\pi}{3}\)，所以 \(\mathbf{R}^3 = \mathbf{I}\)。至於 \(\mathbf{S}\)：它的特徵值是 \(1\) 的立方根。假如兩個特徵值都是 \(1\)，則由於 \(x^3 - 1\) 的根各不相同，\(\mathbf{S}\) 可對角化（diagonalisable），因而等於 \(\mathbf{I}\)。實矩陣的非實數特徵值必以共軛對的形式出現，所以特徵值是 \(\mathrm{e}^{\pm2\pi\mathrm{i}/3}\)：\(\det\mathbf{S} = 1\) 及 \(\operatorname{tr}\mathbf{S} = -1\)。

  2. 特徵值必定是六次本原單位根（primitive sixth roots of unity）\(\mathrm{e}^{\pm\mathrm{i}\pi/3}\)（若選取其他六次單位根並與其共軛配對，都會得出 \(\mathbf{M}^2 = \mathbf{I}\) 或 \(\mathbf{M}^3 = \mathbf{I}\)）。所以 \(\operatorname{tr}\mathbf{M} = 1\) 及 \(\det\mathbf{M} = 1\)。

  3. 特徵值是乘積為 \(1\) 的單位根，所以它們是 \(\mathrm{e}^{\pm\mathrm{i}\theta}\)（或同為 \(\pm1\)），而跡 \(2\cos\theta\) 是 \([-2, 2]\) 內的整數。階（order）為 \(6\) 的例子：\(\begin{pmatrix} 1 & -1 \\ 1 & 0 \end{pmatrix}\)。

  4. \(\mathbf{M}^3 = (t^2 - d)\mathbf{M} - td\mathbf{I}\) 及 \(\mathbf{M}^4 = (t^3 - 2td)\mathbf{M} - d(t^2 - d)\mathbf{I}\)。要使 \(\mathbf{M}^4 = -\mathbf{I}\)（\(\mathbf{M}\) 不可能是 \(\mathbf{I}\) 的倍數），須有 \(t(t^2 - 2d) = 0\) 及 \(d(t^2 - d) = 1\)。\(t = 0\) 給出 \(-d^2 = 1\)，不可能成立；所以 \(t^2 = 2d\)，\(d^2 = 1\)，於是 \(d = 1\)，\(t^2 = 2\)。

7.5 三維空間中的旋轉

  1. \(z \mapsto a + \mathrm{e}^{\mathrm{i}\theta}(z - a)\)。複合變換是 \(z \mapsto \mathrm{e}^{\mathrm{i}(\theta + \phi)}z + k\)，其中 \(k = \mathrm{e}^{\mathrm{i}\phi}a(1 - \mathrm{e}^{\mathrm{i}\theta}) + b(1 - \mathrm{e}^{\mathrm{i}\phi})\)；若 \(\mathrm{e}^{\mathrm{i}(\theta+\phi)} \neq 1\)，它有不動點（fixed point）\(c = \frac{k}{1 - \mathrm{e}^{\mathrm{i}(\theta+\phi)}}\)。若 \(\theta + \phi = 2\pi\)，它就是位移為 \((b - a)(1 - \mathrm{e}^{-\mathrm{i}\theta})\) 的平移（translation）。

  2. \(\begin{pmatrix} 0 & 0 & 1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}\)：它保持 \((1, 1, 1)\) 不變，跡為 \(0 = 1 + 2\cos120^\circ\)，並把 \(\mathbf{i} \to \mathbf{j} \to \mathbf{k} \to \mathbf{i}\)。

  3. \(\mathbf{K}^2\mathbf{r} = \mathbf{n} \times (\mathbf{n} \times \mathbf{r}) = (\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\)，於是 \(\mathbf{K}^3\mathbf{r} = \mathbf{n} \times \bigl((\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\bigr) = -\mathbf{Kr}\)。在級數（series）中，奇數次冪給出 \((\theta - \frac{\theta^3}{3!} + \cdots)\mathbf{K} = \sin\theta\,\mathbf{K}\)，偶數次冪（由 \(\mathbf{K}^2\) 起）給出 \((\frac{\theta^2}{2!} - \frac{\theta^4}{4!} + \cdots)\mathbf{K}^2 = (1 - \cos\theta)\mathbf{K}^2\)。

  4. 複合變換保持交線上的每一點不變，而且行列式為 \((-1)^2 = 1\)。在每個垂直於該交線的平面上，它是對兩條夾角為 \(\alpha\) 的直線先後作反射的乘積，即轉角為 \(2\alpha\) 的旋轉（rotation）。

7.6 雙曲旋轉與相對論

  1. \(T(u)T(w)\) 的元素是 \(\cosh u\cosh w + \sinh u\sinh w = \cosh(u + w)\) 和 \(\sinh u\cosh w + \cosh u\sinh w = \sinh(u + w)\)。所以 \(T(u)^{-1} = T(-u)\)。

  2. 由 \(\tanh u = 0.8\) 得 \(u = \frac12\ln\frac{1.8}{0.2} = \ln3 \approx 1.099\) 及 \(\cosh u = \frac12(3 + \frac13) = \frac53\)。在飛船上，過去的時間是 \(10 \times \frac35 = 6\) 年。

  3. 面積是 \(\frac12\oint(x\,\mathrm{d}y - y\,\mathrm{d}x)\)。兩條直邊沒有貢獻；沿着雙曲線（hyperbola），取 \(x = \cosh s\)，\(y = \sinh s\)，被積函數（integrand）是 \((\cosh^2s - \sinh^2s)\,\mathrm{d}s = \mathrm{d}s\)，得出 \(\frac v2\)。\(T\) 的行列式為 \(\cosh^2u - \sinh^2u = 1\)，所以它保持面積不變；它把雙曲線映射到自身，並把參數為 \(v\) 的點移到參數為 \(v + u\) 的點。

  4. \(x' + y' = (\cosh u + \sinh u)(x + y) = \mathrm{e}^up\) 及 \(x' - y' = \mathrm{e}^{-u}q\)；另外 \(x^2 - y^2 = pq\)。在這組坐標下，\(T\) 是一個擠壓映射（squeeze）：沿漸近線（asymptote）\(y = x\) 拉伸 \(\mathrm{e}^u\) 倍，沿 \(y = -x\) 壓縮至 \(\mathrm{e}^{-u}\) 倍，使各點沿着每條雙曲線 \(pq =\) 常數滑動。

7.7 永恆不變的量

  1. \(\dot a = -Ct = -tc\)，\(\dot d = Ct = tc\)，\(\dot c = 0\)，以及 \(\dot b = (A - D)t - Ct^3 = t(a - d)\)，與 \(\mathbf{MN} - \mathbf{NM} = t\begin{pmatrix} -c & a - d \\ 0 & c \end{pmatrix}\) 吻合。

  2. \(\dot{\mathbf{M}} = -\mathbf{S}^{-1}\dot{\mathbf{S}}\mathbf{S}^{-1}\mathbf{M}_0\mathbf{S} + \mathbf{S}^{-1}\mathbf{M}_0\dot{\mathbf{S}} = -\mathbf{NM} + \mathbf{MN}\)，當中用到 \(\dot{\mathbf{S}} = \mathbf{SN}\)。

  3. \(\mathbf{N} = \mathbf{M}^{-1}\dot{\mathbf{M}} = \begin{pmatrix} 2 & 0 \\ 0 & -1 \end{pmatrix}\)，而 \(\ln\det\mathbf{M} = 2t - t = t\)，其導數（derivative）為 \(1 = \operatorname{tr}\mathbf{N}\)。

  4. 利用跡的循環性質（cyclic property），\(\frac{\mathrm{d}}{\mathrm{d}t}\operatorname{tr}(\mathbf{M}^k) = \sum_j\operatorname{tr}(\mathbf{M}^j\dot{\mathbf{M}}\mathbf{M}^{k-1-j}) = k\operatorname{tr}(\mathbf{M}^{k-1}\dot{\mathbf{M}})\)；再用一次循環性質，\(\operatorname{tr}(\mathbf{M}^{k-1}(\mathbf{MN} - \mathbf{NM})) = \operatorname{tr}(\mathbf{M}^k\mathbf{N}) - \operatorname{tr}(\mathbf{M}^{k-1}\mathbf{NM}) = 0\)。

7.8 四個平方數

  1. \((L_1, L_2, L_3, L_4) = (1, 4, 4, 4)\)，而 \(1 + 16 + 16 + 16 = 49\)。這個表示法與 \(7^2 + 0^2 + 0^2 + 0^2\) 不同。

  2. 取 \(c = d = r = s = 0\)：\(L_1 = ap - bq\)，\(L_2 = aq + bp\)，\(L_3 = L_4 = 0\)，即 \((a^2 + b^2)(p^2 + q^2) = (ap - bq)^2 + (aq + bp)^2\)。

  3. 平方數模（modulo）\(8\) 只可能是 \(0\)、\(1\) 或 \(4\)。三個這樣的數之和模 \(8\) 可得 \(0, 1, 2, 3, 4, 5, 6\)，但永遠不會是 \(7\)。

  4. \(2 = (\pm1)^2 + (\pm1)^2 + 0^2 + 0^2\)：選出兩個非零的位置（\(6\) 種方法）及它們的正負號（\(4\) 種方法），共 \(24\) 種。由於 \(2\) 不能被 \(4\) 整除，雅可比（Jacobi）公式給出 \(8\sigma(2) = 8 \times 3 = 24\)。

7.9 只有五種柏拉圖立體

  1. 設 \(h = 2m + 2n - mn\)，則 \(V = \frac{4m}{h}\)，\(E = \frac{2mn}{h}\) 及 \(F = \frac{4n}{h}\)；把 \(m\) 和 \(n\) 對調，\(V\) 和 \(F\) 也隨之對調。正方體與正八面體（octahedron）互為對偶（dual），正十二面體（dodecahedron）與正二十面體（icosahedron）亦然；正四面體（tetrahedron）則是自對偶（self-dual）的。

  2. \(F = 32\)，\(E = \frac12(12 \cdot 5 + 20 \cdot 6) = 90\) 及 \(V = \frac13(180) = 60\)，而 \(60 - 90 + 32 = 2\)。一般而言，若有 \(P\) 個五邊形和 \(H\) 個六邊形，則 \(E = \frac12(5P + 6H)\) 及 \(V = \frac13(5P + 6H)\)，所以 \(V - E + F = -\frac16(5P + 6H) + P + H = \frac P6\)。這個值等於 \(2\)，所以 \(P = 12\)。

  3. 把頂面和底面（兩者都有洞）各分成四個梯形（trapezium）。於是 \(V = 16\)，\(F = 4 + 4 + 4 + 4 = 16\) 及 \(E = 12 + 12 + 8 = 32\)，所以 \(V - E + F = 0\)。

  4. \(180^\circ n(1 - \frac2m) < 360^\circ\) 即 \(n(m - 2) < 2m\)，也就是 \(mn - 2m - 2n < 0\)，或 \((m - 2)(n - 2) < 4\)。當 \(m, n \geq 3\) 時，解為 \((3, 3)\)、\((3, 4)\)、\((4, 3)\)、\((3, 5)\) 和 \((5, 3)\)。
