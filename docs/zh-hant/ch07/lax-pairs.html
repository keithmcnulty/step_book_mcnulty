永恆不變的量

引子

物理學中一些最深刻的事實是守恆定律（conservation laws）：無論運動多麼複雜，能量、動量和角動量始終保持不變。當一個系統有足夠多的守恆量時，它的運動可以精確地解出；守恆量太少時，運動則可能是混沌的。

這道題展示了一種製造守恆量的絕妙方法。若一個矩陣按照 \(\frac{\mathrm{d}\mathbf{M}}{\mathrm{d}t} = \mathbf{MN} - \mathbf{NM}\) 隨時間變化，那麼無論它的元素變化得多麼劇烈，它的跡（trace）和行列式（determinant），以至它的特徵值（eigenvalues），都永遠不變。這樣的一對 \((\mathbf{M}, \mathbf{N})\) 稱為拉克斯對（Lax pair），以彼得．拉克斯（Peter Lax）命名。他在 1968 年提出這個想法，用來解釋孤立子（solitons）的驚人表現：孤立子是一種孤立波，彼此穿過之後絲毫不變。

動筆之前

表達式 \(\mathbf{MN} - \mathbf{NM}\) 稱為 \(\mathbf{M}\) 與 \(\mathbf{N}\) 的交換子（commutator）。它在甚麼時候等於零？根據第 (i) 部分，它的跡是多少？

它等於零，當且僅當 \(\mathbf{M}\) 與 \(\mathbf{N}\) 可交換。而根據第 (i) 部分，它的跡是 \(\operatorname{tr}(\mathbf{MN}) - \operatorname{tr}(\mathbf{NM}) = 0\)，恆常如此。這一個事實，就是題目中每一條守恆定律的起點。

逐步解題

階段 1 跡

設 \(\mathbf{M} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\) 及 \(\mathbf{N} = \begin{pmatrix} p & q \\ r & s \end{pmatrix}\)，則 \(\mathbf{MN}\) 的對角線元素是 \(ap + br\) 和 \(cq + ds\)，所以 \(\operatorname{tr}(\mathbf{MN}) = ap + br + cq + ds\)。把 \(\mathbf{M}\) 與 \(\mathbf{N}\) 的角色對調，得 \(pa + qc + rb + sd\)，結果相同。顯然 \(\operatorname{tr}(\mathbf{M} + \mathbf{N}) = \operatorname{tr}\mathbf{M} + \operatorname{tr}\mathbf{N}\)。■

階段 2 行列式的導數

用積法則求 \(\det\mathbf{M} = ad - bc\) 的導數。然後利用 \(\mathbf{M}^{-1} = \frac{1}{\det\mathbf{M}}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}\)，計算 \(\mathbf{M}^{-1}\frac{\mathrm{d}\mathbf{M}}{\mathrm{d}t}\) 及其跡。

以字母上的一點表示導數，則 \(\frac{\mathrm{d}}{\mathrm{d}t}\det\mathbf{M} = \dot ad + a\dot d - \dot bc - b\dot c\)。而 \[\mathbf{M}^{-1}\dot{\mathbf{M}} = \frac{1}{\det\mathbf{M}}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}\begin{pmatrix} \dot a & \dot b \\ \dot c & \dot d \end{pmatrix}\] 的對角線元素是 \(\frac{d\dot a - b\dot c}{\det\mathbf{M}}\) 和 \(\frac{-c\dot b + a\dot d}{\det\mathbf{M}}\)。兩者之和是 \(\frac{1}{\det\mathbf{M}}\frac{\mathrm{d}}{\mathrm{d}t}\det\mathbf{M}\)。■

階段 3 三個守恆量

對 \(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\) 取跡。至於行列式，則用第 (ii) 部分：\(\mathbf{M}^{-1}(\mathbf{MN} - \mathbf{NM})\) 是甚麼？

跡：\(\frac{\mathrm{d}}{\mathrm{d}t}\operatorname{tr}\mathbf{M} = \operatorname{tr}\dot{\mathbf{M}} = \operatorname{tr}(\mathbf{MN}) - \operatorname{tr}(\mathbf{NM}) = 0\)。

行列式：根據第 (ii) 部分， \[\frac{1}{\det\mathbf{M}}\frac{\mathrm{d}}{\mathrm{d}t}\det\mathbf{M} = \operatorname{tr}\bigl(\mathbf{M}^{-1}(\mathbf{MN} - \mathbf{NM})\bigr) = \operatorname{tr}\mathbf{N} - \operatorname{tr}(\mathbf{M}^{-1}\mathbf{NM}) = \operatorname{tr}\mathbf{N} - \operatorname{tr}\mathbf{N} = 0,\] 當中用到第 (i) 部分的以下形式：\(\operatorname{tr}\bigl(\mathbf{M}^{-1}(\mathbf{NM})\bigr) = \operatorname{tr}\bigl((\mathbf{NM})\mathbf{M}^{-1}\bigr) = \operatorname{tr}\mathbf{N}\)。

平方的跡：\(\operatorname{tr}(\mathbf{M}^2) = (\operatorname{tr}\mathbf{M})^2 - 2\det\mathbf{M}\)（見 第 7.4 節），由於兩項都是常數，所以它也是常數。■

階段 4 一個顯式解

設 \(\mathbf{N} = t\mathbf{I} + t\mathbf{E}\)，其中 \(\mathbf{E} = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}\)，計算 \(\mathbf{MN} - \mathbf{NM}\)，並寫出 \(a\)、\(b\)、\(c\)、\(d\) 所滿足的微分方程。按以下次序求解：先解 \(c\)，然後 \(a\) 和 \(d\)，最後 \(b\)。

\(t\mathbf{I}\) 這部分與任何矩陣都可交換，所以 \(\mathbf{MN} - \mathbf{NM} = t(\mathbf{ME} - \mathbf{EM})\)。現在 \(\mathbf{ME} = \begin{pmatrix} 0 & a \\ 0 & c \end{pmatrix}\) 而 \(\mathbf{EM} = \begin{pmatrix} c & d \\ 0 & 0 \end{pmatrix}\)，所以 \[\dot a = -tc, \qquad \dot b = t(a - d), \qquad \dot c = 0, \qquad \dot d = tc.\] 因此 \(c = C\) 是常數；於是 \(a = A - \frac12Ct^2\) 及 \(d = D + \frac12Ct^2\)；繼而 \(\dot b = t(A - D - Ct^2)\)，所以 \(b = B + \frac12(A - D)t^2 - \frac14Ct^4\)。故此 \[\mathbf{M} = \begin{pmatrix} A - \frac12Ct^2 & B + \frac12(A - D)t^2 - \frac14Ct^4 \\[0.5ex] C & D + \frac12Ct^2 \end{pmatrix}. \qed\] 驗算：跡是 \(A + D\)，而行列式是 \((A - \frac12Ct^2)(D + \frac12Ct^2) - C\bigl(B + \frac12(A - D)t^2 - \frac14Ct^4\bigr) = AD - BC\)，一如所料是常數（圖 7.7.1）。

階段 5 另一條方程

若 \(\dot{\mathbf{M}} = \mathbf{MN}\)，則 \(\mathbf{N} = \mathbf{M}^{-1}\dot{\mathbf{M}}\)，而根據第 (ii) 部分，\(\operatorname{tr}\mathbf{N}\) 就是 \(\det\mathbf{M}\) 的對數導數（logarithmic derivative）。\(\mathbf{M}\) 的跡能否保持不變，而它的行列式卻在改變？

當然可以。取 \(\mathbf{M} = \begin{pmatrix} 1 & t \\ t & 1 \end{pmatrix}\)，其中 \(|t| < 1\)（此時 \(\det\mathbf{M} = 1 - t^2 \neq 0\)）。它的跡恆等於 \(2\)。定義 \(\mathbf{N} = \mathbf{M}^{-1}\dot{\mathbf{M}}\)，使得 \(\dot{\mathbf{M}} = \mathbf{MN}\)： \[\mathbf{N} = \frac{1}{1 - t^2}\begin{pmatrix} 1 & -t \\ -t & 1 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} = \frac{1}{1 - t^2}\begin{pmatrix} -t & 1 \\ 1 & -t \end{pmatrix},\] 這是一個非奇異（non-singular）矩陣，而且當 \(t \neq 0\) 時，\(\operatorname{tr}\mathbf{N} = \frac{-2t}{1 - t^2} \neq 0\)。所以答案是否定的，\(\operatorname{tr}\mathbf{N}\) 不一定等於零。■

回顧

  • 交換子的跡等於零。由 \(\operatorname{tr}(\mathbf{MN}) = \operatorname{tr}(\mathbf{NM})\) 出發，每一條守恆定律都隨之而來。

  • 對數導數。第 (ii) 部分把行列式的導數化為一個跡，而跡是線性的，容易處理。

  • 在顯式解中檢查守恆。我們確認了 \(\mathbf{M}(t)\) 的跡和行列式都是常數，藉此驗算它的公式。

背後的數學

孤立子與拉克斯對

1834 年，蘇格蘭工程師 John Scott Russell 策馬追蹤一個沿愛丁堡附近的聯合運河（Union Canal）前進的孤立波，追了超過一英里，波形始終沒有改變。這類波由科特韋赫－德弗里斯（Korteweg–de Vries，簡稱 KdV）方程描述。到了 1960 年代，Norman Zabusky 與 Martin Kruskal 的電腦實驗顯示，兩個這樣的「孤立子」可以相撞，然後原封不動地離開，彷彿它們是粒子一樣。要解釋這個現象，需要無窮多個守恆量。彼得．拉克斯在 1968 年證明，KdV 方程可以寫成 \(\dot L = LP - PL\)，其中 \(L\) 和 \(P\) 是一對微分算子（differential operators）；於是，與這道題完全一樣，\(L\) 的特徵值是守恆的，而它們正好提供了那無窮多條守恆定律。擁有拉克斯對的系統稱為可積（integrable）系統，它們屬於少數可以精確求解的非線性系統。

等譜流

由於 \(\mathbf{M}\) 的跡和行列式決定了它的特徵多項式（characteristic polynomial）\(\lambda^2 - (\operatorname{tr}\mathbf{M})\lambda + \det\mathbf{M}\)，\(\mathbf{M}\) 的特徵值不隨時間改變。流 \(\dot{\mathbf{M}} = [\mathbf{M}, \mathbf{N}]\) 使 \(\mathbf{M}\) 在特徵值固定的矩陣所組成的集合之內移動。事實上，解總是具有 \(\mathbf{M}(t) = \mathbf{S}(t)^{-1}\mathbf{M}(0)\mathbf{S}(t)\) 的形式，其中 \(\mathbf{S}(t)\) 是某個可逆矩陣：這個矩陣始終與它的初始值相似（similar）。同一個想法貫穿整個物理學：在量子力學中，可觀測量（observable）\(\mathbf{A}\) 按 \(\frac{\mathrm{d}\mathbf{A}}{\mathrm{d}t} = \frac{\mathrm{i}}{\hbar}[\mathbf{H}, \mathbf{A}]\) 演化，其中 \(\mathbf{H}\) 是能量，所以凡是與能量可交換的量都是守恆的。

雅可比公式

第 (ii) 部分對任何大小的可逆矩陣都成立，稱為雅可比公式（Jacobi’s formula）。最穩妥的寫法是不用對數，寫成 \(\frac{\mathrm{d}}{\mathrm{d}t}\det\mathbf{M} = \det\mathbf{M}\,\operatorname{tr}\bigl(\mathbf{M}^{-1}\dot{\mathbf{M}}\bigr)\)，因為 \(\det\mathbf{M}\) 可能是負數；對數形式 \(\frac{\mathrm{d}}{\mathrm{d}t}\ln\det\mathbf{M} = \operatorname{tr}\bigl(\mathbf{M}^{-1}\dot{\mathbf{M}}\bigr)\) 需要 \(\det\mathbf{M} > 0\)（一般情況下則用 \(\ln|\det\mathbf{M}|\)）。由此可得一個推論：若 \(\dot{\mathbf{M}} = \mathbf{AM}\)，其中 \(\mathbf{A}\) 是常數矩陣，則 \(\det\mathbf{M}(t) = e^{t\operatorname{tr}\mathbf{A}}\det\mathbf{M}(0)\)。在微分方程的研究中，這個結果告訴你相空間（phase space）中的體積如何增長或縮小；對於經典力學的方程，這個跡等於零，體積保持不變，這個結果稱為劉維爾定理（Liouville’s theorem）。

思維技巧

找出不變的東西

當某樣東西在演化時，試找出由它構成而又保持不變的量。這些量限制了運動，並往往揭示出它的結構。

在這裏，跡和行列式之所以守恆，是因為變化率是一個交換子。在力學中，守恆量來自對稱性（諾特定理，Noether’s theorem），而找出守恆量往往是解題的第一步。

延伸練習

  1. 驗算解。透過求導，驗證第 4 階段的矩陣 \(\mathbf{M}(t)\) 滿足 \(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\)。

  2. 相似性。證明：若 \(\mathbf{M}(t) = \mathbf{S}^{-1}\mathbf{M}_0\mathbf{S}\)，其中 \(\mathbf{M}_0\) 是常數矩陣，而 \(\mathbf{S}(t)\) 滿足 \(\dot{\mathbf{S}} = \mathbf{SN}\)，則 \(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\)。（提示：\(\frac{\mathrm{d}}{\mathrm{d}t}\mathbf{S}^{-1} = -\mathbf{S}^{-1}\dot{\mathbf{S}}\mathbf{S}^{-1}\)。）

  3. 體積增長。設 \(\mathbf{M}(t) = \begin{pmatrix} e^{2t} & 0 \\ 0 & e^{-t} \end{pmatrix}\)。求滿足 \(\dot{\mathbf{M}} = \mathbf{MN}\) 的 \(\mathbf{N}\)，並驗證 \(\frac{\mathrm{d}}{\mathrm{d}t}\ln\det\mathbf{M} = \operatorname{tr}\mathbf{N}\)。

  4. 更高次冪。直接證明：當 \(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\) 時，對每個正整數 \(k\) 都有 \(\frac{\mathrm{d}}{\mathrm{d}t}\operatorname{tr}(\mathbf{M}^k) = 0\)。
