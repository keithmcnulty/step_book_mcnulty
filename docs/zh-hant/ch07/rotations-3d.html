7.5

三維空間中的旋轉

繼續之前，請先閱讀題目（原題為英文）。題目載於 OCR 提供下載的 2022 年 STEP 試卷（zip 檔案）內的 STEP III 試卷： www.ocr.org.uk/Images/696587-2022-past-papers.zip

引子

在二維空間中，旋轉（rotation）一個點很容易：乘以 \(e^{\mathrm{i}\theta}\) 便可。到了三維空間，事情就困難得多。沒有一個複數可以讓我們直接相乘，繞不同軸的旋轉不可交換（commute），而要寫出「繞通過 \((1, 2, 2)\) 的軸旋轉 \(37^\circ\)」的矩陣，看來更是令人卻步。

本題利用叉積（cross product），為任意的軸和任意的角構造出這個矩陣。所得的結果就是羅德里格旋轉公式（Rodrigues’ rotation formula），由羅德里格（Olinde Rodrigues）於 1840 年發表。機械人技術、電腦圖像和太空船導航每天都用到它，而它亦揭示了一個優美的事實：與 \(\mathbf{n}\) 作叉積，就是「繞 \(\mathbf{n}\) 旋轉 \(90^\circ\)」，而每一個繞 \(\mathbf{n}\) 的旋轉都由它構成，正如 \(e^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta\) 是由乘以 \(\mathrm{i}\) 構成一樣。

動筆之前

當 \(\mathbf{r}\) 垂直於 \(\mathbf{n}\) 時，\(\mathbf{n} \times \mathbf{r}\) 在幾何上是甚麼樣子？當 \(\mathbf{r}\) 平行於 \(\mathbf{n}\) 時又如何？

若 \(\mathbf{r} \parallel \mathbf{n}\)，則 \(\mathbf{n} \times \mathbf{r} = \mathbf{0}\)。若 \(\mathbf{r} \perp \mathbf{n}\)，則 \(\mathbf{n} \times \mathbf{r}\) 的長度與 \(\mathbf{r}\) 相同（因為 \(|\mathbf{n}| = 1\)，而夾角是 \(90^\circ\)），與兩者皆垂直，而且根據右手定則（right-hand rule），它就是 \(\mathbf{r}\) 繞 \(\mathbf{n}\) 逆時針旋轉 \(90^\circ\) 的結果（沿 \(\mathbf{n}\) 向下看）。因此 \(\mathrm{f}\) 消去 \(\mathbf{r}\) 沿 \(\mathbf{n}\) 方向的分量（component），並把垂直的分量旋轉 \(90^\circ\)。這幅圖像足以解釋整條題目。

逐步解題

階段 1 作兩次叉積

\(\mathrm{f}(\mathbf{r}) = \mathbf{n} \times \mathbf{r} = (bz - cy,\ cx - az,\ ay - bx)\)。再與 \(\mathbf{n} = (a, b, c)\) 作一次叉積，\(\mathrm{f}(\mathrm{f}(\mathbf{r}))\) 的 \(x\) 分量是 \[b(ay - bx) - c(cx - az) = -x(b^2 + c^2) + aby + acz. \qed\] 由於 \(a^2 + b^2 + c^2 = 1\)，上式等於 \(-x(1 - a^2) + aby + acz = a(ax + by + cz) - x\)，這正是 \((\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\) 的 \(x\) 分量。其餘分量可由對稱性得出，所以 \(\mathrm{f}(\mathrm{f}(\mathbf{r})) = (\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\)。■

設 \(\mathbf{r} = \mathbf{r}_\parallel + \mathbf{r}_\perp\)，其中 \(\mathbf{r}_\parallel = (\mathbf{n}.\mathbf{r})\mathbf{n}\) 是沿 \(\mathbf{n}\) 方向的分量。用這兩部分表示，\(\mathrm{f}(\mathrm{f}(\mathbf{r}))\) 是甚麼？

\(\mathrm{f}(\mathrm{f}(\mathbf{r})) = \mathbf{r}_\parallel - \mathbf{r} = -\mathbf{r}_\perp\)。施行 \(\mathrm{f}\) 兩次，會消去平行的部分，並把垂直的部分繞 \(\mathbf{n}\) 旋轉 \(180^\circ\)，亦即把它反向（圖 7.5.1）。這就是 \(\mathrm{i}^2 = -1\) 的類比。

階段 2 旋轉

計算 \(\mathrm{g}(\mathbf{n})\)。然後對於 \(\mathbf{r} \perp \mathbf{n}\) 的情況計算 \(\mathrm{g}(\mathbf{r})\)，並利用 \(\mathrm{f}(\mathrm{f}(\mathbf{r})) = -\mathbf{r}\) 對這樣的 \(\mathbf{r}\) 成立這一點。

\(\mathrm{f}(\mathbf{n}) = \mathbf{n} \times \mathbf{n} = \mathbf{0}\)，所以 \(\mathrm{g}(\mathbf{n}) = \mathbf{n}\)：軸保持不動。若 \(\mathbf{r} \perp \mathbf{n}\)，則 \(\mathrm{f}(\mathrm{f}(\mathbf{r})) = -\mathbf{r}\)，於是 \[\mathrm{g}(\mathbf{r}) = \mathbf{r} + \sin\theta\,(\mathbf{n} \times \mathbf{r}) - (1 - \cos\theta)\mathbf{r} = \cos\theta\,\mathbf{r} + \sin\theta\,(\mathbf{n} \times \mathbf{r}).\] 由於 \(\mathbf{n} \times \mathbf{r}\) 是 \(\mathbf{r}\) 繞 \(\mathbf{n}\) 轉過 \(90^\circ\) 的結果，長度不變，所以上式就是 \(\mathbf{r}\) 繞 \(\mathbf{n}\) 旋轉 \(\theta\) 的結果，與平面上的 \((\cos\theta + \mathrm{i}\sin\theta)z\) 如出一轍。由於 \(\mathrm{g}\) 是線性（linear）的，而每個向量都可寫成 \(\mathbf{n}\) 的倍數與一個垂直於 \(\mathbf{n}\) 的向量之和，所以 \(\mathrm{g}\) 就是繞通過原點、方向為 \(\mathbf{n}\) 的軸旋轉角 \(\theta\) 的旋轉（從 \(\mathbf{n}\) 的尖端望去為逆時針方向）。■

階段 3 反射

利用第 (i) 部分化簡 \(\mathrm{h}(\mathbf{s}) = -\mathbf{s} - 2\mathrm{f}(\mathrm{f}(\mathbf{s}))\)。它對沿 \(\mathbf{n}\) 方向的向量有甚麼作用？對垂直於 \(\mathbf{n}\) 的向量又有甚麼作用？

\(\mathrm{h}(\mathbf{s}) = -\mathbf{s} - 2\bigl((\mathbf{n}.\mathbf{s})\mathbf{n} - \mathbf{s}\bigr) = \mathbf{s} - 2(\mathbf{n}.\mathbf{s})\mathbf{n}\)。垂直於 \(\mathbf{n}\) 的向量保持不變，而 \(\mathrm{h}(\mathbf{n}) = -\mathbf{n}\)。所以 \(\mathrm{h}\) 是對通過原點且垂直於 \(\mathbf{n}\) 的平面的反射（reflection）。■

回顧

  • 分解為平行和垂直的部分。一旦把 \(\mathbf{r}\) 分解為沿 \(\mathbf{n}\) 方向和與之垂直的分量，每一步都變得清晰。

  • 線性減省工夫。要辨認一個線性映射（linear map），只需知道它對幾個精心挑選的向量有甚麼作用便足夠。

  • 複數的類比。在垂直於 \(\mathbf{n}\) 的向量上，\(\mathrm{f}\) 的表現就像乘以 \(\mathrm{i}\)：\(\mathrm{f}^2 = -1\)，而 \(\mathrm{g} = \cos\theta + \sin\theta\,\mathrm{f}\)。

背後的數學

歐拉旋轉定理

三維空間中每一個固定原點的旋轉，都是繞某條通過原點的軸的旋轉。歐拉（Euler）於 1775 年證明了這一點。用矩陣的語言來說，每個 \(3 \times 3\) 旋轉矩陣都有一個特徵值（eigenvalue）為 \(1\) 的特徵向量（eigenvector），也就是旋轉軸。羅德里格公式給出其逆命題：對每一條軸 \(\mathbf{n}\) 和每一個角 \(\theta\)，旋轉矩陣是 \[\mathbf{R} = \mathbf{I} + \sin\theta\,\mathbf{K} + (1 - \cos\theta)\,\mathbf{K}^2, \qquad \mathbf{K} = \begin{pmatrix} 0 & -c & b \\ c & 0 & -a \\ -b & a & 0 \end{pmatrix},\] 其中 \(\mathbf{K}\) 是 \(\mathbf{r} \mapsto \mathbf{n} \times \mathbf{r}\) 的矩陣。由於 \(\mathbf{K}^3 = -\mathbf{K}\)，指數級數（exponential series）\(e^{\theta\mathbf{K}} = \mathbf{I} + \theta\mathbf{K} + \frac{\theta^2}{2!}\mathbf{K}^2 + \cdots\) 恰好化簡成這條公式，它就是 \(e^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta\) 的三維版本。旋轉與「無窮小旋轉」\(\mathbf{K}\) 的指數之間的這種聯繫，正是李羣（Lie groups）理論的起點。

旋轉不可交換

把一本書平放，先繞垂直軸旋轉 \(90^\circ\)，再繞水平軸旋轉 \(90^\circ\)；然後從頭再來，以相反的次序做這兩個旋轉。書最終的位置並不相同。三維空間中旋轉的複合（composition）不符合交換律，與二維的情況不同。這正是 第 6.7 節 的四元數（quaternion）有用的原因之一：繞 \(\mathbf{n}\) 旋轉 \(\theta\) 對應於四元數 \(\cos\frac\theta2 + \sin\frac\theta2(a\mathrm{i} + b\mathrm{j} + c\mathrm{k})\)，而複合旋轉就是把四元數相乘，不可交換性已包含在其中。羅德里格本人在 1840 年的論文中，已找到旋轉的複合公式，比哈密頓（Hamilton）發明四元數還早三年。

思維技巧

分解為不變的部分

要理解一個變換，可把空間分成變換處理得簡單的幾塊：在這裏，就是軸（保持不動）和與軸垂直的平面（被旋轉）。

這與 第 7.2 節 中特徵向量的想法相同：找出變換所保持的子空間（subspace），然後在每一塊上分別研究它。

延伸練習

  1. 平面上的旋轉。試做 STEP III 2017，第 2 題。該題利用複數，證明平面上的兩個旋轉複合起來仍是一個旋轉，只有一種例外。找出這個例外，以及此時複合的結果是甚麼。

  2. 一個具體的旋轉。求繞方向為 \((1, 1, 1)\) 的軸旋轉 \(120^\circ\) 的矩陣。證明它把各坐標軸循環置換。

  3. \(\mathbf{K}\) 的冪。證明 \(\mathbf{K}^2\mathbf{r} = (\mathbf{n}.\mathbf{r})\mathbf{n} - \mathbf{r}\) 及 \(\mathbf{K}^3 = -\mathbf{K}\)，並由指數級數推導出羅德里格公式。

  4. 兩次反射構成一個旋轉。證明先後對兩個通過原點、互成 \(\alpha\) 角的平面作反射，結果是繞兩平面的交線旋轉 \(2\alpha\)。

延伸閱讀

  • Simon Altmann, Rotations, Quaternions, and Double Groups（Dover）。關於三維旋轉的權威論著，當中包括羅德里格的貢獻。

  • Simon Altmann, “Hamilton, Rodrigues, and the quaternion scandal”, Mathematics Magazine 62 (1989)。一篇簡短而生動的歷史敍述。

  • John Stillwell, Naive Lie Theory（Springer）。為大學本科生而寫的旋轉、四元數與李羣入門。
