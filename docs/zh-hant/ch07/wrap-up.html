第 7 章 · 線性代數與幾何

我們學到了甚麼

本章開首我們說過，矩陣（matrix）是空間的一種變換（transformation），自有其生命；我們還提出了三個問題：矩陣與數有何相似、有何不同，矩陣究竟做了甚麼，以及甚麼保持不變。以下是本章九道題目所揭示的答案。

1. 矩陣與數有何相似，又有何不同？

矩陣可以相加和相乘，但 第 7.1 節 指出了哪些熟悉的法則不再成立。乘法不符合交換律（commutative law），所以 \((\mathbf{A} - \mathbf{B})(\mathbf{A} + \mathbf{B})\) 未必等於 \(\mathbf{A}^2 - \mathbf{B}^2\)；矩陣中存在零因子（zero divisor），所以 \(\mathbf{AB} = \mathbf{0}\) 並不保證 \(\mathbf{BA} = \mathbf{0}\)；而一條二次矩陣方程可以有無限多個根。每一項法則的失效都有幾何解釋，可以從這些矩陣對平面的作用來理解。至關重要的是，有一項性質保留了下來：行列式（determinant）可乘，即 \(\det(\mathbf{AB}) = \det\mathbf{A}\det\mathbf{B}\)。第 7.3 節 說明這項性質基本上刻劃了行列式，而 第 7.8 節 則用它證明了歐拉（Euler）的四平方恆等式（four-square identity），這正是拉格朗日（Lagrange）定理的關鍵一步；該定理指出每個正整數都是四個平方數之和。

2. 矩陣究竟做了甚麼？

有幾節透過找出合適的觀點來回答這個問題。

  • 特徵向量（eigenvector）（第 7.2 節）是矩陣不會轉動的方向。在以特徵向量為軸的坐標下，對稱矩陣（symmetric matrix）只不過是一個伸縮，而圓的像是一個橢圓，其軸和面積都可以直接讀出。

  • 行列式（第 7.3 節）是帶正負號的面積比例因子：錯切（shear）保持面積不變，對換會把定向（orientation）反轉，奇異矩陣（singular matrix）則把平面壓扁。

  • 跡（trace）與行列式（第 7.4 節）透過凱萊–哈密頓定理（Cayley–Hamilton theorem），決定一個矩陣會否在若干步之後回到單位矩陣（identity matrix）。滿足 \(\mathbf{M}^8 = \mathbf{I}\) 的矩陣未必是旋轉；它是在歪斜坐標下看到的旋轉。又由於整數矩陣的跡是整數，晶體不可能有五重對稱。

  • 三維空間中的旋轉（第 7.5 節）可由向量積（cross product）透過羅德里格斯公式（Rodrigues’ formula）構造出來，這是 \(e^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta\) 在三維的對應版本。

  • 雙曲旋轉（hyperbolic rotation）（第 7.6 節）使點沿雙曲線移動，並把它們的雙曲角相加。它們就是狹義相對論中的洛倫茲變換（Lorentz boost），而它們的不變直線（invariant line）就是光的路徑。

3. 甚麼保持不變？

不變量（invariant）無處不在。旋轉保持 \(x^2 + y^2\) 不變，洛倫茲變換保持 \(x^2 - y^2\) 不變，而相似矩陣（similar matrices）有相同的跡和行列式。在 第 7.7 節 中，一個按 \(\dot{\mathbf{M}} = \mathbf{MN} - \mathbf{NM}\) 演化的矩陣，不論其元素如何變化，它的跡和行列式都保持不變，因而它的特徵值（eigenvalue）也保持不變：這就是孤立子（soliton）各條守恆定律背後的機制。而在 第 7.9 節 中，不變量是一個數，\(V - E + F = 2\)，它對每個凸多面體（convex polyhedron）都成立，並把正多面體限定為僅有五種。這個數稱為歐拉示性數（Euler characteristic），是拓撲學（topology）中最早出現的不變量之一。

如果你想在入讀大學之前再走遠一點

  • 3Blue1Brown, Essence of Linear Algebra（線性代數的本質）：一套免費的影片系列，展示矩陣究竟做了甚麼。請先看這個。

  • Gilbert Strang, Introduction to Linear Algebra（線性代數導論）：經典的入門課程，十分着重理解和應用。

  • Sheldon Axler, Linear Algebra Done Right（線性代數應該這樣學）：較為抽象的處理手法，以線性映射（linear map）為中心；可在網上免費閱讀。

  • David Richeson, Euler’s Gem（歐拉的瑰寶）：歐拉公式與拓撲學的誕生。

Kaplansky 曾打趣說，他和 Halmos 思考時不用坐標，但關起門來卻「拼命地」用矩陣計算。這句話正好道出本章想說明的事：矩陣既具體又可以計算，但每一項計算背後都有幾何（一個伸縮、一個旋轉、一個投影、一個洛倫茲變換），還有一個不變量，它不取決於你怎樣把它寫下來。學會在這兩種觀點之間來回轉換，是數學家所能擁有的最寶貴技能之一。
