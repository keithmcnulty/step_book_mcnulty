第 8 章 · 微分方程與動力系統

延伸練習答案

以下只是簡短的答案和提示，並非完整解答：只列出結果和關鍵步驟，方便你核對自己的做法。請先認真做過每道練習，然後才翻看。

8.1 當解不唯一

  1. 設 \(y = v^2\)：\(2vv' = \alpha v - \beta v^2\)，所以 \(v' = \frac12(\alpha - \beta v)\)，而 \(y_1 = \frac{\alpha^2}{\beta^2}\bigl(1 - \mathrm{e}^{-\beta t/2}\bigr)^2\)。設 \(y = v^3\)：\(v' = \frac13(\alpha - \beta v)\)，而 \(y_1 = \frac{\alpha^3}{\beta^3}\bigl(1 - \mathrm{e}^{-\beta t/3}\bigr)^3\)。常數函數 \(y = 0\) 令等式兩邊都等於零；推導時除以 \(v\)，就把這個解丟掉了。

  2. \(2\sqrt h = 2\sqrt{h_0} - kt\)，所以 \(h = \bigl(\sqrt{h_0} - \frac12kt\bigr)^2\)，水桶在 \(T = \frac{2\sqrt{h_0}}{k}\) 時流乾。\(h \equiv 0\)，以及當 \(t \leq T\) 時 \(h = \frac{k^2}{4}(T - t)^2\)、當 \(t \geq T\) 時 \(h = 0\) 的函數，兩者都滿足方程，而且由 \(T\) 起都等於零：看着一個空桶，你無法知道它是何時流乾的。

  3. \(\frac{\mathrm{d}}{\mathrm{d}x}(y\mathrm{e}^{-2x}) = (y' - 2y)\mathrm{e}^{-2x} = 0\)，所以 \(y = C\mathrm{e}^{2x}\)，而 \(y(0) = 0\) 迫使 \(C = 0\)。函數 \(2y\) 滿足利普希茨（Lipschitz）條件（它的變化至多為 \(2|y_1 - y_2|\)），而 \(2\sqrt y\) 在 \(0\) 處的斜率為無窮大。

  4. 對任意 \(b \leq 0 \leq a\)（容許 \(b = -\infty\) 或 \(a = \infty\)）：當 \(x < b\) 時 \(y = (x - b)^3\)，當 \(b \leq x \leq a\) 時 \(y = 0\)，當 \(x > a\) 時 \(y = (x - a)^3\)。\(a = b = 0\) 的情況就是 \(y = x^3\)。

8.2 不求解而估界

  1. \(\frac{\mathrm{d}}{\mathrm{d}x}\bigl((y')^2 + y^2\bigr) = 2y'(y'' + y) = 0\)，所以 \((y')^2 + y^2 = A^2\)，因而 \(|y| \leq A\)。精確解是 \(A\cos x\)。

  2. \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl((\theta')^2 - 2\cos\theta\bigr) = 2\theta'(\theta'' + \sin\theta) = 0\)。由靜止開始，\((\theta')^2 = 2(\cos\theta - \cos\theta_0) \geq 0\)，所以 \(\cos\theta \geq \cos\theta_0\)；當 \(|\theta_0| < \pi\) 時，連續性（continuity）令 \(\theta\) 留在 \([-|\theta_0|, |\theta_0|]\) 之內，而當 \(|\theta_0| = \pi\) 時，擺倒立平衡，並一直停在那裏。若 \(|\theta_0| > \pi\)，例如 \(\theta_0 = \frac{3\pi}{2}\)，則 \(\theta''(0) = -\sin\frac{3\pi}{2} = 1 > 0\)，所以 \(\theta\) 起初遞增：擺其實位於角度 \(\theta_0 - 2\pi = -\frac\pi2\)，並在由該處量起的 \(\pm\frac\pi2\) 之間擺動。

  3. \(\frac{\mathrm{d}}{\mathrm{d}t}\bigl((y')^2 + y^2\bigr) = 2y'(y'' + y) = -4k(y')^2 \leq 0\)。它確實趨向零，但單憑單調性（monotonicity）並不足以證明這一點：你還需要其他工具，例如顯式解，其指數 \(-k \pm \sqrt{k^2 - 1}\) 的實部為負。

  4. \((y')^2 - \frac12y^4\) 是常數，等於 \(-\frac12\)。由此得 \((y')^2 = \frac12(y^4 - 1)\)，但這給不出任何界：「位能」\(-\frac12y^4\) 沒有可以困住 \(y\) 的位阱，而事實上 \(y\) 會在有限時間內趨向無窮（blow up）。

8.3 收穫種羣

  1. 方程是 \(x' = \alpha^2 - (x - K)^2\)，可化為 \(y' = y(2\alpha - y)\)。設 \(w = \frac1y\)，則 \(w' = 1 - 2\alpha w\)，所以 \(w = \frac{1}{2\alpha} + C\mathrm{e}^{-2\alpha t}\)。若 \(y(0) < 0\)，則 \(w(0) < 0 < \frac{1}{2\alpha}\)，所以 \(w\) 在有限時間內經過 \(0\)，而 \(y \to -\infty\)；\(x\) 在此之前已到達 \(0\)。

  2. 設 \(z = x - K\)，則 \(z' = -(z^2 + \beta^2)\)，所以 \(\tan^{-1}\frac z\beta = \tan^{-1}\frac K\beta - \beta t\)。種羣數量在 \(t = \frac2\beta\tan^{-1}\frac K\beta\) 時降至零（\(z = -K\)）。

  3. \(x' = x(2K - h - x)\) 的平衡點（equilibria）是 \(0\) 和 \(2K - h\)。當 \(h < 2K\) 時，這是一條環境承載量（carrying capacity）為正的邏輯斯諦方程（logistic equation），每個正數解都趨向 \(2K - h\)。捕獲量隨種羣數量下降而減少，所以永遠不會把種羣數量逼至零。

  4. \(x = K + K\tanh Kt\)，而 \(\tanh Kt = \frac12\) 給出 \(t = \frac{1}{K}\tanh^{-1}\frac12 = \frac{\ln3}{2K}\)。

8.4 盤旋趨向圓

  1. 曲線與半徑之間的夾角 \(\psi\) 滿足 \(\tan\psi = \frac{r}{\mathrm{d}r/\mathrm{d}\theta} = -1\)，在每一點都相同：曲線與每條射線都以 \(45^\circ\) 相交。

  2. \(x\,\mathrm{d}x + y\,\mathrm{d}y = \frac12\,\mathrm{d}(x^2 + y^2) = r\,\mathrm{d}r\)。另外 \(x\,\mathrm{d}y - y\,\mathrm{d}x = r\cos\theta(\sin\theta\,\mathrm{d}r + r\cos\theta\,\mathrm{d}\theta) - r\sin\theta(\cos\theta\,\mathrm{d}r - r\sin\theta\,\mathrm{d}\theta) = r^2\,\mathrm{d}\theta\)。

  3. 設 \(s = r^2\)，則 \(\dot s = 2s(1 - s)\)，是一條邏輯斯諦方程，所以對任意 \(s(0) > 0\) 都有 \(s \to 1\)。寫成笛卡兒（Cartesian）形式：\(\dot x = x(1 - x^2 - y^2) - y\)，\(\dot y = y(1 - x^2 - y^2) + x\)。

  4. \(\dot r = r(r - 1)(r - 2)\)，\(\dot\theta = 1\)。在 \(0\) 與 \(1\) 之間，\(\dot r > 0\)；在 \(1\) 與 \(2\) 之間，\(\dot r < 0\)；超過 \(2\) 之後，\(\dot r > 0\)。所以 \(r = 1\) 是吸引的，而 \(r = 2\) 是排斥的。

8.5 格力犬追逐格力犬

  1. 由對稱性可知，幾隻狗始終構成一個正方形。\(A\) 沿 \(AB\) 以速率 \(v\) 奔跑，令距離以速率 \(v\) 縮短；\(B\) 沿 \(BC\) 奔跑，而這個方向垂直於 \(AB\)，所以在一階近似下不會改變距離。因此 \(AB\) 恰好以速率 \(v\) 縮短，由 \(s\) 減至 \(0\)，需時 \(\frac sv\)。

  2. \(r = \lambda\mathrm{e}^{-\sqrt3\theta}\)。距離以速率 \(v - v\cos120^\circ = \frac32v\) 縮短，所以牠們在時間 \(\frac{2s}{3v}\) 後相遇，每隻各跑了 \(\frac{2s}{3}\)（這與 \(\frac{s}{2\sin^2(\pi/n)}\) 在 \(n = 3\) 時的值吻合）。

  3. 每轉一圈，\(r\) 就乘以 \(\mathrm{e}^{-2\pi} \approx \frac{1}{535}\)：轉一圈後約為 \(19\) cm。轉兩圈後約為 \(0.35\) mm，所以轉足兩圈便已足夠。

  4. 兩隻狗筆直地向對方奔跑，在時間 \(\frac{s}{2v}\) 後於中點相遇。公式在此失效：\(\tan\frac\pi2\) 為無窮大，正好對應完全沒有轉彎這個事實。

8.6 量子振子

  1. 這只需直接求導（雖然頗為繁瑣）；另一個做法是由第 4 題推出。取 \(2\lambda = \omega\)，則 \(\int y_0y_2 = \int(2\omega x^2 - 1)\mathrm{e}^{-\omega x^2}\,\mathrm{d}x = 2\omega \cdot \frac{1}{2\omega}\sqrt{\frac\pi\omega} - \sqrt{\frac\pi\omega} = 0\)。

  2. \(y'' = (4\lambda^2x^2 - 2\lambda)y\)，所以方程要求 \(4\lambda^2 = \omega^2\) 及 \(2\lambda = (2\nu + 1)\omega\)。取 \(\lambda = \frac\omega2 > 0\)（使解衰減），得 \(\nu = 0\)。

  3. \(\frac{\mathrm{d}}{\mathrm{d}x}(y_my_n' - y_ny_m') = y_my_n'' - y_ny_m'' = (m^2 - n^2)y_my_n\)。由 \(0\) 積分至 \(\pi\)：因為 \(y_m\) 和 \(y_n\) 在兩端都等於零，左邊得 \(0\)，而 \(m^2 \neq n^2\)。

  4. 記 \(c = (2n + 1)\omega\)，於是 \(y_n'' = (\omega^2x^2 - c)y_n\)。把 \(z = \omega xy_n - y_n'\) 求導兩次，並運用上式（及其導數），得 \(z'' - \omega^2x^2z = -(c + 2\omega)z\)，而 \(c + 2\omega = (2n + 3)\omega\)。由 \(y_0 = \mathrm{e}^{-\omega x^2/2}\) 出發：先得 \(2\omega x\mathrm{e}^{-\omega x^2/2}\)，再得 \(2\omega(2\omega x^2 - 1)\mathrm{e}^{-\omega x^2/2}\)，它們分別是 \(y_1\) 和 \(y_2\) 的倍數。

8.7 可以解出的混沌

  1. (i) 用歸納法（induction）：若 \(0 < x < 1\)，則 \(0 < x(1 - x) \leq \frac14\)，所以 \(0 < kx(1 - x) < 1\)。(ii) \(a = ka(1 - a)\) 給出 \(k = \frac{1}{1 - a}\)。(iii) 由於 \(x_1 = ka(1 - a) = ab\)，條件 \(x_2 = a\) 即 \(kab(1 - ab) = a\)；代入 \(k = \frac{b}{1 - a}\) 後，化為 \(ab^3 - b^2 + 1 - a = 0\)。根 \(b = 1\) 對應不動點（fixed point）（\(x_1 = a\)），所以把它提出來：\(ab^2 + (a - 1)b + (a - 1) = 0\)；解出 \(b\)，便得 \(k = \frac{b}{1 - a}\)。等價的說法是：\(2\)-循環（cycle）的兩點是 \(k^2x^2 - k(k + 1)x + (k + 1) = 0\) 的兩個根，其判別式（discriminant）\(k^2(k + 1)(k - 3)\) 只在 \(k > 3\) 時為正。

  2. \(p = -1\)，\(q = 0\)，\(r = -2\)：\(4pr = 8 = 8 + 2q - q^2\)。比較係數得 \(\alpha = \frac4p = -4\) 及 \(\beta = \frac{q - 4}{2p} = 2\)，所以 \(v_n = 2 - 4\sin^2(2^n\theta) = 2\cos(2^{n+1}\theta)\)，即 \(2\cos(2^n\phi)\)，其中 \(\phi = 2\theta\)。

  3. \(u_3 = u_0\) 要求 \(\sin^2 8\theta = \sin^2\theta\)，所以 \(8\theta = \pm\theta + k\pi\)。取 \(\theta = \frac\pi7\)：得循環 \(\sin^2\frac\pi7 \to \sin^2\frac{2\pi}{7} \to \sin^2\frac{4\pi}{7} \to \sin^2\frac{8\pi}{7} = \sin^2\frac\pi7\)。取 \(\theta = \frac\pi9\)：\(\sin^2\frac\pi9\)，\(\sin^2\frac{2\pi}9\)，\(\sin^2\frac{4\pi}{9}\)。映射（map）\(u \mapsto u_3\) 有 \(2^3 = 8\) 個不動點；其中兩個（\(0\) 和 \(\frac34\)）是原映射本身的不動點，餘下 \(6\) 個點的週期恰好是 \(3\)：即兩個 \(3\)-循環。

  4. 每一步都把 \(\theta\) 加倍，因而損失一個二進制數位的準確度，所以大約 \(50\) 步之後，計算所得的數值與真實數值已毫無關係。但這些數值並非沒有用處：計算所得的數列始終貼近一條由稍為不同的起點出發的真實軌道（orbit）（這就是影隨（shadowing）性質），所以它的統計特性仍然正確。

8.8 週期三蘊含混沌

  1. 設 \(a\)、\(b\)、\(c > 0\) 而 \(d < 0\)：\(b = 7 - 2a\)，\(c = 7 - 2b\)，\(d = 7 - 2c\)，\(a = 7 + 2d\)。解得 \(17a = 49\)，所以循環是 \(\frac{49}{17} \to \frac{21}{17} \to \frac{77}{17} \to -\frac{35}{17} \to \frac{49}{17}\)，其中三點在 \(I_2 = [1, 5]\) 內，一點在 \(I_1 = [-3, 1]\) 內。

  2. 所找到的點的行程（itinerary）是 \(I_2, I_2, \ldots, I_2, I_1\)（其中有 \(n - 1 \geq 3\) 步在 \(I_2\) 內）。循環 \(1 \to 5 \to -3\) 不可能依循這個行程：\(-3\) 不在 \(I_2\) 內，所以 \(1\)（它的第二個像是 \(-3\)）、\(5\)（它的第一個像是 \(-3\)）以及 \(-3\) 本身，都不可能是該點。

  3. 覆蓋圖（covering diagram）是 \([1, 2] \to [3, 4], [4, 5]\)；\([2, 3] \to [4, 5]\)；\([3, 4] \to [2, 3], [3, 4]\)；\([4, 5] \to [1, 2]\)。長度為 \(3\) 的迴路只有 \([3, 4] \to [3, 4] \to [3, 4]\)，它給出的是不動點，而不是 \(3\)-循環。

  4. 設 \(x = 14y - 7\)，則 \(\frac{\mathrm{f}(x) + 7}{14} = 1 - |2y - 1|\)，即帳篷映射（tent map）。加倍會把二進制數位向左移一位；若移出的數位是 \(1\)，結果便是 \(2 - 2y\)，即把餘下的數位逐一反轉。\(3\)-循環有 \(\frac27 \to \frac47 \to \frac67\) 和 \(\frac29 \to \frac49 \to \frac89\)（即 \(x = -3, 1, 5\) 和 \(x = -\frac{35}{9}, -\frac79, \frac{49}{9}\)）；以二進制表示，\(\frac27 = 0.\overline{010}\) 而 \(\frac29 = 0.\overline{001110}\)。
