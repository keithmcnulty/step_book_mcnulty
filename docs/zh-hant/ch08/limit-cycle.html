8.4

盤旋趨向圓

工作紙題目連結、提示、大學數學及練習 第 8 章整章的 PDF 版本
題目

STEP III 2015，第 8 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/15-s3-q8

引子

自然界中有許多系統，無論起始狀態如何，最終都會進入同一種規律的節奏：心臟的跳動、蟋蟀的鳴叫、穩定拉奏的小提琴弦、捕食者與獵物的種羣數量週期。稍加擾動，它們又會回到原來的節奏。用微分方程（differential equation）的語言來說，它們的解會趨近一條閉合曲線，稱為極限環（limit cycle）。

這道題目正是要構造一個極限環。方程以 \(x\) 和 \(y\) 表示時看似無從入手，但換成極坐標（polar coordinates）後，就化簡成可以求解的形式，而且各個解原來都會從內側和外側盤旋着貼近單位圓。當中的關鍵一步，是選取與問題的對稱性（symmetry）相配的坐標，這也是本書一直沿用的手法。

動筆之前

兩條方程其實都暗藏 \(x\,\mathrm{d}x + y\,\mathrm{d}y\) 和 \(x\,\mathrm{d}y - y\,\mathrm{d}x\) 這兩個組合。它們在極坐標中是甚麼？

由於 \(r^2 = x^2 + y^2\)，求導後得 \(x\,\mathrm{d}x + y\,\mathrm{d}y = r\,\mathrm{d}r\)。另外 \(x\,\mathrm{d}y - y\,\mathrm{d}x = r^2\,\mathrm{d}\theta\)（這就是 第 4.9 節 中的面積公式）。有了這兩條恆等式（identity），變數代換（change of variables）幾乎毫不費力：只要把方程改寫成只含這兩個組合的形式即可。

逐步解題

階段 1 以極坐標處理第 (i) 部分

把方程寫成 \((y + x)\,\mathrm{d}y - (y - x)\,\mathrm{d}x = 0\)，再重新整理： \[(x\,\mathrm{d}x + y\,\mathrm{d}y) + (x\,\mathrm{d}y - y\,\mathrm{d}x) = 0.\]

展開算式，驗證以上的整理無誤。然後運用上面兩條恆等式。

\((y + x)\,\mathrm{d}y - (y - x)\,\mathrm{d}x = y\,\mathrm{d}y + x\,\mathrm{d}y - y\,\mathrm{d}x + x\,\mathrm{d}x\)，正是上面的算式。化成極坐標形式就是 \(r\,\mathrm{d}r + r^2\,\mathrm{d}\theta = 0\)，兩邊除以 \(r^2\,\mathrm{d}\theta\)（其中 \(r > 0\)），得 \[\frac{\mathrm{d}r}{\mathrm{d}\theta} + r = 0. \qed\] 方程的解是 \(r = Ce^{-\theta}\)：這些是對數螺線（logarithmic spiral），隨着 \(\theta\) 增加而向原點捲入，隨着 \(\theta\) 減少而向無窮遠處捲出。

階段 2 第 (ii) 部分

新方程是在舊方程之上，加入含有 \(x^2 + y^2 = r^2\) 的額外項。用同樣的方法改寫，並求出 \(\frac{\mathrm{d}r}{\mathrm{d}\theta}\)。

方程是 \(\bigl(y + x - xr^2\bigr)\,\mathrm{d}y - \bigl(y - x - yr^2\bigr)\,\mathrm{d}x = 0\)，即 \[\bigl[(y + x)\,\mathrm{d}y - (y - x)\,\mathrm{d}x\bigr] - r^2\bigl(x\,\mathrm{d}y - y\,\mathrm{d}x\bigr) = 0.\] 第一個括號和之前一樣，等於 \(r\,\mathrm{d}r + r^2\,\mathrm{d}\theta\)，第二個括號則是 \(r^2\,\mathrm{d}\theta\)。因此 \(r\,\mathrm{d}r + r^2(1 - r^2)\,\mathrm{d}\theta = 0\)，由此得 \[\frac{\mathrm{d}r}{\mathrm{d}\theta} = r^3 - r.\]

這條方程對 \(r\) 而言並非線性（linear），但換成 \(u = r^{-2}\) 後就變成線性。\(u\) 滿足甚麼方程？

設 \(u = r^{-2}\)，則 \(\frac{\mathrm{d}u}{\mathrm{d}\theta} = -2r^{-3}\frac{\mathrm{d}r}{\mathrm{d}\theta} = -2r^{-3}(r^3 - r) = -2 + 2u\)。所以 \(\frac{\mathrm{d}u}{\mathrm{d}\theta} - 2u = -2\)，其解為 \(u = 1 + Ae^{2\theta}\)。因此 \[r^2 = \frac{1}{1 + Ae^{2\theta}}. \qed\]

階段 3 三類解

  • \(A = 0\)：\(r = 1\)。單位圓是一個解。

  • \(A > 0\)：恆有 \(r < 1\)。當 \(\theta \to -\infty\) 時，\(r \to 1\)；當 \(\theta \to +\infty\) 時，\(r \to 0\)。曲線在圓與原點之間盤旋。

  • \(A < 0\)：\(r > 1\)，而且公式只在 \(1 + Ae^{2\theta} > 0\) 時才有意義，即 \(\theta < \frac12\ln\left(-\frac1A\right)\)。當 \(\theta \to -\infty\) 時，\(r \to 1\)；當 \(\theta\) 趨近該上界時，\(r \to \infty\)。曲線在圓與無窮遠之間盤旋。

所以當 \(\theta \to -\infty\) 時，每條解曲線都會從內側或外側趨近單位圓（圖 8.4.1）。

回顧

  • 善用對稱性。這些方程對所有方向一視同仁，而極坐標令這一點顯露出來。

  • 認出標準組合。\(x\,\mathrm{d}x + y\,\mathrm{d}y = r\,\mathrm{d}r\) 和 \(x\,\mathrm{d}y - y\,\mathrm{d}x = r^2\,\mathrm{d}\theta\) 完成了大部分工作。

  • 代換可使方程線性化。非線性方程 \(r' = r^3 - r\) 換成 \(u = r^{-2}\) 後變成線性（這是一條伯努利方程（Bernoulli equation））。

背後的數學

極限環

龐加萊（Henri Poincaré）在 1880 年代研究平面上微分方程的定性行為時，引入了極限環。不妨把題目中的方程理解為描述一個點在平面上運動的路徑。單位圓是一條孤立的閉軌道（closed orbit），附近的每條軌道都會纏繞着向它靠近（或遠離它，視乎時間的方向而定）。1926 年，荷蘭工程師 Balthasar van der Pol 在一個裝有真空管的電路中發現了極限環，並提出類似的方程可以描述心臟的跳動。凡是具有自持而穩定節奏的系統，都可以用極限環作為模型：生理時鐘、神經脈衝、捕食者與獵物種羣數量的週期。

平面上沒有混沌

龐加萊–本迪克松定理（Poincaré–Bendixson theorem）指出，對於平面上的光滑系統，如果一條軌道一直留在某個有界區域內，又不趨近任何平衡點（equilibrium），它就必定趨近一條閉軌道。所以在二維的情況下，長期行為只限於平衡點和環：混沌（chaos）沒有容身之處，因為軌道不能相交。混沌至少需要三維，正如洛倫茲（Edward Lorenz）在 1963 年以他那著名的三變數對流模型（「蝴蝶」）所發現的那樣。至於離散時間的情況，我們會在 第 8.7 節 看到，即使只有一維，混沌也可能出現。

一個未解決的問題

1900 年，希爾伯特（David Hilbert）在他的第十六問題中問道：當 \(P\) 和 \(Q\) 是 \(n\) 次多項式時，系統 \(x' = P(x, y)\)，\(y' = Q(x, y)\) 最多可以有多少個極限環？即使是 \(n = 2\) 的情況，答案至今仍然未知：已知有些系統具有四個極限環，但是否可能有更多，則無人知曉。在希爾伯特的問題之中，這是極少數至今仍然完全懸而未決的一個。

思維技巧

轉換坐標以配合對稱性

如果問題具有旋轉對稱性，就用極坐標；如果具有其他對稱性，就找出與之相配的坐標。

合適的坐標把一條難以處理的方程變成可分離變數（separable）的方程，並令解的幾何形狀（圓和螺線）一目了然。

延伸練習

  1. 螺線。對於第 (i) 部分的解 \(r = e^{-\theta}\)，證明曲線與每條由原點出發的射線都以相同的角度 \(45^\circ\) 相交。（這就是對數螺線又稱為等角螺線（equiangular spiral）的原因。）

  2. 極坐標恆等式。證明 \(x\,\mathrm{d}x + y\,\mathrm{d}y = r\,\mathrm{d}r\) 和 \(x\,\mathrm{d}y - y\,\mathrm{d}x = r^2\,\mathrm{d}\theta\)。

  3. 隨時間變化的系統。考慮系統 \(\dot r = r(1 - r^2)\)，\(\dot\theta = 1\)。證明當 \(t \to \infty\) 時，每個滿足 \(r(0) > 0\) 的解都趨近單位圓。把這個系統以 \(x\) 和 \(y\) 表示。

  4. 兩個環。找出一個形如 \(\dot r = f(r)\)，\(\dot\theta = 1\) 的系統，使它有兩個極限環，分別位於 \(r = 1\) 和 \(r = 2\)，其中一個是吸引的（attracting），另一個是排斥的（repelling）。
