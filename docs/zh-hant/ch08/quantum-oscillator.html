8.6

量子振子

工作紙題目連結、提示、大學數學及練習 第 8 章整章的 PDF 版本
題目

STEP III 1988，第 7 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/88-s3-q7

引子

繫在彈簧上的質點，振動的能量可以隨你喜歡：把它拉開少許也好，拉開很遠也好。但在 1900 年，普朗克（Max Planck）發現，要解釋高溫物體所發出的光的顏色，唯一的辦法是假定振動中的原子只能具有某些特定的能量，每級相差一個固定的大小。在原子的尺度上，能量是一份一份的，稱為量子（quanta）。二十五年後，量子力學（quantum mechanics）解釋了箇中原因。

這道題目正包含了這個解釋。題中的微分方程（differential equation）經過單位轉換後，就是一個量子粒子處於彈簧式勢能中的薛定諤方程（Schrödinger equation），亦即量子諧振子（quantum harmonic oscillator）。只有當能量取某些特殊的值時，它才有性質良好的解，即在無窮遠處衰減至零的解；這些能量值以 \(n = 0, 1, 2, \ldots\) 標記，彼此等距排列。而且不同的 \(n\) 所對應的解是正交（orthogonal）的：它們乘積的積分為零，就像傅立葉級數（Fourier series）中的 \(\sin mx\) 與 \(\sin nx\) 一樣。量子諧振子是研究分子、固體和光的物理學的起點。

動筆之前

為甚麼像 \(e^{-\lambda x^2}\) 這樣的函數會是一個合理的猜測？當 \(x \to \pm\infty\) 時，\(e^{-\lambda x^2}\) 及其導數會怎樣？

當 \(|x|\) 很大時，方程主要由 \(y'' \approx \omega^2x^2y\) 支配，而高斯函數（Gaussian）\(e^{-\lambda x^2}\) 在 \(x\) 很大時滿足 \(y'' \approx 4\lambda^2x^2y\)，只要 \(4\lambda^2 = \omega^2\)，兩者便吻合。若 \(\lambda > 0\)，高斯函數及其所有導數衰減至 \(0\) 的速度比 \(x\) 的任何次冪都要快。因此邊界條件（boundary conditions）會自動成立；真正要下工夫的，是令函數符合方程。

逐步解題

階段 1 基態

把 \(y_0 = e^{-\lambda x^2}\) 求導兩次，代入 \(n = 0\) 時的方程，然後比較 \(x^2\) 的係數和常數項。

\(y_0' = -2\lambda xe^{-\lambda x^2}\)，而 \(y_0'' = (4\lambda^2x^2 - 2\lambda)e^{-\lambda x^2}\)。\(n = 0\) 時的方程要求 \[4\lambda^2x^2 - 2\lambda - \omega^2x^2 = -\omega\] 對所有 \(x\) 成立。比較係數（match coefficients）：\(4\lambda^2 = \omega^2\) 及 \(2\lambda = \omega\)。取 \(\lambda = \frac\omega2\) 時兩式同時成立（取 \(\lambda > 0\)，使得 \(y_0 \to 0\)）。而且當 \(x \to \pm\infty\) 時，\(y_0\)、\(y_0' \to 0\)。■

階段 2 第一激發態

\(y_1 = xe^{-\lambda x^2}\) 滿足 \(y_1' = (1 - 2\lambda x^2)e^{-\lambda x^2}\) 及 \(y_1'' = (4\lambda^2x^3 - 6\lambda x)e^{-\lambda x^2}\)。\(n = 1\) 時的方程要求 \[4\lambda^2x^3 - 6\lambda x - \omega^2x^3 = -3\omega x,\] 而同樣取 \(\lambda = \frac\omega2\) 時此式成立。\(y_1\) 與 \(y_1'\) 同樣在 \(\pm\infty\) 處衰減至零。■

階段 3 一個恆等式

用積法則（product rule）對 \(y_my_n' - y_ny_m'\) 求導。四項之中有兩項互相抵銷。然後利用微分方程代換 \(y_n''\) 和 \(y_m''\)。

\(\dfrac{\mathrm{d}}{\mathrm{d}x}(y_my_n' - y_ny_m') = y_m'y_n' + y_my_n'' - y_n'y_m' - y_ny_m'' = y_my_n'' - y_ny_m''\)。由方程可得 \(y_n'' = \bigl(\omega^2x^2 - (2n + 1)\omega\bigr)y_n\)，對 \(m\) 亦有類似的式子。所以 \[y_my_n'' - y_ny_m'' = y_my_n\bigl[\omega^2x^2 - (2n + 1)\omega - \omega^2x^2 + (2m + 1)\omega\bigr] = 2(m - n)\omega y_my_n. \qed\]

階段 4 正交性

把恆等式由 \(-\infty\) 積分至 \(\infty\)。左方是甚麼？

左方積分後得 \(\bigl[y_my_n' - y_ny_m'\bigr]_{-\infty}^{\infty} = 0 - 0 = 0\)，因為每個 \(y\) 和 \(y'\) 在兩端都趨向 \(0\)。所以 \(2(m - n)\omega\int_{-\infty}^{\infty}y_my_n\,\mathrm{d}x = 0\)，而由於 \(m \neq n\) 及 \(\omega > 0\)， \[\int_{-\infty}^{\infty}y_m(x)y_n(x)\,\mathrm{d}x = 0. \qed\] 對於 \(y_0\) 和 \(y_1\)，這一點很容易直接看出：\(y_0y_1 = xe^{-\omega x^2}\) 是奇函數（odd function）。但這個恆等式毋須知道函數本身是甚麼，便一舉證明了每一對解都正交。

回顧

  • 比較係數。代入猜測的形式，並要求方程對所有 \(x\) 成立，便確定了 \(\lambda\)。

  • 朗斯基行列式（Wronskian）的技巧。\(y_my_n' - y_ny_m'\) 這個組合求導後，其中的二階導數可以用方程代換，餘下的式子十分簡單。

  • 邊界條件消去邊界項。解在無窮遠處衰減，令左方積分後為零，從而得出正交性。

背後的數學

薛定諤方程

1926 年，薛定諤（Erwin Schrödinger）提出，量子粒子可用波函數（wave function）\(\psi(x)\) 來描述；若粒子的能量為 \(E\)，並處於勢能 \(V(x)\) 之中，則波函數滿足 \[-\frac{\hbar^2}{2m}\psi'' + V(x)\psi = E\psi.\] 對於彈簧，\(V(x) = \frac12m\Omega^2x^2\)，把 \(x\) 重新標度後，這正是題目中的方程，其中 \(E = \bigl(n + \frac12\bigr)\hbar\Omega\)。物理上要求 \(\psi\) 在無窮遠處衰減至零（這樣粒子才確實身處某處），而只有這些能量才能滿足這個要求：這就是量子化（quantisation），是由數學自然推導出來的結果。留意最低的能量並不是零，而是 \(\frac12\hbar\Omega\)：量子諧振子永遠不可能完全靜止。這種零點能（zero-point energy）真實存在，而且可以量度；正因如此，液態氦在常壓下即使到了絕對零度也不會凝固。

埃爾米特函數與施圖姆－劉維爾理論

通解為 \(y_n = H_n(\sqrt\omega x)e^{-\omega x^2/2}\)，其中 \(H_n\) 是一個 \(n\) 次多項式，稱為埃爾米特多項式（Hermite polynomial）（圖 8.6.1）。正交性並非這條方程獨有。只要一條方程可以寫成 \((py')' + qy = -\lambda wy\) 並配上適當的邊界條件，屬於不同 \(\lambda\) 值的解便互相正交，所用的論證與第 4 階段完全相同。這就是施圖姆－劉維爾理論（Sturm–Liouville theory，1830 年代），它涵蓋了傅立葉級數中的正弦函數（第 3.7 節）、鼓面的振動、靜電學中的勒讓德多項式（Legendre polynomials），以及氫原子的波函數。第 4.7 節 的特徵值問題（eigenvalue problem）是另一個例子：在那裏求得的臨界值就是特徵值 \(\lambda\)，而那些正交函數就是系統固有的「模態」（modes）。

思維技巧

由恆等式得出正交性

要證明相關方程的兩個解正交，可找出一個恰當導數（exact derivative），使它的積分因邊界條件而為零，而它本身又等於兩個解的乘積的某個倍數。

這比直接計算積分有力得多：它一次過適用於每一對解，即使你無法把解寫出來也行。

延伸練習

  1. 下一個態。證明 \(y_2 = (4\lambda x^2 - 1)e^{-\lambda x^2}\)（其中 \(\lambda = \frac\omega2\)）滿足 \(n = 2\) 時的方程。利用 \(\int_{-\infty}^\infty e^{-\omega x^2}\,\mathrm{d}x = \sqrt{\pi/\omega}\) 及 \(\int_{-\infty}^\infty x^2e^{-\omega x^2}\,\mathrm{d}x = \frac{1}{2\omega}\sqrt{\pi/\omega}\)，直接驗證 \(\int_{-\infty}^\infty y_0y_2\,\mathrm{d}x = 0\)。

  2. 沒有其他能量。把 \(n\) 換成一般的數 \(\nu\)，並嘗試 \(y = e^{-\lambda x^2}\)。證明只有當 \(\nu = 0\) 時它才是解。（事實上，只有當 \(\nu\) 是非負整數時，才存在衰減的解。）

  3. 正弦波。由 \(y'' = -n^2y\) 及 \(y(0) = y(\pi) = 0\) 出發，用同樣的方法證明當 \(m \neq n\) 時 \(\int_0^\pi \sin mx\sin nx\,\mathrm{d}x = 0\)。

  4. 階梯。證明若 \(y_n\) 是方程的解，則 \(y_{n+1} = \omega xy_n - y_n'\) 是把 \(n\) 換成 \(n + 1\) 後的方程的解。利用這個結果，由 \(y_0\) 生成 \(y_1\) 和 \(y_2\)。（這就是量子力學中的「升算符」（raising operator）。）
