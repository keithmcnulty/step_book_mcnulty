集齊一套

題目

STEP II 1994，第 13 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/94-s2-q13

引子

一本足球貼紙簿要集齊 \(600\) 張貼紙，貼紙每次隨機發售一張。要貼滿整本貼紙簿，你預計要買多少張貼紙？最初幾百張很快到手，因為幾乎每一張都是新的。但貼紙簿愈貼愈滿，新貼紙就愈來愈罕有，單是最後一張，平均就要買 \(600\) 次。總數大約是 \(4200\) 張，是貼紙簿大小的七倍。

這就是集券問題（coupon collector’s problem）。它的答案結合了兩個想法：等候一次成功所需的時間，以及調和級數（harmonic series）\(1 + \frac12 + \frac13 + \cdots\)，後者的增長與 \(\ln n\) 相若。你在 第 2.3 節 見過調和級數發散（diverge）；在這裏，它那緩慢的增長正正就是集齊一套收藏品所要付出的代價。

動筆之前

如果每包各自獨立地以概率 \(p\) 開出一張新卡，那麼直至開出第一張新卡為止（連這一包計算在內），你開包數目的期望值（expectation）是多少？

開包數目 \(X\) 服從幾何分佈（geometric distribution）：\(\mathrm{P}(X = k) = (1 - p)^{k-1}p\)。它的期望值是 \(\frac1p\)。（有一個快捷的看法：\(\mathrm{E}(X) = 1 + (1 - p)\mathrm{E}(X)\)，因為你先開一包，然後有 \(1 - p\) 的概率回到起點。）如果有三分之一的機會開出新卡，你預計要等三包。

逐步解題

階段 1 等候一張新卡

手上已有 \(r\) 張不同的卡時，一包開出新卡的概率是 \(\frac{n - r}{n}\)，與之前各包獨立。因此，直至開出下一張新卡為止，所需包數的期望值是 \[\frac{1}{(n - r)/n} = \frac{n}{n - r}. \qed\]

階段 2 比較和與積分

在區間 \(r \leq x \leq r + 1\) 上，\(\frac1x\) 介乎哪兩個值之間？這對曲線下的面積有甚麼啟示？

由於 \(\frac1x\) 是遞減的，在 \([r, r + 1]\) 上有 \(\frac{1}{r+1} \leq \frac1x \leq \frac1r\)。在長度為 \(1\) 的區間上積分，得 \[\frac{1}{r + 1} \leq \int_r^{r+1}\frac{\mathrm{d}x}{x} \leq \frac1r. \qed\] 用圖來看（圖 9.11.1）：曲線下的面積夾在高度為 \(\frac{1}{r+1}\) 的長方形與高度為 \(\frac1r\) 的長方形之間。把這些不等式由 \(r = 1\) 加到 \(r = n - 1\)，各個積分便連接成 \(\int_1^n\frac{\mathrm{d}x}{x} = \ln n\)，於是 \[\frac12 + \frac13 + \cdots + \frac1n \leq \ln n \leq 1 + \frac12 + \cdots + \frac{1}{n - 1}. \qed\]

階段 3 集齊全套

總包數是等候第一張卡、第二張新卡……各段等候時間之和。它的期望值是多少？

設 \(X_r\) 為由 \(r\) 張不同的卡增至 \(r + 1\) 張所需的包數。總數是 \(X_0 + X_1 + \cdots + X_{n-1}\)，而期望值可以相加，所以 \[\mathrm{E}(\text{總數}) = \sum_{r=0}^{n-1}\frac{n}{n - r} = n\Bigl(\frac1n + \frac{1}{n - 1} + \cdots + 1\Bigr) = nH_n,\] 其中 \(H_n = 1 + \frac12 + \cdots + \frac1n\) 是第 \(n\) 個調和數（harmonic number）。由第 2 步，\(\ln n + \frac1n \leq H_n \leq \ln n + 1\)，所以當 \(n\) 很大時 \(H_n\) 約為 \(\ln n\)，而我預計大約要吃掉 \[n\ln n \text{ 包}. \qed\]

回顧

  • 把漫長的等候分成多個階段。總時間拆成 \(n\) 段等候時間，每一段都屬於簡單的幾何分佈。

  • 期望值可以相加。我們從頭到尾都不需要總數的分佈，只需要各部分的期望值。

  • 比較和與積分。那幅圖把一個我們無法求值的和化成一個對數，誤差至多為 \(1\)。

背後的數學

這個估計有多準確？

這個比較還可以再精確一些。圖 9.11.1 中曲線與上方長方形之間的陰影空隙，總面積是有限的，所以 \(H_n - \ln n\) 趨向一個極限， \[\gamma = \lim_{n \to \infty}(H_n - \ln n) = 0.5772156649\ldots,\] 即歐拉常數。（沒有人知道 \(\gamma\) 是否有理數。）因此包數的期望值是 \(n\ln n + \gamma n + \frac12 + \cdots\)。以 \(600\) 張貼紙的貼紙簿為例，\(600 \times (\ln 600 + 0.577) \approx 4185\)，這就是引子中所引述的數字。

時間都花到哪裏去了？各個階段極不平均。集齊全套的前一半只需大約 \(n\ln 2 \approx 0.69n\) 包，而單是最後一張卡，平均就要 \(n\) 包。大部分工夫都花在最後幾張卡上，這正是收藏者要互相交換重複卡的原因。

集中現象

期望值只是個開始：總數的變動有多大？總數的方差（variance）是 \(\sum n r/(n - r)^2\)，約為 \(\frac{\pi^2}{6}n^2\)（第 2.4 節 中的和 \(\sum 1/k^2 = \pi^2/6\) 在這裏出現了）。所以標準差（standard deviation）約為 \(1.28n\)，當 \(n\) 很大時遠小於平均值 \(n\ln n\)：總數集中在其平均值附近。艾狄胥（Paul Erdős）和雷尼（Alfréd Rényi）在 1961 年證明了一個更精確的結果：總數減去 \(n\ln n\) 再除以 \(n\)，會有一個極限分佈（limiting distribution），即耿貝爾分佈（Gumbel distribution），這個分佈也描述了許多隨機量之中最大的一個（第 12.25 節）。

無處不在的集券問題

這個問題可追溯至棣莫弗（Abraham de Moivre，1712 年）和拉普拉斯（Laplace）。如今它以許多不同的面貌出現。要檢查一個系統的每個組件，需要做多少次隨機測試？在一個網絡上進行隨機漫步（random walk），要多久才會走遍每個節點？電腦的雜湊表（hash table）要探查多少次？每一種情況的答案都涉及 \(n\ln n\)。在生物學中，同樣的計算可用來估計要有多少個定序「讀段」（reads）才能覆蓋整個基因組。

思維技巧

期望值的線性性質（linearity of expectation）

和的期望值等於期望值之和，不論各部分是否獨立。把一個複雜的隨機量拆成簡單的部分。

這是概率論中最有用的事實之一。在這裏，它把集券問題簡化為 \(n\) 段幾何等候；在 第 9.8 節 中，它不用任何計算就給出了配對數目的期望值。到了大學，同一個想法推動着演算法分析，以及組合數學中的概率方法（probabilistic method）。

延伸練習

  1. 半套。證明集齊 \(\frac n2\) 張不同的卡（\(n\) 為偶數）所需包數的期望值是 \(n(H_n - H_{n/2})\)，並且這個值約為 \(n\ln 2\)。

  2. 不同的卡。證明開了 \(k\) 包之後，你手上不同的卡的數目的期望值是 \(n\bigl(1 - (1 - \frac1n)^k\bigr)\)。（提示：對每一張卡，求出你擁有它的概率，然後相加。）大約要開多少包，才能得到全套的 \(95\%\)？

  3. 兩位收藏者。兩個小孩收集同一套卡，並共用所開的各包，因此對其中一人來說是重複的卡，對另一人來說可能是新的。證明集齊兩套所需包數的期望值約為 \(n(\ln n + \ln\ln n)\)。（這題較難；先說服自己這個數目遠小於 \(2n\ln n\)。）

  4. 更精確的界。改用梯形法則（trapezium rule）的圖像而不用長方形，證明 \(H_n - \ln n\) 是遞減的，而 \(H_n - \ln n - \frac{1}{2n}\) 是遞增的。由較小的 \(n\) 值推導出 \(0.5 < \gamma < 0.7\)。

延伸閱讀

  • Julian Havil, Gamma: Exploring Euler’s Constant（Princeton University Press）。關於 \(\gamma\) 和調和級數的一切，寫得深入淺出。

  • Michael Mitzenmacher & Eli Upfal, Probability and Computing（Cambridge University Press）。集券問題及其在電腦科學中的應用。
