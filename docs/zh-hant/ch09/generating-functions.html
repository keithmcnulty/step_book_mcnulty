9.4

把數列看成函數

工作紙題目連結、提示、大學數學及練習 第 9 章整章的 PDF 版本
題目

STEP I 2016，第 8 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/16-s1-q8

引子

用計算機算一算 \(1/89\)：\(0.011235955\ldots\)。開首的數字是 \(0, 1, 1, 2, 3, 5\)，正是斐波那契數（Fibonacci numbers）。這是巧合嗎？不是，而這道題目正好解釋了原因。

這個想法是組合數學（combinatorics）中最強大的想法之一。取一個無窮數列，把各項用作冪級數（power series）的係數，從而把整個數列包裝成單一個函數。這樣，關於數列的事實就變成關於函數的事實，你便可以用代數和微積分來處理。Herbert Wilf 有一句令人難忘的話：「生成函數（generating function）是一條晾衣繩，我們把一列數字掛在上面展示。」

動筆之前

哪個數列的生成函數是 \(\dfrac{1}{1 - x}\)？\(\dfrac{1}{1 - 2x}\) 又如何？如果把一個數列的生成函數乘以 \(x\)，數列會有甚麼變化？

等比級數（geometric series）\(\frac{1}{1 - x} = 1 + x + x^2 + \cdots\) 是 \(1, 1, 1, \ldots\) 的生成函數，而 \(\frac{1}{1 - 2x} = 1 + 2x + 4x^2 + \cdots\) 則是 \(2\) 的各次冪的生成函數。乘以 \(x\) 會把每一項向後移一位：\(x \cdot \frac{1}{1-x} = x + x^2 + \cdots\) 對應的數列是 \(0, 1, 1, 1, \ldots\)。

逐步解題

階段 1 自然數與三角形數

用二項級數（binomial series）展開 \((1 - x)^{-2}\)。\(x^n\) 的係數是甚麼？

由二項級數可得 \[(1 - x)^{-2} = 1 + 2x + 3x^2 + 4x^3 + \cdots = \sum_{n \geq 0}(n + 1)x^n,\] 所以 \(x(1 - x)^{-2} = x + 2x^2 + 3x^3 + \cdots = \sum n x^n\)：這就是 \(u_n = n\) 的生成函數。

同樣地，\((1 - x)^{-3}\) 中 \(x^n\) 的係數是 \(\frac{(-3)(-4)\cdots(-3-n+1)}{n!}(-1)^n = \frac{(n + 1)(n + 2)}{2}\)，所以 \[x(1 - x)^{-3} = \sum_{n \geq 1}\frac{n(n + 1)}{2}\,x^n = x + 3x^2 + 6x^3 + 10x^4 + \cdots,\] 這就是三角形數（triangle numbers）\(u_n = \frac12 n(n + 1)\) 的生成函數。

怎樣用 \(n\) 和 \(\frac12n(n + 1)\) 來表示 \(n^2\)？

由於 \(n^2 = 2 \cdot \frac12 n(n + 1) - n\)，而生成函數可以像數列一樣相加， \[\sum n^2 x^n = \frac{2x}{(1 - x)^3} - \frac{x}{(1 - x)^2} = \frac{2x - x(1 - x)}{(1 - x)^3} = \frac{x(1 + x)}{(1 - x)^3}. \qed\]

階段 2 遞推關係變成方程

把 \(u_n = ku_{n-1}\) 乘以 \(x^n\)，然後對所有 \(n \geq 1\) 求和。兩邊用 \(\mathrm{f}\) 表示，分別是甚麼？

左邊是 \(\sum_{n \geq 1}u_nx^n = \mathrm{f}(x) - u_0 = \mathrm{f}(x) - a\)。右邊是 \(kx\sum_{n \geq 1}u_{n-1}x^{n-1} = kx\,\mathrm{f}(x)\)。所以 \(\mathrm{f}(x) = a + kx\,\mathrm{f}(x)\)，於是 \[\mathrm{f}(x) = \frac{a}{1 - kx}. \qed\] 當然，\(u_n = ak^n\)；把 \(\frac{a}{1 - kx}\) 展開成等比級數，便可確認這一點。

階段 3 斐波那契數

對 \(u_n = u_{n-1} + u_{n-2}\)（其中 \(n \geq 2\)）作同樣的處理： \[\sum_{n \geq 2}u_nx^n = x\sum_{n \geq 2}u_{n-1}x^{n-1} + x^2\sum_{n \geq 2}u_{n-2}x^{n-2},\] 即 \[\mathrm{f}(x) - u_0 - u_1x = x\bigl(\mathrm{f}(x) - u_0\bigr) + x^2\,\mathrm{f}(x).\] 代入 \(u_0 = 0\) 和 \(u_1 = 1\)，上式即 \(\mathrm{f}(x) - x = x\,\mathrm{f}(x) + x^2\,\mathrm{f}(x)\)，所以 \[\mathrm{f}(x) = \frac{x}{1 - x - x^2}. \qed\]

階段 4 解釋 \(1/89\)

暫且不理收斂（convergence）的問題（這裏沒有問題：級數在 \(|x| < 0.618\) 時收斂），把 \(x = \frac{1}{10}\) 代入 \(\mathrm{f}\)。你得到甚麼？

\[\frac{1}{10}F_1 + \frac{1}{100}F_2 + \frac{1}{1000}F_3 + \cdots = \mathrm{f}\Bigl(\frac{1}{10}\Bigr) = \frac{1/10}{1 - 1/10 - 1/100} = \frac{10}{89}.\] 除以 \(10\)，得 \(\frac{1}{89} = \sum F_n/10^{n+1}\)。斐波那契數依次放在相繼的小數位上，當它們大於 \(9\) 時便會互相重疊（圖 9.4.1）。\(1/89\) 開首的數字顯示出斐波那契數；其後的數字則因進位而變得模糊。

回顧

  • 把數列變成函數。整個無窮數列變成了一個有理函數（rational function）。

  • 遞推關係變成方程。乘以 \(x^n\) 再求和，便把規則 \(u_n = u_{n-1} + u_{n-2}\) 變成一條關於 \(\mathrm{f}\) 的方程，可以用代數方法解出。

  • 從舊的造出新的。把生成函數相加、平移和求導，便能得出新的生成函數，無須從頭做起。

背後的數學

從生成函數到公式

生成函數不只是把數列編碼：它還可以把數列解出來。分母可以因式分解為 \(1 - x - x^2 = (1 - \varphi x)(1 - \psi x)\)，其中 \(\varphi = \frac{1 + \sqrt5}{2}\) 和 \(\psi = \frac{1 - \sqrt5}{2}\) 是 \(t^2 = t + 1\) 的根。由部分分式（partial fractions）可得 \[\frac{x}{1 - x - x^2} = \frac{1}{\sqrt5}\Bigl(\frac{1}{1 - \varphi x} - \frac{1}{1 - \psi x}\Bigr),\] 再把每個分式展開成等比級數， \[F_n = \frac{\varphi^n - \psi^n}{\sqrt5}.\] 這就是比內公式（Binet’s formula）。由於 \(|\psi| < 1\)，第二項非常小，所以 \(F_n\) 是最接近 \(\varphi^n/\sqrt5\) 的整數，而相鄰兩個斐波那契數之比趨向黃金比（golden ratio）（這是 第 2.2 節 的主題）。同一方法可以解任何常係數線性遞推關係（linear recurrence with constant coefficients）；練習中有一個來自 STEP I 2004 的例子。

生成函數為何如此有用

真正的威力在相乘時才顯現出來。乘積 \(\mathrm{f}(x)\mathrm{g}(x)\) 中 \(x^n\) 的係數是 \(\sum_k u_kv_{n-k}\)，即對所有把 \(n\) 拆成兩部分的方法求和。要數算由兩個部分組成的東西，這正是我們所需要的。接下來的兩節會用它來數算找換零錢的方法（第 9.5 節），以及找出點數古怪、但總和的分佈與普通骰子相同的骰子（第 9.6 節）。在概率中，同一想法給出概率生成函數（probability generating function），它把獨立隨機變量之和變成乘積。

棣莫弗、歐拉與拉普拉斯

棣莫弗（Abraham de Moivre）在 1720 年代用生成函數來解線性遞推關係，所用的方法基本上就是上面的方法。歐拉（Leonhard Euler）在 1748 年用它們來研究整數的分拆（partitions），而拉普拉斯（Pierre-Simon Laplace）則以它們作為其著作 Théorie analytique des probabilités（1812）的基礎。到了二十世紀，生成函數成為組合數學的核心，而解析方法（把生成函數看成複變數的函數來研究）如今能為複雜得無法精確求解的計數問題給出精確的估計。

思維技巧

轉換表示方式

一個關於數列的問題，在把數列變成函數、矩陣或圖形之後，可能會變得容易。

生成函數把遞推關係翻譯成代數，把計數翻譯成乘法。在大學裏你會遇到許多這類翻譯：傅立葉級數（Fourier series）把函數變成數列，拉普拉斯變換（Laplace transforms）把微分方程變成代數，而矩陣則把幾何變成算術。

延伸練習

  1. 每次兩位數字。試做 STEP II 2022，第 3 題 （載於 OCR 提供下載的 2022 年試卷 zip 檔案內）。它解釋了為何 \(\frac{1}{89}\) 的小數展開式以斐波那契數開首，並要求找出一個分數，其小數每次兩位數字地顯示這個規律。

  2. 解遞推關係。試做 STEP I 2004，第 7 題。它用生成函數和部分分式解一個線性遞推關係，然後把這個方法倒過來做。

  3. 逐一數數。證明 \(\frac{1}{9801} = 0.00\,01\,02\,03\,04\ldots\)，其中每兩位數字為一組，逐一向上數。這個規律最先在哪裏出錯？為甚麼？

  4. 平方和。解釋為何 \(\frac{1}{1-x}\mathrm{f}(x)\) 是部分和 \(u_0 + u_1 + \cdots + u_n\) 的生成函數。利用這一點和第 (i) 部分的答案，求 \(1^2 + 2^2 + \cdots + n^2\) 的公式。
