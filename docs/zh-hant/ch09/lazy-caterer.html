直線分割平面

STEP II 1990，第 4 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/90-s2-q4

引子

用 \(n\) 刀直線把一個薄餅切開，各塊不必大小相同，最多可以切成多少塊？一刀得 \(2\) 塊，兩刀得 \(4\) 塊，三刀得 \(7\) 塊（不是 \(8\) 塊：不妨試試），四刀得 \(11\) 塊。數列 \(1, 2, 4, 7, 11, 16, \ldots\) 稱為懶惰宴會承辦人數列（lazy caterer’s sequence），而本題要求的正是它的公式。

這道題是一種貫穿整個組合數學（combinatorics）的技巧的第一課：不要試圖一次過把所有東西數完，而應該問：多加一個對象時，有甚麼改變？而答案原來是歐拉公式（Euler’s formula）\(V - E + F = 2\) 的一個特殊情況，你在 第 7.9 節 討論柏拉圖立體時已經見過這條公式。

動筆之前

仔細畫出 \(n = 1, 2, 3, 4\) 的情況，並保持各直線處於一般位置（general position）（沒有兩條平行，沒有三條共點）。數一數每種情況中線段和區域的數目。你能猜出當中的規律嗎？

你應該會得到：

\(n\) \(0\) \(1\) \(2\) \(3\) \(4\)
線段 \(0\) \(1\) \(4\) \(9\) \(16\)
區域 \(1\) \(2\) \(4\) \(7\) \(11\)

線段的數目看來是 \(n^2\)。區域的數目則依次增加 \(1, 2, 3, 4\)：相鄰兩項之差正是自然數。

逐步解題

階段 1 數線段

集中看其中一條直線。其餘的直線中有多少條與它相交？它們把這條直線切成多少段？

每條直線都與其餘 \(n - 1\) 條直線逐一相交（沒有一條與它平行），而且交於 \(n - 1\) 個不同的點（沒有三條直線交於同一點）。這 \(n - 1\) 個點把該直線切成 \(n\) 段：兩端各有一段無限長的，中間有 \(n - 2\) 段有限長的。共有 \(n\) 條直線，所以共有 \[n \times n = n^2 \text{ 條線段}. \qed\] 這是直接點算，無需使用歸納法（induction）：我們是逐條直線去數線段的。

階段 2 加一條直線時會怎樣？

假設已畫好 \(n - 1\) 條直線，現在加上第 \(n\) 條。它被其餘直線切成 \(n\) 段。每一段對它所穿過的區域有甚麼影響？

畫出新直線時，它的 \(n\) 段各自穿過一個原有的區域，並把該區域一分為二（圖 9.1.1）。不同的線段位於不同的區域內，因為新直線要由一個區域走到另一個區域，就必須越過一條原有的直線。因此，加上第 \(n\) 條直線後，區域的數目恰好增加 \(n\)： \[R(n) = R(n - 1) + n.\]

階段 3 解遞歸關係

由 \(R(0) = 1\)（沒有直線，只有一個區域）開始， \[R(n) = 1 + (1 + 2 + \cdots + n) = 1 + \frac{n(n + 1)}{2} = \frac{n^2 + n + 2}{2}.\] 若要寫成歸納法證明：公式對 \(n = 1\) 成立，因為 \(\frac12(1 + 1 + 2) = 2\)；而若 \(R(n - 1) = \frac12\bigl((n - 1)^2 + (n - 1) + 2\bigr) = \frac12(n^2 - n + 2)\)，則 \(R(n) = \frac12(n^2 - n + 2) + n = \frac12(n^2 + n + 2)\)。■

回顧

  • 每次只數一部分。線段是逐條直線去數的；區域則是按每條新直線所增加的數目去數的。

  • 把幾何上的一步化為遞歸關係。「每條新線段把一個區域一分為二」這項觀察，化成了 \(R(n) = R(n - 1) + n\)。

  • 一般位置十分重要。若有平行的直線，或有三條直線共點，區域的數目就會較少。試找出每項假設在哪裏用過。

背後的數學

喬裝的歐拉公式

以下是第二個證明，它不僅推導出答案，更解釋了答案從何而來。把這些直線組成的圖形看成一幅地圖：交點是頂點（vertices），線段是邊（edges），區域是面（faces）。圖中有 \(V = \binom{n}{2}\) 個頂點（每一對直線對應一個）和 \(E = n^2\) 條邊。無限長的線段只有一個端點，所以我們額外加上一個「在無窮遠處」的頂點，讓它們全部在那裏相遇；這樣，整幅圖就成為畫在球面上的地圖（想像把平面包在一個球上，無窮遠點位於球頂）。由 第 7.9 節 的歐拉公式 \(V - E + F = 2\) 可得 \[\Bigl(\binom{n}{2} + 1\Bigr) - n^2 + F = 2, \qquad\text{所以}\qquad F = n^2 - \frac{n(n - 1)}{2} + 1 = \frac{n^2 + n + 2}{2}.\] 同一個數，卻來自完全不同的方向。這些區域還可以整齊地分成兩類：其中 \(2n\) 個是無界的（每兩條相鄰的無限射線之間有一個），其餘 \(\frac12(n^2 + n + 2) - 2n = \binom{n - 1}{2}\) 個是有界的。

二項式係數與高維空間

這條公式可以寫成 \[R(n) = \binom{n}{0} + \binom{n}{1} + \binom{n}{2},\] 而這並非巧合。把圖形轉動，使得沒有一條直線是水平的。一個下方有界的區域必有一個最低點，而這個點必定是交點；每個交點又恰好是一個區域（即它正上方的那個）的最低點：這樣就得到 \(\binom{n}{2}\) 個區域，每一對直線對應一個。其餘每個區域都向下無限延伸，因而會與一條畫在所有交點下方很遠處的水平線相遇；那 \(n\) 條直線把這條水平線切成 \(n + 1\) 個區間，每個這樣的區域內各有一個。合共 \(\binom{n}{2} + n + 1\) 個。在三維空間中，\(n\) 個處於一般位置的平面把空間切成 \[\binom{n}{0} + \binom{n}{1} + \binom{n}{2} + \binom{n}{3} = \frac{n^3 + 5n + 6}{6}\] 塊（即蛋糕數（cake numbers）\(1, 2, 4, 8, 15, 26, \ldots\)），而這個規律在任何維數都成立。證明用的是同一個歸納法：新加的平面被其餘平面切成若干區域，其排列方式就如平面上的直線所分成的區域，而每個這樣的區域都把一塊空間一分為二。

施泰納與超平面排列

直線和平面所分割出的區域數目的公式，是施泰納（Jakob Steiner）在 1826 年發現的。今天，它是超平面排列（hyperplane arrangements）理論的起點；這套理論點算任意一組直線、平面及其高維類比所形成的區域數目，包括並非處於一般位置的情況。Thomas Zaslavsky 在 1975 年證明了一條非凡的定理：利用一個記錄了哪些超平面相交的多項式，就可以數出任何排列的區域數目。同樣的想法也出現在機器學習之中：由「ReLU」單元構成的神經網絡，會用超平面把輸入空間切成多個區域，而區域的數目正好衡量它所能表示的函數有多複雜。

思維技巧

問一問：多加一個時，有甚麼改變

要點算由 \(n\) 個對象組成的構形，可把它與 \(n - 1\) 個對象的構形比較。點算其中的改變，往往比點算整體容易得多。

這是把歸納法用作發現的工具，而不僅是證明的工具。它是組合數學中最常見的手法之一，能把幾何問題化為可以求解的遞歸關係（recurrence relation）。

延伸練習

  1. 圓。證明：若 \(n\) 個圓中每兩個都交於兩點，且沒有三個圓共點，則它們把平面分成 \(n^2 - n + 2\) 個區域。

  2. 平行線。若 \(n\) 條直線中有 \(k\) 條互相平行（其餘方面均處於一般位置），共有多少個區域？

  3. 蛋糕數。用歸納法證明：\(n\) 個處於一般位置的平面把空間分成 \(\frac16(n^3 + 5n + 6)\) 個區域。

  4. 會失效的規律。在圓周上取 \(n\) 個點，並把每一對點用弦連起來，其中沒有三條弦在圓內交於同一點。當 \(n = 1, 2, 3, 4, 5\) 時，分別得到 \(1, 2, 4, 8, 16\) 個區域。數一數 \(n = 6\) 時的區域數目。（提示：使用歐拉公式；每四個點給出一個交點。）證明區域的數目是 \(1 + \binom{n}{2} + \binom{n}{4}\)。

延伸閱讀

  • Ronald Graham, Donald Knuth & Oren Patashnik, Concrete Mathematics（Addison-Wesley），第 1 章。開首討論的正是這個問題，還有「薄餅」和「之字形」的變化題。

  • Miklós Bóna, A Walk Through Combinatorics（World Scientific）。一本平易近人的入門教材，設有歸納法、圖和歐拉公式等章節。

  • Richard Guy, “The strong law of small numbers”，American Mathematical Monthly 95 (1988)。收錄了許多看似明顯、其實不成立的規律，包括練習中的圓問題。
