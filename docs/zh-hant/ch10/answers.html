第 10 章 · 守恆定律、碰撞與引力

延伸練習答案

以下只是簡短的答案和提示，並非完整解答：只列出結果和關鍵步驟，方便你核對自己的做法。每道練習請先認真做過，然後才看答案。

10.1 牛頓擺

  1. 所有碰撞（collision）結束後，運動中的質點後面不可能跟着一個較慢的質點。因此，若恰好只有一個質點在動，它必定是 \(A_n\)，而 \(\lambda mv = mu\)、\(\lambda mv^2 = mu^2\) 在 \(\lambda \neq 1\) 時互相矛盾。若只有 \(A_{n-1}\) 和 \(A_n\) 在動，則方程與質量為 \(m\) 和 \(\lambda m\) 的兩個質點相碰時的方程相同，得出 \(A_{n-1}\) 的速度為 \(\frac{1 - \lambda}{1 + \lambda}u < 0\)；但這樣它便會撞上 \(A_{n-2}\)。有三個質點在動的情況，可完全仿照第 (ii) 部分排除。在動的兩個質點是 \(A_0\)（以 \(\frac{\lambda - 1}{\lambda + 1}u\) 向後運動）和 \(A_n\)（以 \(\frac{2u}{\lambda + 1}\) 向前運動）。

  2. 質量相等的彈珠相碰時會交換速度，所以速率 \(u\) 一直傳到 \(A_n\)。之後 \(A_n\) 撞上 \(A_{n+1}\)：\(A_{n+1}\) 以 \(\frac{2u}{1 + \lambda}\) 離開，而 \(A_n\) 則以 \(\frac{\lambda - 1}{\lambda + 1}u\) 反彈。這個向後的速度沿着整列彈珠傳回 \(A_0\)，使它以該速率向後離開。

  3. 「兩球以 \(u\) 彈出」所帶的動量（momentum）是 \(2mu\)，能量是 \(mu^2\)，與碰撞前相同。另一個解（之後不再有碰撞）是：最後三個球分別以 \(\frac u3\)、\(\frac u3\) 和 \(\frac{4u}{3}\) 離開（驗算：總和為 \(2u\)，平方和為 \(2u^2\)）。真實的牛頓擺選擇第一個解，是因為各球之間並非完全貼緊，所以碰撞是一對一對地先後發生的。

  4. 速率一直傳到 \(A_n\)，它再撞上較輕的 \(A_{n+1}\)：\(A_{n+1}\) 以 \(\frac{2u}{1 + \lambda}\) 離開，而 \(A_n\) 則以較慢的 \(\frac{1 - \lambda}{1 + \lambda}u\) 跟在後面。其餘質點全都不動。

10.2 疊球效應

  1. 球以 \(U = \sqrt{2gH}\) 到達地面，再以 \(eU\) 反彈，上升 \(e^2H\)。把小球放在上面時：大球以 \(eU\) 向上運動，遇上以 \(U\) 向下運動的小球。由動量守恆和恢復係數（restitution）的關係，可得小球向上的速率為 \(w = U\frac{Me(2 + e) - m}{M + m}\)。小球球心由 \(2R + r = 0.45\) 出發，升至 \(4.5\)，所以 \(\frac{w^2}{2g} = 4.05\)，而 \(\frac wU = \sqrt{\frac{4.05}{1.8}} = 1.5\)。代入 \(e = \frac23\)，得 \(\frac{16}{9}M - m = 1.5(M + m)\)，於是 \(M = 9m\)。

  2. 由動量守恆和恢復係數的關係，\(P_1\) 的速率為 \(\frac{1 + e}{1 + \lambda}u\)；每次碰撞的質量比都相同，情況重複出現，所以 \(P_n\) 以 \(\bigl(\frac{1 + e}{1 + \lambda}\bigr)^nu\) 運動。速率為 \(s\) 的質點撞上下一個質點後，餘下的速率為 \(\frac{1 - \lambda e}{1 + \lambda}s\)，而下一個質點經過自己的下一次碰撞後，速率減至 \(\frac{(1 + e)(1 - \lambda e)}{(1 + \lambda)^2}s\)。當 \(\lambda e < 1\) 時，前者只有在 \(\frac{1 - \lambda e}{1 + \lambda} > \frac{(1 + e)(1 - \lambda e)}{(1 + \lambda)^2}\) 時才會再次追上後者，即 \(\lambda > e\)；所以若 \(e > \lambda\)，每個質點只會被撞一次，也只會撞別的質點一次。若 \(\lambda e = 1\)，每個質點撞上下一個之後便立即停下。

  3. 最底的球以 \(U\) 反彈，遇上中間的球（正以 \(U\) 向下運動）：相對速率為 \(2U\)，所以中間的球以 \(3U\) 離開。最上面的球與它相遇時相對速率為 \(4U\)，於是以 \(7U\) 離開，上升 \(49H\)。一般而言 \(u_{j+1} = 2u_j + U\)，所以 \(u_j + U = 2^jU\)。

  4. 彈性碰撞（elastic collision）中動能（kinetic energy）守恆。\(A\) 的能量是 \(\frac12m\bigl(\frac{2\lambda}{1 + \lambda}\bigr)^{2n}u^2\)，而最初的能量是 \(\frac12\lambda^nmu^2\)，又因 \(\frac{4\lambda}{(1 + \lambda)^2} < 1\)，所以 \(A\) 得到的能量永遠不會多於原有的總能量。較重的質點繼續向前運動，各自保留原來速率的 \(\frac{\lambda - 1}{\lambda + 1}\) 倍，餘下的能量便留在它們身上。

10.3 火箭與槍炮

  1. 一次過全部發射：\(Mu = nm(v - u)\)，所以 \(u = \frac{nmv}{M + nm}\)。逐個發射：第 \(r\) 次發射給出 \(\bigl(M + (n - r + 1)m\bigr)(u_r - u_{r-1}) = mv\)，所以 \(u_n = \sum_{j=1}^n\frac{mv}{M + jm}\)，而除最後一項外，每一項都大於 \(\frac{mv}{M + nm}\)。因此 \(u_n > u\)。

  2. 動量：\(M(1 + bx)v = MV\)。於是 \((1 + bx)\frac{\mathrm{d}x}{\mathrm{d}t} = V\)，所以 \(x + \frac12bx^2 = Vt\)，而 \(x = \frac{\sqrt{1 + 2bVt} - 1}{b}\)。有外力時，\(\frac{\mathrm{d}}{\mathrm{d}t}\bigl(M(1 + bx)v\bigr) = Mf\) 給出 \((1 + bx)v = ft + V\)。若速率為常數 \(c\)，則須有 \(x = ct\) 及 \((1 + bct)c = ft + V\)，所以 \(c = V\) 且 \(bV^2 = f\)。否則 \(x + \frac12bx^2 = \frac12ft^2 + Vt\)，所以 \(x \sim t\sqrt{f/b}\)，而 \(v \to \sqrt{f/b}\)。

  3. 單級：\(v\ln10 \approx 2.30v\)。兩級：\(v\ln\frac{10}{5.5} + v\ln\frac{5}{0.5} \approx 0.60v + 2.30v = 2.90v\)。

  4. 當 \(0 \leq s \leq x\) 時，\(\frac{1}{1 + x} \leq \frac{1}{1 + s} \leq 1\)；在 \([0, x]\) 上積分即可。

10.4 一個分子與一個活塞

  1. 這個遞推關係（recurrence）逐項相消後得 \(d_n = \frac{(v + u)d_1}{v + (2n - 1)u}\)，所以 \(v_nd_n = \frac{(v + 2nu)(v + u)d_1}{v + (2n - 1)u}\)，它比 \((v + u)d_1\) 大 \(\frac{u(v + u)d_1}{v + (2n - 1)u} \to 0\)。

  2. 把 \(u\) 換成 \(-u\)：每次從後退中的活塞反彈，速率都減少 \(2u\)，所以 \(v_n = v - 2nu\)（只要質點仍能追上活塞），\(d_n = \frac{(v - u)d_1}{v - (2n - 1)u}\)，而 \(v_nd_n = \frac{(v - 2nu)(v - u)d_1}{v - (2n - 1)u}\)，同樣接近 \((v - u)d_1\)。

  3. 當 \(v = u\) 時，\(v_n = (2n + 1)u\)。第 \(n\) 次碰撞時動量的改變量為 \(m(v_{n-1} + v_n) = 4nmu\)，而 \(t_n = \frac{d_1}{un(n + 1)}\)，所以平均力為 \(\frac{4mu^2n^2(n + 1)}{d_1}\)，量級為 \(n^3\)。每個循環所作的功約為力 \(\times\ ut_n\)，大約是 \(4nmu^2\)，這些功加起來是無窮大：要把活塞完全推到底，需要無窮多的功，正如分子的能量 \(\frac12m(2n + 1)^2u^2\) 會無止境地增長一樣。

  4. 不變量（invariant）是 \(\oint p\,\mathrm{d}q = 2\int_0^h m\sqrt{2g(h - z)}\,\mathrm{d}z \propto h^{3/2}\)，其中 \(h\) 是彈跳離地板的高度。所以當地板緩慢上升時，\(h^{3/2}\)（等價地說，即 \(v^3\)，或能量乘以週期）幾乎保持不變。

10.5 有限時間內的無限次反彈

  1. 由正弦定理（sine rule），\(M_1N_1 = \frac{OM_1\sin30^\circ}{\sin\theta}\)，而相繼各段路程按比率 \(\rho = \frac{\sin(\theta - 30^\circ)}{\sin\theta} < 1\) 縮短。總和為 \(\frac{M_1N_1}{1 - \rho} = \frac{OM_1}{2\bigl(\sin\theta - \sin(\theta - 30^\circ)\bigr)} = \frac{OM_1}{4\sin15^\circ\cos(\theta - 15^\circ)}\)。

  2. 由三角形 \(OM_1N_1\) 的各角可得 \(\varphi = \theta - \alpha\)。時間之比為 \(\frac{\rho}{k} = \frac{\sin(\theta - \alpha)\cos(\theta - \alpha)}{\sin\theta\cos\theta} = \frac{\sin(2\theta - 2\alpha)}{\sin2\theta}\)，它小於 \(1\) 當且僅當 \(\alpha < \theta < 45^\circ + \frac12\alpha\)。

  3. 把楔形沿它的壁反射，可將路徑展開成一條直線。圍繞 \(O\) 剛好可放十二個楔形，而一條不通過 \(O\) 的直線最多穿過其中六個。所以質點只會反彈有限次，然後逃離，除非它正對着 \(O\) 射去。

  4. 它首先下落 \(t_0 = \sqrt{2/9.8} \approx 0.452\) s。每次彈跳歷時 \(2e^kt_0\)，所以總時間為 \(t_0\bigl(1 + \frac{2e}{1 - e}\bigr) = 9t_0 \approx 4.07\) s。總路程為 \(1 + 2\sum_{k \geq 1}e^{2k} = 1 + \frac{2(0.64)}{0.36} \approx 4.56\) m。

10.6 二體化為一體

  1. 繩子保持拉緊，相對速度與繩子垂直，大小恆為 \(u\)，所以 \(\theta = \frac{ut}{r}\)。由動量可得 \(my + MY = mut\)。利用 \(A = G - \frac{M}{m + M}\overrightarrow{AB}\) 和 \(\overrightarrow{AB} = r(\cos\theta, -\sin\theta)\)，得 \(y = \frac{1}{m + M}\bigl(mut + Mr\sin\frac{ut}{r}\bigr)\)。於是 \(\dot y = \frac{u}{m + M}\bigl(m + M\cos\frac{ut}{r}\bigr)\)，它在 \(\cos\frac{ut}{r} < -\frac mM\) 時為負，而這在 \(M > m\) 時才有可能。

  2. 現在 \(\ddot z = -\frac{3}{z^3}\)，所以 \(\dot z^2 = \frac{3}{z^2} - 2\)（利用 \(z = 1\)、\(\dot z = -1\)）。設 \(w = z^2\)，則 \(\ddot w = 2\dot z^2 + 2z\ddot z = -4\)，所以 \(z^2 = 1 - 2t - 2t^2\)。兩者在 \(t = \frac{\sqrt3 - 1}{2} \approx 0.366\) 時相撞。

  3. \(z^2 = 4t^2 - 2t + 1 = |\mathbf{p} + \mathbf{q}t|^2\)，其中 \(\mathbf{p} = (1, 0)\)，\(\mathbf{q} = (-1, \sqrt3)\)：這是通過 \((1, 0)\)、方向為 \((-1, \sqrt3)\) 的直線，而 \(\theta = \tan^{-1}\frac{\sqrt3t}{1 - t}\)。於是 \(z^2\dot\theta = |\mathbf{p} \times \mathbf{q}| = \sqrt3\)。這個斥力正好就是平面上自由運動的「離心」項 \(\frac{h^2}{z^3}\)，其角動量（angular momentum）為 \(h = \sqrt3\)。

  4. 兩顆星與質心（centre of mass）的距離分別為 \(\frac{m_2a}{m_1 + m_2}\) 和 \(\frac{m_1a}{m_1 + m_2}\)。對第一顆星，\(\frac{Gm_1m_2}{a^2} = m_1\omega^2\frac{m_2a}{m_1 + m_2}\)，所以 \(\omega^2 = \frac{G(m_1 + m_2)}{a^3}\)，而 \(T = \frac{2\pi}{\omega}\)。

10.7 球殼內的引力

  1. 在球殼外（\(b > a\)），與第 3 階段相同的積分改為對 \(s\) 由 \(b - a\) 積至 \(b + a\)，結果是 \(\frac{GM}{b^2}\)。實心球是多個同心球殼的併集，每個球殼的作用都如同其質量集中於球心。

  2. 設 \(r = R\cos^2\alpha\)，則 \(\frac1r - \frac1R = \frac{\tan^2\alpha}{R}\)，所以速率為 \(\sqrt{2GM/R}\tan\alpha\)。於是 \(\mathrm{d}t = \frac{2R\sin\alpha\cos\alpha\,\mathrm{d}\alpha}{\sqrt{2GM/R}\tan\alpha} = \sqrt{\frac{R^3}{2GM}}\,2\cos^2\alpha\,\mathrm{d}\alpha\)；再積分即可。

  3. 根據球殼定理（shell theorem），只有半徑 \(b\) 以內的質量（即 \(M\frac{b^3}{a^3}\)）產生引力，結果是 \(\frac{GMb}{a^3}\)。這是簡諧運動（simple harmonic motion），其中 \(\omega^2 = \frac{GM}{a^3}\)，週期為 \(2\pi\sqrt{a^3/GM} \approx 84\) 分鐘，這裏取 \(a = 6.37 \times 10^6\) m 及 \(GM = 3.99 \times 10^{14}\) m\(^3\) s\(^{-2}\)。在半徑 \(a\) 處運行的衛星滿足 \(\omega^2a = \frac{GM}{a^2}\)：\(\omega\) 相同。

  4. 不會。換成 \(\frac{1}{s^3}\) 後，被積函數不再化簡為常數，球殼較近的一側佔了上風：質點會被拉向球殼最近的部分。只有平方反比定律（inverse-square law）才會完全抵消（球殼上一小塊的面積按 \(s^2\) 增長，剛好抵消引力的減弱）。

10.8 排成三角形的三顆恆星

  1. 每顆星與中心的距離為 \(\frac{a}{\sqrt2}\)。相鄰兩顆星的引力指向中心的分量合共為 \(\frac{2\gamma m^2}{a^2}\cos45^\circ = \frac{\sqrt2\gamma m^2}{a^2}\)，而對面那顆星的引力為 \(\frac{\gamma m^2}{2a^2}\)。令 \(\frac{\gamma m^2}{a^2}\bigl(\sqrt2 + \frac12\bigr) = m\omega^2\frac{a}{\sqrt2}\)，得 \(\omega^2 = \frac{(4 + \sqrt2)\gamma m}{2a^3}\)。

  2. 在中心處各引力互相抵消，所以行星處於平衡（equilibrium）。沿着兩顆星的連線方向，平衡是不穩定的：向其中一顆星移動距離 \(x\)，便會受到約為 \(\frac{32\gamma Mx}{a^3}\) 的向外淨力。在垂直於軌道平面的方向，平衡是穩定的，回復力約為 \(\frac{16\gamma Mz}{a^3}\)。（在軌道平面內垂直於連線的方向，引力有回復作用，但旋轉會把這個方向的運動與不穩定的方向耦合起來。）

  3. 作用於 \(m_1\) 的力為 \(\frac{\gamma m_1}{a^3}\bigl(m_2(P_2 - P_1) + m_3(P_3 - P_1)\bigr)\)。由於 \(m_1P_1 + m_2P_2 + m_3P_3 = (m_1 + m_2 + m_3)G\)，這個力等於 \(\frac{\gamma m_1(m_1 + m_2 + m_3)}{a^3}(G - P_1)\)。每顆星都被拉向 \(G\)，引力與它跟 \(G\) 的距離成正比，而且比例常數相同，所以三顆星可以像剛體一樣一起旋轉，其中 \(\omega^2 = \frac{\gamma(m_1 + m_2 + m_3)}{a^3}\)。

  4. 相隔 \(k\) 個位置的那顆星，距離為 \(2R\sin\frac{k\pi}{n}\)，其引力指向中心的分量佔 \(\sin\frac{k\pi}{n}\)。所以 \(m\omega^2R = \frac{\gamma m^2}{4R^2}\sum_{k=1}^{n-1}\frac{1}{\sin(k\pi/n)}\)，得 \(\omega^2 = \frac{\gamma m}{4R^3}\sum_{k=1}^{n-1}\frac{1}{\sin(k\pi/n)}\)。當 \(n = 3\)、\(R = \frac{a}{\sqrt3}\) 時，結果是 \(\frac{3\gamma m}{a^3}\)。
