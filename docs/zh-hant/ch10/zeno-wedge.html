10.5

有限時間內的無限次反彈

工作紙題目連結、提示、大學數學及練習 第 10 章整章的 PDF 版本
題目

STEP III 2002，第 11 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/02-s3-q11

引子

埃利亞的芝諾（Zeno of Elea）曾經論證，你永遠走不到一堵牆：你必須先走完一半的距離，然後再走完餘下距離的一半，如此類推，永無止境。化解這個悖論的關鍵，在於無窮多步所需的總時間可以是有限的，也就是一個收斂（converge）的無窮級數（infinite series）。這道題目正是芝諾悖論（Zeno’s paradox）的真實版本：一個冰球滑進楔形的角落，在兩面牆之間反彈無窮多次，卻在有限時間內到達角落。

大自然也會這樣做。一個球在地板上彈跳，若恢復系數（coefficient of restitution）小於 \(1\)，它會在有限時間內彈跳無窮多次，然後靜止下來。在顆粒物質（沙、穀物、雪）的電腦模擬中，這種「非彈性坍縮」（inelastic collapse）是個實實在在的難題：電腦要在有限時間內處理無窮多次碰撞。

動筆之前

當一個質點（particle）以恢復系數 \(e\) 撞向一面光滑的牆時，速度沿牆方向的分量會怎樣？垂直於牆的分量又會怎樣？

光滑的牆不會沿着牆面施力，所以速度平行於牆的分量保持不變。垂直分量則會反向，並乘以 \(e\)。因此，若質點以與牆成 \(\alpha\) 的角度到達，並以 \(\beta\) 的角度離開，則 \[\tan\beta = e\tan\alpha,\] 而由於平行分量不變，（入射速率）\(\cos\alpha\) =（離開速率）\(\cos\beta\)。

逐步解題

階段 1 離開的角度

質點到達 \(M_1\) 時與牆 \(OA\) 成角 \(\theta\)（在遠離 \(O\) 的一側量度）。它離開時與 \(OA\) 所成的角 \(\varphi\) 是多少？利用三角形 \(OM_1N_1\)，以 \(\theta\) 表示 \(\varphi\)。

質點離開 \(M_1\) 時朝着 \(O\) 的一側前進，與牆成角 \(\varphi\)，所以角 \(OM_1N_1\) 等於 \(\varphi\)。在三角形 \(OM_1N_1\) 中，位於 \(O\) 的角是 \(30^\circ\)。在 \(N_1\)，角 \(M_1N_1B\) 等於 \(\theta\)，而 \(O\)、\(N_1\)、\(B\) 在同一直線上，所以角 \(ON_1M_1\) 等於 \(180^\circ - \theta\)。三角形的內角和為 \(180^\circ\)： \[30^\circ + \varphi + (180^\circ - \theta) = 180^\circ, \qquad\text{所以}\qquad \varphi = \theta - 30^\circ.\] （特別地，\(\theta > 30^\circ\)。）於是由恢復定律 \(\tan\varphi = e\tan\theta\) 可得 \[e = \frac{\tan(\theta - 30^\circ)}{\tan\theta},\] 而由平行分量守恆 \(u_1\cos\theta = v_1\cos\varphi\) 可得 \[\frac{v_1}{u_1} = \frac{\cos\theta}{\cos(\theta - 30^\circ)}. \qed\]

階段 2 規律重複出現

在 \(N_1\)，質點到達時與牆 \(OB\) 成角 \(\theta\)（在遠離 \(O\) 的一側量度）。把這個情況與它到達 \(M_1\) 時的情況比較一下。接下來會發生甚麼事？

\(N_1\) 的情況是 \(M_1\) 的情況的鏡像：質點以角 \(\theta\) 撞上一面牆，而這個角位於遠離 \(O\) 的一側。所以它以角 \(\theta - 30^\circ\) 離開，再以角 \(\theta\) 撞上 \(OA\)，如此類推，永無止境。每一次反彈都是第一次反彈按比例縮放後的複製品。三角形 \(OM_kN_k\)、\(ON_kM_{k+1}\)、… 每一個都與前一個相似（圖 10.5.1），而每次反彈時速率都乘以同一個因子。

階段 3 兩個比

由一次反彈到下一次反彈，與 \(O\) 的距離按甚麼因子 \(\rho\) 縮小？速率按甚麼因子 \(k\) 縮小？那麼每一段路程所需的時間又按甚麼因子縮小？

在三角形 \(OM_1N_1\) 中應用正弦定理（sine rule），可得 \[\rho = \frac{ON_1}{OM_1} = \frac{\sin\varphi}{\sin(180^\circ - \theta)} = \frac{\sin(\theta - 30^\circ)}{\sin\theta}.\] 下一個三角形的所有長度都是這個三角形的 \(\rho\) 倍，所以路徑的每一段都是前一段的 \(\rho\) 倍長。每次反彈時速率都乘以 \(k = \frac{\cos\theta}{\cos(\theta - 30^\circ)}\)。時間等於長度除以速率，所以每一段所需的時間是前一段的 \[\frac{\rho}{k} = \frac{\sin(\theta - 30^\circ)\cos(\theta - 30^\circ)}{\sin\theta\cos\theta} = \frac{\sin(2\theta - 60^\circ)}{\sin 2\theta}\] 倍。

階段 4 一個等比級數

總時間是 \(T_1(1 + r + r^2 + \cdots)\)，其中 \(T_1\) 是第一段所需的時間，而 \(r = \frac{\sin(2\theta - 60^\circ)}{\sin 2\theta}\)。這是一個等比級數（geometric series），若 \(0 < r < 1\)，總時間便是有限的。

\(\sin(2\theta - 60^\circ) < \sin 2\theta\) 在甚麼時候成立？利用恆等式 \(\sin X - \sin Y = 2\cos\tfrac12(X + Y)\sin\tfrac12(X - Y)\)。

\[\sin 2\theta - \sin(2\theta - 60^\circ) = 2\cos(2\theta - 30^\circ)\sin 30^\circ = \cos(2\theta - 30^\circ),\] 當 \(2\theta - 30^\circ < 90^\circ\)，即 \(\theta < 60^\circ\) 時，上式為正。另外，由於 \(\theta > 30^\circ\)，故 \(r > 0\)。所以當 \(30^\circ < \theta < 60^\circ\) 時，級數收斂：質點反彈無窮多次，它與 \(O\) 的距離每次按因子 \(\rho < 1\) 縮小，並在有限時間 \(\frac{T_1}{1 - r}\) 之後到達 \(O\)。■

回顧

  • 自相似性（self-similarity）。一旦弄清楚一次反彈，其後每一次反彈都只是按比例縮放的複製品，所以整個無窮過程就歸結為兩個比。

  • 正確地組合各個比。距離按 \(\rho\) 縮小，速率按 \(k\) 縮小，所以時間按 \(\rho/k\) 縮小。

  • 無窮多個事件，有限的總和。公比小於 \(1\) 的等比級數收斂。

背後的數學

當 \(\theta \geq 60^\circ\) 時

當 \(\theta = 60^\circ\) 時，這個比恰好等於 \(1\)：每一段所需的時間都相同，質點雖然愈來愈接近 \(O\)，卻永遠到不了。（速率和每段的長度都按同一個因子縮小。）當 \(\theta > 60^\circ\) 時，每一段所需的時間愈來愈長。在所有情況下，質點都會趨近 \(O\)，並反彈無窮多次；只有當 \(\theta < 60^\circ\) 時，它才會在有限時間內到達。\(e = \tan 30^\circ/\tan 60^\circ = \frac13\) 這個值就是分界線。

彈跳的球與非彈性坍縮

同一現象最簡單的例子：一個球掉落到地板上，反彈至高度 \(e^2H\)，然後是 \(e^4H\)，如此類推。兩次彈跳之間的時間與每次彈跳時的速率成正比，而速率按因子 \(e\) 縮小，所以總時間是一個等比級數：設 \(T_0 = \sqrt{2H/g}\) 為第一次下落的時間，則球在 \[T_0 + 2eT_0 + 2e^2T_0 + \cdots = T_0\,\frac{1 + e}{1 - e}.\] 之後停止彈跳。無窮多次彈跳，然後靜止。1992 年，Sean McNamara 和 William Young 證明了，在模擬排成一直線的多個非彈性質點時，同樣的事情也會發生：其中一組質點可以在有限時間內發生無窮多次碰撞，這就是「非彈性坍縮」。沙和顆粒流的模擬必須加入特別的規則來避免這種情況，而這個現象也有助解釋為何顆粒氣體會自發地聚集成團。

芝諾與收斂

芝諾的悖論約於公元前 450 年提出，困擾了哲學家兩千年。數學上的解答，即無窮和可以有有限的值，要到十九世紀才變得嚴謹，當時柯西（Cauchy）、魏爾斯特拉斯（Weierstrass）等人以極限（limit）來定義收斂（這是第 2 章的主題）。這道題目令人驚訝之處，在於這個過程在物理上是無窮的：確確實實有無窮多次碰撞，發生在有限時間之內。研究多邊形內的桌球運動和碰撞質點運動的數學家，把這種行為稱為芝諾現象（Zeno phenomenon）；要證明由互相碰撞的硬球組成的系統在所有時刻都有明確定義的運動，這正是其中一個微妙之處。

思維技巧

為無窮過程求和

當一個過程以固定的縮放因子不斷重複時，任何可加的量（時間、距離、能量）的總和都是一個等比級數。根據公比判斷它是否收斂。

這裏的關鍵是找出正確的比：不是距離之比，也不是速率之比，而是時間之比。在大學裏，同樣的推理支配着迭代法（iterative methods）的收斂性、分形（fractal）理論，以及對反覆把問題減半的演算法（algorithm）的分析。

延伸練習

  1. 總距離。證明對於 \(30^\circ\) 與 \(90^\circ\) 之間的每一個 \(\theta\)，由 \(M_1\) 到 \(O\) 所走的總距離都是有限的，並以 \(OM_1\) 和 \(\theta\) 表示這個總距離。

  2. 其他楔形。把 \(30^\circ\) 換成角 \(\alpha\) 的楔形，重做這道題目。證明 \(\varphi = \theta - \alpha\)，並求出質點在有限時間內到達 \(O\) 時 \(\theta\) 須滿足的條件。

  3. 彈性牆。若 \(e = 1\)，質點有可能到達 \(O\) 嗎？（提示：把楔形沿它的牆反覆反射，使路徑變成一條直線。圍繞 \(O\) 可以放下多少個 \(30^\circ\) 的楔形？）

  4. 彈跳的球。一個球從 \(1\) m 的高度掉下，\(e = 0.8\)。它會彈跳多久？它總共走了多遠？（取 \(g = 9.8\) m s\(^{-2}\)。）
