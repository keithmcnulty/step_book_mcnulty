第 11 章 · 振動、轉動與運動參考系

延伸練習答案

以下只是簡短的答案和提示，並非完整解答：只列出結果和關鍵步驟，讓你核對自己的做法。請先認真做完每道練習，然後才翻看。

11.1 共振

  1. 在升降機的參考系（frame）中，重力實際上相當於 \(g - f\)，而弦線的勁度（stiffness）是 \(\frac{mg}{a}\)（在 \(mg\) 的作用下它伸長 \(a\)）。因此 \(\ddot y + \frac gay = g - f\)，開始時 \(y = a\)、\(\dot y = 0\)。新的平衡位置（equilibrium）是 \(a - \frac{af}{g}\)，所以 \(y = a - \frac{af}{g}(1 - \cos\omega t)\)：振幅（amplitude）為 \(\frac{af}{g}\)，而最小伸長量 \(a(1 - \frac{2f}{g})\) 是正數。升降機停止加速時，平衡位置回到 \(a\)，此時質點的位移是 \(-\frac{af}{g}(1 - \cos\omega T)\)，速度是 \(-\frac{af}{g}\omega\sin\omega T\)。新的振幅是 \(\frac{af}{g}\sqrt{(1 - \cos\omega T)^2 + \sin^2\omega T} = \frac{2af}{g}\bigl|\sin\frac12\omega T\bigr|\)。

  2. 由 \(x = Ct\cos nt\) 得 \(\ddot x + n^2x = -2Cn\sin nt\)，所以 \(C = -\frac{nb}{2}\)。再加上 \(\frac b2\sin nt\) 以符合初始條件：\(x = \frac b2(\sin nt - nt\cos nt)\)。對題目中的公式就 \(p\) 使用洛必達法則（L’Hôpital’s rule），當 \(p \to n\) 時會得到相同的結果。

  3. \(n\sin pt - p\sin nt = n(\sin pt - \sin nt) + (n - p)\sin nt = 2n\cos\frac{(n + p)t}{2}\sin\frac{(p - n)t}{2} + (n - p)\sin nt\)。第二項很小。第一項是一個快速振盪，被包在緩慢變化的包絡（envelope）\(\bigl|\sin\frac{(n - p)t}{2}\bigr|\) 之內，而這個包絡每隔 \(\frac{2\pi}{n - p}\) 重複一次。

  4. 振幅是 \(\frac{F}{\sqrt{(n^2 - p^2)^2 + 4k^2p^2}}\)。把分母對 \(p^2\) 求極小：\(-2(n^2 - p^2) + 4k^2 = 0\)，所以 \(p^2 = n^2 - 2k^2\)。

11.2 簡正模式

  1. 求導後，能量的變化率是 \(\dot x\bigl(m\ddot x + \frac\lambda a(2x + y)\bigr) + \dot y\bigl(m\ddot y + \frac\lambda a(x + 2y)\bigr) = 0\)。設 \(u = x - y\) 及 \(v = x + y\)，能量便是 \(\bigl(\frac m4\dot u^2 + \frac{\lambda}{4a}u^2\bigr) + \bigl(\frac m4\dot v^2 + \frac{3\lambda}{4a}v^2\bigr)\)，每個括號都是一個簡諧振子（simple harmonic oscillator）的能量，所以各自都是常數。

  2. 週期 \(\frac{2\pi}{\omega}\)：以 \(x = -y\) 及 \(\dot x = -\dot y\) 開始（使得 \(v \equiv 0\)）。週期 \(\frac{2\pi}{\sqrt3\omega}\)：以 \(x = y\) 及 \(\dot x = \dot y\) 開始。

  3. 作用於 \(X\) 的力是 \(-\frac\lambda ax - \frac\mu a(x + y)\)。模式（mode）\(x - y\) 仍然有 \(\omega^2 = \frac{\lambda}{ma}\)，而 \(x + y\) 現在則是 \(\frac{\lambda + 2\mu}{ma}\)。當且僅當頻率之比 \(\sqrt{1 + 2\mu/\lambda}\) 是有理數時，所有運動都是週期性的。

  4. 矩陣是 \(\frac km\begin{pmatrix} 2 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 2 \end{pmatrix}\)，特徵向量（eigenvector）為 \((1, \sqrt2, 1)\)、\((1, 0, -1)\) 和 \((1, -\sqrt2, 1)\)，分別對應 \(2 - \sqrt2\)、\(2\) 和 \(2 + \sqrt2\)。三個模式是：三者一同擺動，中間的擺幅最大；外側兩個反向擺動，中間的靜止不動；以及中間的與外側兩個反向擺動。

11.3 真實的擺

  1. 能量：\(\frac12m\dot x^2 + \frac{\lambda}{2a}\bigl(\sqrt{x^2 + a^2} - a\bigr)^2 = \frac12mv^2\)。位移最大時 \(\sqrt{x^2 + a^2} = a + \frac vk\)，所以 \(x_{\max} = \sqrt{\frac{2av}{k} + \frac{v^2}{k^2}}\)。當 \(v\) 很小時，伸長量約為 \(\frac{x^2}{2a}\)，所以 \(\dot x^2 \approx v^2 - \frac{k^2x^4}{4a^2}\)。設 \(x = Xu\) 及 \(X = \sqrt{2av/k}\)，週期 \(4\int_0^X\frac{\mathrm{d}x}{\dot x}\) 便化為 \(\frac{4X}{v}\int_0^1\frac{\mathrm{d}u}{\sqrt{1 - u^4}}\)。回復力（restoring force）與 \(x^3\) 成正比，而不是與 \(x\) 成正比（在 \(x = 0\) 時弦線剛好處於自然長度），所以不存在簡諧極限。

  2. \((1 - m\sin^2\phi)^{-1/2} \approx 1 + \frac m2\sin^2\phi + \frac{3m^2}{8}\sin^4\phi\)，其中 \(m = \sin^2\frac\gamma2 \approx \frac{\gamma^2}{4} - \frac{\gamma^4}{48}\)。對 \(\phi\) 取平均得 \(1 + \frac m4 + \frac{9m^2}{64}\)，而 \(\gamma^4\) 項是 \(-\frac{1}{192} + \frac{9}{1024} = \frac{11}{3072}\)。

  3. 由 \(1\) 和 \(\cos45^\circ = 0.70711\) 開始：\((0.85355, 0.84090)\)，然後 \((0.84722, 0.84720)\)，然後 \(0.847213\)。週期因子是 \(\frac{1}{0.847213} = 1.18034\)。

  4. 週期因子的變化是 \(\frac{1}{16}(\gamma_5^2 - \gamma_4^2) \approx 1.71 \times 10^{-4}\)（以弧度計），所以時鐘每天大約慢 \(15\) 秒。

11.4 等時曲線

  1. 由於 \(y = \frac{s^2}{4k}\)，\(\ddot s = -g\frac{\mathrm{d}y}{\mathrm{d}s} = -\frac{g}{2k}s\)：這是 \(\omega^2 = \frac{g}{2k}\) 的簡諧運動（simple harmonic motion）。由 \(s_0 = 2\sqrt{kh}\) 出發，在 \(V\) 處的速率是 \(\omega s_0 = \sqrt{2gh}\)。

  2. 這個碗相當於一個長度為 \(R\) 的擺。從很小的高度出發，到達底部所需的時間是 \(\frac\pi2\sqrt{R/g}\)。從碗邊（\(\gamma = 90^\circ\)）出發，所需時間是這個值的 \(1.180\) 倍，約為 \(1.85\sqrt{R/g}\)。

  3. 會。兩者都在四分之一週期後到達 \(V\)，並在該處碰撞。無論它們碰撞後以甚麼速度離開，各自都以 \(s\) 作簡諧運動，而且週期相同，所以各自恰好在半個週期後回到 \(V\)，並再次在 \(V\) 碰撞。（碰撞後靜止於 \(V\) 的質點則會一直留在該處。）

  4. 設 \(x = R(\theta - \sin\theta)\) 及 \(y = R(1 - \cos\theta)\)，則 \(\mathrm{d}s = 2R\sin\frac\theta2\,\mathrm{d}\theta\)，所以一拱的長度是 \(\int_0^{2\pi}2R\sin\frac\theta2\,\mathrm{d}\theta = 8R\)。面積是 \(\int y\,\mathrm{d}x = R^2\int_0^{2\pi}(1 - \cos\theta)^2\,\mathrm{d}\theta = 3\pi R^2\)。

11.5 加速火車中的重力

  1. 在車廂的參考系中，每單位質量受到一個向後（向南）的力 \(a\)，方向與發射方向相同。飛行時間為 \(\frac{2V\sin\theta}{g}\)，所以射程是 \(\frac{V^2}{g}\bigl(\sin2\theta + \frac ag(1 - \cos2\theta)\bigr)\)。當 \(\tan2\theta = -\frac ga\) 時它的導數為零，所以 \(2\theta \approx \frac\pi2 + \frac ag\)。極大值是 \(\frac{V^2}{g}\bigl(\sqrt{1 + a^2/g^2} + \frac ag\bigr) \approx \frac{V^2}{g} + \frac{V^2a}{g^2}\)。

  2. \(x = ut\cos\theta - \frac12ft^2\)，在 \(t = \frac{2u\sin\theta}{g}\) 時着地，着地點為 \(x = \frac{2u^2\sin\theta}{g^2}(g\cos\theta - f\sin\theta)\)。若 \(\tan\theta > \frac{g}{2f}\)，水平速度 \(u\cos\theta - ft\) 會在着地前變為負數，所以 \(\alpha = \tan^{-1}\frac{g}{2f}\)。當 \(f = g\) 及 \(\theta = 45^\circ\) 時，加速度剛好與初速度方向相反：拋體（projectile）沿直線 \(y = x\) 筆直向上，停下，然後沿原路直接返回 \(O\)。

  3. 有效重力（effective gravity）是向下的 \(g\) 加上向後的 \(a\)。自由液面與它垂直，所以傾斜的角度是 \(\tan^{-1}\frac ag\)。

  4. 有效重力的大小是 \(\sqrt{g^2 + a^2}\)，在 \(x = \frac{ak}{2g}\) 處斜率是 \(\frac ag\)，曲率半徑（radius of curvature）是 \(\rho = \frac{k}{2}\bigl(1 + \frac{a^2}{g^2}\bigr)^{3/2}\)。週期是 \(2\pi\sqrt{\rho/\sqrt{g^2 + a^2}} = 2\pi\sqrt{\frac{k(g^2 + a^2)}{2g^3}}\)，當 \(a = 0\) 時簡化為 \(2\pi\sqrt{\frac{k}{2g}}\)。

11.6 後旋

  1. 摩擦力作用於接觸點，所以對該點的角動量（angular momentum）守恆：\(maV + \frac25ma^2\frac Va = mav_0 + \frac25ma^2\omega_0\)。因此 \(V = \frac{5v_0 + 2a\omega_0}{7}\)，當 \(\frac{v_0}{a\omega_0} < 1\) 時它大於 \(v_0\)。

  2. \(V = \frac57v_0\)。最終能量是 \(\frac12m\bigl(\frac57v_0\bigr)^2\bigl(1 + \frac25\bigr) = \frac57 \cdot \frac12mv_0^2\)，所以損失了 \(\frac27\) 的能量。

  3. 以 \(I = ma^2\) 重複同一論證，得 \(V = \frac12(v_0 - a\omega_0)\)。令 \(V = -\frac{v_0}{7}\)，得 \(\frac{v_0}{a\omega_0} = \frac79\)。

  4. 在球心上方高度 \(h\) 處施加衝量（impulse）\(J\)，得 \(mv = J\) 及 \(\frac25ma^2\omega = Jh\)。滾動需要 \(v = a\omega\)，所以 \(h = \frac25a\)。

11.7 桿中的辛普森法則

  1. \(\frac16\bigl(1 + 4 \cdot \frac45 + \frac12\bigr) = \frac{47}{60} \approx 0.7833\)，而 \(\frac\pi4 \approx 0.7854\)。對於 \(\int_{-1}^1\)，法則 \(\frac13\bigl(\mathrm{f}(-1) + 4\mathrm{f}(0) + \mathrm{f}(1)\bigr)\) 對 \(x^3\) 給出 \(0\)，對 \(x^2\) 給出 \(\frac23\)（兩者都是準確值），但對 \(x^4\) 給出 \(\frac23\)，而它的積分其實是 \(\frac25\)。

  2. 對於與基準方向成角 \(\psi\) 的軸，轉動慣量（moment of inertia）是一個二次型（quadratic form）\(A\cos^2\psi + B\sin^2\psi + 2C\sin\psi\cos\psi\)。在 \(\psi \mapsto \psi + 90^\circ\) 之下不變，迫使 \(A = B\) 及 \(C = 0\)，所以對每一條軸都相同：\(\frac13Ma^2\)，即對平行於一邊的軸的值。

  3. 在每邊中點各放置 \(\frac13\) 的面積，便能準確地在三角形上積分任何二次式（可在直角三角形上驗證 \(1\)、\(x\)、\(x^2\)、\(xy\)）。所以這三個質點與該薄片（lamina）有相同的質量、質心（centre of mass）和二階矩（second moments）。

  4. 在每個方向上，取桿在 \(-a\)、\(0\)、\(a\) 處的權重 \(\frac16\)、\(\frac23\)、\(\frac16\) 的乘積：頂點處為 \(\frac{M}{216}\)，棱的中點處為 \(\frac{M}{54}\)，面心處為 \(\frac{2M}{27}\)，中心處為 \(\frac{8M}{27}\)。對通過中心且平行於一條棱的軸，\(I = M\bigl(\frac{a^2}{3} + \frac{a^2}{3}\bigr) = \frac23Ma^2\)。根據平行軸定理（parallel axis theorem），對一條棱的轉動慣量是 \(\frac23Ma^2 + M(\sqrt2a)^2 = \frac83Ma^2\)。

11.8 傾斜的平衡

  1. 由公共面起向圓錐方向量度，\(G\) 位於 \(\frac{-\frac23 \cdot \frac{3a}{8} + \frac\lambda3 \cdot \frac{\lambda a}{4}}{\frac23 + \frac\lambda3} = \frac{a(\lambda^2 - 3)}{4(2 + \lambda)}\)。在半球上，接觸點處的法線必定通過該面的中心，所以當 \(G\) 低於該中心，即 \(\lambda < \sqrt3\) 時，玩具會自行回正。側臥時，玩具沿圓錐的一條母線（generator）及在邊緣處與桌面接觸；若通過 \(G\) 的鉛垂線落在頂點與邊緣之間，它便會停留在那裏。這需要 \(G\) 的高度至少為 \(-\frac a\lambda\)，化簡後即 \(\lambda^3 + \lambda + 8 > 0\)：恆成立。

  2. 均勻球體上的每一點都是平衡位置（隨遇平衡）。若質心稍微偏離球心，便只有兩個：\(G\) 在最低處（穩定）和 \(G\) 在最高處（不穩定）。

  3. 平衡出現在法線通過中心之處：即兩軸的四個端點。靠在短軸的一端是穩定的（\(G\) 盡可能低）；靠在長軸的一端則不穩定。

  4. 由對稱性，\(G\) 在原點。當 \(n = 2\) 時，\(Y = r\bigl(\frac12 - p^2\bigr)\)，而傾斜平衡需要法線通過 \(G\)，所以 \(Y = 0\) 及 \(p = \frac{1}{\sqrt2}\)。該處的斜率是 \(-\sqrt2\)，所以 \(\overrightarrow{AB}\) 傾斜的角度是 \(\tan^{-1}\sqrt2 \approx 54.7^\circ\)，若靠在另一個拋物面上則是 \(125.3^\circ\)。兩者互為關於 \(x\) 軸的反射，這就是傾斜角成對出現的原因。

11.9 安全拋物線

  1. 每個質點位於 \(ut\,\hat{\mathbf{n}} - \frac12gt^2\mathbf{j}\)，即在以 \(-\frac12gt^2\mathbf{j}\) 為球心、半徑為 \(ut\) 的球面上。從 \((0, \frac{u^2}{2g})\) 水平射出的質點沿 \(y = \frac{u^2}{2g} - \frac{gx^2}{2u^2}\) 運動：這正是安全拋物線（parabola of safety）。以角 \(\alpha\) 射出的質點在時間 \(\frac{u}{g\sin\alpha}\) 於 \(x = \frac{u^2}{g\tan\alpha}\) 處與它相切；水平射出的質點需時 \(\frac{x}{u}\) 到達該處，所以它必須在時間 \(\frac{u(1 - \cos\alpha)}{g\sin\alpha} = \frac ug\tan\frac\alpha2\) 發射（這需要 \(\alpha \geq 45^\circ\)，使切點在地面之上）。

  2. 該直線與安全拋物線相交於 \(R\sin\beta = \frac{u^2}{2g} - \frac{gR^2\cos^2\beta}{2u^2}\) 之處，得 \(R = \frac{u^2}{g(1 + \sin\beta)}\)。在極大值處，練習 3 的兩個角重合，所以最佳角度是角平分線的方向，即 \(45^\circ + \frac12\beta\)。

  3. 設 \(\lambda = \tan\theta\)，兩個值滿足 \(\lambda_1 + \lambda_2 = \frac{2u^2}{gx}\) 及 \(\lambda_1\lambda_2 = 1 + \frac{2u^2y}{gx^2}\)。所以 \(\tan(\theta_1 + \theta_2) = -\frac xy\) 及 \(\theta_1 + \theta_2 = 90^\circ + \varphi\)，其中 \(\varphi\) 是 \(OP\) 的仰角。\(OP\) 與鉛垂線的角平分線位於 \(\frac12(90^\circ + \varphi)\)。

  4. 頂點位於 \(\bigl(\frac{u^2}{2g}\sin2\theta, \frac{u^2}{2g}\sin^2\theta\bigr)\)，焦距（focal length）是 \(\frac{u^2\cos^2\theta}{2g}\)，所以焦點（focus）的高度是 \(\frac{u^2}{2g}(\sin^2\theta - \cos^2\theta)\)。無論 \(\theta\) 是多少，它與 \(O\) 的距離都是 \(\frac{u^2}{2g}\)。

11.10 會朝你飛回來的球

  1. 取單位使 \(u = g = 1\)，則 \(\frac{\mathrm{d}}{\mathrm{d}t}OP^2 = t(t^2 - 3t\sin\alpha + 2)\)，其根為 \(t \approx 1.050\)（局部極大，\(OP \approx 0.516\frac{u^2}{g}\)）和 \(t \approx 1.904\)（局部極小，\(OP \approx 0.336\frac{u^2}{g}\)）。球在 \(t \approx 1.970\) 着地。

  2. 沿斜面及垂直於斜面方向分解，\(OP^2 = u^2t^2 - ugt^3\sin(\alpha' + \beta) + \frac14g^2t^4\)，其中 \(\alpha'\) 由斜面起量度。這就是平地的公式，只是 \(\alpha = \alpha' + \beta\)。所以條件 \(\sin(\alpha' + \beta) > \frac{2\sqrt2}{3}\) 所涉及的是與水平所成的角；若由斜面起量度，臨界角便降至 \(70.5^\circ - \beta\)（前提是球尚未着地）。

  3. 較小。阻力（drag）抵消水平運動，並使下降變得更陡，所以球落回時更接近鉛垂方向，令 \(OP\) 更容易縮短。

  4. \(OP^2\) 的公式不涉及着地點，所以與之前一樣，當且僅當 \(\sin\alpha > \frac{2\sqrt2}{3}\) 時，\(OP\) 會有一段時間遞減（而飛行時間較長，意味着遞減階段必定在着地之前出現）。最終下落佔主導，\(OP\) 便會遞增。

11.11 外野手如何接球

  1. 若她站在 \(D_0\) 處，並以速度 \(v\) 背離擊球手（batsman）跑動，球便在她前方 \(D_0 + vt - Ut\) 的距離處。要接到球，她需要 \(D_0 + vT = UT\)，這時距離是 \((U - v)(T - t)\)，所以 \(\tan\theta = \frac{gt}{2(U - v)}\)，同樣是線性的。若球落在她身後，則 \(UT > D_0\) 及 \(v > 0\)：她向後跑。

  2. \(\theta = \tan^{-1}\frac{gt}{2U}\)，所以 \(\dot\theta = \frac{g/2U}{1 + (gt/2U)^2}\)，它是遞減的。\(\tan\theta\) 之所以是線性的，是因為高度 \(\frac12gt(T - t)\) 和距離 \(U(T - t)\) 有公因式 \(T - t\)。

  3. 會。相對於她眼睛的高度是一個在接球時刻為零的二次式，所以可因式分解為 \((T - t)(c + dt)\)；除以 \(U(T - t)\) 後剩下一個線性函數（它起初是負數：她最初要向下看）。

  4. 不會。有阻力時，水平距離是 \(\frac Uk(\mathrm{e}^{-kt} - \mathrm{e}^{-kT})\)，而高度並不等於它乘以 \(t\) 的一個線性函數，所以 \(\tan\theta\) 不再是線性的。

11.12 橡皮繩上的螞蟻

  1. \(\frac{x}{a + ut} = \frac1k\ln\frac{a + ut}{a}\)，它在 \(t = \frac au(\mathrm{e}^{k/2} - 1)\) 時等於 \(\frac12\)。由於 \(\frac T2 = \frac{a}{2u}(\mathrm{e}^{k/2} - 1)(\mathrm{e}^{k/2} + 1)\) 而 \(\frac12(\mathrm{e}^{k/2} + 1) > 1\)，這個時刻在 \(\frac T2\) 之前。

  2. \(\frac{\mathrm{d}}{\mathrm{d}t}\frac xL = \frac vL = \frac va\mathrm{e}^{-\lambda t}\)，所以 \(\frac xL = \frac{v}{a\lambda}(1 - \mathrm{e}^{-\lambda t})\)，只有當 \(v > \lambda a\) 時才會達到 \(1\)。

  3. \(\frac xL = v\int_0^t\frac{\mathrm{d}s}{a + \frac12bs^2}\)，它趨向 \(\frac{v\pi}{\sqrt{2ab}}\)。所以只有當 \(v > \frac{\sqrt{2ab}}{\pi}\) 時，螞蟻才會到達。

  4. 這需要 \(\frac{H_N}{100\,000} = \frac{1}{100}\)，所以 \(H_N = 1000\)，而 \(N \approx \mathrm{e}^{999.4} \approx 10^{434}\) 秒。

11.13 鏟雪車問題

  1. 正午後時間 \(t\) 的積雪深度與 \(t + t_0\) 成正比，所以鏟雪車走過的距離是 \(c\ln\frac{t + t_0}{t_0}\)。條件 \(x(1) = 2\) 及 \(x(2) = 3\) 給出 \(\bigl(1 + \frac{1}{t_0}\bigr)^3 = \bigl(1 + \frac{2}{t_0}\bigr)^2\)。設 \(u = \frac{1}{t_0}\)，這便化簡為 \(u^2 - u - 1 = 0\)，所以 \(u = \frac{1 + \sqrt5}{2}\) 及 \(t_0 \approx 0.618\) 小時：大約在 11:23 開始下雪。

  2. \(\frac{\mathrm{d}t}{\mathrm{d}y} = \frac{\alpha h}{k}\mathrm{e}^{\alpha y} - \frac{\alpha h}{k}\mathrm{e}^{\alpha y} + \alpha\bigl(T - \frac{\alpha hy}{k}\bigr)\mathrm{e}^{\alpha y}\)，而 \(\alpha\bigl(t - (\mathrm{e}^{\alpha y} - 1)\frac hk\bigr)\) 與它相同。

  3. 時間差距是 \(\bigl(T - \frac{\alpha hy}{k}\bigr)\mathrm{e}^{\alpha y}\)，它的導數在 \(y = \frac{kT - h}{\alpha h}\) 處為零。若 \(kT > h\)，差距會一直增大到該處，然後縮小，在 \(y = \frac{kT}{\alpha h}\) 處減至 \(0\)。若 \(kT \leq h\)，導數 \(\alpha\mathrm{e}^{\alpha y}\bigl(T - \frac hk - \frac{\alpha hy}{k}\bigr)\) 對所有 \(y > 0\) 都是負數，所以差距從一開始便縮小。第二輛鏟雪車面對的積雪深度是 \(k \times\)（差距）；只要這比第一輛鏟雪車在同一地點遇到的積雪深，它便會落後得更遠。

  4. \(\frac1\alpha\frac{\mathrm{d}t_3}{\mathrm{d}y} = t_3 - t_2(y)\)。寫成 \(t_3 = t_2 + g\)，得 \(g = \mathrm{e}^{\alpha y}\bigl(T - \alpha Ty + \frac{\alpha^2hy^2}{2k}\bigr)\)。若 \(kT \geq 2h\)，它在 \(y = \frac{k}{\alpha h}\bigl(T - \sqrt{T^2 - 2hT/k}\bigr)\) 處為零，早於第二輛鏟雪車追上第一輛之處；若 \(kT < 2h\)，則第二輛會先追上第一輛。

11.14 是拋物線，不是懸鏈線

  1. 是。水平張力 \(H\) 仍然是常數，中間一段的斜率為 \(0\)，其後斜率每次遞增 \(\frac wH\)。以水平一段的中點為起點量度 \(x\)，第 \(k\) 個接點位於 \(x = (k - \frac12)h\)，比最低的接點高出 \(\frac{wh}{2H}k(k - 1)\)，即 \(\frac{w}{2Hh}\bigl(x^2 - \frac{h^2}{4}\bigr)\)：是一條拋物線。

  2. 張力是 \(\sqrt{H^2 + V^2}\)，在垂直分量 \(V\) 最大之處最大：即在兩端的一段，該處 \(V\) 承托一半的負載，即 \(\frac{(2n + 1)w}{2}\)。所以 \(T_{\max} = \sqrt{H^2 + \frac14(2n + 1)^2w^2}\)。

  3. \(y' = \sinh\frac xc\) 及 \(y'' = \frac1c\cosh\frac xc = \frac1c\sqrt{1 + \sinh^2\frac xc}\)。長度是 \(\int_0^X\cosh\frac xc\,\mathrm{d}x = c\sinh\frac Xc\)。

  4. 對於垂度（sag）為 \(s\) 的平緩曲線，懸鏈線（catenary）和拋物線的長度都約為 \(2d + \frac{4s^2}{3d}\)，所以兩者都給出 \(s \approx \sqrt{\frac32d(L - d)}\)；它們只在 \(s^4\) 階才有分別。對於一條幾乎拉緊的鏈，這個差別遠小於伽利略（Galileo）所能量度的任何數值。
