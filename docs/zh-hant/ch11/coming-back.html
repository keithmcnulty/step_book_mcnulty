11.10

會朝你飛回來的球

引子

把球向前拋出，它在落地之前會一直離你而去。這是理所當然的。把球垂直向上拋，它卻會回到你手上。在這兩種情況之間，必定有些事情起了變化：必定存在某些角度，令球先遠離你，然後向你靠近，到落地之前又再遠離。本題要找出的正是那個確切的分界線：\(\sin\alpha = \frac{2\sqrt2}{3}\)，即大約 \(70.5^\circ\)。

這個結果是數學中一種常見情況的好例子：人人都以為某個量是單調（monotonic）的，其實不然。它同時展示了一個在大學裏經常用到的標準技巧：要判斷一個距離是否正在增加，就對它的平方求導（differentiate），這樣便可避開平方根。

動筆之前

為甚麼處理 \(OP^2\) 比處理 \(OP\) 容易？「\(OP\) 遞增」與「\(OP^2\) 遞增」是同一回事嗎？

\(OP^2 = x^2 + y^2\) 是 \(t\) 的多項式（polynomial），而 \(OP\) 則涉及平方根。由於 \(OP \geq 0\)，而平方運算在非負數上是遞增的，所以 \(OP\) 遞增的時候，正正就是 \(OP^2\) 遞增的時候。

逐步解題

階段 1 距離的平方

由 \(x = ut\cos\alpha\) 及 \(y = ut\sin\alpha - \frac12gt^2\)，可得 \[OP^2 = u^2t^2\cos^2\alpha + u^2t^2\sin^2\alpha - ugt^3\sin\alpha + \tfrac14g^2t^4 = u^2t^2 - ugt^3\sin\alpha + \tfrac14g^2t^4.\]

對 \(t\) 求導。抽出因子 \(t\) 之後，剩下的是甚麼？它在甚麼情況下對所有 \(t\) 皆為正？

\[\frac{\mathrm{d}}{\mathrm{d}t}OP^2 = 2u^2t - 3ugt^2\sin\alpha + g^2t^3 = t\bigl(g^2t^2 - 3ug\sin\alpha\,t + 2u^2\bigr).\] 當 \(t > 0\) 時，其正負號與二次式（quadratic）\(g^2t^2 - 3ug\sin\alpha\,t + 2u^2\) 的正負號相同。這個二次式的首項係數為正，所以只要它的判別式（discriminant）為負，它對每一個 \(t\) 都是正的： \[9u^2g^2\sin^2\alpha - 8u^2g^2 < 0 \quad\Longleftrightarrow\quad \sin^2\alpha < \frac89 \quad\Longleftrightarrow\quad \sin\alpha < \frac{2\sqrt2}{3}.\] 在這情況下，\(OP\) 在整個飛行過程中都在遞增。■

階段 2 較陡的拋擲

若 \(\sin\alpha > \frac{2\sqrt2}{3}\)，這個二次式有兩個實根。它們是正數嗎？較小的那個根是否出現在質點落地之前？

兩根之和為 \(\frac{3u\sin\alpha}{g} > 0\)，兩根之積為 \(\frac{2u^2}{g^2} > 0\)，所以兩根皆為正數；而在兩根之間，這個二次式為負，因而 \(\frac{\mathrm{d}}{\mathrm{d}t}OP^2\) 也為負。質點在 \(T = \frac{2u\sin\alpha}{g}\) 時落地。較小的根是 \[t_1 = \frac{u}{2g}\bigl(3\sin\alpha - \sqrt{9\sin^2\alpha - 8}\bigr) < \frac{u}{2g}\cdot3\sin\alpha < \frac{2u\sin\alpha}{g} = T.\] 所以緊接 \(t_1\) 之後（而且在落地之前），\(OP\) 正在遞減。■

階段 3 移動的觀察者

\(Q\) 沿地面朝相反方向以速率 \(v\) 離開 \(O\)。從 \(Q\) 量度，水平距離是 \(x + vt\)。這對計算有甚麼影響？

間距 \(QP\) 的水平分量為 \((u\cos\alpha + v)t\)，垂直分量為 \(ut\sin\alpha - \frac12gt^2\)。所以 \[QP^2 = \bigl((u\cos\alpha + v)^2 + u^2\sin^2\alpha\bigr)t^2 - ugt^3\sin\alpha + \tfrac14g^2t^4,\] 與之前的式子相同，只是第一項中的 \(u^2\) 換成了 \(w^2 = (u\cos\alpha + v)^2 + u^2\sin^2\alpha\)。其導數（derivative）為 \(t\bigl(g^2t^2 - 3ug\sin\alpha\,t + 2w^2\bigr)\)，而它對所有 \(t > 0\) 皆為正的條件是 \[9u^2\sin^2\alpha < 8w^2 \quad\Longleftrightarrow\quad u^2\sin^2\alpha < 8(u\cos\alpha + v)^2,\] 這是在兩邊消去 \(8u^2\sin^2\alpha\) 之後所得的結果。兩邊取平方根（\(u\sin\alpha\) 與 \(u\cos\alpha + v\) 皆為正數），即得 \(u\sin\alpha < 2\sqrt2(u\cos\alpha + v)\)，整理後就是 \[2\sqrt2\,v > (\sin\alpha - 2\sqrt2\cos\alpha)u. \qed\] （這個條件足以令 \(QP\) 在整個飛行過程中遞增，因為此時導數對所有 \(t > 0\) 皆為正。）

回顧

  • 對平方求導。距離的平方是多項式，而它的導數與距離本身的導數正負號相同。

  • 恆為正的二次式。「在所有時間都遞增」這個條件，化成了一個關於判別式的條件。

  • 把新問題化為舊問題。移動的觀察者只改變了一個係數，所以之前的分析可以直接套用。

背後的數學

幾何觀點

\(OP\) 遞減的時候，正正就是 \(P\) 的速度指向「內側」的時候，即速度與向量 \(\overrightarrow{OP}\) 成鈍角（obtuse angle），也就是 \(\overrightarrow{OP}\cdot\mathbf{v} < 0\) 的時候。對於陡峭的拋擲，質點在接近飛行最高點時，位於拋球者的高處而略為偏前，幾乎是水平地向外移動，但已開始下墜；相對於 \(\overrightarrow{OP}\) 的方向而言，一旦速度中向下的部分蓋過向外的部分，質點便會靠近。對於較平的拋擲，質點總是在前方足夠遠的位置，以致它的速度從不指回 \(O\)。臨界情況就是速度恰好只在一個瞬間與 \(\overrightarrow{OP}\) 垂直，亦即圖 11.10.1 中距離停頓的那一刻。

單調性並非必然

許多「顯然」會增加的量，其實並不如此。月球與地球的距離會來回振盪；在彎曲的路上，即使其中一輛車一直領先，兩車之間的距離仍可以減少；獵物大量繁殖的時候，捕食者的數量卻可以下降。要證明一個量是單調的，通常就是要證明某個導數的正負號固定不變，而這裏所用的技巧（化為多項式，再檢查它的根或判別式）正是標準的做法。在分析學（analysis）中，單調性往往是證明收斂（convergence）的關鍵：有界的單調數列必定收斂，正如你在第 2 章所見。

思維技巧

藉導數檢查單調性

要判斷一個量是否一直遞增，可對它（或對它的某個方便處理的函數，例如它的平方）求導，然後問：導數會否變號？

在大學裏，這類關於正負號的論證會用來證明不等式、找出極大值和極小值，以及研究微分方程（differential equation）解的穩定性；在後者中，一個一直遞減的量（如 第 8.2 節 所示）便證明了系統會趨於平穩。

延伸練習

  1. 有多近？對於 \(\alpha = 80^\circ\)，求 \(OP\) 取得局部極大值（local maximum）和局部極小值（local minimum）的時間，以及該兩刻的距離，以 \(u^2/g\) 為單位。

  2. 在斜面上。把球沿一個與水平成 \(\beta\) 角的斜面向上拋出，並落在斜面上，就這個情況重做第 (i) 部分。臨界角（從斜面量起）會改變嗎？

  3. 考慮空氣阻力。假設球還受到一個與其速度成正比的阻力（resistance）。不作計算，你預期臨界角會大於還是小於 \(70.5^\circ\)？為甚麼？

  4. 從高處拋出。若球從懸崖頂拋出，並落在遠低於崖頂的地方，證明無論以甚麼角度拋出，\(OP\) 最終都會遞增，並判斷是否存在某些角度，令它在某個階段遞減。
