延伸練習答案

以下只是簡短的答案和提示，並非完整解答：它們給出結果和關鍵步驟，方便你核對自己的做法。請先認真做過每道練習，然後才看答案。

12.1 精確地取條件

  1. 在 (iv) 和 (v) 中，其餘 \(k - 1\) 塊圓片都是從餘下的 \(b + n - 1\) 塊中隨機抽出的，其中 \(n - 1\) 塊有編號，所以兩者都等於 \(\frac{(n - 1)\binom{b}{k-2}}{\binom{b+n-1}{k-1}}\)。(vi) 的答案是 \(\frac{\binom n2\binom{b}{k-2}}{\binom{b+n}{k} - \binom bk}\)。設 \(N = b + n\)，兩者只在 \((2N - nk)\binom{N-1}{k-1} = 2k\binom bk\) 時才相等。這只會在個別特殊情況下發生，例如 \((b, n, k) = (2, 4, 3)\)、\((3, 3, 4)\) 或 \((6, 11, 3)\)，又或者是 \(n = 2\) 而所有圓片都被抽出這種平凡情況。對於題目所給的數值，等式並不成立。

  2. 兩個孩子的（性別，星期幾）組合共有 \(14^2 = 196\) 種，各種組合可能性相等，其中 \(196 - 13^2 = 27\) 種包含至少一個星期二出生的男孩。在這些組合之中，\(7^2 - 6^2 = 13\) 種是兩個男孩。所以概率是 \(\frac{13}{27}\)。

  3. 你選了 1 號門。若汽車在 1 號門後（概率 \(\frac13\)），換門會輸；若汽車在 2 號或 3 號門後，主持人必須打開另一扇後面是山羊的門，換門便會贏：概率為 \(\frac23\)。若主持人隨機打開一扇門，而門後碰巧是山羊，那麼根據你所見，「汽車在你選的門後」和「汽車在另一扇關着的門後」這兩個結果的可能性相等：概率為 \(\frac12\)。

  4. \(\mathrm{P}(\geq2 \mid \geq1) = \frac{1 - \mathrm{P}(0) - \mathrm{P}(1)}{1 - \mathrm{P}(0)} \approx 0.370\)，但 \(\mathrm{P}(\geq2 \mid \text{葵扇 A}) = 1 - \binom{48}{12}\big/\binom{51}{12} \approx 0.561\)。知道是哪一張 A，會令手上有第二張 A 的可能性增加。

12.2 基本比率謬誤

  1. 若屍體在那裏，兩者都說「有屍體」的概率是 \(pq\)；若不在，則是 \((1 - p)(1 - q)\)。先驗勝算（prior odds）為 \(1 : 1\)，所以後驗概率（posterior probability）是 \(\frac{pq}{pq + (1 - p)(1 - q)} = \frac{pq}{1 - p - q + 2pq}\)。至於第二部分，在三種可能性相等的情況中，有兩種情況下「\(A\) 在那裏」為真，所以 \(\mathrm{P}(\text{兩者都在} \mid \text{兩者都說 } A) = \frac{pq}{2pq + (1 - p)(1 - q)}\)。

  2. 我們需要 \(0.9\pi > \frac{1}{11}(1 - \pi)\)，即 \(\pi > \frac{10}{109} \approx 9.2\%\)。

  3. 每一次 AL 測試呈陽性，都會把勝算乘以 \(\frac{0.9}{1/11} = 9.9\)。由先驗勝算 \(\frac{1}{99}\) 開始：一次陽性之後，勝算為 \(0.1\)（概率 \(\frac{1}{11}\)）；兩次之後，勝算為 \(0.99\)（概率約 \(0.497\)）；三次之後，勝算為 \(9.8\)（概率約 \(0.907\)）。

  4. 在 \(100\) 名患者之中，\(99\) 人測試呈陽性；在 \(999\,900\) 名沒有患病的人之中，約有 \(9999\) 人呈陽性。所以約有 \(10\,100\) 人被告知可能患病，而當中只有 \(99\) 人（約 \(1\%\)）真正患病。

12.3 「隨機」是甚麼意思？

  1. 弦（chord）比內接等邊三角形的邊長 \(\sqrt3a\) 長的條件分別是：它的遠端落在與近端相對的那三分之一圓周上（\(\frac13\)）；它與 \(O\) 的距離小於 \(\frac a2\)（\(\frac12\)）；它的中點落在半徑為 \(\frac a2\) 的圓內（\(\frac14\)）。

  2. 以 \(C\) 為中點的弦垂直於 \(OC\)，所以它就是通過 \(C\) 而角度為 \(t = \frac\pi2\) 的弦，而 \(L(\frac\pi2) = \frac{4a}{3}\bigl(0 + \frac12\sec^2\frac\pi4\bigr) = \frac{4a}{3}\)。

  3. 弦長為 \(2\sqrt{a^2 - d^2}\)，平均值為 \(\frac2a\int_0^a\sqrt{a^2 - d^2}\,\mathrm{d}d = \frac2a \cdot \frac{\pi a^2}{4} = \frac{\pi a}{2}\)。

  4. 隨機端點：\(\frac{2}{\pi\sqrt{4a^2 - \ell^2}}\)。隨機距離：\(\frac{\ell}{2a\sqrt{4a^2 - \ell^2}}\)。隨機中點：\(\frac{\ell}{2a^2}\)。

12.4 兩兩獨立，卻非相互獨立

  1. 展開後得 \(\mathrm{E}(XY) - \mathrm{E}(X)\mathrm{E}(Y) = (a - pq)(x_1 - x_2)(y_1 - y_2)\)，所以 \(a = pq\)；其餘三格隨之確定，於是兩者獨立。例子：在 \((0, 0)\) 放概率 \(\frac13\)，在 \((\pm1, \pm1)\) 各點放概率 \(\frac16\)。兩個邊際分佈（marginal distribution）都是均勻的，而且 \(\mathrm{E}(AB) = 0\)，但 \(\mathrm{P}(A = 0, B = 1) = 0 \neq \frac19\)。

  2. 共有 \(21\) 對，每對相同的概率是 \(\frac16\)，而各指示變量（indicator）兩兩獨立（pairwise independent）。所以平均值是 \(3.5\)，方差（variance）是 \(21 \cdot \frac16 \cdot \frac56 \approx 2.92\)，標準差約為 \(1.71\)。得分 \(7\) 大約比平均值高出兩個標準差。

  3. 平均值是 \(\binom k2\frac{1}{365}\)。各指示變量兩兩獨立，與骰子的情況完全一樣，所以方差是 \(\binom k2\frac{1}{365}\cdot\frac{364}{365}\)。（它們並非相互獨立（mutually independent）：若 \(1, 2\) 相同，\(2, 3\) 也相同，則 \(1, 3\) 亦相同。）

  4. 取八個可能性相等的結果，\(A = B = \{1, 2, 3, 4\}\)，\(C = \{1, 5, 6, 7\}\)。那麼 \(\mathrm{P}(A \cap B \cap C) = \frac18\)，但 \(\mathrm{P}(A \cap B) = \frac12 \neq \frac14\)。

12.5 最後一位乘客的座位

  1. 對所有 \(n \geq 3\)，答案都是 \(\frac13\)。最後一個座位現在是 \(S_1\)、\(S_2\) 和 \(S_n\) 其中之一，而每一次隨機選擇對這三個座位都是對稱的。

  2. 若 \(T_1\) 坐了 \(S_1\)，沒有人要讓位。若 \(T_1\) 坐了 \(S_3\)，則 \(T_1\) 和 \(T_3\) 都坐錯了位。若 \(T_1\) 坐了 \(S_2\)，便由 \(T_2\) 選擇：選 \(S_1\) 有 \(2\) 人坐錯位，選 \(S_3\) 則有 \(3\) 人。期望值（expectation）是 \(\frac13\bigl(0 + 2 + \frac52\bigr) = \frac32\)，與公式給出的 \(\frac23 + \frac13 + \frac12\) 一致。

  3. 當 \(r \geq 2\) 時 \(P_r = \frac12\)，於是 \(\frac1n\bigl(1 + \frac{n - 2}{2}\bigr) = \frac12\)，所以遞推關係（recurrence）與 \(P_n = \frac12\) 相容。

  4. 最後一個空位必定是 \(S_1\) 或 \(S_n\)（任何其他 \(S_k\) 最遲在 \(T_k\) 登機時已被佔去）。所以若它不是 \(S_n\)，就是 \(S_1\)。

12.6 多一枚硬幣

  1. 設 \(H'\) 為 Bob 首 \(n + 1\) 次擲幣的結果，\(X\) 為他最後一次擲幣的結果。若 \(H' > H_A\)，或者 \(H' = H_A\) 而 \(X\) 是正面，Bob 便勝出。所以概率是 \(\mathrm{P}(H' > H_A) + \frac12\mathrm{P}(H' = H_A)\)，而根據「多一枚硬幣」的結果，\(\mathrm{P}(H' > H_A) = \frac12\)。

  2. 不成立。當 \(n = 0\) 時，Bob 勝出的概率是 \(p\)。那個巧妙的證明把正面和反面對調，而這只有對公平硬幣才是一種對稱。

  3. \(H_A = H_B\) 恰好在 \(H_A + (\text{Bob 的反面數目}) = n\) 時成立，即一個 \(\mathrm{B}(2n, \frac12)\) 變量等於 \(n\)。數值：\(\frac12\)、\(\frac38\)、\(\frac{5}{16}\)。

  4. 不成立：擲出六點就像一枚 \(p = \frac16\) 的硬幣。當 \(n = 0\) 時概率是 \(\frac16\)，而一般而言概率低於 \(\frac12\)。

12.7 淘汰賽中誰會遇上誰

  1. 第 \(k\) 輪有 \(2^{n-k}\) 場比賽，而根據對稱性，每場比賽由 \(\binom{2^n}{2}\) 對球員中任何一對對賽的可能性都相等。把整個淘汰賽的 \(2^n - 1\) 場比賽加起來，得 \(\frac{2^n - 1}{\binom{2^n}{2}} = \frac{2}{2^n}\)。

  2. 不會：在固定的對陣表中隨機編排位置，對稱性依然保持，同樣的計數方法仍然適用。

  3. \(X\) 在第 \(k\) 輪的對手來自一組 \(2^{k-1}\) 名球員，每人從該組勝出的可能性相等。所以 \(Y\) 是該對手的概率為 \(\frac{2^{k-1}}{2^n - 1} \cdot \frac{1}{2^{k-1}} = \frac{1}{2^n - 1}\)，而 \(n\) 輪的總和是 \(\frac{n}{2^n - 1}\)。

  4. 共有 \(\binom{2n}{2} = n(2n - 1)\) 場比賽；每一對都會相遇，所以概率是 \(1\)。

12.8 Penney 遊戲

  1. HHT 只有在頭兩次擲出 HH 時才會勝出；否則在湊成 HH 之前已出現一個 T，THH 必定先出現。所以 HHT 勝出的概率是 \(\frac14\)。四人一起玩時：HH 之後，HHT 必勝；TT 之後，TTH 必勝；由 HT 和 TH 開始，HTT 和 THH 的勝出機會分別是 \(\frac23\) 和 \(\frac13\)（或倒過來），於是每名玩家的勝出概率是 \(\frac14 \cdot 1\) 或 \(\frac14\bigl(\frac23 + \frac13\bigr)\)，即 \(\frac14\)。TTH 擊敗 THH 的概率是 \(\frac23\)（第 (i) 部分）。

  2. 對於 HH：\(e_0 = 1 + \frac12e_{\mathrm{H}} + \frac12e_0\) 及 \(e_{\mathrm{H}} = 1 + \frac12e_0\)，得 \(e_0 = 6\)。對於 HT：一旦有了一個 H，便等待一個 T（平均擲兩次），而第一個 H 平均要擲兩次：共 \(4\) 次。

  3. HHH 和 TTT 分別被 THH 和 HTT 擊敗，概率為 \(\frac78\)；HHT 和 TTH 分別被 THH 和 HTT 擊敗，概率為 \(\frac34\)；其餘四個（HTH、HTT、THH、THT）分別被 HHT、HHT、TTH、TTH 擊敗，概率為 \(\frac23\)。HHH 和 TTT 最容易被擊敗。

  4. 設 \(A =\) HTT，\(B =\) HHT，各相關數（correlation）為 \(AA = 4\)、\(AB = 0\)、\(BB = 4\)、\(BA = 2\)。\(B\) 勝出的勝算是 \((AA - AB) : (BB - BA) = 4 : 2\)，即概率為 \(\frac23\)。

12.9 用不公平的硬幣作公平的決定

  1. 所需輪數服從幾何分佈（geometric distribution）：第 (i) 部分的平均值是 \(\frac{1}{p^2 + q^2}\)，而馮·諾伊曼（von Neumann）的方法（HT 或 TH）的平均值是 \(\frac{1}{2pq}\)。由於 \(p^2 + q^2 - 2pq = (p - q)^2\)，對所有 \(p \neq \frac12\)，馮·諾伊曼的方法都較慢。不過，公平的卻是它。

  2. 用馮·諾伊曼的技巧製造公平的位元（bit）。每次取兩個：\(00\)、\(01\) 和 \(10\) 分別代表三個選項，\(11\) 則表示重新開始。

  3. 把擲幣結果逐次與二進制展開式 \(\frac13 = 0.010101\ldots\) 比較（把 H 讀作 \(1\)，T 讀作 \(0\)）。在第一次出現不同的那一擲，若擲幣結果小於該位數字（T 對着 \(1\)），便宣佈「正面」，否則宣佈「反面」。這樣得出正面的概率恰好是 \(\frac13\)，平均用 \(2\) 次擲幣。

  4. 在未能決定的一輪之後，其中一面有兩個，另一面有一個，而整個過程是這兩個狀態上的馬可夫鏈（Markov chain）。解之得 \(\mathrm{P}(\text{酒店}) = \frac{p^3}{p^3 + q^3}\)，當 \(p = \frac12\) 時等於 \(\frac12\)：這時是公平的，其他情況則不然。

12.10 把繩頭繫起來

  1. 第一次打結形成一個環的概率是 \(\frac13\)（其餘三個繩端之中，有一個屬於同一條繩），而最後一次打結則必定形成一個環。環的數目：\(2\) 個的概率是 \(\frac13\)，\(1\) 個的概率是 \(\frac23\)；平均值是 \(\frac43\)。

  2. 餘下 \(k\) 條繩時，一次打結不形成環的概率是 \(1 - \frac{1}{2k - 1}\)。乘積 \(\prod_{k=2}^{n}\frac{2k - 2}{2k - 1}\) 等於 \(\frac{4^n}{2n\binom{2n}{n}}\)，約為 \(\frac{\sqrt{\pi n}}{2n} = \sqrt{\frac{\pi}{4n}}\)。

  3. 依次插入元素 \(1, 2, \ldots, n\)：元素 \(k\) 要麼開始一個新的循環（cycle）（概率 \(\frac1k\)），要麼放在之前 \(k - 1\) 個元素其中一個之後。把各指示變量加起來便得 \(H_n\)。

  4. 各次打結的成環指示變量互相獨立，概率為 \(\frac{1}{2k - 1}\)，所以方差是 \(\sum\frac{1}{2k - 1}\bigl(1 - \frac{1}{2k - 1}\bigr)\)。另外 \(\sum_{k \geq 1}\frac{1}{(2k - 1)^2} = \frac{\pi^2}{6} - \frac14 \cdot \frac{\pi^2}{6} = \frac{\pi^2}{8}\)。

12.11 郵票、杯子與 \(e\)

  1. \(\sum_{k \geq 2}\frac{k - 1}{k!}t^k = t\mathrm{e}^t - (\mathrm{e}^t - 1) = 1 + (t - 1)\mathrm{e}^t\)。求導後得 \(\mathrm{E}(N) = \mathrm{G}'(1) = \mathrm{e}\) 及 \(\mathrm{E}(N(N - 1)) = \mathrm{G}''(1) = 2\mathrm{e}\)，所以 \(\mathrm{Var}(N) = 3\mathrm{e} - \mathrm{e}^2\)。

  2. \(\mathrm{P}(N = j)\) 在 \(k = 0, \ldots, j - 1\) 的 \(\mathrm{P}(N > k)\) 中出現，即共 \(j\) 次。這裏 \(\mathrm{P}(N > k) = \frac{1}{k!}\)，所以 \(\mathrm{E}(N) = \sum\frac{1}{k!} = \mathrm{e}\)。

  3. 完全沒有改變：只有一個杯時，Jim 必定「猜」中。期望價格仍然是 \(\mathrm{e}\)。

  4. \(\int_0^1\frac{(1 - u)^2}{2}\,\mathrm{d}u = \frac16\)。一般而言，在 \(u_k = u\) 處的截面是一個按 \(1 - u\) 縮放的 \((k - 1)\) 維單純形（simplex），所以 \(V_k = V_{k-1}\int_0^1(1 - u)^{k-1}\,\mathrm{d}u = \frac{V_{k-1}}{k}\)。

12.12 何時停止尋找

  1. 若最大的在第 \(k \geq 2\) 位，你恰好在第一個雪糕是首 \(k - 1\) 個之中最大時才會得到它，概率為 \(\frac{1}{k - 1}\)。對 \(k\) 取平均得 \(\frac1n\sum_{k=2}^n\frac{1}{k - 1}\)，當 \(n = 4\) 時是 \(\frac{11}{24}\)。列出全部 \(24\) 種次序，可知得到第二、第三和第四大的概率分別是 \(\frac{7}{24}\)、\(\frac16\) 和 \(\frac{1}{12}\)。

  2. 拒絕 \(r = 0, 1, 2, 3\) 人分別給出 \(\frac14\)、\(\frac{11}{24}\)、\(\frac{5}{12}\)、\(\frac14\)。所以應拒絕一名候選人，成功概率為 \(\frac{11}{24}\)。

  3. 首 \(n\) 人之中最好的一個位列頭兩名的概率是 \(\frac nN + \frac nN\cdot\frac{N - n}{N - 1}\)，當 \(n\) 很小時接近 \(\frac nN\) 的兩倍。若頭兩名任何一個都可以接受，你便可以少看一些候選人才作決定。（以此為目標的最佳策略，成功概率約為 \(0.57\)。）

  4. 設 \(\mathrm{P}(r) = \frac rN\sum_{k=r}^{N-1}\frac1k\)：當 \(N = 10\) 時，\(r = 2, 3, 4\) 給出 \(0.366\)、\(0.399\)、\(0.398\)；當 \(N = 100\) 時，\(r = 36, 37, 38\) 給出 \(0.3710\)、\(0.3710\)、\(0.3708\)，其中 \(r = 37\) 僅僅領先。

12.13 三人決鬥

  1. Algernon 擲失後，Bertie 擲向 Cuthbert。若他擲中（\(\frac35\)），便是 Algernon 對 Bertie，由 Algernon 先擲，Bertie 勝出的概率是 \(1 - \frac{2/5}{2/5 + 3/5 - 6/25} = \frac{9}{19}\)。若他擲失，Cuthbert 會擲中 Bertie，然後除非 Algernon 先擲中（\(\frac35\)），否則 Cuthbert 勝出。所以 Bertie 勝出的概率是 \(\frac35 \cdot \frac{9}{19} = \frac{135}{475}\)，Cuthbert 則是 \(\frac25 \cdot \frac35 = \frac{114}{475}\)。

  2. 對所有 \(a < 1\) 都成立。擲失給出 \(\frac35\cdot\frac{a}{a + \frac35 - \frac35a} + \frac25a\)；擲中 Cuthbert 給出 \(1 - \frac{3/5}{3/5 + a - \frac35a}\)（這時 Bertie 先向他擲），這個值總是較小；擲中 Bertie 則給出 \(0\)。

  3. 不應該。若 Bertie 擲向 Algernon 而擲中，Cuthbert 隨即擲中 Bertie；若他擲失，Cuthbert 照樣擲中 Bertie。無論如何 Bertie 都一無所得，而擲向 Cuthbert 則有 \(\frac{27}{95}\)。

  4. \(p + (1 - p)(1 - r)p\)，它小於 \(\frac{p}{p + r - pr}\)，即整個等比級數（geometric series）之和。

12.14 混合策略

  1. 取 \(b = (\frac14, \frac12, \frac14)\)，則 \(X = Y = Z = 0\)，所以無論對方怎樣做，B 都贏得 \(0\)。對着 \((\frac13, \frac13, \frac13)\)，A 猜 \(1\)、\(2\) 和 \(3\) 的期望贏款分別是 \(-\frac13\)、\(0\) 和 \(\frac13\)，所以 A 應該每次都猜 \(3\)。

  2. 收益矩陣（payoff matrix）的對角線上是 \(0\)，其餘位置是 \(\pm1\)，把三個策略循環置換後矩陣不變，所以最優策略是 \((\frac13, \frac13, \frac13)\)。在原題中，相差 \(1\) 和相差 \(2\) 的罰則不同，所以各策略不能互換。

  3. 若 \(X\)、\(Y\)、\(Z \geq 0\) 且 \(X + 2Y + Z = 0\)，則三者都是 \(0\)。由此必有 \(b_1 = b_3\) 及 \(b_2 = 2b_3\)。

  4. 現在 \(X = -b_2 + 3b_3\)、\(Y = b_1 - b_3\) 及 \(Z = -3b_1 + b_2\)，而 \(X + 3Y + Z = 0\)。令三者都等於零，得 \((\frac15, \frac35, \frac15)\)。

12.15 滅絕還是爆發

  1. 滅絕概率（extinction probability）是 \(s = (q + ps)^2\) 在 \([0, 1]\) 內的最小根。兩個根是 \(1\) 和 \(\bigl(\frac qp\bigr)^2\)，而第二個根恰好在 \(p > \frac12\) 時小於 \(1\)。

  2. 給定 \(X_{n-1}\)，\(X_n\) 的平均值是 \(2pX_{n-1}\)，方差是 \(2pqX_{n-1}\)，所以 \(\mathrm{Var}(X_n) = \mathrm{E}(2pqX_{n-1}) + (2p)^2\mathrm{Var}(X_{n-1})\)。當 \(p = \frac12\) 時：\(\mathrm{Var}(X_n) = \mathrm{Var}(X_{n-1}) + \frac12\)，所以 \(\mathrm{Var}(X_n) = \frac n2\)。

  3. 在第 \(n\) 代或之前滅絕，表示第一代每一顆粒子的後代都在 \(n - 1\) 代之內消亡。取 \(p = \frac34\)：\(e_1 = 0.0625\)，\(e_2 \approx 0.0881\)，\(e_3 \approx 0.0999\)，遞增並趨向 \(\frac19 \approx 0.111\)。

  4. \(s = \frac14(1 + s + s^2 + s^3)\) 可因式分解為 \((s - 1)(s^2 + 2s - 1) = 0\)，所以滅絕概率是 \(\sqrt2 - 1 \approx 0.414\)。

12.16 順向與逆向的馬可夫鏈

  1. 根據對稱性 \(p_B = p_D\)；另外 \(p_A = \frac13 + \frac23p_B\)、\(p_B = \frac13p_A + \frac13p_C\) 及 \(p_C = \frac23p_B\)。所以 \(p_A = \frac{7}{15}\)。由 \(A\) 出發，不經過 \(C\) 而在 \(A\) 離開：\(x_A = \frac13 + \frac23x_B\) 及 \(x_B = \frac13x_A\)，所以 \(x_A = \frac37\)。條件概率是 \(\frac{3/7}{7/15} = \frac{45}{49}\)。

  2. 把第一行乘以 \(P\)：\((0.19, 0.33, 0.48)\)。

  3. 跡（trace）是 \(1.3\)，行列式（determinant）是 \(0.02\)，而 \(1\) 是一個特徵值（eigenvalue）（各行之和為 \(1\)）。另外兩個特徵值之和為 \(0.3\)，積為 \(0.02\)：它們是 \(0.2\) 和 \(0.1\)。

  4. \(a_1p_{12} = \frac{1}{20}\) 但 \(a_2p_{21} = \frac{1}{15}\)，所以這條鏈不是可逆的（reversible）：倒過來運行時，它的轉移概率並不相同（第 (iii) 部分的 \(q_{ij}\) 與 \(p_{ij}\) 不同）。

12.17 巴拿赫的火柴盒

  1. 若第二次伸手要拿的與第一次是同一種，她當下便發現那包已空（\(N = 2\)）；否則她拿走另一顆糖果，並在第三次伸手時發現有一包已空。所以 \(N = 2\) 或 \(3\)，概率各為 \(\frac12\)。

  2. \(n = 1\)：\(\frac12 + \frac12 = 1\)。\(n = 2\)：\(\frac{6}{16} + \frac{6}{16} + \frac{4}{16} = 1\)。

  3. \(\binom{2n - 1}{n}2^{-(2n-1)} = \frac12\binom{2n}{n} \cdot 2 \cdot 4^{-n} = \binom{2n}{n}4^{-n}\)。

  4. 就餘下的拖肥糖和薄荷糖數目作首步遞推（first-step recursion），得 \(\frac{64}{81} \approx 0.79\)。

12.18 無記憶性

  1. \(\mathrm{P}(\min > t) = \mathrm{e}^{-\lambda_1t}\mathrm{e}^{-\lambda_2t}\)。等候下一班巴士的時間服從指數分佈（exponential distribution），率為每分鐘 \(\frac{1}{15} + \frac{1}{30} = \frac{1}{10}\)，所以其中位數（median）是 \(10\ln2 \approx 6.9\) 分鐘。

  2. \(\mathrm{P}(Y \geq k) = (1 - p)^k\)，所以比值是 \((1 - p)^n\)。

  3. 包含 \(t\) 的那段間隔，由回溯至上一班巴士的時間和前望至下一班巴士的時間組成，兩者都服從平均值為 \(\frac1\lambda\) 的指數分佈（當 \(t\) 很大時），所以間隔的期望長度是 \(\frac2\lambda\)。較長的間隔較有可能包含某個指定時刻。

  4. 在 \([0, 1]\) 上為 \(\frac{\lambda\mathrm{e}^{-\lambda z}}{1 - \mathrm{e}^{-\lambda}}\)。當 \(\lambda = 1\) 時，它由約 \(1.58\) 緩緩下降至 \(0.58\)；當 \(\lambda = 5\) 時，它集中在 \(0\) 附近，由約 \(5.03\) 下降至 \(0.03\)。

12.19 平面上的隨機點

  1. 由 \(1 - \mathrm{e}^{-\pi ky^2} = \frac12\) 得中位數為 \(\sqrt{\frac{\ln2}{\pi k}} \approx \frac{0.470}{\sqrt k}\)，比平均值 \(\frac{1}{2\sqrt k}\) 略小。

  2. \(\mathrm{P}(Y_2 > y) = \mathrm{e}^{-\pi ky^2}(1 + \pi ky^2)\)，所以概率密度（density）是 \(2\pi^2k^2y^3\mathrm{e}^{-\pi ky^2}\)。

  3. 在極坐標下，\(R\) 的密度是 \(\frac{1}{2\pi\sigma^2}\mathrm{e}^{-r^2/(2\sigma^2)} \cdot 2\pi r\)。當 \(\sigma^2 = \frac{1}{2\pi k}\) 時，它與超級市場的分佈吻合。

  4. 取 \(k = 4 \times 10^{-4}\) 每 m\(^2\)，完全隨機的假設預測平均值為 \(\frac{1}{2\sqrt k} = 25\) m。觀察所得的 \(35\) m 較大，這顯示樹木是互相疏開的（競爭），而不是聚集成叢。

12.20 蒲豐投針

  1. 把針切成很多小段。相交次數的期望值具有可加性，而每一小段的貢獻與其長度成正比，所以無論 \(a\) 是多少，總和都是 \(\frac{2a}{\pi b}\)。

  2. 根據同樣的可加性（蒲豐投麵條，Buffon’s noodle），仍然是 \(\frac{2a}{\pi b}\)。

  3. 圓心與每條邊的距離都必須至少為 \(r\)：\(\frac{(s - 2r)^2}{s^2}\)。

  4. 由 \(\frac{1808}{3408} \approx \frac{5}{3\pi}\) 得 \(\pi \approx \frac{5 \times 3408}{3 \times 1808} = \frac{17\,040}{5424} = \frac{355}{113}\)：完美得令人起疑。

12.21 折斷一根棒

  1. 要組成三角形，每一段都必須短於 \(\frac12\)。在由折斷點組成的單位正方形中，這個條件劃出一個面積為 \(\frac14\) 的區域。

  2. 假設第一個折斷點在 \(x < \frac12\)（另一情況是對稱的），而較長的一段 \(1 - x\) 再被均勻地折斷。新的兩段都必須短於 \(\frac12\)，其概率為 \(\frac{x}{1 - x}\)。所以答案是 \(2\int_0^{1/2}\frac{x}{1 - x}\,\mathrm{d}x = 2\ln2 - 1\)。

  3. 當 \((2 - x - y)^2 > x^2 + y^2\)，即 \(y < \frac{2 - 2x}{2 - x}\) 時，\(C\) 處的角是鈍角。這條曲線與 \(x + y = 1\) 之間的面積是 \(\frac32 - 2\ln2\)，所以概率是 \(3 - 4\ln2\)，與 \(B\) 處的相同。這並非巧合：三條邊各自最多為 \(1\)，總和為 \(2\)，並且是均勻分佈的，所以它們可以互換。因此 \(\mathrm{P}(\text{鈍角三角形}) = 9 - 12\ln2 \approx 0.68\)。

  4. 根據容斥原理（inclusion–exclusion），最長的一段 \(M\) 滿足 \(\mathrm{P}(M > m) = 3(1 - m)^2 - 3(1 - 2m)_+^2 + (1 - 3m)_+^2\)，其中 \(x_+ = \max(x, 0)\)。在 \([0, 1]\) 上積分得 \(\mathrm{E}(M) = 1 - \frac12 + \frac19 = \frac{11}{18}\)。

12.22 沒有平均值的分佈

  1. \(\mathrm{P}(\tan\Theta \leq k) = \frac1\pi\bigl(\tan^{-1}k + \frac\pi2\bigr)\)，求導後得 \(\frac{1}{\pi(1 + k^2)}\)。

  2. 把 \(U\) 和 \(V\) 對調，徑向對稱的密度保持不變，所以 \(\frac VU\) 與 \(\frac UV\) 有相同的分佈。

  3. 密度是對稱的，所以中位數是 \(0\)；而 \(\mathrm{P}(C \leq 1) = \frac12 + \frac1\pi\tan^{-1}1 = \frac34\)。

  4. \(\frac{1}{2\pi}\mathrm{e}^{-r^2/2}\,r\,\mathrm{d}r\,\mathrm{d}\theta\)，而令 \(s = r^2\) 後這就是 \(\frac{1}{2\pi}\,\mathrm{d}\theta \cdot \frac12\mathrm{e}^{-s/2}\,\mathrm{d}s\)：角度是均勻分佈的，\(R^2\) 服從平均值為 \(2\) 的指數分佈，而且兩者獨立。

12.23 由概率得出斯特靈公式

  1. \(\sqrt{20\pi}(10/\mathrm{e})^{10} \approx 3\,598\,696\)（約低 \(0.8\%\)）及 \(\sqrt{40\pi}(20/\mathrm{e})^{20} \approx 2.4228 \times 10^{18}\)（約低 \(0.4\%\)）。

  2. \(\frac{(2n)!}{(n!)^2} \approx \frac{\sqrt{4\pi n}(2n/\mathrm{e})^{2n}}{2\pi n(n/\mathrm{e})^{2n}} = \frac{4^n}{\sqrt{\pi n}}\)。

  3. \(100\log_{10}\frac{100}{\mathrm{e}} + \frac12\log_{10}(200\pi) \approx 157.97\)，所以 \(100!\) 有 \(158\) 位數字。

  4. \(\binom{1000}{500}2^{-1000} \approx \frac{1}{\sqrt{500\pi}} \approx 0.0252\)。

12.24 中心極限定理

  1. 作卷積（convolution），得 \(\frac14\int\mathrm{e}^{-|x| - |y - x|}\,\mathrm{d}x = \frac14(1 + |y|)\mathrm{e}^{-|y|}\)。方差是 \(2 + 2 = 4\)。

  2. \(\mathrm{E}(\mathrm{e}^{\theta X}) = \frac12(\mathrm{e}^{\theta/2} + \mathrm{e}^{-\theta/2}) = \cosh\frac\theta2\)。標準化後的和 \(\frac{2}{\sqrt n}\sum X_i\) 的母函數（generating function）是 \(\cosh^n\frac{\theta}{\sqrt n}\)，其對數為 \(n\ln\bigl(1 + \frac{\theta^2}{2n} + \cdots\bigr) \to \frac{\theta^2}{2}\)。

  3. 把 \(Y\) 寫成兩個獨立的 \(\Gamma(82, 1)\) 變量之差，再作數值積分，得 \(\mathrm{P}(|Y| \geq 25) \approx 0.051\)：正態近似（normal approximation）非常準確。

  4. 它沒有矩母函數（moment generating function），甚至連平均值也沒有。事實上，\(n\) 個獨立柯西（Cauchy）變量的平均值本身也服從柯西分佈：取平均完全不會令它變得集中。

12.25 眾多之中的最大值

  1. \(n\) 個壽命之中，最先完結的一個平均需時 \(\frac{1}{n\lambda}\)；之後餘下 \(n - 1\) 個，一切重新開始，如此類推。所以 \(\mathrm{E}(Y) = \frac1\lambda\bigl(\frac1n + \frac{1}{n - 1} + \cdots + 1\bigr)\)。

  2. \(\mathrm{P}(\min > t) = (\mathrm{e}^{-\lambda t})^n = \mathrm{e}^{-n\lambda t}\)。

  3. 由 \((1 - \mathrm{e}^{-\lambda y})^n = \frac12\) 得 \(\lambda y = -\ln(1 - 2^{-1/n})\)。當 \(n = 10\) 時這是 \(2.704\)，而近似值為 \(\ln10 - \ln\ln2 \approx 2.669\)。

  4. \(\mathrm{P}(M \leq m) = m^n\)，所以 \(\mathrm{P}\bigl(n(1 - M) > s\bigr) = \bigl(1 - \frac sn\bigr)^n \to \mathrm{e}^{-s}\)。這屬於韋布爾（Weibull）型：各變量有上界，而最大值會擠向這個上界。
