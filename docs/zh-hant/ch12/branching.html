滅絕還是爆發

題目

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/03-s2-q12

引子

1873 年，高爾頓（Francis Galton）在《Educational Times》上提出一個問題：為甚麼貴族的姓氏那麼容易失傳？每個男人所生的兒子數目是隨機的，而每個兒子都會把姓氏傳下去。即使每個男人平均有多於一個兒子，這個姓氏就能永遠流傳下去嗎？這個問題開創了分支過程（branching process）的理論，如今這套理論用來模擬核連鎖反應、傳染病的擴散、細胞羣體的增長，以及突變能否存活下去。

本題建立的是最簡單的模型：每個粒子分裂成 \(0\)、\(1\) 或 \(2\) 個粒子。粒子總數的期望值（expectation）按幾何級數增長或縮減。但期望值並不是故事的全部。即使期望的粒子總數急劇膨脹，整個族系完全滅絕的概率仍然是正數，而一個漂亮的不動點（fixed point）論證就能把這個概率求出來。

動筆之前

如果某一階段有兩個粒子，下一階段粒子數目的分佈是甚麼？

兩個粒子各自獨立地產生後代，後代數目服從 \(\mathrm{B}(2, p)\)，所以總數服從 \(\mathrm{B}(4, p)\)：共有四次獨立的「機會」，每次成功的概率為 \(p\)。

逐步解題

階段 1 先是兩個，然後又是兩個

\(\mathrm{P}(X_1 = 2) = p^2\)，然後 \(\mathrm{P}(X_2 = 2 \mid X_1 = 2) = \binom42p^2q^2 = 6p^2q^2\)。所以 \[\mathrm{P}(X_1 = 2, X_2 = 2) = 6p^4q^2. \qed\]

階段 2 逆向推理

\(X_2 = 2\) 可以有多少種方式發生？（\(X_1\) 可以是甚麼？）

要使 \(X_2 = 2\)，可以是 \(X_1 = 1\)（概率為 \(2pq\)），其後產生 \(2\) 個後代（\(p^2\)）；也可以是 \(X_1 = 2\)，其後由 \(\mathrm{B}(4, p)\) 得出 \(2\) 個。（\(X_1 = 0\) 則甚麼也不剩。）所以 \(\mathrm{P}(X_2 = 2) = 2p^3q + 6p^4q^2\)，而 \[\mathrm{P}(X_1 = 2 \mid X_2 = 2) = \frac{6p^4q^2}{2p^3q + 6p^4q^2} = \frac{3pq}{1 + 3pq}.\] 令此式等於 \(\frac{9}{25}\)：\(75pq = 9 + 27pq\)，所以 \(pq = \frac{3}{16}\)，即 \(p(1 - p) = \frac{3}{16}\)，由此得 \(p = \frac14\) 或 \(p = \frac34\)。■

階段 3 粒子總數的期望值

如果在第 \(n - 1\) 階段有 \(k\) 個粒子，第 \(n\) 階段粒子數目的期望值是多少？然後對 \(k\) 取平均。

每個粒子平均有 \(\mathrm{E}(X) = 2p\) 個後代，所以 \(k\) 個粒子平均有 \(2pk\) 個後代：\(\mathrm{E}(X_n \mid X_{n-1} = k) = 2pk\)。對 \(k\) 取平均，得 \(\mathrm{E}(X_n) = 2p\,\mathrm{E}(X_{n-1})\)。由於 \(\mathrm{E}(X_0) = 1\)， \[\mathrm{E}(X_n) = (2p)^n.\] 當 \(p = \frac14\) 時，\((2p)^n = 2^{-n} \to 0\)；當 \(p = \frac34\) 時，\((2p)^n = \bigl(\frac32\bigr)^n \to \infty\)。■

回顧

  • 獨立二項變量之和。\(k\) 個粒子各自給出 \(\mathrm{B}(2, p)\)，合起來就是 \(\mathrm{B}(2k, p)\)。

  • 時間上的貝葉斯定理（Bayes’ theorem）。\(\mathrm{P}(X_1 = 2 \mid X_2 = 2)\) 是由較後的觀察結果逆向推斷較早的狀態。

  • 條件期望值（conditional expectation）。以上一代的情況為條件，期望值就化成一個等比數列（geometric sequence）。

背後的數學

滅絕的概率

當 \(p = \frac34\) 時，粒子總數的期望值無止境地增長。這是否表示羣體一定能存活下去？不一定：如果第一個粒子沒有後代（概率為 \(q^2 = \frac{1}{16}\)），這個族系便立即終結。設 \(e\) 為最終滅絕的概率。第一個粒子有 \(k\) 個後代，而每個後代的族系各自獨立地以概率 \(e\) 滅絕，所以 \[e = q^2 + 2pq\,e + p^2e^2 = (q + pe)^2 = \mathrm{G}(e),\] 其中 \(\mathrm{G}(s) = (q + ps)^2\) 是後代數目的概率生成函數（probability generating function）。滅絕概率是 \(\mathrm{G}\) 的一個不動點：事實上是最小的非負不動點。當 \(p = \frac34\) 時，由 \((1 + 3e)^2 = 16e\) 得 \(9e^2 - 10e + 1 = 0\)，所以 \(e = \frac19\) 或 \(1\)，而滅絕概率是 \(\frac19\)。當 \(p = \frac14\) 時，在 \([0, 1]\) 內唯一的不動點是 \(e = 1\)：滅絕是必然的（圖 12.15.1）。

臨界門檻

一般而言，如果後代數目的平均值小於 \(1\)，分支過程必然滅絕；平均值等於 \(1\) 時也是如此，唯一的例外是每個個體都恰好有一個後代的平凡情況（這時族系只是一個接一個地永遠延續下去）；如果平均值大於 \(1\)，則分支過程以正概率存活下去。後代數目的平均值就是流行病學中的繁殖數（reproduction number）\(R\)：\(R > 1\) 的疫症有可能大規模爆發，但即使如此，早期的爆發仍可能純粹因為偶然而無疾而終，其概率正好由上面的不動點方程給出。在核物理學中，如果每次裂變平均恰好引發另一次裂變，連鎖反應就處於臨界（critical）狀態，而操作反應堆的學問，就在於讓它一直保持在這個狀態。

高爾頓、Watson 與 Bienaymé

高爾頓的問題在 1874 年由 Henry William Watson 牧師作答，但答案有部分是錯的：他找到了不動點方程，卻漏掉了第二個根，因而斷定每個姓氏最終都會失傳。其實正確的分析早在 1845 年已由法國統計學家 Irénée-Jules Bienaymé 提出，只是他的研究一直被人遺忘，直到 1970 年代才重見天日。這個模型現在稱為高爾頓–Watson 過程（Galton–Watson process，有時稱為 Bienaymé–Galton–Watson 過程），是每一門隨機過程（random processes）課程中的核心例子。

思維技巧

以第一代為條件

一個會自我更新的過程（每個後代都開始一個獨立的、與整個過程相同的複本），必定滿足一條以第一步為條件而得出的方程。

方程 \(e = \mathrm{G}(e)\) 是一個不動點問題，與 第 2.2 節 和 第 8.7 節 中遇到的屬同一類。在大學裏，生成函數和不動點是研究分支過程、隨機樹和隨機網絡的主要工具。

延伸練習

  1. 一般情況下的滅絕。設後代數目的分佈為 \(\mathrm{B}(2, p)\)，證明當 \(p \leq \frac12\) 時滅絕概率為 \(1\)，而當 \(p > \frac12\) 時滅絕概率為 \(\bigl(\frac qp\bigr)^2\)。

  2. 方差（variance）。證明 \(\mathrm{Var}(X_n)\) 滿足 \(\mathrm{Var}(X_n) = (2p)^2\mathrm{Var}(X_{n-1}) + 2pq\,\mathrm{E}(X_{n-1})\)，並求 \(p = \frac12\) 時的方差。

  3. 在第 \(n\) 代或之前滅絕。設 \(e_n = \mathrm{P}(X_n = 0)\)。證明 \(e_n = \mathrm{G}(e_{n-1})\)，並就 \(p = \frac34\) 計算 \(e_1\)、\(e_2\)、\(e_3\)。它們是否趨近 \(\frac19\)？

  4. 姓氏。如果每個男人有 \(0\)、\(1\)、\(2\) 或 \(3\) 個兒子的概率各為 \(\frac14\)，他的姓氏最終失傳的概率是多少？

延伸閱讀

  • Geoffrey Grimmett & David Stirzaker, Probability and Random Processes（Oxford University Press），論分支過程的一節。

  • Adam Kucharski, The Rules of Contagion（Profile）。講述繁殖數與疫症爆發，適合一般讀者。

  • David Kendall, “Branching processes since 1873”，Journal of the London Mathematical Society 41 (1966)。講述這段歷史，包括 Bienaymé 的貢獻。
