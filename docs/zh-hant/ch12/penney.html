12.8

Penney 遊戲

工作紙題目連結、提示、大學數學及練習 第 12 章整章的 PDF 版本
題目

STEP III 2001，第 13 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/01-s3-q13

引子

你和朋友各自選定一個由三次擲硬幣結果組成的序列，然後不斷擲硬幣，直至其中一個序列出現為止。在任何一個時刻，每個三次投擲的序列出現的機會都相同，那麼無論選哪一個，理應同樣好吧？完全不是。無論朋友選哪個序列，你都可以選出一個勝過它的序列，勝算（odds）有時更高達 \(7\) 比 \(1\)。

這就是 Penney 遊戲（Penney’s game），由 Walter Penney 於 1969 年發明。本題要證明 \(A\) 勝 \(B\)，\(B\) 勝 \(C\)，\(C\) 勝 \(D\)，而 \(D\) 又勝 \(A\)：這是一個循環，就像包剪揼一樣。「勝過」這種關係並不具傳遞性（transitive）。長遠而言，後選的一方總能勝出。

動筆之前

假設至今的投擲結果以 TT 結尾，而且仍未有人勝出。THH 有沒有可能比 TTH 先出現？

從 TT 出發，之後每擲出一個 T，最後兩次投擲仍然是 TT，而第一個 H 一出現就湊成 TTH。要 THH 出現，必須先有 TH，而 TH 只能由一個 T 後接一個 H 而來，但這個 H 已經湊成了 TTH。所以 TT 一旦出現，\(A\) 必勝。

逐步解題

階段 1 狀態

兩個序列都不可能在兩次投擲內完成。擲了兩次之後，從每個狀態（state）出發，下一次投擲會帶來甚麼結果？

由於遊戲只取決於最後兩次投擲，我們可以追蹤狀態（即最後兩次投擲的結果）：

  • 從 TT 出發：\(A\) 勝（上面已證），所以 \(p_{\mathrm{TT}} = 1\)。

  • 從 HT 出發：下一次投擲會得出 TH 或 TT，所以 \(p_{\mathrm{HT}} = \frac12p_{\mathrm{TH}} + \frac12p_{\mathrm{TT}}\)。

  • 從 TH 出發：擲出 H 便湊成 THH（\(B\) 勝）；擲出 T 則得出 HT。所以 \(p_{\mathrm{TH}} = \frac12 \cdot 0 + \frac12p_{\mathrm{HT}}\)。

  • 從 HH 出發：擲出 H 仍是 HH；擲出 T 則得出 HT。所以 \(p_{\mathrm{HH}} = \frac12p_{\mathrm{HH}} + \frac12p_{\mathrm{HT}}\)，由此得 \(p_{\mathrm{HH}} = p_{\mathrm{HT}}\)。

階段 2 求解

把 \(p_{\mathrm{TH}} = \frac12p_{\mathrm{HT}}\) 代入 HT 的方程：\(p_{\mathrm{HT}} = \frac14p_{\mathrm{HT}} + \frac12\)，所以 \(p_{\mathrm{HT}} = \frac23\)、\(p_{\mathrm{HH}} = \frac23\) 及 \(p_{\mathrm{TH}} = \frac13\)。四個起始狀態的概率（probability）各為 \(\frac14\)，所以 \[\mathrm{P}(A \text{ 勝}) = \tfrac14\bigl(\tfrac23 + \tfrac23 + \tfrac13 + 1\bigr) = \tfrac23. \qed\]

階段 3 \(B\) 對 \(C\)

\(C\) 想要 HHT，\(B\) 想要 THH。\(C\) 在甚麼情況下勝出？（留意第一個 HH 之前緊接着的必定是甚麼。）

如果頭兩次投擲是 HH，那麼其後第一個 T 便湊成 HHT，THH 來不及出現：\(C\) 勝。否則，在 HH 首次出現之前的某處必有一個 T，因此第一個 HH 的前一次投擲必定是 T：THH 就在那一刻出現，早於 HHT（HHT 還需要在 HH 之後再擲出一個 T）。所以只有當遊戲以 HH 開始時 \(C\) 才會勝出： \[\mathrm{P}(B \text{ 勝}) = \tfrac34. \qed\]

階段 4 循環

用同樣的方法（或「背後的數學」一節的捷徑）可以證明 \(C\)（HHT）勝 \(D\)（HTT）的概率是 \(\frac23\)，而 \(D\)（HTT）勝 \(A\)（TTH）的概率是 \(\frac34\)；後者正是第 3 階段把正面與反面對調後的鏡像。所以 \[A \text{ 勝 } B, \qquad B \text{ 勝 } C, \qquad C \text{ 勝 } D, \qquad D \text{ 勝 } A. \qed\]

回顧

  • 選對狀態。只有最後兩次投擲才有影響，所以四個狀態、四條方程便概括了整個遊戲。

  • 首步分析（first-step analysis）。每條方程都是以下一次投擲為條件：從某狀態出發的概率，就是下一次投擲所到達的各個狀態的概率的平均值。

  • 找出決定性的事件。在第 3 階段，「第一個 HH 之前是 T」這一點無須列方程便決定了勝負。

背後的數學

為甚麼有些序列較好

在任何一個位置，所有三次投擲的序列出現的機會都相同，而每個序列的期望等待時間（expected waiting time）也不難計算。但各序列的等待時間並不相同：TTH 平均要等 \(8\) 次投擲，TTT 卻要等 \(14\) 次，因為與自身重疊的序列（例如 TTT，只差一步的 TTH 會令已累積的兩次投擲前功盡廢）出現得較慢。而在兩個序列的競賽中，關鍵在於每個序列與對方如何重疊。THH 勝 HHT，是因為 HHT 每次出現（除了在最開頭之外），前面都有一個 T，這表示 THH 剛剛已經出現。後選一方的竅門總是一樣：取對手序列的頭兩個符號，再在前面加上與對手中間符號相反的那個符號。

康威公式（Conway’s formula）

約翰·康威發現了一條計算勝算的絕妙公式。對於長度為 \(n\) 的兩個序列 \(X\) 和 \(Y\)，定義相關數（correlation）\(XY\) 為一個 \(n\) 位的二進制數：由左至右，若 \(X\) 中由第 \(i\) 個符號開始的部分與 \(Y\) 開頭相同長度的部分相同，則第 \(i\) 位為 \(1\)。那麼 \(Y\) 比 \(X\) 先出現的勝算是 \[(XX - XY) : (YY - YX).\] 取 \(X =\) HHT 及 \(Y =\) THH：\(XX = 100_2 = 4\)（只有整個 HHT 與自身吻合）；\(XY = 001_2 = 1\)（只有 HHT 末尾的 T 與 THH 的開頭吻合）；\(YY = 100_2 = 4\)；而 \(YX = 011_2 = 3\)（THH 末尾的 HH 和 H 都與 HHT 的開頭吻合）。所以 THH 先出現的勝算是 \((4 - 1) : (4 - 3) = 3 : 1\)，即第 3 階段的 \(\frac34\)。康威公式適用於任何長度、任何字母表的序列，其證明用到鞅（martingale）的理論：想像有一間賭場，賭客就序列的出現下注，再利用公平遊戲的期望利潤為零這一事實。

Penney 與加德納（Gardner）

Walter Penney 於 1969 年在 Journal of Recreational Mathematics 的一篇短文中介紹了這個遊戲。馬丁·加德納於 1974 年在他的 Scientific American 專欄中介紹了它，使它廣為人知，文中還包括康威公式，這條公式是康威發現的，但他一直沒有發表。這類非傳遞關係（埃弗龍骰子（Efron’s dice）是另一個例子：骰子 \(A\) 勝 \(B\)，\(B\) 勝 \(C\)，\(C\) 勝 \(D\)，而 \(D\) 勝 \(A\)）一再令人驚訝，在投票理論中也很重要，因為多數人的偏好可以形成循環：這就是孔多塞悖論（Condorcet’s paradox）。

思維技巧

首步分析

若一個過程在各狀態之間轉移，要求出與它有關的概率或期望值（expectation），可以第一步為條件。這樣每個狀態都給出一條線性方程。

這是處理馬可夫鏈（Markov chain）的基本技巧，你會在 第 12.16 節 以及大學概率課程中一再遇到。同樣的方法可以求出先到達某一狀態而非另一狀態的概率、被吸收前的期望時間，以及賭博問題中的破產概率。

延伸練習

  1. 四人同場。試做 STEP II 2015，第 12 題：四名玩家同時參與的 Penney 遊戲。

  2. 等待時間。證明直至 HH 首次出現的期望投擲次數是 \(6\)，而直至 HT 首次出現的則是 \(4\)。（使用首步分析。）

  3. 最佳對策。對於八個長度為三的序列，逐一找出以最大概率勝過它的序列。哪個序列最容易被擊敗？

  4. 康威公式。用康威公式驗證 HHT 勝 HTT 的概率是 \(\frac23\)。
