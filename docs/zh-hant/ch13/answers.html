第 13 章 · 統計與現實世界中的隨機性

延伸練習答案

以下只是簡短的答案和提示，並非完整解答：這裏只給出結果和關鍵步驟，方便你核對自己的做法。每道練習都應先認真做過，然後才看答案。

13.1 解讀新聞標題

  1. \(1 - \sum_{k=0}^{6}\mathrm{e}^{-2.96}\frac{2.96^k}{k!} \approx 0.0315\)，所以一年之中大約有 \(11\) 天會出現七宗或以上的死亡個案。\(\mathrm{P}(X \geq 9) \approx 0.0035\)：大約一年一天。

  2. 死亡人數為 \(150K\)，其中 \(K\) 服從平均值（mean）為 \(1.2\) 的泊松分佈（Poisson distribution）：平均值為 \(180\)，方差（variance）為 \(150^2 \times 1.2 = 27\,000\)，標準差（standard deviation）約為 \(164\)。死亡人數為 \(125\) 或以下的年份，就是沒有發生空難的年份，其概率為 \(e^{-1.2} \approx 0.30\)：完全是尋常事。但在這個模型中，死亡人數不可能恰好是 \(125\)，因為死亡人數只能是 \(150\) 的倍數。平均值和標準差都顯示不出這一點：個案扎堆出現，令分佈變得一團一團，全部概率都集中在 \(0\)、\(150\)、\(300\) 等數值上。

  3. \(z = \frac{1349.5 - 1080}{33} \approx 8.2\)：概率的數量級為 \(10^{-16}\)。穩定不變的發生率無法解釋 \(1350\) 這個數字；必定是有些事情真的改變了（又或者是統計死亡人數的方法改變了）。

  4. 例如：(i)「單憑總數，無法判斷乘飛機與步行哪樣較安全」；(ii)「1990 年空難死亡人數屬正常範圍」；(iii)「星期二七名行人死亡：不幸的一天，但這樣的日子一年約有十一次」；(iv)「1990 年行人死亡人數急升：必須追查原因」。

13.2 點算田鼠

  1. \(\frac{p_N}{p_{N-1}} = \frac{(N - M)(N - C)}{N(N - M - C + R)}\)，而這個比值不小於 \(1\)，當且僅當 \(NR \leq MC\)。所以 \(p_N\) 一直遞增至 \(N = \frac{MC}{R}\)，然後遞減，而最大值就在該數的整數部分取得。

  2. 從 \(a\) 名女性和 \(b\) 名男性中選出 \(c\) 人組成委員會，按其中女性的人數 \(j\) 來數：對每個 \(j\)，共有 \(\binom aj\binom{b}{c - j}\) 種。

  3. \(\frac{\mathrm{d}}{\mathrm{d}p}\bigl(h\ln p + (n - h)\ln(1 - p)\bigr) = \frac hp - \frac{n - h}{1 - p} = 0\) 給出 \(p = \frac hn\)。

  4. 當 \(R = 0\) 時，\(p_N\) 永遠遞增，估計值是無限大。這個方法只有在第二個樣本中有足夠多已標記的動物時才行得通；重複捕獲的數目少的話，估計值會非常不穩定。

13.3 德國坦克問題

  1. 設 \(M\) 為最大值，則 \(\mathrm{E}(M) = \frac{nN}{n + 1}\) 及 \(\mathrm{Var}(M) = \frac{nN^2}{(n + 1)^2(n + 2)}\)，所以 \(\mathrm{E}(M - N)^2 = \frac{2N^2}{(n + 1)(n + 2)}\)。這是 \(\mathrm{Var}(Z_1) = \frac{N^2}{n(n + 2)}\) 的 \(\frac{2n}{n + 1}\) 倍：較差。最佳的倍數是 \(c = \frac{N\mathrm{E}(M)}{\mathrm{E}(M^2)} = \frac{n + 2}{n + 1}\)，其均方誤差（mean squared error）為 \(\frac{N^2}{(n + 1)^2}\)，比 \(Z_1\) 稍佳。

  2. \(\mathrm{E}(\min) = \frac{N}{n + 1}\)，而 \(\min\) 的方差與 \(M\) 的相同，所以 \(\mathrm{Var}\bigl((n + 1)\min\bigr) = \frac{nN^2}{n + 2}\)。這個方差不會隨 \(n\) 增大而縮小：是個差劣的估計量（estimator）。

  3. 最大值不超過 \(m\)，當且僅當全部 \(k\) 個數都來自 \(\{1, \ldots, m\}\)。當 \(k = 1\) 時，估計量是 \(2X - 1\)，其平均值為 \(2 \cdot \frac{N + 1}{2} - 1 = N\)。

  4. \(98 + \frac{98}{5} - 1 = 116.6\)：大約 \(117\) 輛坦克。

13.4 平均數還是中位數？

  1. 先選定哪一個值是中位數（median）（有 \(2n + 1\) 種選法），再選定其餘各值中哪 \(n\) 個在它之下（有 \(\binom{2n}{n}\) 種選法）。所求概率為 \((2n + 1)\binom{2n}{n}y^n(1 - y)^n\,\delta y = \frac{(2n + 1)!}{(n!)^2}y^n(1 - y)^n\,\delta y\)。

  2. \(\mathrm{Var}(Y) = \frac{1}{4(2n + 3)} = \frac{1}{20}\) 及 \(\mathrm{Var}(\bar X) = \frac{1}{12(2n + 1)} = \frac{1}{36}\)。平均值較佳。

  3. \(\mathrm{Var}(\max) = \mathrm{Var}(\min) = \frac{m}{(m + 1)^2(m + 2)}\) 及 \(\mathrm{Cov}(\max, \min) = \frac{1}{(m + 1)^2(m + 2)}\)，由此得出 \(\frac{1}{2(m + 1)(m + 2)}\)。它縮小的速度與 \(\frac{1}{m^2}\) 同階，遠快於平均值的 \(\frac{1}{12m}\)：對於均勻分佈（uniform distribution）的數據，資訊都在極端值之中，與坦克問題的情況一樣。

  4. 平均值約為 \(18.6\)，被一個打字錯誤完全破壞；中位數是 \(10.1\)，不受影響。

13.5 問尷尬的問題

  1. 設 \(t = ap + bq\)，即答案屬實的概率。回答「是」的概率為 \(\frac12t + \frac12(1 - t) = \frac12\)，所以 \(\mathrm{P}(\text{正面} \mid \text{是}) = t\)，而它等於 \(\frac12\)，當且僅當 \(2t = 1\)。若由同一名孿生兒回答兩次，則不論硬幣擲出的是正面還是反面，先答「是」後答「否」的概率都是 \(pa(1 - a) + qb(1 - b)\)，所以後驗概率（posterior probability）是 \(\frac12\)。兩次都答「是」的概率分別為 \(pa^2 + qb^2\)（正面）和 \(p(1 - a)^2 + q(1 - b)^2\)（反面），兩者相等當且僅當 \(2(ap + bq) = 1\)。

  2. \(\mathrm{P}(\text{是}) = \frac34\pi + \frac14(1 - \pi)\)，所以 \(\hat\pi = \frac{0.4 - 0.25}{0.5} = 0.3\)。標準誤（standard error）為 \(\frac{\sqrt{0.4 \times 0.6/400}}{0.5} \approx 0.049\)。

  3. \(\mathrm{E}(Y^2) = \sum_c\mathrm{P}(C = c)\bigl(\mathrm{Var}(Y \mid c) + \mathrm{E}(Y \mid c)^2\bigr)\)；減去 \(\mathrm{E}(Y)^2 = \bigl(\sum_c\mathrm{P}(C = c)\mathrm{E}(Y \mid c)\bigr)^2\) 便得 \(\mathrm{E}(\mathrm{Var}(Y \mid C)) + \mathrm{Var}(\mathrm{E}(Y \mid C))\)。

  4. \(Z_2\) 接近 \(\frac n6\)（正面）或 \(\frac{5n}{6}\)（反面），兩種情況的概率各為 \(\frac12\)。所以 \(\mathrm{P}(Z_2 > \frac n2) \to \frac12\)，儘管 \(Z_2\) 幾乎從不接近 \(\frac n2\)。

13.6 累積起來的誤差

  1. 每個截尾誤差（truncation error）都在 \((-1, 0]\) 上均勻分佈；各加上 \(\frac12\) 後，便在 \((-\frac12, \frac12]\) 上均勻分佈，與四捨五入（rounding）的情況完全一樣。所以修正後的 VOZ 與 LEP 一樣好。

  2. 每個誤差都在 \((-0.05, 0.05)\) 上均勻分佈，方差為 \(\frac{0.1^2}{12}\)，所以總和的標準差為 \(\sqrt{10\,000 \times 0.01/12} \approx 2.9\)。

  3. \(3000 \times 250 \times 0.0005 = 375\) 點。

  4. 兩個誤差時，是 \([-1, 1]\) 上的 \(1 - |x|\)。三個誤差時：當 \(|x| \leq \frac12\) 時為 \(\frac34 - x^2\)，當 \(\frac12 \leq |x| \leq \frac32\) 時為 \(\frac12\bigl(\frac32 - |x|\bigr)^2\)，已經很接近正態曲線（normal curve）。

13.7 製造相關性

  1. 對於標準化變量（standardised variables），\(\mathrm{Var}(X_1 + X_2 + X_3) = 3 + 6\rho \geq 0\)，所以 \(\rho \geq -\frac12\)。對於 \(n\) 個變量，\(n + n(n - 1)\rho \geq 0\) 給出 \(\rho \geq -\frac{1}{n - 1}\)。

  2. 取 \(b = \frac{\rho_{23} - \rho_{12}\rho_{13}}{\sqrt{1 - \rho_{12}^2}}\)，則 \((1 - \rho_{12}^2)(1 - \rho_{13}^2 - b^2) = 1 - \rho_{12}^2 - \rho_{13}^2 - \rho_{23}^2 + 2\rho_{12}\rho_{13}\rho_{23} = \det R\)。由於 \(1 - \rho_{12}^2 > 0\)，這兩個條件等價。

  3. \(\mathrm{Var} = \frac14(0.04 + 0.09 + 0.12\rho)\)：當 \(\rho = -1\)、\(0\)、\(1\) 時，標準差分別為 \(0.05\)、\(0.18\) 和 \(0.25\)。除非兩隻股票完全相關（perfectly correlated），否則這個組合的風險低於兩者風險的平均值（\(0.25\)）。

  4. \(Z_2 = \dfrac{Y_2 - \rho_{12}Y_1}{\sqrt{1 - \rho_{12}^2}}\)。
