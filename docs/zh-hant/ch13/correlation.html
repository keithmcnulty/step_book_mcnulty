13.7

製造相關性

工作紙題目連結、提示、大學數學及練習 第 13 章整章的 PDF 版本
題目

STEP III 2010，第 13 題

繼續之前，請先閱讀題目（原題為英文）。題目載於 STEP Support Programme 的題目資料庫： step.maths.org/questions/10-s3-q13

引子

一間銀行想知道，手上的股票投資組合（portfolio）有多大機會虧蝕。股價往往一起變動：一隻股票下跌，其他股票也傾向跟着下跌。要模擬數以千計的可能未來，銀行必須產生一批隨機數，而這些隨機數之間的相關程度要恰到好處。如果手上只有互相獨立（independent）的隨機變量（random variable），怎樣才能製造出具有指定相關係數（correlation）的隨機變量呢？

這道題就三個變量的情形，一步一步給出了配方。每個新變量都是先前各個獨立材料的組合，再加上一份全新的獨立材料，用來補足方差（variance）。這個構造其實是線性代數（linear algebra）中一個著名結果的化身，即科列斯基分解（Cholesky decomposition），它同時揭示了一個隱藏的限制：並非每一組相關係數都有可能出現。

關於課程範圍的說明

協方差（covariance）和相關係數已於 2019 年從 STEP 的考試範圍中刪去。協方差是 \(\mathrm{Cov}(U, V) = \mathrm{E}(UV) - \mathrm{E}(U)\mathrm{E}(V)\)；獨立變量的協方差為零，而且協方差對每個變元都是線性的：\(\mathrm{Cov}(aU + bV, W) = a\,\mathrm{Cov}(U, W) + b\,\mathrm{Cov}(V, W)\)。此外 \(\mathrm{Var}(U) = \mathrm{Cov}(U, U)\)。相關係數必定介乎 \(-1\) 與 \(1\) 之間。

動筆之前

\(Z_1\) 和 \(Z_2\) 互相獨立。它們的協方差是多少？相關係數又是多少？

獨立變量滿足 \(\mathrm{E}(Z_1Z_2) = \mathrm{E}(Z_1)\,\mathrm{E}(Z_2)\)。所以協方差是 \(0\)，而 \(\mathrm{Corr}(Z_1, Z_2) = 0\)。

逐步解題

階段 1 兩個變量

\(\mathrm{E}(Y_2) = 0\)。由於 \(Z_1\) 和 \(Z_2\) 互相獨立，方差均為 \(1\)， \[\mathrm{Var}(Y_2) = \rho_{12}^2 + (1 - \rho_{12}^2) = 1, \qquad \mathrm{Cov}(Y_1, Y_2) = \mathrm{Cov}\bigl(Z_1, \rho_{12}Z_1 + \sqrt{1 - \rho_{12}^2}\,Z_2\bigr) = \rho_{12}.\] 兩個方差都是 \(1\)，所以 \(\mathrm{Corr}(Y_1, Y_2) = \rho_{12}\)。■

把 \(Z_1\) 和 \(Z_2\) 想像成互相垂直的單位向量。\(Y_2\) 在哪裏？\(Y_1\) 與 \(Y_2\) 之間夾角的餘弦是多少？

\(Y_2 = \rho_{12}Z_1 + \sqrt{1 - \rho_{12}^2}\,Z_2\) 是一個單位向量，與 \(Z_1 = Y_1\) 的夾角為 \(\theta\)，其中 \(\cos\theta = \rho_{12}\)。把變量看成向量，相關係數就是它們之間夾角的餘弦（圖 13.7.1）。

階段 2 第三個變量

試以 \(a\)、\(b\)、\(c\) 寫出 \(\mathrm{Var}(Y_3) = 1\)、\(\mathrm{Cov}(Y_1, Y_3) = \rho_{13}\)、\(\mathrm{Cov}(Y_2, Y_3) = \rho_{23}\) 這三個條件。

利用線性和獨立性： \[a^2 + b^2 + c^2 = 1, \qquad a = \rho_{13}, \qquad \rho_{12}a + \sqrt{1 - \rho_{12}^2}\,b = \rho_{23}.\] 所以 \[a = \rho_{13}, \qquad b = \frac{\rho_{23} - \rho_{12}\rho_{13}}{\sqrt{1 - \rho_{12}^2}}, \qquad c = \sqrt{1 - \rho_{13}^2 - \frac{(\rho_{23} - \rho_{12}\rho_{13})^2}{1 - \rho_{12}^2}}. \qed\] （由於 \(c \geq 0\)，這裏取非負平方根。）

階段 3 任意的均值和方差

縮放和平移都不會改變相關係數，所以 \[X_i = \mu_i + \sigma_iY_i \qquad (i = 1, 2, 3)\] 的均值為 \(\mu_i\)，方差為 \(\sigma_i^2\)，相關係數為 \(\rho_{ij}\)。■

\(c\) 的公式要求平方根內的量非負。試取 \(\rho_{12} = \rho_{13} = \rho_{23} = -0.6\)。哪裏出了問題？三個變量不可能兩兩之間都有很強的負相關，為甚麼這是合理的？

回顧

  • 每次只構造一個變量。每個新變量都從先前的材料中取用適當的份量，再加入一份全新的獨立材料。

  • 協方差是線性的。所有條件都化成了關於係數的簡單方程。

  • 相關係數是餘弦。把標準化後的變量看成單位向量，相關係數就變成了夾角。

背後的數學

科列斯基分解

用矩陣形式來寫，這個構造就是 \(\mathbf{Y} = L\mathbf{Z}\)，其中的矩陣是下三角（lower triangular）矩陣 \[L = \begin{pmatrix} 1 & 0 & 0 \\ \rho_{12} & \sqrt{1 - \rho_{12}^2} & 0 \\ a & b & c \end{pmatrix},\] 而 \(\mathbf{Y}\) 的相關矩陣（correlation matrix）是 \(R = LL^{\mathsf T}\)。把一個對稱矩陣寫成 \(LL^{\mathsf T}\) 的形式，就是科列斯基分解，由法國軍事工程師科列斯基（André-Louis Cholesky）約於 1910 年發現，用來求解大地測量中的方程組（他在第一次世界大戰中陣亡，這項成果在他身後才發表）。只要 \(R\) 是正定（positive definite）的，這個分解就行得通，而計算過程正是我們剛才用手做的：逐行求解。在金融、工程和氣候模型中，這是模擬相關變量的標準方法。

哪些相關係數是可能的？

\(c\) 的平方根內的數必須非負。展開後，條件是 \[1 - \rho_{12}^2 - \rho_{13}^2 - \rho_{23}^2 + 2\rho_{12}\rho_{13}\rho_{23} \geq 0,\] 這正是相關矩陣的行列式（determinant）非負的條件。從幾何上看：三個單位向量兩兩之間的夾角為 \(\theta_{ij}\)（其中 \(\cos\theta_{ij} = \rho_{ij}\)），它們必須真的能在空間中拼合起來。如果 \(\rho_{12} = \rho_{13} = \rho_{23} = -0.6\)，各個夾角都約為 \(127^\circ\)，而三個兩兩相隔 \(127^\circ\) 的向量，夾角之和就要超過 \(360^\circ\)：這是不可能的。一般而言，一個矩陣要成為相關矩陣，必須是半正定（positive semi-definite）的，即所有特徵值（eigenvalue）均非負（第 7.2 節）。如果各個相關係數是根據不完整的數據分別估計出來的，這個條件就可能不成立，統計學家於是要找出最接近的有效相關矩陣，這個問題由 Nicholas Higham 在 2002 年解決。

高爾頓、皮爾遜與相關係數

高爾頓（Francis Galton）在 1888 年研究父母與子女身高的關係時引入了相關的概念，而皮爾遜（Karl Pearson）在 1896 年給出了本題所用的積矩（product moment）公式。高爾頓還注意到均值回歸（regression to the mean）的現象（第 13.1 節）。皮爾遜於 1911 年在倫敦大學學院（University College London）創立了全世界第一個大學統計學系。「相關不等於因果」這句警告，幾乎與相關係數本身一樣古老。

思維技巧

逐步構造，每次加入全新的獨立材料

要構造具有指定關係的對象，可以逐個加入，每一個都是先前各個對象的組合，再加上一些全新而獨立的東西。

這是線性代數中的格拉姆–施密特（Gram–Schmidt）正交化過程倒過來做，也就是科列斯基分解。在大學裏，它會出現在最小二乘法（least squares）、多元正態分佈（multivariate normal distribution）的理論，以及隨機過程的模擬之中。

延伸練習

  1. 不可能的相關係數。證明：除非 \(\rho \geq -\frac12\)，否則三個隨機變量不可能兩兩之間的相關係數都是 \(\rho\)。對於 \(n\) 個變量，相應的結論是甚麼？

  2. 檢查行列式。證明 \(1 - \rho_{13}^2 - b^2 \geq 0\) 等價於 \(\det R \geq 0\)，其中 \(R\) 是 \(3 \times 3\) 相關矩陣。

  3. 投資組合的風險。兩隻股票回報的標準差（standard deviation）分別為 \(\sigma_1 = 0.2\) 和 \(\sigma_2 = 0.3\)，相關係數為 \(\rho\)。若投資組合中兩隻股票各佔一半，求 \(\rho = -1\)、\(0\) 和 \(1\) 時該組合的標準差。分散投資達到了甚麼效果？

  4. 還原材料。給定題目中的 \(Y_1\)、\(Y_2\)，試以 \(Y_1\) 和 \(Y_2\) 表示 \(Z_2\)。（這就是格拉姆–施密特過程中的一步。）

延伸閱讀

  • Gilbert Strang, Introduction to Linear Algebra（Wellesley-Cambridge），講述正定矩陣和科列斯基分解。

  • Paul Glasserman, Monte Carlo Methods in Financial Engineering（Springer）。講述實際應用中如何模擬相關變量；內容較深，但開頭幾章不難讀。

  • Theodore Porter, Karl Pearson: The Scientific Life in a Statistical Age（Princeton University Press）。
