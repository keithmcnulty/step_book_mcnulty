私隱

Beyond STEP 是一本免費書籍。閱讀時毋須登記帳戶，本網站亦不會索取或儲存任何個人資料。

分析工具

如果你同意，本網站會使用 Google Analytics（評估 ID：G-M8RDPR4MXR）統計瀏覽情況：哪些頁面有人閱讀、哪些 PDF 及工作紙被下載、訪客在網站內搜尋甚麼，以及訪客的大致來源（國家、裝置類型、連結至本站的網站）。為此，Google Analytics 會在你的瀏覽器內設置 cookie。這些資料只會用於了解本書哪些部分有用，以及用於改善本書；不會用於廣告用途，亦不會與任何其他數據合併。

英國法律（《私隱及電子通訊規例》（Privacy and Electronic Communications Regulations）及英國《通用數據保障條例》（UK GDPR））規定，在設置分析 cookie 等非必要 cookie 之前，必須先取得同意，因此本網站會先徵求你的同意。除非你選擇「接受」，否則本網站不會收集任何資料。如果你選擇「拒絕」，或者沒有作出選擇，Google Analytics 的程式碼便絕不會載入，亦不會設置任何分析 cookie。你的選擇會儲存在瀏覽器的本機儲存空間內，這樣便毋須在每一頁再次詢問。

你可以隨時透過每頁底部的 cookie 設定連結更改決定；撤回同意後，分析 cookie 會被移除。Google 本身的私隱權政策載於 policies.google.com/privacy。

電子通訊

首頁的登記欄只會在你按下「訂閱」時，才把你輸入的電郵地址傳送至營運 The STEP Up 的 Substack。在此之前，本網站不會從 Substack 載入任何內容。Substack 本身的私隱政策載於 substack.com/privacy。

網站寄存

本網站寄存於 GitHub Pages。與任何網頁伺服器一樣，GitHub Pages 會基於保安理由，在伺服器記錄中記下 IP 位址等基本技術資料。詳情請參閱 GitHub 的私隱聲明。數學公式以 MathJax 顯示，搜尋頁面則使用 MiniSearch 程式庫；兩者均從 jsDelivr 內容傳遞網絡載入。
