詳細解答

1987 至 2025 年每一道 STEP 題目的詳細解答，每份均為可列印的 PDF。

打開解答之前，請先認真嘗試解題：STEP 的收穫來自苦思的過程，太早看解答，所學到的遠不及苦思一小時後才看那麼多。每份解答均以關鍵思路開首，因此你可以只讀這一部分，然後回到題目再試。

本站不會轉載題目本身。每個題目連結均通往官方來源：2018 年或以前的試卷連往 STEP Support Programme 的題目資料庫，2019 年起的試卷則連往 OCR 的下載頁面（該年度試卷的 zip 檔案）。如果某道題目在書中有完整的引導式講解，§ 連結會帶你前往該節，當中有提示、工作紙及題目背後的大學數學。

每一年的解答亦另有合訂本，附有封面、目錄，以及該年度試卷的全部解答：請使用該年度標題下方的連結。

每個答案均已用數值方法核對，但解答數量如此之多，難免會有疏漏：如果發現有可疑之處，請相信自己的演算，並仔細檢查。 如有更正，非常歡迎以 GitHub issues 的形式提出。
