數學符號

下載 PDF專為列印而排版

數學寫作往往以寥寥幾個記號承載豐富的意思，而大學講師所用的許多符號，在中學課本裏甚少出現。下面各表按主題列出本書用到的符號，並說明每個符號的含義和讀法。入讀大學後不出幾個星期，其中大部分都會變得習以為常；在此之前，這裏可供你隨時查閱。

有兩項慣例值得一開始就知道。第一，本書依照 STEP 的做法，把某些具有固定含義的字母印成正體而非斜體：\(\mathrm{e}\) 表示自然對數的底，\(\mathrm{i}\) 表示 \(\sqrt{-1}\)，\(\mathrm{d}y/\mathrm{d}x\) 中的 \(\mathrm{d}\)，以及函數的名稱，例如 \(\mathrm{f}(x)\) 和 \(\mathrm{P}(A)\)。斜體字母則表示變數。第二，同一個符號在不同場合有時會有不同的意思；\(\equiv\) 和 \(\sim\) 是最常見的例子，表中會在相應位置指出。

邏輯與證明

符號 含義 例子或讀法
\(P \Rightarrow Q\) \(P\) 蘊含（implies）\(Q\)：若 \(P\) 成立，則 \(Q\) 亦成立 \(x = 2 \Rightarrow x^2 = 4\)；「\(P\) 蘊含 \(Q\)」
\(P \Leftarrow Q\) \(P\) 由 \(Q\) 所蘊含 「只要 \(Q\) 成立，\(P\) 就成立」
\(P \iff Q\) \(P\) 當且僅當（if and only if）\(Q\)：兩者互相蘊含 \(x^2 = 4 \iff x = \pm2\)；亦寫作「iff」
\(\forall\) 對所有、對每一個 \(\forall x \in \mathbb{R},\ x^2 \geq 0\)
\(\exists\) 存在 \(\exists\, n \in \mathbb{Z}\) 使得 \(n^2 = 9\)
\(\neg P\) 非 \(P\)，即 \(P\) 的否定（negation） 「\(\forall x,\ P(x)\)」的否定是「\(\exists\, x\) 使得 \(\neg P(x)\)」
\(:=\) 定義為 \(\mathrm{f}(x) := x^2 + 1\)
\(\blacksquare\) 證明完畢；亦寫作 QED 源自拉丁文 quod erat demonstrandum，意即「這就是所要證明的」

集合與數系

符號 含義 例子或讀法
\(\{\,\ldots\}\) 由所列元素組成的集合（set） \(\{1, 2, 3\}\)
\(\{x : \ldots\}\) 所有滿足 … 的 \(x\) 所組成的集合；亦寫作 \(\{x \mid \ldots\}\) \(\{x : x^2 < 2\}\)；「滿足 \(x^2 < 2\) 的 \(x\) 所組成的集合」
\(x \in A\) \(x\) 是 \(A\) 的元素（element） \(\sqrt2 \in \mathbb{R}\)；「\(\sqrt2\) 屬於 \(\mathbb{R}\)」
\(x \notin A\) \(x\) 不是 \(A\) 的元素 \(\sqrt2 \notin \mathbb{Q}\)
\(A \subseteq B\) \(A\) 是 \(B\) 的子集（subset）：\(A\) 的每個元素都在 \(B\) 之內 \(\mathbb{Z} \subseteq \mathbb{Q}\)
\(A \cup B\) 併集（union）：屬於 \(A\) 或 \(B\)（或同時屬於兩者）的元素 \(\{1, 2\} \cup \{2, 3\} = \{1, 2, 3\}\)
\(A \cap B\) 交集（intersection）：同時屬於 \(A\) 和 \(B\) 的元素 \(\{1, 2\} \cap \{2, 3\} = \{2\}\)
\(A \setminus B\) 屬於 \(A\) 但不屬於 \(B\) 的元素 \(\{1, 2, 3\} \setminus \{2\} = \{1, 3\}\)
\(A'\) 補集（complement）：所有不屬於 \(A\) 的元素 亦寫作 \(A^\mathrm{c}\) 或 \(\bar A\)
\(\varnothing\) 空集（empty set），不含任何元素 \(\{x \in \mathbb{R} : x^2 < 0\} = \varnothing\)
\(|A|\) 有限集 \(A\) 的元素個數 \(|\{a, b, c\}| = 3\)
\(A \times B\) 所有數對 \((a, b)\) 所組成的集合，其中 \(a \in A\)，\(b \in B\) \(\mathbb{R} \times \mathbb{R}\) 就是平面，亦寫作 \(\mathbb{R}^2\)
\(\mathbb{N}\) 自然數（natural numbers）\(1, 2, 3, \ldots\) 有些作者把 \(0\) 也算在內
\(\mathbb{Z}\) 整數（integers）\(\ldots, -2, -1, 0, 1, 2, \ldots\) 源自德文 Zahlen，意即「數」
\(\mathbb{Q}\) 有理數（rational numbers），即分數 源自 quotient 一字
\(\mathbb{R}\) 實數（real numbers）
\(\mathbb{C}\) 複數（complex numbers）
\(\mathbb{H}\) 四元數（quaternions） 以哈密頓（Hamilton）命名（第 6.7 節）
\(\mathbb{Z}[\mathrm{i}]\) 形如 \(a + b\mathrm{i}\) 的數，其中 \(a, b \in \mathbb{Z}\) 高斯整數（Gaussian integers）（第 1.6 節）
\([a, b]\) 閉區間（closed interval）：\(a \leq x \leq b\) 包含端點
\((a, b)\) 開區間（open interval）：\(a < x < b\) 不包含端點；亦可表示數對或點

數、整除性與近似

符號 含義 例子或讀法
\(a \mid b\) \(a\) 整除（divides）\(b\)：\(b\) 是 \(a\) 的整數倍 \(3 \mid 12\)；「\(3\) 整除 \(12\)」
\(a \nmid b\) \(a\) 不整除 \(b\) \(5 \nmid 12\)
\(a \equiv b \pmod n\) \(a\) 與 \(b\) 除以 \(n\) 所得的餘數相同 \(17 \equiv 2 \pmod 5\)；「\(17\) 與 \(2\) 模 \(5\) 同餘（congruent）」
\(\equiv\) （不帶模時）恆等於：對所有值都成立 \((x + 1)^2 \equiv x^2 + 2x + 1\)
\(\lfloor x \rfloor\) 下取整（floor）：\(\leq x\) 的最大整數 \(\lfloor 3.7 \rfloor = 3\)，\(\lfloor -3.7 \rfloor = -4\)
\(\lceil x \rceil\) 上取整（ceiling）：\(\geq x\) 的最小整數 \(\lceil 3.2 \rceil = 4\)
\(n!\) \(n\) 的階乘（factorial），即 \(1 \times 2 \times \cdots \times n\) 按慣例 \(0! = 1\)
\(\binom{n}{r}\) 二項式係數（binomial coefficient）\(\frac{n!}{r!\,(n - r)!}\) 讀作「\(n\) choose \(r\)」；亦寫作 \({}^n\mathrm{C}_r\)
\(\approx\) 約等於 \(\pi \approx 3.1416\)
\(\sim\) 漸近於（asymptotic to）：兩者之比趨向 \(1\) \(n! \sim \sqrt{2\pi n}\,(n/\mathrm{e})^n\)（但另見概率部分）
\(\propto\) 與……成正比 \(v \propto 1/d\)
\(\pm\), \(\mp\) 正負；負正 \(\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B\)
\(0.\overline{01}\) 循環數字 \(0.\overline{01} = 0.010101\ldots\)

函數

符號 含義 例子或讀法
\(\mathrm{f} : A \to B\) \(\mathrm{f}\) 是由集合 \(A\) 到集合 \(B\) 的函數（function） \(\mathrm{f} : \mathbb{R} \to \mathbb{R}\)
\(x \mapsto \ldots\) \(x\) 被送到 … \(x \mapsto x^2 - 2\)；「\(x\) 映射到 \(x^2 - 2\)」
\(\mathrm{f} \circ \mathrm{g}\) 複合（composition）：先作 \(\mathrm{g}\)，再作 \(\mathrm{f}\) \((\mathrm{f} \circ \mathrm{g})(x) = \mathrm{f}(\mathrm{g}(x))\)
\(\mathrm{f}^{-1}\) \(\mathrm{f}\) 的反函數（inverse function） 並非 \(1/\mathrm{f}\)
\(\mathrm{f}^n\) 在本書中，通常指把 \(\mathrm{f}\) 施行 \(n\) 次 \(\mathrm{f}^3(x) = \mathrm{f}(\mathrm{f}(\mathrm{f}(x)))\)；但 \(\sin^2 x\) 表示 \((\sin x)^2\)
\(|x|\) 模（modulus），或絕對值 \(|-3| = 3\)
\(\exp x\) 指數函數（exponential function）\(\mathrm{e}^x\)
\(\ln x\) 自然對數（natural logarithm），以 \(\mathrm{e}\) 為底 在大學裏常寫作 \(\log x\)
\(\sec\), \(\mathrm{cosec}\), \(\cot\) \(1/\cos\), \(1/\sin\), \(1/\tan\)
\(\arcsin\), \(\arccos\), \(\arctan\) 反三角函數 亦寫作 \(\sin^{-1}\) 等
\(\sinh\), \(\cosh\), \(\tanh\) 雙曲函數（hyperbolic functions）：\(\sinh x = \frac12(\mathrm{e}^x - \mathrm{e}^{-x})\)，\(\cosh x = \frac12(\mathrm{e}^x + \mathrm{e}^{-x})\)，\(\tanh = \sinh/\cosh\) 讀作「shine」（或「sinch」）、「cosh」和「than」（或「tanch」）
\(\operatorname{artanh}\) \(\tanh\) 的反函數 \(\operatorname{artanh} x = \frac12\ln\frac{1 + x}{1 - x}\)
\(\max\), \(\min\) 當中最大者、最小者 \(\max(3, 7) = 7\)
\(\Gamma(x)\) 伽瑪函數（gamma function） \(\Gamma(n + 1) = n!\)（第 4.4 節）

求和、極限與微積分

符號 含義 例子或讀法
\(\sum\) 求和 \(\sum_{k=1}^n k = \frac12n(n + 1)\)
\(\prod\) 求積 \(\prod_{k=1}^n k = n!\)
\(\infty\) 無窮大：並不是一個數，而是「沒有界限」的簡寫 \(\sum_{k=1}^\infty \frac1{k^2} = \frac{\pi^2}{6}\)
\(x \to a\) \(x\) 趨向 \(a\) 當 \(n \to \infty\) 時，\(\frac1n \to 0\)
\(\lim\) 極限（limit） \(\lim_{x\to0}\frac{\sin x}{x} = 1\)
\(\mathrm{f}'(x)\), \(\mathrm{f}''(x)\) 一階及二階導數（derivative） 讀作「f dash」或「f prime」
\(\dot x\), \(\ddot x\) 對時間的導數 \(\dot x = \frac{\mathrm{d}x}{\mathrm{d}t}\)；讀作「\(x\) dot」、「\(x\) double dot」
\(\frac{\partial f}{\partial x}\) 偏導數（partial derivative）：對 \(x\) 求導，其他變數保持不變 讀作「partial \(f\) by partial \(x\)」
\(\int_a^b\) 由 \(a\) 到 \(b\) 的定積分（definite integral）
\(\oint\) 沿閉合迴路的積分 \(\oint p\,\mathrm{d}q\)（第 10.4 節）
\(\delta x\), \(\Delta x\) \(x\) 的微小變化；\(x\) 的變化
\(\varepsilon\), \(\delta\) 分析學中慣常用來表示細小正數的記號 「對每個 \(\varepsilon > 0\)，都存在 \(\delta > 0\) 使得 …」

複數

符號 含義 例子或讀法
\(\mathrm{i}\) \(-1\) 的一個平方根 工程師寫作 \(\mathrm{j}\)
\(\operatorname{Re} z\), \(\operatorname{Im} z\) 實部與虛部 若 \(z = 3 + 4\mathrm{i}\)，則 \(\operatorname{Re} z = 3\)，\(\operatorname{Im} z = 4\)
\(z^*\), \(\bar z\) 共軛複數（complex conjugate） \((3 + 4\mathrm{i})^* = 3 - 4\mathrm{i}\)；兩種記法都有人使用
\(|z|\) 模：與 \(0\) 的距離 \(|3 + 4\mathrm{i}| = 5\)
\(\arg z\) 輻角（argument）：由正實軸量起的角 \(\arg \mathrm{i} = \frac\pi2\)
\(\mathrm{e}^{\mathrm{i}\theta}\) \(\cos\theta + \mathrm{i}\sin\theta\) \(\mathrm{e}^{\mathrm{i}\pi} = -1\)
\(\omega\) 慣常表示 1 的一個複立方根（cube root of unity） \(\omega = \mathrm{e}^{2\pi\mathrm{i}/3}\)，\(1 + \omega + \omega^2 = 0\)

向量與矩陣

符號 含義 例子或讀法
\(\mathbf{a}\), \(\overrightarrow{AB}\) 向量（vector）；由 \(A\) 到 \(B\) 的向量 手寫時作 \(\underline{a}\)
\(\hat{\mathbf{n}}\) 單位向量（unit vector），長度為 \(1\) 讀作「\(n\) hat」
\(|\mathbf{a}|\) \(\mathbf{a}\) 的長度（大小）
\(\mathbf{a} \cdot \mathbf{b}\) 純量積（scalar product），又稱點積（dot product） \(\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos\theta\)
\(\mathbf{a} \times \mathbf{b}\) 向量積（vector product），又稱叉積（cross product） 同時垂直於 \(\mathbf{a}\) 和 \(\mathbf{b}\)
\(\mathbf{M}\) 矩陣（matrix）
\(\mathbf{I}\) 單位矩陣（identity matrix） 對每個 \(\mathbf{v}\) 都有 \(\mathbf{I}\mathbf{v} = \mathbf{v}\)
\(\mathbf{M}^{-1}\) 逆矩陣（inverse matrix） \(\mathbf{M}\mathbf{M}^{-1} = \mathbf{I}\)
\(\det \mathbf{M}\) \(\mathbf{M}\) 的行列式（determinant） \(\det\begin{pmatrix} a & b \\ c & d\end{pmatrix} = ad - bc\)
\(\operatorname{tr} \mathbf{M}\) 跡（trace）：對角線上各元素之和 \(\operatorname{tr}\begin{pmatrix} a & b \\ c & d\end{pmatrix} = a + d\)
\(\lambda\) 慣常表示特徵值（eigenvalue） \(\mathbf{M}\mathbf{v} = \lambda\mathbf{v}\)

概率與統計

符號 含義 例子或讀法
\(\mathrm{P}(A)\) 事件 \(A\) 的概率（probability）
\(\mathrm{P}(A \mid B)\) 已知 \(B\) 發生時 \(A\) 的概率 \(\mathrm{P}(A \mid B) = \mathrm{P}(A \cap B)/\mathrm{P}(B)\)；讀作「\(A\) given \(B\)」
\(\mathrm{E}(X)\) \(X\) 的期望值（expectation），即平均值 亦寫作 \(\mu\)
\(\mathrm{Var}(X)\) \(X\) 的方差（variance） \(\mathrm{E}(X^2) - \mathrm{E}(X)^2\)；亦寫作 \(\sigma^2\)
\(\mathrm{Cov}(X, Y)\) 協方差（covariance） \(\mathrm{E}(XY) - \mathrm{E}(X)\mathrm{E}(Y)\)
\(\mathrm{Corr}(X, Y)\) 相關係數（correlation） \(\mathrm{Cov}(X, Y)/\sqrt{\mathrm{Var}(X)\mathrm{Var}(Y)}\)；亦寫作 \(\rho\)
\(X \sim \ldots\) \(X\) 的分佈為 … \(X \sim \mathrm{B}(16, \frac12)\)；「\(X\) 的分佈為 …」
\(\mathrm{B}(n, p)\) 二項分佈（binomial distribution） \(n\) 次試驗中成功的次數
\(\mathrm{N}(\mu, \sigma^2)\) 正態分佈（normal distribution），平均值為 \(\mu\)，方差為 \(\sigma^2\)
\(\mathrm{f}(x)\), \(\mathrm{F}(x)\) 概率密度函數（probability density function）；累積分佈函數（cumulative distribution function） \(\mathrm{F}(x) = \mathrm{P}(X \leq x)\)
\(\mathrm{G}(t)\) 概率生成函數（probability generating function） \(\mathrm{G}(t) = \mathrm{E}(t^X)\)
\(\mathrm{M}_X(\theta)\) 矩生成函數（moment generating function） \(\mathrm{M}_X(\theta) = \mathrm{E}(\mathrm{e}^{\theta X})\)
\(\bar x\) 樣本的平均值 \(\bar x = \frac1n\sum x_i\)
\(\hat\theta\) 未知量 \(\theta\) 的估計值 讀作「theta hat」

希臘字母

希臘字母在數學中隨處可見，而且往往有約定俗成的含義。下表列出各字母的小寫和大寫形式（與羅馬字母外形相同的大寫字母，例如 alpha 的大寫 A，不會用作獨立的符號，故此從略）、名稱，以及一些常見用途。

字母 名稱 常見用途
\(\alpha\) alpha 角；方程的根
\(\beta\) beta 角；方程的根；貝塔函數（beta function）
\(\gamma\), \(\Gamma\) gamma 歐拉（Euler）常數 \(\gamma \approx 0.5772\)；伽瑪函數 \(\Gamma\)；在相對論中，\(\gamma = 1/\sqrt{1 - v^2/c^2}\)
\(\delta\), \(\Delta\) delta 微小的量；\(\Delta\) 表示變化，或表示三角形、判別式（discriminant）
\(\varepsilon\), \(\epsilon\) epsilon 微小的正數量；在力學中表示相位角
\(\zeta\) zeta 黎曼（Riemann）zeta 函數，當 \(s > 1\) 時 \(\zeta(s) = \sum_{n=1}^\infty n^{-s}\)（以更高深的方法可推廣至 \(s = 1\) 以外的其他值）
\(\eta\) eta 效率；微小的量
\(\theta\), \(\Theta\) theta 角；統計學中的未知參數
\(\iota\) iota 甚少使用
\(\kappa\) kappa 曲率；常數
\(\lambda\), \(\Lambda\) lambda 特徵值；參數，例如泊松（Poisson）分佈的率；波長
\(\mu\) mu 平均值；摩擦係數
\(\nu\) nu 頻率
\(\xi\), \(\Xi\) xi 變數或隨機量
\(\pi\), \(\Pi\) pi \(\pi \approx 3.14159\)；\(\Pi\) 表示求積
\(\rho\) rho 密度；相關係數；與原點的距離
\(\sigma\), \(\Sigma\) sigma 標準差；\(\Sigma\) 表示求和
\(\tau\) tau 時間；力矩
\(\upsilon\), \(\Upsilon\) upsilon 甚少使用
\(\phi\), \(\varphi\), \(\Phi\) phi 角；黃金比 \(\phi = \frac12(1 + \sqrt5)\)；快度（rapidity）；\(\Phi\) 表示標準正態分佈函數
\(\chi\) chi \(\chi^2\)（卡方，chi-squared）分佈
\(\psi\), \(\Psi\) psi 量子力學中的波函數
\(\omega\), \(\Omega\) omega 角速度或角頻率；1 的立方根；\(\Omega\) 表示樣本空間

力學

符號 含義 例子或讀法
\(g\) 重力加速度 在地球表面約為 \(9.8\,\mathrm{m\,s^{-2}}\)
\(G\) 萬有引力常數 兩個質量之間的力為 \(Gm_1m_2/r^2\)
\(e\) 恢復係數（coefficient of restitution）（以斜體印刷，切勿與 \(\mathrm{e}\) 混淆） 沿碰撞線方向，分離速率 \(= e \times\) 接近速率
\(\omega\) 角速度；角頻率 簡諧運動（simple harmonic motion）中 \(\ddot x = -\omega^2x\)
\(I\) 轉動慣量（moment of inertia） 轉動動能 \(\frac12I\omega^2\)（第 11.7 節）
\(c\) 光速 約為 \(3 \times 10^8\,\mathrm{m\,s^{-1}}\)
\(\hbar\) 普朗克（Planck）常數除以 \(2\pi\) 讀作「h bar」（第 8.6 節）
